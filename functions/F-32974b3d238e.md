## Behavior

### Reachability and validity

The supplied body contains no ordinary data-dependent branch or loop. Later operations are nevertheless conditional on all preceding accesses and dependency invocations completing.

Each reached access requires storage valid for its width and access permission. The body supplies no explicit bounds, null, alignment, overflow, or accessibility checks. This matters especially where signed halfwords, widened characters, and products become address bases.

There is no rollback. A fault or non-returning dependency can leave an already completed prefix of mutations visible. The platform’s response to an invalid access is unknown.

### Initial externally observable commitments

The first represented memory effect is a 16-bit write. Its destination combines argument 3 with one incoming address-like quantity. Its payload is the low sixteen bits of another incoming quantity, which is also used as an address elsewhere.

The early accesses impose several specific ordering obligations:

- A word at offset 68 of an incoming base is captured before the initial working base receives its own address at offset 84.
- The first external selection is evaluated after that self-address write.
- The captured word is transferred to offset 20 of the externally selected destination.
- Argument 4 is written at offset 17 of the initial working base before the word read through argument 1 at offset 100.

The external word supplying the first selected destination and the external word supplying its associated offset-68 installation are separate represented evaluations of the same external storage. No function-owned write lies between those evaluations. The preceding self-address write therefore cannot, by itself, make the two evaluations differ.

For stable ordinary memory, both evaluations observe the same word. External interference or special memory semantics could invalidate that condition, but neither is established. Separate evaluations do not prove separate physical bus transactions.

### Ordered mutation rather than final-state replacement

The operation is sensitive to the history of memory, not merely its eventual contents.

Some source words are captured before intervening writes and used later. Other locations are read again after writes that may overlap them. A replacement that snapshots all inputs at entry would lose the latter behavior; a replacement that reloads every source would lose the former.

The represented effects include:

- Installing address-like values into their own offset-52 or offset-84 words.
- Installing external words at offset 68 of other destinations.
- Transferring captured words into offset-20 storage.
- Moving offset-116 contents into later offset-36 or offset-84 destinations.
- Writing low-byte portions of arguments, loaded words, address-like quantities, and arithmetic results.
- Writing halfwords at computed destinations without a wider represented write.

These are individual effects, not enduring invariants. Later writes may overwrite them, and aliases may cause apparently unrelated updates to affect subsequent selections.

Argument 4’s early byte write is specifically not a promise about the final byte at that address. The same working-base offset is written repeatedly with other payloads.

Repeated writes remain part of the represented behavior even when their values happen to coincide. No supplied memory model authorizes collapsing the sequence into one final memory image.

### Narrow values and read-after-write distinctions

Signed 16-bit reads contribute signed values to later calculations. A halfword pattern of FFFF therefore contributes negative one, not 65535.

A character loaded through a signed-halfword-derived address later supplies both a halfword payload and address calculations. Character signedness is unresolved. High-bit-set characters consequently have interpretation-dependent widening behavior.

A later word captured at offset 100 is installed at another base’s offset 68. That offset-68 location is subsequently read again. Intervening narrow writes may alias it, so the later read is a fresh observation, not an unconditional reuse of the installed word.

The representation also contains repeated self-address writes through a signed-halfword-derived base, interleaved with byte writes elsewhere. Those interleavings matter when destinations overlap; the apparent repetition does not establish redundancy.

### Arithmetic interpretation

Byte writes replace an 8-bit pattern; halfword writes replace a 16-bit pattern. No wider read-modify-write is represented for either.

Narrowing to a byte or halfword retains the corresponding low-order bit pattern under the represented interpretation. Widening a loaded character requires a signedness decision that the evidence does not supply.

The arithmetic includes addition, multiplication, and left shifts by one, four, and eight bits. The evidence does not establish a universal modulo-\(2^{32}\) model. In particular, overflowing signed arithmetic and left shifts of negative signed values must not silently be assigned wrapping behavior.

Endianness is unknown. Overlapping accesses must therefore be described by address, width, payload, and order rather than an unconditional numerical value for the resulting wider word.

## Acceptance examples

These are conditional static criteria, not executed tests. Each assumes the relevant prefix is reached, the accesses are valid, and any required arithmetic interpretation has been established.

### Initial narrowing

If the incoming halfword payload has low sixteen bits BEEF, the first memory effect writes the 16-bit pattern BEEF at the computed destination. Acceptance does not require a 32-bit write or prescribe byte order.

### Capture survives source mutation

If the early offset-68 source overlaps the following self-address destination, the subsequent offset-20 transfer still uses the word captured before that write. Reloading the modified source would not satisfy the capture relationship.

### Stable external selection

If the initial self-address write changes the external selection word, both immediately subsequent evaluations occur after that change. In stable ordinary memory, both observe the resulting word. Attributing a difference between them to that earlier write is incorrect.

### Byte replacement and overlap

For argument 4 equal to A5, its early destination byte receives A5. A later write may replace it.

Separately, if a word write at offset 20 precedes a byte write at offset 21 of the same base, one byte of the word’s storage is replaced. A numerical final-word expectation additionally requires endianness and the byte payload.

### Signed halfword and character widening

A signed halfword pattern of FFFF contributes negative one to address arithmetic.

For a loaded character pattern of 80, unsigned widening yields 128 and signed widening yields negative 128. Address and halfword expectations using that widened value must state which interpretation applies.

### Installation followed by a fresh read

Suppose a saved word is installed at offset 68, and an intervening narrow write overlaps that storage. The subsequent offset-68 read observes storage after the overlapping write; it must not automatically reuse the saved word.

### Unresolved initial bytes

An early write consuming one of the three unresolved byte values has no established fixed payload. Neither zero nor the byte’s later assigned value is an acceptable unconditional expectation.

### Independent shift preparation

For a captured base of one, where the shifts are defined, the prepared quantities are 16 and 256. Producing 4096 for the second quantity would incorrectly compose the shifts.

### Dependency mutation and reachability

If the indirect dependency changes the external word used by F-cdec09f5d432, the later call uses its post-call evaluation.

If the indirect dependency never returns, the subsequent clears and F-cdec09f5d432 invocation are not reached. If both dependencies return and all intervening operations complete, terminal processing is reached; ordinary successful return is still not established.
