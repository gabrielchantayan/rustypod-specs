## Behavior

1. Invoke F-9520dd1831b4.
2. After that dependency returns normally, store its complete eight-byte result at base offset 8.
3. Read the 16-bit field at base offset 28.
4. Preserve that field’s upper eleven bits and replace its lower five bits with eight.
5. Write the resulting 16-bit value back at base offset 28.
6. Return a 32-bit zero.
