A **retained observation** continues to supply its designated consumers even if its original memory location changes. A **fresh observation** must reflect preceding writes that overlap its location.

The ordering described here is logical ordering in the supplied representation. It does not establish volatile semantics, atomicity, synchronization, or a fixed number of physical transactions.

Each publication stage has a cursor, destination, payload, and distinct external contribution source. Its common contract is:

## Acceptance examples

These are conditional acceptance criteria, not executed tests. Unless otherwise stated, assume valid arithmetic, valid reached accesses, and no additional mutation.

1. **Partial progress:** If the initial byte write succeeds but the following primary-base word observation fails, the byte is not required to be restored.

2. **Signed entry selection:** An entry selector of −2 selects a character two bytes below the second-input base. Character bits of 255 do not establish destination address 255 while character signedness remains unresolved.

3. **Preparation overlap:** If an entry preparation write changes seed offset 68 after the anchor assignment, the first payload reflects the later word observation rather than automatically equaling the anchor.

4. **Contribution occurrences:** If a stage retains contribution 200 but its subsequent occurrence yields 300, destination offset 68 receives 300 while payload delivery uses address 220.

5. **Third-stage discovery:** If either early third-transition write changes third-destination offset 116, the subsequently discovered traversal address reflects that change.

6. **Selector-relative cursor:** A fourth- or fifth-transition selector of −4 places replacement-cursor discovery at address 16, independently of the preceding cursor.

7. **Fifth-stage retention:** Later changes to the fourth external source do not replace the retained contribution used in fifth-transition preparation. Later changes to primary-base offset 100 do not replace the byte retained for fifth-stage completion.

8. **Saved-word-relative factor:** A saved endpoint word of 200 places factor discovery at address 220. If endpoint replacement overlaps that address, the factor observation accounts for the replacement.

9. **Distinct late samples:** If intervening publications change third-product offset 68, its earlier sample controls fifth-contribution offset 9 while its later sample controls third-product offset 17.

10. **Traversal-slot aliasing:** If a feasible addressed write changes the internal traversal slot, a later slot observation uses the changed storage. This criterion does not assert that such an alias exists.

11. **Arithmetic boundary:** A product outside the signed 32-bit range has no established wrapped-address interpretation.

12. **Execution boundary:** If the first dependency changes the later external argument source, F-cdec09f5d432 receives the post-call value. If the first dependency does not return, seventh-input clearing and subsequent handoffs are unreached.
