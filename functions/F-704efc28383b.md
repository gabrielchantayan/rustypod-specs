## Behavior

The function obtains the 32-bit value stored at the source address and writes that value to the destination address.

This is a transfer of one four-byte storage unit. No arithmetic, comparison, masking, byte-order conversion, truncation, or sign extension is expressed for its contents. In particular, the leading value is not examined to select a branch or determine a transfer length.

The source value must be obtained before the destination assignment can take effect. The assignment precedes the dependency invocation in the supplied representation.

These are logical access-order statements. The evidence does not establish atomicity, memory-ordering guarantees, volatile access semantics, or the physical width and number of machine transactions.

### Delegation

After the leading-unit assignment, the function invokes F-47d8e93d0701 exactly once along the normal path, with:

1. The destination address advanced by four bytes.

No size, count, leading-unit value, mode flag, or explicit ownership indicator is passed as an additional argument in the supplied representation. Any interpretation of the trailing regions must come from the dependency’s own contract or external context.
