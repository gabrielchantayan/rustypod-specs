# F-163aa6442bb1

## Purpose

The classification has two levels:

- A primary three-bit group can determine the result immediately.
- For primary patterns that do not determine the result, a secondary three-bit group distinguishes result 1 from result 0.

The primary group takes precedence. In particular, secondary bits cannot change a result already determined by the primary group.

For primary groups 1 through 5, the result is determined without a secondary field examination. In those cases, all seven nonzero secondary patterns, as well as the zero secondary pattern, produce the same result for a given primary group.

### Secondary classification

For primary groups **0, 6, and 7**, the source expresses another read of the word at the same field address. The function applies **0x001C0000** to this later value.

- If any of bits 18–20 is set, it returns **1**.
- If all three bits are clear, it returns **0**.

The secondary group is tested for zero versus nonzero. Its individual nonzero values are not distinguished.

A later primary pattern is not reclassified during this secondary examination. If the first observation selects fallback and the word subsequently changes, the result is governed by the secondary bits of the later observation, not by the later primary bits.

- Primary group 0, 6, or 7 produces 1 when the secondary group is nonzero, otherwise 0.
