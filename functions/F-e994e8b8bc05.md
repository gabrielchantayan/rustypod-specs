# F-e994e8b8bc05

## Purpose

The established behavior is a sequence of helper calls, up to two indirect method calls, one explicit four-byte transfer, and a constant return value on normal completion. A nonnegative index enables an additional acquisition-and-transfer phase. A negative index skips that phase but does not skip the subsequent update or final state-related operation.

Interpreting this as selecting an indexed value and applying it is plausible intent, not an established semantic guarantee. The meanings of the values, the object field, and the final state-related operation are not available.
