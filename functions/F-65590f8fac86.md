# F-65590f8fac86

## Purpose

F-65590f8fac86 conditionally updates two shared signed measurements, prepares invocation-local descriptor storage, and invokes dependencies in a mode-dependent order.

The established behavior consists of direct memory accesses, argument construction, conditional calls, and forwarding of dependency results. Lazy measurement caching, template copying, allocation, and object construction are inferred intent, not established dependency guarantees.

Two distinctions are essential:

- Some global values are captured for later use, while other expressions reread the corresponding globals.
- The measurement output area, the zero-mode descriptor, and the extended descriptor share local storage. They are not independent objects.

## Interface

### Arguments and result

| Input | Representation | Established use |
|---|---|---|

| Mode | Signed 32-bit integer | Zero selects one branch; every nonzero value selects the other. Exactly 1 additionally affects two selection fields. |

The function returns no value and provides no explicit success or failure status.

### Shared and fixed data

A global supplies a shared-state base. Signed 32-bit measurements reside at offsets 72 and 76 from a selected base.

Other globals supply lookup keys, a resource-selection value, template addresses, two table bases, an extended-descriptor word, a size-shaped value, and an additional data-region base. Their numerical contents and meanings are unavailable.

Each selection table is accessed as two 32-bit entries, indexed by 0 or 1.

## Behavior

### Shared-base capture and sentinel test

The function first captures the shared-state base global.

The sentinel expression then reads that base global again and tests the signed 32-bit field at offset 72 from this subsequently read base. The tested address is therefore not unconditionally the captured base plus 72.

All later direct measurement stores and measurement snapshots use the base captured on entry. They do not reload the shared-state base global.

If the sentinel read is nonzero, the measurement sequence is skipped. The second measurement is not independently checked. If the sentinel read is zero, the following sequence executes.

### Conditional measurement sequence

The function calls F-9d0ecc5f6adf without arguments and retains its 32-bit result for both resource-related calls.

For the first measurement:

1. F-ed4b1fd8953e receives the context and the first lookup key.
2. After that call, the resource-selection global is captured for later reuse.
3. A 32-bit record pointer is read at offset 8 of the lookup result.
4. F-5710a8628cba receives the retained F-9d0ecc5f6adf result, a **new read** of the resource-selection global, and the record’s 32-bit word at offset 0.
5. F-59c1430f85c2 receives the measurement output-area address, the preceding dependency result, the low 16 bits of the record’s 32-bit word at offset 4, and the unsigned byte at record offset 12.
6. Two signed 16-bit fields are read through addresses derived from the output area’s first 32-bit word. Bit 0 of that word is cleared with the 32-bit mask `0xfffffffe`; the field offsets are 82 and 84.
7. The sign-extended fields are added and the signed 32-bit sum is written at offset 72 of the captured shared-state base.

The resource-selection capture precedes the first record-pointer read. The first F-5710a8628cba call nevertheless uses a separate global read, not that captured value. The relative evaluation order of its resource-global read and record-offset-0 read is not independently established.

The second measurement repeats the lookup, record-pointer access, resource call, output-area call, and signed-field calculation using the second key. Its differences are:

- F-9d0ecc5f6adf is not called again.
- F-5710a8628cba uses the resource-selection value captured during the first measurement, not a fresh global read.
- The resulting sum is written at offset 76 of the captured shared-state base.

Both F-59c1430f85c2 calls receive the same local output-area address. The caller does not initialize the area before the first call or clear it between calls. Only its first word is directly read for measurement calculation.

The two measurement address expressions each refer to that first word. A single immutable reference snapshot across both signed-field reads is not established. Their relative evaluation order is also not established.

For each record, the offset-0 word is read before F-5710a8628cba executes. The offset-4 word and offset-12 byte are read afterward, so that dependency can affect the later arguments by modifying accessible record storage.

Each individual signed 16-bit field lies between −32,768 and 32,767. Their sum lies between −65,536 and 65,534 and fits in signed 32-bit storage.

A first sum of zero leaves the sentinel field zero at that store. If it remains zero at a later invocation’s sentinel test, that invocation can repeat the sequence. A nonzero sentinel suppresses the sequence even if the second measurement is stale or zero.

### Initial descriptor preparation

The unmapped three-argument dependency is designated F-external-1. This is a document-local opaque identifier. Its arguments resemble destination, source, and byte count, but copying is not established without its contract.

The caller performs:

1. A count-104 F-external-1 call for the leading descriptor.
2. A count-104 call for the zero-mode secondary descriptor.
3. A count-104 call for the nonzero-mode secondary descriptor.
4. Signed 32-bit snapshots of measurements at captured-base offsets 72 and 76, in that order.
5. A signed 32-bit snapshot of the context extent at offset 8.
6. A count-104 call for the primary descriptor.
7. The primary selection write, followed by the primary position write.
8. A count-104 call for the common trailing descriptor.
9. The common trailing selection write.
10. A count-104 call for the optional descriptor.

All six external calls occur regardless of mode.

The arithmetic uses the measurement and extent snapshots taken before the primary external call. Mutations to their original storage during that call do not trigger rereads for this calculation.

### Selection fields and captured table base

Before computing the primary selection, the function captures the first table-base global. It then reads context flag bit 0 and chooses:

- Index 1 if the bit is set and mode is exactly 1.
- Index 0 otherwise.

The primary’s 32-bit selection field at offset 72 is read through a **subsequent read of the first table-base global**, not necessarily through the captured table base.

After the common trailing external call, the flag is read again and the same index rule is applied. This time the selected word is read through the previously captured table base and written at common trailing offset 72.

Thus both the flag and table contents may differ between selections. The common trailing lookup does not follow a replacement table base installed by an intervening dependency; it uses the captured base. The primary lookup uses the separately read base.

Each condition reads the flag even when mode is not 1.

### Position arithmetic

The primary position field at offset 60 receives:

**first measurement + truncation toward zero of ((extent − (first measurement + second measurement) − 2) / 2)**

The additions and subtractions are signed 32-bit expressions without explicit widening or overflow checks. The stated result applies when all intermediate arithmetic is representable. Overflow behavior is documented_only.

Negative odd division numerators truncate toward zero, not toward negative infinity.

## Side effects

Direct shared writes are limited to the two measurement stores on the conditional path. The caller does not directly write the context.

Direct local writes include descriptor fields and the nonzero branch’s overwrites of the aliased measurement output area. External dependencies may have additional effects; no preservation of globals, context, tables, templates, or accessible local storage is assumed.

On normal completion:

- Mode zero makes five F-8157a180d901 calls, plus one if the final flag is set.
- Nonzero mode makes four such calls, plus one if the final flag is set.
- Each result is forwarded to its associated descriptor consumer before the next such request.
- F-external-1 is called seven times: six common calls and one branch-specific call.

There is no explicit validation, rollback, deallocation, or failure cleanup. Nonreturning dependencies or invalid accesses can leave earlier effects observable.

All descriptor and measurement-output addresses refer to invocation-local storage. Retention, ownership transfer, and release obligations are unknown. In particular, a dependency retaining the measurement output address could encounter later contents in the same storage: the nonzero branch directly writes 25 and 0 there, and an ordinary zero-mode copy overwrites it with template bytes. No independent preserved measurement-output object exists.

The lifetime requirements for retained addresses after return are documented_only.

## Acceptance examples

These are conditional static examples, not executed tests. They assume valid accesses and normally returning dependencies unless stated otherwise.

1. **Distinct shared bases.** If entry capture observes base A and the sentinel expression observes base B, the sentinel is read at B+72. Any measurement stores and later measurement snapshots use A+72 and A+76. Equality of A and B is not a contract requirement.

2. **Distinct resource reads.** If the retained resource-selection read observes R and the later first-call read observes S, the first F-5710a8628cba receives S and the second receives R. It is incorrect to substitute either value for both calls.

3. **Distinct table-base reads.** If the captured first-table base is T and the primary lookup’s later base read is U, primary selection uses U. Common trailing selection uses T, with its separately read flag.

4. **Nonzero sentinel.** A nonzero initial sentinel skips all measurement-related calls. The second measurement is nevertheless read later from the captured shared base.

5. **Signed measurements.** If the two signed fields read for one calculation are −7 and 12, that calculation writes 5. A first sum of zero remains eligible for recalculation on a later invocation if the later sentinel read is still zero.

6. **Position arithmetic.** Measurements 10 and 20 with extent 101 produce numerator 69, quotient 34, and position 44. With extent 29, the numerator is −3, the quotient is −1, and the position is 9.

7. **Mode distinctions.** With flag bit 0 consistently set, mode 1 selects entry 1 for both first-table writes and the second-table write. Mode 2 or −1 selects entry 0 for both first-table writes but entry 1 for the extended write.

8. **Direct output-area replacement.** In any normally progressing nonzero invocation, extended offsets 116 and 120 are directly written with 25 and 0 before the extended external call. These are the same addresses previously supplied as the two-word measurement output area.

9. **Conditional zero-mode overwrite.** If F-external-1 performs an ordinary bounded 92-byte copy, the zero-mode call replaces both measurement output words with source bytes 84–91. No claim about their resulting numeric values follows without source contents and byte order.

10. **Late flag change.** A dependency that changes the flag before the final read can enable or suppress the optional sequence independently of earlier selections.

11. **Zero-mode request order.** With the final flag clear, F-8157a180d901 receives 560, 544, 164, 560, and 544. These calls alone establish neither successful allocation nor successful construction.
