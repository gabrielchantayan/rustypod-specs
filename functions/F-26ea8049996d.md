## Acceptance examples

These are conditional static acceptance cases, not executed tests.

1. **Initial extraction.** If R is `0x80000000` and the first G snapshot is `0x80000000`, P is 512 and Q is 256. The second initial word store receives 512, and the associated four-argument call receives J, J, 256, 512.

2. **Twice-shifted zero.** For every possible initial 32-bit G value, its unsigned right shift by 23 is at most 511. Shifting that result right by 23 produces zero. The corresponding word store must therefore write zero.

3. **Truncated high-bit byte.** If T is `0xffc00000`, T logically shifted right by 22 is 1023. Its byte publication is `0xff`, not a saturated or full-width representation of 1023.

4. **Fresh low-address read.** If one read of `B[1]` yields 7 and a later read yields 9, their byte destinations are 24 and 26 respectively. Retaining 7 for the later operation would violate the visible reads.

5. **Full-word preservation.** If X is `0x123456ab`, the immediate byte refresh writes `0xab`. Subsequent stores of retained X write `0x123456ab`, including the store using the 16-byte stride.

6. **Repeated refresh.** If `W[D + 116]` changes from `0x00000011` to `0x00000022` during intervening calls, the repeated refreshes write `0x11` and then `0x22`.

7. **Final H replacement.** If the final byte result is `0x5a` and the three-byte quantity has value `0x123456`, H becomes `0x1234565a`. This replaces the earlier full-word publication to H.

8. **Nonreturning final transfer.** If calling address zero faults, the function does not reach its return. Earlier completed writes are not visibly rolled back.
