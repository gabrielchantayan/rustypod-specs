# F-6226c2e4e442

## Behavior

### Initial updates and decision input

The first direct memory operation writes 1 to the byte at offset 0x69. The next direct memory operation writes 1 to the byte at offset 0x6A.

After both writes, the function reads the four-byte value at offset 0xD0 and invokes F-342542431c39 with that value as its sole visible argument. It passes the field’s value, not the address of the field.

The read occurs after the initial writes and before the dependency invocation. Any later modification of the field by a dependency does not change the argument value already supplied for that invocation. This function contains no second read of that field.

- This function performs no direct write to offset 0x68.

1. The original address-bearing input.
