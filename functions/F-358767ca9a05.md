# F-358767ca9a05

## Purpose

F-358767ca9a05 updates a caller-supplied mutable object. It snapshots a current value, optionally classifies a retained control word, invokes an indirect callback with either a reset or enabled flag, performs branch-dependent calculations, and writes a completion marker.

Established behavior consists of access widths, read/write and call ordering, branch conditions, retained values, and integer calculations. Numerical conversion or scaling is suggested by the helper calls and constants, but their mathematical meanings are not established.

The function has no explicit return value. Its observable results are object mutations and dependency effects.

## Behavior

### Entry, snapshot, and mode reads

The function first reads the current value at +0x18 and writes its 32 bits to the snapshot at +0x1C. It then reads and retains the control word at +0x1207C.

This retained control governs optional classification and the reset decision. Later modifications to the object’s control field do not revise those decisions.

The first mode test reads the word at +0x44 and compares its low eight value bits with two. A later reset-decision mode test, when required, is a separate word read. The enabled callback is followed by another separate word read for branch selection.

### Optional selector classification

Classification occurs only when the first mode test equals two. Otherwise, it makes no selector store and reads neither external selector bound.

With classification enabled, signed comparisons against the retained control select:

| Condition, in priority order | Selector |
|---|---:|
| Control ≥ 0x3FE00000 | 1 |
| Otherwise, control ≥ 0x3FB00000 | 3 |
| Otherwise, control ≥ 0x3F900000 | 7 |

A successful fixed-threshold condition completes classification without reading either external bound.

Only after all three conditions fail does classification read the external upper bound as a signed 32-bit value. If upper bound ≤ retained control, it selects one and does not read the lower bound.

Otherwise, it next reads the external lower bound as a signed 32-bit value. Control below that lower bound selects one; control at or above it selects three. The selected value is stored as 16 bits at +0x6E.

For stable external values, this final portion selects three precisely when:

**lower bound ≤ control < upper bound**

This interval description does not replace the access contract: upper is read first, and lower is read only when upper exceeds control. If lower ≥ upper, the interval is empty.

### Reset decision and reset path

The retained control is first tested for exact equality to 0x3F800000. Equality selects reset without the reset-decision mode read.

Otherwise, the function reads the 32-bit word at +0x44 again. Reset is selected if its low eight value bits are zero.

Reset performs the following ordered object updates before callback invocation:

1. Reread the current value and copy it to the primary output.
2. Store zero to the 32-bit adjustment output.
3. Store selector one as 16 bits.
4. Store zero to the 16-bit narrow output.
5. Store zero to the 16-bit auxiliary field.
6. Store 0x00010000 to the 32-bit scale-like output.
7. Store zero to the single byte at +0x44.

The last store leaves the other three bytes of the mode-test word untouched. Its effect on the tested low eight value bits depends on byte order.

The indirect callback then receives the object pointer and flag zero. The stores precede that call but need not survive it: callback preservation is unknown.

After a returning reset callback, the only remaining explicit object update is the final completion-marker store. There is no further mode test on this path.

### Enabled callback and subsequent branch selection

If reset is not selected, the callback receives the object pointer and flag one.

After it returns, the function reads the 32-bit word at +0x44 and tests its low eight value bits:

- One selects the special mode-one path.
- Every other value, including zero, selects the general path.

A callback therefore redirects subsequent computation by changing the tested bits. Merely changing the byte at +0x44 has that effect only if the target layout makes that byte contain those bits. A post-callback tested value of zero does not trigger another reset decision.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Word-based mode tests.** A mode-test word of 0x12345602 enables classification; 0x12345600 satisfies the reset mode condition; 0x12345601 selects the special path when read after an enabled callback. The upper 24 value bits do not affect these comparisons.

2. **Byte store versus tested bits.** Suppose reset reaches its byte store while the word at +0x44 is 0x12345602. Before callback effects, little-endian layout yields word 0x12345600; big-endian layout yields 0x00345602. Both satisfy the one-byte-store contract. Neither byte order is selected by the supplied evidence.

3. **Reset by tested mode.** If the reset-decision word read has low eight value bits zero and retained control differs from 0x3F800000, reset stores precede callback flag zero. If the callback preserves them, primary equals the reset-time current read; adjustment, narrow output, and auxiliary are zero; selector is one; scale-like output is 0x00010000. The byte at +0x44 is zero, and completion becomes one.

4. **Reset by exact control.** Retained control 0x3F800000 selects reset without the reset-decision word read. The initial classification mode read still occurs. If its tested bits equal two, classification precedes reset’s selector-one store.

5. **Fixed thresholds.** With classification enabled, controls 0x3FE00000, 0x3FB00000, and 0x3F900000 initially select one, three, and seven respectively. Neither selector bound is read.

6. **External-bound boundaries.** When external comparisons are reached, upper equal to control selects one without reading lower. If upper exceeds control, lower is read next: lower equal to control selects three; lower greater than control selects one.

7. **Callback redirection.** After an enabled callback, tested bits equal to one select the special path; zero selects the general path, not reset. A change only to the byte at +0x44 is insufficient to predict this result without byte-order information.

8. **Adjustment cap.** In the at-or-above-external-threshold branch, retained current 10, primary result 15, and selector three produce initial adjustment 20. Without interference or overflow, replacement adjustment is 15 and shared input is five.

9. **Above-control arithmetic.** Retained current 10, primary result 12, and selector three produce adjustment 32 and shared input negative eight, without overflow.

10. **Narrow output and interruption.** A final conversion result of 0x12345678 produces a 16-bit store of 0x5678, not a wider neighboring write. A callback that does not return prevents the final completion store; a previously set marker does not establish current completion.
