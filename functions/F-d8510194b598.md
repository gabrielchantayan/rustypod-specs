# F-d8510194b598

## Behavior

### Initialization and fallback selection

F-0ec4c847eecb is invoked before either side is processed for comparison. It receives no explicit argument in the visible call.

Its return value becomes the first-side state. If that value is zero, the routine reads the shared fallback and uses that value instead. A nonzero return value prevents this first fallback read.

After first-side initialization, the routine examines the second argument. If that argument is zero, the routine reads the shared fallback and uses the value read as the second-side state. Otherwise, it uses the argument unchanged.

These are separate conditional reads of shared storage, not one snapshot reused for both sides. When both fallback conditions apply, the first read precedes the second. The visible routine does not cache the first fallback value for the second side or require both reads to produce the same value.

Because F-0ec4c847eecb runs before fallback selection, changes it makes to shared storage may affect subsequent fallback reads. Its effects are not specified here.

A fallback value of zero is accepted as state. The visible body neither repeats fallback selection nor reports an error because the selected fallback is zero.

### Comparison and continuation

After both comparison values have been obtained, inequality takes precedence over termination.

If the values differ, the routine immediately returns their difference. This applies when either value is zero as well as when both are nonzero. No further comparison round is performed.

If the values are equal and the first-side value is zero, the routine returns zero. Equality means that the second-side value is also zero in this case.

If the values are equal and nonzero, another round begins. The routine does not visibly reinitialize either state cell, call F-0ec4c847eecb again, or reread the fallback during continuation. Changes that dependencies made to the state cells remain available to later calls.

No iteration limit is visible. A run producing equal nonzero values indefinitely does not terminate through this routine’s own comparison logic.
