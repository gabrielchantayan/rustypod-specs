A **five-call group** consists of one call with the stated explicit argument list, followed by four calls with no explicit arguments. Whether the fifth result is retained is stated for each group. “No explicit arguments” does not establish that incoming machine registers are irrelevant.

A **nine-call group** consists of:

- A no-explicit-argument call whose opaque 32-bit result is forwarded to the next call.
- Another no-explicit-argument call whose opaque 32-bit result is forwarded to the following call, sometimes with an additional stated argument.

The next retained data value comes from the global read, not from this group.

The loop retains its selector-source address \(D_{\text{selector}}\), a loop argument, and a shifted state initially equal to \(E_{\text{initial}}\).

- The first group opens with the loop argument and the current shifted state logically shifted right by eight. Its fifth result is retained.

## Acceptance examples

These are **conditional static examples**, not executed tests.

1. **Initial byte truncation and selector refresh.** With first argument `0x12345678` and initial selector `0x20`, the first write stores `0x78` at `0x31`. If intervening dependencies change the selector to `0x21`, the second write stores `0x48` at `0x32`.

2. **Unretained second group.** After the second initial byte write, the next five-call group receives the earlier captured result shifted left two bits. Its return values are not explicitly retained. No acceptance condition may require its fifth return to become the next captured data value; the next explicit capture is the global read.

3. **Third-argument boundary.** Third arguments zero through 127 select `0x14`; 128 selects `0x18`. Both writes use the captured \(G\), even if an intervening dependency changes the global.

4. **Write-before-read aliasing.** If \(A=0\), the opening word write and capture of \(W\) both address `0x14`. Under ordinary coherent memory semantics without intervening external modification, \(W=0\).

5. **Full-word shifted writeback.** If \(V=\texttt{0xA1B2C3D4}\), the later word write stores `0x00A1B2C3`, not merely `0xC3`.

6. **Direct byte destination.** A captured \(W\) with its highest bit clear selects `0x1C`; one with that bit set selects `0x1D`.

7. **Fresh zeroing destinations.** If dependencies alter a selector between zero writes, each write follows its own fresh selector read. Equal destinations are not required.

8. **Loop progression.** The first loop call passes zero as its second explicit argument. Under the conditional 32-bit interpretation, a final second-group result of one makes the next shifted state `0x04000000`, so the following iteration passes `0x00040000` as that argument.

9. **No normal completion.** If execution reaches the loop and every operation continues completing, no normal function return occurs.
