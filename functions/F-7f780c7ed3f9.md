# F-7f780c7ed3f9

## Purpose

Two preliminary lookup failures produce an immediate result of −1. Otherwise, the obtained value is returned unless both object-dispatched checks return nonzero and the obtained value is less than the threshold.

This is an established description of the visible control flow, not an identification of the underlying application operation. The meanings of the object, lookup result, queried value, and two checks are unknown. In particular, −1 is not an unambiguous error indicator: the value-producing dependency may itself return −1, and this function can return that value without taking a rejection branch.
