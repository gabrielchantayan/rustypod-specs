# F-9bc708735a2e

## Purpose

The function performs a fixed, ordered sequence of indirect calls, word transfers, byte-selected updates, global-state accesses, and a terminal halfword clear. Its last explicit call targets address zero with three zero arguments.

No application-level purpose is established. Initialization, serialization, allocation, and device control are not supported interpretations without additional evidence.

This contract describes the supplied body’s observable operations. It does not establish that the displayed interface is a complete machine-level interface, that any indirect target is executable, or that execution can return normally.

### Widths, locations, and notation

A **word** is 32 bits, a **halfword** is 16 bits, and a **byte** is 8 bits. A low-byte store preserves only the least significant eight bits of its input.

For this contract:

- A **scaled-word destination** is an address formed as four times an index, plus 20.
- A **forwarding pair** consists of a call with no displayed arguments, immediately followed by a call receiving its ordinary result.
- A **four-call group** contains four distinct, ordered calls with no displayed arguments. Unless stated otherwise, its fourth call supplies the ordinary result subsequently used.
- A **selector** is an unsigned byte loaded from memory and used numerically as an address component. It is not a pointer-width pointer load.

Three global locations receive neutral labels:

| Label | Established use |
|---|---|
| State A | A 32-bit global sampled twice. |
| State B | A global receiving two 32-bit assignments. |
| State C | A three-byte global contribution used as the upper 24 bits of the final State B assignment. |

The source identifies State C with a location at address 9. Its byte order is not established. Global symbols may overlap smaller symbols; independence between globals, low-address memory, and computed destinations must not be assumed.

Unsigned word shifts are logical. Some multiplication and left-shift expressions instead operate on signed 32-bit values in the displayed representation. Overflow and negative-operand behavior for those expressions are **documented_only**. Unconditional mathematical or wraparound interpretations are not interchangeable.

## Behavior

The phases below preserve observable call and memory-access order. A call whose ordinary result is unused remains an observable dependency invocation; it is not assumed effect-free.

### 1. Entry dispatch and initial word store

The initial target is formed by adding 3,896 to the inherited control-flow value. It receives the second explicit argument.

A forwarding pair follows. After its consumer returns, **four** no-explicit-argument calls occur in order. The fourth supplies the index for the first scaled-word destination.

The function writes the inherited first payload as a complete word to that destination, then reads State A and retains the first snapshot. It next calls a dependency with four times the index.

Another four-call group follows. A secondary result associated with this sequence supplies the destination index used in the next phase. The exact machine-level return channel is unresolved.

The first State A read therefore occurs after the initial word store and before the scaled-index consumer. Aliasing can make the store affect this snapshot.

### 2. Upper-bit payload stores and a guaranteed zero

The inherited unsigned payload is logically shifted right by 22, producing a value from 0 through 1,023. The first State A snapshot is logically shifted right by 23, producing a value from 0 through 511.

The function writes the upper-bit payload as a complete word at the secondary index’s scaled-word destination. A dependency then receives, in order:

1. That index.
2. The same index again.
3. The shifted State A snapshot.
4. The upper-bit payload.

A forwarding pair follows. During this interval, the already-shifted State A value is shifted right by another 23 bits. The result is necessarily zero.

After the forwarding consumer, **four** no-explicit-argument calls occur. Their fourth call supplies the index for a second scaled-word store of the upper-bit payload. A dependency receives four times that index.

Another four-call group follows. A secondary unsigned word result is retained as a later address input. The function writes zero at its scaled-word destination and calls a dependency with the retained result itself, not four times that result.

### 3. Masked word read and first selector update

A forwarding pair and then a four-call group produce a fresh ordinary index.

The function writes zero at that index’s scaled-word destination. It then reads a word at an address obtained by:

- Keeping the low 29 bits of the retained secondary result.
- Logically shifting those bits right by 19.
- Adding 20.

This read address ranges from 20 through 1,043; the expression does not guarantee word alignment.

A dependency receives four times the fresh index, followed by another four-call group.

The loaded word is logically shifted right by 22. The function then reads the selector at address 1 and writes the low byte of the shifted word at selector plus 17. The address-1 read follows from the guaranteed zero established in phase 2.

A dependency subsequently receives one secondary word result three times, followed by zero.

### 4. Selector clears and retained secondary payload

One call with no displayed arguments is followed by a dependency receiving zero. A four-call group follows.

Using the phase-3 shifted word, the function reads a selector at four times that value plus 1, then writes zero at selector plus 17. The selector-read address is between 1 and 4,093.

The latest ordinary result, shifted left by two, is passed to a dependency. Another four-call group follows, then a dependency receives its latest result shifted left by two twice.

A no-explicit-argument producer returns a word, which is forwarded to a consumer. One further no-explicit-argument call occurs before another selector read at address 1 and another zero-byte store at selector plus 17.

A secondary word result is retained for later left shifts. A dependency receives that retained value three times.

### 5. First State B assignment and selector-relative word transfer

A no-explicit-argument producer supplies the first argument to a dependency. The second argument is the ordinary word produced near the end of phase 4, logically shifted right by 23.

A four-call group follows. The selector at address 1 is read again, retained as an unsigned address component, and used for a zero-byte store at component plus 17.

The latest ordinary result shifted left by two is passed onward. Another four-call group follows, then its latest result shifted left by two is passed twice.

A subsequent no-explicit-argument call produces a word. The function writes that word to State B, passes the same retained word to a dependency, and makes another no-explicit-argument call.

Only then does it read a word at the retained selector component plus 116 and write its low byte at component plus 1. The selector component is not reread after the intervening calls.

A dependency next receives the retained secondary payload from phase 4 shifted left by 11.

### 6. Wide-result forwarding and repeated refresh

A no-explicit-argument call produces a displayed 64-bit result. A dependency receives its low word, its high word, and the word previously assigned to State B logically shifted right by 23. This third argument uses the retained produced word, not a fresh State B read.

A four-call group supplies an index. Four times that index becomes the **first retained base**. The function reads a word at this base plus 116, writes its low byte at base plus 1, and passes the base to a dependency.

Another four-call group supplies an index whose left shift by two becomes the **second retained base**.

Before the next call, the function again reads a word at the **first** retained base plus 116 and writes its low byte at that same first base plus 1. The second base does not replace the first for this refresh.

The next dependency receives:

- The phase-4 secondary payload shifted left by 12.
- The second retained base twice.
- The latest ordinary index shifted left by 18.

The two refreshes are separate reads. Intervening callees may change the observed word.

### 7. Full-word propagation through different strides

Two successive forwarding pairs occur: the first producer and consumer, then a second producer and consumer. A four-call group follows.

Four times its final index supplies a new base. The function reads a complete word at base plus 116, retains that complete word, writes its low byte at base plus 1, and passes the base onward.

After another four-call group, the retained complete word is stored at sixteen times the latest index, plus 20. This destination has stride 16, not stride 4.

A dependency then receives the second retained base logically shifted right by two and subsequently shifted left by 16. The intervening right shift must remain part of the expression; the earlier base-forming left shift may have discarded bits.

After this dependency, **two successive forwarding pairs** occur, in order. Both producers and both consumers are observable calls with unknown effects.

Only after those four calls does a four-call group occur. Its fourth result selects a scaled-word destination receiving the same retained complete word. Four times that index is then passed to a dependency.

### 8. Linking stores, zeroing, and another State A snapshot

A four-call group supplies a new index. Its left shift by two is written as a complete word at the second retained base, with its low two bits cleared, plus 20. A dependency receives the shifted result twice.

Next come **two successive forwarding pairs**, followed by a four-call group. Its final result selects a scaled-word destination that receives zero. Four times that index is passed onward.

Another four-call group ends in a displayed 64-bit result. Its low word is shifted left by two; its high word supplies the index for a scaled-word destination. The shifted low word is written there.

State A is then read again. This is a fresh snapshot.

A dependency receives the shifted low word, the high word, and the shifted low word twice more, in that order. A four-call group follows, and its final index selects another scaled-word destination receiving the same retained shifted low word.

The function then reads a word at the second State A snapshot plus 20, retains that word, and calls a dependency with four times the latest index.

### 9. Final selector-based payload updates

A four-call group ends in another displayed 64-bit result. Both halves are retained.

Before the next dependency call, the complete payload retained in phase 7 is logically shifted right by 23. A selector is read at that result plus 1, and the low byte of the State-A-derived word from phase 8 is written at selector plus 17.

A dependency receives the latest high word three times, followed by the latest low word shifted left by two.

A forwarding pair and a four-call group follow. The function then masks the retained low word to 30 bits, logically shifts it right by 21, and reads a selector at the result plus 1. It writes the low byte of the State-A-derived word shifted right by 22 at selector plus 17.

Both selector-read expressions in this phase range from address 1 through address 512.

The latest ordinary result shifted left by two is passed to a dependency. Another four-call group follows, then its latest result shifted left by two is passed twice.

### 10. Terminal writes and call

One no-explicit-argument call occurs. A differently formed indirect target is then called without displayed arguments, and its ordinary result is forwarded to a consumer. A final no-explicit-argument call produces a byte-sized result.

The terminal memory effects occur in this order:

1. Write a zero byte through a secondary pointer result.
2. Read State C’s three-byte contribution and assign State B a word containing that contribution in bits 31–8 and the final byte result in bits 7–0.
3. Write a zero halfword at the address obtained by retaining the low 30 bits of phase 9’s retained low word and logically shifting right by 7.
4. Call address zero with three zero arguments.

The halfword destination ranges from zero through 8,388,607 and need not be aligned.

The displayed body returns only after the address-zero call. Normal return is conditional on that call returning.

## Acceptance examples

These are conditional static consequences, not executed tests.

1. **Initial call count.** After the initial forwarding consumer, four distinct no-explicit-argument calls precede the first word store. Conditional on their return, the fourth supplies its index; the preceding three still remain observable calls.

2. **Second upper-bit store.** After the phase-2 forwarding consumer, all four no-explicit-argument calls precede the payload store. The fourth result selects its destination.

3. **Upper-bit boundary.** An inherited unsigned payload of `0xFFFFFFFF` produces 1,023 after the right shift by 22. Both upper-bit-payload stores write that complete word.

4. **Guaranteed zero.** Every unsigned 32-bit State A value becomes zero after successive right shifts by 23 and 23. The associated selector load is therefore at address 1.

5. **Selector interpretation.** A selector value of 200 makes an offset-17 byte store target address 217, without loading a pointer from the selector location.

6. **Full word versus low byte.** A phase-7 payload of `0x123456AB` causes the immediate byte store to write `0xAB`; both subsequent payload word stores preserve `0x123456AB`.

7. **Two forwarding pairs.** Between phase 7’s shifted-base consumer and the next four-call group, both forwarding pairs must occur in order. The same two-pair requirement applies before phase 8’s zero-word-store group.

8. **Fresh refresh.** If a dependency changes the first retained base’s offset-116 word between phase-6 refreshes, the second refresh uses the changed word’s low byte.

9. **Terminal composition and aliasing.** If State C supplies the numeric 24-bit value `0x123456` after the terminal pointer clear, and the final byte is `0xAB`, State B receives `0x123456AB`. A pointer clear aliasing State C can change that contribution first.

10. **Terminal failure.** If address zero is not executable, successful return is not required. No visible recovery reverses preceding writes.
