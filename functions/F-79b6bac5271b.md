# F-79b6bac5271b

## Purpose

The indirect invocation combines the returned receiver, a field read through the first input, the remaining four inputs, and a trailing zero.

The established behavior is forwarding and dispatch, not a demonstrated allocation, construction, notification, or ownership-transfer operation. Those interpretations would require evidence about the dependency and indirect target.

A significant feature is that the first input is dereferenced both before and after F-a6226d4de001 executes. The later access is not specified as using a saved copy of the earlier value. Consequently, changes made by that dependency can affect the field supplied to the indirect invocation.
