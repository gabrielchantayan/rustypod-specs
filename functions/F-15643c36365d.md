## Behavior

### Pointer capture and branch decision

It then evaluates whether the integer designated through the global pointer equals zero. These are distinct source-level operations. The captured pointer controls the later explicit store and final read; the condition is expressed through the global pointer.

With an unchanged global pointer, the condition examines the captured slot. If some permitted external mechanism changes the global pointer between those operations, the captured address and the condition’s address need not coincide. The excerpt supplies no synchronization or execution model that makes such changes safe, so this distinction must not be interpreted as a concurrency guarantee.

Equality with zero is the sole branch criterion. Any nonzero signed value, including a negative value, bypasses the dependencies.
