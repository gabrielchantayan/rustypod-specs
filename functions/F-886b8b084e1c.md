# F-886b8b084e1c

This contract describes the supplied static representation. It does not establish the dependency’s behavior, application-level meaning, target arithmetic rules, or runtime correctness.

## Behavior

The following sequence describes the wrapper’s explicit operations on a normal path. It does not assert individual machine instructions or physical memory transactions.

1. **Capture the input word.**  
   The wrapper reads four bytes through the input address and places that value in its temporary copied-word object. This occurs before the dependency invocation.

2. **Initialize a separate temporary object.**  
   The wrapper sets another four-byte object to zero. No explicit later read of this object is shown, and its address is not explicitly passed to the dependency.

3. **Invoke F-ec9a8c39dd4b once.**  
   The dependency receives three arguments, in this order:
   - The address of the first element of the three-integer result array.
   - The opaque four-byte argument.
   - The address of the temporary copied word.

   The third argument is not the original input address. It points to a copy made before invocation. Consequently, writes through that argument alone would affect the temporary copy rather than the original caller-owned word.

4. **Consume the first result element.**  
   After the dependency returns normally, the wrapper reads the first integer from the result array. It does not explicitly read the other two elements.

5. **Apply the offset and return.**  
   The wrapper adds decimal 20 to that integer and returns the result.

There is no explicit branch, retry, loop, error translation, or validation step in this sequence.
