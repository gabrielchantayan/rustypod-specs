### Preparation action

Preparation performs three external factor reads, in this order:

1. It forms the first prepared value from the first argument and the first factor observation.
2. It forms the third-argument prepared value from the captured scale, the second factor observation, and the third argument.
3. It forms the fourth prepared value from the fourth argument and the third factor observation.

The third-argument product groups the scale and factor multiplication before multiplication by the third argument. This matters where arithmetic overflows.

The three factor observations must not be collapsed into one assumed constant. The visible routine does not cache a single factor for all three products.

Preparation then reads the preparation successor, retains the fifth argument, and retains the second argument. It preserves the carried result from the start of the iteration.

If preparation runs again, these retained argument values and all three prepared values are replaced from the original arguments and newly observed factors. Earlier rescaling of the first and fourth prepared values is thereby discarded.

It reads its external gate word twice. The first observation is reduced by five; the second observation is used without that adjustment. The next control is:

- The first observation minus five when the retained second argument is zero.
- The second observation when the retained second argument is nonzero.

The fifth-argument gate similarly examines the retained fifth argument. It reads its gate word twice and chooses:

- The second observation when the retained fifth argument is nonzero.

Both gates preserve the incoming carried result. Their selected control values are subjected to another selector-offset addition on the next iteration; they are not themselves guaranteed to be selector numbers.
