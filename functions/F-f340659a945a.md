## Behavior

### Interpretation and aliasing

No supplied region, external source, invocation field, or derived destination is established as disjoint from another.

A **retained value** means an earlier observation whose value remains available. A **fresh read** observes storage when reached. Retaining an address does not retain that address’s contents. In particular, the anchor and terminal payload are live invocation-area fields rather than immutable snapshots.

The following semantic roles describe memory relationships, not object types:

- **Working address:** an incoming address replaced at specified routing positions.
- **Selection:** the address-like value obtained from the current routing source.
- **Carried word:** data delivered from the preceding routing position.
- **Continuation:** the base for the next routing-source deposit.
- **Retained link:** a captured word from entry-working offset 68 where required.
- **Auxiliary address:** the opening memory-derived address.

“Entry working” means the working address before replacement at that position. Ordering below is not a guarantee of atomicity, synchronization, volatility, or physical transaction count.
