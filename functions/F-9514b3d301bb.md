# F-9514b3d301bb

## Purpose

The established behavior is the ordering and construction of dependency calls. The supplied evidence does not establish what data those calls process, whether they copy or transform records, or what the carried value represents.

A plausible intent is to combine adjacent runs of 12-byte elements. That interpretation is inferred, not a guaranteed semantic description.

## Behavior

The function maintains a current start and a current carry, initially equal to the corresponding inputs.

### Loop eligibility

1. End minus current start.
2. The integer constant 12.

The result is interpreted as a signed integer for the following comparison.

If the comparison is false, the function leaves the loop. The result that caused loop exit is not reused for the final split calculation.

### Repeated delegated operation

For each accepted iteration, the wrapper constructs:

- A middle address equal to current start plus 12 times the original group size.
- A next-start address equal to current start plus 24 times the original group size.

It then calls F-1f5b9bde2df1 with six arguments:

| Position | Value |
|---|---|
| 1 | Current start |
| 2 | Middle address |
| 3 | The same middle address |
| 4 | Next-start address |

The equality of arguments 2 and 3 is required. This establishes a common boundary between the two address pairs, without independently establishing the dependency’s range semantics.

After that call returns:

2. The current start advances to the previously constructed next-start address.
3. A new loop-condition call to F-870c4fcf7295 is made.

The advance occurs only after the delegated call returns. If the dependency does not return, subsequent wrapper activity is not reached.

There is no wrapper-level check of the delegated result. Any returned 32-bit value becomes the fifth argument of the next delegated operation, including the final one.

### Final split selection

2. The integer constant 12.

This call occurs even though the immediately preceding loop-condition call used the same numeric arguments. The two results need not be equal unless the dependency’s contract guarantees that property.

- The original group size.
- The result of this new dependency call.
