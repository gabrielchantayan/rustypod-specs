## Behavior

### Initial observations and eligibility

The observable initial order is:

1. Read the owner value from context `+0`.
2. Invoke F-360e96025c32 with the replacement descriptor.
3. Read the record address from context `+4`.

Consequently, a dependency mutation of the context can affect the record address selected without changing the already captured owner value.

Preliminary comparison operands are derived from the 64-bit result: one is its low 32 bits XOR one, and the other is its high 32 bits. If the record address is non-null, both are replaced: the first by replacement `+4`, and the second by a 32-bit global limit.

A null record is rejected regardless of the preliminary operands. The supplied condition short-circuits that rejection before direct eligibility reads of replacement `+12`.

For a non-null record, acceptance requires all three conditions:

1. The captured global limit is strictly greater than replacement `+4`, using unsigned 32-bit comparison.
2. Replacement `+12`, interpreted as signed 32-bit, is nonnegative.
3. The captured limit, interpreted as signed 32-bit, is strictly greater than replacement `+12`, interpreted as signed 32-bit.

The conditions are evaluated in that order. Failure of an earlier condition suppresses later condition reads. The representation shows separate reads of replacement `+12` for the nonnegative check and the final signed comparison; it does not capture that word once for both uses.

For stable replacement storage, acceptance therefore requires a limit from `1` through `0x7FFFFFFF`, replacement `+4` below that limit as unsigned, and signed replacement `+12` in the range zero through limit minus one. A high-bit-set limit cannot pass the final signed comparison after a nonnegative signed operand passes the preceding check.

There is no eligibility comparison involving replacement `+0`.

If any condition fails, the function returns `0x0000001A`. No accepted-path calls or direct output or record writes occur. This is not a side-effect-free rejection: F-360e96025c32 has already run.
