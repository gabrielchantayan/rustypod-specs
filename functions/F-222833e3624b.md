# F-222833e3624b

## Purpose

F-222833e3624b selects an index from five fixed-stride records in a table whose base address is obtained from shared state. A record is eligible when its byte at offset 14 is nonzero.

The function visits records in ascending index order. The first eligible record becomes the incumbent without a dependency call. Each later eligible record replaces the incumbent only when F-d1a3481e68e2, called with the candidate record followed by the incumbent record, returns exactly −1.

The result is the selected index, or −1 if no visited record was eligible at the time its eligibility byte was read.

This is an order-dependent selection operation. Interpreting it as finding a minimum, maximum, or highest-priority record requires additional knowledge of F-d1a3481e68e2. That interpretation is not established by the supplied evidence.

## Behavior

### Initial state

Before examining a record, the function captures the shared table base and establishes that no incumbent exists.

The shared base is not refreshed between records. This remains true even if a dependency call changes the shared base location.

### Traversal and eligibility

The function visits all five record positions in ascending order. At each position, it reads that record’s eligibility byte once for that visit.

A zero eligibility byte causes the record to be skipped. A skipped record does not become the incumbent and does not cause a dependency call.

A nonzero eligibility byte makes the record a candidate. Eligibility is evaluated at the time of the read; the function does not first capture a five-record eligibility snapshot.

### First eligible record

If a candidate is encountered while no incumbent exists, its index becomes the incumbent immediately.

F-d1a3481e68e2 is not called for this first selection. Consequently, its validity or preference relative to an absent record is never delegated.

### Later eligible records

For every later candidate, the function calls F-d1a3481e68e2 with two record addresses in this order:

1. The current candidate’s address.
2. The current incumbent’s address.

Both addresses derive from the same captured table base.

If the dependency returns exactly −1, the candidate replaces the incumbent. Every other normally returned value leaves the incumbent unchanged. In particular, zero, positive values, and negative values other than −1 all retain the incumbent.

The function does not treat an arbitrary negative return as a replacement decision. It also does not expose any dependency result as a separate error status.

### Completion

The function continues through index 4 regardless of which index is currently selected. It does not stop after finding an eligible record or after receiving a particular dependency result.

After the fifth visit, it returns the incumbent index, or −1 if no incumbent was ever established.

Assuming all calls return normally, the function makes exactly five direct eligibility reads. If \(k\) of those reads yield nonzero values, it makes no dependency calls when \(k=0\), and \(k-1\) calls otherwise. The maximum is four calls.

### Mutation-sensitive behavior

The order of reads and calls matters when the dependency changes accessible state.

A dependency call occurs after the current candidate’s eligibility read and before the next record’s eligibility read. Therefore:

- A change to a later record’s eligibility byte can affect whether that later record becomes a candidate.
- A change to an already visited record’s eligibility byte does not cause that record to be revisited.
- An incumbent is not rechecked for eligibility before being passed as the second dependency argument.
- A candidate’s eligibility is not reread after its dependency call. A return of −1 selects it even if the call changed its eligibility byte to zero.
- A change to the shared base location does not redirect this invocation’s later address calculations.

These statements describe the surrounding function’s read order. They do not assert that the dependency actually performs such mutations, nor that mutation is valid under its undisclosed contract.
