# F-20460b92cd86

## Purpose

F-20460b92cd86 selects a 32-bit result through two ordered comparison gates and, if neither gate succeeds, a field-based fallback.

The established selection priority is:

1. A value read from a first shared result slot when the first comparison returns zero.
2. A value read from a second shared result slot when the second comparison returns zero.
3. A previously read 32-bit field value, unless a subsequent read of that field is zero.
4. A value read from a shared fallback slot when that subsequent field read is zero.

The first gate does not use the supplied input. The second gate passes an address derived from the input to a dependency. The final selection reads directly from input-relative storage.

The names and surrounding operations suggest classification or lookup behavior, but that intent is not established. In particular, the comparison dependency is not sufficiently identified to establish string comparison, case handling, or the meaning of a nonzero result.

### Field-based fallback

This stage occurs only when both comparisons return nonzero.

2. The second read determines whether to replace that candidate with the shared fallback value.

The fallback slot is read only when the second field read is zero. The function does not require that the fallback value itself be nonzero.
