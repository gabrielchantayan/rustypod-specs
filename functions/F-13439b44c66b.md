## Behavior

### Numeric interpretation and observation rules

The following semantic quantities describe related effects without assigning meanings to the affected objects:

- **Shifted input:** the signed first argument shifted right by 23, subsequently represented as unsigned 32 bits.
- **Reduced payload:** shifted input minus 0x38, retaining 32 bits.
- **Masked difference:** shifted input minus 0xE0, retaining 32 bits, then clearing bit 31.
- **Half difference:** masked difference logically shifted right by one.
- **Halfword-region base:** twice the unsigned 32-bit difference between shifted input and 0xE0, retaining 32 bits.

The half difference is between zero and 0x3FFFFFFF. Narrow payloads retain the low 8 or 16 bits. These numeric definitions do not establish memory byte order.

Unsigned calculations above have a 32-bit interpretation. Other expressions involve signed additions, signed left shifts, address conversions, or shifts by 32. Their target semantics must not be replaced indiscriminately with unsigned wrapping arithmetic.

The ordering below is observable. Earlier writes may affect subsequent reads through aliasing. Distinct semantic names do not guarantee disjoint storage, and a global used again later must not automatically be treated as a preserved local copy. The representation does not settle finer evaluation ordering within individual expressions.

## Acceptance examples

These are conditional consequences of static evidence, not execution results. Each assumes the relevant stage is reached, required accesses succeed, and any stated arithmetic interpretation applies.

1. **Displacement versus payload.** A second argument of 0x00012345 produces first-write payload 0x2345 while retaining displacement 0x00012345.

2. **Byte-selected address.** An early lookup byte of 0xFF selects destination 0x11B for the later byte write. Its payload comes from the previously captured state-offset-0x5C word, not a mandatory reread.

3. **Uninitialized region head.** With no relevant aliases, the three 0xFFFF halfword writes leave region offset 0 unchanged. If that halfword is 0x1234, the subsequent indirect word write targets address 0x1234.

4. **Termination is not an entry guard.** A signed-negative first dependency address still has a preceding secondary-base-offset-4 halfword write in the represented ordering. This does not prove that the unresolved secondary base is usable.

5. **Repeated effects.** A nonnegative continuation must retain both halfword/self-address pairs, with the signed-halfword read between them. Collapsing each pair to its last write violates the access contract.

6. **Selector alternatives.** Clear dependency-address bit 2 gives selector 0x58, with word destinations 0x5C and 0x170. Set bit 2 gives selector 0x5C, with destinations 0x60 and 0x180.

7. **Pointer overwrite boundaries.** Without other aliases, pointer offset 0 holds the pointer-representation word after its self-write; the doubled-pointer read subsequently replaces a halfword there. Which two bytes of the prior word remain is endian-dependent.

8. **Distinct late families.** With pointer 0x1000, late source word 0x2000, compatible arithmetic, and no relevant aliases, pointer-family writes target 0x4000 and 0x4004. The separate late-source self-write targets 0x8000 and contains 0x8000.

9. **Concatenation is not write width.** A byte-alias value of 0xAB yields concatenated value 0x0005AB. This alone does not establish a three-byte store.

10. **Unused argument.** Changing only the third explicit argument, while preserving all other represented inputs and state, changes no visible operation.
