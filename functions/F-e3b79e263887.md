## Acceptance examples

These are conditional criteria, not executed tests.

### Width-sensitive transformation

If a relevant low component is 0x12345678 and its consumer receives a 32-bit left shift by eight, the argument is 0x34567800. An unbounded product is not equivalent.

If a paired result’s high component is 0x89ABCDEF, unsigned extraction after shifting the full pair right by 36 yields 0x089ABCDE.

### Unsigned byte propagation

If the initial offset-five read yields 0xFE, its corresponding word publication supplies 254, not −2, provided execution reaches that store.

### Constant-store ordering

If execution reaches all three 0x3A stores, the adjusted quantity has not yet been formed at the byte store but has been formed before the halfword and word stores. Those wider stores retain their loaded-word-derived destinations.

### Publication-base snapshot

If the fixed-location word read yields an address-bearing value and the subsequent 0x60 store affects the same underlying storage, publication still uses the already-retained value. Reading the publication base after the store is not equivalent.

### Distinct 0x67 observations

If intervening operations change the byte at 0x67, the copy to 0x21 and the two later offset-nine stores use their respective reload values. They need not equal the originally stored low byte of the 0xA9 word.

### Aliasing and repetition

If a prior store overlaps a later load, that load uses the then-current memory. If an observer records the successive offset-0x20 stores, it must distinguish 0x20, 0x2F, the byte-derived word, and 0x20; final-state equality alone is insufficient.

### Final transfer

If preceding operations complete, the first argument is 0x72. The remaining arguments preserve their distinct loaded-versus-saved origins, even when intervening writes modify the original locations.
