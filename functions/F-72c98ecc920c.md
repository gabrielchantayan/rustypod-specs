# F-72c98ecc920c

## Purpose

F-72c98ecc920c coordinates collaborator operations, branch-dependent notifications, a final update, and cleanup of local helper-managed values.

Its visible behavior distinguishes three cases:

- A negative signed selector.
- A nonnegative selector whose subsequent collaborator query returns unsigned 0 or 1.
- A nonnegative selector whose subsequent collaborator query returns an unsigned value of at least 2.

A narrowed receiver flag further controls message-resource selection. Resource naming suggests artist/album selection behavior; that domain interpretation is inferred intent, not an established description of the underlying data.

The function returns the 32-bit result of F-16012161395f. Earlier results are used for intermediate operations or ignored; they are not returned as status.

## Acceptance examples

These are conditional static scenarios, not executed tests. Each assumes that reached dependencies return normally and required storage remains valid.

1. **Negative-selector coverage.** Selectors −1, −2, and the minimum signed 32-bit value all skip indexed dispatch and the unsigned query. Each reaches the negative notification with `0x80` and is forwarded unchanged to F-16012161395f.

2. **Ordered helper arguments.** For selector 0, after indexed dispatch returns, F-46f0b3cb316e receives working-value offset `0x04` as argument 1 and indexed-temporary offset `0x04` as argument 2. Acceptance does not require either region to be copied into the other.

3. **Post-helper direct assignment.** If indexed-temporary offset `0x0C` contains `0x12345678` when F-46f0b3cb316e returns, the subsequent explicit assignment writes that pattern to working-value offset `0x0C` before indexed-temporary cleanup. Its value before the helper call is not decisive.

4. **Unsigned boundary.** For a nonnegative selector and a narrowed flag that is zero when read, query results 0 and 1 select the single-album-named resource; result 2 selects the multiple-albums-named resource. All cases perform service notification and final update.

5. **High-bit query result.** Query result `0xFFFFFFFF` belongs to the at-least-2 branch. It is not treated as signed −1.

6. **Narrowed flag.** If the full receiver field is nonzero but its narrowed eight-bit value is zero, selection follows the zero-flag case. A full-width nonzero test would be incorrect.

7. **Late flag mutation.** If a preceding service-notification call changes the flag, message selection uses the narrowed value observed afterward. A nonzero value selects the shared alternate resource on either selector path.

8. **Negative zero-flag resource.** A negative selector with a zero narrowed flag selects the address exactly one byte past the all-albums-named resource base. No particular displayed text is required without resource contents.

9. **Message value and result preservation.** Receiver notification receives F-9b9c1c7483f4’s returned value. Separately, if F-16012161395f returns a particular 32-bit pattern and final cleanup returns normally, F-72c98ecc920c returns that pattern unchanged.
