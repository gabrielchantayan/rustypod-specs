# F-224b08a286ab

## Purpose

F-224b08a286ab invokes three dependencies, performs two 32-bit writes relative to the second dependency’s result, and performs three further writes relative to the third dependency’s result.

The established behavior is an ordered sequence of calls, global reads, and memory writes. Allocation, construction, and subobject initialization are possible interpretations, not established requirements. The available evidence does not establish that any dependency succeeds, that returned addresses identify valid objects, or that the affected memory remains available afterward.

A significant value-flow distinction is that Global A is read **twice**. Its first observed value supplies the adjusted value written at object offset `0xD0`; its second observed value supplies the value written at object offset `0x00`. Equality between those observations is not guaranteed by the supplied representation.

No disjointness checks are visible. Overlap involving the adjustable 16-bit destination therefore makes write order significant.

Under ordinary byte-address interpretation, without address wrap or distinct addresses mapping to the same physical storage:

- The fixed 32-bit write occupies final-base offsets `0x30` through `0x33`.
- The fixed zero-byte write occupies final-base offset `0x38`.
- Those two fixed destinations do **not** overlap.
- The adjustable 16-bit write can overlap the 32-bit destination or the zero-byte destination, depending on Global B.
- Where the adjustable write overlaps the earlier 32-bit write, its bytes replace the overlapping bytes.

The final zero-byte write does not directly overwrite the fixed 32-bit write under this interpretation. Additional physical-memory aliasing would require an environment property not established by the evidence.
