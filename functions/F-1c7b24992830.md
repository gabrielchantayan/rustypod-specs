## Acceptance examples

### Compact boundary and widening

### Early fixed-address ordering

If address 5 supplies 200, its captured value remains the base for the specified offset-21 write and offset-84 snapshot even if the later address-1 write aliases storage affecting address 5.

Acceptance preserves address-5 read before address-1 publication, address-84 word publication from the retained-base left shift, and the later address-21 byte publication from the compact base.

### Publication-base aliasing

Suppose the stored publication-base word contains one value after the offset-32 sequence, but the address-96 write changes its storage. Repetition uses the value captured before address 96, not the changed word. Aliasing during repetition likewise does not cause a reload.

### Address-58 snapshot boundary

Under low-eight-bit arithmetic, post-subtraction value 106 produces byte 128 at address 58: \(106\times8+48=896\).

The address-169 and calculated offset-116 snapshots precede that write. The work-base offset-20 and publication-arithmetic-base offset-four snapshots follow it and must reflect any applicable overlap.

### Address-103 reloads

If address 103 initially receives 171 but an intervening calculated store changes it to 42 before a later specified read, that later publication uses 42. Reusing 171 would violate the fresh-read dependency.

### Aliasing and partial execution

A word cleared before intervening writes reads back as zero only if those writes do not modify its bytes and the memory environment supplies ordinary storage behavior.
