## Acceptance examples

These examples are conditional consequences of the static representation, not executed tests.

1. **Unsigned address-bearing halfword.** If the initial unsigned halfword is `0xFFFF`, its value is 65535. Its word-store destination at offset `0x08` is `0x00010007`, not an address based on signed −1.

2. **Signed payload widening.** A signed halfword with bits `0x8000` supplies word payload `0xFFFF8000` when widened for the initial signed-halfword store.

3. **Independent A and B.** If A is 3 and B is 7, the table word is stored at `0x0B`, the later A-derived word read uses `0x2B`, and the final B-derived byte destination is `0x23`. The word stored at shifted argument plus `0x40` contains 3; the byte stored at working base plus `0x10` contains 7.

4. **Negative first dependency address.** If that address is negative as signed 32-bit, and preceding accesses complete, the halfword store at unresolved base plus `0x04` precedes the first invalid-instruction boundary. Later operations are not represented on this branch.

5. **Computed-address mutation.** If the self-address store changes the computed-address global through aliasing, the next destination uses the value read afterward plus `0x04`, not necessarily the originally assigned product.

6. **Late-base destination operand.** If the late base is `0x100` and the represented signed shifts have their ordinary arithmetic results for these operands, the shifted destination term is zero. The destination is therefore `0x100`; the payload still depends on the second dependency address.

7. **Fresh composite input.** If an intervening write changes the upper-halfword global to `0x1234`, and it remains unchanged until the final read, the composite is `0x1234EA70`, regardless of the earlier assignment.

8. **Access failure.** If an early access cannot complete, later global updates and either invalid-instruction boundary need not be reached. No explicit rollback is represented; persistence and visibility of earlier effects remain unresolved.
