## Behavior

The offset is applied in bytes. Adjacent effective offsets select adjacent byte addresses. No multi-byte entry width, stride greater than one, or additional indirection through a table entry is visible.

### Lookup sequence

The established logical sequence is:

1. Obtain the base value from the shared location.
2. Select the byte address at the effective offset from that base.
3. Read one byte from that selected address.
4. Return the byte read.

Computing the effective offset requires no externally visible memory access. Its timing relative to obtaining the base is not important to the established contract. The selected byte read depends on the obtained base.

There is no visible loop, retry, fallback lookup, or second candidate address. A normal invocation performs one selected-byte lookup. It does not scan the range or require every possible entry to be read.
