# F-957d746db33b

## Purpose

F-957d746db33b transforms primary byte input into caller-provided output using local staging, repeated dependency calls, conditional mixing, an optional in-place transformation, and final table mapping.

The retained outer position advances by 16 after each completed iteration. This supports an inference of block-oriented intent, but does **not** establish a 16-byte access footprint, conventional block boundaries, or that argument 5 is a byte length. Global-dependent conditions and address calculations govern the actual accesses.

This contract distinguishes:

- **Established static evidence:** visible accesses, calls, arithmetic widths, and capture/reload boundaries.
- **Conditional interpretation:** algebraic conclusions requiring consistent 32-bit arithmetic and stable reads where identified.
- **Inferred intent:** apparent block processing, without an established algorithm or protocol identity.
- **documented_only:** behavior requiring unavailable global contents, dependency contracts, or target execution semantics.

No runtime tests have been performed.

### Entry state and outer continuation

- **Offset scalar:** contributes to entry adjustments, local indices, and external addresses.
- **Origin scalar:** initializes the outer position and several later counters.
- **Control scalar:** contributes to repeated transformations, mixing selection, and other arithmetic.

Other global boundary, mask, and address-forming values also participate. None is assumed immutable.

Before processing, the function captures:

1. An adjustment from argument 5 minus an offset-scalar read.
2. An adjustment from argument 4 minus a separate offset-scalar read.
3. Another continuation adjustment involving origin-scalar evaluations, a signed shift by 31, and another argument-5-minus-offset evaluation.

These evaluations must not be collapsed into one global snapshot. The captured adjustments are retained across calls and outer iterations; later global changes do not recompute them.

At each outer-loop head, the function captures the negation of the retained outer position. Continuation combines that value, retained entry controls, and fresh global reads. Termination returns zero before that iteration performs acquisition, dependency calls, or output writes.

A completed iteration advances the retained outer position by 16. Later origin-scalar reads initialize stage-specific counters, not a replacement outer position.

**Shared-table destination.** Argument 24 supplies the table. The destination displacement contains the retained outer position, the output counter, and **one offset-scalar read multiplied by two**. This does not make that read identical to offset reads used elsewhere in the same iteration.

**Position-dependent destination.** Argument 22 supplies the tables. After preparing the working-byte-derived value, the function captures an intermediate displacement containing:

- Retained outer position.
- Current output counter.
- One offset-scalar read.

The following output assignment forms its destination by adding a **separately evaluated offset-scalar read** to that retained displacement. The intermediate is not recomputed if the later read differs.

Consequently, the position-dependent destination is equivalent to “outer position plus counter plus twice the offset” only if the two reads agree **across the intervening statement boundary**. Stability merely within each individual expression is insufficient.
