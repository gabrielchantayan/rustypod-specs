# F-d87b4883d945

## Purpose

Its directly established behavior is:

- Initialize using an address derived from the second input.
- Initialize using an address derived from the first input.
- Acquire a first integer result through a two-call dependency sequence.
- Acquire a second integer result through the same dependency sequence, using a different local scratch address.
- Return their arithmetic difference if they differ.
- Return zero if both are zero.
- Otherwise repeat the acquisition and comparison.

This resembles comparison of two sequences terminated by zero. That interpretation is inferred intent, not an established contract of the dependencies.
