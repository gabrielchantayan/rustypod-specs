# F-1122df39285e

## Purpose

F-1122df39285e conditionally produces a pointer-valued result using two dependencies: one obtains a candidate storage address, and another returns a status while receiving access to a mutable, local 32-bit value.

The established success behavior is narrow: the function stores a nonzero dependency result at byte offset 8 from the candidate address, stores the resulting local value at byte offset 0, and returns the candidate address. If the status is zero, it passes the candidate address to a cleanup dependency and returns null. If the candidate address is null, it invokes a reporting dependency and, if that call returns normally, returns null.

Interpreting this as construction of an object is plausible but inferred. The supplied evidence does not establish an object type, allocation units, ownership policy, or the meanings of either stored word.

### Non-null candidate path

When that call returns normally, its 32-bit result is stored at byte offset 8 from the candidate address. This write occurs before the function selects the success or cleanup path. Consequently, the offset-8 write also occurs when the returned status is zero.

The offset-8 write precedes the offset-0 write. The visible function does not call its cleanup dependency on this path.

If F-3e73fa53d4da leaves the local slot unchanged, the offset-0 word receives the original fourth argument. If the dependency changes the slot, the offset-0 word receives that changed value. The function performs no visible validation or transformation of it.
