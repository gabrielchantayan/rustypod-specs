These are conditional static examples, not executed tests. Each assumes all preceding operations complete and the stated observations occur.

2. **Selector width.** A selector byte of \(0xff\) selects byte address \(0x110\), without a pointer-width load from the selector location.

4. **Global sampling order.** The initial word store precedes the global read. A sampled global value of \(0xffc00000\) supplies byte \(0xff\) to the first selector-directed write.

5. **Unresolved call-site argument.** The call following the first shifted-word store receives zero as its first argument under modular arithmetic. Its second argument remains whatever unresolved register-state value is present then; the displayed entry arguments do not determine it.

6. **Independent late sources.** With \(N=0\) and \(O=1\), the replacement second hidden base is zero, while the later store at \(W(16R+0x14)\) writes \(0x80000000\). With \(N=3\) and \(O=0\), that base is \(0xc0000000\), while the word is zero.

7. **Direct clear ordering.** Each late clearing pair writes zero at the replacement base plus \(0x11\) before writing zero at base plus 1, without loading a selector for either destination.

8. **Late read boundaries.** \(P=0\) selects word-read address \(0x14\); \(P=0x3fffffff\) selects \(0x413\). The latter is not word-aligned.

9. **Final selector reread.** If intervening calls change the final selector after the write of \(b(S_2(U))\), the later read may choose a different destination for \(e(U)\) and a different next-iteration first hidden base.

10. **Conditional repetition.** If all calls return and accesses succeed indefinitely, iterations continue indefinitely. A dependency that never returns prevents all subsequent operations from being reached.
