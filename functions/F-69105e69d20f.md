## Purpose

### Important width consequences

Under the stated bit-vector interpretation:

- \(L_{28}(S)=0\), because \(S=L_{12}(R)\). Epoch 2 still contains the call and both explicit argument positions.
- \(K=L_{30}(j)\) has only four possible values: zero or one of the three nonzero multiples of \(2^{30}\).
- \(L_{31}(k)\) depends only on the low bit of \(k\).
- \(E(q)+20\) ranges from 20 through 1043. The word read in epoch 13 is not necessarily aligned.
- Byte-selected addresses plus 17 range from 17 through 272. The retained-selector word address \(\beta+20\) ranges from 20 through 275 and is not necessarily aligned.
- \(B(E(x))\) retains original bits 20–27; original bits 28–29 are discarded by the byte store.
- \(B(L_2(x))\) retains original bits 0–5, shifted into byte bits 2–7.
- \(B(G\gg22)\) retains original bits 22–29.

These relationships do not establish that the resulting addresses are valid.

## Side effects

### Memory ordering and aliasing

No disjointness is established among:

- Explicitly computed word addresses.

## Acceptance examples

These examples are conditional static acceptance criteria, not executed tests.

1. **Initial write precedes all calls.**  
   Given a valid initial base and byte value, the first direct memory effect is that byte written at the base plus 17. The first dependency call follows it.

2. **Fourth-argument scaling.**  
   If \(C=2\) and \(R=3\), epoch 1 writes word 12288 at address 8212, assuming valid memory and the stated arithmetic model.

3. **A zero-valued argument does not remove its call.**  
   In epoch 2, the third call’s first explicit argument is zero under 32-bit arithmetic. The call still occurs, and its other argument remains observable.

4. **Selector rereads observe mutation.**  
   If epoch 3 reads selector 5 and intervening dependencies change \(H+1\) to 9, epoch 3 writes at address 22, while epoch 4’s clear writes at address 26.

5. **Retained selector is stable across calls.**  
   If epoch 16 retains \(\beta=7\), epoch 17 writes its word at address 27 even if intervening dependencies change \(K+1\).

6. **High-bit payload is not a general multiplication result.**  
   If \(k\) is even, epoch 13 writes zero. If \(k\) is odd, it writes the word with only bit 31 set.

7. **Repeated clears remain observable.**  
   Both clear pairs in epochs 11 and 12 occur. A dependency may modify either location between the pairs.

8. **Continuation has no normal exit.**  
   If all accesses succeed and every dependency returns, epoch 26 transitions directly to another iteration. The next initial byte value is zero, not the initial caller-supplied byte state.
