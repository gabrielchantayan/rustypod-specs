## Behavior

If its result is null, the subtraction is skipped. Execution nevertheless continues to the first table lookup using the null address.

Consequently, the null check is not a null-result exit path. A null acquisition result has no established successful or recoverable outcome. The visible path attempts to obtain an object word through a null base before it can invoke the first query. Depending on the actual execution environment, that access may fault or otherwise lack defined behavior. No particular exception, signal, or return behavior is established.
