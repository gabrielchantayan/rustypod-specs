## Acceptance examples

These are conditional static criteria, not executed tests.

- **Third-input shift:** under a 32-bit bit-vector interpretation, an input of 1 supplies 8 at the early three-bit-shifted argument position. An input of 0x20000000 supplies zero there after truncation; whole-execution equivalence to input zero does not follow.
- **Compact boundary:** relevant low seven bits all zero produce compact base zero; all one produce compact field 508 and compact base 1016.
- **Byte extension:** a scaled-anchor offset-5 byte of 0xE7 supplies word value 231, not a sign-extended negative value.
- **Fixed-byte address capture:** if 0x05 yields 0xE7, its subsequent offset-0x15 destination is 0xFC. The 0x01 write occurs between the read and that computed store; changing 0x05 afterward does not change the captured base.
- **Anchor snapshot:** if the fixed anchor load yields an address and a later aliasing write changes its original storage, subsequent publications still use the captured address. The fixed 0x60 store occurs after capture.
- **Fixed snapshot versus reread:** if 0xA9 yields 0x123456E7, the later explicit write to 0x67 uses 0xE7, and the full snapshot publication uses 0x123456E7. Subsequent changes to 0xA9 do not replace those captured values.
- **Mutable 0x67:** if intervening aliasing or mapped-memory behavior changes 0x67 between its three reads, the write to 0x21 and the two computed offset-9 writes may receive different bytes. Reusing one cached byte for all three is not justified.
- **Ordered literal overwrite:** ordinary non-overlapping memory leaves 0x20 at the four-write word destination, but acceptance in an access-observable environment must also preserve the intervening byte read.
- **Final transfer:** reaching the final target establishes first argument 0x72, not successful return.
