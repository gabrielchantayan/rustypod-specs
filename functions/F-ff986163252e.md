# F-ff986163252e

## Purpose

F-ff986163252e initializes a six-byte region at a caller-supplied destination. It copies a four-byte value from a shared source cell into the first four bytes, writes zero into the fifth byte, and writes a supplied one-byte value into the sixth byte.

This is a description of the behavior established by the supplied static evidence. The meaning of the copied value and the two trailing bytes is not established. In particular, the evidence does not identify them as a type tag, status field, flag, character, or object header.

The function has no explicit return value. Its useful result is the modification of destination memory.

## Behavior

### Ordered effects

1. Obtain the four-byte value from the shared source cell and store that value at destination offsets zero through three.
2. Store a zero byte at destination offset four.
3. Store the supplied trailing byte at destination offset five.
4. Return without an explicit result value.

The source-cell read supplies the value for the first store and therefore precedes that store. The subsequent two stores follow the first assignment in the supplied representation.

This ordering describes the operations expressed by the static evidence. It does not establish atomicity, synchronization, hardware transaction boundaries, or the observations available to another thread, interrupt handler, device, or signal handler.

### Value handling

For example, a zero trailing input produces zero in both offsets four and five. A trailing input with all bits set produces zero at offset four and an all-bits-set byte at offset five.
