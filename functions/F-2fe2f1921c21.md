## Purpose

No application-level purpose is established. Address-valued stores suggest connections between memory regions, but do not establish a collection, allocator, ownership protocol, or initialization routine.

This contract separates:

## Behavior

### Widths, notation, and ordering

Offsets are in bytes. Memory accesses are 8, 16, or 32 bits wide. Unless explicitly identified as byte or halfword operations, the reads and writes below are 32-bit operations.

Byte and halfword stores retain the corresponding low-width payload. A 32-bit source read remains a full-width access even when only its low byte is subsequently stored.

Halfword reads are signed 16-bit reads. Their wider uses use the signed value, not zero extension. Plain-byte signedness is unresolved, including when a loaded byte becomes an address or a halfword payload.

Address calculations involve represented 32-bit values, signed narrow values, sums, multiplication, doubling, tripling, and left shifts by 1, 4, and 8. No universal wrapping contract is established. Overflow, invalid signed shifts, address wrapping, alignment, and byte order are **documented_only**.

The following are specification labels, not implementation identifiers:

- **S-01 through S-22:** external selector expressions in encounter order.
- **B-01 through B-22:** their first captured values, used as region bases.
- **D-01 through D-22:** bases whose offset-68 fields receive the corresponding selector’s second evaluation.
- **L-01 through L-22:** captured payloads written at offset 20 of the corresponding B region.
- **W:** the current working base, initially E.
- **R:** a retained region captured in the S-13 window.
- **H:** the signed halfword captured in the particular window under discussion.

Labels do not imply disjoint storage. Captures are not permission to reread their sources. Later reads occur after earlier writes, including overlapping writes.

### Selector-boundary rule

Each boundary has three ordered events:

1. Capture the external expression as B.
2. Evaluate that same expression again and write the result at D offset 68.
3. Write the already captured L at B offset 20.

The two external evaluations are distinct. Their equality requires suitable stability conditions; it is not unconditional. The selected-region write follows the offset-68 write.

No selector is an entry-time snapshot. Each is evaluated after its entire preceding window.

1. Signed-value-base offset 84 receives that base.
2. B-22 offset 17 receives W’s low byte.
3. Signed-value-base offset 84 receives that base again.

## Acceptance examples

These are conditional static obligations, not executed tests.

1. **Initial overlap:** If E offset 17 overlaps argument 1 offset 100, the argument-4 byte write precedes the first full-width read. The later argument-derived replacement does not erase this ordering.

2. **Early signed reads:** If D-02 offset 52 overlaps E + B-01, H is captured before that self-address write. In S-03, H likewise precedes D-03’s writes, while the auxiliary-base read falls between D-03’s offset-13 and offset-84 writes.

3. **Split pointer chain:** If the S-06 auxiliary-offset-21 byte overlaps the captured intermediate region’s offset 20, D-06 is obtained by reading after that byte write. The earlier E-offset-68 read is not repeated.

4. **Previously omitted effects:** The doubled-base byte writes before S-12, S-13, S-17, and S-18 must occur even if later offset-17 writes replace them. S-18’s W-offset-84 self-address write precedes both S-18 evaluations.

5. **S-22 destination:** The second before-definition byte is written to old W offset 17, not L-21 offset 17, between the L-21-offset-84 write and D-22-offset-68 write.

6. **Selector capture:** If the two S-17 evaluations differ under the applicable memory model, B-17 retains the first value and D-17 offset 68 receives the second.

7. **Signedness and width:** A halfword representing minus two contributes minus two when widened. A byte pattern FE has unresolved wider interpretation. A byte payload sourced by a 32-bit read does not permit narrowing that source access.

8. **Late interleaving:** If signed-value-base offset 84 overlaps B-22 offset 17, the alternating self-address and byte writes remain alternating; grouping identical writes is not equivalent.

9. **Known late byte:** If B-22 offset 17 overlaps the first product’s offset-116 source, the saved-pre-overwrite-value byte write occurs before that source is read.

10. **Late reread:** If B-22 offset 100 overlaps the second product’s offset 68, the reread observes memory after the full-width offset-100 store and intervening byte write. Reusing the earlier read is insufficient.

11. **Continuation:** A nonreturning first dependency prevents the represented second call. If it returns after mutating the second call’s external source, that source is evaluated afterward. If both calls return, the annotated nonreturning operation is reached rather than an ordinary return.
