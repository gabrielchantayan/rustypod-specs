# F-1a1143dd2594

## Purpose

F-1a1143dd2594 performs an ordered sequence of address-derived memory accesses and six external calls. The supplied representation ends at a bad-instruction marker rather than an ordinary return.

No application-level purpose is established. Descriptions such as initialization, allocation, object construction, device configuration, or cleanup would require evidence not supplied here.

This contract describes the visible static behavior, conditional on each preceding operation completing. It does not establish that the representation is a complete, executable routine. In particular, a right shift by the operand’s full width, potentially overflowing signed arithmetic, and invalid instruction data prevent an unconditional portable-language interpretation.

## Behavior

### Initial writes and captured values

The initial sequence is:

1. Calculate **Small scale** as Index multiplied by 0x200, using the represented signed arithmetic.
2. Write its halfword-narrowed value at address Small scale + 8.
3. Write Stack halfword to Pair pointer’s second halfword, at byte offset 2.
4. Read a 32-bit value at the address obtained from Index multiplied by 0x200000. Retain this as **Captured word**.
5. Write a zero halfword at the address obtained from Index multiplied by 0x200000, plus 32 bytes.
6. Write the halfword-narrowed numeric value of Pair pointer to Pair pointer’s first halfword.
7. Read Scale seed from its designated global location.
8. Overwrite Pair pointer’s first halfword with the halfword-narrowed Captured word.
9. Calculate twice the signed integer interpretation of Pair pointer’s numeric value. The representation assigns this 32-bit result to an entry-stack-associated slot at offset zero and uses it as the first call argument.
10. Capture Code base before the first call.

The displacement in step 5 is **32 bytes**: the represented addition advances by eight 32-bit elements before the halfword store.

The two writes to Pair pointer’s first halfword are separate represented effects. The later write does not justify omitting the earlier one when access ordering, faults, or externally observable storage matter.

The accesses are not assumed disjoint. For example, an early store could affect Captured word or Scale seed if their storage overlaps its destination. Scale seed is read between the pointer-derived and Captured-word-derived writes to Pair pointer’s first halfword.

### First call and full-width shift

The first dependency, **F-00000001**, is called through the target:

**(Link value AND 0xFFFFFFFC) + 4**

This calculation uses the unsigned 32-bit Link value, including wraparound of the addition. Its represented arguments are, in order:

1. twice the numeric Pair pointer, calculated as above;
2. captured Scale seed;
3. Small scale.

After this call returns, **Shift result** is formed by right-shifting Shift input by 32 and assigning the result to an unsigned 32-bit quantity.

For a 32-bit operand, this shift count is outside the valid language-level range. The supplied representation does not establish whether a concrete instruction masks the count, produces a sign-dependent result, or behaves otherwise. All later behavior depending on Shift result is conditional on a chosen concrete interpretation; no default result is assumed.

### Scaled writes and selector capture

Using the previously captured Scale seed, calculate **Expanded scale** as Scale seed multiplied by 0x800.

The following accesses occur in order:

1. Write the halfword-narrowed Expanded scale at address Expanded scale + 0x38.
2. Read an unsigned byte at address Expanded scale + Index and retain it as **Selector**.
3. If Secondary result equals zero, write the 32-bit value Expanded scale + 0x14 at address Expanded scale + 0x54.

These arithmetic expressions retain their represented signed-arithmetic limitations.

The selector read precedes the conditional word write. If they overlap, Selector remains the value read before that write.

A nonzero Secondary result skips only the conditional store. It does not skip the subsequent combined-value accesses or later calls.

### Combined-value writes

Define:

- **Combined value**: the unsigned 32-bit sum of Shift result and Secondary result, with Secondary result converted to unsigned.
- **Doubled bits**: Combined value multiplied by two in unsigned 32-bit arithmetic.
- **Doubled value**: the signed integer representation to which Doubled bits is assigned.

The sum and multiplication wrap modulo \(2^{32}\). Conversion of Doubled bits to a signed integer is not independently resolved when the unsigned value exceeds the signed range.

The represented stores occur in this order:

1. Write Doubled value as a 32-bit word at address Selector + 0x28.
2. Write Doubled value as a 32-bit word at the address represented by Doubled value itself.
3. Write a halfword at address  
   **8 + ((Combined value AND 0x7FFFFFFF) logically shifted right by 17)**.

The third store’s value is Doubled value converted to unsigned 32 bits, logically shifted right by 18, then narrowed to 16 bits.

Selector is an unsigned byte, so the first destination is numerically between 40 and 295 inclusive. The third destination is between 8 and 16,391 inclusive. No alignment adjustment is visible.

The second store requires an interpretation of the integer-derived pointer, including high-bit-set Doubled value cases.

### Character read and returned-pointer handling

Calculate a 32-bit unsigned address by XORing Selector with Shift result, then multiplying by 0x200. This multiplication wraps modulo \(2^{32}\).

Read one character-width value at that address and convert it to an integer argument for **F-00000005**.

Its target is:

**0x0897EF69 + 0xA84 = 0x0897F9ED**

Unlike Selector, this read uses a character type whose signedness is not supplied. A byte with its high bit set can therefore produce different integer arguments under signed-character and unsigned-character interpretations.

F-00000005 returns a value used as a pointer to halfword storage. The next operations are:

1. Write a zero halfword through that pointer.
2. Call **F-00000006**, passing that same pointer.

The sixth target is:

**(0x0897F3D5 AND 0xFFFFFFFC) + 0x604 = 0x0897F9D8**

There is no null, alignment, bounds, or accessibility check before the halfword write. If that write fails, F-00000006 is not reached.

Neither the returned pointer’s storage class nor its ownership is established.

### Final writes and termination

After F-00000006 returns, the represented sequence is:

1. Write the halfword constant **0xF484** at the address formed by shifting Index right by 4.
2. Write a zero 32-bit word at the address formed by shifting unsigned Shift result left by 3.
3. Form **Final address** by shifting Index right by 31 and converting the result to a character pointer.
4. Write the byte-narrowed shift result at Final address.
5. Store Final address through Output pointer as a represented 32-bit value.
6. Write the halfword-narrowed result of Index shifted right by 31 at Final address + 0x34.
7. Reach the bad-instruction marker.

The left shift of unsigned Shift result retains a 32-bit result. The right shifts of signed Index require a concrete rule for negative operands.

The Output pointer store precedes the final halfword store. Failure of the latter does not imply that the output location remained unchanged.

No ordinary return follows in the supplied representation.
