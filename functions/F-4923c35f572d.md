It then obtains the dispatch-table reference stored at the beginning of that object. From the referenced table, it obtains the callable entry at byte offset 224, equivalent to hexadecimal offset E0.

1. The object address returned by F-e2d601cfddc7.

After the indirect call returns normally, the function calls F-876f4b90d114 with the two original inputs. The second input is not normalized to 1 for this forwarding call: its original signed 32-bit value is retained.
