## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Explicit byte truncation.** An explicit computed byte store supplied 0x123456AB stores 0xAB if it completes. This does not establish the width of a named fixed-address assignment.

2. **Established unsigned expansion.** An explicitly unsigned computed byte read yielding 0xFE expands to 254. This applies to the represented offset-5 byte reads, not automatically to fixed storage at 0x05.

3. **Unresolved fixed-source type.** If 0x05 is an unsigned eight-bit source containing 0xFE, conversion yields 254. If it is a signed eight-bit source representing −2, conversion to unsigned 32 bits yields 0xFFFFFFFE. The supplied evidence does not select either declaration.

4. **Masked selection.** Retaining twenty low bits of 0xFFFFFFFF and shifting right ten yields 1023. Shifting that field left six yields 65472.

5. **Distinct result words.** Given a 64-bit result with high word 0x12345678 and low word 3, shifting the low word left eight yields 0x300. Forwarding the unshifted high word preserves 0x12345678.

6. **Fixed chronology without invented widths.** The named 0x05 read precedes the named 0x01 assignment. The named 0x54 assignment precedes the named 0x15 assignment, with intervening computed accesses retained. Neither criterion requires guessing named access widths.

7. **Captured address.** If the 0x60 assignment changes storage overlapping the separately named address source, subsequent publication still uses the already captured 32-bit address-bearing quantity.

8. **Ordered overwrite.** If the four computed offset-0x20 word stores complete in ordinary non-aliased memory, the destination ends at 0x20. One final store does not preserve the intermediate sequence.

9. **Terminal capture.** A later change to the 0xA9 source does not refresh the saved 32-bit capture. This criterion does not require a four-byte source read.

10. **Fresh 0x67 values.** If successive fresh 0x67 reads yield values whose low bytes are 0x34 and 0x56 at the two computed offset-9 copies, those explicit byte destinations receive 0x34 and 0x56 respectively. Reusing the earlier supplied value is unjustified. The named 0x21 assignment additionally depends on its missing destination declaration.

11. **Oversized shift.** A terminal shift count of 40 has no exact resulting-byte requirement under this contract alone.

12. **Interrupted execution.** If an indirect invocation never returns, later direct mutations are not reached. Completion and rollback are not promised.
