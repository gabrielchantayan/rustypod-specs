# F-0b4658e20c99

## Purpose

F-0b4658e20c99 conditionally updates a memory-resident counter and selects its return value according to a one-byte flag.

Its distinguishing behavior is that the returned value has two different meanings:

- When the flag is zero, the function returns its original argument unchanged.
- When the flag is nonzero, the function increments a counter and returns an unsigned byte read from a different field.

The function does not return the updated counter. It does not clear the flag or modify the byte selected for return.

This contract describes the behavior established by the supplied static representation. The domain meaning of the fields is unknown. Calling them a flag, a result byte, and a counter describes their observed uses, not an established application-level purpose.

## Behavior

### Preconditions

If the flag is nonzero, the counter must also permit a signed integer read and write, and the result byte must permit a byte read. Any alignment requirement for the counter depends on the target platform and is not specified by the supplied material.

The function performs no explicit checks that establish these preconditions.

### Zero-flag path

The function first reads the byte at offset +9 and compares it with zero.

If the byte is zero:

- The original argument is returned unchanged.
- The result byte is not read.
- The counter is neither read nor written.
- No memory write is shown.

The original argument is returned as a value. The function does not read a value from the base address for this return.

### Nonzero-flag path

If the flag is nonzero, the established sequence is:

1. Read the signed integer counter at offset +12.
2. Compute that counter value plus one.
3. Write the incremented value back to the counter location.
4. Read the unsigned result byte at offset +10.
5. Return that byte’s value, widened to the return type.

The counter update precedes the result-byte read in the supplied representation. The function does not obtain the result byte first and then perform the update.

Every nonzero flag value selects this path. The flag need not equal one. Whether the flag byte is interpreted as signed or unsigned does not change the zero-versus-nonzero decision.

The flag is read once in the supplied representation. No second flag check is established before the counter update or before the result-byte read.
