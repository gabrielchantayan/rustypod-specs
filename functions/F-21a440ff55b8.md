# F-21a440ff55b8

## Purpose

F-21a440ff55b8 repeatedly invokes opaque dependencies and transfers values among global, ambient, fixed, returned, and computed addresses. Its explicit memory accesses use 8-bit, 16-bit, and 32-bit widths.

No application-level purpose or data-structure interpretation is established. In particular, the accessed locations are not established to be allocated objects, buffers, device registers, or conventional stack storage.

The represented control flow is an unconditional loop without an ordinary return. Each iteration reaches software breakpoint **0x92** if preceding operations complete. Operations after that breakpoint require execution to continue beyond it.

This contract distinguishes:

- **Established static evidence:** represented calls, access widths, ordering, arithmetic, retained values, and equalities between calculated call-target addresses.
- **Inferred intent:** possible interpretations that impose no requirements.
- **documented_only:** unresolved behavior, including dependency implementations, environmental effects, and arithmetic outside established domains.

No runtime execution or tests have been performed.

## Interface

| Quantity | Established width |
|---|---:|

For split results, **low** and **high** mean the low and high 32-bit halves. They do not establish separate language-level return values.

Unsigned halfword reads yield values from 0 through 65535. When subsequently stored as words, these values have zero upper halves. Byte and halfword writes transfer the corresponding low-width payload.

Unsigned shifts and arithmetic operate at 32-bit width. Signed additions, signed left shifts, and signed multiplication must not generally be treated as unsigned wraparound. Their behavior outside the defined signed domain is **documented_only**.

One expression requires a mixed-signedness distinction: F-U06’s second argument first adds the signed 32-bit interpretations of the first split result’s high and low halves. Only after that signed addition is its result converted to unsigned 32-bit and added to an unsigned, zero-valued byte term. The final argument is therefore unsigned; the initial addition remains subject to signed-overflow uncertainty.

Byte order, alignment requirements, address mapping, and memory-fault behavior are **documented_only**.

## Behavior

F-U01 through F-U37 identify call sites in execution order, not necessarily distinct dependency implementations. Established shared targets are listed under Dependencies.

### 1. Initial calls and first captured base

At the start of each iteration, establish zero-valued byte state and invoke **F-U01** with two zero arguments. Its target is calculated from the represented link-related state plus **0xFFE**. On initial entry, that state is ambient.

Then, in order:

1. Invoke **F-U02**, then **F-U03**.
2. Read the first global word and retain it as the **first captured base**.
3. Invoke **F-U04**.
4. Invoke **F-U05**, obtaining the **first split result**.
5. Invoke **F-U06** with:
   - First argument: the signed 32-bit interpretation of the low half.
   - Second argument: add the signed 32-bit interpretations of the high and low halves; convert that intermediate result to unsigned 32-bit; then add the unsigned zero-valued byte term.
6. Store an additional byte output from F-U06 at **first captured base + 0x11**.
7. Invoke **F-U07**.
8. Store a zero byte at **first captured base + 0x15**.
9. Invoke **F-U08**, obtaining a halfword payload and an additional address output.
10. Store that payload as a halfword at **F-U08 additional address + 0x0C**.

F-U05 and F-U06 have equal calculated target addresses. They remain separate invocations with different represented input and output uses.

The first captured base is read before F-U04 and is not explicitly reloaded for either byte store. A dependency’s modification of the global location does not introduce a represented reread. Preservation of underlying machine state across unresolved dependencies is **documented_only**.

### 2. Second split result and early stores

Invoke **F-U09**, obtaining the **second split result**.

Continue in order:

1. Store a zero halfword at **high(second split result) + 0x2C**.
2. Store **low(second split result) logically shifted right by 26** as a word at **frame base + 0x26C**.
3. Establish the working constant **0x21C48960**.
4. Invoke **F-U10**.
5. Read a word at **frame base + 0x320**, retaining it as the **indirect base**.
6. Invoke **F-U11**, then **F-U12**.
7. Store **low(second split result) shifted left by two at unsigned 32-bit width** as a word at **indirect base + 0x54**.

The right-shift result lies between 0 and 63. The unsigned left shift discards the original upper two bits.

The indirect base is retained across F-U11 and F-U12; its source location is not explicitly reread for the store.

### 3. Fixed-address read and breakpoint

Invoke **F-U13**, **F-U14**, **F-U15**, **F-U16**, and **F-U17**, in order.

Then:

1. Read an unsigned halfword at **0x21C48994**, retaining its zero-extended value as the **small base**.
2. Invoke **F-U18**.
3. Read a word at **frame base + 0x280**.
4. Pass that word to **F-U19**, retaining its word result as the **index result**.
5. Execute software breakpoint **0x92**.

No branch bypassing the breakpoint or local recovery handler is represented.

Exactly **six explicit stores** precede the breakpoint: two byte stores, two halfword stores, and two word stores. If execution reaches and stops at the breakpoint, these six store operations have executed, while none of the nine subsequent explicit stores has executed. This does not guarantee that earlier stored values remain unchanged after intervening dependencies or aliased accesses.

### 4. Post-breakpoint derivation and halfword stores

After continuation:

- Form the **scaled index** by shifting the index result left by two in a signed-word expression.
- Form the **derived constant** by logically shifting **0x21C48960** right by 18 and multiplying by four. The result is **0x21C4**, representable as a signed 32-bit value.

The small base is the zero-extended halfword itself. No pointer dereference or scaling precedes its use as this address component.

Continue in order:

2. Invoke **F-U21**, retaining its word result.
3. Read a word at **small base + 0x04**.
4. Invoke **F-U22** with the F-U21 result and the newly read word.
5. Read the second global word, retaining it as the **second captured base**.
6. Invoke **F-U23**.
7. Store the low halfword of the second captured base at **second captured base + scaled index**.
8. Invoke **F-U24**.
9. Read a word at **derived constant + 0x54**, equivalently **0x2218**, retaining it as the **table base**.

The second captured base supplies both an address component and the halfword payload. It is captured before F-U23; no reload is represented between that call and the store.

### 5. Third split result and frame-base update

Then:

1. Read an unsigned halfword at **table base + 0x34**, retaining its zero-extended value as the **small offset**.
2. Invoke **F-U28**, obtaining the **third split result**.
3. Store its low word at **frame base + 0x258**.
4. Read an unsigned halfword at **high(third split result) + 0x14**, retaining its zero-extended value as the **copied halfword**.
5. Form the **shifted low value** by shifting the signed-word interpretation of the third result’s low half left by six.
6. Form the **scaled high value** by multiplying the signed-word interpretation of its high half by four.
7. Decrease the represented frame base by **0xF4**.
8. Form the **scaled small offset** as four times the small offset.
9. Store the third result’s low word at **scaled small offset + 0x74**.

The frame-relative store precedes the frame-base decrement. No restoration is represented before repetition.

The small offset ranges from 0 through 65535; its scaled value ranges from 0 through 262140. This unsigned multiplication is exact, and its result is also representable as a signed 32-bit value.

The frame-base update is established at the represented level. Conventional stack allocation and cumulative physical stack consumption are not established.
