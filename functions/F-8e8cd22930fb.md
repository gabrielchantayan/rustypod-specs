# F-8e8cd22930fb

## Purpose

F-8e8cd22930fb conditionally invokes a dependency, then returns either a stored integer or the sum of two stored integers. Two bits in a control field select the observable path.

The established behavior is:

- When control bit `0x0010` is clear, invoke F-21f3f42d1b03 with the input object and the integer argument `1`.
- If that invocation returns zero, return zero immediately.
- Otherwise, examine control bit `0x0800`.
- Return the integer at slot 6 when that bit is clear.
- Return the sum of the integers at slots 0 and 6 when that bit is set.

## Behavior

### Initial control decision

The function first reads the unsigned-short control field beginning at slot 7 and tests bit `0x0010`.

If that bit is set, it skips F-21f3f42d1b03 and proceeds to the result-selection decision. Skipping the dependency does not itself imply success, initialization, or object validity; it establishes only that the call does not occur.

If the bit is clear, the function invokes F-21f3f42d1b03 exactly once with:

- The same input pointer.
- The integer argument `1`.

No integer value from slot 0 or slot 6 is explicitly read by this function before that call.

### Dependency result

When F-21f3f42d1b03 returns zero, F-8e8cd22930fb returns zero immediately. It does not perform its later control-field read or its result-field reads.

When the dependency returns any nonzero integer, execution continues. Positive and negative nonzero values have the same local effect. The magnitude of the dependency result does not enter the returned arithmetic.

The input object may have changed during the dependency call. The function does not preserve a pre-call copy of either result field for subsequent use.

### Result-selection decision

After either skipping the dependency or receiving a nonzero result from it, the function reads the control field again and tests bit `0x0800`.

This is a separate source-level read. The selection is based on the control value at that later point, not on a saved initial value. Consequently, changes made by the dependency to bit `0x0800` can change the result path.

At this second decision, bit `0x0010` is not tested again. If the dependency changes that bit, this invocation does not restart the initial decision or make an additional dependency call.

When bit `0x0800` is clear, the function reads and returns slot 6. It does not explicitly read slot 0 on that path.

When bit `0x0800` is set, it reads slots 0 and 6 and returns their sum. Both operand reads follow the second control decision. The supplied expression does not establish which operand is read first.
