## Behavior

The wrapper retains this adjusted receiver address throughout its visible dispatch sequence. It does not reacquire a receiver from F-b7af80e829ec between dispatches.

The adjustment is pointer arithmetic, not a read of the five preceding elements. The first visible receiver-content read occurs during the first dispatch lookup.

### First dispatch and exact-one gate

The first dispatch uses the table entry at byte offset 0x1c0.

Its lookup consists of reading the receiver’s first word to obtain the table base, then obtaining the callable entry at that offset. The receiver is supplied as an explicit argument to the selected target.

When that target returns:

- A result equal to exactly one permits the second dispatch.
- Every other result is returned immediately.

This distinction is exact equality, not truthiness. A result of two, minus one, or another nonzero value does not permit the second dispatch.

On an ordinary path ending here, neither the second dispatch nor either terminal dispatch occurs.

### Second dispatch and terminal selection

The receiver is again supplied as an explicit argument.

| Second dispatch result | Selected terminal table offset |

### Lookup timing and mutable dispatch state

- The terminal dispatch uses the table reachable after the second target returns.
