## Behavior

2. If execution continues, attempt the first indirect call.
3. If that call returns to the next recovered operation, attempt the second indirect call.
4. If that call returns, derive two arguments from the third explicit input and attempt the third indirect call.
5. If that call returns, attempt the fourth indirect call.
6. If that call returns, attempt the fifth indirect call.
7. If that call returns, reach the unrecovered invalid-instruction boundary.

There is no recovered branch that selects among these calls. There is also no recovered loop, retry, cleanup branch, or error-handling branch.

## Acceptance examples

These examples are conditional static criteria, not reports of executed tests.

### Zero third input

If F-U03, F-U04, and F-U05 subsequently return, execution reaches the unrecovered boundary. This example does not imply successful function completion.

### Ordinary nonnegative third input

Given a third input of `0x00012345`, the explicit arguments to F-U03 are, in order:

- `0x00000123`
- `0x12345000`

Both results fit within signed 32-bit range, so this example does not depend on negative-right-shift behavior or signed left-shift overflow.

### Low-byte distinction

Given third inputs `0x00000100` and `0x000001FF`, the first explicit argument to F-U03 is `0x00000001` in both cases.

The second explicit arguments differ: `0x00100000` and `0x001FF000`, respectively. The right-shifted argument discards the low eight input bits; the left-shifted argument can retain their contribution.

### Negative-input ambiguity

For a third-input bit pattern of `0xFFFFFFFF`, an arithmetic right shift would produce `0xFFFFFFFF`, while a logical right shift would produce `0x00FFFFFF`.

A truncating 32-bit left shift would produce `0xFFFFF000`, but that is not established merely by the signed expression representation. This case is `documented_only` until the relevant machine instructions and execution semantics are known.

### Early non-return

If F-U02 does not return to the represented continuation, F-U03, F-U04, and F-U05 are not required to occur on that path. The function has no recovered mechanism for forcing continuation or compensating for earlier side effects.

### Coprocessor rejection
