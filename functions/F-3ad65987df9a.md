# F-3ad65987df9a

- If the decision callable returns zero, the function returns one global value without explicitly reading the object-relative return field.

### Nonzero-decision path

If F-unresolved-01 returns any nonzero integer, the function proceeds to the integer field at offset `0x2C`.

The supplied representation contains two distinct reads of that field:

1. The first read supplies a candidate return value.
2. The second read determines whether the field is zero for fallback selection.

The return rule is:

- If the second read is zero, return the field fallback.
- If the second read is nonzero, return the value obtained by the first read.

For stable, ordinary memory, the two reads produce the same value. Under that condition, the behavior simplifies to returning the field when nonzero and the field fallback when zero.
