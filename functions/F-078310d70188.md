# F-078310d70188

## Behavior

### 1. Obtain the count before visible output writes

F-078310d70188 calls F-1cb585febd84 exactly once with the second argument.

No destination access is visible before that call. If the dependency does not return normally, the supplied body establishes no subsequent header write, payload write, or normal return.

The dependency’s result is retained as N. The visible body does not call the dependency again to refresh the count.

The dependency may have changed source memory, destination memory, or other state before returning. Its implementation and side effects are unknown; the contract must not assume that memory contents remain as they were at function entry.

### 2. Write the header

After the dependency returns, the function writes destination offset 0 first, using the count-derived character-sized value.

It then writes the constant byte 3 at destination offset 1.

These writes occur even when N is zero or negative. There is no separate empty-output or error branch for such counts.

Under low-eight-bit narrowing, H is always even and repeats whenever N changes by 128. Consequently, the first byte cannot uniquely identify the count or the full output size.

### 3. Expand the payload in forward order

For positive N, source positions are processed in ascending order.

For each position j, the visible operation order is:

1. Read the byte at source offset j.
2. Write that byte at destination offset 2 + 2j.
3. Write zero at destination offset 3 + 2j.

The next source position is not processed until those two destination writes have completed.

The function does not stop at a zero source byte. A zero source byte produces a pair of zero bytes, and processing continues until all N positions have been handled.

There is no extra terminator after the final pair. For positive N, the last written byte is the zero at offset 2N + 1. That zero is part of the final pair rather than an additional suffix.

### 4. Read and return the first destination byte

After the loop, or immediately after the header for nonpositive N, the function reads destination offset 0 and returns that character-sized value.

In ordinary valid, non-wrapping memory execution without external mutation, the payload writes begin at offset 2 and do not change the header. Under those conditions, the returned byte equals the initially written H.

The final read remains part of the behavior. It should not be replaced in a behavioral specification by an assumption that the initially computed header value is returned without rereading memory.
