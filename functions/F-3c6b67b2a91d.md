## Behavior

### Established expression-level sequence

The static representation establishes the following sequence:

1. Read the input-associated integer field at byte offset 8 and retain its value as the candidate result.
2. Read the same field again and compare this decision value with zero.
3. If the decision value is zero, read the shared fallback slot and use that value as the result instead of the initial candidate.
4. Return the selected result.

The fallback read is conditional. It is absent from the nonzero decision branch and occurs after both field-read expressions on the zero decision branch.

Only the second field-read expression determines whether fallback is selected. The initially captured value is not the value explicitly tested.

### Stable-memory behavior

If the field remains unchanged throughout the operation:

- A positive field value is returned unchanged.
- A negative field value is returned unchanged.
- A zero field value selects the fallback.
- A positive, negative, or zero fallback is returned unchanged when selected.
- A zero fallback does not trigger another selection stage.

There is no visible range check, normalization, clamping, or conversion of the selected integer into a Boolean. Comparison with zero determines the branch; it does not transform the returned value.
