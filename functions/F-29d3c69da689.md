These examples are conditional consequences of static evidence, not executed tests. Each assumes execution reaches the operation and required accesses complete.

1. **Initial forwarding:** Inputs 7 and 11 cause F-U001 to receive 7, 11, and 11, in that order.

2. **Distinct address scales:** Index 3 gives word address 32 and expanded address 68. Publishing the scaled value 12 at address 68 is not interchangeable with storing it at address 32.

3. **Selector range and truncation:** A selector byte of 200 chooses address 217. A source of 516 stores byte value 4.

4. **Fresh observations:** If a dependency changes a selector byte between two reads, the later write uses the later observed selector. The two writes need not share a destination.

5. **Global mutation:** A dependency may modify G0 after its reset. A fresh read uses the then-current global value; locally retained zeros remain zero independently.

6. **Full-width source:** A base-plus-116 word of `0x123456ab` produces a low-byte store of `0xab`. The source operation remains a 32-bit read.

7. **Byte versus word arithmetic:** Masking a zero-extended byte with `0x3fffff` and shifting right by 12 always yields zero. Applying that transformation to the full 32-bit value `0x1000` yields 1.

8. **Concatenation:** If H24 supplies `0x123456` and the final dependency supplies byte `0xab`, the final G1 value is `0x123456ab`. This does not specify physical load width or byte order.

9. **Fragment aliasing:** If the final destination-byte clear changes storage contributing to H24, the concatenation uses the fragment after that clear, not a presumed earlier value.

10. **Ending order:** The destination-byte clear precedes the H24 value read and G1 assignment; the assignment precedes the 16-bit clear; that clear precedes the zero-target call attempt.
