The second input has unconditional precedence when nonzero: the function returns that input without consulting the first input or either shared cell. When the second input is zero, the first input selects a fixed result, a shared-cell value, or zero.

The function first determines whether override is zero.

If override is nonzero, the result is exactly override. No restriction to positive values, known constants, or single-bit values is applied. Negative values also take precedence.

This path does not evaluate selector-dependent conditions and does not access either shared cell in the supplied implementation.

### Selection boundaries

Selection is by exact integer value. The function does not combine alternatives or decompose a selector into constituent bits.

For example, selector 3 produces zero when override is zero, despite being the sum of 1 and 2. Selector 12 likewise produces zero rather than combining the results for 4 and 8. Selector 48 does not cause both shared cells to be read.

All negative selector values produce zero when override is zero. They do not select a shared cell.

The supported selectors do not form a contiguous interval. Values between supported selectors, and values greater than 32, produce zero unless override takes precedence.

1. Override is examined before any selector-dependent decision.
2. If override is zero, selector 4 is recognized before the lower-versus-higher selector partition.

4. The higher-selector portion recognizes 8, 16, and 32. Other values in that portion produce zero.
