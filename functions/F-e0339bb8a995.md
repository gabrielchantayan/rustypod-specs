# F-e0339bb8a995

## Purpose

F-e0339bb8a995 conditionally writes a four-byte value into an indexed location relative to a caller-supplied base address.

Its ordinary path accepts an index no greater than twelve and writes the value at a displacement of one hundred bytes plus eight bytes per index unit. The visible upper-bound check does not reject negative indices.

For an index greater than twelve, the function invokes F-a817d8d58c10. The supplied static evidence identifies that dependency as non-returning. Under that annotation, the rejected-index path does not reach the destination write or return normally.

Interpreting the destination as one field within an array of eight-byte records is plausible intent, not an established object-layout contract. The evidence establishes a stride and a four-byte write, but does not identify the enclosing object, the other four bytes of a possible record, or the intended valid lower bound.

## Behavior

- If the index is greater than twelve, F-a817d8d58c10 is invoked.
- If the index is twelve or less, the function proceeds to the write without invoking that dependency.

The comparison is not an inclusive rejection at twelve: twelve follows the write path.

The comparison also does not establish that the index is nonnegative. Negative indices follow the same write path as zero and positive indices up to twelve.
