# F-421ee22ef2f3

## Purpose

The first storage position supplies the starting value; the next supplies the ending value. When the separation is nonnegative and representable in the calculation’s signed integer type, the returned value is half the separation, rounded downward.

Direction matters. The operation is not an absolute distance, an average, or a comparison result. Reversing the two values can change both the sign and the rounding behavior.

The supplied material does not establish application-level meaning, units, or a requirement that the ending value be greater than the starting value. Negative values and negative separations are not explicitly rejected. Exact results for negative separations depend on an unresolved target arithmetic property.

## Behavior

### Directed separation and rounding

For a representable nonnegative separation, the result is determined as follows:

- Zero separation returns zero.
- An even separation returns its exact half.
- An odd separation returns the integer immediately below its mathematical half.

The scaling applies to the combined separation. Independently rounding or scaling the two inputs before comparing them is not equivalent.

For example, a starting value of one and an ending value of two require zero. Separately halving those inputs with downward rounding and then finding their separation would instead produce one, which would not satisfy this contract.

### Negative separations

The static evidence establishes that negative separations are subjected to the target’s rule for right-shifting a negative signed integer by one bit. That rule is not supplied.

These are conditional requirements, not unconditional guarantees. A replacement using division rounded toward zero would differ for negative odd separations under that target rule.
