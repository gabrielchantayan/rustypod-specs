# F-9eb45489ebb0

## Purpose

F-9eb45489ebb0 queries an acquired state object and writes a selector-dependent result to caller-provided storage. Reached operations produce one, two, four, or ten 32-bit words, or return without storing a result. Operations include state reads, compact-value translations, dependency-mediated results, and an indexed search.

Unsupported-selector handling conditionally records `0x500` in the first state word. The function has no explicit return value or separate success indicator.

This contract describes the supplied static representation, not verified runtime behavior. Selector-global declarations, dependency implementations, and target details are unavailable. In particular, the signed selector parameter does not establish the signedness of comparisons against undeclared globals, and an unsigned result destination does not establish unsigned evaluation of preceding arithmetic.

## Acceptance examples

These are conditional criteria, not executed tests. Each assumes valid accesses, defined arithmetic, and routing to the named operation.

1. **Null state:** Acquisition returning null still permits the subsequent copy-source-global read. No direct output or state store follows. Output preservation additionally requires acquisition to preserve it.

2. **Error aliasing:** For unsupported handling with `W[0] = 0` and output pointing there, output word zero becomes `0x500` through the state write. An existing nonzero error is not replaced.

3. **Pre-recognition reads:** Reached search reads the default argument, L’s argument, and the `0xD57` argument before searching. Rejection after failed `0xD54` and `0xD55` tests includes both argument reads.

4. **Compact fallthrough:** `0xB45` mode three reads all three result globals and then returns without direct output or error stores. `0xB65` mode one still reads its first result global before outputting `0x800`.

5. **Discarded result read:** `0xB46` with nonzero `B[901]` reads its result global before selecting `0x900`.

6. **Character interpretation:** Reached `0xBC1` reads and evaluates the initial T subtraction before its dependency call. With `B[9C9] = 0xFE`, the argument is −2 under signed eight-bit character interpretation, or 254 under unsigned interpretation.

7. **Defined subtraction:** If initial T is two, mode four produces `0xFFFFFFFF` under either signed or unsigned 32-bit subtraction: the signed result −1 converts to the same output pattern. This does not resolve evaluation type for overflow-boundary inputs.

8. **Fresh T read:** If mode five’s fresh T read is nine, its output is seven regardless of the initial value, provided the earlier subtraction and intervening execution are defined.

9. **Ordered writes:** Two-one operations write position one before zero. With disjoint storage and dependency preservation, later output positions remain unchanged.

10. **Search filtering:** Stable candidates `[7, 8, 8]`, comparison value eight, and decimal count three produce index one. The odd first candidate does not cause a comparison-storage read. No match produces zero, indistinguishable from a match at index zero.

11. **Dependency effects:** If the first `0xB00` call changes `W[88]`, the second call reads that changed word after the first result store.

12. **Comparison typing:** A negative selector compared with a positive selector-global value cannot be assigned an unconditional signed-order route. Its route requires the global’s declaration and applicable arithmetic conversions.
