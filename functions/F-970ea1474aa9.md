## Acceptance examples

These are conditional deductions, not runtime results. Each assumes all preceding accesses complete and the relevant arithmetic has defined target semantics.

1. **Unused second input.** Changing only the second input changes no visibly input-dependent expression. Undocumented calling-convention effects are outside this conclusion.

2. **Input truncation.** Third input `0x12345678` supplies full word `0x12345678` and byte `0x78` at the corresponding stores. Its direct address use is not reduced to `0x78`.

3. **Signed widening.** Signed byte `0xfe` becomes `0xfffffffe`, not 254, in a represented 32-bit conversion.

4. **Global capture and reuse.** If the ordered word read at `0xdb` yields `0x89abcdef`, the two identified offset-`0x54` stores write that full word, and the identified branch offset-`0x11` store writes `0xef`. Subsequent overwrites remain possible.

5. **Global-read aliasing.** If byte-base plus `0x09` equals `0xdb`, the second immediately preceding byte store changes the first addressed byte of the subsequently captured word. The read must not use a word cached before those stores. Numeric reconstruction depends on endianness.

6. **Final argument capture.** If the terminal-context offset-`0x44` word read yields `0x11223344`, that is the third argument even if the following byte or word stores overwrite its source memory.

7. **Final external-data ordering.** If the separate external data read yields `0x55667788`, the word store at twice the captured external address uses that value. A later aliasing mutation of the external source does not cause a reread.

8. **Argument OR.** Dispatch source byte `0x80` produces dispatch value `0xffffff80` and first argument `0xffffffc4`. Source byte `0x01` produces first argument `0x00000045`.

9. **Partial overwrite.** A halfword store followed by a byte store at the same starting address leaves the other byte governed by the earlier store unless another access changes it.

10. **Access failure.** An intermediate invalid access has no specified status result or rollback. Clean rejection cannot be claimed from this evidence.
