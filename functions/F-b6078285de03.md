## Behavior

### Address notation and dependency boundaries

To describe repeated effects without implying object layouts:

- **Selector byte write at base B** means: read the unsigned byte at address B + 1, then write one byte at address 17 plus the byte just read.
- **Word slot for index X** means address 4X + 20.
- **Wide-stride word slot for index X** means address 16X + 20.
- **Page-stride word slot for index X** means address 4096X + 20.

These are absolute computed addresses. No hidden object base is established.

A selector byte ranges from 0 through 255, so its selected destination ranges from address 17 through address 272. The read and store are separate observable accesses. Repeated selector operations perform fresh reads unless explicitly described as using a retained selector.

The dependency labels below identify occurrence roles, not proven distinct callees. Intervening calls must not be treated as inert: they may change memory, global state, or other state not characterized here.

## Acceptance examples

These examples are conditional arithmetic and access-order criteria, not executed tests.

1. **First word-store payload.** If A is 3, the fourth argument is 2, and the relevant addresses are valid, the first cycle stores 12 at address 8212.

2. **Byte-selected destination.** If a selector read yields 255, the following selected byte store targets address 272. It does not target an address relative to the selector’s base.

3. **Extraction truncation.** If P is 0x3ff00000, the masked right shift produces 1023, but the byte store writes 255.

4. **32-bit wraparound.** If A is 0x40000000, P is zero under the stated arithmetic model. Both stores carrying P write a zero word if reached.

5. **Distinct repeated accesses.** If a dependency changes a selector between two zero-writing selector operations, the later operation uses the new selector. Equal payloads do not make the operations interchangeable.

6. **Saved-selector behavior.** If the saved selector is 7 and a dependency subsequently changes U + 1 to 9, the later third-argument-derived word store still targets address 27.

7. **Global snapshot timing.** If the global word is read and then a dependency changes that global, the later byte payload uses the retained read value, not the changed global.

8. **Failure without rollback.** If a dependency fails to return after an earlier store, subsequent operations are not reached. No visible mechanism restores the earlier contents.

9. **Cycle carry.** If the final dependency result is 5, both arguments supplied at the next cycle’s opening are 20.
