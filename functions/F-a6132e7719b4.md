# F-a6132e7719b4

## Purpose

F-a6132e7719b4 implements prioritized value selection. It performs a dependency-mediated comparison, conditionally performs a second comparison, and reaches an input-field fallback only when both comparison results are nonzero.

The selected return source is, in priority order:

1. A global value selected by a zero first comparison result.
2. A different global value selected by a zero second comparison result.
3. An input-relative integer field, unless a second read of that field is zero, in which case another global supplies the candidate.

This establishes selection behavior, not the semantic meaning of the selected values. The supplied representation does not establish that they are filenames, strings, pointers, handles, owned allocations, or error codes.

Both dependency results used as first comparison operands pass through an explicitly four-byte intermediate. The function returns through its integer return type; selecting a source does not establish unconditional preservation of a source value whose type or width is unknown.
