### 4. Write the first byte selected through the incoming base

2. Adds `0x11` to the byte’s numerical value.
3. Writes the low byte of the later scaled value to that address.

The loaded byte is used as an address component, not as a pointer to another object. The resulting destination is between `0x11` and `0x110`, inclusive.

For an unsigned later result, the stored byte corresponds to its low six bits shifted left by two. Bits above that range do not survive the byte store.

### 5. Write the second byte selected through the incoming base

F-U14 and F-U15 execute with no displayed arguments. F-U16 then executes with no displayed arguments and produces a 32-bit result.

The routine performs a fresh byte read at the incoming base plus one. It does not visibly reuse the byte read from the preceding stage.

- Masking the later unsigned result with `0x3fffffff`.
- Shifting the masked value right logically by 20.
- Retaining the low eight bits for the store.

The final stored byte therefore corresponds to bits 20 through 27 of the later unsigned result. Although the mask and shift can leave ten bits, the byte store discards the upper two.

F-U17 is then invoked with one displayed argument: the F-U16 result shifted left by two.
