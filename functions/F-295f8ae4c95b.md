# F-295f8ae4c95b

## Purpose

- For a zero result, it writes an all-ones pattern to each eight-byte output and zero to the byte output.

This contract describes the supplied function body only. Dependency behavior is not available, and no runtime tests have been performed.

### Overlapping outputs

Where overlapping accesses are valid, the direct stores retain their stated order.

- If the two eight-byte output addresses are identical, the second publication replaces the first at that address.
- If those regions partially overlap, the later publication determines the shared bytes, subject to intervening dependency effects.
- If the byte output points inside either eight-byte region, the final one-byte store replaces the byte at that address.
- On the zero-result path, a byte output inside an otherwise all-ones region changes the addressed byte from `0xFF` to `0x00`.

For identical eight-byte output addresses on the nonzero path, the second value is therefore not an unconditional description of final memory. Even if dependencies perform no additional writes, an overlapping byte output can alter that value after its publication. The final region equals the second value only if the byte output is outside it or the last byte store writes the same byte already present at the affected address.
