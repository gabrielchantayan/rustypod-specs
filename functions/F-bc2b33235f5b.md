- For an index less than or equal to 2, calculate the selected address, read four bytes there, and return that value.
- For an index greater than 2, invoke F-a817d8d58c10. The supplied static representation identifies that invocation as non-returning.

This is an upper-bound check, not a complete range check. Negative indices take the retrieval path. The evidence therefore does not establish a safe accessor restricted to three records.
