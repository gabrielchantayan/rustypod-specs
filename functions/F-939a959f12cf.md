Incoming execution state and dependency results determine the data addresses and arguments used. Its represented endpoint transfers execution through a terminal mechanism on a path marked non-returning.

No application-level purpose is established. The available evidence does not identify a protocol, object model, allocation scheme, or user-facing operation. Numerical address relationships do not establish arrays, records, or fields.

This contract separates three levels of certainty:

- **Established static evidence:** access widths, ordering relationships, argument relationships, and retained values visible in the supplied representation.
