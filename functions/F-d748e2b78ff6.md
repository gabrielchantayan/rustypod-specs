# F-d748e2b78ff6

## Purpose

F-d748e2b78ff6 coordinates preparation of a second object, obtains a signed decision result using data from two objects, and conditionally dispatches one of two actions.

Its established behavior is:

- Invoke two dependencies on the second input, in a fixed order.
- Obtain a signed decision result from a third dependency.
- Inspect a one-byte control field in the first input **after** that decision dependency returns.
- If the control field is zero, dispatch a negative-result action or a positive-result action. A zero result dispatches neither.
- After a dispatched action returns normally, invoke a final dependency with the integer argument 1.
- Return the 32-bit value 1 on every path that reaches a normal return.

The semantic meanings of the objects, decision result, actions, and final dependency are not established. In particular, the final call is not established to terminate execution.

### Control-field check

Only after F-aa672b15efb7 returns does the function read the one-byte control field at A plus offset 0xBC.

If this byte is nonzero, the function returns 1 without making either result-dependent action call or the final dependency call.
