# F-cb38d8d650b2

## Purpose

F-cb38d8d650b2 transfers a fixed 65-byte representation between caller-supplied memory regions. The first argument identifies the destination; the second identifies the source. Neither the contents of either region nor any embedded zero changes the transfer extent.

The operation is **progressive, not snapshot-based**. Destination updates occur before all source data has been acquired. Consequently, overlapping regions can produce a result different from copying the source’s entry-state contents.

For disjoint, stable, valid ordinary memory, normal completion makes the destination’s 65 bytes match the source’s original 65 bytes. This result is conditional on valid address arithmetic, address conversion, storage access, and representation handling. The function does not check those conditions.

Copying a fixed-size representation is inferred intent. No application-level record type, encoding, or meaning for the final byte is established.

## Behavior

### Extent and observation model

The transfer is content-independent. An initial zero, an all-zero region, or data resembling a terminator does not reduce the number of bytes covered.

The leading 64-byte portion is observed and updated progressively in increasing offset order. For each four-byte unit, the source value is obtained before the corresponding destination update; that update precedes acquisition of the next source unit. The trailing source byte is acquired only after all leading destination units have been updated.

This ordering establishes the important behavioral boundary: **later source observations may include changes caused by earlier destination writes**. A replacement that first captures all 65 source bytes would not preserve every established overlap outcome.

These are source-level access relationships. They do not establish:

The last four-byte unit occupies offsets 60–63. Offset 64 is accessed separately as one byte. No explicit access extends past offset 64 or before offset 0 in either region.

When the destination begins below the source, the forward progression does not overwrite source bytes needed by later units. Under valid overlapping ordinary-memory semantics, the original source sequence is therefore reproduced at the destination.
