# F-09823da3d75e

## Purpose

The only explicitly established return value is the 32-bit value `4`, produced when a 16-bit field in the descriptor is nonzero. The apparent intent is to report a queried state and an associated value, using all-one bits when the queried state is zero. This interpretation is inferred; the meanings of the queried state, associated value, descriptor, and fixed control arguments remain unknown.

- No dependency call shown in the body is reached.
- The descriptor’s first 32-bit word is not read by this function.

### Primary-object acquisition
