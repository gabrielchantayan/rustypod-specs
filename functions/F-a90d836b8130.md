# F-a90d836b8130

## Purpose

F-a90d836b8130 coordinates dependency calls, object-field extraction, a query, unsigned 32-bit scaling, and a dispatched request with a count argument of four. It invokes a status-related dependency if the query returns nonzero or the final request returns anything other than four.

Construction, metadata retrieval, output, and cleanup are plausible interpretations of these operations. Their application-level meanings are not established by the supplied body.

Termination is unusual. After the main work, a nonzero retained object address selects a cleanup-related call followed by a call annotated as non-returning. The visible ordinary-return path requires that address to be zero, despite earlier unconditional field reads through it. The function therefore does not establish safe null-result handling or promise normal return after successful processing.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. Each assumes preceding accesses are valid and relevant dependencies return.

1. **Query returns nonzero.**  
   The second F-DISPATCH-01 invocation, scaling, F-EXT-02—the external operation whose third argument is four—and F-DISPATCH-04 are skipped. F-7f008c1060db receives the retained initial result and two.

2. **Final result equals four.**  
   With a zero query result and a final dispatched result of four, F-7f008c1060db is bypassed. Final cleanup-related processing still occurs; normal return is not promised.

3. **Other final results.**  
   Final results of zero, three, five, or a negative integer each select the same F-7f008c1060db call. There is no retry.

4. **Ordinary arithmetic.**  
   If the quantity is 2048 at the read immediately after the second F-DISPATCH-01 call returns, and that call returns three, the calculated replacement is six.

5. **Wrapping multiplication.**  
   If the quantity is \(2^{31}\) at that same read point and the dispatched result is two, the calculated replacement is zero. The product wraps before shifting.

6. **Aliased quantity changes during dispatch.**  
   Suppose the query leaves 2048 in the quantity and retains its address. If the subsequent F-DISPATCH-01 call changes it to 4096 through an alias and returns three, the calculated replacement is twelve, not six.

7. **Distinct repeated results.**  
   If the two F-DISPATCH-01 calls return different values, the first feeds F-9b3ee6b2bfa6; the second supplies the scaling multiplier.

8. **Fresh field and pair reads.**  
   A change to the retained object’s offset-0x04 field before the query affects the query argument. A change to either source word during F-EXT-02 affects the subsequently copied request pair.

9. **Nonzero retained object address.**  
   F-ffa7163332aa receives that address, followed, if it returns, by F-feee9156a257. Under the non-return annotation, the local-address cleanup call and ordinary return do not follow.
