## Side effects

The function’s direct persistent memory effects are the 32-bit destination write at offset 12 and the 16-bit destination write at offset 4.

Those writes occur before descriptor preparation and submission. A later failure does not trigger any visible restoration of the earlier destination contents. Thus, completion of the overall sequence is not established as transactional.

The temporary descriptor occupies local storage. No explicit dynamic allocation, deallocation, ownership transfer, or resource-release operation is visible in the function itself. This does not imply that dependencies allocate nothing, release nothing, or preserve unrelated state.

Passing the descriptor pointer does not by itself establish an ownership transfer. Its local storage lifetime does not extend beyond this invocation. If F-927075e1520a retains the pointer for later use, correctness requires an external lifetime arrangement not shown in the evidence. A synchronous copy is plausible but unproven.

The direct destination writes preserve other destination bytes only insofar as those bytes do not overlap the two written ranges. Dependencies may independently modify the destination, source, configuration scalar, or other global state. No global-preservation guarantee is established.

No locking, atomic operation, memory barrier, or reentrancy guard is visible. Concurrent mutation and reentrant execution are therefore outside the established safety guarantees.
