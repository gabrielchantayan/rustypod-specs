## Acceptance examples

These examples are conditional acceptance criteria, not executed tests.

### Initial invocation

Given valid incoming context and an additional incoming word equal to 3, the first invocation receives the explicit inputs unchanged and third displayed argument 96. Later direct-memory accesses do not precede it.

### Field-width distinction

For a word equal to 0xFFFABCDE, retaining 20 bits and shifting right by 10 produces 0x2AF. Subsequent left shifts by five and six produce 0x55E0 and 0xABC0. The two forms are not interchangeable.

### Intermediate truncation

Under low-32-bit arithmetic, consecutive left shifts by 28 and 28 produce zero. A nonzero result obtained by retaining a wider intermediate fails that conditional width requirement.

### Two writes to one byte

Given a completing prefix and accessible memory, Q + 9 receives H’s low byte before receiving Q’s low byte. Observing only the final byte does not prove that both accesses occurred.

### Mixed-width constants

Given valid destinations, the 0x3A cluster performs distinct 8-, 16-, and 32-bit stores. Three byte stores do not match that trace.

### Overwritten word sequence

Given noninterfering ordinary memory and byte 0x7E at B + 4, the word-store values at B + 0x20 are 0x20, 0x2F, 0x7E, and 0x20, in order.

### Global sampling boundary

If the final computed store, global load, and absolute-address store complete, their order is: word store at B + 0x20, word load retaining G, word store at absolute address 0x60.

An implementation loading G only after the absolute-address store fails this ordering criterion even if ordinary nonaliasing memory happens to yield the same G.

If writing absolute address 0x60 changes what a subsequent global read would return, the repeated region still uses the value sampled before that write.

### Invalid destination

### Terminal invocation
