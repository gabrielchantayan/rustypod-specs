# F-08aceac14924

## Purpose

F-08aceac14924 selects one of two extraction paths using a discriminator obtained from an object-associated callback. For a supported discriminator, it obtains a base value, derives three or four address-like arguments from that value, and invokes F-07a442f63e69. Its result is the result supplied by that final dependency.

The established distinction between the two supported forms is:

- Discriminator **0** selects F-0a14bde72a48 and supplies a literal zero as the final argument to F-07a442f63e69.
- Discriminator **1** selects F-e2669f32f0eb and supplies the extracted base value plus 12 as that final argument.
- Any other discriminator causes an immediate result of **3**, without either extraction dependency or F-07a442f63e69 being invoked.

The interpretation of these forms as particular record types, formats, or object classes is unknown. The four-byte spacing suggests a layout with four-byte units, but field meanings are not established.

## Behavior

### 1. Obtain the discriminator

The function creates a temporary four-byte buffer and passes its address to the object-associated callback selected through the dispatch entry at byte offset 8.

The buffer is not explicitly initialized before this call. After the callback returns, only its first byte is inspected. The remaining three bytes do not directly affect this function's branch selection.

No callback return value is used to determine the next action. The meaningful local output is the first byte written into the supplied buffer.

This callback occurs before either extraction dependency and before any possible invocation of F-07a442f63e69. Its effects are therefore observable even when the eventual discriminator is unsupported.

### 2. Select the extraction path

The function recognizes exactly two discriminator byte values.

**Discriminator 0**

It invokes F-0a14bde72a48 with the fourth input and a reference to a temporary integer result location. After that call returns, the final argument intended for F-07a442f63e69 is set to zero.

**Discriminator 1**

It invokes F-e2669f32f0eb with the same two kinds of arguments: the fourth input and a reference to the temporary integer result location. After that call returns, the final argument intended for F-07a442f63e69 is the extracted integer plus 12.

**Any other discriminator**

It returns 3 immediately. Neither extraction dependency is invoked, and F-07a442f63e69 is not invoked.

The unsupported case concerns the byte's value, not a multibyte integer formed from the whole buffer. Whether plain character values are signed in the underlying environment does not alter recognition of 0 and 1.

### 3. Construct the final arguments

Let **B** denote the integer established by the selected extraction dependency. This name describes the contract value, not a source identifier.

For either supported discriminator, F-07a442f63e69 receives seven arguments in the following positions:

| Position | Value |
|---|---|
| First | Original first input |
| Second | Original second input |
| Third | Original third input |
| Fourth | B |
| Fifth | B + 4 |
| Sixth | B + 8 |
| Seventh | Zero for discriminator 0; B + 12 for discriminator 1 |

The additions are integer additions in the supplied representation. They are not scaled pointer increments: the numeric offsets are exactly 4, 8, and, where applicable, 12.

This function does not directly load data from B, B + 4, B + 8, or B + 12. It passes those values to F-07a442f63e69. Whether that dependency treats them as addresses, offsets, handles, or another representation is not established here.

The zero in the discriminator-0 path is a literal argument value. It is not derived from B and must not be replaced with B + 12. Describing it as an “absent fourth field” is plausible intent, not established semantics.

### 4. Return the final result

After F-07a442f63e69 returns, this function returns its four-byte result.

There is no subsequent validation, result mapping, explicit cleanup call, or retry. No extraction return status is checked. The extraction dependencies influence the final invocation through the integer they establish in the supplied output location and through any other effects they may have.

### Zero base value

For discriminator 0, the final four arguments are 0, 4, 8, and 0. For discriminator 1, they are 0, 4, 8, and 12. Whether F-07a442f63e69 accepts these values is unknown.

### Downstream result of 3
