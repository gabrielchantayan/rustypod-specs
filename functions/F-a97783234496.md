### Halfword output and initial state fields

F-U09 then supplies a paired result. Its high component determines a destination for a zero halfword at offset `0x2C`. After that clear, the function stores the low component, logically shifted right by 26 bits, as a word at current-state-base offset `0x26C`. This stored value is between `0` and `63`.

The fixed base used later is established as `0x21C48960`. F-U10 executes, and the function reads the initial word destination from current-state-base offset `0x320`. F-U11 and F-U12 execute before a word is written at that destination’s offset `0x54`.

The state-base references at offsets `0x26C` and `0x320` are separated by F-U10. The source does not independently establish that an unknown callee preserves the underlying machine state.

The function derives:

- A link-like address from the high component multiplied by four.

The first two calculations use signed-looking 32-bit arithmetic. The selector multiplication is bounded: its mathematical result is at most `262140`.

After the state store and attribute read, the represented state base is explicitly decreased by `0xF4`. The function then writes the F-U28 low component as a word at absolute address:

**`0x74` + four times the selector**

This destination does not include the state base.

The offset-`0x258` store precedes the explicit base reduction. No explicit restoration is shown. However, an exact `0xF4` difference between corresponding state-base uses in successive iterations additionally requires preservation by all intervening calls and machine transitions. 9. **Breakpoint interruption.**
