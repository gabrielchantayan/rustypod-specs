These are conditional static criteria, not executed tests.

1. **Initial status selection.** With entry byte 0x00, successful initial accesses store 0xFFFFFFFF at third-argument offset 4 and 0xFFFF at offset 2. With entry byte 0x40, both stores contain zero. Other byte bits do not affect this selection.

2. **Defined initial mask expression.** With first argument 3 and mask 0x2F, the initial address-directed word contains 0x20. Its destination comes from the halfword read after the preceding byte and global effects, not an entry-time cached halfword.

3. **Negative branch quantity.** If the first obtained F-e47d7b2e9c88-associated quantity is negative as signed 32 bits, and all preceding effects are executable, the offset-4 halfword store occurs before the first invalid-instruction boundary. The offset-18 stores do not occur on that represented path.

4. **Interleaved alias-sensitive updates.** With bit 2 clear, the first selected word destination is 0x5C and the second is 0x170. The upper-fragment assignment, low-byte assignment, and related-global reread occur between them. An implementation that performs both word stores first does not preserve this contract.

5. **Stack write ordering.** If the stack-associated regions alias, observations must reflect the shifted-base store at offset 0, then its store at offset 20, then the pointer-representation store at offset 0.

6. **Distinct final dependency values.** If the earlier F-8afdaab91693-associated acquisition yields 0x100 and the later yields 0x120, with valid arithmetic and storage, the final clearing base is 0x800 while the captured shifted data is 0x480. Substituting either acquisition for both is incorrect.

8. **Global widths.** Assigning 0x1A to a fixed-location global does not establish an 8-bit store. Acceptance of a concrete access width requires its missing declaration or equivalent independent evidence.
