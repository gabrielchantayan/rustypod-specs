# F-9d05fd487ca3

## Purpose

F-9d05fd487ca3 performs an ordered sequence of unresolved indirect invocations, arithmetic transformations, fixed-state accesses, and derived-address memory mutations, followed by an unresolved four-argument transfer.

No application-level purpose is established. Repeated offsets and character-like constants do not establish allocation, object construction, text output, or device initialization.

This contract distinguishes:

- **Established static evidence:** represented operations, explicit widths, value dependencies, and access ordering.
- **Inferred intent:** possible application interpretations, none required for acceptance.
- **documented_only:** properties not established by the supplied material.

Ordinary sequential, byte-addressed memory semantics support some definite conclusions despite unresolved addresses. Device behavior, asynchronous mutation, and unusual address translation are separate environmental unknowns.

## Acceptance examples

These are conditional static obligations, not executed tests.

- **Cleared-word capture:** with successful ordinary sequential memory accesses and no external mutation, the shifted-base-offset-0x14 capture is zero, regardless of its contents before the clear.
- **Overlapping zero store:** if the compact-base clear overlaps any portion of that word, the capture remains zero. Overlap does not create nonzero bytes.
- **Nonzero neighboring store:** even if the byte read at shifted-base offset 5 yields 0xff, the resulting word at offset 0x34 cannot change the cleared word at offset 0x14.
- **Zero propagation:** under those conditions, both immediate compact-base-offset-0x15 byte stores write zero; the retained-word store targets absolute 0x54; and the replacement at fixed-derived-base offset 0x54 stores a zero word. The saved link retains its separately captured pre-replacement value.
- **Environment outside that model:** a device returning nonzero from the cleared location is not explained by the represented ordinary writes. Such a result requires separately established environmental semantics.
- **Explicit narrowing:** an explicit byte destination supplied 0x12345678 receives 0x78. A fixed-global assignment supplied an 8-bit value does not thereby become a byte write.
- **Unsigned extension:** an explicit unsigned-byte read yielding 0x80, converted to unsigned 32 bits, yields 128. The undeclared global associated with 0x05 has no unconditional equivalent requirement.
- **Arithmetic boundary:** under 32-bit bit-vector semantics, successive left shifts by 25 and 11 yield zero; unlimited-precision retention is not equivalent.
- **Fresh observations:** an overlapping write that changes the effective value of the 0x67 global may affect its next evaluation. Forwarding the originally assigned value is not equivalent.
- **Completion:** F-U005 receives 0x72 first. If it does not return, enclosing completion is not required; earlier effects need not be rolled back.
