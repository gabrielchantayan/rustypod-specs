### Suppressed-call branch

- F-1b53b60f7062 is not invoked.
- The four-byte field at offset 0xB4 is not read by this function.
- The function returns the four-byte value 1.

### Calling branch

If the byte differs from 3, the function next reads four bytes beginning at base offset 0xB4. It passes the resulting 32-bit quantity as the sole argument to F-1b53b60f7062.

1. Read the decision byte.
2. Read the four-byte argument field, only if the decision selects the calling branch.
3. Invoke F-1b53b60f7062 with that field value.
4. Return 1 if the dependency returns normally.
