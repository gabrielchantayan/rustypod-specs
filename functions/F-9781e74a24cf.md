# F-9781e74a24cf

## Purpose

F-9781e74a24cf searches an ordered collection of 128 fixed-stride records for the first record whose one-byte comparison field equals a supplied unsigned search value.

On a match, it stores the record’s zero-based index through a caller-supplied output address and returns status 0. If no record matches, it returns status 2 without writing the output.

The established behavior is a bounded, first-match search. The meaning of the records, the comparison field, and the two status values beyond their observed use is unknown. In particular, the byte is not established to be a type, identifier, flag, or character.

## Behavior

### Search order and comparison

The function begins with record index 0 and examines records in increasing index order. It has no input that changes the starting index, record count, stride, or field offset.

For each examined record, it reads the comparison byte and compares its unsigned value with the full 32-bit unsigned search value.

The search value is not narrowed to one byte. Consequently:

- Values from 0 through 255 can match a stored byte.
- Values from 256 through 4,294,967,295 cannot match any stored byte.
- A search value of 256 does not match a stored byte of 0.
- A search value of 257 does not match a stored byte of 1.

The source-level behavior still examines all 128 comparison fields when the search value exceeds 255. There is no explicit early rejection for an out-of-range search value.

### Successful search

At the first equality:

1. The matching index is stored as a 32-bit unsigned value at the index destination.
2. The function returns status 0.
3. No later record is examined.

If several records match, only the lowest matching index is reported.

The output store follows the comparison-byte read that establishes the match. The output’s previous contents are not read by the function.

Every index written by a successful invocation is between 0 and 127. A successful invocation performs one explicit output store.

### Unsuccessful search

If every comparison fails, the function examines indices 0 through 127 and then returns status 2.

On this path:

- All 128 comparison bytes are explicitly read.
- The index destination is neither read nor written.
- No failure sentinel is stored.
- The previous output value remains unchanged by this function.

There is no extra comparison-field access for index 128.

### Boundaries and arithmetic

The largest stride product used to address an examined record is \(127 \times 20 = 2540\). Adding the field offset gives 2548. These relative offsets do not overflow a 32-bit unsigned integer.

Adding an offset to an arbitrary base address can nevertheless cross an address-space boundary. The supplied representation does not justify a portable wrapping-address contract or establish a checked failure for that case. Callers must provide addresses whose required accesses are valid.
