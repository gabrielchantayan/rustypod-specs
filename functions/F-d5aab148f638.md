# F-d5aab148f638

## Purpose

The established behavior is a sequence of word reads, word writes, and one dependency invocation. Describing the operation as initialization is inferred intent: the supplied material does not establish the state’s application-level meaning.

This is not a whole-object reset. The function assigns selected words, masks two words, and leaves gaps without direct writes. The dependency may have additional effects, including effects on those gaps.

The first update reads word 0 through the global state-selector expression, retains only bit 1, and writes the result through that expression.

With a stable selector, the captured state’s word 0 becomes either 0 or 2. Every bit other than bit 1 is cleared; bit 1 retains its prior value.

### 4. Flag update and numeric configuration

1. Read it, clear its lowest five bits, and store the result.
2. Read it again, set bit 4, and store that result.

For stable ordinary memory, the combined result preserves bits 5–31, clears bits 0–3, and sets bit 4. The low five bits therefore finish as 0x10.

The intermediate store is part of the established sequence: after the first store, all five low bits are zero. The second operation is a fresh read, rather than merely a write of a value retained from the first operation.

## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not executed tests. Unless stated otherwise, they assume 32-bit words, ordinary valid memory, stable relevant inputs, and a normally returning dependency.

1. **Initial mask preserves only bit 1.**  
   If entry word 0 is 0xFFFFFFFF and the selector is stable, its pre-call value becomes 2. If it is 0xFFFFFFFD, its pre-call value becomes 0. A dependency may subsequently change that word.

2. **Unsigned subtraction wraps.**  
   If both A reads produce 5, words 0x07, 0x0A, and 0x0C receive 5. Words 0x08 and 0x0B receive 0xFFFFFFFC; word 0x09 receives 0xFFFFFFF5. No underflow error is reported.

3. **Repeated A reads remain distinct.**  
   If the early A sample is 20 and the later read is 30, word 0x07 receives 30; words 0x0A and 0x0C receive 20; words 0x08 and 0x0B receive 11; and word 0x09 receives 4.

4. **The flag update uses post-call state.**  
   If word 0x60 is 0xABCDEFED when the first post-call mask reads it, the first store is 0xABCDEFE0. With no intervening change, the second store is 0xABCDEFF0.

5. **Signed shifts use the retained D sample.**  
   If the D sample is 0x80000000, words 0x68 and 0x6A receive 0xFFFFC000 under arithmetic-right-shift semantics. If the sample is 0x7FFFFFFF, both receive 0x00003FFF.

6. **The raw D destination can differ.**  
   If the D sample is 0x00040000 and the subsequent D read produces 0x00060000, word 0x67 receives 0x00060000 while words 0x68 and 0x6A each receive 2.

7. **Dependency changes are overwritten selectively.**  
   If the dependency changes word 0x40 to a nonzero value, the function subsequently clears it. If the dependency changes word 0x03, no later direct write restores 6 there.

8. **Pointer replacement does not redirect later stores.**  
   If the dependency changes the global selector from one valid state object to another while leaving the original alive, the post-call stores still target the original object.
