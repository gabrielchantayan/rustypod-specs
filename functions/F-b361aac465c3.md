# F-b361aac465c3

## Purpose

F-b361aac465c3 dispatches a property-like request against a caller-supplied context. Recognized requests publish a 32-bit result: a literal, a dependency result, an address into shared data, or the address of an embedded context object.

A normal return of 1 indicates that a recognized branch reached its completion point. It does not establish successful resource lookup, valid produced content, or independent ownership of the result. Some dependency outcomes select ordinary response values rather than an error return. One branch invokes a dependency identified in the supplied representation as non-returning.

Property retrieval and response formatting are inferred intent. The established contract is the dispatch, argument preparation, memory access, publication, and call ordering below.

## Behavior

### External reads and dispatch precedence

Entry snapshots occur in this order:

1. Alternate failure.
2. Ordinary failure.
3. Restricted mode.
4. Boundary base.

These snapshots remain distinct from subsequent external reads.

Boundary dispatch first compares the selector for equality with a **freshly read** boundary base plus `0x8E`. If equality fails, a signed less-than comparison uses **another fresh read** of that base plus `0x8E`. Neither comparison uses the entry snapshot.

Consequently, “below Boundary” means that the second comparison actually succeeds. Failure enters the literal switch even if concurrent changes make the two boundary observations inconsistent.

Below Boundary, dispatch has these ordered gates:

| Region | Selection and precedence |
|---|---|
| First test | Equality with a read of Probe-A key selects its probe branch. |
| Probe-A non-equality | A subsequent read of Probe-A key is compared using key ≤ selector. If true, enter the upper lower-tree region; otherwise enter the lower region. |
| Upper region | Equality with Raw-buffer key selects its buffer branch. |
| Raw-buffer non-equality | A subsequent signed comparison tests Raw-buffer key < selector. If true, only `0x6429` and then `0x642A` are recognized. Otherwise, only `0x63F5` and then `0x63F8` are recognized. |
| Lower region | Equality with Scaled key selects its direct-value branch. |
| Scaled non-equality | A subsequent signed comparison tests selector < Scaled key. If true, only `0x6395` and then `0x6396` are recognized. Otherwise, only `0x63F2` and then `0x63F3` are recognized. |

With stable external keys, the upper region is strictly above Probe-A key and the lower region strictly below it. The relational gates are nevertheless separate external reads; equality failure does not justify treating later reads as unchanged.

Failure to match an allowed literal in the selected region returns 0. Literals in other regions are not considered.

The outer switch recognizes `0x642C` through `0x6435`. It is reached only after Boundary equality fails and the subsequent less-than comparison fails. External-key collisions therefore do not behave like a flat property table.

#### Normalizing and zero-index policy

Boundary equality and selectors `0x642C`–`0x642E` share this ordering:

- Read Normalizing mode and compare it with the supplied mode.
- Publish Shared default.
- Use the comparison already obtained to decide normalization.

Thus, an output write aliasing Normalizing mode cannot retroactively change that comparison.

If the modes matched, index zero becomes one; other indices remain unchanged. If they did not match and index is zero, production is bypassed:

- Mode different from **captured Restricted mode** causes another explicit publication of Shared default and return 1.
- Mode equal to captured Restricted mode causes F-9d0ecc5f6adf to run. Its result and the **boundary base captured at entry** are passed to F-c0b020cd3882. The resolved result is published, followed by return 1.

Restricted mode controls entry into this response path; it is not the response argument.

All remaining cases use adjusted index minus one. For `0x642D`, an additional check occurs after zero-index handling: mode unequal to captured Restricted mode invokes F-a817d8d58c10, identified as non-returning. Under that characterization, production and normal completion do not follow.

## Side effects

Output publication is not transactional. Preliminary writes remain observable if a later dependency does not return. Enumeration publishes before candidate processing; temporary finalization on enumeration and `0x6432` occurs after publication.

The embedded result may be modified twice in one call. Its published address refers to context storage, not an independently allocated result with an established lifetime.

Output may alias context fields or external data. Preliminary publication can therefore affect later handle reads or other later external reads. Entry snapshots and comparisons completed before publication are not reread merely because such an alias exists.

Calls to F-c5cf4e75bd67 occur in candidate order. No explicit restoration call is visible. Actual candidate-selection state mutation is not established because that dependency’s implementation is unavailable.

No direct heap allocation or release is established. Initialization, application, conversion, and finalization do not prove copying, retention, ownership transfer, or resource release. Dependencies must not be assumed to preserve globals or output storage. In particular, a dependency called after publication may affect what a caller subsequently observes.

## Acceptance examples

These are conditional static-contract examples, not executed tests.

1. **Unmatched dispatch:** If the selected region recognizes no branch, return 0 with no explicit output write or dependency call. External dispatch reads still occur.

2. **Collision precedence:** With stable keys, if selector equals both Boundary and Probe-A key, Boundary wins. If below Boundary and equal to both Probe-A and Raw-buffer keys, the probe wins.

3. **Literal gated out:** Below Boundary, `0x6429` is not recognized merely because it is a known literal. It must reach the region above Probe-A and above Raw-buffer.

4. **Normalization ordering:** For Boundary in Normalizing mode with index zero, compare mode before publishing Shared default, then produce with argument zero, apply the buffer, and publish the embedded-result address.

5. **Restricted zero response:** For reachable `0x642C`, assume index zero, mode equals captured Restricted mode, and the Normalizing-mode comparison failed. F-c0b020cd3882 receives the captured boundary base, even when that base differs from Restricted mode.

6. **Aliased mode value:** If preliminary output publication overwrites external Normalizing mode, the already-completed comparison still controls this call’s normalization.

7. **Restricted production:** Reachable `0x642D` with nonzero index and mode unequal to captured Restricted mode invokes F-a817d8d58c10 after preliminary publication. No normal completion is promised.

8. **Unsigned wrap:** Reachable `0x642F` with index `0xFFFFFFFF` passes zero to F-d11fab2df1db.

9. **Sparse enumeration:** If candidate zero is null and candidate one is non-null, index zero selects candidate one. Index one selects neither. Candidate calls occur in order without establishing their state effects.

10. **Content short-circuit:** For selected `0x6395` content with byte `0x40` equal to signed −1, neither later content byte is needed and formatting is skipped. Final application and finalization still follow.

11. **Range boundary:** If F-d86da6473925 returns 7, index 6 publishes zero; index 7 resolves Range failure.

12. **Indirect gate:** A nonzero F-1680077436f7 result skips the table lookup and indirect call, but not conversion, publication, or finalization.
