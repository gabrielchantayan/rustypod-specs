# F-8c0a602cc700

## Purpose

The supplied static representation establishes the following broad sequence:

- Store the first explicit argument at an address derived from the second argument.
- Invoke a series of indirect dependencies.
- Store an incoming, otherwise unspecified 32-bit register value at an address derived from a dependency result.
- Perform four byte stores, interspersed with further indirect calls.
- Reach a boundary marked as invalid instruction data, rather than a demonstrated normal return.

A higher-level purpose—such as device configuration, serialization, or table management—is not established. In particular, the apparent low-address accesses must not be reinterpreted as accesses through an omitted object base.

This contract describes the supplied static representation. Its instruction-validity warning materially limits confidence that the represented operations are an accurate executable function.

### 3. First byte store

**524,288 × hidden word + 1**

It reads one unsigned byte from that address. The read value is an address selector, not the byte to be stored.

**17 + selector byte**

Consequently, the represented destination lies between absolute addresses 17 and 272 inclusive.

The stored byte is:

**low eight bits of (first packed word shifted left by two)**

Equivalently, it contains bits 0–5 of the first packed word in destination bits 2–7, with destination bits 0–1 clear.

Immediately after the store, a dependency receives the full 32-bit left-shifted value. This argument is not restricted to the byte just written.

A subsequent call produces a result passed directly to another dependency. Three further calls follow, and another dependency returns a value used later as a shifted call argument.

### 4. Second byte store

The function reads the selector byte again from the retained selector address. It must not reuse the first selector value: intervening calls, or the first store itself if addresses alias, may have changed memory.

It stores a byte at:

**17 + newly read selector byte**

The stored byte is the low eight bits of:

**(first packed word masked with 1,073,741,823) shifted right by 20**

After byte truncation, this selects original bits 20–27 of the first packed word. Original bits 28–31 do not contribute to the stored byte.

The following dependency receives the preceding slot-like result shifted left by two bits. It does not receive the extracted byte or the first packed word.

Three more calls follow. The next dependency returns the **second packed word**, a distinct 32-bit unsigned result.

### 5. Third byte store

It writes at:

**17 + this third selector byte**

The stored byte is the low eight bits of four times the second packed word. This has the same bit-selection effect as the first byte store: original bits 0–5 become stored bits 2–7.

The immediately following dependency receives the zero-extended selector byte from this third read. It does **not** receive the destination address or the shifted second packed word.

This distinction is observable even when different values happen to coincide numerically.

A following dependency produces another value that is passed directly to a subsequent dependency. Three further calls occur, followed by a dependency whose result is used as a shifted argument after the final byte store.

**8 × second packed word + 1**

The function reads one unsigned byte there and stores at:

**17 + final selector byte**

The stored byte is the low eight bits of:

**(second packed word masked with 1,073,741,823) shifted right by 20**

The next dependency receives the most recent slot-like result shifted left by two bits.
