# F-6a405dd699da

## Purpose

F-6a405dd699da invokes one dependency with a writable, initially caller-supplied 32-bit value, then subtracts an explicit amount from a caller-addressed integer. It returns a 64-bit result combining the integer’s pre-update value with the dependency-visible value and an ambient condition-state contribution.

The returned lower half and the stored integer serve different purposes: the lower half reports an earlier read, while the store is calculated from a subsequent read. They are not established to use one shared snapshot.

The interpretation of the upper half as a status-bearing value is inferred intent. The established operation is a bitwise OR, not replacement of a dedicated status field.

### Upper-half construction

The upper return half combines:

- The value present in the local auxiliary slot when it is used for return construction.
- A contribution derived from the represented ambient condition values.

The ambient contribution is formed by combining shifted condition values, narrowing the combination to eight bits, converting that result to unsigned 32-bit form, and shifting it left by 27 within 32 bits.

Only the lowest five bits of the narrowed combination survive that final shift. The other three bits are shifted beyond the 32-bit result.

If every condition value is normalized to zero or one, the resulting placement is:

| Condition | Bit in upper 32-bit half | Bit in complete 64-bit result |
|---|---:|---:|
| Negative | 31 | 63 |
| Zero | 30 | 62 |
| Carry | 29 | 61 |
| Overflow | 28 | 60 |
| Additional condition state | 27 | 59 |

That table is conditional on normalization. The additional condition state is represented as a byte, and no explicit one-bit mask is applied before it is combined with the other values. Its bits 0–4 can therefore contribute to all five high positions. Likewise, non-normalized values for the other condition inputs can contribute beyond the single position suggested by their names, subject to their shifts and the final five-bit retention.

The operation combines this contribution with the auxiliary value using bitwise OR:

- Bits 0–26 of the upper half come from the auxiliary value unchanged.
- Bits 27–31 can be set by either the auxiliary value or the ambient contribution.
- No auxiliary bit is cleared.
- A set bit in the result does not, by itself, identify which source set it.

The whole 64-bit result is then the concatenation of this upper half and the retained 32-bit lower half.
