# F-a0126c111c6b

## Purpose

On the ordinary successful path, it returns a non-null candidate object pointer. If configuration returns zero, it invokes an indirect operation associated with that candidate and then returns null. A separate null-candidate branch invokes F-a817d8d58c10, which the supplied static representation identifies as non-returning.

The interpretation of this routine as an object factory is inferred intent. The established behavior is the sequence of calls, four-byte reads and writes, pointer derivation, conditional dispatch, and return selection described below. Allocation failure handling, ownership transfer, and the semantics of the constructed object are not established.
