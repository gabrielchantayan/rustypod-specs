### Selector decision

With a nonzero prerequisite result, the function recognizes only the six values listed in the interface.

For every other selector, it returns the retained prerequisite result. This includes:

- Values immediately below or above either supported group.
- Values in the gap between the groups.

Although the supplied decision structure uses ordering comparisons to partition selectors, acceptance is determined entirely by exact equality with the six supported values. It does not mask bits, truncate the selector to a smaller field, or treat nearby values as equivalent.

No arithmetic is performed on the selector. Consequently, this function introduces no selector addition, subtraction, multiplication, or arithmetic-overflow boundary.
