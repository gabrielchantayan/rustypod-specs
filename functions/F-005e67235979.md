### Integer interpretation

For conditional arithmetic examples, words are 32-bit bit vectors:

- Left shifts discard bits beyond bit 31.
- Unsigned right shifts insert zeros.
- Multiplication and address arithmetic retain the low 32 bits.
- Narrowing to a byte retains the low eight bits.
- Narrowing to a halfword retains the low sixteen bits.

Several represented expressions use signed quantities. These rules are therefore an explicit interpretation model, not proof that all target operations follow ordinary signed-language arithmetic.

The dependency phase includes masks retaining 24, 22, 20, 19, 17, and 13 low bits, followed by shifts. Masking to 20 bits and shifting right by ten extracts ten bits. Whole 64-bit results are also shifted right by 34, 36, or 44 bits before narrowing. Those operations must not be replaced by shifts of an already narrowed low word.

Successive shifts are not generally reversible. For example, shifting a word left by eight and then logically right by eight loses the original high byte.

Some transformation chains start with zero. Their subsequent fixed shifts and masks remain zero under this model, but the invocations receiving those values remain observable operations.

Under the 32-bit model, the narrow index ranges from 0 through 508 in multiples of four. The doubled-index base ranges from 0 through 1016 in multiples of eight. Consequently, some ensuing accesses can target low memory rather than ordinary heap storage.

### Intervening byte write affects the saved argument

Assume execution reaches the final phase, little-endian ordinary memory applies, the linked base plus 0x14 equals 0x3A, and the word there initially equals 0x112233AA. Assume the intervening byte write supplies 0x40.

The saved word read after that write is 0x11223340. That is the retained value used for the final invocation’s third argument. Reading 0x112233AA before the byte write and retaining it instead is not equivalent.

This example is conditional on the reached state and access validity; it does not establish that all dependencies can produce that state.

### Disjoint late reads still preserve ordering

If the late word-read ranges are disjoint from address 0x3A and memory is stable, the byte write does not change their numeric results. The represented order nevertheless remains two word reads, the byte write, then two word reads where access events are observable.

### Separate narrowing writes

Two successive byte writes with supplied low bytes 0x12 and 0xAB remain two ordered events. The final byte is 0xAB only if no later overlapping write changes it.

### Zero initialization with aliasing qualification

With disjoint relevant addresses and stable ordinary memory, the word read at the high-scale base plus 0x14 yields zero after initialization. If an intervening access overlaps it, the expected read must incorporate that effect.

### Narrow-index boundary

Under 32-bit bit-vector interpretation, the narrow index cannot exceed 508 and must be divisible by four. Its doubled base cannot exceed 1016 and must be divisible by eight.

### Whole-result extraction

For a 64-bit result whose high word is 0x12345678, shifting the whole result right by 36 and narrowing yields 0x01234567. Shifting the low word right by four is not equivalent.
