## Behavior

3. Read the source unit at offset 8, then write that value to the destination unit at offset 8.
4. Read the source unit at offset 12, then write that value to the destination unit at offset 12.

### Overlapping regions

Overlap is not detected or handled through a separate mechanism. Results follow the increasing-offset read/write sequence.

When the destination begins one unit after the source, the first write replaces the source location used by the second read. That replacement can then propagate through subsequent operations. Consequently, the result need not match the source’s complete entry-time contents.

When the destination begins one unit before the source, earlier destination writes do not replace the later source units in that particular arrangement. With stable ordinary memory, the four original source values are transferred successfully.
