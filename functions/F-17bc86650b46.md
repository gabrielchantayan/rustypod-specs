# F-17bc86650b46

## Purpose

F-17bc86650b46 coordinates creation or acquisition of a storage object, initializes two of its words, obtains a related handle through a dependency, and submits that handle to two separately acquired dispatch objects. It returns an address-like value 92 bytes below the handle supplied to those dispatches.

The established behavior is an ordered sequence of dependency calls, direct memory accesses, and indirect calls. The supplied static representation does not establish the application-level meaning of the objects, the allocation policy, or whether the returned value denotes an owned resource.

A construction-and-registration interpretation is plausible but remains inferred intent, not a guaranteed semantic description.

### Direct initialization

After acquiring the storage base, the function performs the following direct accesses in order:

1. It reads the global word and retains that first value.
2. It reads the same global word again and writes the second value to the 32-bit word at the storage base.
3. It writes the first retained value plus 248 to the 32-bit word at storage-base offset 28.

The two global reads are distinct in the supplied representation. Consequently, the values written at offsets zero and 28 are not unconditionally related by a difference of 248. That relationship holds if both global reads observe the same value.

The offset-28 write uses the value from the first global read, not a reread of the word just written at offset zero. This distinction also matters if the storage base or its written fields alias other relevant memory.

Only these two direct initialization writes are visible. The function does not directly initialize the intervening words or the word at offset 92.
