# F-39a169b4a9ec

The second input does not participate in these copies or any subsequent visible operation.

The supplied call representation shows no explicit arguments to this indirect query. In particular, it does not explicitly pass the address returned by F-938c950e5046 as a receiver. Any receiver conveyed through an unstated ABI mechanism remains unknown.

### Dispatch through the first input
