# F-14a841015476

## Purpose

F-14a841015476 computes a directional difference from one of two pairs of signed fields in a supplied record. A single control bit determines which pair contributes to the result.

The functional result is the selected minuend minus the selected subtrahend. Zero and negative results are ordinary outcomes, not established error indications. The operation does not normalize the result, choose a pair according to its values, or update the record.

The application meaning of the fields is unknown. They might describe quantities with additional external invariants, but this contract does not identify them as positions, capacities, lengths, or counters.

**Evidence status:** The selection rule, relevant offsets, signed arithmetic, and explicit memory accesses are established by the supplied static representation. A query-like purpose is inferred from the absence of explicit modifications. No runtime tests have been performed.

## Behavior

| Selector bit with weight 4 | Selected pair | Required relationship |
|---|---|---|
| Clear | Pair A | Result equals the value at 0x28 minus the value at 0x20 |
| Set | Pair B | Result equals the value at 0x1C minus the value at 0x14 |
