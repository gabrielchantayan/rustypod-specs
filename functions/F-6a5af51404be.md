## Behavior

1. Invoke F-ca033ea7f0a4 without explicit arguments.
2. Receive its result in the unsigned intermediate.
3. Compute one minus that unsigned value.
4. Convert the subtraction result to the signed integer used for the return result.
5. If execution continues, compare the received unsigned value with one.
6. For a value greater than one, replace the signed result with zero.
7. Return the signed result.

The conversion in step 4 precedes the conditional replacement in step 6. It is not conditional on the received value being zero or one.
