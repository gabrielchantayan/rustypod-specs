## Acceptance examples

These are conditional static expectations, not executed tests.

1. **Unsigned input shift.** If execution reaches the first store and Argument 4 is `0xFFFFFFFF`, the stored word is `0x1FFFFFFF`. If Argument 4 is seven, it is zero.

2. **Byte truncation.** If first payload is `0x41`, the first byte store writes `0x04`, because four times the payload is `0x104`. Its word-store uses retain the full scaled value.

3. **Changed selector between reads.** If the first entry-base byte read yields two and the second yields nine, the first byte store targets `0x13`, while the second targets `0x1A`. Subsequent selector-based calculations use nine.

4. **Upper-slice truncation.** For a payload of `0x3FF00000`, the masked right shift produces `0x3FF`; the stored byte is `0xFF`, not a wider value.

5. **Distinct word addresses.** If third wide index is two, its sixteen-scale store targets `0x34`, while the subsequent quarter-scale word read targets `0x1C`. Equality of their contents is not implied.

6. **Extent calculation.** If central value is sixteen, central half is eight, large extent is `0x400`, and small extent is `0x80`. The earlier selector-block store still uses the selector-derived quantity, not central half.

7. **Repeated zeroing.** If all dependencies return and accesses succeed, four explicit zero-word stores to address `0x24` occur in order. A dependency may modify that address between them.

8. **No completion guarantee.** Reaching the final call family does not establish a successful return. The supplied representation ends at a truncated-flow marker.
