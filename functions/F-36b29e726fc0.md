The following descriptive quantities identify captured values, not object types:

| Doubled index | Twice the small index |

The first direct-memory group writes the positioned field as a word at the terminal high component plus 0x14. It then writes the high component’s low byte at positioned field plus 9, writes the scaled base at terminal low component times 256 plus 0x54, and overwrites positioned field plus 9 with the positioned field’s low byte.

Next, scaled base plus 0x14 is cleared as a word. A byte is captured from scaled base plus 5. Doubled index plus 0x14 is cleared; the captured byte is widened into a word at scaled base plus 0x34. The word at scaled base plus 0x14 is then captured as the **cleared-slot value**.

Doubled index plus 0x14 is cleared again. Two successive byte stores at doubled index plus 0x15 both use the cleared-slot value’s low byte.

**Only after those two stores**, storage at 0x05 is read and converted to an unsigned 32-bit **early global base**. Its declaration and original load width are unavailable; treating it as necessarily an unsigned byte would be unsupported.

The next fixed-address update writes the doubled index’s low byte at 0x01. The captured early global base then supplies derived addresses:

- Early global base plus 0x15 receives the small index’s low byte.
- Scaled base plus 0x11 receives the shifted payload’s low byte.
- Cleared-slot value plus 0x54 receives the shifted payload as a word.
- Scaled base plus 0x11 is overwritten with zero.
- A word is captured from early global base plus 0x54 as the **anchor**.
- That same apparent location is overwritten with the cleared-slot value.

The anchor remains the captured pre-overwrite value. Later changes to 0x05 or early global base plus 0x54 do not retroactively change it.

Define the **quadrupled anchor** as four times the anchor and the **octupled anchor** as eight times the anchor. Two byte stores at doubled index plus 0x15 use the quadrupled anchor’s low byte. **After both**, fixed storage at 0x15 receives the doubled index’s low byte.

## Acceptance examples

These are conditional criteria, not executed tests.

- **Input positioning:** Under 32-bit bit-vector shifting, inputs 1, 63, and 64 produce first shifted arguments 0x04000000, 0xFC000000, and zero, respectively. Equal shifted arguments do not establish equal overall behavior.
- **Masked extraction:** Applying the 24-bit mask and right shift of eight to 0x12ABCDEF yields 0xABCD.
- **Early global timing:** If a preceding derived store changes storage at 0x05, the later early-global capture must reflect that state under the actual global declaration. An entry-time snapshot is insufficient.
- **Middle capture:** If the 0x60 write changes storage supplying the other base, the repeated region still uses the value captured before that write.
- **Interleaved fixed write:** A consumer observing writes must retain the 0x54 update between the specified doubled-index updates; moving it to the end is not equivalent when addresses alias.

- **Byte widening:** An explicit unsigned byte read of 0xFE contributes word value 254, not a sign-extended negative value.
- **Partial failure:** Failure after a mutation does not require restoration or an error code.
- **Final transfer:** The represented first argument is 0x72; the remaining arguments use the specified captures.
