# F-582ac8a54e0d

## Purpose

F-582ac8a54e0d performs an ordered sequence of unresolved indirect invocations, transforms dependency-produced words, modifies fixed-address and computed-address storage, and finishes with an unresolved four-argument indirect transfer.

**Established static evidence:** argument forwarding, paired-result extraction, access widths, retained values, transient overwrites, repeated stores, and final argument positions are represented. No domain-level purpose, conventional success result, or valid object model is established.

**[INFERENCE]** Repeated offsets and address chains resemble record manipulation. They do not establish a list, allocator, parser, formatter, or device protocol.

This contract distinguishes access events from final memory contents. It preserves alias sensitivity without assuming that every computed destination can overlap every fixed address: arithmetic restrictions exclude some overlaps.

### Widths, retained quantities, and arithmetic

A byte, halfword, and word occupy 8, 16, and 32 bits respectively. Paired results occupy 64 bits. Narrow stores retain the low destination-width bits. Unsigned byte loads used as words are zero-extended.

Unsigned extraction beginning at bit 34, 36, or 44 of a paired result is equivalent to taking its high word and logically shifting that word right by 2, 4, or 12. These are not 32-bit shifts by the original extraction counts.

Intermediate truncation matters. A 32-bit left shift followed by a right shift does not restore discarded bits. Under ordinary 32-bit bit-pattern semantics, two successive left shifts by 28 produce zero.

Some address-producing shifts and multiplications have signed 32-bit operands. Negative left operands and signed overflow do not acquire portable arithmetic semantics from the representation. Modular identities below are conditional on ordinary 32-bit bit-pattern behavior.

The following descriptive terms name retained dataflow values, not object types:

| Quantity | Definition |
|---|---|
| Final low/high words | Last paired dependency result before the explicit memory-update region. |
| Shifted base | An earlier dependency-produced low word shifted left by 25. |
| Scaled base | Another dependency result multiplied by \(2^{25}\). |
| Small index | A dependency word shifted left by eight, masked with 0x7fff, then logically shifted right by six. |
| Index base | Twice the small index. |
| Retained shifted word | Another dependency result shifted left by eight. |
| Saved link | A word loaded through scalar base + 0x54 before that location is overwritten. |

Under 32-bit bit-pattern semantics, the small index ranges from 0 through 508 in multiples of four. The index base ranges from 0 through 1016 in multiples of eight.

Later values satisfy:

\[
\text{adjusted value}=4\times\text{saved link}-0x96
\]

\[
\text{computed base}=4\times\text{adjusted value}
=16\times\text{saved link}-0x258.
\]

Thus the adjusted value is congruent to 2 modulo 4 and cannot equal 1 under ordinary integer or 32-bit modular arithmetic. The computed base is congruent to 8 modulo 16.

The word at scalar base + 0x54 is retained as the saved link before that location receives the opening saved word. The small index is also stored as a word at index base + 0x34.

Further accesses use words loaded through offsets 0x74 and 0x54 as address-like values. Externally changing storage need not return equal values.

The saved link is stored at its own offset 0x24 twice. Those stores are interleaved with byte writes at offset 9 of a base loaded from scaled base + 0x74, and a word overwrite at that loaded base’s offset 0x54.

### Late fixed-storage effects

After repetition, a word is read from fixed address 0xa9, followed by a word from four times the selected target + 0x74.

This write precedes word reads from doubled target + 0x14 and computed base + 4. The first is retained as the **saved final word**.

Subsequent byte writes affect doubled target + 0x0d and computed base + 8, +0x0d, and +9. The +8 byte receives 0x6c. A word store places the doubled target at its own offset 0x54.

Fixed address 0x67 receives the earlier 0xa9 word’s low byte. After a word read from doubled target + 0x44, fixed address 0x67 is read to supply the byte written at fixed address 0x21. This is a storage read, not unconditional reuse of the retained 0xa9 word.

The +0x44 word supplies a byte at computed base + 0x10 and a word at repetition base + 0x54. It also supplies a signed variable right shift whose count is computed base’s low eight bits. The shift result’s low byte is stored at doubled target + 1.

That shift and byte store precede the word read at computed base + 0x40. Between them and that read, repetition base + 0x54 is overwritten with the computed base. After the read, repetition base + 0x74 receives the earlier computed-base +4 word, and computed base + 0x10 receives the newly loaded +0x40 word.

The word at computed base + 0x54 is then retained as the **late linked base**. Another read of fixed address 0x67 supplies another byte at computed base + 9. Neither later fixed-byte read may be replaced unconditionally with an earlier saved byte.

### Terminal effects and transfer

The late linked base receives a byte at +0x0d derived from the earlier selected-target-related +0x74 word. The saved final word is restored at doubled target + 0x54. A word subsequently read from computed base + 0x14 supplies the later byte at late linked base + 0x11.

Additional writes affect doubled target + 0x11 and computed base + 9 and +0x44. A word read from doubled target + 4 supplies the **terminal base**.

## Acceptance examples

These are conditional static-review examples, not executed tests.

1. **Initial forwarding.** With third argument 3 and ordinary shift behavior, F-000000000001 receives 96 as its second word and 3 as its third. Its first and fourth words equal the first argument.

2. **Paired extraction.** An initial result with low word 0x00123456 and high word 0x89abcdef supplies 0x12345600 and 0x89abcdef to the next invocation.

3. **Supported fixed-word alias and sampling time.** If the final high word is 0x087fbba8, the first explicit word store targets 0x087fbbbc. Sampling still occurs after the transient computed-base stores and before the fixed 0x60 store. Those transient words cannot themselves modify the sampled word under the stated address interpretation.

4. **Early fixed writes.** Index base 0x108 is compatible with small index 0x84. The fixed byte writes at 0x01 and 0x15 each carry 0x08 at their distinct positions. Under 32-bit bit-pattern doubling, saved link 0x12345678 supplies 0x2468acf0 to fixed word address 0x54.

5. **Reachable arithmetic byte.** Saved link 0x26 gives adjusted value 2 and computed base 8. The late arithmetic byte at 0x3a is 0x40. Its write remains between the selected-target-derived +0x74 read and the doubled-target +0x14 read. Adjusted value 1 is not an admissible example.

6. **Arithmetic-byte boundary.** Saved link 0x28 gives adjusted value 0x0a and computed base 0x28. The arithmetic-byte expression yields 0x80, a multiple of 0x20. A result congruent to 0x10 modulo 0x20 is incompatible with the established expression under ordinary bit-pattern semantics.

7. **Reloaded fixed byte.** If an intervening computed write changes 0x67 before a later read, that read supplies the changed byte. Reusing the retained low byte from 0xa9 is not generally equivalent.

8. **Late ordering and partial failure.** An access-observable trace places the variable-shift byte store before the +0x40 word read, and the 0x65 halfword store before the terminal-base +0x64 read and subsequent decimal-100 word store. If a later access faults, earlier stores need not be rolled back. Final-state-only substitution does not preserve these access events.
