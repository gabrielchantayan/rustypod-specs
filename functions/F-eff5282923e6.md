# F-eff5282923e6

## Purpose

The entry arguments depend on **two ordered source-visible evaluations of the same shared 32-bit location**. The first evaluation supplies the retained numeric value for the first entry. The second supplies the operand for addition by 2, whose result is retained for the second entry. The second entry’s numeric value equals the first entry’s numeric value plus 2 only if both evaluations yield the same value and the addition has defined behavior.

Every visible normal-return path returns the 32-bit value 1. The return value does not distinguish a negative-selector no-op, rejection by either check, or completion of the submission path.
