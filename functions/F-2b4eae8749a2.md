## Behavior

### Ordered operation

The established sequence is:

1. Derive the address at byte offset eight from the supplied object pointer.
2. Invoke the unconditional dependency with that address.
3. If that dependency returns normally, read the one-byte flag at byte offset four and compare it with zero.
4. If the flag is zero, skip F-ade1ebf0703a.
5. If the flag is nonzero, read the four-byte field at offset zero and invoke F-ade1ebf0703a with that value.
6. If execution reaches the normal return, return the original object pointer.

The unconditional dependency is invoked once on every execution that reaches its call. The conditional dependency is invoked at most once through the shown path.

No direct read of either field is shown before the unconditional call. No dependency return value controls the branch or supplies the final return value.
