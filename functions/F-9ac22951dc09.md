# F-9ac22951dc09

## Purpose

F-9ac22951dc09 performs a guarded sequence of operations on a caller-supplied object. If the object’s entry guard is zero, the function optionally invokes an indirect target, sets the guard, marks an associated object between two dependency calls, conditionally invokes a two-argument operation with at most one recovery-and-retry sequence, and calls a final dependency.

If the entry guard is nonzero, the function skips that sequence and returns zero.

The conditional operation is selected by a separate byte read **after** the marking dependencies return. Its value at function entry does not determine that later branch: preceding dependencies may change it.

These are structural descriptions. Shutdown, synchronization, resource release, and similar semantic interpretations are not established.
