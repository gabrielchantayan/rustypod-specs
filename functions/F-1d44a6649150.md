# F-1d44a6649150

## Purpose

- An optional entry action selected by an initial state-byte value of 5.
- Three update-related dependency calls, with a 32-bit accumulation between the second and third calls.
- A conditional selection stage when a later observation of the state byte equals 4.

### Main update sequence

### State-4 selection

After F-c55abf694c7b returns, the function rereads the byte at `0x04`.

If it is not 4, this stage makes no direct writes to `0x6C` or `0x70` and calls neither predicate.

If it is 4, the function first initializes a 32-bit predicate temporary to zero, then loads a separate 32-bit predicate temporary from `0x9C`. F-a09269e75221 receives two writable addresses, in this order:

1. The address of the word loaded from `0x9C`.
2. The address of the word initialized to zero.

These are distinct from the two words used to assemble the return value.

A nonzero result from F-a09269e75221 causes the function to:

- Write `0x01680000` to `0x6C`.
- Write zero to `0x70`.
- Skip F-5552a4ebb581.

A zero result causes the function to prepare the return-assembly words for F-5552a4ebb581:

- Set the low return word to zero.
- Reload the high return word from `0x9C`.
- Pass the high word’s address first and the low word’s address second.
