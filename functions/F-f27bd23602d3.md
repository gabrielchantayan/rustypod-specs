# F-f27bd23602d3

## Purpose

Its visible work includes transferring dependency-produced values into indexed storage, extracting bit fields, copying the low byte of stored words into nearby byte fields, updating global storage, and finally attempting a call to address zero.

No application-level purpose is established. In particular, the evidence does not establish that the routine initializes an object, processes a message, allocates storage, or implements a supervisor service.

The supplied static representation shows one straight-line path. It contains no explicit conditional branches, loops, validation, or recovery. Actual completion depends on every preceding dependency returning and every preceding memory operation succeeding.

## Behavior

### 1. Initial calls and first word transfers

The first dependency receives the second explicit argument. Its target is formed from the incoming control-register value plus a fixed displacement.

Subsequent indirect calls obtain a 32-bit result, forward that result to another dependency, and execute a sequence of additional calls. A later primary result selects a word slot. The routine writes the incoming word-valued register into that slot.

It then reads G-A and retains that sampled word across subsequent calls. The next dependency receives the selected index multiplied by four, rather than the word-slot address itself.

After another sequence of calls:

- The second incoming register value is logically shifted right by 22 bits.
- The sampled G-A value is logically shifted right by 23 bits.
- A secondary-register result selects another word slot.
- The 22-bit-shifted value is written to that slot.
- The next boundary call receives four explicit arguments: the secondary result twice, the shifted G-A value, and the shifted incoming-register value.

Subsequent calls obtain and forward another word result. During this interval, the already shifted G-A value is shifted right by 23 bits again. Because the first shift leaves at most nine significant bits, the second shift produces zero for every 32-bit G-A value.

A later primary result selects a word slot receiving another copy of the incoming-register value shifted right by 22. After further calls, a secondary-register result selects a word slot receiving zero. The following boundary call receives that secondary result.

### 2. Zero word publication and first byte transfer

Another dependency result is forwarded, followed by a sequence of calls that supplies a word-slot index.

That word slot receives the previously shifted G-A value shifted right by 23 again. This stored word is necessarily zero under the represented unsigned widths.

The routine then reads a word from:

**20 + ((the preceding secondary-result index AND 0x1fffffff) shifted right by 19).**

This is not the ordinary four-byte-scaled word-slot calculation. Its offset is between 0 and 1023, and it may be unaligned.

After further dependency calls, the sampled word is shifted right by 22. The routine then:

1. Reads a byte at absolute address 1, because the earlier twice-shifted G-A value is zero.
2. Adds 17 to that byte value.
3. Writes the low byte of the newly shifted word to that address.

The destination therefore lies between addresses 17 and 272. Only bits 29 through 22 of the sampled word reach this byte store; bits 31 and 30 are discarded by truncation.

The next boundary call receives one secondary-register word repeated three times and an explicit zero as its fourth argument.

### 3. Further byte clearing and dependency result retention

The routine executes another call sequence, including a call explicitly passed zero.

It then reads a byte at:

**1 + four times the word value obtained by the preceding 22-bit right shift.**

That shifted value is between 0 and 1023. The byte read therefore occurs at an address between 1 and 4093. The byte supplies an address component; the routine writes zero to address 17 plus that byte.

The next dependency receives a newly obtained primary result shifted left by two bits. Further calls obtain another primary result, and a following call receives its left-shift-by-two value twice.

A later 32-bit primary result is retained and forwarded. After another call:

- The byte at absolute address 1 is read again.
- Zero is written to address 17 plus that newly read byte.
- A secondary-register result is retained for later shifts.
- The next boundary call receives that secondary result three times.

The next result-producing call supplies a word forwarded together with the retained primary result logically shifted right by 23.

Following another call sequence, the byte at address 1 is sampled yet again. Zero is written to address 17 plus this sampled byte, and the byte value itself is retained as an address base.

These separate reads of address 1 must not be collapsed into one read. Dependencies occur between them and may alter memory.

### 4. First global assignment and word-to-byte copies

The routine passes a newly produced result shifted left by two to a dependency. A later result is similarly shifted and passed twice to another dependency.

A subsequent 32-bit result is:

1. Assigned to G-B.
2. Passed to the next dependency.

After another call, the routine reads a 32-bit word at offset 116 from the retained byte-valued base and writes its low byte at offset 1 from that same base.

The following boundary call receives the retained secondary-register result shifted left by 11.

A dependency then supplies a represented 64-bit result. Its low word, high word, and the result previously assigned to G-B shifted right by 23 are passed as three arguments to the next dependency.

Further calls supply an index. Four times that index becomes a new base. The routine reads a word at base + 116 and writes its low byte at base + 1. A dependency receives the base.

After another call sequence produces a new index, the routine retains four times that index. Before the next boundary call, it repeats the word read at offset 116 and byte write at offset 1 using the **previous** base. This is a fresh read, not a reuse of the earlier word.

The next boundary call receives:

- The retained secondary result shifted left by 12.
- Four times the new index.
- The same four-times-index value again.
- The new index shifted left by 18.

### 5. Captured word propagation and scaled link storage

Further calls obtain and forward results through another boundary. A later index selects another four-times-index base.

The routine reads a word at base + 116, retains the entire 32-bit word, and writes its low byte to base + 1. This full retained word remains significant after the byte store.

After a call receiving that base and another call sequence, a new index selects a destination at:

**20 + sixteen times the index.**

The retained full word is written there. This is a distinct scaling rule, not the ordinary word-slot address.

The next boundary call receives a value derived from the four-times-index retained in the preceding phase: logically shift it right by two, then shift left by 16. The original index’s highest two bits cannot be recovered after the initial scaling truncates them.

Results are then obtained and forwarded through further calls. A later index selects an ordinary word slot, which receives the same retained full word.

After a dependency receives four times that index and another call sequence completes:

- A new result is shifted left by two.
- That scaled result is written to address 20 plus the earlier retained scaled value with its lowest two bits cleared.
- The next boundary call receives the newly scaled result twice.

No explicit evidence identifies this stored value as an owned pointer, a linked-list link, or an allocation handle.

### 6. Zeroing and pair-result publication

Additional result-forwarding calls and intervening dependencies produce an index. Its ordinary word slot receives zero. The next dependency receives four times that index.

A later represented 64-bit result is split into two words:

- The low word is shifted left by two and retained.
- The high word selects an ordinary word slot.
- The retained scaled low word is written into that slot.

G-A is then read again. This is a new sample and need not equal the initial sample.

The next call receives four arguments: the scaled low word, the unscaled high word, and two further copies of the scaled low word.

After another sequence produces an index:

1. Its ordinary word slot receives the retained scaled low word.
2. A word is read from address 20 plus the newly sampled G-A value.
3. The next dependency receives four times the newly produced index.

The ordering is significant: the store precedes the read. If the two locations alias, the read can observe the just-written word.

### 7. Final byte transfers and terminal operations

Another sequence supplies a represented 64-bit result. Its low and high words are retained separately.

The routine uses the full word captured in phase 5, shifted right by 23, to select a byte-read address at that value plus 1. It then writes the low byte of the word sampled in phase 6 to address 17 plus the byte read.

The following boundary call receives:

- The latest high word three times.
- The latest low word shifted left by two as the fourth argument.

After further result forwarding and calls, another index is produced. Before passing four times that index to a dependency, the routine:

1. Masks the retained low word with 0x3fffffff.
2. Logically shifts it right by 21.
3. Reads a byte at that result plus 1.
4. Writes the low byte of the phase-6 sampled word shifted right by 22 to address 17 plus the byte read.

A further call sequence produces an index and passes its left-shift-by-two value twice. More calls obtain and forward another result.

The last visible dependency result used as a primary scalar is one byte wide. After that call:

1. Zero is written through a pointer supplied in the secondary result register.
2. G-C is read as a 24-bit value.
3. G-B receives a 32-bit composition with the dependency-produced byte in bits 7–0 and G-C in bits 31–8.
4. A zero halfword is written at address formed by masking the retained low word with 0x3fffffff and logically shifting right by seven.
5. A call to absolute address zero is attempted with three explicit zero arguments.

The final halfword destination ranges from zero through 0x007fffff and is not guaranteed to be aligned.

## Acceptance examples

These are conditional static acceptance cases, not executed tests. Each assumes preceding calls return and required accesses are valid.

1. **Successive shifts produce zero.** For any 32-bit initial G-A value, shifting right by 23 twice produces zero. The word store using this twice-shifted value must store zero.

2. **Incoming-register extraction.** If the relevant incoming register contains 0x00c00000, its logical shift right by 22 is 3. Both early word stores using that extraction receive 3.

3. **Byte truncation after extraction.** If the phase-2 sampled word is 0xc0000000, shifting right by 22 produces 0x300. The subsequent byte store writes zero, not 0x300 and not 3.

4. **Different scaling rules.** If both applicable dependency indices equal 3, an ordinary word slot is at address 32, whereas the sixteen-times-index destination is at address 68.

5. **Read after an aliasing write.** If the phase-6 word-slot destination equals the subsequent G-A-derived read address, the read observes the newly stored word, absent other memory semantics. Moving the read before the store changes behavior.

6. **Fresh low-memory observations.** If a dependency changes the byte at address 1 between two reads, the later destination uses the new byte. Reusing the earlier sample is not equivalent.

7. **Full-word retention.** If phase 5 samples 0x12345678, its immediate byte write stores 0x78, while later full-word publications still use 0x12345678.

8. **Final composition.** If the last primary byte result is 0x5a and G-C is 0x123456, the final composed assignment to G-B is 0x1234565a.

9. **Address-zero failure.** If address zero is not executable, the final call cannot be assumed to return normally. Earlier stores are not rolled back by any visible mechanism.
