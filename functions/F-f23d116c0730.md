## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Immediate return:** If the first effective state is 1, the routine returns without dependency calls or record accesses. Entry reads and the first dispatch-offset read still occur.

2. **Entry initialization:** The initial dispatcher read precedes null initialization of the working record pointer; that null initialization precedes zero initialization of the comparison operand. Argument saves follow all three operations.

3. **Setup sampling:** If the setup multiplier changes between its two reads, the derived argument and comparison operand may reflect different values. Reusing one multiplier snapshot would not preserve the accesses.

4. **Before setup:** State 0 receives three zero working arguments; state 11 receives one zero working argument.

5. **State 7 transition:** On reaching state 7, the saved and main accumulators are updated before its next-dispatch global is read. The comparison operand is updated afterward, followed by a fresh dispatch-offset read.

6. **Distinct saved values:** After state 0 establishes a retained value, state 7 can change the saved accumulator without changing that retained value. A later state 12 restores the retained value.

7. **State 8 restoration:** After state 6 replaces the main accumulator, state 8 discards that replacement and transforms the saved accumulator instead.

8. **Unrefreshed comparison:** State 2 can change the main accumulator without changing the comparison operand. A subsequent state 10 consumes the existing comparison operand.

9. **Byte masking:** A table byte of 255 becomes 55 after multiplication by 201 and eight-bit retention. A record byte of 255 becomes 5 after multiplication by 251 and eight-bit retention.

10. **Call boundary:** If F-d7be9cfb4000 changes transformation globals, the first transformation uses pre-call accesses and the second uses post-call accesses.

11. **Output ordering:** With termination index 20, the zero store at output offset 20 precedes submission with literal argument 21. With the entry index unchanged, the store occurs at offset 0 instead.

12. **State 12 branch reads:** The first candidate read precedes retained restoration; the second follows it. Collapsing them into one read loses an established access boundary.
