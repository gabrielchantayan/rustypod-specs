# F-128bc7e093a3

## Purpose

F-128bc7e093a3 updates one bit in a word located at byte offset 16 from a supplied base address. The second argument selects whether that bit is cleared or set:

- Zero clears bit 2, whose numeric mask is 4.
- Any nonzero value sets bit 2.

All other bits in the value read from that word are retained in the value written back.

**Established static behavior:** the function performs a read–modify–write of the selected word. It does not compare the requested state with the existing state before writing.

**Inferred intent:** the selected bit likely represents a Boolean property within a larger flags field. Neither the property’s meaning nor the surrounding object’s identity is established. This contract therefore calls it the **target bit**, not an enabled, active, visible, or other domain-specific state.

## Behavior

### Ordered memory effects

For a valid invocation, the source establishes this logical sequence:

1. Select the clear or set operation using the second argument’s zero/nonzero value.
2. Read one unsigned word at the supplied base address plus 16 bytes.
3. Form the replacement value by clearing or setting the target bit in the value read.
4. Write that replacement value to the same address.
5. Return without a result value.

Only one branch executes. Each branch contains one field read, and both converge on one field write.

This is a source-level access sequence. It does not establish an exact processor instruction sequence, bus transaction count, or memory-mapped device transaction pattern.

### Clear operation

When the selector is zero, the stored result is the word read combined with the clear mask by bitwise AND.

Under the 32-bit field model:

- Bit 2 becomes zero.
- Bits 0, 1, and 3 through 31 retain their values from the read.
- No carry, borrow, saturation, or arithmetic normalization occurs.

If the target bit was already zero, the replacement value equals the value read. The function still reaches the store.

### Set operation

When the selector is nonzero, the stored result is the word read combined with mask 4 by bitwise OR.

Under the 32-bit field model:

- Bit 2 becomes one.
- Every other bit retains its value from the read.

If the target bit was already one, the replacement value equals the value read. This case also reaches the store.
