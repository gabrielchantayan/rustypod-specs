# F-168d7d8f17dc

## Purpose

For a representable, nonnegative difference, the return value is the difference divided by four, rounded down. The shift applies to the completed difference, not separately to each input.

A possible intent is to express a distance in four-unit quantities. This is inferred intent only. The supplied source does not establish that either element represents an address, offset, length, counter, or particular unit.
