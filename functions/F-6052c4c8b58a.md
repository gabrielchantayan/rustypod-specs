# F-6052c4c8b58a

## Purpose

F-6052c4c8b58a performs state-dependent indirect calls, mixed-width memory accesses, arithmetic transformations, and nested iteration. The supplied static representation does not establish an application-level purpose.

Behavior depends on implicit machine state as well as four explicit inputs. Several paths construct addresses from small integers. One attempts a halfword write at address zero. Several terminate at marked invalid-instruction boundaries.

This contract describes operations conditional on execution reaching them. It does not establish valid memory mappings, successful calls, reachability of every branch, or reachability of the represented normal return.

## Behavior

### Outer-loop entry

Each outer iteration:

1. Initializes a destination state **W** to G.
2. Reads a 32-bit word at current S + 0x28, initially becoming selected state **M**.
3. Forms **T** from the signed 32-bit subtraction R − 0xD1, assigning the result to a 32-bit unsigned quantity.
4. Tests whether the signed low half of V, reduced by 0xDF, is negative.

Both subtractions require qualification at signed-overflow boundaries. The initial memory read occurs before the path selection, even if its result is not subsequently consumed.

### Negative-result path

This path captures current S into U and initializes a 32-bit accumulator to zero. No dependency call intervenes between the outer-entry read and this capture. W and M retain their outer-entry values.

Each inner iteration performs, in order:

1. Store V’s low 32 bits at W + 0x30.
2. Store M’s low 16 bits at D + 0x0E.
3. Read a 32-bit address **I** at U + 0x36C.
4. Store L at U − 4, E at U − 8, and V’s high half at U − 12, in that order.
5. Invoke F-000000000001.
6. Store the accumulator’s low 16 bits at I + T.
7. Read an unsigned halfword at I + 0x1C; its zero-extended value becomes address **H**.
8. Read the signed word at U + 0xA0, arithmetically shift it right by 30, and replace D with that 32-bit pattern.
9. Read an unsigned halfword **N** at H + 0x2C and replace M with N.
10. Invoke F-000000000002, replacing V with its paired result.
11. Read an unsigned byte **Q** at V’s high-half address + 9 and replace W with Q.

The read at U + 0xA0 uses the saved cursor, not current S after F-000000000001. More generally, this inner path has no further explicit S-relative access: its cursor-relative operations continue to use U despite possible dependency effects on S.

W and M are carried state. A repeated iteration starts with the preceding Q as its destination state and the preceding N as its selected halfword. G is not restored on the inner back edge.

#### N at least two

U becomes D logically shifted right by nine. An unsigned halfword **Z** is read at V’s high-half address + 0x6C.

The following word stores occur in order:

| Destination | Value |
|---|---|
| Q + 0 | Q |
| Q + 4 | U |
| Q + 8 | N |
| Q + 12 | V’s low half |
| U + 0 | Zero |
| U + 4 | Q |
| U + 8 | H |
| U + 12 | U |
| U + 16 | N |
| U + 20 | Z, converted to a nonnegative signed 32-bit value, arithmetically shifted right by Q, then reduced by four |

Q is between 0 and 255, so the first group targets low numerical addresses. Regions may overlap; later stores occur after earlier stores without an intervening snapshot.

Counts Q ≥ 32 leave the shift behavior unresolved. Execution then reaches an invalid-instruction boundary; no continuation is represented.

#### N zero or one

E becomes H + 0xF3, L receives a fixed link marker, and F-000000000003 is invoked. Its paired result replaces V; its low half also replaces the accumulator.

If bit 26 of T is set, execution reaches an invalid-instruction boundary. Otherwise, T shifts left by nine, retaining its low 32 bits, U retreats by twelve bytes, and the inner loop repeats.

The repeated iteration retains updated D, E, L, V, accumulator, W, and M. Its U is the previous saved cursor minus twelve, not a recapture of current S.

### Other outer-loop path

Let **X** be signed T arithmetically shifted right by eight. The function records whether subtracting 0x13 from X causes signed 32-bit overflow, then:

1. Invokes F-000000000004 with 0xB5, X, and 0xF3.
2. Replaces L with a fixed link marker.
3. Invokes F-000000000005 with the preceding result and α.
4. Replaces V with that dependency’s paired result.
5. Captures **current S, after F-000000000005, into U**.

Descriptor processing occurs when the negative-sign predicate on V’s low half equals the recorded overflow flag. Otherwise, execution proceeds to outer-loop continuation.

Under ordinary 32-bit arithmetic-right-shift semantics, X ranges from −8,388,608 through 8,388,607. Subtracting nineteen cannot overflow, so the flag is false and descriptor processing requires a nonnegative low half. The represented condition is nevertheless equality between Boolean predicates, not a comparison with nineteen.

2. Read a 32-bit data pointer **P** at descriptor + 4.
3. Read a signed 32-bit quantity **J** at descriptor + 12.
4. Read the descriptor’s first word and pass it to F-000000000007.
5. Arithmetically shift saved J right by 27 to obtain **K**.

### Common loop

Both continuing nonzero-K branches repeatedly:

1. Invoke F-000000000012 with the current signed 32-bit loop value.
2. Subtract 0x95 from the returned signed value.
3. Store Q’s low byte at P + 0x1C.
4. Repeat if the subtraction result is negative.

The subtraction remains unresolved at signed-overflow boundaries. The byte store precedes the repetition decision.

The first indirect target depends on the entering branch; subsequent iterations use another fixed target. The opaque ID identifies a dependency role, not a proven single function.

Loop exit reaches an invalid-instruction boundary, not a return.

### Outer-loop continuation

Only paths skipping descriptor processing or completing the K-zero branch reach this continuation. They replace R with the low 32 bits of T × 0x40, assign S from saved U, and repeat.

- **Descriptor processing skipped:** U is the S value captured after F-000000000005. It need not equal the outer iteration’s entry base.
- **K zero:** U is the post-F-000000000007 base plus four, captured after reading Y. It need not equal the outer entry base plus four. F-000000000008 may change live S, but continuation overwrites it with saved U.

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Initial negative path.** With A zero and ordinary signed arithmetic, the first word store targets G + 0x30 and contains zero, conditional on reaching and completing that access.

2. **Carried state.** If a negative iteration reads N = 1 and Q = 37, F-000000000003 completes, and bit 26 of T is clear, the next word store targets address 85. Its following halfword store contains one and uses updated D.

3. **Saved negative cursor.** If F-000000000001 changes S, the subsequent +0xA0 word read still uses saved U. The next inner iteration retreats that U by twelve; it does not capture the changed S.

4. **Skipped descriptor processing.** Suppose outer entry uses base s₀, F-000000000005 leaves S equal to s₁, and descriptor processing is skipped. Continuation assigns S from captured s₁, not necessarily s₀.

5. **K-zero continuation.** If F-000000000007 leaves S equal to s₂, Y is read through s₂ and U becomes s₂ + 4. Even if F-000000000008 subsequently changes S, continuation restores the saved s₂ + 4, subject to address-arithmetic validity.

6. **Nonnull live destination.** If U was captured as s₂ + 0x44 and the two following calls leave S equal to s₃, the pointer read uses s₃ + 0x11C and the cursor store targets s₃ + 0xC0 while storing saved s₂ + 0x44.

7. **Narrowing.** A descriptor byte of 200 produces adjusted Q = 299. The nonnull-path halfword store contains 598; common-loop byte stores contain 43.

8. **Null write and arithmetic boundary.** Completion of the two null-P calls leads first to the attempted halfword write at zero. If execution later reaches B₂ formation with B₀ = 0x7FFFFFFF, no wrapped B₂ value is guaranteed because signed addition overflows.

9. **Conditional return.** A result of 0x12000000 from F-000000000010 selects the Ω-to-P word transfer and return, after the live-S +0x220 store. A result of 0x12000001 does not.
