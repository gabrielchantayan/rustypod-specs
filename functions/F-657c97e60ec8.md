# F-657c97e60ec8

## Behavior

It then invokes F-U01 with one visible argument: four times the explicit input. Four further calls follow, F-U02 through F-U05, with no explicit arguments shown.

The operation then:

2. Reads an unsigned 32-bit word from its word location.
3. Retains that loaded word for later bit extraction.

The store precedes the read. They address the same location when the first returned index is zero; additional aliasing depends on the machine address model.

There is no intervening visible call between this store and load.

### 2. Shifted-word store

F-U06 receives four times the first returned index. F-U07 through F-U10 then execute without explicit arguments shown.

The result of F-U10 is retained as the **second returned index**.

The operation stores the previously loaded unsigned word, logically shifted right by 12 bits, at the word location of the second returned index.

This stored value is derived from the earlier load, not from a fresh read after F-U06 through F-U10. Changes those dependencies make to the original memory location do not, by themselves, change the retained value.

### 3. Second wide-stride store and three-argument call

F-U11 receives four times the second returned index. F-U12 through F-U15 follow without explicit arguments shown.

The result of F-U15 is retained as the **third returned index**.

The operation stores four times the third returned index at its wide-stride location. It then invokes F-U16 with three visible arguments, in this order:

1. The low six bits of four times the second returned index, shifted left by 14 bits.
2. Four times the third returned index.
3. The second returned index shifted left by 30 bits.

Under 32-bit bit-vector arithmetic, the first argument can be written mathematically as

\[
((4 \times \text{second returned index}) \mathbin{\&} 63) \times 2^{14}.
\]

It is always a multiple of \(2^{16}\), ranging from zero through \(15 \times 2^{16}\). The second returned index shifted left by 30 retains only that index’s lowest two bits.

F-U17 through F-U20 then execute without explicit arguments shown. The result of F-U20 is retained as the **fourth returned index**.

The operation stores four times the third returned index at the word location of the fourth returned index.

### 4. First byte-selected write

F-U21 receives four times the fourth returned index. F-U22 through F-U25 follow without explicit arguments shown.

The unsigned 32-bit result of F-U25 is retained as the **payload word**.

The operation then:

1. Reads one unsigned byte from the selector location of the second returned index.
2. Adds 17 to that byte’s numerical value.
3. Writes the low byte of the payload word shifted left by two bits to the resulting address.

The byte read is used directly as an address selector. It is not established to be an offset within an object, a pointer-table index, or an owned allocation.

Because the selector is an unsigned byte, the numerical destination address lies between 17 and 272 inclusive. This range does not establish that those addresses are mapped or writable.

Under 32-bit address arithmetic, the selector location depends only on the lowest four bits of the second returned index. It is one byte beyond the address formed by shifting those four bits into the highest nibble.

### 5. Payload forwarding and intervening calls

After the first byte store, F-U26 receives three visible arguments:

1. The payload word shifted left by two bits.
2. The same shifted value again.
3. The payload word shifted left by four bits.

The first two arguments are equal. The third is separately formed from the original retained payload word.

F-U27 is then called without explicit arguments shown. Its 32-bit result is passed as the sole visible argument to F-U28.

F-U29 through F-U32 follow without explicit arguments shown. The result of F-U32 is retained as the **fifth returned index**.

The visible body does not use the result of F-U27 for any other purpose. No ownership transfer or resource lifecycle can be inferred from this forwarding.

### 6. Second byte-selected write

After F-U32 returns, the operation reads the selector byte again from the selector location of the second returned index.

This is a new memory read, not reuse of the first selector byte. The dependencies between the two reads may have changed that memory.

The operation retains the newly read byte as an unsigned word and writes one byte at its numerical value plus 17. The written value is the low byte of:

\[
(\text{payload word} \mathbin{\&} \texttt{0x3fffffff}) \mathbin{\gg} 20.
\]

The right shift is logical. After the byte-width truncation, the written byte corresponds to payload bits 20 through 27. Payload bits 28 and 29 survive the shift but not the final byte store; bits 30 and 31 are removed by the mask.

The payload word is the retained F-U25 result. It is not obtained again from a dependency or memory.

If the selector byte is unchanged, the second byte store targets the same address as the first and replaces its value. If it changes, the two stores may target different addresses.

### 7. Final dependency group and visible boundary

F-U34 through F-U37 follow without explicit arguments shown. The result of F-U37 is retained as the **sixth returned index**.

F-U38 then receives two visible arguments:

1. The sixth returned index shifted left by two bits.
2. The zero-extended selector byte captured immediately before the second byte store.

The second argument is that captured byte, not another memory read and not the address obtained by adding 17.

F-U39 is invoked without explicit arguments shown. The supplied representation then reaches the invalid-data boundary.
