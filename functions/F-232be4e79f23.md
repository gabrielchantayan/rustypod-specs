# F-232be4e79f23

### Four-byte context replacement

The result designated for byte write 14 also supplies a signed multiplication by four. That replacement value is calculated before byte write 14.

## Acceptance examples

These examples are conditional requirements, not executed tests. Each assumes that the relevant events are reached and that the necessary arithmetic, conversions, storage accesses, and invocations are supported.

1. **Nonzero byte replacement.** If the replacement byte at a reached write is 165, that write stores 165. Replacing it unconditionally with zero violates the value relationship.

2. **Address rather than stored contents.** A context-address conversion of 1 gives write 1 a numerical destination of 256. If both following argument evaluations also use 1, both arguments are 524,288. Changing only the old contents at the context address does not directly change these calculations.

3. **Same producer, different scales.** A designated result of 5 for write 2 gives destination 40 and two following arguments of 81,920. Neither argument is derived from the byte written at destination 40.

4. **Retained secondary information.** A captured secondary value of 3 gives write 8 destination 6,144 and two following arguments of 12,582,912. The four designated additional arguments between writes 8 and 12 still use 3 when later secondary observations differ.

5. **Read after an overlapping write.** A context conversion of 16 gives observation address 2,080. A designated result of 260 for write 12 targets the same starting byte. The subsequent read concerns the then-current two-byte span. Its complete value also depends on the other byte, byte order, and any interference.

6. **Retained replacement rather than reread memory.** A designated result of 7 for write 14 gives byte destination 56 and four-byte replacement value 28. The context replacement precedes the consumer receiving three copies of 28. If later activity changes the stored contents to 99, the designated retained argument still derives from 28.

7. **Overlap preserves order, not both final values.** If write 14 targets storage within the context span, the following four-byte write may overwrite that byte. The contract requires the ordered effects, not independent persistence of both replacements.

8. **Argument arithmetic can exceed its range first.** An ordinary paired-argument operand of 131,071 gives 2,147,467,264. Operand 131,072 would require 2,147,483,648, outside signed 32-bit range, although its eightfold destination fits. Wrapping is not an established requirement.

9. **Separate secondary occurrences.** The secondary value forwarded between writes 2 and 3 need not equal the retained value used for write 8. Substituting the retained value solely because both are 32 bits violates their distinct provenance.

10. **Partial effects are possible.** If a dependency prevents continuation after earlier writes, those writes need not be undone. If F-D03 prevents continuation, F-D04 is not required.
