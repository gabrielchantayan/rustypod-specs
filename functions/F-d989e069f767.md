# F-d989e069f767

### Optional call controlled by the second input

- If the control argument is nonzero, the function invokes F-5c5958cfd5fe without arguments.

### Eligibility for context inspection

After the optional call, or immediately after the primary operation when that call is skipped, the function reads the 16-bit source field at offset 0xE6.

The remaining propagation behavior requires both:

- The value observed in that source-field read is nonzero.
- The original control argument is nonzero.

The source-field read occurs before the control argument’s test within this eligibility condition. Thus, a zero control argument suppresses later context inspection and copying, but does not suppress the source-field read.

If the source-field value is zero, no further dependency is called and no explicit field write is performed by this function.

If the source-field value is nonzero but the control argument is zero, the same outcome applies: no further dependency is called and no explicit field write is performed.

### Context inspection and conditional propagation

When both eligibility conditions hold, the function calls F-fdd8589eca2d again. It reads the 16-bit field at offset 0x80 from the address returned by this invocation.

If that observed context field is nonzero, propagation stops. There is no further context lookup and no explicit field write.

If that observed context field is zero, the function:

- Calls F-fdd8589eca2d one more time.
- Reads the source field at offset 0xE6 again.
- Writes that newly read 16-bit value to offset 0x80 of the address returned by this final context lookup.

The context whose field was checked is not necessarily the context whose field is written. The function obtains their bases through distinct dependency calls and does not establish that the returned addresses are equal.

Likewise, the value written is not necessarily the nonzero value that originally enabled propagation. The source field is read again after the final lookup. If intervening effects change it to zero, zero is copied. If they change it to another nonzero value, that later value is copied.

There is no second zero check on the destination field. If the final lookup returns a different context with a nonzero field, that field is still overwritten.

The function does not explicitly write the source field. That does not establish that the source remains unchanged: dependencies may modify it, and the eventual destination may alias source storage.
