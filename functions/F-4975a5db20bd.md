## Behavior

### Eligibility gate

The function reads the 16-bit field at record offset 12 and compares it with exactly 1.

If the comparison fails:

- The function returns 4.
- The byte-source address is not read.
- The byte at that address is not read.
- The first record word is not read.
- None of the three dependencies is called.

The gate is an equality test, not a general truth test. Values such as 2, −1, and any other nonzero value except 1 select the ineligible path.
