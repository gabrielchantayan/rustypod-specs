Its directly represented effects include two stores of the same 32-bit payload, a retained-base word read, two byte stores whose destinations are selected by byte lookups, publication of a dependency result to global storage, two clears, and a final call to address zero.

## Behavior

### Initial store and base capture

The first visible memory operation stores the full payload at the address calculated as four times the initial index plus `0x14`. No dependency call or bounds check precedes this store.

The function then captures G-base into a retained signed 32-bit value. That retained value later supplies the base for a word-read address.

This order permits the initial payload store to affect the captured value if the store overlaps G-base. A later change to G-base does not redirect the represented word read, because that read uses the retained value rather than rereading the global.

### First call group and captured-word read

F-dep-01 receives these explicit arguments, in order:

1. Payload.
2. Initial index.
3. Payload.
4. Payload.

Its target is formed from the incoming link-like value plus `0xFFE`.

Next, it reads an unsigned 32-bit word at the retained G-base value plus `0x14`. This contract calls that result the **captured word**.

The read follows F-dep-01 through F-dep-05 and the second payload store. Those calls and that store can therefore affect the value read through aliasing. The base addition uses a represented signed value; wrapping is not established.

2. High result.

Only original low-result bits 21–29 influence this address. Its range is 1 through 512, inclusive.

An unsigned byte is read from that address. The byte’s numeric value plus `0x11` selects the second byte-store destination, again between `0x11` and `0x110`, inclusive.

The stored byte consists of captured-word bits 22–29. The represented operation shifts the unsigned captured word right by 22 bits and retains the low eight bits. Original bits 30–31 do not survive the byte-width conversion.

The function uses the retained captured word. It does not reread the memory from which that word was obtained.
