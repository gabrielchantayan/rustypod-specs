## Behavior

The first externally relevant operation is a call to F-9c7d16339f0f with the original input and the integer value one.

The result controls entry into processing:

- If the observed result equals zero, the function enters the processing phase.
- If the observed result is any value other than zero, the function returns one immediately after that query returns.

An initial result of one therefore does **not** cause processing. It causes immediate return of one. This differs from the interpretation of one at later query points.

On the immediate-return path, F-cef945e6e384 is never invoked.

### Processing phase

Entry into the processing phase guarantees an invocation of F-cef945e6e384, provided execution reaches that invocation normally. There is no additional query between the initial zero result and this first processing call.

After each invocation of F-cef945e6e384:

- An observed result unequal to zero causes an immediate return of zero.
- An observed result equal to zero permits a call to F-9c7d16339f0f with the same two argument values used for the initial query.

No query is made after a nonzero processing result. In particular, a nonzero result is not followed by a final status check or by any visible cleanup call.

### Continuation and termination after processing

A query made after a zero processing result uses a different continuation condition from the initial query:

- An observed result equal to one causes another processing iteration.
- An observed result unequal to one causes the function to return one.

Consequently, a later query result of zero terminates the function, even though an initial query result of zero starts processing. A later query result other than zero or one also terminates with one.

The processing and query calls alternate strictly after entry into the processing phase. Two processing calls cannot occur consecutively without an intervening query that returned one. Two query calls cannot occur consecutively without an intervening processing call that returned zero.

### Termination and call counts

If the initial query returns zero, every processing call returns zero, and every later query returns one, the function continues indefinitely, assuming the dependencies keep returning normally.

- If termination occurs at the processing dependency on processing call number *n*, there have been *n* processing calls and *n* query calls, including the initial query.
