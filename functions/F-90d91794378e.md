# F-90d91794378e

## Purpose

F-90d91794378e accepts four represented 32-bit words and normally returns a 32-bit word. It classifies the primary input, conditionally invokes numerical dependencies, applies table-driven adjustments, and constructs a result using integer operations.

**Established static behavior:** small primary magnitudes return `0x3f800000`; positive and negative upper cutoffs produce different early returns. Remaining inputs enter helper-driven processing, where rejected states invoke a dependency with no represented normal return. Later processing includes exponent gates, ordinary-operand result assembly, exceptional-operand handling, and unresolved indirect continuation.

**Inferred intent:** the constants, reduction structure, and exponent manipulation suggest an exponential-like numerical operation. They do not establish a mathematical identity, accuracy bound, IEEE 754 contract, or conventional floating-point calling interface.

This contract describes the supplied static representation. No runtime tests have been performed.

## Behavior

### Entry reads and classification

The function first reads a stored 32-bit result word. Denote this captured word by \(C\). This read precedes all entry-classification returns.

Classification then proceeds in this order:

1. Magnitude below `0x33800000` returns `0x3f800000`.
2. Otherwise, a clear sign bit and magnitude at least `0x42b40000` cause a **second read of the same result storage**; that newly read word is returned.
3. Otherwise, a set sign bit and magnitude at least `0x42d00000` return zero.
4. All remaining primary words enter helper-driven processing.

The positive cutoff does not return the captured word \(C\). The two storage reads must remain distinct because storage stability is unestablished.

Consequences:

- Both signed zeros, all subnormal primary encodings, and other magnitudes below the small-input threshold return `0x3f800000`.
- The small-input comparison is strict; both upper cutoffs include equality.
- Positive-sign infinity and NaN encodings take the positive cutoff and its second read.
- Negative-sign infinity and NaN encodings return zero after the entry read.
- No primary NaN payload propagation or signaling behavior is established.

A later primary-input branch tests for an all-ones exponent. Every primary word satisfying that test has already returned through an upper cutoff. Its internal alternatives are therefore unreachable in the represented end-to-end flow.

\[

### Reachable exceptional-operand behavior

Exceptional scaling is selected when either exponent is zero or 255. At this point, however, \(R\)'s exponent is nonzero and \(S\)'s fraction is zero.

If both exponents are below 255, the exceptional condition therefore means that \(S\) has exponent zero and \(R\) has exponent 1 through 254. The returned word is zero with the XOR of the operand signs. This return occurs before any dispatch-related read.

The represented fragment also contains zero-exponent-\(R\) alternatives, including a different zero-sign rule for a nonzero fraction. Those alternatives are unreachable after the earlier rejection and do not extend this contract’s achievable outputs.

For the remaining exceptional cases:

1. Select wrapped \(2R\) if it is unsigned-greater than `0xff000000`; otherwise select wrapped \(2S\).
2. Read a stored dispatch-related word.
3. Compare the selected classification word against `0xff000000`.

The dispatch-related read occurs even when no indirect continuation follows.

If the selected word does not exceed `0xff000000`:

- A zero exponent in either operand causes a subsequent read of separate special-result storage, whose newly read word is returned. In the reachable flow, only \(S\) can have that zero exponent.
- Otherwise, return an infinity encoding with the XOR of the operand signs.

If the selected word exceeds `0xff000000`, execution reaches unresolved indirect continuation handling. Because \(S\)'s fraction is zero, this condition requires an all-ones exponent and nonzero fraction in \(R\).

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Small boundary.** Primary `0x00000000`, `0x80000000`, or magnitude `0x337fffff` returns `0x3f800000` after the entry read. Magnitude `0x33800000` passes this test.

2. **Distinct positive-cutoff read.** If entry result storage first yields \(X\) and subsequently yields \(Y\), primary `0x42b40000` returns \(Y\), without the listed helper calls. Primary `0x42b3ffff` enters helper-driven processing.

3. **Negative cutoff and primary exceptions.** Primary `0xc2d00000` returns zero; `0xc2cfffff` enters helper-driven processing. Positive infinity and positive NaN encodings take the positive cutoff. Negative infinity and negative NaN encodings return zero.

4. **Reduction rejection order.** A signed reduction index of −110 invokes F-a817d8d58c10 after the initial helper sequence but before F-870c4fcf7295. Index −109 passes that rejection.

5. **First-base timing.** Conditional on a nonzero high word, use the first base read after F-870c4fcf7295 returns. The entry address is that base plus `0x08034010` plus four times the high word, wrapping to 32 bits. A pre-call base value is not a substitute.

6. **Secondary-base timing and positions.** If the first combining call changes the positive base and the secondary adjustment is 1, read the positive base afterward and access that base plus `0x08034044`. For secondary adjustment −1, read the negative base and access that base plus `0x08034070`. Adjustment −11 uses that base plus `0x08034098`.

7. **Invalid secondary adjustment.** Adjustments −12 and 9 invoke F-a817d8d58c10 without a secondary-base or secondary-entry read. Any selected first-table access and combining call have already occurred.

8. **Intermediate rejection and captured overflow.** Every zero-exponent \(R\), including a subnormal encoding, invokes F-a817d8d58c10 before scaling. For a nonzero exponent satisfying the first exponent gate, return entry-captured \(C\), without rereading its storage.

9. **Ordinary boundary predicates.** Conditional on reaching ordinary scaling with \(K=\texttt{0x00fbffff}\), return \(V\). At \(K=\texttt{0x00fc0000}\), clear bit zero before the subsequent boundary decision. This is not a numerical tie-rule assertion.

10. **Exceptional read order.** Conditional on reaching scaling with \(R=\texttt{0x7f800000}\) and \(S=\texttt{0x00000000}\), select classification, read dispatch-related storage, then read and return special-result storage.

11. **Reachable zero-sign rule.** Conditional on reaching exceptional scaling with \(R=\texttt{0xbf800000}\) and \(S=\texttt{0x00000000}\), return `0x80000000` without the dispatch-related read. A zero-exponent \(R\) is not an alternative achievable example.
