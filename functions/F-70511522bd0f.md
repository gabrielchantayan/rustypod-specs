## Acceptance examples

These are **conditional static acceptance examples**, not executed tests. Each assumes that preceding dependencies return normally, required accesses succeed, and unspecified dependency effects do not invalidate the stated conditions.

1. **Full-word retention.**  
   If F-D09 returns `0x100` and address `0x474` contains `0xA1B2C3D4`, the initial byte store writes `0xD4` at `0x401`. Later original-word stores use all of `0xA1B2C3D4`.

3. **Third-argument transformation.**

4. **Unsigned destination wraparound.**

5. **Split-result forwarding.**  
   If F-D42’s low half is `3` and high half is `5`, the corresponding store writes `12` at `0x28`, and F-D43 receives `12, 5, 12, 12`.

6. **Captured base, delayed word read.**

9. **Unaligned final clearing.**
