# F-71750d535707

## Purpose

F-71750d535707 selects one of two layout-related descriptors using a flag in a caller-supplied object, passes the selected descriptor and two mutable argument slots to an opaque dependency, and forwards that dependency’s result to another dependency together with the object. It then invokes a final dependency on one of the argument slots and returns the 32-bit value 1.

The established behavior is this selection and call sequence. The descriptor labels suggest a choice between a scrub layout and a scrub-video layout. Their application meaning, and whether the calls actually perform navigation, are inferred intent rather than established behavior.

This contract describes static evidence only. No runtime tests have been performed.
