## Acceptance examples

These are conditional static obligations, not executed tests.

- **Opening alias sensitivity:** If writing opening B value’s low byte to A at `0x09` changes bytes belonging to A’s `0x74` link through overlap, the subsequent link read must observe the changed memory. Capturing that link first is incompatible.
- **Retained versus fresh:** Opening C value remains the payload of the early A-at-`0x54` store even if an intervening write changes C at `0x74`.
- **Separated redistribution reads:** If the word store of `0x73` to redistribution child at `0x20` changes primary at `0x64`, early and late redistribution values may differ. Primary at `0x44` receives the early capture; descendant child at `0x24` receives the late capture.
- **Full-width descendant propagation:** Both the selected current-primary-target `0x14` destination at `0x54` and redistribution region at `0x34` receive the complete descendant link, not just its low byte.
- **Captured pre-self-reference byte:** Linked byte target at `0x11` receives the low byte captured from primary at `0x54` before its self-reference replacement, not necessarily primary’s low byte.
- **Character signedness:** For terminal byte representation `0x80`, signed 8-bit character semantics yield terminal byte value `0xffffff80` and first argument `0xffffffc4`. Unsigned semantics yield `0x00000080` and `0x000000c4`. Representation `0x01` yields first argument `0x00000045` under either interpretation.
- **Repeated accesses:** Both consecutive primary-at-`0x0d` byte stores and both terminal-link-plus-primary halfword stores remain required.
- **Access failure:** An inaccessible derived destination does not require successful dispatch, a status result, or rollback.
