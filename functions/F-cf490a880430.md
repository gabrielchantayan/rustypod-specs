# F-cf490a880430

## Purpose

F-cf490a880430 transfers two consecutive 32-bit words from a source region to a destination region.

The distinguishing behavior is **ordered, word-at-a-time transfer**: the first source word is read and written to the first destination word before the second source word is read. The function does not first capture both source words. Consequently, overlapping regions can cause the first destination write to change the value subsequently read for the second transfer.

This contract describes the behavior established by the supplied static representation. It does not establish a general-purpose, overlap-preserving memory-copy operation.

## Interface

The function accepts two pointer arguments, in this order:

| Argument | Role | Required accessible region |
|---|---|---|
| First | Destination | Two consecutive writable 32-bit words |
| Second | Source | Two consecutive readable 32-bit words |

The function returns no value. Its result is communicated through destination memory.

### Width and layout

Each transferred element is 32 bits wide. The second element immediately follows the first, at an offset of four bytes under the represented four-byte word layout. The total destination footprint is eight bytes.

There is no supplied evidence that either word is an integer with a particular signedness, a floating-point value, a pointer, or a field with application-specific meaning. The transfer preserves each word’s bit pattern without a visible arithmetic conversion.

The function does not interpret byte order. Both words are transferred in the target’s existing representation; there is no visible byte swap or serialization step. The representation does not establish the target’s endianness.

### Preconditions

For an ordinary successful invocation:

- The source must permit a 32-bit read at its base and another at the four-byte offset.
- The destination must permit a 32-bit write at its base and another at the four-byte offset.
- Both addresses must satisfy the execution environment’s validity and alignment requirements for these accesses.
- Computing and accessing the second word must be valid in the applicable address and memory model.

No explicit non-overlap check or restriction is present. Overlap behavior is therefore described below, subject to the same access-validity requirements.

No ownership transfer is expressed by either argument. The function neither allocates nor explicitly releases memory.

## Behavior

### Observable access order

The supplied representation establishes the following sequence:

1. Read the first 32-bit word from the source.
2. Write that value to the first 32-bit word of the destination.
3. Read the second 32-bit word from the source.
4. Write that value to the second 32-bit word of the destination.
5. Return without a result value.

The second source read occurs after the first destination write. That ordering is material when the regions overlap or when memory accesses have externally observable effects.

There is no visible early return, conditional branch, loop, comparison, or data-dependent choice. The same two transfers are attempted regardless of the word values.

### Disjoint regions

For valid, disjoint ordinary-memory regions without concurrent modification:

- The first destination word becomes the first source word’s value.
- The second destination word becomes the second source word’s value.
- Neither source word is written by this function.

No destination memory outside the two-word footprint is explicitly written.

### Identical regions

When source and destination designate the same two words, each source word is read and then written back to its own location.

For ordinary memory without external interference, the final bit patterns are unchanged. This is nevertheless a read-and-write operation, not a visibly implemented no-op. The supplied representation contains no equality check that skips the accesses.

### Overlapping regions

The operation is not specified as taking a snapshot of the original eight source bytes.

If the destination begins one word after the source, the first write replaces the second source word before that word is read. With ordinary memory and no external interference, both destination words therefore receive the original first source word’s value.

If the destination begins one word before the source, the first write does not replace either source word needed by a later read. Under the same conditions, the destination receives the two original source word values in their original order.

For any other overlap that is valid in the execution environment, the governing rule remains the ordered accesses above. The contract does not assume that unaligned or partially overlapping word accesses are supported.

### Arithmetic and value handling

The only visible address displacement selects the next 32-bit word. There is no value arithmetic, length arithmetic, truncation from a wider data value, sign extension, or overflow-dependent branch.

The function accepts no length argument. It always attempts to transfer exactly two words; it does not inspect a terminator or infer available storage.

## Side effects

The explicit side effects are two destination word writes, interleaved with two source word reads.

The function does not visibly:

- Allocate, free, retain, or release storage.
- Invoke another function.
- Read or update a named global.
- Produce an error code or status result.
- Validate either address.
- Roll back an earlier write.

Those statements describe explicit operations, not a guarantee that the affected memory is private. If a supplied pointer designates global or shared storage, that storage is accessed normally through the pointer.

There is no transaction or all-or-nothing mechanism. For example, the first destination write precedes the second source read. The contract therefore provides no rollback guarantee if a later access cannot complete.

No synchronization or atomicity guarantee is established. In particular, the two destination writes are not established as an indivisible eight-byte update. Hardware atomicity of an individual word access is also outside the supplied evidence.
