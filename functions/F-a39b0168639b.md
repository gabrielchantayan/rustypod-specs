No application-level purpose is established. Initialization, decoding, hardware configuration, and other higher-level interpretations remain unsupported.

This contract distinguishes:

These are conditional static examples, not executed tests.

1. **Initial sign extension.** If R is 0xFFFFFFFF, S is 0xFFFFFFE0. Arithmetic-right-shifting S by five yields 0xFFFFFFFF, which becomes F-I12’s second argument—not 0x07FFFFFF.

2. **Shift pair does not restore R.** If R is 0x04000000, S is 0x80000000, and F-I12’s second argument is 0xFC000000.

3. **Zero arguments independent of T.** For every 32-bit T, U has no set bits below position 27. F-I28 therefore receives zero, zero; F-I33’s second argument is also zero.
