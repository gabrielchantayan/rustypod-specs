# F-4e8f26adb996

## Purpose

F-4e8f26adb996 reports the zero-based position of the highest set bit of an unsigned integer. An input of zero also produces zero.

For positive inputs, the result is the integer part of the base-two logarithm. It is not the number of set bits, the number of trailing zero bits, or the full bit length. The full bit length of a positive input is one greater than this function’s result.

The highest-set-bit interpretation is established by the supplied operations. Any broader application purpose—such as selecting a storage size or classifying a magnitude—is unknown.

## Behavior

The mathematical result is:

\[
R(x)=
\begin{cases}
0, & x=0,\\
\lfloor\log_2 x\rfloor, & x>0.
\end{cases}
\]

Equivalently, a positive input returns the unique integer \(k\) for which:

\[
2^k \le x < 2^{k+1}.
\]

For the largest representable input class, the upper bound is a mathematical bound, not a requirement to represent \(2^W\) in the input type.

### Classification and boundary behavior

Zero and one both return zero. They are intentionally indistinguishable through the result alone.

For positive inputs, only the position of the highest set bit determines the result. Lower bits do not affect it. Consequently:

- An exact power of two returns its exponent.
- Adding lower set bits without introducing a higher set bit leaves the result unchanged.
- Crossing a power-of-two boundary increases the result by one.
- The greatest representable unsigned value returns \(W-1\).

The function does not round a logarithm to the nearest integer. It classifies the input into intervals bounded by consecutive powers of two.

### Evaluation order and termination

The supplied body establishes a local examination that begins with coverage of the least significant bit. Each continuation extends that coverage upward by exactly one bit and increases the prospective result by one.

The termination decision precedes each such extension. The decision asks whether the input has any set bit outside the currently covered low-order region. When none remains, the current result is returned.

This order establishes several edge cases:

- Zero and one require no coverage extension.
- A positive input whose highest set bit is at position \(k\) requires exactly \(k\) extensions.
- There is one more termination decision than coverage extensions.
- An input containing the highest representable bit requires \(W-1\) extensions.
- Once coverage includes all \(W\) bits, the next decision terminates; another extension is unnecessary.

Under the stated fixed-width model, the function terminates for every input. Its number of local examination steps depends on the highest set-bit position. No constant-time execution guarantee is established.

### Arithmetic constraints

Each supplied shift is by one bit, rather than by an input-derived shift distance. The unsigned coverage value expands toward an all-ones value.

For the conventional 32-bit interpretation, the greatest returned result is 31. Neither an unrepresentable signed result nor a shift by 32 is needed. For another width, the same reasoning applies only if the signed return type can represent \(W-1\) and the unsigned operations have the stated width semantics.

There is no saturation result, wraparound result, or exceptional result on the established path. A materially different integer model is outside the verified scope of this contract.
