# F-8f180221fee0

The established behavior is a 14-bit field extraction. The field’s meaning is unknown. Identifying it as a counter, status field, device measurement, identifier, or encoded state would require evidence not supplied here.

This contract describes the supplied static representation. No runtime tests have been performed.

## Behavior

### Field selection

For the value obtained from the shared word, the result is the unsigned numerical value of bits 8 through 21.

The extraction first excludes all bits above bit 21 with the mask `0x003FFFFF`. Shifting the retained unsigned value right by eight positions then discards bits 0 through 7 and moves the selected field into the low 14 result bits.

An equivalent numerical characterization is:

- Retain the input’s least significant 22 bits.
- Divide that nonnegative value by 256, discarding the remainder.

This characterization does not require signed arithmetic or rounding toward a negative value. The largest value remaining after the mask is 4,194,303; after the shift, the largest possible result is 16,383. No addition, multiplication, or overflow-dependent behavior is involved.

### Observable access order

The supplied representation contains one shared-word read as the input to the extraction. The selected value is then returned. There are no visible function calls or intervening shared-state writes.

This establishes the following source-facing order:

1. Obtain the shared-word value.
2. Derive the selected field from that value.
3. Return the field value.

It does not establish the number or width of physical bus transactions, a machine-level atomicity guarantee, or synchronization with another execution context.

### Independence from discarded bits

For a given observed input value:

- Changing only bits 0 through 7 cannot change the result.
- Changing only bits 22 and above cannot change the result.
- Changing input bit 8 changes result bit 0.
- Changing input bit 21 changes result bit 13.

More generally, two input values produce the same result exactly when their bits 8 through 21 agree.

The function does not normalize, interpret, or reject any selected-field value. Every value from `0x0000` through `0x3FFF` is a possible result. No value is visibly reserved as an error indicator.

### Repeated calls and concurrent changes

Each invocation uses the shared-word value obtained for that invocation. There is no visible local cache, accumulated history, retry, or comparison with a previous result.

Calls that obtain identical selected bits return identical numerical results. Calls made at different times need not return the same value if the shared storage changes.

The evidence does not specify which value a call obtains when another agent modifies the storage concurrently. It also does not establish whether a read can observe a torn value, whether access is ordered relative to other operations, or whether reading the underlying storage itself changes external state.

### Error behavior

A zero result means that the observed bits 8 through 21 were all zero. It is not evidence of an access failure. Likewise, `0x3FFF` is an ordinary maximum field value, not a visible error code.
