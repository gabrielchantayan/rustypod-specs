## Purpose

The established behavior is:

- When the dependency returns zero, return **1** exactly when the first pair of the first object is lexicographically less than the second pair of the second object.
- When the dependency returns any nonzero value, return **1** exactly when the second pair of the first object is lexicographically greater than the first pair of the second object.

“Lexicographic” means that the first word decides the result unless those words are equal; only then does the second word decide it. All word comparisons are unsigned.
