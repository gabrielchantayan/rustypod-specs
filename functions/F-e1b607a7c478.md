# F-e1b607a7c478

## Purpose

F-e1b607a7c478 conditionally updates a caller-supplied object, performs one of two preparation sequences, and invokes subsequent operations.

The established gates are:

- F-b7abcf60c990 must return nonzero.
- An object-dispatched predicate must return zero.
- An associated-object address must be nonzero when inspected after a paired-region entry call.

If a gate rejects progress, the explicit normal return is 0. If all gates permit progress and the remaining operations return normally, the function returns 1.

The return value reports which control-flow path completed. It does not establish that every dependency succeeded according to its own contract: most dependency return values are not inspected.

The sequence suggests initiation or activation of an operation. That interpretation, and any synchronization meaning assigned to the paired-region calls, are inferred intent rather than established semantics.

## Behavior

First, call F-b7abcf60c990 with the address of the embedded region at object offset `0x060`.

- If its result is zero, return 0.
- Otherwise, read the object’s dispatch information and call F-indirect-01, selected at table offset `0x1A4`, with the object address.

If F-indirect-01 returns nonzero, return 0. A zero result permits progress.

The second predicate is not called when the first returns zero. Both predicates execute before paired-region entry.

### 2. Enter the paired region and inspect the association

After F-unmapped-01 returns, read the associated-object address at object offset `0x054`.

If it is zero:

1. Call F-unmapped-02 with the retained region address.
2. Return 0.

This branch performs none of the function’s explicit state-field writes, preparation calls, or post-region calls. Dependencies already invoked may nevertheless have side effects.

If the association is nonzero, continue. The outer gates are not reevaluated.

### 3. Select the preparation mode

No explicit arguments are shown for this call. The representation does not establish a receiver argument or other hidden calling-convention inputs.

- If F-indirect-03 returns zero, select **data-derived mode** without reading `0x944` for this decision.
- If it returns nonzero, read the 32-bit field at object offset `0x944` and narrow it to eight bits:
  - Low eight bits zero: data-derived mode.
  - Low eight bits nonzero: **fixed-value mode**.

The field access is represented as a 32-bit read followed by narrowing, not as a direct one-byte read. Upper bits do not affect mode selection.

### 4. Perform data-derived preparation
