# F-a3f7d9036f6c

The established behavior is an ordered dispatch loop. A record matching the termination marker is still offered to handlers and is still subject to post-processing before the function returns. Termination is determined from the record’s first field at the end of the iteration, not necessarily from the value originally supplied by the record producer.

Interpreting the records as events and the registry entries as event handlers is inferred intent. The supplied material does not establish a particular application domain, scheduling model, or ownership protocol.
