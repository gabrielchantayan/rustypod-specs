# F-361a9118be4a

## Purpose

F-361a9118be4a obtains an output object, writes a value read from global memory into its first 32-bit word, and processes a collection obtained through an input context. Every visited entry undergoes resolution. Entries selected by discriminator values 1 or 31 cause additional dependency calls and writes to branch-specific output fields.

After traversal, the function copies one context byte into the output, conditionally invokes a collection-associated virtual operation, and returns the original output pointer.

Collection-driven construction or configuration is inferred intent, not an established domain meaning. Neither global-memory input is established to be constant or immutable.

This contract describes static evidence only. No runtime tests have been performed.

## Behavior

### Output acquisition and initial write

F-60d99bc349ed is called first, with no explicit arguments shown.

After it returns, the function reads global input A and writes that 32-bit value to output offset 0x00. The read is not an earlier snapshot: any change made by F-60d99bc349ed before returning can affect the stored value.

The output pointer is not checked for null before this write. An invalid output address has no visible local error-return path.

The function next reads the context word at offset 0xB4 and supplies it to F-73d4385c28ec.

### Endpoint capture and traversal count

From the returned collection address, the function reads the 32-bit endpoint at offset 0x18 first, then the endpoint at offset 0x14. These endpoint values are retained for traversal-count calculation; the function does not visibly reload them during traversal.

The represented count calculation:

- Subtracts the offset-0x14 endpoint from the offset-0x18 endpoint using a signed 32-bit expression.
- Right-shifts that signed result by two positions.
- Converts the shifted result to an unsigned 32-bit bound.

For a nonnegative, representable difference, the count is the difference divided by four, rounded down. There is no visible alignment or divisibility check.

Negative differences and signed subtraction overflow are not validated. Exact overflowing-subtraction behavior and negative signed-right-shift behavior require target-level confirmation. If a negative shifted result is converted to unsigned, it can become a large traversal bound rather than zero.

The loop counter is unsigned and 32 bits wide. It starts at zero and increments once per completed iteration. Before each call to F-6e0389afef8f, it is narrowed to signed 16 bits and then widened to the integer argument width.

Under the conventional low-16-bit narrowing and sign extension represented by these conversions:

| Counter | Index supplied to F-6e0389afef8f |
|---|---|
| 32,767 | 32,767 |
| 32,768 | −32,768 |
| 65,535 | −1 |
| 65,536 | 0 |

Thus, a sufficiently large traversal does not present a monotonically increasing nonnegative index sequence to the dependency. No visible guard prevents that conversion boundary.

### Resolution on every iteration

F-6e0389afef8f receives the saved collection address and the converted index. Its returned entry address is used without a null check.

The function reads the entry’s first 32-bit word and passes it to F-283eda65a14c. A per-entry working value is initialized to zero.

If F-283eda65a14c returns a nonzero address, the function reads an address-bearing word from that object, treats it as a dispatch-table address, selects the target at byte offset 0x14, and invokes it. The result becomes the 32-bit working value.

If resolution returns zero, that virtual operation is skipped and the working value remains zero. This does not reject or skip the entry’s discriminator-specific processing.

The virtual target’s identity, receiver convention, and complete argument contract are unknown. Resolution and any resulting virtual call occur before discriminator inspection, even for entries that select neither specialized branch.

### Discriminator 1

The first discriminator read examines the byte at entry offset 0x08.

If it equals 1:

1. F-8157a180d901 receives the integer value 200.
2. After that dependency returns, the function reads the entry’s 32-bit payload at offset 0x04.
3. F-637a7738122d receives the preceding dependency’s result, the working value, and the payload.
4. Its 32-bit result is written to output offset 0xA4.

There is no visible success check on either dependency result. A zero result from F-637a7738122d is stored without a separate failure branch.

The branch decision is not repeated after F-8157a180d901. That dependency may affect the subsequently read payload without changing which branch executes.

### Discriminator 31

If the first discriminator read does not equal 1, the function reads the same discriminator byte again. The second read is compared with 31.

If the second read equals 31:

1. The function obtains a 32-bit value from global input B and a 32-bit payload from entry offset 0x04.
2. F-5710a8628cba receives the working value, that global value, and that payload.
3. Its 32-bit result is written to output offset 0xA8.
4. F-08381bb55f88 receives the output pointer and working value.
5. The entry payload is read again and passed to F-8ef069adf52b together with the output pointer.
6. F-8f9bd59e3ec5 receives the working value and output pointer.

The global input B read and the first payload read both supply the F-5710a8628cba invocation. Their relative evaluation order is not established. Neither is specified to precede the other.

Global input B is read anew for every selected discriminator-31 branch. The function does not retain one global value for the entire traversal. Changes by earlier dependencies can therefore affect later calls to F-5710a8628cba.

The later payload read for F-8ef069adf52b is distinct from the payload read for F-5710a8628cba. Intervening dependencies may change the entry, so the two payload values need not match.

### Other discriminator outcomes

If the first discriminator read is not 1 and the second is not 31, neither specialized branch runs. That iteration makes no direct write to output offset 0xA4 or 0xA8.

Resolution has nevertheless already occurred.

The two discriminator reads are separate accesses. The representation provides no synchronization or guarantee that they observe the same byte if the execution environment permits intervening external mutation. This observation does not establish that concurrent unsynchronized mutation is valid under the original program’s memory model.

### Completion

After traversal, the function reads the context byte at offset 0xB8 and writes exactly one byte to output offset 0xAC. It does not directly clear adjacent output bytes.

The saved collection pointer is then tested for zero. If nonzero, the function reads its dispatch-table address and invokes the target at dispatch-table byte offset 0x04.

This late null check does not make a null collection valid: the endpoint reads already occurred without a null check.

Finally, the original output pointer is returned. The final virtual operation occurs after the final direct output write and may affect output storage through aliases or other state. No preservation guarantee is established.

## Side effects

Ownership and retention are unknown for the collection, entries, resolved objects, branch results, payloads, and output. No dependency is assumed to preserve globals, retain arguments, relinquish ownership, or free memory.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. Each assumes valid required storage, normally returning dependencies, and no mutation except where stated.

1. **Global value changed during output acquisition.** If F-60d99bc349ed changes global input A before returning, the initial output-word write uses the value subsequently read from that global, not a pre-call value.

2. **Empty traversal.** If the captured endpoint difference is zero, F-6e0389afef8f is not called. The function still reads global input A, writes the initial output word, copies the final context byte, and invokes the collection-associated virtual operation for a nonzero collection. Global input B is not read.

3. **One discriminator-1 entry with unresolved reference.** With a representable endpoint difference of four, discriminator 1, and a zero resolution result, the resolved-object virtual operation is skipped. F-637a7738122d receives a zero working value, and its result is stored at output offset 0xA4.

4. **One discriminator-31 entry.** If the discriminator reads select 31, F-5710a8628cba receives a value read from global input B for that branch. Its result is stored before F-08381bb55f88, F-8ef069adf52b, and F-8f9bd59e3ec5 execute in that order.

5. **Global value changes between matching entries.** If a dependency changes global input B after one discriminator-31 call and before the next branch’s read, the later F-5710a8628cba call receives the newly read value. Equality with the earlier argument is not required.

6. **Argument-read ordering.** An acceptance trace must not require global input B to be read before, or after, the payload used by the same F-5710a8628cba invocation. That ordering is unresolved.

7. **Unrecognized discriminator.** If both discriminator reads yield 2, resolution still occurs, but neither specialized branch runs and global input B is not read for that entry.

8. **Payload changes during the discriminator-31 sequence.** If F-08381bb55f88 changes the entry payload, F-8ef069adf52b receives the later payload value rather than a required copy of the earlier argument.

9. **Non-multiple endpoint difference.** A nonnegative, representable difference of seven produces one iteration. The remaining three units do not cause an additional iteration or visible validation failure.

10. **Late context-byte change.** If an earlier dependency changes context offset 0xB8 and the byte remains unchanged until completion, the changed byte is copied to output offset 0xAC.

11. **Index conversion boundary.** If traversal reaches counter 32,768, conventional low-16-bit narrowing and sign extension supply −32,768 to F-6e0389afef8f. This criterion does not imply that the dependency accepts negative indices safely.
