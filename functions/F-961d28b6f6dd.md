# F-961d28b6f6dd

## Purpose

The established behavior is a fixed-size, in-place write. The function does not inspect the destination’s previous contents, select among formats, or calculate a result from the supplied values. Each value is assigned to its corresponding destination slot unchanged.

A likely intent is to initialize or replace a four-word record. That interpretation is not required by the behavior: the supplied evidence establishes neither a record type nor meanings for its fields.

1. The first value replaces slot 0.
2. The second value replaces slot 1.
3. The third value replaces slot 2.
4. The fourth value replaces slot 3.

It then returns without producing a return value.
