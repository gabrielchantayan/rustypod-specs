### 4. Calculate the write destination

The third argument undergoes a signed right shift by 11 bit positions in the recovered representation. Call the resulting 32-bit signed quantity the **shifted value**.

A second term is formed by interpreting the shifted value’s bit pattern as an unsigned 32-bit integer and shifting that unsigned value right by two bit positions.

The destination integer is the sum of:

1. The shifted value, converted to unsigned 32-bit form for the addition.
2. The unsigned right-shifted term.

Under the represented 32-bit integer rules, this addition is modulo \(2^{32}\). The destination integer is then treated as the address of the write. No base pointer is added.

For an arithmetic signed right shift, the calculation can be expressed mathematically as follows:

- \(s=\lfloor x/2048\rfloor\), where \(x\) is the signed third argument.
- \(u\) is the unsigned 32-bit interpretation of \(s\).
- \(a=(u+\lfloor u/4\rfloor)\bmod 2^{32}\).

Here, \(a\) is the destination integer before its interpretation as an address.

This arithmetic is not equivalent to dividing the original input by a single positive constant, particularly for negative inputs. The unsigned reinterpretation is behaviorally significant.

The representation establishes a signed shift operation, but the actual target’s signed-right-shift semantics have not been independently verified. Numerical examples below that use negative inputs are conditional on arithmetic right shift.
