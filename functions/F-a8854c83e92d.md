# F-a8854c83e92d

## Purpose

F-a8854c83e92d specifies a non-returning processing flow consisting of an entry stage, a repeatable inner stage, and a transition back to entry. Observable behavior includes computed-address memory accesses, dependency calls, carried-state changes, an external byte-state update, and a conditional software breakpoint.

The supplied static representation establishes operation ordering, represented widths, branch structure, and state assignments. It does not establish an application-level purpose. Allocation, serialization, device initialization, and object management are not supported interpretations.

Three distinctions govern this contract:

- Inner address state is initialized before the entry decision. The zero-decision path retains that initialization; the nonzero-decision path replaces it after the breakpoint.
- The repeat control base is selected immediately before F-000000000006, not after it. That selection subsequently supplies both the repeated inner-call target and the transition dependency target.
- The replacement source-pointer location uses signed conversion and signed addition. Its calculation is not unconditionally defined unsigned wrapping arithmetic.

## Behavior

### Entry stage

Each entry pass captures the low eight bits of the current byte source and selects the control base associated with zero-path entry into the inner stage.

F-000000000001 is called at a target 4094 bytes beyond the current continuation address. No explicit arguments are shown. Its consumed result is 64 bits.

Let the result halves be L and H. The following memory effects occur in order:

| Order | Width | Destination | Value |
|---:|---:|---|---|
| 1 | 8 bits | Twice the signed integer interpretation of L | Captured byte |
| 2 | 8 bits | L plus eight bytes | Low eight bits of H |
| 3 | 32 bits | Twice the current signed link value | Current destination-pointer value |
| 4 | 64 bits | L | Entire dependency result |

The second destination advances by one eight-byte result-sized element, so it is L plus eight, not L plus one. The full-result store covers offsets zero through seven and does not inherently overwrite the byte at offset eight.

Both doubling expressions involve signed multiplication. Their portable result is unresolved when the multiplication exceeds the signed 32-bit range.

The link value is then replaced by four times the signed integer interpretation of the destination pointer. Out-of-range conversion and signed multiplication overflow remain target-dependent or otherwise unresolved.

Inner address state is initialized from the source pointer by conversion to signed 32-bit form, signed left shift by eight, and assignment to unsigned 32-bit state. This is persistent state used by the inner stage, not merely an intermediate stored value.

Three consecutive 32-bit stores then write, in order:

- The current payload at the destination pointer.
- The initialized inner address state four bytes later.
- The current source-pointer value eight bytes later.

No non-aliasing condition is shown. Earlier writes can affect later reads or overlap other writes.

### Entry decision

The decision is derived from the source pointer through a signed 32-bit conversion, signed left shift by 31, signed right shift by 32, unsigned conversion, and unsigned right shift by 20.

A shift count equal to the represented 32-bit operand width has no portable interpretation under ordinary 32-bit shift rules. The preceding signed left shift also has restricted defined cases. The evidence does not establish whether this expression represents special target behavior, an imperfect static representation, or another mechanism.

Both branches are therefore specified conditionally. The decision must not be simplified into zero, a sign test, or a particular source-pointer bit.

### Zero-decision path

When the decision is zero, the external byte-state location is first set to zero.

The link value is then increased by the current payload and assigned back to signed link state. Because the payload is unsigned 32-bit and the link is signed 32-bit, the represented equal-width arithmetic converts the link operand to unsigned before addition. The sum wraps modulo $2^{32}$. Assignment back to signed state is a separate conversion whose result is unresolved when the unsigned sum exceeds the signed range.

The resulting link value is stored as a 32-bit word at H. The byte-state update precedes this store; failure of the latter has no shown rollback.

The inner-call argument becomes zero, and the byte source becomes the current payload. Processing enters the inner stage using the entry-selected control base.

**Inner address state remains unchanged on this path.** Its source-pointer-derived initialization survives into all subsequent inner iterations until another entry pass initializes it again.

### Nonzero-decision path

When the decision is nonzero, it is stored as a 32-bit word at the address obtained from unsigned payload multiplication by 256 followed by unsigned addition of 32.

A different control base is selected for the first inner call. Its argument comes from converting the unsigned payload-times-256 result to signed 32-bit form and shifting right by 29.

A software breakpoint with immediate value 4 occurs next. Only if execution resumes does the function replace inner address state using H converted to signed 32-bit form, shifted right by 18, and assigned to unsigned state. The byte source then becomes the current payload.

Thus, the breakpoint precedes both the replacement of inner address state and the first inner call. Out-of-range signed conversion and right shifting a negative signed value require target-specific interpretation.

### Inner-stage accesses

Each iteration calls F-000000000002 through the current control base plus 2590 bytes, passing the current inner-call argument. Its consumed result is 64 bits.

Let its halves be L₂ and H₂, and let A denote the current inner address state. The following accesses occur in order:

| Order | Access |
|---:|---|

Under an interpretation retaining low bits, its stored pattern equals the old source pointer plus four modulo $2^{16}$, but that interpretation is not established universally.

After these accesses, calls occur in this order:

2. F-000000000004, with no explicit arguments.
3. F-000000000005, receiving the current payload.

**Immediately after F-000000000005 and immediately before F-000000000006, the control base is assigned the repeat selection.**

The repeat-selected control base has two subsequent uses: selecting F-000000000002 on repetition and selecting F-000000000007 on the transition back to entry. No post-F-000000000006 base assignment is shown.

### Repetition or transition

The scaled address is compared with 19 as an unsigned value.

If it is at most 19, the next inner-call argument becomes zero and the byte source becomes the current payload. The next iteration uses the already-selected repeat control base. A remains unchanged.

Under a wrapping-product interpretation, a product by 32 has its low five bits clear, so this comparison succeeds only when the scaled address is zero. The original low result half need not be zero.

If the scaled address exceeds 19, the transition performs these effects in order:

- Store A as a 32-bit word at the scaled address plus 88 bytes.
- Store the current, already-replaced source pointer narrowed to a signed halfword at A plus 14 bytes.
- Replace the payload with A shifted left by two using unsigned 32-bit arithmetic.
- Store the low eight bits of the current byte source to the external byte-state location.
- Replace the continuation address with a fixed continuation.
- Call F-000000000007 through the repeat-selected control base plus 174 bytes, passing the current source pointer shifted right by two as unsigned.

If that call returns, another entry pass begins.

The byte-state store uses the retained byte source, not automatically the payload most recently read. Repetition refreshes the byte source; merely reading a new payload does not.
