## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Unscaled selector.** With initial selector `3`, read the signed halfword at entry context plus `3` and the saved word at numerical address `0x37`.

2. **Signed displacement.** A displacement halfword containing `0xfffe` selects primary base minus two.

3. **Overlapping publication.** If the first halfword destination overlaps the low-word record, perform that halfword store first; subsequent record stores may overwrite it.

4. **Final carry.** If offset plus loaded word gives `0xffffffff` without carry and the result base exceeds `0xf8ffffff`, adding the adjustment selects the carry path. Equality with `0xf8ffffff` gives adjustment zero.

5. **Routing threshold.** Under arithmetic-right-shift semantics, shifted values `-65` and `-1` satisfy the unsigned threshold; `-66` and zero do not.

6. **Initial upper entry.** If initial routing selects the upper section, F-U28 targets `0x085737fc`. If that upper section reaches the common section, F-U35 targets `0x08573eaf`.

7. **Direct common entry and repetition.** If initial routing goes directly to the common section, F-U35 targets `0x08573dff`. If loop control subsequently selects repetition, the next F-U28 targets `0x08573900`, not its initial-entry target.

8. **Pre-increment store address.** With current high value `0x1000`, the upper-section difference store uses `0x103e`; the incremented value used in arithmetic tests is `0x100a`.

9. **Constant argument.** Whenever F-U33 is reached, its first represented argument is `0x085734e8`, irrespective of the loaded byte or adjusted intermediate.

10. **Late global observations.** A loop-control modification by F-U37 affects the following branch. A mask modification by F-U32 does not replace the XOR mask already captured before that call.

11. **Shared return.** With selected input `3` and return global `0x100`, the constructed low word is `6` and high word is `0xac`, assuming a valid reached path.
