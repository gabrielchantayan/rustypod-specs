# F-7c87d6325a96

## Purpose

F-7c87d6325a96 conditionally invokes two dependencies using values stored in a caller-supplied, two-slot record, then returns the same record pointer.

The condition is determined by the record’s second slot. If that slot is zero when checked, neither dependency is invoked. If it is nonzero, F-3f7c53af7a20 is invoked with the first slot’s value, followed by F-58ba61416cc9 with a newly read value from the second slot.

This is an established control-flow contract, not an established resource-management contract. The evidence does not identify the slots as owned resources, prove that either dependency releases anything, or establish that the record remains valid after either call.

## Behavior

### Initial decision

The function first reads the second slot and compares its 32-bit value with zero.

If the value is zero, control proceeds directly to returning the original pointer. This path makes no explicit read of the first slot and invokes neither dependency.

If the value is nonzero, control proceeds to the two-call sequence. Every nonzero 32-bit pattern takes this branch. The function does not distinguish negative interpretations, high-bit values, or particular nonzero constants.

### First dependency invocation

On the nonzero branch, the function reads the first slot and supplies that 32-bit value to F-3f7c53af7a20.

This read follows the initial second-slot check. The first slot is not used to decide whether the branch is taken.

The dependency’s return value, if any, is not used by F-7c87d6325a96. However, normal continuation depends on the dependency returning control. The supplied function contains no explicit recovery mechanism if the dependency fails, terminates execution, transfers control elsewhere, or invalidates storage needed later.

### Second dependency invocation

After F-3f7c53af7a20 returns normally, the function reads the second slot again and supplies the value obtained by that later read to F-58ba61416cc9.

The initial condition value is not retained as the argument to this call. This distinction matters if the first dependency can reach and modify the record, directly or through shared state.

There is also no second zero/nonzero condition. Once the initial check has selected the nonzero branch, a later second-slot value of zero is still passed to F-58ba61416cc9.

The second dependency’s return value, if any, is likewise unused.

### Return

If all operations reached on the selected path complete normally, the function returns the original input pointer.

Returning that pointer does not certify that its target still exists, that either slot is unchanged, or that the dependencies succeeded. The function does not inspect a dependency result to qualify its return.

### Ordering guarantees and limits

The established function-level sequence on the nonzero branch is:

1. Read the second slot for the condition.
2. Read the first slot for the first call’s argument.
3. Invoke F-3f7c53af7a20.
4. After that invocation returns, read the second slot again.
5. Invoke F-58ba61416cc9.
