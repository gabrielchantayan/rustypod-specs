## Behavior

### Classification and forwarding

This classification changes only the value of the initial direct write. It does not select different dependency paths. Every normally progressing invocation reaches the same three calls regardless of the control value.

Both dependencies that receive the control value receive its original integer value. For example, an input of two is not reduced to one, and an input of negative one is not replaced by zero. What those dependencies do with such values remains outside the established contract.

### Temporal contract

The intervening dependency receives three arguments in this order: the interior address at `0xE0`, numeric zero, and the original control value. Its opaque identity is unavailable in the supplied dependency map.

F-6f6f610b40c6 receives, in argument order, the interior address at `0xAC`, the retained four-byte result, and the original control value. Its call begins only after the intervening dependency returns normally. The visible function neither recomputes the retained result nor requests another result from F-380d68353221.

The final one-byte write at `0xA8` follows normal return from F-6f6f610b40c6. The function then returns without an explicit value. The supplied representation establishes no consumption of return values from the latter two dependencies.

These are ordering requirements, not guarantees of isolation. Earlier dependency activity may change state observed by later calls.

### Memory observation

The final direct write establishes a byte value of `1` at its destination when that write completes. It does not establish that the byte was previously zero, that a state transition occurred, or that dependent resources are valid.
