# F-44578f5f92bb

### Width and arithmetic conventions

A **byte** is 8 bits; a **word** is 32 bits. Byte loads used as address selectors are unsigned and therefore range from 0 through 255.

For concise description:

- **Low byte** means bits 0–7 of the specified result.
- **Scale by a power of two** describes multiplication or a left shift, retaining the low 32 bits.
- Right shifts of unsigned values are logical.
- A represented 64-bit result has a **lower half** comprising bits 0–31 and an **upper half** comprising bits 32–63.

Address arithmetic is described as apparent 32-bit bit-vector arithmetic. This convention does not establish portable signed-arithmetic semantics or prove actual machine behavior on overflow. Endianness, alignment restrictions, address-space mapping, and fault behavior remain unknown.

## Acceptance examples

These are conditional consequences of the static representation, not executed tests. Each assumes execution reaches the relevant operation and the required accesses complete.

1. **Argument-width distinction.** For Argument 3 equal to **0x123456AB**, the first store writes byte **0xAB**; the later Argument 3 word store writes **0x123456AB**. The word’s byte order is unresolved.

2. **Small-index boundary.** An initial result of **0xFFFFFFFF** produces a small index of **0x3FF**. The Argument 4-derived byte store therefore targets address **0x406**.

3. **Byte truncation after doubling.** Argument 4 equal to **0x00000081** supplies byte **0x02**. No explicit overflow-error path is represented.

4. **Fresh selector reads.** If the first Primary base plus 1 read yields **0x20** and the second yields **0x40**, the small-index byte is stored at **0x31**, while the subsequent zero is stored at **0x51**.

5. **Shift before byte truncation.** A retained unsigned result of **0x12345678** produces retained byte **0xCF**. The later word-width store derived from the same shifted result writes **0x02468ACF**.

6. **Absolute-address aliasing.** A retained second selector of zero makes the doubled selector zero. The retained-byte store at Doubled selector plus **0x0D** and the immediately following **0xC0** store then both target absolute address **0x0D**, in that order.

7. **Ten-bit intermediate, eight-bit store.** A late unsigned result of **0x3FF00000** produces **0x3FF** after the specified mask and right shift. The byte-selected store writes **0xFF**, not a ten-bit value.

8. **Fresh final destinations.** Final selector reads yielding **0x01** and **0x02** cause zero stores at **0x12** and **0x13**, respectively.
