# F-274c75489cee

## Purpose

F-274c75489cee performs an ordered series of memory reads, indirect writes, static-storage updates, and conditional abnormal termination. The available static evidence does not establish an application-level purpose.

The representation includes bad-instruction warnings, overlapping static storage, incoming register values without visible initialization, and shifts by the apparent operand width. It therefore does not establish a complete, portable executable definition.

This contract distinguishes:

- **Established static evidence:** access widths, expressions, ordering, and branches explicitly represented.
- **Inferred intent:** possible interpretations that are not required behavior.
- **documented_only:** unresolved behavior that must not be replaced with an assumed implementation.

Neither dependency is visibly invoked. Their addresses are used as data.

A byte is 8 bits, a halfword 16 bits, and a word 32 bits where an access explicitly establishes that width. An untyped static assignment does not independently establish its destination width.

The following are descriptive contract labels, not source identifiers:

- **Offset**: second explicit input.
- **External base**: fourth explicit input.

- **Stack pointer value**: the incoming stack-derived pointer.
- **State base** and **displacement**: the first two static values read.
- **First dependency address**: the numeric address of F-e47d7b2e9c88.
- **Second dependency address**: the numeric address of F-8afdaab91693.

Several derived unsigned 32-bit quantities are useful:

| Quantity | Meaning |
|---|---|
| Combined input | Hidden mask bitwise-OR Input |
| Reduced input | Input minus `0x38`, modulo \(2^{32}\) |
| Cleared difference | Input minus `0xE0`, modulo \(2^{32}\), then masked with `0x7FFFFFFF` |
| Half difference | Cleared difference shifted right by one |
| Doubled address | Twice the unsigned 32-bit difference Input minus `0xE0`, modulo \(2^{32}\) |

### Initial accesses

The function first reads the signed 32-bit state base from one static location, then the signed 32-bit displacement from another. Both reads precede the first represented store.

The following accesses occur in order:

1. Store Offset’s low 16 bits at Hidden base plus Offset.
2. Read a word at Combined input plus displacement. This becomes the **loaded word**.
3. Read an unsigned byte at Hidden base plus Combined input. This becomes the **loaded byte**.
4. Store the loaded word at External base plus `0x08`.
5. Store External base as a word at Input plus `0x40`.
6. Store the loaded word at State base plus `0x74`.
7. Read a signed word at External base plus `0x28`. This becomes the **derived source**.
8. Read a word at State base plus `0x5C`. This becomes the **secondary word**.
9. Store State base’s low byte at Loaded word plus `0x03`.
10. Store the loaded byte at State base plus `0x10`.
11. Store the secondary word’s low byte at Loaded byte plus `0x1C`.

The final destination uses the byte’s numeric value, not its source address. Before target-specific address interpretation, it lies between `0x1C` and `0x11B`.

Reads observe memory at their represented positions. For example, State base plus `0x74` can overlap External base plus `0x28` when their bases have suitable values. The earlier store then affects the later read under ordinary memory semantics.

By contrast, the word ranges at External base plus `0x08` and External base plus `0x28` are distinct under ordinary byte-addressed memory semantics. Overlap with a third address does not by itself make them alias.

### Dependency-address branch

The first dependency address is treated as a 32-bit value.

Two quantities are formed:

- An **unresolved dependency base**, obtained by interpreting the address as signed and shifting right by 32.
- A **dependency sign halfword**, obtained by a signed right shift by 31 and conversion to 16 bits.

The former is unresolved because the shift count equals the apparent operand width. Under arithmetic signed-right-shift semantics, the latter is `0x0000` for a nonnegative address and `0xFFFF` for a negative address.

The function stores the dependency sign halfword at Unresolved dependency base plus `0x04`, then tests the first dependency address as signed 32-bit.

If negative, the early abnormal endpoint follows. No continuation below is represented on that branch.

Otherwise:

1. Store the dependency sign halfword at Unresolved dependency base plus `0x12`.
2. Store the first dependency address as a word at that same numeric address.
3. Read a signed halfword at Unresolved dependency base plus Half difference.
4. Repeat the halfword store at Unresolved dependency base plus `0x12`.
5. Repeat the self-addressing word store at the first dependency address.
6. Sign-extend the halfword read in step 3, shift that signed value right by 16, and store the resulting word at Unresolved dependency base plus `0x08`.

With arithmetic signed right shift, the last word is zero for a nonnegative halfword and `0xFFFFFFFF` for a negative halfword.

The repeated stores remain separate observable accesses. The intervening read and possible aliasing prohibit describing this region as a single initialization.

## Acceptance examples

These are conditional static acceptance criteria, not execution reports. Each assumes preceding operations complete and the relevant target arithmetic is meaningful.

### Halfword truncation

If Offset’s low 16 bits are `0x2345`, the first store writes halfword `0x2345` at Hidden base plus Offset. It does not write a word.

### Byte-derived address

If the loaded byte is `0xA0`, the later secondary-word byte store targets address `0xBC`, not an address relative to the byte’s original source.

### Supported aliasing

If State base plus `0x74` equals External base plus `0x28`, the later word read observes the earlier loaded-word store under ordinary memory semantics, absent another intervening overlapping write.

The stores and reads at External base plus `0x08` and plus `0x28` do not overlap merely because they share a base.

### Halfword-selected destination

If the halfword read at Doubled address is `0x1234`, the masked-word destination is address `0x1234`. The stored word is Reduced input masked by `0x897E8B80`.

### Early termination

If the first dependency address has its top bit set, the halfword store at Unresolved dependency base plus `0x04` precedes the early endpoint. The continuation’s self-addressing dependency stores are not reached.

This does not resolve the dependency-base calculation.

### Repeated stores

On the nonnegative branch, an observer of individual accesses must retain both stores at Unresolved dependency base plus `0x12` and both self-addressing word stores at the first dependency address.

### Address-cell reload

If the address cell initially receives a value selecting a word location that overlaps the cell itself, and the self-addressing store changes its subsequently read contents, the following Half difference store uses the newly read cell value plus four. It must not automatically use four times Stack pointer value plus four.

The actual effect depends on storage width, layout, and target memory semantics.

### Late concatenation input

If the static halfword is assigned `0x1234` from Final base but an intervening overlapping store changes it to `0xABCD`, the final concatenation expression is `0xABCDEA70`, not `0x1234EA70`.

This establishes the expression, not the unresolved destination’s assignment width.

### No successful-return condition

Even if all accesses complete and the first dependency address is nonnegative, the represented path reaches the final abnormal endpoint. Ordinary successful return is not a supported acceptance condition.
