Only after that invocation returns normally does the function add 20 to its result and invoke F-603a53835f04. The adjusted result occupies the first argument position; zero occupies each of the remaining three positions.

Only after the second invocation returns normally does the function subtract 52 from its result and return.

There is no wrapper-level branch, retry, loop, or alternative dependency selection. Every normal execution invokes each dependency exactly once, in the order above. If the first dependency does not return normally, the second invocation and final return are not reached. The second call uses the first dependency’s result, not the original input. The returned value uses the second dependency’s result, not either earlier value.
