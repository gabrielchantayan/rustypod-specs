## Behavior

### Initial restriction gate

The function first inspects the byte at record offset 52.

If that byte is zero, it proceeds directly to the indirect-state stage. No context fields are locally read on that route.

If the byte is nonzero, the function obtains the pointer-bearing value at context offset 0 and reads the unsigned 32-bit flags word at offset 12 from that address.

- If mask `0x00000800` is set, the function proceeds to the indirect-state stage without reading the context byte at offset 19.
- If the mask is clear, it reads that context byte.
  - A nonzero byte permits continuation.
  - A zero byte selects diagnostic category A immediately.

Thus, the initial gate selects category A when the initial flag is nonzero, the mask is clear, and the secondary context byte is zero.

An initial rejection does not evaluate the record link, indirect state, mode condition, or record offset-24 condition.

These conditions describe values obtained at their respective accesses. If storage overlaps, the values must be interpreted consistently with that overlap; the contract does not treat overlapping fields as independent storage.

### Indirect-state stage

After the initial gate permits continuation, the expression evaluates the record’s offset-60 field for comparison with null.

If this first evaluation is null, the function skips the indirect access and proceeds to the mode-and-record stage.

If the first evaluation is nonnull, the expression evaluates the record’s offset-60 field **again**. The value from this second evaluation supplies the address used for the pointer read. Through that pointer, the function obtains the 32-bit state at offset 52.

- A nonzero state permits continuation to the mode-and-record stage.
- A zero state selects diagnostic category A.

The mode cannot override a zero indirect state. The record’s offset-24 condition is not read on that rejection path.

For stable storage, the two evaluations of the link produce the same value, so this stage can be summarized as “null link or nonzero indirect state permits continuation.” Without stability, that shorthand is insufficient: the first value determines whether indirection is attempted, while the second value supplies its address.

This is an expression-level re-evaluation requirement, not a claim that the implementation necessarily issues exactly two machine loads. The supplied representation does not establish volatile access semantics, compiler treatment of concurrent changes, or synchronization guarantees.

### Mode-and-record stage

This stage is reached only after:

- The initial gate permits continuation; and
- Either the first link evaluation is null or the indirect state obtained through the second link evaluation is nonzero.

The mode is tested first.

- A nonzero mode causes an immediate zero return.
- A zero mode causes the function to read the 32-bit value at record offset 24.

With zero mode:

- A zero record value produces a zero return.
- A nonzero record value selects diagnostic category B.

Negative mode values behave like other nonzero values. No magnitude comparison or arithmetic on the mode is shown.

The offset-24 field is likewise tested only for zero versus nonzero; its signed interpretation does not affect this decision.

### Diagnostic completion

Once either diagnostic category is selected, the function reads the 32-bit payload at record offset 0 and calls F-2022b0f73f3b with:

1. The original context address.
2. The fixed diagnostic selector for the selected category.
3. The payload value just read from record offset 0.

Category A is shared by initial-gate rejection and a zero indirect state. Category B is selected only by the zero-mode, nonzero-offset-24 case after the earlier gates permit continuation.

The dependency’s returned value, if any, is not used. If the call returns normally, F-956f9fcb5326 returns one. If it does not return normally, this body does not establish a subsequent normal result.
