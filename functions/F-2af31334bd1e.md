# F-2af31334bd1e

## Purpose

F-2af31334bd1e conditionally sets or clears bits in externally addressed 32-bit storage. Its behavior is selected by an 8-bit value read from the caller’s memory and a separate zero/nonzero mode argument.

The distinguished byte value 200 causes an immediate return of 200. For every other byte value, the function invokes F-d1db756204ac and then performs one of two operations:

- **Nonzero mode:** set a dependency-selected bit in three words, with the word addresses separated by 32 bytes.
- **Zero mode:** clear an argument-selected bit in one word.

The normal return value is zero. It is not a count of changed bits, and it does not distinguish an actual bit transition from a write that leaves the word numerically unchanged.

This contract describes the supplied static representation. It does not establish the application-level meaning of the bits, the ownership of the surrounding storage, or the full behavior of the dependency.

## Behavior

### 1. Initial read and distinguished return

The function first reads one byte through the input pointer.

If that byte is 200, it returns 200 immediately. This path contains no visible dependency call, destination-base lookup, or destination-word access.

The distinguished return takes precedence over both the mode and the bit argument. In particular, a bit argument that would be problematic on an ordinary path is not used on this path.

All subsequent behavior uses the byte already read. No second read through the input pointer is shown.

### 2. Word-position selection

For every byte other than 200, the function derives a word position from the byte’s upper three bits. The represented calculation subtracts the byte divided by 32, discarding the remainder, from six.

The resulting address displacement is:

| Initial byte | Word position | Byte displacement from the applicable base |
|---|---:|---:|
| 0–31 | 6 | +24 |
| 32–63 | 5 | +20 |
| 64–95 | 4 | +16 |
| 96–127 | 3 | +12 |
| 128–159 | 2 | +8 |
| 160–191 | 1 | +4 |
| 192–223, excluding 200 | 0 | 0 |
| 224–255 | Represented negative-one position | −4 under the apparent 32-bit address model |

The four-byte spacing follows from the visible word-address calculation.

The final row requires care. The subtraction is shown with unsigned arithmetic followed by assignment to an integer temporary. For the highest byte band, the apparent 32-bit result has all bits set and is subsequently used as a negative-one displacement. The static representation therefore indicates a word immediately before the base, not a validated rejection of these byte values. Exact conversion and address semantics remain target-dependent.

No range check restricts the input byte to the first seven bands.

### 3. Nonzero mode: dependency-selected bit setting

For any nonzero mode, the function performs the following observable sequence:

1. Derive the word position from the initial byte.
2. Initialize a 32-bit temporary with the complete bit argument.
3. Invoke F-d1db756204ac with the byte value and the temporary’s address.
4. Obtain the set base from global state after the call.
5. Read a destination word, combine it with a one-bit mask using bitwise OR, and write the result back.
6. Repeat that read-modify-write operation at the corresponding word 32 bytes earlier.
7. Repeat it again at the corresponding word 64 bytes earlier than the first.
8. Return zero.

For a stable set base \(B\) and selected byte displacement \(d\), the three destinations, in write order, are:

- \(B+d\)
- \(B-32+d\)
- \(B-64+d\)

The mask selection uses the low eight bits of the temporary as it exists after F-d1db756204ac returns. The initial bit argument is therefore not necessarily the effective selection.

For effective selections from 0 through 30, the visible mask operation sets the corresponding bit in each 32-bit destination word, preserving every other bit of that word.

Selection 31 has the apparent intent of selecting the highest bit. Its exact evaluation is not established independently of the target’s shift and literal semantics. Selections from 32 through 255 are likewise not assigned portable behavior by this contract. The explicit low-byte extraction must not be confused with reduction modulo 32.

The first read-modify-write uses direct references to the global set-base value in the supplied representation. The later two use a base value captured immediately after the dependency call. With ordinary stable global storage, these identify the three addresses listed above. The excerpt does not establish coherent behavior if that global location changes asynchronously.

### 4. Zero mode: argument-selected bit clearing

For zero mode, the function:

1. Derives the word position from the initial byte.
2. Invokes F-d1db756204ac with the byte and the address of a stack-resident location.
3. Obtains the clear base from global state after that call.
4. Reads one destination word.
5. Clears the selected bit using bitwise AND with an inverted one-bit mask.
6. Writes the resulting word back.
7. Returns zero.

For clear base \(C\) and selected byte displacement \(d\), the destination is \(C+d\).

The mask selection uses the low eight bits of the original fourth argument. Unlike the nonzero-mode path, no value returned through the dependency’s pointer argument is visibly used to select the mask.

For selections from 0 through 30, the chosen bit is cleared and all other bits are preserved. The same target-semantic uncertainties apply to selection 31 and selections above 31.

The stack location passed to the dependency in this branch has no visible initialization in the supplied representation. Its initial contents, intended role, and relationship to any omitted stack context are not established. A contract for F-d1db756204ac that requires a preinitialized input through that pointer cannot be assumed satisfied.

This example depends on the post-call value 3, not on the original fourth argument.

- F-d1db756204ac is called before the destination access.

- A value written by the dependency through its pointer argument does not visibly replace the fourth argument in the mask calculation.

### Only the low byte selects the mask

In zero mode, a fourth argument of hexadecimal 00000102 selects bit 2, just as a fourth argument of 2 does. The upper 24 bits do not participate in that branch’s visible mask calculation.

In nonzero mode, the corresponding statement applies to the post-call temporary, not necessarily to the original argument.

### Band boundaries affect addresses

Input bytes 31 and 32 select displacements +24 and +20 respectively. Bytes 199 and 201 both select displacement zero, while 200 takes the distinguished return instead.

For byte 224, the apparent address calculation selects one word before the applicable base. Acceptance requires valid storage there; the function does not provide a bounds error instead.

### Already-satisfied bits still cause accesses
