## Behavior

This retained address does not imply that the selected memory remains allocated, writable, or semantically associated with the same object. Those conditions depend on the surrounding program and dependency behavior.

### Input-field capture

The captured value, not a deferred reference to the field, becomes the second argument to F-36dea6346cdf. A later change to the field therefore does not change the argument already supplied to that invocation.

4. Invoke F-3475b4980949.
