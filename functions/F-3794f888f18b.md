# F-3794f888f18b

## Purpose

The assignment reads an integer from an address formed by adding 4 to the second argument, adds 68 to the value read, and stores the result through the first argument. That store occurs before F-4a19e3742733 is invoked.

This is a contract for the visible wrapper, not for the dependency’s internal behavior. In particular, the value stored before the dependency call is not necessarily the value present when the wrapper returns. The dependency’s effects are unknown.
