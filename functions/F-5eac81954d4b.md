# F-5eac81954d4b

## Purpose

“Selection,” “position,” “availability,” and “transition” describe an inferred purpose. The established behavior is the ordering of field observations, dependency calls, conditional failure, and a possible one-byte write. The object’s domain and the meanings of its modes are not established.

The function has no explicit result value. Observable outcomes consist of dependency effects, a possible selection update, indirect calls, and a represented nonreturning failure path.

## Behavior

### 1. Entry dependency

The first established operation is a call to F-338d16f9ce72 with the address of the object field at offset `0x18`.

The supplied argument is an interior field address, not the pointer value stored there. The dependency can therefore access that field’s storage.

Mode, gate, index-dependent selection processing, and completion checks occur after this call returns. No preservation of object fields, source-designated data, or external state by this dependency is established.

### 2. Initial mode and gate decisions

The function observes the mode at offset `0x20`.

- If the mode is zero, selection processing is skipped and execution reaches completion.
- If the mode is nonzero, the function reads the 32-bit gate at `0xF0`.

When the gate is zero, the function observes the mode again:

- An observed mode of 1 permits completion without selection processing.
- Any other observed mode invokes F-a817d8d58c10.

These are distinct mode observations. The second is not replaced by the first observation.

When the gate is nonzero, the function proceeds to index validation. Neither the zero-mode path nor the permitted zero-gate path validates the requested index or calculates an availability address.

### 3. Index bound and existing selection

On the nonzero-mode, nonzero-gate path, the unsigned requested index is checked against 3.

An index greater than 3 invokes F-a817d8d58c10 before any current-selection comparison or availability lookup. This includes index 4 even if the current-selection byte represents 4.

For indices 0 through 3, the function compares the signed-byte current selection with the unsigned requested index. The represented signed-to-unsigned comparison cannot make a negative selection equal to an accepted index.

If the values are equal, selection processing stops. This path does not:

- Inspect the preparation byte at `0xE9`.
- Call the preparation dependency.
- Read the availability word.
- Inspect the sentinel-transition byte at `0xEA`.
- Directly rewrite the selection.
- Invoke I-1.

Entry behavior has already occurred, and completion behavior still applies.

### 4. Preparation and availability

If the requested index differs from the current selection, the function reads byte `0xE9`.

- Zero causes a call to F-9050aa7a4a59 with the object address.
- Nonzero suppresses that call.

After the optional call returns, the function reads the requested position’s availability word at offset `0x24 + 0x18 × index`.

The prior unsigned bound guarantees an offset between `0x24` and `0x6C`. The established path therefore involves neither large-index address arithmetic nor arithmetic wraparound.

A zero availability word ends selection processing and proceeds to completion. Preparation may already have produced effects; those effects are not undone.

A nonzero availability word permits further processing. There is no subsequent availability recheck, including after later dependency calls.

### 5. Sentinel-specific transition work

After a nonzero availability observation, the function observes the current-selection byte again. This observation is distinct from the earlier equality comparison and may reflect effects of the preparation dependency.

If the selection is not −1, sentinel-specific work is skipped.

If the selection is −1:

1. The function reads byte `0xEA`.
2. A nonzero byte invokes F-a817d8d58c10.
3. Otherwise, it observes the mode.

5. Any other observed mode causes a call to F-052494b1687e with the object address.

After F-052494b1687e returns, specialization uses **two distinct, ordered mode observations**:

- First, the function observes the mode and compares it with 2. If equal, it calls F-6fcd85a213a6 with the object address, requested index, and integer argument 1. The later comparison with 3 is not reached.
- Only if that first observation is not 2 does the function observe the mode again and compare it with 3. If this second observation is 3, it calls F-b2775cd390a6 with the object address and requested index.
- If the first observation is not 2 and the second observation is not 3, neither specialized dependency is called.

Thus, the specialized calls are not alternatives selected from one captured mode value. A first observation of 3 does not alone establish that F-b2775cd390a6 will be called. Conversely, a first observation other than 2 or 3 can still lead to that call if the second observation is 3.

### 6. Selection update and selection-related dispatch

The index has already been bounded to 0 through 3, so conversion to a byte preserves its value. This assignment directly changes only that byte, not the other bytes of the containing word.

The function then observes the mode again:

- Any other observed mode causes invocation of I-1.

The selection write precedes this dispatch. The representation does not establish a finer evaluation order between resolving the dispatch target and accessing D-1.

The function shows no rollback if I-1 changes state, fails, or does not return.

The function reads the pointer-like field at object offset `0x18`.

- If null, it returns without reading a pointee.
- If nonnull, it reads the first 32-bit word at that pointer.

The pointer and pointed-to word are invocation gates only. The callable target comes from D-2, not from the pointed-to word or a dispatch table reached through the completion pointer.

No explicit arguments are shown for I-2. Its implicit inputs and calling convention are unknown. If I-2 returns, this function returns.

## Acceptance examples

These are conditional static acceptance examples, not executed tests. Each assumes valid reached memory and returning dependencies except where nonreturning failure is specified. Conditions apply at the stated observation points, not merely at function entry.

2. **Permitted zero gate.** If the initial mode is nonzero, the gate is zero, and the second mode observation is 1, any requested index bypasses selection processing.

3. **Disallowed zero-gate state.** If the gate is zero and the second mode observation is 2, F-a817d8d58c10 is invoked. Completion is not reached.
