# F-f4b40037f410

The established behavior is narrow: inspect the address-bearing field at byte offset `0x40` from the supplied base. If that field is zero, return a four-byte zero. Otherwise, obtain the address from that field again and return the four bytes at byte offset `0x14` from the resulting address.
