## Behavior

1. Calls F-da04303b789f once and uses its return value as the destination base.
2. Reads the external shared 32-bit word and writes it at destination offset `0x00`.
3. Writes a 32-bit zero at destination offset `0xEC`.
4. Writes the 8-bit value one at destination offset `0xF0`.
5. Writes a 32-bit zero at destination offset `0xF4`.
6. Reads 16 bits at source offset `0x5C` and writes that value at destination offset `0xE8`.

The first source-derived write precedes the second source read. This matters if the source and destination overlap.
