# F-cfb711b78946

## Purpose

F-cfb711b78946 stores a 32-bit input value into four consecutive destination bytes in most-significant-byte-first order.

The established behavior is a fixed-width byte representation, not a variable-length encoding. Each invocation assigns all four byte positions. Zero-valued bytes are written explicitly; leading zeros are not omitted. The function does not append a terminator, return an advanced destination, or report a byte count.

Interpreting the result as a big-endian serialization of an unsigned 32-bit quantity is inferred intent. The narrower established fact is that four parts of the input bit pattern are assigned to consecutive byte positions in descending significance.

## Behavior

### Normal execution

For a destination satisfying the write preconditions, the represented operation consists of four assignments:

1. Store the highest-order input byte at offset 0.
2. Store the next input byte at offset 1.
3. Store the next input byte at offset 2.
4. Store the lowest-order input byte at offset 3.

This is the assignment order established by the supplied representation. Each destination position is assigned once. No destination byte is read to compute its new value, and the previous contents do not affect the result.

The three shifts use distances of 24, 16, and 8 bits after unsigned conversion. These distances are within a 32-bit operand width. Conversion to a byte-sized result discards the portions above the selected low eight bits under the represented target behavior. The last assignment selects the low eight bits without a shift.

There is no addition, multiplication, sign-dependent branch, carry propagation, saturation, or rounding in the value transformation. All 32 input bits contribute to the output: each contributes to exactly one output byte.

### Fixed extent

Only offsets 0 through 3 are explicitly written. There is no represented write before the destination, at offset 4, or farther beyond it. In particular, the fourth output byte is data, not a string terminator.
