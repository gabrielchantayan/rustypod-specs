# F-cead90729166

## Purpose

F-cead90729166 returns a Boolean-valued integer based on two caller-supplied objects. It examines a discriminator at byte offset 4 in each object and conditionally invokes two dependencies:

- F-11c1b7e655b3 supplies an integer used to refine decisions about the second object.
- F-1c60e26b3436 is invoked with the first object and the fixed value 22 under particular conditions.

The final result is a membership test on the first object’s discriminator. Depending on observations of the second object, the accepted set is either:

- **Broad set:** {10, 13, 14, 15, 24, 25, 35}.
- **Narrow set:** {13, 24, 25}.

The dependency calls and repeated field reads are part of the behavior. A contract that replaces them with one initial snapshot would not describe all executions permitted by the supplied evidence.

The application-level meanings of the discriminators, dependency results, and value 22 are not established.

## Behavior

Execution has three ordered decision phases, followed by one membership test. All conditions use short-circuit evaluation. A dependency is not called when an earlier condition already determines the outcome.

The descriptions below refer to **current observations**, not necessarily to values present at entry.

### 1. Initial conditional invocation of F-1c60e26b3436

The function first checks whether the second object’s discriminator is 13 or 8.

The check itself has observable read order:

- The discriminator is read and compared with 13.
- Only if that comparison fails is it read again and compared with 8.

If neither comparison succeeds, this phase makes no dependency calls.

If either succeeds, the function calls F-11c1b7e655b3 with the second object address and examines its return:

- A return of 69 ends this phase without invoking F-1c60e26b3436.
- Otherwise, a second, distinct call to F-11c1b7e655b3 is made.
- A return of 77 from that second call ends this phase without invoking F-1c60e26b3436.
- Otherwise, a third, distinct call to F-11c1b7e655b3 is made.

The third result controls one exception to invoking F-1c60e26b3436:

- If the third result is 28, the second object’s discriminator is read again. A value of 8 suppresses the invocation.
- If the third result is not 28, there is no discriminator read for this exception, and the invocation occurs.
- If the third result is 28 but the reread discriminator is not 8, the invocation occurs.

When invoked, F-1c60e26b3436 receives the first object address and 22. Its return value is not used.

The three F-11c1b7e655b3 calls are not interchangeable. The first result is tested against 69, the second against 77, and the third against 28. For example, a first result of 77 does not itself suppress the action.

### 2. Independent conditional invocation of F-1c60e26b3436

After the first phase completes, the second object’s discriminator is read again.

If it is 6, F-11c1b7e655b3 is called with the second object address. If that call returns 59, F-1c60e26b3436 is invoked with the first object address and 22.

If the discriminator is not 6, no dependency is called in this phase.

This phase is independent of the first phase. Earlier dependency effects can make it reachable even when the initial discriminator was 13 or 8. Consequently, the function can invoke F-1c60e26b3436 twice in one execution; there is no “already invoked” suppression.

### 3. Selection of the acceptance set

The function next makes fresh observations to select the broad or narrow set.

First, it reads the second object’s discriminator:

- If it is 6, F-11c1b7e655b3 is called.
- If that call returns 59, the narrow set is selected immediately.
- In that case, the discriminator-13 alternative below is not evaluated.

Otherwise, the function separately reads the second object’s discriminator to check for 13:

- If it is 13, F-11c1b7e655b3 is called.
- If that call returns 28, the narrow set is selected.
- If the discriminator is not 13, or the call does not return 28, the broad set is selected.

The read for 13 is distinct from the preceding read for 6. In particular, a dependency call made after observing 6 may change the discriminator before the later read for 13.

Similarly, this phase does not reuse a result obtained in phase 2. A phase-2 result of 59 may trigger F-1c60e26b3436, yet a later result may cause broad-set selection.

### 4. Final membership test

After selecting a set, the function reads the first object’s discriminator once.

- With the broad set selected, it returns 1 for 10, 13, 14, 15, 24, 25, or 35.
- With the narrow set selected, it returns 1 only for 13, 24, or 25.
- All other discriminator values produce 0.

The first object’s discriminator is not read earlier by this function. Its value at entry need not equal the value used for the result, because dependency calls may intervene.

No arithmetic is performed on discriminator values. They are compared for equality with small, nonnegative integer constants. Negative values and values outside the listed sets receive no special treatment.
