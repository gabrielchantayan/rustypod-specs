## Acceptance examples

These are conditional static examples, not executed tests. Each assumes execution reaches the relevant operation and required accesses and calls permit continuation.

- **Initial sign selection:** A relevant signed result of zero selects byte address 0x10. Negative one selects 0x11. The argument delivered is the byte present when the read occurs.

- **Bit 24 isolation:** A result of 0x01000000 delivers one. A result of 0x02000000 delivers zero. Bits outside the selected position do not contribute.

- **Bit 29 selection:** A group-4 result of 0x20000000 selects 0x11. A result of zero selects 0x10. These select addresses, not fixed byte values.

- **Unsigned subtraction:** A group-5 high half of six delivers one; seven delivers zero. A high half of 0x80000007 also delivers one because the wrapped difference is 0x80000000.

- **Signed subtraction without overflow:** A group-6 signed high half of six selects 0x11; seven selects 0x10. No corresponding guarantee is made for an input whose subtraction overflows the signed range.

- **Wide sign observation:** Two group-7 results with identical low halves but differing only in bit 63 forward the same low half and later deliver different observations, zero and one.

- **Nibble delivery:** A chained result of 0xA1234567 supplies decimal ten to F-2cc1255261f3.

- **Read-base arithmetic:** An incoming contributor of 0x33 produces read base zero. A contributor of zero produces base 255 because subtraction wraps before shifting.

- **Source overlap:** If the computed read base is 0xC3, the four source reads still precede all record writes. This does not guarantee that any source location or record value survives later execution unchanged.

- **Control boundary:** A saved control word of eight permits the final sequence and selects halfword address 0x30. Nine selects the earlier invalid-instruction boundary after the offset-0x68 write.

- **Saved control value:** If the offset-0x68 write changes the memory location from which control was read, the represented comparison still uses the previously acquired control word.

- **No persistence guarantee:** A later dependency overwriting an earlier destination is not excluded by this contract. The established requirement is access ordering, not survival of earlier stored values.

- **No normal success result:** Reaching F-U005 does not establish a successful return; the represented continuation ends at an invalid-instruction marker.
