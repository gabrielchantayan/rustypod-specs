# F-128f2a4a8199

## Purpose

F-128f2a4a8199 performs an ordered sequence of indirect calls and memory writes, then enters an unconditional loop containing further indirect calls and selector-directed byte writes.

The supplied static representation establishes access widths, address calculations, dependency ordering, retained values, and loop-state transitions. It does not establish an application-level purpose such as initialization, serialization, allocation, or device control.

No normal return path is visible. If every dependency returns and every memory access succeeds, execution remains in the final loop indefinitely.

Warnings about invalid instruction data and omitted unreachable regions limit the completeness of this model. The contract describes the represented path, not independently verified executable behavior.

The first primary-selector write stores the low byte of H shifted left by 2.

Seven-call group F-D017 follows:

`(H masked with 0x3FFFFFFF) shifted right by 20`.
