2. Stores the captured 16-bit result at the anchor address.
3. Calls F-000000000002 without explicit arguments.
4. Stores the anchor pointer at byte offset 44 from the register-supplied address exposed after that call.

### Initial derived addresses and fourth-argument writes

The third argument is reinterpreted as signed 32-bit data and shifted right by a count equal to its low eight bits. At byte offset 26 from the resulting numeric value, the procedure stores the low 16 bits of the fourth argument’s address.

For counts of 32 or greater, the shift result is documented-only: the representation does not establish whether hardware count masking, another instruction rule, or an invalid reconstructed expression applies. For smaller counts, interpreting the signed shift as arithmetic is a machine-model inference.

The anchor’s numeric value is multiplied by 512 to form the **scaled anchor address**. The low 16 bits of that address are stored at its byte offset 8.

Next, the stack-resident 16-bit value is stored at byte offset 2 of the fourth argument.

The anchor’s numeric value multiplied by 2,097,152 supplies another address. The procedure:

- Reads a 32-bit word there, called the **loaded word**.
- Stores a 16-bit zero at byte offset 32 from that same address.

The second displacement is 32 bytes, not eight: the represented addition advances a pointer to 32-bit elements by eight elements before the store is treated as 16-bit.

### Intervening global capture

The following order is significant:

1. The low 16 bits of the fourth argument’s address are stored at the fourth argument’s first element.
2. The sample global is read as a 32-bit value. This captured value is the **global sample**.
3. The low 16 bits of the loaded word are stored at the fourth argument’s first element.

Thus, the sample-global read occurs **between** the two stores to the fourth argument’s first element.

If that element overlaps the sample global, the first store may affect the captured sample. The second store may then change global memory again, but it does not retroactively change the already captured sample. Later uses of the global sample refer to that captured value, not an implicit reread.

## Acceptance examples

These are conditional static cases, not executed tests.

1. **Aliasing preserves the intervening capture.**  
   Suppose the fourth argument points to the beginning of the sample global, accesses are little-endian, and no intervening operation changes that storage. After the address-truncation store, the sample read captures the global with its low 16 bits replaced by the fourth argument’s low address bits. The loaded-word store then replaces those low 16 bits again. F-000000000003 and later sample-based address calculations use the earlier captured value, not the subsequently modified global.

2. **Non-aliasing still preserves read order.**  
   If the fourth argument does not overlap the sample global, the address-truncation store precedes the sample read, and the loaded-word store follows it. Non-aliasing does not authorize describing the read as occurring after both stores.

3. **Element widths determine byte offsets.**  
   The anchor self-pointer store uses offset 24. The zero store associated with the loaded-word address uses offset 32. Offsets 12 and eight would contradict the represented pointer scaling.

4. **The branch controls only its own store.**  
   A zero post-call register value enables the 32-bit store at scaled sample offset 84. A nonzero value omits that store but still contributes to the sum.

5. **Unsigned-byte addressing is bounded without sign extension.**  
   If the earlier unsigned byte is 255, the first sum-derived 32-bit store targets address 295, not 39.

6. **Shift precedes narrowing.**  
   Conditional on the doubled sum having the 32-bit pattern `0x80000000`, the third sum-derived store receives `0x2000`. Narrowing to 16 bits before shifting would incorrectly produce zero.

7. **An unusable returned pointer is not handled locally.**  
   If F-000000000007 returns an unusable pointer, the next represented operation attempts the 16-bit zero store. No safe error-return path is established.

8. **Full traversal does not establish normal return.**  
   Even if all calls return and all accesses succeed, the displayed path reaches the invalid-instruction boundary.
