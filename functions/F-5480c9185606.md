# F-5480c9185606

## Purpose

F-5480c9185606 is a read-only predicate over a position in a byte sequence. It returns whether four bytes surrounding that position have a specific pattern, subject to an initial pointer-boundary condition.

The accepted pattern, in increasing address order, is:

| Position relative to the first input | Required byte value |
|---|---:|
| Two bytes before | 0 |
| One byte before | 0 |
| At the input position | 3 |
| One byte after | 0, 1, 2, or 3 |

The initial boundary condition requires the address one byte after the first input to be strictly below the second input.

**Established behavior:** the result is either 0 or 1, determined by that boundary comparison and the conditional byte reads described below.

**Inferred intent:** the second input appears to serve as an exclusive upper boundary, and the function appears to recognize a four-byte marker ending immediately after the first input. Neither a surrounding format nor a higher-level meaning for the marker is established.

## Interface

The function takes two pointer inputs:

- **Position:** a pointer identifying the third byte of a potential four-byte pattern.
- **Boundary:** a pointer used in a strict address comparison. The function does not dereference this pointer.

The result occupies a **32-bit return value**:

- **1:** the boundary condition and all four byte requirements succeed.
- **0:** the boundary condition fails or a required byte does not match.

There is no distinct error result, output buffer, length result, or diagnostic channel in the supplied representation.

Byte interpretation is significant. The final byte is compared as an **unsigned byte** against 4. Consequently, values from 128 through 255 do not satisfy that comparison; they are not accepted as negative values. The other three byte requirements are exact equality comparisons with 0, 0, and 3.

## Behavior

### Boundary gate

The function first considers whether the address one byte after Position is strictly less than Boundary.

If this condition is false, the function returns 0 without reading any pattern byte.

The strict comparison has two important consequences:

- Boundary equal to the address one byte after Position is insufficient.
- Boundary equal to the address two bytes after Position satisfies the gate, assuming the pointer arithmetic and comparison are valid.

No numeric length is supplied or computed as part of the visible contract. In particular, this is not a subtraction-based length check, and it does not verify that two bytes exist before Position.

### Pattern evaluation

When the boundary gate succeeds, the function examines the candidate pattern in increasing address order, beginning two bytes before Position.

The source-level sequence of required reads is:

1. Read the byte two positions before Position.
2. Only if that byte is zero, read the byte one position before Position.
3. Only if both preceding bytes are zero, read the byte at Position.
4. Only if those preceding bytes are zero and the byte at Position is 3, read the byte one position after Position.

A mismatch prevents later pattern-byte reads. The function returns 0 after the first failed requirement. It returns 1 only when every requirement succeeds.

Thus, the final byte is not examined merely because the boundary gate succeeds. Both zero-prefix requirements and the value 3 at Position must also succeed.

These statements describe the observable evaluation represented by the supplied source. They do not assert a particular machine-instruction sequence, processor speculation policy, or number of physical memory transactions.

### Complete decision rule

For valid inputs and stable readable memory, a result of 1 requires all of the following:

- The address one byte after Position is strictly below Boundary.
- The byte two positions before Position is zero.
- The byte one position before Position is zero.

Any failed condition produces 0.

There is no scan, retry, search for another candidate, pointer advancement, or consumption of bytes. The caller receives a decision only about the supplied position.
