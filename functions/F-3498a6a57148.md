# F-3498a6a57148

### Eligibility read and short-circuiting

This read is reached for both zero and nonzero control values. Its value is not a snapshot taken before the preceding dependencies: it reflects whatever is present when the read actually occurs.

If the field is zero, no destination lookup or direct field write follows.

If the field is nonzero but the control value is zero, no destination lookup or direct field write follows.

Only when the field is nonzero and the control value is nonzero does the function continue to the destination-side check.

Earlier dependencies may have changed the source field or other relevant state. The supplied source provides no preservation guarantee for those dependencies.

### Destination check

When eligible, the function calls F-fdd8589eca2d again and treats its result as an address.

It reads the 16-bit field at that address plus `0x80`.

If this field is nonzero, the function performs no further dependency call and no direct field write.

If the field is zero, the function enters the copy path.

There is no explicit validity check on the returned address before this read.

### Copy path

The function calls F-fdd8589eca2d a third time overall. The result of this third call supplies the destination address for the write.

After that call returns, the function reads the source field at the original object address plus `0xE6` again and writes its 16-bit value to the new destination address plus `0x80`.

Two distinctions are essential:

- **The source is reread.** The copied value is not necessarily the nonzero value that enabled the copy path. An intervening dependency call may change it, including changing it to zero.
- **The destination is reacquired.** The object receiving the write is not necessarily the object whose field was tested for zero. The write target’s current field is not separately checked.

The copy path therefore does not establish a general “write only if this destination is empty” guarantee. It establishes only that one returned object had a zero field before another returned object was selected for writing.

### Completion

Following the skipped or completed copy path, the function returns the retained result from D-01.

There is no visible retry, rollback, result-dependent cleanup, or conversion of memory-access failures into a return code. If a dependency does not return normally, or a reached access fails under the execution environment, normal completion is not established.
