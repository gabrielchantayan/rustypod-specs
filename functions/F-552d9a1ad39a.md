# F-552d9a1ad39a

## Purpose

The available static representation ends at an invalid-instruction boundary. It does not establish a normal return, a complete calling convention, or the intended role of the low-address store. No runtime tests have been performed.

This contract describes the recoverable behavior of that representation. It does not treat the invalid-instruction diagnostic as proof of a deliberate processor halt, nor does it assume that the recovered instruction stream is complete or correctly aligned.

### Destination-address calculation

Let \(x\) denote the unsigned 32-bit second input.

The represented calculation first shifts \(x\) right by 9 bits. Its largest possible intermediate value is therefore 8,388,607, which fits in a positive signed 32-bit integer.

The subsequent signed right shift by 11 positions consequently operates on a nonnegative value. Define:

\[
q = \left\lfloor \frac{x}{2^{20}} \right\rfloor
\]

The destination’s numeric address is:

\[
A = q + \left\lfloor \frac{q}{4} \right\rfloor
\]

Equivalently:

\[
A =
\left\lfloor \frac{x}{2^{20}} \right\rfloor
+
\left\lfloor \frac{x}{2^{22}} \right\rfloor
\]

This equivalence follows from the widths and shift order in the supplied representation; it does not require assuming how negative signed right shifts behave.

The bounds are:

- \(q\): 0 through 4,095.
- The added term: 0 through 1,023.
- \(A\): 0 through 5,118.

The addition cannot overflow a 32-bit integer within those bounds.

Only the upper 12 bits of the second input affect the address. Changes restricted to its lower 20 bits leave the computed destination unchanged.

No base pointer or allocation address is added. The representation converts the small computed integer directly into a destination pointer. The contract therefore does not reinterpret it as an offset within an unstated object.
