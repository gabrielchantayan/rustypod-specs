## Acceptance examples

### Saturation boundary

With a second input of 254 and a first indirect result of 10, F-d7be9cfb4000 receives 2,540 and 255.

With a second input of 255 and the same indirect result, it receives 2,550 and 255.

With a second input of 256, or 4,294,967,295, and the same indirect result, it still receives 2,550 and 255. Implementations that truncate the input to a byte would not satisfy this behavior.

If that dependency returns a particular 32-bit value, the second acquisition still occurs, and the final dispatch receives that returned value and zero after the second object pointer. No special final value follows merely from the zero product.
