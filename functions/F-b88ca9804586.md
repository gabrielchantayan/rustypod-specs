# F-b88ca9804586

## Purpose

F-b88ca9804586 returns an integer unchanged or reduced by one, according to two zero/nonzero tests on storage reached through an unsigned address input.

The first test controls whether the second location is accessed. A nonzero value at the first location selects the decrement without reading the second location. A zero value at the first location requires the second read; the integer remains unchanged only if that second value is also zero.

This is an established description of the supplied body. The meanings of the storage, the two values, and the integer are unknown. Interpreting the integer as a count or the two values as flags is inferred intent, not part of the contract.

## Behavior

### Decision and access order

The source-level access sequence is:

1. Read the value at offset 0x25 and determine whether it is zero.
2. If that value is nonzero, select the decrement without reading offset 0x26.
3. If that value is zero, read offset 0x26. Select the decrement when this second value is nonzero; otherwise select the unchanged result.
4. Return the selected integer result.

The resulting decision table is:

| First observed value | Second observed value | Result, when arithmetic is defined |
|---|---|---|
| Nonzero | Not read | Integer input minus one |
| Zero | Zero | Integer input unchanged |
| Zero | Nonzero | Integer input minus one |

The magnitude of either nonzero value is irrelevant. Two nonzero locations do not produce two decrements: the second location is not read when the first is nonzero. A nonzero second value never determines the amount subtracted.

The first decision is retained for the rest of the function. There is no source-level reread of the first location after the conditional second read.

### Integer result

The selected adjustment is exactly one decrement. There is no saturation, lower-bound check, repeated subtraction, or special treatment of zero and negative inputs.

For representable arithmetic:

- An input of 1 becomes 0 when the decrement is selected.
- An input of 0 becomes −1 when the decrement is selected.
- An input of −4 becomes −5 when the decrement is selected.
- Any input remains unchanged when both observed values are zero.
