# F-5e239de0a7a5

## Purpose

F-5e239de0a7a5 sets or clears the least-significant bit of a designated word according to whether its input is nonzero. The other bits of the value read from that word are retained in the value subsequently written. The function then returns zero.

The established behavior is a read–modify–write operation, not a direct assignment of the input. Every nonzero input selects the same bit value, regardless of its magnitude, sign, or least-significant bit.

Interpreting the target as an enable flag or hardware control register would be inferred intent. The supplied evidence does not establish what the bit controls, what entity owns the target storage, or whether accesses have hardware side effects.

## Behavior

### Target selection

### Read and transformation

The function reads the target as an unsigned word. It computes the prospective stored value by clearing bit 0 of the value read.

The input then determines whether that bit remains clear or becomes set:

- For a zero input, the computed value has bit 0 clear.
- For a nonzero input, the computed value has bit 0 set.

For a 32-bit word, let \(W\) denote the value read and \(A\) the input. The value written is:

\[
W_{\text{written}} =
\begin{cases}
W \mathbin{\&} \texttt{0xFFFFFFFE}, & A = 0 \\
(W \mathbin{\&} \texttt{0xFFFFFFFE}) \mathbin{|} \texttt{0x00000001}, & A \ne 0
\end{cases}
\]

This formula describes the resulting value, not an additional access to the target.

The transformation uses bitwise operations, with no arithmetic increment, decrement, or carry. A nonzero input is not combined directly with the stored word. In particular, input value 2 sets bit 0; it does not set bit 1 on account of the input’s binary representation.

### Write and return

The computed value is written to the target word. This write occurs even when the computed value equals the value originally read. There is no shown equality check that suppresses a redundant write.

After the write, the function returns zero.

The target-operation sequence shown is therefore:

1. Read the target word.
2. Derive the replacement value using the input’s zero/nonzero classification.
3. Write the replacement word.
4. Return zero.

No second target read, read-back verification, retry, or alternate success path appears in the supplied evidence.

### Preservation and concurrency limits

For a stable target in ordinary memory without competing modification, the operation preserves bits 1 through 31 and makes bit 0 match the requested zero/nonzero state.

This preservation applies to the value that was read. It is not a guarantee that independently modified bits will survive a concurrent update. A change made by another actor between the read and write may be overwritten by this function’s stored snapshot.

No lock, atomic read–modify–write primitive, synchronization barrier, or interrupt exclusion is shown. The evidence therefore does not support treating the whole operation as atomic. It also does not establish the physical atomicity of either individual word access.
