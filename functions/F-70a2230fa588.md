2. The second read determines whether the global fallback is selected.

The distinction between the reads is behaviorally important:

- The branch decision uses the second read.
- The non-fallback return uses the first read.
- The fallback slot is read only when the second read is zero.

If both reads observe a stable field, the behavior reduces to returning that field when nonzero and returning the global fallback when zero. Stability is a conditional assumption, not a general guarantee.

The function makes no intervening dependency call between these two reads.
