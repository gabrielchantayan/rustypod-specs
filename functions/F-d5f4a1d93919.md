# F-d5f4a1d93919

## Purpose

F-d5f4a1d93919 produces a Boolean-valued, 32-bit result through one of two paths:

- A descriptor-matching path requires a 16-bit discriminator equal to 1 and an indirectly stored 32-bit value equal to the first argument.
- A preliminary dependency, invoked only when the first argument is zero, can establish success without the descriptor-matching reads.

The distinction is observable. Success does not always establish that the descriptor has discriminator 1 or that its indirect value equals the first argument. When the first argument is zero, a nonzero result from F-8f8b4462085f bypasses both checks.

The supplied static representation establishes this control flow. It does not establish an application-level meaning for the discriminator, the indirect value, or the preliminary dependency.

## Interface

**First argument — comparison value**

An unsigned 32-bit value. Zero selects the preliminary-dependency path; every nonzero value bypasses that dependency.

The full 32-bit value participates in the eventual equality comparison. There is no narrowing to 16 bits and no signed comparison.

**Second argument — descriptor address**

An address supplied as a pointer to 16-bit unsigned storage. On the descriptor-matching path, the function interprets memory relative to this address as follows:

| Location | Interpretation | Access condition |
|---|---|---|
| Byte offset 0 | Unsigned 16-bit discriminator | Matching path is reached |

The byte offsets follow from the represented 16-bit element type. The pointer field begins four bytes after the descriptor address; it is not itself an inline 32-bit comparison value.

The supplied representation does not independently establish pointer width. On an ABI with four-byte pointers, the pointer field occupies offsets 4–7. Other pointer widths change the field’s extent, not its starting offset. Pointer encoding, byte order, and alignment requirements remain platform-dependent.

### Output

On normal completion, the function returns exactly one of these 32-bit values:

- **1:** acceptance.
- **0:** rejection.

A nonzero result from F-8f8b4462085f is normalized to 1; its original value is not forwarded.

### Preconditions

For the descriptor-matching path to complete normally:

- The discriminator must be readable as a 16-bit value.
- If the discriminator equals 1, the pointer field at offset 4 must be readable.
- That pointer must designate storage readable as a 32-bit unsigned value.
- Accesses must satisfy the execution platform’s applicable memory and alignment requirements.

These requirements are path-dependent. A discriminator other than 1 does not require a valid indirect pointer. A preliminary dependency result other than zero avoids all descriptor reads explicitly performed by this function, although the dependency may impose its own requirements.

There is no explicit null-pointer check, length parameter, bounds check, or memory-access error conversion.

## Behavior

### First argument is nonzero

F-8f8b4462085f is not invoked.

The function first reads the descriptor’s 16-bit discriminator. If that discriminator is not exactly 1, it returns 0 without retrieving the pointer field or reading the indirect value.

If the discriminator equals 1, the function retrieves the pointer stored at descriptor offset 4 and reads a 32-bit unsigned value through that pointer. It returns 1 if that value exactly equals the first argument; otherwise, it returns 0.

A nonzero first argument therefore requires successful descriptor matching. There is no dependency-based shortcut on this path.

### First argument is zero

The function first invokes F-8f8b4462085f with the descriptor address.

If that dependency returns any nonzero signed 32-bit result, the function returns 1. Positive and negative dependency results both qualify. This function performs no subsequent discriminator, pointer-field, or indirect-value read on that path.

If the dependency returns zero, the function proceeds to descriptor matching:

- A discriminator other than 1 produces 0.
- A discriminator equal to 1 causes retrieval of the pointer at offset 4 and a 32-bit read through it.
- An indirect value equal to zero produces 1.
- Any other indirect value produces 0.

The descriptor-matching reads occur after the dependency returns. Consequently, if the dependency changes the descriptor or the pointed-to value, the subsequent reads use the resulting accessible state. The supplied material does not establish that the dependency preserves either location.

### Read order and conditional access

For normal, sequential execution, the explicit access order is:

1. Where required, complete the dependency call.
2. Read the 16-bit discriminator.
3. Only if that discriminator equals 1, retrieve the stored pointer.
4. Read the 32-bit value through the retrieved pointer.
5. Return the corresponding Boolean result.

Steps 2–4 are entirely bypassed when the first argument is zero and the dependency returns nonzero.

There is no second discriminator read shown, no pointer-field access for a mismatching discriminator, and no direct descriptor validation beyond the discriminator comparison. These are logical access guarantees from the supplied representation, not guarantees about speculative processor activity or memory-transaction granularity.

### Widths and arithmetic

The discriminator comparison uses the unsigned value of the complete 16-bit field. Only the value 1 qualifies; other nonzero values do not.

The indirect comparison uses all 32 bits of both operands. Values with the high bit set are ordinary unsigned comparison values, not negative values.

There is no numeric accumulation, truncating conversion of the comparison value, or overflow-dependent comparison. The relevant address calculation locates the pointer field four bytes after the descriptor address. Validity of that address calculation and the resulting accesses remains a precondition rather than a checked condition.

Invalid memory does not have a specified rejection result. If a required descriptor or indirect access is invalid, the supplied representation establishes neither a normal return nor an error-reporting mechanism.

If the dependency fails to return normally, this function has no shown recovery path. Dependency exceptions, process termination, faults, and other nonlocal behavior are not specified here.
