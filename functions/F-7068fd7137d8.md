## Acceptance examples

These examples are conditional static expectations, not executed tests. Each assumes execution reaches the described event and all required accesses and calls complete.

1. **Unsigned byte selection.** If an applicable selector read returns hexadecimal FF, the corresponding byte destination is address 272, not an address obtained by sign-extending that byte.

2. **Byte truncation.** If the first packed value is hexadecimal 00000123, its first byte update stores hexadecimal 8C: only the low byte of four times that value is written.

3. **Masked extraction.** If the first auxiliary value is hexadecimal FFFFFFFF, its masked-and-shifted call argument is hexadecimal 000FFFFF, not an arithmetic right-shift result.

4. **Visible zero write.** If the byte at address 1 is decimal 7 when the absolute-address read occurs, the next byte store writes zero at address 24.

5. **Wide-result split.** If the recovered 64-bit result has high half 3 and low half 5, the immediate zero store targets address 32. The subsequent indirect call receives 3. Later wide-low transformations use 5, not 3.

6. **Distinct address scales.** For a link index of 3, the link-stage store writes 12 at address 68. A word read from Word slot(3) instead accesses address 32. These locations must not be conflated.

7. **Retained extraction.** If the extracted word is hexadecimal ABCDEFFF, the later extraction store writes hexadecimal 000ABCDE, even if intervening calls change the original read location.

8. **Repeated selector read.** If dependencies change the final selector byte between its two reads, the final two byte stores may have different destinations. Reusing the first selector is not supported.

9. **Low-six-bit argument.** For an extraction index of 15, four times the index is 60; masking to six bits and shifting left by 14 produces hexadecimal 000F0000.

10. **No proven successful termination.** Completion of the last listed call does not establish a normal return, successful status, or any application-defined error code.
