### Result selection

The indirect operation’s return is treated as a pointer.

If that pointer is null, the function performs no result-memory read and returns the fallback word captured earlier.

If that pointer is non-null, the function reads one 32-bit word at the returned address and returns that word instead. There is no scan, length check, additional dereference, or subsequent interpretation of its contents in the supplied body.

Every 32-bit result-memory value is eligible for return. In particular:

- A pointed-to zero is returned as zero; it does not select the fallback.
- A word with its high bit set is returned without a wrapper-side range check.
- A word equal to the captured fallback produces the same returned bits through a different path.

The decision is based on pointer nullness, not on the contents of result memory.
