## Acceptance examples

These examples are conditional specifications, not reports of executed tests.

### Normal sequence with stable dependencies

Assume all dependencies return normally, the returned storage is valid, no dependency changes previously written bytes, and external values remain stable.

If the header source is decimal `1000`, the explicit stores produce `1000` at `0x000` and `1500` at `0x01C`. The returned pointer must equal the pointer supplied by F-3c6991d61386.

Under those assumptions, the listed zero stores and fixed-value stores remain visible at return. Without the noninterference assumption, only the write events and their ordering are established.

### Dependencies change external values

Suppose the indirect registration-style operation changes the setup value.

The later F-1855137c994c call must use the value sampled after that indirect operation, rather than a value assumed to have been captured at function entry.

Similarly, if initialization of the region at `0x078` changes the region configuration value, the immediately following F-6904f7699031 call uses the subsequently read value.

### Byte-width preservation

Assume the four bytes starting at `0x0C4` initially contain distinct nonzero values and no dependency later touches them.

The explicit operation clears only the byte at `0x0C4`. It must not be interpreted as clearing bytes `0x0C5` through `0x0C7`.

The four F-861a66c91b48 calls must target `0x044`, `0x078`, `0x0EC`, and `0x11C`, in that order.

F-a062a6eb1219 must receive the literal `1` first and the interior pointer at `0x14C` second. Reversing those arguments does not satisfy this contract.

### Final result storage

Assume F-17fe47085641 returns a particular 32-bit value and returns normally. That value is written at `0x040`, followed by a 32-bit zero write at `0x18C`, followed by return of the original object pointer.

### Interrupted initialization
