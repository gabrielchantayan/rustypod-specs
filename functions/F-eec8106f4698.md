# F-eec8106f4698

## Purpose

The visible operation is a multiply-add recurrence followed by selection of 15 bits. This is consistent with a pseudorandom-state update, but that purpose is inferred, not established. The evidence does not establish randomness quality, a particular generator family, a fixed multiplier, or an intended application.

## Behavior

### Arithmetic transition

Let **S** denote the state value read for the calculation and **M** denote the multiplier value used in that calculation.

Under 32-bit unsigned arithmetic, the next state is:

**N = (M × S + 12,345) modulo 4,294,967,296.**

The function stores **N** into the state cell and returns:

**R = floor(N / 65,536) modulo 32,768.**

Equivalently, the return value consists of bits 16 through 30 of the updated 32-bit state. Bits 0 through 15 and bit 31 do not contribute to the return value.

The increment of 12,345 is established by the supplied operation. No particular multiplier value is established.

Multiplication and addition are not checked for overflow. Under the stated unsigned model, values beyond the 32-bit range wrap modulo 2³². The function neither saturates the state nor reports overflow.

### Relationship between stored state and result

The state write preserves the entire 32-bit next state, including bit 31 and the low 16 bits. The returned value is narrower in information content, not a replacement for the stored state.

In particular:

- An updated state with bit 31 set does not produce a negative result.
- Updated states differing only in bit 31 produce the same return value.
- Updated states differing only in their low 16 bits produce the same return value.
- A zero return does not imply a zero stored state.
- The output is derived from the updated state, not directly from the previous state.

The visible operation first shifts the unsigned next state right by 16 bits and then applies a mask. Under the 32-bit model, the shift leaves at most 16 significant bits. The mask then removes the remaining bit corresponding to original state bit 31, leaving the stated 15-bit result. Its other set positions cannot introduce bits into the result.
