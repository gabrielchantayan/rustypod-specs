## Acceptance examples

These are conditional static cases, not executed tests.

- **Stable two-record selection:** Count 2, mandatory selectors zero, and disabled optional selectors select current-record entries 0 and 1. Disabled fields are not thereby zero.
- **Optional range:** Stable count 5 and word 1 equal to 1 select entries 1–4. Word 1 equal to 2 requires unpopulated entry 5.
- **Signed guards:** Guard values 0x80000000 and 0xffffffff disable their optional selections.
- **Changing counts:** A first loop populating only entries 0–1 followed by a second loop consuming entry 2 violates population requirements, despite counts remaining below ten.
- **Capacity:** Stable count 9 fits the arrays with valid selectors. Count 10 exceeds capacity without an established diagnostic.
- **Allocation-context mutation:** If the first inner allocation changes the container’s offset-4 field, the next allocation receives its reread value.
- **Ordered merges:** The adjustment merges pass later count before initial count, and later pointer before initial pointer.
- **Preserved saved owner:** If all intervening effects preserve relative offset 64, both later reads yield the original owner. This is conditional, not an unconditional identity.
- **Saved-owner replacement:** If the saved slot contains another valid owner-like address when subordinate-call arguments are read, that address is passed as the first argument. If the subordinate call replaces the slot again and subsequent effects preserve it, the late mode access uses the replacement, not the earlier argument.
- **Late mode:** A byte of 4, 6, or 255 reached through the late saved-slot-based pointer chain selects immediate 2, 1, or 0, respectively.
