## Behavior

### Dispatch selection

The input storage is dereferenced once to obtain the base value.

The fixed displacement 292 is added to that loaded value. The resulting integer is used to locate storage containing a callable address. The function reads that callable address and invokes it.

This establishes two distinct data reads:

1. The integer read through the input pointer.
2. The callable-address read from the computed location.

The second read depends on the result of the first. The invocation depends on the result of the second. Target execution therefore follows both dispatch-selection reads.

The function does not directly invoke the computed slot address. It invokes the address **stored at** that location. This distinction is observable when the slot address and its contents identify different executable locations.
