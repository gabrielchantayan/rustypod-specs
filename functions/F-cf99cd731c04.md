# F-cf99cd731c04

## Purpose

F-cf99cd731c04 performs a fixed, ordered construction-and-submission operation over four positions. It obtains two shared 32-bit values, then, for each position, obtains four additional values, requests three position-specific values, issues four operations with numeric operation tags, and submits one result at a position-dependent destination coordinate.

The established contract is the sequence of calls and the flow of 32-bit values between them. The supplied evidence does not establish the meaning of the operation tags, the representation of the returned values, or whether the final submission writes ordinary memory, modifies an intermediate representation, or performs some other operation.

An inferred intent is that the function constructs a small expression or instruction graph and submits four outputs. That interpretation is not required for the behavioral contract.

## Behavior

The following ordering is established for an execution in which all reads and dependency calls complete normally.

### Initial read and shared-value requests

First, the function reads the 32-bit word at A2 plus byte offset 4. This is the initial captured word.

It then invokes F-3976e291be48 twice, in this order:

1. With A1, A2, A3, selector 0, and A7.
2. With A1, A2, A3, selector 1, and A7.

The returned 32-bit words become the first and second shared values, respectively. Each is obtained once and reused for all four positions.

The initial captured word is read before either request. If either request changes the memory at A2 plus offset 4, that change does not replace the word already captured by this function.

The second shared-value request occurs after the first has completed. Its behavior may therefore reflect side effects of the first request. Nothing in the evidence guarantees that either request is pure.
