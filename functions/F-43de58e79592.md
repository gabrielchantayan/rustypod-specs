# F-43de58e79592

## Purpose

F-43de58e79592 selects and returns one of two four-byte values associated with a caller-supplied base address. The second input determines which location is read:

- A zero selector chooses the four-byte value at byte offset 12.
- Any nonzero selector chooses the four-byte value at byte offset 4.

The established behavior is a conditional memory read, not a comparison of the stored values. The selector does not supply an index, count, or displacement.

The meanings of the two stored values are unknown. They may represent numbers, flags, addresses, or other four-byte data, but the supplied evidence establishes none of those interpretations.

## Behavior

### Selection

The selector is examined before the selected memory access.

When the selector is zero, the function reads the four bytes beginning at base address plus 12 bytes.

When the selector is nonzero, the function reads the four bytes beginning at base address plus 4 bytes.

The magnitude of a nonzero selector has no further effect. For example, selectors 1 and 2 choose the same location. If negative selector values are representable at the interface, they also choose that location.
