These are conditional static acceptance examples, not executed tests. Unless stated otherwise, they assume preceding operations are interpretable and all reached accesses succeed.

3. **Zero halfword base.** For input 2 equal to `0xA8`, the index and halfword base are zero. The initial halfword writes target addresses four, six, and two, followed later by a halfword read at zero.

4. **Early termination ordering.** If the first address has its signed sign bit set, the halfword write at dependency base plus four precedes the first termination site. The subsequent write at dependency base plus `0x12` is not reached through that branch.

5. **Bit-selected destinations.** A clear bit 2 selects destinations `0x5C` and `0x170`; a set bit selects `0x60` and `0x180`.

6. **Conditional sign propagation.** Under arithmetic signed right shift, a read halfword of `0x7FFF` produces a zero word at dependency base plus eight; `0x8000` produces `0xFFFFFFFF`.
