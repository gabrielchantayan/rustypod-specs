# F-71a01537ac20

- Return **1** if acquisition produces a null object pointer.
- Return **1** if acquisition produces a non-null object pointer and the invoked operation returns a nonzero 32-bit integer.
- Return **0** if acquisition produces a non-null object pointer and the invoked operation returns zero.

In particular, null acquisition and a nonzero operation result intentionally share the same outward value, but their application-level meanings are unknown.
