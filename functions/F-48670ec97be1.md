# F-48670ec97be1

## Purpose

F-48670ec97be1 performs one of two memory-update sequences, selected by whether its second explicit input is zero. Both sequences depend on a halfword obtained through an implicitly supplied context value. The zero-selected sequence also uses a second sampled halfword, an implicit auxiliary value, and five global storage destinations.

On normal completion, the function returns its fifth explicit input unchanged.

Zero is a branch selector, not an established indication that an address may be omitted. A read relative to the second input precedes the branch decision. Consequently, selecting the zero path requires an initial halfword read at address 4.

No application-level purpose is established. The available evidence does not justify assigning processor-management, exception-handling, initialization, or ownership semantics to the updates.

## Behavior

### Sampling and selection

Two samples are obtained before any visible write:

1. An unsigned 16-bit value from the second input plus 4.
2. An unsigned 16-bit value from context plus 40.

The supplied representation places the first read before the context read, and both before the zero/nonzero decision. This is the represented access order, not independent instruction-level confirmation.

The context sample is widened to 32 bits without sign extension. Its numeric range remains 0 through 65,535. A sample of 65,535 therefore produces a 32-bit value of 65,535, not a value with all 32 bits set.

Both samples remain available for later use. The visible behavior contains no reread of either source after mutations begin. Overwriting a source location later does not retroactively change its sampled value.

### Nonzero selection

Any nonzero second input selects the shorter sequence. The condition does not distinguish positive from negative nonzero values; whether the corresponding initial address is usable remains an environmental requirement.

The function requests one 32-bit write at context plus 48. The value written is the zero-extended context sample.

There are no explicit assignments to G1–G5 on this path. This does not guarantee that their physical storage remains unchanged: the destination may alias global storage if the external memory layout permits it.

After the write completes, the function returns the fifth input unchanged.

### Zero selection

A zero second input selects the broader sequence, but only after the initial reads. The first sample therefore comes from address 4.

The updates have three ordered phases.

**Global preparation.** G1 first receives the result of subtracting five from context. G2 is then assigned a value obtained by multiplying the value of G1 by 256.

The dependence on G1 is material. Without G1’s declaration, the contract cannot replace this dependency with an unconditional calculation using only the original context. Conversion during assignment to G1, the value subsequently obtained from G1, and the multiplication’s width may affect the result.

**Intermediate publication.** After the G2 assignment, the function requests a 32-bit write at context plus 59. The value is the previously sampled context halfword, widened without sign extension.

This is a four-byte write despite the odd offset. It does not change which context sample is used, even if the write overlaps a sampled source.

**Remaining publication.** After the intermediate write, the representation forms the final address base by shifting context left by eight bits. The remaining global assignments then occur in this order:

- G3 receives the first sample, widened to a 32-bit unsigned value.
- G4 receives context.
- G5 receives auxiliary.

The final requested memory write places the 32-bit numeric value 141 at the shifted context base plus 48. It follows all five global assignments and the intermediate write.

Normal completion then returns the fifth input unchanged.

The values supplied to G3–G5 do not establish the destinations’ physical widths. In particular, supplying a zero-extended 32-bit value to G3 does not prove that G3 occupies four bytes.
