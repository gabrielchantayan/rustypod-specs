# F-e057994d7e78

In particular, the return value must not be described unconditionally as success, failure, completion, or pending status: the supplied evidence supports only the numeric outcomes and conditions specified below.

This is a static behavioral contract. No runtime tests have been performed.

## Behavior

### Entry observation and branch selection

### Zero selector

When the captured selector is zero:

1. F-b1e0e0283908 is invoked with the original object base and the 32-bit all-ones argument `0xFFFFFFFF`.
2. If that invocation returns normally, the function writes a 32-bit zero to offset `0xC4` relative to the original base.
3. The function returns 1.

The second dependency argument has all 32 bits set. It can represent −1 under a signed 32-bit interpretation, but its semantic role is unknown. This contract does not label it a sentinel or a request to process all entries.

### Nonzero selector above the comparison value

When the selector is nonzero, the function reads the signed 32-bit value at offset `0x5C`.

If the selector is greater than that signed value:

- Neither dependency is invoked.
- The function performs no direct write to the resettable field.
- The function returns 0.

The selector remains a nonnegative value after widening. Consequently, every negative comparison value selects this path for every nonzero selector. A comparison value of zero also selects this path for every nonzero selector.

“No direct write” does not imply that unrelated external activity cannot change the object.

### Nonzero selector at or below the comparison value

When the nonzero selector is less than or equal to the signed comparison value, the function invokes F-7ec140c78f52 with:

- The original object base.
- The captured selector, widened to a 32-bit value without sign extension.

The dependency’s 32-bit result is tested against zero.

If the result is nonzero, the function returns 1 without directly writing the resettable field. The dependency result is normalized: its original nonzero value is not forwarded to the caller.

If the result is zero, the function writes a 32-bit zero at offset `0xC4` and returns 0.

Equality belongs to the dependency-invoking path. The boundary is inclusive.

- Each direct reset write occurs after the relevant dependency returns normally.
