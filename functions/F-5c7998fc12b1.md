# F-5c7998fc12b1

## Purpose

F-5c7998fc12b1 dispatches according to a 32-bit discriminator stored in a caller-supplied object. It recognizes two discriminator values:

- **30:** invoke F-e9b8c3dcb7c6 with the first argument, then return **1**.
- **35:** invoke F-682adfd5a561 with the object address and the constant **14720**, pass its 32-bit result to F-deca110c5079 together with the first argument, and return the latter dependency’s 32-bit result.
- **Any other value:** return **0** without invoking either recognized branch’s dependencies.

These are dispatch and return-value semantics, not established application-level meanings. The evidence does not identify what the object represents, what either recognized discriminator means, or whether any return value denotes success.

This contract describes behavior visible in the supplied static source representation. It does not establish the internal effects of the dependencies. No runtime tests have been performed.

## Behavior

The evidence describes ordinary sequential control flow. It does not establish synchronization or behavior under concurrent modification of the object.

No return value from F-e9b8c3dcb7c6 is used to determine the wrapper’s return value. Whether the dependency actually has a meaningful return value is not established here.

### Discriminator 35

When the loaded discriminator equals 35:

   - The original second argument, unchanged.
   - The constant **14720**, hexadecimal **0x3980**.

3. F-deca110c5079 is invoked with two arguments, in this order:

   - The captured 32-bit result from F-682adfd5a561.

The first dependency call precedes the second. The second call is not reached unless the first returns control.

There is no visible test of the intermediate value before it is passed onward. In particular, zero is not treated as a special case by this function. There is also no visible conversion, dereference, copy of pointed-to data, or cleanup applied to that value between the two calls.

F-e9b8c3dcb7c6 is not invoked by this branch.
