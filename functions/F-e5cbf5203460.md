Under a 32-bit bit-vector interpretation, each left shift or multiplication retains only the low 32 bits. Successive shifts lose information at each stage; combining them as unbounded arithmetic is not valid. A sequence whose accumulated left displacement reaches 32 bits produces zero under that interpretation, but signed-shift semantics remain **documented_only**.

The calls cannot safely be replaced by a pure calculation. Unknown dependencies may change memory or globals, fail, or not return.

### Values entering explicit mutation

The memory phase uses several retained values:

- A call-result-derived value shifted left 25 positions, used both as stored data and as a byte-address base.
- A separate call result scaled by 2²⁵.
- An earlier result shifted left eight positions.
- The low and high words of the last combined call result.

Under ordinary 32-bit bit-vector arithmetic, that index is not an arbitrary integer from 0 through 511. The preceding eight-position shift leaves its low eight bits zero. Consequently, the index ranges from 0 through 508 in steps of four. Its doubled value ranges from 0 through 1016 in steps of eight.

This bound provides no evidence that accesses through the doubled value are valid or relative to an allocation.

## Acceptance examples

These are conditional static examples, not executed tests.

### Equal initial arguments

If the incoming argument-bearing value is 1 and shifting uses 32-bit bit-vector semantics, the first call receives 128 in both represented argument positions. Target validity is a separate precondition.

### Unsigned promotion

If the opening offset-5 byte read yields 0xfe, its corresponding offset-0x34 word store receives 254, not a sign-extended negative value.

### Reachable index boundary

If the index-producing call result is 0x7f, its eight-position shift is 0x7f00. Masking and shifting right six positions yields 508; doubling yields 1016.

An index of 511 is not reachable through this bit-vector expression because the shifted intermediate’s low eight bits are zero.

### Saved global base precedes fixed-address mutation

If the separate global-base read yields address A, repeated-region stores use A even if the subsequent word write at fixed address 0x60 changes the storage from which that base was read. Reloading the base afterward is not equivalent.

### Interleaved final reads

If writing the byte at fixed address 0x3a overlaps either following computed word read, that read observes the post-write storage. A trace that performs both reads before the byte write does not satisfy the represented ordering.

### Intervening word read before global-byte copy

After writing fixed byte 0x67, the doubled-chain-base offset-0x44 word read occurs before the fresh byte read used for fixed address 0x21. Even when the copied byte happens to match the saved low byte, omitting that intervening read is not trace-equivalent.
