### Arithmetic notation

For describing address and value formation:

- \(L_n(x)\) means the low 32 bits of \(x\) shifted left by \(n\), retaining only 32 bits.
- \(P_k(x)\) means multiplication by \(k\), retaining only 32 bits.
- \(\operatorname{lo}(x)\) and \(\operatorname{hi}(x)\) select the lower and upper 32-bit halves of a represented 64-bit result.
- \(\operatorname{byte}(x)\) selects the low eight bits.
- \(R_8(a)\) and \(R_{32}(a)\) denote an unsigned byte read and a 32-bit read at address \(a\).
- \(W_8(a,v)\) and \(W_{32}(a,v)\) denote byte and 32-bit writes.

These conventions express the apparent 32-bit machine behavior. They are not a claim that signed overflow or signed left shifts have portable language-level semantics.

## Acceptance examples

These are conditional acceptance criteria, not executed tests.

1. **Saved selector versus fresh selector.**  
   If the opening read returns 7, the opening byte write targets address 24 and the subsequent word write targets address 27. A dependency changing the selector location before that word write does not redirect the word write. A later fresh selector read can redirect a later byte write.

2. **Byte truncation.**  
   If the opening byte-source state is `0x123456AB`, the opening byte store writes `0xAB`. It does not write a 32-bit value.

3. **Unsigned selector range.**  
   A selector byte of `0xFF` selects address 272 for an offset-17 byte write, not address 16 through signed-byte interpretation.

4. **Shifted argument truncation.**  
   If the current third argument is `0x40000001`, its opening shifted word value is `0x00000004` under 32-bit machine arithmetic.

5. **Forced-zero dependency argument.**  
   F-U13-3 receives zero as its first explicit argument under the stated arithmetic model, regardless of \(V\). Its second argument remains unresolved.

6. **Repeated clearing is not redundant.**  
   If F-U23 modifies \(B'+1\) after the first direct clearing pair, the second clearing pair writes zero there again. An implementation cannot remove the second pair merely because the earlier stored values were zero.

7. **Dependency mutation remains visible.**  
   If a dependency after the second clearing pair changes \(B'+1\) to 9, and no later dependency changes it, the closing byte-selected write targets address 26.

8. **No ordinary completion.**  
   If all dependencies return and all memory accesses succeed, completing the closing sequence starts another iteration. No return value is delivered to the caller.
