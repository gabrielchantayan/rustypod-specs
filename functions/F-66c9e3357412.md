## Acceptance examples

These are conditional contract examples, not executed tests.

1. **Zero prerequisite result.** Given valid storage and normal completion of the prerequisite, a zero result causes return value 1 without any conditional calls or global input reads. The byte update occurs before the prerequisite; the byte remains 17 only if the prerequisite leaves it unchanged.

2. **Nonzero and negative results.** A prerequisite result of 1 or a four-byte signed representation of −1 selects the same conditional sequence. Treating a negative value as an automatic early exit would not preserve the visible branch.

3. **First direct global changes.** If F-6a21f4f07f67 changes the global supplying F-aaf1683df92f’s third argument from value A to value B, and no subsequent change intervenes, that argument is B. Reading A before the call would violate the established ordering.

6. **Slot reuse.** If the first production call modifies the auxiliary slot, the second production call receives that same storage with its intervening state. The caller does not restore zero. The same no-reset rule applies to the resource slot.
