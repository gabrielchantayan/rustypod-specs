## Behavior

### Classification rule

A pair qualifies when its value field is zero and its flag field contains bit `0x00000020`.

The result is:

- **1** when the higher-offset pair qualifies, regardless of the lower-offset pair.
- **1** when the higher-offset pair does not qualify but the lower-offset pair qualifies.
- **0** when neither pair qualifies.

Bits other than `0x00000020` in either flag field do not affect classification. A flag value need not equal `0x00000020`; any 32-bit value containing that bit satisfies the flag condition.

1. Read the 32-bit value at offset `0x68`.
2. If that value is zero, read the 32-bit flags at offset `0x6C`.
3. If those two observations establish that the higher-offset pair qualifies, return **1** without evaluating either lower-offset field.
4. Otherwise, read the 32-bit value at offset `0x50`.
