### Classification rule

For an unsigned 32-bit temporary, the masked result is necessarily one of 0, 1, 2, or 3. All four possibilities have an established output:

- A masked result of 0 selects byte 4.
- A masked result of 1 selects byte 6.
- A masked result of 2 selects byte 7.
- A masked result of 3 selects byte 1.

Bits 2 through 31 do not affect the classification. Values that differ only in those bits select the same output byte, provided execution otherwise proceeds normally.

There is no signed comparison, multiplication, increment, or arithmetic operation that can overflow in this classification. The selected values all fit in an unsigned eight-bit byte.
