# F-397d1a5eac14

## Purpose

F-397d1a5eac14 conditionally dispatches a call through a callback obtained from a descriptor referenced by the first argument. It forwards the callback’s result unchanged unless that result is the signed 32-bit value −1. Three conditions instead select a diagnostic call and, if that call returns normally, a return value of zero:

- The first argument’s initial 32-bit field is zero.
- The descriptor’s callback slot is null.
- The callback returns −1.

The established behavior is dispatch plus diagnostic reporting. The meaning of the descriptor, the operation performed by the callback, and the significance of successful return values are unknown. In particular, zero is not an unambiguous failure indication: a callback may return zero directly without triggering the diagnostic dependency.

## Behavior

### Initial descriptor access

The function first reads the 32-bit field at byte offset 0 from the first argument.

If this value is zero, it selects diagnostic selector 131, hexadecimal 0x83. It does not inspect a callback slot and does not invoke a callback. It proceeds directly to the diagnostic operation.

If the value is nonzero, the function reads the callback pointer at byte offset 44 from the referenced descriptor.

The supplied expression structure contains an initial field access for the zero test and another access to obtain the descriptor reference on the nonzero branch. With stable storage, both refer to the same descriptor value. The excerpt does not establish volatile semantics, atomicity, synchronization, or an exact machine-load count. It therefore does not support a guarantee that concurrent mutation is observed consistently.

### Callback availability

If the callback slot is null, the function selects diagnostic selector 132, hexadecimal 0x84. No callback is invoked. Processing proceeds to the diagnostic operation.

If the callback slot is nonnull, the function invokes that callback using the five-argument interface above.

The excerpt contains no additional callback validation. It does not check whether the target is executable, has a compatible calling convention, or can safely process the forwarded arguments.

### Callback completion

After a normal callback return, the function compares the signed 32-bit result with −1.

If the result is not −1, the function immediately returns that result. It does not call the diagnostic dependency on this path. This applies to zero, positive values, and negative values other than −1.

If the result is −1, the function selects diagnostic selector 133, hexadecimal 0x85, and proceeds to the diagnostic operation.

There is no retry, alternate callback, or fallback computation. The callback is invoked at most once by one invocation of this function. After the callback returns, the function does not revalidate the descriptor or callback slot.
