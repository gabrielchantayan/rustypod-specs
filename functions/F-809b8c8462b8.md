# F-809b8c8462b8

## Purpose

Its established behavior is narrow:

- Obtain two values from a caller-provided object.
- Add 544 to the first value.
- Pass the resulting value, the second value, an uninterpreted 32-bit argument, and an optional word pointer to F-c45cb3f8e7fd.
- If that dependency returns normally and the word pointer is non-null, replace the word’s then-current value with its unsigned value shifted right by one bit.

### Conditional post-call transformation

If F-c45cb3f8e7fd returns normally, the function checks whether the optional word pointer is null.

For a null pointer, it performs no direct word read or write.

For a non-null pointer, it:

- Reads the unsigned 32-bit word currently stored at that location.
- Discards its least significant bit by shifting right once.
- Writes the resulting unsigned 32-bit value back to the same location.

The input to this transformation is the value present **after** the dependency call. It is not a saved copy of the word from before the call.

The shift inserts a zero at the most significant bit. Its result is equivalent to rounding the unsigned value divided by two downward. Consequently, the stored result is between 0 and 2,147,483,647, inclusive.

The wrapper performs this transformation regardless of whether the dependency represents its outcome as success or failure through memory or an otherwise unused return value, provided the dependency returns normally and leaves the word accessible.
