## Behavior

### Post-call read and object updates

1. Read one byte from N plus `0x18`. Interpret the byte as an unsigned value V in the range 0 through 255.

2. Form T from H plus `0x31`.

3. Form J by shifting R left by one bit.

4. Write the one-byte value decimal 100, hexadecimal `0x64`, to H plus `0x45`.

5. Load P from the four-byte storage location at H plus `0xA5`.

6. Write T as a four-byte value to the address V plus `0x38`.

7. Write decimal 100 as a four-byte value at P.

8. Write T as a four-byte value at P plus four bytes.

9. Write T as a four-byte value at P plus eight bytes.

10. Write P itself as a four-byte pointer representation at P plus twelve bytes.

The read of V occurs before the byte write at H plus `0x45`. The pointer load occurs after that byte write. Therefore, if the byte write overlaps the pointer storage, the pointer load uses the resulting memory contents rather than an earlier pointer value.

The low-address word write at V plus `0x38` occurs after P has been loaded but before the record is initialized. If this write overlaps the storage from which P was loaded, it does not retroactively change the already obtained P. If it overlaps the record addressed by P, the later record writes can overwrite it.

The representation uses V directly as the base for the word write. It does not show a pointer-table lookup, a dereference through a larger object, or an extension of V from any additional bytes.
