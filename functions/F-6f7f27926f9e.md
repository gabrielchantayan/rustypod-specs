- The external dependency is not invoked.
- No second input read is expressed.

### Nonzero case and dependency call

If the first read is nonzero, the supplied representation expresses a **second read through the same pointer** to obtain the dependency argument. The dependency receives that second integer value by value.

The established order is therefore:

1. Read the integer for the zero/nonzero decision.
2. If that read was nonzero, read the integer again for the dependency argument.
3. Invoke the dependency once.
4. Compare its normally returned integer with 10.
5. Return 15 for equality, otherwise return 0.
