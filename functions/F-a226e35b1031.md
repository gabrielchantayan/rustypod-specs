# F-a226e35b1031

## Purpose

F-a226e35b1031 classifies a single integer obtained through a caller-supplied pointer. It returns a zero result for exactly three values: 3, 4, and 49165, the last also expressed as 0xC00D. For every other value, it returns the 32-bit pattern 0xFFFFFFEA.

The established behavior is a membership check, not a transformation of the supplied value. The function does not change the referenced integer, return its address, or produce a separate output object.

A plausible intent is to validate a category, status, or operation identifier. That interpretation is not established: the supplied material gives no domain meaning to the three accepted values. Likewise, the nonzero result could represent an error status, but its symbolic meaning and the caller’s interpretation are unknown.

This contract describes the supplied static representation. It does not establish behavior through execution or independently verified machine instructions.

## Behavior

The supplied representation contains one read of the caller-designated integer. It does not show a second read when an earlier comparison fails. Consequently, the established source-level behavior is classification of one obtained value, not repeated sampling of the caller’s storage.

The decision order is:

1. Values 3 and 4 are considered first. Either produces the zero result.
2. If neither matches, the obtained value is compared with 49165.
3. A match with 49165 also produces the zero result.
4. Every remaining value produces 0xFFFFFFEA.

The comparisons are exact integer equalities. There is no range acceptance, masking, truncation to a smaller field, normalization, or interpretation of selected bits. In particular, having some bits in common with an accepted value is insufficient.

No input arithmetic appears in the supplied representation. The function does not add, subtract, multiply, shift, or otherwise calculate a new value from the input before classifying it. Therefore, there is no input-dependent arithmetic overflow path in the represented behavior.
