# F-0aa58f6267f3

## Purpose

F-0aa58f6267f3 returns a scaled, directional difference between two signed integers held in adjacent storage positions.

The second value is measured relative to the first. For a nonnegative, representable difference, the result is the number of complete four-unit increments in that difference. Positive remainders are discarded, not rejected or rounded to the nearest increment.

This is a numeric operation on stored integers. It does not establish that either integer represents an address, an allocation boundary, or an element count.

**Established static evidence:** the scaling operation is a signed right shift by two positions, applied to the signed difference. This matters for negative differences and intermediate overflow.

**Inferred intent:** the result may express a separation in four-unit increments. The application-level meaning of those units is unknown.

No runtime tests have been performed.

## Behavior

### Direction and scaling

The result reflects the second value relative to the first. Reversing the stored values can change both the sign and the rounding behavior.

For nonnegative differences, each complete group of four contributes one to the result. Differences from zero through three all return zero. A positive remainder has no separate representation and triggers no error.

There is no absolute-value conversion, operand-wise scaling, saturation, or alignment check. The operands need not be multiples of four.

Negative operands are not intrinsically exceptional. Their difference determines which arithmetic rules apply. For example, two negative values can produce a positive result, and a pair crossing zero can still have a representable difference.

### Negative differences

Negative differences remain signed when shifted. Their interpretation cannot be replaced unconditionally with division rounded toward zero.

On an implementation using arithmetic right shift:

- A difference of negative four returns negative one.
- A difference of negative one also returns negative one.
- A difference of negative five returns negative two.

The latter two cases distinguish this convention from division rounded toward zero.

Without target evidence establishing the signed-shift convention, a particular numeric result for a negative difference remains **documented_only**. The function does not select or normalize that convention.

No explicit overflow check, wider subtraction, modular reduction, or clamping is present. Consequently, an out-of-range difference has no guaranteed numeric return. Wrapping behavior must not be inferred from a likely processor representation.
