## Acceptance examples

These examples are conditional static checks, not executed tests.

1. **Low-byte truncation.** If the early result is 255, multiplication by four produces 1020, and each corresponding byte write stores 252. A wider store is not equivalent.

2. **Fresh selector reads.** If an intervening dependency changes a selector byte from 3 to 9, a later separately represented read selects address 26 rather than reusing address 20.

3. **Retained selectors.** Where a selector byte is explicitly retained, later accesses derived from that retained value use it even if memory at the original selector address changes.

4. **Seed arithmetic.** If the fourth input is 1, the seed is 256. Its product with \(2^{19}\) is \(2^{27}\), not zero; its product with \(2^{20}\) is \(2^{28}\). Neither selector calculation may be discarded as an unconditional read from address 1.

5. **Mask distinction.** Two fourth-input values differing only above bit 21 produce the same seed, but may still produce different direct addresses. Equal seeds do not establish equivalent executions.

6. **Word-to-byte copy.** If a completed word read yields the numeric value \(0x123456AB\), the following low-byte copy stores \(0xAB\), independent of how that word is laid out in memory.

7. **Intermediate visibility.** A dependency between the two writes at eight-scaled base plus 52 may observe the first word. Keeping only the replacement write changes the represented behavior.

8. **Literal-address order.** If execution reaches both writes to address 13, the selector-derived byte is written first and 192 later. Failure between them leaves only the earlier represented write completed.

9. **Partial execution.** If an indirect call does not return, no later explicit write is required to occur. Earlier writes are not required to be undone.
