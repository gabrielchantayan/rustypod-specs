It writes one 32-bit value obtained from a global location, clears a contiguous 512-byte region, and copies three bytes of information from a caller-supplied record using a 16-bit transfer followed by an 8-bit transfer.

## Behavior

   Invoke F-60d99bc349ed and use its result as the destination base. The invocation precedes every explicit destination write and both source-field reads.

2. **Write the leading 32-bit value.**  
   Read the global 32-bit value and store it at destination offset `0x000`. This occurs after the dependency invocation. The value is therefore not established as a snapshot from function entry: any dependency effect on that global precedes the read.

3. **Clear the 512-byte region.**  
   Perform exactly 128 stores, each 32 bits wide, in increasing address order. The first starts at offset `0x0A4`; the final store starts at `0x2A0` and covers offsets `0x2A0` through `0x2A3`.

4. **Copy the 16-bit field.**

5. **Copy the 8-bit field.**  
   Read 8 bits from source offset `0x5E`, then store that value at destination offset `0x2A6`. This source read occurs after the preceding 16-bit destination store.

6. **Return without an explicit value.**

There is no visible branch on the contents of the source, destination, or global value. The only visible repetition controls the fixed-size clearing sequence.
