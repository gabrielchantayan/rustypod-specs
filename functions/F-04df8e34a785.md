## Acceptance examples

These are conditional arithmetic and ordering examples, not executed tests. Each assumes earlier operations continue normally and the relevant accesses are supported.

1. **Initial alignment mask.** With C = 0x00001003 and A = 0x11223344, the first store writes that word pattern at 0x00001014. C values 0x00001000 through 0x00001003 select the same address.

2. **Nine-bit shifted value.** With R = 0xFFFFFFFF and I = 0x00000100, the next word store writes 0x000001FF at 0x00000414. An eight-bit truncation would be incorrect.

3. **Paired-result roles.** If F-000000000014 supplies P = 3 and Q = 5, T is 12. The word store targets address 40 and writes 12; F-000000000015 receives 12, 5, 12, 12.

4. **Saved global value.** If G yields H and a subsequent dependency changes G, the W read still targets H + 20. If that dependency instead changes memory at H + 20, W can reflect the changed contents.

5. **First byte-selected store.** If the selector at R + 1 contains 0x20 and W = 0xA5C3D27E, the store writes 0x7E at address 0x31. The destination is not R + 17.

6. **Second field extraction.** For W = 0xA5C3D27E, the second stored byte is 0x97. A second selector value of 0xFF selects destination 0x110.

7. **Distinct U-derived addresses.** With U = 0x00200080, the second selector read targets address 2, while the halfword clear targets 0x4001. The function does not correct the odd halfword address.

8. **Selector aliasing.** If the first byte store targets the second selector-read address, and no intervening effect changes it, the later selector read observes the first store’s byte.

9. **Unresolved E.** Knowing only F-000000000041’s ordinary result is insufficient to predict the byte-clear destination. If E is separately established as address 0x2000 at its use, the byte clear targets 0x2000 after the S assignment; that condition does not identify E’s producer.

10. **Final-call failure.** If all writes complete but the address-zero call faults, nominal return is not reached. No visible recovery undoes the preceding writes.
