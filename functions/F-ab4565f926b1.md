The supplied static evidence establishes individual operations and their conditional effects. It does **not** establish a complete execution sequence: the entry state, transition targets, branch arithmetic, and several dependency arguments depend on global values whose contents were not supplied.

Accordingly, this contract distinguishes:

- **Established behavior:** operations explicitly present in the supplied representation.

This establishes reversible byte encoding. It does not establish the semantic meaning of any encoded value.

## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Preserving unrelated status bits.** If the operation setting 0x00020000 is reached with a status word of 0x00000005, its direct write must produce 0x00020005.

2. **Write-before-call ordering.** If the operation setting 0x00010000 is reached, that write must occur before F-d1228fe0890f is invoked with literal 15. A later status-word value cannot be predicted without the callee’s effects.

3. **Buffer boundary.** If the captured pointer denotes the temporary buffer, the flag operation must write 1 to byte 248. It must not directly write byte 247 or byte 249.

4. **Encoding a negative result.** If a signed 16-bit dependency result is −1, the encoded byte must be 71. Decoding 71 through multiplication by 137 and low-byte retention yields 255.

5. **Encoding beyond the byte range.** A signed 16-bit result of 256 encodes to zero. The transform does not preserve the upper eight bits.

6. **Opaque call ordering.** If the ten-argument operation is reached and its first call returns normally, F-db9bb4e5e044 must precede F-573b63bda7bf. No intervening dispatch is shown.

7. **Return semantics.** If the return operation is reached with accumulator 0x80000000, the returned unsigned 32-bit value must be 2147483648. It is not automatically converted to a Boolean or signed error.

8. **Invalid pointer precondition.** Reaching the byte-write operation with a null captured pointer does not establish a defined failure return. The evidence shows no protective check or recovery path at that operation.
