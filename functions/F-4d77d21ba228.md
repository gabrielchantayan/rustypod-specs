## Behavior

1. The supplied value is stored in the four-byte field at destination offset `0x30`.
2. The supplied value shifted left by two bit positions is stored in the four-byte field at offset `0x1C`.
3. Four zero bytes are stored in the field at offset `0x20`.
4. A four-byte zero result is returned.

The second update uses the supplied argument. It does not read back the field written by the first update.
