# F-968c88301966

### Candidate selection and read order

The traversal cursor advances by one 32-bit word before each signed count comparison, including the final comparison that ends traversal. A candidate word is loaded only if the iteration index is less than the stored count.

Consequently, cursor advancement is not itself a candidate read. With a nonpositive count, the first comparison fails and no candidate is loaded.

For each successful iteration condition, the current word is loaded and tested:

- **Zero:** no measurement, growth, or writer call occurs for that candidate.
- **Nonzero:** measurement occurs, followed by conditional growth and then a writer call unless growth fails.

After a completed iteration, the index advances by one. Zero candidates therefore do not suppress later candidates.

Only the three candidate words in the displayed local arrangement are established. Reads beyond them, and pointer movement outside valid traversal storage, do not acquire defined meaning merely because the count requests further iterations.

4. Cursor advancement and count comparison.
