- First output: the first input multiplied by a shared scale, then increased by an offset.
- Second output: the second input multiplied by that scale, without the offset.

### Overlapping storage

If output element zero occupies the same location as input element one, the first result replaces the value subsequently used as the second input. The second result then depends on the newly stored first result, not the original second input.

If output element zero occupies the scale location, the first result replaces the scale before the second calculation. The second calculation consequently uses the replacement scale, assuming the overlap is otherwise valid.

An output store can also alter other overlapping storage, including the offset. Changing the offset after the first calculation has completed does not, by itself, affect the second calculation: the second calculation does not use that field.
