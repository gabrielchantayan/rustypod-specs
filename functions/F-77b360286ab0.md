# F-77b360286ab0

## Purpose

F-77b360286ab0 maps sixteen recognized 32-bit selector values to consecutive zero-based indices. The recognized values are the inclusive range 0x00001500 through 0x0000150F. Their corresponding results are 0 through 15. Every other input produces the 32-bit result 0xFFFFFFFF.

This is an exact-value mapping, not a general extraction of the input’s low bits. An input with the same low-order bits as a recognized selector but different higher-order bits is not recognized.

**Established static evidence:** The supplied representation explicitly associates each of the sixteen selectors with its result and defines a common result for all unmatched inputs.

**Inferred intent:** The recognized values may be identifiers being normalized to compact indices, and 0xFFFFFFFF may serve as an invalid-selector sentinel. Neither the identifiers’ domain nor the caller’s interpretation of the sentinel is established. Those interpretations are not required to describe the mapping.
