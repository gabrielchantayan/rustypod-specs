# F-6216bd86674e

## Purpose

F-6216bd86674e classifies a 32-bit selector into one of two 32-bit return values.

The result is **2** exactly when the selector is one of **3, 4, 5, 8, or 10**. Every other selector produces **0**. The first argument does not affect this classification.

This is the complete behavior established by the supplied static evidence. The meaning of the selected values is not established. In particular, the evidence does not identify the result as an error code, Boolean, capability flag, enumeration, or resource identifier.

### Value interpretation

The selector is compared against the exact values 3, 4, 5, 8, and 10. All are representable identically as positive signed or unsigned 32-bit integers. Therefore, the classification does not depend on choosing a signed or unsigned interpretation for these matching values.

For acceptance purposes, hexadecimal selector values denote complete 32-bit patterns. A value whose low bits resemble a selected value does not match unless its entire 32-bit value matches. For example, `0x00000103` is not selector 3.
