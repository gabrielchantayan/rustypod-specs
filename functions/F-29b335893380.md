# F-29b335893380

## Purpose

F-29b335893380 selects between two synchronous processing paths for a caller-supplied object:

- A direct path that passes the caller’s context, an object-resident 32-bit value, and an address within that object to F-df91cc54e996.
- An alternate path that passes a temporary 40-byte region through F-19de4dea6bf0, F-a0669252660e, and F-93092e17776d, in that order.

The selection depends on one or two calls to F-900e57cefc4b and, conditionally, on 32-bit fields within the object. An unmapped dependency is called before this selection begins; another unmapped dependency is called after either processing path completes normally.

This is a source-derived behavioral contract. The roles of the object fields, the temporary representation, and the two unmapped dependencies are not established. In particular, synchronization, initialization, destruction, and resource ownership are possible interpretations, not proven dependency contracts.

## Behavior

### Entry operation

The first observable call is to an unmapped dependency, receiving the address at object offset +36.

No object-field read by this function precedes that call. The dependency’s return value, if any, is not used.

If it returns normally, the function invokes F-900e57cefc4b with:

1. The object base.
2. The 32-bit constant `0x00040000`, decimal 262144.

The meaning of that constant is unknown. The function treats the dependency’s result only as zero or nonzero.

### Initial gate

The initial gate is satisfied in either of these cases:

- The first F-900e57cefc4b result is nonzero.
- That result is zero, and the unsigned 32-bit field at +24 is strictly less than the unsigned 32-bit field at +28.

The second condition is evaluated only if the first result is zero. Thus, a nonzero first result bypasses both comparison-field reads at this stage.

The comparison is unsigned. Values whose highest bit is set are treated as large nonnegative 32-bit values, not as negative numbers. Equality does not satisfy the strict comparison.

The source establishes that the comparison occurs after the first dependency call returns. It does not establish the relative order of the +24 and +28 reads within that comparison.

If the initial gate is not satisfied, the function proceeds directly to the alternate path. There is no second F-900e57cefc4b call in that case.

### Second query and direct-path decision

If the initial gate is satisfied, F-900e57cefc4b is called a second time with the same two argument values: the object base and `0x00040000`.

The two results are separate observations. The function does not reuse the first result and does not require the second result to match it.

The second result selects the remaining decision:

- **Second result zero:** select the direct path without reading either subtraction operand.
- **Second result nonzero:** read the 32-bit fields at +80 and +24, form their difference, and select:
  - The direct path if the difference is nonzero.
  - The alternate path if the difference is zero.

These subtraction operands are represented as signed 32-bit values in the supplied source. No wider intermediate is shown. The difference is not returned or forwarded; it is used only for a zero test.

Within the defined range of signed 32-bit subtraction, the zero test is equivalent to equality of the two field values. Unequal operands with a representable difference select the direct path. Equal operands select the alternate path.

For operands whose mathematical difference is outside the signed 32-bit range, portable arithmetic semantics are not established by the supplied representation. A wrapping 32-bit interpretation would still make the result zero exactly when the two operand bit patterns are equal. That interpretation must not be elevated to a proven target-independent guarantee.

The relative order of the +80 and +24 reads is not established. Both occur after the second dependency call returns, and only when that result is nonzero.

### Direct path

On the direct path, the function loads the 32-bit field at object offset +4 and calls F-df91cc54e996 with:

1. The original context value.
2. The value loaded from offset +4.
3. The address at object offset +8.

The field load occurs after the branch decision, including after any required second query and subtraction-field reads. It is not an entry-time snapshot.

After F-df91cc54e996 returns normally, the function calls the unmapped exit dependency with the address at object offset +36, then returns without a value.

The three temporary-region dependencies are not called on this path.

### Alternate path

On the alternate path, the function uses a local 40-byte region and makes these calls in order:

1. F-19de4dea6bf0 receives the region’s address.
2. F-a0669252660e receives the original context and that same region’s address.
3. F-93092e17776d receives that same region’s address.

The function performs no explicit initialization of the region before the first call. Any initialization needed by later calls must come from dependency behavior; it is not supplied directly by this function.

After the third call returns normally, the function calls the unmapped exit dependency with the address at object offset +36, then returns without a value.

F-df91cc54e996 is not called on this path. The function does not directly load the field at +4.

### State freshness and sequencing

Field reads use the state present when those reads occur. There is no object snapshot.

Consequently:

- The first query may affect fields used by the initial comparison.
- The second query may affect fields used by the subtraction.
- A +24 value used by the initial comparison need not equal the +24 value used later.
- The value at +4 may have changed before the direct-path load.

No dependency purity or state-preservation guarantee is assumed.

For normal execution, the entry dependency precedes every query and processing call. The exit dependency follows the selected processing sequence. The source establishes that control-flow ordering, but not a concurrency or memory-barrier contract.

## Acceptance examples

These are conditional static acceptance cases, not observed runtime results. Unless otherwise stated, every dependency returns normally and all required accesses are valid.

### Initial gate fails

Assume the first query returns zero and, when compared, the unsigned fields at +24 and +28 both contain 9.

Expected behavior:

- The initial comparison is false.
- There is exactly one query call.
- The alternate-path dependencies run in their specified order.
- There are no direct reads of +80 or +4.
- The exit dependency runs after F-93092e17776d.

### A nonzero first query bypasses the comparison

Assume the first query returns nonzero and the second returns zero.

Expected behavior:

- The initial +24/+28 comparison is skipped.
- The subtraction-field reads are skipped.
- The direct path is selected.
- F-df91cc54e996 receives the context, the then-current value at +4, and the address at +8.
- The exit dependency follows that call.

Thus, nonzero followed by zero does not select the alternate path.

### Unsigned comparison differs from signed comparison

Assume the first query returns zero, the compared +24 field is `0xFFFFFFFF`, and the +28 field is 1.

Expected behavior:

- The initial comparison is false because 4294967295 is not less than 1.
- There is no second query.
- The alternate path runs.

Treating the first value as signed −1 would select the wrong gate outcome.

### A successful comparison leads to a second observation

Assume the first query returns zero, the comparison observes 3 at +24 and 4 at +28, and the second query returns nonzero. After that second call, the subtraction reads observe 17 at both +80 and +24.

Expected behavior:

- The second query occurs.
- The subtraction result is zero.
- The alternate path runs.

The earlier observation of 3 at +24 does not constrain its later value.

### Unequal subtraction operands select the direct path

Assume the first query returns nonzero, the second query returns nonzero, and the subtraction reads observe 12 at +80 and 7 at +24.

Expected behavior:

- The initial comparison is skipped.
- The subtraction has the representable result 5.
- The direct path runs.

### Equal subtraction operands select the alternate path

Assume the initial gate is satisfied, the second query returns nonzero, and both subtraction operands are zero.

Expected behavior:

- The subtraction result is zero.
- The alternate path runs.
- No direct-path +4 load occurs.

### A processing dependency does not return normally

Assume the direct path is selected, but F-df91cc54e996 does not return normally.

Expected conclusion:

- The supplied body does not establish that the exit dependency executes.
- An unconditional cleanup guarantee is not an acceptable contract claim.
