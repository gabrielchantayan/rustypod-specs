## Acceptance examples

These are conditional arithmetic and ordering deductions, not executed tests.

1. **Initial destination boundary.** If the initial selector is 255 and the incoming byte is `0xa6`, the first direct write stores `0xa6` at address 272 before F-D001.

2. **Zero third argument.** A zero third argument makes the clearing selector read occur at address 1. The write clears address 17 only if that read yields zero.

3. **Shift wrapping.** Under the 32-bit interpretation, a first argument of `0x40000001` causes F-D001 to receive `0x00000004`.

4. **Pair layout.** If F-D023 produces low pair word 3 and high pair word 7, the next direct write stores zero at address 48, and F-D024 receives 7. This does not depend on memory byte order.

5. **Mask before extraction.** If low pair word is `0xffffffff`, the value written through second slot index is `0x000fffff`, because masking to 29 bits precedes the nine-bit right shift.

6. **Separate repeated reads.** If F-D044’s two reads observe different words, its first and third arguments derive from their respective observations. Their relative read order remains unspecified; a forced common snapshot is not justified.

7. **Different capture addresses.** If fourth node index is 1, the direct write before capture targets address 36 with value 4; the following read targets address 24. The captured word is therefore determined by address 24, not necessarily by that write.

8. **Final byte truncation.** If final payload is `0x3fffffff`, the first final byte write stores `0xfc` and the second stores `0xff`.

9. **Selector refresh.** If a dependency between the final selector reads changes the byte at their calculated source address, the second final write uses the newly read selector. It need not target the first final write’s destination.

10. **Conditional continuation.** If any dependency fails to return, subsequent direct events are not required to occur. No undoing of earlier writes is shown.
