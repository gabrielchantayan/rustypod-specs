The next accesses establish an important conditional invariant:

- The 32-bit word at the retained scaled base plus 0x14 is cleared.
- A byte is read at that same base plus 0x05.
- The small-base-plus-0x14 destination receives a 32-bit zero.
- The previously read byte is zero-extended and written as 32 bits at the retained scaled base plus 0x34.

Ordinary destination aliasing is therefore not a reason for this readback to be nonzero. A nonzero observation would require an additional unresolved condition, such as external mutation, nonordinary memory-mapping behavior, or executable arithmetic differing from the assumed address interpretation.

## Acceptance examples

These are conditional static criteria, not executed tests.

- **Argument preservation:** If F-U001 is reached, its displayed argument preserves all 32 bits of the first input.
- **Third-input truncation:** Under 32-bit bitvector semantics, third-input value 1 contributes 32 after shifting; bit pattern 0x08000000 contributes zero.
- **Unsigned byte promotion:** A byte observation of 0xFE used for an unsigned 32-bit store contributes 254, not a sign-extended negative value.
- **Small-base boundary:** A contributing result whose low seven bits are all set produces small quantity 508 and small base 1016.
- **Zero readback despite overlap:** With valid ordinary memory and no external mutation, overlap between the small-base zero store and the retained-scaled-base cleared word does not make the readback nonzero.
- **Disjoint byte-derived store:** Under the same conditions, even a byte sample of 0xFF written as 255 at retained-scaled-base-plus-0x34 leaves the cleared offset-0x14 readback zero.
- **Zero propagation:** Under those conditions, both initial small-base-plus-0x15 byte stores write zero, the readback-based 32-bit store targets 0x54, and the later snapshot-plus-0x54 write stores zero.
- **Fixed-0x05 ordering:** The fixed-0x05 snapshot is sampled after both duplicated byte stores and before the fixed-0x01 write.
- **Pre-store loaded base:** If its source overlaps the fixed store beginning at 0x60, later loaded-base accesses still use the value sampled before that store.
- **Snapshot preservation:** An adjusted-offset-0x04 snapshot of 0x12345678 remains the value written at loaded-base-plus-0x74 even if its source subsequently changes.
- **Fresh fixed-byte observations:** If an intervening computed write changes 0x67, a later explicit read supplying adjusted-base-plus-0x09 observes the changed byte.
- **Partial completion:** A nonreturning dependency prevents later effects from being required. A later failure does not imply restoration of earlier writes.
