## Behavior

### Preparation and dependency calls

The following ordering is established:

1. The fourth input is copied into a temporary four-byte slot.
2. F-238a2c37377e is called with the first input plus one.
3. Its returned address is retained as B.
4. One byte containing zero is written at B − 1.
5. The temporary four-byte slot is overwritten with zero.
6. F-1ce349eea4a0 is called with B as its first argument and the temporary slot’s address as its second argument.

8. The function returns B − 1.
