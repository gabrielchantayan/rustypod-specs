# F-3bcb17ec4705

## Purpose

F-3bcb17ec4705 conditionally retrieves a four-byte value from a fixed offset relative to an address-like input.

A zero input returns a four-byte zero without accessing memory through that input. A nonzero input causes one four-byte read beginning 2,968 bytes from the supplied base, and the value read becomes the return value.

This is a raw fixed-offset accessor. The supplied evidence does not establish the meaning of the retrieved value, the identity of the enclosing object, or whether the value represents a number, flags, a handle, or an address. A zero result is not a distinct error indication: it can mean either that the input was zero or that the accessed field contained zero.

## Behavior

When the input is zero:

1. The selected return value is four-byte zero.
2. No field read through the supplied input is performed.
3. The function returns that zero value.

This path does not attempt to access address `0xB98`. The displacement is relevant only to the nonzero path.
