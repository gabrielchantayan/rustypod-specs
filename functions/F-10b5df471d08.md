## Acceptance examples

These are conditional static expectations, not executed tests.

1. **Explicit argument duplication.** For explicit arguments 7 and 9, the first dependency receives 7, 9, and 9.

2. **Changed initial selector.** Suppose the incoming value is 0x3AB0005A. If the first selector read returns 200, the first byte store writes 0x5A at address 217. If intervening dependencies change the selector to 7, the second initial read returns 7 and the second store writes 0xAB at address 24. It does not reuse address 217.

3. **Unchanged initial selector.** If both initial reads return 200, both stores target address 217. Destination equality follows from equal observed selector values, not cached destination reuse.

4. **Selector boundaries.** Selector values 0 and 255 produce destinations 17 and 272, respectively.

5. **Truncation.** A ten-bit extracted field equal to 0x3AB produces byte 0xAB.

6. **Halfword addressing.** A shifted address component of 100 and retained byte value 3 produce halfword-read address 103, not 106. Completion depends on alignment and access permissions.

7. **Shared-state mutation.** If a dependency changes state word A after its clear, a later read captures the changed value. If another dependency changes it after that capture, a later access explicitly using the capture still uses the captured address component.

8. **Packed replacement.** If the terminal byte is 0xAB and the three-byte quantity evaluates to 0x123456, state word B receives 0x123456AB regardless of its former contents, assuming the preceding clear has not changed those inputs.

9. **Terminal failure.** If execution at address zero faults, the represented return is not reached. Earlier writes have no established rollback.
