## Behavior

### Common prefix

The third and fourth argument values are first copied into their respective local 32-bit cells. The entry dependency, D-01, is then called with 3.

After D-01 returns normally, the function reads the shared pointer slot and retains the resulting address as P. It then reads the slot again, obtaining R, and overwrites the byte at R + 11 with 1.

The initial write is an assignment. It does not preserve any bits of the byte previously stored at R + 11. It is not explicitly performed through P.

F-c252663d1c18 is then called with the address of the first local cell. Its recovered result is a 32-bit integer, compared against zero. All nonzero results select the same branch; no distinction between positive and negative values affects the visible control flow.

Changes made by D-01 to the shared pointer slot precede both pointer observations. Changes during or after those observations can affect their relationship. The supplied body does not establish an atomic snapshot of the pointer slot and the state object.

### Zero-result branch

When F-c252663d1c18 returns zero, all direct branch writes use the previously captured address P. Their order is:

| Order | Destination | Stored value |
|---:|---|---:|
| 1 | 16-bit field at P + 0 | 2000 |
| 2 | 16-bit field at P + 4 | 3 |
| 3 | Byte at P + 8 | 0 |
| 4 | Byte at P + 9 | 0 |
| 5 | Byte at P + 10 | 0 |
| 6 | Byte at P + 7 | 0 |
| 7 | Byte at P + 6 | 0 |

The byte-write order is deliberately not described as ascending address order. In particular, offset 7 is written before offset 6.

After these writes, the function reads the shared pointer slot a third time and calls F-a04c50db480a with the resulting address Q. It does not necessarily pass P or R.

Thus, the object receiving the fixed-value writes and the object passed to F-a04c50db480a can differ. A replacement of the shared pointer during F-c252663d1c18 does not redirect the direct branch writes away from P, but can change Q.

This branch performs no direct assignment to P + 11 after F-c252663d1c18. The earlier assignment of 1 targeted R + 11. Consequently, even without dependency mutation, the value at P + 11 is not necessarily 1 when P and R differ.

### Nonzero-result branch

For any nonzero result, the function first obtains the numeric low eight bits of the current fourth-argument local cell and stores them at P + 6.

It then selects the byte at representation offset 1 within that local cell and stores it at P + 7. These are post-dependency selections from local storage, not guaranteed selections from the original caller value.

The two selections have different definitions:

- The value written at P + 6 is the 32-bit cell narrowed to eight bits.
- The value written at P + 7 is the cell’s byte at representation offset 1.

On a little-endian 32-bit representation, these correspond to bits 0–7 and 8–15 respectively. The supplied evidence does not independently establish target endianness, so that equivalence is conditional.

After the two byte writes, the function reads the current byte at P + 11 and writes back that value with bit 1 set. All other bits from the value just read are preserved. The operation remains confined to one byte.

This is not an unconditional assignment of 3. For an eight-bit input, the result is 3 exactly when the byte read is either 1 or 3.

The initial assignment through R does not establish the byte later read through P unless the addresses coincide and intervening activity has not changed the byte. F-c252663d1c18 may also have modified that byte before this read.

F-a04c50db480a is not called on this branch. There is no third direct read of the shared pointer slot.

### Zero result with one stable object

### Little-endian byte selection

Suppose the fourth local cell contains 0x1234ABCD when selected, the representation is little-endian, and F-c252663d1c18 returns nonzero.

P + 6 receives 0xCD and P + 7 receives 0xAB. No fixed-value branch writes occur, and F-a04c50db480a is not called.

### Bit preservation

Suppose the byte read at P + 11 is 0xA0. The final direct write is 0xA2.

If that byte is 0x01 or 0x03 instead, the final direct write is 0x03 in either case. This distinguishes the operation from both an unconditional assignment and an operation that yields 3 only from an input of 1.

Suppose F-c252663d1c18 changes the shared pointer slot to a different valid address and returns zero.

The fixed-value writes still target captured P. F-a04c50db480a receives the address observed by the third read, Q. The initial byte assignment remains associated with the earlier R observation.
