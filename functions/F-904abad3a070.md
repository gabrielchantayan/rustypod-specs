# F-904abad3a070

The destination is selected by reading that global slot **after the preliminary dependency returns**. Consequently, a change the preliminary dependency makes to the slot can affect which destination is invoked. The dependency is not established to preserve that slot.

This is a structural description, not an established application-level purpose. The evidence does not identify the meaning of the four-byte result, the input byte, or the indirect destination.
