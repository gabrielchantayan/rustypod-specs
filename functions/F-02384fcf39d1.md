# F-02384fcf39d1

The established behavior is structural:

- Obtain a 32-bit value from F-c0a513a969e0 using the second input.
- Invoke F-8bb3020950cd on that same input.
- Pass two 32-bit object fields and the previously obtained value to F-aa672b15efb7.
- Store that dependency’s 32-bit result in the first object.
