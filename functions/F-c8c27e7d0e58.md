# F-c8c27e7d0e58

## Purpose

F-c8c27e7d0e58 exposes a partially recovered sequence of indirect calls with one intervening byte-memory update. The available static representation does not establish an application-level purpose.

On the represented path, the function attempts five indirect calls, reads one byte through an implicit address-bearing input, uses that byte to select a low memory address, writes a byte derived from another implicit input, and then attempts five further indirect calls. The sixth call receives a value derived from the fifth call’s result. The represented path ends at an invalid-instruction boundary rather than a recovered normal return.

This is a **documented_only** contract for the visible static evidence. It is not a claim that the represented instructions are valid, reachable, or executable as shown. In particular, the invalid-instruction warning materially limits conclusions about control flow and termination.

- Read one unsigned byte at displacement 1 from the implicit address-bearing base.
- Treat that byte’s numeric value as an address component.
- Add decimal 17, or hexadecimal 0x11, to obtain the destination address.
- Write one byte to that destination.

The destination is therefore a low address selected by a byte value. It is **not** represented as a displacement from the original read base, nor as a displacement from another recovered object pointer.

For every possible source byte, destination selection is exact:

- Source byte 0 selects address 0x11.
- Source byte 255 selects address 0x110.
