## Behavior

### Traversal and termination

Each invocation begins at position zero. The function does not obtain a starting position from the object and does not persist its traversal position there.

For the current position, it reads the leading word at offset `0x3C + 8 × position`.

If that word is zero, the function returns immediately:

- No helper call occurs for that position.
- No counter update occurs for that position.
- No later leading word is examined.
- The two address-valued fields are not read for that position.

Any nonzero leading-word value passes this test. No sign, range, flag, or additional entry-content check is shown.

After a nonzero position’s helper call returns, the internal position advances and the counter update occurs. Only after that update does the function decide whether another position is permitted. Consequently, the update associated with position seven occurs before the final return.

No leading word at position eight is read. A zero is not required within the first eight positions for normal termination.

### Helper arguments and read ordering

For each processed position, F-50772239ffa0 receives these arguments in positional order:

1. The address-valued word read from object offset `0x04`, increased by `0x10` bytes.
2. The address **B + `0x3C` + 8 × position**.
3. The address-valued word read from object offset `0x9C`, increased by **8 × position** bytes.

The second argument is an address into the supplied object, not a copy of the entry and not the value of its leading word.

The third argument is independently derived from the current word at offset `0x9C`. Its indexed displacement ranges from zero through `0x38` bytes. Neither the base nor the resulting address is shown to identify distinct storage.

Both address-valued fields are read for every helper invocation. Their values are not cached across the traversal. A helper’s changes to either field can therefore affect subsequent calls.

The leading-word read precedes the helper call. Both field reads used to form the arguments also precede that call. The supplied representation does not establish a relative evaluation order between those two field reads; the contract does not assign one.

No helper result is inspected or used.

This is an ordinary read-and-write update. No atomic operation, synchronization, or protection against concurrent modification is shown.

### Mutation during traversal

The sequence is not snapshotted.

If a helper changes a later leading word before it is examined, the later test uses the changed value. A newly written zero terminates processing there; a nonzero value permits processing.

Changing the current leading word during its helper call does not cause the caller to test that position again. After normal helper return, the caller updates the counter and proceeds toward the next position.
