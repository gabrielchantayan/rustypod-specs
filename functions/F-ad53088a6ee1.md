# F-ad53088a6ee1

The established behavior is limited to the supplied static representation:

- An incoming condition determines whether the two coprocessor operations are attempted.

## Behavior

1. The incoming zero condition is true; or
2. The incoming negative and overflow values differ.

They are skipped only when the incoming zero condition is false and the other two condition values compare equal.

| Zero | Negative | Overflow | Coprocessor sequence selected |
|---|---|---|---|
| False | False | False | No |
| False | False | True | Yes |
| False | True | False | Yes |

## Acceptance examples

These examples are conditional acceptance criteria derived from static evidence. They are not reports of executed tests.

### Zero condition selects the operations

Given a true incoming zero condition, the represented path selects both coprocessor operations regardless of the negative and overflow values.

If both operations complete normally, an acceptable observation is two ordered operation attempts followed by arrival at the termination boundary. A normal return is not established.

### Unequal conditions select the operations

Given a false zero condition and unequal negative and overflow values, the represented path selects the two operations.

For example, with normalized negative true and overflow false, omitting the first operation or merging both into one would fail to preserve the established sequence.

### Equal conditions skip the operations

Given a false zero condition and equal negative and overflow values, neither operation is selected.

This applies both when the normalized values are false and when both are true. Reaching the common termination boundary without either operation is consistent with the representation.

### Matching operand values remain opaque

Given an incoming four-byte value of zero, selection still depends only on the incoming conditions. Zero is not established as a special case, null pointer, or instruction-suppression value.

On the selected path, both data-operand positions in both operations receive that represented incoming value. The same relationship applies to any other four-byte bit pattern.

### An opaque operation prevents further progress

If the first completes but the second traps, the contract does not require rollback of the first operation’s effects.

These examples preserve control-flow ordering without inventing dependency behavior.
