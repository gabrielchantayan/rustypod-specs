## Behavior

### Selection rule

The function distinguishes two cases:

- **Sixth input is nonzero:** that input becomes the selected value. The default-value field is not read by this function.
- **Sixth input is zero:** the function reads one 32-bit value from the address obtained by adding 2472 bytes to the base. The loaded value becomes the selected value.

The fallback is performed once. If the loaded value is zero, zero is passed onward. There is no second fallback, retry, or visible rejection.

The selected value is not otherwise changed. In particular, there is no visible masking, clamping, sign-based filtering, or conversion into a Boolean.
