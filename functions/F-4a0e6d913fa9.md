# F-4a0e6d913fa9

## Purpose

F-4a0e6d913fa9 specifies an operation whose visible behavior consists of two unresolved calls, input-derived memory accesses, overlapping stores, global-state changes, and a terminal invalid-instruction boundary. No normal return is established.

No application-level purpose is established. The operation must not be characterized as allocation, record construction, interrupt setup, or device initialization solely from these effects.

This contract describes the supplied static representation. It does not establish that every represented operation is executable. The representation explicitly warns of overlapping global symbols and invalid instruction data.

A symbol mapped to F-8afdaab91693 is evaluated twice as a scalar expression. Whether either evaluation denotes an address or reads storage contents is unresolved. The two evaluations must remain distinct.

Another destination is formed from the address four bytes beyond that pointer, converted to signed 32 bits, shifted right by 32, and increased by 64. The shift prevents an unconditional numeric interpretation of this destination.

| Width | Stored value |
|---:|---|

## Acceptance examples

These are conditional static-contract examples, not executed tests. Each assumes execution reaches the relevant accesses and that required arithmetic and memory operations complete.

1. **Nonnegative first input.** With conventional signed shifts, the upper fragment is between zero and 127 and the small fragment is zero. The byte store at first-derived base plus 20 contains zero; the store at small fragment plus 60 targets address 60. Address validity is not implied.

2. **Negative first input.** With arithmetic right shifts, the first shift yields a value between −128 and −1. Its unsigned representation shifted logically by 18 yields 0x3fff. Using an unsigned interpretation for the original shift would change this behavior.

3. **Character widening.** An unsigned upper byte of 0xff can produce an intermediate 16-bit store of 0xffff under sign-extending character conversion, or 0x00ff under zero-extending conversion. The subsequent 32-bit overwrite does not remove this access.

4. **Adjusted negative third input.** With arithmetic shifts, a third input of −1 produces an adjusted value of −2. Both adjusted-value stores use −2, but their destinations are determined at different points.

5. **Zero loaded word.** A loaded word of zero produces a zero word-derived base. The operation includes stores at zero and 20, another store at zero through the mask-derived destination, and a subsequent read at zero. No visible null-address branch skips them.

6. **Unwritable second-call destination.** If the second dependency’s low result word designates unwritable memory, its immediate 16-bit store may fail. Later effects are not thereby established as completed.

7. **Distinct storage-backed symbol samples.** Suppose both symbol evaluations read overlapping storage, the first yields 3, and the intervening slot assignment changes that storage to 4. With defined arithmetic, the later base derived from the first sample is 24, while the second sample’s shifted stored value is 16. Replacing both samples with one cached value would change this behavior.

8. **Immutable-address interpretation.** If external evidence establishes that both symbol expressions denote the same immutable address, both samples may have that value. Their derived results still differ: the first is multiplied by eight for a memory base; the second is shifted left by two for stored data, subject to arithmetic rules.

9. **Mutable slot aliasing.** If the slot-based self-address store changes the global slot, the following adjusted-value store uses the changed slot. Reusing the originally assigned scaled base requires a non-aliasing guarantee.

10. **Overwritten component and terminal boundary.** If an intervening assignment changes the 16-bit component, the final composite uses its changed contents. If all accesses complete, the final assignment is followed by the reported invalid-instruction boundary, not an established successful return.
