# F-4c0261234a20

## Purpose

F-4c0261234a20 performs a two-dependency sequence around a masked transformation of a temporary 32-bit word.

It initializes that word from its fourth input, exposes the word by address to F-69829acf9af8, transforms the word after that dependency returns, and then invokes F-9be1212b18a7 using the original first input.

The transformation preserves only unselected bits from the low 16 bits of the word and obtains selected bits from the third input. Selected bits can include the upper 16 bits; the final word is therefore not necessarily limited to 16 bits.

The supplied evidence does **not** establish that the transformed word is committed to an external object. F-9be1212b18a7 receives no explicit word argument or word address. Any connection between the transformed temporary and an externally visible update depends on behavior of the dependencies that is not supplied.

## Behavior

### Ordered sequence

On the ordinary, normally returning path, the function performs the following operations in order:

1. It initializes its temporary word with all 32 bits of the fourth input.
2. It calls F-69829acf9af8 with the first input and the address of that temporary.
3. After that call returns, it reads the temporary’s then-current value and computes the masked transformation described below.
4. It writes the transformed value back to the same temporary storage.
5. It calls F-9be1212b18a7 with the first input.
6. After that call returns, it returns without a specified result.

There is one visible call to each dependency, in that order. There is no visible loop, retry, conditional skip, or alternate normal-return branch.

The transformation uses the temporary’s value **after** F-69829acf9af8 returns. It does not necessarily use the original fourth input: the dependency has been given an address through which it may change that word.

### Masked transformation

Let:

- \(W\) be the 32-bit temporary value after F-69829acf9af8 returns;
- \(M\) be the 32-bit selection mask;
- \(R\) be the 32-bit replacement input;
- \(T\) be the value written back to the temporary.

The established transformation is:

\[
T =
\bigl((W \mathbin{\&} \text{0x0000FFFF})
       \mathbin{\&} \neg_{32}M\bigr)
\mathbin{|}
(R \mathbin{\&} M)
\]

Here, \(\neg_{32}\) denotes bitwise complement over exactly 32 bits.

The bitwise contract is:

- For each bit position from 0 through 15:
  - If the corresponding mask bit is clear, the result retains that bit from \(W\).
  - If the corresponding mask bit is set, the result takes that bit from \(R\).
- For each bit position from 16 through 31:
  - If the corresponding mask bit is clear, the result bit is zero.
  - If the corresponding mask bit is set, the result takes that bit from \(R\).

Thus, the operation is not a general 32-bit masked replacement that preserves every unselected bit of the old word. Unselected upper-half bits are cleared.

It is also not an unconditional 16-bit truncation of the result. Upper-half bits selected by the mask can be introduced from the replacement input.

The two contributions cannot overlap at a bit position: the retained contribution requires a clear mask bit, while the replacement contribution requires a set mask bit. The operation uses bitwise operations only; there is no carry, borrow, arithmetic overflow, or signed comparison involved.

## Acceptance examples

These are conditional acceptance examples derived from the visible behavior, not executed tests. They assume the dependencies return normally and do not invalidate the invocation’s storage or execution state.

The stated word values describe the temporary immediately after its transformation. They do not assert that the caller receives those values.

### First dependency leaves the initial word unchanged

If the initial word is `0x89ABCDEF`, the mask is zero, and F-69829acf9af8 does not change the word, the transformed temporary is `0x0000CDEF`.

The upper half is cleared even though the mask selects no replacement bits. F-9be1212b18a7 is still called.

### First dependency changes the word

If the initial word is `0x11112222`, but F-69829acf9af8 leaves the temporary containing `0xDEADBEEF`, a zero mask produces `0x0000BEEF`.

Producing `0x00002222` instead would incorrectly ignore the first dependency’s write.

### Every bit is selected

With mask `0xFFFFFFFF`, the transformed temporary equals the replacement input exactly, regardless of the post-call word.

For replacement `0x87654321`, the transformed value is `0x87654321`.

### Only the lower half is selected

With mask `0x0000FFFF`, the transformed temporary equals the low 16 bits of the replacement input, with its upper half zero.

For replacement `0xABCDEF01`, the result is `0x0000EF01`.

### Only the upper half is selected

If the post-call word is `0x12345678`, the mask is `0xFFFF0000`, and the replacement input is `0x9ABCDEF0`, the transformed temporary is `0x9ABC5678`.

The lower half comes from the post-call word, while the upper half comes from the replacement input.

### Selection crosses both halves

If the post-call word is `0xA1B2C3D4`, the mask is `0x00FF00FF`, and the replacement input is `0x11223344`, the transformed temporary is `0x0022C344`.

This distinguishes the contract from both full-width preservation and unconditional truncation to 16 bits.

### The first dependency does not return

If F-69829acf9af8 does not return control, neither the subsequent transformation nor the call to F-9be1212b18a7 is reached through the visible sequence.
