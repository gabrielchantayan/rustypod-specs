# F-a917d321a439

If that target returns, the function performs further storage preparation and invokes F-cdec09f5d432. A return from that dependency leads to a path represented as non-returning.

### Transient argument-4 value

### Signed-halfword addressing

A relevant halfword containing `0xFFFF` contributes negative one after promotion, rather than 65,535. Its tripled contribution is therefore negative three where the arithmetic is representable.

This example establishes arithmetic interpretation, not validity of the resulting address.

### Conditional byte widening

For a loaded byte with bit pattern `0x80`, a halfword transfer derived from that byte can differ between signed-byte and unsigned-byte models: the corresponding patterns are `0xFF80` and `0x0080`.

Neither result is an unconditional requirement without an established plain-byte model.

### Narrowed address-bearing value

A halfword transfer derived by narrowing `0x1234ABCD` carries `0xABCD`, not the complete word. This says nothing about the order of the two stored bytes.

### Overlap and captured observations

If an earlier write overlaps a later read, that read is constrained by the reached memory state and applicable access semantics—not automatically by entry memory.

Likewise, when a word is captured before its location is overwritten with a doubled active-region value, later use of the captured word must not be replaced with use of the replacement merely because both involve the same original location.

### Missing byte definitions

### Dependency mutation and reachability
