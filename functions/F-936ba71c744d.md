### Termination test

- If that read yields zero, traversal ends immediately.
- If it yields any nonzero value, the function obtains the record’s three field values and invokes F-5a2305f408b6.

At a terminating record, the wrapper does not read the second or third field and does not call the dependency.

An empty sequence is therefore represented by a zero first integer at the initial pointer. This case still requires a valid readable first field; an invalid pointer is not an alternative empty-sequence representation.
