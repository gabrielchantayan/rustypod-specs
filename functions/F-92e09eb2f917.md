## Behavior

### Local rejection

The function first determines whether either of these conditions holds:

- The first input equals −1.
- The second input equals zero.

If either condition holds, the function returns −50 without invoking either dependency. If both hold, the result is still −50; the function exposes no distinction between the two rejection reasons.

These checks apply regardless of the fourth input. Selecting the alternate dependency does not bypass validation of the first and second inputs, even though those inputs are not explicitly passed to that dependency.

Only those exact values are rejected locally. A negative first input other than −1 is not rejected by this wrapper. A negative second input is likewise not rejected merely for being negative.
