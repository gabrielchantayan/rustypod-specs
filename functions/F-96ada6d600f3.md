# F-96ada6d600f3

## Purpose

F-96ada6d600f3 selects a numeric transformation using a byte in caller-supplied state, calls one of two dependencies, adds 128 to the dependency’s result, and bounds the biased result to the inclusive interval 0–65,536.

Two selector values choose multiplication-based transformations:

- Selector 1 extracts a 32-bit middle field from one signed 64-bit product.
- Selector 2 performs that extraction, squares the extracted value with signed interpretation, and extracts the same middle field again.

Every other stable selector value chooses a shifted difference and a different dependency.

**Inferred intent:** the multiplication paths resemble fixed-point operations with 16 fractional bits. The output adjustment resembles conversion into a bounded numeric domain. No particular unit, curve, or application meaning is established.

This contract describes static evidence and conditional arithmetic consequences. No runtime tests have been performed.

## Behavior

- Equality selects the single-product path.
- Otherwise, a second selector access is represented, this time testing against 2.
- Equality in the second test selects the squared-product path.
- Failure of both tests selects the shifted-difference path.

Under stable state, exactly one of these three paths is selected.

The two selector references do not establish two distinct physical memory transactions. Load combining, access volatility, and synchronization properties are unknown. ### Product extraction

The initial multiplication uses two signed 32-bit operands widened to signed 64-bit values. Their product fits in signed 64 bits. The largest possible nonnegative product is 2⁶².

The extraction retains product bits 16 through 47 inclusive as a 32-bit pattern:

- Bits 0–15 are discarded.
- Bits 48–63 are discarded.

### Common output adjustment

After the selected dependency returns, the function adds 128 to its signed 32-bit result.

It applies bounds to that biased value in this order:

1. A negative biased value produces 0.
2. Otherwise, a biased value greater than 65,536 produces 65,536.
3. Otherwise, the biased value is returned unchanged.
