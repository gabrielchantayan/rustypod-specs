## Behavior

The supplied body contains one dereference expression. There is no represented branch, loop, retry, fallback, validation step, or call to another function. There is also no represented arithmetic on the address or the retrieved value.

The behavior is therefore determined by two prerequisites:

1. The address reference must resolve to storage that can be read under the applicable execution environment.
2. The value obtained by that read must be representable or convertible according to the actual underlying types and return interface.

The first prerequisite is not checked by the represented function. The second cannot be fully specified because the referenced object’s type is absent.

### Observable read ordering

The dependency order is limited but clear: the referenced location must be determined before its contents can supply the return value, and that value must be obtained before normal return completes.
