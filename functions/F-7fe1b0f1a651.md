# F-7fe1b0f1a651

## Purpose

F-7fe1b0f1a651 is a non-returning control-transfer routine with a conditional 16-bit memory copy before an indefinite sequence of calls and software interrupts.

The supplied representation establishes no application-level purpose. Names such as “copy,” “entry state,” and “dispatch address” describe observable operations, not an inferred subsystem or data format.

Most of the apparent conditional processing cannot affect execution under the 32-bit arithmetic model described below. In particular, the later apparent record writes and signed-value processing are unreachable from the represented entry point. They must not be presented as unconditional functionality.

### Width and arithmetic model

The supplied representation supports the following working model:

- Addresses and general arithmetic operands are 32 bits.
- Unsigned address arithmetic wraps modulo \(2^{32}\).
- A halfword is 16 bits.
- Adding one to a halfword pointer advances its numerical address by two bytes.
- Right shifts of unsigned quantities are logical shifts.
- A 16-bit store retains the low 16 bits of its value.

Reachability conclusions in this contract are conditional on that model. The representation is not a portable language-level specification for pointer overflow, invalid addresses, or unrelated-pointer comparison.

For compactness, the behavior section uses descriptive mathematical labels:

- \(Q\): entry selector from r4.
- \(A\): entry source address from r10.
- \(D\): entry displacement from r9.
- \(E\): entry displacement from r11.
- \(L\): entry link-register address.
- \(S\): numerical address of the entry stack slot.
- \(X=(Q\times 2^{22})\bmod 2^{32}\).

These labels are explanatory notation, not implementation identifiers.

## Behavior

### Initial branch and conditional copy

The first decision tests whether \(X\) is zero. Under 32-bit wrapping arithmetic, this is equivalent to the low ten bits of \(Q\) being zero.

If \(X\) is nonzero:

- No pre-dispatch memory read or write is reached.
- The first dispatch base remains \(L\).
- Execution proceeds to the indefinite dispatch sequence.

If \(X\) is zero, one halfword copy occurs:

- The source is the 16-bit value at address \(A\).
- The destination address is \((A+D)\bmod 2^{32}\).
- The source is read before the destination is written.
- The same 16-bit value is stored at the destination.
- A secondary address is derived as \((A+D-E)\bmod 2^{32}\).

The displacement \(D\) is a byte displacement. It is not multiplied by the halfword size for this copy.

There is no null check, bounds check, alignment check, overlap check, or error return before the copy. A zero destination displacement therefore produces a read followed by a write to the same address. Overlapping or aliased storage is not excluded.

The secondary address is only an arithmetic value on the reachable paths; deriving it does not itself read memory at that address.

### Gates following the copy

After the copy, further pre-dispatch effects require all intervening gates to succeed. The first gate requires \(L=0\). A nonzero link-register address therefore ends this conditional processing without undoing the copy.

When \(X=0\), bit 8 of \(Q\) is also zero. This matters because the apparent carry input to the following address calculation is necessarily zero.

With \(L=0\), the next effective gate requires:

\[
S\mathbin{\text{logical-right-shift}}1=0.
\]

In the 32-bit model, this restricts \(S\) to zero or one.

Several intervening operations contain variable-shift syntax in the supplied representation. At every reachable evaluation of these operations, the value supplying the shift count is already zero. Their relevant behavior is consequently equality testing, not general variable-shift processing.

The remaining gates for the exceptional side-effect block require:

- The entry value in r8 equals \(D\).
- The secondary address \((A+D-E)\bmod 2^{32}\) equals \(E\).
- The entry value in r12 is zero.
- \((S+2D)\bmod 2^{32}=0\).

These requirements are cumulative. Failure of any one prevents the exceptional block and leaves the first dispatch base at \(L\).

The final address equation also clarifies the boundary conditions:

- \(S=1\) cannot satisfy it, because \(2D\) is even modulo \(2^{32}\).
- Consequently, the exceptional block requires \(S=0\).
- With \(S=0\), \(D\) must be either zero or 0x80000000.
- The secondary-address condition can equivalently be written as \(A+D=2E\), modulo \(2^{32}\).

A real execution environment may make a zero stack-slot address impossible or inaccessible. No such environmental guarantee is supplied here, so this path is retained as a conditional, documented-only behavior.

### Exceptional side-effect block

If every gate above succeeds, the representation performs two additional effects before dispatch:

1. It assigns \(64S\), modulo \(2^{32}\), to an unresolved special machine-state location.
2. It performs a halfword write whose destination and value are obtained from halfword reads through the link-register address.

At this point, the gates require both \(S=0\) and \(L=0\). Thus the special-state assignment has numerical value zero, and the halfword reads are through address zero.

The additional halfword operation has these operand relationships:

- One halfword read supplies a zero-extended destination address in the range 0 through 65535.
- A halfword read supplies the value to which 15 is added.
- The stored result is truncated to 16 bits.

The representation contains two read expressions at the same address. It does not establish their relative evaluation order. It also does not establish that an execution engine performs exactly two physical bus reads. For ordinary stable memory, both reads obtain the same halfword. That equality must not be assumed for memory-mapped devices or other read-sensitive storage.

Both operand values must be available before the dependent store occurs. There is no represented validation of the derived low-address destination.

The initial copy precedes this exceptional operation. If the initial destination aliases address zero, that earlier store can affect the halfword values subsequently observed.

### Why later apparent processing is unreachable

The exceptional block sets a halfword-based address value to two: the earlier shifted selector is zero, and advancing its halfword pointer by one produces numerical address two.

The next gated comparison first permits continuation through a zero result, but the following comparison combines that numerical value two with a value already constrained to zero. Its result is therefore nonzero.

That failed gate disables all subsequent conditional processing before dispatch. If the exceptional block was not reached, those later gates were never enabled in the first place.

Accordingly, the represented entry point does not reach the later apparent operations involving:

- Additional displacement increments.
- A pointer read through a signed-byte-derived address.
- A signed halfword load followed by paired pointer-sized stores.
- A later signed-halfword-derived pair of writes.

This is a static reachability conclusion, not evidence that those operations were exercised or that they belong to a meaningful record format.

### Indefinite dispatch sequence

All paths that reach the dispatch sequence use the original \(L\) as the first dispatch base. The exceptional path also has this property: its constraints force the apparent base adjustment to zero.

Each completed iteration has this order:

1. Call the address at a byte offset of 0xEB6 from the current dispatch base.
2. If that call returns, call fixed address 0x0857A94B.
3. If the second call returns, request software interrupt 0x5B.
4. If execution resumes after the interrupt, replace the dispatch base with 0x083D4CC2 and repeat.

The first call receives three represented 32-bit argument values:

- Zero.
- Zero.
- 0xFFFFFFA5.

The third value has signed interpretation −91 if the callee interprets it as a signed 32-bit integer. Its actual parameter type is unknown.

The first call target is the computed address itself. The representation does not show a memory load of a function pointer from that address.

From the second iteration onward, the first call target is therefore 0x083D5B78. The initial iteration instead targets \((L+0xEB6)\bmod 2^{32}\).

No explicit arguments are shown for the second call. This does not establish that it ignores incoming registers or other machine state. Neither call’s return value is consumed by the represented routine.

## Side effects

### Memory access ordering

The established pre-dispatch ordering is:

- When enabled, the initial source halfword read precedes its destination halfword write.
- That copy finishes before any exceptional-block memory operation.
- When enabled, the exceptional operation obtains its address and value operands before its halfword store.
- All such pre-dispatch effects precede the first call.

No rollback is represented. If an access or call faults after an earlier write, the earlier write has already occurred.

## Acceptance examples

These are conditional acceptance criteria derived from static analysis. No runtime tests have been performed.

### Selector bypasses the copy

Given a selector whose low ten bits are nonzero, such as one:

- No pre-dispatch data-memory access is required.
- The first call targets \(L+0xEB6\), modulo \(2^{32}\).
- Returning calls and a resuming interrupt lead to subsequent iterations using first-call target 0x083D5B78.

### Copy followed by ordinary dispatch

Given a selector whose low ten bits are zero, valid halfword storage at \(A\) and \(A+D\), and nonzero \(L\):

- Exactly the represented initial halfword copy is enabled before dispatch.
- Its destination uses the byte displacement \(D\).
- The deeper gated effects do not occur.

### Self-copy

Given the same copy-enabling selector and \(D=0\):

- The routine reads a halfword from \(A\), then writes that value back to \(A\).
- The operation is not omitted merely because source and destination coincide.

### Exceptional gates fail on stack-address parity

Given \(L=0\), \(S=1\), and otherwise matching comparison inputs:

- The exceptional block remains disabled for every 32-bit \(D\).
- The equation \(1+2D=0\) cannot hold modulo \(2^{32}\).

### Exceptional low-address write

Given a hypothetical environment permitting \(S=0\), \(L=0\), a copy-enabling selector, \(D=0\), matching r8, zero r12, and \(A=2E\) modulo \(2^{32}\):

- The exceptional block is enabled if all required accesses succeed.
- The unresolved special-state location receives numerical zero.
- If the halfword reads at address zero both yield 0xFFFF, the derived destination is 0x0000FFFF and the stored halfword is 0x000E.
- Later apparent record-processing writes remain unreachable.

### A non-returning first call

If the first call does not return:

- The fixed second call and the interrupt are not reached.
- Any completed pre-dispatch writes remain observable.
