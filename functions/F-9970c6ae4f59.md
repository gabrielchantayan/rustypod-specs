# F-9970c6ae4f59

## Purpose

F-9970c6ae4f59 conditionally invokes an operation associated with two locations derived from one caller-supplied base value.

Its established behavior is a two-path dispatch:

- Invoke F-ab290785cbcc with the location four bytes beyond the supplied base.
- If that dependency returns a nonzero result, return the 32-bit value 1 without invoking either remaining dependency.
- If that dependency returns zero, invoke F-8f6053ffecbf, then pass its result and two base-relative locations to F-793b94643d2e. Return the latter dependency’s 32-bit result.

The branch condition and forwarding behavior are established by the supplied static representation. Descriptions such as “validation,” “initialization,” “lookup,” or “resource acquisition” would assign meanings not established by that evidence.

## Behavior

### Nonzero-result path

If F-ab290785cbcc returns any nonzero result, F-9970c6ae4f59 returns the 32-bit value 1.

On this path:

- F-8f6053ffecbf is not invoked.
- F-793b94643d2e is not invoked.
- The specific nonzero result from F-ab290785cbcc is not forwarded.
- Any side effects already produced by F-ab290785cbcc remain subject to that dependency’s behavior; there is no visible rollback.

Under the represented signed 32-bit interpretation, negative results take this path just as positive nonzero results do. The condition is not a positive-value test.

### Zero-result path

The result of F-8f6053ffecbf is then supplied as the first argument to F-793b94643d2e. The full argument sequence for that invocation is:

| Position | Supplied value |
|---|---|
| First | The 32-bit result from F-8f6053ffecbf |
| Second | Second location: base plus 44 bytes |
| Third | Numeric zero |
| Fourth | First location: base plus 4 bytes |

F-9970c6ae4f59 returns the 32-bit result from F-793b94643d2e directly. It performs no visible subsequent dependency call, cleanup, retry, or result classification.
