## Behavior

### Ordered operations

1. Obtain the target storage value for the masking operation.
2. Form its bitwise intersection with 0x1000.
3. Assign that result back to the target storage.
4. Observe the target storage for the return comparison.
5. Return whether that observation differs from zero.

The return expression refers to the storage again. It is not represented as a comparison of a saved pre-write value or of the assignment result.

This distinction is observable if the storage changes between the assignment and the return comparison, or if the storage has nonordinary access semantics. It must therefore remain part of the behavioral contract rather than being simplified unconditionally to “return the original bit 12.”

### Masking effect

Under ordinary integer and writable-storage semantics, with a target capable of representing 0x1000:

- If bit 12 of the initially observed value is clear, the assigned value is zero.
- If bit 12 is set, the assigned value is 0x1000.
- Every other bit in the target value is cleared by the mask.
- The operation does not retain unrelated flags.

This is a destructive update even when the caller is interested only in the returned Boolean. Other information held in the same target value is discarded under those conditions.

There is no addition, subtraction, multiplication, division, shift, or address arithmetic in the represented operation. No arithmetic carry or borrow is involved.
