# F-a3ab0f0268b0

## Purpose

F-a3ab0f0268b0 prepares or reuses a destination descriptor, conditionally obtains replacement backing storage, and invokes a dependency to populate that storage from a source object. It returns the destination descriptor on the visible success path and a null pointer on either of two explicitly checked failures.

The established behavior includes a special treatment of a zero result from the population dependency: the function writes one zero byte into the destination buffer and records a count of one.

Interpreting the operation as a conversion or serialization is inferred intent. The source object’s representation, the meaning of its discriminator, and the units of the resulting count are not established by the supplied material.

## Interface

The function has four arguments:

1. **Source reference.** A value used as an address. The function directly reads a signed 32-bit field at byte offset 12 from this address and passes the source reference to two dependencies.
2. **Optional destination descriptor.** A pointer to a mutable descriptor, or null to request a descriptor from F-f9450f0778b9.
3. **Unused 32-bit argument.** The visible body neither reads this argument nor forwards it to a dependency.
4. **Opaque 32-bit growth argument.** Forwarded unchanged as the fifth argument to F-8b998a07b5e1, but only when the growth condition is satisfied.

The field names above describe uses, not independently established type semantics. In particular, the first field is used both for a pre-population size comparison and for recording the population result. It is not established that it is consistently a capacity field.

The backing-storage address is carried in a 32-bit descriptor field. The visible operations require an address model in which that field can represent the storage addresses used by the dependencies.

It returns null after either:

These return guarantees are conditional on the invoked dependencies returning normally. No exception, nonlocal-exit, or fault handling is visible.

## Behavior

### Descriptor selection

If a destination descriptor is supplied, the function uses it directly and makes no descriptor-request call.

If the destination argument is null, the function calls F-f9450f0778b9 with the single argument 2. A null result immediately selects the common failure path. A non-null result becomes the working descriptor.

The argument 2 is established. Its interpretation as an allocation size, object kind, or another selector is unknown.

### Early descriptor classification

After selecting a non-null descriptor, the function reads a 32-bit global value. It then reads the source field at offset 12.

- If that source field is zero, the value selected for the descriptor’s field at offset 4 is 2.
- Otherwise, the selected value is the previously read global value.

The selected value is written to descriptor offset 4 before the measurement dependency is called.

The global read occurs even when the source field is zero and the global value will not be used. Consequently, the source-field test does not eliminate that earlier read.

No rollback of the descriptor’s offset-4 write is visible on a later growth failure.

### Measurement and threshold calculation

The function calls F-ae3bc1bfd2a8 with the source reference. Its return is represented as a 64-bit quantity, but only its low 32 bits influence subsequent visible behavior. The high 32 bits do not affect the threshold.

Interpret the low 32 bits as a signed integer \(m\). The comparison threshold \(t\) is:

- \(t = 4\), when \(m = 0\).
- \(t = \operatorname{trunc}(m/8) + 5\), when \(m \ne 0\), with division truncated toward zero.

This description captures the signed adjustment and right-shift arithmetic in the supplied representation. It must not be replaced by unsigned division or by floor division for negative values.

For every signed 32-bit \(m\), the calculation stays within signed 32-bit range. The possible threshold range is from −268,435,451 through 268,435,460.

Zero is a special case: a measurement of zero produces threshold 4, while measurements from 1 through 7 produce threshold 5. Negative measurements are not rejected.

### Conditional backing-storage growth

After measurement returns, the function reads the descriptor’s field at offset 0 and performs a signed comparison against \(t\).

If that field is greater than or equal to \(t\), it skips the growth dependency and proceeds to population.

If it is less than \(t\), the function calls F-8b998a07b5e1 with:

1. The backing-storage address read from descriptor offset 8.
2. The calculated threshold \(t\).
3. Zero.
4. Zero.
5. The fourth argument supplied to F-a3ab0f0268b0.

A zero return selects the common failure path.

A nonzero return is written to descriptor offset 8 as the new backing-storage address. The function does not separately update descriptor offset 0 to the requested threshold.

The visible body does not establish whether the growth dependency preserves, releases, moves, or copies the old storage. Nor does it establish the state of the old storage after a zero return.

### Population and zero-result normalization

The function reads the descriptor’s backing-storage address and calls F-29c531f09e4a with the source reference and that address.

The returned 32-bit value is written to descriptor offset 0.

If the result is nonzero, the function returns the descriptor without an additional direct buffer write. This includes negative results: the function does not distinguish a negative value from another nonzero value.

If the result is zero:

1. The function writes zero to descriptor offset 0 as the initial result assignment.
2. It reads the backing-storage address from descriptor offset 8.
3. It writes a single zero byte to that address.
4. It writes one to descriptor offset 0.
5. It returns the descriptor.

The buffer address used for the zero-byte write is therefore read after the population call and after the initial count write. It is not necessarily identical to the address previously passed to F-29c531f09e4a if shared state or aliasing permits intervening changes.

There is no visible requirement that a nonzero population result fit the previously calculated threshold, and there is no post-population growth or bounds check.

### Common failure path

The function calls F-4fc89ec41a6d with arguments 13 and 139.

After that call returns, it compares the working descriptor pointer with the original destination argument:

- If they differ, it calls F-6c81b0b12feb with the working descriptor.
- If they are equal, it makes no release call.

It then returns null.

For an unsuccessful descriptor request, both pointers are null, so no release call is made.

For a growth failure using a caller-supplied descriptor, both pointers are equal, so the descriptor is not passed to the release dependency.

For a growth failure after successful descriptor acquisition, the working pointer is non-null and the original destination argument is null, so the working descriptor is passed to the release dependency.

This cleanup rule is pointer-identity based. It does not prove what resources the release dependency actually releases.

It also invokes dependencies that may have additional side effects. No preservation of global state, descriptor contents, source contents, or backing storage is established for those dependencies.

- The global read precedes the source-field read.
