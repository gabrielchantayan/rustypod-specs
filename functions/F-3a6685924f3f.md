# F-3a6685924f3f

## Purpose

F-3a6685924f3f resolves a signed 16-bit result from a descriptor and an associated object, returning it as a signed 32-bit integer.

Resolution is ordered. Object lookup and an object/global comparison precede the descriptor’s explicit value. If neither supplies an early result, two control inputs determine whether to consult an indirect method, an object-resident fallback value, or both.

The distinguished signed 16-bit value −1 means “unavailable” in several paths, but its treatment depends on where it is encountered:

- In the descriptor, −1 selects further resolution.
- From a method called with the nonzero fourth input, −1 selects a retry or fallback.
- From the zero-argument method call or object fallback, −1 becomes a return value of zero.

**Inferred intent:** this is a precedence-based value resolver with an optional context-specific method lookup. The semantic meaning of the result, descriptor, object, and control inputs is not established.

## Behavior

### 1. Resolve the object before considering the explicit result

The function reads the descriptor’s 32-bit value at +4 and invokes F-23c46a4f09c5 with:

1. The lookup context.
2. The value read from descriptor offset +4.
3. A 32-bit zero.

This call occurs on every path, including paths that ultimately return the descriptor’s explicit result.

If lookup yields null, F-a817d8d58c10 is invoked. The supplied representation marks this invocation as non-returning. Consequently, the descriptor’s explicit result does not provide an escape from null lookup.

If lookup yields a non-null address, that returned address is the resolved object used by the remaining logic.

### 2. Apply the object/global short circuit

The function compares the object’s 32-bit field at +76 with a global 32-bit value.

If equal, it immediately returns zero. This takes precedence over:

- The descriptor’s explicit result.
- Both control inputs.
- The indirect method.
- The object fallback.

The global value’s meaning and numeric contents are unknown. Equality is established; no ordering or signed comparison is involved.

Lookup occurs before this comparison. The contract therefore does not assume that the comparison uses global state as it existed before lookup.

The representation does not establish which of the two comparison operands is physically read first.

### 3. Apply the descriptor’s explicit result

If the comparison does not return zero, the descriptor’s +14 field is interpreted as a signed 16-bit value.

If its tested value is not −1, the function returns the signed 16-bit descriptor value, extended to signed 32 bits. Neither the indirect method nor the object fallback is used.

The supplied expression contains a test read and a return expression referring to the same field. With stable storage, the value tested is the value returned. Exact machine-level load count and behavior under concurrent mutation are not established. In particular, the source alone is insufficient to promise one atomic read or a snapshot spanning both expressions.

If the tested descriptor value is −1, resolution continues below.

### 4. Resolve an unspecified descriptor value

With the explicit descriptor value equal to −1, the two controls select the following behavior:

| Method argument | Selection control | Method activity | Final candidate |
|---|---|---|---|
| Zero | Zero | Call the method with argument zero. | That method result. |
| Zero | Nonzero | No method call. | Object fallback. |
| Nonzero | Zero | Call the method with the supplied argument. If its narrowed result is −1, call again with zero. | First result if not −1; otherwise second result. |
| Nonzero | Nonzero | Call the method once with the supplied argument. | Object fallback, regardless of the method result. |

Every method invocation uses the resolved object as its first argument.

A method result is assigned to signed 16-bit storage before testing or return. Thus, where the underlying method returns a wider integer, only its low 16 bits affect this function’s result selection. The method’s declared return type and ABI are not otherwise supplied.

#### Zero method argument, zero selection control

The method is invoked once with a second argument of zero. Its signed 16-bit result is the final candidate.

A candidate of −1 becomes zero. Every other signed 16-bit candidate is returned with sign extension.

#### Zero method argument, nonzero selection control

The method is not invoked.

The function reads the object’s 32-bit field at +44 and narrows it to signed 16 bits. A narrowed value of −1 becomes zero; otherwise that narrowed value is returned with sign extension.

#### Nonzero method argument, zero selection control

The method is first invoked with the supplied nonzero argument.

If its signed 16-bit result is not −1, that result is returned immediately. There is no zero-argument retry and no fallback-field read.

If that result is −1, the method is invoked again with a second argument of zero. The second result is narrowed to signed 16 bits. A second result of −1 becomes zero; otherwise the second result is returned with sign extension.

There are at most two indirect method calls.

#### Nonzero method argument, nonzero selection control

The method is invoked once with the supplied nonzero argument.

Its result does not supply the returned value. Whether the narrowed result is −1 or any other value, execution reaches the object fallback. There is no zero-argument retry.

The fallback read occurs after the method returns. Accordingly, a method mutation of the object’s +44 field can affect the returned result. This call must not be omitted merely because its numeric result is discarded.

### 5. Narrow and normalize the fallback

The fallback source is a 32-bit object field, not a 16-bit field. The function reads it as 32 bits and then retains its low 16 bits as a signed value.

Examples of this conversion:

- Low 16 bits of 0x7FFF represent 32767.
- Low 16 bits of 0x8000 represent −32768.
- Low 16 bits of 0xFFFE represent −2.
- Low 16 bits of 0xFFFF represent −1 and therefore produce zero.

Upper 16 bits do not influence the returned numeric value after narrowing. They remain part of the represented 32-bit read.
