# F-3d96cf963d99

## Purpose

F-3d96cf963d99 consumes one 32-bit value through a cursor stored in a caller-supplied state object, passes that value to a dependency, and selects one of two state-update paths through another dependency.

Both paths expose a four-word temporary record to a dependency, then copy its resulting contents into the state object. The nonzero-selection path additionally mirrors those four state words into an earlier region of the object and performs a second three-argument dependency call.

The returned 64-bit value contains the first two words of the temporary record, not necessarily the values originally supplied by the caller.

This is the established structural behavior. An interpretation involving a stack, saved execution context, or interpreter state is plausible but unconfirmed. Those interpretations are not required by this contract.

## Interface

### Inputs

The function accepts four arguments:

1. A pointer to a writable state object represented as 32-bit words.
2. A 32-bit integer.
3. A 32-bit integer.
4. A 32-bit integer.

The state pointer is also stored as a 32-bit value in a temporary record. The supplied representation therefore establishes a 32-bit pointer model for the operations described here. Porting this behavior to a wider-pointer environment requires an explicit address-representation decision; silently truncating wider pointers is not an established contract.

The following state-object layout is observable:

| Byte offset | Width | Role in this function |
|---|---:|---|
| 0–12 | Four 32-bit words | Written only on the nonzero-selection path, as a mirror of the words at offsets 16–28 |
| 16–28 | Four 32-bit words | Replaced from the temporary record on both paths |
| 28 | 32 bits | Initially interpreted as an address-sized cursor; subsequently overwritten from the fourth temporary word |
| 36 | 32 bits | First argument of the final dependency call on the nonzero-selection path |
| 40 | 32 bits | Second argument of that final dependency call |

Offset 32 has no explicit access in the supplied body.

The initial cursor at offset 28 points to a 32-bit word. The function also computes the address one word before that cursor. On the zero-selection path, it later reads a 32-bit integer through the cursor value then present at offset 28.

These are distinct accesses: the first reads through the original cursor, while the later read uses the current state field after intervening dependency calls.

### Temporary record

The function creates a contiguous, four-word temporary record with this initial layout:

| Record byte offset | Width | Initial contents |
|---|---:|---|
| 0 | 32 bits | State-pointer representation |
| 4 | 32 bits | Second function argument |
| 8 | 32 bits | Third function argument |
| 12 | 32 bits | Fourth function argument |

A dependency receives the address of this record. Its contents after that call determine the state update and return value.

The record is temporary storage belonging to this invocation. No ownership transfer or permission to retain its address beyond the invocation is established.

### Output

On either normally completing path, the function returns a 64-bit bit pattern composed as follows:

- Bits 0–31: the first temporary word.
- Bits 32–63: the second temporary word.

This is word concatenation, not a signed numerical conversion of the first word. In particular, a first word with its high bit set does not sign-extend into the upper half of the result.

The temporary record may have been modified by the dependency that receives it. Consequently, neither half of the return value is guaranteed to equal its initial contents.

### Preconditions and failure surface

Normal completion requires all performed memory accesses and dependency calls to be valid. Relevant conditions include:

- The state pointer identifies suitably aligned, accessible storage for the fields used on the selected path.
- The original cursor identifies a readable 32-bit word.
- The cursor decrement has a meaningful representation in the execution environment.
- On the zero-selection path, the cursor present after the intervening calls identifies a readable 32-bit integer.
- Dependencies accept the supplied argument forms and complete normally.

There are no explicit null checks, bounds checks, error returns, exception handlers, or rollback actions. Behavior after an invalid access, arithmetic violation, or abnormal dependency exit is not established.

## Behavior

### Initial cursor operation

Before making any dependency call, the function:

1. Reads the cursor field at state offset 28.
2. Writes that field with an address four bytes lower than the captured cursor.
3. Reads one 32-bit value through the captured original cursor.

The write therefore precedes the pointed-to read. This ordering matters if the pointed-to word aliases the cursor field itself: the subsequent read observes the preceding write, subject to the execution environment’s memory rules.

The operation does not read the word at the decremented cursor during this initial phase.

After obtaining the value, the function initializes the four-word temporary record described above.

### Initial dependency sequence and selection

The next calls occur in this order:

1. F-a2ee2ea15a51 is called without explicit arguments. Its 32-bit result is retained.
2. F-ff1bdc376dcd is called with:
   - The word read through the original cursor.
   - The retained result.

3. F-83d59a117d49 is called with the state pointer.

The return value of F-ff1bdc376dcd is not used by this function. Its effects, if any, are not thereby excluded.

The 32-bit result from F-83d59a117d49 selects the remaining path:

- Any nonzero result takes the nonzero-selection path.
- Exactly zero takes the zero-selection path.

Negative values, when interpreted as signed, are nonzero and therefore select the first path.

No guarantee is available that these dependencies preserve the state object, global state, or memory reachable through either. Subsequent state reads must therefore be understood as reads of the then-current contents.

### Nonzero-selection path

The function calls F-f1741872dc8d with three explicit arguments:

- The address of the temporary record.
- Zero.
- Zero.

After that call completes, the function copies the four temporary words into state offsets 16, 20, 24, and 28, in that order.

It then mirrors these state fields into the beginning of the state object:

1. The word at offset 16 is read and written to offset 0.
2. The word at offset 20 is read and written to offset 4.
3. The word at offset 24 is read and written to offset 8.
4. The word at offset 28 is read and written to offset 12.

The mirror is expressed as reads from the newly updated state fields, rather than a second direct copy from the temporary record.

The function next reads state offsets 36 and 40 and calls F-ff1bdc376dcd with those two values and a third argument of zero. The source establishes no ordering between the two argument-field reads. Both occur for this final call, after the explicit state-copy and mirror operations.

The final dependency’s return value is ignored. Its possible mutations are not undone.

The function then returns the concatenation of the first two temporary words. It does not reconstruct the return value from the state object after the final dependency call.

### Zero-selection path

The function calls F-a2ee2ea15a51 a second time, without explicit arguments. For this use, its 32-bit result is treated as an integer.

After that call, the function obtains a 32-bit integer by reading through the cursor then stored at state offset 28. The initial decrement does not prove that this is still the decremented original cursor: the preceding dependencies may have changed the state field.

The function forms a second argument from:

- The pointed-to 32-bit integer, plus
- Four times the second result of F-a2ee2ea15a51.

The multiplication is integer arithmetic. It is not, in this expression, a typed-pointer increment.

F-f1741872dc8d is then called with the temporary-record address and this computed argument. Only two explicit arguments are present in the supplied representation of this call. A third zero argument must not be assumed.

After that call completes, the four temporary words are copied into state offsets 16, 20, 24, and 28, in that order.

This path performs no explicit mirror writes to offsets 0–12 and no final call to F-ff1bdc376dcd. Dependencies may nevertheless have modified those fields or produced other effects.

The function returns the concatenation of the first two temporary words.

## Side effects

### Explicit memory effects

The function explicitly writes:

- State offset 28 before its initial pointed-to read.
- All four temporary words during initialization.
- State offsets 16–28 after F-f1741872dc8d returns.
- State offsets 0–12 additionally on the nonzero-selection path.

The temporary-record dependency can affect the values subsequently copied and returned. No restriction to only its first two words is established.

The final value at offset 28 is not necessarily the decremented cursor. Both paths overwrite it with the fourth temporary word. If that word remains unchanged throughout the dependency call, offset 28 receives the fourth function argument.

### Dependency-visible state

The initial cursor update is visible before any dependency is invoked.

On the nonzero-selection path, the final F-ff1bdc376dcd call occurs after both state-copy stages. Its argument fields are read at that late point, not captured at function entry.

Dependencies may mutate globals or reachable memory. This function provides no isolation or restoration guarantee for such effects.

### Ownership and lifetime

Passing the consumed word or state fields to a dependency does not establish whether they represent handles, pointers, ordinary integers, or owned resources. Likewise, passing the temporary-record address does not establish that the callee owns or releases that storage.

No concurrency, reentrancy, or atomicity guarantee is established. The ordered writes are separate operations rather than a transactional state replacement.
