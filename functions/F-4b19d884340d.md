# F-4b19d884340d

The represented behavior includes extracting fields from 32-bit values, deriving addresses by scaling or shifting values, copying captured words, and using unsigned bytes to select low-address write destinations. These operations do not establish a particular domain interpretation, such as serialization, allocation, reference counting, or device configuration.

This contract distinguishes:

- **Established static evidence:** access widths, explicit data relationships, and ordering represented in the supplied material.

## Behavior

### Arithmetic requirements

Unsigned right shifts are logical. Masks, shifts, scaling, and narrowing are distinct operations.

For apparent 32-bit machine calculations, arithmetic descriptions below retain the low 32 bits where needed. This does not establish portable signed-overflow semantics for every expression in the representation.

Relevant consequences include:

- Left shift by two followed by a byte store retains original bits 0–5 in output bits 2–7.
- A 29-bit mask followed by right shift by nineteen produces ten bits before byte truncation.
- A 30-bit mask followed by right shift by twenty likewise produces ten bits before byte truncation.
- Unsigned right shift by twenty-two produces ten bits before byte truncation.
- A 22-bit mask followed by right shift by twelve produces ten bits.
- A 30-bit mask followed by right shift by ten produces twenty bits.
- Left shift by twenty-eight retains only the original low four bits in a 32-bit result.
- Extracting a paired result starting at bit fifty-four is equivalent to shifting its high half right by twenty-two before narrowing.

Address calculations and value calculations must remain distinct even when both use multiplication by four. Equal-looking scales do not establish equal addresses.

8. **Fixed-byte arguments.** If the two fixed-byte argument expressions observe `0x20` and `0x30` in their respective positions, the dependency receives those values separately. The contract assigns no temporal order to those observations.

9. **Fixed-byte reload.** If a fixed-byte observation selects `0x31`, but intervening calls change address `0x01` to `0x30`, a later explicit reload selects `0x41`.
