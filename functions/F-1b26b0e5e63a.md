These are conditional static examples, not executed tests.

1. **Terminal zero address.** If the relevant final 64-bit result has bits 52–63 all clear, and intervening operations complete, the store address is zero. No null-address rejection is represented.

2. **Terminal odd address.** If those bits encode 1, the store address is 1. The operation remains a 16-bit store; no alignment adjustment is represented.

3. **Terminal address scaling.** If those bits encode 4, the address is 5. If they encode 4095, the address is 5118.

4. **Irrelevant terminal bits.** Changing only bits 0–51 of that final result does not change the derived store address. Such a change may still affect other call arguments or dependency behavior.
