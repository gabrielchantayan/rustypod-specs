# F-8d47b7092597

## Purpose

F-8d47b7092597 performs an indirect operation through a dispatch structure associated with its first input. It supplies that operation with an addressable four-byte copy of its second input, an additional dispatch-derived value, its fourth input, and a repeated reference to its first input.

The first indirect operation produces a result. If that result is anything other than signed negative one, F-8d47b7092597 performs a second indirect operation using the first input and that result. On normal completion, it returns the first operation’s result unchanged.

The established behavior is conditional dispatch, not a demonstrated allocation, lookup, registration, or release protocol. Those higher-level interpretations are not established by the supplied evidence.
