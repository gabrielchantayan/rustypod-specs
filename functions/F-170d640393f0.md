### First destination-selection read and byte write

1. Read one unsigned byte from the address one byte beyond the ambient address-bearing value.
2. Interpret that byte as an unsigned destination selector in the range 0 through 255.
3. Add 17 to obtain the numerical destination address.
4. Write one byte to that destination.

The written byte is obtained by logically shifting the ambient unsigned 32-bit value right by 22 bits and retaining the low eight bits of the shifted result.

Consequently, the stored byte corresponds to original bit positions 22 through 29. Original bits 30 and 31 do not affect the stored byte, despite surviving the initial right shift.

The intermediate conversion is represented through a character-sized value. Its signed interpretation is not established, but the intended one-byte bit pattern is the low eight bits described above.

The destination-selection byte is used as an integer address component, not as a pointer-sized value loaded from memory. The resulting numerical destination lies between 17 and 272 inclusive.
