### Transformation under the 32-bit interpretation

Describe the dependency result as four 8-bit groups ordered from most significant to least significant. The output contains those same groups in the opposite order.

The bit-position mapping is:

| Input bit positions | Output bit positions |
|---|---|
| 0–7 | 24–31 |
| 8–15 | 16–23 |
| 16–23 | 8–15 |
| 24–31 | 0–7 |

Within each row, relative bit positions are preserved. Input bit 0 becomes output bit 24; input bit 7 becomes output bit 31. This is group-order reversal, not reversal of all 32 individual bits.

The middle groups are selected with masks before being moved. The outer groups are selected by the effects of shifting within the 32-bit unsigned width. Left-shifted bits beyond that width do not appear in the result, and unsigned right shifts introduce zeros.

The transformed groups are combined with bitwise OR. Under the 32-bit interpretation, they occupy disjoint output positions, so combination does not introduce arithmetic carries or alter the individual groups.

There is no conditional branch based on the returned value. Zero, the maximum unsigned value, and values with the most significant bit set all pass through the same transformation.
