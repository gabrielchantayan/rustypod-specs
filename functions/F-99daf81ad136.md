# F-99daf81ad136

## Purpose

The established behavior is a narrow dispatch operation:

- Forward the first input unchanged as the first dependency argument.
- Use a value obtained from the primary storage location when the second input is zero.

## Behavior

4. Invoke the dependency using the resulting selected value.
