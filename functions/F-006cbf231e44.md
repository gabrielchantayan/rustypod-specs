# F-006cbf231e44

## Purpose

F-006cbf231e44 coordinates an initial object operation, a lookup or eligibility decision, and an optional secondary-object processing sequence. Every explicitly shown control-flow path ends by invoking a dependency marked as non-returning. No normal return value or ordinary return path is established.

The behavior has two terminal outcomes:

- A general terminal action follows a rejected lookup result or the absence of a secondary object.
- A distinct terminal action follows two operations on a nonzero secondary-object value.

These descriptions distinguish control flow, not application meaning. The available evidence does not establish whether either terminal action exits a thread, transfers control, raises an exception, terminates a process, or performs another non-returning operation.

## Behavior

The function reads the object's dispatch-table pointer and selects the callable entry at table offset 0x130. It invokes that operation with the object as receiver and the third explicit input as the other displayed argument.

This invocation is unconditional: it precedes the lookup decision and occurs even when that later decision rejects the request.

The invocation's return value is not used by this function. Its side effects are not known. In particular, the evidence does not establish that it preserves the object, the object's dispatch table, the byte at offset 0x11d, or any global state.

If this dependency does not return normally, the later steps are not reached.

### 2. Read the selector byte and obtain a decision

After the initial dynamic operation returns, the function reads one byte at object offset 0x11d.

It calls F-058144d59a45 with:

- The first explicit input.
- The byte just read.

The access is byte-wide. The available representation does not establish whether the callee interprets that byte as signed or unsigned after argument promotion, or what the byte denotes.

The result is treated as a 32-bit integer and compared with −1, whose 32-bit representation is 0xffffffff.

- If the result equals −1, the function skips all secondary-path work and invokes F-a817d8d58c10.
- Every other result enters the secondary path.

This is an exact sentinel test, not a positive-value or nonzero test. Zero and negative values other than −1 enter the secondary path.

The result's magnitude is not otherwise used. It is not forwarded to a later dependency.

### 3. Perform the secondary dynamic operation
