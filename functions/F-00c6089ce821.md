# F-00c6089ce821

## Purpose

When the controlling field is nonzero, the function returns the 32-bit value 4 without invoking either identified dependency. When the field is zero, the function captures the record’s first 32-bit word, obtains a value through a dynamically selected operation, and passes that value by address to F-dece790ddc92. If that sequence returns normally, this function returns the 32-bit value 0.

This is an established structural description, not an interpretation of the application protocol. The meanings of the controlling field, the constants supplied to dependencies, and the generated value are not established. In particular, 0 and 4 must not be described as application-level success and failure without additional evidence.

## Behavior

### Initial branch

The function first reads the 16-bit field at byte offset 12 of the record and compares it with zero.

Although the field is represented as signed, the only test is equality with zero. Positive and negative nonzero values therefore select the same path.

For a nonzero value:

- The first 32-bit word of the record is not read by this function.
- Neither identified dependency is called.
- No indirect operation is invoked.
- The function returns 4.

The return value is not the field’s value or an encoding derived from its magnitude.

### Zero-field path

For a zero value, the visible sequence is ordered as follows:

1. The function reads and captures the 32-bit word at byte offset 0 of the record.
2. It initializes a local 32-bit slot with the fourth argument.
3. It calls F-b7af80e829ec with the numeric argument 4.
4. It reads the first 32-bit word at the address returned by that dependency.
5. It uses that word as the address of a dispatch structure and selects the callable entry at byte offset 80.
6. It invokes that entry. The supplied representation shows no explicit arguments for this invocation.
7. It stores the indirect operation’s result in the local 32-bit slot, replacing the earlier value.
8. It calls F-dece790ddc92 with seven ordered arguments.
9. If that call returns normally, it returns 0.

The arguments to F-dece790ddc92 are:

| Position | Supplied value |
| --- | --- |
| 1 | The original record address |
| 2 | The 32-bit record word captured before the other dependency calls |
| 3 | Numeric zero |

### Captured values and intervening changes

The record word passed in position 2 is captured before F-b7af80e829ec and the indirect operation execute. There is no visible reread before the final call. Consequently, if an intervening dependency changes the record’s first word, the second argument remains the earlier captured value, while the first argument still identifies the original record storage.

The controlling field is also read only once in the visible body. A later change to that field does not cause the function to revisit the initial branch.

These observations do not imply that dependencies preserve the record or any global state. They identify which values this function captures and which address it later forwards.
