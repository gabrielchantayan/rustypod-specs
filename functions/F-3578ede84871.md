# F-3578ede84871

## Purpose

F-3578ede84871 performs ordered, conditional dispatch for a context and an object. It can invoke a preliminary dependency, one of two primary callbacks, and a final callback. Any nonzero result from a result-producing stage terminates processing and is returned unchanged.

The established behavior is dispatch and result propagation. The meanings of the object’s numeric tags, the context’s fields, and the callback results are not established. In particular, nonzero must not be interpreted specifically as success, failure, or “handled” without an external contract.

A significant property is that dispatch decisions use fields read at different times. Calls may change the context, the object, or reachable memory; subsequent decisions use the values obtained by the later reads rather than an entry-time snapshot.

## Interface

### Inputs

The function receives two arguments:

- **Context:** an address identifying a structure whose first field provides access to a callback table or equivalent dispatch structure.
- **Object:** an address identifying a structure containing a discriminator at byte offset `+0x04` and a conditionally interpreted field at `+0x08`.

The available representation uses 32-bit integer values for field reads, comparisons, intermediate results, and the return value. It also represents some addresses through those 32-bit values. This supports a 32-bit address model for the described layout; portability to a wider-pointer ABI is not established.

### Required layout

Only the following locations are established as relevant to this function:

| Base | Byte offset | Interpretation in this function |
|---|---:|---|
| Context | `+0x00` | Address of the dispatch structure, loaded when selecting or invoking a callback |
| Context | `+0x50` | 32-bit value compared with the object’s field at `+0x08` during the final-stage eligibility check |
| Object | `+0x04` | 32-bit discriminator, read separately at multiple stages |
| Object | `+0x08` | Address of a secondary structure when the primary-stage discriminator is `0x16`; comparison value when the final-stage discriminator is `0x0F` |
| Secondary structure | `+0x04` | 32-bit value used to distinguish the primary callback |
| Dispatch structure | `+0x10C` | Primary callback address for one narrowly defined case |
| Dispatch structure | `+0x110` | Primary callback address for all other cases |
| Dispatch structure | `+0x0E0` | Final callback address |

The context comparison field is at `+0x50` because its access is twenty 32-bit elements from the context base. It is not at byte offset `+0x14`.

Offsets alone do not establish full structure sizes, field names, or semantic types.

### Output

The function returns a 32-bit integer:

- A nonzero result from the preliminary dependency, selected primary callback, or final callback is returned unchanged.
- Otherwise, the function returns zero.

There is no result aggregation, normalization, or translation.

### Preconditions

Each memory access reached by the actual execution path must be valid. In particular:

- The object discriminator must be readable at entry and whenever a later stage reads it.
- The context and its dispatch structure must support the callback lookup that is reached.
- When primary selection observes discriminator `0x16`, the object’s `+0x08` field must identify memory readable at secondary offset `+0x04`.
- When final-stage eligibility observes discriminator `0x0F`, the object’s `+0x08` and context’s `+0x50` fields must be readable.
- Each callback address used must identify a callable target compatible with the invocation.

The function supplies no explicit null checks, bounds checks, callback-availability checks, or pointer validation. Invalid memory or callback addresses are outside its established normal behavior; no particular fault or recovery behavior is specified.

## Behavior

### 1. Preliminary eligibility and invocation

The function first reads the object’s 32-bit discriminator at `+0x04`.

If that value is not `0x0D`, it does not invoke either preliminary dependency and continues to primary selection.

If that value is `0x0D`, it invokes **F-468ee00d626a** with the object argument only. It compares the returned 32-bit value with `0x6F`.

- If the result is not `0x6F`, the preliminary result-producing dependency is skipped.
- If the result is `0x6F`, the function invokes **F-d5d58619c20d** with the context followed by the object.

A nonzero result from F-d5d58619c20d is returned immediately. A zero result allows processing to continue.

The result from F-468ee00d626a is used only as an eligibility value. Even a nonzero result other than `0x6F` is not returned by this function.

The initial discriminator check is not repeated before deciding whether to invoke F-d5d58619c20d. Consequently, if F-468ee00d626a changes the discriminator but returns `0x6F`, F-d5d58619c20d is still invoked.

### 2. Primary callback selection

After any preliminary processing that does not return early, the function reads the object discriminator again.

If this new value is `0x16`, it:

1. Reads the 32-bit field at object offset `+0x08` as a secondary-structure address.
2. Reads the 32-bit value at secondary offset `+0x04`.
3. Selects dispatch slot `+0x10C` if that secondary value is `0x2A`.

In every other case, it selects dispatch slot `+0x110`. This includes:

- Any object discriminator other than `0x16`.
- Discriminator `0x16` with a readable secondary value other than `0x2A`.

The secondary address and secondary field are not read when the discriminator is not `0x16`.

Only after this selection does the function load the dispatch-structure address from the context and obtain the selected callback address. Thus, a preliminary dependency’s change to the context’s dispatch pointer can affect primary dispatch.

The selected primary callback is invoked with the context followed by the object.

- A nonzero callback result is returned immediately.
- A zero result advances to final-stage eligibility.

In ordinary completion, exactly one primary callback is invoked unless F-d5d58619c20d has already returned a nonzero result.

### 3. Final-stage eligibility and invocation

After a zero primary result, the function reads the object discriminator again.

If this value is not `0x0F`, it returns zero without reading the final-stage comparison fields or loading the final callback.

If the value is `0x0F`, it reads:

1. The object’s 32-bit field at `+0x08`.
2. The context’s 32-bit field at `+0x50`.

These values are compared for equality.

- If they differ, the function returns zero.
- If they match, the function loads the context’s dispatch-structure address, obtains the callback at slot `+0x0E0`, and invokes it with the context followed by the object.

A nonzero final callback result is returned unchanged. A zero final callback result leads to a zero return.

The comparison is equality of the observed 32-bit values. No dereference of either comparison value is performed for this stage, and their signedness does not affect equality.

### 4. Ordering and mutation visibility

The relevant order is:

- Entry discriminator read.
- Conditional F-468ee00d626a call.
- Conditional F-d5d58619c20d call.
- Fresh discriminator read for primary selection.
- Conditional secondary-address and secondary-field reads.
- Primary dispatch-pointer and callback-address reads.
- Primary callback invocation.
- Fresh discriminator read for final eligibility.
- Conditional object comparison-field read, then context comparison-field read.
- Conditional final dispatch-pointer and callback-address reads.
- Final callback invocation.

No entry-time snapshot binds these stages together.

For example, a primary callback that returns zero can make the final callback eligible by changing the discriminator to `0x0F` and arranging equal comparison fields. It can also prevent final invocation by changing those fields. A change to the context’s dispatch pointer can affect which final target is loaded.

These are consequences of the explicit later reads, not guarantees about what any dependency actually changes.

9. **All reached result-producing stages return zero.**
