# F-4a95613e1504

## Purpose

F-4a95613e1504 returns a 32-bit value calculated from a selected base and an index. A zero selector obtains the base directly from a field in the supplied object. A nonzero selector obtains the base from dependency F-2f10201b02bc. A zero base produces a zero result; a nonzero base is adjusted by a stride of 20 bytes.

The arithmetic is consistent with selecting an entry in a one-based, fixed-stride collection. That interpretation is **inferred intent**, not an established object model. The supplied evidence does not establish that the selected storage contains an array, that an entry is 20 bytes long, or that the returned value identifies accessible memory.

The function calculates and returns a value. It does not itself read or write the purported selected entry.

## Behavior

### Base selection

The selector is tested before the base is acquired.

If the selector is zero:

- The function reads the integer-sized field at object-reference offset 44.
- That value becomes the selected base.
- F-2f10201b02bc is not called.
- Neither auxiliary word affects any explicit local operation.

If the selector is nonzero:

- The function calls F-2f10201b02bc exactly once.
- Its four arguments, in order, are the object reference, selector, auxiliary word A, and auxiliary word B.
- The index is not passed to the dependency.
- The dependency’s returned value becomes the selected base.
- The function does not explicitly read the field at offset 44 on this path.

Positive and negative nonzero selectors receive the same local treatment: both cause delegation, with the original selector passed through. Their interpretation by the dependency is unknown.

There is no fallback between paths. In particular, a zero dependency result does not cause a subsequent direct field read, and a zero field value does not cause a dependency call.

### Result calculation

After acquiring the selected base, the function tests it for equality with zero.

If the selected base is zero, the function returns zero without performing the index-based result calculation. Thus, for a normally completed base acquisition, any index yields zero in this case.

If the selected base is nonzero, the function applies a stride of 20 and an adjustment of −20. Consequences within representable arithmetic include:

- Index 1 returns the selected base unchanged.
- Index 2 returns the selected base plus 20.
- Index 0 returns the selected base minus 20.
- Index −1 returns the selected base minus 40.

There is no local check rejecting zero, negative, or unusually large indices. There is also no check that a calculated result remains within the selected storage.

A nonzero selected base can produce a zero result through arithmetic. Accordingly, a zero return does not uniquely mean that base selection returned zero.
