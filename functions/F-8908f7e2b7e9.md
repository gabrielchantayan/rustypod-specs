# F-8908f7e2b7e9

## Purpose

F-8908f7e2b7e9 transforms selected unsigned words in a caller-provided memory region in place. Under the 32-bit word interpretation, it reverses the four bytes within twelve selected words and exchanges the positions of two of those words.

The transformation is selective. It does not reverse the entire region, process every word, or exchange every adjacent pair. In particular, word positions 7 and 8 are not accessed.

**Established static behavior:** the supplied representation contains only argument-relative reads, unsigned bit operations, and argument-relative writes. It contains no dependency calls, validation branches, loops, allocation, or explicit error reporting.

**Inferred intent:** this resembles a byte-order conversion for a fixed-layout record containing both individual 32-bit fields and one two-word field. The record format and field meanings are not established. Reversing bytes and exchanging two words is insufficient evidence to assign a particular numeric or protocol type to that field.

### Value transformation

### Arithmetic properties

Under the 32-bit interpretation:

- All value manipulation is unsigned.
- The transformation uses fixed masks, shifts by 8 or 24 bits, and bitwise combination.
- Right shifts move zeroes into the vacated high bits.
- Left-shifted bits beyond the 32-bit result are discarded.
- The selected byte contributions occupy disjoint result positions.
- There is no signed overflow, division, rounding, saturation, or data-dependent arithmetic failure.
- The exchange at positions 5 and 6 does not depend on their numeric values.

The operation is an involution: two complete calls on unchanged, valid storage restore the original contents. Individual byte reversal is self-inverse; exchanging the selected pair while reversing each member is also self-inverse.

## Acceptance examples

The examples below are conditional acceptance criteria, not runtime observations. They assume 32-bit unsigned words, valid ordinary memory, and no interfering accesses.

### Individual word reversal

If position 0 initially contains `0x12345678`, it must contain `0x78563412` after completion.

The same value rule applies independently at positions 1, 2, 3, 4, 9, 10, 11, 12, and 13.

### Pair exchange with reversal

If the initial values are:

| Position | Initial value |
|---|---|
| 5 | `0x11223344` |
| 6 | `0xA1B2C3D4` |

then the final values must be:

| Position | Final value |
|---|---|
| 5 | `0xD4C3B2A1` |
| 6 | `0x44332211` |

Reversing each word without exchanging their destinations would not satisfy the contract.

### Untouched gap

If positions 7 and 8 initially contain `0x01234567` and `0x89ABCDEF`, respectively, those exact values must remain after completion. Neither position participates in the access sequence.

### Nonascending processing order

For valid storage exposing the logical access sequence, the read and write at position 10 precede those at position 11, which precede those at position 9.

A final-state comparison alone cannot establish this ordering. Neither can this representation guarantee a particular hardware observation order.

### Byte-symmetric values

A directly transformed word containing `0x00000000`, `0xFFFFFFFF`, or `0x12212112` retains its numeric value.

For positions 5 and 6, byte symmetry alone does not guarantee that either position retains its value: the transformed values also exchange destinations.

### Repeated application

Given any valid initial 14-word region, two complete consecutive calls, with no intervening changes, must restore every word to its initial value. Positions 7 and 8 remain unchanged throughout.

### Invalid input

A null pointer or undersized region is not an accepted input with a defined status result. Acceptance must not require a clean failure or unchanged memory in those cases; neither behavior is established.
