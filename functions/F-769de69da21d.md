# F-769de69da21d

## Purpose

F-769de69da21d describes a sequence of low-level memory operations, two external calls, a conditional repetition, and an abnormal terminal operation. The supplied static representation does not establish a normal return or a reliable higher-level purpose.

The observable structure is:

- Repeatedly read a byte from an input-derived address, perform several writes, and invoke an external dependency.
- Continue repeating unless the dependency’s upper result word exceeds 127 and its lower result word is nonzero.
- On that condition, perform a further sequence of writes and invoke a second dependency.
- Reach a terminal bad-instruction indication, provided no earlier operation faults or transfers control elsewhere.

This is a **documented_only static contract**, not a verified executable specification. The supplied representation explicitly reports invalid instruction data and overlapping global symbols. Those limitations affect control-flow confidence, memory aliasing, and the interpretation of several shifts.

## Behavior

### Entry and repeated phase

The following ordering is established by the supplied static representation. It describes successful progression through each operation; no rollback, fault recovery, or atomic grouping is shown.

1. **Read an input-derived byte.**  
   A is shifted left by 26, and the resulting value is used as a byte address. The byte read is zero-extended to a 32-bit value, U.

   A 32-bit truncating interpretation would make the address depend only on A’s lowest six bits. That interpretation is conditional: the representation does not establish the target’s complete shift and overflow semantics.

2. **Capture address arithmetic and write through P.**  
   The address value of P is multiplied by four to form Q. A 16-bit value of 0xF770 is then written at P.

   Q is computed before this write. It is an address-derived integer, not four times the value stored at P.

3. **Perform shared-state writes.**
   - Write 8 to G2.
   - Read G1 and write a 32-bit packed value to G3: G1 supplies the upper 16 bits, and 8 supplies the lower 16 bits.
   - Write address value 8 to G4.
   - Write H to G5.

   G2’s exact storage width is not explicit in the supplied fragment. G1 is read after the write to G2, which matters if the locations overlap.

4. **Invoke F-EXT-001.**  
   Its four represented arguments, in order, are:
   - A 32-bit word read from S minus 32.
   - A fixed address-valued token.
   - U.
   - Zero.

   The result is represented as 64 bits. Let L be its lower 32 bits and V its upper 32 bits.

5. **Use L as an address before testing it.**
   - Write the 32-bit value L at address L plus 16.
   - Read G6 and replace P with that pointer value.
   - Write the low 16 bits of L at address L plus 6.

   The later nonzero condition does not protect either write. If L is zero, the representation still attempts writes at addresses 16 and 6 before evaluating loop exit.

6. **Evaluate the exit condition.**  
   Exit the repeated phase only when V is greater than 127 under an unsigned comparison **and** L is nonzero.

7. **On a non-exiting iteration:**
   - Write Q as a 32-bit value at address U plus 4.
   - Replace A with zero.
   - Increase H by 112.
   - Decrease S by 416.
   - Begin another iteration.

Because U is an unsigned byte value, the non-exiting write starts at an address from 4 through 259. No alignment check is shown.

On every later iteration reached through this path, the initial byte read is from address zero under the displayed shift expression. P is then the value obtained from G6 during the preceding iteration, not necessarily the caller’s original pointer.

There is no iteration bound, timeout, or visible error exit.

### Exit-phase operations before F-EXT-002

After a successful loop exit, L and V remain the two halves of the most recent F-EXT-001 result. P remains the pointer loaded from G6 during that iteration.

The represented ordering is:

1. Write a 32-bit value at L plus 72. Its value is expressed as a signed 32-bit conversion of U followed by a right shift of 32. The numeric result is unresolved because the shift count equals the operand width.
2. Write one byte at L plus 6. The byte is the low eight bits of P’s address value plus 229. This overlaps the earlier 16-bit write at L plus 6.
3. Read G7 into an 8-bit snapshot, T.
4. Read G8 and add two to obtain X.
5. Read G9, shift its converted value left by 16, and assign that result to G4.
6. Read G10, shift it left by 25, and write the result to G11.
7. Read G7 again. Add that newly read byte to the signed-right-shift expression X shifted right by seven, and write the 32-bit value 216 at the resulting address.
8. Write the 32-bit value 40 to G12.
9. Write T as one byte at address twice X.
10. Write the low eight bits of X shifted right by seven to that same byte address.

The two reads of G7 are distinct. In particular, the second read occurs after intervening shared writes. Aliasing or externally modified memory can make it differ from T.

The final two writes target the same byte address. They are separate represented writes; the later one replaces the earlier byte if both complete without intervening external effects.

## Acceptance examples

These examples describe conditional static expectations, not executed tests.

1. **Upper result word equals 127.**  
   If F-EXT-001 returns V = 127 and L is nonzero, the repeated phase does not exit. The writes through L still precede that decision, followed by the write at U plus 4 and the iteration-state updates.

2. **Smallest qualifying upper word.**  
   If V = 128 and L is nonzero, and all preceding accesses complete, execution leaves the repeated phase. It does not perform that iteration’s non-exit write at U plus 4 or its H and S adjustments.

3. **Zero lower result word.**  
   If L = 0, even with V greater than 127, the displayed path attempts the writes at addresses 16 and 6 before rejecting loop exit. A contract promising null-result safety would contradict the supplied evidence.

4. **Second iteration.**  
   If an iteration does not exit and another iteration begins, A is zero, H has increased by 112, and S has decreased by 416. The initial byte read therefore targets address zero under the represented arithmetic. The halfword destination is the P value loaded from G6 in the previous iteration.

5. **Partial overwrite after loop exit.**  
   If the halfword write at L plus 6 and the later byte write there both complete, the byte at that address contains the low eight bits of P plus 229 after the latter operation. This does not establish the complete final halfword independently of endianness and aliasing.

6. **Second dependency result is not validated.**  
   If F-EXT-002 returns M = 0, the next represented memory operation writes 88 at address 100. No intervening null check is shown.

7. **Fault partway through execution.**  
   If an early write succeeds and a subsequent access faults, no visible mechanism restores the earlier destination. Expectations of all-or-nothing state change are unsupported.
