# F-80e26123b3b1

## Purpose

The established behavior is an ordering contract for calls, memory accesses, and loop-carried state. An application-level purpose is not established. In particular, the representation does not establish allocation, object construction, serialization, or a named protocol.

Every operation described below is conditional on execution reaching it. An indirect dependency can have unknown effects, fault, or fail to return. A computed memory access can also prevent further progress.
