# F-570d5ddce076

## Purpose

F-570d5ddce076 obtains a 32-bit value from one dependency, then dispatches that value and a byte read through its input pointer to an indirectly selected destination.

The destination is obtained by reading a **global function-pointer reference after the first dependency returns**. It is not established as a target captured at wrapper entry. The first dependency may modify that global reference; the subsequent dispatch uses the destination obtained afterward.

The established argument order is:

1. The 32-bit result of the initial dependency.
2. A value sourced from the single byte read through the input pointer.

No application-level meaning is established for either argument. The byte is not established to be an opcode, character, flag, or table index. No visible wrapper operation computes the destination from the byte.

The supplied static representation has an explicit indirect-control-flow recovery limitation. It establishes the argument sources and the post-dependency target acquisition more clearly than it establishes ordinary call-and-return behavior.
