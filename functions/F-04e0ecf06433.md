## Acceptance examples

These are conditional static acceptance examples, not executed tests. They assume valid memory, returning dependencies, and faithful execution of the represented path.

1. **Separated word writes.** With a first argument of 3, the scaled value is 12 and the computed word address is 32. The first direct word write stores 3 there. After F-000000000001 through F-000000000005, the second direct word write stores 12 there. Dependency writes between them remain possible.

2. **Byte truncation.** If the first retained result is hexadecimal `12345678`, the first selected byte write stores hexadecimal `E0`. The later selected byte write derived from that same retained result stores hexadecimal `23`. Each write obtains its destination through its own selector read.

4. **Direct-write aliasing.** If fourth-argument base plus 28 equals entry base plus one, the direct byte write updates the selector itself. The immediately following zero write must use that updated byte to choose its destination.

5. **Extraction limits.** If the second retained result is hexadecimal `FFFFFFFF`, F-000000000025 receives hexadecimal `00FFFFFF`. If the result of F-000000000034 is also hexadecimal `FFFFFFFF`, F-000000000035 receives 62, and the first loop-entry call still receives zero as its second argument.

7. **No normal completion.** If every dependency returns and every access succeeds, completion of one loop iteration leads to another iteration, not a normal return.
