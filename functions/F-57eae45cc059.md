Each dispatch-selection attempt performs these global reads in this statement order:

1. The global record pointer.
2. A first 32-bit arithmetic coefficient, called coefficient A below.
3. A second 32-bit arithmetic coefficient, called coefficient B below.
4. A state-offset value, used with the incoming state to form the unsigned selection value.
5. A fallback-state value, installed as the current state.

The selection is accepted only when its unsigned value is at most 41. Otherwise, selection repeats using the fallback state and rereads all five items in the same order. The fallback read occurs even on an accepted attempt.

After acceptance, another global coefficient is read and right-shifted by one bit. This read precedes execution of the selected alternative, including the return alternative.

These reads do not form an atomic snapshot. The record pointer and coefficients captured by the accepted attempt are distinct from fresh reads of the corresponding global locations inside an alternative. Rejected attempts do not supply the final captured values.

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Dispatch rejects a selection.**  
   The record-pointer, A, B, offset, and fallback reads occur in that order. Selection retries using the fallback state and rereads all five. An accepted attempt additionally reads the shifted coefficient before executing its alternative.

2. **Initialization dependencies mutate later argument globals.**  
   A mutation by the first call can affect the second address, because that address is fetched after the first returns. The first call’s address remains the value computed before the flags store.

3. **A byte transfer follows a destination-base reassignment.**  
   With valid incoming bases and offset, the byte read through the source base is written through the current destination base. If that base identifies temporary storage or the final initialization address, writing instead to the record payload would violate the contract.

4. **F-ab4565f926b1 returns normally.**  
   The mutable buffer reference subsequently identifies the four-word temporary region. A later address comparison must compare that reference with the incoming comparison anchor, not assume two payload addresses.

5. **Header update is reached.**  
   The record receives the represented 32-bit product of the input header and the two fresh coefficients, followed by a four-byte zero store at offset 40.

6. **F-d7be9cfb4000 changes coefficient globals.**  
   Immediate post-call displacement arithmetic still uses accepted-attempt coefficients A and B. If the selected payload byte is zero, the stored intermediate byte is 236; if it is one, the byte is 137.

7. **Publication is reached.**  
   A valid output slot receives the current record pointer. Equality with the eventual return is not required.

8. **Null arguments, overlapping storage, or an out-of-range intermediate index occur.**  
   Null-safe exit and overlap-safe complete copying are not established. An executed intermediate access outside its 16-byte region violates the storage precondition; no supported recovery behavior is specified.
