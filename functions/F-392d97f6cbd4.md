# F-392d97f6cbd4

## Purpose

F-392d97f6cbd4 produces a Boolean classification from an integer stored eight bytes beyond an address supplied by the caller.

For a valid location whose contents remain unchanged during the invocation, the result is false when the stored value is −1 or −5, and true for every other representable value.

The source expresses two separate accesses to that location, with the second access conditional on the first comparison. Consequently, “the value is neither −1 nor −5” describes the stable-memory case, not necessarily an invocation during which the location changes.

The meanings of the two excluded values are unknown. Interpreting them as particular statuses, errors, or object states would go beyond the supplied evidence.

## Behavior

### Address selection

The function selects memory at a fixed displacement of eight bytes from the supplied base. It does not read a pointer from the base, inspect a length, or traverse another object.

The displacement is applied through integer arithmetic before the result is treated as an address. The source does not establish that this is a pointer-width calculation. In particular, it does not justify assuming 64-bit address arithmetic merely because a possible host uses 64-bit pointers.

The displacement is small, but adding it to a base near the limit of the applicable integer type can still exceed that type’s range. Such inputs have no established portable behavior here; wrapping is not part of the demonstrated contract.

### Ordered comparisons

The source-level evaluation order is:

1. Read the integer at the selected address and compare it with −1.
2. If that comparison finds −1, produce false without evaluating the second comparison.
3. Otherwise, read the integer at the selected address again and compare it with −5.
4. Produce true if the second read differs from −5; otherwise produce false.

The first comparison therefore controls whether the second memory access is expressed. There is no third read.

The exclusion checks are ordered, not interchangeable when the contents can differ between accesses. The first read is checked only against −1. The second read, when reached, is checked only against −5.

For example, if the first read yields an ordinary value and the second yields −1, the source-level expression produces true: the first comparison already passed, and −1 differs from the second comparison’s excluded value, −5. This is a conditional description of the expression, not a guarantee that an unsynchronized concurrent update is valid or observable.
