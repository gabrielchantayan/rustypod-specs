### Allocation-shaped call

- the retained capacity shifted left four bits using unsigned 32-bit arithmetic;
- a second argument of zero.

The first argument equals 16 times the capacity modulo \(2^{32}\). For capacities below \(2^{28}\), no high bits are discarded. For capacities at or above that boundary, the shift may wrap to a smaller value, including zero. No overflow check intervenes.

The returned 32-bit value is written into the stored-base field. The function does not test it before proceeding.

This is an allocation-shaped interaction only. Neither the argument’s semantic unit nor the result’s resource meaning is established. In particular, a numeric first argument of 512 is not, by itself, proof of a 512-byte allocation.
