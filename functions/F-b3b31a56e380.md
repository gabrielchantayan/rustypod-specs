# F-b3b31a56e380

## Purpose

F-b3b31a56e380 is a discriminator-based dispatcher. It examines a 32-bit unsigned field in a caller-supplied object and selects one of two dependencies, forwarding four additional 32-bit arguments unchanged.

For discriminator values below two, the selected dependency receives an address inside the supplied object. For discriminator value two, the selected dependency receives a 32-bit value loaded from a different field of that object. Other values reach a dependency identified by the supplied static evidence as non-returning.

The established behavior is dispatch and argument selection. The semantic meaning of the discriminator, the object, the forwarded arguments, and the selected operations is unknown. Describing this routine as a constructor, destructor, allocator, or resource-management operation would exceed the evidence.

## Behavior

### Initial discrimination

The routine first reads the 32-bit unsigned discriminator at offset +8.

If that value is zero or one, it selects F-2dde9a1feb08. That dependency receives:

- The object address advanced by 20 bytes.
- Forwarded arguments A, B, C, and D, in their original order.

This path does not read the field at offset +16 and does not perform the second discriminator read shown on the other path. If F-2dde9a1feb08 returns normally, the dispatcher returns.

The comparison is unsigned. A field whose bit pattern is all ones therefore does not satisfy the less-than-two condition.

### Recheck and value-based dispatch

If the initial discriminator read is at least two, the supplied representation shows another read of the discriminator at offset +8.

If this second value is two, the routine then reads the 32-bit field at offset +16. It invokes F-eba31d0911df with:

- The exact 32-bit value loaded from offset +16.
- Forwarded arguments A, B, C, and D, in their original order.

If F-eba31d0911df returns normally, the dispatcher returns.

The first argument on this path is neither the address of the field at offset +16 nor the interior address at offset +20. It is the field’s loaded value. Its interpretation by F-eba31d0911df is undocumented.

### Unsupported discriminator
