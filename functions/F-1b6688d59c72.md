# F-1b6688d59c72

## Purpose

F-1b6688d59c72 conditionally dispatches two operations against a location selected from a global base and a signed selector. A preliminary dependency determines whether those operations occur.

The established normal-return outcomes are:

- **0:** the preliminary dependency returned exactly zero, and both subsequent dependencies returned normally.
- **64:** the preliminary dependency returned a nonzero value; neither subsequent dependency was invoked.

A selector greater than 2 invokes a dependency annotated as non-returning before the preliminary dependency is called.

These outcomes describe control flow, not independently verified operational success. In particular, the function does not inspect the results of either operation performed after the preliminary check.

**Inferred intent:** the stride and fixed offset suggest selection of a field within a repeated record structure. That interpretation is not required by the contract. The available evidence does not establish a record type, a buffer size, or the meanings of the two external operations.

### Relevant global state and layout

A global base value is consulted only on the path where the preliminary dependency returns zero.

The selected location is formed from:

- The global base value read on that path.
- The selector multiplied by **276**, corresponding to a stride of **0x114**.
- A further offset of **20 bytes**, corresponding to **0x14**.

For a representable computation, the target is therefore the global base plus 276 times the selector, plus 20 bytes.

This describes an address calculation, not a proven allocation layout. The available evidence does not establish:

- The size or ownership of the storage associated with the base.
- The number of valid entries.

- Whether the target must be aligned.

## Behavior

### 1. Selector check

Before invoking the preliminary dependency, the function compares the signed selector with 2.

If the selector is greater than 2, it invokes **F-a817d8d58c10** with no explicit arguments. The supplied evidence marks this dependency as non-returning.

Consequently, under the represented non-returning behavior:

- The preliminary dependency is not reached.
- The global base is not read by this function.
- Neither target operation is invoked.
- No normal return value is produced.

The exact termination mechanism is unknown. The evidence does not distinguish process termination, an exception, a nonlocal transfer, an indefinite wait, or another non-returning action.

The visible check is an upper-bound check only. Zero, 1, 2, and all negative signed selector values pass it. There is no visible lower-bound check and no visible conversion to an unsigned value before this comparison.

### 2. Preliminary dependency

For a selector that passes the check, the function invokes **F-33e4c1b6fdcc** with these arguments, in this order:

1. The fourth input.
2. The third input.

The dependency’s result is interpreted as an integer and compared with zero. Only the distinction between exactly zero and nonzero affects the visible control flow.

The supplied body does not establish whether this dependency validates inputs, examines data, acquires resources, or changes state. Its zero result must not be described as “valid” or “successful” without additional evidence.

If the dependency does not return normally, the enclosing function does not reach any later visible action.

### 3. Nonzero preliminary result

If F-33e4c1b6fdcc returns any nonzero value, the function returns the 32-bit value **64**.

On this path, the function itself:

- Does not read the global base.
- Does not compute or use a selected target.
- Does not invoke either subsequent operation.

The preliminary dependency may nevertheless have produced side effects. Returning 64 does not establish that the overall call was side-effect-free.

### 4. Zero preliminary result

If F-33e4c1b6fdcc returns exactly zero, the function reads the global base and computes the selected target.

The timing of this read is significant: it occurs **after** the preliminary dependency returns. If that dependency changes the global base, the visible function uses the value read afterward, not a value saved before the call.

The function then invokes two dependencies in sequence. Because the supplied dependency map does not assign them published opaque IDs, this document uses **F-X01** and **F-X02** as document-local opaque identifiers.

First, it invokes **F-X01** with:

1. The selected target.
2. The integer value **255**, corresponding to **0xFF**.

If F-X01 returns normally, the function invokes **F-X02** with:

1. The same previously computed target.
2. The fourth input.
3. The third input.

The target is computed once in the visible body and reused. A change to the global base during F-X01 does not cause this function to recompute the target for F-X02.

No result from F-X01 or F-X02 is checked. If both return normally, the function returns the 32-bit value **0**.

Thus, returning 0 establishes that the zero-result branch was taken and both operations completed their normal returns. It does not establish that either operation achieved an intended data transformation.

## Side effects

### Established direct behavior

The visible function performs no direct writes through the supplied arguments and no direct write to the global base. Its directly established interactions are dependency calls and, conditionally, a read of the global base.

For a selector that passes the check and a zero preliminary result, the observable ordering imposed by this function is:

1. Call F-33e4c1b6fdcc.
2. Observe its zero result.
3. Read the global base.
4. Compute the selected target.
5. Call F-X01.
6. If that call returns normally, call F-X02.
7. If that call returns normally, return 0.

This ordering does not imply any ordering among reads or writes performed internally by the dependencies beyond their call boundaries.

That absence does not establish equivalent restrictions on its dependencies. In particular:

There is no visible rollback or compensating operation. If F-X01 changes state and F-X02 subsequently fails to return normally, no restoration by this function is shown.
