### 2. Transform the local words in reverse address order

The function transforms all four local words in place. It visits them from the highest-addressed word to the lowest-addressed word:

1. Fourth word.
2. Third word.
3. Second word.
4. First word.

Each transformation is a logical right shift by one bit on a 32-bit unsigned value.

For an input word with unsigned value \(x\), the resulting word is:

\[
\left\lfloor x / 2 \right\rfloor
\]

The low bit is discarded. A zero enters the high bit. There is no signed interpretation, sign extension, carry between words, or rotation.

Consequently:

- Every transformed value lies between 0 and 2,147,483,647 inclusive.
- Inputs differing only in their least significant bit produce the same transformed value.
- The four words are transformed independently.
- This is not a right shift of a single concatenated 128-bit quantity.

The reverse processing order does not reverse the final word order. The transformed first source word remains at offset 0, and the transformed fourth source word remains at offset 12.
