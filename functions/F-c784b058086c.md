# F-c784b058086c

## Purpose

F-c784b058086c performs an ordered sequence of address-derived memory accesses and global assignments. One branch ends at an invalid-instruction boundary. The continuing branch performs additional mutations and reaches a second invalid-instruction boundary. No ordinary return path is represented.

The supplied static representation does not establish an application-level purpose. Initialization, allocation, decoding, and dispatch are not established interpretations.

This contract distinguishes:

- **Established static evidence:** represented inputs, widths, expressions, access ordering, captured values, branches, and termination boundaries.
- **Conditional consequences:** results requiring explicitly stated arithmetic or memory assumptions.
- **documented_only:** behavior that cannot be resolved from the supplied representation.

Warnings about invalid instruction data and overlapping global storage limit executable interpretation. Two apparent shifts by 32 on 32-bit operands are additional unresolved points.

- **Adjusted input:** second input minus 0xA8, modulo \(2^{32}\).
- **Halfword base:** twice the adjusted input, modulo \(2^{32}\).

The index ranges from zero through 0x3FFFFFFF. Its use as an address displacement does not narrow it to 16 bits.

The **fourth-input destination** is represented by shifting the signed fourth input left by 2 and then right by 32. An apparent 32-bit operand shifted by 32 has no ordinary defined width-preserving interpretation. ### Early termination and signed propagation

If the first captured F-e47d7b2e9c88-associated value has bit 31 set, the secondary-base-offset-4 store precedes the first invalid-instruction boundary. Continuing-path accesses do not occur.

The stored halfword comes from the separate sign-producing evaluation, not necessarily the branch operand.

On the continuing path, with arithmetic signed right shift, an indexed halfword of 0x8000 produces word 0xFFFFFFFF at secondary-base offset 8; 0x7FFF produces zero. The offset-0x12 store and captured-value self-address store occur both before and after the indexed read.

### Shared instruction-composite destination

Suppose the index is 0x1234. The early assignment to the instruction-composite global uses the 16-bit expression 0x0034.

If its current overlapping byte is still 0x34 when later read, the composite expression assigned back to the same destination is 0x000534. If an intervening write instead leaves that byte as 0xAB, the composite is 0x0005AB.

Using a saved 0x34 despite the changed byte is incorrect. Assigning the composite to a different destination also violates the established identity. These examples specify numeric expression values, not the unresolved complete write width.

### Separate retained dependency results

Suppose the first F-8afdaab91693-associated evaluation yields 0x100 and the second yields 0x300, with relevant arithmetic valid.

The order is capture 0x100, assign the derived-address global, then evaluate and shift 0x300. The shifted payload is 0xC00; the zeroing base is 0x800.

A zeroing base of 0x1800 incorrectly substitutes the second evaluation. A payload of 0x400 incorrectly substitutes the first. This example does not assert that actual evaluations differ.
