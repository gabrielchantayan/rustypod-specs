# F-5d124778b4a2

## Purpose

F-5d124778b4a2 performs a fixed sequence of indirect calls interleaved with direct memory updates. It transfers and scales opaque 32-bit values, copies selected words and bytes, constructs several index-derived addresses, publishes a final dependency result to a global location, clears two memory locations, and attempts a call through address zero.

No application-level purpose is established. Interpreting the values as object identifiers, handles, table entries, links, or encoded addresses would be inferred intent, not a supported contract.

The observable contract is principally ordering: dependency calls may change memory, so reads separated by calls must remain separate reads, and values explicitly retained across calls must remain retained values.

7. Invoke **F-C008** with A4.
8. Invoke **F-C009**, **F-C010**, and **F-C011**, in order, with no explicit arguments.

- The first input shifted left by one.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Upper-nine-bit extraction.** If the fourth argument is `0x00800000`, F-C003 receives 1 as its third explicit argument. With `0xffffffff`, it receives 511.

2. **Independent repeated reads.** Suppose A is 16. The first source read is at address 180 and the byte destination is address 65. If the source word is `0x12345678`, the first byte written is `0x78`. If intervening dependencies change that word to `0xaabbccdd`, the second write must use `0xdd`, not the earlier byte.

3. **Retained source snapshot.** If C is 32 and W(244) is `0x89abcdef`, S becomes that complete word and B(129) receives `0xef`. Later S-based word stores still receive `0x89abcdef` even if dependencies subsequently modify W(244).

4. **Truncation before shifting again.** Under a 32-bit bit-vector interpretation, B equal to `0x40000001` produces B4 equal to 4. F-C027 therefore receives `0x00010000`; it does not recover B’s discarded high bits.

5. **Captured base versus mutable global.** If the global-base read yields 4096, the later T read uses address 4116. A dependency changing the global base to 8192 does not redirect that read.

6. **Byte-directed destination.** If S shifted right by 23 is 2, the first table read uses address 3. If that byte is 7 and byte(T) is `0xab`, the resulting write places `0xab` at address 24.

7. **Second byte extraction.** If J is `0x00600000`, the second table-read address is 4. If its byte is 9 and T is `0x2ac00000`, the write places `0xab` at address 26.

8. **Terminal failure ordering.** If the environment rejects calls through address zero, all preceding completed effects remain observable. Such an environment must not be described as observing a normal return.
