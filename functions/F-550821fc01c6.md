# F-550821fc01c6

## Purpose

F-550821fc01c6 performs one of two ordered sequences of external operations, selected by a byte in a caller-supplied state object. Both sequences finish by passing an interior address of that object to F-58b3b644ea3d. On normal completion, the function returns the 32-bit value zero.

The zero-selector sequence invokes a callback with a pointer to a mutable, call-local 32-bit value initialized from the fourth argument. The nonzero-selector sequence optionally resolves another object and invokes one of its methods, uses fields from the supplied state object in subsequent calls, and writes the byte value `0x41` into that object.

These are structural descriptions. The application-level meanings of the selectors, constants, referenced objects, callback, and final operation are not established.

## Behavior

### Entry and branch selection

The fourth argument is first copied into a call-local 32-bit value. The function then reads the byte at state offset `0x28`.

A zero byte selects the callback sequence. Any nonzero byte selects the alternate sequence. The branch is not reconsidered later, even if a dependency changes the selector.

### Zero-selector sequence

The following operations occur in order, provided each preceding call returns normally:

1. Call F-9cd38f533e00 with `0x200`.
2. Read the 32-bit field at state offset `0x30` and pass that value to F-34751ba0ae74.
3. Fetch the callable address at state offset `0x38` and invoke it with two arguments:
   - `0x400`;
   - the address of the call-local 32-bit value initialized from the fourth argument.
4. Read the 32-bit field at state offset `0x30` again. Call F-b3f03f4809f5 with:
   - this newly read field value;
   - `0x1000`;
   - the call-local 32-bit value after the callback returns.
5. Continue to the common final operation.

The callback’s direct return value is not used. Its mutation of the pointed-to 32-bit value is relevant: the value subsequently passed to F-b3f03f4809f5 comes from that storage after the callback.

If the callback leaves the storage unchanged, the original fourth argument is passed onward. If it replaces the stored value, the replacement is passed onward. No validation or range restriction is applied by the visible body.

The two reads of offset `0x30` are distinct. F-34751ba0ae74 or the callback may change the state object, directly or indirectly. The later call is therefore not guaranteed to receive the earlier field value.

No explicit store to state offset `0x60` occurs on this path. This does not imply that dependencies leave that byte unchanged.

### Nonzero-selector sequence

The function first reads a 32-bit global value as the tentative argument for a later call to F-9cd38f533e00. It then tests the byte at state offset `0x2A`.

#### Optional operation when offset `0x2A` is nonzero

If the selector is nonzero:

1. Supply the selector byte, widened according to the effective character-promotion rules, to F-cdd33263ee89.
2. Treat that dependency’s result as an object address.
3. Read the object’s leading 32-bit word as a method-table address.
4. Fetch the callable entry at method-table byte offset `0x110`.
5. Invoke that entry with the object address and zero.
6. Pass the method result and `1` to F-d8eafb5f244b.
7. Read a second 32-bit global value, replacing the tentative value selected before the optional operation.

The first global read precedes the selector test. When this optional operation completes, the second global read supplies the eventual argument to F-9cd38f533e00. Changes to that second global by earlier dependencies can therefore affect the argument.

The selector test and the byte supplied to F-cdd33263ee89 are separate visible uses. No intervening dependency call appears between them. Behavior under concurrent or asynchronous modification is not established.

If the selector is zero, none of these optional calls occurs, and the initially read global value remains selected.

#### Remaining nonzero-selector operations

After the optional operation, or immediately after skipping it:

1. Call F-9cd38f533e00 with the selected 32-bit global value.
2. Call F-557ed731ad0e with `0x5C`.
3. Read the 32-bit field at state offset `0x2C` and pass it to F-34751ba0ae74.
4. Read the 32-bit fields at offsets `0x2C` and `0x44`. Call F-b3f03f4809f5 with:
   - the newly read value at `0x2C`;
   - `0x1000`;
   - the value at `0x44`.
5. Store exactly one byte, `0x41`, at state offset `0x60`.
6. Continue to the common final operation.

The relative evaluation order of the two field reads supplying F-b3f03f4809f5 is not established. Both occur after F-34751ba0ae74 returns and before the invocation uses their values.

The field at `0x2C` is not cached across F-34751ba0ae74. If that dependency changes the field, F-b3f03f4809f5 receives the later value.

The store at `0x60` occurs only after F-b3f03f4809f5 returns. It precedes the common final call, whose effects on that byte are unknown.

### Common final operation and return

After either branch completes, F-58b3b644ea3d is called with the state-object address plus `0x3C`.

Its return value is ignored. If it returns normally, F-550821fc01c6 returns the 32-bit value zero.

No visible branch handles dependency failures or substitutes a different final result. A dependency that does not return prevents subsequent operations from being reached.

## Side effects

Additional side effects can occur through every external or indirect call. They may include changes to the state object, globals, referenced objects, or external state; their scope is not established here. In particular:

- The zero-selector callback receives writable access to call-local 32-bit storage.
- The resolved object’s indirect method receives that object’s address.
- F-58b3b644ea3d receives an interior address into the caller-supplied state object.
- Dependencies may change fields that this function reads later.

No global writes are explicit in the visible body. Two global reads are visible on the nonzero-selector path, with the second performed only after the optional operation.

There is no visible rollback, compensation, or cleanup sequence for partial execution. Earlier side effects need not be undone if a later call fails to return normally.

Address calculations use byte offsets in the apparent 32-bit address model. The visible body performs no checked arithmetic. Safe execution requires valid resulting addresses rather than reliance on overflow or address wrapping.

## Acceptance examples

These are conditional contract examples, not executed tests.

### Zero selector with an unchanged callback value

Given a zero byte at `0x28`, a fourth argument of `0x12345678`, valid accessible storage, and normally returning dependencies:

- F-9cd38f533e00 receives `0x200`.
- F-34751ba0ae74 receives the then-current field at `0x30`.
- The callback receives `0x400` and access to 32-bit storage initially containing `0x12345678`.
- If the callback leaves that storage unchanged, F-b3f03f4809f5 receives `0x12345678` as its third argument.
- The common final dependency is called before the function returns zero.

No explicit `0x41` store is required on this path.

### Zero selector with callback mutation

If the callback changes its pointed-to value to `0xFFFFFFFF` and returns normally, F-b3f03f4809f5 receives the 32-bit pattern `0xFFFFFFFF` as its third argument. The visible body does not reject, clamp, or otherwise transform it.

If an intervening dependency also changes the field at `0x30`, the final three-argument call uses the later field value.

### Nonzero selector without the optional operation

Given a nonzero byte at `0x28` and zero at `0x2A`, the object-resolution call, indirect method call, and F-d8eafb5f244b call are skipped.

The initially read global supplies the argument to F-9cd38f533e00. After the remaining branch calls return, the function writes `0x41` at `0x60`, invokes the common final dependency, and returns zero if that dependency returns.

### Nonzero selector with the optional operation

Given a nonzero byte at `0x2A` and valid resolved-object machinery, the required order is resolution, indirect method invocation, F-d8eafb5f244b, second-global read, then F-9cd38f533e00.

If F-d8eafb5f244b changes the second global, the subsequent global read observes the resulting value under ordinary sequential execution.

### Mutation between repeated field reads

If F-34751ba0ae74 changes the field at `0x2C` before returning on the nonzero-selector path, F-b3f03f4809f5 receives the changed value. Reusing the earlier read would not match the visible behavior.

### Interrupted execution

If F-b3f03f4809f5 does not return on the nonzero-selector path, neither the explicit byte store at `0x60` nor the common final call is reached. No normal return value is produced.
