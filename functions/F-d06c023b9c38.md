## Behavior

### Initial write and signed gate

The function derives the first symbol word, initial base, and sign halfword. It then performs a **16-bit write at initial base plus `4`**, before applying the signed gate.

If the first symbol word is negative under signed 32-bit interpretation, the represented path reaches an abnormal-stop boundary immediately after that write. No later operation is shown on this path.

Under arithmetic right-shift semantics, the sign halfword is `0xffff` for a negative first symbol word and zero otherwise. This conditional result does not resolve the initial base.

The initial write can fault before the gate is reached. The gate is not a validity check protecting that write.

### Repeated writes and signed-halfword use

On the nonnegative path, the function writes the sign halfword at initial base plus `0x12`, then writes the first symbol word as 32 bits to the address numerically equal to that word.

It next reads a signed 16-bit value at initial base plus the inherited word. After the read, it repeats both preceding writes in the same order: the halfword at base plus `0x12`, followed by the fullword at the first-symbol address.

Finally, it promotes the previously read signed halfword to a signed 32-bit value, shifts it right by 16, and writes the 32-bit result at initial base plus `8`.

Under arithmetic right-shift semantics, that result is zero for a nonnegative halfword and `0xffffffff` for a negative halfword. It is not a copy of the original halfword.

The repeated writes remain distinct observable accesses. Their matching values do not justify collapsing them, particularly where faults, device behavior, or overlapping memory are possible.

### Selector and early global assignments

The next sequence begins by assigning zero to an abort-labeled global. Its destination width is unknown.

The selector is `0x58` plus the value of bit 2 of the first symbol word. The function writes the initial base as 32 bits at selector plus `4`.

Three named-global assignments then occur in order:

1. A separate global receives the inherited word’s upper 16 bits, explicitly converted to a 16-bit value.
2. An instruction-labeled global receives the inherited word explicitly converted to an unsigned 8-bit value.
3. A related instruction-labeled global receives the current value read from the preceding global, explicitly converted to an unsigned 16-bit value.

The conversions have established widths; the three destination objects do not. In particular, the third assignment does not establish a 16-bit store, and its input must not be modeled as an inherently byte-sized storage object.

If the first symbol word is negative as signed 32 bits, the halfword write at initial base plus `4` precedes the abnormal-stop boundary. Under arithmetic right shift, the written halfword is `0xffff`.

No later represented operation occurs on that path. The write address remains unresolved.

### Selector alternatives

### Pointer-write ordering
