2. **Obtain and retain the destination address.** F-aa8f83707009 is called with the first input and a second argument equal to zero. Its result is used as the destination address.

3. **Sample shared storage and perform the first destination write.** After F-aa8f83707009 returns, the function reads a shared 32-bit value and writes the sampled value at destination offset 0.

4. **Call the first temporary-area dependency.** F-3b3feb156f36 receives the address of the first temporary word. No return value from this call is consumed by this function.

5. **Call the second temporary-area dependency.** F-9a770d6f49ee receives the same address. Its returned value is consumed as a 32-bit word.
