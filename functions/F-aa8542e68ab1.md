### Narrow address input and breakpoint boundary

### Result publication and frame-like state change

The low word of C is written to `word(frame + 0x258)`. An unsigned halfword is then read from `high(C) + 0x14` and retained as **N**.

The routine forms an address component by shifting low(C) left six bits and forms **E** by multiplying high(C) by four. Both calculations involve represented signed 32-bit values, so their overflow boundaries remain qualified.

The frame-like base is then decreased by `0xf4`. The write at offset `0x258` therefore precedes this represented base change.

The routine forms **L = 4 × J** and writes low(C) to `word(L + 0x74)`. Since J is an unsigned halfword, J ranges from 0 to 65,535 and L ranges from 0 to 262,140; this scaling does not require 32-bit overflow.

The subsequent effects are interleaved with calls:

- F-000000000029 precedes a word write of zero-extended N at `D + 0x54`.
- F-000000000030 precedes a word write of zero-extended N at `D + 0x64`.
- F-000000000031 precedes a halfword write containing the low 16 bits of D. Its destination combines the previously formed `low(C) << 6` component with a register-carried address-like output associated with that call.

The two N-based word writes each have their upper 16 bits clear. Their final memory contents are not guaranteed to remain equal because intervening dependencies may alter memory.

### Breakpoint interruption
