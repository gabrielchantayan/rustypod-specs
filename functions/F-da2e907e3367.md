## Purpose

The established decision is:

- Return **0** if F-0a044f6748a6 reports zero.
- Otherwise, return **1** if the 32-bit state field at byte offset 4 from the first argument equals exactly 1.
- Otherwise, call F-d7be9cfb4000 with the difference between the values designated by the third and second arguments. Return **1** if the auxiliary output tested after that call is zero; return **0** otherwise.
