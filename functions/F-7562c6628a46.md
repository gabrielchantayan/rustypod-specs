## Side effects

The visible sequence performs byte and 32-bit word stores to computed addresses, including byte writes at absolute addresses `0x0d` and `0x11`. Those addresses are not established to represent globals, device registers, or valid writable memory.

The listed order applies even when writes appear redundant. In particular, the phase-4 absolute `0x11` write precedes the repeated slot-relative byte write.

Aliasing may connect otherwise distinct address expressions. A write may affect a later read, including a byte used to select another write address. Reads separated by calls cannot be collapsed on an assumption of stable memory.

## Acceptance examples

These examples are conditional consequences of the static representation, not executed tests.

1. **Unsigned byte addressing.** If the initial byte read yields `0xff`, the first byte store targets `0x110`. Sign-extending the byte would not match the represented behavior.

2. **Field extraction and truncation.** If the argument word is `0xffffffff`, the ten-bit field is `0x3ff`. The duplicated masked-field arguments are each `0x3fe00000`; the later field-derived word store contains `0xff800000`.

3. **Raw-index arithmetic.** If the raw index is `0xc0000001`, the early word store writes `0x00000004` at `0x00000024` under 32-bit truncation. The retained masked index is one and the quarter-index is zero.

4. **Required phase-4 write order.** If the slot index is one and the raw index is three, immediately after the `D-09` four-call chain the first write is byte `0x10` at absolute `0x11`. The next write is byte `0x0c` at `0x1d`. Reversing these accesses does not satisfy the contract, regardless of whether ordinary memory would ultimately contain the same bytes.

5. **Fresh byte selection.** If the first expanded-base byte read yields two and the later read yields nine, the compact-field byte write targets `0x13`, while the later zero write targets `0x1a`.

6. **Absolute overwrite.** If both absolute `0x0d` stores are reached, the selected byte is written first and `0xc0` later. Intervening dependencies may observe or alter that storage.

7. **Full word versus status byte.** If the phase-5 fresh word is `0x00000800`, the status byte is zero, but the later paired-result-directed word store contains `0x00000100`.

8. **Repeated final reads.** If the final two byte reads yield four and seven, their zero stores target `0x15` and `0x18`, respectively. Reusing the first read would be incorrect.

9. **Interrupted execution.** If the initial byte read faults, no later represented store is established to occur. No conversion to a returned error code is visible.
