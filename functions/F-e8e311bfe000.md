# F-e8e311bfe000

## Purpose

The established behavior is an ordered sequence of indirect calls, integer transformations, memory reads, and memory writes. The represented body contains no conditional branches or loops. It makes **113 dependency calls**, performs **19 explicit memory writes**, and then attempts a separate indirect call to address zero with three zero arguments.

No application-level purpose is established. Repeated scaling and offsets do not establish allocation, serialization, device initialization, or a particular data structure. Likewise, the names assigned to global roles below do not establish service semantics.

This contract describes the supplied static representation. It does not establish that the represented execution is feasible in an ordinary process address space.

## Interface

The visible interface has four 32-bit input slots:

### Implicit inputs and retained state

## Acceptance examples

These are conditional static criteria, not executed tests. They assume all relevant earlier operations complete and the selected accesses are valid.

- **Unsigned input extraction:** Input 4 equal to `0xFF800000` supplies `0x1FF` to F-dep-003. A signed arithmetic right shift would not match.
- **Selected-byte destination:** If the first selector read returns `0xFE`, its write targets address `0x10F`. With entry selector A equal to `0xABC00000`, the written byte is `0xAF`.
- **Fresh selector reads:** If the two selector reads based on entry selector B return 5 and 9, their zero writes target addresses 22 and 26. Reusing the first byte is incorrect.
- **Truncation versus retention:** A payload read yielding `0x123456AB` causes byte `0xAB` to be written at base B plus 1. The subsequent payload writes retain all 32 bits, `0x123456AB`.
- **Repeated base-A transfer:** If base A plus 116 changes between the two reads, the second base-A byte write reflects the second read.
- **Scaling loss:** Under 32-bit modular arithmetic, scale source `0x40000001` yields scaled word 4. F-dep-059 receives `0x00010000`; the discarded high bits are not recovered.
- **Saved global address:** If G-pointer changes during F-dep-087 through F-dep-091, the global-payload read still uses the saved global base. If those calls instead change memory at that base plus 20, the read observes that memory when reached.
- **Final global composition:** If G-upper supplies `0x123456` and F-dep-113 supplies byte `0xAB`, the final assigned G-control value is `0x123456AB`, provided overlapping writes do not change the supplying storage before it is read.
- **Potentially unaligned halfword:** Final low word `0xFFFFFFFF` yields final halfword destination `0x007FFFFF`. Its odd alignment makes successful completion environment-dependent.
- **Terminal failure:** Where address zero is not callable, normal return is not established. Earlier completed writes have no represented rollback.
