# F-0b737b24b057

2. Obtains an address through a dependency operating on an embedded receiver region and reads one 32-bit word from that address.
3. Calls two dependencies in sequence, passing the first result into the second.
4. Uses the second result as an **associated address**, supplying it and the previously read word to another dependency.

6. Passes the local payload through two dependencies.
7. Writes a derived 32-bit value at an offset from the associated address.
