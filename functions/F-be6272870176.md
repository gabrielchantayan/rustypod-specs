# F-be6272870176

## Purpose

Its direct effects distribute an inherited byte, literal zero, address-derived bytes, and extracted fields to computed destinations. Two halfword observations and a late word update also participate in the interaction sequence.

The supplied representation does not establish an application-level purpose. In particular, neither the repeated writes nor the global-byte assignment establishes initialization, reset, decoding, or device-control semantics.

This contract distinguishes:

- **Established static evidence:** visible access widths, value relationships, retention, and ordering.

All requirements are conditional on execution reaching the relevant operation. No runtime tests have been performed.

8. **Three-bit field, not Boolean.** Captured upper bytes 0xE0 and 0x1F produce field values seven and zero. Later representation changes do not reduce seven to zero.
