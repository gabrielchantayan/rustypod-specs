## Behavior

### Observable sequence

1. Invoke dependency **F-D01**, passing base plus `0xB4`.
2. After F-D01 returns, read four bytes beginning at base plus `0x44` and retain that value as the pending result.
3. Invoke dependency **F-D02**, passing base plus `0xB4`.
4. After F-D02 returns, return the retained four-byte value.

F-D01 and F-D02 are document-local opaque function IDs for the two distinct dependencies. Their identities beyond these call positions are unknown.

The read does not precede F-D01. The pending result is obtained before F-D02 is invoked. There is no second explicit read from the base-relative value location after F-D02 returns.

The two dependency arguments use the same supplied base and the same displacement. No explicit argument transformation distinguishes the first call from the second.

### Effects of dependency mutations

F-D02 runs after the pending result has been obtained. An ordinary write by F-D02 to the original four-byte location does not cause this function to reload that location. Consequently, the returned value can differ from the contents left in memory when the function returns.
