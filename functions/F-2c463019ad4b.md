## Acceptance examples

These are **conditional acceptance examples**, not executed tests. They assume the relevant prefix is reachable, the specified dependencies return, required memory is accessible, and the inferred word-width arithmetic applies.

1. **Initial byte destination.** If the first byte read yields 255 and the incoming byte value is 171, the initial byte write targets numerical address 272 and stores 171. It does not target the incoming pointer plus 17.

2. **Fourth-input truncation.** A fourth input of 1 produces T = 1024. A fourth-input bit pattern of 0x00400000 produces T = 0 after word-width truncation. The two F-U04 arguments and the subsequent T store must use that same transformed word.

3. **Separation of paired halves.** If F-U04’s paired result has H = 3 and L = 1, the first subsequent word store targets address 32 and stores T. The later low-half-derived store targets 0x10000014 and stores 0x04000000.

4. **Masked extraction.** If L is 0xFFFFFFFF, the value written after F-U07 is 0x000FFFFF. A sign-propagating right shift would not satisfy the represented unsigned extraction.

5. **Aliasing at a zero selector.** If F-U14’s final selector is zero, its following scaled-address store writes zero at address 20. The subsequent explicit word read is also at address 20. With ordinary stable memory and no external modification, W is zero.

6. **Distinct repeated reads.** If the two word reads used for F-U09’s arguments observe different values, the first and third arguments derive from their respective observations. A single cached read is not required or justified.

7. **Final byte truncation.** If Q is 0xFFFFFFFF, the first final byte store writes 252 and the second writes 255. Neither stores an entire shifted word.

8. **Reread-sensitive destinations.** If the first late byte read yields 2 and the later reread yields 7, the corresponding byte writes target addresses 19 and 24. Reusing the earlier byte for both is incorrect.

9. **Partial execution.** If a dependency fails to return after an explicit store, no later store is required to occur. The contract provides no rollback of the completed store.
