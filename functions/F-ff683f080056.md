# F-ff683f080056

## Purpose

F-ff683f080056 performs a long, ordered sequence of indirect dependency calls and memory updates. Its directly visible effects include:

- Writing 32-bit values into several index-derived locations.
- Copying the low byte of selected 32-bit words into byte fields.
- Updating byte locations through a second level of byte-sized addressing.
- Reading one distinguished global word twice and assigning another distinguished global word twice.
- Clearing a dependency-supplied byte location and a derived 16-bit location.
- Finally attempting to call address zero with three zero arguments.

The supplied representation does not establish an application-level purpose. Descriptions such as initialization, object construction, serialization, or supervisor dispatch would be inferred intent, not established behavior.

This contract describes the visible sequence conditionally: each later operation requires all preceding calls and memory accesses to complete normally. It does not promise successful completion or a normal return.

## Behavior

### Dependency-call ordering

The body is a single visible linear sequence: no conditional branch or loop is shown. Calls separate many of the direct reads and writes below. They are observable operations and cannot be discarded merely because their displayed return values are unused.

A recurring pattern obtains a word from one dependency and forwards it to another, followed by several further calls. Other calls supply indices, paired results, or secondary register values used by subsequent accesses.

The following phases preserve the order of direct memory effects and consequential argument forwarding. Intervening dependencies remain part of that order. They must not be assumed to preserve globals or memory.

### 1. Initial word stores and linked reads

The first dependency receives the second explicit input. Its target is derived from incoming link state.

After an intervening call sequence, an index is returned. The function:

1. Writes the second additional entry-state word to that index’s slot.
2. Reads a word at the address obtained by logically shifting the unsigned entry-state value right by 22 and adding 20.
3. Passes the first index scaled by four to a dependency.

After another call sequence, a second index is returned. Using the word read in step 2, the function:

4. Writes the second index scaled by four to the slot selected by the read word shifted right by one.
5. Reads another word at the unshifted read word plus 20.
6. Passes the read word shifted right by one to a dependency.

After another call sequence, a third index is returned. The function:

7. Writes the second index scaled by four to the third index’s slot.
8. Reads Global A.
9. Passes the third index scaled by four to a dependency.

The reads in steps 2, 5, and 8 occur after their preceding stores. If their addresses overlap, they observe the resulting memory state rather than an assumed entry snapshot.

### 2. Shifted values and explicit zero stores

Following further calls, a secondary result supplies another slot index.

The function shifts the word from step 5 right by 22. It also shifts the captured Global A word right by 23. It then:

1. Writes the first shifted value to the secondary-result-selected slot.
2. Calls a dependency with the slot index repeated twice, the shifted Global A value, and the first shifted value.
3. Calls further dependencies, including forwarding a returned word.
4. Writes the first shifted value to a newly returned index’s slot.

A further secondary result supplies another index. The function:

5. Writes zero to that index’s slot.
6. Calls a dependency with that index.
7. Executes another call sequence.
8. Writes the captured Global A value shifted right by 23 a second time to a newly returned index’s slot.

The value in step 8 is necessarily zero under the displayed unsigned 32-bit interpretation: shifting the original word right by 23 leaves at most nine bits, and shifting that result right by another 23 removes them all.

The function next reads a word at:

- The secondary index from step 5, masked to its low 29 bits;
- Then shifted right by 19;
- Then increased by 20.

This is not the same address calculation as a four-byte slot lookup.

### 3. First byte-indirected updates

After further calls, the most recently read word is shifted right by 22.

The function reads a byte at address one and writes the low byte of that shifted word to the read byte’s value plus 17.

The address-one read follows from the previously double-shifted Global A value being zero. This is an arithmetic consequence of the displayed widths, not evidence that address one is valid.

A dependency then receives a secondary result repeated three times and a fourth argument of zero. Subsequent calls include a call with zero.

The function then:

1. Reads a byte at four times the shifted word plus one.
2. Writes zero to that byte value plus 17.
3. Passes a newly returned index scaled by four to a dependency.
4. Executes further calls.
5. Passes another newly returned index scaled by four twice to a dependency.
6. Obtains a new word result and forwards it to another dependency.

Following another call, the function freshly reads the byte at address one and writes zero to that byte value plus 17.

Those address-one reads are distinct observations. Earlier writes and intervening callees may change their values.

### 4. Global assignment and word-to-byte copies

After further calls, including forwarding a word together with the preceding word result shifted right by 23, the function:

2. Saves its zero-extended value as a small base address.

It then executes more calls, including calls receiving a returned index scaled by four, and later the same scaled index twice.

A newly returned word is assigned to Global B before being forwarded to another dependency. After another call, the function reads a word at the saved small base plus 116 and writes its low byte to that same base plus one.

Next:

1. A dependency receives the captured secondary result shifted left by 11.
2. Another dependency returns a represented 64-bit result.
3. A dependency receives its low half, high half, and the word just assigned to Global B shifted right by 23.

The function uses that index scaled by four as a new base. It reads a word at base plus 116 and writes the low byte to base plus one. A dependency then receives the base.

After further calls return another index, the function saves that index scaled by four. Before proceeding, it repeats the word read at the previous base plus 116 and byte write at that base plus one.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Early slot write.** If the first index-producing call returns 3 and the additional entry word is 9, the first direct word store writes 9 at address 32, provided the access is valid.

2. **Different linked-read addresses.** If the early selected word is 8, its right-shift-by-one slot address is 36, while the following word read is at address 28. An implementation must not substitute one address calculation for the other.

3. **Double-shift zero.** Even if the first Global A snapshot is the maximum unsigned word, its first shift by 23 yields 511 and the subsequent shift by 23 yields zero. The corresponding slot store is zero, and the related byte lookup is at address one.

4. **Byte truncation.** If a base-plus-116 read returns decimal 4660, the base-plus-one write stores byte value 52. Where the full word is retained for later distribution, it remains 4660.

5. **Fresh repeated read.** If an intervening dependency changes a word between the two copies from the same base-plus-116 location, the second copy uses the changed word.

6. **Byte-indirected addressing.** If a selected byte lookup returns 200, the resulting byte write is at address 217, not at an address scaled by four.

7. **Independent global snapshots.** If a dependency changes Global A before its second read, the later Global-A-derived word lookup uses the second value.

8. **Terminal failure.** If address zero is not callable, normal return is not an acceptance requirement. The preceding byte clear, Global B assignment, and halfword clear still precede the attempted call if execution reaches them.
