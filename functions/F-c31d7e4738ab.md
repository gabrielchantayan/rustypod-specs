# F-c31d7e4738ab

## Purpose

F-c31d7e4738ab performs an ordered sequence of indirect calls, computed-address memory transfers, bit-field extraction, and global updates. It has no explicit parameters or explicit return value. Its final action before a possible return is a call to address zero with three zero arguments.

**Established static evidence:** the supplied representation establishes the access widths, address expressions, call ordering, explicitly supplied arguments, and consumed results described below. Each later effect is conditional on all preceding calls returning and memory accesses succeeding.

**Inferred intent:** repeated four-byte scaling and byte-selected destinations suggest indexed storage transfers. No application-level object model, protocol, instruction set, or ownership model is established.

This is a static behavioral contract, not evidence that the routine can execute successfully in a particular environment.

### Widths, addressing, and notation

A byte is 8 bits, a halfword 16 bits, a word 32 bits, and a wide result 64 bits. A wide result’s low and high halves are bits 0–31 and 32–63 respectively. “Low byte” means bits 0–7; a byte store discards all higher bits.

The following address descriptions are used:

- **Slot address:** four times an index, plus 20.
- **Scaled base:** four times an index.
- **Selected destination:** read an unsigned byte at a specified selector address, then add 17 to its value. The destination therefore lies between addresses 17 and 272.

A selected destination is not obtained by loading a pointer.

Unsigned right shifts are logical. Word reads used for field extraction are unsigned. The retained value called **scaled later index** below is unsigned, so its right shift by two is logical.

Many dependency indices are represented as signed 32-bit values. Their multiplication, left shifts, and address additions have unresolved signed-overflow semantics. A 32-bit modular interpretation is useful conditionally, but is not asserted as the unconditional execution model. Address-space width and integer-to-address conversion are also unresolved.

### Preconditions and completion

There is no visible validation of call targets, memory permissions, alignment, object bounds, or secondary results. Successful execution requires each reached access and call to be valid under the actual environment.

The routine has no explicit error result. Normal return is possible only if the final zero-address call returns. An earlier failure may leave already-performed writes intact.

## Acceptance examples

These are conditional static criteria, not executed tests. All require prior calls and accesses to succeed.

1. **Unscaled initial extraction.** An incoming unsigned selector of 0x00c00000 makes the first derived word read occur at address 23, not 32.

2. **Distinct linked addresses.** With first address word 10 and second index 3, phase 1 stores word 12 at address 40, then reads at address 30.

3. **Zero derivation and phase placement.** A first global snapshot of 0xffffffff produces global field 511 and collapsed field zero. Phase 3 stores the linked field and later clears the clear index’s slot. Phase 4 separately stores global field shifted right by 23, hence zero, and reads its first selector at address 1.

4. **Truncation with retained field width.** If phase 4’s word read yields 0xffffffff, the selected field is 1023. Its byte write carries 255, while phase 5’s selector address is 4093.

5. **Byte selection.** A selector byte of 200 selects destination address 217 without another pointer-sized dereference.

6. **Fresh reads.** If the first repeated-copy read yields 0x11223344 and intervening effects change that word to 0x55667788, the corresponding byte writes carry 0x44 and 0x88.

7. **Full-word preservation.** A preserved word of 0xaabbccdd produces a byte write of 0xdd, but subsequent preserved-word stores carry all 32 bits.

8. **Conditional arithmetic equivalence.** Under 32-bit modular arithmetic, later-index bit pattern 0xc0000001 produces scaled later index 4. F-1712’s argument is 0x00010000, equal to the original bit pattern shifted left by 16. This does not establish defined signed-shift behavior.

9. **Global timing and terminal overlap.** G-B receives the second forwarding word before F-1514. Its terminal update follows the secondary-pointer byte clear and subsequent three-byte read; overlap may therefore affect the constructed value.

10. **Completion boundary.** If the final zero-address call traps, the explicit return is not reached, regardless of earlier successful writes.
