# F-1c1375207113

## Purpose

F-1c1375207113 obtains a 32-bit value through an address stored in a caller-supplied location. If the stored address is null, it returns a 32-bit zero instead.

The null handling applies to the **stored address**, not to the function’s input pointer. The function must first access the location designated by its input to determine whether the stored address is null. No input-pointer validity check is shown.

This is an observational accessor: the supplied static representation contains no explicit writes, allocation, release, or dependency calls. It does not establish the meaning of the returned bits or the ownership of either accessed location.

## Interface

### Input

The function receives one pointer argument designating an address-bearing storage location.

The supplied representation uses an integer-sized storage slot for the stored address and treats that value as a pointer when deciding whether to access a second location. This supports a 32-bit address-slot interpretation for the represented target. The representation does not independently establish the platform ABI or justify treating the slot as a native-width pointer on a different target.

The input layout relevant to this function is:

| Location | Required content | Role |
|---|---|---|
| Location designated by the input | One address-sized value, represented as a 32-bit integer slot | Selects whether and where a second access occurs |
| Location designated by a non-null stored address | Four readable bytes | Supplies the result |

Only the first slot of the input location is used. No additional fields, lengths, tags, or terminators are inspected.

### Output

The function returns one 32-bit value:

- If the address read from the input location is null, the result is all zero bits.
- If that address is non-null and the subsequent access completes, the result is the four-byte value read through the stored address.

The result should be understood as a bit pattern. The supplied representation does not establish signedness, an enumeration domain, a floating-point interpretation, or any application-specific meaning.

The function cannot distinguish a null stored address from a non-null stored address whose contents are zero through its return value alone.

No explicit mechanism enforces these conditions. In particular, a null input argument is not a supported shortcut for obtaining zero.

## Behavior

### Address selection and result selection

The function begins with a zero result available for the null-address case.

It obtains the stored address from the location designated by its input and compares that address with null. This initial access is required even when the function ultimately returns zero.

If the stored address is null, the function returns zero without an explicit access through that null address.

If the stored address is non-null, the function obtains a 32-bit value through an address read from the input location and returns that value. It does not apply a mask, shift, sign extension within the result width, arithmetic adjustment, range check, or content-dependent transformation.

Under stable-memory conditions, the behavior is therefore:

| Stored address | Target contents | Result |
|---|---|---|
| Null | Not accessed | 32-bit zero |
| Non-null and readable | Any four-byte value | That 32-bit value |
