# F-37dd54a89a78

On acceptance, the function invokes an action with selector 10, obtains a replacement 32-bit value, stores it, and clears the primary flag. It then checks a secondary flag and, if nonzero, invokes the same action dependency with selector 11 before clearing that flag.

### Accepted primary processing

1. F-5da1ad7278c2 is invoked with selector 10.
2. F-UNMAPPED-02 is invoked without explicit arguments.
3. The 32-bit result from F-UNMAPPED-02 is written to offset `0x460`.
4. A zero byte is written to the primary flag at offset `0x45e`.

The replacement value is stored as a 32-bit quantity. The function performs no explicit arithmetic, range checking, conversion, or error classification on that value. A zero result is stored just as any other result would be.

The existing field value is not explicitly released or otherwise processed by this function before replacement. That observation does not establish that it represents owned memory, nor that any dependency performs ownership management.

The primary flag is cleared only after both calls return and the replacement store occurs. It is not cleared before invoking either dependency.

### Secondary processing

After storing the replacement value and clearing the primary flag, the function reads the secondary flag at offset `0x45f`.

This is a fresh read at that point in execution. Its decision therefore uses any changes made before that read, including changes made by the earlier dependencies.

If the secondary flag is zero, the function returns without the secondary action.

If it is nonzero, the function:

- Invokes F-5da1ad7278c2 with selector 11.
- Writes a zero byte to the secondary flag after that call returns.
- Returns.

The secondary flag is not cleared before the selector-11 call. If that dependency changes the secondary flag and returns, the subsequent explicit zero write overwrites its change.

There is no later explicit restoration of the primary flag or replacement field. If the selector-11 call changes either field, those changes are not undone by this function.
