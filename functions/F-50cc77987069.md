## Behavior

### Source capture

The function captures the six global source values in first-to-sixth order, placing each value in its corresponding 32-bit payload word.

All six captures occur before payload transformation begins. They are individual ordered reads, not an established atomic snapshot. Concurrent changes could therefore affect which combination of values is captured; synchronization guarantees are unknown.

Subsequent transformations target the local payload. There are no explicit assignments naming the six source locations as destinations. This does not guarantee that their storage remains unchanged: dependencies may modify it, and the final indirect byte store may overlap it.

### Six unsigned shifts

After capture, the function processes the payload from the sixth word back through the first word. Each word is replaced by its unsigned 32-bit value shifted right by one bit.

For every word:

- The original least-significant bit is discarded.
- A zero enters the most-significant bit.
- The resulting value is the original unsigned value divided by two, rounded down.
- No sign extension occurs.

Exactly six payload words are processed. The traversal begins from a position immediately beyond the payload and moves backward before accessing a word; that initial position does not supply a seventh shifted value.

No dependency call occurs during these transformations. Reverse order is established by the body, even though independent shifts of ordinary private storage would produce the same final values in forward order.

### Three-byte-field narrowing

After all six shifts, the function reads the three-byte unsigned field at payload offsets 20–22, converts its value to unsigned 16-bit width, and assigns the converted value back to the three-byte field.

This operation:

- Retains the field’s low 16 value bits.
- Sets its upper eight value bits to zero.
- Does not write the adjacent byte at payload offset 23.

It is not another right shift. It is also not a conversion of the entire sixth word to a 16-bit value. The adjacent byte remains as produced by the earlier 32-bit shift, until some later operation changes it.

Only the sixth word has this additional overlapping-field transformation. The first five words receive only the unsigned shift.

The whole-word numerical effect depends on the representation’s byte order. Under a little-endian interpretation, the narrowing clears bits 16–23 of the shifted sixth word while retaining bits 0–15 and 24–31. That interpretation is conditional; byte order is not independently established here.
