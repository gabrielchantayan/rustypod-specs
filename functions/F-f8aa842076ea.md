# F-f8aa842076ea

## Purpose

F-f8aa842076ea specifies an operation whose observable boundaries are eighteen indirect calls, four coprocessor transfers, and an attempted 16-bit write to a computed low numeric address. The supplied representation has no established normal return: its final boundary is marked as invalid instruction data.

No application-level purpose is established. Names such as initialization, decoding, allocation, or device configuration would add unsupported meaning.

This contract distinguishes:

- **Established static evidence:** represented inputs, call ordering, data dependencies, access widths, and the terminal boundary.
- **Conditional arithmetic deductions:** consequences of interpreting ordinary values as 32-bit words and paired results as 64-bit bit patterns.
- **Documented-only unknowns:** dependency behavior, machine-specific execution rules, memory accessibility, ownership, and the consequence of the invalid-instruction boundary.

All completion claims are conditional on execution reaching the relevant boundary. A call or coprocessor transfer may prevent every later effect.

### Value model

A **word** is a 32-bit bit pattern. A **wide result** is a 64-bit bit pattern, divided into lower and upper 32-bit words.

For the conditional arithmetic model used here:

- Left shifts discard bits beyond the 32-bit word.
- Logical right shifts insert zeros.
- Splitting a wide result selects bits, not bytes in memory.
- A 16-bit store writes the numeric halfword value, not a single byte.

Some represented expressions use signed integer types for left shifts. The supplied material does not establish portable signed-language semantics for those expressions. The truncating bit-vector interpretation is therefore an explicit condition of the arithmetic deductions, not proof of the underlying architecture.

### Shared word transformations

The **masked word** is obtained by retaining the bottom two bits of the spread word and shifting them left by sixteen bits.

Under the stated 32-bit model, the masked word is always zero: forming the spread word already clears its bottom four bits. This is an arithmetic invariant, not a runtime check.

Two call arguments depend on that invariant:

- F-000000000009 receives the masked word shifted left by eight bits.
- The second argument of F-000000000011 is the masked word shifted left by twenty-five bits.

Both arguments are therefore zero under the model. Neither call may be treated as unnecessary: their dependency effects remain unknown.

F-000000000005 receives one explicit zero argument and returns a word. F-000000000006 receives three arguments:

1. The spread word shifted left by eight bits.
2. The spread word shifted left by twelve bits.
3. The result of F-000000000005 shifted left by nine bits.

The result of F-000000000006 is not explicitly consumed.

### Paired-result exchanges

**First exchange.** F-000000000007 has no explicit arguments and returns a wide result. F-000000000008 receives its lower word, its upper word, and its lower word shifted left by one bit, in that order. No result from F-000000000008 is explicitly consumed.

### Destination and write contract

Define the **selector** as the uppermost twelve bits of the wide result returned by F-00000000000e.

The represented extraction first performs a logical 64-bit right shift by 41 bits and narrows the result to 32 bits. That intermediate has at most 23 significant bits and is therefore nonnegative as a signed 32-bit value. Its subsequent signed right shift by eleven bits consequently introduces no sign extension under the stated model. The combined extraction selects exactly bits 52–63.

The destination address is:

**selector + floor(selector / 4)**

No additional base pointer, relocation, or region offset is represented.

Consequences under this model:

- The selector ranges from 0 through 4,095.
- The destination ranges from 0 through 5,118.
- The address arithmetic does not overflow 32 bits.
- Zero and odd addresses are possible.
- Some addresses within the range are never selected.

After all preceding calls, the operation attempts to store the 16-bit value 205, hexadecimal 00CD, at that address.

A successful conventional two-byte memory access affects the destination and the following byte. Byte order is unknown. Alignment faults, device-specific access behavior, memory translation, and partial effects of a failing access are not established.

The representation ends at an invalid-instruction boundary after this write. It does not establish a return, cleanup, intentional halt, particular exception, or continuation beyond that boundary.

## Acceptance examples

These are conditional static acceptance cases, not executed tests.

1. **Word-width truncation.** If entry register 3 contains hexadecimal 00000400, its first argument to F-000000000001 is zero and its second is hexadecimal 00200000 under the word model. Retaining a 33-bit first argument would violate that model.

2. **Logical entry shift.** If entry register 5 contains hexadecimal FFFFFFFF, the second argument to F-000000000002 is hexadecimal 07FFFFFF, not FFFFFFFF.

3. **Zero-valued consumers.** For any initial reply, the argument to F-000000000009 and the second argument to F-000000000011 are zero under the model. Both calls still occur if preceding interactions complete.

4. **Wide-result significance.** If F-000000000007 returns hexadecimal 123456789ABCDEF0, F-000000000008 receives hexadecimal 9ABCDEF0, 12345678, and 3579BDE0, in that order. This expectation does not depend on byte order.

5. **Lowest destination.** If the selector is zero, the attempted destination is address zero. There is no represented null-address guard or substitute destination.

6. **Gaps and alignment.** Selectors 3 and 4 produce addresses 3 and 5. Address 4 is skipped, and the selected address may be odd.

7. **Maximum destination.** Selector 4,095 produces address 5,118. A successful conventional two-byte store affects addresses 5,118 and 5,119.

8. **Signed-shift boundary.** If F-00000000000e returns all one bits, the 41-bit logical shift produces hexadecimal 007FFFFF. The later signed shift yields selector 4,095, not a negative value.

9. **Interrupted progress.** If F-000000000010 never returns, F-000000000011, F-000000000012, and the explicit write are not reached. No bypass is represented.

10. **Rejected access.** If the destination rejects halfword writes, successful mutation cannot be claimed. The representation supplies no local recovery contract.
