# F-654a426acf73

## Purpose

F-654a426acf73 computes an integer from a conditionally obtained base value and a scaled displacement.

The base is zero when a caller-provided address slot converts to a null pointer. Otherwise, the base is the integer obtained by dereferencing the address represented by that slot. The displacement is the second argument multiplied by four. The function returns the sum.

This is an integer-returning operation. Although its result could be intended for address or offset calculations, the supplied evidence does not establish that interpretation. It does not show the function returning a pointer, accessing the location described by its result, allocating storage, or changing an object.

## Interface

### Inputs

The function takes two arguments:

1. **Address-slot reference.** A pointer to an integer-sized slot. The slot’s contents are converted to an integer pointer and examined for nullness. On the non-null branch, the slot supplies the address used for an integer load.
2. **Displacement.** A signed integer multiplied by four before being added to the selected base.

The first argument is a reference to a slot, not directly the optional base-value pointer. There are two distinct levels of access:

- The outer reference identifies the address slot.
- The value in that slot, after conversion to a pointer, identifies the optional integer base.

A valid slot containing a value that converts to a null pointer is therefore different from a null outer reference. The former selects a zero base. The latter does not receive a protective check.

### Output

The function returns one integer:

**selected base + displacement × 4**

The selected base is either zero or the integer read through the address slot.

There is no separate success indicator, output parameter, or explicit error return. Zero is a possible ordinary result and is not established as an error sentinel.

## Behavior

### Base selection

The function initially selects zero as its base.

It then reads the address slot through the first argument and converts the resulting integer to an integer pointer. If that pointer compares equal to null, the base remains zero. No indirect base-value access is requested on this branch.

If the converted pointer is non-null, the source expression obtains the address-slot value again, converts it to an integer pointer, and reads an integer through that pointer. That loaded integer becomes the selected base.

This distinction matters for changing storage: the non-null branch is selected using one evaluation of the slot, while the dereference expression contains another evaluation. The excerpt does not retain the first evaluated address as an explicitly saved pointer for the subsequent load.

For ordinary, stable memory, both evaluations identify the same slot contents. For memory that changes between evaluations, the excerpt does not establish a safe or atomic “check this exact address, then use this exact address” operation.

### Arithmetic and return

After selecting the base, the function multiplies the displacement by four and adds the selected base. The resulting integer is returned.

The multiplier is the integer value four. The evidence does not establish that it denotes an element size, a byte stride, a particular object layout, or a requirement that the returned value be aligned.

Negative displacements are not rejected. A negative loaded base is also not rejected. Both participate in signed arithmetic subject to the target’s representable range and execution semantics.

No bounds check, saturation, clamping, or explicit overflow check appears. In particular, a multiplication that overflows cannot be justified by a subsequent addition that would bring the mathematical total back into range.

The supplied evidence does not establish modulo wrapping as the contract for signed overflow. Exact overflow behavior requires target-level evidence or an applicable execution-language guarantee.

1. Read the address slot for the null-pointer comparison.
2. On the non-null branch, evaluate the slot again and load the integer at the resulting address.
