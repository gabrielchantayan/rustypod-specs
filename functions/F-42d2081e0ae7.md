# F-42d2081e0ae7

## Purpose

F-42d2081e0ae7 returns the nonnegative magnitude of a signed integer whenever that magnitude is representable in the function’s integer type.

For a nonnegative input, the result equals the input. For a negative input with a representable positive counterpart, the result equals that counterpart.

The most-negative value requires separate treatment: in a conventional fixed-width signed representation, its positive magnitude may not be representable. The supplied evidence does not establish a portable return value for that case. In particular, this contract does not promise saturation, an unsigned result, a wider result, or preservation of the negative input.

## Behavior

### Defined magnitude domain

The function makes a signed comparison of the input against zero.

- If the input is zero or positive, it returns the input unchanged.
- If the input is negative, it applies arithmetic negation and returns the resulting signed value, provided that result is representable.

For inputs in the representable-magnitude domain, this establishes the following properties:

- The result is nonnegative.
- Zero produces zero.
- Positive values retain their exact value.
- Negative values produce the corresponding positive magnitude.
- Positive and negative inputs of the same representable magnitude produce equal results.
- Applying the function again to an ordinary result leaves that result unchanged.

There is no rounding, scaling, clamping, modulus operation, or explicit range conversion in the supplied behavior.

### Order of evaluation

The established logical order is:

1. Inspect the signed input to determine whether it is below zero.
2. Perform negation only for a negative input.
3. Return the unchanged or negated value.

No dependency invocation or explicit external-memory access occurs between these operations in the supplied evidence.

This describes the function’s logical behavior, not a guaranteed machine-instruction sequence. The evidence does not establish whether an executable uses a branch, a conditional operation, or another equivalent instruction sequence.
