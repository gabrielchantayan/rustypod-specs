# F-3296137c6dab

## Purpose

F-3296137c6dab constructs a linked record using storage returned by one dependency and a four-byte value returned by another, then publishes the record through a caller-supplied memory slot.

The established behavior is a sequence of two dependency calls followed by four memory writes. The record receives:

- A four-byte value obtained from the second dependency.
- A four-byte value read from the destination’s existing slot.
- A one-byte value supplied by the caller.

The destination slot is then replaced with the address of the record.

**Inferred intent:** this resembles inserting a record at the front of a singly linked collection. The existing slot value becomes a link in the new record, and the slot becomes the new collection head. The source does not establish the application-level meanings of the collection, the one-byte field, or the value returned by the second dependency.
