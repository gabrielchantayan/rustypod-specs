# F-4c7a1523c7ce

## Purpose

The selection is strictly prioritized. A zero result from an earlier comparison prevents all later selection stages from running. The selected return value is not itself tested for zero before return: a successful comparison may therefore select a zero return value.

The established behavior is value selection, not string lookup, validation, or error reporting. A prioritized lookup with defaults is a reasonable interpretation of intent, but the supplied evidence does not establish the semantic meaning of the input, comparison operands, or returned values.
