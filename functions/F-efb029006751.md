## Acceptance examples

These are conditional static cases, not executed tests.

1. **Input order.** Inputs 0x11223344 and 0xAABBCCDD produce first-call arguments 0x11223344, 0xAABBCCDD, 0xAABBCCDD, 0x11223344.

2. **Selected destination.** A selector byte of 0x7F selects address 0x90. It does not identify a pointer-sized pointer.

3. **Fresh selectors.** If two selector reads return 2 and 9, their stores target addresses 19 and 26. Calls or aliasing may explain the difference; caching the first selector is unacceptable.

4. **Narrowing.** A byte store supplied 0x1234 writes 0x34. Masking 0xFFFFFFFF to 30 bits and shifting right by 20 produces 0x3FF, whose stored low byte is 0xFF.

5. **Address-48 arguments.** The contract contains one invocation with four occurrences of that word expression. It does not require four invocations or establish argument-read order.

6. **Reset mutation.** If a dependency changes the reset word to 0x00800000 and that value remains present until the first capture, R₁ is 0x00800000. If another dependency or aliased store changes it before capture, the capture instead observes the value then present.

7. **First-capture arithmetic.** If R₁ is 0xFFFFFFFF, its first right-by-23 value is 0x1FF and its second right-by-23 value is zero. A later reset-word mutation does not change either retained derivation.

8. **Separate second capture.** If R₁ is 0xFFFFFFFF but R₂ is 0x1000, the second capture’s dependent word read uses address 0x1014, assuming ordinary non-overflowing addition. Substituting R₁ or the earlier assigned zero is unacceptable.

9. **Read-time contents.** If memory at 0x1014 changes between capturing R₂ and its dependent read, the read obtains the contents present when it executes. Capturing R₂ does not capture that memory word.

10. **Terminal composition.** Final byte 0x5A and 24-bit source 0x123456 compose numeric value 0x1234565A, conditional on those values being present at their respective observations.

11. **Partial execution.** If a dependency does not return, later writes and the terminal invocation need not occur.
