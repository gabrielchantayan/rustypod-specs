## Behavior

### Trace conventions

The displayed path contains no explicit loop or conditional branch.

A **four-call interval** consists of four successive indirect calls with no displayed arguments. When an interval supplies a value, that value is the final call’s result. Otherwise, the displayed results are unused.

A **forwarding interval** consists of:

1. One call with no displayed arguments.
2. One call receiving that call’s returned word.
3. A trailing four-call interval.

Unless additional arguments are stated, the forwarding call receives only the returned word. A forwarding interval therefore contains six calls, including five with no displayed arguments. Its final result is the final result of the trailing four-call interval—not the fourth no-displayed-argument result counted across the entire forwarding interval.

All dependency occurrences belong to the unresolved set F-U001. These conventions describe call order, not shared target identity, purity, or interchangeable results. Payload names below identify retained values without implying ownership or object identity.

These are conditional static deductions, not executed tests. Each assumes execution reaches the stated operation and the relevant accesses complete.

1. **Quotient boundary.** Fourth arguments zero through seven produce quotient zero. The quotient-dependent store targets address 20 and writes zero. Fourth argument eight instead targets 2,097,172 and writes 524,288.

2. **Maximum input with wrapping.** Fourth argument 4,294,967,295 produces quotient 536,870,911. Under the 32-bit arithmetic model, the quotient-dependent store targets 4,292,870,164 and writes 4,294,443,008.

3. **Byte truncation.** First payload 1,073,741,823 produces first scaled payload 4,294,967,292. Its low-byte store writes 252; its bits-20-through-27 store writes 255.

4. **Fresh selectors.** If the first two reads at input quotient plus one return five and nine, their corresponding byte destinations are 22 and 26. Reusing the first selector for the second store would violate the trace.

5. **Correct forwarding-result selection.** Suppose the forwarding interval before the central-base reread has an initial no-displayed-argument result of 11, followed by trailing four-call results of two, three, five, and seven. After the selector reread and clear, the dependency receives 28. It does not receive 20 from the fourth no-displayed-argument call overall, or 44 from the initial call.

6. **Distinct earlier shift source.** If the earlier shift source is three while the central-clear continuation result is seven, the later four-argument shift invocation still derives its arguments from three. The call immediately after the central-base reread and clear instead receives 28.

7. **Later continuation selection.** If the forwarding interval preceding the repeated reduced-payload selector read ends with result nine, the dependency after that read and clear receives 36. Results from the four-call interval that occurs afterward cannot supply this argument.

8. **Penultimate continuation.** A penultimate continuation result of nine makes the dependency after the penultimate payload’s bits-20-through-27 store receive 36. The following four-call interval separately supplies the final payload.

9. **Zero does not trigger explicit rejection.** A zero destination-selecting word produces address 20 for a four-times-result-plus-20 store. Whether the access succeeds depends on the environment.
