# F-1823302f0a1d

## Purpose

F-1823302f0a1d conditionally obtains an eight-byte, two-word result from an object-like input. It first applies eligibility checks and, if those checks permit processing, prepares a temporary value, invokes a processing dependency, conditionally updates two object-relative destinations, and performs a final dependency call before publishing the result.

An ordinary rejected path publishes the pair **0xffffffff, 0**. An admitted path publishes the final contents of a working pair whose initial contents are **0, 0** and which is exposed to dependencies before publication.

These are behavioral descriptions, not established domain meanings. The evidence does not identify the result as a handle, range, position, resource, or other specific abstraction. In particular, the pair **0xffffffff, 0** is the rejection representation, but the evidence does not establish that an admitted path cannot produce the same pair.

## Interface

### Inputs

The function receives three arguments:

1. **Output address.** An address at which two consecutive 32-bit words are written on ordinary completion. The output occupies eight bytes.
2. **Object address.** A pointer to storage used both by dependencies and by direct field accesses. Direct field access uses four-byte word spacing.
3. **Control value.** A 32-bit integer. Zero and nonzero select different eligibility rules; its sign and magnitude otherwise have no visible effect.

The function has no explicit return value. Its directly published result is the two-word output.

## Behavior

### Eligibility and preliminary effects

F-cf17a2203afd is called first with the object address.

If its result is zero, the function performs no other dependency calls and publishes the rejection pair.

If its result is nonzero, including a negative result:

1. F-e4011efab98e is called with the address at object offset 44.
2. F-35cac9dbc6c0 is called without explicit arguments.
3. Its result is interpreted as a signed 32-bit integer for the next eligibility decision.

F-35cac9dbc6c0 is called even when the control value is zero. Zero control bypasses the restriction imposed by its result; it does not bypass the call or its possible effects.

Eligibility proceeds as follows:

- With zero control, the function proceeds to the indirect call regardless of the signed result from F-35cac9dbc6c0.
- With nonzero control, the function proceeds only if that result is strictly positive.
- With nonzero control and a zero or negative result, the function publishes the rejection pair without reading or invoking the indirect target.

The indirect-target lookup occurs after these preliminary dependency calls. The function therefore uses the object’s dispatch information as it exists at that later point, rather than a value captured on entry.

The indirect target is invoked with the object address. A zero result admits the processing path. Any nonzero result rejects it and causes publication of the rejection pair.

### Admitted processing

After a zero indirect-call result, the function reads the flag word at object offset 16.

If bit 0x00000002 is set, F-77b5790538ba is called with the object address. If the bit is clear, that call is omitted. Other flag bits do not directly affect this decision.

This flag read occurs after the indirect call. Changes made before that read can therefore affect whether F-77b5790538ba is called.

The function then establishes a working two-word value with both words zero. It also provides a separate eight-byte temporary region to F-75176395cf5a, together with the object address.

The temporary region has no visible initialization before F-75176395cf5a receives it. Its resulting contents and the extent of that dependency’s writes are not established by the supplied evidence.

Next, F-dd25b8fb230c receives:

- The address of the working two-word value.
- The address of the temporary region.

The return value from this invocation is not used by this function.

A second two-word local value is then initialized to **0xffffffff, 0**. F-521df88daa8c is called with the addresses of the working value and this second value.

Both arguments are addresses. The evidence does not establish that either is read-only. In particular, the working value may be changed by this dependency.

### Conditional object updates

The result from F-521df88daa8c controls two additional calls:

- If the result is zero, both calls are skipped.
- If the result is nonzero, including a negative result, both calls occur in order.

For a nonzero result:

1. F-dd25b8fb230c is called with the object-relative address at offset 60 and the address of the working value.
2. The 32-bit return value from that call is passed as the second argument to another F-dd25b8fb230c call, whose first argument is the object-relative address at offset 52.

The second call consumes the first call’s returned value. It does not visibly receive the working-value address directly. The meaning of the forwarded value is unknown; treating it as necessarily a pointer, success flag, or destination address would require additional evidence.

The return value from the second call is ignored.

A zero result from F-521df88daa8c does **not** itself cause rejection. It only suppresses these two conditional calls.

### Finalization and publication

Only after that call returns does the function publish the working value:

1. Store its first 32-bit word at the output address.
2. Store its second 32-bit word four bytes later.

The function does not publish the separately initialized **0xffffffff, 0** local value directly. That value is supplied to F-521df88daa8c; any effect it has on the result depends on that dependency.

On an ordinary rejected path, publication instead consists of:

1. Store **0xffffffff** at the output address.
2. Store **0** four bytes later.

The two stores are distinct and ordered in the visible implementation. No atomic eight-byte publication guarantee is established.

### Dependency-mediated effects

In particular:

- Preliminary calls may change object or global state before later eligibility checks and reads.
- The indirect call may change the flag word subsequently inspected.

The evidence does not prove that its contents remain unchanged during later calls through retained references or other indirect access. The published result is therefore the working value as read at publication, not necessarily a snapshot from immediately after F-521df88daa8c.
