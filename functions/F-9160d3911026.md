# F-9160d3911026

## Purpose

The established selection order is:

1. Obtain a value from F-3ad65987df9a and compare it with a global reference. A zero comparison result selects a first global result.
2. Otherwise, obtain a value from F-44362605ab79 using an address 40 bytes beyond the input address. Compare that value with a second global reference. A zero comparison result selects a second global result.
3. Otherwise, inspect a 32-bit field 44 bytes beyond the input address. The supplied representation reads this field twice. The second read determines whether to select a global fallback; if the second read is nonzero, the value from the first read is returned.

The available evidence does not establish what the compared values represent, what a zero comparison result means beyond branch selection, or what the selected results signify.
