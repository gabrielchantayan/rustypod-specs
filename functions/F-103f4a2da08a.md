# F-103f4a2da08a

## Purpose

F-103f4a2da08a obtains two unsigned quantities through dependencies, writes the smaller quantity to a first output, and writes a nonnegative unsigned difference, converted to a signed output type, to a second output.

The first quantity is obtained using an address 56 bytes beyond the input object address. The second is obtained by passing a dependency-produced value and the constant 1000 to another dependency.

For distinct, valid output locations, the intended numerical relationship is:

- First output: the smaller of the two obtained quantities.
- Second output: the amount by which the first quantity exceeds the second, or zero if it does not.

That interpretation has an important width qualification: a positive difference can exceed the largest representable signed 32-bit integer. The supplied evidence does not establish the target’s rule for that unsigned-to-signed conversion.

The function also has an observable write-order contract. It first writes the second obtained quantity to the first output. When that quantity is at least the first quantity, it overwrites the first output with the first quantity. Only afterward does it write the second output. A contract describing only the final minimum and difference would omit this behavior.

### Comparison and difference

If the second quantity is strictly less than the first:

- It computes the first quantity minus the second.
- It does not perform a second store to the unsigned output.
- It converts or assigns the difference to the signed result used for the final output store.

Because subtraction is reached only when the first quantity is greater, the unsigned subtraction does not underflow. Its possible positive results range from 1 through 4,294,967,295.

A result through 2,147,483,647 is representable in the signed output type. A larger result is not. The supplied source does not specify the target conversion rule for that case; the function must not be described unconditionally as producing a nonnegative signed remainder for every unsigned input pair.

If the second quantity is greater than or equal to the first:

- It selects zero for the signed output.
- It stores the first quantity to the unsigned output, overwriting the earlier store.

Equality takes this latter branch. It therefore causes two stores to the unsigned destination, even though both stores contain the same numerical value.

This is the last explicit memory write in the function. There is no further dependency call or output correction afterward.
