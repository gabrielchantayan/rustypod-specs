# F-54301695cd6c

## Purpose

F-54301695cd6c performs one of two narrowly scoped updates to caller-supplied storage, selected by a 32-bit integer input:

- For selector **2898**, it stores a normalized Boolean derived from a third input at byte offset **2302** from the supplied base address.
- For every other selector, it examines the 32-bit integer at the base address and replaces it with **1280** only when its current value is zero.

These are distinct operations. The special-selector operation does not perform the zero-to-default update, and the ordinary operation does not update the Boolean field.

The interpretation of 1280 as a default, and of the distant Boolean as a flag, is inferred intent. The established behavior is the specific read, comparison, and conditional or unconditional write described below. The surrounding storage’s application-level meaning is unknown.

## Behavior

### Selection and access order

The selector determines the branch before either target field is accessed. Exactly one branch executes.

The branches use different storage locations and have different access requirements. Their behavior must not be combined into an unconditional read of the initial integer followed by a selector-dependent update.

### Selector equal to 2898

The function evaluates whether the Boolean-source input is nonzero and writes that truth value to the Boolean field at byte offset 2302.

The observable target-storage operation is a write. There is no preceding read of that field and no read of the initial 32-bit integer.

Consequences include:

- A Boolean source of zero writes false.
- Positive and negative nonzero inputs both write true.
- The input is normalized; its low byte is not copied directly.
- The write occurs even if the Boolean field already contains the resulting value.
- The initial integer is not initialized to 1280 by this branch, even if it is zero.

The offset is measured in bytes, not in 32-bit integer elements. Decimal 2302 is hexadecimal `0x8FE`.

The supplied representation performs address arithmetic after converting the base address to an integer. Valid execution therefore requires the resulting effective address to identify the intended field under the target’s address model. Behavior at address-space boundaries, including arithmetic overflow or wrapping, is not established.

### Selector different from 2898

The function reads the 32-bit integer beginning at the base address and compares the full integer with zero.

If the value is zero, it writes the 32-bit integer 1280, hexadecimal `0x00000500`, to that same location.

If the value is nonzero, it returns without a target-storage write.

Consequences include:

- Every nonzero initial value is retained, including negative values.
- The Boolean-source input has no effect.
- The Boolean field at byte offset 2302 is neither read nor written.
- The zero case has a read followed by a write.
- The nonzero case has a read but no write.

The integer assignment specifies the resulting numeric value. The supplied material does not establish byte order, so the contract does not prescribe a particular four-byte sequence for that value.
