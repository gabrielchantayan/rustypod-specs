# F-049f25d41fb1

## Purpose

F-049f25d41fb1 conditionally writes the byte value 1 at a fixed offset from a caller-supplied address and returns a 32-bit status value.

The accepted selector values are exactly 0 and 2. Either value causes the same write and a return value of 0. Every other selector value causes a return value of 4 without accessing the destination memory.

This is the established behavior of the supplied static representation. Interpreting the byte as an enabled flag, or the return values as success and failure codes, is inferred intent rather than an established semantic meaning.

| Selector | 32-bit integer | Compared for exact equality with 0 and 2. No other value is accepted. |

The supplied representation models both inputs as signed integers. For selector classification, signedness does not change the result: only the bit patterns representing 0 and 2 are accepted. Negative values and all other positive values are rejected.

The return type does not establish signedness. Both possible return values are nonnegative and have the same interpretation under signed and unsigned 32-bit representations.

## Behavior

### Selector classification

The function accepts the selector if it equals either 0 or 2.

There is no range-based acceptance. In particular, 1 is rejected despite lying between the two accepted values. There is no bit-mask interpretation, normalization, or conversion into a Boolean value.

The selector is classified before any destination write occurs. Its value is supplied directly as an argument; the function does not obtain it by reading the destination object.

### Accepted path

For either accepted selector:

- The destination byte is located at the supplied base plus 8 address units, represented as a byte offset in the supplied memory access.
- That byte is overwritten with the 8-bit value 1.
- The function returns the 32-bit value 0 after the write completes.

The prior byte value is not read and does not affect the result. A prior value of 0, 1, or any other 8-bit value leads to the same attempted store of 1.

The write is unconditional within the accepted path. If the byte already contains 1, the function still performs a write; it does not first compare the stored value or skip an apparently redundant update. This distinction can matter if the address refers to memory with write-sensitive behavior.

The operation is an overwrite, not a bitwise update. It does not preserve selected bits of the previous byte.

The return value is not a prior value, a write count, or a readback result. The supplied representation contains no readback or explicit check that the destination retained the written value.

### Rejected path

For every selector other than 0 or 2:

- The function performs no destination-memory read.
- The function performs no destination-memory write.
- The function returns the 32-bit value 4.

The function does not clear the destination byte, restore any earlier value, or record a diagnostic on this path. It also does not validate the destination address before returning 4.

### Ordering and arithmetic

On the accepted path, the destination write precedes the normal return of 0. On the rejected path, there is no destination access to order relative to the return.

The supplied representation uses a 32-bit integer base and adds the constant offset 8.
