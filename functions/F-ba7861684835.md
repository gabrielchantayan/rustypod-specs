## Acceptance examples

These examples are conditional static expectations, not runtime test results. Each assumes that all executed calls return normally and all accessed addresses are valid.

1. **Initial preparation skipped.**  
   If the first dispatch returns zero, this body does not clear offset 0x1F1 and does not call F-151ab4bfe553. It still performs the second dispatch.

2. **Initial preparation taken.**

4. **Low-byte distinction.**  
   With a nonzero first eligibility result, an offset-0xA0 value of 0x00000100 permits evaluation of the global condition. A value of 0x00000101 prevents it.

5. **Global gate fails.**  
   If the first two eligibility checks pass but the global-referenced byte is zero, F-e57b05520b65 and all subsequent processing dependencies are skipped.

6. **Captured field remains authoritative.**  
   Suppose the offset-0x34 capture is zero and F-e57b05520b65 subsequently makes that field nonzero. F-ee8733a08210 is still skipped. Conversely, a nonzero capture still causes the call even if that dependency clears the object field.

7. **Final pair omitted.**  
   If record processing reaches F-ffe0d92c57b7 and it returns zero, neither F-c9b5d17d8d1e nor F-4d037ecf0f82 is called.

8. **Final pair ordered.**
