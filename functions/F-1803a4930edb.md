### Fixed-width input arithmetic

Under 32-bit bit-vector semantics, second input 1 supplies 64 as the opening invocation’s third argument and 4096 for the later additional shift. Second input 0x04000000 becomes zero after the first shift.

### Fixed storage is not automatically byte-sized

If the missing declaration permits the fixed-location 0x05 read to yield 0x1234, unsigned 32-bit conversion can retain 0x1234. The later computed byte destination uses that base plus 0x15, not necessarily 0x34 plus 0x15.

For adjusted base 50, character conversion preserves 50 and promoted arithmetic produces 448 for assignment at 0x3A. A sufficiently wide destination can retain 448; an unsigned eight-bit destination would retain 192. The supplied declarations do not select between them.

### Publication and closing interleaving

An access-sensitive publication destination must receive the ordered 0x20, 0x2F, loaded-byte, and 0x20 stores, not merely the last value.

The global-base offset-0x44 word store must occur after the publication-base offset-0x10 word store and before the next 0x67 read. If its four-byte destination overlaps storage observed by that read, the read must observe the applicable post-store state, subject to the unresolved fixed-storage width and byte order.

### Late replacement of publication destinations

Conditionally, suppose the loaded publication link is 0x12345678 and all intervening accesses complete. The late byte publication at publication-base offset 0x09 supplies 0x78, followed by a word store of 0x12345678 at publication-base offset 0x44.

Earlier 0x67-derived and 0xA9-derived publications remain required events, not the final values attributable to these destinations. Other aliasing writes can still alter resulting storage.

### Saved values versus current memory
