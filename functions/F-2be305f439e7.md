# F-2be305f439e7

## Purpose

F-2be305f439e7 reads bytes through a caller-supplied cursor slot, assembles an unsigned numeric result from selected byte bits, and updates that slot to a later address.

For stable, nonoverlapping storage, the function recognizes one-byte, two-byte, and three-byte patterns resembling a restricted UTF-8 decoder. It is not a validating UTF-8 decoder: it does not validate continuation-byte prefixes, reject overlong encodings, exclude surrogate values, or decode four-byte sequences. Unsupported high-bit lead patterns return zero after reading a second byte and advancing the cursor by three bytes.

The resemblance to UTF-8 is inferred intent. The access ordering, bit selection, arithmetic, and cursor updates are established by the supplied body.

The caller supplies the cursor slot, but ownership of the slot and input storage is not established.

### Ordered accesses and cursor updates

The supplied body establishes this logical access order:

1. Read the entry input address from the cursor slot.
2. Write the entry address plus one byte into the slot.
3. Read the first input byte and retain its unsigned value.
4. Evaluate the high bit through a separate expression referring to the first input address.
5. If that high bit is clear, return the retained first-byte value.
6. Otherwise, write the entry address plus two bytes into the slot, then read and retain the second byte.
7. Classify the retained first-byte value for the two-byte lead pattern. If it matches, return the two-byte result.
8. Otherwise, write the entry address plus three bytes into the slot.
9. Classify the retained first-byte value for the three-byte lead pattern. If it matches, read the third byte and return the three-byte result. If it does not match, return zero without reading the third byte.
