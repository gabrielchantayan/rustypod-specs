# F-927372e9397c

## Purpose

F-927372e9397c forms the difference between two two-component values. It then repeatedly decreases the first result component while updating a negative second result component using a global adjustment value.

The adjustment is asymmetric:

- A negative second-component result enters the adjustment loop.
- A zero or positive second-component result bypasses adjustment.
- There is no corresponding reduction of a large positive second component.
- Output is written only after the adjustment loop finishes.

Subtraction with borrowing is **inferred intent**. The evidence does not establish a domain, units, a fixed radix, normalized inputs, or a positive global adjustment value.

The global value’s declaration is absent. Its type, signedness, and width are therefore unknown. Consequently, the loop’s addition cannot unconditionally be described as signed-integer addition of the same width as the components. Numerical borrowing properties below are conditional on explicitly stated arithmetic semantics.

## Behavior

### Initial operand reads and differences

Before writing the destination, the function obtains:

1. The left first component minus the right first component.
2. The left second component minus the right second component.

The first-component calculation precedes the second-component calculation. Within either subtraction, the relative evaluation order of the left and right operand reads is not established.

Both differences are retained before adjustment begins. The source component expressions are not evaluated again during the loop or during output.

This ordering does not make the four operand reads an atomic snapshot. Concurrent mutation, special memory-access behavior, and synchronization guarantees are not established.

### Adjustment condition

The retained second component is a signed integer value. Its comparison with zero determines whether the loop executes.

If it is zero or positive, the function proceeds directly to output. On this path:

- The first-component difference is unchanged.
- The second-component difference is unchanged.
- The global adjustment expression is not evaluated.
- No upper-bound check or positive-value normalization occurs.

Thus, a second-component difference larger than an intended radix is still stored unchanged.

### Adjustment iterations

When the retained second component is negative, each iteration has this source-visible order:

1. Decrease the retained first component by one.
2. Evaluate the global-dependent addition using the retained second component.
3. Assign the addition’s result back into the retained second component.
4. Test that stored signed integer value against zero.

No destination write appears within the loop.

The loop condition therefore observes the value **after conversion back to the declared signed integer type**, not necessarily the addition’s intermediate result.

The global value is referenced in the update expression on each iteration. There is no explicit pre-loop snapshot. This establishes expression placement, not a guarantee of one physical memory load per iteration. Volatile status, synchronization, permitted asynchronous modification, and compiler treatment of repeated accesses are not supplied.

### Conditional borrowing properties

Assume:

- The global adjustment is a stable positive mathematical integer \(B\).
- The exact-addition condition holds for every update.
- The initial subtractions and every first-component decrement are representable.

Let \(H\) and \(L\) denote the initial first- and second-component differences. If the loop completes after \(k\) iterations, its output is:

\[
H_{\mathrm{out}}=H-k,\qquad L_{\mathrm{out}}=L+kB.
\]

For \(L\geq0\), \(k=0\), and the global-dependent arithmetic is not used.

For \(L<0\), \(k\) is the smallest positive integer satisfying:

\[
L+kB\geq0.
\]

Under these conditions, an initially negative second component finishes in the range \(0\) through \(B-1\), inclusive. An initially nonnegative second component has no such bound.

These equations describe conditional results. They do not establish that the implementation computes an iteration count, uses division, or uses a wider intermediate representation.

A positive global value alone is not a sufficient termination guarantee without the arithmetic and range conditions above. In particular, the first-component decrements can leave their representable range before adjustment completes.

### Destination writes

Once the loop is bypassed or terminates, the function writes:

1. The retained first component to destination element 0.
2. The retained second component to destination element 1.

The function then returns without a value.

The stores are separate and ordered in the supplied representation. No atomic two-component update, transaction, or rollback mechanism is visible. This ordering does not establish a supported cross-thread observation model.

### Aliasing

Other valid overlaps likewise introduce no later source reread. They remain subject to alignment, lifetime, access permissions, and applicable object-access rules.
