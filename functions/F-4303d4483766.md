# F-4303d4483766

## Purpose

1. Obtain a candidate address through F-b7af80e829ec, adjust a nonzero result backward by five 32-bit integer elements, and invoke the indirect target selected at byte offset 448 from the table address stored there.
2. If that invocation returns zero, pass the original input to F-17fab3ca59b5 and invoke the indirect target selected at byte offset 120 from the table address stored in its result.
