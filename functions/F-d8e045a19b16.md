# F-d8e045a19b16

## Purpose

F-d8e045a19b16 replaces a caller-designated unsigned-word field with a packed numeric value. Three contributions come from explicit arguments. A fourth comes from an unsigned-byte read through a global reference.

Under an eight-bit-byte, 32-bit-word interpretation, the replacement contains four eight-bit numeric lanes. The destination address is obtained by adding 24 to the destination-base integer before converting the result to an unsigned-word address.

The selected-byte address depends on the unavailable type of the global reference. The representation applies an index multiplied by eight, then adds four, and only afterward converts the result to a byte address. Consequently, an eight-byte selection stride and a four-byte offset are established only under a compatible integer-address or byte-pointer interpretation. A pointer to larger elements can scale both additions.

The established purpose is numeric composition and field replacement. Any interpretation as a color, identifier, or protocol field is **inferred intent**, not established application behavior.
