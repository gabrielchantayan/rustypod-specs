# F-f21200c8b6d5

## Purpose

F-f21200c8b6d5 describes an order-sensitive sequence of memory accesses, address calculations, fixed-global assignments, and conditional termination.

The supplied static representation establishes no normal return. A signed-negative dependency address reaches an early invalid-instruction boundary; the continuing path reaches another. Earlier access faults or unresolved arithmetic semantics can prevent either boundary from being reached.

No application-level purpose is established. The address patterns do not establish initialization, object management, exception handling, or intentional modification of executable memory.

Two distinctions are essential:

- An assigned value’s width does not establish the physical footprint of an undeclared fixed global.
- Repeated references to a stack-resident pointer do not establish an immutable pointer snapshot. Intervening writes can overlap its storage, and the representation does not resolve actual reload behavior.

## Behavior

The following phases preserve the represented order of effects. A fault can prevent all later effects. Explicitly captured values remain snapshots; repeated stack-pointer references and later global reads must not automatically be replaced by earlier snapshots.

### 1. Initial stores and narrow-value indirection

Using E1, perform these accesses in order:

1. Store A as a word at E1 + R.
2. Store the low halfword of E1 at E1 + D.
3. Store the low byte of B at C + D.
4. Read a word at twice C.
5. Add the captured word to A; read an unsigned halfword at that address. Call its zero-extended value N.
6. Read an unsigned byte at E1 + B. Call it J.
7. Read a signed halfword at A + N.

Then:

1. Store J, zero-extended to a word, at N + 8.
2. Store the captured signed halfword, sign-extended to a word, at J + 0x28.
3. Store V as a word at D + 0x4c.
4. Store N as a word at N + 0x70.

N is in 0–65535; J is in 0–255. Their use as addresses establishes neither valid low-memory mappings nor object boundaries.

1. The low byte of Z at X + 1.
2. The low byte of V at D + 0x0b.

### 6. Fixed-state assignments and stack-derived accesses

4. Store the halved value as a word at four times the selected value + 0x10.

#### Stack-pointer observation rule

Each following reference to the stack-resident pointer denotes the value available at that reference, not necessarily P₀ or the value used by a preceding event.

If references reload the represented slot, they observe intervening writes to that slot. If the actual implementation retains a value elsewhere, some references may instead reuse it. The supplied representation does not resolve that distinction, exact load placement, or finer evaluation order within an expression.

Accordingly, the following sequence establishes operations and dependencies, but not a unique concrete address trace under slot aliasing:

1. Store the low halfword of the selected value through the pointer reference used for this event.
2. Store the base left-shifted by 8 as a word through the next pointer reference.
3. Store the same represented shift expression as a word at the next referenced pointer plus 0x14.
4. Store a word through a pointer reference, using the pointer value referenced by the value expression as the stored value.
5. Read a word at twice the pointer value referenced for this read. Capture the result as T.
6. Store the low halfword of T through the pointer reference used here.
7. Store T as a word at address T.
8. Store a word at 32 × S + 0x18, containing the pointer value referenced here, interpreted as signed 32-bit and right-shifted by 31.
9. Read the byte-valued input associated with the byte-carry publication.
10. Assign to that publication a concatenation placing 16-bit value 5 above the newly consumed byte.
11. Store a represented pointer as a word at four times a referenced pointer value + 0x18.

Events 4 and 11 each contain pointer references for both destination calculation and stored value. Their finer evaluation order is not established. They cannot be specified unconditionally using P₀.

For example, if the pointer initially targets its own slot, event 1 can modify that slot before event 2. Whether event 2 follows the modified pointer or a retained value is **documented_only**. Events 2–8 and 11 can themselves alter the slot through aliasing and thereby affect later references.

T, once captured, remains the value used in events 6 and 7. It is not a reread of the pointer slot.

The byte input in event 9 is consumed after event 8; it cannot be replaced with the earlier assigned byte. Event 10 defines a 24-bit concatenated value, not a three-byte write footprint.

## Acceptance examples

These are conditional static criteria, not executed tests. Each assumes preceding effects complete and required unresolved semantics are supplied.

1. **Signed conversion.** An early signed-halfword pattern of 0xff80 produces word-store value 0xffffff80.

2. **Distinct byte roles.** With B₁ = 0x20 and B₂ = 0x70, W is stored at 0x28, K is read at 0x48, word 0x20 is stored at Q + 0x40, and phase 3’s final byte store targets 0x8c.

3. **Independent region head.** Without aliasing, halfword stores at doubled-address offsets 2, 4, and 6 leave offset 0 unchanged. Its preexisting halfword determines the later destination.

4. **Value versus footprint.** For Q = 0, the masked value is 0x7fffff20 and the halved value is 0x3fffff90. The shifted publication receives 0x3fff; the byte-carry publication receives 0x0090. Neither proves a two-byte write.

5. **Selected destinations.** On a continuing path with E2 bit 2 set, the selected value is 0x5c. The explicit base-word destination is 0x60; the explicit halved-value word destination is 0x180.

6. **Self-targeting pointer slot.** Assume the first stack pointer observation equals S, that observation reloads the slot, and required arithmetic is defined. The first halfword store targets S and writes the selected value’s low 16 bits. A subsequent reload observes the modified slot contents according to the supplied layout and endianness—not unconditionally P₀. A retained-value implementation remains a distinct unresolved possibility.

7. **Late pointer publication.** If the pointer observation used by the later 0x0897ea80 assignment is 0x1000, that assignment receives 0x4000, provided its signed multiplication is defined. An earlier P₀ of 0x2000 does not instead require 0x8000.

8. **Overlapping-global reread.** If the byte input consumed after the slot-address-derived store is 0xa7, the concatenated assigned value is 0x0005a7. No three-byte footprint follows.

9. **Publication reread.** If the explicit self-store changes the 0x0897ea80 publication, the following offset-4 destination uses the changed value.

10. **Late composition.** A later upper-publication input of 0x1234 produces composed value 0x1234ea70; the destination width remains unknown.

11. **Narrow store and termination.** If the scaled E3 address ends in 0xfc, its offset-16 byte receives 0x04. For signed-negative E2, that phase is never reached: the base + 4 halfword store precedes the early termination boundary.
