7. **Global capture ordering.** If the 0x60 word store overlaps the global storage, publication still uses the value read before that store.

8. **Final capture ordering.** If the 0x3A byte write overlaps one of the earlier word-read locations, it does not retroactively alter the saved read result. If it overlaps a subsequently read field, that later read must reflect the intervening mutation.

9. **Observable overwrite sequence.** A write-observing environment sees adjusted-base offset-0x20 values 0x20, 0x2F, the freshly widened byte, and 0x20 in that order, provided execution reaches them.
