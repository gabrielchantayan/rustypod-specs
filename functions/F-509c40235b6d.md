# F-509c40235b6d

## Purpose

F-509c40235b6d prepares arguments and temporary writable storage for F-eb0844e8e085, then reduces that dependency’s return value and a separate status word to a Boolean result.

The wrapper optionally captures a caller-provided 32-bit value, clears a caller-provided output word, and makes two preliminary dependency calls. The second preliminary call receives a value read from global storage **after the first preliminary call returns**. Its result determines whether the main dependency receives the constant 3 or a 32-bit field read from the context at byte displacement 8.

Normal completion returns true exactly when:

- F-eb0844e8e085 returns nonzero; and
- the separate status word supplied to it as argument 10 is nonzero afterward.

The caller-visible output word is not tested when determining this result.

These statements describe static behavior. The operation’s domain meaning, output semantics, and dependency-specific resource rules remain unknown. No runtime tests have been performed.

## Behavior

### Initialization and optional input capture

The wrapper initializes a two-word internal control area:

- The first word starts at 1 and is the status word used in the final decision.
- The second word starts at 0 and is supplied separately to the main dependency.

The initial value to be forwarded defaults to zero. If the optional initial-value pointer is non-null, the wrapper reads one 32-bit word from it and retains that value for the main call.

This optional read occurs before the output write. When the initial-value pointer and output pointer designate the same word, the main call therefore receives the word’s value from before it was cleared.

There is no later direct read through the optional initial-value pointer.

### Output clearing

The wrapper writes a 32-bit zero through the output pointer.

This occurs before either preliminary dependency call and before the main dependency call. The clearing is unconditional on any later success result. The wrapper neither saves the former output for restoration nor performs a final clearing after the main call.

Consequently, the output is known to be zero immediately after this direct write, but its value at return depends on subsequent dependency effects.

### Preliminary calls and intervening global read

The wrapper calls F-e3253cb77678 once with the context.

After that call returns, the wrapper reads a value from a global data location. It then calls F-061c2693b838 with:

1. The result returned by F-e3253cb77678.
2. The value obtained by that global read.

The second argument is **a value read from global storage**, not an established fixed constant or the established address of that storage. Its contents, semantic type, and stability are unknown.

The timing matters: effects of F-e3253cb77678 may influence the value subsequently read from the global location. The wrapper does not establish that this dependency preserves global state. Nor is the value guaranteed to be the same across separate invocations.

The global read occurs before F-061c2693b838 is invoked. Once read, its value is the argument supplied for that invocation; later global changes do not retroactively change that argument.

Both preliminary calls occur on every normally progressing invocation, regardless of whether the optional initial-value pointer was null.

### Conditional context access and remaining preparation

The return from F-061c2693b838 is tested for zero.

If it is nonzero, the wrapper reads a 32-bit word from the address derived from context plus the byte displacement 8. That word becomes the selected fifth argument for the main dependency.

This read happens after both preliminary calls. It therefore observes the context field after any effects those calls have had, rather than necessarily observing the field’s entry value.

If the return is zero, the wrapper does not directly read that context field.

After the comparison and any conditional field read, the wrapper initializes two additional internal 32-bit words to zero. These words are separate from the two-word control area and from each other. The word later supplied as argument 8 is initialized before the word supplied as argument 9.

On the zero-comparison path, the selected fifth argument is then set to 3. Thus, on every normally progressing path, that argument is either:

- 3 when F-061c2693b838 returned zero; or

No visible mask, range check, or substitution is applied to the field value. A selected field value of zero remains zero.

## Side effects

1. Read the optional initial word, if its pointer is non-null.
2. Write zero to the output word.
3. After F-e3253cb77678 returns, read the global operand.
4. After F-061c2693b838 returns, conditionally read the context field at byte displacement 8.

- Aliased initial and output pointers preserve the old word as main-call argument 1 before clearing it.

- If the output write aliases the global operand storage, the later global read occurs after that write and after F-e3253cb77678. The precise resulting operand depends on the actual storage widths, overlap, and intervening effects.

These consequences require all accesses and dependency preconditions to remain valid.
