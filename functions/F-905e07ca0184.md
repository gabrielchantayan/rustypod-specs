# F-905e07ca0184

## Purpose

The first stage obtains two integer results from separate dependencies and tests whether their difference is nonnegative. Only when that test passes does the function invoke a third dependency, using an address within the supplied object and the previously captured global value. The third dependency permits a return of 1 whenever its result is anything other than −1.
