## Behavior

1. The original first argument.

### Equality gate

If F-c45cb3f8e7fd returns zero, the function reads the resulting check temporary and compares it with the original fourth argument.

- Equal values permit the second dependency call.
- Unequal values cause a return of 0 without that call.

The original third argument is not the reference value for this gate. It merely supplied the check temporary’s initial contents. Consequently, if the first dependency leaves the check temporary unchanged, the gate passes exactly when the original third and fourth arguments are equal.

Changes to the candidate temporary do not affect the equality gate.
