## Behavior

It obtains a signed 8-bit value from the second base plus one byte. Its numerical range is −128 through 127. This signed interpretation matters: a stored byte with its high bit set is not established as a positive bit index.

Only those two byte locations supply data to the expressed calculation. There is no visible loop, table lookup, alternate offset, or additional memory operand.

### Bit selection

- Position 0 selects the bit with numerical weight 1.
- Position 1 selects the bit with numerical weight 2.
- Position 7 selects the bit with numerical weight 128.

Endianness does not affect this selection because the source value is a single byte.

The unsigned source byte undergoes integer promotion before shifting. Its promoted value remains nonnegative. Consequently, within the defined shift-count domain, there is no negative-value right-shift ambiguity for that operand.
