# F-9c79105b41a5

## Purpose

The first check uses a value obtained without passing the function’s input. A zero result from that check causes an immediate return of a designated global value. Only if the first check returns nonzero does the function use its input to obtain the value for the second check. A zero result from the second check causes an immediate return of a different global value. If both checks return nonzero, the function selects between a value read from the input-relative field and a third global value.
