### Entry and selector-mediated byte writes

The first indirect call receives the explicit input. Several more calls precede the first visible store. One receives an incoming unsigned value shifted right by eleven.

The function then reads a selector byte at that incoming value plus one. At selector plus `0x11`, it stores the low byte obtained by clearing bit 31 of the other incoming value and shifting right by 21. The stored byte therefore contains original bits 21–28.

Subsequent call groups frequently forward dependency results scaled by four, sometimes together with a retained selector. Argument positions vary; a selector is not invariably the second argument.

The recurring byte-write pattern is a fresh selector read followed by a store at selector plus `0x11`. Selector-read addresses include transformations involving multiplication by four, eight, sixteen, sixty-four, 1024, and 4096; unsigned right shifts; masked arithmetic; and large signed scale factors.
