# F-d12dbb806497

## Purpose

- **Iteration path:** obtain entries through dependencies, inspect one byte per successful advance, and invoke an object-level action whenever that byte is nonzero. This path has a represented normal return.
- **Alternate path:** repeatedly query object state, invoke a coordination dependency while the state remains nonzero, then choose between terminal continuations. Every represented exit from this path calls a dependency marked non-returning.

The established contract concerns call order, arguments, local storage, byte accesses, and branch conditions. “Iteration,” “query,” and “coordination” describe apparent roles; they do not establish the dependencies’ internal semantics.
