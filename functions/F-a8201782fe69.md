# F-a8201782fe69

## Purpose

The established behavior is narrower than a semantic description such as “render,” “measure,” or “advance a cursor”:

- Capture a value from the record before invoking the first dependency.
- Invoke F-f445983e29a8 on an interior portion of the record.
- Invoke F-53c2c68b7811 with ten arguments assembled from the record, the caller’s second argument, and the first dependency’s result.
- Replace the record’s first 32-bit word with the second dependency’s result minus a value read from the record after that dependency returns.

The paired additions and final subtraction suggest translation between local and externally adjusted coordinates. That interpretation is inferred intent, not an established meaning for any field.

This contract describes the supplied static evidence. No runtime tests have been performed.

The ninth argument has an established arithmetic grouping: first subtract the first dependency’s result from the word at offset 0x04, then add the word at offset 0x30. Reassociation can change overflow behavior and is not justified merely by algebraic equivalence.

### 4. Store the adjusted result

If F-53c2c68b7811 returns normally, its result is consumed as a 32-bit integer.

The function then reads the word at offset 0x2C again, subtracts that post-call value from the dependency result, and writes the difference to offset 0x00.

The final subtraction therefore does not necessarily reverse the addition used for argument eight. Those two operations can use different values from offset 0x2C if the second dependency changes that field.

The final write replaces the first word; it does not add to the value currently stored there. If the second dependency changed the first word, this wrapper overwrites that change on normal return.
