# F-53ba1bc17290

## Purpose

1. The supplied object pointer is non-null.
2. The object's second 32-bit word equals 22.

## Behavior

### Null-object path

The object pointer is tested for null before any object storage is read.

If it is null, the function returns null. It does not inspect the opaque value, invoke the indirect operation, or invoke F-d272596e03a3.

This is a pointer-value check, not a validation of arbitrary non-null addresses.

### Object-tag gate

For a non-null object, the first object-memory observation is the 32-bit word at byte offset 4. The function compares that word with 22, equivalent to hexadecimal 0x16.

If the comparison fails, it returns null immediately. In particular, a readable nonmatching tag is sufficient for this path; the dispatch-table word at offset 0 is not read.

The comparison is exact. No other tag value receives special treatment.

### Indirect operation

When the tag equals 22, the function obtains the dispatch-table address from the object's word at offset 0 and obtains the callable entry at byte offset 20 within that table.

It invokes that entry once, supplying:

1. The same object pointer received as input.
2. The value 3840.

The opaque first input to F-53ba1bc17290 is not an argument to this indirect operation.

The callback is selected only after the tag gate passes. The function does not invoke an alternative entry if the selected entry is absent or unusable, and it does not retry the call.

### Result-word gate

After the indirect operation returns, its result is used as the base address for a 32-bit read at byte offset 8.

There is no intervening null check on that result. A null result is therefore not a defined “condition not satisfied” outcome of the indirect operation. It leads to an attempted read at address 8 under the represented address model; whether that faults or has another platform-specific consequence is not established.

The inspected word is tested only for zero versus nonzero:

- Zero causes a null return.
- Any nonzero 32-bit value causes F-d272596e03a3 to be called.

The value is not required to equal one. A word with its high bit set also satisfies the nonzero test.

The read occurs after the indirect operation completes. Consequently, the gate reflects the storage observed at that time, including any relevant changes made by the operation. The function does not use a previously captured copy of that word.

Its return value becomes the return value of F-53ba1bc17290, interpreted as a pointer. The wrapper performs no demonstrated inspection, dereference, modification, or release of that result.

There is no subsequent recheck of the object tag or the result word.
