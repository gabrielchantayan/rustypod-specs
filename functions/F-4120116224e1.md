# F-4120116224e1

## Purpose

F-4120116224e1 conditionally updates an object from a nonzero source address, invokes a dependent operation, optionally dispatches through an associated object, and finally marks an object returned by another dispatch.

The established behavior is an ordered sequence of memory accesses and calls. The apparent intent is to import a block of state, merge selected flags, perform associated processing, and mark a resulting object. That interpretation is inferred; the meanings of the data block, masks, associated object, and returned object are not established.

A zero source argument bypasses the entire sequence. A nonzero source argument enables it without any visible validation of the destination, source, dispatch tables, or returned address.

## Behavior

The function first tests whether the source argument is zero.

If it is zero:

- No visible destination or source memory access follows.
- No dependency is invoked.
- No visible memory write occurs.
- The function returns.

A nonzero source argument proceeds through the remaining stages.

### 3. Mask sampling and destination flag merge

After F-EXT-01 returns, the function reads a global 32-bit mask value and retains that sampled value for a later argument to F-6d16652f2d03.

It then updates the destination’s 32-bit flags word at offset `0x48`. The visible expression preserves destination bits outside a global mask and obtains masked bits from the source’s flags word at offset `0x18`.

For a stable global mask \(M\), destination flags \(D\), and source flags \(S\), the merged word is:

\[
(D \mathbin{\&} \operatorname{NOT}_{32}(M))
\mathbin{|}
(S \mathbin{\&} M)
\]

The complement is a 32-bit complement, not an unbounded mathematical complement.

There is an important evidence boundary: the merge expression references the global mask separately from the earlier retained sample, and references it twice within the expression. The representation does not establish that all those accesses use one atomic snapshot. Nor does it establish the relative evaluation order of the expression’s individual reads.

Thus the stable-mask formula is a conditional description. If the mask can change between accesses, a single-mask interpretation is not guaranteed.

After writing the merged flags, the function performs a second read-modify-write on the same destination word, setting bit `0x20`:

\[
D_{\text{next}} = D_{\text{merged}} \mathbin{|} 0x00000020
\]

This is visibly a separate update, not merely one final combined assignment. Under stable, ordinary memory conditions, it leaves all merged bits unchanged except that bit `0x20` becomes set.

### 5. Optional associated-object dispatch

After F-6d16652f2d03 returns, the function evaluates a short-circuit condition:

1. Read the destination field at offset `0x34` and test whether its address value is nonzero.
2. Only if that test succeeds, read the word at destination offset `0xA0`, convert it to a character-sized value, and test whether the converted value is zero.

If the associated-object address is zero, the second test is skipped and the optional dispatch does not occur.

The conversion is not established as a full-word zero comparison. Under an 8-bit character interpretation, a word such as `0x00000100` converts to a zero low-byte value and satisfies the second test despite being nonzero as a 32-bit word. The source representation does not justify replacing this condition with a test of the first byte in memory without also establishing the target’s byte order and conversion rules.

If both tests succeed, the function:

- Reads the associated-object address from destination offset `0x34` for dispatch.
- Reads a dispatch-table address from the beginning of that associated object.
- Obtains a callable target from dispatch-table byte offset `0x128`.
- Invokes that target, identified here as F-INDIRECT-01.

The supplied representation shows no explicit arguments to F-INDIRECT-01. It does not establish whether the actual calling convention supplies an implicit receiver or other register arguments.

The associated-object field is used again for dispatch rather than represented as one retained value spanning the condition and call. Concurrent modification or unusual memory behavior therefore cannot be ignored by assuming a single stable read.

- Obtain a callable target from dispatch-table byte offset `0x5C`.
- Invoke that target, identified here as F-INDIRECT-02, with the destination object address as its explicit argument.

This lookup occurs after the optional call. It must not be assumed to use a dispatch-table value sampled before that call.

The return value is treated as an object address. The function reads its 32-bit word at offset `0x48`, sets bit `0x40`, and writes the result back:

\[

The function then returns. It performs no visible restoration of earlier destination flags or cleanup after this final write.

## Acceptance examples

These are conditional acceptance examples derived from static evidence. They are not reports of executed tests.

### Zero source

Given a zero source argument, the function returns without invoking any listed dependency or accessing the destination. This remains the expected visible path even if the destination address would otherwise be invalid.

### Stable-mask merge

Assume:

- F-EXT-01 returns normally.
- The global mask remains `0x0000000F` throughout mask sampling and merging.
- Destination flags at merge time are `0x000001A5`.
- Source flags at merge time are `0x0000000A`.
- No intervening external modification occurs during the two flag updates.

The merge writes `0x000001AA`. The subsequent setting of bit `0x20` leaves that value unchanged because the bit is already set. F-6d16652f2d03 receives the retained mask value `0x0000000F`.

This example does not require later dependencies to preserve those flags.

### Forced destination marker

With a stable zero mask and destination flags initially zero at the merge stage, the merge leaves the word zero and the next update writes `0x00000020`.

With a stable all-ones 32-bit mask, the merged flags equal the source flags, after which bit `0x20` is forced on.

### Optional-call suppression

If the associated-object field is zero after F-6d16652f2d03 returns, F-INDIRECT-01 is not called and the offset-`0xA0` condition is not evaluated.

If that field is nonzero but the character-converted value is nonzero, F-INDIRECT-01 is likewise skipped. F-INDIRECT-02 still follows, provided execution otherwise continues normally.

### Character-conversion boundary

Under an 8-bit character interpretation, a post-helper word of `0x00000100` at destination offset `0xA0` satisfies the zero-character condition. With a valid nonzero associated object, the optional call occurs.

A word of `0x00000101` does not satisfy that condition.

### Final marker on a distinct object

Suppose F-INDIRECT-02 returns a valid distinct object whose flags word is `0x00000002`. With no intervening modification, the final write makes that word `0x00000042`.

The destination does not receive this final write merely because it was the explicit argument to the dispatch.
