# F-d761f0580f57

## Purpose

F-d761f0580f57 conditionally writes a fixed byte value to a location identified by its first input, then returns a fixed 32-bit value.

The condition depends solely on whether the second input equals 3:

- If the second input is not 3, write the byte value 7 at byte offset 44 from the address represented by the first input.
- If the second input is 3, perform no explicit memory access.
- On either normally completing path, return the 32-bit value 12.

## Behavior

If the input differs from 3, the function writes 7 to the one-byte destination at base plus 44, then returns 12.

The write is an overwrite, not a read-modify-write operation. There is no explicit dependence on the previous destination value. If the byte already contains 7, the writing path still specifies a write of 7; unchanged final contents do not imply that the access was skipped.
