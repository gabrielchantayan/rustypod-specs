## Acceptance examples

These are conditional static criteria, not executed tests. They assume the relevant arithmetic is defined, calls return as required, and memory accesses succeed.

1. **Selector aliasing:** if selector storage coincides with the second destination’s offset-`8` field, the branch uses the value read before the self-address store, not that subsequently stored address.

2. **Byte-derived reads:** a retained unsigned byte of `0xff` requires the destination-base read at `0x133` and the primary-address read at `0x113`. Adding an unstated table base would violate the contract.

3. **Early invalid-instruction boundary:** a zero character and zero index produce a zero shifted operand. F-a0b433c2a519 is not reached on that route.

4. **Working-word selection:** a zero character with a defined nonzero shifted index retains the inherited working word. A nonzero character instead selects the shifted secondary observation from F-U05.

5. **Nonzero working word:** the third-input word store and working-word halfword store precede the invalid-instruction boundary. The retained-result store at displacement `0x0c` and the later byte writes do not occur on this principal route.

6. **Unsigned address displacement:** with a zero working word and secondary word `0xfffffff0` after F-a0b433c2a519, the zero halfword is written at `0x0000001c`, and the retained result at `0xfffffffc`. The captured carry is zero.

7. **Distinct halfword observations:** the 16-bit value read from the scaled address is used for the post-F-U20 narrow write. The separately observed unsigned halfword supplies the final records.

8. **Zero extension:** an unsigned halfword of `0xffff` produces a final record word of `0x0000ffff`, not `0xffffffff`.

9. **Separated external reads:** changes during F-U23–F-U25 can alter the subsequently read secondary record address, but cannot alter the payload already retained after F-U22.

10. **Repeated primary update:** with disjoint records and no intervening interference, the primary record’s final first word comes from the secondary observation after F-U28. Both primary updates must still occur.
