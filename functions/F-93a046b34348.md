## Behavior

### Initial access and continuation

The function begins by calculating the initial base plus twelve and reading an integer from the resulting address. It does not first compare the input with zero.

The loaded integer becomes the current traversal value. The function then tests that value:

- If it is zero, traversal ends and the function returns.
- If it is nonzero, that value supplies the base for the next address calculation and read.

The same rule applies after every subsequent load. Termination depends on a loaded successor being zero, not on the original argument, the contents of a separate payload, or the number of steps already taken.

Once a load produces zero, the function does not use that terminal zero as the base of another read.

### Ordering and access count

At the represented semantic level, reads form a dependent sequence. Each later read address depends on the integer obtained from the preceding read.

For a stable chain, the initial base’s successor is read first, then the successor associated with the next base, and so on. No reverse traversal, look-ahead, second pass, or remembered collection of visited bases is present.

An immediate zero successor requires one read. Two nonzero successors followed by zero require three reads. A finite traversal therefore includes the read that discovers its terminating zero.

These counts describe represented loads under valid execution. They do not establish a machine-instruction count, physical memory-transaction count, or guarantee that every represented load survives executable optimization.
