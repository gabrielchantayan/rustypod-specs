# F-57414c61f130

## Purpose

F-57414c61f130 makes a short-circuit eligibility decision using incoming masks and, on selected paths, flag bytes obtained through two indirect references. It may return an incoming 32-bit value unchanged, return a fixed result, or consult F-9c4f3d705d74 before producing a result.

The established behavior is a decision procedure, not a complete domain-level operation. The supplied material does not establish what the masks represent, what the referenced objects contain beyond the accessed byte, or what the result values mean to consumers. Descriptions such as “primary” and “secondary” below distinguish the two references; they do not assign business meaning.

Four result forms are visible:

- The incoming passthrough value, unchanged.
- Fixed value **4**, when neither reference qualifies.
- Fixed value **3**, when the dependency is called and returns zero.
- Fixed value **0**, when the primary reference qualifies, or when the dependency is called and returns nonzero.

These forms are not necessarily distinguishable by the caller: the incoming passthrough value may itself be 0, 3, or 4.

## Behavior

### 1. Initial passthrough decision

First, the function tests the bitwise intersection of the common mask and the entry mask.

If that intersection is zero, it also checks whether the low six bits of the byte selector are all zero. When both conditions hold, it returns the incoming passthrough value immediately.

Consequences:

- Byte-selector bits 6 and 7 do not prevent this initial return.
- A byte selector of 0x40, 0x80, or 0xC0 satisfies the low-six-bits test.
- A nonzero common-mask/entry-mask intersection prevents passthrough regardless of the byte selector.
- Neither reference cell, neither object flag byte, and neither dependency argument is used by the remaining decision logic after this return.
- F-9c4f3d705d74 is not called.

If the initial conditions do not both hold, evaluation proceeds to the primary qualification decision.

### 2. Primary qualification

The primary branch qualifies when either of the following is true:

- The common mask and primary mask share at least one set bit.
- The primary object’s flag byte and the byte selector share at least one set bit.

These alternatives are evaluated in that order.

When the word-mask intersection is nonzero, the primary reference cell and primary object byte are not read for this decision. The function returns 0 without evaluating the secondary branch or calling the dependency.

When the word-mask intersection is zero, the function reads the primary reference cell, obtains the primary object address, and reads the flag byte at offset 0x46. A nonzero intersection between that byte and the byte selector also causes a return of 0.

The object-byte comparison uses all eight bits of the byte selector. It is not restricted to the low six bits used by the initial passthrough decision.

Only if both primary qualification alternatives fail does the function proceed to the secondary decision.

### 3. Secondary qualification

The secondary branch qualifies when either of the following is true:

- The common mask and secondary mask share at least one set bit.
- The secondary object’s flag byte and the byte selector share at least one set bit.

Again, the word-mask test comes first.

If the word-mask intersection is nonzero, the secondary reference cell and secondary object byte are skipped. Otherwise, the function reads the secondary reference cell and then the byte at offset 0x46 of the resulting object address.

If neither alternative qualifies, the function returns 4. The dependency is not called.

If either alternative qualifies, the function calls F-9c4f3d705d74.

### 4. Dependency-mediated result

F-9c4f3d705d74 receives the two 32-bit dependency arguments, in their listed order.

Its returned value is tested for equality with zero:

- Zero produces a result of 3.
- Any nonzero value produces a result of 0.

The dependency’s exact nonzero value is not forwarded. In particular, a negative 32-bit result is treated as nonzero, not as a separate error category.

There is at most one visible call to this dependency per invocation. No retry or subsequent input re-evaluation is shown.

The byte selector and object flags are eight-bit quantities. Their intersections therefore depend only on bits 0 through 7. The initial low-six-bits check depends only on bits 0 through 5.

## Side effects

No explicit writes to caller-provided memory, object fields, reference cells, or global state appear in the function body.

Its direct data-memory reads are path-dependent:

1. Inputs needed for the entry decision are evaluated.
2. If passthrough is not selected, the primary word-mask condition is evaluated.
3. Only after primary word-mask failure is the primary reference cell read, followed by its object flag byte.
4. Only after complete primary failure is the secondary word-mask condition evaluated.
5. Only after secondary word-mask failure is the secondary reference cell read, followed by its object flag byte.
6. Only after secondary qualification is the dependency called with its two arguments.
