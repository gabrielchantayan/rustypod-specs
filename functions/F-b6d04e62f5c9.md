## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Initial byte extraction.** If the incoming extraction quantity is `0x00400000`, the first direct byte store writes 1. Its destination is determined by the byte read immediately beforehand, not by the incoming address itself.

2. **Byte-address range.** If that first byte is 255, the first byte store targets address 272, the first argument-copy word store targets address 1040, and the later step-22 word store targets `0x00f80024`.

3. **Mask before shift.** If \(t=\text{0xfffffffc}\), step 16 stores `0x1ffffffe`. It must not store the result of an unmasked right shift.

6. **Distinct scaled locations.** A result \(h=1\) makes the step-18 destination address 36, while step 19 reads address 24. A conforming interpretation must not merge those accesses.

7. **Failure after partial effects.** If a dependency faults after an earlier direct store, no rollback is specified. The represented sequence provides no recovery path.
