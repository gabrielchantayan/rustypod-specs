# F-0f216d118f97

## Purpose

F-0f216d118f97 selects a construction path using a 32-bit mode and returns a 64-bit value containing an address in its low half and a branch-dependent word in its high half.

- **Mode zero:** obtains an initial dependency result, performs three cursor-producing calls, applies default or configuration-derived payload operations, and writes a header. The returned address is derived from the final cursor; the returned high word comes from a stack-held word exposed to a dependency.
- **Mode one:** substitutes a fixed shared-object address and the auxiliary value one for the caller’s corresponding arguments, then follows the nonzero construction path.
- **Other nonzero modes:** use the caller’s input address and auxiliary word on the nonzero construction path.

Two distinctions are part of the observable contract:

1. Mode zero reads the configuration-pointer global twice: first for the retained branch/source pointer, then for a separate stack-held pointer slot. The two observations are not unconditionally equal.
2. The nonzero path reads its header global twice after construction: first for the returned high word, then for the destination store. The stored header and returned high word are equal only if those reads observe equal values.

Construction, initialization, conversion, encoding, allocation, and release are inferred roles, not established dependency semantics.

## Behavior

2. Read the configuration-pointer global and retain that observation as the pointer controlling the configuration branch and its source accesses.
3. Read the configuration-pointer global again and place this second observation in a separate stack-held pointer slot.
4. Set a stack-held 32-bit word to zero.
5. Call F-fa879efbfc82 with the initial dependency result, zero, and 128.
6. Call F-b872376ec5c5 with the preceding result plus 20 bytes and the address of the zero-initialized word.
7. Call F-b872376ec5c5 with the preceding cursor result plus 4 bytes and the address of another stack location whose initial contents are not established.
8. Call F-b872376ec5c5 with the preceding cursor result plus 4 bytes and the address of the pointer slot initialized by the second configuration-global read.

The two configuration reads are distinct and ordered. The supplied representation shows no intervening dependency call, but that does not establish equality of their observed values or atomicity of the pair. Equality requires a stability assumption.

- A different value observed by the second read does not replace the retained branch/source pointer.
- A dependency’s modification of the pointer slot does not, by itself, replace that retained pointer.
- A null retained pointer selects defaults even if the second observation was non-null.
- A non-null retained pointer selects configuration processing even if the second observation was null.

The cursor chain depends on all three F-b872376ec5c5 return values. No fixed cursor advancement, identity return, or preservation of the addressed stack contents is established.

## Acceptance examples

These are conditional static criteria, not executed tests.

### Different configuration-pointer observations

Suppose the first configuration-global read observes null and the second observes a valid non-null address.

The pointer slot initially contains the non-null second observation and is passed by address to the third cursor call. The function nevertheless selects default punctuation because the retained first observation is null. It makes no configuration-processing or conditional release call.

Conversely, if the first observation is a valid non-null address and the second is null, configuration accesses use the first address. The pointer slot initially contains null.

### Default payload with stable destination

Given a null retained pointer, valid cursor results, and no later interference with the destination:

- Returned-address offsets 16 and 17 contain 46 and 44.
- Offset 0 contains the mode-zero header observation made after cursor construction.
- The high return component equals the stack-held word’s final value, even if a dependency changed it from zero.

### Sequential configuration reads

Given a valid retained record, if the first word-processing call changes the source word at offset 8 before the next load, the second word-processing call receives the changed value.

If a dependency changes the condition byte to nonzero before its final read, F-58ba61416cc9 is called regardless of the condition byte’s earlier value. The record must remain readable through that final access.

### Mode-one substitution

For mode one, the effective arguments are the fixed shared-object address and auxiliary value one, regardless of the caller’s corresponding values. This specifies argument selection, not overall result invariance under arbitrary dependency or shared-state behavior.

### Distinct nonzero header observations

Suppose construction returns a valid writable destination. If the first subsequent header read observes 17 and the second observes 29:

- The returned high word is 17.
- The destination receives a 32-bit store of 29.
- The returned low word is the construction result.

If both reads observe 17, both the returned high word and stored header are 17. Equality is conditional on equal observations, not guaranteed by reuse of one captured value.

### General nonzero mode

For any mode other than zero or one, including negative 32-bit values, the caller’s input reaches F-94789b030a7f and the caller’s auxiliary word reaches F-b2c3aa1253d0. The separate-header-read rule still applies.
