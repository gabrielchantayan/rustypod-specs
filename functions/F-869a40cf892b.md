## Behavior

### Reading the ordered description

The numbered stages describe observable ordering, not independent operations that may be rearranged.

A **five-call burst** means five successive indirect dependency invocations. Unless otherwise stated:

- Only the first invocation has explicitly represented arguments.
- The following four invocations have no explicitly represented arguments.
- When a burst result is used, it is the result of its fifth invocation.

“No explicitly represented arguments” does not establish that no argument registers or ambient state are consumed.

A **two-call bridge** means an invocation with the stated arguments followed by an invocation with no explicitly represented arguments. Its result is the second invocation’s result.

Every invocation is unresolved. A dependency may change memory before the next explicit access. Consequently, repeated reads of the same address must remain separate reads, and repeated writes cannot be discarded merely because their values appear equal.

For compactness, **byte-selected store** means: read an unsigned byte from the specified source address, then write one byte at the numerical address equal to that byte plus `0x11`. This is not evidence of a pointer-containing object. Its destination lies between `0x11` and `0x110`, inclusive.
