These are conditional static criteria, not executed tests.

1. **Input preservation.** If preceding calls complete and the first word destination is writable, the stored pattern equals the second argument, including its high bit.

2. **Byte truncation.** An initial selector of 65 produces a four-times value of 260; its corresponding byte store writes 4.

3. **Selector range.** A selector byte of 255 selects address 272, without an additional object base.

4. **Independent global snapshots.** If the first global read yields hexadecimal `00000400` and the second yields `00000800`, the masked, right-shifted-by-10 call argument is 1. 5. **Snapshot stability is conditional.** If an external guarantee makes both global reads observe the same word, their values may coincide. Both represented reads still belong to the contract; equality is not unconditional.

6. **Fresh selector reads.** If a dependency changes the byte at the saved second-snapshot scale plus 1 between its two reads, the later write uses the new byte. A later change to global storage alone does not replace the saved scale.

7. **Masked extraction.** A field value of hexadecimal `fff00000`, masked with `3fffffff` and shifted right by 20, yields `3ff`; its byte store writes `ff`.

8. **Width-sensitive zero.** Under 32-bit modular arithmetic, shifting the second-snapshot scale left by 26 and multiplying by 1024 yields zero. The resulting selector reads address location 1, independently of whether the global snapshots matched.

9. **Distinct layouts.** A quantity of 3 selects scaled address 32 and expanded address 68. A store at address 68 does not establish the word read at address 32.
