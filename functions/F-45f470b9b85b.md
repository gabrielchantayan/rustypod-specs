## Acceptance examples

These are conditional static examples, not observed test results. Each assumes valid accesses and returning callees through the step being illustrated.

### Initial store and argument distinction

For an initial index of 3 and a payload of `0x12345678`:

- The first explicit store writes that 32-bit payload at address `0x20`.
- F-0001 subsequently receives 3 and 12.
- The second argument is not `0x20`.

The payload’s byte ordering in memory remains unspecified.

### Secondary index aliases the initial index

If the initial index and the secondary index are both 3:

- Both explicit word stores target `0x20`.
- The second explicit store writes the ambient word there.
- Intervening or later calls may also modify that location; unchanged final contents are not guaranteed.

### Low-bit extraction and full-width call argument

If the first extracted word is `0x12345678` and the first primary selector read returns `0x20`:

- The first byte destination is `0x31`.
- The byte stored is `0xe0`.
- F-0013 receives `0x48d159e0`, not merely `0xe0`.

If the later primary selector read returns `0x21`, the second byte write instead targets `0x32` and stores `0x23`.

### Repeated reads observe changes

Suppose the first primary selector read returns `0x20`, but a later dependency changes that source byte to `0x40` before the second read:

- The first byte write targets `0x31`.
- The second byte write targets `0x51`.

Caching the first selector for both writes would not reproduce the visible sequence.

### Captured selector differs from stored value

If the second extracted word is 3 and the third primary selector read returns `0x7f`:

- The third byte write stores `0x0c` at `0x90`.
- F-0025 receives `0x0000007f`.
- The subsequent secondary byte-source address is `0x19`.

### High-bit exclusion

If the first extracted word is `0xc0000000`, its second-byte extraction yields zero. Its top two bits do not contribute to that byte.

### Interrupted execution

If F-0007 does not return, the first explicit word store has already occurred, but the second explicit word store has not. The visible sequence specifies no rollback or compensating call.
