## Acceptance examples

These are conditional static consequences, not executed tests.

1. **Initial width:** with valid storage and incoming halfword 0xABCD, the first access stores that halfword at twice the second argument.

2. **Short-circuit read omission:** suppose the retained doubling carry is one, the first carry-base read is 0x1000, and the second is 0xFFFFFFA7. The carry-adjusted base is 0x1001. The displacement increment is one, and no third carry-base read occurs.

3. **Conditional third read:** suppose the doubling carry is one, the first carry-base read is 0x1000, the second is zero, and the third is 0xFFFFFFA6. The carry-adjusted base remains 0x1001. The threshold comparison is false, so the third read occurs; adding 0x59 produces 0xFFFFFFFF, and adding the retained carry produces a carry. The displacement increment is therefore one. If that third value were instead zero, the increment would be zero.

4. **Distinct snapshot source:** if working offset 0x64 contains 0x11223344 when the early working snapshot is captured, while first-child offset 0x64 contains 0x55667788, the snapshot is 0x11223344. Its later uses supply byte 0x44 at working offset 9 and word 0x11223344 at working offset 0x44.

5. **Independent comparison reload:** an intervening mutation of the comparison cell does not alter the initially captured halfword payload stored at twice the doubled result. The later comparison predicate uses the reload.

6. **Partial replacement:** if separate traversal offset 0x45 overlaps the displacement-relative word, its halfword store can alter principal-base selection. The principal word-0x45 store still precedes the character-sum store.

7. **Character interpretation:** final character byte 0xFF becomes unsigned 0xFFFFFFFF under signed-character interpretation, or 0x000000FF under unsigned-character interpretation. OR with 0x44 changes neither value; character-derived destinations differ.

8. **Nonreturning target:** if the final target does not return, normal return is not required. No visible mechanism rolls back preceding mutations.
