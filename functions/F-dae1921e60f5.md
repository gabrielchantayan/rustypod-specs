# F-dae1921e60f5

## Purpose

F-dae1921e60f5 coordinates two dependent operations. It first calls F-4e6cefe281de using an address derived from a supplied base and a mutable, invocation-local 32-bit value. If that dependency returns zero, the function returns status value 3 without directly writing the caller’s output destination. Otherwise, it calls F-b8bab6835ed5, publishes a shifted version of a second mutable local value, and returns the second dependency’s result.

The function converts two inputs into quantities scaled down by 512 and converts the second dependency’s mutable result back into a quantity scaled up by 512. This establishes the arithmetic, not the units: interpreting these quantities as byte offsets, lengths, or block counts is inferred intent rather than established behavior.

This contract describes the supplied static evidence. No runtime tests have been performed.

## Behavior

### Local state and initial dependency call

Before calling either dependency, the function establishes two distinct invocation-local values:

- A mutable 32-bit unsigned word initialized from C.
- A mutable integer initialized from D.

These values are separate from the caller’s output destination. Changing either local value does not by itself update E.

The first dependency invoked is F-4e6cefe281de. It receives six arguments in this order:

1. The address derived from A plus 1,004.
2. B.
3. The address of the mutable local integer initialized from D.
4. The original value D.
5. The original base value A.
6. B again.

The repeated occurrences of B carry the same input value. Their semantic roles may differ inside the dependency; the wrapper provides no evidence that they are interchangeable there.

The third argument allows F-4e6cefe281de to modify the local integer. The wrapper later uses its post-call value if execution continues along the nonzero-result branch.

The fourth argument remains the original D. It is not a read of the mutable local after the dependency has changed it.

### Zero result from the first dependency

If F-4e6cefe281de returns zero:

- F-b8bab6835ed5 is not called.
- The wrapper does not directly write through E.
- The wrapper returns 3.

Any change made to the invocation-local integer is not subsequently used by this wrapper on that branch.

This is not a rollback guarantee. F-4e6cefe281de may have changed externally visible state before returning zero. Its implementation is not supplied, and the wrapper neither records nor reverses such changes.

### Nonzero result from the first dependency

Every nonzero first-dependency result selects the same continuation. The value is tested only for equality with zero; it is neither returned nor otherwise used.

F-b8bab6835ed5 receives six arguments in this order:

1. The current value of the mutable local integer initially populated from D.
2. C shifted right by nine bits.
3. The original D, converted into the unsigned 32-bit arithmetic domain, increased by 511 with 32-bit wraparound, and then shifted right by nine bits.
4. The address of the mutable unsigned local word initially populated from C.
5. F.
6. G.

The second argument is an unsigned logical right shift. It therefore equals the integer quotient of C divided by 512, rounded downward.

The third argument has a different rounding rule and an important overflow boundary. Its calculation is:

- Interpret D as an unsigned 32-bit value.
- Add 511 modulo \(2^{32}\).
- Logically shift the result right by nine bits.

For a nonnegative D in the signed 32-bit range, this equals D divided by 512 rounded upward. That interpretation does not extend to all signed inputs: negative values are processed through their unsigned representations, and the addition may wrap.

A change made by F-4e6cefe281de to its mutable local affects the first argument of F-b8bab6835ed5. It does not replace the original D used for the third argument.

The mutable unsigned word passed by address to F-b8bab6835ed5 still contains C when that call begins, absent effects outside the supplied function’s explicit operations. Its initialization is not the shifted value of C.

### Publication and return

After F-b8bab6835ed5 returns normally, the function reads the current mutable unsigned local word, shifts it left by nine bits in the 32-bit unsigned domain, and writes that 32-bit result through E.

This shift multiplies the local word by 512 modulo \(2^{32}\). Bits shifted beyond the 32-bit width are discarded. Consequently:

- Every value written by this operation has its low nine bits clear.
- A sufficiently large local value can produce a smaller output through truncation.
- The output can be zero even when the local value is nonzero.

The write occurs regardless of the result returned by F-b8bab6835ed5. There is no intervening status test.

The function then returns that dependency’s result unchanged. Output publication is therefore not restricted to result values a caller might regard as successful.

## Side effects

The wrapper’s explicit caller-visible memory operation is one 32-bit write through E on the branch where F-4e6cefe281de returns nonzero and F-b8bab6835ed5 returns normally.

The observable call-and-write order is:

1. F-4e6cefe281de executes.
2. Its result determines whether execution continues.
3. On continuation, F-b8bab6835ed5 executes.
4. After that dependency returns, the wrapper writes through E.
5. The wrapper returns the second dependency’s result.

The output write cannot be treated as preceding effects performed by the second dependency.

No explicit allocation, deallocation, resource acquisition, or resource release appears in the wrapper. Neither this absence nor the use of opaque word arguments establishes what the dependencies do.

Both dependencies receive pointers to invocation-local storage. Those pointers provide access during their calls; the wrapper does not provide persistent backing storage or establish permission to retain them. Whether either dependency retains a pointer is unknown.

The wrapper itself does not visibly read or write global state. No claim is made that either dependency preserves globals, avoids indirect writes to caller memory, or leaves shared state unchanged.

If E aliases memory that a dependency can access, that dependency’s effects can precede the final wrapper write. On the zero-result branch, “no direct output write” must not be strengthened into “the destination remains unchanged.”

   If F-b8bab6835ed5 leaves its mutable word equal to 7 and returns any result R, the wrapper writes 3,584 through E and returns R. This remains true if R is considered an error by some external contract.

   Let C be 513. If F-b8bab6835ed5 does not change the mutable unsigned word and returns normally, the wrapper writes 262,656. It does not automatically restore C or round C down before publishing it.

   With D equal to −1 in the 32-bit model, unsigned conversion followed by addition of 511 wraps to 510. The third argument to F-b8bab6835ed5 is therefore zero, provided the first dependency returns nonzero.
