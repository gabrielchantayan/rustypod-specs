## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Input forwarding.** For explicit input 0x89abcdef, the first call receives that same 32-bit value without represented validation.

2. **Unsigned selector.** A lookup byte of 0xff selects destination 0x110. Signed-byte interpretation selecting 0x10 is inconsistent.

3. **Fresh lookup.** If the initial lookup yields 3, publication targets address 20. If a later reread yields 9, that publication targets address 26, not 20.

4. **Byte truncation.** Shifting unsigned 0xffc00000 right by 22 and storing its low byte writes 0xff, not a whole word.

5. **Unsigned subtraction.** A saved lookup byte of 3 minus a saved unsigned word of 5 supplies two arguments of 0xfffffffe.

6. **Three evaluations at 0x28.** Suppose the saved read yields 0x11111111, while the argument-position reads yield 0x22222222 and 0x33333333. The call receives the latter values in their respective positions. The later derived word store writes 0x11111111. Neither argument-read temporal order is required.

7. **Separate global snapshots.** If the first anonymous-global read yields 0x00000400 and the second yields 3, the later masked-and-right-shifted argument is 1. The second snapshot supplies the four-times-derived value 12 and lookup address 13. Using 4096 to derive that lookup address incorrectly substitutes the first snapshot.

8. **Field-store order.** A saved lookup byte of 7 produces consecutive word stores of 7 and 14 at the relevant offset-0x34 field. Retaining only the final write does not preserve the represented access sequence.

9. **Overlapping widths.** If both address-zero stores are reached, the earlier access writes four bytes and the later access writes two. A single replacement word store is not established as equivalent.

10. **Partial execution.** If a dependency does not return, subsequent accesses need not occur. Earlier effects need not be undone. Reaching the terminal boundary does not establish success.
