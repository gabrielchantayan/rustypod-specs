# F-e180009f4387

## Purpose

In particular, interpreting the operation as initialization, serialization, device control, or memory management would be speculative. ## Side effects

- Eight word stores before the byte-processing section.
- Several byte stores before the repeating section.
- A fresh byte read before every lookup-directed byte store.
- One lookup-directed zero-byte store per loop iteration.

No explicit ordinary data-memory word reads appear in this representation. Indirect calls may perform arbitrary additional accesses.

### Aliasing and ordering

Computed destinations may alias one another, a lookup byte, callee-managed memory, or other state.

Consequently:

- A write may affect a later lookup result.
- A callee may alter a lookup byte between reads.
- Repeated zero stores cannot be treated as one store.
- The two writes involving the sixth selector must remain separated by the intervening calls.
- Calls cannot be assumed harmless merely because their return values are unused.
