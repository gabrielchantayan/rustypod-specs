# F-12db11666861

The established normalization behavior is:

## Behavior

### Normalization of the related pair

Call the first bounded result P and the second bounded result Q.

The selection rules before lower-bound enforcement are:

| Input condition | Source of P | Source of Q |
|---|---|---|
| B is zero | C | C |
| B is nonzero and C is zero | B | B |
| B and C are both nonzero | B | C |

Each selected value is then independently compared with 64 as a signed 32-bit integer. A selected value below 64 becomes 64. A selected value equal to or above 64 is retained.

Consequently:

- P and Q are always between 64 and 2,147,483,647, inclusive, at dependency entry.
- When either B or C is zero, P and Q are equal after normalization.
- When both are nonzero, the two results can differ.
- A negative nonzero input participates in selection as a nonzero value, then becomes 64 if selected.
- There is no upper cap other than the range of the signed input type.
- Zero substitution occurs before lower-bound enforcement.

The distinction between zero and a negative input matters. For example, with B equal to −1 and C equal to 200, the first result is 64 and the second is 200. B is not treated as absent merely because it falls below the minimum.

### Normalization of the auxiliary values

Call the two auxiliary results R and S.

R is 72 when D is zero; otherwise R retains D’s complete 32-bit value. S is 72 when E is zero; otherwise S retains E’s complete 32-bit value.

These defaults are independent. Neither auxiliary input influences the other, and neither is subject to the minimum of 64 applied to P and Q. In particular, 1, 63, and negative nonzero values remain unchanged in these positions.
