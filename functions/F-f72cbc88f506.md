# F-f72cbc88f506

## Purpose

F-f72cbc88f506 is represented as a stateful processing loop with no normal return. Each outer iteration reads two words from a current record, invokes dependencies, selects a processing path using the second word, and, on paths that reach the iteration boundary, obtains a replacement record address.

The supplied representation does not establish an application-level purpose. It does not justify describing this function as a parser, allocator, device operation, or message handler.

This contract distinguishes:

- **Established static behavior:** explicit operations, operand widths, value transformations, call ordering, and control-flow relationships in the supplied representation.
- **Inferred consequences:** conclusions derived from those operations, such as the selector ranges and loops whose captured conditions remain unchanged.
- **documented_only behavior:** displayed operations whose ordinary reachability or execution meaning is not established.

All conclusions are static. No runtime tests have been performed.

## Behavior

### Outer-iteration entry

The function first reads, in order:

1. A 32-bit primary word at A plus 0 bytes.
2. A 32-bit selector word at A plus 8 bytes.

The primary word becomes mutable working state. Three conditions are captured from the selector:

- Whether bit 13 is set.
- Whether its signed 32-bit interpretation, arithmetically shifted right by 14, is negative.
- Whether that shifted value is zero.

The negative condition is equivalent to selector bit 31 being set. The zero condition holds exactly for unsigned selector values 0 through 16,383.

The resulting path split is:

- **Low range:** 0 through 16,383.
- **Upper range:** every other 32-bit selector value.

The conditions are captured before the initial dependency sequence and are not explicitly refreshed from memory afterward.

Six calls then occur in this order:

1. An indirect dependency receiving A plus 12 bytes.
2. An indirect dependency with no explicit argument shown.
3. F-fd74adab24b4.
4. F-172f180ab937.
5. An indirect dependency with no explicit argument shown.
6. Another indirect dependency with no explicit argument shown.

The first target is formed from the current link-like address plus 0x9fe. Other indirect targets are formed from address tokens and offsets, without a supplied trusted dependency mapping.

The range branch follows these calls. No dependency is assumed to preserve global memory.

### Upper-range preparation

The upper-range path performs:

1. One indirect call.
2. Capture of C’s low 16 bits.
3. Capture of H2 as auxiliary state.
4. **Eleven further indirect calls before the sign/overflow decision.**

Thus this preparation contains twelve indirect calls in total, not eleven. The third call in the eleven-call sequence receives an opaque fixed address token.

A decision then uses the captured zero condition, captured negative condition, and incoming overflow condition. Since the upper-range path requires the zero condition to be false, this decision reduces to whether the selector’s sign differs from the incoming overflow condition.
