## Acceptance examples

These are conditional static acceptance cases, not executed tests.

1. **Initial truncation.** If the root is 0x1234ABCD and the initial store is valid, its sixteen-bit data is 0xABCD. Byte ordering remains target-dependent.

2. **Transient byte remains observable.** With fourth argument 0xA6 and source word 0x12345678, initial target +0x11 receives 0xA6 and later 0x78. An implementation preserving only the eventual value would omit a required represented write.

3. **Signed selection.** A selected-address halfword of 0xFFFF extends to −1, not 65535. A halfword of 0x8000 extends to −32768. Neither example establishes that subsequent addresses are valid.

4. **Repeated pair.** Where individual stores are observable, the two consecutive pairs produce self-address store, intermediate-address byte store, self-address store, intermediate-address byte store. Combining the pairs changes the access contract.

5. **Overwrite affects traversal.** If the saved chain value equals the chain address, ordinary coherent storage and no intervening external mutation make the later +0x14 read observe the shifted intermediate-address value just stored there.

6. **Fresh read is required.** If a second-anchor update changes second product address +0x44, the byte subsequently written at second product address +0x11 comes from the fresh read. It need not equal the retained product observation’s low byte.

7. **Stack multiplicity and timing.** With first argument 1, supported shifts, and disjoint ordinary storage, the two four-bit-shift slots receive 16 and the four eight-bit-shift slots receive 256. Slot 0x108 receives the destination earlier than its two later copies.

8. **Dependency changes the later argument.** If the indirect target changes the dependency-argument global and returns, and nothing subsequently changes it, F-cdec09f5d432 receives the changed value.

9. **Non-returning dependency.** If the indirect target does not return, no post-call clearing, marker assignment, F-cdec09f5d432 invocation, or terminal invocation is reached. If only F-cdec09f5d432 fails to return, the earlier post-call assignments may already be visible, but the terminal invocation is not reached.
