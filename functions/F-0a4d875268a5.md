# F-0a4d875268a5

## Purpose

F-0a4d875268a5 classifies an unsigned integer by whether its binary representation contains **at most one set bit**.

The result is true for zero and for every representable positive power of two. It is false for every other representable input.

This is a bit-pattern predicate, not a strict positive-power-of-two predicate. In particular, zero is accepted. A caller that requires a positive power of two must impose the nonzero requirement separately.

The classification is established by the supplied static definition. Any intended application—such as validating a flag selection, recognizing an alignment, or checking a capacity—is unknown.

## Behavior

### Classification rule

The result depends only on the unsigned input value supplied to this invocation.

Zero is accepted because it contains no set bits. Each representable positive power of two is accepted because its binary representation contains exactly one set bit. Every remaining value is rejected because it contains at least two set bits.

The position of a single set bit does not change acceptance. A value with only the highest unsigned value bit set is accepted just as a value with only the lowest bit set is accepted. No signed-number interpretation is used.

The predicate is exact. It does not accept a value merely because it is close to a power of two, contains a contiguous run of bits, or becomes a power of two after rounding.

### Width and arithmetic

The supplied unsigned arithmetic supports the following equivalent characterization:

\[
\text{result is true}
\quad\Longleftrightarrow\quad
x\mathbin{\&}\bigl((x-1)\bmod 2^W\bigr)=0.
\]

Here the ampersand denotes bitwise intersection, and subtraction is interpreted modulo the unsigned range. This equation characterizes the result; it does not require a particular replacement implementation.

For a nonzero unsigned value, subtracting one clears its least significant set bit and sets any lower positions that were zero. The intersection with the original value therefore retains precisely the original set bits other than that least significant set bit. It is zero exactly when there were no other set bits.

For zero, the modular predecessor is the largest representable unsigned value. Its intersection with zero is still zero. Consequently, zero returns true rather than causing an arithmetic error.
