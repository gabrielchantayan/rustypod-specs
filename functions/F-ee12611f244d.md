The opening mutations interleave two writes to the retained shifted address plus 9 with word writes elsewhere. The first byte uses the high half of the final dependency result; the second uses the low byte of the retained shifted address. Between them, a word destination formed from the final result’s low half, scaled by 256 and offset by 0x54, receives the shifted base. Before these operations, the final result’s high half plus 0x14 receives the retained shifted address as a word.

The shifted-base word at offset 0x14 is then cleared. A byte read at shifted base plus 5 precedes clearing the doubled-index word at offset 0x14. ### Early fixed-storage ordering and propagation

After the two byte writes at doubled index plus 0x15, the function reads **one byte at fixed address 0x05**. It retains the zero-extended result as an address base. The next represented memory effect writes the low byte of the doubled index to **fixed address 0x01**.

The 0x05 read therefore precedes the 0x01 write. It is not a read of a state produced by that write.

The retained fixed byte then participates in computed accesses, including a byte write at its value plus 0x15 and a later word read at its value plus 0x54. Between those accesses, the shifted-base region receives byte mutations, and a destination based on the earlier retained word receives a word write.

Define the **propagation word** as the value obtained by this particular word read at retained-fixed-byte value plus 0x54. Its source is then overwritten with the earlier retained word. Subsequent propagation uses the saved value, not an implicit reload of that source.

Further updates load words through offsets such as 0x74, write values relative to those loaded words, and repeat self-relative word and byte mutations. These establish an access footprint, not a structure definition.

A later fixed-word write has a recoverable position among computed writes:

- The doubled-index word at offset 0x14 first receives twice the shifted base.
- **Fixed address 0x54 receives twice the propagation word as a 32-bit write.**
- The doubled-index word at offset 0x14 then receives the propagation word twice.

Thus the fixed 0x54 write is bracketed by computed writes to the same offset-0x14 destination. It must not be moved before the first or after the later pair when transaction order is observable.

Afterward, the doubled-index byte at offset 0x15 receives the low byte of four times the propagation word twice. **Fixed address 0x15 then receives the low byte of the doubled index**, before further computed word writes, including an offset-0x34 write of four times the propagation word.

These relationships remain significant if computed destinations overlap fixed storage.

### Scaled destinations and the late stored base

The intervening mutations propagate loaded words, scaled values, and narrowed bytes through computed regions. A byte read at a base plus 5 can select a word at that byte’s value plus 0x74. Loaded words can themselves become destination bases.

Repeated reads of a byte or word are separate accesses. For example, two reads at the same computed base plus 5 are separated by other mutations and need not return the same value.

A later group writes 0x3A using three different access widths: a byte at one scaled destination, a halfword at another, and a word at an offset-0x20 destination.

For the remaining description, define:

- **Adjusted quantity:** four times the propagation word, minus 0x96.
- **Computed base:** four times the adjusted quantity.
- **Stored base:** the 32-bit value loaded late from fixed stored-base storage.
- **Scaled loaded value:** four times a word previously obtained through byte-selected offset-0x74 storage.
- **Paired base:** twice that same previously obtained word.

The computed-base word at offset 0x20 receives 0x20, then 0x2F, then a zero-extended byte read from computed base plus 4, then 0x20 again.

**The stored base is loaded after that last 0x20 write and before the 32-bit write of 0x20 at fixed address 0x60.** Both the load and the fixed 0x60 write precede the repeated cross-region updates.

The stored base is a retained value. Even if the 0x60 write or a subsequent computed write overlaps its storage, the represented updates do not reload that base.

### Repeated cross-region updates

The byte values are respectively the low byte of the computed base and the low byte of the stored base. The scaled destination receives the scaled loaded value.

The first group differs from later groups:

### Input and result widths

### Compact-index boundary

A compact-index producer result of 0x7F yields compact index 508 and doubled index 1016. Doubled index plus 0x14 is address 0x40C. No local rejection of that address is represented.

### Fixed-read ordering

If the read at 0x05 returns 0x80, the retained base is 0x00000080. The following write at 0x01 does not replace that retained value. Later accesses based on it use the saved read result.

### Bracketed fixed-word write

If the propagation word is 0x12345678, the fixed 0x54 word write carries 0x2468ACF0 under bit-vector arithmetic. It occurs after the doubled-index offset-0x14 write of twice the shifted base and before the subsequent writes of 0x12345678 to that computed destination.

### Stored-base retention

If the late stored-base load returns an address and the following 0x60 write overlaps its source storage, repeated updates still use the retained address. Moving the base load after the 0x60 write is not equivalent.

### Fresh 0x67 consumers

Suppose the retained 0xA9 word ends in 0xAB. Initialization writes 0xAB to 0x67.

If an intervening computed write changes 0x67 to 0xCD before the first later computed-base-plus-9 consumer, that consumer reads 0xCD. If another intervening write changes it to 0xEF before the second consumer, the second reads 0xEF. Neither consumer may unconditionally substitute 0xAB.

### Retained terminal argument

If paired base plus 0x14 is read as 0x11223344 and later overwritten, F-dep-003’s third represented argument remains 0x11223344. A new read would not preserve the retained-value relationship.
