**Established static behavior:** the routine has a 24-byte local transformation area, a 48-byte local processing area, two distinct byte-transformation operations, a shared flag update, and separate publication and return operations.

Argument preparation assigns the scaled selector to that scalar, but either byte transformation and either continuation calculation can overwrite it before selection.
