### Cursor adjustment and byte read

When the matching-sign condition holds, the effective byte cursor is moved backward by 4,197 bytes, or hexadecimal 0x1065. One byte is read at the resulting address.

The byte is widened to an unsigned 32-bit value. Its possible values are therefore 0 through 255; it is not sign-extended.

The adjusted cursor and widened byte replace the cursor and general-register-10 state used later in the visible fragment. Consequently, if the state record is also selected, it contains the adjusted cursor and the widened byte, rather than their incoming counterparts.

The cursor adjustment is address arithmetic. It is not a 4,197-byte read, allocation, copy, or clearing operation. The evidence does not define behavior when the subtraction crosses the usable address-space boundary.

After the byte read, the fragment requests a coprocessor load using coprocessor selector 5, coprocessor register selector 10, and an address 476 bytes above the incoming address base.

The byte read precedes this load in the representation. The load's transfer width, alignment requirements, privilege requirements, completion behavior, and coprocessor-state consequences are not established.
