# F-da0d60967c48

## Purpose

This routine coordinates a fixed sequence of indirect calls, captures values returned by selected calls, and performs interleaved memory reads and writes. Its explicit effects include distributing a retained word, publishing scaled results, performing two byte-table-directed writes, assigning a dependency result to a global destination, clearing two locations, and attempting a call to address zero.

No application-level purpose is established. The available evidence does not justify describing these operations as allocation, initialization, serialization, device control, or cleanup.

This contract describes the visible static path. It does not establish that any dependency returns normally, that every calculated address is accessible, or that execution reaches the nominal return.

- Next, read **G-source** and retain its address-like value as **G**.
- Then invoke **F-U39** with **W**, **H₁**, **W**, and **W**, in that argument order.

## Acceptance examples

These are conditional consequences of the static representation, not observed executions. Relevant calls must return, accesses must be valid, and arithmetic must follow the stated width interpretation.

1. **Retained word versus byte truncation.** With **A = 0x100**, the initial word address is **0x474**. If that read yields **0x123456ab**, the immediate byte write stores **0xab** at **0x401**. The later copies use the full **0x123456ab**.

2. **Input-bit selection.** With **P = 0xffffffff**, **F-U11** receives **0xffff0000**. With **P = 3**, it receives zero. The transformation does not preserve all bits above the low two.

3. **Masked input address.** With **P = 0x1003** and **D = 5**, the write before **F-U25** stores the word **20** at **0x1014**. Both arguments to **F-U25** are **20**.

4. **Capture between publications.** If **G** is captured as **0x2000**, a subsequent dependency changing **G-source** to **0x3000** does not redirect the later read: it still uses **0x2014**. The capture occurs after the first write of **W**, not after both writes.

5. **Second publication aliases the read.** If captured **G = 0x2000** and **J = 0x800**, the second **W** destination and the subsequent **Q** source are both **0x2014**. For ordinary memory with no intervening external modification, the read yields the just-written **W**.

6. **First table-directed write.** With **V = 0x00800000**, the first lookup address is **2**. If that byte is **0x7f** and **Q = 0x123456ab**, the write stores **0xab** at **0x90**.

7. **Second table-directed write.** With **L₂ = 0x00200000**, the second lookup address is also **2**. If its byte is **0x7f** and **Q = 0x00400000**, the second write stores **1** at **0x90**, after the first byte-directed write.

8. **Unaligned final clear.** With **L₂ = 0x80**, the final halfword address is **1**. The body attempts the access without a visible alignment check; success depends on target behavior.

9. **Failure at the last call.** If the call to address zero faults after all prior operations complete, the assignment to **R** and both final clears precede that fault. No visible rollback follows.
