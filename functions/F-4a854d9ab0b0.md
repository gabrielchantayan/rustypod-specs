# F-4a854d9ab0b0

## Purpose

- A nonzero result from prerequisite dependency F-392d97f6cbd4.
- A nonnegative descriptor index strictly below a signed limit read from the receiver.

When either condition fails, the function returns the 32-bit value zero. When dispatch occurs, it returns the indirect operation’s 32-bit result unchanged.

### Descriptor reads

2. The signed index from descriptor byte offset 8.

### Signed range decision

For a negative index, the function does not read the receiver limit and does not dispatch. It returns zero.

For every nonnegative index, including zero, the function reads the signed 32-bit limit at receiver byte offset 4. It dispatches exactly when the index is strictly less than that limit.

The effective condition is therefore:

- Index is at least zero.
- Index is less than the receiver’s signed limit.

Important boundary behavior follows directly:

- Index zero is eligible when the limit is positive.
- An index equal to the limit is rejected.
- A negative limit rejects every nonnegative index.
- A zero limit rejects every index.
- No index of −1 has special sentinel behavior beyond being negative.

The comparisons are signed 32-bit comparisons. The function does not subtract one from the limit, increment the index, or perform other range arithmetic. There is consequently no range-calculation overflow introduced by this body.

The third explicit input does not supply an alternate limit. On the path where a comparison against a limit matters, the limit comes from the receiver. On the negative-index path, dispatch is already excluded. Changing only the third input therefore does not change this function’s visible control decision.

It then calls that entry once with the receiver, index, and payload described above.

The selected entry is not checked for nullness or callability. The function provides no visible recovery for an invalid receiver, invalid table, invalid target, or incompatible calling interface.
