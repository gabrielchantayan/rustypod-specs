1. The first read, plus two, initializes the default continuation.
2. A subsequent read initializes the initial control seed.

The two reads need not return the same value. The default continuation is retained for the invocation; later fallback does not reread G0.

Each cycle then:

1. Retains the accumulator from the preceding cycle.
2. Reads G1 and adds it to the current control value to obtain the dispatch value.
3. Resets the prospective next control value to the retained default continuation.
4. Reads G6 into the provisional next accumulator.
5. Performs the selected dispatch behavior.

Consequently, even a cycle selecting immediate return has already read G1 and G6. A case that preserves the previous accumulator still performs, but discards, the cycle-level G6 read.

## Acceptance examples

These examples assume that actual global reads and defined arithmetic select the stated dispatch sequence.

1. **Immediate return.** If the first dispatch is 13, the function returns unsigned zero without invoking either dependency. Entry still performs the two ordered G0 reads, followed by the cycle’s G1 and G6 reads.

2. **Independent entry observations.** If the first G0 read yields four and the second yields nine, the default continuation is six and the initial control seed is nine. The first dispatch uses nine plus its G1 read; fallback uses six, not eleven.

3. **Two G6 observations.** If a cycle selects dispatch 2, its cycle-level G6 read yields five, and its case-specific G6 read yields eight, the next accumulator is eight. For an unrecognized dispatch with the same provisional value five, no second G6 read occurs and the next accumulator remains five.

4. **Return without capture.** Any finite execution reaching 13 without visiting 3 returns zero, regardless of argument capture or dependency calls.

5. **Captured accumulator.** If dispatch 8 loads seven, dispatch 3 follows with G3 equal to three, and dispatch 13 follows without another capture, the returned result is 21. A preceding dispatch 7 instead makes that captured result zero.

6. **Before argument capture.** If dispatch 6 occurs before dispatch 1, its second and third dependency arguments are necessarily zero. Its first argument is not necessarily zero: a preceding dispatch 17 can replace the current fourth-argument operand. If dispatch 6 is the first dispatch, all three arguments are zero.

7. **Last capture wins.** If visits to dispatch 3 capture 21 and then 12 before return, the result is 12. Later argument capture alone does not erase it.

8. **Zero is not rejection.** After argument capture, a zero first argument selects the G5-minus-seventeen candidate at dispatch 16. No error or immediate return follows solely from that zero.

9. **Post-call mutations matter.** If F-b09db3398a5a changes G2 or G3 and returns normally, subsequent arithmetic reads those globals after the call. Pre-call values cannot be substituted merely because they were previously observed.

10. **Unresolved G14 shift.** A numerical expectation for dispatch 4 that depends on shifting a high-bit-set G14 value is not established without its type or target shift semantics. Unsigned destination storage does not resolve the expectation.

11. **Possible nontermination.** If the actual control arithmetic continually selects dispatches other than 13 and no dependency interrupts execution, the function continues rather than implicitly returning zero.
