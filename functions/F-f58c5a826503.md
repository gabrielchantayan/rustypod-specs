## Acceptance examples

These examples are conditional static consequences, not executed tests.

1. **Byte-derived absolute destination.** If the first byte read yields `0x80`, the following byte store targets `0x91`. It does not target the incoming address plus `0x91`.

2. **Intervening mutation.** If an initial read at `Q + 1` yields 3 and a later callee changes that byte to 7, the next corresponding store targets `0x18`, not `0x14`.

3. **Cached destination.** If the cached destination in phase 9 is `0x20`, the later word store targets `0x34`, even if an intervening callee changes `B[T + 1]`.

4. **Tag truncation.** For a value of `0x3ff00000`, `tag` is `0xff`. The ten-bit masked extraction is truncated to eight bits by the byte store.

5. **Shifted-result zero.** In phase 3, `L(P, 28)` is zero under the 32-bit model regardless of **B**. The call still occurs with its other argument.

6. **Restricted direct-clear bases.** **T** is one of `0`, `0x40000000`, `0x80000000`, or `0xc0000000`, determined by the low two bits of **N**.

7. **No guaranteed successful iteration.** If a dependency never returns, no later explicit access occurs. If a calculated word address is invalid or unsupported for unaligned access, successful continuation is not established.

8. **Repeated execution.** If all calls return and all accesses succeed, completion of phase 12 immediately starts another iteration with the replacement inputs and hidden state.
