## Behavior

### 1. Initial branch and halfword transfer

The primary scaled address is the low 32 bits of the control word multiplied by \(2^{22}\). It is zero exactly when the control word’s low ten bits are zero.

If the primary scaled address is nonzero:

- The initial halfword transfer is skipped.
- The equality-gated prefix cannot advance.
- The rare transition is skipped.
- The eventual dispatch base remains the incoming link address.

Thus, a control word of 1 establishes a primary scaled address of `0x00400000`, but does not establish a dispatch target of `0x00400EB6`.

If the primary scaled address is zero, the function performs the initial transfer:

1. It derives an auxiliary address from the incoming link address, the control word’s bit-8 condition, and the entry stack location shifted right by one.
2. It derives a secondary scaled address from the control word multiplied by \(2^{23}\), retaining 32 bits.
3. It forms the destination by adding the byte displacement to the incoming source address.
4. It reads one 16-bit value from the incoming source address.
5. It replaces the source-state address with the destination minus the adjustment word.
6. It writes the previously read halfword to the destination.

The temporary value used by subsequent gates is then selected from the incoming link address. This selection is distinct from the primary scaled address and from the destination.

On this branch, the control word’s low ten bits are zero. Consequently, its bit-8 condition is false and the secondary scaled address is also zero.

The displacement is measured in bytes, not halfwords. The operation transfers exactly one halfword. Source and destination may coincide; the represented order is still a source read followed by a destination write. Partial overlap, memory-mapped devices, and concurrent modification receive no additional atomicity guarantee.

### 2. Equality-gated prefix

Further conditional progress requires both a zero primary scaled address and a zero incoming link address. A nonzero incoming link address therefore permits the initial transfer but prevents the deeper prefix.

The prefix contains several conditional XOR-and-shift expressions. Each is entered only when the previous result is zero. Its shift count is extracted from that zero result, so every reached shift in this prefix has count zero.

Under the stated interpretation, progress therefore requires these equalities:

- The auxiliary address is zero.
- The primary scaled address agrees with the relevant auxiliary and secondary scaled addresses.
- The byte displacement equals the comparison word.
- The updated source-state address equals the adjustment word.

The scaled addresses are already zero on this path. Repeated equality checks do not themselves introduce additional memory reads or writes.

Next, the function adds the accumulator word, a control-derived contribution, and a propagated carry-like condition. The control-derived contribution is the control word’s low ten bits multiplied by \(2^{21}\).

On a path reaching this addition:

- The low ten control bits are zero.
- The propagated carry-like condition is false.
- The addition result equals the accumulator word.
- Further progress requires that accumulator word to be zero.
- The carry-out from this addition is false.

The next gate adds the entry stack location, twice the byte displacement, and the incoming carry. Twice the displacement is evaluated as a 32-bit quantity. Progress requires a zero 32-bit sum. A wrapping sum is not rejected merely because carry-out occurs.

Failure of any gate skips the remaining conditional work. It does not return an error or undo the initial halfword transfer. Execution proceeds toward dispatch with the incoming link address unchanged.

### 3. Rare conditional transition

If the complete prefix succeeds, the function performs a further transition in this represented order:

1. An unidentified machine-state slot receives the entry stack location multiplied by 64, reduced to 32 bits.
2. A candidate replacement link address is calculated as the incoming link address plus the same byte-scaled stack contribution.
3. Halfword references through the old incoming link address provide a destination address and a stored value.
4. A halfword store is performed.
5. A separate comparison address becomes the primary scaled address plus two bytes.
6. The carry-like condition is cleared.
7. The incoming link state is replaced by the candidate address.

For the halfword store:

- The destination is the zero-extended 16-bit value read through the old incoming link address.
- The stored value is a halfword read through that same old address, increased by 15 and reduced to 16 bits.

The destination is therefore in the low 64 KiB of the address space. It is not necessarily the old incoming link address.

The representation contains two references to the old halfword but does not establish their relative evaluation order or whether they correspond to one physical read or two. If the location changes between reads, equality of the destination-producing and value-producing readings is not guaranteed. The dependent readings must complete before their store can complete.

The machine-state write precedes these halfword accesses. A failure during the subsequent reads or store therefore has no represented rollback of that earlier update.

There is a stronger derived constraint under the 32-bit model. Reaching this transition requires a zero incoming link address and a zero auxiliary address, making the entry stack location either zero or one. The final addition gate requires that location plus an even value to be zero modulo \(2^{32}\), excluding one. Thus:

- The entry stack location must be zero.
- The byte displacement must be either zero or `0x80000000`.
- The machine-state slot receives zero.
- The replacement link address is zero.

These are static consequences, not evidence that an actual execution environment provides a valid stack location at zero.
