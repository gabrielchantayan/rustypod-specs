# F-8810f53aaa0b

## Purpose

F-8810f53aaa0b computes a terminator-inclusive length for a null-terminated character sequence. For a non-null input, the result is the number of character elements before the first zero-valued element, plus one. For a null input, the result is one.

The established behavior is a scan and an integer result. The function does not allocate storage, copy the sequence, append a terminator, or validate the accessible extent of the input.

An inferred use is calculating storage required to hold a sequence together with its terminating zero. That use is not established by any caller evidence. In particular, the null-input result does not establish that a null pointer identifies an allocated empty sequence.

## Interface

The function accepts one pointer to character storage.

There are two supported input cases:

- **Null pointer:** No character storage is read.
- **Non-null pointer:** The pointer identifies the first character element to examine. The function proceeds through consecutive elements until it reads a zero-valued element.

For a non-null input, defined completion requires every element from the starting position through the first zero-valued element to be readable during the scan. A terminator somewhere outside the readable extent does not satisfy that requirement.

There is no explicit length, capacity, encoding, ownership, or error-reporting argument.

### Output

The function returns a signed integer.

Let **N** denote the number of consecutive nonzero character elements preceding the first zero-valued element:

- For a non-null input, the result is **N + 1**, subject to the arithmetic constraints below.
- For a null input, the result is **1**.

A null input and a non-null input whose first element is zero therefore produce the same result. The return value does not distinguish these cases.

## Behavior

### Null input

The function determines whether the input pointer is null before attempting a character read.

If it is null, scanning is skipped and the function returns one. It does not report an error or dereference the null pointer.

This is an explicit special case, not a consequence of treating null as readable empty storage.

### Non-null input

The first character access is at the supplied address.

The function examines elements in increasing address order. Each nonzero element contributes one to the count and causes the scan position to advance by one character element. Reading a zero-valued element ends the scan.

The terminator is read but does not contribute to the count of preceding nonzero elements. The returned result includes one additional unit for that terminator.

Consequently:

- An immediate terminator produces one.
- One nonzero element followed by a terminator produces two.
- Data following the first terminator does not affect the result.
- An embedded zero ends the scan even if later elements contain meaningful data.
- A nonzero element does not stop the scan merely because it is whitespace, a control value, or invalid in some external text encoding.

No text decoding, normalization, character classification, or multi-element character counting is established.
