## Acceptance examples

These examples are conditional static expectations, not executed tests. They assume preceding calls return, required accesses are permitted, and the supplied representation accurately captures the relevant operations.

### A-high aliases the explicit zero destination

If A is zero, A-low and A-high are both zero. The second and fourth word stores each write a 32-bit zero to address 0x24. The sixth word store writes another 32-bit zero there.

All three writes remain observable events. Intervening dependencies may change that address.

### Unaligned high-derived destination

If A equals 0x00400000, A-high is 1. Both A-high stores therefore write the 32-bit value 1 at address 0x25.

There is no visible alignment adjustment. On a target that rejects this word access, later behavior is not required to occur.

### Retaining the earlier scaled result

If I₆ is 3 and I₇ is 5, without arithmetic overflow:

- The ninth word store writes 12 at address 0x44.
- The tenth word store writes the same retained value 12 at address 0x28.
- F-044 receives 20.

The tenth store must not substitute 20 for its retained value merely because its destination uses I₇.

### Byte truncation

If J is 0x12345678:

- The first byte write stores 0xe0.
- The second byte write stores 0x23.

These values go to destinations selected by separate byte reads. Equal destination addresses are not required.

### Repeated selector reads

If the first three reads from Q + 1 yield 2, 7, and 9, their writes target 0x13, 0x18, and 0x1a, respectively. F-073 receives 9.

This remains the expected sequence even though all three reads use the same address expression.

### Conditional address wraparound

Under 32-bit wrapping arithmetic, if B-low is 0x2000, Q becomes zero because the mathematical product is 0x100000000. The first three byte reads then use address 1.

This example does not establish that address 1 is valid or that the target necessarily implements wrapping arithmetic.
