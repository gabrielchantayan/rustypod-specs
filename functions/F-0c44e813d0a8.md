# F-0c44e813d0a8

## Purpose

F-0c44e813d0a8 performs two sequential zero/nonzero checks. If both return zero, it prepares a temporary object, increments a 16-bit state field, invokes an indirectly selected callable, obtains a 32-bit result from another dependency, writes that result and a marker into state, and invokes a final dependency.

Its return value is the status from the last check executed. No later operation supplies a separate success or failure result to the caller.

“Eligibility check,” “initialization,” “conversion,” “publication,” and “finalization” describe inferred roles. The supplied static evidence establishes the operations and their ordering, but not their application-level meanings.

### Shared addressing structure

Three distinct address-related values must not be conflated:

1. A **root-selector global** contains a 32-bit pointer to a root location.
2. A **root location** contains a 32-bit state address.
3. A **lookup-base global** supplies an address-like value added to a state address for a 16-bit lookup read.

After the first check, the function reads the root-selector global and retains the resulting **root-location pointer**. That retained pointer identifies a location, not a snapshot of the state address stored there.

The second check’s argument preparation does **not** use the retained pointer. Each of its two state-address expressions independently reads the root-selector global and dereferences the root-location pointer obtained by that expression.

Later state updates instead dereference the retained root-location pointer. Consequently, changing the selector global and changing a root location’s contents have different effects.

## Behavior

### First check and root-location capture

Thus, this selector read occurs even when the first check returns nonzero. The pointed-to root location is not dereferenced as part of this capture.

F-5f5f14cedda3 and F-256e8a77aa59 have already executed. Their effects are not undone.

### First-record preparation and second check

If the first status is zero, the function writes a 32-bit zero into the first word of the first temporary record and the payload into its second word.

It calls F-43ce968102ca with four arguments:

1. A state address obtained by freshly reading the root-selector global and then reading the root location identified by that value.
2. The retained 32-bit result from F-5f5f14cedda3.
3. A 16-bit value read from the address formed by adding the lookup-base value to a state address. This state address is obtained through a separate fresh read of the root-selector global and a dereference of the resulting root-location pointer.

The two selector reads in this argument preparation are independent of the earlier capture. The supplied representation does not establish their relative evaluation order or a coherent snapshot across the argument expressions.

The lookup uses address addition. No scaling, index normalization, range check, or overflow check is shown. Address validity and the relevant machine address arithmetic are preconditions; no portable behavior for an invalid or overflowing address expression is established.

If F-43ce968102ca returns nonzero, the function returns that exact status. Initialization and all later operations are skipped. The first record has already received the zero-and-payload pair, but this is a local workspace change, not a state publication.
