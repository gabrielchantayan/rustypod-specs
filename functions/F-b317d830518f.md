# F-b317d830518f

## Purpose

The supplied static representation establishes two paths:

- If a receiver byte at offset +0xE8 is nonzero, record the request at +0xE0 and return immediately.
- Otherwise, record an input byte, resolve the request, apply a derived value to the receiver, construct temporary state, optionally dispatch the resolved item, record the request, and finalize the temporary state.

## Behavior

### 1. Initial path selection

The first explicit receiver access reads the byte at +0xE8.

If that byte is nonzero:

1. Write the request value as 32 bits at +0xE0.
2. Return without invoking any dependency.

On this path, the function does not explicitly write the request attribute, resolve the request, construct temporary state, or perform dispatch.

The selector is sampled once. There is no later direct reread of +0xE8, so a dependency changing that byte during the processing path does not trigger the short path within this invocation.

### 2. Attribute storage and resolution

If the initial selector byte is zero:

1. Write the eight-bit request attribute at receiver offset +0xE4.
2. Invoke F-1f46730b1ced with the address at receiver offset +0xB0 and the 32-bit request value.
3. Test the returned 32-bit result against zero.

There is no visible rollback of the attribute write before this failure call. The precise failure mechanism—termination, exception, transfer of control, or another mechanism—is unknown. No recoverable error value is returned to this function’s caller.

If the resolution result is nonzero, that result is retained for subsequent calls. The function does not repeat resolution.

### 3. Receiver modification

1. F-d2f99870cc43 receives the resolution result and returns a 32-bit value.
2. F-bf557f07179f receives the receiver address and that returned value.
3. F-fa8898fa75ae receives the resolution result.

### 4. Temporary-state construction

2. Read one byte at offset +0x2C from its returned address.
3. Invoke F-fdd8589eca2d again.

### 5. Optional dispatch decision

After temporary-state construction, invoke F-5c5958cfd5fe and compare its 32-bit result with exactly 8.

If the result equals 8, skip optional dispatch entirely and proceed to request recording and finalization.

For every other result:

1. Invoke F-fdd8589eca2d a third time.
2. Select a 16-bit auxiliary argument.
3. Invoke F-818c773e8c8a with:
   - The third context lookup’s result.
   - The local temporary-storage address.
   - The retained resolution result.
   - The original 32-bit dispatch argument.
   - The selected 16-bit auxiliary argument.

The auxiliary argument is selected as follows:

| Suppression selector | Dispatch argument | Auxiliary argument |
|---|---|---|
| Nonzero | Any value | Zero |
| Zero | Zero | Zero |
| Zero | Nonzero | Current 16-bit receiver field at +0xE6 |

The third context lookup occurs before the conditional read at +0xE6. Consequently, if that lookup changes the field, the later field read observes the changed value under ordinary sequential execution.

When either zero-producing condition applies, the function does not explicitly read +0xE6. A nonzero suppression selector does not suppress dispatch itself; it suppresses use of the receiver’s auxiliary field.

The function does not visibly branch on a dispatch result.

### 6. Request recording and finalization

1. Write the original request value as 32 bits at receiver offset +0xE0.
2. Invoke F-920630e53283 with the temporary-storage address.
3. Return.

The request write precedes finalization. It is not deferred until finalization succeeds.

The request is therefore recorded at different points on the two main paths: immediately after the initial selector read on the short path, but after all preceding processing and any optional dispatch on the longer path.
