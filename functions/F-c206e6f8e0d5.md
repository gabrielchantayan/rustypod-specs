# F-c206e6f8e0d5

## Purpose

F-c206e6f8e0d5 performs three ordered delegated operations involving an object base and two interior addresses. It then clears one byte, examines a pointer-valued field and, conditionally, an integer reached through that field. When both inspected values are nonzero, it reads a global function-pointer slot and invokes the target obtained from that read.

The established contract is the ordering of invocations, memory accesses, and branch conditions. The representation does not establish that the function destroys, resets, closes, or releases the object. Those interpretations must not replace the concrete requirements below.

This document distinguishes:

- **Established static evidence:** behavior directly represented in the supplied function.
- **Inferred intent:** possible semantic interpretations, not acceptance requirements.
- **Unknowns — documented_only:** details not established by the supplied evidence.

No runtime tests have been performed.

- The global target slot is not read by the represented final-dispatch path.

### Pointed-to integer read

If that integer equals zero:

- The global target slot is not read by the represented final-dispatch path.
- No final indirect invocation occurs.
- The function returns.

The test is strictly zero versus nonzero. No positive-value condition, bit-mask condition, magnitude threshold, or arithmetic transformation of the integer is represented. Under a signed interpretation, negative values satisfy the nonzero condition.

The representation shows one pointer-field read and, on the non-null path, one pointed-to integer read for this decision. It does not show a second field read or integer read immediately before dispatch.

### Conditional global read and indirect invocation

Only after the loaded object-field pointer is non-null and the pointed-to integer has been read as nonzero does the function read the global function-pointer slot.

That read supplies the target for the immediately following indirect invocation. It is a distinct direct memory access, not merely an unspecified source of target identity.

The established ordering is:

2. The byte at +0x70 is written with zero.
3. The pointer field at +0x74 is read.
4. If the pointer is non-null, its pointed-to integer is read.
5. If that integer is nonzero, the global target slot is read.
6. The target obtained from the global read is invoked.
