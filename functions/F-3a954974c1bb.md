## Behavior

1. Store the first 32-bit value at offset 0.
2. Store the 8-bit byte value at offset 4.
3. Store 32-bit zero at offset 32.
4. Store the second 32-bit value at offset 8.
5. Store the third 32-bit value at offset 12.

The byte write at offset 4 does not itself clear offsets 5–7. The zero write at offset 32 is a single 32-bit store, not evidence of clearing the surrounding region.

These are the explicit operation order shown by the supplied representation. They do not establish atomicity, memory barriers, or safe observation by concurrent threads.
