## Acceptance examples

These examples are conditional static consequences, not executed tests. Calls must return and accesses must be permitted for the described operations to occur.

1. **Absolute byte-derived destination.** If the first source byte is 0x80 and the incoming byte is 0xab, the first write stores 0xab at address 0x91, independent of the original source base.

2. **Third-input collapse.** Under wrapping 32-bit arithmetic, every third input produces a zero derived base. The associated byte reads therefore address 1. Earlier word reads still use the shifted input plus 28 and are not eliminated.

3. **Separate rereads.** If a source byte is 3 for one update and becomes 9 during an intervening dependency, the corresponding destinations are 20 and 26. Reusing the first captured byte for the later update would not match the trace.

4. **Separate equal-address word reads.** If changing memory returns different values for the two represented reads at one address, the resulting arguments may differ. A single cached read is not justified.

5. **Byte truncation versus full argument.** If the first field value is 0x7f, its scaled value is 0x1fc. The byte write stores 0xfc; the following dependency receives 0x1fc.

6. **Upper-half placement.** If the upper half is 3, the first split-result write stores a 32-bit zero at address 32. Address validity remains a precondition.

7. **Different scaled addresses.** For a stage selector of 2, the initial write is at address 52 and the later scaled-value-based read is at address 28. They are not inherently the same location.

8. **Direct-write accounting.** If execution reaches every represented direct write, it performs nine byte writes and sixteen word writes, even if addresses overlap. Additional callee writes cannot be counted from this evidence.

9. **Partial progress.** If a later access fails after earlier mutations, no rollback or defined error return is established.
