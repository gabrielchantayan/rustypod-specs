## Behavior

The displacement is 16 bytes, not 16 pointer elements. No other descriptor field is visibly accessed.

The loaded target is then tested against null:

- A null target causes normal completion without dispatch.
- A non-null target is selected for invocation.

There is no visible retry, alternative lookup, fallback to the apparent target input, or search for a different target.
