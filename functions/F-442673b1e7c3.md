## Behavior

### Entry reads and first byte write

The first visible operation reads the signed 32-bit integer addressed by the fourth input. This read precedes the ambient byte read and every dependency call.

Next, the function reads one unsigned byte from the ambient base plus one. The byte is zero-extended to a 32-bit unsigned quantity.

That quantity is used as an address component, not as a pointer to another pointer. The function adds 17 and writes the low eight bits of the first input to the resulting address.

Consequently:

- The destination lies in the inclusive numeric range 17 through 272.
- The stored value is the first input reduced modulo 256.
- No visible validation, bounds check, permission check, or error branch precedes the write.
- The byte selecting the address has already been captured when the write occurs.

These are unusually low numeric addresses. The representation does not establish whether they are usable ordinary memory, special mappings, or artifacts of unreliable decoding.

### First dependency call

After the first byte write, F-UNRESOLVED-01 is called with four represented arguments, in this order:

1. The zero-extended byte captured from the ambient base plus one.
2. The same captured value.
3. The unchanged third explicit input.
4. The entry-read signed integer shifted left by ten positions.

The first two arguments are the selector byte itself, not the destination address after adding 17.

The fourth argument needs a width qualification. The represented operand is a signed 32-bit integer. A mechanical 32-bit bit-pattern interpretation would shift left ten positions and discard bits above bit 31. ### Second selector read and byte write

- Multiply the unsigned 32-bit input by two.
- Add one.
- Interpret the result as the address of a byte.

For the represented unsigned arithmetic, both operations are modulo \(2^{32}\). The resulting numeric address is always odd. In particular, the high bit of the first input is lost in the multiplication; inputs differing only in bit 31 produce the same selector-read address.

The function reads an unsigned byte at that address and adds 17 to obtain the second write destination. As with the first write, the resulting destination is between 17 and 272 inclusive.

The byte written there is the low eight bits of the first input after an unsigned right shift by 22. Equivalently, it is original input bits 22 through 29. Bits 30 and 31 do not contribute to the stored byte.

This selector read occurs after calls 1 through 7. Its result therefore depends on memory as it exists at that time. Neither the initial memory state nor preservation by those dependencies may be assumed.
