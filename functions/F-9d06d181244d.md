# F-9d06d181244d

## Purpose

F-9d06d181244d selects a fixed configuration from a 32-bit selector returned by F-cb9fa74c0a71, constructs a temporary stack-backed record, and passes that record and the original first argument to an external dependency.

The record is presented to the external dependency with a size argument of 32 bytes. Its fields are not fully initialized on every path. Even configurations with all named fields assigned leave four bytes without explicit initialization in the supplied evidence.

**Established behavior:** selection, field assignments, dependency argument order, reads of configuration globals, and the final external invocation.

**Inferred intent:** the record resembles a dimensional or image-layout configuration, containing two dimensions, a row-size-like quantity, and format-related fields. These interpretations are not established field semantics and are not requirements.

**Unknown:** the meaning of the two public inputs, the underlying global values, and the effects of either dependency beyond the caller-visible invocation structure.

## Behavior

### Evaluation sequence

On normal execution, the supplied evidence establishes this sequence:

1. Invoke F-cb9fa74c0a71 with B, B, and A.
2. Assign zero to Field E.
3. Assign zero to Field F.
4. Read the baseline-format global, designated **G-BASE**, and retain its low 16 bits.
5. Select assignments according to the full 32-bit selector.
6. Invoke the external dependency with A, the temporary record address, and `0x20`.
7. Return if that dependency returns.

The baseline global read occurs even when the selector later chooses a different global for Field H or selects no complete configuration.

The first dependency is invoked before the baseline global is read. Consequently, the baseline value used is the value available after that dependency returns. It must not be assumed to be the value that existed at function entry.

The selector comparisons are exact 32-bit comparisons. No masking, normalization, clamping, or selector arithmetic is shown.
