The following formulas describe addresses, not established data structures:

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Write accounting.** If execution reaches every represented explicit store, it performs 10 byte writes and 17 word writes. Dependency writes do not change these explicit-store counts.

2. **Byte truncation.** An extracted value of 63 produces a four-times byte value of 252. A value of 64 produces a stored byte of zero.

3. **Masked fragment.** An extracted value of `0x3ff00000`, masked to 30 bits and shifted right by 20, yields 1023; its byte publication stores 255. For `0x40000000`, the same publication stores zero.

4. **Selector re-read.** If an initial selector is 3, the destination is address 20. If an intervening dependency changes the selector source to 9, the later read selects address 26. Reusing the earlier selector would violate the represented access relationship.

5. **Different middle sources.** The first middle selector source uses eight times the paired value plus one. The second uses 64 times the middle extracted value plus one. They need not coincide.

6. **Conditional modular zero.** Under a uniform 32-bit modular interpretation, shifting the entry base left by 26 and multiplying by 1024 produces zero. The affected selector reads then use address one; they and the intervening calls still occur.

7. **Split publication.** For low result 5 and high result 7, the first post-split word store writes zero at address 48. The low-result-scaled store writes `0x14000000` at `0x50000014`, assuming the relevant accesses are valid.

8. **Independent reads.** If the two reads in the first scaled-link stage observe `0x1000` and `0x2000` respectively for the first and third arguments, those arguments are 1 and `0x8000`. A required shared snapshot would add an unsupported guarantee.

9. **Partial effects.** If a dependency does not return, later explicit writes are not required to occur. No represented mechanism guarantees undoing earlier completed writes.
