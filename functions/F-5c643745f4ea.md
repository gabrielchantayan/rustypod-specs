# F-5c643745f4ea

## Purpose

F-5c643745f4ea obtains a value through dependencies, treats it as an object address, stores it in two fields of a caller-supplied context, invokes an operation selected through that object, and returns a subsequent read of the first context field.

The established behavior includes two reads from **distinct global storage locations**:

- A preparation global is read to supply an argument to the initial external operation.
- An invocation global is read later to supply an argument to the indirect operation, after the preceding dependency calls and both context writes.

The invocation global is not established as immutable. Its later value cannot be replaced by a value cached at function entry: intervening dependencies or memory effects may change it.

**Inferred intent:** the function appears to acquire or create an object, associate it with a context, and perform an initialization or configuration operation. The object’s domain and the meanings of the context fields and global values are not established.

This is a static behavioral contract. No runtime tests have been performed.

## Interface

|---|---|---|

No context null check, bounds check, or explicit alignment check is visible. Successful execution requires the two fields to be writable and the first field to remain readable when the final read occurs. Dependencies may impose additional requirements, including access to other context fields.

### Output

On normal completion, the function returns the 32-bit value read from context offset 0x28 **after the indirect operation returns**.

The return value is not necessarily the originally obtained object address:

- If offset 0x28 remains unchanged, the function returns that address.
- If the indirect operation or another applicable memory effect replaces the field, the function returns the replacement.
- A replacement value of zero is returned normally; the function does not repeat its earlier zero check.

The representation establishes a four-byte result but does not establish a more specific semantic type or ownership rule.
