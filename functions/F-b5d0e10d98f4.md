# F-b5d0e10d98f4

- A zero classification supplies integer **0** to F-5812b0720631 and requires a subsequent call to F-d53862ada031.
- A nonzero classification supplies integer **1** to F-5812b0720631 and requires no direct call to F-d53862ada031.

These are established interactions, not established application semantics. The evidence does not identify the selected integers as enablement states, or the conditional operation as cleanup, release, or destruction.

This example does not assume that the change transfers ownership or that the additional dependency releases B.

Even if a dependency changes the field, this body must perform neither the conditional field read nor the direct call to F-d53862ada031. Normal completion still returns 1. A representable negative classification result has the same branch behavior.
