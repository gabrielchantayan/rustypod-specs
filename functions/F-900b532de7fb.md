# F-900b532de7fb

The dependency receives an invocation-local copy of an opaque four-byte payload together with the signed difference between a comparison value and that baseline.

The output is the captured baseline plus the dependency result. It is not necessarily the comparison value, the difference, or the dependency result alone. Equality between baseline and comparison does not bypass the dependency. Negative dependency results receive no distinct treatment.
