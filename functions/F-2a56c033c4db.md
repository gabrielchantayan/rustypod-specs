## Purpose

F-2a56c033c4db produces an ordered sequence of indirect calls and memory mutations. No application-level purpose is established. In particular, the evidence does not establish object initialization, allocation bookkeeping, serialization, supervision, or shutdown.

Its observable behavior is the call-and-access trace, including intermediate writes subsequently overwritten. There is no explicit returned result.

This contract distinguishes:

- **Established:** explicit accesses, call boundaries, arguments, widths, and retained data dependencies in the supplied static representation.
- **Inferred intent:** interpretations not required for acceptance.
- **documented_only:** behavior that the supplied evidence cannot resolve.

Every later event is conditional on preceding accesses succeeding and preceding dependencies returning normally.

## Side effects

All direct stores have the widths stated above. Computed destinations can overlap each other or shared storage. Calls can modify memory between any two direct accesses.

No allocation, release, ownership transfer, reference counting, synchronization, atomicity, transaction boundary, or rollback is established. Unknown dependencies may perform such operations; their absence cannot be assumed.

The frame-local address is available during its call. Its extent, initialization, contents, permitted retention, and ownership are **documented_only**. Passing it does not establish that the dependency owns it or may retain it after return.

No explicit bounds, null, alignment, or call-target validation is represented. Failure can leave every earlier write visible. No error-status translation is established.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Initial ordering:** With \(X=1\) and a valid initial access, word value one is written at \(0x18\) before F-D001.
2. **Truncation:** If \(E_1=0x41\), its first selected byte store contains \(0x04\), not \(0x104\).
3. **Selector interpretation:** A selector byte of \(0xff\) selects destination \(0x110\), independently of the selector’s source address.
4. **Low-bit shift:** Under 32-bit bit-vector interpretation, \(Z=2\) gives zero for \(Z\ll31\); \(Z=3\) gives \(0x80000000\).
5. **Observable overwrite:** Both offset-0x0d writes must occur, with the intervening word read and calls preserved.
6. **Independent late selectors:** If the selector used for the \(c\)-derived write yields two and the later independently read selector yields seven, their stores target \(0x13\) and \(0x18\), respectively.
7. **Unhalved late read:** If \(l_2=0x100\), the selected word-store destination is \(0x214\), while the subsequent distinct word read is at \(0x114\). If that read returns \(0x00c00000\), its later publication payload is three.
8. **Loaded-word consumer:** If the late masked-secondary address reads \(0x01400000\), the later selected byte payload is five, regardless of the numeric selector-source address.
9. **Global mutation:** A dependency changing \(G_0\) after its reset changes the later reload; zero cannot be substituted.
10. **Fresh field sampling:** Changing \(W(K+0x74)\) between its two reads may change the second byte stored at \(K+1\).
11. **Partial failure:** If F-D001 never returns, the initial word store has already occurred; no subsequent direct event is required.
12. **Terminal failure:** An uncallable address zero does not undo earlier writes or require a success result.
