## Behavior

### Empty sequence

The current source position is compared with the sentinel before any helper invocation or direct memory access.

If the source start equals the sentinel:

- No helper is called.
- No direct source read or destination write occurs.
- No position is advanced.
- The destination start is returned unchanged.

This path does not require the function itself to dereference either address-like input. Requirements imposed by a surrounding calling convention remain outside this contract.

### Processing order

For each iteration entered with current source position S and destination position D, the established order is:

1. F-4fcc06b56813 is invoked with D as its first argument and S as its second argument.
2. After that invocation returns, F-4fcc06b56813 is invoked with D + 4 as its first argument and S + 4 as its second argument.
3. After the second invocation returns, a four-byte quantity is read at S + 8 and written at D + 8.
4. The current destination position advances by 12.
5. The current source position advances by 12.
6. The source position is compared with the sentinel before another iteration begins.

These are abstract operation-order guarantees from the supplied representation, not guarantees about individual machine instructions, bus transactions, or atomicity.

The direct source read occurs after both helper calls. Therefore, the transferred quantity is the value present at S + 8 at that time. It is not necessarily the value that occupied that location when the function was entered or when the iteration began.
