Because each input byte is at most 255, the component sum is between 0 and 1020 inclusive. Consequently:

- The sum cannot overflow 32-bit unsigned arithmetic.
- Every possible sum already fits within ten bits.
- Masking with 1023 preserves the sum for every valid input.

\[
