## Acceptance examples

These are conditional static-contract examples, not executed tests.

1. **Input boundary.** Third inputs 0x000003FF and 0x00000400 produce extracted fields zero and one. The duplicated later arguments are zero and 0x800.

2. **Signed scaling.** Fourth input one supplies 128 twice to the fourth call. Input 0x01000000 cannot be scaled by 128 within signed 32 bits; 0x80000000 is only a conditional wrapping result.

3. **Unknown global source.** If an independently supplied declaration establishes an unsigned-byte source at 0x05, the global-derived base ranges from zero through 255. Without that declaration, rejecting a converted value of 0x1234 solely because it exceeds 255 is unsupported.

4. **Unknown global destination.** Assigning an 8-bit-converted value at 0x01 does not establish preservation of storage at 0x02. Such preservation requires the destination declaration and memory model.

5. **Correct offset-0x34 destination.** With selector 4, small base 8, and captured word 0x100, the relevant 32-bit store targets 0x3C and supplies 0x400 under compatible arithmetic. It does not target 0x434. Earlier, 0x3C received selector 4.

6. **Zero readback.** With ordinary sequential memory and supported arithmetic and accesses, packed base plus 0x14 reads zero. The intervening overlapping zero clear cannot introduce nonzero bits.

7. **Fixed sampling.** The publication-base global is sampled after the final derived-base-plus-0x20 write and before the 0x60 assignment. A later change to that global alone does not redirect the retained base. Its read width remains unresolved.

8. **Distinct observations.** If intervening writes change the value obtained from 0x67, the two later explicitly 8-bit stores at derived base plus 0x09 can differ. Neither source access is thereby proved byte-wide.

9. **Intermediate effects.** An access-sensitive observer retains all four derived-base-plus-0x20 writes, not merely their final value.

10. **Partial completion.** A fault does not require rollback or a returned error code.
