## Behavior

### 1. Repeated initial writes

The initial phase repeatedly writes four destinations. Their order within a complete group is:

| Position | Destination | Width | Value |
|---|---|---:|---|
| First | Base A + 0x11 | Byte | Low byte of base B |
| Second | Base B + 0x34 | Word | Secondary input in the first group; twice base A thereafter |
| Third | Twice base A + 0x54 | Word | Primary input |
| Fourth | Base B + 0x19 | Byte | Low byte of base A |

There are thirteen complete groups. A final partial group performs only the first and second writes, using twice base A for the second write.

Thus, before the next phase:

- Base A + 0x11 has received fourteen byte writes.
- Base B + 0x34 has received fourteen word writes.
- Twice base A + 0x54 has received thirteen word writes.
- Base B + 0x19 has received thirteen byte writes.

The secondary input is used only by the first word write to base B + 0x34. The later writes to that destination do not read it back.

Twice base A is unsigned 32-bit arithmetic. Its value wraps modulo \(2^{32}\), as does the subsequent unsigned addition of 0x54 in that destination expression.

These writes must not be reduced to a single final-state assignment when access ordering or write multiplicity is observable. Likewise, their apparent final values are conditional on the destinations not overlapping one another.

### 2. Initial snapshots and byte-valued state

1. A word from fixed address 0xA9.
2. A word from the primary input plus 0x74.

It then assigns fixed-address state at 0x3A a value formed from twice the character-sized interpretation of base A’s low byte, plus 0x30.

The expression resembles character-value construction, but no textual or numeric-formatting purpose is established. If the destination is byte-sized, its resulting bit pattern is:

### 3. Value propagation and overlapping updates

The function now reads a signed word from base C + 0x44. Call this the **first loaded value**.

The next observable actions are:

1. Assign the current state at 0x67 to fixed-address state at 0x21.
2. Write the low byte of the first loaded value to base A + 0x10.
3. Write the first loaded value as a word to base B + 0x54.
4. Write a byte to base C + 0x01, derived from a signed right shift of the first loaded value. The shift count is the low eight bits of base A.
5. Overwrite base B + 0x54 with base A as a word.

The shift is not fully specified for all inputs by the supplied representation. In particular, counts of 32 or greater and right shifts of negative signed values require execution-environment semantics. No masking to five bits or zero-fill rule should be invented.

Next, the function reads a word from base A + 0x40, then performs these updates:

- Base B + 0x74 receives the previously captured word from base A + 0x04.
- Base A + 0x10 receives the newly read word from base A + 0x40.
- Base B + 0x44 receives base C as a word.
- Base A + 0x09 receives a byte obtained from the current state at 0x67.
- Base C + 0x09 receives the low byte of base A.
- Base A + 0x44 receives the earlier word captured from fixed address 0xA9.

### 4. First memory-derived destination

It then:

- Writes the low byte of the earlier primary-input-plus-0x74 snapshot to destination D + 0x0D.
- Writes the earlier base-C-plus-0x14 snapshot to base C + 0x54 as a word.

The last write reuses the earlier snapshot. It is not a fresh read from base C + 0x14, and it need not restore the value present at base C + 0x54 on entry.

Next, the function reads a word from base A + 0x14. It then writes:

## Side effects

- Multiple writes target the same address.
- A word write overlaps earlier byte writes.
- Any entry base or memory-derived address may alias another destination.
