The established operation is a subtraction followed by a shift. It is not generally interchangeable with division by four: the distinction matters for negative differences, and subtraction can encounter signed overflow before the shift occurs.

An inferred use is conversion of a distance into a count of four-unit elements. That interpretation is not established by the supplied evidence. The function does not establish that the inputs are addresses, byte offsets, ordered endpoints, or multiples of four.

## Behavior

Only the first two integer elements are used. Later elements, if present, do not contribute to the result.

The first element is the value to subtract. The second element is the value from which it is subtracted. Reversing the two inputs therefore changes the sign of the mathematical difference, subject to the arithmetic limitations below.

There is no established requirement that the second value be greater than or equal to the first. Negative differences reach the signed right-shift operation when subtraction is representable.

### Arithmetic

The function first forms the signed difference:

**second value minus first value.**

It then right-shifts that difference by exactly two bit positions and returns the shifted value.

The subtraction is not widened by an explicit conversion. The shift and the return do not repair an overflow that already occurred during subtraction.

For a representable, nonnegative difference, the returned value is the mathematical difference divided by four with any fractional part discarded. Consequently:

- Differences zero through three return zero.
- Differences four through seven return one.
- Differences eight through eleven return two.
- No divisibility check is performed.
- A positive remainder is discarded rather than reported.

For a representable negative difference, the supplied signed right shift does not establish a target-independent numerical result. Under an arithmetic signed right shift, the result corresponds to division by four rounded toward negative infinity. That behavior must remain conditional unless the target’s signed-shift rules are independently established.

The function must not be described as truncating signed division toward zero. For example, a difference of negative one can produce negative one under arithmetic right shift, whereas division by four with truncation toward zero would produce zero.
