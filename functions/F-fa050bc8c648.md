Its explicit input is forwarded to the first dependency. Later operations depend on dependency results, an incoming word not represented as an explicit parameter, and incoming control state.

After F-47 returns, the routine performs a new unsigned byte read from:

\[
1 + 2^{28} \times \text{Selector E}.

This read must not be replaced with the first captured byte. F-41 through F-47 may have changed the source location; the first byte store may also have aliased it.

The newly captured byte, plus 17, selects the destination of the second byte store. Its stored value is obtained from the Packed word by clearing its top two bits, logically shifting right by 20, and truncating to eight bits. Consequently, the stored byte is exactly the Packed word’s bits 20–27.

Bits 28 and 29 survive the intermediate mask and shift but are discarded by byte truncation. Bits 30 and 31 are removed by the mask.

## Acceptance examples

These are conditional deductions, **not executed tests**. They assume valid targets, returning dependencies, accessible memory, and 32-bit wrapping arithmetic where relevant.

### Distinct word addresses

If Selector D is 3, the routine writes the word 12 at address 68 and then reads a word at address 32. The read cannot be replaced with the value 12 merely because it follows that store.

If the read yields `0xABCDEF01`, the later Selector E-associated store writes `0x000ABCDE`. Subsequent changes to the original read location do not change that saved result.

### Coincident word addresses

If Selector D is zero, the store and read both use address 20. With ordinary memory, no fault, and no external interference, the store of zero precedes the read, so the captured word is zero.

This conclusion does not establish device-memory behavior.

### Selector-derived arguments

If Selector E is 17 and Selector F is 3:

- F-31 receives 65,536, 12, and `0x40000000`, in that order.
- The byte-source address is `0x10000001`.

These results follow from arithmetic and bit selection, not an inferred field format.

### Byte values and intervening effects

If the Packed word is `0xCAFEBABE`, the first byte store writes `0xF8`, and the second writes `0xAF`.

If the first byte read yields 9, its destination is address 26. Suppose F-46 subsequently changes the byte-source location to 200, and F-47 returns without changing it. The second read must occur after both calls and yields 200 under ordinary memory assumptions. The second destination is then address 217.

F-48 receives shifted Selector I. After F-49 through F-52, **F-53 receives 200 as its second argument**, even if those calls have since changed the byte-source location. F-54 follows F-53.
