# F-e18131ab2fc4

## Purpose

The static evidence does not establish an application-level purpose. In particular, it does not justify describing the function as constructing objects, initializing hardware, serializing data, allocating storage, or releasing memory.

## Behavior

### Widths and notation

The following names describe observations, not implementation variables:

- **W(x)**: the low 32 bits of a value.
- **L(x, n)**: a left shift by *n*, retaining the low 32 bits.
- **B(x)**: the low 8 bits.
- **X(x)**: bits 20 through 29, interpreted as an unsigned value; equivalently, mask with `0x3fffffff` and shift right by 20.

Letters identify distinct dependency results within an iteration. A two-word result is divided into a low 32-bit word and a high 32-bit word. This division does not specify an in-memory byte order or a complete result-return convention.

### Layout, bounds, and aliasing

Two address forms are materially different:

1. A scaled 32-bit value plus a fixed offset.
2. A computed-address unsigned byte read whose numeric result becomes a new address base.

The second form does not read a full pointer. Its selector is between 0 and 255:

- Selector-based byte destinations range from address 17 through address 272.
- The selector-based word destination at order 14 starts between address 20 and address 275.
- A four-byte access beginning at 275 extends through 278.
- The computed word read after order 10 starts between address 20 and address 1043, because **X(F)** is between 0 and 1023.

No alignment adjustment, bounds check, or accessible-memory check is displayed.

Under the stated 32-bit interpretation, **P** can only be `0x00000000`, `0x40000000`, `0x80000000`, or `0xc0000000`. Only the low two bits of **D** contribute. The selector-address base at order 20 has the same four possible patterns, determined by the low two bits of **O**.

Distinct accesses may alias or overlap. A word store may change a later selector byte. A selector-based store may affect a later read. Dependencies may also change any accessible storage between explicit operations. Consequently, earlier zero stores do not establish that later selector reads return zero.

## Acceptance examples

These are conditional static criteria, not execution results. Each assumes that execution reaches the relevant operation and that the environment permits the accesses.

1. **Incoming carried word.** If **A = 3** and the incoming carried word is `0x12345678`, order 1 writes that word at address 32.

2. **Retained scaled value.** If **B = 5**, order 2 writes 20 at address 100. If **C = 7**, order 3 later writes the same value at address 48.

3. **Byte truncation.** If **J = 65** and order 12 reads selector 9, it writes byte value 4 at address 26. The shifted word is 260; only its low eight bits are stored.

4. **Saved selector.** If order 13 reads selector 7, order 14 writes its word at address 27 even if an intervening dependency changes the selector storage to 8.

5. **Fresh selector.** If order 21 reads selector 5 and order 22 reads selector 6, their zero-byte destinations are addresses 22 and 23 respectively. The second read is not replaced by the first result.

6. **Captured global.** If order 14 captures global word `0x00400000`, order 15’s byte value is 1. A later global change does not replace the captured **U**.

7. **Field truncation.** If **J = 0x3ff00000**, then **X(J) = 1023**, but order 13 writes byte value 255.

8. **Iteration carry.** If **AA = 1** and **AB = 3**, the next four arguments are 4096, 4096, 16384, and 12. The next carried word is also 12. This transition does not return normally.

9. **Access accounting.** If one complete iteration is traversed, the explicit body contributes thirteen word stores, fourteen byte stores, ten selector reads, and two other word reads, regardless of address aliasing.

10. **Paired results.** The high words accompanying **K** and **O** are forwarded separately. Only the two later two-word results have displayed invocations receiving both halves together.

11. **Invalid access conditions.** An inaccessible low address or unaligned word destination does not select a visible validation branch. Successful continuation is not promised.
