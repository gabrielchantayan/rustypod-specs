## Acceptance examples

These are conditional static criteria, not executed tests.

### Distinct expressions with coincident bytes

Assume 32-bit wrapping arithmetic and successful execution through the first two stores at shifted base plus 9.

If the latest high word has a zero low byte, both stores supply byte zero: the first by narrowing that high word, the second by narrowing the retained value shifted left by 25.

An implementation must not force different bytes merely because the expressions differ. It must also not remove either represented store on the basis of equal payloads.

If the latest high word instead has low byte 0x7A, the first store supplies 0x7A and the second supplies zero under the same arithmetic assumption. The intervening word store remains ordered between them.

### Unsigned-byte propagation

If the initial byte sampled at large base plus 5 is 0xFE, the subsequent word store at large base plus 0x34 supplies 254.

Supplying a sign-extended −2 would violate the unsigned-byte conversion.

### Small-base boundary

Under 32-bit bit-vector arithmetic, an input whose low seven bits are 127 produces selector 508 and doubled base 1016. Higher input bits do not change this result.

An input whose low seven bits are zero produces doubled base zero; no represented validation rejects it.

### Saved old contents

Assume successful preceding accesses and nonaliasing ordinary memory. If the word captured from the fixed-byte-selected base’s offset 0x54 is different from its replacement, subsequent uses of the captured word must retain the old value.

Reloading the overwritten location is not equivalent.

### Repeated-access observation

An environment recording represented writes must distinguish two consecutive stores to doubled base plus 0x15, even if their payloads match.

Likewise, retaining only the final 0x20 store from the four-store offset-0x20 sequence loses the required intermediate payloads and sampling read.

### Overlapping byte and word stores

If the relevant computed offset 0x10 is ordinary writable memory, the later word store replaces the byte previously written there as part of its wider footprint. Exact constituent bytes depend on byte order.

If writes trigger external behavior, both accesses may matter independently of final contents.

### Final transfer

Normal return is conditional on the target returning normally; it is not an unconditional success outcome.
