# F-b6b18c9159c8

## Purpose

F-b6b18c9159c8 selects an unsigned result through one of two paths:

- For a selector equal to 512, return a value read from a global 32-bit source.
- For every other selector, call F-7cb60db72009. Return zero if that dependency returns a null pointer; otherwise, return a zero-extended 16-bit field reached through the returned pointer.

The global read occurs before the selector-dependent behavior, including on calls that do not return the global value.

This contract describes statically established behavior. The application-level meaning of the selector, global value, and referenced field is unknown.

## Interface

The function accepts three arguments, in this order:

|---|---|---|
| First argument | 32-bit opaque value | Not used by the represented function body |
| Second argument | 32-bit opaque value | Not used by the represented function body |
| Selector | 32-bit signed integer | Compared for equality with 512 |

The first two arguments are neither dereferenced nor explicitly forwarded to F-7cb60db72009. No validity requirement for them follows from this body. This does not establish that arguments can be omitted under the calling convention.

For the selector, only equality with 512 matters. Every other represented value—including zero and negative values—takes the dependency path. There is no established range check or selector-specific rejection.

### Output

The function returns a 32-bit unsigned value on normal completion:

- The global-source path can return any 32-bit unsigned value.
- The dependency path returns either zero or an unsigned value between 0 and 65,535, inclusive.

A zero result is ambiguous. It may represent a zero global value, a null dependency result, or a successfully read zero field. There is no separate status output in the supplied body.

### Referenced memory

The body accesses these logical locations:

1. **Global source:** a location read as a 32-bit value.
2. **Returned reference:** if non-null, a pointer returned by F-7cb60db72009, from which a 32-bit word is read.
3. **Indirect field:** a 16-bit unsigned field at byte offset 60 from the address represented by that word.

The returned reference is not itself the base address for the field. It identifies storage containing the base address. The two levels of access must remain distinct.

## Behavior

### Common entry behavior

The function first reads the global source into a 32-bit result candidate. This read precedes the branch-specific operations in the supplied body.

The read is not conditional on the selector being 512. Consequently, even a call that later returns zero or an indirect field value includes this initial read in the represented access sequence.

For normal completion, the global source must be readable. An invalid global location is not handled by an alternate path in this body.

### Selector equal to 512

When the selector equals 512:

- The function returns the initially read global value.
- F-7cb60db72009 is not called.
- Neither the returned-reference storage nor the indirect field is accessed.

The function does not narrow the global value to 16 bits. Values above 65,535 remain possible on this path.

The result is the value obtained by the initial read, rather than a later read of the same location. No second global read appears.

### Selector unequal to 512

For any selector other than 512, the function calls F-7cb60db72009 once, after the initial global read. The dependency has no explicit arguments at this call site.

If the dependency returns normally, the function uses zero as the fallback result and checks whether the returned pointer is null.

If the returned pointer is null:

- The function returns zero.
- It does not read a word through that pointer.
- It does not attempt the indirect field read.
- It does not return the previously captured global value.

If the returned pointer is non-null:

- The function reads a 32-bit word through that pointer.
- It interprets that word as the base address for a subsequent memory access.
- It reads an unsigned 16-bit value at byte offset 60 from that base address.
- It zero-extends that value to the 32-bit unsigned return width.

The only explicit pointer check is on the pointer returned by the dependency. The body does not separately check the base address read from that pointer.

A non-null returned pointer therefore does not establish that either memory access is valid. Both the pointer-containing storage and the resulting field address must be readable for normal completion.

### Widths and address calculation

The field occupies two bytes. Its offset is 60 bytes, not 60 elements or 60 words. There is no established scaling by the size of the intermediate 32-bit word.

The field is unsigned. In particular:

- A field value of 32,768 returns 32,768, not a negative result or a sign-extended bit pattern.
- A field value of 65,535 returns 65,535, not 4,294,967,295.

The intermediate address-bearing word is represented as 32 bits. This does not establish support for addresses requiring additional bits.

The body does not provide checked address arithmetic. Portable behavior for a base address near the address-space boundary is not established. Such cases must not be assigned an assumed wraparound, trapping, or saturation rule.

### Errors and abnormal completion

No explicit error handler, retry, alternate lookup, or cleanup path appears.

In particular, the function does not convert an invalid memory access into a zero result. Zero is the established fallback for a null dependency result, not for every failure encountered on the dependency path.

Behavior when F-7cb60db72009 fails to return normally is unknown. Any platform-level response to inaccessible or improperly aligned memory is also outside the established contract.
