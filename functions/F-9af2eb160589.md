## Behavior

The logical gates are evaluated in this order:

1. The first record’s classification must match classification A or classification B.
2. The second record’s classification must match classification A or classification B.
3. The second record’s leading word must equal the first record’s leading word.

The alternatives within each classification check are short-circuited: classification B is considered only when the comparison against classification A fails.

The gates also short-circuit:

- A rejected first classification prevents evaluation of the second classification and the leading-word comparison.
- A rejected second classification prevents the leading-word comparison.
- Failure of any eligibility gate prevents the count checks and traversal.
