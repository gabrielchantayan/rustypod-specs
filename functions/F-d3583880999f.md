# F-d3583880999f

## Purpose

F-d3583880999f processes a zero-terminated byte sequence into caller-supplied destination storage. For each nonzero source byte admitted by an output-position check, it searches three table entries in order. An unmatched byte is copied directly. A match causes a call to F-e7c5183babcf, followed by a scan of destination memory for a zero byte.

The supplied body does **not** establish that F-e7c5183babcf writes a replacement, writes anything at all, or provides termination. Replacement-writing behavior is an inferred use, valid only when that dependency satisfies additional conditions.

On normal return, F-d3583880999f writes a final zero byte and returns the original destination pointer. It provides no count or completion indicator.

This is not an established capacity-bounded copying interface. The limit controls admission of another source byte; it does not directly bound dependency writes or the destination scan.

## Behavior

### Initialization and retained state

Initialization precedes the first source-byte inspection.

The matching-table pointer is captured first. Separately, the global slot is evaluated to access a first table entry, and that entry’s 32-bit value is passed to F-1cb585febd84. The returned signed integer is retained for the remainder of processing.

This contract calls that result the **reserve value**, describing its arithmetic role only. Its meaning, range, and relationship to any replacement length are unknown.

F-1cb585febd84 can have effects before the function inspects the source. Consequently, an input byte that was zero before the call is not necessarily zero when inspected. The same qualification applies to table contents, destination contents, and storage validity.

The captured matching-table pointer is not refreshed after initialization. A subsequent change to the global slot does not by itself retarget matching. Conversely, the captured pointer does not freeze the contents or lifetime of the storage it identifies.

### Admission and stopping

For purposes of the output-position comparison, the threshold is the original destination pointer offset by:

**limit minus reserve value**

The difference is signed 32-bit arithmetic in the supplied representation. The body does not clamp a negative result or establish that the subtraction is representable. Forming and comparing the resulting pointer also requires a valid target-specific interpretation.

At each processing position, the source byte is read before deciding whether output processing is allowed.

If that byte is zero, the threshold expression is bypassed. The function writes zero at the current output position and returns the original destination pointer.

Otherwise, the function compares the current output position with the threshold. If the threshold is at or before that position, it writes zero there and returns without processing the already-read nonzero source byte.

Thus:

- Exhausted output allowance does not eliminate the source read.
- An empty source does not eliminate initialization.
- A normal stop still requires one writable destination byte.
- Threshold termination does not consume or transform the stopping byte.
- A zero source byte does not require evaluation of potentially problematic threshold arithmetic on that iteration.

The threshold is a pre-processing admission condition, not an enforced upper bound on all effects of an admitted operation.

### Table selection

An admitted nonzero source byte is compared against the leading bytes addressed by matching-table entries zero, one, and two, in ascending order.

The first equality selects the entry. Later entries are not consulted for that source byte. If all three comparisons fail, the byte takes the direct-copy path.

The source byte used for these comparisons is the value already read for the current iteration. A later mutation of its original storage does not change that retained byte value.

Source zero is recognized before matching, so a zero table key cannot transform the source terminator.

Table entries are accessed during processing, not captured as a private three-entry snapshot. The selected entry is also evaluated for the dependency argument. The body does not establish that this value must equal the value previously used to obtain the matching leading byte if an allowed intervening change occurs. This observation does not establish supported concurrent mutation or a particular number of physical reads.

### Direct-copy path

When all three keys differ, the source position advances by one byte. The previously inspected byte is written to the current destination position, and the output position advances by one byte.

The next iteration inspects the next source byte before performing its admission comparison.

There is no F-e7c5183babcf call on this path. With overlapping storage, the direct write can affect future source reads or table accesses.

### Matched-byte path

A selected entry causes a call to F-e7c5183babcf with:

- The current output address.
- The selected 32-bit entry value increased by one.

The dependency’s return value is ignored.

After the call returns, the function reads destination bytes starting at the supplied output address. It advances the output position over nonzero bytes until a zero byte is encountered. The output position remains at that zero byte.

Only after this scan finishes does the source position advance by one byte.

This behavior depends on destination contents after the call, not on a returned length. The scanned bytes may have been written by the dependency or may already have existed. If a zero is present immediately at the starting position, output does not advance.

The next direct write or dependency call starts at the zero found by this scan. Under a replacement-writing dependency contract, this permits successive output segments to join by overwriting intermediate terminators. Such concatenation is conditional, not proof of that dependency’s semantics.

There is no additional capacity argument, in-call threshold enforcement, bounded scan, or rollback in the visible body. A scan may pass the threshold before any further admission comparison. If no readable zero is reachable, the body supplies no bounded or recoverable outcome.
