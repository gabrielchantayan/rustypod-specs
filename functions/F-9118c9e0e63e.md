# F-9118c9e0e63e

## Purpose

F-9118c9e0e63e sets the mask `0x10000000` in twelve addressed unsigned words. The accesses form six ordered pairs: one word selected using a lower address base, followed by one word selected using an upper address base.

Each update reads the selected word, combines that value with the mask using bitwise OR, and writes the result to the same address. Under a 32-bit word interpretation, this sets bit 28, counting the least significant bit as bit 0. All other bits of the value read are preserved in the value written.

The apparent intent is to mark six entries in each of two regularly spaced regions. That interpretation is inferred, not established: the supplied material does not identify the words as records, flags, device registers, or any particular application state.

## Behavior

### Base acquisition

Before updating any target word, the function evaluates the global address datum twice:

1. It captures U.
2. It captures S and derives L by subtracting `0x200`.

Subsequent iterations use the captured values; they do not reevaluate the global datum.

Consequently, a change to the global datum between its two evaluations can cause the two groups of accesses to use different source bases. A change after both evaluations does not, by itself, redirect the remaining accesses.

These are the evaluations and sequencing visible in the supplied representation. The precise machine-level treatment of a nonvolatile global load is not established.

### Individual word updates

For each selected address, the function:

- Reads an unsigned word.
- Forms the bitwise OR of that value and `0x10000000`.
- Writes the resulting unsigned word to the same address.

The write is not conditionally skipped when the mask is already present. The supplied behavior still includes a read and a write.

On ordinary memory, the written value differs from the read value only if the mask bit was previously clear. The written mask bit is always set. Other bits retain their values from that particular read.

The sequence completes each lower-word update before beginning the corresponding upper-word update. It completes that upper-word update before advancing to the next position. There is no preliminary pass that reads all twelve words before writing them.
