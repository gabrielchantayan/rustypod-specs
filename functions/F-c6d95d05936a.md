# F-c6d95d05936a

## Purpose

F-c6d95d05936a transforms four consecutive signed integer elements in caller-provided storage. Its result has two leading zeros followed by two differences: the original third element less the original first, and the original fourth element less the original second.

The established contract is an in-place arithmetic transformation. Interpreting the elements as coordinates, bounds, dimensions, or displacements is inferred intent, not established behavior. There is no returned value, status result, allocation, or dependency call.

All four initial values are inputs to the transformation. In particular, the leading elements are not merely output fields: their existing values affect the trailing results before being cleared.
