# F-f13024dd99c5

## Purpose

F-f13024dd99c5 coordinates an ordered sequence of dependency calls and conditionally copies a 16-bit field from an input object into a field reached through a dependency result. Its return value is the 32-bit result of F-a3c410f12096, not the result of the later calls or conditional copy.

The established behavior comprises three parts:

- Obtain a value from F-fdd8589eca2d and pass it, the input object address, and a literal zero to F-3e5212464798.
- Invoke F-a3c410f12096 with both original inputs, retaining its result for return. Invoke F-5c5958cfd5fe afterward if the second input is nonzero.
- Under specific field-value conditions, obtain a destination address through F-fdd8589eca2d and write a freshly read 16-bit source value to that destination.

The apparent intent is to populate an empty destination field from an object field when an operation is enabled. That interpretation is inferred, not established: the meanings of the fields, the operation, and the objects returned by dependencies are unknown.

## Behavior

### Initial dependency sequence

On entry, F-fdd8589eca2d is called without explicit arguments.

Its result is passed as the first argument to F-3e5212464798. The second argument is the original object-address input, and the third argument is a 32-bit zero. No result from F-3e5212464798 is used by the visible function.

After that call returns, F-a3c410f12096 is called with the original object address followed by the original control value. Its 32-bit result is retained.

These calls occur regardless of whether the control value is zero. They also occur before the function directly reads the source field at offset `0xE6`.

### Conditional call

If the original control value is nonzero, F-5c5958cfd5fe is called without explicit arguments after F-a3c410f12096 returns.

If the control value is zero, that call is skipped.

No result from F-5c5958cfd5fe is used. Nevertheless, its side effects cannot be assumed absent: it executes before the subsequent source-field read and any destination lookup.

The retained result from F-a3c410f12096 is not used as a condition for this call.

### Source-field gate

After the preceding dependency calls have returned, the function reads the 16-bit field at the input object address plus `0xE6`.

This read occurs even when the control value is zero. A zero control value therefore does not make an invalid object address safe.

Further destination processing requires both:

- The value observed by this source-field read is nonzero.
- The original control value is nonzero.

If the source-field read yields zero, no destination-related call to F-fdd8589eca2d occurs. If it yields nonzero but the control value is zero, no such call occurs either.

The source-field value is observed after the earlier dependencies have run. The function does not capture an entry-time source value before those dependencies can affect memory.

### Destination-field gate

When both source-field conditions hold, F-fdd8589eca2d is called again without explicit arguments.

The function treats this call’s result as a base address and reads a 16-bit field at offset `0x80`.

- If the observed destination field is nonzero, the function performs no direct write and proceeds to return the retained result.
- If that field is zero, the function enters the write path.

The zero test applies to this particular dependency result. It does not establish that any later result designates the same address or contains a zero field.

### Conditional write

On the write path, F-fdd8589eca2d is called a third time overall.

The result of this latest call supplies the destination base. After that call returns, the function reads the input object’s 16-bit field at offset `0xE6` again and writes that value into the 16-bit field at the latest destination base plus `0x80`.

Consequences of this ordering:

- The copied value is a fresh source-field observation, not the value retained from the earlier nonzero test.
- The copied value may be zero if the source changes between the two reads.
- The write destination may differ from the object whose field was checked.
- The actual write destination is not rechecked for a zero value.
- The latest F-fdd8589eca2d call can affect state before the source is reread.

After the write, the function returns the retained 32-bit result from F-a3c410f12096. There is no additional visible dependency call.
