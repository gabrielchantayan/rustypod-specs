2. Add `0x11` to that byte value.

An indirect call then receives \(X \ll 2\). After intervening calls, a second byte write repeats the byte lookup at \((P \gg 8)+1\), then writes the low byte of:

\[

These examples are conditional static acceptance criteria, not runtime observations.
