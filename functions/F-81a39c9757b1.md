## Behavior

### Empty traversal

The function compares the initial position with the endpoint before making any dependency call.

If they are equal, it returns immediately. This applies regardless of the numeric value shared by the two inputs. No address validity check is performed by this function on the empty path.

### Processing one position

When the current position differs from the endpoint, the function performs these actions in order:

1. Invoke F-8a5aadac202f with the current position plus four.
2. After that invocation returns, invoke F-8a5aadac202f with the current position.
3. After the second invocation returns, advance the position by twelve.
4. Compare the updated position with the endpoint before processing another position.

The advance occurs only after both invocations have returned. There is no explicit error-handling branch between them. No dependency return value is inspected or used to decide whether processing should continue.
