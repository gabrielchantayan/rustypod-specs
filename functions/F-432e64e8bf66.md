# F-432e64e8bf66

## Purpose

The supplied static representation describes a routine that interleaves indirect calls with direct memory updates, two global-state accesses, and a final call to address zero.

The observable core is:

- Store scaled call results into several computed word locations.
- Copy two different eight-bit portions of a captured word into byte locations selected through other byte reads.
- Assign a late call result to a global location.
- Clear one byte and one halfword.
- Invoke address zero with three explicit zero arguments.

No application-level purpose is established. In particular, the representation does not establish that the routine allocates objects, decodes a format, initializes a valid data structure, or deliberately raises an exception.

This contract distinguishes direct static evidence from conditional interpretations. It does not certify that the represented control flow is executable.

## Acceptance examples

These are conditional acceptance criteria, not executed tests. They assume execution reaches the relevant operation, required accesses are valid, and intervening dependencies do not change the stated values.

1. **Initial alignment and scaling.** If the third argument is 4,099 and F-A001 returns 3, the initial word destination is 4,116: align 4,099 down to 4,096, then add 20. The stored word is 12, and F-A002 receives 12 twice.

2. **Inherited upper-bit extraction.** If the inherited unsigned word is 4,294,967,295 and F-A010 returns 2, the second word store writes 511 at address 28.

3. **Address snapshot versus mutable global.** If the address-like global is read as 4,096, and F-A016 later changes that global to 8,192, the represented payload read still uses address 4,116. Its contents are read at the later payload-read point, not at the global-read point.

4. **Distinct payload byte selections.** For payload snapshot `0x3FC000A5`, a first selector of 7 causes byte `0xA5` to be stored at address 24. A second selector of 9 causes byte `0xFF` to be stored at address 26. The second byte is bits 22–29, not simply the most significant byte.

5. **Derived selector and clear addresses.** For retained F-A025 low word `0x00600080`, the second selector is read at address 4. The final halfword clear is at address 49,153. Whether that odd-address halfword write succeeds is environment-dependent.

6. **Mask boundaries.** Retained F-A025 low words zero and `0xC0000000` both produce selector-read address 1 and final halfword address zero. Their top two bits do not affect those two addresses.

7. **Conditional wraparound interpretation.** Under a 32-bit bit-vector execution model, scaling word `0x40000001` by four produces 4. This example does not establish defined signed-overflow behavior for the supplied representation.

8. **Terminal ordering.** If F-A042 returns normally and both clear operations succeed, the global assignment precedes the byte clear, which precedes the halfword clear, which precedes F-A043. Normal return cannot be accepted merely because the earlier stores completed.
