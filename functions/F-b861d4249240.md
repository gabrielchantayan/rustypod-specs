# F-b861d4249240

## Purpose

F-b861d4249240 selects among two dependency-mediated update paths, an indexed byte-transfer path, and early return.

Selection first depends on whether a stored four-byte value equals one of two addresses within an object supplied by F-7fba0909c452:

- Equality with object base plus `0x04` selects two intermediate update requests followed by a shared final update.
- Otherwise, equality with object base plus `0x10` selects only the shared final update.
- If neither comparison succeeds, a four-byte mode determines whether to return or perform an indexed byte transfer.

The indexed transfer is selected only when that mode equals `0x1702`.

These descriptions identify observable roles, not application semantics. The supplied body does not establish what the object represents, what the update dependencies compute, or what the copied byte means.

## Behavior

### First identity path

1. F-0ff9271d6c39 receives object base plus `0x04`.
2. After that call returns, the byte at object offset `0x904` is read.
3. F-e571c15425a7 receives the workspace address, the preceding resolution result, and that byte, in that argument order.
4. F-cb38d8d650b2 receives object base plus `0x38` and the workspace address.
5. F-0ff9271d6c39 again receives object base plus `0x04`.

7. F-cb38d8d650b2 receives object base plus `0x7C` and the workspace address.
