# F-5e09117d9644

## Purpose

F-5e09117d9644 selects a 32-bit association value, requests construction of a separate object using the second input, and writes two words into the returned object.

Association selection depends on a 64-bit result, a conditional lookup, and a field in a candidate object. The selected association may be an existing candidate, a construction result, or zero. Some paths permit two association-construction attempts; others permit one or none.

After final-object construction returns, the function reads a 32-bit global source word. It stores the sampled value at final-object offset 0, then stores the association at offset 16. The global source word is not established to be constant, and dependencies may change it before it is read.

**Established behavior:** there is no explicit return value, no local error reporting, and no explicit release operation.

**Inferred intent:** the final object appears to carry an optional association. The global source word may identify or configure that object, but neither its semantic role nor its constancy is established.

## Behavior

If the 64-bit result is zero, the function skips lookup and association construction. It proceeds to final-object construction with association zero.

### Association selection

#### Equal cursors

If the lookup cursor equals the boundary cursor, the function performs one association-construction attempt.

It does not read the word preceding the cursor or inspect a candidate object. The attempt's return value becomes the association, including when it is zero. There is no retry on this path.

#### Different cursors

If the cursors differ, the function first reads a 32-bit candidate address from eight bytes before the lookup cursor. It then reads a 32-bit word at offset 32 from that candidate address.

The field read happens even when the candidate address is zero. The subsequent zero test is not a protective null check.

Selection then follows these rules:

| Candidate field at offset 32 | Candidate or construction result | Required action |
|---|---|---|
| Nonzero | Candidate address nonzero | Retain the candidate; perform no association construction |
| Nonzero | Candidate address zero | Perform one association-construction attempt; retain its result without retry |
| Zero | First construction result nonzero | Retain that result |
| Zero | First construction result zero | Perform a second association-construction attempt; retain the second result without another test |

Thus, a nonzero candidate field is not by itself sufficient to skip construction. The candidate address must also be nonzero.

When the candidate field is zero, the first construction attempt replaces the selected association before the additional association-zero test. A zero result triggers one further attempt. A nonzero result proceeds directly to final-object construction.

When the candidate field is nonzero but the candidate address is zero, there has been no earlier construction attempt. The association-zero test therefore leads to exactly one attempt, not two.
