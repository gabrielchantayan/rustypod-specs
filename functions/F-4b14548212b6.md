# F-4b14548212b6

## Purpose

F-4b14548212b6 selects three 32-bit payload words and a 32-bit control word, performs three consecutive word writes at a control-derived address, performs a separate 16-bit write, invokes an unresolved dependency, and reaches a breakpoint followed by an invalid-instruction termination marker in the supplied representation.

There are two selection modes:

- **Direct mode:** A nonzero third explicit argument selects the second and fourth explicit arguments together with an ambient payload word.
- **Traversal mode:** A zero third explicit argument selects values through an ambient linked-record cursor.

The established behavior is a sequence of address calculations, memory accesses, and a dependency invocation. The data’s application-level meaning is unknown. In particular, the evidence does not establish that the destinations are ordinary RAM, device registers, a command buffer, or any particular object type.

No normal return or return value is represented. The precise runtime effect of the terminal sequence is unresolved because the supplied representation reports instruction-decoding and control-flow problems.

## Behavior

### 1. Select the working values

In direct mode:

- The first payload word is the second explicit argument.
- The control word is the fourth explicit argument.
- The third payload word is the ambient payload word.
- The ambient cursor is not dereferenced by the visible body.

In traversal mode, each iteration operates on the current cursor as follows:

1. Identify the flags location at the current record’s offset `+8`.
2. Read the 32-bit successor address from the current record’s offset `+16` and advance the cursor to that address.
3. Read the flags word from the **previous** record’s offset `+8`.
4. Continue if bit 21 of that flags word is set; otherwise stop.

The successor read therefore precedes the flags read in the supplied representation. Computing the flags address before the successor read is not itself a memory read.

The traversal executes at least once. It advances the cursor even when the first record’s continuation bit is clear. The record used for payload selection is consequently the successor of the last record whose flags were examined, not that last examined record itself.

After traversal stops, the function reads these fields from the now-current record, in the represented order:

1. Offset `+4`: first payload word.
2. Offset `+12`: control word.
3. Offset `+16`: third payload word.

The stack-associated word supplies the second payload word in either mode.

There is no visible null check, cycle detection, iteration bound, successor validation, or error result. If continuation bits remain set indefinitely, execution does not reach the output writes unless some external effect changes the situation or interrupts execution.

### 2. Derive the three-word destination

Let the selected unsigned 32-bit control word be \(C\). The base destination address is:

\[
B = \left((C \mathbin{\mathrm{>>}} 4)\times 8192\right)\bmod 2^{32}.
\]

The multiplication must not be interpreted as an unbounded integer operation. It can overflow 32 bits.

Equivalently, the resulting base preserves control bits 4 through 22, positions them at address bits 13 through 31, and clears address bits 0 through 12. Control bits 0 through 3 and 23 through 31 do not contribute to this base.

No allocation or lookup is performed to obtain this destination.

### 3. Write the three payload words

The visible write sequence is:

| Order | Destination | Width | Value |
|---|---|---:|---|
| 1 | \(B\) | 32 bits | Selected first payload word |
| 2 | \(B+4\) | 32 bits | Stack-associated word |
| 3 | \(B+8\) | 32 bits | Selected third payload word |

The base is a multiple of 8192 in the represented address model. Its maximum value is `0xFFFFE000`, so the following two word addresses do not wrap past the 32-bit address-space boundary.

The representation does not establish a physical load time for the stack-associated word. An alias between its backing storage and a destination therefore requires information beyond the supplied evidence.
