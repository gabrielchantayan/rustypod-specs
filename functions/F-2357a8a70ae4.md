The addition and right shift occur before conversion to that unsigned word. Consequently, a negative shifted result can be represented as an unsigned word whose signed interpretation is negative.

For description, call the stored word the **scaling index word**, and call its signed 32-bit interpretation the **scaling index**.

The function then reduces the first input by adding the scaling index word multiplied by negative 65,536. Because the multiplication involves the unsigned word, the visible type structure implies unsigned 32-bit arithmetic for that product and the associated addition. The resulting word is subsequently used as the signed integer **residual**.

Where the initial addition is representable, the right shift of a negative signed value is arithmetic, and the word-to-signed conversion preserves its two’s-complement interpretation:

- The scaling index is the ceiling of the first input divided by 65,536.
- The residual equals the first input minus 65,536 times that index.
- The residual lies between −65,535 and zero, inclusive.

These relationships are conditional arithmetic interpretations, not evidence that all signed operations in the supplied representation have portable behavior.

For a signed 32-bit first input, adding 65,535 exceeds the signed range when the input is greater than 2,147,418,112. The supplied evidence does not establish the intended behavior for that upper interval.

### 7. Apply the scaling branch

| Scaling index | Visible final operation |
|---|---|
| Less than −31 | Replace the unscaled result with zero. |
| −31 through −1 | Right-shift the signed unscaled result by the negated index. |
| 0 through 16 | Left-shift the unscaled result by the index. |
| Greater than 16 | Leave the unscaled result unchanged. |

- An index of −31 performs a 31-bit right shift.
- An index of zero selects a zero-bit left shift.
- An index of 16 performs a 16-bit left shift.
- An index of 17 performs no shift.
