## Behavior

### Equal-pointer path

When they compare equal:

1. F-176c75806347 is not called.
2. The source’s pointed-to value is not read.
3. F-56a266ab3332 is not called.
4. The destination pointer is returned.

This path depends on pointer equality, not on equality of stored contents. No content comparison occurs.

Within the visible function body, this path does not change pointed-to storage or globals. It also does not validate the shared address or inspect any object there.

### Unequal-pointer path

When the pointers compare unequal, the established sequence is:

1. Call F-176c75806347 with the destination pointer.
2. Wait for that call to return normally.
3. Read the 32-bit unit addressed by the source pointer.
4. Call F-56a266ab3332 with the destination pointer and that loaded 32-bit value.
