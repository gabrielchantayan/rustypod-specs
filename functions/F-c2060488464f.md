# F-c2060488464f

## Purpose

F-c2060488464f performs a straight-line sequence of indirect calls, byte-selected writes, indexed word transfers, shared-storage updates, and a terminal call to address zero.

**Established static evidence:** The supplied representation declares no parameters and no returned value. It consumes implicit entry state, primary and secondary call outputs, paired outputs, and memory contents. Access order and call placement are observable parts of its behavior.

### Widths, addressing, and notation

Byte, halfword, and word accesses are respectively 8, 16, and 32 bits. Paired call results contain 64 bits, divided into low and high 32-bit halves.

The following descriptive notation is used:

- **Slot(index):** address \(4 \times index + 0x14\), containing a word.
- **Selected write(selector-address, value):** first read an unsigned byte at selector-address; then store the low eight bits of value at that byte’s value plus `0x11`.
- **Primary:** the represented primary call output.
- **Secondary:** the separately represented secondary output.
- **Pair:** a represented 64-bit output.
- **∅:** no explicit arguments appear. This does not exclude implicit machine-state inputs.

Selected-write destinations range from `0x11` through `0x110`. A selector byte supplies an address component, not a loaded pointer.

Logical right shifts operate on unsigned 32-bit values. Their relevant bounds are:

| Expression | Range |
|---|---:|
| Word shifted right by 22 | 0–1023 |
| Word shifted right by 23 | 0–511 |
| Word shifted right by 23 twice | Exactly zero |

| `(word & 0x3fffffff) >> 21` | 0–511 |
| `(word & 0x3fffffff) >> 7` | 0–`0x7fffff` |

Unsigned 32-bit arithmetic uses its 32-bit width. Some scaling and left shifts are represented using signed 32-bit quantities; their machine-level overflow interpretation remains unresolved. Portable signed-overflow behavior must not be substituted. Pointer width and address-conversion behavior are also unresolved.
