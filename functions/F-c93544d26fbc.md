## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not executed tests.

### Distinct, stable storage

Given disjoint readable source storage, writable destination storage, and stable header storage, with the dependency returning that destination:

- Destination 0xB8 receives the source word at 0x6C.
- Destination 0xC0 receives the source word at 0x68.
- Destination 0xF8 receives the source word at 0x8C.
- The nine listed zero fields contain zero after ordinary completion.
- Destination bytes outside the listed writes retain their previous contents, provided neither the dependency nor another actor changes them.

### Full-width preservation

Given a source word whose highest bit is set, its destination receives the same 32-bit pattern. No sign normalization, boolean conversion, or truncation to a smaller field is established.

The same applies to zero and all-ones patterns.

### Dependency changes header storage

Given that F-e9175b650588 changes header storage and returns normally, and no subsequent actor changes it before the header read, destination offset 0x00 receives the updated value. A pre-call cached header value would not match the observed ordering.

### Source and destination share a base

Given identical source and destination bases, valid storage through destination offset 0xFB, and stable ordinary memory, the direct writes do not overlap the listed source fields: source reads occupy selected words between 0x68 and 0x8F, while direct writes occur at 0x00 and from 0xB4 onward.

Under those conditions, this particular overlap does not itself corrupt the copied source values.

### A destination write overlaps a later source read

Given an arrangement where destination offset 0xB4 coincides with source offset 0x68, with no intervening change to that location, the source read at 0x68 obtains zero: the destination clear occurs before that read.

An implementation that snapshots all source values before clearing destination 0xB4 would not preserve this behavior.

### Final source value is read before its neighboring clear

Given an arrangement where source offset 0x8C coincides with destination offset 0xBC, the value read before that clear is the value subsequently written at destination offset 0xF8, provided no other effect changes the relevant observations.

Reading source 0x8C only after clearing destination 0xBC would change this behavior.
