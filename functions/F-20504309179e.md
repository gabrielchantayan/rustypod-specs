# F-20504309179e

## Purpose

The established behavior is a set of address calculations, three memory reads, four memory writes, and an indirect invocation. The supplied representation does not establish a higher-level purpose such as initialization, device control, serialization, or object management. In particular, repeated use of the value 68 does not establish the meaning of either the affected byte or the first outgoing argument.

This contract distinguishes:

- **Established static evidence:** operations and ordering directly present in the supplied representation.
- **Inferred interpretation:** a conventional 32-bit interpretation of its integer and address operations.

## Behavior

### Ordered memory-access prefix

For an execution in which each operation completes, the visible memory-access sequence is:

| Order | Access |
|---|---|

| 2 | Read the integer value from G; retain it as K |
| 3 | Read four bytes from H; retain them as V |
| 4 | Read four bytes at S plus 68; retain them as W |

| 6 | Write the four-byte value V at the address obtained by doubling K |
| 7 | Write the two-byte narrowing of K at D plus K |

After these accesses, control transfers to T with three explicitly represented arguments, in this order:

1. B combined with 68 using bitwise inclusive OR.
2. K.
3. W.

The representation shows no conditional branch, loop, validation, or retry in this prefix.

This is the access order established by the supplied representation. It is not evidence of hardware memory barriers, atomicity, or visibility ordering between processors or devices.

### Address and value distinctions

A serves two roles in the first write: it determines the displacement from B, and it supplies the value stored there. The operation is not a write of B, the destination address, or a value read from that destination.

K likewise has several distinct uses:

- It is doubled to obtain the destination address for the four-byte write.
- It is added to D to obtain the destination address for the two-byte write.
- It is narrowed for the two-byte stored value.
- It is passed to T without that two-byte narrowing.

Doubling K supplies the destination address itself. No additional base is visible for that write.

The first outgoing argument uses bitwise OR, not addition. Since decimal 68 is hexadecimal 44, it forces the corresponding bits of B to one and leaves its other bits unchanged. It need not equal the address B plus 68 used for the earlier byte write.

### Captured values and aliasing

K, V, and W are captured at their respective read positions. No later reread of their source locations appears.

Consequently, aliasing affects behavior according to access order:

- The initial write can change G, H, or the location at S plus 68 before the corresponding read.
- A later write to G does not replace the already captured K.
- A later write to H does not replace the already captured V.
- A later write to the location at S plus 68 does not replace the already captured W.

There is no visible disjointness requirement among these locations. Partial overlap matters as well as exact overlap. Determining a numeric value after partial overlap requires byte order and storage-layout information not supplied here.

When write destinations overlap, later writes replace the affected bytes of earlier writes. The final two-byte write can therefore overwrite part of the preceding four-byte write. T receives control only after the displayed writes have completed successfully.

### Arithmetic boundaries

Under a conventional 32-bit machine interpretation:

- B plus A is an address-width addition involving an unsigned base.
- B plus 68 is an address-width addition.
- The first outgoing argument is a 32-bit bitwise OR.
- The two-byte store retains the low 16 bits of K.
- K itself remains the full-width second outgoing argument.

The doubling of K, D plus K, and S plus 68 are represented using signed integer arithmetic. Their exact out-of-range behavior is not established by this artifact. A consumer must not infer either a checked arithmetic exception or guaranteed wrapping from the notation alone.

Negative A or K is not explicitly rejected. Such values can select addresses outside ordinary object bounds or outside accessible memory. No length, capacity, or address-range check is visible.

## Acceptance examples

These examples are conditional expectations derived from static evidence, not executed tests. Unless stated otherwise, assume the conventional 32-bit interpretation, suitable access alignment, accessible storage, nonoverlapping locations, and no external mutation during the prefix.

### Independent locations

Suppose:

- B is 4096.
- A is 8.
- D is 12288.
- G supplies K equal to 4096.
- H supplies a four-byte value V.
- S plus 68 supplies a four-byte value W.

The local prefix must:

- Write integer value 8 at address 4104.
- Read K, V, and W in the specified order.
- Write byte value 68 at address 4164.
- Write V at address 8192.
- Write two-byte value 4096 at address 16384.
- Invoke the unresolved destination with 4164, 4096, and W.

The first outgoing argument equals B plus 68 in this example only because the relevant bits of B are clear.

### OR is not addition

If B is 4164, its bits corresponding to 68 are already set.

The byte-write destination is B plus 68, or 4232. The first outgoing argument is B bitwise-OR 68, or 4164. An implementation that substitutes the byte-write address for that outgoing argument would not match the representation.

### Initial write changes a later read

Suppose G occupies exactly the integer-sized location at B plus A, with compatible width and interpretation.

The initial write occurs before the read of G. In the absence of intervening mutation, K is therefore read from the representation of the newly stored A, rather than from G’s previous contents.

### Narrowed store, full-width argument

Suppose K is 65537 and all derived addresses are accessible.

Under the conventional narrowing interpretation:

- The four-byte write destination is 131074.
- The two-byte write at D plus 65537 stores the low-16-bit value 1.
- The second outgoing argument remains 65537.

### Overlapping final writes

Suppose D equals K, so D plus K equals twice K.

The four-byte write of V occurs first. The two-byte write then replaces the first two addressed bytes of that destination with the narrowed representation of K. The remaining two bytes retain the corresponding bytes from V.

The resulting four-byte numeric value cannot be specified without byte order.

### Indirect destination does not return
