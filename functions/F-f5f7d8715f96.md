# F-f5f7d8715f96

## Purpose

F-f5f7d8715f96 conditionally replaces a receiver’s current object reference through a dependency-mediated operation. When that dependency reports zero, this function transfers a receiver-held value into a 16-bit field of the selected object, clears a byte through the receiver’s then-current object reference, invokes another dependency, installs the selected object, and clears three receiver fields.

The final status distinguishes a zero from a nonzero 16-bit field in the selected object. A zero field produces status 11 even though the replacement and resets have already occurred. Status 11 is therefore not evidence that the receiver was left unchanged.

This is an established description of the visible operations, not an identification of their application-level purpose. Names such as “receiver,” “selected object,” and “current object” describe access roles only. Allocation, reference counting, destruction, synchronization, and resource ownership are not established.

## Behavior

### Dependency-mediated selection

The function first initializes a local 32-bit selection slot with the fourth input.

It then calls F-6293178c6e41 with four arguments:

1. The 32-bit value read from receiver offset +4.
2. The second input, unchanged.
3. The address of the local selection slot.
4. The 32-bit value read from receiver offset +24.

The two receiver reads occur in preparation for this call. Their relative evaluation order is not established by the supplied representation.

The writable slot permits the dependency to select a different object reference. The visible caller does not require the dependency to change it.

The dependency’s return value controls whether this function performs its subsequent mutations. A nonzero result causes an immediate return of that result. On that path, this function performs no explicit receiver or object writes after the call. That is not a guarantee of unchanged state: the dependency may already have modified reachable memory or other state.

### Zero-status transition

When F-6293178c6e41 returns zero, the following visible operations occur in order.

1. **Transfer receiver metadata to the selected object.**  
   The function reads the 32-bit value at receiver offset +28, converts it to a 16-bit value, and stores that value at offset +16 of the object referenced by the selection slot.

   The source value is read after F-6293178c6e41 returns. It is not an entry-time snapshot.

2. **Clear a byte through the receiver’s current reference.**  
   The function rereads the 32-bit reference at receiver offset +24 and writes zero to the byte at offset +1 of that referenced object.

   This is not necessarily the reference previously passed to F-6293178c6e41. The dependency, or an aliased preceding write, may have changed the receiver field.

3. **Invoke F-6cc778185718.**  
   The visible call supplies no explicit arguments. Any result from this dependency is ignored.

   The call occurs after the selected-object metadata write and current-object byte clear, but before installation and receiver-field resets. Its effects cannot be treated as absent merely because no explicit arguments are visible.

4. **Install the selected reference.**  
   The function writes the selection slot’s 32-bit contents to receiver offset +24.

5. **Clear the metadata source field.**  
   It writes a 32-bit zero to receiver offset +28.

6. **Clear a 16-bit receiver field.**  
   It writes a 16-bit zero to receiver offset +62.

7. **Clear an 8-bit receiver field.**  
   It writes an 8-bit zero to receiver offset +66.

8. **Determine the final status.**  
   It reads the 16-bit field at selected-object offset +20. Zero yields return value 11; any nonzero 16-bit value yields return value zero.

The final field check occurs after all listed writes and after F-6cc778185718. It is not a prerequisite for the replacement. No rollback is visible when the check yields status 11.
