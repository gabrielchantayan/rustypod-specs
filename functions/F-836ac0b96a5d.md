# F-836ac0b96a5d

## Purpose

F-836ac0b96a5d conditionally copies one unsigned 16-bit value. Under restrictive additional conditions, it also assigns a special machine-state location and performs a second 16-bit write. It then enters an unconditional cycle consisting of two executable transfers followed by software interrupt selector `0x5B`.

There is no represented ordinary return. If both transfers return and the interrupt resumes execution, the cycle repeats indefinitely.

No application-level purpose is established. The available evidence does not justify describing this routine as a parser, allocator, constructor, or device protocol. Its behavior depends on entry state beyond its single declared argument.

## Behavior

### Selector classification

Only the selector’s lowest two bits determine whether the initial copy occurs.

Under 32-bit wrapping arithmetic, multiplying the selector by `0x40000000` produces zero exactly when the selector is divisible by four.

If the selector is not divisible by four:

- The initial copy is skipped.
- The restrictive branch is not entered.
- The later conditional memory operations are not enabled.
- The initial executable-transfer base remains the entry link address.

The selector’s lowest bit also participates in intermediate flag calculations. On the copy path, however, the selector is divisible by four, so that bit is zero. It does not introduce an additional reachable direct-effect case.

### Initial halfword copy

If the selector is divisible by four, the routine:

1. Reads an unsigned 16-bit value from the copy source.
2. Writes that value to the copy source plus the copy displacement, with the destination address reduced modulo \(2^{32}\).

The displacement counts bytes, not halfwords. An odd displacement can therefore produce an unaligned destination.

The source read precedes the destination write. No call or interrupt intervenes in the represented sequence. Identical or overlapping addresses do not eliminate the write.

An internal address value used by subsequent gates becomes:

\[
\text{copy source}+\text{copy displacement}-\text{comparison value}
\pmod{2^{32}}.
\]

That arithmetic introduces no additional direct memory access.

- The selector is divisible by four.
- The entry link address is zero.
- The stack anchor is zero.
