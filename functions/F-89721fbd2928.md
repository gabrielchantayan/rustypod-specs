# F-89721fbd2928

## Purpose

- When its record input is absent, it performs a global publication write and returns a 32-bit zero.
- When its record input is present, it conditionally performs two additional context operations, requests a resource with size argument 168, and returns the result of a downstream operation receiving that resource, the context, and the record’s leading 32-bit word.

These are established structural behaviors. The meanings of the context, resource, record fields, and published value are not established. In particular, describing the operation as formatting, serialization, object construction, or registration would require dependency evidence not supplied here.

All behavior below is based on static evidence. No runtime tests have been performed.

### Absent-record path

When the record pointer is zero:

- A value from one fixed global binding is stored through the address obtained from another fixed global binding.
- The stored value is 32 bits under the supplied representation.
- The function returns zero.

For this contract, those bindings are called the **publication value** and the **publication destination**. Those labels identify their visible roles, not their application meaning.

### Present-record path

When the record pointer is nonzero, the visible operations occur in this order:

1. Read the 16-bit field at byte offset 4.
2. If that read yields a nonzero value, invoke F-9db770e2e593 with the temporary region and a value obtained from the first optional global binding.
3. Read the 16-bit field at byte offset 6.
4. If that read yields a nonzero value, invoke F-9db770e2e593 with the temporary region and a value obtained from the second optional global binding.
5. Invoke F-8157a180d901 with the literal argument 168.
6. Read the 32-bit field at byte offset 0 and invoke F-e6301aa4cb21 with the resource-operation result, the temporary region, and that field value.
7. Return the result of F-e6301aa4cb21.

The two field tests are independent. If both are nonzero, the first optional invocation precedes the second. If both are zero, neither optional invocation occurs, but the resource request and final invocation still occur.
