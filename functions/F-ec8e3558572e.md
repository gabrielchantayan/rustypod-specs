## Behavior

### Selection and result

The function first inspects the character-sized value at offset 84 from the address-bearing input. It compares that value with zero.

If the value is zero, it adjusts the second input downward by two. Otherwise, it adjusts the second input downward by one. It then returns the adjusted value.

No other field or memory location is explicitly read in the supplied body. In particular, no length, tag, pointer, or neighboring field is consulted before selecting the adjustment.

The two branches differ only in the amount subtracted. A nonzero inspected value does not itself become part of the arithmetic. For example, inspected values of one and two both select subtraction of one; they do not select different adjustment amounts.
