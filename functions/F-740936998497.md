## Behavior

The comparison is a zero-versus-nonzero test. It does not require the value to equal one or any other particular marker. Every nonzero byte representation selects the active path.

If the byte is zero, the function returns the four-byte value zero without making either dependency call and without directly writing the byte.

### Active path

1. F-fd3ad4a90253 is invoked with the original input value.
2. After that call returns, the argument supplied from shared storage is evaluated for the call to F-da57943a3d4d.
3. F-da57943a3d4d is invoked with that argument.
4. After that call returns, the function stores one zero byte at input-relative offset 6.
5. The function returns the four-byte value zero.

Neither dependency’s return value is inspected or used to construct the result. There is no visible conditional branch based on either return value.

The field is not rechecked between the calls or before the final store. Consequently, changes to its contents during either dependency do not alter the already-selected path, provided execution continues normally.

For example, if F-fd3ad4a90253 clears the field, the second dependency is still called. If F-da57943a3d4d subsequently sets the field to a nonzero value, the final store overwrites that value with zero.
