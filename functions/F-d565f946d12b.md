### Snapshot, reread, and aliasing rules

Saved values remain the inputs to their later uses. A subsequent mutation of their source storage does not itself refresh them:

- The saved payload supplies the later 32-bit write.
- The saved doubled-address value supplies the constant-write destination.
- The saved index supplies the derived offset, payload-write destination, final destination calculation, and final stored value.
- The saved base supplies the indirect-call argument.

The two rereads have separate roles:

- The reread index supplies only the earlier doubled-index byte-write destination.
- The reread base supplies the base-plus-offset byte-write destination.

There is no intervening visible write between the saved-index read and index reread. Likewise, no visible write occurs between the saved-base read and base reread. Stable ordinary storage would therefore yield equal values in each pair. The source nevertheless contains separate references, and effects such as external mutation or special memory behavior cannot be excluded.

The initial two writes occur before all six fixed-location read occurrences. If either write overlaps fixed source storage, subsequent reads can reflect that mutation.

The doubled-index byte write and constant 16-bit write occur after both index reads but before both base reads. They can affect the values subsequently obtained from the base source if storage overlaps. They cannot retroactively change the saved payload, saved doubled-address value, or either already obtained index value.

Writes after the base reread cannot retroactively change either retained base value. This remains true if they overlap base-source storage.

No non-aliasing guarantee is established among destinations and source locations.

### Conditional overlap of the two doubled-index writes

The earlier byte write uses twice the **reread index**. The later payload write uses twice the **saved index**.

Their starting addresses are equal when the two index reads yield equal values and the address calculations are valid. Under ordinary byte-addressed memory semantics, the later 32-bit write then replaces the byte previously written at that starting address.

If the two index values differ, equal starting addresses must not be assumed. Whether the resulting ranges overlap depends on the values and address interpretation.

Even when the byte is subsequently overwritten, its earlier write remains part of the recovered sequence. Final memory contents alone do not describe every intermediate effect.
