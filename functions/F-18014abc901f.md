# F-18014abc901f

## Purpose

F-18014abc901f performs a conditional, indexed lookup using a record obtained from F-ecd921e533b1. It accepts a signed 32-bit index and returns a 32-bit value.

The established lookup rule is an exclusive upper bound:

- A negative index produces zero without a record or table read by this function.
- A nonnegative index causes a signed bound to be read from the record.
- An index equal to or greater than the bound produces zero without reading the table-address field or a table entry.
- An index strictly below the bound selects a four-byte table entry and returns its stored value.

F-ecd921e533b1 is called before any of these outcomes, including rejection of a negative index.

Interpreting the bound as an element count and the selected value as an object pointer is **inferred intent**, not an established semantic contract. The static representation establishes the comparisons, accesses, and returned value, but not the application-level meaning of the stored data.

Zero does not uniquely identify rejection. An accepted entry containing zero also produces zero.
