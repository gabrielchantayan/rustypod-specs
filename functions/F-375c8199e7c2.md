## Behavior

### Incoming value is zero

The incoming value is checked before any access through the destination.

If it is exactly zero, the function returns immediately. The destination’s current contents do not affect this outcome. No destination read or destination write is required by this path.

Consequently, zero cannot be used through this function to clear an existing value. It also cannot cause an empty slot to be inspected or explicitly rewritten as zero.

### Incoming value is nonzero

When the incoming value is nonzero, the function reads the integer at the destination and compares that value with zero.

If the destination value is zero, the function assigns the incoming value to that same integer object and returns. The assignment is a replacement, not an accumulation, bitwise merge, or transformation.

If the destination value is nonzero, the function returns without assigning to it. There is no comparison between the incoming value and the existing nonzero value: equality, sign, and relative magnitude do not alter the decision.
