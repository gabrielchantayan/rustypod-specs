## Acceptance examples

These are conditional static obligations, not executed tests. They assume valid memory and defined or independently established arithmetic.

- **Entry aliasing:** if root `0x54` overlaps source `0x05`, the byte capture observes the root write, but precedes the first-argument write.
- **Payload capture:** if selector plus `0x54` aliases payload-record `0x60`, entry payload can determine payload word. The subsequent selector-plus-`0x11` write cannot retroactively change it.
