# F-7047016ff2bf

## Purpose

F-7047016ff2bf reverses the order of the four 8-bit groups in a 32-bit unsigned value.

The transformation operates on the numeric value, not on an addressed sequence of bytes. The most significant input byte becomes the least significant output byte; the next most significant input byte becomes the next least significant output byte, and conversely. Bit order within each byte is preserved.

## Behavior

The function returns the input’s four bytes in reverse order of numeric significance. It preserves all eight bit positions within each byte.

For example, when the input bytes, from most significant to least significant, are 0x12, 0x34, 0x56, and 0x78, the result’s bytes are 0x78, 0x56, 0x34, and 0x12.

The transformation has the following consequences under the 32-bit precondition:

- The input’s least significant bit becomes output bit 24, not output bit 31.
- The input’s most significant bit becomes output bit 7, not output bit 0.
- A zero byte remains zero in its destination position.
- A byte containing all set bits remains an all-set byte in its destination position.
- Equal bytes remain indistinguishable after exchanging positions.
- Applying the function twice restores the original value.

This is therefore a byte reversal, not a reversal of all 32 individual bits, a rotation, a signed conversion, or a numerical negation.

### Arithmetic and width

The supplied transformation uses shifts by 8 and 24 bit positions. Both shift counts are below a 32-bit operand width.

For a 32-bit unsigned operand, left shifting uses unsigned semantics: bits shifted beyond bit 31 do not contribute to the result. In particular, moving the least significant byte into the most significant byte position does not produce a signed-overflow error.

The contributions to the returned value occupy separate byte positions. Their bitwise combination does not add values or propagate carries between bytes.

The result depends only on the argument’s bit pattern. No input value selects a different branch or exceptional path in the supplied body.
