# F-1c2147d338bf

It then passes the original two arguments to F-36a285714182, uses that dependency’s integer result to select a field in a globally based table, and passes the selected 32-bit value to F-5bcae2eff9a7.

If execution reaches the ordinary return, the function returns a 32-bit zero. This return value does not report the results of the first or third dependency and is not evidence that any dependency completed its intended operation successfully.

## Behavior

On an execution that proceeds normally, the wrapper’s operations occur in this order:

1. Read the four-byte field at offset 52 from the first argument’s address base.
2. Call F-8b341d935c06 with that field value as its sole visible argument.
3. After that call returns, call F-36a285714182 with the original first and second arguments.
4. Interpret the second dependency’s result as the integer selector for the table lookup.
5. Obtain the global table base and read the four-byte field at offset 4 within the selected 24-byte record.
6. Call F-5bcae2eff9a7 with that field value as its sole visible argument.
7. After the final call returns, return a four-byte zero.

Each of the three dependencies is called once on this normal path. The wrapper contains no loop, retry, or conditional branch that omits one of these calls.
