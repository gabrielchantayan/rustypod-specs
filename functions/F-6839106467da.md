The destination accesses suggest a header, a bitmap, trailing metadata, and additional regions spaced by a context-supplied length. ### Bitmap and final trailing field

- F-4055be9c3f18 with B + 0x24, followed by F-b5c826d2ab04 without an explicit argument.
- F-4055be9c3f18 with B + 0x28, followed by F-b5c826d2ab04 without an explicit argument.

Let **N** be the first value minus the second, assigned to an unsigned 32-bit quantity. The signed-intermediate qualification in Uncertainties applies.

Beginning at B + 0xf8, the function writes one byte 0xff for each complete group of eight in N. It then **always writes one additional byte**, selected by the remainder:

| Remainder | Additional byte |
|---|---|
| 0 | 0x00 |
| 1 | 0x80 |
| 2 | 0xc0 |
| 3 | 0xe0 |
| 4 | 0xf0 |
| 5 | 0xf8 |
| 6 | 0xfc |
| 7 | 0xfe |

The direct bitmap-write length is therefore **floor(N / 8) + 1 bytes**. A count below eight writes its additional byte directly at B + 0xf8. An exact multiple of eight still appends a zero byte after the complete-group bytes.

No capacity check bounds these writes. A difference assigned a large unsigned value can produce a large write range.

## Acceptance examples

These are conditional static criteria, not executed tests. They describe the relevant observation or phase without assuming later dependencies preserve its effects.

1. **Entry aliasing:** If input 7 addresses context offset 20, the zero store precedes the V read. Under ordinary memory behavior, V is therefore read as zero. Initial flags have already been retained.

2. **Output access distinction:** Input 6 requires a direct 32-bit store, not a direct read. Input 7 supports direct stores and later reads. Dependency-specific access requirements remain additional.

3. **Header extent versus bitmap extent:** The bit-2-clear header branch directly stores a byte at B + 0x33. If the later bitmap count is zero, the bitmap additionally stores 0x00 at B + 0xf8. Thus B + 0x33 bounds the listed fixed header stores, not all direct destination stores.

4. **Unknown dependency extent:** Calling dependencies with B + 0x34 does not establish that B + 0x37 is accessed, nor does it establish any particular write width.

5. **Flag-selected byte:** On the bit-2-clear header branch, the subsequent bit-3 observation selects 0xcf when clear and 0xbc when set for B + 0x33.

6. **Threshold equality:** If the unsigned comparison value equals wrapped 8U, the optional phase is skipped. No replacement of extra count occurs in that phase; this does not guarantee that dependencies preserved its initial zero.

7. **Bitmap boundaries:** N = 0 produces 0x00 at B + 0xf8. N = 7 produces 0xfe there. N = 8 produces 0xff followed by 0x00. N = 9 produces 0xff followed by 0x80.

8. **Mixed flag observations:** Initial bit 0 set and construction-time bit 2 set select the three-call construction branch even if current bit 0 is clear.

9. **Final arithmetic:** If the final paired observations yield 20 and 12, the subsequently read extra count is 2, and L is 512, the final stored product is 3072.

10. **Aliased outputs:** Under the preceding arithmetic conditions, if inputs 6 and 7 address the same word, that word becomes 3072, while the final handoff receives retained extra count 2 and retained product 3072.
