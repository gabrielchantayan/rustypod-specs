## Acceptance examples

These are conditional static expectations, not executed tests. They assume the represented prefix is accurate, required storage and calls are valid, dependencies return as specified, and no unmentioned effects change the scenario.

### Store-before-read ordering

For P equal to zero, both initial accesses address 20. The store writes zero before the snapshot read, so S is zero under ordinary memory semantics. The snapshot-derived store subsequently writes zero.

Reading the previous contents before storing P would violate the ordering.

### Logical shift and retained snapshot

If S is hexadecimal ABCDEF12, the snapshot-derived word store writes hexadecimal 000ABCDE at \(U+20\).

A dependency changing the original snapshot location afterward does not change S’s retained value.

### Distinct address and data scales

For B equal to 7 and C equal to 9:

- V is 28.
- The B-derived store writes 28 at address 132.
- The C-addressed store writes the same 28 at address 56.

Using address 48 for the first store, or storing 36 at the second, would not satisfy the contract.

### Fresh selector reads

Suppose D is hexadecimal 12345678, the first selector read produces 5, and an intervening dependency changes the selector so the second read produces 9. Under the stated 32-bit and low-byte interpretation:

- The first byte store writes hexadecimal E0 at address 22.
- The second writes hexadecimal 23 at address 26.
- F-X33 later receives 9 as its second explicit argument.

Reusing Q₁ for the second destination or rereading the selector for F-X33 would change the behavior.

### General selector/store noncoincidence

Under 32-bit wraparound, every selector address is \(1+k2^{28}\), with \(0\leq k\leq15\). The smallest is 1; every other candidate exceeds 272. Every byte-store destination is in 17–272.

Thus no unsigned selector-byte value can make a byte-store destination numerically equal the selector address, regardless of A. The same noncoincidence follows under nonoverflowing signed arithmetic from the congruence modulo \(2^{28}\).

A change between Q₁ and Q₂ may be attributed to an intervening dependency under suitable dependency behavior, but not to numeric-address aliasing by the first byte store.

### Conditional signed-shift interpretation

Under 32-bit bit-vector semantics, A equal to 3 makes F-X11’s first argument 196,608 and its third argument hexadecimal C0000000.

The third argument requires that arithmetic assumption; it is not guaranteed merely by treating the expression as a defined signed left shift.
