# F-28d7572fac38

## Purpose

F-28d7572fac38 performs an ordered sequence of indirect calls, scaled-address calculations, byte accesses, and 32-bit memory updates. Its application-level purpose is not established.

The visible effects include forwarding the first input, extracting the upper seven bits of the fourth input, propagating dependency results into memory, writing selected bytes, and repeatedly clearing the 32-bit location at absolute address 0x24.

The access patterns distinguish reads from writes:

- Writes occur at base-relative offsets 1, 0x0f, 0x11, 0x14, 0x24, and 0x44.
- Reads occur at base-relative offsets 1, 0x14, and 0x74.
- Offset 0x74, decimal 116, is used for 32-bit reads, not writes.

These offsets use different bases and scaling rules. They do not establish a common object layout. Initialization, serialization, device control, and memory management remain unproved interpretations.

The supplied representation ends at a bad-instruction boundary. This contract describes visible static behavior, conditional on execution reaching each operation; it does not establish successful execution or normal completion.
