### Negative first input and negative second input

For \(x<0\) and \(y<0\), classification proceeds in this order:

1. Return **−2** if both:
   - \(12x\ne y\); and
   - \(-12x\le -y\).

2. Otherwise, return **4** if either:
   - \(12y=x\); or
   - \(-x<-12y\).

3. Otherwise, return **−1**.

The equality exclusion in the first rule is significant. Equality \(12x=y\) prevents that rule from returning −2 even though the other comparison may hold.

The equality \(12y=x\) in the second rule explicitly selects 4. It must not be replaced with a strict comparison that assigns that boundary to −1.

### Negative first input and nonnegative second input

For \(x<0\) and \(y\ge0\):

1. Return **2** if \(-12x<y\).
2. Otherwise, return **4** if either:
   - \(-12y=x\); or
   - \(-x<12y\).
3. Otherwise, return **−1**.

The first threshold is strict. Equality \(y=-12x\) does not return 2.

The second rule includes both an explicit equality boundary and a strict comparison. A caller must not collapse the entire case into a single approximate ratio test.

### Nonnegative first input and negative second input

For \(x\ge0\) and \(y<0\):

1. Return **−2** if both:
   - \(-12x\ne y\); and
   - \(12x\le -y\).

2. If the first rule does not return, form the scaled second value \(-12y\).

3. Return **1** if that scaled value is less than \(x\). Otherwise, return **4**.

Thus, equality between \(-12y\) and \(x\) returns 4, not 1.

Equality \(y=-12x\) blocks the initial −2 result. This boundary treatment is deliberate in the supplied representation, regardless of its unknown application meaning.

### Nonnegative first input and nonnegative second input

1. Return **2** if \(12x<y\).
2. Otherwise, form the scaled second value \(12y\).
3. Return **1** if that scaled value is less than \(x\). Otherwise, return **4**.

Both comparisons are strict. Consequently:

- \(y=12x\) does not select 2.
- \(x=12y\) does not select 1.
- The origin returns 4.
