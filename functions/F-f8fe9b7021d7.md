## Acceptance examples

These are conditional analytical examples, not executed tests. Address calculations requiring wrapping assume the stated bit-vector model.

1. **Initial extraction.** If the second input is `0xABCDEF01` and the first byte read returns `0x20`, the first byte store writes `0xAF` at `0x31`. This describes that event, not the final contents after later effects.

2. **Byte-index boundaries.** An index of zero selects destination `0x11`; an index of `0xFF` selects `0x110`, not `0x10`. No visible rejection precedes either destination.

3. **Split-result stores.** If H is 3 and L is 5, the first word store writes zero at `0x20`. The later low-half-derived store writes `0x14000000` at `0x50000014`, if reached.

4. **Masked extraction.** If L is `0xFFFFFFFF`, the word stored through the F-09e result is `0x000FFFFF`.

5. **Distinct scaled locations.** If C is 1, P is 4. The store after F-10e targets `0x24`, while both subsequent argument-preparation reads target `0x18`. Treating these reads as automatic readbacks of that store is incorrect.

6. **Argument precedence.** F-03a receives a scaled dependency result before the first byte index. F-06a receives the second byte index before its scaled result. Swapping either pair changes the represented interface.

7. **Independent word observations.** If the read feeding F-11a’s first argument observes `0x00001000` and the read feeding its third argument observes 3, those arguments are 1 and 12, respectively. Their chronological read order remains unresolved.

8. **Late reread.** If the two late byte reads observe `0x20` and `0x21`, their stores target `0x31` and `0x32`. Intervening calls may make such differing observations possible; caching the first byte would not preserve this behavior.

9. **Late byte truncation.** If Y is `0xFFFFFFFF`, the first late byte store writes `0xFC`; the second writes `0xFF`. Both remain subject to their separately observed destinations.

10. **Effect inventory.** A trace covering every represented direct access through F-23b contains fourteen word stores, not fifteen, alongside five byte stores, five byte reads, and three word reads.
