# F-bdf0400286de

## Purpose

F-bdf0400286de performs a fixed sequence of indirect calls interleaved with address calculations, memory stores, a global-pointer snapshot, byte-table lookups, and final zeroing operations.

The established behavior is operational rather than semantic: the supplied representation does not establish an application-level purpose for the stored values or the called operations. In particular, it does not justify describing this function as initialization, serialization, resource management, or successful completion of a service request.

The final explicit call targets address zero. Ordinary return is therefore conditional on the execution environment supporting that call and allowing it to return. This contract does not replace that call with a no-op, an error result, or an assumed trap.

- Address additions are interpreted in the same 32-bit machine address space.
- Right shifts of unsigned quantities are logical.

These are the machine-level interpretations suggested by the recovered operations. Exact overflow behavior of operations presented with signed types requires underlying instruction evidence; it is not independently established by the supplied representation.

Thus, the low two bits of C do not affect this destination. No read of the destination’s prior contents is shown.

The following calls then occur in order:

2. F-ext-02 produces a 32-bit result.
3. F-ext-03 receives that result.
4. F-ext-04 produces a 32-bit result.
5. F-ext-05 receives that result.
6. F-ext-06, F-ext-07, and F-ext-08 run in that order, with no explicit arguments.

The function next stores **R shifted right by 23** as a 32-bit word at:

**scale(I) + 0x14**

Only the low nine bits of this stored value can be nonzero.

F-ext-10 then receives scale(I). F-ext-11, F-ext-12, and F-ext-13 follow, with no explicit arguments.

### 2. First two-word result and global-address snapshot

F-ext-14 produces a result represented as 64 bits. Let its low word be **L1** and its high word be **H1**. Define **V = scale(L1)**.

The function stores V as a 32-bit word at:

**scale(H1) + 0x14**

After that store, it reads the address held in G and retains that address as a snapshot. This read is before F-ext-15.

F-ext-15 receives four explicit arguments, in order:

**V, H1, V, V**

F-ext-16, F-ext-17, and F-ext-18 then run with no explicit arguments. F-ext-19 produces another 32-bit index, **J**.

The function stores the previously retained V at:

**scale(J) + 0x14**

It then reads a 32-bit word, designated **W**, at:

**the snapshotted G address + 0x14**

This distinction is observable: the address is captured before F-ext-15, but the word at that address is read after F-ext-19 and the intervening store. Changes made by those calls to the contents of the snapshotted object can affect W. Changes to G itself do not redirect this particular read.

F-ext-20 receives scale(J). F-ext-21, F-ext-22, and F-ext-23 follow with no explicit arguments.

### 3. Second two-word result and first byte-table update

F-ext-24 produces another result represented as 64 bits. Let its low word be **L2** and its high word be **H2**.

The function then:

- Reads an unsigned byte at **R + 1**.
- Adds 0x11 to that byte’s value to obtain a destination address.
- Stores the low byte of W at that destination.

The resulting destination lies between 0x11 and 0x110 inclusive. This is an address calculation from the byte value, not a write back to R + 1.

F-ext-25 receives four explicit arguments:

**H2, H2, H2, scale(L2)**

F-ext-26 produces a 32-bit result, which F-ext-27 receives. F-ext-28, F-ext-29, and F-ext-30 then run with no explicit arguments.

### 4. Second byte-table update

F-ext-31 produces a 32-bit index, **K**.

The function computes a lookup address:

**((L2 AND 0x3FFFFFFF) shifted right by 21) + 1**

It reads an unsigned byte from that address, adds 0x11 to the byte value, and stores the low eight bits of **W shifted right by 22** at the resulting destination.

Consequently:

- The lookup address is in the inclusive range 1 through 512.
- The byte-store destination is again in the inclusive range 0x11 through 0x110.
- The stored byte represents bits 22 through 29 of W.
- Bits 30 and 31 of W do not contribute to this byte.

The index K does not determine this byte store’s address or value. It is used by the next call: F-ext-32 receives scale(K).

F-ext-33, F-ext-34, and F-ext-35 then run with no explicit arguments.

### 5. Final calls and zeroing operations

F-ext-36 produces a 32-bit index, **M**. F-ext-37 receives scale(M) twice. F-ext-38 follows with no explicit arguments.

F-ext-39 produces a 32-bit result, which F-ext-40 receives. F-ext-41 then runs with no explicit arguments, and its represented result is assigned to global S.

Following that assignment, the function performs these operations in order:

1. Stores an 8-bit zero through P, the register-carried pointer available after F-ext-41.
2. Stores a 16-bit zero at **(L2 AND 0x3FFFFFFF) shifted right by 7**.
3. Calls F-ext-42 at address zero with three explicit zero arguments.

The halfword destination is in the inclusive range 0 through 0x7FFFFF. It is not rounded for alignment. Whether an odd destination is legal depends on the execution environment.

No later explicit read of L2 from memory occurs: the halfword address is derived from the retained low word of the F-ext-24 result.

No transaction, rollback, synchronization, atomicity, or memory-barrier guarantee is shown.

## Acceptance examples

These are conditional contract examples, not executed tests.

### Initial alignment

If C is 0x1003 and address 0x1014 is writable, the first explicit store writes A at 0x1014. The same destination results from C values 0x1000, 0x1001, and 0x1002.

### Shifted ambient word

If R is 0xFFFFFFFF and F-ext-09 returns 3, the subsequent word store writes 0x000001FF at address 0x20, assuming that address is writable.

### Captured address versus later contents

Suppose G contains address X when captured. If F-ext-15 changes G to Y, the subsequent read of W still uses X + 0x14. If an intervening dependency instead changes the word at X + 0x14, that changed word is read, subject to any later aliasing store.

### First byte selector

If the byte read at R + 1 is 0xFE and W is 0xA1B2C3D4, the first byte update writes 0xD4 at address 0x10F.

### Second byte selector

If L2 is 0xC0200000, the second lookup address is 2: masking removes the top two bits before shifting. If the byte at address 2 is 0x07 and W is 0x3FC00000, the resulting store writes 0xFF at address 0x18.

### Final halfword address

If L2 is 0xC0000180, the final halfword destination is address 3. The contract preserves that odd address; successful completion requires the environment to support the store there.

### Terminal call

If F-ext-42 does not return, this function does not reach its explicit return. If address zero is not callable, normal completion is not established, even if every preceding write succeeded.
