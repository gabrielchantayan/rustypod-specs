# F-8cfb43901820

## Purpose

The special case applies when a subsequent observation of the selector equals 2. In that case, the function passes a two-byte field from the record to F-6985300e27da. A zero return from that dependency triggers the decrease; any nonzero return leaves the selected result unchanged.

## Behavior

The function then evaluates the selector at offset 4 again to decide whether the special case applies.

1. The initial observation determines the table entry.
2. The subsequent observation determines whether the dependency is called.

This distinction matters when describing the source-level behavior. However, the material does not establish volatile accesses, synchronization, or an exact machine-load count. ### Ordinary path

If the subsequent selector observation is anything other than 2:

- The function does not explicitly read the two-byte field at offset 6.
- It does not call F-6985300e27da.
- It returns the candidate table value without the conditional decrease.

Values other than 2 are not rejected. In particular, selectors 0, 1, and 255 follow the same ordinary-path rule, provided their table entries are accessible.

### Special path

If the subsequent selector observation equals 2, the function reads the two-byte field at offset 6 and passes that value to F-6985300e27da.

The dependency is called once on this path. Its return is tested for exact equality with zero:

- A zero return causes the candidate result to be decreased by one.
- Any nonzero return leaves the candidate result unchanged.

No particular nonzero value is distinguished. The dependency result is not returned to the caller.

The candidate result was obtained before the dependency call. There is no explicit table reread afterward. Thus, a table change performed by the dependency does not itself replace the already selected candidate through this function’s normal data flow.
