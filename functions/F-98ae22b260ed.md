# F-98ae22b260ed

## Purpose

F-98ae22b260ed obtains a 32-bit handle through two dependency calls, reads an associated record address from that handle, initializes selected fields in the record, and publishes the handle through a caller-provided output pointer.

The established behavior consists of ordered calls, reads, and writes. It does not establish the application-level meaning of the handle or record.

The apparent intent is to install a five-word configuration, set a field to the address of that configuration within the record, clear three other fields, and set another field to one. This interpretation is inferred intent. The evidence does not establish that the cleared fields are counters, that one denotes a Boolean state, or that the five configuration words have any particular semantic type.

Only selected record fields are initialized. The function does not establish a fully initialized record.
