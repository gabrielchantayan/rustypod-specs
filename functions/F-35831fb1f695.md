# F-35831fb1f695

The established behavior has three outcomes:

- A zero preliminary result causes a normal return of zero.
- A nonzero preliminary result with an unrecognized selector causes a normal return of that preliminary result, unchanged.

The recognized selectors are 0x1200 through 0x1209, inclusive. Under the supplied non-returning model, they have the same externally described dispatch behavior.
