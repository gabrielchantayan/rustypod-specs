## Behavior

### State selection and termination

The function saves both arguments and initializes numerous working values to zero, including the return storage, working buffer base, indices, arithmetic intermediates, and a flag used by the default transition. The 16-byte scratch area is not initialized as a whole.

The first state token comes from global data. Each dispatch combines the current token with a global decoding offset. The resulting selector chooses among numbered operations from 0 through 25, or a default operation.

Transitions are also controlled by global data. Some install a global destination directly; others select between destinations using an arithmetic predicate. Several predicates use the high bit of a 32-bit intermediate. Two relevant forms are distinct:

- A logical right shift by 31 produces zero for a clear high bit and one for a set high bit.
- An arithmetic right shift by 31, followed by adding one, produces one for a nonnegative signed interpretation and zero for a negative interpretation.

The subsequent destination calculation chooses between two state-token values using that binary result. These are not necessarily equivalent to ordinary comparisons between the original arguments.

The default operation computes another token from a flag initialized to zero. The visible assignments to that flag only assign zero. Thus, in the supplied representation, its default transition reduces to the corresponding global transition word minus one. This does not establish that the next dispatch reaches a known operation or eventually returns.

There is no visible iteration limit, timeout, exception handler, or general failure exit. Nontermination cannot be excluded.
