## Acceptance examples

These are conditional static acceptance examples, not executed tests. They assume the relevant calls return and all mentioned accesses are permitted.

1. **Initial byte truncation.** If EntryWord is 0x123456AB, the first byte write stores 0xAB. The later indexed word write still stores the full 0x123456AB.

2. **EntryIndex destination bounds.** EntryIndex equal to zero selects address 13. EntryIndex equal to 0xFFFFFFFF selects address 1036. Neither address is relative to EntryBase.

3. **Distinct size transformations.** If SizeResult is 3, the write at EntryBase + 36 stores 12, while the later write at CapturedAddress + 36 stores 96.

4. **Masked call argument.** If CapturedAddress is 0x80000004, F-D12 receives 1 as its fourth argument. Under 32-bit modular shifting, its second argument is 8.

5. **Paired-result ordering.** If F-D21 produces high half 3 and low half 5, the EntryWord write targets address 32. F-D22 receives 20, 20, 20, and 0.

6. **Selector re-read.** If the first read at CapturedAddress + 1 yields 4 and the second yields 9, the two byte writes target addresses 21 and 26 respectively. Reusing the first selector for the second write would not satisfy the represented behavior.

7. **Packed-byte payloads.** If PackedResult is 0xABCDEF01, PackedScaled is 0xAF37BC04 under 32-bit shifting. The first selected payload is 0x04. The second is 0xBC after masking, shifting, and byte truncation.

8. **Tail-selector independence.** If the first computed selector read yields 2 and the second yields 7, zero bytes are written at addresses 19 and 24. Equal payloads do not justify omitting either selector read or write.

9. **Interrupted execution.** If F-D12 does not return, the two initial byte writes and the write at EntryBase + 36 precede that interruption. The later write at CapturedAddress + 36 is not reached.
