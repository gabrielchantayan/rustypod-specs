# F-0559024c3751

## Purpose

F-0559024c3751 conditionally reduces its signed-integer input by 32. Eligibility for reduction comes from a classification value obtained through a dependency-mediated lookup. The classification bit with numeric weight 8 selects reduction, except that input 223 is always returned unchanged.

The exemption changes the numeric result, not the lookup obligations. Input 223 still requires the dependency call, the read supplying the lookup address basis, and the classification read.

The operation resembles table-driven character case conversion. That is **inferred intent**, not an established encoding or character-processing contract. No character repertoire, locale, table contents, or supported input interval is supplied.

## Behavior

### Lookup and decision

Every ordinary entry into the supplied body calls F-2a4c402ba617 once without arguments. The function uses that call’s result to obtain the address of the signed-integer read.

After the dependency returns, the address-basis read precedes the classification read: the latter address depends on the value obtained by the former. The classification read supplies the value whose bit of weight 8 is tested.

If that bit is clear, the function returns the original input. If it is set, the function returns the original input reduced by 32 unless the original input is 223. Input 223 is returned unchanged regardless of the selected classification value.

All other classification bits are irrelevant to the numeric decision. This does not imply that the classification value as a whole is ignored or that the read can be omitted.

### Exemption and unchanged results

The lookup occurs before the exemption can affect the branch outcome. Consequently, input 223 does not bypass any of the following:

- The dependency call.
- The signed-integer address-basis read.
- The classification-byte read.

Likewise, a clear classification bit does not bypass either read.

The exception applies to the original input, not to possible output values. A different input may legitimately produce 223 after reduction. For example, input 255 with the selected bit set produces 223, subject to the normal-completion prerequisites.
