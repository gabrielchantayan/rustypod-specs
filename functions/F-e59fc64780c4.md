If the invocation returns normally, the wrapper completes without an explicit return value.

## Behavior

1. It obtains the destination designated by the referenced dispatch location.
2. It invokes that destination without explicit arguments.
3. If that invocation completes normally, the wrapper returns without an explicit value.

The supplied representation contains no source-level work before dispatch other than obtaining the destination. It contains no source-level work after a normal return other than completing the wrapper.

There is no represented branch selecting among several destinations, no fallback destination, and no loop. Although the representation includes a warning about unsuccessful jump-table recovery, that warning does not establish a recovered table layout, an index, a number of alternatives, or selection rules. None can be added to the behavioral contract.

### Dispatch selection

The destination is indirect rather than named directly by the wrapper. The contract therefore does not bind successive invocations to a particular destination.

If the dispatch location changes between invocations, and a later invocation observes the new valid value, that invocation is directed to the newly observed destination. The representation does not establish who may change the location, when initialization occurs, or whether concurrent modification is supported.

There is one source-level occurrence of the dispatch lookup. This is not evidence of a particular machine load count, access width, atomicity guarantee, memory-ordering operation, or synchronization protocol.

### Completion and noncompletion

Normal completion is conditional on the destination returning normally through a mechanism compatible with the wrapper.

If the destination does not return, the wrapper has no represented alternative path that completes independently. If the destination terminates execution, blocks indefinitely, or transfers control elsewhere, the supplied representation provides no wrapper-level recovery behavior.

If obtaining or invoking the destination fails, no explicit wrapper-level handler, status conversion, retry, or fallback is present. The resulting behavior depends on the execution environment and the nature of the failure; it is not specified here as a particular exception, fault, or error code.
