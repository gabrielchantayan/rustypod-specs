2. Store the working buffer address through the active address-output destination.
3. Store a computed 32-bit word through the active word-output destination.

## Acceptance examples

These examples are conditional static acceptance criteria, not observed executions.

1. **Acquisition returns zero.** If execution reaches acquisition and F-d33f6d597e5d returns zero, zero is retained as the working address and release candidate, and the zero-result dispatch alternative is selected. A particular error code or immediate return is not required by the supplied evidence.

2. **Caller-output publication.** If preparation has selected D and B, no subsequent state redirects them, and publication is reached, the working address is stored through D before the computed word is stored through B.

3. **Overlapping output destinations.** If B and D designate the same valid word and publication uses both caller destinations, the computed-word store occurs last. The final word therefore reflects that second store, assuming no intervening external fault.

4. **Four-byte mutation.** If the four-write operation is reached after the offset preparation, and the target memory is valid, the write order is offsets 12, 13, 14, then 15. The transformed values, not unscaled extracted bytes, are the acceptance criterion.

5. **Byte-transform boundary values.** A read byte of 0 produces \(T(0)=44\); a read byte of 255 produces \(T(255)=157\). These values establish only the intermediate transformation, not the subsequent branch or output byte.

6. **Aliased byte regions.** If the two-read/one-write operation targets overlapping regions, both reads for that operation occur before its write. Later operations may observe the newly written byte.

7. **Return without accumulator replacement.** If the return state is reached without executing an assignment that replaces the initialized return accumulator, the returned value is zero. Reachability of such a path is not established.
