## Behavior

The following order is established by the supplied representation:

1. A local 32-bit word is initialized from the fourth input.
2. F-76c6a182f91b is called with the first input and the address of that local word.
3. After that call returns, the current value of the local word is supplied as the second argument to F-EXT-01. Its first argument is zero.
4. After F-EXT-01 returns, the function checks whether the second input is null.
5. If it is non-null, the first output word is written with zero, followed by the second output word.
6. The function returns a 32-bit zero.

F-EXT-01 is a document-local opaque identifier for the external dependency whose mapped identity was not supplied. It does not assert a resolved implementation identity.

The first dependency receives the address of the local word, not merely its initial value. Its ability to modify that word is therefore significant. The value passed to F-EXT-01 is the value held after the first dependency returns; it is not necessarily the original fourth input.

For a non-null second input, the function writes two separate 32-bit zero values in ascending word order. It does not explicitly read the old contents of either output word before overwriting them.
