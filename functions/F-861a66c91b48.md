# F-861a66c91b48

## Purpose

F-861a66c91b48 performs a dependency-driven initialization of a caller-supplied destination, then writes three consecutive 32-bit fields at byte offsets 32, 36, and 40 from that destination.

The last field receives either an explicitly supplied nonzero value or a value obtained through a fallback dependency when the supplied value is zero. Zero is therefore a selector for fallback behavior, not an unconditional request to store zero.

The established behavior is a sequence of one mandatory dependency call, two direct field writes, an optional dependency call and fallback read, and one final field write. The source does not establish the destination’s complete type, the semantic meaning of the fields, or whether initialization creates or transfers ownership.

## Behavior

It then invokes F-c3c20ba60cab with four arguments:

2. The word obtained through the shared base location.
3. The initialization value.
4. A zero-valued argument.

No result from that dependency is used by this function. If the dependency does not return normally, the subsequent direct writes are not reached through the shown control flow.

The indirect argument read precedes the dependency invocation. The source does not require an ordering among evaluations of the other, side-effect-free argument expressions.

### First two destination writes

After F-c3c20ba60cab returns, the function reads the shared field-value location and writes that 32-bit value to destination offset 32.

It then writes the attached value to destination offset 36.

The timing of the shared field-value read matters: it occurs after the mandatory dependency call, not before it. If that dependency changes the shared field-value location, the subsequent write uses the value present when the read actually occurs.

The word used as the second argument to F-c3c20ba60cab, by contrast, has already been read before the call begins. A later change to the shared base or its referenced storage does not retroactively change the argument supplied to that invocation.

### Selection and fallback

After the first two destination writes, the function tests whether the selection value equals zero.

If it is nonzero:

- F-3fdd14ecd250 is not called.
- The selection value is written as a 32-bit integer to destination offset 40.

If it is zero:

- F-3fdd14ecd250 is called without explicit arguments.
- The function reads a 32-bit integer at byte offset 28 from the returned address.
- That integer is written to destination offset 40.

The fallback result is not tested for zero or any other distinguished value. In particular, a fallback field containing zero is stored as zero; it does not trigger another fallback call.

Negative selection values are nonzero and therefore take the direct-write path. There is no visible positivity check, range check, normalization, or clamping.

### Observable ordering

For an invocation that returns normally, the established source-level sequence is:

1. Read the shared base location and its referenced 32-bit word at offset 4.
2. Call F-c3c20ba60cab.
3. Read the shared field-value location.
4. Write destination offset 32.
5. Write destination offset 36.
6. If the selection value is zero, call F-3fdd14ecd250 and then read its returned object at offset 28.
