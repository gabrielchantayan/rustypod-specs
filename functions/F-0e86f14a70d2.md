# F-0e86f14a70d2

## Purpose

The function exposes two distinct results:

- An integer return value.
- A value written through an output pointer, either directly by this function or potentially by a dependency.

A specialized dependency’s nonzero return is propagated unchanged. A fallback result is written to the output destination, but the function’s return is normalized to one for any nonzero result and zero for a zero result. One exceptional route writes a stored value and returns one without invoking a dependency.

The dispatch values are evaluated at distinct source-level occurrences. The body does **not** establish one shared snapshot of those values across the function. In particular, the final dispatch branch means that two preceding comparisons failed; it does not necessarily mean that the selector exceeds a single stable pivot.

The application meaning of the context, selectors, requests, and output values is unknown.
