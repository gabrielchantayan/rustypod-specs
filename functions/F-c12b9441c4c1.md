# F-c12b9441c4c1

## Purpose

F-c12b9441c4c1 delegates acquisition of a writable destination to F-17c2f3b940d8, then writes three 32-bit values into that destination. The values occupy the first, third, and fourth 32-bit slots. The second slot is not explicitly accessed by this function.

The first input is passed to the dependency. The second and third inputs become the values in the third and fourth destination slots, respectively. The value written to the first slot comes from a separate global source read after the dependency returns.

This establishes a small initialization operation. Interpreting the destination as an allocated object, its first slot as a type tag, or its remaining slots as particular fields would require additional evidence.
