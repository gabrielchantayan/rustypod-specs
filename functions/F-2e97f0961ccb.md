## Acceptance examples

These examples are conditional static acceptance criteria, not executed tests.

1. **Entry ordering.** Given a readable incoming selector whose byte is 7, and an incoming write byte of 165, the first direct store writes byte 165 at address 24 before F-000000000001 is invoked.

2. **Fourth-argument boundary.** If the fourth argument is zero, its early selector read is at address 1. If it is the maximum unsigned 32-bit value, that read is at address 8192. Neither case is explicitly rejected.

3. **Fresh selectors across calls.** If the byte at a repeated selector-read address changes from 3 to 9 during an intervening dependency, the associated stores target addresses 20 and 26 respectively. Reusing the old selector would not match the represented reads.

4. **Byte truncation.** If a word used in a left-by-two byte store is 65, the stored byte is 4, because only the low eight result bits are retained.

5. **Word-slot addressing.** If a dependency-selected index is 3 and arithmetic does not overflow, its word-slot store begins at address 32 and writes four bytes. Its wide-stride slot instead begins at address 68.

6. **Bounded shift.** If an unsigned result is shifted right by 20 and retained, passing that retained quantity shifted right by 21 supplies zero for every possible original 32-bit value.

7. **Shared-state interference.** Clearing shared word A does not require a later read to return zero. If a dependency changes it before the later read, the function uses the changed value.

8. **Final ordering and failure.** If the final pointer write and shared-word assignment succeed but the 16-bit zero write fails, those earlier writes have already occurred. F-000000000003 has not yet been invoked.

9. **Null-target behavior.** If the environment makes address zero callable and that invocation returns, the represented function reaches its return. If that invocation traps, the representation supplies no recovery path.
