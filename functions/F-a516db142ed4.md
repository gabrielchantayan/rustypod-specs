# F-a516db142ed4

## Purpose

It compares the dependency’s first result with a 32-bit field read from the object after that call. Equality causes one additional invocation using a different temporary whose first 32-bit element is set to one. The selected invocation result is increased by 20 and returned.

The available evidence does not identify the object type or the dependency’s operation.
