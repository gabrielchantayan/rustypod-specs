# F-616a3e217b7c

## Purpose

F-616a3e217b7c advances a mutable, table-driven context toward a converted requested position. It can restart traversal, refresh table windows, apply interval adjustments, capture marker snapshots, emit marker metadata, and restore a selected snapshot at normal completion.

Seeking and time conversion are inferred purposes. Established behavior consists of the arithmetic, comparisons, dependency calls, and memory effects specified below.

The 32-bit result is 0 on normal completion or the sentinel exit, and 3 on specified refresh failures or interval exhaustion. Result 0 does not guarantee that the target was reached: the raw-position limit can also stop traversal.

## Interface

### Arguments and result

The visible interface accepts three 32-bit arguments:

1. **Context address:** addresses mutable state, descriptor pointers, and output pointers.
2. **Request address:** addresses a signed 32-bit requested position. It is read before any dependency call and conditionally overwritten at normal completion.
3. **Selection mask:** a 32-bit mask.

Mask bit 0 enables snapshot restoration. Independently, any nonzero mask permits final request writeback unless the initially observed first-value descriptor mode suppresses it.

No argument validation is visible.

## Behavior

### Preliminary operations and sentinel

After reading the request, call F-d9fe8636257c with the context. If its result is nonzero, call F-e20f2f20dc42 with the handle at `0x1bc` and zero, then reread that handle and pass it to F-12b428194529.

Next call F-3213a09e8d2f with the context. If nonzero, obtain a value from F-8b2d02fa1959, pass that value and zero to F-ce1ad0b83e05, then pass the same retained value to F-59abec8e3a9d.

Check `0xe4` against signed −1, followed conditionally by `0xe0`. If both equal −1, return 0 without conversion or direct request writeback. Preliminary effects have already occurred.

Otherwise, read the mode at `+4` of the descriptor referenced by `0x18`. If it equals 1, use zero instead of the original request. Retain this decision for final writeback suppression; later mode changes do not revise it.

### Conversion and restart decision

Before the first conversion call, retain the adjusted-position pair and signed scale.

Call F-1e0edc6e0bc9 with:

- The retained adjusted position multiplied by 1000, truncated to 64 bits.
- The retained scale sign-extended to 64 bits.

Only the low 32 bits of this result affect the restart decision.

Call the same dependency again with the signed 64-bit product of the effective signed request and the retained signed scale, and denominator words representing 1000. The signed 32-by-32-bit product fits in signed 64 bits. Retain the complete 64-bit result as the target.

Division is inferred, not established as a complete dependency contract.

Restart when the target is less than the retained pre-conversion adjusted position under unsigned 64-bit comparison, or when the first conversion result’s low word is zero. Dependency mutations cannot change these retained comparison operands or the scale used for target construction.

### Restart effects

On restart, perform these writes in order:

1. Stored cursor = 1.
2. 12-byte-record index = 0.
3. Secondary index = 1.
4. Within-record counter = 0.
5. Accumulated offset = 0.
6. Duration-record index = 0.

Then conditionally refresh, in order:

- First-value window through F-3563447b05c9 with context and zero, if its live base is nonzero.
- 12-byte-record window through F-bc4667302afc with context and zero, if its live base is nonzero.
- Duration window through F-58e3c92f2660 with context and zero, if its live base is nonzero.

After successful refreshes, clear the interval index. If the interval pointer is nonzero, call F-b1214ca19495 and ignore its result. Then clear adjusted-position low/high, raw-position low/high, duration repetition counter, and next-marker index, in that order. Interval bounds and adjustment are not directly cleared.

### Preparation and stopping

1. Stop if the live adjusted position is at least the retained target, using unsigned 64-bit comparison.
2. Otherwise stop if live raw position is at least the live raw-position limit, also unsigned.

### Marker capture

On equality:

- Increment the context marker index.
- Make the snapshot selectable.
- Capture, in order: 12-byte-record index, secondary index, within-record counter, accumulated offset, duration repetition counter, adjusted-position low/high, raw-position low/high, duration-record index, interval index, interval-start low/high, interval-end low/high, and interval-adjustment low/high.

At most one marker is captured per iteration. There is no nonnegative-index guard. Failure of the signed count guard prevents the marker-entry read.

### Table windows and retained values

Increment the private cursor after these checks, before interval and counter processing.

### Interval eligibility

Without an interval descriptor, the iteration is eligible to advance adjusted position.

With an interval descriptor, while both interval-start words equal −1:

1. Add the full interval adjustment to adjusted position modulo \(2^{64}\), storing low word before high word.
2. Increment the interval index.
3. Call F-b1214ca19495, ignoring its result.

No count check or termination bound is visible in this loop.

Then interpret only raw position’s low word as signed 32-bit and sign-extend it to 64 bits. Eligibility holds exactly when that derived signed value lies in the signed half-open interval from start, inclusive, to end, exclusive.

The stored raw-position high word does not participate. Retain eligibility through subsequent counter processing and metadata calls.

### Counter and record transitions

Compare the duration repetition counter with the current duration record’s first word as signed values. If smaller, increment the counter. Otherwise set it to 1, increment the duration-record index, and refresh the duration window if required.

Next increment the within-record counter. If the new signed value exceeds the current 12-byte record’s second word:

- Increment the secondary index.
- Refresh its window if required.
- Reload the retained secondary word.
- Clear accumulated offset.
- Set the within-record counter to 1.

Then advance the 12-byte-record index by at most one if it is below count minus one and the next record’s signed first word is no greater than the live secondary index. The next-record boundary is read before any refresh for the resulting index. Refresh that resulting window if required.

A refresh failure returns 3 after all preceding mutations.

### Advancement and final marker guard

If retained eligibility permits, read the signed increment from the then-selected live duration record and add it to adjusted position with sign extension and carry, modulo \(2^{64}\). Store low word before high word.

Read the duration increment again and always add it to raw position in the same manner. Counter rollover has already occurred; metadata dependencies or aliased stores may also have changed the selected record or its contents between reads.

Add the retained first selected value to accumulated offset.

If intervals are currently enabled, sign-extend the newly computed raw-position low word. If it is at least the live signed interval end:

- Increment the interval index.
- Return 3 if the new signed index is at least the interval descriptor’s signed count.
- Otherwise call F-b1214ca19495, ignoring its result.

Finally, apply a separate, guarded snapshot-invalidation check:

- Read the live next-marker index at `0xa4` and the signed marker count from the descriptor currently referenced by `0x40`.
- Only if the index is signed-less-than the count, read the indexed marker.
- Clear snapshot selectability only if that marker equals the incremented private cursor.

If the count guard fails, no marker entry is read and snapshot selectability remains unchanged. If the guard passes but the marker differs, selectability also remains unchanged. No nonnegative-index guard is visible.

Thus reaching the next marker can invalidate the previous snapshot before the next stopping check, but marker exhaustion alone does not invalidate it.

### Normal completion

If mask bit 0 and snapshot selectability are both set, restore the captured fields in capture order and select the captured cursor.

Store the selected private cursor at `0x88`. Convert live adjusted position using multiplication by 1000 and the live scale, even when request writeback is disabled.

If the mask is zero or the retained forced-zero decision is true, return 0 without direct request writeback. Otherwise write the conversion result’s low word to the request location and return 0.

## Side effects

Failures are nontransactional. Completed writes, metadata stores, and dependency effects remain observable.

Result 3 bypasses snapshot restoration, normal cursor storage, final conversion, and direct request writeback.

Restoration does not restore marker index, descriptor windows, metadata outputs, scale, limits, or unlisted state. Marker exhaustion can leave a captured snapshot selectable for this partial restoration.

The target and private cursor are retained independently of context mutations. Live fields are reread where specified.

No disjointness restriction is established for output arrays, request storage, and context memory. Aliasing can therefore affect later reads. Dependencies may cause additional effects even when no direct output write occurs. No synchronization guarantee is visible.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Sentinel:** If both sentinel words are −1 when checked, return 0 after preliminary operations, without conversion or direct request writeback.

2. **Cached restart operands:** Retained adjusted position is 100, target is 90, and the first conversion’s low result is nonzero. Restart occurs even if conversions change live adjusted position to 20. Target construction still uses the retained scale.

3. **Preparation stop:** If the first check after F-94bd82ad6ce8 observes adjusted position at least target, no marker capture or iteration occurs. Normal finalization still runs.

4. **Restart failure:** If the first required restart refresh fails, return 3 after the six initial reset writes, before later position clears.

5. **Mask distinction:** Mask 2 permits request writeback but cannot restore a snapshot. Mask 1 permits both, subject to the independent conditions.

6. **Aliased direct output:** If the position store changes the marker-index field, the value store uses the changed index.

7. **Selector rereads:** If conversion changes mode or marker index, the second selector receives the changed values. If the final selector changes accumulated offset, the offset store uses that changed offset.

8. **Duration rollover:** When repetition counter equals threshold, duration index advances before position additions. Without intervening mutations, the newly selected record supplies the increment.

9. **Low-word interval comparison:** Raw low word `0x80000000` supplies signed value −2147483648, regardless of raw high word.

10. **Exhausted marker list:** Suppose a snapshot is selectable, the live next-marker index equals signed count, and no earlier failure occurs. The final marker guard reads no marker entry and leaves selectability set. If normal completion follows with mask bit 0 set, the snapshot is restored.

11. **Next-marker invalidation:** If the signed count guard passes and the indexed marker equals the incremented private cursor, selectability is cleared. A subsequent stopping check can end traversal before that marker is captured.

12. **Interval exhaustion:** Exhaustion after advancement returns 3 with preceding position and offset updates retained, without normal finalization.
