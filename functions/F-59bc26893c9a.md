# F-59bc26893c9a

## Purpose

The supplied static representation describes a routine that interleaves indirect calls with two 32-bit memory writes and four byte writes. Its data flow includes index scaling, extraction of bit fields, and byte-selected destination addresses.

No application-level purpose is established. In particular, the evidence does not identify these writes as device operations, serialization, object initialization, or ordinary storage.

The visible path ends at an invalid-instruction boundary rather than a normal return. Because the supplied representation explicitly warns of invalid instruction data and truncated control flow, this contract distinguishes the visible operations from claims about valid executable behavior.

## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Initial word-store address.** With initial index 3, the first store writes the payload as a 32-bit word at `0x20`. F-000000000001 is subsequently called with 3 and 12. This requires the store and indirect call to be valid.

2. **Repeated selector reads remain observable.** Suppose the first source word is `0xABCDEF12`. If the first context-derived selector read returns `0x20`, the first byte store writes `0x48` at `0x31`. F-00000000000d receives `0xAF37BC48`. If the second selector read later returns `0x21`, the next byte store writes `0xBC` at `0x32`, not at `0x31`.

3. **Retained selector argument.** If the third context-derived selector read returns `0x7F`, the subsequent byte store targets `0x90`, and F-000000000019 receives `0x0000007F`. This argument remains the loaded byte even if the store aliases memory that held the selector.

4. **Second-source selector address.** With second source word `0x12345678`, its final selector-read address is `0x91A2B3C1` under the visible unsigned arithmetic. If that read returns 2, the final byte store writes `0x23` at `0x13`.

5. **Unsigned multiplication wraparound.** With context word `0x00002000`, multiplying by \(2^{19}\) wraps to zero. The first three selector reads therefore address `0x00000001`. Separately, the argument supplied as context word >> 3 is `0x00000400`.

6. **Failure preserves no transactional guarantee.** If the initial payload store succeeds but the first dependency fails to return, the visible routine provides no operation that restores the previous word. No later explicit store is reached.
