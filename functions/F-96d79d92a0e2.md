# F-96d79d92a0e2

## Purpose

F-96d79d92a0e2 conditionally updates a four-field shared state record and invokes associated dependencies. Before deciding whether to update that record, it processes two independent byte-sized indicators, clearing each active indicator before making its associated call.

The update decision depends on four calls to F-1d1b465375c3. If any of those calls returns nonzero, the function:

- Stores four possibly modified 32-bit input values into the shared record.
- Makes a fifth call to F-1d1b465375c3 using the fourth value and a 32-bit value of 65,536.
- Conditionally invokes one of two dependencies and then writes the record’s leading indicator byte.
- Invokes F-d0d21b1f4b75 with four values obtained from global reference storage.

If all four initial results are zero, those update-stage actions are skipped. The preliminary indicator processing and four initial dependency calls still occur.

This purpose is established as control flow and data movement. Any interpretation as graphics configuration, cache invalidation, resource management, or another domain operation is unestablished.

## Behavior

If it is nonzero:

1. The byte is written to zero.
2. F-90dc765b2896 is called with the designated global-derived argument.

The write precedes the call. Consequently, the dependency can observe the cleared byte if it reads that storage. There is no subsequent restoration or verification of that byte.

If the byte is already zero, neither the write nor this call occurs.

The state-record base is obtained only after this stage. If F-90dc765b2896 changes the global source of that base, the later capture can therefore use the changed pointer.

### 2. Capture the record and process its secondary indicator

It checks the byte at record offset 1. If nonzero:

1. That byte is written to zero.
2. F-3f358d6f0679 is called with the constant 7,424, represented as hexadecimal 0x1D00.

If the byte is zero, this write and call are skipped.

Again, the write precedes the call. A dependency may change the byte afterward; the function does not clear it a second time merely because it was initially active.

### 3. Perform four initial reference operations

1. With the address of the first local 32-bit value and the first global reference operand.
2. With the address of the second local value and the second reference operand.
