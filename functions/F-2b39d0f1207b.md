# F-2b39d0f1207b

## Purpose

F-2b39d0f1207b conditionally stores a 32-bit unsigned value at an address selected by a signed index and an external base address. It returns a 32-bit status indicating whether the store was accepted by its explicit checks.

The established acceptance conditions are:

- The signed index is less than 3.
- The unsigned value is less than 131,072.

Both conditions must hold before the store occurs. The function returns 0 after an accepted store and 9 when either condition fails.

The index check has no lower bound. Negative indices therefore pass that check. Describing this function as a setter restricted to three entries would misstate its behavior.

An apparent intent is to update one of a small number of 32-bit entries while restricting the stored value to 17 bits. That intent is an inference, not an additional validation rule or a guarantee about the destination’s allocation.

## Behavior

### Validation order

The function first evaluates the signed index against the exclusive upper limit of 3.

If the index is 3 or greater, it returns 9. The value-range condition and destination store are not reached on this path.

If the index is less than 3, the function evaluates whether the unsigned value fits in 17 bits. Equivalently, the accepted interval is 0 through 131,071 inclusive.

If the value lies outside that interval, the function returns 9 without the destination store.

Only after both checks pass does the function use the external base to select the destination and perform the write. This is the control-flow order established by the supplied representation; it is not a guarantee about speculative hardware activity or an exact instruction trace.

### Address selection and layout

The selected location has a four-byte stride relative to the external base:

- Index 0 selects the base location.
- Index 1 selects the location four bytes after the base.
- Index 2 selects the location eight bytes after the base.
- Index −1 selects the location four bytes before the base, provided the recovered address calculation has the expected interpretation for that input.

Each accepted operation writes one 32-bit unsigned value at the selected location. The function does not read the old destination value, combine it with the input, or preserve selected bits through a read-modify-write operation.

The four-byte stride and 32-bit access are established. Byte order is not established, so the individual bytes representing an accepted value must not be prescribed without additional platform evidence.
