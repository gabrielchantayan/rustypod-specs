## Behavior

### Normal operation

The established sequence is:

1. Write numeric value 1 to the one-byte field at offset `0x1E`.
2. Store the supplied four-byte value at offset `0x20`.
3. Return without an explicit result.

This sequence is unconditional. There is no visible branch based on the destination’s contents, the supplied value, or the flag’s previous value.

The first store is an assignment, not a bitwise update. A previous flag byte of zero, one, or any other value is replaced with 1. Other bits in that same byte are not preserved.

The second store replaces the entire four-byte field. It is not a partial update, increment, merge, comparison, or conditional assignment. A zero supplied value is still stored and does not prevent the flag from being set.
