# F-e54a36d39b7a

## Purpose

The supplied static representation describes an execution prefix that coordinates indirect dependency calls, transforms returned values, and performs byte and 32-bit memory accesses at calculated addresses.

No application-level purpose is established. The recurring offsets and scaling factors do not establish objects, arrays, hardware registers, allocation metadata, or any other storage model.

This contract covers only the represented prefix, conditional on its accuracy and executability. It does not establish normal completion or behavior beyond that boundary.

### Arithmetic conventions

## Acceptance examples

These are conditional deductions from the static representation, not executed tests. Each assumes execution reaches the relevant event and the stated arithmetic interpretation applies.

1. **Initial store and invocation count.** If \(A=3\) and the incoming auxiliary word is `0xAABBCCDD`, the first word store writes that value at `0x20`, after C005 and before C006. C002, C003, C004, and C005 must all precede it.

2. **Byte truncation.** If \(B=0x41\) and the first selector byte is `0xFF`, the first byte store writes `0x04` at `0x110`, not the wider value `0x104`.

3. **Selector-read ordering.** After C011, the represented order is C012, C013, C014, C015, then the read at \(64B+1\). Collapsing those calls into an optional or single invocation would not preserve the contract.

4. **Extracted byte.** If \(B=0x0AB00000\), the later byte store derived from \(B\) writes `0xAB`.

5. **Fourth input versus constant read.** If the fourth input has bit pattern 1, C023 receives `0x400` twice. After C024, the clearing selector is nevertheless read at address 1.

6. **Split result.** If C038 returns upper half 2 and lower half 1, the immediate zero store targets `0x1C`. The later lower-half-scaled store writes `0x04000000` at `0x10000014`.

7. **Distinct scaled locations.** For \(N_1=2\), \(P_1=8\). The stage’s first store targets `0x34`; the two reads feeding C059 target `0x1C`. Those reads are not guaranteed to obtain the stored value or equal each other.

8. **High-bit argument.** If \(R=3\), C099’s third argument is `0xC0000000`. If \(R=4\), it is zero. Replacing this argument with an unconditional zero is incorrect.

9. **Fresh final selector.** If the final selector location yields 2 on its first read and 7 on its second, the corresponding byte destinations are `0x13` and `0x18`. Reusing the first selector would change behavior.
