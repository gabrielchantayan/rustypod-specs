The observable contract is therefore a **conditional, source-facing description of the represented execution**, not a claim that the function implements a recognized data structure, protocol, allocator, or device operation.

For the conditional behavioral model below:

- \(S\) denotes the additional incoming address/register value.

- \(B(a)\) means an unsigned 8-bit read at address \(a\).

That last convention captures the apparent machine-level calculations; it is not a claim that every displayed signed operation would have defined semantics in a high-level language.

A **selector write through base \(a\)** means: read \(B(a+1)\), zero-extend that byte, then write one byte at the resulting address plus 17. The destination is consequently between addresses 17 and 272, inclusive. It is not a pointer-width read from \(a+1\).

A **word-to-byte copy at base \(a\)** means: read the full word \(W(a+116)\), then write its low byte at \(a+1\).

Neither notation implies an object type, allocation boundary, or ownership relationship.

## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Byte truncation.** If the value \(A\) in stage 2 is 255, the first byte stored at \(P+15\) is 252. The selector write immediately following stores the same byte.

2. **Selector width.** If a selector read returns 255, its destination is address 272. Adjacent bytes do not contribute to a wider pointer.

3. **Reread after a call.** If the first selector at \(1024P+1\) is 3 and an intervening dependency changes it to 9, the first selector write targets address 20 and the later write targets address 26.

5. **Captured selector.** If \(b=7\), the stage-11 three-argument call receives 14, 152, and 608. A later change to the original selector location does not change the already captured \(b\).

6. **Literal overwrite order.** If execution reaches both stage-11 literal writes, address 13 first receives \(b\), then later receives 192. Intervening calls may observe or modify that location.

7. **Fault boundary.** If a required word read faults, no successful completion or rollback is established. Earlier calls and writes may already have occurred.

8. **Endpoint.** Reaching the represented endpoint is not acceptance of a normal return; the supplied representation terminates at invalid instruction data.
