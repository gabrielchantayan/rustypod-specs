# F-2c7931f41334

## Purpose

F-2c7931f41334 conditionally exports a 16-byte region of a caller-supplied object, invokes an operation on that region, clears an adjacent one-byte flag, and returns a 32-bit outcome indicator.

- Return **0** when F-ddca41e891a8 returns a nonzero result and the flag subsequently read at object offset **0xEC** is zero.
- Otherwise, optionally copy four 32-bit words to the supplied output destination, invoke F-ca73cb512206, clear the flag, and return **1**.

Both normally returning paths begin with F-338d16f9ce72 and end with F-1333331b2da1, each receiving the address at object offset **0xD4**.

- **Nonzero result, zero flag:** take the rejection path.
- **Nonzero result, nonzero flag:** take the export/consume path.
- **Zero result:** take the export/consume path without a conditional read of the flag.

The flag comparison is an exact zero-versus-nonzero test on one byte. Every nonzero byte value has the same effect on this decision; there is no visible restriction to a value of one.

### Export/consume path

If the rejection condition does not hold, a nonnull output address causes a four-word export.

The source-level access order visible in the supplied body is significant:

1. Read the 32-bit word at object offset **0xE0**.
2. Read the 32-bit word at object offset **0xE4**.
3. Read the 32-bit word at object offset **0xE8**.
