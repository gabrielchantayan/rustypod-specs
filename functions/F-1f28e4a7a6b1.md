### Result transformation

Bit zero is the least significant bit. The transformation has these properties for the unsigned value v:

- If bit zero is clear, it becomes set.
- If bit zero is set, it becomes clear.
- Every other bit retains its value.
- An even value becomes the next larger odd value.
- An odd value becomes the preceding even value.

The parity descriptions are consequences of toggling bit zero, not separate arithmetic operations required of an implementation.

The transformation cannot overflow the W-bit unsigned range. An even value cannot be the maximum unsigned value, because that maximum has bit zero set. An odd value is at least one, so clearing its least significant bit cannot underflow.

The mapping exchanges neighboring pairs: zero with one, two with three, and so on. In particular, it has exactly one input value that produces zero: v equal to one.

Applying this mathematical transformation twice to the same W-bit value restores that value. This does **not** imply that two calls to F-1f28e4a7a6b1 cancel each other: two calls invoke F-064aa06b1650 twice, and those invocations may return different values or change state.
