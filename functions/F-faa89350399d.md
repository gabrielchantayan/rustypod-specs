## Acceptance examples

These are conditional static acceptance cases, not executed tests. They assume dependencies return normally and permit the stated accesses.

1. **Allocation failure does not short-circuit allocation.**  
   If the first request returns null and the remaining three succeed, all four requests occur. Successful blocks are initialized and cleaned up in reverse allocation order. Result: 4. Neither control predicate executes.

2. **Rejection observes a late global value.**  
   Suppose the return global contains 9 at function entry, but a preceding allocator or the initial predicate changes it to 23. If all allocations succeed and the initial predicate returns 2, the function reads and returns 23 at the immediate return site. It does not return the entry-time 9. No ordinary cleanup executes.

3. **Rejection can numerically resemble success.**  
   If the initial predicate rejects and the global contains zero at the return-site read, the result is zero despite bypassing transfers and cleanup. This is distinct from the ordinary successful path.

4. **Direct-transfer success.**  
   If both predicates return 1 and all three transfers return zero, result 0 follows ordinary cleanup. No iterative transformation occurs.

5. **Partial transfer failure.**  
   If the first transfer succeeds and the second returns 7, the third is not called. Result: 1 after cleanup. The first transfer’s effects are not undone.

6. **Preparation comparison uses exact −1.**  
   Result −1 requires the checked Scalar B operation and another comparison. Result −2 instead ends the preparation comparison loop.

7. **Advancement accepts any nonzero terminal result.**  
   Immediately after successful composition, a Scalar B test result of 2 selects result 0 without another Destination transformation.

8. **Source selection treats 2 differently.**

9. **Negative status is still failure.**
