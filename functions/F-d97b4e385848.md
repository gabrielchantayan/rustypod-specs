## Acceptance examples

These are conditional static consequences, not runtime observations. Each assumes that preceding operations complete and all relevant accesses and calls are valid.

1. **Initial store and reads use different scaling.**  
   With **A = 0x100**, the initial word store writes **0x100** at **0x414**. Both read expressions for **F-I01** address **0x114**, not **0x414**.

2. **The captured word need not equal the preceding stored word.**  
   With **R6 = 3**, the corresponding store writes **12** at **0x44**. The following read obtains **V** from **0x20**. It is not required to return 12.

3. **Unsigned shifting preserves no sign extension.**  
   With **V = 0xABCDEF01**, the later word store at **S7 + 0x14** writes **0x000ABCDE**.

4. **Bit-derived arguments use R7 and S7.**  
   With **R7 = 3**, **S7 = 12**. The first argument to **F-I41** is **0x30000**, and its third argument is **0xC0000000** under the low-32-bit interpretation. The second argument depends on **R8**.

5. **The fourth input is narrowed by its shift.**  
   Under the low-32-bit interpretation, **B = 1** and **B = 65** both produce **0x04000000** as the third argument to **F-I11**. This does not establish that either input is valid for the target.

6. **Both byte stores can select one destination.**  
   With **Q = 0x12ABCDEF** and both selector reads returning **0x20**, the first store writes **0xBC** at **0x31**. The second writes **0x2A** there. The second direct write replaces the first direct value, absent other effects.

7. **A changed selector changes the second destination and later argument.**  
   With the same **Q**, a first selector of **0x20** and second selector of **0x40** produce byte destinations **0x31** and **0x51**. **F-I63** receives **0x40** as its second explicit argument, even if an intervening callee changes the selector memory again.

8. **Partial execution has no visible rollback.**  
   If an early indirect call does not return, later operations need not occur. Stores already completed are not visibly undone.
