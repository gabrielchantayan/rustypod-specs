## Acceptance examples

These examples are conditional static requirements, not executed tests.

### Third-argument width

For input `0x00000100`, conditional 32-bit shifts produce zero for the shift-by-24 and low-byte-shift-by-5 contributions, but `0x00040000` for successive shifts by 3 and 7.

Truncating the entire input to one byte would violate the latter contribution. For input `0xFFFFFFFF`, the low-byte-shift-by-5 contribution is `0x1FE0`, and the shift-by-24 contribution is `0xFF000000`.

### Unsigned widening and narrow stores

If a reached unsigned byte read yields `0xFE`, its widened word is `0x000000FE`, not `0xFFFFFFFE`.

An 8-bit write changes only its addressed byte under ordinary byte-addressed memory semantics; it does not authorize replacing an enclosing word.

### Association-base snapshot timing

If the four adjusted-region `0x20` writes change the separate global through aliasing, the association-base load sees the state after the fourth write. If the later fixed `0x60` store changes that global, associations still use the already saved base.

### Post-association snapshot timing

If the fixed `0x3A` byte store overlaps the doubled-region `0x14` word, the subsequent snapshot includes that byte mutation according to the environment’s byte order. The earlier `0xA9` and link-region `0x74` snapshots are not retroactively changed.

### Fresh `0x67` reads

Assume ordinary mapped memory, no concurrent modification, a saved `0xA9` word whose low byte is `0xAB`, doubled-region offset `0x09` equal to address `0x67`, and an adjusted-region address whose low byte is `0x38`.

If no other intervening access changes `0x67`, the copy to `0x21` and the second fresh read obtain `0xAB`. The intervening doubled-region `0x09` store then writes `0x38` to `0x67`, so the third fresh read obtains `0x38`. The adjusted-region destination may be overwritten again later.
