The established behavior is orchestration, not a known higher-level operation. The available evidence does not establish whether the dependencies format data, perform I/O, access a device, or implement another service.

The central observable rules are:

- F-360d49b83f75 is called first, with a selector determined by whether the context field at byte offset 2 equals `0x482B`.
- F-f26976f63516 is called afterward, using a four-byte context field at byte offset `0x158` and the same 520-byte temporary region supplied to the first dependency.
- If the third public argument is zero, the fourth public argument is replaced with a four-byte zero for the second call.
- A second-dependency result equal to `0x20` is returned as `0x30`. Every other normally returned result is passed through unchanged.
