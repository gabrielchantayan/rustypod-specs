# F-d32b2075c9a4

## Purpose

F-d32b2075c9a4 reports the zero-based position of the most significant set bit in an unsigned integer. It returns zero for both zero and one.

For every positive input, the result is the unique integer \(k\) satisfying:

\[
2^k \leq \text{input} < 2^{k+1}.
\]

The zero-input result is an explicit boundary behavior, not a mathematical logarithm of zero.

**Established static evidence:** The supplied representation compares an unsigned input against one, repeatedly shifts qualifying inputs right by one bit until zero, and derives its result from the number of shifts.

In particular, it does not return the number of bits needed to represent a positive input; that quantity is one greater than this function’s result.

## Behavior

### Boundary inputs

For input zero or one, the function returns zero without entering the repeated-shift path.

This includes zero even though zero has no set-bit position. Consumers requiring a distinct “no set bit” outcome must distinguish zero themselves; this function does not provide such an outcome.

### Inputs greater than one

For a qualifying input, the function repeatedly performs a one-bit unsigned right shift until the working value becomes zero. It counts those reductions and returns one less than their total.

Because the input is unsigned, the right shift introduces zero bits at the high end rather than extending a sign bit. For any positive \(W\)-bit value, repeated shifts reach zero after at most \(W\) reductions.

The externally meaningful result depends only on the position of the highest set bit. Lower set bits do not affect it. Consequently:

- Every representable value in \([2^k, 2^{k+1}-1]\) returns \(k\).
- An exact power of two returns its exponent.
- Incrementing a value changes the result only when the increment reaches a new power of two.
- The result is nondecreasing over the unsigned input domain.
- Zero and one deliberately share the same result.

The interval expressions above describe mathematical values; they do not require a caller or implementation to evaluate \(2^{k+1}\) in the input type. At the top of the input range, that mathematical upper bound may not itself be representable.

### Arithmetic constraints

Each shift distance is exactly one. There is no shift by the full input width and no shift distance derived from the input.

The largest intermediate count is \(W\), whereas the largest returned result is \(W-1\). The signed arithmetic must therefore be capable of representing \(W\), not merely the maximum result.

For a 32-bit input with ordinary 32-bit signed arithmetic, the maximum intermediate count is 32 and the maximum result is 31; both are representable. No signed overflow occurs under that interpretation.
