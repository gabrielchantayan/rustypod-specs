### Conditional gate

- The observed source field is nonzero.
- The control value is nonzero.

If either condition is false, the function performs no further local field access and returns the saved result.

### Conditional copy

If the inspected destination-associated field is zero, the function calls F-fdd8589eca2d a third time overall.

It then rereads the two-byte source field at input base plus `0xEA` and writes that value to the two-byte field at offset `0x80` from this latest dependency result.

Two distinctions are part of the contract:

- **The destination is obtained again.** The final write uses the result of the third call, not the result used for the zero check.
- **The source is read again.** The final write uses the source value observed after the third call, not the value that originally passed the nonzero gate.

The final destination is not independently checked for zero. If the second and third calls return different bases, the function may inspect one object and write another.

Likewise, the copied value need not remain nonzero. If an intervening dependency call changes the source field to zero, the wrapper writes zero after the earlier nonzero gate has already succeeded.
