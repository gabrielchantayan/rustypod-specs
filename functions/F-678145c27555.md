# F-678145c27555

## Purpose

F-678145c27555 is represented as a sequence of indirect calls interleaved with byte and 32-bit memory accesses. It transforms call-produced values through scaling, masking, shifting, and indexed stores. The supplied representation ends at an explicitly reported invalid-instruction boundary, not at an ordinary return.

No application-level purpose is established. In particular, the evidence does not establish that the accessed locations are ordinary objects, device registers, allocated records, or valid memory.

This contract distinguishes:

- **Established static evidence:** operations and ordering explicitly present in the supplied representation.
- **Inferred interpretation:** a 32-bit machine-level interpretation of the arithmetic.
- **documented_only unknowns:** unresolved calling conventions, dependency behavior, memory validity, and execution beyond the invalid-instruction boundary.

The behavioral requirements below are conditional on execution reaching each operation. They do not establish that the represented path is executable.

## Acceptance examples

These are conditional specification examples, not executed tests.

1. **Byte-selected destination.** If the first selector read yields 255 and the incoming byte is 171, the first direct store writes byte value 171 at address 272. It does not write at the incoming base plus 17.

2. **Third-argument address equivalence.** Under 32-bit wrapping arithmetic, third-argument bit patterns zero and 64 both produce read address one for the zero-byte update. If that read succeeds and returns seven, the subsequent store writes zero at address 24.

3. **Fourth-argument truncation.** A fourth-argument bit pattern of 2²² produces zero in both shifted arguments under the wrapping interpretation. An implementation using an unbounded arithmetic product would not match that interpretation.

4. **Masked extraction.** If low half is all one bits, the masked-and-shifted word value is 1,048,575. Shifting the original low half right by nine would yield a different result.

5. **Captured-word extraction.** If the separately captured word is 2,882,400,000, the later extraction store contains that value shifted logically right by 12. Intervening calls do not cause the represented operation to reread the word.

6. **Changing final selector.** If the first final selector read returns three and the later reread returns nine, the two byte stores target addresses 20 and 26 respectively. Reusing the first selector would change observable behavior.

7. **Aliasing.** If an earlier store changes a location subsequently read as a selector or word, the later read observes memory at its own execution point, subject to the actual memory model. The contract does not permit treating all reads as observations of entry state.

8. **Early failure.** If an indirect call does not return, later direct stores are not reached. Successful completion of earlier stores does not imply completion of the entire represented path.
