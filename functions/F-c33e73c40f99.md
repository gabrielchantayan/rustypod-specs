## Acceptance examples

These examples are conditional static consequences, not executed tests.

### Width-sensitive transformation

If `0x12345678` undergoes an eight-position left shift under conditional 32-bit arithmetic, the result is `0x34567800`. A subsequent unsigned eight-position right shift produces `0x00345678`, not the original word.

### Compact-base boundary

If the compact-index input is `0x0000007F`, shifting and masking produces `0x7F00`. Unsigned right shifting by six yields 508; doubling yields compact base 1016. This establishes arithmetic, not address validity.

### Converted global is not necessarily a byte

If the missing declaration makes the global at `0x05` a signed source whose value is −1, conversion to 32-bit unsigned form produces `0xFFFFFFFF`. Under conditional 32-bit address arithmetic, adding `0x54` produces `0x00000053`.

That case cannot be rejected solely by asserting that the source was an unsigned byte. Whether the declaration permits it and whether the resulting access succeeds remain documented_only.

Conversely, if a supplied declaration establishes an unsigned 8-bit source containing `0xE1`, its converted base is 225. That range follows from the additional declaration, not from the conversion alone.

### Explicit unsigned-byte publication
