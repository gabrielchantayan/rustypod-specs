# F-509760e56f35

## Purpose

For stable ordinary memory, let the original words at increasing addresses be W0, W1, W2, and W3. The resulting bytes, at offsets 0 through 7, are:

| Offset | Resulting byte |
|---|---|
| 0 | High-order byte of W3 |
| 1 | Low-order byte of W3 |
| 2 | High-order byte of W2 |
| 3 | Low-order byte of W2 |
| 4 | High-order byte of W1 |
| 5 | Low-order byte of W1 |
| 6 | High-order byte of W0 |
| 7 | Low-order byte of W0 |

This is a numeric word-to-byte transformation. Calling it an unconditional eight-byte reversal would overstate the evidence: that description is correct when the input words are loaded using little-endian byte order. With big-endian word loads, the operation reverses the order of the four two-byte groups without reversing the bytes inside each group.

## Behavior

### Stable-memory transformation

The function first retains the original values of the first two 16-bit words. Those retained values supply the final four output bytes, even though the first four bytes of the input region are overwritten earlier.

The remaining two words are read from their original positions while the transformation is in progress. Each is read separately for its high-byte and low-byte extraction; neither is explicitly retained as a single full-word snapshot for both output bytes.

Under stable ordinary memory, these distinctions do not change the result. They do matter when specifying the expressed access sequence or considering independently changing storage.

For a 16-bit word with unsigned value V:

- Its high-order byte is the integer quotient of V divided by 256.
- Its low-order byte is the remainder of V divided by 256.

Both results lie in the range 0 through 255. Bit patterns with bit 15 set are handled by unsigned high-byte extraction, not by sign extension.
