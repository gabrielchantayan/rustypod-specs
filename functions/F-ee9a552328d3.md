# F-ee9a552328d3

## Purpose

It produces two distinct outputs:

- A 32-bit return value, explicitly either **0** or **1** on every visible normal-return path.
- Writes to a caller-supplied one-byte destination. The function first writes **0** and, on selected paths, later writes **1**.

These outputs are not equivalent. In particular, a normal return of **1** can occur without an explicit write of **1** to the byte destination.

The established behavior is the call order, branch structure, explicit memory writes, and normal-path cleanup described below. The semantic meaning of the input, comparison references, and secondary probe is unknown. Interpreting the function as a classifier with an additional context-dependent check is inferred intent, not an established domain contract.
