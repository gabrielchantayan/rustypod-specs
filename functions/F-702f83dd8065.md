## Acceptance examples

These are conditional static examples, not runtime observations.

1. **Zero fourth input.** If execution reaches the fourth-input-derived write with \(P=0\), the function attempts a 32-bit zero write at address 20. F-U011 receives zero. The later masked-and-shifted write also stores zero. The evidence does not justify rejecting this input first.

2. **Unsigned wraparound.** With \(P=\text{0xffffffff}\), the fourth-input-derived write targets address \(\text{0xf0000014}\) and stores \(\text{0xfc000000}\), under 32-bit unsigned arithmetic. The masked-and-shifted value is \(\text{0x000fffff}\).

3. **Distinct scaled addresses.** If \(R_{20}=1\), the word write after F-U020 targets address 36 and stores 4. The two subsequent word reads target address 24. An implementation that reads back address 36 instead would not match the represented behavior.

4. **Two distinct read results.** If the two reads before F-U021 observe different values, its first argument derives from the read used by the right-shift expression and its third from the read used by the left-shift expression. Which read occurs first remains unspecified.

5. **Byte truncation.** If \(U=\text{0x12345678}\), the first byte write stores \(\text{0xe0}\), and the second stores \(\text{0x23}\). The destination for each still depends on its own byte read.

6. **Changing byte destinations.** If the first byte-source read returns 5 and the second returns 9, the writes target addresses 22 and 26 respectively. F-U083 receives 9 as its second explicit argument.

7. **Interrupted execution.** If F-U036 does not return, the preceding write at \(B_{35}+20\) has already been attempted, but no subsequent operation in this function is reached. No cleanup path is shown.
