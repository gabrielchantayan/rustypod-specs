# F-1654b76744c9

## Purpose

F-1654b76744c9 conditionally reverses the order of the four bytes in an unsigned 32-bit value.

The first input selects the behavior. A selector equal to exactly one requests byte reversal. Every other selector value requests an unchanged result.

The operation concerns the numerical positions of bytes within a value. It does not read a byte buffer, inspect the machine’s byte order, or perform memory-based serialization. ## Behavior

### Selection

The selector is compared with exactly one.

If it differs from one, the function returns the unsigned value unchanged. This applies to zero, negative selector values, and positive selector values other than one, provided those values are representable by the selector’s declared type.

If it equals one, the function returns the byte-reversed result.

There is no rejection of an unrecognized selector and no normalization to a Boolean value. In particular, a selector of two does not request reversal merely because it is nonzero.

### Reversal

Under the 32-bit interpretation, reversal relocates each of the four input bytes to the opposite position in the result.

The least significant input byte occupies result bits 24–31. The next byte occupies result bits 16–23. The next occupies result bits 8–15. The most significant input byte occupies result bits 0–7.

The supplied expression combines the four contributions using exclusive-or. Their result bit ranges do not overlap under this interpretation, so combination cannot cancel a bit contributed by another byte. The resulting observable behavior is byte relocation, not a checksum or a general mixing operation.

All shifts operate on unsigned values. Consequently:

- Right shifts introduce zero bits rather than replicating a sign bit.
- Left-shifted bits outside a 32-bit unsigned result are discarded.
- A set high bit does not make the input negative.
- No signed arithmetic overflow is involved in the reversal.

The shift distances are eight, sixteen, and twenty-four bits. All are less than a 32-bit operand width. The masks used for the middle bytes restrict the selected portions before their final placement.

### Boundary behavior and invariants

Zero remains zero in either selector branch. An input with every bit set also remains unchanged after reversal.

Values whose outer bytes match and whose inner bytes match are unchanged by reversal. Such an unchanged result does not demonstrate that the identity branch was selected.

For a fixed selector and value, the visible definition produces a deterministic result. It does not consult ambient state.

Under the 32-bit interpretation, applying the function twice with selector one restores the original value. Reversal changes byte positions but preserves the contents of every byte and the total number of set bits.
