# F-2e3236133452

## Purpose

F-2e3236133452 reports whether two designated bits in a shared value are both set.

The established predicate concerns bit positions 10 and 11, numbering the least significant bit as position 0. Their combined mask is hexadecimal `0xC00`, or decimal 3072. The result is true exactly when both positions contain one. It is false when either or both contain zero.

The meaning of these positions is not established. Interpreting them as readiness flags, hardware status, permissions, or completion indicators would require additional evidence. The contract therefore describes a bit-state query, not a higher-level readiness or validity check.
