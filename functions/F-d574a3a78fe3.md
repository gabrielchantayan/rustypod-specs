# F-d574a3a78fe3

## Purpose

F-d574a3a78fe3 copies four 32-bit fields from a caller-supplied memory region into caller-supplied destinations, then writes ten fixed values to additional destinations. It returns a 64-bit value formed from the first two argument values, not from the copied data.

The established behavior is a sequence of memory transfers and constant writes. The meanings of the source fields and fixed values are not established. Describing them as dimensions, flags, format identifiers, or status values would introduce unsupported semantics.

The operation is not necessarily a snapshot. Source reads and destination writes are interleaved, so overlapping destinations can affect later source reads.

### Aliasing and overlap

The contract does not require distinct destinations. Overlap changes the resulting memory according to the established access order.

A write to destination argument 2 occurs before the second source read. If that destination overlaps the source field at offset 196, the second copied value can reflect the first write rather than the source region’s entry-state contents. Corresponding effects are possible for the later source reads.

When destinations overlap each other, later writes replace the overlapping bytes written earlier. An 8-bit destination write affects only its addressed byte; it does not clear or initialize an adjacent 32-bit quantity.

The first four source reads precede all fixed-value writes. Consequently, a fixed-value write can modify the source region’s final contents if it aliases that region, but it cannot alter a source value already read by this invocation.

No temporary copy of the complete source region is established.
