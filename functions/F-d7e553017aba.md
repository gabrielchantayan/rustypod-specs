# F-d7e553017aba

## Purpose

The first dependency is selected by a nonzero field at byte offset 16 together with a nonzero value conditionally captured from byte offset 4. The second dependency is selected by the field at byte offset 0, read after the first dependency has returned if it was invoked.

The established behavior is conditional dispatch. Resource cleanup, destruction, reference counting, and object initialization are possible interpretations, but none is established by the supplied evidence. In particular, the wrapper does not itself establish that either dependency releases memory.

## Behavior

### First selection phase

It reads the object’s field at offset 16. If that read produces a nonzero value, it reads the field at offset 4 and retains that value for the following selection decision. If the offset-16 value is zero, the offset-4 read is skipped and the captured value remains zero.

The wrapper then evaluates a second test of the field at offset 16. F-58ba61416cc9 is invoked only when both of the following hold:

- This second offset-16 test is nonzero.
- The previously captured value is nonzero.

The captured value is not refreshed during this decision. With stable object contents, this selects F-58ba61416cc9 precisely when both the offset-16 field and the offset-4 field are nonzero.

The supplied representation contains two evaluations of the offset-16 field. They must not be described as an explicitly single cached read. Its dependencies are potentially side-effecting. The supplied evidence does not establish whether they:
