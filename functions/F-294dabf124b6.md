# F-294dabf124b6

## Purpose

F-294dabf124b6 exposes a sequence of external invocations and memory updates. Its established effects include publication of 32-bit values into computed locations, byte updates selected through memory, two samples of one global word, two replacements of another global word, and a terminal invocation of address zero.

No application-level purpose is established. Repeated scaling and fixed offsets could indicate encoded references or structured state, but those interpretations are **inferred intent**, not requirements.

This contract describes the supplied static representation. It does not establish that the recovered interface or control flow matches an executable, that any computed address is accessible, or that execution can complete.

## Behavior

### Ordering and dependency boundaries

The represented body is straight-line: no explicit branch, loop, validation, status check, or recovery path appears.

The memory effects described below occur in their stated relative order. External invocations separate many of them. An implementation conforming to this representation must not combine fresh reads, move accesses across intervening calls, or assume those calls leave memory or globals unchanged.

The descriptions “retained,” “cached,” and “sample” identify values already obtained. They do not authorize rereading their original locations. Conversely, an explicitly repeated read remains fresh.

### Initial publication and input-dependent updates

The first invocation receives the first input. Its target is derived from incoming control-flow state by addition of 4094. Four further invocations precede the first explicit memory write.

That first write publishes the incoming register word at an indexed word location selected by a call result. The following call receives four times that index, without the additional 20-byte offset.

The next input-dependent effect is a selector update:

- The selector address is the third input logically shifted right by one, plus one.
- The written byte is the low eight bits of a byte-valued call result shifted left by two.

The fourth input establishes a separate narrowed value: its logical right shift by 22. One invocation receives, in order, that narrowed value, the unchanged fourth input, and the narrowed value again. A later invocation receives a forwarded call result followed by two copies of the narrowed value.

After further calls, a selector read at the narrowed value plus one directs a zero-byte write. The subsequent call receives a newly obtained result shifted left by two.

Another shifted call result is retained for a sparse clear. A later unsigned result becomes a retained reference word, and another result becomes a retained base. Before any explicit access relative to that base, a zero byte is written at the earlier shifted result multiplied by 8192, plus nine. This sparse clear is not relative to the retained base.

A call then receives the retained base, the reference word shifted right by 22, and the unchanged reference word. Following additional invocations, a 64-bit result is obtained. The next memory effects are a byte write of the retained base’s low eight bits at retained base plus nine, followed by a word read at retained base plus 52. The next call receives the 64-bit result’s low component shifted left by two, its high component, and that loaded word.

### Word publication and narrowing

The retained base is published twice more before it ceases to be relevant:

- First, an indexed word location selected through a secondary result register receives the retained base. A word is then read at that secondary value plus 20, **without scaling the value by four**. The secondary value is subsequently supplied to a call.
- Later, another call-selected indexed word location receives the retained base. A word is then read at the preceding loaded word shifted right by 22, plus 20.

The second loaded word controls a new publication. Its logical right shift by one selects an indexed word location, which receives a new call result shifted left by two. Only after that write does the function read a word at the unshifted loaded word plus 20. The shifted index is then supplied to a call.

A later indexed word location receives the same shifted call result. The first global-source sample follows this write.

Two independently narrowed values now matter:

- The most recent chained word read, shifted right by 22.
- The first global-source sample, shifted right by 23.

The narrowed chained word is published first through a secondary-result-selected indexed location and later through a call-result-selected indexed location. Between those publications, an invocation receives the secondary value twice, followed by the narrowed global sample and the narrowed chained word.

The narrowed global sample is itself shifted right by 23 again. Because its original width is 32 bits, the second shift necessarily produces zero. Subsequent publications include:

- A zero word at an indexed location selected by an unsigned secondary result.
- Another zero word at a later call-selected indexed location.

The unsigned secondary result from the first of these publications is also retained for a word-read address. Its low 29 bits, shifted right by 19 and then increased by 20, determine that address. Intervening calls do not replace this retained value with a newer secondary-register result.

### Low-address selection and first global replacement

The word obtained through the masked address is narrowed by logical right shift by 22. Its low byte is written through a selector read at absolute address 1. That selector address follows from the established double-shift-to-zero result, not from an assumption about the global source’s contents.

The following invocation receives three copies of another secondary-register value and a fourth argument of zero. A later invocation receives zero.

After further calls, another selector address is formed from four times the narrowed loaded word, plus one. Its selected destination receives a zero byte. Subsequent calls receive first one shifted result and later two copies of a separately obtained result shifted left by two.

Two further zero-byte selector updates use fresh reads of address 1, with calls between them. The first is followed by capture of a secondary-register value retained as a control value; a call receives that value three times. A subsequent result-forwarding call also receives a separate unsigned call result shifted right by 23. That argument is not established to be zero.

The second fresh selector value from address 1 is retained as a small base. Following further calls, a new result replaces the global destination word. The same result is supplied to a call, another call occurs, and then a word-to-byte copy uses the small base: the word at small base plus 116 supplies the low byte stored at small base plus one.

A call subsequently receives the retained control value shifted left by 11. A later 64-bit result is forwarded as separate low and high components, accompanied by the **retained value previously written to the global destination**, shifted right by 23. The global destination is not reloaded for that argument.

### Repeated copies, cached data, and link publication

A call-derived index scaled by four establishes a copy base. A word-to-byte copy occurs at that base. After intervening calls produce another index, the copy is repeated at the **same base**, with a fresh word read.

The newer index shifted left by two becomes a retained link value. A subsequent invocation receives:

- The retained control value shifted left by 12.
- The retained link value twice.
- The newer index shifted left by 18.

Another call-derived index, scaled by four, establishes a different copy base. The word read at that base plus 116 is cached, and its low byte is written at that base plus one.

The cached word then participates in later full-width publications:

| Relative order | Required effect |
|---|---|
| First | Store the cached word at a call result multiplied by 16, plus 20. |
| Later | Store the cached word at a call-selected indexed word location. |
| Later still | Store a new call result shifted left by two at the retained link value masked with `0xfffffffc`, plus 20. |
| Subsequently | Store zero at another call-selected indexed word location. |

Between the first two publications, a relevant invocation receives the retained link value logically shifted right by two and then left by 16. It is not equivalent in general to shifting an assumed original, untruncated index.

The shifted result used in the link-relative store is also supplied twice to an invocation.

A later 64-bit result establishes another link from its low component shifted left by two. Its high component selects an indexed word location receiving that link. The second global-source sample occurs after this publication.

The next relevant invocation receives the new link, the high component, and two additional copies of the link. After further calls, another indexed word location receives the same link. A word is then read at the **retained second global-source sample** plus 20. This access does not reload the global source.

### Final updates and termination boundary

A final 64-bit result supplies a low and a high component. Before its components are forwarded, a selector read at the cached word shifted right by 23, plus one, directs a byte write containing the low eight bits of the word loaded through the second global-source sample.

The following invocation receives three copies of the final high component and the final low component shifted left by two.

After further calls, another selector update uses the final low component masked to 30 bits, shifted right by 21, plus one. Its written byte is the low eight bits of the previously loaded word shifted right by 22.

Subsequent calls consume another result shifted left by two, and later two copies of a separately obtained shifted result. Further invocations include result forwarding and produce a final byte-valued result and a pointer exposed through a secondary result register.

The terminal memory effects and control transfer have this strict order:

- A zero byte is written through that pointer.
- The three-byte quantity associated with address 9 is consumed to form the upper 24 bits of the replacement global-destination word; the final byte-valued result supplies its low eight bits.
- A zero halfword is stored at the final low component masked to 30 bits and logically shifted right by seven.
- Address zero is invoked with three explicit zero arguments.

An apparent return follows only if that invocation returns. The pointer-directed clear precedes evaluation of the three-byte quantity, so aliasing can affect the final global value.

## Acceptance examples

These are conditional consequences of the static representation, not executed tests. Arithmetic examples assume the relevant operations and addresses are valid.

- **Input-derived selection:** With third input 100, the early selector address is 51. A selector byte of 7 and relevant byte-valued result of 3 require byte value 12 at address 24.

- **Fourth-input narrowing:** Fourth input `0x00800000` narrows to 2. Its selector address is 3. Selector value 255 directs the zero-byte write to address 272.

- **Scaled versus unscaled access:** A secondary value of 8 requires the retained-base publication at address 52, followed by a word read at address 28. Substituting either address for the other violates the contract.

- **Aliasing after publication:** When a chained publication overlaps the following unscaled word-read location, the read occurs after the publication. It cannot be evaluated using a pre-write snapshot merely because the accesses were described as different roles.

- **Double-shift collapse:** Every unsigned 32-bit first global-source sample yields zero after two successive right shifts by 23. The associated later word publication stores zero, and the associated selector address is 1.

- **Fresh repeated copy:** If the first word read at a copy base plus 116 yields `0x12345678`, the byte copy stores `0x78`. If an intervening call changes that word to `0xabcdef01`, the repeated copy stores `0x01`.

- **Independent global samples:** If the source global changes between its two samples, the later word-read address uses the second retained sample plus 20. Neither the first sample nor an additional fresh global read is interchangeable with it.

- **Terminal aliasing:** If the terminal pointer clear changes storage contributing to the three-byte quantity, the final global replacement uses the quantity after that clear. With contributing upper value `0x123456` and final result byte `0xab`, the assembled word is `0x123456ab`.

- **Termination failure:** A fault on the zero-address invocation occurs after the terminal global replacement and halfword clear. The contract provides no rollback of those effects.
