# F-6c4993504605

## Purpose

F-6c4993504605 copies one four-byte field within a caller-supplied memory region into the immediately following four-byte field.

The established behavior is a raw field copy, not a numeric conversion, increment, exchange, or ownership transfer. The source field is not explicitly modified. The previous contents of the destination field are overwritten without being read or released.

Interpreting the fields as “current” and “previous” values, pointers, counters, or application state would be inferred intent rather than established behavior.

## Behavior

For a valid invocation in ordinary memory, the routine obtains the 32-bit contents at base plus 44 and stores those contents at base plus 48.

The established logical order is:

1. Obtain the source field’s four-byte value.
2. Write that value to the destination field.
3. Return without a value.

The destination receives the value obtained by the source read, not a value derived from its own previous contents. No arithmetic, comparison, mask, sign extension, or interpretation of the copied field is expressed.

On successful completion, in the absence of concurrent changes or unusual memory semantics:

- The destination field equals the source value observed during the invocation.
- The source field remains unchanged by this routine.
- Other storage remains unchanged by this routine.
- The previous destination value is discarded.

The operation does not depend on whether the source and destination initially contain equal values. The supplied behavior includes a destination write even when the values are equal; it contains no equality check or conditional skip.

There is no explicit validation, conditional branch, retry, or recovery path. In particular, the routine does not check for a null base, insufficient storage, inaccessible pages, or misalignment.

The evidence establishes a four-byte read and a four-byte write at the logical operation level. It does not establish indivisibility, processor instruction count, bus transaction width, or inter-thread visibility guarantees.
