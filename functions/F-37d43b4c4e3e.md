## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

- **Byte-derived addressing:** If an applicable selector read yields `0xa5`, the corresponding `+0x11` destination is `0xb6`. It is not an address obtained by reading a full pointer from the selector location.
- **Initial payload truncation:** With payload seed `0xffc00000`, shifting right by 22 yields `0x3ff`; the initial byte store is `0xff`.
- **Word-to-byte transfer:** If a represented `+0x74` word read yields `0x123456ab`, the following associated `+1` byte store is `0xab`, irrespective of platform byte order.
- **Word-width arithmetic:** Under the stated 32-bit interpretation, four times `0x40000001` is `4`. Address calculations must not silently use unbounded arithmetic.
- **Intervening mutation:** If a call changes a selector byte between two explicit reads, the later write follows the later selector. Combining those writes into one destination would violate the represented behavior.
- **Absolute-address ordering:** On a path reaching both stores, absolute address `0x0d` receives the retained selector before receiving `0xc0`. That is not a guaranteed final memory value because calls and aliases may also modify it.
- **Partial execution:** If a dependency never returns, subsequent explicit accesses do not occur. No rollback of earlier writes is specified.
