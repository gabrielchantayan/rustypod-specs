## Acceptance examples

These are conditional static expectations, not executed tests. Numerical examples involving scaling or left shifts use the stated 32-bit wrapping interpretation.

1. **Initial ordering.** With first input 3 and a supported initial store, the routine writes the 32-bit value 3 at address 32 before calling F-D001.

2. **First-selector masking.** First inputs differing only in bit 31 yield the same first selector-read address. Their initial stored values and F-D001 arguments nevertheless differ.

3. **Scaled byte truncation.** If F-D024 returns 64, its first selector-based store writes zero because four times 64 has low byte zero.

4. **Later F-D024 extraction.** If F-D024 returns `0x3FF00000`, the later extraction produces 1,023 before byte truncation, so the store writes 255.

5. **Fresh selection.** If the first selector byte is 5 for one read and becomes 9 before a later read, the corresponding destinations are 22 and 26, absent further changes affecting those reads.

6. **Direct address boundary.** Fourth inputs from 0 through 127 produce direct byte-store address 28. A fourth input of 128 produces address 29.

7. **First loop opening.** Every possible F-D048 result gives F-D051 a second explicit argument of zero. This does not constrain later F-D061 second arguments to zero.

8. **Complete loop-tail order.** If all calls return, each F-D056 call is followed by F-D057, F-D058, F-D059, and F-D060, in that order, before the next F-D061 opening call. Unknown side effects of F-D059 remain observable possibilities.

9. **Next-iteration arguments.** If F-D060 returns 1, the next F-D061 receives 4 and 262,144. F-D060 is the result-producing tail role; F-D061 is the subsequent opening role. They are not established to identify the same underlying function.

10. **Tail low-bit boundary.** If F-D060 returns 64, the next F-D061 receives 256 as its first argument and zero as its second. The second argument retains only the tail result’s low six bits.

11. **Continued execution.** If calls return and memory accesses complete indefinitely, the routine does not return normally. Each iteration includes the second-selector read, its zero store, and all specified calls.
