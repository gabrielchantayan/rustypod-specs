## Acceptance examples

These examples are conditional static expectations, not runtime results.

1. **Initial selector:** If the first selector read yields 0x20 and the incoming payload’s low byte is 0xab, the initial store writes 0xab at address 0x31, before the first dependency call.

2. **Selector mutation across calls:** If dependencies change the selector from 0x20 to 0x40 before its next read, the second selected write targets 0x51, not 0x31.

3. **Shifted payload byte:** For incoming payload 0x89abcdef, the low byte after logical right shift by 22 is 0x26. The second selected write uses that byte.

4. **Word truncation:** If a represented word-to-byte transfer reads 0x123456ab at base plus 0x74, it writes 0xab at base plus 1. It does not copy four bytes.

7. **Invalid selector address:** If a required selector read is inaccessible, the evidence provides no fallback selector or error return. Successful continuation must not be invented.

8. **Terminal boundary:** Reaching the final represented calls does not demonstrate normal return. Behavior after the invalid-instruction boundary remains unresolved.
