### 1. Entry store and initial selected-byte update

The first operation stores the inherited payload as a 32-bit word at the entry-store base plus 20.

Five indirect calls follow. The first receives the current first argument. The other four have no displayed arguments; the fifth returns the **initial scaling result**.

The function then reads the selector at the inherited selector base plus one and writes a selected byte. Its payload is obtained from the fourth argument by masking to 30 bits, shifting right by 20, and retaining eight bits. Consequently, original bits 20 through 27 determine the stored byte. Bits 28 and 29 do not survive byte truncation.

### 2. Initial exchanges and first word-payload propagation

A dependency receives the inherited payload shifted left by 12. Another returns a scalar. A subsequent dependency receives that scalar first and the initial scaling result shifted left by 30 second.

The next call supplies a represented 64-bit result. The following call receives its low half and then its high half. Two more calls follow, the latter supplying a scalar.

The function rereads the inherited selector and clears the selected byte. A dependency then receives four times the latest scalar.

Four calls follow. Four times the last result becomes the **first word payload**, which is stored at 16,384 times the initial scaling result plus 20.

The next dependency receives, in order:

1. 4,096 times the initial scaling result.
2. The same value.
3. 16,384 times the initial scaling result.
4. The first word payload.

Four further calls produce an address-forming result. The first word payload is stored at four times that result plus 20. A dependency receives four times that result.

### 3. Two scaled-store groups

The next group has this structure:

- Four calls produce a result.
- Its fourfold value is stored at its sixteenfold value plus 20.
- A dependency receives that fourfold value in three argument positions.
- Four more calls produce a different result.
- The same payload is stored at four times the newer result plus 20.
- A dependency receives four times the newer result.

This group occurs twice, with independently obtained results.

During the second group, the result used for the sixteenfold destination also establishes a **byte-control base** equal to that result multiplied by \(2^{30}\). Under 32-bit truncation, only its low two bits affect this base.

The final result used for the second group’s fourfold destination is retained for a later high-bit-only word payload.

### 4. Direct byte clears and a derived word read

A dependency receives four times the read-address result. Another returns a scalar, which is passed to the following dependency.

Four more calls produce a result. The function repeats the two direct clears, again at offset 17 before offset one. A dependency receives four times this latest result.

Four further calls produce a result whose fourfold value is retained as a **saved scaled argument**. At sixteen times this result plus 20, the function stores the final address-forming result from phase 3 shifted left by 31.
