# F-a71d6492ee32

## Purpose

F-a71d6492ee32 performs an ordered sequence of object-state writes and dependency calls, then returns the original object pointer if execution completes normally.

Its established direct behavior is to:

- Write an initial 32-bit state value at object byte offset 0.
- Read a 32-bit condition word at object byte offset 28.
- Invoke F-029930293dcb if that word is nonzero.
- Write a second 32-bit state value at object byte offset 0.
- Invoke F-03b9616af95f with a value obtained through a globally supplied pointer, the object pointer, two explicit 32-bit inputs, and two inherited 32-bit execution-context values.
- Return the original object pointer.

The state writes may represent changes to a dispatch table, type marker, or lifecycle state. Those interpretations are inferred intent only. The evidence does not establish that this function constructs, destroys, resets, or releases an object.

## Behavior

### Ordered direct operations

For an execution that reaches each operation normally, the following order is established:

1. **Install the initial state.**  
   The function obtains the initial state-source value and writes it as a 32-bit word at object offset 0. There is no preceding null check or object-validation branch.

2. **Read the condition.**  
   It reads the 32-bit word at object offset 28, after the initial state write.

3. **Make the conditional call.**  
   If the condition word is nonzero, it invokes F-029930293dcb with no explicit arguments shown. If the condition word is zero, it skips that call.

4. **Install the second state.**  
   After F-029930293dcb returns normally, or after the call is skipped, the function obtains the second state-source value and writes it as a 32-bit word at object offset 0.

5. **Obtain the pointer-derived argument.**  
   After the second state write, the function obtains a pointer from a global source and dereferences that pointer. The resulting value supplies the first argument to F-03b9616af95f.

6. **Make the final call.**  
   F-03b9616af95f receives the following arguments in order:

   | Position | Argument |
   |---:|---|
   | First | Value obtained by dereferencing the globally supplied pointer |
   | Second | Original object pointer |
   | Third | Third explicit input, 32 bits |
   | Fourth | Fourth explicit input, 32 bits |
   | Fifth | Inherited register-associated value, 32 bits |
   | Sixth | Incoming link-state value, 32 bits |

7. **Return the pointer.**  
   If the final dependency returns normally, the function returns the original object pointer. No further direct object-state write is shown.

There is one direct conditional call site and one direct unconditional call site. “Unconditional” means that the final call has no additional branch guarding it; earlier failure or nonreturn can still prevent it from being reached. Calls made inside dependencies, recursion, and re-entry remain outside the established direct sequence.
