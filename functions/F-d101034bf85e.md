## Behavior

### Widths, arithmetic, and notation

Words are 32 bits; bytes are eight bits. Dependency IDs F-01 through F-64 identify invocation sites in execution order, not proven distinct runtime functions. Different sites may resolve to the same target. “No displayed arguments” does not establish an argument-free machine interface.

For an invocation result:

- Its **fourfold value** is the result multiplied by four.
- Its **fourfold location** is the corresponding fourfold value plus 20, interpreted as an address.
- Its **sixteenfold location** is sixteen times the result plus 20, interpreted as an address.

These terms describe calculations, not object layouts. The constant offset does not establish a field, header, allocation boundary, or buffer capacity.

Most result-dependent multiplication and addition is represented using signed 32-bit operands. Signed overflow and problematic signed left shifts are not given an executable arithmetic model by the supplied representation. Conclusions requiring wrapping signed arithmetic are therefore explicitly conditional.

There is an important exception at F-35:

1. F-35 supplies a signed 32-bit result.
2. Multiplication by four is initially a signed 32-bit operation.
3. The multiplication result is converted to, and retained as, an **unsigned 32-bit value**.
4. Adding 20 to that retained value uses unsigned 32-bit arithmetic, modulo 4,294,967,296.
5. Masking that retained value with `0x3F`, then shifting left by 14, also uses unsigned arithmetic.

Unsigned retention does not retroactively make the initial multiplication unsigned or settle overflow in that multiplication. Conversely, a valid signed multiplication does not make the subsequent addition signed.

The sampled word and F-50’s result are also unsigned 32-bit values. Their logical right shifts and unsigned left shifts have the indicated unsigned semantics. Converting any resulting integer to a usable address remains a separate uncertainty.

## Acceptance examples

These are conditional static examples, not executed tests. Required calls and accesses must complete; arithmetic qualifications apply independently at each stage.

1. **Access ordering.** At the unsigned word read, six direct word stores have completed. Three more word stores occur later. A trace placing eight word stores before that read does not match the visible behavior.

2. **Distinct addresses.** If F-30 returns one, its store targets numeric address 36 and its read targets 24. Reading back 36 unconditionally would be incorrect.

3. **Coincident addresses.** If F-30 returns zero and address 20 supports ordinary word accesses, the sixth store writes zero there before the word read. No call separates those accesses.

4. **Unsigned word extraction.** A sampled word of `0xABCDEF01` produces `0x000ABCDE` for the seventh word store.

5. **Unsigned address addition after valid signed multiplication.** If F-35 returns 536,870,911, its multiplication by four is within signed 32-bit range. The retained unsigned value is `0x7FFFFFFC`; unsigned addition of 20 produces `0x80000010`. Rejecting this addition solely as signed overflow is incorrect. Address validity and later signed calculations remain unresolved.

6. **Unsigned mask-and-shift.** For that same retained value, masking with `0x3F` yields 60, and the unsigned shift by 14 yields 983,040, or `0x000F0000`, for F-41’s first argument if that call is reached. This does not settle F-41’s separate signed third-argument shift.

7. **Conditional shifted-input equivalence.** Under a 32-bit bitvector interpretation, fourth-input values one and 65 both produce `0x04000000` for F-11’s third argument. This does not imply otherwise identical execution.

8. **Byte-selected destinations.** A first lookup sample of 255 selects address 272. Samples of 32 and 48 on the two reads select addresses 49 and 65 respectively; F-63 later receives 48 as its second argument.

9. **Two extractions from one retained result.** If F-50 returns `0xABCDEF13`, the first byte store writes `0x4C` and the second writes `0xBC`. If their destinations coincide, the second direct write occurs later; dependency effects remain unconstrained.

10. **Interrupted execution.** If F-31 does not return, the sampled word read has occurred, but the seventh through ninth word stores and both byte updates have not occurred on this path.
