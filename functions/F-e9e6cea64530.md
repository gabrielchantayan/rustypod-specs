1. **Unsigned offset interpretation.**  
   If the 16-bit offset field contains `0xffff`, the captured offset is 65,535, not −1. The lookup address is the captured derived base plus 65,535.

2. **Unsigned byte widening.**  
   If the lookup reads `0xfe`, the subsequent 32-bit store at derived base plus `0x3c` contains the numerical value 254. It is not sign-extended to a negative value.

3. **Distinct byte-write destination.**  
   If the captured offset is 3 and the lookup byte is 7, the later byte-write destination is address 10. It is not derived base plus 10. If address 10 is inaccessible, normal completion of that access is not guaranteed.

4. **Truncation of the stored base.**
