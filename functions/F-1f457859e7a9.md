- If the destination byte overlaps the retained object’s initial dispatch-base representation, the write can affect which dispatch base is subsequently read.
- If it overlaps the selected callable entry’s storage, it can affect the callable entry subsequently read.
- If it overlaps the global datum supplying the fifth argument, it can affect that argument.
