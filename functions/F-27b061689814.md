# F-27b061689814

## Purpose

On normal completion, the result is:

- **0** when the lookup-like dependency returns a non-null pointer and the subsequent indirect operation returns zero.
- **1** when the lookup-like dependency returns null, or when the indirect operation returns any nonzero value.

The temporary context is passed to a finalization-like dependency before either result is returned.

These are established control-flow properties. Describing the operation as an existence check, readiness test, validation, or success/failure check would require additional evidence. In particular, the meanings of zero and one are not established.
