## Behavior

2. Form the address of a slot using that base and the fixed displacement of 348 bytes.
3. Read a callable address from that slot.
4. Invoke the selected address with no explicit arguments.
5. Return without an explicit result if the invocation returns normally.

The displacement is 0x15c, or 348 decimal. It is a displacement from the loaded integer value, not an index into an array of integers. The input pointer itself is not advanced by 348 bytes.

There are two distinct data dereferences before control transfer: the initial integer read and the callable-address read. The dispatcher does not directly invoke the integer value from the first read. Nor does it invoke the slot address itself without reading the callable address stored there.

Only one indirect invocation appears in the local behavior. There is no local loop, retry, second dispatch, or post-call inspection of the input.
