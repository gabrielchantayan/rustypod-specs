# F-74803456ff0c

## Purpose

- A path through two dependencies, the second annotated as nonreturning.
- A result-producing path through four ordered invocations of one dependency.

The replacement precedes selection. It is not contingent on a zero selector, successful dependency execution, or normal return. No restoration is established.

The application-level meaning of the replacement, selector, and returned integer is unknown. This contract specifies storage effects, invocation conditions, argument relationships, and control-flow consequences without assigning object or lifecycle semantics.

All behavioral claims derive from static evidence. Acceptance examples are conditional requirements, not observed executions.
