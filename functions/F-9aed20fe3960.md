## Acceptance examples

These are conditional static expectations, not executed tests. Stability assumptions apply only where stated.

1. **Bypass without Force.** Force zero and Bypass nonzero skip preliminary processing without reading byte 0x68 for that decision. Control reaches the combination test directly.

2. **First-range-only read sequence.** Preliminary processing enabled and word 1 zero at the test after the first range cause a direct word-0 read as combined input. There is no second word-1 test.

3. **Second range followed by a changed decision.** If that first test finds word 1 nonzero, the second range executes. If its dependencies change word 1 to zero, the subsequent combination test reads zero and selects word 0 without F-5a0f0ba632c0.

4. **Global A read timing.** With initial mode one, if the first additional handle-acquisition call changes Global A to a value representable in 32 bits, that value is supplied to the immediately following opcode-0x28 call, absent another intervening modification. A value observed earlier is not substituted.

5. **Global B read timing.** With simple-path terminal mode one, all three additional handle acquisitions precede the Global B read. A modification by the third acquisition affects the immediate operand, absent another intervening modification.

6. **Provided Base.** Nonzero Base suppresses F-710832a1dbe4 and this function’s word-13 read.

7. **Selector seven.** With stable simple-path configuration, byte 0x8f nonzero and selector seven cause the condition call but no second-selector call. Terminal processing remains possible.

8. **Unsupported terminal mode.** A later simple-path mode outside zero and one returns original Output without F-a40430e2991a; preceding effects remain.

9. **Multi-container completion.** Assuming dependencies return normally and all accesses succeed, three container results are written through slots in first, third, second order. The third result is returned.

10. **Separate mask reads.** A configuration change during the first masked-immediate emission may make the next separately emitted mask differ from the mask used in the AND.
