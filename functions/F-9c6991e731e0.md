## Acceptance examples

These are conditional static cases, not executed tests.

1. **Read width versus store width.** If the initial comparison/data read yields 0x1234ABCD, the store at twice D writes halfword 0xABCD. The originating environmental read remains a word read.

2. **Environmental reread.** If the comparison/data source changes between its initial read and later comparison read, C₀ supplies the doubled-address store, while the later value determines b.

3. **Carry-source independence.** If the carry source changes between its E calculation and subsequent threshold test, the calculations use their respective reads. A single captured carry-source value is not equivalent. When the threshold test succeeds, its short-circuited alternative need not read that source again.

4. **Preparation before pointer-directed write.** If the first A₀-directed byte write aliases the pointer-base source, G nevertheless retains the value read before that write. The narrowing operand has also already been read.

5. **Pointer-source mutation.** If the repeated halfword store changes the word at input base plus L, the A₁-directed word store follows the new word read there, not A₀.

6. **Active-base transition.** If intervening writes change O+0x14 after S is loaded, M comes from the later read. Subsequent M-relative accesses do not automatically target S.

7. **Unsigned carry.** With W equal to 0x80000000 and a equal to zero, D is zero and doubling carry is set.

8. **Retained final argument.** If either final store aliases M+0x44, the third explicit argument remains argument₃, captured before those stores.

9. **Terminal character conversion.** A byte representation of 0x80 can yield k equal to 0xFFFFFF80 with signed-character promotion, or 0x00000080 with unsigned-character promotion. These alternatives change the character-derived destinations and first argument.

10. **Partial mutation on failure.** If a late traversal faults, no restoration or explicit error return is shown. Earlier writes need not be undone.
