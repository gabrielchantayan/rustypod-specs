## Behavior

The function:

2. Derives an initial working word pointer by converting the parameter-slot address to signed 32 bits and shifting left by four.
3. Writes a byte at input 2 plus 7, using the low byte of the parameter-slot address logically shifted right by 12.
4. Writes the halfword `0xED38` at that logically shifted address plus 6.
5. Reads an initialization global and captures its value in a signed 32-bit temporary.
6. Computes input 2 minus `0xF9`, then holds the result as unsigned 32 bits.
7. Assigns the address value `0x97ED3800` to the global at that address. The declaration needed to establish the destination’s storage width is absent.

Initial state then selects:

- Working address value: `0x97ED3800`.
- Setup integer: zero.
- Separate address base: input 4 shifted left by 14, subsequently held in a signed integer.
- Record base: `0x000000A1`.

The earlier captured initialization value is retained separately from the later reread described below.

### Optional initialization

Initialization is selected exactly when input 4’s low 15 bits are nonzero.

In order:

1. The global at `0x225FB880` receives `0x10`.
2. Another fixed global receives `0x18`.
3. The initialization global read earlier is **read again**.
4. A byte `0xCE` is written at `0x97ED3800` plus this second read’s value.
5. The global at `0x0CE00026` is read and converted to unsigned 32 bits, replacing the working arithmetic value.
6. The global at `0x0CE00000` receives zero.
7. F-000000000001 is called.

Neither the global read at `0x0CE00026` nor the fixed-global assignments have an established storage width merely from these expressions.

F-000000000001 receives, in visible argument order:

- `0xC0`.

### Common setup

2. Multiply the setup integer by `0x02000000`, then write that word at the product plus `0x40`.
3. Write a zero byte at the record base.
4. Write the working arithmetic value as a word at the same record base.
5. Write word `0x40` at record offset 40.
6. Write the record-base address as a word at record offset 44.
7. Mask the working arithmetic value with the working address value. This becomes the arithmetic accumulator.

The initial byte write and overlapping word write are distinct operations.

A call-target base is set to `0x08BFED9A`. A second working value is calculated as eight times the signed interpretation of the working address value, minus two.

Next:

2. Add its signed interpretation to the signed interpretation of the working word pointer, then add 8.

### Outer write sequence

2. Call F-000000000002 at the current call-target base plus `0xA1E`, passing the current call argument.

8. Call F-000000000003.

### Final condition and continuation

The condition is formed by interpreting the replacement pointer as signed, shifting left by 31, shifting that signed result right by 32, converting to unsigned, and logically shifting right by 20.

A unique result is not established. The signed left shift and shift by the operand width prevent assigning this expression a portable numerical meaning.

The current destination is set to zero **before** testing the condition.

- **Condition zero:** Reenter the outer write sequence. The call-target base remains `0x0897EE1D`. The first outer operation attempts a byte write to address zero.
- **Condition nonzero:** Write the condition as a word at working-word address plus `0x20`; set the call-target base to `0x08790D52`; derive the next call argument by arithmetic-right-shifting the signed working word by 29; execute a software breakpoint with immediate 4.

The base update and argument calculation occur before the breakpoint. Breakpoint termination, resumption, and externally modified state remain environment-dependent.

### Result multiplication

### Saved byte and continuation
