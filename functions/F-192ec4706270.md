# F-192ec4706270

## Purpose

F-192ec4706270 describes an ordered path containing two byte stores and up to ten indirect calls. Each store selects its destination using a separate read of an unsigned selector byte. The stored values come from two different bit ranges of an implicit unsigned state word.

The first call receives four explicit arguments, including two identical scaled values. The fifth call supplies an integer result that is scaled and passed to the sixth call. The remaining calls have no explicit arguments in the supplied representation.

This contract describes the represented path, not a verified executable implementation. The supplied static evidence reports problematic instruction data and ends at an invalid-instruction boundary rather than an ordinary return. Every operation after a call is conditional on that call returning and execution continuing.

No application-level purpose is established. Interpreting the sequence as initialization, device control, decoding, or another domain-specific operation would be inference.

## Behavior

### Ordered operations

Subject to successful earlier accesses and normally returning earlier calls, the represented order is:

1. Read the unsigned selector byte at selector base plus one.
2. Store the low eight bits of the state word at the address equal to that selector plus `0x11`.
3. Invoke F-U01 with four explicit arguments, in order:
   - The scaling input shifted left by three bits.
   - The same shifted value.
   - The original scaling input.
   - The unchanged payload.
4. Invoke F-U02 with no explicit arguments.
5. Invoke F-U03 with no explicit arguments.
6. Invoke F-U04 with no explicit arguments.
7. Invoke F-U05 with no explicit arguments and retain its represented signed integer result.
8. Read the unsigned selector byte at selector base plus one again.
9. Store bits 22 through 29 of the state word at the address equal to this newly read selector plus `0x11`.
10. Invoke F-U06 with the F-U05 result shifted left by two bits as its sole explicit argument.
11. Invoke F-U07 with no explicit arguments.
12. Invoke F-U08 with no explicit arguments.
13. Invoke F-U09 with no explicit arguments.
14. Invoke F-U10 with no explicit arguments.
15. Reach the represented invalid-instruction boundary, if execution continues through all preceding operations.

This order describes the local sequence. It establishes neither atomicity nor memory barriers, and it does not order individual effects inside a dependency.

“No explicit arguments” describes the supplied call representation. It does not establish that the dependency consumes no implicit register values, stack contents, global state, or other inputs.

### Store values

The first store retains bits 0 through 7 of the state word and discards the rest.

The second store uses an unsigned right shift by 22 bits and then retains the low eight bits. Its value is therefore determined by original state bits 22 through 29:

- Bits 0 through 21 do not contribute.
- Bits 30 and 31 do not contribute.
- Sign extension is not involved in this unsigned shift.

For an unchanged state word of `0x004000AB`, the first stored byte is `0xAB` and the second is `0x01`. For an unchanged state word of `0xFFFFFFFF`, both stored bytes are `0xFF`.

These are byte-value operations. No memory-endianness assumption is needed to derive them.

### Fresh selection and aliasing

The second destination must be based on the second selector read, not on a cached copy of the first selector. F-U01 through F-U05 intervene between the two reads. Those dependencies, or an external actor, may change relevant memory.

The first destination may also alias the selector location itself. No exclusion prevents that overlap. In such a case, the first store can change the value observed by the second selector read even when every dependency leaves memory unchanged.

The two destinations can otherwise be equal or different. If they are equal, the later store can overwrite the earlier stored byte. That does not erase any observation or device effect caused by the first store.

The represented reuse of the state word and selector base is not a general preservation guarantee. Examples requiring them to remain unchanged state that condition explicitly.

F-U06 receives the F-U05 result shifted left by two bits. Nonnegative signed 32-bit results from 0 through 536,870,911 have representable scaled values equal to four times that result.

The supplied evidence does not establish a portable result for negative operands or signed left shifts whose mathematical results exceed the signed 32-bit range.
