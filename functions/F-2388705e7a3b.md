## Behavior

### Gate evaluation

The first decision examines the field at offset 16 after narrowing it to a character-sized value. The comparison is against zero.

For the represented widths, this is a low-eight-bit zero test. It is not a test of whether the entire four-byte field is zero. A field can therefore have nonzero upper bits and still cause an immediate return. Character signedness does not affect this particular decision: zero and nonzero remain distinguishable either way.

If the narrowed value is zero, the function returns without evaluating the signed integer gate or initiating dispatch.

If the narrowed value is nonzero, the function reads the signed four-byte integer at offset 4. A value less than one causes an immediate return. Consequently:

- Zero fails the gate.
- Every negative signed value fails the gate.
- Every positive signed value passes the gate.
