# F-302b0bc01d2a

**Established static behavior:** each outer cycle calls a dependency, reads shared storage, and selects either record processing or a terminal path. Record processing contains an inner loop. Once that loop takes its continuation path, its represented control-value updates prevent a subsequent exit through the ordinary comparison.

The terminal path performs two distinct operations before the interrupt/halt sequence:

1. Writes a byte to a stack-relative region, using a signed terminal index.

## Behavior

The represented negative and overflow conditions then select the path:

- Unequal conditions select terminal processing.
- Equal conditions select record processing.

The shared-word read occurs even when terminal processing is selected immediately.

The representation does not derive this decision from F-D01’s return value. It carries condition-state values across the call. This does not establish that an unknown machine-level callee preserves processor flags.

### Common inner-loop prefix

Each inner iteration performs the following represented operations in order:

1. Writes the current cycle-carried word to active-record offset 56.
2. Replaces the shifted-address state with the unsigned active-record address shifted right by nine bits.
3. Writes the low 16 bits of the argument-carried value to shared address `0x083ff1cc`.
4. Replaces the argument-carried value with the word read from active-record offset 4.
5. Compares the signed loop-control value with 17.

A value below 17 exits the inner loop. A value of at least 17 selects continuation.

An immediate exit therefore still includes the offset-56 write, shifted-address update, shared halfword write, and offset-4 read. The shared halfword receives the value carried into the iteration, not the word loaded later from offset 4.

### Inner continuation

Continuation first reads an unsigned halfword from the address formed by adding:

- The current shifted-address state.
- The word read from active-record offset 0.

The addition is represented at unsigned 32-bit width.

An unsigned byte is then read from anchor-record offset 17. Its zero-extended value becomes the cycle-carried word for the next iteration’s offset-56 write.

F-D03 is called through a target `0x6ae` bytes beyond the current local call-address base. Both the halfword and anchor byte have been captured before this call.

After F-D03, the loop-control value becomes the captured halfword plus 202. Its storage is not re-read for this calculation.

The argument-carried value is then replaced through two dependent reads:

1. A 32-bit pointer is read from `0x41ff8d7c`.
2. An unsigned byte is read from that pointer plus 22.

The fixed pointer-read address follows from the represented calculation of `0x083ff1ac` multiplied by eight, then increased by `0x1c`. It is not itself the address of the byte read.

F-D04 is called at `0x083ffba3`. Its result plus 16 becomes the next active-record address. F-D05 is then called at `0x083ff290`, receiving F-D04’s result. F-D05’s result becomes the next anchor-record address.

The unsigned halfword ranges from 0 through 65,535. Adding 202 produces a 32-bit control value from **202 through 65,737**, inclusive.

This addition does not truncate to 16 bits and does not overflow signed 32-bit arithmetic. Every possible result is at least 17.

Consequently, once continuation is selected, the displayed local control-value evolution cannot subsequently select the ordinary inner-loop exit.

This is not proof of indefinite real execution. Calls may fail to return, accesses may fault, and the control-flow representation may be incomplete. It does rule out a represented finite traversal that terminates because this particular control value eventually falls below 17.

**stack-relative byte region beginning at `0x214`, plus the signed terminal index.**

The byte-write destination depends on the region base and terminal index. Its value depends on the current F-D01 result. It does **not** depend on the shifted-address state.

After that write, the function reads a function pointer from the current shifted-address state plus 32 and calls F-D07 through it.

3. Invalid-instruction termination if execution proceeds further.
