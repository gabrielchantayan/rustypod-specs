# F-7b0a29f56739

## Purpose

F-7b0a29f56739 returns a Boolean indicating whether a shared comparison value differs from a value derived from its second argument.

The derivation is not an unrestricted multiplication or a conventional address-alignment operation. Under the 32-bit unsigned interpretation of the supplied representation, it selects input bits 20 through 30 and places them in result bits 21 through 31. Input bits 0 through 19 and input bit 31 do not affect that derived value.

The first argument does not contribute to the result.

**Established static evidence:** the supplied function consists of a single inequality expression. It contains no explicit calls, assignments, loops, or branches other than the Boolean outcome of that comparison.

**Inferred intent:** the function may be checking whether an input belongs to a category different from a shared category value. Neither the meaning of the input nor the meaning of the shared value is established. This contract does not assign them address, region, cache, or ownership semantics.

## Behavior

### Derived value

The function first has a mathematical dependence on the second argument shifted right by 20 bits. This removes the lowest 20 bits and leaves a value between 0 and 4,095.

That shifted value is multiplied by 2,097,152, which is \(2^{21}\). Under 32-bit unsigned arithmetic, the multiplication is reduced modulo \(2^{32}\).

For a second argument \(x\), the derived value \(d\) is:

\[
d=\left(\left\lfloor\frac{x}{2^{20}}\right\rfloor
\times 2^{21}\right)\bmod 2^{32}.
\]

An equivalent description, useful for understanding the lost bit, is:

\[
d=\left(\left\lfloor\frac{x}{2^{20}}\right\rfloor
\bmod 2^{11}\right)\times 2^{21}.
\]

Consequently:

- Input bits 0 through 19 are discarded by the right shift.
- Input bits 20 through 30 become result bits 21 through 31.
- Input bit 31 would contribute \(2^{32}\), which vanishes in 32-bit unsigned arithmetic.
- Result bits 0 through 20 are always zero.
- There are exactly 2,048 possible derived values.
- The maximum derived value is 4,292,870,144, or `0xFFE00000`.

Overflow in this multiplication is unsigned wraparound, not a separate failure condition. A replacement that retains the product in a wider integer without reducing it to 32 bits would change the behavior.

### Comparison and return

### Input equivalence

Inputs that differ only in their lowest 20 bits produce the same derived value.

Inputs that differ only in bit 31 also produce the same derived value. Thus, for an unchanged comparison value, toggling bit 31 cannot change the Boolean result under the stated arithmetic model.

Each derived value corresponds to \(2^{21}\) distinct second-argument bit patterns: \(2^{20}\) choices for the discarded low bits, multiplied by two choices for the discarded high bit.

Changes to the first argument have no effect on the shown computation.
