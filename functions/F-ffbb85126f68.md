# F-ffbb85126f68

## Purpose

No application-level purpose is established. The repeated scaling operations do not establish that the values are array indices, pointers, sizes, or object handles. The writes do not establish initialization, clearing of an object, or serialization.

This contract describes the visible operations conditionally: execution must reach each operation, earlier calls must return, and computed addresses must support the attempted accesses. The supplied representation includes warnings about invalid instruction data and ends at a truncated control-flow boundary. Consequently, it does not establish a valid, normally returning implementation over the entire displayed region.

### Entry and first write

F-E01 is invoked first. Its target is derived from the entry control-link value plus 4094. Its result is not visibly consumed.

F-E02 is invoked next through a different target expression. Its returned 32-bit word controls the only visible conditional selection:

- If bit 30 is set, the selected word is the return value shifted left by two bits.
- If bit 30 is clear, the selected word is the entry selector word shifted left by ten bits.

The routine then attempts the first byte write:

| Property | Requirement |
|---|---|
| Destination | Twice the selected word |
| Stored byte | Low eight bits of the entry payload word |
| Ordering | After F-E02 returns and before F-A01 is invoked |

The selection tests bit 30 specifically. Bit 31 does not independently select the branch. The entry selector word does not contribute to the selected word when bit 30 is set.

There is no visible address validation before the store.

### First call phase

After the first write, the F-A family proceeds as follows:

1. F-A01 receives two explicit arguments, both equal to the selected word. These arguments are not the doubled destination used by the preceding store.
2. F-A02 through F-A04 run with no displayed arguments; their results are discarded.
3. F-A05 produces a 32-bit value. F-A06 receives that value unchanged as one explicit argument.
4. Nine ordered transfer rounds follow. Each round contains three calls with no displayed arguments and discarded results, followed by a result-producing call, followed by a call receiving that result shifted left by two bits.
5. Three additional calls with discarded results precede a final result-producing call, F-A55.

Each transfer round uses its own producer’s result. No accumulator, reuse of an earlier round’s result, conditional repetition, or early-exit check is visible.

The return value of F-A55 supplies the next store address and the next pair of arguments.

### Second write and second call phase

The second byte write occurs after F-A55 returns and before F-B01 is invoked.

| Property | Requirement |
|---|---|
| Destination | F-A55’s result shifted left by three bits |
| Stored byte | Bits 22–29 of the entry payload word |

The byte is obtained by an unsigned right shift of the payload by 22 bits followed by byte truncation. Payload bits 30 and 31 are not included in the stored byte.

F-B01 then receives two explicit arguments derived from F-A55’s result:

- First argument: the result multiplied by four.
- Second argument: the result shifted left by ten bits.

The remaining F-B phase contains:

- Eight calls with no displayed arguments and discarded results.

### Bit 30 set selects the dependency result
