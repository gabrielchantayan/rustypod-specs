## Acceptance examples

These are conditional static examples, not executed tests.

1. **Entry aliasing.** If the first and second incoming bases are equal, the initial word store precedes the word read at offset `0x14`. Without intervening external mutation, the read observes the incoming payload.

2. **Byte truncation.** If the first field-extraction result is `0xffffffff`, its four-times-scaled low byte is `0xfc`. The later masked right shift by 20 is `0x3ff`, whose stored low byte is `0xff`.

3. **Selector rereading.** If a selector read yields `2`, the corresponding byte destination is `0x13`. If an intervening dependency changes that selector to `7`, a later selector-based write targets `0x18`, not `0x13`.

4. **High-offset word access.** Under 32-bit bit-vector arithmetic, if the relevant retained result is `0x00080000`, shifting it right by 19 produces `1`; shifting that field left by 31 produces `0x80000000`. The word read therefore uses address `0x80080000`, subject to mapping and alignment.

5. **Overwritten byte remains observable.** If execution reaches both offset-`0x0d` writes, the first truncated value is written before the later constant `4`. Intervening dependencies are allowed to observe it.

6. **Global reset is not preservation.** If a dependency changes the global scratch location after its zero assignment, the later explicit global read observes the changed value. An implementation that replaces that read with zero violates the visible access contract.

7. **Terminal failure preserves prior effects.** If address zero is not callable, the final transfer may fault. The preceding pointer clear, publication assignment, and halfword clear have already occurred.
