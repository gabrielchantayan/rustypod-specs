# F-006c9f412ead

## Purpose

The available static representation describes a linear sequence of indirect calls interleaved with five 32-bit memory writes and four byte writes. Call results provide indices, byte payloads, and values forwarded to later calls. Two additional entry-state values supply an initial word payload and a source for shifts and address calculations.

No application-level purpose is established. In particular, the evidence does not establish that the function initializes an object, accesses a device, encodes a message, or manages a resource.

The representation ends at an invalid-instruction boundary rather than a normal return. Its reliability is limited by an explicit control-flow warning. This contract therefore specifies the visible prefix, conditional on execution reaching each operation, without claiming that the prefix is a complete, normally executable function.

## Acceptance examples

These are conditional acceptance criteria, not executed tests. They assume valid accessible memory, returning dependencies, and the stated 32-bit interpretation.

1. **Initial write precedes calls.**  
   With \(P=3\), the first direct effect writes \(W\) at address 32. F-a00000000001 then receives 12. A call occurring before that write would violate the visible ordering.

2. **Payload and destination use different results.**  
   With \(A=2\) and \(B=7\), the second word write stores 8 at address 52. The third word write stores 8 at address 48. Storing 28 in the third write would not match the evidence.

3. **Two-argument call excludes the write offset.**  
   With \(C=3\), the fourth word write stores 12 at address 68. F-a00000000016 receives 12 and 48, not 12 and 68.

4. **Logical shifts use the unsigned entry value.**  
   With \(R=\texttt{0x80000000}\), the argument paired with \(T_1\) is \(\texttt{0x02000000}\), and the fifth word-write payload is \(\texttt{0x10000000}\). Sign-extending either shift would differ.

5. **Byte payloads truncate.**  
   With \(U=\texttt{0x12345678}\), the first byte payload is \(\texttt{0xe0}\), while F-a00000000028 receives \(\texttt{0x48d159e0}\). The second byte payload is \(\texttt{0x23}\).

6. **Selector reads are independent.**  
   If the first two reads at \(H+1\) yield 5 and 9, the first two byte-write destinations are 22 and 26. Reusing the first selector for both writes would violate the contract.

7. **Captured selector survives the third write.**  
   If the third selector is 255, the third byte write targets address 272 and F-a00000000040 receives 255. The argument is not replaced by the stored payload.

8. **Final selection uses a different address formula.**  
   With \(V=\texttt{0x00100001}\), the fourth selector is read at \(\texttt{0x00800009}\), and the fourth byte payload is 1. This remains true independently of \(G\), which supplies only the later shifted call argument.
