Conversely, if the word is initially zero and becomes nonzero before the read, F-dc842e45211e is invoked. This distinguishes the specified ordering from an implementation that samples state too early.

Likewise, a state word containing any nonzero bit pattern selects the conditional call; no positive-value test is shown.

### Interrupted execution
