# F-45daac91f886

## Purpose

F-45daac91f886 is a dispatcher controlled by global integer values. It accepts one integer argument, conditionally captures that argument as an outgoing payload, may invoke F-5e3309c9d083 with the payload, and returns a four-byte zero if execution reaches its return action.

Termination is not guaranteed. Depending on entry reads, subsequent alternate-destination reads, arithmetic behavior, and dependency behavior, execution may return without a call, call and then return, or continue indefinitely.

**Established static evidence:** each action is selected by adding a retained bias to the current state. Most routing values are sampled at entry. One alternate destination is referenced during conditional routing.

**Inferred intent:** the function implements indirect control flow rather than an application-level calculation. No meaning for the argument or global values beyond their dispatcher roles is established.

**Important boundary:** conditional routing uses unsigned arithmetic before assigning its result to a signed state. Under the 32-bit model used below, selecting a negative destination requires an unsigned-to-signed conversion whose result is not established by the supplied representation. This boundary is separate from signed overflow.

## Behavior

### Entry sampling

The represented sequence performs these logical reads and derivations in order:

1. Read the routing slot and retain its value as the **primary destination**.
2. Read the bias slot and retain its value as the **dispatch bias**.
3. Read the initial-state slot, subtract two, and retain the result as the **capture destination**.
4. Read the routing slot again, add one, and retain the result as the **default destination**.
5. Read the initial-state slot again and retain its value as the **current state**.

The function then initializes the outgoing payload to zero and the selection flag to false.

The two reads of each repeated slot are distinct in the representation. Without a stability guarantee:

- The default destination need not equal the primary destination plus one.
- The capture destination need not equal the initial current state minus two.

The entry derivations precede dispatch even if the first action returns immediately.

Subtracting two and adding one are signed arithmetic under the stated model. Their overflow behavior is unresolved. For example, a stable initial-state value at the minimum signed value cannot safely be treated as an immediate-return setup merely because a later selector might otherwise be four: deriving the capture destination has already crossed the signed arithmetic boundary.

The ordering above describes represented logical operations. It does not establish volatile accesses, atomic transactions, or externally enforced memory ordering.

### Dispatch cycle

Each iteration first adds the retained bias to the current state to obtain the selector. This is signed arithmetic under the stated model.

After computing the selector, the function provisionally replaces the current state with the retained default destination. It then performs the selected action:

| Selector | Action | Subsequent state or outcome |
|---:|---|---|
| 0 | Conditional routing | Result of the routing arithmetic and conversion described below. |
| 1 | Dependency call | Primary destination, if the dependency returns normally. |
| 2 | Capture argument | Capture destination; payload and flag are updated. |
| 3 | No additional action | Default destination remains in effect. |
| 4 | Return | Return four-byte zero. |
| Any other value | No additional action | Default destination remains in effect. |

Negative selectors and selectors greater than four use the default behavior.

A destination is a state, not an action number. After assigning a destination, the next iteration adds the retained bias again before choosing an action.

### Conditional routing and its conversion boundary

Selector zero evaluates a numeric combination controlled by the selection flag. The flag is Boolean, so its integer values are zero and one.

Under the 32-bit model, the relevant arithmetic is:

- The complementary flag factor is formed using an unsigned literal and therefore has unsigned type.
- Multiplication of the primary destination by that factor is unsigned. A negative primary destination is first represented modulo 2³².
- Multiplication of the alternate destination by the flag is signed, with a factor of zero or one. For a representable alternate value, this multiplication does not itself overflow.
- The final addition is unsigned because one operand is unsigned. A negative alternate contribution is consequently converted to unsigned.
- The unsigned sum is assigned to the signed current state.

The unsigned arithmetic is modulo 2³² under this model. The assignment back to signed state is a separate operation.

The resulting cases are:

| Flag | Selected numeric destination | Result before signed assignment |
|---|---|---|
| False | Primary destination | Its corresponding unsigned value. |
| True | Alternate destination from this action | Its corresponding unsigned value. |

If the selected destination is nonnegative and representable as a signed integer, the final unsigned result is within the signed range. The next state equals that destination.

If the selected destination is negative, the unsigned result lies above the maximum signed value. **The supplied representation does not establish what signed state results from that conversion.** A target rule that preserves the corresponding 32-bit bit pattern would recover the negative destination, but that rule is an additional assumption, not an unconditional property of this function.

A negative value in the unselected branch does not by itself create this conversion boundary. Its multiplied contribution is zero. For example, a negative primary destination with a true flag does not prevent a nonnegative alternate destination from being assigned exactly.

The alternate slot is referenced in the represented expression even when its factor is zero. The expression does not use short-circuit selection. However, the representation does not establish that an optimized executable must physically load that slot when its value cannot affect the result.

The alternate destination is not retained at entry. Its value may differ between conditional-routing actions.

3. Set the selection flag according to whether the argument is nonzero.
