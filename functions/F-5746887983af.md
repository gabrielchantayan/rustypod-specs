## Acceptance examples

These are conditional static criteria, not executed tests. Each assumes that execution reaches the relevant operation and that required accesses and arithmetic are valid.

1. **Representable negative F-D06 sum.** If both halves of Pair A have bit pattern `0xFFFFFFFF`, each signed conversion represents −1. The signed intermediate is −2 without overflow, and F-D06’s second argument is `0xFFFFFFFE`.

2. **Overflowing F-D06 intermediate.** If one converted half is `0x7FFFFFFF` and the other is 1, the signed addition overflows. The later unsigned conversion does not establish a defined intermediate result; this case remains documented_only.

3. **Zero-byte reset.** The store at First object base plus `0x15` writes zero, independently of the byte captured late in a previous cycle.

4. **Pair B extraction.** For a low half of `0xFC000003`, the word at Context base plus `0x26C` receives 63. The later unsigned left-shifted word is `0xF000000C`.

5. **Breakpoint boundary.** If execution stops at breakpoint `0x92`, six direct stores have been reached: two byte, two halfword, and two word stores. No post-breakpoint store has been reached.

6. **Indexed truncation.** If Table base is `0x12345678` and F-D19 returns 3, the halfword store targets Table base plus 12 and writes `0x5678`.

7. **Sample extension.** A Sample of `0xFFFF` produces `0x0000FFFF` in both Sample word stores. F-D30 separates those operations.

8. **Captured byte.** If the byte read at five times Selector B is `0xA7`, the late byte store writes `0xA7` even if F-D34 changes the source byte.

9. **Context transition.** If Context base is `0x1000` immediately before the Pair C word store, its destination is `0x1258`. The subsequent reduction produces `0x0F0C` without changing that completed store.

10. **Target equalities.** F-D05/F-D06, F-D09/F-D13, F-D17/F-D24, F-D19/F-D31, and F-D25/F-D32 each use equal calculated targets. No matching-signature conclusion follows.

11. **Next-cycle target.** If the late link-like assignment remains effective through F-D37, the next F-D01 target is `0x0871302F`.
