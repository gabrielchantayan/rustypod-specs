# F-58205e0d2cf0

## Purpose

F-58205e0d2cf0 obtains an object pointer, selects a path according to whether that pointer is null, and returns a 64-bit result after invoking a final status dependency.

The supplied static representation establishes two normally completing paths:

- **Null object:** invoke F-038b46411c0c with status 9 and return the 64-bit all-ones value.
- **Non-null object:** obtain an associated-record address through two successive 32-bit memory reads, perform an ordered sequence of dependency calls and two 16-bit field reads, invoke F-038b46411c0c with status 0, and return the main operation’s 64-bit result unchanged.

The dependencies’ application-level purposes are not established. “Acquisition,” “associated record,” and “main operation” identify their roles in this function, not verified resource-management or domain semantics. In particular, the calls surrounding the main operation are not established to acquire and release a lock.

1. The selected 64-bit result becomes all ones.

- Changing the intermediate storage’s 32-bit contents during a dependency call also does not redirect the later field read.
