# F-9166ce8922cc

## Purpose

F-9166ce8922cc changes an object's mode and, on continuing paths, recalculates associated state, invokes an indirect callback, and marks the object as updated.

The established behavior consists of object accesses, **conditionally evaluated global reads**, opaque dependency calls, integer arithmetic, and conditional returns. The unavailable global words are not established as immutable constants. Earlier dependencies may change them before this function reads them.

Four entry behaviors are visible:

- Selector **0** disables the mode, writes a numeric word, invokes the callback, and returns.
- Selector **1** computes a selected value through dependencies, passes it to another dependency, and returns.
- Selector **2** selects a value using the adjustment argument. One selection returns early; the others enter the main update.
- Other selectors return without explicit object accesses or dependency calls.

Field labels describe usage, not established domain meanings. Some immediate words have recognizable IEEE 754 binary32 encodings, but dependency arithmetic is unresolved.

No runtime tests have been performed.
