# F-5b11d8d4a9e9

## Purpose

For an ordinary memory location with a stable address and no concurrent modification, the operation preserves every other bit. If the selected bit is already set, the resulting word has the same numerical value as before. The supplied representation nevertheless includes a store; it does not condition the store on a change in value.

- Every other result bit equals the corresponding bit of the value read.
