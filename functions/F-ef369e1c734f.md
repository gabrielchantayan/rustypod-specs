# F-ef369e1c734f

## Purpose

The supplied static representation does not establish an application-level purpose. Descriptions such as allocator, serializer, device initializer, or reference decoder would require additional evidence.

This contract is conditional: each operation is reached only if all preceding calls return and all preceding accesses complete. It does not establish that the entire sequence is executable on a particular platform.

## Interface

- Two uninterpreted 32-bit values, neither directly referenced by the visible body.
- An unsigned 32-bit value, designated **P**.

The first two arguments are not proven irrelevant to execution. Indirect dependencies have incompletely represented interfaces and may consume additional incoming register state.

For compactness, **S(value)** denotes its fourfold value in the apparent 32-bit arithmetic. Logical shifts are used unless a signed shift is explicitly identified. A represented 64-bit result is described as low and high 32-bit halves.

The representation mixes unsigned operations with signed multiplication and left shifts. Where arithmetic is well-defined and representable, the expressions below are direct consequences of the supplied body. A universal wraparound rule for signed overflow, overflowing address formation, or invalid pointer arithmetic is not established. ## Side effects

Offsets 1, 20, and 116 describe accesses only. They do not establish a structure, allocation size, array stride, or valid object boundary.

All stated reads are fresh. Dependencies may modify their sources between accesses. Earlier direct stores may also alias later sources, G, H, or T. In particular:

- The two sign-selected reads can differ.
- The two reads at \(n+116\) can differ.

No ownership transfer, borrowing guarantee, allocation, or release is established by the visible body. Dependencies may have ownership effects, but none may be assumed. The final pointer must designate writable storage for its byte store to complete; its provenance and owner remain unknown.

There are no visible bounds checks, null checks, alignment checks, conditional branches, recovery paths, or rollback. A failed access or nonreturning dependency can prevent all later effects. Previously completed effects are not visibly undone.

## Acceptance examples

These are conditional static expectations, not executed tests. Required calls must return, accesses must complete, and arithmetic must satisfy the qualifications above.

1. **Initial extraction.** If P is `0xFFFFFFFF` and a is 3, the first word store places 511 at address 32. If P is `0x007FFFFF`, that stored value is zero.

2. **Unscaled read.** If A is `0x00400000`, the first saved word is read at address 21, not 24. Whether that unaligned access completes is platform-dependent.

3. **Byte truncation.** If b is `0xFFFFFFFF`, d is 1,023. If the byte read at \(B+1\) is 7, the next byte store places 255 at address 24.

4. **Zero argument.** For every unsigned 32-bit B, F-B03’s explicit argument is zero.

5. **Sign-selected reads.** With B’s high bit clear, both sign-selected lookups use address 1; with it set, both use address 2. Intervening calls may make their returned bytes different.

6. **Repeated transfer ordering.** After F-E08, the intervening calls are F-E09, F-E10, F-E11, and F-E12, with q supplied by F-E12. If they change the word at \(n+116\) from a value ending in `0x12` to one ending in `0x34`, the two stores at \(n+1\) write `0x12` and `0x34`. F-E13 occurs after the second store.

7. **Saved full-width value.** If v is `0xA1B2C3D4`, the immediate byte transfer writes `0xD4`. The later stores at \(16t+20\) and \(S(u)+20\) use the full `0xA1B2C3D4`, even if dependencies subsequently change the original source memory.

8. **Saved base.** If H supplies base 100 and is later changed to 200 before the delayed dereference, that dereference still reads address 120, assuming the saved base remains represented as specified.

9. **Terminal effects.** If T supplies `0x123456` and F-J16 returns `0xAB`, G receives `0x123456AB`. This is a bit-value expectation, not an assertion about byte order in memory. The pointer-directed byte zero precedes this assignment, which precedes the halfword zero and F-J17. If F-J17 does not return, normal completion is not reached.
