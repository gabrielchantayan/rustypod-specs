## Behavior

### Classification

The function first evaluates the input relative to the digit range. Inputs from 48 through 56 satisfy the lower portion of that range directly. Input 57 is accepted through a separate equality condition. Together, these checks accept exactly 48–57.

When the unsigned digit-relative value exceeds 9, the function evaluates the input relative to the uppercase range. Inputs from 65 through 89 satisfy its lower portion; input 90 is accepted through the corresponding equality condition.

If the active classification has established neither an in-range value nor its separately tested upper endpoint, the function evaluates the lowercase range. Inputs from 97 through 121 satisfy its lower portion; input 122 is accepted through an equality condition.

The final result combines the active range comparison and endpoint equality. This produces the three inclusive ranges specified in the purpose.

### Evaluation order and conditional work

The observable interface contains no external reads or writes after receipt of the argument. Nevertheless, the supplied representation establishes this internal evaluation order:

1. Digit-relative arithmetic and comparisons occur first.
2. Uppercase-relative arithmetic and comparisons occur only when the digit-relative unsigned value is greater than 9.
3. Lowercase-relative arithmetic and comparisons occur only when the currently active result rejects both the range interior and its upper endpoint.

Consequently:

- Accepted digits do not require uppercase or lowercase evaluation.
- Accepted uppercase letters do not require lowercase evaluation.
