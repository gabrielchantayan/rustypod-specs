# F-0e17a706db33

## Purpose

F-0e17a706db33 computes an updated integer from an initial stored value and the product of two integer inputs. It writes the updated value to the first and second destinations, then writes the initial value to the third destination.

The established behavior is an ordered sequence of one initial-value read and three destination writes. Aliasing between destinations can change the final stored values. In particular, the third write can overwrite an updated value written earlier.

Interpreting this operation as advancing a position by a count times a stride is plausible intent, but not established behavior. The contract assigns no application-specific meaning or units to the integer inputs.

## Behavior

Let **S** be the integer value obtained by the initial read through the first address. Let **A** and **B** be the fourth and fifth integer inputs.

Where the arithmetic is defined, the updated value is:

**U = S + (B × A)**

The observable memory-access order established by the supplied representation is:

1. Read **S** through the first address.
2. Compute **U** from that captured value and the two integer inputs.
3. Write **U** through the first address.
4. Write the same **U** through the second address.
5. Write the captured **S** through the third address.
6. Return without a result value.

This is a behavioral access order, not a guarantee about individual machine instructions, bus transactions, or synchronization visibility.

The updated value is determined before the destination writes begin. There is no visible reread of the first destination between the first and second writes. The third write uses the captured initial value, not the value then present at any destination.

### Distinct destinations

- First destination: **U**.
- Second destination: **U**.
- Third destination: **S**.

Only the first object's initial value participates in the calculation.

### Exact aliasing

For addresses that identify the same complete integer object, the last applicable write determines that object's final value:

| Address relationship | Final state after successful completion |
|---|---|
| First and second coincide; third is distinct | Shared first/second object contains **U**; third contains **S** |

| Second and third coincide; first is distinct | First contains **U**; shared second/third object contains **S** |
