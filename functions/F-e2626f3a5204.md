# F-e2626f3a5204

## Purpose

F-e2626f3a5204 performs an ordered sequence of indirect calls and memory updates. Its visible operations include:

- Storing an incoming context word into a caller-addressed object.
- Converting several call results into four-byte-scaled quantities.
- Storing words at computed addresses with a displacement of 20 bytes.
- Reading a global-held address and subsequently reading a word through that captured address.
- Writing two selected portions of that word through byte-indexed destinations.
- Assigning a final call result to a global slot.
- Clearing one byte and one halfword before attempting a call to address zero.

The supplied static representation does not establish a higher-level application purpose. In particular, it does not establish that the computed addresses identify valid objects, that the indirect calls return normally, or that the final call is executable.

This contract describes the visible sequence conditionally: each later operation is reached only if all preceding operations complete and control returns as represented.

- The first byte write stores hexadecimal 7E at address 49.

This example establishes the calculation only. A platform may reject the resulting unaligned halfword access, preventing the address-zero call from being reached.
