# F-ac559731d5ae

## Purpose

F-ac559731d5ae coordinates a keyed operation against an existing object. Its normal path resolves a record, passes record-derived data to an embedded object, invokes two additional operations, constructs a temporary context, and conditionally submits an action. It then stores the supplied key and passes the temporary context to a final dependency.

A nonzero byte in the object selects a short path: only the supplied key is stored, and the function returns without invoking any dependency.

These are established control-flow and data-flow properties. Describing the operation as a selection change, refresh, notification, or deferred request would be inferred intent, not an established semantic guarantee.

## Behavior

### Short path

The first direct access reads the byte at object offset `0xE8`.

If that byte is nonzero:

1. The key is written as a 32-bit value at object offset `0xE0`.
2. The function returns.

On this path, the function does not directly write the option byte, inspect the conditional halfword, construct the temporary context, or call any dependency. The other inputs do not affect this path.

The selector is read only once by this function. There is no later recheck.

### Record resolution and embedded-object update

If the initial selector byte is zero, the function first writes the option byte at object offset `0xE4`.

It then invokes F-1f46730b1ced with the address at object offset `0xB0` and the supplied 32-bit key. The returned value is retained for subsequent calls.

If that result is zero, the function invokes F-a817d8d58c10. The supplied static material classifies this invocation as non-returning. Accordingly, the represented zero-result path has no normal continuation, no later direct key store, and no temporary-context finalization.

If lookup returns a nonzero value, the following calls occur in order:

1. F-d2f99870cc43 receives the retained lookup result and returns a 32-bit value.
2. F-89eab22346b0 receives the address at object offset `0x94` and that returned value.
3. F-81a479b6091f receives the original object address.
4. F-fa8898fa75ae receives the retained lookup result.

This sequence establishes neither ownership transfer nor release semantics. In particular, the lookup result is still supplied to a later dependency on some paths, after F-fa8898fa75ae has received it.

None of these calls is followed by an explicit status check in this function. Their mutations, failures, and nonlocal control effects are unknown unless separately specified.

### Temporary-context preparation

After the preceding calls, the function invokes F-fdd8589eca2d twice, with a direct read after each invocation:

1. From the address returned by the first invocation, it reads one byte at offset `0x2C` and retains that byte.
2. From the address returned by the second invocation, it reads a 32-bit value at offset `0x28`.

It then invokes F-2c5a9f9c1eb3 with:

- the address of the 92-byte temporary region;
- the 32-bit value read through the second returned address;
- the byte read through the first returned address.

The two returned addresses must not be assumed identical. The two reads must not be treated as an atomic snapshot. Even if both addresses identify the same storage, the byte read occurs before the second dependency invocation and therefore before any mutations that invocation may perform.

No null check or other address validation is visible before either read.

### Conditional action

The function next invokes F-5c5958cfd5fe and compares its result with the exact value `8`.

If the result equals `8`, the action dependency is skipped. There is no third F-fdd8589eca2d invocation on this branch, and the halfword at object offset `0xE6` is not directly read by this function.

For every result other than `8`, including zero and negative represented values, the function invokes F-fdd8589eca2d a third time. Its returned value becomes the first argument to F-818c773e8c8a.

The final argument to that action call is selected as follows:

| Override argument | Action argument | Final action argument |
|---|---|---|
| Nonzero | Any value | Zero |
| Zero | Zero | Zero |
| Zero | Nonzero | The 16-bit value read at object offset `0xE6` |

Where the halfword is required, its direct read occurs **after** the third F-fdd8589eca2d invocation. Earlier dependencies may have changed the object, so this is not necessarily the value present at entry.

F-818c773e8c8a receives, in order:

1. The result of the third F-fdd8589eca2d invocation.
2. The temporary-region address.
3. The retained nonzero lookup result.
4. The original 32-bit action argument.
5. The selected halfword or zero.

A zero action argument does not suppress this call. A nonzero override argument also does not suppress it; it only forces the final argument to zero. The only ordinary branch that suppresses the action call after temporary-context preparation is a result of exactly `8` from F-5c5958cfd5fe.

The selected object value is established as a 16-bit read. Its signedness and any ABI-level extension when supplied as an argument are not established.

### Completion

After either skipping the action or returning from F-818c773e8c8a, the function:

1. Writes the supplied key as a 32-bit value at object offset `0xE0`.
2. Invokes F-920630e53283 with the temporary-region address.
3. Returns normally if that dependency returns normally.

The key store is therefore after the optional action but before the final dependency. The temporary context is passed to the final dependency even when the action was skipped because the mode result was `8`.

The function does not reread the key from object storage. Its final store uses the original supplied value.

## Side effects

The direct writes established by the supplied material are:

- A 32-bit key store at `0xE0` on the short path.
- An 8-bit option store at `0xE4` on the normal path, before lookup.
- A 32-bit key store at `0xE0` after optional action processing on ordinary normal-path completion.

The direct object reads are the initial selector byte and, on one conditional branch, the halfword at `0xE6`. Two additional direct reads use addresses returned by F-fdd8589eca2d.

This list does not constrain dependency side effects. Dependencies may access shared state, modify the object through aliases, perform external operations, or affect memory reached through their arguments. No supplied dependency contract guarantees preservation of globals or object fields.

Consequently, the last direct key store does not establish the key’s value at return if F-920630e53283 can mutate the same storage. Likewise, dependency mutations may affect later reads.

No explicit allocation, deallocation, reference-count operation, lock, rollback, or exception cleanup is visible in this function. The temporary region has invocation-local lifetime; whether dependencies retain its address is unknown. Safe retention beyond that lifetime is not established.

The function does not provide transactional behavior. For example, the option byte has already been written when a zero lookup result reaches the non-returning dependency.

## Acceptance examples

These are conditional static acceptance cases, not runtime test results. Normal completion assumes all invoked dependencies return normally except the dependency explicitly classified as non-returning.

1. **Nonzero selector.** Given any nonzero byte at `0xE8`, the function directly stores the supplied key at `0xE0` and returns without dependency calls. It performs no direct store to `0xE4`.

2. **Lookup failure.** Given a zero selector and a zero result from F-1f46730b1ced, the option store precedes lookup, then F-a817d8d58c10 is invoked. Under its supplied non-returning classification, no later direct key store or temporary-context call occurs.

3. **Exact skip mode.** Given a nonzero lookup result and mode result `8`, temporary-context preparation still occurs. F-818c773e8c8a is skipped; the key is then stored, followed by F-920630e53283.

4. **Zero is not skip mode.** Given mode result zero, F-818c773e8c8a is invoked. If both condition arguments are zero, its fourth and fifth arguments are both zero.

5. **Forwarded halfword.** Given mode result other than `8`, zero override argument, and nonzero action argument, suppose the halfword is `0xBEEF` at its actual read time. The action receives that 16-bit value as its final argument, subject to unknown argument-extension rules.

6. **Override avoids the halfword read.** Given mode result other than `8` and any nonzero override argument, the final action argument is zero regardless of the action argument. This function performs no direct read of `0xE6`.

7. **Distinct context results.** If the first two F-fdd8589eca2d calls return different readable addresses, temporary preparation receives the byte from the first address’s `0x2C` location and the word from the second address’s `0x28` location. Substituting both values from either one address would not preserve the specified behavior.

8. **Mutation before halfword selection.** If the third context call changes the halfword and the branch requires it, the subsequent direct read observes the changed value, assuming ordinary memory semantics. A value captured before that call would not preserve the specified ordering.
