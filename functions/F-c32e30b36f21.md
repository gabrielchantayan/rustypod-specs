## Acceptance examples

These are conditional requirements, not executed tests.

1. **Entry forwarding.** If the second input is 3 and the initial invocation is reached, its third displayed argument is 192. The first input is forwarded unchanged.

2. **Unsigned field extraction.** For an unsigned intermediate of 0x000abc00, bits 10–19 form 687. Placing that field beginning at bit 6 yields 43,968; beginning at bit 5 yields 21,984.

3. **Defined small index.** If the signed result supplying the small index is 127, its eight-bit left shift is representable. The index is 508; twice it is 1016.

4. **Conditional index bounds.** Under an explicit 32-bit bit-vector shift model, any initial pattern produces an index from zero through 508 in multiples of four. Without that model, the bound requires a defined initial signed shift.

5. **Converted-global base without byte narrowing.** If the 0x05-associated global access and conversion produce 0x00000100, the subsequent +0x15 byte-store destination is 0x00000115, and its +0x54 word location is 0x00000154. The contract does not authorize truncating that captured base to zero. Whether this converted value can arise depends on the missing global declaration and environment.

6. **No inferred extension rule.** A hypothetical signed narrow global value of −1 would convert to unsigned 32-bit value 0xffffffff under ordinary integer conversion rules. This is not evidence that the actual global is signed or narrow; it illustrates why unsigned conversion alone cannot establish zero-extension.

7. **Byte truncation.** A value of 0x123456ab contributes 0xab to an explicit 8-bit store. Adjacent word stores retain their word width.

8. **Intermediate overwrites.** Successful execution preserves the +0x20 store sequence 0x20, 0x2f, the zero-extended +4 byte, then 0x20. Final-memory inspection alone does not verify it.

9. **Independent 0x67 observations.** If admissible memory observations supply 0x12, 0x34, and 0x56 for the three later reads, their consumers write 0x12 to 0x21, then 0x34 and 0x56 through working base +9.

10. **Capture timing.** If the 0xa9 capture observes 0x12345678, later uses retain that word despite subsequent changes at 0xa9. Its capture precedes the scaled-terminal +0x74 read and the 0x3a write.

11. **Interruption.** If a dependency does not return, subsequent local effects are not guaranteed. No rollback of preceding effects is required.
