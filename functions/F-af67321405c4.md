# F-af67321405c4

## Purpose

It returns a 32-bit dependency result, with two explicit zero-return branches: a zero scalar preliminary result and a zero captured collection value. Neither branch is established to denote failure.

The call structure suggests calculation followed by optional output generation: some dependencies first receive a zero output argument, and selected paths later invoke dependencies with the caller’s nonzero output argument. This is inferred intent, not evidence that preliminary calls are side-effect-free or that their results measure output size.

This contract specifies argument selection, memory reads, call ordering, return selection, and locally recognized conditions. The meaning of the processed objects, wrapping operations, and returned values remains undocumented.

## Behavior

### Entry state and path precedence

The function first reads the flags at descriptor offset 0 and retains `flags & 0xC0`. All subsequent flag decisions use that initial flags value.

Path precedence is:

1. If either `0x02` or `0x04` is set, use collection processing.
2. Otherwise, if `0x10` is set, use scalar-wrapped processing.
3. Otherwise, use direct processing.

Later dependency mutations of descriptor flags do not change these decisions. Fields at offsets 4 and 16 are instead read at the stages described below; there is no single immutable snapshot of all descriptor fields.

### Direct processing

### Scalar-wrapped processing

The first call is to F-927fe5381082 with:

1. The caller’s object-slot address.
2. Zero.
3. The word read at descriptor offset 16.
4. `0xFFFFFFFF`.

If its 32-bit result is zero, the function returns zero immediately. It does not read the wrapping parameter at offset 4 or make any wrapping or output-stage call. This is a control-flow condition, not an established failure classification.

2. The preliminary result.
3. The word then read at descriptor offset 4.

When the caller’s output argument is zero, no further calls occur. Otherwise, these calls follow in order:

1. F-208392f0520a receives the caller’s output argument, `1`, the preliminary result, a fresh read at descriptor offset 4, and the saved `0xC0` bits.

### Collection processing

The function reads one 32-bit value from the object slot. If that value is zero, it returns zero without calling any dependency. No field at descriptor offset 4 or 16 is read on this branch.

Otherwise, the captured value becomes the collection argument for all collection operations. The caller’s slot is not reread.
