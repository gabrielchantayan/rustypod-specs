# F-f58de5c36c29

## Purpose

F-f58de5c36c29 conditionally forwards a caller-supplied object and a locally assembled three-word request to F-be41255119f8.

Forwarding occurs only when the object pointer is non-null, the object’s first 32-bit word equals a global comparison value, and a 32-bit field at byte offset 68 is nonzero. If any of these checks fails, this function returns the 32-bit value 7 without calling the dependency.

The request incorporates an opaque caller-supplied 32-bit value, an 8-bit input, and selected bits from the object’s 32-bit field at byte offset 12. The dependency’s return value is passed through unchanged.

The evidence establishes these mechanics, but not their domain meaning. Descriptions such as “object,” “request,” and “comparison value” identify structural roles; they do not establish a particular resource type, protocol, or operation.

### Temporary request layout

The request is represented as three adjacent 32-bit words, totaling 12 bytes:

| Request offset | Width | Value |
|---|---:|---|
| 0 | 32 bits | Payload word, unchanged |
| 4 | 32 bits | `0x0000D800` combined with the selector byte in bits 7–0 |
| 8 | 32 bits | `0xB000C24F` combined with the low object byte, after forcing its `0xA0` bits on, in bits 23–16 |

Let *b* denote the least significant eight bits of the 32-bit object field at offset 12. The third request word is:

`0xB000C24F | ((b | 0xA0) << 16)`

This construction does not add quantities or propagate carries. It inserts and forces bits. Every shift shown operates on a byte-sized value promoted to a representation wide enough for the resulting 32-bit word.

These are numeric word layouts. The source does not independently establish byte order for memory serialization.

## Behavior

### Admission checks

Admission uses short-circuit evaluation:

1. The object pointer is checked against null.
2. If it is non-null, the 32-bit field at offset 0 is compared with the global comparison value.
3. Only if those values are equal is the 32-bit field at offset 68 tested for nonzero.
4. Only if all checks pass is the request constructed and F-be41255119f8 called.

Consequences:

- A null pointer produces result 7 without an object-field access by this function.
- An offset-0 mismatch produces result 7 without reading offset 68 or offset 12.
- A zero value at offset 68 produces result 7 without reading offset 12.
- Any nonzero 32-bit value at offset 68 passes that check. No bit mask, positive-value requirement, or comparison with a particular nonzero constant is present.

The equality comparison requires values from both the object and global storage. The supplied expression does not establish which operand is read first. It establishes that their equality must pass before the offset-68 check is reached.

There is no explicit handling for an invalid non-null pointer, unreadable storage, or an access fault. Such cases are not converted into result 7 by any visible recovery path.

### Request construction

After admission, the function constructs the three-word temporary request.

The supplied representation places construction in this order:

1. Form the second word from the selector byte and fixed value `0xD800`.
2. Read the object field at offset 12 and form the third word.
3. Copy the payload word into the first word.
4. Pass the object pointer and the address of the first request word to F-be41255119f8.

This is the established construction order in the supplied representation, not a promise about individual machine-store instructions. The externally supplied dependency is called only after the request has been assembled.

The second word has these fixed properties:

- Bits 31–16 are zero.
- Bits 15–8 are `0xD8`.
- Bits 7–0 equal the selector byte.

The third word has these properties:

- Bits 31–24 are `0xB0`.
- Bits 23–16 equal the low byte of the object field at offset 12, bitwise ORed with `0xA0`.
- Bits 15–0 are `0xC24F`.

Only the low eight bits of the offset-12 field influence the request. Its upper 24 bits are discarded. The intermediate narrowing shown in the source does not introduce sign extension into the final selected byte.

Within the selected byte, bits corresponding to mask `0xA0` are forced to one. Other bits retain their original values. Consequently, distinct object-field values can produce identical requests, including values that differ only in their upper 24 bits or in low-byte bits already forced on.

### Dependency invocation and return

If the dependency returns normally, its result is returned without translation, masking, retry, or additional admission checking. There is no visible post-call read of the object or comparison global.

If the dependency does not return normally, the source establishes no local recovery or alternative result.
