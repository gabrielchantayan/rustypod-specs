## Behavior

| Destination | Replacement | Relative order |
|---|---|---|
| One byte beyond the auxiliary address basis | Input 4 | Before both captured-basis replacements |
| Seventeen bytes beyond the captured basis | Input 2 | After the auxiliary-basis replacement and before the other captured-basis replacement |

Each replacement is exactly one byte wide.

The captured basis is reused for both of its destinations. Changing the memory from which it was obtained does not, by itself, redirect either destination. This guarantee concerns the captured basis only; it does not establish an immutable entry snapshot of all operands.

Under ordinary nonwrapping address formation, the captured-basis destinations are eight bytes apart. The auxiliary-basis destination can overlap either one. No overlap detection or special overlap handling is established.

When destinations overlap, stable replacement operands and uninterrupted execution give the later replacement precedence at the shared byte. This is a boundary-specific result, not a guarantee that subsequent dependencies preserve the byte.

The external update is not transactional. A later failure does not require restoration of earlier completed writes.
