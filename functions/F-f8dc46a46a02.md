## Acceptance examples

These are conditional static examples, not executed tests.

1. **First store precedes all calls.**  
   Given Slot equals 3 and a valid writable destination, the first explicit effect is a four-byte Payload store at address 32. F-D001 follows that store.

2. **Distinct stores at one calculated word address.**  
   Given R028 equals 2 and valid arithmetic, the function first writes 8 at address 52. After F-D029 through F-D033 return, it writes 32 at address 52. An implementation that emits only the latter store would not preserve the visible contract.

3. **Source-byte changes affect destination selection.**  
   Given First byte-source address initially contains 5, the first associated byte destination is 22. If the byte becomes 9 before its next read, the next destination is 26, not 22.

4. **Byte truncation is observable.**  
   Given R038 equals `0x00100041`, First byte value has low byte `0x04`. The later masked-and-shifted byte value is `0x01`. These are separate stores with intervening calls and separate destination-selection reads.

5. **Fourth-derived store.**  
   Given Fourth equals 256, Fourth base is 2 and the direct byte-store address is 30. Given R050 equals 65, that store writes `0x04`, subject to the stated 32-bit shift interpretation.

6. **First loop argument pair.**  
   Given R062 equals `0x3fffffff`, Initial fragment is 31. F-D063 receives 62. The first F-D065 receives R064 as Carry and zero as its second argument.

7. **Continuing loop state.**  
   Under 32-bit truncating shifts, if an iteration’s R074 equals 3, the next Carry is 12 and the next F-D065 second argument is `0x000c0000`.

8. **No normal completion requirement.**  
   If all dependencies keep returning and every access remains valid, reaching another loop iteration is consistent with the representation. Returning normally after a fixed number of iterations is not.
