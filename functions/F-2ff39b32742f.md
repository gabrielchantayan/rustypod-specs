# F-2ff39b32742f

## Purpose

F-2ff39b32742f conditionally performs four ordered operations and stores four 32-bit results in a destination object. A single unsigned address comparison determines whether those operations occur.

The established behavior is structural: each operation passes an address derived from the input base to F-703a21d21b61, calls F-7431d9b27a62 with no explicit arguments, and stores the latter call’s result. The available evidence does not establish what either dependency does or what the stored values mean.

On normal completion, the function returns a 32-bit status:

- **0x000000A1** when the comparison rejects the operation.
- **0x00000000** after all four result stores complete.

These values distinguish the two visible control-flow outcomes. Their application-level meanings are unknown.

## Behavior

### Initial reads and decision

The direct operations occur in this order:

1. Read the 32-bit destination address from B + 0x198 and retain it as D.
2. Read the 32-bit comparison operand from B + 0x190.
3. Compare that operand against the unsigned 32-bit result of adding 0x1C to B.

The operation is accepted when:

**unsigned32(B + 0x1C) ≤ unsigned32(value read at B + 0x190).**

The addition used for this comparison is 32-bit unsigned arithmetic. It wraps modulo 2³² rather than introducing a wider carry into the comparison. Equality is accepted.

This is an address-value comparison, not an established count-of-bytes check. In particular, the function does not subtract B from the stored operand or independently check how much valid memory follows B.

If the comparison rejects the operation, the function returns 0x000000A1. Neither dependency is called, and no direct destination store occurs.

### Captured addresses and mutable state

D is captured once, before any dependency call. The function does not reread B + 0x198 between stages.

Accordingly, if a dependency changes that field, subsequent direct stores still use the originally captured D. This does not imply that the destination remains valid: a dependency could change memory mappings, release storage, or otherwise make a later access unsafe. Such behavior is neither established nor excluded by the available evidence.

The comparison operand is also read only once by this function. Later changes to B + 0x190 do not cause a second decision.

The addresses passed to F-703a21d21b61 are derived from the original input base, not from a destination field reloaded between calls.

### Partial completion and exceptional outcomes

The comparison is the only visible rejection branch. Null addresses, invalid mappings, dependency-level errors, and invalid destination storage are not converted into additional explicit status codes by this body.
