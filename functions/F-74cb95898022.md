## Behavior

### Initial repeated updates

The first visible operation stores A as a word at B offset `0x54`.

A repeated update pattern then writes:

| Destination | Width | Value |
|---|---:|---|
| Y offset `0x19` | Byte | Low byte of X |
| X offset `0x11` | Byte | Low byte of Y |
| Y offset `0x34` | Word | Initially B; D in subsequent repetitions |
| D offset `0x54` | Word | A |

Within each complete occurrence, the byte write into Y precedes the byte write into X, which precedes the word write into Y, which precedes the word write into the D-derived destination. The final occurrence ends after the word write into Y; the next phase follows rather than another D-derived word write.

These are repeated accesses to the same calculated addresses, not an established traversal through advancing elements. No input-dependent termination condition appears in this region.

For disjoint ordinary memory with no intervening mutation, many of these writes have identical final-state effects. That does not authorize replacing the represented access history with a single write per destination. Aliasing, memory-mapped side effects, concurrent observation, and access faults can make the repetitions observable.

The exact repeated-access count is **documented_only** in this contract; no count has been independently validated.

### Fixed storage and captured words

After the repeated region, execution reads a word from fixed address `0xA9`, followed by a word from A offset `0x74`.

The byte at fixed address `0x3A` is then written with the low eight bits of:

**twice the low byte of X, plus `0x30`.**

This byte result is independent of whether the intermediate character interpretation is signed or unsigned: truncation preserves the same low eight bits. No decimal-digit restriction is established.

Next, word values are read from Z offset `0x14` and X offset `0x04`, in that order. These captured values are used later; they are not specified as fresh reads at their later use sites.

The following visible changes occur before the next word read:

- Z offset `0x0D` receives the low byte of X.
- X offset `0x08` receives byte `0x6C`.
- X offsets `0x0D` and `0x09` receive the low byte of Y, in that order.
- Z offset `0x54` receives Z as a word.
- Fixed address `0x67` receives the low byte of the previously captured word from fixed address `0xA9`.

These writes can alter later read results if their destinations alias later sources.

### Intermediate linkage and overlapping updates

A word is read from Z offset `0x44`; call that captured value **Q**.

The byte at fixed address `0x67` is read and copied to fixed address `0x21`. X offset `0x10` receives the low byte of Q, and Y offset `0x54` receives the full word Q.

Z offset `0x01` then receives a byte derived from a right shift of Q. The represented shift count is the low byte of X. The shift’s signedness and valid-count boundaries require special treatment under **Uncertainties**.

Y offset `0x54` is next overwritten with X. Thus Q is an observable intermediate value there, even though X is the later stored value.

A word is read from X offset `0x40`. Subsequently:

- Y offset `0x74` receives the earlier captured word from X offset `0x04`.
- X offset `0x10` receives the full word just read from X offset `0x40`.
- Y offset `0x44` receives Z.
- X offset `0x09` receives a fresh byte read from fixed address `0x67`.
- Z offset `0x09` receives the low byte of X.
- X offset `0x44` receives the earlier captured word from fixed address `0xA9`.

The word write at X offset `0x10` covers offsets `0x10` through `0x13`. It therefore overlaps both the earlier byte write at `0x10` and the repeated byte writes at `0x11`. Final-byte expectations must account for this word write and target byte order.

### Indirect destinations and terminal updates

A word is now read from X offset `0x54`; call it **P**. This is a current-memory read, not necessarily an entry-state value.

X offset `0x09` again receives a fresh byte read from fixed address `0x67`. P offset `0x0D` receives the low byte of the earlier captured word from A offset `0x74`.

Z offset `0x54` is overwritten with the earlier captured word from Z offset `0x14`. A word is then read from X offset `0x14`; call it **R**.

After that read:

- Z offset `0x11` receives the low byte of the captured word from A offset `0x74`.
- X offset `0x09` receives the low byte of P.
- X offset `0x44` receives P as a word.

A word is read from Z offset `0x04`; call it **J**. A halfword with value `0x0065` is written at the address obtained by doubling J. A word is then read from J offset `0x64`; call it **K**.

P offset `0x11` receives the low byte of R, and P offset `0x54` receives the 32-bit value 100.

A word is next read from J offset `0x74`; call it **T**. A word is then read from Z offset `0x64`; call it **L**.

The final visible memory updates are:

- Z offset `0x09` receives the low byte of J.
- L offset `0x54` receives K as a word.
- The address obtained by doubling K receives L as a word.

The reads defining K and T occur after the doubled-J halfword write. The read defining L occurs after the writes through P. Any aliasing among these locations must therefore be resolved using their values at the indicated access times.

## Acceptance examples

These examples are conditional static expectations, not executed tests.

### Disjoint ordinary memory

Assume all accesses are valid, regions do not overlap, no external mutation occurs, and the indirect target returns without changing the observed locations.

Expected state immediately before the transfer includes:

- B offset `0x54` contains A.
- D offset `0x54` contains A.
- Y offset `0x34` contains D rather than the initially stored B.
- Y offset `0x54` contains X rather than the earlier Q.
- Z offset `0x54` contains the captured entry-phase word from Z offset `0x14`, rather than Z.
- P offset `0x54` contains 100.
- L offset `0x54` contains K.
- The word at doubled K contains L.

These expectations require disjointness from all other destinations, including fixed storage.

### Byte truncation

If X has low byte `0xF0`, the byte written to fixed address `0x3A` is `0x10`: twice `0xF0` plus `0x30` is `0x210`, whose low byte is `0x10`.

Writes described as using the low byte of X contain `0xF0`, regardless of whether a character interpretation treats that byte as negative.

### Replaced intermediate value

If Q differs from X and the two writes to Y offset `0x54` are observable, an observer sees Q before X. A final-state-only implementation that never exposes Q does not reproduce that access history.

### Overlapping byte and word destinations

Assume the later word write at X offset `0x10` stores `0x11223344`, with no subsequent aliasing write to that region.

Under little-endian storage, bytes at offsets `0x10` and `0x11` finish as `0x44` and `0x33`. Under big-endian storage, they finish as `0x11` and `0x22`. Earlier byte writes do not determine these final bytes.

### Aliased indirect source

If P offset `0x54` aliases Z offset `0x64`, the write of 100 through P precedes the read defining L. With ordinary coherent memory and no intervening mutation, L is therefore 100, not the original contents of that location.

### Late failure

If the final doubled-K word destination is inaccessible, earlier writes have already been attempted before that access. No rollback or subsequent indirect invocation is established for the faulting execution.
