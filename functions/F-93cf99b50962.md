# F-93cf99b50962

## Purpose

F-93cf99b50962 prepares an invocation-local context, acquires four 32-bit values, derives two adjustments, performs twelve ordered resource operations, and makes a final context call.

Each iteration uses a dependency’s secondary result to select a three-word record. Two record words supply position components; the third selects an object-relative resource slot. A separate captured base supplies successive address-like arguments for context configuration.

**Established static behavior:** the caller prepares one context, rewrites part of the acquisition workspace, conditionally enables both adjustments, executes twelve iterations on the normal path, and passes the context to a final dependency.

**Inferred intent:** the operation resembles positioning or rendering twelve elements within an available region. Rendering, geometric axes, and the application meanings of the context settings are not established and do not define this contract.

### Adjustment calculation and workspace mutation

Define the **primary span** as the fourth acquired value minus the second acquired value. Define the **secondary span**, when calculated, as the third acquired value minus the first acquired value. Comparisons against 39 are signed.

The calculation has both numerical results and observable workspace writes:

1. The first adjustment is initialized to zero.
2. The caller unconditionally replaces the workspace’s fourth word with the primary span.
3. If the primary span exceeds 39, the caller copies the first acquired value into temporary input storage and writes the third acquired value into the workspace’s second word.
4. The second adjustment is initialized to zero.
5. If the primary span exceeds 39, the caller subtracts the saved first acquired value from the current second workspace word, producing the secondary span, and writes that span back into the second word.
6. Adjustments are calculated only when both spans exceed 39.

Thus, before F-33ca0546dba1 is entered, the caller-written workspace state is:

| Word | Primary span at most 39 | Primary span greater than 39 |
|---|---|---|
| First | First acquired value; not rewritten | First acquired value; not rewritten |
| Second | Second acquired value; not rewritten | Secondary span |
| Third | Third acquired value; not rewritten | Third acquired value; not rewritten |
| Fourth | Primary span | Primary span |

In the right-hand case, the second word has two ordered writes: first the third acquired value, then the secondary span. The second write occurs even if the secondary span is 39 or less and both adjustments remain zero. No dependency call intervenes between these two writes.

This state is not merely scratch arithmetic hidden from dependencies. F-412e4635fdb0 received the workspace address. If it retains that address and makes it available to later dependencies, those dependencies may observe the rewritten words while the invocation remains active. The caller provides no non-retention guarantee.

When both thresholds pass:

- The first adjustment is the primary span minus 39, divided by 2.
- The second adjustment is the secondary span minus 39, divided by 2.

Otherwise, both adjustments remain zero. A large primary span alone does not enable the first adjustment.

The first adjustment applies to record offset 0; the second applies to offset 4. Their order must not be exchanged to fit an assumed geometric convention.

For calculations within the signed 32-bit range, division discards the fractional part. The numerators are positive whenever division is reached. A span of 40 passes its threshold but contributes an adjustment of zero.

The calculations use 32-bit quantities. The supplied representation does not establish a portable overflow rule for subtraction, position addition, or address formation. Widening, saturation, or additional rejection checks are not established equivalents.
