# F-20358a94893b

This contract describes the supplied static evidence. No runtime tests have been performed.

### Postprocessing the optional result

After the dependency returns normally:

- If the optional result pointer is null, this function performs no result-pointer read or write.
- If it is non-null, this function reads the unsigned 32-bit value currently stored there, logically shifts it right by one bit, and writes the resulting 32-bit value back to the same location.

The shift discards the least significant bit and inserts zero at the most significant position. For a value interpreted as an unsigned integer, the stored result is its quotient by two, rounded down.

Crucially, this read occurs **after** the dependency call. The transformed value is whatever is present at that point, not necessarily the value present on entry. The dependency might have written it; it might have left it unchanged; other permitted effects might have changed the storage. The supplied evidence does not choose among those possibilities.

For a valid unsigned 32-bit input to this postprocessing step, the stored result is between 0 and 2,147,483,647 inclusive.

## Acceptance examples

3. **Post-call value takes precedence.**  
   If the result word contains 100 on entry but the dependency leaves it containing 9, the final stored value is 4, not 50.

   Post-call result words of 0 and 1 both become 0.

6. **Logical rather than signed shift.**  
   A post-call result word of `0x80000000` becomes `0x40000000`. A post-call word of `0xFFFFFFFF` becomes `0x7FFFFFFF`. No sign bit is propagated.

7. **Aliasing the first object field.**  
   If the optional result pointer addresses the object’s first field, the dependency’s first argument is formed from the field before the call. After normal return, the current contents of that same field are shifted and overwritten.

8. **Dependency does not return.**
