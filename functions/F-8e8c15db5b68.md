# F-8e8c15db5b68

## Purpose

F-8e8c15db5b68 dispatches a 32-bit selector among three kinds of operation:

- Produce a 16-bit result through a selector-specific static-data dependency.
- Write a zero 16-bit result and, when a context-associated handle is nonzero, invoke a control dependency.
- Invoke a conditional handle operation followed by an unconditional context operation.

Selectors from `0x2E` through `0x3F`, inclusive, are recognized. Other selectors return without directly accessing the context or output destination.

The function also returns a 64-bit value containing two independently significant 32-bit fields. The low field distinguishes recognized from unrecognized selectors. The high field normally preserves the selector, but becomes zero for selectors `0x2E` and `0x2F` when the associated handle is nonzero. Consequently, this return value must not be treated as a simple Boolean or dependency-success result.

These behaviors are established by the supplied static evidence. The application-level meanings of the selectors, static data, and dependent operations are unknown.

## Behavior

### Dispatch and unsupported selectors

Selection uses the complete unsigned 32-bit selector. There is no visible truncation to a byte or normalization before dispatch.

For any value outside `0x2E`–`0x3F`, the function:

- Makes no visible dependency call.
- Performs no direct context read.
- Performs no direct output write.
- Returns the selector in the high 32 bits and zero in the low 32 bits.

Thus an unrecognized selector of zero returns numeric zero, while most other unrecognized selectors return a nonzero value despite having a zero low field.

### Zero-output control operations: `0x2E` and `0x2F`

Both selectors first write a 16-bit zero to the output destination. This write precedes the first context-field read.

The function prepares a 32-bit temporary control value:

| Selector | Initial control value |
|---|---:|
| `0x2E` | `2` |
| `0x2F` | `6` |

It then reads the handle field at context offset `0xB0`.

If that field is zero:

- No F-fc9444c74c1d call occurs.
- The field at offset `0xB4` is not read by this function.
- The return high field remains the original selector.
- The return low field is one.

If the handle test is nonzero:

- The selector value used for the return high field becomes zero.
- The handle field is read for the dependency argument.
- The 32-bit field at offset `0xB4` is read and masked to its low eight bits.
- F-fc9444c74c1d is called with six arguments, in this order:
  1. The handle value.
  2. The masked field value, in the range `0`–`255`.
  3. Zero.
  4. The address of the 32-bit temporary control value.
  5. Zero.
  6. Zero.
- After normal dependency return, this function returns numeric `1`.

The relative evaluation order of the handle argument read and the masked-field argument read is not established by the supplied representation. Both occur after the nonzero test and before the dependency call.

The temporary is addressable by the dependency during the call. Any modification to that temporary is not subsequently used by this function to determine its output or return value. The evidence does not establish permission to retain or later dereference its address after this invocation ends.

The dependency’s return value, if any, is not used. No visible dependency-result check changes the recognized-status field.
