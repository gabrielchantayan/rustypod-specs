On its full-processing path, it also resolves that value through an embedded object region, invokes several dependent operations, constructs a temporary context, and conditionally submits an operation using that context.

Two paths are established by the supplied static evidence:

- **Full-processing path:** Otherwise, record an input byte, resolve the supplied value, perform dependent processing, construct a temporary context, optionally invoke a further operation, record the supplied value, and invoke the temporary context’s final dependency.
