### Immediate termination

- Processing is never invoked.
- No replacement-state acquisition occurs.
- No replacement-to-working-state transfer occurs.

### Negative test result

### Test-side mutation

If the test instead returns zero, the function exits without a subsequent processing or replacement step.

### Complete versus partial replacement

If F-f970f3b0ebd4 writes both replacement words, the next working state receives those two words.

If it leaves a word unwritten, the caller still transfers that word. For the first replacement acquisition, the first word initially contains 1, while the second has no visible initialization. ### Continued traversal
