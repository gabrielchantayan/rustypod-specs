# F-c9f8b0134d07

## Purpose

F-c9f8b0134d07 tests whether an unsigned integer matches a byte encountered while scanning a globally selected, zero-terminated byte sequence.

Under stable-memory conditions, the function returns the 32-bit value **1** if a nonzero byte equal to the complete input value occurs before the first zero byte. It returns the 32-bit value **0** when it encounters that terminator before finding a match.

The input is not visibly narrowed to a byte. Consequently, values greater than 255 cannot match a byte, and an input of zero does not match the terminator under stable-memory conditions.

## Behavior

### Scan origin and progression

Scanning begins at offset zero from the globally supplied base. The function does not skip a header, inspect a length field, or begin after the first byte.

At each offset, it first reads a byte for the terminator decision:

- If that read produces zero, the function immediately returns 0.
- Otherwise, it proceeds to an equality decision at the same offset.

The equality decision uses another byte access. If that access produces a value equal to the input argument, the function immediately returns 1.

If neither decision returns, the offset increases by one, and the same ordered decisions are made at the next offset.

The offset does not advance between the terminator decision and the equality decision.

### Terminator precedence

The terminator decision has priority over equality. Under stable memory, a zero byte ends the scan without being tested as a successful match.

Thus, requesting zero is not a way to find the terminating byte. For an ordinary stable, readable, zero-terminated sequence, input zero returns 0 regardless of the nonzero bytes preceding the terminator.

Bytes after the first observed terminator are not examined. A matching value after that terminator does not affect the result.

### Comparison width

A sequence byte contributes an unsigned value in the range 0 through 255. The supplied representation compares that value with the unsigned integer argument; it does not visibly reduce the argument to eight bits.

This distinction is observable. An argument of 257 does not match a sequence byte of value 1. An argument of 256 does not match a zero byte, and the terminator decision would return 0 before equality at that position in any event.

For stable, properly terminated input memory, every argument greater than 255 returns 0. Such an argument does not cause an immediate rejection: the function still scans until it observes a zero terminator.

### Distinct reads and changing memory

The supplied representation contains separate accesses for the terminator check and the equality check. It also refers to the global base separately for those accesses, rather than visibly taking one immutable base snapshot for the entire scan.

Accordingly, the static description must not collapse an iteration into one byte observation:
