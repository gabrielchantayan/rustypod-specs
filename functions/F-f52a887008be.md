# F-f52a887008be

## Purpose

F-f52a887008be selects one of four byte-sized values using an unsigned 16-bit shared quantity and writes `1` to the object byte at offset `0xCC`. It then follows one of two paths:

- An object-local path records the selected value and a value returned by a dependency.
- A shared-state path publishes the selected value, conditionally returns early, or requests an operation and waits for a nonzero byte before invoking a final dependency.

The application meanings of the quantity, selected values, object fields, shared fields, and requested operation are not established. In particular, the write at `0xCC` does not establish an active-state interpretation.

The function has no explicit return value. Observable behavior consists of memory accesses, dependency calls, and possible nontermination while waiting.

## Behavior

### Initial capture and conditional call

The function captures the address held in G1 before reading the object byte at `0xC1`.

If that object byte equals `5`:

1. F-e1ece1dbf991 is called with the object address.
2. After it returns, `1` is written to byte offset `0` of the previously captured G1 target.

Otherwise, neither this call nor this write occurs.

G1 is not reloaded for the conditional write. Replacing G1 during F-e1ece1dbf991 therefore does not redirect that write. Mutations to the captured target, including effects through overlapping storage, can influence subsequent reads.

### Selection from the shared quantity

The function selects a byte using the unsigned 16-bit quantity at offset `2` of the captured G1 target. When that quantity remains stable during selection, the mapping is:

| Quantity | Selected byte |
|---:|---:|
| `0`–`99` | `1` |
| `100`–`499` | `4` |
| `500`–`999` | `6` |
| `1000`–`65535` | `7` |

Selection is represented by successive conditional reads rather than a single captured quantity:

- The first read is compared with `1000`. A value at least `1000` selects `7`.
- If the first read is below `1000`, a second read is compared with `500`. A value at least `500` selects `6`.
- If the second read is below `500`, a third read is compared with `100`. A value below `100` selects `1`; otherwise it selects `4`.

Thus, one, two, or three represented 16-bit reads occur. If the quantity changes between them, the result follows the decisions from those successive reads, not necessarily the stable-value table.

The comparisons do not scale, subtract from, or otherwise arithmetically transform the quantity. All four possible results fit in eight bits.

### Common object write and dependency call

After selection, the function:

1. Writes `1` to the object byte at `0xCC`.
2. Reads the 32-bit object field at `0x34`.
3. Calls F-unmapped-01 with that field value.
4. After the call returns, reads the object byte at `0x60`.

The path decision uses the byte read after F-unmapped-01. Effects of that dependency can therefore change which path is taken. The selected byte is retained and is not recomputed after the call.

### Object-local path

When the object byte at `0x60` is nonzero, the function:

1. Writes `1` to object byte `0x61`.
2. Writes the selected byte to object byte `0x68`.
3. Calls F-unmapped-02 with no explicit arguments.
4. Writes its 32-bit result to object offset `0x64`.
5. Returns.

This path does not directly perform shared-state publication, call F-f864d4b0c549, capture G3, or enter the polling loop.

The result write occurs after F-unmapped-02 returns. The function does not restore the earlier object-byte writes if that dependency changes them.

### Shared-state publication

When the object byte at `0x60` is zero, the function:

1. Calls F-c979b3c48e40 with no explicit arguments.
2. Captures the target address held in G2.
3. Publishes the selected byte at offset `0` through G2.
4. Calls F-fa1e7c5a0d15 with the Boolean result of “selected byte is greater than `3`.”
5. Reads byte offset `1` of the captured G2 target.
6. Interprets that byte as signed eight-bit data, extends it to a signed 32-bit integer, and passes it to F-c39b71dff8cc.

The target capture and publication use separate G2 expressions in the supplied representation. No dependency call intervenes. With a stable G2 slot, both refer to the same target; no concurrency guarantee establishes that the slot cannot change between them. Subsequent offset-`1` accesses use the captured target.

F-fa1e7c5a0d15 receives `0` for selected value `1`, and `1` for selected values `4`, `6`, and `7`.

The byte passed to F-c39b71dff8cc is read after F-fa1e7c5a0d15 returns. That dependency can therefore affect the argument. Under the represented signed-byte interpretation, stored values `0x80` and `0xFF` become `-128` and `-1`, respectively.

### Conditional early return

The result of F-c39b71dff8cc is treated as an unsigned 32-bit value. It is compared with the Boolean result of “selected byte is greater than `4`”:

| Selected byte | Comparison value |
|---:|---:|
| `1` | `0` |
| `4` | `0` |
| `6` | `1` |
| `7` | `1` |

If the result is unequal to this comparison value, execution continues without a sentinel read.

If the result is equal, the function reads byte offset `1` of the captured G2 target again:

- A value other than `0xFF` causes an immediate return.
- A value of `0xFF` permits execution to continue.

This second byte read occurs after F-c39b71dff8cc returns and can differ from the byte used as its argument.

The two Boolean thresholds are distinct. Selected value `4` produces argument `1` for F-fa1e7c5a0d15 but comparison value `0` for this early-return decision.

Early return does not undo publication or any preceding writes and calls.

### Operation request

If execution does not return early, the function:

1. Writes the selected byte to offset `1` of the captured G2 target.
2. Writes the fourth argument into the first 32-bit word of the temporary two-word storage.
3. Calls F-f864d4b0c549 with integer `4` and the temporary storage address.
4. After that call returns, loads the address held in G3.

The second temporary word is not explicitly initialized. The dependency’s actual read range, write range, and retention behavior are unknown. The first word cannot be assumed to retain the fourth argument after the call.

The G3 address load is represented even when F-f864d4b0c549 returns zero.

### Conditional wait and final call

If F-f864d4b0c549 returns zero, the function returns without directly reading G3’s target byte or calling F-b4c8a64376c1.

If the result is nonzero:

- The least significant eight bits of the temporary first word, as it exists after the dependency call, are captured.
- The byte at offset `2` of the captured G3 target is read.
- Each zero readiness read is followed by a call to F-unmapped-03 with arguments `0` and `1`, followed by another readiness read.
- When a readiness read is nonzero, F-b4c8a64376c1 is called with the captured eight-bit value and integer `0`.
- The function returns after that final call returns.

The eight-bit conversion truncates the first word to its low eight bits. It is not described as reading the first addressed byte, so this value rule does not depend on an assumed memory byte order.

The captured value is not refreshed during polling. The captured G3 target is likewise not refreshed if a polling dependency replaces G3.

There is no visible timeout, iteration limit, cancellation check, or error result. If readiness remains zero and each polling call returns, execution continues indefinitely.

## Acceptance examples

These are conditional static acceptance examples, not executed tests. Unless otherwise stated, assume valid nonoverlapping storage, stable global pointer slots and quantity reads, returning dependencies, and no dependency mutations beyond those specified.

1. **Threshold boundaries.** Quantities `99`, `100`, `499`, `500`, `999`, and `1000` select `1`, `4`, `4`, `6`, `6`, and `7`, respectively.

2. **Changing quantity.** If the successive quantity reads are `900`, `400`, and `150`, all three reads occur and the selected byte is `4`. The first value does not independently determine selection.

3. **Initial conditional call.** If object byte `0xC1` is `5`, F-e1ece1dbf991 runs before the write of `1` to captured G1 byte `0`. Replacing G1 during that call does not redirect the write.

4. **Common write and branch timing.** The write of `1` to object byte `0xCC` precedes F-unmapped-01. If that dependency changes object byte `0x60` from zero to nonzero, the subsequent path is object-local.

5. **Object-local completion.** With selected value `4` and a nonzero post-call byte at `0x60`, the function writes `1` at `0x61`, writes `4` at `0x68`, and stores F-unmapped-02’s 32-bit result at `0x64`, then returns.

6. **Distinct Boolean thresholds.** With selected value `4`, F-fa1e7c5a0d15 receives `1`. If F-c39b71dff8cc returns `0` and the later sentinel read is not `0xFF`, execution returns before overwriting captured G2 byte `1` or requesting an operation.

7. **Sentinel permits continuation.** With selected value `6`, a result of `1` satisfies the first early-return comparison. If the subsequent sentinel read is `0xFF`, execution continues, writes `6` to captured G2 byte `1`, and calls F-f864d4b0c549.

8. **Signed argument and reread.** If the argument byte is initially `0xFF`, F-c39b71dff8cc receives `-1`. If it changes that byte to `2` and returns the matching comparison value, the subsequent read causes early return.

9. **Unequal result.** If F-c39b71dff8cc returns `2`, it cannot equal either Boolean comparison value. The sentinel read is skipped and the operation-request path is reached.

10. **Zero operation result.** If F-f864d4b0c549 returns zero, G3 is loaded, but there is no direct readiness-byte read or final dependency call.

11. **Post-call value and waiting.** If the temporary first word is `0x123456AB` after a nonzero operation result, and readiness reads are zero, zero, then nonzero, F-unmapped-03 is called twice. F-b4c8a64376c1 then receives `0xAB` and `0`.

12. **No readiness transition.** If every readiness read is zero and every polling call returns, there is no final call and no normal return.
