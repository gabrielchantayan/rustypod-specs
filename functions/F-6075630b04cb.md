## Acceptance examples

These are conditional static criteria, not executed tests.

- **Initial publication:** Selector 3 produces destination `0x20`. If writable, it receives the complete payload before the ambient read or any dependency call. Selector zero produces `0x14`, without a visible skip.
- **Explicit byte selection:** An explicitly read selector byte of `0xff` directs a byte write to `0x110`. This bound is not imposed on undeclared-global expressions without their missing types.
- **Fresh global arguments:** The call after the upper-result-plus-`0x1c` publication and subsequent selector sequence must obtain its arguments through two fresh direct `0x01` global references. Reusing the preceding retained selector twice does not satisfy the contract. Either argument-reference evaluation order is admissible.
- **Ordering boundary:** That call precedes the clear using signed-result-times-\(2^{25}\)-plus-one and both zero-address publications.
- **Global reread:** If the direct global clear after the zero-address word publication selects one destination, intervening calls may change the global so the later unsigned capture selects another. Equality is not required.
- **Unknown-width assignment:** If the retained result assigned to `0x7c` is `0x12345678`, the following duplicated arguments use that retained result. Four stored bytes equal to it are not required by the available evidence.
- **Retained `0x28` capture:** A first reference converted to `0x11223344` supplies the later 32-bit publication even if the two argument references produce different values.
- **Separate conversions:** If the first separate-global reference converts to unsigned `0x400`, its masked-right-shift argument is 1. Independently, if the second reference’s multiplication and conversion produce signed 12, its selector-source address is `0x0d`.
- **Repeated writes:** Captured selector `0x81` produces successive word values `0x81` and `0x102` in the first `0x34` pair. Both writes remain required displayed events.
- **Interruption:** If the first dependency never returns, the initial write and ambient read have already occurred; later effects and cleanup are not promised.
