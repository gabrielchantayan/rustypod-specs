# F-3bcbe089f356

## Purpose

F-3bcbe089f356 conditionally copies one 32-bit value from a fixed byte offset within a caller-supplied memory region into an optional output location.

The first argument controls the result status. A zero first argument produces a failure-status bit pattern without accessing either memory location. A nonzero first argument produces a success status on normal return, whether or not an output location was supplied.

**Inferred intent:** this is an accessor with an optional output argument. The semantic meaning of the accessed value and the status convention are not established.

## Behavior

The function first tests whether the source reference is zero.

If it is zero, the function returns `0xFFFFFF40`. It does not read the value at byte offset 12, write to the output, or inspect the output pointer to decide whether a write is needed.

A nonnull output does not change this result. Any existing output contents remain untouched by this function.

### Nonzero source reference with null output

If the source reference is nonzero, the function tests the output pointer.

If the output is null, the function returns zero without reading the source value. Consequently, this path does not establish that the source region exists, is readable, has sufficient extent, or contains a meaningful value.

This distinction is part of the behavior: a nonzero source paired with a null output is accepted without dereferencing the source.

### Nonzero source reference with nonnull output

- Reads one 32-bit unit beginning at byte offset 12 from the source base.
