# F-b297900df1c3

## Purpose

F-b297900df1c3 selects an action using a lookup result and, when that result is nonzero, up to two bytes in the returned record. Its observable behavior consists of dependency calls, conditional state writes, and a conditional write through an address stored in the input object.

There are four outcomes:

- A zero lookup result causes an immediate return.
- Two zero selection bytes cause a dependency-provided value to be submitted with an embedded-object address.
- A zero primary byte and nonzero secondary byte cause an embedded-object operation followed by two writes.
- A nonzero primary byte causes a state write followed by submission of a value obtained from global storage.

“Object,” “record,” “state,” and “submission” describe structural roles. Their application meanings are not established. In particular, the embedded-object operation is not established to destroy, reset, cancel, or release anything.

This contract describes static evidence, not observed execution.
