# F-049c16594f8c

## Purpose

One branch additionally copies that record into an earlier region of the object and performs a final dependency call.

**Established static behavior:** the function returns a 64-bit value assembled from the first two words of its working record. The branch decision comes from F-341a4429b84a, not from an explicit comparison of the consumed word.

**Inferred intent:** the object appears to contain cursor-driven state and two four-word records. The function may be preparing or restoring a state transition. No domain interpretation, ownership transfer, or success/failure meaning is established.

This contract describes the supplied static representation. No runtime tests have been performed.

It then writes the address one four-byte word before the entry cursor back to offset 28. Only after this write does it read the four-byte word at the entry cursor.

The ordering is significant:

1. Read the entry cursor from offset 28.
2. Publish the decremented cursor to offset 28.
3. Read the word at the entry cursor.

The consumed word is therefore not necessarily the word that existed before the function began. If the entry cursor points to offset 28 itself, the read observes the cursor field after its decrementing write, subject to the target’s memory semantics.
