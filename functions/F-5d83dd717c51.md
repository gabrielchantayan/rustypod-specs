# F-5d83dd717c51

## Purpose

F-5d83dd717c51 conditionally performs an opaque numeric calculation, writes a derived 32-bit word into a receiver, and invokes a method on an associated object. A nonzero result from that method causes a further method call on the receiver.

The active path requires both:

- A non-null associated-object pointer captured from the receiver.
- A receiver field strictly greater than the second argument under signed 32-bit comparison.

If either condition fails, the function returns 3 without invoking dependencies or explicitly writing receiver state.

The numeric dependencies’ mathematical meanings are not established. This contract specifies their observable inputs, result flow, memory accesses, and ordering without treating them as known conversions or arithmetic operators.

## Behavior

### Gate

The first relevant memory access captures the associated-object pointer from receiver offset `0x010`.

If that pointer is null, the function returns 3. It does not read receiver offset `0x42C`, read the two global inputs, call a dependency, or explicitly write receiver state.

Otherwise, it reads receiver offset `0x42C`. The active path is taken only if this field is strictly greater than the second argument when both are interpreted as signed 32-bit values.

The comparison combines inequality with subtraction-sign and signed-overflow information. It must not be replaced by an unsigned comparison or by testing only the sign of wrapped subtraction. Equality fails the gate.

If the gate fails, the function returns 3 without entering the numeric pipeline. The gate is not reevaluated after dependency calls.

## Acceptance examples

These are conditional consequences of static evidence, not executed tests.

### Null associated object

Given a receiver readable at offset `0x010`, with that field zero:

- Return 3.
- Do not read offset `0x42C` or either global input.
- Do not call numeric dependencies or virtual methods.
- Do not explicitly write offset `0x43C`.

The other three arguments do not change this path.

### Equality and signed boundaries

With a non-null associated object, equal bit patterns in receiver offset `0x42C` and the second argument fail the gate.

For a comparison field of `0x80000000` and a second argument of `0x7FFFFFFF`, the gate also fails: the first value is signed-negative and smaller.

Reversing those two values passes the gate, even though wrapped subtraction alone has a misleading sign.

### Global values changed by a dependency

F-596e18a33aec receives those changed values as its third and fourth explicit arguments, respectively. Entry-time contents are not substituted.

This example does not specify which global is read first. If contents can change between the reads, the supplied evidence does not establish a paired snapshot or a particular read order.
