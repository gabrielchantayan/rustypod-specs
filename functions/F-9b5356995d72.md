# F-9b5356995d72

## Purpose

The second call produces an integer result. The third receives that result shifted left by two bit positions. No other ordinary-call result is explicitly used.

The established contract concerns call order, target selection, argument formation, and the terminal boundary. An application-level purpose—such as initialization, resource management, or shutdown—is not established.

This specification rests on static evidence only. Dependency behavior, machine-specific arithmetic, and the final disposition of execution remain unresolved where stated.
