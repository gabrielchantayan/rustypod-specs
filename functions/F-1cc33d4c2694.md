## Acceptance examples

These examples are conditional static expectations, not executed tests. Each requires valid accessible storage and the absence of aliasing that would invalidate its stated premises.

### Explicit input truncation

If the second input is `0x123456AB`, P offset `0x24` receives the full value, while the two consecutive early writes to A offset `0x0D` each write `0xAB`.

A later observation of A offset `0x0D` need not yield `0xAB`: subsequent stores replace that byte with the low byte of R1 and then the low byte of X.

### Replacement at A offset `0x54`

If the relevant regions do not overlap unexpectedly, A offset `0x54` is read into U, then receives A, and later receives decimal 100 as a full-width value.

The byte written to L offset `0x11` comes from the captured U, not from the later value A or 100.

### Fresh linkage reads

If an earlier write changes Q offset `0x04`, the subsequent traversal used to obtain S follows the changed value. An implementation that reuses R0 without preserving this possibility would not match the represented behavior.

Likewise, the late read producing Q1 must not be replaced unconditionally with the earlier Q.

### Character-conversion boundary

If the byte read at A plus Z is `0x7F`, J is 127 under either ordinary signed-byte or unsigned-byte interpretation.

If that byte is `0xFF`, J remains documented-only: it may be 255 or `0xFFFFFFFF` under those two interpretations. Destinations derived from J and the first indirect argument depend on that unresolved choice.

### Addition versus bitwise OR

If J is 1, the byte-store destination based on J and `0x44` is address `0x45`, but the first indirect argument is also `0x45` only because of that particular bit pattern.

If J is `0x44`, that destination is address `0x88`, while the first indirect argument remains `0x44`.

### Failure after partial mutation

If the store at the address formed by doubling N cannot complete, earlier successful stores have already occurred. The representation provides neither rollback nor a guaranteed subsequent indirect invocation.
