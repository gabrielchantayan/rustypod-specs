# F-8b354e218ab8

## Purpose

- **0** means all four corresponding pairs compare equal.
- **1** means at least one corresponding pair compares unequal.

Comparison proceeds from the first position toward the fourth. An unequal pair prevents comparison of every later pair.

This is not an ordering comparator. It does not distinguish a smaller value from a larger value, identify the mismatch position, or count differences. Describing it as a fixed-size equality helper is inferred intent; the supplied body establishes no application-specific meaning for the elements.

| First | Unconditional | Return 1 without comparing later positions |
| Second | First pair equal | Return 1 without comparing later positions |
| Third | First and second pairs equal | Return 1 without comparing the fourth position |
| Fourth | First three pairs equal | Return 1 |

No element value acts as a terminator. Zero, negative values, repeated values, and integer boundary values are ordinary comparison operands. Equal zero values do not end the comparison.
