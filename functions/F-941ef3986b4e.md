### Opening memory boundary

A word store at 256 times the final lower word plus 0x54 contains the multiplied base. Only afterward is shifted base plus 9 overwritten with the shifted base’s low byte. The two byte stores have different payload origins and are separated by a word access; neither may be discarded solely because their destinations coincide.

Multiplied base plus 0x14 next receives a zero word. A byte read from multiplied base plus 5 precedes a zero-word store at selector base plus 0x14. That byte is widened into a word at multiplied base plus 0x34.

### Upper-word byte origin

Suppose the final upper word is 0x123456ab, the lower word is 0x000003cd, and the shifted base is 0x02000000.

If reached arithmetic and accesses succeed, the first byte write at 0x02000009 contains 0xab, not 0xcd. The intervening word write addresses 0x0003cd54 and contains the multiplied base. The subsequent byte write at 0x02000009 contains 0x00.

The final byte value alone does not establish equivalent behavior.

### Selector source versus indirect destination

Suppose the selector is 0x84, making the selector base 0x108. Its offset-0x74 word is therefore at 0x17c.

If both reads used by the indirect assignment return 0x1000, that assignment stores word 0x1000 at 0x1054. It does not explicitly assign 0x17c. Under ordinary memory semantics and absent overlapping writes, the source word remains unchanged.

If the later fresh read from 0x17c instead returns 0x2000 because of an intervening overlapping store, its doubled result is 0x4000, not the cached double of 0x1000. Conversely, if a loaded destination base makes its offset-0x54 address equal 0x17c, an indirect store can modify the source through aliasing.

### Width and input propagation

For third input 1, the early consuming call receives 64 in its third represented position. Input zero supplies zero without bypassing surrounding calls.

For an apparent 64-bit result whose upper word is 0x00000080, a wide right shift by 36 yields 8. A reduced-count 32-bit shift is not equivalent.

### Distinct fixed-write payloads

For loaded link 0x1234 and selector 0x84, with defined arithmetic, fixed word 0x54 receives 0x2468, while fixed byte 0x15 receives 0x08. Neither payload may be substituted for the other.

### Retention versus fresh reads

If the 0x05 byte read returns 0x80, the retained base is 128 and its offset-0x54 load addresses 0xd4. Later changes to 0x05 do not replace that base.

The three 0x67 reads are fresh. Under coherent ordinary-memory semantics, an overlapping write changing 0x67 from 0xab to 0x5e causes a later read to supply 0x5e, not cached 0xab.
