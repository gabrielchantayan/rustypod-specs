# F-f98e532f5404

It first clears both caller-provided outputs. It then checks whether a selector matches a shared comparison value and, only if that comparison succeeds, whether a 32-bit field located four bytes beyond an input base is nonzero. If both conditions hold, it invokes F-e19a821f5d85 and publishes two temporary words to the outputs.

The established behavior is a conditional call and ordered output writes. The meanings of the selector, shared comparison value, object field, and produced words are not established. ### Gate evaluation

The selector is compared for equality with the shared comparison value.

- If they differ, the function returns zero without reading the field at base plus four and without calling F-e19a821f5d85.
- If they are equal, the function reads the integer field at base plus four.
