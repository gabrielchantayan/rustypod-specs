# F-ae8c01d8231d

## Purpose

F-ae8c01d8231d performs a fixed sequence of indirect calls interleaved with memory reads, memory writes, and a global assignment. It forwards input and return-value bits, retains selected values across calls, copies and clears fields, performs two byte-selected writes, and finally attempts a call through address zero.

No application-level purpose is established. Initialization, serialization, resource management, and shutdown are possible interpretations, not supported contracts.

This specification distinguishes:

- **Established static evidence:** explicitly represented operations, widths, arguments, and ordering.
- **Inferred interpretation:** arithmetic relationships or descriptive groupings that do not assign an application purpose.
- **documented_only:** unresolved behavior that must not be replaced with assumptions.

Every later operation is conditional on earlier calls returning and earlier accesses completing. No runtime tests have been performed.

## Interface

### Explicit inputs

The represented interface has four 32-bit input slots.

| Input | Established use |
|---|---|
| First | Passed unchanged to F-d001. |
| Second | No explicit use is represented. |
| Third | No explicit use is represented. |
| Fourth | Logically shifted right by 23 bits and passed as F-d003’s third explicit argument. |

The fourth-input extraction includes bits 23–31 and therefore ranges from 0 through 511. It is a nine-bit extraction, not an eight-bit extraction.

The absence of explicit uses of the second and third inputs does not establish their irrelevance to indirect dependencies. Hidden register arguments and the actual calling convention are **documented_only**.

### Implicit inputs

Execution also depends on:

- An incoming link-related value used to derive F-d001’s target by adding 3976.
- An incoming register-derived 32-bit value that is later shifted left by one.
- An address-base global read partway through execution.
- Contents of the locations read by the routine.
- Indirect dependency behavior and return values.
- An auxiliary pointer exposed by the return state of the final result-producing dependency.

The routine does not explicitly validate these prerequisites.

### Outputs and completion

No explicit return value is represented.

Observable outputs comprise dependency invocations, direct memory writes, and assignment to the global `SupervisorCall`. A return is represented after F-d082, but F-d082 is called through address zero. Whether this transfer executes, faults, does not return, or returns normally is **documented_only**.

No explicit error code, status check, exception handler, rollback, or alternate recovery path is shown.

### Values and widths

The following descriptive names are used throughout:

- **First scaled address:** four times F-d007’s result.
- **Retained scaled value:** F-d012’s result shifted left by two.
- **Saved word:** a 32-bit word acquired after F-d021.
- **Saved global base:** the address-base global’s value captured after F-d054.
- **Captured word:** a 32-bit word subsequently read at saved global base plus 20.
- **Final low half** and **final high half:** the low and high 32-bit halves of F-d064’s represented 64-bit result.

All offsets are byte offsets. A word access is 32 bits; a halfword access is 16 bits; a byte access is eight bits. Byte stores retain the source’s low eight bits. Selector-byte reads are unsigned.

Logical right shifts of unsigned 32-bit values insert zeros. Unsigned 32-bit left shifts discard bits beyond bit 31. Some other scaling and address calculations use signed 32-bit intermediates in the supplied representation. Overflow, negative signed shifts, and resulting machine-address semantics are **documented_only**. This contract does not impose a universal wrapping rule on those cases.

No additional object base is implicit in the small arithmetic addresses described below.

## Behavior

### Call-site notation

F-d001 through F-d082 are opaque identifiers for ordered call sites. They do not establish 82 distinct callee implementations.

“No explicit arguments” means none are represented at that site; it does not exclude hidden register, memory, or global inputs. Unless a result is described as consumed, the caller does not explicitly use it.

### 1. Initial forwarding and repeated byte copy

The initial call sequence is:

1. F-d001 receives the first input.
2. F-d002 returns a represented 64-bit pair.
3. F-d003 receives the pair’s low 32 bits, its high 32 bits, and the fourth input logically shifted right by 23, in that order.
4. F-d004, F-d005, and F-d006 execute in order without explicit arguments.
5. F-d007 supplies a 32-bit result.

Four times F-d007’s result becomes the first scaled address. The routine reads a word at that address plus 116 and writes the word’s low byte at that address plus 1.

F-d008 receives the first scaled address. F-d009, F-d010, and F-d011 then execute in order without explicit arguments. F-d012 supplies another 32-bit result, whose left shift by two forms the retained scaled value.

After F-d012 returns, the routine again reads a word at first scaled address plus 116 and writes its low byte at first scaled address plus 1. This is a fresh read. It must not be replaced by reuse of the first word, because intervening dependencies may have changed memory.

F-d013 receives four explicit arguments:

1. The incoming register-derived value shifted left by one.
2. The retained scaled value.
3. The retained scaled value again.
4. F-d012’s result shifted left by 18.

The signed-shift caveat applies where the represented operands are signed.

### 2. Saved-word acquisition and first propagation

F-d014 returns a value forwarded unchanged to F-d015. F-d016 returns another value forwarded unchanged to F-d017.

F-d018, F-d019, and F-d020 execute in order without explicit arguments. F-d021 returns a result that is multiplied by four to form a source address.

The routine then:

1. Reads a 32-bit word at that source address plus 116.
2. Retains the entire value as the saved word.
3. Writes its low byte at source address plus 1.
4. Calls F-d022 with the source address.

F-d023, F-d024, and F-d025 execute without explicit arguments. F-d026 returns a result. The saved word is written as a full 32-bit value at sixteen times that result plus 20.

F-d027 receives the retained scaled value logically shifted right by two and then shifted left by 16. This argument’s low 16 bits are zero.

If formation of the retained scaled value is interpreted as a wrapping 32-bit left shift, F-d027’s argument contains F-d012’s original low 16 bits in the upper halfword. That equivalence is conditional on the arithmetic interpretation; it does not resolve problematic signed shifts.

### 3. Further saved-word propagation and scaled-value store

F-d028 returns a value forwarded unchanged to F-d029. F-d030 returns a value forwarded unchanged to F-d031.

F-d032, F-d033, and F-d034 execute without explicit arguments. F-d035 returns a result. The routine writes the saved word at four times that result plus 20, then calls F-d036 with four times that result.

F-d037, F-d038, and F-d039 execute without explicit arguments. F-d040 returns a result that is shifted left by two.

The routine writes this new scaled result at the address obtained by clearing the retained scaled value’s low two bits and adding 20. F-d041 then receives the new scaled result in both explicit argument positions.

Under ordinary low-bit arithmetic, clearing the retained scaled value’s low two bits changes nothing, because that value was formed by shifting left by two. This observation does not eliminate the represented masking operation or its arithmetic qualifications.

### 4. Zero store

F-d042 returns a value forwarded unchanged to F-d043. F-d044 returns a value forwarded unchanged to F-d045.

F-d046, F-d047, and F-d048 execute without explicit arguments. F-d049 returns a result.

The routine writes a 32-bit zero at four times that result plus 20. F-d050 then receives four times that result.

No explicit comparison, range check, or null check precedes this store or the preceding stores.

### 5. Pair-derived stores and global-base capture

F-d051, F-d052, and F-d053 execute without explicit arguments. F-d054 returns a represented 64-bit pair.

The routine shifts the pair’s low 32-bit half left by two and writes that scaled value at four times the pair’s high 32-bit half plus 20.

After this store, and before F-d055, the routine reads the address-base global and retains its value as the saved global base. A preceding store that aliases the global can therefore affect the captured base.

F-d055 receives:

1. The scaled low half.
2. The unscaled high half.
3. The scaled low half again.
4. The scaled low half again.

F-d056, F-d057, and F-d058 execute without explicit arguments. F-d059 returns a result.

The routine then performs these operations in order:

1. Writes the previously scaled low half at four times F-d059’s result plus 20.
2. Reads a 32-bit word at saved global base plus 20, retaining it as the captured word.
3. Calls F-d060 with four times F-d059’s result.

The address-base global is not reread for this word access. Changes to that global during F-d055 through F-d059 do not alone redirect the read.

The immediately preceding word store may alias the captured-word source. If it does, the subsequent read observes the store’s effect, subject to the target’s memory-access semantics.

### 6. First byte-selected write

F-d061, F-d062, and F-d063 execute without explicit arguments. F-d064 returns a represented 64-bit pair, establishing the final low half and final high half.

Before F-d065, the routine:

1. Logically shifts the saved word right by 23.
2. Adds 1 to obtain a selector-byte address.
3. Reads an unsigned byte at that address.
4. Adds 17 to the byte’s numeric value to obtain a destination address.
5. Writes the captured word’s low byte at that destination.

The selector address ranges from 1 through 512. The destination ranges from 17 through 272. The selector byte supplies a numeric address component, not a pointer-sized value.

F-d065 receives the final high half in each of its first three explicit argument positions, followed by the final low half shifted left by two.

### 7. Second byte-selected write

F-d066 returns a value forwarded unchanged to F-d067. F-d068, F-d069, and F-d070 execute without explicit arguments. F-d071 returns a 32-bit result.

Before F-d072, the routine:

1. Clears the final low half’s top two bits.
2. Logically shifts the remaining value right by 21.
3. Adds 1 and reads an unsigned selector byte at that address.
4. Adds 17 to the selector’s numeric value.
5. At the resulting destination, stores the low byte of the captured word logically shifted right by 22.

The stored byte consists of original captured-word bits 22–29, not its highest byte.

This selector address also ranges from 1 through 512, and its destination ranges from 17 through 272.

F-d072 receives F-d071’s result shifted left by two.

The two selected destinations may coincide. If they do, the second direct byte write replaces the first byte at that address. Intervening dependencies may also modify it. The second selector is read later and may observe an earlier write, including the first selected write if their addresses overlap.

### 8. Final calls, global assignment, and clearing

F-d073, F-d074, and F-d075 execute without explicit arguments. F-d076 returns a result. F-d077 receives that result shifted left by two in both explicit argument positions.

F-d078 executes without explicit arguments. F-d079 returns a value forwarded unchanged to F-d080.

F-d081 then executes without explicit arguments. Its result is assigned to `SupervisorCall`.

After that assignment, the routine:

1. Writes a zero byte through the auxiliary pointer exposed by the return state.
2. Writes a zero halfword at the address obtained by clearing the final low half’s top two bits and logically shifting right by seven.
3. Calls F-d082 through address zero with three explicit zero arguments.

No dependency call intervenes between F-d081, the global assignment, the two clearing writes, and F-d082.

The halfword-clear address ranges from 0 through 8,388,607. It can be odd; alignment is not guaranteed. The acceptability of an odd halfword address is **documented_only**.

- Three corresponding byte stores, including two stores to the same first address expression at different times.
- Six direct 32-bit memory stores: two saved-word stores, three scaled-value stores, and one zero store.

## Acceptance examples

These are conditional consequences of the static representation, not executed tests. Each assumes preceding execution completes and required accesses and arithmetic are valid.

1. **Nine-bit input extraction.** A fourth input of `0xFFFFFFFF` produces 511 as F-d003’s third explicit argument. A fourth input of `0x00800000` produces 1.

2. **Fresh repeated read.** If the first scaled address is 64, the first copy reads address 180 and writes address 65. A source word of `0x12345678` produces byte `0x78`. If intervening dependencies change the source word to `0xABCDEF01`, the second copy writes `0x01`, not the earlier byte.

3. **Two saved-word stores.** If the saved word is `0x89ABCDEF`, F-d026 returns 3, and F-d035 returns 5, the corresponding destinations are 68 and 40. Both stores carry the full 32-bit saved word.

4. **First selector.** If the saved word shifted right by 23 equals 2, the selector is read at address 3. If that byte is 200 and the captured word’s low byte is `0xA5`, address 217 receives `0xA5`.

5. **Second selector and bit extraction.** With final low half `0x00600000`, the second selector is read at address 4. If that byte is 7 and the captured word is `0x3FC00000`, address 24 receives `0xFF`.

6. **Saved-base timing.** If the global base is captured as 4096, later dependencies changing the global to 8192 do not alone change the captured-word read address: it remains 4116.

7. **Store/read aliasing.** If F-d059’s word-store destination equals saved global base plus 20, the captured-word read follows that store and reads its resulting word under ordinary memory semantics.

8. **Final misalignment.** A final low half of `0x00000180` produces halfword-clear address 3. This establishes a possible odd address, not successful execution there.

9. **Partial completion.** If F-d081 returns but the auxiliary-pointer byte clear faults, the `SupervisorCall` assignment has already occurred. Neither the halfword clear nor F-d082 is then guaranteed to occur.
