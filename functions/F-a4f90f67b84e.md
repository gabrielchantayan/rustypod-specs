# F-a4f90f67b84e

## Purpose

F-a4f90f67b84e selects an object through a globally based, indexed address slot and replaces one 32-bit field in that object with the low 15 bits of an input value.

The established operation is a masked assignment, not a bit-field update: the destination’s previous contents are not read or preserved. After a successful assignment, the stored value is between 0 and 32,767 inclusive.

The apparent intent is to assign a bounded value to a selected object. Neither the meaning of that value nor the role of the object is established. In particular, the evidence does not identify the field as a counter, identifier, position, flag set, or signed quantity.

## Behavior

### Address selection

The function uses the signed selector to choose an address slot at a displacement of 396 bytes per selector unit from the globally supplied base.

A selector of zero chooses the slot at the base itself. A selector of one chooses a slot 396 bytes after the base. A selector of negative one chooses a slot 396 bytes before the base. Negative selection is therefore part of the address expression, not an explicitly handled error case.

The selected slot supplies the address used for the second level of indirection. The destination is not located directly at the indexed base location.

### Value transformation

The input value is masked with the unsigned value 32,767, equivalently hexadecimal 0x00007FFF.

Consequently:

- Bits 0 through 14 retain their input values.
- Bits 15 through 31 become zero.
- No rounding, saturation, sign extension, or range-dependent branch is present.
- Inputs that differ only in bits 15 through 31 produce the same stored value, provided destination selection and memory conditions are otherwise identical.

For example, an input of 32,768 produces zero rather than 32,767. This distinguishes the operation from clamping.

### Destination replacement

The masked result replaces the entire 32-bit destination field.

There is no read-modify-write operation on that field. Existing high bits are cleared by the replacement; existing low bits do not influence the result. Bytes outside the four-byte destination are not explicit write targets.

The function does not inspect the selected object’s contents to determine whether the assignment is appropriate.

### Ordering

The established data-dependent memory sequence is:

1. Obtain the globally supplied base needed for selection.
2. Read the selected address slot.
3. Write the masked value at the fixed offset from the selected address.

The address-slot read must provide the address used by the destination write. The source does not establish a meaningful ordering between the purely arithmetic masking operation and the address calculations.

This sequence describes the recovered operation, not an inter-thread synchronization guarantee or an exact machine-instruction trace. No locking, atomic operation, memory barrier, or volatile access is specified.
