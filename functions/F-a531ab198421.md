## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Opening forwarding:** On reaching the opening invocation, its represented argument is the second explicit 32-bit input.

2. **Selector addressing:** A selector of 0xff selects address 0x110. A selector of zero selects address 0x11. Neither destination includes an input-object base.

3. **Byte truncation:** For a logical twenty-two-bit right shift of 0xffffffff, the intermediate value is 0x3ff and the stored byte is 0xff.

4. **Address-0x28 evaluations:** If the initial capture supplies 0x12345678, the later specified word store uses 0x12345678 even if the two argument evaluations or intervening calls observe or produce other contents. Acceptance must not require either call argument to equal the capture.

5. **Address-0x28 argument independence:** If the memory environment permits the two argument evaluations to observe different contents, the contract does not reject unequal arguments. It does not specify which argument is evaluated first.

6. **Publication ordering:** The word write to address 0x7c precedes the following invocation receiving the published result twice.

7. **Address-0x01 arguments:** Two argument expressions evaluate the byte at address 0x01 independently. Treating them as one captured byte requires additional evidence; distinct hardware transactions are not themselves an acceptance requirement.

8. **Final shared-global origins:** If the first evaluation supplies 0x00000400 and the second supplies one, the later masked right-shift-by-ten argument is one. Under 32-bit modular arithmetic, the second evaluation produces a four-times basis of four, then 0x10000000 after the twenty-six-bit left shift, then zero after multiplication by 0x400.

9. **Overlapping writes:** If both address-zero stores are reached, the word store occurs before the halfword store. Acceptance must not assume the original word remains intact.

10. **Consecutive stores:** A captured selector of three produces consecutive stores of three and six at the first +0x34 destination. Keeping only six loses a represented event.

11. **Unsupported memory and termination:** The evidence supplies no checked error return for prohibited address-zero accesses and no normal-return guarantee after the final calls.
