These predicates describe the incoming condition values referenced by that representation. They do not establish that real interrupt handlers or coprocessor operations preserve processor flags, globals, registers, or memory.

   Under the strict condition, request the coprocessor operation represented with numeric selector fields `(0xF, 5, 0)` and opaque operands C and D, in that order.

2. **First coprocessor load.**

3. **First interrupt group.**

4. **Zero-dependent interrupt.**  
   If the zero condition is false, request software interrupt `0x1EDF1D` once. This selection does not additionally require the equal condition.

5. **Central conditional sequence.**
   - Under the alternate condition:
     - Request software interrupt `0x1CDF1C` seven times consecutively.

     - Request software interrupt `0x1CDEFC` once.
     - Request software interrupt `0x1DCEBB` once.

     - Request the coprocessor operation represented with selector fields `(0xF, 5, 0)` and opaque operands B and D, in that order.

   Under the equal condition, request the represented long coprocessor-load operation with selector `5`, opaque operand A, and an address formed from the second address base plus `0x25C`.

7. **Final interrupt group.**

The two operations using selector fields `(0xF, 5, 0)` are distinct operation sites. When the strict condition holds, both are selected, with the first load between them. They must not be collapsed into one operation.
