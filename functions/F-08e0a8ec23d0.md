If the second call returns, the function selects a third fixed anchor and calls the target calculated from the second anchor plus hexadecimal `FFE`. The result of this third call is retained as a 32-bit integer.

The anchor selection and target calculation order is significant. A target is not necessarily based on the most recently selected anchor. These anchors are address values; the representation does not show the function reading a function pointer from memory at an anchor.
