## Acceptance examples

These examples are conditional static deductions, not execution results. All preceding operations must be reachable, and required accesses and calls must be valid.

1. **Low-byte transfer.** If a relevant word read yields hexadecimal 123456AB, its following byte transfer writes hexadecimal AB. It does not itself write the remaining three bytes.

2. **Fresh repeated read.** If the first source read ends in hexadecimal 11 and intervening effects change that location to a word ending in hexadecimal 22, the second transfer writes 22. Reusing the first read would violate the represented behavior.

3. **Captured-word reuse.** If captured word is hexadecimal 89ABCDEF, both propagation stores write that complete value. Later changes to the original source location do not refresh it.

4. **Shift identity despite discarded bits.** Under 32-bit bitvector arithmetic, an F-1104 result of hexadecimal 40000001 yields retained scale four. Shifting that right by two and left by 16 yields hexadecimal 00010000. Shifting the original hexadecimal 40000001 left by 16 and retaining 32 bits also yields hexadecimal 00010000. The example demonstrates the equality, not a numerical difference caused by lost high bits.

5. **First lookup boundaries.** Captured word zero selects lookup address one; hexadecimal FFFFFFFF selects address 512. Lookup bytes zero and 255 select write addresses 17 and 272 respectively.

6. **Second indexed byte.** Captured state hexadecimal FFFFFFFF produces hexadecimal FF. Captured state hexadecimal C0000000 produces zero, because the byte conversion retains only original bits 22 through 29.

7. **Captured-base timing.** If captured base is P and F-1605 changes the global slot to Q, the later state read still addresses P plus 20. Changes to memory at P plus 20 before that read remain observable.

8. **Lookup aliasing.** If the first indexed store changes the location read by the second lookup, and intervening effects leave it unchanged, the second lookup observes the changed byte.

9. **Final clear widths.** With valid, independent destinations, the auxiliary clear writes one zero byte and the computed clear writes a zero halfword. Neither is a word-width clear.

10. **Unavailable zero target.** If address zero cannot support the final call, normal return is not established. Earlier writes are not thereby undone.
