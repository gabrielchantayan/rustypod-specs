## Acceptance examples

These are conditional static deductions, not executed tests. Arithmetic examples involving overflow or left shifts assume 32-bit modular behavior.

1. **Unsigned selector endpoints.** A selector of 0 produces byte destination 17; a selector of 255 produces destination 272. Neither destination includes the selector’s original base.

2. **Fresh reads versus captured selectors.** If a dependency changes a selector between two specified reads, the later destination uses the later byte. If it changes the selector after phase 1 captures it, the subsequent third-argument word store still uses captured selector plus 20.

3. **First field truncation.** For first field value 0x12345678, the initial selector-mediated byte store writes 0xE0. The later masked-and-shifted store writes 0x23.

4. **Global snapshot.** A captured global value of 0xFFFFFFFF produces byte value 0xFF after the right shift by 22 and byte truncation. A later change to global storage does not substitute a new snapshot.

5. **Fifth replication argument.** If the fifth replication destination result is 7, the fifth payload is written at address 48. The immediately following invocation receives 28, not 48 and not the fifth payload.

6. **Final retained destination.** If that retained destination result is odd, its left shift by 31 produces stored bits 0x80000000. If it is even, the stored bits are zero.

7. **Final lookup boundary.** Final lookup value 0xFFFFFFFF produces word-read start address 1043. This does not establish that the address is mapped, readable, or suitably aligned.

8. **Replacement-base range.** Multiplication by 1073741824 produces one of 0, 1073741824, 2147483648, or 3221225472. Direct clearing uses this result as the base, without selector mediation.

9. **Loop-carried zero.** If a second iteration is reached, its first word store uses zero as the carried payload. Its destination remains dependent on that iteration’s F-D01 result.

10. **Interrupted continuation.** If a dependency never returns, subsequent represented operations are not required to occur. Whether earlier effects remain, are restored, or become unobservable is unresolved.
