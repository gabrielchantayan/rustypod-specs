# F-6be091907cda

## Purpose

F-6be091907cda derives an integer result from two dependent memory reads. It reads an address-bearing integer from an input-relative location, reads another integer at a fixed offset from that address, and returns the second integer minus 28.

The established behavior is an indirect lookup followed by arithmetic adjustment. An interpretation such as recovering an enclosing object address is **inferred intent only**: the supplied representation does not establish an object type, allocation boundary, or pointer-valued return contract.

This specification describes static evidence only. No runtime tests have been performed.
