# F-c376d94baa30

## Purpose

F-c376d94baa30 performs a fixed sequence of indirect calls and memory accesses. Its explicit effects include byte-indirected writes, copying the low byte of word-sized fields, retaining and propagating complete words, installing scaled values, updating a global word twice, and clearing byte-, halfword-, and word-sized locations. It ends by attempting an indirect call through address zero.

No application-level purpose is established. Repeated scaling and recurring field offsets suggest structured or encoded references, but that is **inferred intent**, not a validity, ownership, or layout guarantee.

This contract describes the supplied static representation. It does not establish that the represented function boundary, call targets, or calling conventions accurately describe executable instructions.

## Acceptance examples

These are **conditional static acceptance examples**, not executed tests. Each assumes preceding operations complete and relevant addresses and arithmetic are valid.

1. **Byte-indirected destination.** If the initial lookup yields 0x20 and incoming r5 is 0x0AC00000, the first store writes 0x2B at address 0x31.

2. **Fresh selected clear.** If the two r7-derived lookups yield 0x10 and 0x30, the clears target 0x21 and 0x41. Reusing the first lookup result for the second clear is incompatible with the represented accesses.

3. **Repeated field read.** If the first copy-base word read yields 0x123456AB and the later read yields 0x987654CD, the successive byte writes at copy base plus one are 0xAB and 0xCD. Both source reads remain 32-bit accesses.

4. **Retained payload.** A captured payload of 0x89ABCDEF is propagated in full to both later destinations even if dependencies modify its original source. If F-d058 and F-d067 both return three, those destinations are respectively 0x44 and 0x20.

5. **F-d059 arithmetic equivalence.** Under a 32-bit wrapping interpretation, an original F-d044 result of 0xC0001234 gives scaled reference 0x000048D0. F-d059 receives 0x12340000, also the wrapped result of shifting the original value left by sixteen. This does not establish portable validity of the displayed signed shifts.

6. **Captured base, later field read.** If the global base capture yields 0x1000 and a dependency changes the global base source to 0x2000, the captured-state read still uses 0x1014. If the intervening second link installation aliases 0x1014, that later read observes the installed value, absent other intervening effects.

7. **Masked halfword destination.** A final low half of 0xC0000180 selects address three for the terminal halfword clear. Whether this unaligned access succeeds is environment-dependent.

8. **Terminal composition and ordering.** If the 24-bit source read yields 0x123456 and F-d113 yields 0xAB, the terminal global write is 0x123456AB. The source value must be the one observed after the terminal pointer clear.

9. **Terminal call failure.** If zero is not callable, normal completion is not promised. If preceding operations completed, the terminal byte clear, global write, and halfword clear have already occurred.
