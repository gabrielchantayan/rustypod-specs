## Behavior

### 1. Capture the state address and construct the word

The routine first reads a 32-bit value at offset 0x10 from the first input. That value becomes the state address used throughout the remaining direct operations.

It then constructs a 32-bit word from:

- The global 32-bit value.
- The byte at offset 0x0C from the second input.

Only the byte’s low nibble is retained. Its value is therefore between 0 and 15 inclusive. Shifting that value left by 12 produces a value between 0x00000000 and 0x0000F000. This shifted value is combined with the global word using bitwise inclusive OR.

Consequently:

- Bits 0–11 of the emitted word equal the corresponding global bits.
- Bits 12–15 equal the OR of the corresponding global bits and the input’s low nibble.
- Bits 16–31 equal the corresponding global bits.
- The input byte’s upper four bits have no effect.
- Set bits in the global word cannot be cleared by the input.

This is not replacement of a four-bit field unless the global word’s bits 12–15 are already zero.

The state-address read precedes construction of the word. Both the global read and the input-byte read occur before either dependency call. Their order relative to each other is not established by the supplied expression.
