# F-39c0e5471bab

## Purpose

F-39c0e5471bab coordinates a resource-dependent operation using an input descriptor, two quantities represented as pairs of 32-bit words, and a byte-sized fallback indicator.

The established behavior is:

- Invoke an entry dependency with the value 216.
- Attempt to obtain a resource.
- If a resource is available, obtain a descriptor-derived value, store it in the resource, and resolve a second object from a descriptor byte.
- If that second object is available, submit an operation using the sum and difference of the supplied word pairs, invoke a subsequent dependency on that object, and transfer control to an exit dependency.
- Otherwise, write 1 to the caller-supplied indicator and, if a resource was obtained, pass it to a cleanup dependency before invoking the exit dependency.

The numerical transformation is consistent with advancing a starting position and reducing a corresponding extent. That interpretation is inferred intent, not an established domain meaning. The supplied evidence does not establish what the objects represent, what the submitted operation does, or whether the indicator means failure, fallback, or some other condition.

## Behavior

### 5. Arithmetic boundaries

For the low-word addition, carry is 1 exactly when the mathematical sum of the starting low word and adjustment low word exceeds 4,294,967,295. Otherwise carry is 0.

For the low-word subtraction, borrow is 1 exactly when the extent low word is less than the adjustment low word.

Under 32-bit word arithmetic:

- The new starting pair represents the original starting pair plus the adjustment, modulo \(2^{64}\).
- The new extent pair represents the original extent pair minus the adjustment, modulo \(2^{64}\).

No visible range check rejects an adjustment larger than the extent. No visible check rejects carry beyond the final high word. There is no saturation or clamping.

These are arithmetic transformations, not evidence that all resulting values are valid inputs to F-cc3be638e231.
