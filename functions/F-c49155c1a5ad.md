# F-c49155c1a5ad

## Purpose

1. A dependency evaluates a 32-bit value obtained from the first input together with a 32-bit result derived from the second input.
2. Only when the low 32 bits of that dependency’s result are zero, the function compares a further pair of 32-bit values, one from each input.
