# F-c16c8f56111f

## Purpose

F-c16c8f56111f conditionally transforms a descending sequence of 32-bit words in place. An outer progression controls entry into an inner progression; each accepted inner iteration reads and overwrites one word.

Neither progression has an explicit element count. The second and third arguments participate in global-dependent continuation decisions. They are not established as lengths, dimensions, or memory bounds. Zero-valued control arguments do not necessarily prevent writes.

Normal completion returns the 32-bit value zero. That result does not report how many words were processed.

## Interface

The function accepts three 32-bit arguments and returns a 32-bit value.

| Input | Established role |
|---|---|
| First argument, \(A\) | Address-like value identifying the position immediately above the first potentially processed word |
| Second argument | Input to the outer control progression, after adjustment by a global baseline |
| Third argument | Input to the inner control progression, independently adjusted by the baseline |

Eight global 32-bit words supply control values and transformation coefficients. This contract uses descriptive labels rather than source identifiers.

| Global label | Established role |
|---|---|
| Baseline | Adjusts both control arguments and initializes outer state |
| Limit | Participates in both continuation decisions and inner initialization |
| Outer mask | Referenced repeatedly during each outer continuation decision |
| Inner mask | Sampled once at the beginning of each outer attempt |
| First multiplier | Multiplies the original word |
| First addend | Added after the first multiplication |
| Second multiplier | Multiplies the first-stage result |
| Second addend | Added to produce the stored word |

These labels do not establish application-level meaning.

## Behavior

### Initialization and retained state

The read and write cursors both start four bytes below the first argument. Although maintained separately, they remain equal because each advances downward by four bytes after every processed word.

The second argument is reduced by a baseline read to produce the retained **adjusted outer input**.

The **outer state** is initialized by subtracting a baseline read from the sign expansion of another baseline read. If those reads agree, the result is the baseline’s modular negation when its high bit is clear, or its bitwise complement when its high bit is set.

The **outer auxiliary word** is then established as the initial outer state minus one minus the adjusted outer input.

The third argument is independently reduced by a baseline read to produce the retained **adjusted inner input**.

The relevant ordering is:

- The outer-input adjustment precedes outer-state initialization.
- Outer-state initialization precedes establishment of the outer auxiliary word.
- The inner-input adjustment follows those operations.
- All of these operations precede the first outer attempt.

Separate baseline appearances need not observe the same value. In particular, the two reads used to initialize outer state are not established as one atomic snapshot, and their relative evaluation order is unspecified.

The adjusted inputs and outer auxiliary word are retained after initialization. Later baseline changes do not recompute them.

### Continuation decisions

Both progressions make a 32-bit decision whose sign determines admission:

- A clear high bit admits the iteration.
- A set high bit rejects it.

The decisions depend on the current progression state, its adjusted input, its retained auxiliary word, and limit reads. The outer decision also references the outer mask repeatedly. The inner decision uses the inner-mask value already retained for the current outer attempt.

The following is an independently reduced behavioral characterization, not a transcription of the control expression. It applies when repeated limit reads within a decision agree and, for an outer decision, repeated outer-mask reads also agree.

Consider two wraparound distances:

- The limit minus the current progression state.
- The adjusted input minus the current progression state, then minus one.

Classify each distance by its resulting 32-bit sign bit.

| Auxiliary word’s high bit | Admission requirement |
|---|---|
| Clear | Both distances must be nonnegative |
| Set | At least one distance must be nonnegative |

Equality at zero therefore satisfies the corresponding distance requirement. These are signs of modular differences, not unrestricted mathematical comparisons between signed integers. Overflow can make ordinary ordering intuition incorrect.

Under the stated read-consistency conditions, the mask value does not change admission: its contributions cancel in the fixed-width calculation. This does **not** remove the mask reads from the observable behavior. In particular:

- The inner mask is still sampled before every outer decision.
- Repeated outer-mask reads that disagree are outside the simplified rule.
- Repeated limit reads that disagree cannot be represented by one limit value.

The stable-read characterization does not require globals to remain constant for the entire call. Different decisions may observe different values, provided the repeated reads within each relevant decision satisfy its assumptions.

Without those assumptions, admission depends on the individual read results. The exact inconsistent-read outcome is documented_only here; it must not be replaced by the stable-read rule or an assumed single snapshot.

### Outer progression

Every outer attempt begins by reading and retaining the inner mask. This read occurs even if that attempt immediately rejects entry.

The outer decision uses the current outer state, adjusted outer input, fixed outer auxiliary word, limit reads, and outer-mask reads.

If rejected, the function returns zero without starting another inner progression.

If admitted, it starts a new inner progression. When that inner progression ends, the outer state increases by one modulo \(2^{32}\), and another outer attempt begins.

The outer auxiliary word does not advance with the outer state.

### Inner progression

For each admitted outer iteration, the function first establishes an **inner auxiliary word** by subtracting the retained adjusted inner input from a limit read.

It then initializes the **inner state** from additional limit reads. With consistent reads, this state is the bitwise union of the limit and the arithmetic-right-shifted complement of the limit, shifted by 20 positions. The complement’s high bit is propagated by that shift.

The auxiliary-word initialization occurs before inner-state initialization. The limit appearances within inner-state initialization are separate references; a common value is not guaranteed.

The inner decision uses the current inner state, adjusted inner input, inner auxiliary word, current limit reads, and the inner mask retained for this outer attempt.

A rejected inner decision ends the current inner progression without reading or writing a data word for that decision. It does not return from the function: the outer state subsequently advances.

An admitted inner decision processes exactly one word and then increments the inner state modulo \(2^{32}\). The inner auxiliary word and retained inner mask remain unchanged throughout that inner progression.

Neither address cursor is reset when a new inner progression begins.

### Word transformation and access order

For an original word \(z\), the stored result is:

\[
\text{Second multiplier}\times
\left(\text{First multiplier}\times z+\text{First addend}\right)
+\text{Second addend}
\pmod{2^{32}}.
\]

Each accepted inner iteration has these established effects, in order:

1. Read the current source word.
2. Move the source cursor downward by four bytes.
3. Store the transformed word at the current destination.
4. Move the destination cursor downward by four bytes.
5. Advance the inner state.

The source and destination addresses for that iteration are equal. The original value is therefore read before being overwritten.

The coefficient references occur in producing the stored result after the source word has been obtained. Their complete relative evaluation order is not established. They are not established as entry-time snapshots or as values retained across iterations.

### Completion and termination

Normal completion occurs when an outer decision rejects continuation.

There is no explicit iteration limit, bounds check, overflow report, or wraparound exit. Termination is not established for arbitrary arguments and global-read histories. An inner progression may fail to finish; repeated outer admission may also prevent return.

## Side effects

Each accepted inner iteration causes one direct 32-bit data read and one direct 32-bit data write at the same address.

After \(k\) words have been processed, the next potentially processed location is:

\[
A-4(k+1).
\]

This progression continues across outer-iteration boundaries.

The body contains no explicit assignment to the eight global words. Nevertheless, the destination range is not established as disjoint from them. A word transformation can therefore overwrite global storage and affect subsequent control or coefficient reads.

The important retention boundaries are:

- Adjusted control inputs and the outer auxiliary word are fixed before processing begins.
- Outer state advances locally after each completed inner progression.
- The inner mask is sampled anew at every outer attempt.
- Inner auxiliary state is established anew for every admitted outer iteration.
- Limit reads recur during continuation decisions.
- Transformation coefficients are referenced for each processed word.

If a store changes the inner-mask storage, the current inner progression still uses its retained sample. A later outer attempt may observe the changed storage. Changes to the limit or coefficients can affect later reads without waiting for a new outer iteration.

## Acceptance examples

These examples are conditional static deductions. No runtime tests have been performed.

### Zero-valued control inputs can process one word

Assume the baseline, limit, and both masks remain zero throughout execution. Let the second and third arguments also be zero. Assume the relevant data location is valid and disjoint from global storage.

Initialization gives:

- Adjusted outer and inner inputs of zero.
- Outer state zero.
- Outer auxiliary word `0xFFFFFFFF`.

The first outer decision admits entry: the auxiliary high bit is set, and the limit-relative distance is zero.

The first inner progression starts with auxiliary word zero and inner state `0xFFFFFFFF`. Its two wraparound distances are one and zero, so it admits one word. After the inner state advances to zero, its distances are zero and `0xFFFFFFFF`; the clear auxiliary high bit requires both to be nonnegative, so the next inner decision rejects.

The outer state then advances to one. Both outer distances are negative, so the next outer decision rejects.

Exactly one word is read and overwritten at \(A-4\). The word at \(A\) is not processed.

If the original word is 4 and the coefficients are respectively 2, 3, 5, and 7, the stored result is 62. The function returns zero.

### Outer rejection before any data access

Assume stable zero baseline, limit, and masks, but let the second argument be `0xFFFFFFFF`.

The initial outer state is zero and the outer auxiliary word is zero. The two outer distances are zero and `0xFFFFFFFE`. Because both must be nonnegative, the first outer attempt rejects.

No data word is read or written. The inner mask is nevertheless sampled before rejection. Normal completion returns zero.

### Outer admission does not guarantee a write

Assume stable zero baseline, limit, and masks. Let the second argument be zero and the third be `0xFFFFFFFF`.

The first outer decision admits entry. The inner auxiliary word is one, and the initial inner state is `0xFFFFFFFF`. The inner distances are one and `0xFFFFFFFF`.

The auxiliary high bit is clear, so the negative second distance rejects the first inner decision. The outer state then advances, and the next outer decision rejects.

No data word is processed despite an admitted outer iteration.

### Transformation overflow

For any admitted word, assume the first multiplier and both the first addend and second multiplier are one, while the second addend is zero.

An original word of `0xFFFFFFFF` is stored as zero under 32-bit modular arithmetic. No separate overflow result is produced.

### Consecutive accesses after prior processing

Suppose \(k\) words have already been processed and two further inner iterations are admitted. Their locations are:

\[
A-4(k+1),\qquad A-4(k+2).
\]

Each location is read before being overwritten. For \(k=0\), these are the first two processed words, at \(A-4\) and \(A-8\).

The same rule applies if the two admissions occur in different outer iterations. A new inner progression does not reset either cursor.
