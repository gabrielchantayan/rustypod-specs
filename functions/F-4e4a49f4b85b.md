### Retained-address overwrite

### Extraction and selector rereading

If the first byte source is 0x00100041, the first selector-directed byte value is 0x04 and the second is 0x01.

If their respective selector reads return 5 and 9, the destinations are 22 and 26. Reusing destination 22 for the second write would not satisfy the contract.

### Input write changes the immediate selector

Suppose the selector base is 27, the third input is zero, and the second byte source is 1. The input-directed write stores byte 4 at address 28, which is also the selector location.

If ordinary coherent byte-memory behavior applies, the immediately following selector read obtains 4, and the associated clear targets address 21. Using the selector’s earlier value would be incorrect.

### Initial and recurring loop arguments differ

If F-0084 then returns 1, F-0085 receives 4 and 0x00040000.

Under the qualified 32-bit interpretation, a raw result of 64 instead produces arguments 256 and zero. This last example illustrates truncation; it does not establish defined signed-shift behavior for that input.

### No normal completion
