These are conditional static acceptance examples, not executed tests.

1. **Initial selector of 255.** If the initial byte read yields 255, the first byte destination is 272 and the first selector-derived word destination is 1,040. The later selector-bank destination is 16,252,964.

2. **Initial byte truncation.** If the second auxiliary unsigned input is `0xffffffff`, shifting right by 22 produces 1,023. The byte written is 255, not 1,023.

8. **Partial execution.** If a dependency does not return after an early store, subsequent stores are not established to occur, and no rollback is visible.
