## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Selection precedence.** If both discriminators are nonzero, the function logs through F-e475f4597093 and dispatches `GeniusPlaylistSelected`. It does not perform the nested conversion/action sequence.

2. **Nested route.** If the selection discriminator is zero and the context discriminator is nonzero, F-664473a81df4 and conversion cleanup precede logging. Logging precedes `NestedPlaylistSelected`, which precedes final processing.

3. **Direct route.** If both discriminators are zero, F-b8b805ca9152 receives the original selection argument, zero, and `0xffffffff`. `GotoNowPlaying` follows. No logging call occurs.

4. **Noncanonical discriminator values.** A discriminator represented as −1 follows the nonzero route. The function does not require a discriminator to equal one.

5. **Result preservation.** If F-16012161395f returns the 32-bit pattern `0x80000001` and all cleanup calls return normally, F-212b16383e06 returns that same pattern, regardless of route.

6. **Nested global mutation.** If a nested-action dependency replaces the global record pointer but leaves the captured record valid, the later record read uses the captured record. Replacing the global logging value likewise does not replace the already captured logging argument.

7. **Late state mutation.** If a preceding dependency changes selection-state offset 4, the logging call receives the value read at the logging call site, not a value saved immediately after classification.

8. **No failure fallback.** If wrapper construction returns an unusable value but returns normally, no local validation diverts execution. The value is passed to the next dependency or virtual operation. Whether that use succeeds is undocumented.
