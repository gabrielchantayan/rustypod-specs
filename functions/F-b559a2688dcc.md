# F-b559a2688dcc

## Purpose

F-b559a2688dcc processes a classified input sequence and writes accepted records into storage referenced by a working state. It first invokes a setup dependency, conditionally requests storage, then handles ignored items, record introducers, and terminating items.

Each record occupies 20 bytes and contains five 32-bit fields. After copying the five parsed values into a record, the function conditionally replaces the third field with its negative.

An accepted terminating classification causes a zero return and a write of the accepted-record count to the state. Most explicitly detected failures return 160. A separate status inspected after the storage request can instead be returned directly.

These are source-established operations, not a guarantee of transactional parsing or persistent ownership. The function performs no explicit rollback of earlier record writes. Whether those writes remain intact and accessible after subsequent dependency calls requires additional noninterference and lifetime guarantees.

The semantic meanings of the classifications, record fields, and setup operation are not established. No runtime tests have been performed.

2. The value 20.

### Successful termination

For classification 20, 21, or 23, the function writes the internal record index plus one to state offset 32 and returns zero.

The index begins at −1 and advances only for classification 56. Any failed record attempt ends the invocation before termination. Thus, on a successful termination path:

- No accepted records produces a final count of zero.
- One accepted record produces a final count of one.
- Ignored items do not contribute to the count.

This function publishes that final count only on accepted termination paths. A failure after earlier record writes performs no explicit final-count publication and no explicit rollback of those writes.
