## Acceptance examples

These are conditional static criteria, not executed tests.

- **Input shifts:** Under truncating 32-bit semantics, a fourth input of 1 supplies 0x80 initially; 0x02000000 supplies zero. A third input of 0x12345678 supplies 0x78000000 at sites using its 24-bit shift.
- **Selector boundary:** Under that model, the selector cannot equal 511 because its two low bits are clear. Its maximum is 508.
- **Byte widening:** An early byte read of 0xE7 supplies the widened word 0x000000E7.
- **Fixed ordering:** An execution reaching the first fixed-state region must retain the read at 0x05 before the byte write at 0x01. The later word write at 0x54 precedes the fixed byte write at 0x15.
- **Root capture:** If a computed alias changes 0x087FBBBC after its load, later root-relative stores still use the captured root base. The fixed word store at 0x60 follows that load.
- **Final fixed trace:** The word read at 0xA9 precedes the payload-field read, which precedes the byte write at 0x3A, which precedes the saved-field and work-snapshot reads.
- **Fresh reads at 0x67:** If an intervening alias changes 0x67, a subsequent transfer must use the value returned by its own read. Acceptance cannot require all three reads to equal the originally written byte.
- **Access width:** Replacing a halfword store of 0x3A or 0x65 with a byte store fails width-sensitive acceptance.
- **Partial failure:** An inaccessible derived address has no established graceful-error or rollback requirement.
- **Final dispatch:** If reached, dispatch uses the captured saved field, not a fresh read of tail base plus 0x14.
