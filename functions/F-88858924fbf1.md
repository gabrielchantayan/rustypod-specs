## Interface

The displayed interface declares no explicit parameters or return value. Execution nevertheless consumes:

- **Entry bits:** an incoming unsigned 32-bit value used for bitfield extraction.

There is no visible argument validation, bounds checking, address validation, or sufficiently established calling convention for independent invocation.

### Widths and arithmetic

A **byte** is eight bits. A **word** is 32 bits. Byte stores retain the low eight bits; word transfers move 32 bits. Byte reads used as indices are unsigned, yielding values from 0 through 255.

Unsigned 32-bit arithmetic retains the low 32 bits. Unsigned right shifts are logical. Signed arithmetic and shifts also occur: signed overflow, shifts of negative values, and out-of-range conversions into signed values are not assigned portable semantics by this contract. Pointer width and address wraparound are unresolved. Address formulas below describe the represented calculations, not guaranteed mathematical-integer addressing.
