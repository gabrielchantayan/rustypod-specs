# F-22f023f81f3b

The conditional decision depends on a four-byte field located at byte offset 0xB4 from the address supplied as the first input. A zero field skips the first dependency; any nonzero field selects it. The second dependency is reached on either branch, provided any selected first call returns normally.

This is an orchestration contract. The supplied static evidence establishes the dispatch condition, call order, forwarded inputs, and final return value. It does not establish the application-level purpose of the object, the field, or either dependency. In particular, the return value must not be interpreted as proof that either dependency succeeded.
