# F-20f4a7792eb2

## Purpose

F-20f4a7792eb2 conditionally copies a 32-bit value from a dependency-selected location into caller-provided storage. Its Boolean result reports whether the second dependency returned zero.

The established behavior is narrower than a general lookup contract: two dependencies determine and evaluate a position-like value, but their internal operations are unavailable. Interpreting this operation as finding an entry and extracting its payload is inferred intent, not an established guarantee.

The distinguishing behavior is the order of operations:

1. Invoke F-cb3a3b028def with temporary position storage, the supplied base value, and an addressable copy of the supplied 32-bit argument.
2. Read a 32-bit field at byte offset 16 from the supplied base.
3. Invoke F-2b931655bb54 with addresses of the temporary position and the copied field.
4. If that invocation returns zero, read a 32-bit field at byte offset 20 from the resulting position and copy it to the caller’s output.
5. Return whether the dependency result was zero.

No runtime tests have been performed.

### Conditional payload transfer

1. Reads 32 bits at byte offset 20 from the then-current position.
2. Writes those same 32 bits into the caller’s output destination.
3. Returns true.

The payload is copied without a visible transformation. The payload read precedes the output write.

When the second dependency returns nonzero, the wrapper:

- Does not perform its explicit output write.
- Returns false.
