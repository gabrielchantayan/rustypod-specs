The direct-memory phase follows the calls without a visible validation branch. Dependency results provide its bases and stored values.

One base is formed by multiplying a result by 2²⁵. A small unsigned quantity is formed from another result shifted left by eight, masked to 15 low bits, and shifted right by six.

**[INFERENCE]** With 32-bit bit-vector shifts, the small quantity is a multiple of four between 0 and 508. Its doubled value is between 0 and 1,016 in multiples of eight. These ranges do not imply valid table indices or allocations.

The first memory effects preserve these relationships:

- A word store at offset 84 from the final call’s low component scaled by 256 follows.
- The offset-9 byte destination is then written again, using a different source.

**[INFERENCE]** In ordinary sequential memory without external modification, the reloaded word is zero: intervening writes either store zero or do not overlap that word. ### Fixed-global ordering within computed accesses

The global-associated value at 0x05 is read and converted to unsigned 32 bits **before** the byte write at 0x01. The original global declaration is absent, so its load width is not established. The conversion width does not prove an eight-bit load.

The converted value subsequently acts as an address base, including for an offset-21 byte write and an offset-84 word read followed by a word write. The old offset-84 word is retained and drives later scaled addresses.

The explicit word write at fixed address 0x54 publishes twice that retained word. It occurs **before** the explicit byte write at 0x15. Computed writes occur between these fixed-address effects, so they are not an isolated pair of consecutive stores.

Later, a separate global word is read and retained as the publication address base. That read occurs **before** the fixed word write of 0x20 at 0x60, which occurs **before** the repeated publication region. Consequently, a write at 0x60 that overlaps the source global does not cause the publication base to be reloaded.
