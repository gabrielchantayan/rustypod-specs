# F-97ae53a6a068

## Purpose

An optional source record selects between initialization and copying an existing record. A copied source must also pass an initial processing step and a two-byte nonzero check. The initialized-record path does not perform that initial check.

The record’s application meaning is not established. Descriptions such as “record,” “processing,” and “transfer” identify observable roles, not proven domain semantics.

The function returns a signed 32-bit status. It directly generates two negative statuses and otherwise propagates selected dependency statuses. A zero return establishes that the final transfer operation was invoked after successful processing; it does not independently establish that the transfer succeeded.

These examples are conditional on dependencies returning normally and accessing valid storage. They specify expected behavior, not observed runtime results.
