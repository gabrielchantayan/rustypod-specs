## Behavior

Before every call, the caller stores 0x00000001 into that temporary. Each call receives:

1. The address at byte offset 0x48 from the original object address.

The temporary’s address is exposed to the dependency. Its contents can therefore be read or modified by that dependency. The caller does not visibly inspect the post-call value to choose a branch, a write value, or a return value.

The eight stores of 1 are part of the behavior, not merely a description of intended arguments. A dependency-written value is replaced before the next call. If result storage aliases the temporary, these stores can also overwrite earlier result-relative writes.
