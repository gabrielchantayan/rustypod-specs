# F-f9929344a5c2

## Purpose

On the visible normal-return path, it:

- Obtains a context reference and an object reference.
- Initializes and configures temporary storage using context-associated data and the second input.
- Queries the object and conditionally invokes another object operation with the second input.
- Passes the first input to two dependencies in a fixed order.
- Writes the byte value 1 to a location reached through the context.
- Finalizes the temporary helper.
