## Behavior

Control is subsequently transferred to that target.

These operations form a dependency chain: the first read supplies the base for locating the second read, and the second read supplies the destination for the control transfer. The supplied representation contains no branch that selects a fallback target, retries a read, or bypasses dispatch after detecting an invalid value.

There is one target selection and one represented indirect invocation. No loop or repeated dispatch is visible.

### Address selection

The 24-byte displacement applies to the value loaded from the input location. It does not apply directly to the input pointer.

This distinction is observable. Memory 24 bytes after the input pointer need not be consulted. Instead, the selected slot is 24 bytes after the address-like value stored at the input location.

The evidence does not establish the contents or accessibility of any intervening bytes. Successful dispatch does not, by itself, require that this function read the entire region between the loaded base and the selected slot.
