# F-9b22ad6591cf

## Purpose

F-9b22ad6591cf selects and returns a 32-bit value through an ordered sequence of two dependency-based checks and a final record-field fallback.

The first check can terminate the operation without using the input record. If that check does not select a result, the second check uses a location 40 bytes beyond the input value. If neither check selects a result, the function obtains a candidate from a 32-bit field 44 bytes beyond the input value and conditionally substitutes a global default.

This selection structure is established by the supplied static evidence. The application-level meaning of the checks, the record, and the returned values is not established. In particular, interpreting the operation as a history lookup, name lookup, or ownership transfer would require evidence beyond this function.

### Final record-field selection

If both comparisons return nonzero, the supplied representation performs two reads of the same 32-bit record location at offset 44:

1. The first read supplies a saved return candidate.
2. The second read determines whether to substitute the global default.

If the second read is zero, the function reads and returns the default global, discarding the saved candidate.

If the second read is nonzero, the function returns the saved candidate from the first read. It does not return the second read’s value.

For stable ordinary memory, this reduces to the expected rule: return the field when it is nonzero; otherwise return the default. The two-read distinction matters if reads can differ, such as through concurrent modification or special memory semantics. Whether the actual execution environment permits such variation is not established.

The evidence contains no explicit dependency call between these two reads. It also provides no synchronization, atomicity, or consistency guarantee.

The resulting observable sequence is:

- The first selected-result global is read only if that comparison returns zero.
- F-44362605ab79 runs only if the first comparison returns nonzero.
- The global operand for the second comparison is consumed after F-44362605ab79 returns.
