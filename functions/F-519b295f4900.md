# F-519b295f4900

## Purpose

F-519b295f4900 dispatches on the first byte of an input object, performs tag-dependent checks of integer fields, invokes selected dependencies, and returns the original pointer on paths that return normally.

The established behavior is a validation-and-dispatch sequence, not a general traversal of the object. Only tag values 1 and 2 cause additional field reads. Tag 0 and all other tag values return without invoking a dependency.

Some branches invoke F-feee9156a257, which is marked as non-returning in the supplied static evidence. Other branches invoke a dependency before reaching that non-returning call.

A cleanup, destruction, or invariant-enforcement role is plausible, but not established. In particular, the evidence does not establish what the dependencies do, whether they modify the input object, or whether they release its storage.

## Interface

### Input

The function accepts one pointer to byte-addressable storage.

The pointer must permit a read of its first byte. There is no null-pointer check. A null pointer or another pointer that cannot support this read is outside the established valid-input domain; no controlled error result is specified.

The first byte is a discriminator:

| Discriminator | Selected behavior |
|---|---|
| 0 | Return the original pointer without further field reads. |
| 1 | Check integer fields at byte offsets 8 and 16, in that order, then potentially invoke an object-directed dependency. |
| 2 | Check integer fields at byte offsets 4 and 24, in that order. |
| Any other byte value | Return the original pointer without further field reads. |

The discriminator is read once. Its value selects the branch for the rest of the invocation.

### Field representation and accessible extent

The checked fields are represented as integer reads in the supplied evidence. Each check distinguishes zero from nonzero; it does not use magnitude, ordering, or sign.

The evidence does not independently establish the target ABI’s integer width, alignment rules, byte order, or validity rules for typed access. Consequently, the exact byte extent of each integer read is **documented_only** pending ABI confirmation.

Under a 32-bit-integer ABI, the relevant layout is:

|---|---:|---|
| 0 | 1 byte | Every invocation |
| 4 | 4 bytes | Discriminator is 2 |

Offsets are byte offsets from the original pointer. No field value is treated as a pointer, length, count, or arithmetic operand by this function.

### Output

## Behavior

### Initial dispatch

The function first reads the discriminator byte.

If it is 0, the function returns the original pointer immediately.

If it is neither 1 nor 2, the function likewise returns the original pointer. Such values are not rejected, normalized, or forwarded to an error dependency.

Only the selected discriminator branch is evaluated. Fields associated with the other discriminator are not read by this function.

### Discriminator 1

The first checked field is the integer at byte offset 8.

If that value is nonzero:

1. F-68ef4da92b95 is invoked.
2. If that invocation returns normally, F-feee9156a257 is invoked.
3. Under the supplied non-return annotation, the function does not return normally.

On this branch, the function does not read the integer at offset 16 and does not invoke F-3b3d4d4b2da2. A change to the offset-8 field by F-68ef4da92b95 does not trigger a recheck before the subsequent call.

If the offset-8 value is zero, the function next reads the integer at byte offset 16.

If that second value is nonzero:

1. F-c2bce6cc767e is invoked.
2. If that invocation returns normally, F-feee9156a257 is invoked.
3. Under the supplied non-return annotation, the function does not return normally.

The function does not invoke F-3b3d4d4b2da2 on this branch. It does not recheck either field after F-c2bce6cc767e returns.

If both checked values are zero, F-3b3d4d4b2da2 is invoked with the original input pointer. If that dependency returns normally, the function returns the original pointer. No dependency result is used to select another branch or construct the return value.

The two field checks have strict precedence: a nonzero value at offset 8 selects its dependency sequence regardless of the value at offset 16.

### Discriminator 2

The first checked field is the integer at byte offset 4.

If it is nonzero, F-feee9156a257 is invoked immediately. No preliminary dependency is invoked, and the integer at offset 24 is not read by this function.

If the offset-4 value is zero, the function reads the integer at byte offset 24.

If that second value is nonzero:

1. F-65595e93cad9 is invoked.
2. If that invocation returns normally, F-feee9156a257 is invoked.
3. Under the supplied non-return annotation, the function does not return normally.

If both checked values are zero, the function returns the original pointer without invoking a dependency.

The check at offset 4 has precedence over the check at offset 24.

The fixed field addresses must be valid under the target’s pointer and object-access rules. The function contains no bounds check, overflow check, alignment repair, or alternate access mechanism.
