# F-78b6d35bd892

## Purpose

F-78b6d35bd892 specifies a state-dependent sequence of external calls, memory accesses, stack updates, and software exceptions. A sampled selector byte chooses between two paths. Both can reach a shared continuation, through three distinct represented entry targets.

No application-level purpose is established. Static-data references do not establish loading, initialization, formatting, or successful completion.

This contract is **documented_only**: it describes the supplied static representation, not validated execution. All downstream behavior is conditional on preceding accesses succeeding, dependencies returning, and exceptions permitting continuation. No runtime tests have been performed.

## Interface

### Inputs and preconditions

The represented interface has no explicit parameters. Effective inputs include:

- An incoming return link used to determine the first call target.
- An incoming register used to index entry-stack storage.
- Existing stack addresses and contents.
- A global object pointer whose offset-0x11 byte supplies the selector.
- A global converted to an unsigned 32-bit address on the zero-selector path.
- Other global storage, static data, indirect memory, and dependency results.
- Secondary dependency results whose calling-convention interpretation is unresolved.

The original width and signedness of the zero-path address-source global are not established. Its unsigned 32-bit conversion does not establish a 16-bit memory read.

Safe execution requires accessible memory, suitable implicit machine state, and executable reached targets. No represented validation protects low, computed, or potentially unaligned addresses.

### Widths and outputs

Bytes are 8 bits, halfwords 16 bits, and words and represented pointers 32 bits. Paired results have low and high 32-bit components. Consecutive word fields have four-byte spacing.

Unsigned 32-bit arithmetic wraps modulo \(2^{32}\). Narrow stores retain the low 8 or 16 bits. Logical right shifts insert zeros; represented arithmetic right shifts propagate the sign.

Signed arithmetic also occurs. Its overflow behavior, character signedness, alignment requirements, byte order, and out-of-range signed conversions remain unresolved. Unsigned wrapping must not be applied indiscriminately to signed address calculations or shifts.

No normal return or explicit return value is represented. Both terminal routes reach invalid-instruction boundaries. Observable outputs include reached calls, memory and stack writes, breakpoint 0x2C, and software interrupt 0xAB.

### Nonzero-selector path

If the original low component is zero, F-D11 returns a replacement pair. Its low component is retained; its high component is replaced by the word read at:

**replacement high − destination pointer − correction + 0x74,**

where correction is zero if the retained bit is one, and one otherwise.

The selected pair is passed to F-D12-N when the original low component was nonzero, or F-D12-Z after zero-low replacement. Replacement changes the target, not merely the arguments.

At the selected call’s result plus 0x32, a halfword is stored whose bits represent:

**eight times the unsigned destination-pointer-minus-six difference, reduced to 16 bits.**

The representation narrows the difference to a signed halfword before multiplication; the final stored bits are not those of eight times the pointer minus six.

### Mutable threshold stack object

After F-D13 returns, an unsigned global word is read and assigned to a 32-bit stack object serving as threshold storage. F-D13’s secondary result is then stored at destination base plus 0x68.

The comparison with nine uses the **then-current contents of the threshold stack object**, after that destination store. It is not unconditionally a comparison against the originally sampled global value. The intervening store can affect the stack object if its destination aliases that storage.

If the comparison reads a value below nine, F-D14 returns a pair without explicit arguments. The following operations occur in order:

1. Read the then-current threshold stack value, narrow it to a byte, and store it at destination base plus 0x0F.
2. Read the threshold stack value again, after the byte store, and use that current value plus 0x28 as the destination of a halfword store.
3. Store the low 16 bits of another stack-slot address plus 0x398 at that destination.
4. Assign zero to that addressed 32-bit stack slot; the represented value is address 0xC3 logically shifted right by 14.
5. Assign the saved source offset-16 word to another 32-bit stack slot.
6. Call F-D15 with F-D14’s low component, high component, and constant 0x74.

F-D14 is not established to preserve the threshold stack object. The byte store can also alias it and change the value used for the subsequent halfword-store address. Consequently, entering the region with a comparison value below nine does not constrain that later address to the range implied by the comparison.

This route reaches invalid instruction data. A comparison value of nine or greater skips the conditional operations and reaches an invalid-instruction boundary directly.

## Side effects

Every reached call, memory access, stack assignment, and software exception is part of the represented behavior. Similar-looking calls cannot be combined merely because their results appear unused.

Aliasing can connect globals, stack storage, records, and computed addresses. Record offset 13 explicitly overlaps the preceding word store at offset 12.

A retained scalar expression and an explicitly accessed stack object are not interchangeable guarantees. In particular, threshold storage is repeatedly read and may change between uses. No dependency-preservation or non-aliasing guarantee establishes its stability.

No allocation, release, ownership transfer, or lifetime extension is established. Passing an address does not establish permission to retain it. Dependencies may affect memory or globals, fail to return, or raise exceptions; their unspecified behavior is not constrained here.

No rollback, error translation, access-fault recovery, alignment recovery, or guaranteed exception resumption is represented.

## Acceptance examples

These are conditional static criteria, not executed tests. Preceding accesses and calls must complete, and exceptions must permit continuation.

1. **Selector sampling:** A sampled zero selects the zero path even if F-D02 changes the backing byte.

2. **Zero-path ordering:** Coincident initial store destinations still receive both stores. Skipping the conditional region selects F-S01-ZS; completing it selects F-S01-ZC.

3. **Replacement:** Original F-D10 low zero selects F-D12-Z even if the replacement low is nonzero. Later accesses still use original-base addresses 0x70 and 0x09.

4. **Narrow arithmetic:** Destination pointer 0x10 produces halfword 0x0050 at the selected F-D12 result plus 0x32.

5. **Displacement:** Selector one produces displacement −1, so the secondary-result store is one byte before the destination pointer.

6. **Call-result arithmetic:** F-D08 result 0x200 supplies 0x184 to F-D09, before the record-offset-4 read.

7. **Shared subtraction:** F-S49 high component zero supplies one to F-S52; high component seven supplies zero.

8. **Tail ordering:** F-S89 produces its value before the halfword store; F-T01 consumes that value twice after the store.

9. **Source calculation:** Retained branch value 0x32 produces source address 0xFF; 0x33 produces zero.

10. **Global versus stack copy:** If the sampled global contains eight, subsequently changing only that global to nine does not change an independent threshold stack copy. Entry into the conditional region additionally requires that the intervening destination-base-plus-0x68 store not change the stack copy to nine or greater.

11. **Stack alias before comparison:** If that intervening store changes threshold storage from eight to nine, the comparison skips the region.

12. **Dependency and byte-store interference:** If the comparison reads eight but F-D14 changes threshold storage to 0x100, the byte store uses low byte zero. If that byte store leaves threshold storage unchanged, the halfword destination is 0x128. If it changes threshold storage, the halfword address instead follows the post-store value.

13. **Boundaries and termination:** A comparison reading eight enters the region; nine skips it. A persistently negative zero-path loop test repeats without represented local progress. Neither establishes normal return.
