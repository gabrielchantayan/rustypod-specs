## Interface

### Input

The function accepts one object-like pointer.

The pointer is used in two distinct ways:

- Its first four-byte word supplies the base address used to locate an indirect callable.
- The original pointer value is passed as the first explicit argument to that callable.

The input is not inspected before the two named dependencies execute. Consequently, the object and dispatch storage must be valid when the indirect dispatch is reached; their validity at entry alone is insufficient if either dependency can affect them.

The supplied representation uses a four-byte integer word to obtain the dispatch base. This supports a 32-bit address-layout interpretation, but does not establish a portable interface for wider pointers.

### Output

On normal completion, the function returns a four-byte value equal to 1.

Neither dependency’s result is returned directly. The result of the second dependency is instead passed to the indirect callable. Any return value from that callable is ignored.

No alternative normal return value is established.

- A readable first word at the input object’s address.
