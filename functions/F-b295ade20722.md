# F-b295ade20722

## Purpose

F-b295ade20722 sets a single byte at displacement eight from a caller-supplied base address and returns a 32-bit result determined by whether its second input is zero.

The established relationship is:

| Second input | Byte written | Return value |
|---|---:|---:|
| Zero | 2 | 0 |
| Any nonzero value | 0 | 4 |

The nonzero input is not copied, narrowed, or otherwise represented in the destination byte. Every nonzero value selects the same outcome.

The meaning of the byte, the surrounding object, and the return values is not established. In particular, describing zero as “success,” four as “failure,” or the destination byte as an enable flag would add semantics not demonstrated by the supplied material.

## Behavior

- Exactly zero selects the first outcome.
- Every nonzero value selects the second outcome.

### Zero-selector outcome

- The function writes the numeric value 2 to the byte at displacement eight.
- It then returns the 32-bit value 0.

The write replaces the previous contents of that byte. The previous value is neither preserved nor incorporated into the result.

### Nonzero-selector outcome

When the selector is nonzero:

- The function writes the numeric value 0 to the byte at displacement eight.
