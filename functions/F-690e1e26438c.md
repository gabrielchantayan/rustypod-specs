# F-690e1e26438c

## Purpose

F-690e1e26438c specifies a statically represented execution prefix containing 78 indirect-call occurrences interleaved with direct memory accesses. Incoming arguments, additional machine state, call results, and memory observations determine the values passed to dependencies and the addresses and values of direct writes.

No application-level purpose is established. In particular, the evidence does not establish initialization, allocation, serialization, device control, or object management.

The supplied representation reports invalid instruction data and ends at an invalid-instruction boundary. This contract describes the represented sequence conditionally; it does not establish a valid function boundary, executable call targets, complete reachability, or normal completion.

- A **word** is 32 bits.
- A **wide observation** is 64 bits, separated into low and high 32-bit halves.

These are conditional static examples, not executed tests. Each assumes execution reaches the relevant operations and dependencies and memory permit the stated observations.

1. **Initial-word wrapping.** If F-U005 supplies 0xFFFFFFFF, the scaled base is 0xFFFFFFE0, the shifted initial word is 0xFFFFFF80, and the reduced initial value is 0x3FF. The fourth-argument byte store consequently targets 0x406. No overflow-rejection branch is represented.

3. **Maximum saved byte.** A saved byte of 0xFF produces a zero-byte write at 0x110 and a doubled-byte base of 0x1FE. F-U026 receives 0x1FE as its first argument. The subsequent global assignment receives the numeric value 0xFF, without establishing its write width.

4. **Token byte versus word.** A token of 0x12345678 yields 0x02468ACF after logical right shift by three. The explicit token-byte stores contain 0xCF; the later token-word store contains 0x02468ACF.

5. **Coincident address with unresolved global representation.** If the saved byte is zero, the phase-4 token-byte store targets 0x0D. With the global’s width, destination type, and endianness unresolved, the contract does **not** promise that the byte at 0x0D becomes 0xC0 or that only one byte is affected.

7. **Selector truncation and address wrapping.** A final selector of 0xFFFFFFFF yields quadrupled selector 0xFFFFFFFC, first stored selector byte 0xFC, masked-selector byte 0xFF, and final read address 0xFFFFF001 under the represented 32-bit arithmetic.
