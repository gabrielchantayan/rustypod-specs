# F-764e8cc35410

## Purpose

F-764e8cc35410 reports whether two pointed-to integer values differ.

The established behavior is value comparison, not pointer comparison. Distinct addresses can produce false when their stored values are equal. The same address can produce false when both operand evaluations obtain the same value.

The function does not modify either operand, calculate a difference, or establish an ordering between the values. Its result distinguishes only equality from inequality.

## Behavior

### Normal operation

The function evaluates the integer designated by each pointer and returns their inequality relation.

For stable, valid input objects, the behavioral contract is:

| Relationship between stored values | Result |
|---|---|
| Equal | False |
| Unequal | True |

Pointer identity is not an independent input to the decision. There is no address-order comparison, identity shortcut, or special treatment of equal pointers in the supplied definition.

No arithmetic difference is calculated. Consequently, comparing values near the integer type’s minimum or maximum does not itself introduce subtraction overflow. Negative values, zero, and positive values participate in the same equality test.

### Access ordering

The supplied expression requires a value from each operand. It does not establish which pointer’s operand is evaluated first.

The contract therefore does not promise:

- A first-pointer read before a second-pointer read.
- A second-pointer read before a first-pointer read.
- An atomic snapshot of the two objects.
- Any synchronization or memory-ordering operation.

These are source-level value accesses. The supplied definition does not establish a particular number or order of physical machine loads. The pointers are not declared as volatile-qualified, and there is no basis for treating this function as a hardware-register access protocol.

Where the two pointers alias the same stable integer object, both operands obtain the same value and the result is false. This does not require two separate physical reads.
