## Behavior

2. The four-byte field at offset four is written with numeric zero.
3. F-27684eb6b19e is invoked with the original input address.
4. If that invocation returns normally, the original input address is returned.

The external value must be obtained for the first assignment before that assignment completes. The first assignment precedes the zero assignment, and both precede the dependency invocation. These are source-level ordering facts, not claims about individual processor instructions, bus transactions, or atomicity.

There is no visible conditional branch selecting whether either write or the dependency invocation occurs. Subject to execution reaching each operation without interruption or failure, both writes and the invocation occur on every call.
