## Behavior

If the bit is clear, the function invokes F-938c950e5046 with no explicit arguments.

- If its result is zero, the initial phase performs no direct write to object offset `0x10C` and makes no call to F-4f0f1cd223e8 or F-8f9bd59e3ec5.
- If its result is nonzero, the function invokes F-4f0f1cd223e8 with no explicit arguments. It reads one byte at offset `0x4C8` from the returned address, writes that byte at object offset `0x10C`, and then invokes F-8f9bd59e3ec5 with the returned address and the object address, in that order.

### Dispatch gate

After the initial phase, including any completed dependency calls, the function reads the 32-bit field at object offset `0x44`.

If the value is zero, the function returns without entering the later lookup or dispatch phase.

If the value is nonzero, the function proceeds. This is a zero/nonzero test, not a positivity test or a comparison against a particular enabled value.

The dispatch gate is read after the initial phase rather than captured before it. Consequently, changes made by initial-phase dependencies can affect whether dispatch is reached.
