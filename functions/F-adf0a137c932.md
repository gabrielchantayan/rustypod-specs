# F-adf0a137c932

## Purpose

The established behavior is:

- Query a dependency and distinguish exactly the result `1` from every other result.
- For any other result, invoke an additional dependency before reading the object’s dispatch field.
- Read a 32-bit value at object offset `0xD0` and one of two global 32-bit values.
- Pass those values to F-b58e53cafbfd.
- Create a writable, invocation-local 32-bit value initialized to decimal `28`.
- Invoke F-338d16f9ce72, F-1216949dec94, and F-1333331b2da1 in that order, using two interior addresses of the supplied object and the address of the local value.

The purpose of the object, the meaning of the dispatched values, and the significance of `28` are not established. The final three calls might implement a protected update, but synchronization is an inference, not part of the established contract.
