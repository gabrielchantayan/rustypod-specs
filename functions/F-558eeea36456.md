# F-558eeea36456

The established behavior is a direct byte read at an offset of 112 bytes, hexadecimal 0x70, from the supplied base. The byte is returned without a demonstrated transformation. Those interpretations are not part of this contract.

This is a static behavioral specification. No runtime tests have been performed.
