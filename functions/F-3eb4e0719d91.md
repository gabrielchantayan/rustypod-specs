# F-3eb4e0719d91

## Purpose

The static representation establishes an ordered sequence of indirect calls, computed-address memory accesses, global-state updates, and a terminal invalid-instruction boundary. It does not establish an application-level purpose.

This contract describes the observable operations conditionally: each later operation requires all earlier accesses and calls to complete. It does not identify the sequence as a valid initialization, exception-handling, or memory-management service.

The supplied representation includes warnings about invalid instruction data and overlapping global symbols. Consequently, the recovered function boundary, interface, and control flow have unresolved reliability limits. No normal return is visible.

No runtime tests have been performed.

A different global word, **the address-state word**, is associated with `0x0897EA80`. The sequence assigns four times P to it. The following operations do **not** simply retain and reuse that computed value:

1. A self-addressed word store obtains both its destination and its payload from reads of the address-state word.

The representation uses the global separately for the self-addressed store’s destination and payload. It does not establish an ordering between those two operand reads, an atomic snapshot, or that they would observe identical values in a stateful memory environment.

Crucially, the self-addressed store may overlap the address-state word. Its effect can therefore change the value used by the following destination read. A contract that always places D at the originally computed four-times-P address plus four is unsupported. That simpler interpretation requires additional assumptions: stable global reads and no intervening effect that changes the address-state word.

## Acceptance examples

These are conditional static criteria, not executed tests. Each assumes preceding operations complete and explicitly stated stability or non-aliasing conditions hold.

1. **Signed classification.** If the halfword read at R plus D is `0x7FFF`, the derived word written at C plus eight is zero. If it is `0x8000`, that word is `0xFFFFFFFF`.

2. **Low-address selection.** With bit 7 of C clear, the K-derived stores target `0x5C` and `0x170`. With that bit set, they target `0x60` and `0x180`.

3. **Repeated-access trace.** For independently observable destinations, four halfword writes of C16 and four word writes of Q must remain observable in the specified interleaving. One write of each is insufficient.

4. **Overlap at C.** The word at C plus sixteen receives V before later halfword writes at C plus eighteen. Its final bytes need not represent V; the result depends on endianness and other aliases.

5. **Return-derived publication.** D is written at H plus four before H plus eight, with the K-derived D store between them.

6. **Address-state stability case.** If the address-state word retains the assigned four-times-P value throughout its subsequent reads, the self-addressed store uses that value for its address and payload, and the following D store targets that value plus four.

7. **Address-state alias case.** If the self-addressed store changes the address-state word to J, and the next read observes J, the D store targets J plus four—not necessarily four times P plus four.

8. **Late halfword stability case.** If no intervening effect changes the reset-source halfword after its assignment from G, the constructed value has G’s upper sixteen bits and lower sixteen bits `0xEA70`.

9. **Late halfword modification case.** If an intervening overlapping write leaves the reset-source halfword as `0x1234`, the later construction uses `0x1234EA70`, regardless of the earlier upper half of G.

10. **No implied gap clearing.** The E-derived accesses do not guarantee zero bytes at offsets eight through fifteen.

11. **Early failure.** If the first store faults, neither indirect call nor any later effect is reached on the visible path. No rollback or error result is specified.

12. **Unused explicit input.** Changing B alone changes no explicitly represented operation; hidden ABI effects remain outside that claim.
