### Dependency preparation

Preparation is a long, straight-line sequence of distinct indirect invocations, with no represented data-dependent loop or conditional branch.

Arguments include shifted and masked results, duplicated values, explicit zeros, retained earlier results, and secondary machine-result values. An invocation with no represented arguments, or only zero-valued arguments, is not established as a no-op.

The complete preparation-call enumeration remains **documented_only**. Retained values used below have these roles:

### Converted global base and saved link

Global 0x05 is read and converted to unsigned 32-bit, establishing **converted global base**. This capture precedes assignment of compact base’s eight-bit conversion to global 0x01. Converted global base is not established to lie within 0–255.

A byte containing half compact base’s low byte is written at converted global base plus 0x15. Payload word’s low byte is written at primary base plus 0x11; payload word is then published as a word at initial read-back plus 0x54; primary base plus 0x11 is cleared as a byte.

Under the zero-read-back inference, payload publication is a word write at address 0x54.

The word at converted global base plus 0x54 is captured as **saved link**, then replaced with initial read-back. The preceding global-0x01 assignment may affect that read through its unresolved footprint; converted global base itself is already captured.

Half compact base is published as a word at compact base plus 0x34. A word from primary base plus 0x74 establishes the **primary-reached base**, whose offset 0x54 receives twice primary base. Separate word reads at compact base plus 0x74 supply the address and value for a self-publication through offset 0x54; they are not established as one snapshot.

Saved link is written twice at saved link plus 0x24. The first such write is followed by publication of saved link’s low byte at primary-reached base plus 9, replacement of primary-reached base plus 0x54 with payload word, the second self-reference, and another byte publication at primary-reached base plus 9.

Compact base plus 0x14 receives twice primary base, then saved link twice. Between the first and second of these publications, global 0x54 is assigned twice saved link. This global assignment is distinct from an explicit word write at address 0x54.

Two bytes containing the low byte of four times saved link are subsequently written at compact base plus 0x15. Only afterward does global 0x15 receive compact base’s eight-bit conversion.

Global 0x05 has no established equivalent rule. An unsigned eight-bit declaration would support 0x000000FE; a signed eight-bit declaration holding −2 would ordinarily convert to 0xFFFFFFFE. Neither missing declaration is selected here.

### Aliasing final publications

Suppose global base plus 0x74 and scaled base plus 0x10 designate the same ordinary-memory word. The saved scaled-base-plus-4 word is 0x11223344; the captured scaled-base-plus-0x40 word is 0x55667788.

The common destination first receives 0x11223344, then 0x55667788, before doubled-link base is published at global base plus 0x44. Immediately after the second write, the common word is 0x55667788. Reversing those two publications is not equivalent.

If the first publication faults before completing, the subsequent scaled-base-plus-0x10 publication is not reached.

### Snapshot and fresh-read boundaries

If global 0x3A’s actual assignment footprint overlaps a subsequently captured word, that read observes the intervening mutation. Earlier captures do not change retroactively.

### Partial execution
