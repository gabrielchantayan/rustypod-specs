## Behavior

### Field interpretation

The three extracted fields are:

- **High-byte field:** bits 31 through 24, with a range of 0 through 255.
- **Middle-byte field:** bits 23 through 16, with a range of 0 through 255.
- **Low-word field:** bits 15 through 0, with a range of 0 through 65,535.

These fields are disjoint and collectively account for all 32 input bits. None of the packed value’s bits is omitted or included in more than one field.

For explanatory purposes, the packed value equals the high-byte field multiplied by 16,777,216, plus the middle-byte field multiplied by 65,536, plus the low-word field. This identity describes the partition; it does not require the function to perform reconstruction arithmetic.

The shifts operate on an unsigned value. The high-byte extraction therefore does not propagate a sign bit. Setting bit 31 can produce a high-byte value from 128 through 255, not a negative numeric argument.

The two byte fields remain numeric arguments in the 32-bit unsigned expression domain. The low-word field likewise remains a 32-bit unsigned numeric argument whose possible values happen to fit within 16 bits. The function does not construct a packed three-field object in memory.
