## Acceptance examples

These are conditional consequences of the static representation, not executed tests.

1. **Upper-nibble extraction.** If U-07 returns `0xA1234567` and execution reaches F-2cc1255261f3, that dependency receives 10. It does not receive the low nibble, the full word, or a signed-shift result.

2. **Unsigned subtraction wraparound.** If the second ambient value is zero, subtracting `0x33` modulo \(2^{32}\) yields `0xFFFFFFCD`; the read base is `0xFF`. Progress then requires the four word reads beginning at `0xFF`, `0x103`, `0x107`, and `0x10F` to be supported.

3. **Overlapping source and destination.** If the derived read base is `0xC3`, the four reads still occur before the first destination write. The values copied to `0xCB` and `0xCF` are the previously read values from `0xCB` and `0xD3`, respectively.

4. **Rejected gate value.** If the post-U-14 static read yields 9, the base-plus-`0x68` write occurs before the invalid-instruction boundary. U-15 and U-16 are not reached along the represented path.

5. **High-bit gate value.** A gate value of `0xFFFFFFFF` is rejected because the comparison is unsigned. It is not accepted as negative one.

6. **Accepted upper boundary.** If the gate value is 8 and all intervening operations complete, the byte store writes 8 at base plus `0x0F`, and the halfword destination is `0x30`. U-16 receives U-15’s low half, high half, and `0x74`, in that order.

7. **Local-address truncation.** If the contributing local slot’s address has low 16 bits `0xFF00`, the stored halfword is `0x0298`, after truncation of the addition to 16 bits.
