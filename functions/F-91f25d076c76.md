# F-91f25d076c76

## Purpose

F-91f25d076c76 performs a linear sequence of indirect calls, address calculations, byte transfers, 32-bit stores, global-state accesses, and a final call through address zero.

The supplied static representation does not establish an application-level purpose. It does not justify classifying the function as initialization, serialization, allocation, cleanup, or device control.

The declared interface is parameterless and returns no explicit value, but the body consumes incoming machine-state values and dependency results. Its invocation requirements therefore exceed the declared interface.

This contract describes static evidence and conditional consequences only. No runtime tests have been performed.

## Acceptance examples

These examples are conditional consequences of the static representation, not executed tests.

1. **Low-byte selection.** If the initial 32-bit read yields `0x123456AB`, the byte written at entry base plus 1 is `0xAB`. This selects numeric low bits without assuming memory endianness.

2. **Fresh repeated read.** If the first read at first scaled address plus 116 yields `0x11`, and intervening dependencies change that word to `0x22`, the two associated byte writes contain `0x11` and `0x22`.

3. **Retained full word.** If captured word is `0x89ABCDEF`, its immediate byte transfer writes `0xEF`. Both later captured-word stores write all 32 bits, even if the original source word subsequently changes.

4. **Discarded bits.** Conditional on machine-width execution that truncates the initial left shift to 32 bits, an F-D012 result with bit pattern `0x40000001` produces retained scaled value `0x00000004`; F-D027 receives `0x00010000`. This example does not establish defined signed-shift behavior.

5. **Unsigned lookup.** If either lookup reads `0xFE`, its corresponding destination is address 271, not a negative-offset address.

6. **Sampled-bit selection.** For sampled word `0x00400000`, the first table transfer writes zero and the second writes one. For `0xFFFFFFFF`, both write `0xFF`.

7. **Retained global address.** If the global read supplies address A and a dependency later changes that global to B, the sampled-word read still uses A plus 20. Its contents remain subject to intervening writes.

8. **Unresolved late destination.** If execution reaches the byte-zero store with the unresolved pointer value equal to a valid writable address P, one zero byte is written at P after the global result assignment. This does not imply that P was supplied at entry or preserved by any dependency.

9. **Unaligned final store.** If late selector is 128, the final 16-bit store begins at address 1. Whether that access succeeds depends on the execution environment’s alignment and mapping rules.

10. **Partial completion and final transfer.** If F-D041 does not return, later accesses are not reached. If execution instead reaches F-D082 on a platform where address zero is not executable, failure there is consistent with the representation; successful return is not guaranteed.
