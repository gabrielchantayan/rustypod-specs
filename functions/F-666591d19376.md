# F-666591d19376

## Purpose

The available static evidence describes a sequence of indirect calls, arithmetic transformations, byte accesses, and 32-bit memory accesses. It does not establish an application-level purpose.

The observable behavior is dominated by:

- Passing values between unresolved indirect dependencies.
- Using returned values and incompletely recovered register outputs to calculate addresses.
- Writing bytes to addresses selected by previously read bytes.
- Writing 32-bit values to addresses calculated using several different scaling factors.
- Calling F-674e75a953e8 once with two identical arguments.
- Reaching a boundary marked as invalid instruction data, with no established normal return.

This contract describes the visible sequence conditionally: execution must reach each operation, preceding calls must return, and the relevant addresses must be accessible. It does not certify that the recovered sequence represents a valid executable function.

### Arithmetic and memory notation

For describing addresses below:

- A **byte-selected write** reads an unsigned byte from a specified source address and writes one byte to the numeric address equal to that byte plus 17.
- A **word slot** for an index is the address equal to four times that index plus 20.
- A **wide-stride slot** for an index is the address equal to sixteen times that index plus 20.

These are descriptions of address arithmetic, not inferred data structures.

Unsigned 32-bit operations retain their low 32 bits. Unsigned right shifts insert zero bits. A byte store retains only the low eight bits of its value.

A fifth indirect call produces a 32-bit result. Before that result is passed onward:

1. One byte is read at the incoming base plus one.

The earlier result, shifted left by two positions, is then passed to an indirect call.

“No explicit arguments” describes only the recovered call expression. It does not establish that a dependency receives no register, stack, or global inputs.

### 2. Creation and propagation of an early retained value

- That returned value shifted left by two.

The following indirect call returns a value retained for later operations. F-674e75a953e8 is called with that retained value as both arguments.

After another indirect call, the retained value is written to the word slot selected by a recovered auxiliary register output. The next call receives that auxiliary value and its masked fragment: retain bits 0 through 29, then shift right by ten.

The auxiliary output’s producer is not reliably identified by the supplied evidence. It must not be treated as a conventional return value of a particular dependency.

### 3. First auxiliary-value and byte-fragment writes

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Incoming byte selection.** If the initial byte read returns 200 and the incoming byte value is 171, the corresponding direct write stores 171 at numeric address 217.

2. **Zero-byte operation.** If the read from address 1 returns 9, the later zero-byte operation writes zero at address 26. It does not establish that address 1 itself is cleared.

3. **Masked fragment truncation.** If a fragment value is 1,073,741,823, masking to 30 bits and shifting right by 20 produces 1,023. The byte store writes 255, not 1,023.

4. **Distinct slot layouts.** For a returned index of 3, a word-slot address is 32 and a wide-stride-slot address is 68. A wide-stride write of the scaled index stores 12 at address 68. It does not imply a write to address 32.

5. **Unsigned product reduction.** If the paired result’s low half is 64, both its product by 67,108,864 and its product by 268,435,456 reduce to zero in 32-bit unsigned arithmetic. The corresponding direct word write targets address 20 and stores zero.

6. **Repeated selector reads.** If the first late selector read returns 4 and an intervening dependency changes that selector byte to 7, the two late byte writes target addresses 21 and 24 respectively. Reusing the first selector would not match the visible behavior.

7. **Interrupted execution.** If an indirect dependency does not return, no later direct operation is required to occur. No rollback of earlier writes is established.
