# F-86393e9907da

## Purpose

F-86393e9907da prepares a 16-bit combined value in invocation-local storage, invokes three dependencies, and then assigns a value to an externally addressed 16-bit destination.

The prepared representation and destination selection have different information boundaries:

- The less-significant component of the combined value incorporates seven index bits and one value bit.
- The more-significant component is produced by converting the value through plain char. Its exact bit pattern requires an applicable conversion rule.
- The destination displacement uses the full index, not the seven-bit portion represented in the combined value.
- The destination assignment separately converts the value to a signed 16-bit type.

The relative significance of the representation’s components is established. Their order in memory at the pointer passed to the middle dependency is not established without a target storage convention.

An external operation followed by a related memory update is **inferred intent**. The evidence does not establish a device, protocol, register bank, cache, or synchronization mechanism.

### Plain-char conversion

The value passes through plain char before contributing the more-significant component. Plain-char signedness is not supplied.

Under the source-language interpretation used for the signed-arithmetic analysis:

- A conversion whose input is representable in the applicable plain-char type preserves its numeric value.
- If plain char is unsigned and eight bits wide, conversion reduces the value modulo 256.
- If plain char is signed and the input is outside its range, the supplied evidence does not establish the conversion result or whether the applicable rules permit an implementation-defined signal.

Consequently, the unconditional rule “the more-significant component is the value’s low eight bits” is not justified from the supplied evidence alone.

Under an explicit **low-eight-bit retention convention**, the representation has the following properties:

- L contains index bits 0–6 and value bit 8.
- Index bits above bit 6 do not affect the combined value.
- Value bits above bit 8 do not affect the combined value.
