# F-c4d5ae93530f

A zero result from the latter dependency causes the entire cycle to repeat. A nonzero result terminates the function with a 32-bit zero return value.

Within each cycle, the function brackets the result-obtaining phase with two calls whose arguments are read separately from the same location in a caller-provided structure. When the result-obtaining dependency returns zero, an intervening dependency is called before another attempt.

**Established behavior:** the call sequence, zero/nonzero decisions, direct memory reads, argument forwarding, and normal return value described below.

**Inferred intent:** the arrangement resembles synchronized retrieval followed by processing or filtering. ## Behavior

1. The function reads four bytes at structure offset `+0x2C` and passes the resulting 32-bit value to F-3fef4e222917.
2. After that dependency returns normally, the function calls F-08e7aeef99f4 with the address at structure offset `+0x40`.
3. If F-08e7aeef99f4 returns zero, the function calls F-162a41bac6a7 with the address at structure offset `+0x34`. After that call returns normally, it calls F-08e7aeef99f4 again.
4. The preceding retry sequence continues until F-08e7aeef99f4 returns a nonzero 32-bit value.
5. The function reads the four-byte field at offset `+0x2C` again and passes this newly read value to F-599da3979baf.
6. After F-599da3979baf returns normally, the function calls F-31cb038bb61e. Its arguments, in order, are:
   - the nonzero result that ended the inner retry sequence;
   - the first forwarded value;
   - the second forwarded value.
7. A zero result from F-31cb038bb61e starts another complete outer cycle. A nonzero result ends repetition and causes the function to return zero.

There is no visible branch on the results of F-3fef4e222917, F-162a41bac6a7, or F-599da3979baf. If those dependencies return values, this function does not use them.

### Retry boundaries and ordering

The two retry boundaries have distinct effects:

- A zero result from F-08e7aeef99f4 invokes F-162a41bac6a7 and retries F-08e7aeef99f4. It does not directly restart the outer cycle.
- A zero result from F-31cb038bb61e restarts the whole cycle, including a fresh field read and another call to F-3fef4e222917.

Consequently, several calls to F-08e7aeef99f4 may occur between one call to F-3fef4e222917 and the corresponding call to F-599da3979baf. F-3fef4e222917 is not called again merely because an inner attempt returns zero.

The inner sequence always begins with F-08e7aeef99f4. F-162a41bac6a7 is not called before that first attempt, and it is called once after each normally returning zero result before the next attempt.

F-599da3979baf precedes F-31cb038bb61e. The nonzero result selected by the inner sequence is preserved as the latter call’s first argument.
