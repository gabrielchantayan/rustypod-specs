# F-058144d59a45

## Purpose

F-058144d59a45 maps four distinguished integer inputs to four 32-bit results. It returns an all-ones 32-bit result for every other value of the selector. A separate 32-bit input does not affect the mapping.

The established mapping is:

| Selector | Returned 32-bit value |
|---:|---:|
| 1 | 0 |
| 2 | 1 |
| 3 | 2 |
| 4 | 3 |
| Any other value | 4,294,967,295, equivalently `0xFFFFFFFF` |

A plausible intent is conversion from a one-based classification to a zero-based classification, with an out-of-range sentinel. Neither the classification’s meaning nor the sentinel’s interpretation is established. Consumers must not infer that the result is an array index, an error code, or an enumeration without a separate contract.

All remaining selector values produce the same all-ones result. There is no separate treatment for zero, negative values, or values larger than four.
