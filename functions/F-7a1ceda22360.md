# F-7a1ceda22360

## Purpose

F-7a1ceda22360 processes a mutable structured query within a mutable context. It delegates compound queries, recursively processes eligible nested queries, and selects nongrouped, aggregate-without-grouping, or grouped generation.

“Query,” “aggregate,” “grouping,” “cursor,” “register,” and “materialization” are inferred descriptive labels. Established behavior consists of accesses, predicates, explicit mutations, dependency arguments, call order, and return handling. Dependency internals and instruction meanings are not established.

The operation is not transactional. Failure can leave mutations and builder calls in place.

## Behavior

### Entry, preparation, and compound delegation

The context’s state pointer is captured before the null-query test. Null query returns 1 without dependency calls.

For nonnull query, the captured state’s failure byte is tested first. Context offset 0x40 is read only if that byte is zero. Either nonzero value rejects entry. F-0055bebe0706 then receives context, 0x15, and three zeros; nonzero return also rejects entry.

An external initializer receives the working region and size 44. Its opaque ID and initialization semantics are unavailable.

Ordering is saved. For destination selectors below 5, query ordering and the distinct byte are cleared before F-f1d95153eae8 receives context, query, and zero. Preparation failure enters ordinary cleanup without explicit restoration. Preparation success explicitly restores saved ordering, but not distinct. Unknown dependency mutations prevent stronger final-value guarantees.

A nonnull forward link selects compound processing. If the head link is null, the forward chain is traversed from the current query. Each object receives its backward link and a head link to the original query; the first backward link is null. A 32-bit term count accumulates.

Only after these writes is the captured state’s signed compound limit read. A nonzero limit smaller than the signed term count causes F-2022b0f73f3b to receive context and an excessive-compound-term diagnostic, then returns 1. A preexisting head skips rebuilding and this check.

F-4d789aec8f78 receives context, query, destination, and auxiliary value. Its return bypasses ordinary cleanup.

### Ordinary preparation and recursion

The function captures filter, source, grouping, aggregate byte widened to 32 bits, post-group filter, distinct byte, and result pointer. Cleanup follows if captured result is null, context offset 0x40 is signed-positive, or F-9f0c21b197c2 rejects context, destination, and captured result’s leading word. A negative context field does not satisfy this later positive-value check.

Selectors below 5 suppress working ordering independently of restored query ordering. F-9b3ea8470521 obtains the builder; null enters cleanup.

Source entries are visited in increasing order against the current source collection’s signed 16-bit count. Negative counts produce no iterations. Eligibility requires a nonnull nested pointer and zero completion byte.

For each eligible entry:

- A nonzero override saves and replaces context’s nested-context value.
- F-530dbcfdc915 receives query. Its return is added to the accumulator read after that call.
- F-1e7ea6aa642e receives a temporary descriptor, selector 9, and the entry’s destination operand.
- The nested pointer is reread. Recursive F-7a1ceda22360 receives context, nested query, temporary descriptor, current query as parent, entry index, the working aggregate flag’s address, and auxiliary zero.

The recursive return is ignored. A nonzero failure byte in the captured state enters cleanup before accumulator subtraction or override restoration. Otherwise, a second F-530dbcfdc915 return is subtracted from the accumulator read after that call, and an active override is restored. The two contributions need not match.

Filter, source, grouping, distinct, and post-group filter are then reloaded. Ordering is reloaded only when the current selector exceeds 4. Captured result is not reloaded. Recursion can modify the working aggregate flag through its supplied address.
