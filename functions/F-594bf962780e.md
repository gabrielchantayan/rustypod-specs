# F-594bf962780e

## Purpose

F-594bf962780e assembles and returns a 32-bit status mask from a sequence of indirect queries on a supplied object, a query on temporary state, and a conditional query on an auxiliary object.

The established behavior is mask construction, not interpretation of the individual flags. The supplied evidence does not identify the domain meaning of the object, selector, or flags.

For an execution that reaches the return normally:

- Bits 0 through 7 reflect eight nonzero-result conditions.
- Bit 8 represents an additional condition evaluated only when the eighth condition succeeds and the selector has one of two specific values.
- Bits 9 through 31 are zero.
- Bit 8 cannot be set without bit 7.

These guarantees describe the function’s own mask construction. They depend on the called operations returning normally and satisfying the memory and calling-convention requirements described below.
