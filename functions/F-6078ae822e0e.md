## Acceptance examples

These are conditional static-review examples, not executed tests.

1. **Selector destination:** A selector of 0x20 directs its byte write to 0x31. A selector of 0xff directs it to 0x110; addition does not wrap at eight bits.

2. **Truncated extraction:** For a byte write derived from a word shifted right by 22, changing only original bits 30–31 leaves the written byte unchanged.

3. **Three reads at 0x28:** Suppose the initial saved read yields 0x11223344. The two argument reads may be documented separately without requiring either to equal that snapshot or each other. If the later store is reached, its stored value is 0x11223344 despite changes to address 0x28 during either intervening call. The argument reads have no prescribed relative order.

4. **Two late global reads:** If the first read yields 0x400, its later masked-and-shifted argument is 1. If the second read yields 0x800, its four-times-scaled value is 0x2000. The contract must not substitute either read for the other merely because no call intervenes.

5. **Address-1 argument evaluations:** In the unresolved invocation following the offset-0x1c publication and subsequent selector updates, each argument is sourced by its own byte-read evaluation at address 1. Under an environment allowing changing read values, the arguments need not agree. Both precede the following selector-directed clear; their mutual evaluation order remains unspecified.

6. **Snapshot versus fresh selector:** A dependency may change a selector location between updates. A later fresh read uses the then-current selector; a separately saved selector passed as an argument remains the earlier byte.

7. **Repeated stores:** The two adjacent offset-0x34 stores of a selector and its doubled value remain two represented writes, even when the selector is zero.

8. **Conditional low-address reduction:** Under 32-bit truncating arithmetic, scaling a word by four, shifting left by 26, and multiplying by 0x400 yields zero. This does not require the preceding intermediate field-read base to be zero.

9. **Unmapped destination:** If address 0 is not writable, reaching its explicit word store cannot be accepted as successful completion. No visible validation or recovery handles that condition.
