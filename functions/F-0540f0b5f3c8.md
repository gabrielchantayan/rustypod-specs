# F-0540f0b5f3c8

## Purpose

F-0540f0b5f3c8 describes an ordered sequence of three explicit memory writes, two explicit memory reads, and nineteen indirect calls, ending at an unresolved control-flow boundary.

The supplied static representation establishes data dependencies and operation ordering. It does not establish an application-level purpose, a verified calling convention, or normal completion. No initialization, serialization, device-control, allocation, or cleanup role is assumed.

A material distinction governs the first byte write and one dependency call: an unsigned 32-bit shifted result is converted to a signed integer before either operation uses it. When that unsigned result exceeds the signed range, the supplied representation does not establish that conversion as value-preserving or as a low-32-bit reinterpretation.

This is a static, source-facing contract. No runtime tests have been performed.

## Behavior

All later operations are conditional on earlier operations completing and transferring control to the next represented operation. Dependencies are not assumed to return, preserve memory, or preserve hidden state.

### Initial write and first five calls

Before any dependency invocation, store H as a four-byte value at A plus `0x14`. No read of the previous contents, validation branch, or compensating action is shown.

Then invoke:

1. D-01 with A.
2. D-02 with no explicit arguments.
3. D-03 with no explicit arguments.
4. D-04 with no explicit arguments.
5. D-05 with no explicit arguments, obtaining U.

“No explicit arguments” does not mean “no inputs.” A dependency may consume memory, globals, or other machine state.

The initial store precedes these calls. A dependency accessing overlapping storage may observe or overwrite it.

### Unsigned shift, signed conversion, and first byte write

After D-05 returns, form Q by shifting U left by two positions in unsigned 32-bit arithmetic. Thus Q is four times U modulo \(2^{32}\).

Convert Q to the signed temporary T before the first selector read and byte write. This conversion is a distinct behavioral boundary:

- For representable Q, T equals Q.
- For nonrepresentable Q, neither a particular signed value nor uninterrupted progress is established by the supplied source alone.

If execution continues, read one unsigned byte at R plus `1`, obtaining B₁. Use B₁ itself to select the destination address B₁ plus `0x11`, then store the character-converted value of T there.

The destination is a numeric address in the inclusive range `0x11` through `0x110`. It is not R plus a selected offset, and B₁ is not interpreted as a pointer fetched from memory.

If the implementation both preserves the low 32-bit pattern in the Q-to-T conversion and performs low-eight-bit character narrowing, the stored byte equals the low eight bits of Q. Under those conditions, only U’s lowest six bits influence the stored byte, whose lowest two bits are zero. Those conclusions are not unconditional for an out-of-range Q-to-T conversion.

No destination check is shown.

### D-06 and forwarding of V

After the first byte write, invoke D-06 with:

1. T.
2. T again.
3. U shifted left by four positions in unsigned 32-bit arithmetic.

The first two arguments are uses of the same converted signed value. They must not be specified as unconditional forwarding of unsigned Q.

The third argument is independent of that conversion. It equals sixteen times U modulo \(2^{32}\), provided execution reaches the call.

Then invoke, in order:

1. D-07, obtaining V.
2. D-08 with V.
3. D-09.
4. D-10.
5. D-11.
6. D-12, obtaining X.

V is forwarded as an opaque four-byte value. No pointer meaning, ownership transfer, or resource obligation is established.

### Second selector read and byte write

After D-12 returns, read one unsigned byte at R plus `1` again, obtaining B₂.

Using the original saved U, clear its two highest bits and shift the remaining unsigned value right by twenty positions. The resulting integer is in the range 0 through `0x3FF`.

Convert that result to the represented one-byte character type and store it at B₂ plus `0x11`.

Under low-eight-bit character narrowing, this writes bits 20 through 27 of U. The wider extraction also contains U’s bits 28 and 29; those bits do not survive such narrowing. The source-level character conversion remains subject to the qualification in **Uncertainties**.

B₂ is a fresh read, not a reuse of B₁. Intervening calls may change the selector storage. The first byte write may itself change it if the locations overlap.

This extraction does not use T. Its arithmetic does not inherit the Q-to-T conversion uncertainty, although reaching it still depends on prior execution continuing.

### Final calls

After the second byte write, invoke:

1. D-13 with X shifted left by two positions.
2. D-14.
3. D-15.
4. D-16.
5. D-17, obtaining Y.
6. D-18 with Y shifted left by two positions and B₂ widened to an unsigned integer.
7. D-19.

X and Y are represented as signed integers. Under conventional 32-bit signed rules, their shifts are unproblematic for nonnegative values no greater than `0x1FFFFFFF`. Negative operands or results exceeding the signed range cannot be assigned unconditional modular semantics from this representation.

D-18’s second argument is the saved B₂, in the range 0 through 255. It is not another selector read. Later changes to selector storage do not change this saved argument.

The sequence then reaches the unresolved terminal boundary.

## Acceptance examples

These are conditional deductions, not executed tests. Unless stated otherwise, they assume valid accesses, returning dependencies, defined address calculations, and successful continuation through the represented path.

### Zero-valued U

For U equal to zero:

- Q is zero, and conversion to T is value-preserving.
- The first byte write stores zero.
- D-06 receives zero for all three arguments.
- The second byte write stores zero.

B₁ and B₂ may still differ, so the writes need not share a destination.

### Representable shifted result

For U equal to `0x12345678`:

- Q is `0x48D159E0`, within the signed 32-bit range.
- T has that same numerical value.
- D-06 receives T twice and unsigned `0x23456780` as its third argument.
- Under low-eight-bit character narrowing, the first byte write stores `0xE0`.
- The second extraction is `0x123`; under the same narrowing behavior, its byte write stores `0x23`.

The Q-to-T conversion is resolved here. Character narrowing is a separate qualification.

### Nonrepresentable shifted result

For U equal to `0xFFFFFFFF`:

- Q is unsigned `0xFFFFFFFC`.
- Q exceeds the signed 32-bit maximum.
- The source alone does not determine T or guarantee progress beyond its conversion.
- Therefore the first stored byte and D-06’s first two arguments are not unconditionally specified.
- If reached, D-06’s third argument is unsigned `0xFFFFFFF0`.

Under the additional assumptions that Q-to-T conversion preserves its 32-bit pattern using two’s-complement interpretation and character narrowing retains the low eight bits:

- T is −4.
- D-06’s first two arguments are that signed value.
- The first byte write stores `0xFC`.
- The second extraction is `0x3FF`, and its byte write stores `0xFF`.

These are conditional implementation behaviors, not universal acceptance requirements.

### Changed selector

If B₁ is `0x02` and the later read produces B₂ equal to `0xFE`:

- The first byte destination is `0x13`.
- The second byte destination is `0x10F`.
- D-18’s second argument is 254 if that call is reached.

Changes to selector storage after the second read do not change the saved argument.

### Overlapping selector and first destination

If selector storage is at `0x13` and B₁ is `0x02`, the first byte write targets the selector itself.

For U equal to 1, T is 4 and the first stored value is representable as a character. If intervening dependencies leave that location unchanged, B₂ becomes 4, and the second destination is `0x15`.

This illustrates why the second selector read cannot be replaced by B₁.

### Early non-return

If the Q-to-T conversion instead prevents continuation, the initial write and D-01 through D-05 precede that boundary; the first selector read still has not occurred.
