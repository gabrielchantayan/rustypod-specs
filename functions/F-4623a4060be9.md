## Acceptance examples

These are conditional consequences of static evidence, not executed tests.

1. **Unscaled initial selection.** With incoming selector \(0xffffffff\), the first computed word-read address is 1,043, not 4,112. This follows from shifting right by 22 before adding 20, without multiplication by four.

2. **Zero derived from width.** For any unsigned 32-bit shared-source observation, two successive right shifts by 23 produce zero. The associated early byte-source address is therefore 1.

3. **Extraction versus truncation.** If the relevant word is \(0xffffffff\), its right-shift-by-22 extraction is 1,023. A word write preserves 1,023; a byte write preserves 255.

4. **Fresh offset copy.** If a word read at base plus 116 yields \(0x12345678\), the associated byte write stores \(0x78\). If an intervening dependency changes that word to \(0xabcdef02\), the repeated copy stores \(0x02\), provided its fresh read observes that value.

5. **Retained propagation.** If the retained full word is \(0x12345678\), subsequent snapshot-sourced word writes use that value even when a dependency changes its original storage.

6. **Fresh byte selector.** If two explicit reads of address 1 observe 5 and 9, their destination addresses are respectively 22 and 26. The later destination does not reuse the earlier observation.

7. **Terminal composition.** If the three-byte input, when consumed, has abstract value \(0x123456\) and the final byte result is \(0xab\), the shared word becomes \(0x123456ab\). This example does not specify physical byte order.

8. **Terminal failure.** If the pointer-selected zero-byte write faults, the later composition, halfword write, and address-zero call are not reached. If only the address-zero call fails, the preceding completed writes are not rolled back by any represented mechanism.
