# F-48d29e30a224

## Purpose

F-48d29e30a224 resolves an object and returns a signed numeric value chosen by ordered precedence:

1. A matching object-classification comparison forces zero.
2. Otherwise, a non-sentinel descriptor value supplies the result.
3. Otherwise, two control arguments select an indirect method result, an object field, or a method invocation followed by an object-field read.

The sentinel is signed 16-bit −1. Its effect depends on where it is encountered. A descriptor sentinel enables later selection. A first method result of −1 can enable a second invocation. A final selected value of −1 becomes zero.

The function is not a pure lookup: resolution always precedes successful early returns, and some field-selection paths require a method invocation whose numeric result is discarded.

The domain meaning of the returned value is unknown. Interpretations such as size, index, identifier, or resource attribute are not established.

### Output

Normal completion returns a signed 32-bit integer.

Descriptor values and selected method results are treated as signed 16-bit quantities. The selected object field is read as 32 bits and narrowed to signed 16 bits. Returned 16-bit values are sign-extended to 32 bits.

Consequently, normal numeric results lie between −32768 and 32767. Zero does not uniquely identify a particular path: it can result from the classification shortcut, an actual zero value, or final normalization of a sentinel.

### Preconditions for normal completion

The descriptor must support every read reached by the selected path. The +4 read precedes resolution; the +12 reads occur only after successful resolution and a nonmatching classification comparison.

Resolution must produce a non-null object that remains valid for all subsequently reached object reads and calls. A matching classification requires access to the classification field but does not require access to the dispatch entry or selected-value field.

Whenever indirect dispatch is reached, the object’s table pointer and the entry at +0x108 must identify a callable target with a compatible calling convention. Whenever field selection is reached, the object field at +40 must be readable at that time.

These conditions are not checked locally. In particular, a returning dependency must leave sufficient valid state for the continuation that actually occurs; the supplied evidence does not establish that dependencies guarantee this.

## Behavior

### Resolution precedes value selection

The function reads the descriptor’s 32-bit resolution key at +4, then invokes F-23c46a4f09c5 with:

1. The supplied resolution context.
2. The key just read.
3. A zero third argument.

The returned pointer becomes the resolved object.

This call precedes the classification comparison, descriptor override, and control-dependent selection. Supplying an explicit descriptor value does not bypass resolution.

If resolution returns null, the function invokes F-a817d8d58c10. The static representation annotates that dependency as non-returning. No normal numeric result is established for this failure path. If the dependency returns unexpectedly, the represented continuation attempts to use the null object; no safe recovery is established.

Nothing at this call site establishes that resolution preserves the descriptor, globals, or other memory.

### Classification has first precedence

After successful resolution, the function compares the object’s 32-bit classification field at +76 with the global comparison value.

Equality causes an immediate return of zero. The descriptor’s explicit-value field is not reached, and no indirect invocation occurs.

The comparison uses state available after resolution returns. There is no represented snapshot of either comparison operand from before resolution. The relative order of the two operand reads is not established by the supplied representation.

### The explicit descriptor value has second precedence

If the classification comparison does not match, the function reads the signed 16-bit descriptor field at +12.

- A value of −1 continues to control-dependent selection.
- Any other value selects the explicit-return path.

The explicit-return path contains a separate read of that same field for the return value. That value is sign-extended to 32 bits and returned without final sentinel normalization.

Under stable memory, the return is the same non-−1 value that passed the check. The separate represented accesses do not establish a single atomic snapshot. If the field can change between them, the returned value need not equal the tested value. In particular, a second read of −1 would be returned as −1 rather than converted to zero.

No indirect method is invoked on this path.

### Control-dependent selection

This stage is reached only after a nonmatching classification comparison and a descriptor explicit-value read of −1.

The following table gives the complete selection behavior. “Narrowed result” means the method result interpreted as signed 16 bits before any local comparison or return.

| Method selector | Field-selection control | Behavior |
|---|---|---|
| Zero | Zero | Invoke the method with selector zero, then finalize its narrowed result. |
| Zero | Nonzero | Skip indirect dispatch and finalize the object field. |
| Nonzero | Zero | Invoke with the supplied selector. Return a non-−1 narrowed result immediately; otherwise invoke again with zero and finalize the second result. |
| Nonzero | Nonzero | Invoke with the supplied selector, then finalize the object field regardless of the method’s narrowed result. |

#### Zero method selector

With both controls zero, the function invokes the indirect method once with the resolved object and a zero selector. Its narrowed result proceeds to finalization. A sentinel result does not cause another invocation.

With a zero selector and nonzero field-selection control, no method is invoked. The function reads the object’s 32-bit field at +40, narrows it to signed 16 bits, and finalizes that value.

#### Nonzero method selector

A nonzero method selector always causes an initial indirect invocation after the earlier precedence checks have been bypassed. The selector is forwarded unchanged.

If the field-selection control is zero:

- A narrowed first result other than −1 is returned immediately, sign-extended.
- A narrowed first result of −1 causes a second indirect invocation with selector zero. The second result is narrowed and finalized.

If the field-selection control is nonzero, the initial method result does not supply the final numeric result, whether or not it is −1. After the method returns, the function reads the object field at +40, narrows it, and finalizes it.

Thus, nonzero field-selection control is not a general instruction to skip dispatch. A nonzero selector still requires the initial call.

### Finalization and width-sensitive behavior

Finalization applies to:

- A method result obtained using selector zero.
- The object field whenever field selection is reached.

A finalized signed 16-bit value of −1 produces zero. Any other finalized value is sign-extended to the 32-bit return width.

The first nonzero-selector method result is also narrowed before its sentinel comparison. Its full-width value is not the basis for deciding whether to fall back.

For the 32-bit object field, only the low 16 bits determine the narrowed value in the represented conversion:

| Object-field bit pattern | Narrowed value | Final return |
|---|---:|---:|
| 0x00010002 | 2 | 2 |
| 0x0000FFFF | −1 | 0 |
| 0x1234FFFF | −1 | 0 |
| 0x00008000 | −32768 | −32768 |

No value arithmetic other than narrowing and sign extension is represented. There are no local bounds checks for the listed field offsets.

## Side effects

The function contains no explicit writes to descriptor fields, object fields, or globals. Its direct memory operations are reads.

Observable changes can nevertheless arise through resolution, the failure dependency, and indirect method invocations. Their effects are not constrained by this function.

For an invocation that follows the represented normal control flow:

- Resolution is called once.
- The failure dependency is called if resolution returns null.
- Indirect dispatch occurs zero, one, or two times.
- Two indirect invocations occur only with a nonzero selector, zero field-selection control, and a first narrowed result of −1.

These counts concern calls made directly by this function, not calls performed internally by its dependencies.

Each represented indirect invocation obtains its target through the object’s table pointer and the entry at +0x108. A second invocation is not established to reuse the first target. If the first call changes dispatch state, the second can reach a different target, provided the resulting state supports valid continuation.

A field read following a method call occurs after that call returns. The function does not snapshot the field beforehand. Method-induced changes to that field can therefore affect the returned value.

The function does not explicitly acquire ownership, release ownership, adjust a reference count, allocate, or deallocate memory. Absence of those operations locally does not establish that dependencies avoid them. Object lifetime, descriptor stability, and global preservation remain dependency and caller obligations whose precise contracts are unknown.

These are conditional consequences of static evidence, not executed tests.

For all examples, assume required memory accesses are valid, memory is stable except for explicitly described changes, and any dependency expected to return does so normally. Each example states its relevant resolution outcome.

3. **Zero-selector method result.**

4. **Zero-selector sentinel normalization.**  
   Under the shared preconditions, both controls are zero and the method produces narrowed −1. The result is zero. No second invocation occurs.

5. **Nonzero-selector fallback.**  
   Under the shared preconditions, the field-selection control is zero and the selector is 9. The first invocation receives 9 and produces narrowed −1. A second invocation receives zero. If its narrowed result is 31, the function returns 31; if it is −1, the function returns zero.

The subsequent field read yields 12, and the function returns 12 regardless of the method’s narrowed result. Exactly one direct indirect-method invocation occurs.

7. **Field selection without dispatch.**

8. **Resolution failure precedes descriptor override.**

9. **A successful first result avoids fallback.**
