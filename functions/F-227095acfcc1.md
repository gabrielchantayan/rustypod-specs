The established behavior is:

- Pass that value to F-1cb585febd84.
- Read a fallback word from global storage after that dependency returns.

## Behavior

### Derived value

The function computes a derived value from the base and index inputs:

**derived value = base + 66 × index + 87**

Under a 32-bit machine-word interpretation, the calculation uses the low 32 bits of that result. A negative signed base therefore contributes its 32-bit representation to the calculation. No range check, overflow check, alignment check, or address-validity check appears before the value is passed onward.

This is not a guarantee that overflowing signed arithmetic would be portable in a newly written implementation. It is the behavioral interpretation of the recovered word-sized operation.

The auxiliary input is initially placed in local temporary storage. That temporary is not passed by address to either named dependency. On the nonzero path it is overwritten before its contents could be selected for a dependency argument. On the zero path it is not used for an observable result. Thus, in the shown dataflow, the auxiliary input does not affect the externally visible arguments or output.

### First dependency and fallback sampling

After it returns, the function reads a word from global fallback storage. This read occurs on both paths, including the path that subsequently replaces the fallback with the result of F-fe78e25e82ff.

This ordering matters:

- The fallback is not established as a value captured before F-1cb585febd84.
- If F-1cb585febd84 changes that global storage, the subsequent read observes the value present after the call, subject to the execution environment’s memory rules.
- The fallback read remains part of the shown behavior even when the first result is nonzero and the fallback value does not determine the output.

### Zero-result path

If F-1cb585febd84 returns zero:

- F-fe78e25e82ff is not invoked.
- The sampled fallback word becomes the selected result.
- The function stores the selected result plus 12 through the output location.
- The final indirect target is invoked with:

### Nonzero-result path

If F-1cb585febd84 returns a nonzero word, F-fe78e25e82ff is invoked with three arguments:

1. The original output-location pointer.
2. The unsigned maximum of 32 and the first dependency’s result.
3. The first dependency’s result.

The threshold is exact:

- Results from 1 through 32 produce a second argument of 32.
- Results greater than 32 produce a second argument equal to the result.
- A result of exactly 32 produces 32 for both numeric arguments.
- High-bit-set results are treated as large unsigned values, not as negative values, for this comparison.

The result returned by F-fe78e25e82ff becomes the selected result, replacing the previously sampled fallback.

The wrapper then adds 12, stores the adjusted value through the original output location, and passes that same adjusted numeric value as the first argument to the final indirect target.

The wrapper does not directly reread the output word to obtain the final dispatch argument. Consequently, a write performed through the pointer by F-fe78e25e82ff does not itself determine that argument. The dependency’s returned word determines it. Any prior value written by that dependency is overwritten by the wrapper’s direct store if execution reaches that store normally.
