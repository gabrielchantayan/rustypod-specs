1. **Initial arguments.** Under truncation, first input 1, second input 0x11223344, and auxiliary input 2 produce F-D001 arguments 0x100, 0x11223344, 0x4000, and 0x4000.

2. **Masked extraction.** Keeping the low 24 bits of 0xAB123456 and shifting right by 8 yields 0x1234, not 0xAB1234.

3. **Bounded index.** An index-source word of 1 produces index 4 and bounded base 8. This does not establish low-memory validity.

4. **Early byte snapshot.** If absolute 0x05 yields 0x20, later addressing based on that snapshot uses 0x20 even if a calculated write subsequently changes 0x05. The capture precedes the absolute 0x01 store.

5. **Early word snapshot.** With captured byte 0x20, the relevant word is read at 0x74. If it yields 0x10203040, that saved value remains available after 0x74 is overwritten. Writes before its read may affect what is captured.

6. **Global-base overlap.** If the separate global’s storage overlaps the absolute 0x60 word store, repeated publication still uses the base captured before that store, not a reloaded value.

7. **Late absolute snapshot.** If calculated writes alter absolute 0xA9 after its capture, later publication of the full captured word still uses the earlier value.

8. **Fresh 0x67 reads.** If intervening aliasing writes change 0x67 between its three reads, the assignment to 0x21 and the two calculated byte publications may receive different values. Substituting one cached byte for all three is unacceptable.

9. **Intermediate publications.** A trace-capable destination observes 0x20, 0x2F, the loaded unsigned byte, and 0x20 in order. Reporting only the final value loses represented behavior.

10. **Transfer snapshot.** If the retained offset-0x14 word differs from its memory location’s later contents, F-D003 receives the retained word. A fault before transfer establishes no invented failure result or rollback.
