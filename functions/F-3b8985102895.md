## Behavior

4. Invoke that address with no explicit arguments.
5. Return if the invocation returns normally.

There is one visible read of the input-designated integer and one visible read of the callable-address slot. There is one visible indirect invocation. The function contains no branch, retry, loop, fallback selection, or post-call operation other than return.
