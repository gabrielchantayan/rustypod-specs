# F-8af74533f56f

## Purpose

F-8af74533f56f conditionally replaces 32-bit words in place, moving backward through memory in four-byte steps. Two nested iteration decisions determine whether another word is processed. Each accepted inner iteration applies an affine transformation using four global coefficient locations.

The established behavior is the descending traversal, global sampling, arithmetic transformation, and state progression described below. The supplied material does not establish that the control inputs are dimensions, that the memory represents an image or matrix, or that either input directly specifies a word count.

This contract distinguishes:

- **Established static evidence:** behavior directly supported by the supplied representation.
- **Conditional deductions:** consequences that require stated assumptions about arithmetic, memory, or global stability.
- **documented_only unknowns:** properties not established by the available material.

No runtime tests have been performed.

## Interface

### Inputs

The function accepts three scalar inputs:

| Input | Established use |
|---|---|
| Address input | Establishes the starting position for two descending word cursors. |
| Outer control input | Contributes to retained initialization values used by the outer iteration decision. |
| Inner control input | Contributes to a retained value used by the inner iteration decision. |

The representation presents the inputs as integer-valued quantities. The address input is converted into word addresses after subtracting four bytes.

There is no separate allocation length, capacity, stride, ownership flag, or error-output argument. Neither control input is visibly validated as a positive count.

### Return value

Every execution reaching the explicit return produces the 32-bit value zero.

Zero does not indicate that any word was processed. It is also returned when the first outer decision exits immediately or when terminating execution includes outer iterations with no accepted inner body.

There is no visible alternate failure result. Invalid memory access, nontermination, or other abnormal execution may prevent a return.

### Global storage dependencies

Nine distinct global storage locations participate in the visible behavior. The following labels describe their roles, not their values or declarations:

| Label | Role |
|---|---|
| \(A\) | Initialization offset, retained iteration base, and initial outer state |
| \(B\) | Iteration-decision operand and per-outer-entry advancement setup |
| \(C\) | Bitwise operand in the outer decision |
| \(D\) | Value sampled before each outer decision and retained for the associated inner loop |
| \(E\) | Arithmetic operand freshly referenced by inner decisions |

| \(H\) | Multiplier applied to the intermediate word result |

These labels identify storage locations. They do not imply immutability, mutual independence, or freedom from overlap with the processed memory.

### Widths and memory requirements

The supplied representation supports a 32-bit word interpretation: each body reads and writes one four-byte integer, and each cursor moves by four bytes.

Arithmetic descriptions in this contract use reduction modulo \(2^{32}\), with signed decisions interpreting the resulting 32-bit pattern as a two’s-complement value. This is a machine-width interpretation of the representation, not a claim about portable signed-overflow behavior in a source language.

The exact ABI, address-conversion rules, and alignment requirements remain **documented_only**. For each body that executes, its word address must support the required read and write if normal completion is expected.

The first candidate body address is four bytes before the address input. The function does not visibly check whether that address, or any later descending address, remains within an allocation.

## Behavior

### Initialization and retained state

Initialization finishes before the first outer decision. Its significant sampling boundaries are:

1. A reference to \(A\) supplies a retained iteration base.
2. A separate reference to \(A\) adjusts the outer control input.
3. Further references to \(A\), together with the adjusted outer control, produce a retained auxiliary value for the outer decision.
4. Another reference to \(A\) adjusts the inner control input.
5. Both word cursors are positioned four bytes before the address input.
6. A further reference to \(A\) supplies the initial outer iteration state.

The auxiliary calculation includes a signed right shift by 28 of an \(A\) reference and bitwise processing of another \(A\) reference. Its role is an initialization-time contribution to later outer decisions; it is not recomputed at each outer visit.

The retained base, adjusted controls, auxiliary value, and initial outer state are separate captures. They need not reflect one common value of \(A\) if its storage changes between references.

Subsequent changes to \(A\) do not, by themselves, update these retained values. No later direct reference to \(A\) is visible in the iteration bodies or decisions.

### Outer iteration decision

Every outer-condition visit first samples \(D\), including a visit that immediately exits the function’s processing loop.

The outer decision then combines:

- The current outer iteration state.
- The retained adjusted outer control.
- The retained auxiliary initialization value.
- Fresh references to \(B\).
- Fresh references to \(C\).

The calculation uses fixed-width arithmetic and bitwise operations. One contribution contains a right shift of \(B\) by 30. The available declaration information does not establish whether that particular shift is logical or arithmetic.

The final 32-bit decision result is interpreted as signed:

- A negative result ends outer iteration and reaches the explicit zero return.
- A nonnegative result admits the outer iteration.

This decision is not established to be a conventional comparison between an index and the outer control input. No simpler dimension, length, or monotonic-progress interpretation is warranted.

Repeated references to \(B\) and \(C\) belong to the decision expression. Their values must not be assumed equal merely because they name the same locations. Conversely, the supplied representation does not establish the physical number or ordering of loads after compilation.

### Setup after outer entry

An admitted outer iteration captures two values from separate references to \(B\):

- A negated sample retained for the inner decision.
- A sample reduced by one, retained for state advancement.

The two samples are not guaranteed to agree.

The inner iteration state is reset to the initialization-time retained base on every outer entry. Neither word cursor is reset.

The \(D\) sample taken before the admitting outer decision remains the inner loop’s retained \(D\) operand for that entire outer iteration.

### Inner iteration decision

Each inner-condition evaluation depends on:

- The current inner iteration state.
- The retained adjusted inner control.
- The retained negated \(B\) sample for this outer iteration.
- The retained \(D\) sample for this outer iteration.
- Fresh references to \(B\).
- A fresh reference to \(E\).

The decision combines these through 32-bit arithmetic and bitwise operations. Its final result is interpreted as signed:

- A nonnegative result admits one word-processing body.
- A negative result ends the current inner loop.

The representation does not establish that this decision is an ordinary comparison against the inner control input. In particular, there is no justified rule that a nonpositive control input always suppresses processing.

Changes to the backing storage for \(D\) do not replace the retained sample during an already admitted outer iteration. Changes to \(B\) or \(E\) can affect later inner-condition evaluations through their fresh references, while the separately captured setup values remain retained.

### Per-word transformation

Each accepted inner body reads the word at the current source cursor and writes its replacement at the current destination cursor.

For a loaded 32-bit word \(x\), and coefficient values sampled for that body, the replacement is:

\[
y = H(Fx + G) + I \pmod{2^{32}}.
\]

The multiplication and addition stages retain their low 32 bits. This operation is not saturation, checked arithmetic, or an unbounded integer transformation.

The visible ordering is:

- The word is loaded.
- The source cursor moves backward by four bytes.
- The replacement expression is evaluated and stored through the destination cursor.
- The destination cursor moves backward by four bytes.

The representation does not establish a complete order among the coefficient references within the replacement expression. The coefficients are not visibly captured once for the entire function or once per outer iteration.

Both cursors start equal and move by the same amount. Therefore, each accepted body replaces the same addressed word it loaded. Moving the source cursor before the store does not move that body’s destination.

Numbering accepted bodies from zero, their candidate addresses are:

\[
\text{address input} - 4 - 4j.
\]

This expression assumes ordinary address interpretation for the range involved. Address wraparound and integer-to-address behavior remain target-dependent.

The sequence continues across outer-iteration boundaries. No row restart, row stride, skipped-word adjustment, or cursor rewind is visible.

### State advancement and termination

After each accepted body, the inner state advances by a retained increment. That increment comprises one, the captured “\(B\) reduced by one” value, and the initialization-time retained base.

Under 32-bit reduction, the increment equals the retained base plus the particular \(B\) sample used for advancement setup. This simplification does not require that other references to \(B\) agree with that sample.

When the inner loop exits, the outer state advances by the same retained increment. This outer advancement also occurs when the inner loop accepted no bodies.

The increment is fixed within one admitted outer iteration but may differ on a later outer entry because advancement setup samples \(B\) again.

No visible fixed iteration bound guarantees termination. Zero increments, wraparound, changing global operands, or the decision calculations themselves may prevent progress toward an exit. An inner loop that never exits also prevents further outer-condition sampling.

## Side effects

This does not establish that those locations remain unchanged. If the descending word range overlaps a global location, a replacement store may change a value subsequently used by a decision or transformation.

The function does not visibly allocate, release, transfer, or retain ownership of memory. Its visible operation is direct mutation of caller-addressed storage. No ownership-transfer convention is established.

### Observable sequencing

The following ordering is supported:

- Initialization precedes the first outer-condition visit.
- The visit’s \(D\) sample precedes its outer decision.
- Successful outer admission precedes the per-entry \(B\) setup.
- Per-entry setup precedes the first inner decision.
- An accepted inner decision precedes its word load.
- The word load precedes the corresponding replacement store.
- The store precedes inner-state advancement and the next inner decision.
- Inner-loop exit precedes outer-state advancement.

A complete ordering of global references within compound expressions is not established. Volatile declarations, synchronization rules, atomicity, and possible load coalescing remain unknown.

There is no visible rollback. If execution stops after some stores, the supplied material establishes no restoration of earlier words.

## Acceptance examples

These examples are conditional static deductions, not observed executions.

### Immediate outer exit

If the first outer decision is negative:

- Initialization has already occurred.
- The first outer visit has sampled \(D\).
- No word-processing load or replacement store occurs.
- The function returns zero.

This case does not imply that initialization or global references are skipped.

### Outer entry with no accepted body

If an outer decision admits entry but its first inner decision is negative:

- Neither word cursor moves.
- No word is replaced during that outer iteration.
- The outer state advances using that entry’s retained increment.
- Execution returns to the outer-condition visit, which samples \(D\) again.

A zero return follows only if an outer decision eventually exits.

### Exactly one accepted body

If exactly one body executes before eventual outer termination, and the target word is ordinary accessible memory:

- The word four bytes before the address input is loaded and replaced.
- Its replacement follows the stated 32-bit affine transformation.
- The address input itself is not that body’s target.
- The function ultimately returns zero.

The stated body count is a condition of this example, not a conclusion derived from either control input.

### Continuity across outer entries

If two consecutive admitted outer iterations each execute one body:

- The first targets the address input minus four bytes.
- The second targets the address input minus eight bytes.
- Resetting the inner state does not restart memory traversal.

### Arithmetic wraparound

Assume one accepted body reads \(0xffffffff\), with stable coefficient values \(F=2\), \(G=1\), \(H=3\), and \(I=4\).

The first multiplication and addition reduce to \(0xffffffff\). The remaining multiplication and addition reduce to \(0x00000001\). The stored word is therefore \(0x00000001\).

These coefficient values do not independently establish that either iteration decision admits processing.

### Retained and fresh operands

If \(D\) changes after the sample associated with an admitted outer iteration, later inner decisions in that iteration continue using the retained sample. The next outer visit samples its storage again.

If a coefficient changes between body executions, the later body references that coefficient’s storage anew; there is no established function-entry coefficient snapshot.

If the two per-entry \(B\) references observe different values, the inner decision’s retained setup operand and the advancement increment reflect their respective samples. They must not be collapsed into one assumed common value.
