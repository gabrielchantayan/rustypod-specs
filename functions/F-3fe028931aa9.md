# F-3fe028931aa9

## Purpose

F-3fe028931aa9 selects one of two paths using bit `0x00080000` in a root object’s flags.

- **Bit clear:** invoke a preparation dependency, then conditionally update an attached record, submit three produced values, replace a packed position field, and issue an optional notification.
- **Bit set:** increment a state field, pass the existing handle to a dependency, obtain and store a replacement value, and make a separate status field nonzero if necessary.

The branch conditions, accesses, arithmetic, and dependency-call order below are established by the supplied static representation. Labels such as “record,” “position,” “handle,” and “notification” describe apparent roles; they do not establish application-level types or ownership.

The function has no explicit return value. Its outputs are memory changes and dependency interactions.

## Behavior

### Initial branch selection

The function reads the root pointer from the context and tests bit `0x00080000` of the root’s flags at offset `0x0C`.

Only that bit controls branch selection. Other flag bits are irrelevant to this test.

The branch is selected once. Later changes to the flags do not cause the invocation to switch paths.

### Unflagged path: preparation and eligibility

When the bit is clear, the function first invokes **F-3e53ab590d24** with the original context pointer, original position-input pointer, and opaque input. No result is used.

After preparation returns, it reads the attached-record pointer from context offset `0x180`.

Record-update processing proceeds only when:

1. The loaded record pointer is non-null.
2. The state word at context offset `0x40` is zero.

The check is short-circuited: the state word is not read for this gate if the record pointer is null.

If either condition fails, the function returns. Preparation has already occurred, so its effects remain observable. No subsequent direct record writes, submissions, packed-position write, or notification occur through this path.

The gate observes post-preparation values, not entry snapshots.

### Root capture and index lookup

It invokes **F-49f750c2c596** with:

- The captured root.

The returned signed 32-bit value is retained as the table index.

The lookup call completes before either direct record initialization write. There is no visible validation of the returned index, including no rejection of negative values or sentinel values.

### Packed-position update

After the third submission returns, the function replaces the 32-bit packed-position word at context offset `0x16C`.

Let:

- \(P\) be the old packed word’s bit pattern when read for this update.
- \(A\) be the first range word, interpreted modulo \(2^{32}\).
- \(B\) be the second range word, explicitly interpreted as unsigned 32-bit.
- \(C\) be the first position word, interpreted modulo \(2^{32}\).

Define:

\[
H=\left\lfloor B/2\right\rfloor
\]

\[
D=(A+H-C)\bmod 2^{32}
\]

The stored bit pattern is:

\[
(P\mathbin{\&}1)\mathbin{|}\bigl((2D)\bmod 2^{32}\bigr)
\]

The explicit unsigned interpretation of the second range word makes its right shift logical. Through the arithmetic conversions, the subsequent addition, subtraction, and multiplication are also unsigned 32-bit operations. **Their results are defined modulo \(2^{32}\), including overflow and underflow.** This calculation has no uncertain signed-overflow intermediate.

Consequences:

- An odd second range word is halved with rounding down in the unsigned domain.
- A second range word with its high bit set is not treated as negative during halving.
- Only bit zero of the old packed field is preserved.
- All old bits above bit zero are discarded.
- The doubled component has bit zero clear, including after modular reduction.
- Negative signed representations of the first range or position words participate through their modulo-\(2^{32}\) values.

The arithmetic inputs and old packed word are read after the three submissions, not at entry. The supplied representation does not establish an order among the independent reads within this expression. The packed write follows those reads.
