**Output:** A pointer-valued result:

The dependency results are used in a 32-bit address representation: the first becomes the returned pointer, and the second is stored in a 32-bit field before being used as an address. 1. Zero the second region’s word at byte offset 0.
2. Zero its word at byte offset 4.
3. Zero its word at byte offset 8.
4. Zero its word at byte offset 12.
5. Write the 32-bit value four to byte offset 12 of the first region.
6. Write zero to byte offset 16 of the first region.
7. Write zero to byte offset 0 of the first region.

The supplied representation therefore shows four uses of that stored address, rather than an independent cached base governing all four writes. Under ordinary disjoint-memory conditions, each use obtains the same value.
