### Aliasing and final state

The earlier base write can overlap any of the final destinations, the gap at offsets 52–53, or locations outside the final-write span. No visible check prevents such relationships.

Thus, a final-state claim about bytes written only by the base write also requires suitable behavior from that dependency and absence of interfering external writes.

The shared source is not established to be disjoint from any destination. There is no dedicated write to that source, but aliasing can cause an explicit destination write to modify its storage.
