# F-41c2c5f80812

## Purpose

F-41c2c5f80812 performs an ordered sequence of three dependency calls and four memory stores. It obtains an initial value, passes that value and the first caller input to a second dependency, writes a global four-byte value at the returned address, and invokes a third dependency with an interior address. It then writes three fields relative to the third dependency’s returned address.

**Established static behavior:** the argument relationships, call order, global read, address calculations, store widths, and store order described below.

**Inferred intent:** the sequence resembles allocation, object construction, header installation, and initialization of an embedded record. Those interpretations do not establish allocation semantics, object types, ownership, or relationships between returned addresses.

There is no explicit return value. Observable results consist of dependency effects and memory accesses.
