# F-9c08f1dbe441

The established normal-completion effect is a 16-byte overwrite. The routine does not choose an initialization mode, check whether the destination already contains the requested values, or return a status.

### Dependence on prior destination contents

When the source is non-overlapping and its sampled value is held fixed, prior destination contents do not affect the final four-word result. All four destination words are overwritten unconditionally.

More generally, holding the sampled source value fixed is sufficient for that same final-result independence, including where overlap is otherwise valid.

Without that qualification, independence from prior destination contents is false. If the source aliases a destination word, that word’s previous value can supply the first destination word. For example, if the source aliases the second word, the previous second-word value becomes the final first-word value before the second word is cleared.

No branch preserves a word because it already has the desired value. Repeated invocations repeat the writes. If the sampled source value is unchanged, completed invocations produce the same final word values, but the accesses still occur.

Overlap can also make successive invocations differ without an external source update: a destination write in the first invocation may change the storage read as the source by the next invocation.

### Aliasing

The source is sampled before any of the four destination writes. Consequently, a later destination write cannot retroactively change the value already used for the first word.

If the source exactly aliases the second destination word, the first word receives the second word’s value at the time of sampling. The second word is then overwritten with zero.

If the source exactly aliases the third or fourth destination word, its sampled value similarly supplies the first word before the corresponding all-ones write replaces the source storage.

These statements are conditional on the overlap being valid in the execution environment. They do not establish general legality for overlapping typed storage, partially overlapping accesses, unusual memory mappings, or concurrent accesses.
