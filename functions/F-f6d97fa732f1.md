# F-f6d97fa732f1

## Purpose

F-f6d97fa732f1 describes a sequence of indirect calls interleaved with four-byte memory stores and byte-indexed one-byte stores. It consumes inherited execution state, obtains additional values from callees, and forwards selected values to later callees.

**Established static evidence:** the supplied representation contains a single visible straight-line sequence, with 52 call sites, five four-byte stores, four one-byte stores, and four explicit one-byte reads. It ends at an instruction-decoding failure rather than an established ordinary return.

**Inferred intent:** several operations resemble index scaling, packed-field extraction, and publication of values through helper calls. No application-level purpose, object model, or device protocol is established.

This contract specifies the visible prefix only. It does not assert that the represented sequence is a valid, complete execution path.

## Side effects

The visible prefix performs:

- Five four-byte stores to addresses formed from returned integer values and the constant `0x14`.
- Three byte reads from W(K + 1), separated by calls.
- One byte read from W(8 × V + 1).
- Four one-byte stores to addresses obtained by adding `0x11` to unsigned byte values.

Each byte-indexed destination lies between `0x11` and `0x110`, inclusive. This is a direct low-address destination, not an offset relative to an established object base.

## Acceptance examples

These are conditional acceptance criteria derived from the visible operations, not executed tests. Each assumes valid accesses, normally returning callees, and no unspecified interference except where stated.

1. **First store and argument use the same scale.**  
   If A is 3 and S is `0x11223344`, the first four-byte store writes that value at address `0x20`. F-000000000002 subsequently receives 12. Individual stored byte order remains unspecified.

2. **Destination stride differs from stored scale.**  
   If B is 2, the second four-byte store writes 8 at address `0x34`, and F-000000000007 receives 8. If C later equals 5, the next four-byte store writes that retained 8 at address `0x28`; F-000000000012 receives 20.

3. **Two scale arguments retain their order.**  
   If D is 3, the corresponding store writes 12 at address `0x44`. F-000000000017 receives 12 first and 48 second.

4. **Unsigned shifts do not sign-extend.**  
   If R is `0x80000000`, the displayed second argument to F-000000000019 is `0x02000000`. The later four-byte store based on E writes `0x10000000`.

5. **Byte writes truncate, but forwarded words need not.**  
   If U is `0x12345678` and the first index read yields `0x20`, the destination is `0x31`, and the stored byte is `0xE0`. F-000000000029 receives `0x48D159E0`. For the subsequent high-field store using the same U, the stored byte is `0x23`.

6. **Repeated reads can select different destinations.**  
   If successive reads from K + 1 yield `0x20`, `0x21`, and `0x22`, the corresponding stores target `0x31`, `0x32`, and `0x33`. F-000000000041 receives `0x22`.

7. **The final read uses V.**  
   If V is 5, the final explicit byte read is at address `0x29`. If it yields `0xFF`, the destination is `0x110`, and the stored high-field byte is zero.

8. **Effects stop at a nonreturning dependency.**  
   If F-000000000024 does not return, the fifth four-byte store has already occurred. The visible sequence establishes none of the later calls or byte accesses.
