6. **Adding state or ownership guarantees.**  
   A statement that memory is untouched, globals are preserved, or no resources are released is not acceptable without additional evidence. A valid extension would need to identify the relevant state and establish the guarantee across the claimed execution scope.

7. **Claiming implementation conformance.**
