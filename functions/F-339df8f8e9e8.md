If the destination starts one 32-bit unit after the source, the first destination write replaces the source unit that the second transfer will read. Repetition of this effect can propagate the original first source value through the destination.

If the destination starts one 32-bit unit before the source, earlier destination writes do not overwrite the later source units in that particular layout. The destination can therefore receive the four original source values despite the overlap.
