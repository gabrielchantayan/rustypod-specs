# F-10bd82a7f085

## Purpose

This routine repeatedly acquires values through indirect calls, derives addresses and payloads from those values, and performs byte-sized and 32-bit memory updates. The visible control flow repeats unconditionally; it contains no normal return or termination test.

No application-level purpose is established. The accessed locations cannot be identified as ordinary objects, hardware registers, allocator metadata, or a serialized representation from the supplied evidence.

### Widths and notation

A **word** is a 32-bit bit pattern. A **byte** is eight bits; selector-byte reads are zero-extended.

For compactness:

- **Sₙ(x)** means the low 32 bits of word *x* shifted left by *n*.
- **B(x)** means the low eight bits.
- **H(x)** means the unsigned value obtained by masking *x* with `0x3fffffff` and shifting right by 20. Its range is 0–1023.
- A **selected byte write using address A** means: read one byte at A, zero-extend it, then write one byte at that numeric value plus 17.

A selected destination therefore ranges from numeric address 17 through 272. The selector is not a word-sized pointer.

Arithmetic descriptions use 32-bit bit-vector interpretation, including low-32-bit products and address additions. Some displayed expressions involve signed-looking operands; the representation alone does not establish defined source-language overflow behavior. Machine address interpretation remains unresolved.

## Side effects

- Each selector-mediated write includes a byte read followed by a byte write.
- Repeated selector accesses are fresh reads except for the explicitly saved selector.

- The saved-selector word destination survives the intervening F-U21 calls in the visible dataflow.

## Acceptance examples

These are conditional static obligations, not execution reports.

1. **Field narrowing.** If the fourth argument is `0x3ff00000`, the initial field is `0x3ff`, and the selected byte receives `0xff`.

2. **Byte-valued destination.** If a selector read returns 7, its selected byte store targets numeric address 24, not a pointer fetched from a word.

3. **Fresh selector reads.** If a dependency changes a selector from 7 to 9 between fresh reads, the later selected destination is 26 rather than 24.

4. **Saved destination.** If saved selector is 7 and F-U21 changes selector memory to 9, the subsequent word store still starts at address 27.

5. **Required intervening calls.** In F-U02 and F-U08, a side effect of call 6 precedes call 7 and the following selector access. In F-U18, effects of calls 4–6 precede call 7 and the zero-word store. An unused result does not permit skipping these calls.

6. **Forced-zero argument.** For every second seed, S₂₈(second payload) passed inside F-U06 is zero under 32-bit bit-vector arithmetic.

7. **Parity-dependent payload.** The word stored immediately before the lookup is zero for an even retained index and `0x80000000` for an odd retained index.

8. **Captured shared value.** If the shared read yields `0x00400000`, its later publication byte is 1 even if F-U22 subsequently changes the shared location.

9. **Loop-carried target control.** If execution completes F-U26 and continues normally, the next F-U01 target calculation uses `0x0882ce67 + 0xffe`, not the original entry control word.

10. **No normal completion.** If every call returns and every access succeeds, finishing stage 10 begins another iteration rather than returning a result.
