# F-732833a6cc10

## Purpose

F-732833a6cc10 forwards a 32-bit input into a sequence of dependency calls and mutates memory using addresses derived from ambient execution values, dependency results, and memory contents. Visible effects include byte, halfword, and word writes, repeated memory references, and propagation of retained values across calls.

No application-level purpose is established. Descriptions such as initialization, serialization, allocation, decoding, or cleanup would exceed the evidence.

This contract distinguishes:

- **Established static evidence:** operations, widths, value relationships, and ordering expressed in the supplied representation.
- **Inferred intent:** possible interpretations, not requirements.
- **documented_only unknowns:** behavior not established by the supplied material.

The representation has incomplete control-flow recovery and ends at an invalid-instruction boundary. Requirements apply conditionally to each reached portion; they do not establish that the complete sequence is executable.

The first visible memory mutation reads a selector byte one byte beyond that ambient value interpreted as an address. It writes the low byte of the other ambient value shifted right by twenty-two bits to selector plus `0x11`.

The destination is selected by the loaded byte. It is not offset `0x11` within the original ambient region.

After further calls, F-23325cd5e50c receives a 32-bit result. That value is retained for later scaling, subtraction, and bit extraction. A subsequent dependency-produced address supplies another selector whose selected destination is cleared.

The recurring mutation is a byte selector read followed by a byte write at selector plus `0x11`. Selector-source addresses include:

- A base plus one.
- Four, eight, sixteen, or sixty-four times a value, plus one.
- A logically shifted value, plus one.
- Twice a value masked to twenty-two bits, plus one.

Stored bytes include zero, truncated scaled values, and extracted bit fields. Repeated selector reads separated by calls are fresh references; an earlier selector cannot be substituted merely because the source address is unchanged.
