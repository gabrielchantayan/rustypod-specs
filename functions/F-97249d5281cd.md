# F-97249d5281cd

## Purpose

An eligible record receives three zero-byte writes, each preceded by an increment of an eight-bit position field. A subsequent condition selects either a fourth such operation or an allocation branch. The allocation branch requests eight bytes, initializes two four-byte words, and stores the returned pointer in the record. Submission and a subsequent dependency call occur only when the allocation result is non-null.

Every path that completes its preceding operations reaches F-feee9156a257 with the original selected-object pointer, including a null selection. The supplied annotation identifies that dependency as non-returning; its actual termination mechanism is unknown.

“Record,” “identifier,” “position,” and “submission” describe observed roles. They do not establish an application protocol, semantic object type, or ownership convention.
