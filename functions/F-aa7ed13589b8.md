# F-aa7ed13589b8

## Purpose

F-aa7ed13589b8 initializes two temporary 32-bit words, invokes F-53994e63b9d8, and conditionally writes two component differences to caller-provided destinations. It returns true exactly when the dependency returns zero.

The component differences use distinct selection rules:

- The first subtracts **unsigned two-byte components at storage offset 2** within the temporary words.
- The second subtracts **signed numeric low-16-bit components** of the temporary words.

The first selection corresponds to the numeric high half on a little-endian representation, but not on a big-endian representation. Target byte order is not established by the supplied evidence. The second selection is established by signed 16-bit conversion and does not depend on that storage-offset interpretation.

The first temporary is initialized from the numeric representation of an output pointer, not from the value stored at that pointer. A packed-coordinate or displacement calculation is a possible interpretation, but no application-level meaning is established.

### Widths and component layout

For the first difference, each selected component consists of the two bytes beginning at offset 2 from the start of its temporary word. Each component is interpreted as an unsigned 16-bit value, in the range 0 through 65,535.

### Dependency returns zero

A zero dependency result enables two ordered output stores.

**First: unsigned storage-component difference.**

The function selects the unsigned two-byte component at storage offset 2 from the second temporary and subtracts the corresponding component of the first temporary. The operands are represented as 32-bit integers for subtraction.

The result is stored through the offset-two difference destination.

Both operands are between 0 and 65,535, so the result is between −65,535 and 65,535 inclusive. It fits in a signed 32-bit integer without overflow.

This operation is not unconditionally a numeric high-half subtraction. That description applies only under little-endian storage.

**Second: signed numeric low-half difference.**

After the first output store, the function takes the signed low-16-bit value of the second temporary and subtracts the signed low-16-bit value of the first temporary. Each operand is sign-extended to 32 bits before subtraction.

The result is stored through the low-half difference destination.

Both operands are between −32,768 and 32,767, so this result also lies between −65,535 and 65,535 inclusive and fits in a signed 32-bit integer.

After these stores, the function returns true.

The two calculations are component-wise operations, not a complete 32-bit subtraction. No carry or borrow connects the second difference to the first.
