# F-7f5a92d055ba

## Purpose

The destination layout contains four 4-byte locations and two 1-byte locations. The highest addressed byte written is at offset 20, so the caller must provide a writable region covering at least 21 bytes from the destination address. This is a minimum accessed extent, not evidence that the enclosing object is exactly 21 bytes long.
