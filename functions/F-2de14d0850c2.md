### Final address and write

The store address depends on the top 12 bits of the wide result returned by F-U54. Interpret those bits as an unsigned integer \(t\), with \(0 \leq t \leq 4095\). The numeric address is:

\[
t+\left\lfloor t/4\right\rfloor

The represented calculation first logically shifts the wide result right by 41 bits, producing at most 23 bits. This intermediate is nonnegative when interpreted as a signed 32-bit value. Its subsequent signed right shift by 11 bits therefore selects exactly the original wide result’s top 12 bits.

The address addition cannot overflow a 32-bit word: the resulting range is 0 through 5118 inclusive. The target address need not be even.

The attempted store writes the 16-bit value **0x00CD**. No explicit null check, alignment correction, bounds check, permission check, or caller-buffer association precedes it.

2. **Signed recovery changes a word.**

3. **Third-parameter shifts.**  
   If the third parameter has bit pattern 1, F-U14’s second argument is 0x00400000 and F-U21’s first argument is 0x00080000. If its bit pattern is 0x00002000, both arguments are zero after word-width truncation.
