### Widths and address conventions

The following descriptive conventions apply:

- An **ordinary word slot** selected by an index is address `4 × index + 0x14`.

These are conditional static examples, not executed tests.

1. **Byte truncation:** If the first principal word is `0x41`, its four-times value is `0x104`; the corresponding byte store writes `0x04`.

2. **Unsigned selector:** A selector of `0xff` chooses destination `0x110`, not `0x10`.

3. **Separate global observations:** If the first global observation is `0x400` and the second is `2`, the masked call argument is `1`, while the second-observation scale is `8`. Its selector reads use address `9`. Deriving both dependencies from either observation would not preserve this case.

7. **Unsigned product wrap:** If the low result word is `0x10`, its special store targets `0x14` and writes `0x40000000`, provided that address is writable.

8. **Partial execution:** If a dependency fails after the initial word store, that store has already occurred. No represented rollback restores it.
