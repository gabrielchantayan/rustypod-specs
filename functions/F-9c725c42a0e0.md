# F-9c725c42a0e0

## Purpose

F-9c725c42a0e0 repeatedly performs indirect calls, reads bytes and words from computed addresses, and writes bytes and words to computed addresses. The visible control flow is an unconditional loop with no normal return.

No application-level purpose is established. The repeated use of offsets 1, 17, and 20, together with scaled values obtained from dependencies, may indicate structured state manipulation. That interpretation is not sufficient to establish object types, allocation behavior, device semantics, or a higher-level operation.

This contract describes the supplied static representation. It does not establish that every represented operation is reachable or executable on a particular system.

## Interface

### Explicit inputs and result

The represented interface has four 32-bit argument slots:

| Input | Established use |
|---|---|
| First argument | Forwarded to the first dependency call in each iteration; replaced near the iteration boundary by a dependency result. |
| Second argument | Forwarded with the first argument; replaced partway through the iteration by a dependency result, then shifted left by 28 bits before the next iteration. |
| Third argument | No visible use. |
| Fourth argument | Initially contributes to a word-store address and a dependency argument; replaced near the iteration boundary. |

The representation declares no return value. More importantly, it contains no normal exit. A caller cannot rely on successful completion or a returned status.

These are hidden execution-state requirements, not additional documented public parameters. Their initial values and validity requirements are unknown.

- `B(x)` means the low 8 bits.

These conventions express the apparent machine-width dataflow. The supplied representation alone does not establish a portable language-level interpretation of signed overflow or signed left shifts.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Selector width.** If the opening selector read yields 255, the first byte destination is address 272. It is not the entry base plus 272. The entry base identifies the selector’s location only.

2. **Shift truncation.** If the entry word is 1, the initial payload is `0x00001000`. F-A13’s first explicit argument is zero under 32-bit arithmetic, not a wider shifted value.

3. **Selector truncation.** If the initial payload is `0x3ff00000`, its selector is 1023, but the stored byte is 255.

4. **Repeated reads.** If a dependency changes the byte at entry base plus 1 between two selector accesses, subsequent byte stores use the newly read byte. Reusing the original selector would violate the trace.

5. **Saved selector.** If phase 5 saves selector 7 and a later dependency changes its source byte to 9, the phase-5 word store still targets address 27.

6. **High-bit address reduction.** If the second propagation index is 5, the clearing base is `0x40000000` under 32-bit arithmetic. The two direct clears target offsets 17 and 1 from that base, in that order.

7. **Continuation.** If all dependencies return and all accesses complete, execution begins another iteration. A normal return after one iteration would not match the represented behavior.

8. **Interrupted progress.** If F-D02 never returns, F-D03 and every subsequent operation are absent, but the preceding direct clears have already occurred.
