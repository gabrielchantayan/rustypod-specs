# F-60c2da3b202c

## Purpose

F-60c2da3b202c performs two indirect calls followed by an ordered sequence of memory accesses. The supplied representation ends at a bad-instruction marker; it establishes no normal return path.

**Established static evidence:** the representation contains overlapping stores, low-address accesses, address-derived destinations, shared-storage accesses, repeated references to an incoming stack slot, and truncated control flow.

**Inferred intent:** no application-level purpose is sufficiently supported. Storage labels suggestive of reset, interrupt, or exception state do not establish that the function implements those architectural operations.

This contract describes the supplied static representation conditionally. It does not establish that every represented operation is reachable or executable.

## Behavior

The following sections preserve represented operation order. An earlier fault or nonreturning call can prevent all subsequent operations. Evaluation order within expressions is not imposed where the representation leaves it unresolved.

### 1. Initial store and first indirect call

The routine derives Q from A and writes D as 32 bits at B + 8.

It then calls the address formed from L + 12, passing one represented argument: D interpreted through a signed 32-bit value and shifted right by 16. For the supplied positive D, that argument is 0x0897.

The target is formed directly from L + 12. No intervening load of a function pointer from that address appears. F-dd66fecc047e supplies address data; it is not established as the called function.

If the call returns, the routine writes the first argument shifted left by four as 32 bits through O.

Negative signed left operands and signed overflow are not resolved by this representation. A low-32-bit machine result is a possible interpretation, not an unconditional contract requirement.

### 2. Second indirect call

The routine calls the fixed address 0x0897ea31. No explicit arguments are represented.

The result is represented as 64 bits. R receives its low 32 bits and H its high 32 bits. R subsequently supplies data; H supplies address operands.

This may describe recovered register results rather than a genuine language-level 64-bit return value. Neither call is assumed to preserve globals or the incoming stack slot.

### 3. Repeated A-relative stores and signed sample

Let the **A fragment** mean A’s low 16 bits. The accesses occur in this order:

1. Write the A fragment as 16 bits at A + 0x12.
2. Write Q as 32 bits at address Q.
3. Write R as 32 bits at A + 0x10.
4. Write the A fragment as 16 bits at A + 0x12.
5. Write Q as 32 bits at address Q.
6. Write the signed 32-bit interpretation of R, shifted right by 16, as 32 bits at A + 4.
7. Write the A fragment as 16 bits at A + 0x12.
8. Write Q as 32 bits at address Q.
9. Read a signed 16-bit sample at B + O.
10. Write the A fragment as 16 bits at A + 0x12.
11. Write Q as 32 bits at address Q.
12. Sign-extend the sample to 32 bits, shift it right by 16, and write the result as 32 bits at A + 8.

Under arithmetic right-shift semantics, the last value is zero for a nonnegative sample and 0xffffffff for a negative sample.

The 16-bit writes at A + 0x12 overlap the word at A + 0x10. Which numeric half of R they replace depends on byte order. Repeated writes remain distinct observable accesses.

These stores may also overlap S. Consequently, even before the first explicit stack-derived destination is used, the slot may no longer contain its entry value.

### 4. Low-address and stack-derived accesses

The next operations are:

1. Clear prefetch-abort-associated storage; its width is unresolved.
2. Write B as 32 bits at K + 4.
3. Write O as a 32-bit pointer value at H + 4.
4. Write O as a 32-bit pointer value at four times K plus 0x10.
5. Write O as a 32-bit pointer value at H + 8.

K is either 0x58 or 0x5c. The B destination is therefore 0x5c or 0x60; the low-address O destination is 0x170 or 0x180.

The stack-derived sequence then proceeds as follows. Each reference to “the slot pointer” below refers to the stack variable used by that particular expression, not an established snapshot shared with other rows.

Rows containing several slot references do not establish whether those references share one sample, are separately loaded, or have a particular evaluation order. This uncertainty must not be resolved by silently substituting the entry value.

Under the **stable-slot assumption only**, every slot reference above may be described using one P. The resulting destinations include P, P + 20, P + (H bitwise-AND P), twice P, and four times P plus 0x18.

Without that assumption, the first 16-bit store and the next 32-bit store need not target the same address. A store that overlaps S may change the pointer used by subsequent operations. Even the several pointer references within one expression have no established common snapshot.

The destination in row 13 uses S itself, not the pointer stored there. Under arithmetic right shift, its value is zero or 0xffffffff according to the sign bit of the pointer value supplied at that point.

### 5. Shared publication and subsequent updates

The routine reads J once from the 32-bit storage associated with 0x0897ea50. Later references to J use this retained sample.

It next performs these operations:

1. Write four times a pointer value obtained from the stack variable into the publication word.
2. Read the publication word for the destination and separately for the 32-bit value of a self-addressed store, then perform that store.
3. Read the publication word again and write O as a 32-bit pointer value at that newly read address plus four.
4. Write four times J as 32 bits at address four times J.
5. Write E shifted left by two as 32 bits at J plus the signed result of shifting J left by six and then right by 17.
6. Write J’s upper 16 bits into a 16-bit reset-associated quantity.
7. Clear interrupt-associated storage; its width is unresolved.
8. Write a 32-bit zero at eight times E.
9. Write a 32-bit zero four bytes later.
10. Write one byte at eight times E plus 16, using the low-byte address contribution of eight times E increased by eight and narrowed to one byte.

The publication value is **not unconditionally four times the entry stack pointer**. Its pointer operand is another reference to the stack variable, after the preceding potentially aliasing accesses. Under a stable-slot assumption it becomes four times P; otherwise that substitution is unsupported. If the publication word overlaps S, the publication write itself may alter the slot.

The two publication reads in step 2 remain distinct, with unresolved relative evaluation order. Neither is replaced by the preceding assigned value. Step 3 contains another fresh publication read.

Thus the self-addressed store need not write the initially published value to the initially published address. Its destination or value can differ if storage changes between accesses. Its own write can also change the publication word.

For the represented E, eight times E is 0x44bf5230. Under low-eight-bit narrowing, the final byte value is 0x38. Signed-byte conversion details remain unresolved.

## Side effects

Writes target caller-provided, input-derived, stack-derived, low-address, shared, and code-address-derived locations. No disjointness among these regions is established.

In particular:

- Calls and earlier writes may change S before any stack-derived operation.
- A stack-derived store may change S and thereby redirect later accesses.
- The value published later may differ from any earlier pointer sample.
- Publication writes may affect their own subsequent read sources.
- Intervening writes may change the reset quantity before its final read.
- Device-backed storage or external interference may distinguish repeated accesses.

Stable-slot and stable-publication assumptions are separate. Establishing one does not establish the other.

No rollback, bounds check, error return, or recovery branch appears. A fault may leave a visible prefix of effects. Atomicity is not established.

The terminal marker does not determine whether actual execution traps, transfers to a handler, resets, stops, or continues through unrecovered control flow.

## Acceptance examples

These are conditional static criteria, not executed tests.

### Unsigned shift

If A is 0xffffffff, Q is 0x07ffffff. A sign-propagating result of 0xffffffff does not match the represented unsigned shift. Accessibility of resulting addresses is a separate condition.

### Signed sample

Under arithmetic right shift, a sample of 0x7fff at B + O yields zero at A + 8; a sample of 0x8000 yields 0xffffffff. The criterion uses the sample actually observed after preceding writes.

### Low-address selection

If Q’s 0x04 bit is clear, the B store targets 0x5c and the corresponding O store targets 0x170. If set, those destinations are 0x60 and 0x180.

### Overlapping A-relative storage

Assuming ordinary memory, completion, and no other relevant aliases or interference, the final two bytes at A + 0x12 represent A’s low 16 bits in target byte order. The word at A + 0x10 need not still equal R.

### Stack-slot redirection

Assume little-endian ordinary memory, a 32-bit pointer slot at S = 0x00102000, and that the slot still contains 0x00102000 immediately before the first stack-derived store. Let K be 0x58.

The first 16-bit store targets S and changes the stored pointer representation to 0x00100058.

**If the next expression reloads the slot**, its 32-bit shifted-B store targets 0x00100058, not 0x00102000. A contract requiring both stores to use the original pointer would reject this permitted aliasing outcome incorrectly.

The exact reload behavior remains unresolved; this example does not claim it is the recovered machine behavior.

### Stable-slot publication

Assume every relevant slot reference supplies P, four times P is 0x1000 without arithmetic ambiguity, and publication storage is stable and unaffected by the self-addressed store.

The publication assignment writes 0x1000. Both self-addressed-store reads observe 0x1000, producing a write of 0x1000 at 0x1000. The next publication read also observes 0x1000, so O is written at 0x1004.

Without the stable-slot assumption, the initial publication value cannot be derived from an earlier P. Without the publication-stability assumption, subsequent destinations cannot be derived from that initial publication value.

### Publication changes

Suppose the self-addressed store’s destination read observes 0x0897ea80 and its value read observes 0x2000. Their relative order is unspecified.

The resulting write changes the publication word to 0x2000. With no further change, the next publication read makes the O-store destination 0x2004.

### Nonreturning calls

If the first call does not return, the initial D store may be visible, but the explicit O store has not occurred.

If the second call does not return, the explicit O store has occurred, but the repeated A-relative sequence has not begun. Either callee may independently have modified S or other memory.
