# F-0b9a80abb143

## Purpose

The established behavior is an ordered sequence of indirect calls and direct memory accesses, followed by unconditional repetition. Direct accesses comprise 32-bit writes, unsigned 8-bit reads, and 8-bit writes.

No application-level purpose is established. The supplied representation does not justify describing the operation as allocation, decoding, serialization, initialization, or collection processing.

There is no visible normal return. If every dependency returns and every access succeeds, execution remains in the final loop. Instruction-recovery warnings limit what this static representation establishes about the underlying executable.

This contract uses:

## Acceptance examples

These are conditional consequences of the static representation and arithmetic model, not runtime observations.

1. **First write precedes dispatch.** With initial index 3, the payload is written at address 32 before **F-d001**. If that write faults, the visible continuation does not reach the call.

2. **Packed-input extraction.** With packed input `0x12345678`, \(U=\texttt{0x00123456}\), **F-d039**’s third argument is `0x002468ac`, and \(P=\texttt{0x00002468}\). The direct byte destination is `0x00002484`.

3. **Retained word address.** If **F-d038** returns 3, the first write at address 68 stores 12. After **F-d043**, another write at address 68 stores 48, independently of **F-d043**’s result. Intervening dependency effects remain possible.

4. **Fresh selectors.** A selector value of 5 selects destination 22. If a later read of the same location returns 9, that write selects destination 26 instead.

5. **Byte truncation.** If **F-d048** returns `0x12345678`, its first derived byte is `0xe0`; its second is `0x23`.

6. **Immediate aliasing.** If \(W(P+28)=W(H+1)\), and no external mutation intervenes, the direct write supplies the next selector value. The following zero write targets \(B(L)+17\).

7. **Access totals.** Completion of the pre-loop path produces six direct byte writes and five selector reads. One completed iteration raises these totals to seven and six.

8. **Arguments and dispatch change together.** The first **F-d075** uses target-expression value `0x08833787` and second argument zero. If the first **F-d084** returns 1, the next **F-d075** uses target-expression value `0x088337c5` with arguments 4 and `0x00040000`.

9. **Dispatch is not return-value-selected.** If **F-d084** returns zero, the following **F-d075** arguments are both zero, but its target expression is still `0x088337c5`, not the first-entry value.

10. **No normal completion.** If all accesses succeed and all dependencies return, execution continues through **F-d075** repeatedly without visible return or final cleanup.
