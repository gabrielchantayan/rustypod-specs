### Explicit memory read and write

3. It adds **17**, equivalent to **0x11**, to obtain an absolute destination address.
4. It stores the incoming byte value at that destination.

The byte read is **not** treated as a pointer to another object. There is no visible second pointer dereference between reading the byte and selecting the write address. The write is not relative to the incoming address base.
