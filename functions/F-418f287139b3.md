# F-418f287139b3

## Purpose

The supplied representation establishes the state transitions, arithmetic operations, retained-state updates, and external-read dependencies. It does not establish a complete mathematical mapping from argument to result: eleven external scalar values are unspecified. Those values influence entry, routing, arithmetic, and termination.

**Inferred intent:** The thresholds and Boolean-scaled result suggest classification of a transformed input. The actual classification, applicable input domain, and intended external configuration remain unknown.

## Behavior

### Retained state and dispatch

An invocation initializes these retained quantities to zero:

- result;
- first and second working quantities;
- retained distance;
- intermediate word;
- primary and secondary flags.

It then reads Base to establish the initial state.

Before each dispatch, both flag carriers undergo character-sized conversion. The current state is added to a new represented read of Dispatch bias. The sum selects a tag.

Tags 0 through 12 have explicit behavior. Any other value follows the same behavior as tag 6. There is no invalid-tag error path.

Dispatch is iterative. No independent iteration bound, timeout, cycle detection, or termination recovery is visible. Execution can return without loading the argument, load it repeatedly, or continue indefinitely.

### Flag and result invariants

Under the stated 32-bit arithmetic assumptions, both flags remain in \(\{0,1\}\):

- extracting bit 31 of an unsigned word produces 0 or 1;
- negating an arithmetic signed right shift by 31 produces 0 or 1;
- the remaining flag updates copy an existing flag.

Consequently, character-sized conversions preserve the flags on this model.

Tag 2 is the only result-update state. It converts the primary flag through a signed-short representation and multiplies it by 147. The retained result therefore becomes 0 or 147 under the stated assumptions.

A later flag change does not refresh the result. If tag 2 executes repeatedly, its last execution determines the result subsequently returned.

### Argument loading: tag 12

Tag 12 reads Input multiplier and multiplies it by the argument. The product replaces the intermediate word. It then reads Post-input destination and uses that value as the next state.

The represented multiplication has signed operands. Storing its result in an unsigned word does not make signed overflow defined. When the signed product is representable, conversion to unsigned storage supplies its word interpretation.

This state does not reset either flag, either working quantity, the retained distance, or the result.

### Transformation and initial predicate: tag 11

Tag 11 consumes the current intermediate word, which need not still contain the argument product.

It first forms the first working quantity from a read of Transform coefficient multiplied by that word.

It then forms the second working quantity using the intermediate word and a multiplier obtained by XORing:

- a read of Transform coefficient; and
- another read of Transform coefficient, converted to signed integer and shifted right by 30.

The first working quantity is stored before the coefficient accesses needed for the second transformation. The relative order of the two coefficient accesses within the second transformation is not established.

Because the intermediate word is unsigned, both transformation multiplications use unsigned arithmetic under the apparent integer model. Their results are then assigned to signed working quantities. Out-of-range unsigned-to-signed assignments depend on the target conversion rules.

The coefficient expression is not established as an absolute-value operation.

Tag 11 next:

- establishes retained distance from the first working quantity minus 3;
- replaces the intermediate word with the complement of the OR of that distance and the unsigned word for the second working quantity plus 3;
- derives the primary flag by converting the intermediate word to signed integer, shifting right by 31, and negating;
- computes the next state from two represented reads of Predicate destination.

For a primary flag of 1, the destination expression selects the contribution from Predicate destination without an offset. For a flag of 0, it selects the contribution from Predicate destination minus 4. Both destination occurrences are evaluated; they are not guaranteed to observe the same value. Their relative read order is not established.

The secondary flag is unchanged.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Immediate return.** If initial Base plus the first Dispatch bias selects tag 7 with defined arithmetic, the return is 0. Input multiplier and Post-input destination are not read on that route.

2. **Initial clear result.** If tag 2 executes before any primary-flag update, followed by tag 7 without another result update, the return is 0.

3. **Set result and later flag changes.** If tag 2 receives primary flag 1, it stores 147 under the stated model. Clearing both flags later does not change a subsequent return unless tag 2 executes again.

4. **Predicate boundary.** For a top-bit-extracted predicate, two OR operands with bit 31 clear produce flag 1. Either operand having bit 31 set produces flag 0.

5. **Retained-distance distinction.** At tag 10, with the second operand’s top bit clear, a retained distance with bit 31 clear produces secondary flag 1; a retained distance with bit 31 set produces 0. Recalculating the distance unconditionally would violate this behavior.

6. **Unconditional ordered routing reads.** For each of tags 0, 4, 8, and 9, an access-sensitive environment must observe Base before that tag’s clear-destination read, whether the consulted flag is 0 or 1. Skipping the clear-destination read for a set flag, or reversing the reads, does not preserve the represented behavior.

7. **Changing routing storage.** If the environment changes storage between those two reads, the Base-derived contribution uses the earlier Base observation and the clear contribution uses the later destination observation. No common snapshot is promised.

8. **Repeated input loading.** Revisiting tag 12 replaces the intermediate word using the argument and that visit’s Input multiplier observation. It preserves an earlier retained result.

9. **Transformation after a predicate.** If tag 11 follows a predicate state without another tag 12, it consumes the complemented predicate word currently retained, not a saved original input product.

10. **Unlisted tag or cycle.** An unlisted tag executes the threshold-8 behavior. A repeating route excluding tag 7 has no specified successful return or timeout.
