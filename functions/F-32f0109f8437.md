# F-32f0109f8437

### Assignment

The function assigns numeric value 1 using a one-byte store.

This is a replacement of the entire addressed byte, not a bit-setting operation that retains selected bits from its previous value. For example, a prior value of 128 is replaced by 1; it is not combined with 1 to produce 129.

The operation does not depend on the old value. No destination-memory read is expressed before the store, and no read-modify-write operation is expressed.

The one-byte value has no multibyte byte-order distinction. The supplied evidence does not require either a little-endian or big-endian interpretation to identify the value written.
