- Takes the high 32-bit word, converts it to a signed 32-bit value, and multiplies it by `0x10000` using signed 32-bit arithmetic.

That bit-window description is **conditional**, not an unconditional portable arithmetic guarantee:

- Interpreting the combined unsigned word as signed also requires the applicable target conversion semantics when the sign bit is set.
