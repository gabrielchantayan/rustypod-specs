# F-28331cd71600

## Purpose

F-28331cd71600 is a configuration-driven dispatcher that can stage three caller-supplied arguments, invoke F-2105156d4958 using selected fields from a memory object, transform the dependency’s result, and return an integer.

The visible control structure does not establish that every invocation calls the dependency, terminates, or safely handles a null object pointer. Those outcomes depend on global control values whose contents are not supplied.

The established behavior is therefore a state-transition contract, not an unconditional “process object and return status” operation. Interpreting the object as a buffer descriptor, or the byte-derived argument as a length, would be inferred intent rather than established evidence.

### Initialization

Before entering the repeating dispatcher, the function:

1. Initializes a staged nonnull flag to false.
2. Reads Seed and saves that value minus three as a continuation value.
3. Initializes the current result to zero.
4. Reads Seed again and uses that second value as the initial control state.
5. Initializes the staged object address to null.
6. Initializes both staged opaque values to zero.

The two Seed reads are distinct. If the underlying storage changes between them, the initial control state and saved continuation need not be derived from the same value.

The saved continuation is not subsequently recomputed.

### Repeating dispatch

At the beginning of every iteration, the function samples Secondary coefficient and then Primary coefficient. These samples are retained for possible use after a dependency call in that iteration.

It then reads Selector bias and selects a transition by adding that value to the current control state.

The dispatch recognizes selectors 0 through 4. Every other selector takes the default transition.

The presence of global samples at the start of every iteration matters even when the selected transition does not use them. Whether those loads are externally observable as volatile, concurrent, or device accesses is not established.

### Selector 0: multiply the current result

The current result is multiplied by the current Result multiplier. The control state is then replaced with the current Multiplication successor.

There is no return or dependency call in this transition. Execution proceeds to another dispatch iteration.

### Selector 1: return

The current result is returned immediately.

The object need not have been staged or dereferenced before this transition. If this is the first selected transition, the returned result is zero.

### Selector 2: replace the current result

The current result is replaced with the current Replacement result.

The control state is then replaced with the saved continuation computed during initialization. Dispatch resumes.

This transition does not by itself mean that the next transition returns.

### Selector 3: stage caller arguments

The function sets the staged nonnull flag according to whether the original object address is nonnull.

It reads Staging successor and installs that value as the next control state. It also copies the original object address and both original opaque values into the staged values.

No object contents are read in this transition.

Repeated selection of this transition stages the original arguments again; it does not stage any values returned by the dependency.

### Selector 4: construct arguments and call the dependency

This transition uses the staged values, not the original arguments directly.

First, it reads the byte at object offset 32. That byte is interpreted as an unsigned value from 0 through 255. It is multiplied by 209, and only the low eight bits of the product are retained. Call this the transformed byte value.

Next, the function multiplies the transformed byte value by 49, complements the product, and forces the low eight bits of the complemented value to ones. Call the resulting 32-bit unsigned pattern the derived mask.

The multiplication by 49 cannot exceed 12,495. The intermediate conversions through 16-bit signed representations therefore do not make either byte-derived intermediate negative before the complement operation.

The function calls F-2105156d4958 with seven arguments, in this positional order:

| Position | Value |
|---|---|
| 1 | Zero. |
| 2 | The 4-byte word at staged object offset 0. |
| 3 | Primary coefficient multiplied by the 4-byte word at staged object offset 28. |
| 4 | The staged second opaque value. |
| 5 | The constructed value described below. |
| 6 | The staged first opaque value. |
| 7 | An interior pointer at staged object offset 4. |

Argument 5 is Secondary coefficient multiplied by the sum of:

- Primary coefficient multiplied by the bitwise complement of the derived mask;
- Byte coefficient multiplied by the transformed byte value, minus Byte offset;
- Primary coefficient multiplied by two and then by the derived mask.

This construction uses unsigned 32-bit arithmetic where the unsigned intermediates participate. Carries outside 32 bits are discarded under that interpretation.

If all occurrences of each coefficient observe one stable value, argument 5 can equivalently be described as:

Secondary coefficient times the difference between:

- Byte coefficient times the transformed byte value; and
- Byte offset plus Primary coefficient times the quantity “two plus 256 times the whole-number quotient of 49 times the transformed byte value divided by 256.”

This equivalent description is conditional on stable reads. It does not authorize replacing separate global reads with one cached value.

After the dependency returns, the function multiplies its returned integer by the Primary coefficient sample and Secondary coefficient sample taken at the start of this iteration. The product becomes the current result.

The function then installs the saved continuation as the control state and resumes dispatch.

The post-call multiplication does not reload those two coefficients. A dependency that changes their global locations can affect later iterations, but those changes do not replace the samples already retained for this multiplication.

### Default selector: choose a state from the staged null flag

For any selector other than 0 through 4, the function computes the next control state from Branch base and the staged nonnull flag.

With a stable Branch base:

- If the staged flag is false, the next state is Branch base minus two.
- If the staged flag is true, the next state is Branch base.

The visible expression refers to Branch base twice. The stable-value simplification must not be assumed if those reads can observe different values.

The default transition does not read the object, call the dependency, or return. It does not independently prove that null objects take an error path.

## Side effects

### Reads and ordering

The following ordering is visible in the supplied representation:

- The two initialization reads of Seed occur separately.
- Every dispatch iteration samples Secondary coefficient before Primary coefficient.
- The selector is evaluated after those samples.
- In the dependency-call transition, the byte at offset 32 is read and its derived values are calculated before the dependency call.
- All dependency arguments are obtained before control is transferred to F-2105156d4958.
- The dependency returns before its result is scaled and dispatch resumes.

The relative evaluation order among separate dependency-argument expressions is not established. In particular, the evidence does not establish whether the word at offset 0 is read before the word at offset 28, or the exact ordering of coefficient reads used in those argument expressions.

Primary coefficient is referenced separately for argument 3 and twice within argument 5. Secondary coefficient is read again for argument 5, independently of its dispatch-entry sample.

### Writes and ownership

The function passes an interior pointer to F-2105156d4958. That dependency may read or modify memory, change globals, retain addresses, or perform other effects; none of those possibilities is resolved by the caller’s visible body.

### Errors and abnormal behavior

No explicit validation, exception translation, allocation-failure handling, or error-reporting protocol is visible.

Selecting the dependency-call transition before staging uses the initialized null staged address and zero staged opaque values. The offset-32 byte read occurs before the dependency can be called. Such a path is not made safe merely because the original object argument was nonnull.

A staged null address likewise remains unsafe if a dependency-call transition is reached.

The dispatcher has no explicit iteration limit. A configuration can cycle indefinitely without returning.

## Acceptance examples

These examples are conditional contracts, not reports of execution.

1. **Immediate return.** If the initial control state plus Selector bias selects 1, the function returns zero without reading object contents or calling F-2105156d4958.

2. **Result replacement followed by return.** If the first selected transition is 2 and the saved continuation subsequently selects 1, the returned value is the Replacement result read during transition 2.

3. **Result multiplication.** If the current result is 7, selector 0 is taken with Result multiplier equal to 3, and the following transition returns, the result is 21. These values avoid signed-overflow ambiguity.

4. **Staging alone does not dereference.** If selector 3 stages a null object and the next selected transition returns, the visible body does not read object contents.

5. **Unstaged call path is unsafe.** If selector 4 is selected before selector 3, the staged address is still null. A nonnull original argument does not prevent the subsequent invalid direct read.

6. **Byte-transform boundaries.** An input byte of 0 produces transformed byte 0 and derived mask `0xFFFFFFFF`. An input byte of 255 produces transformed byte 47 and derived mask `0xFFFFF7FF`.

7. **Stable-coefficient arithmetic.** With object byte 0, stable Primary coefficient 3, Secondary coefficient 5, and Byte offset 7, argument 5 has the 32-bit pattern `0xFFFFFFBF`. Its arithmetic value before unsigned reduction is −65; this does not establish a signed parameter interpretation.

8. **Post-call samples survive global mutation.** If the dispatch-entry coefficient samples are 3 and 5 and the dependency returns 2, the current result becomes 30 even if the dependency changes those global locations before returning. Later transitions can still alter the eventual returned result.

9. **Repetition is observable.** If control repeatedly reaches selector 4, the object fields and argument-construction globals are read again on each visit. The function does not visibly cache those fields across visits.
