# F-b3f03f4809f5

## Purpose

F-b3f03f4809f5 conditionally forwards two numeric values to F-44b234794ab3, then invokes an indirect target obtained by reading a global pointer location. The indirect invocation receives two bytes read from the caller-supplied object.

The conditional forwarding uses a selector byte at object offset `0x1E`:

- Zero selects the caller’s numeric value before an unsigned object byte.
- One selects the unsigned object byte before the caller’s numeric value.
- Other stable selector values suppress F-44b234794ab3.

The final invocation stage follows either the normally returning forwarding call or the decision to suppress it. At that stage, the function reads the global pointer location supplying the indirect target and reads the two object bytes supplying its arguments. These reads occur after any normally returning F-44b234794ab3 call; their relative order within the final stage is not established.

The application-level meanings of the object, numeric values, global pointer location, and dependencies are unknown. Argument ordering and subsequent dispatch are established behavior; interpretation as a notification, update, or other application operation is not.

## Behavior

### Selecting whether to forward

The first selector observation reads the byte at object offset `0x1E` and compares it with zero.

If that observation is zero, the function reads the byte at offset `0x1C`, interprets it as unsigned, and widens it to 32 bits. It then invokes F-44b234794ab3 with:

1. The original object address value.
2. The caller’s unsigned 32-bit numeric value.
3. The widened unsigned object byte.
4. The original opaque 32-bit payload.

There is no second branch-selection read on this path. A subsequent selector change does not revise the selected argument order.

If the first selector observation is nonzero, the function reads offset `0x1E` again. It compares this second observation with one.

If the second observation is one, the function reads the unsigned byte at offset `0x1C`, widens it to 32 bits, and invokes F-44b234794ab3 with:

1. The original object address value.
2. The widened unsigned object byte.
3. The caller’s unsigned 32-bit numeric value.
4. The original opaque 32-bit payload.

If the second observation is not one, F-44b234794ab3 is skipped. The visible function does not read offset `0x1C` on that path.

For a selector that remains stable during branch selection:

| Selector | Forwarding behavior |
|---:|---|
| `0` | Numeric input precedes the widened object byte. |
| `1` | Widened object byte precedes the numeric input. |
| `2`–`255` | No F-44b234794ab3 invocation. |

The two selector reads on the nonzero path are distinct in the supplied representation. Describing that path using one cached selector value would omit represented behavior.
