# F-51191325a67b

## Purpose

F-51191325a67b describes a recovered sequence of 32-bit memory operations, indirect dependency calls, bit transformations, and two byte stores. The supplied representation ends at an invalid-instruction boundary rather than an ordinary return.

Its application-level purpose is **unknown**. The repeated scaling and stores could represent encoded references or generated execution machinery, but the available evidence does not establish an allocator, serializer, object model, or protocol. Those interpretations are not contractual.

This contract records the statically visible sequence, conditional on execution reaching each operation. It does not establish that the recovered sequence is executable as presented. The supplied material explicitly reports unreliable instruction recovery.

## Acceptance examples

These are conditional static examples, not executed tests. They assume valid memory, returning dependencies, and the arithmetic interpretation stated above.

1. **Distinct initial addresses.** If the first input is `0x100`, the initial store writes `0x100` at `0x414`. The two word reads for F-U01 access `0x114`, not `0x414`. If both reads yield `0x12345678`, F-U01 receives `0x12345`, `0x100`, and `0x48D159E0`.

2. **Different store scaling.** If result B is 3, scaled B is 12. The corresponding store writes 12 at `0x44`. If result C is 5, the later store writes 12 at `0x28`, and F-U16 receives 20.

3. **Captured value survives source mutation.** If the captured word is `0xABCDEFFF`, the later store associated with result G writes `0xABCDE`. A dependency changing the original source word after capture does not trigger a reread in the visible sequence.

4. **Narrowed call arguments.** If result G is 19, scaled G is 76. F-U41’s first argument is `0x30000`; under low-32-bit shift semantics, its third argument is `0xC0000000`.

5. **Byte destinations may differ.** If the first destination-byte load yields `0x20`, the first byte store targets `0x31`. If the later load yields `0x21`, the second byte store targets `0x32`, and F-U63 receives `0x21` as its second argument.

6. **Byte extraction.** If packed word is `0x12345678`, the first byte store writes `0xE0`, and the second writes `0x23`. If both destination-byte loads yield the same value, the second store overwrites the first destination.

7. **Partial execution on failure.** If F-U11 does not return, the preceding stores have already occurred. No later call or store is required to occur, and no visible rollback follows.
