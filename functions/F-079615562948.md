### Widths and address notation

A **byte** is eight bits. A **word** is 32 bits. A **pair** is a represented 64-bit result, divided into low and high 32-bit words.

Arithmetic below uses a conditional 32-bit machine-bit interpretation: products, additions, and left shifts retain the low 32 bits; byte stores retain the low eight bits. Right shifts of explicitly unsigned values are logical. Some supplied expressions have signed intermediate types, so this interpretation does not establish portable signed-language overflow semantics.

A **selector write through a base** means:

- Read the unsigned byte at base + 1.
- Zero-extend that byte.
- Write one byte at the resulting value + 17.

The final address is therefore selector + 17, **not** base + selector + 17. Each selector write performs a fresh selector read unless explicitly described as using a captured selector.

The relevant offsets are 1, 17, and 20 bytes. They do not establish a structure layout. Word accesses occupy four bytes; alignment support and byte order are unknown.
