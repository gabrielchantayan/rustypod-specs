# F-1058afc38c04

On normal completion, it returns the original destination pointer. Neither the callback’s result nor a replacement pointer written into the temporary cell determines that return value.

This is not established as initialization of wholly uninitialized storage: the function reads the destination’s existing 32-bit field at byte offset 48 before replacing that field with the fourth argument.
