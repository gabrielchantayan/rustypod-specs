## Behavior

### Common admission condition

The first explicit operation reads the 32-bit word at offset 0x24. This initial value is retained for subsequent direct-mode decisions.

Admission succeeds when either:

- Bit 0x04 in that initial word is clear; or
- Bit 0x04 is set, and at least one bit selected by mask 0x11 in the word at offset 0x2C is set.

The read at offset 0x2C is conditional. If initial bit 0x04 is clear, admission succeeds without that read.

If initial bit 0x04 is set and both selected bits at offset 0x2C are clear, the function returns 0 immediately. The mode selector does not override this rejection, and F-34450fd9a80e is not invoked.

Bits outside mask 0x11 do not satisfy the second admission alternative.

### Zero mode: direct flag evaluation

After admission, a zero third input selects direct evaluation. This mode does not invoke F-34450fd9a80e.

A result of 1 requires both of the following conditions:

1. Initial bit 0x08 at offset 0x24 is clear, or bit 0x40 at offset 0x30 is set.
2. Initial bit 0x02 at offset 0x24 is clear, or at least one bit selected by mask 0xA0 at offset 0x28 is set.

Otherwise, the result is 0.

The two conditions are evaluated in that order and short-circuit:

- If initial bit 0x08 is clear, the first condition succeeds without reading offset 0x30.
- If initial bit 0x08 is set, offset 0x30 is read. If its bit 0x40 is clear, the function returns 0 without evaluating the second condition.
- Once the first condition succeeds, initial bit 0x02 determines whether offset 0x28 must be read.
- If initial bit 0x02 is clear, the second condition succeeds without that read.
- If initial bit 0x02 is set, either bit 0x20 or bit 0x80 at offset 0x28 is sufficient. Both are not required.

The tests of bits 0x08 and 0x02 use the initially captured word at offset 0x24. The function does not explicitly reread that word in zero mode.

### Nonzero mode: dependency-mediated evaluation

After admission, any nonzero third input selects this mode.

F-34450fd9a80e is invoked once. The supplied representation shows no explicit arguments to that invocation.

If the dependency returns 0, this function immediately returns 0. There are no explicit post-call object reads on that path.

If the dependency returns a nonzero integer, the function rereads the word at offset 0x24. This is a fresh read, not reuse of the initial word.

The result is then determined as follows:

| Post-call bit 0x08 at offset 0x24 | Additional condition | Result |
|---|---|---|
| Clear | Dependency result equals 2 | 0 |
| Clear | Dependency result differs from 2 | Dependency result unchanged |
| Set | Bit 0x04 at offset 0x30 is set | Dependency result unchanged |
| Set | Bit 0x04 at offset 0x30 is clear | 0 |

The read at offset 0x30 occurs only when the dependency returned nonzero and post-call bit 0x08 is set.

Important distinctions:

- The value 2 receives special treatment only when post-call bit 0x08 is clear.
- With post-call bit 0x08 set and bit 0x04 at offset 0x30 set, the result 2 is preserved.
- This mode tests bit 0x04 at offset 0x30, whereas zero mode tests bit 0x40 there.
- This mode does not explicitly read offset 0x28.
- Admission is not reevaluated after the dependency returns.
