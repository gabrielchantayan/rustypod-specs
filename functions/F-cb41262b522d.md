## Behavior

### 1. Initial effects and ordering

The first memory effect is an 8-bit write at offset 9 from the initial base. Its value is the low byte of the initial index.

The second effect is a 16-bit write to the address formed by adding the third explicit argument and the initial index. Its value is the low halfword of the initial base.

Only after those writes does the function read the 32-bit word at offset 68 from the initial index. It then writes the working base to offset 84 from that same working base.

The first global-derived base is selected next. A value obtained from that global symbol is written at offset 68 from the initial base, and the previously loaded word is written at offset 20 from the selected base.

This ordering is part of the represented behavior. Earlier writes can affect later reads through aliasing. Moving the initial word read ahead of either initial write is not justified.

### 2. Sixteen global-derived base selections

There are **sixteen global-derived base selections**, in their represented order. Each takes a value from a global symbol and makes it the current base for subsequent accesses.

This count is not a count of all global reads. For each selection, the selected global symbol also appears in the immediately following offset-68 store expression. The representation therefore contains both:

- The global-valued expression that selects the base.
- A further occurrence of that global-valued expression supplying the offset-68 store.

These occurrences must not be collapsed into a claim that the entire function reads globals only sixteen times. Conversely, subsequent bases obtained from ordinary memory loads are not additional global selections.

A recurring transition includes reading the current base’s offset-68 word, writing a working value at offset 84, selecting the next global-derived base, writing a global-derived value at another location’s offset 68, and copying the saved word to offset 20 from the newly selected base.

This is not a uniform operation. The source and destination bases change, and intervening accesses differ. Some later working bases come from loaded words rather than directly from global selections. A contract describing only a generic “link update” would omit behavior.

The global-derived values are used as writable addresses. Their origin in global storage does not make the addressed memory immutable. The representation does not independently establish whether repeated global-valued expressions correspond to distinct physical bus reads.

### 3. Early byte and halfword effects

Early transitions repeatedly write bytes at offset 17 from the working base. Values include the low byte of the working base shifted left by one and low bytes of words read at offset 100 from the first explicit argument.

The function also:

- Writes a loaded word’s low byte at offset 9 from the first explicit argument.
- Stores the full auxiliary word at offset 84 from that argument.
- Writes low bytes of bases and loaded values at offsets 1, 9, and 13 from other derived addresses.
- Reads words at offsets 20 and 68 to determine later destinations and values.

Halfword reads are represented as signed 16-bit values. When used in address arithmetic, they are not generally interchangeable with unsigned offsets. A halfword bit pattern representing −2 is used as a negative value in the represented arithmetic, not automatically as 65,534.

Halfword stores narrow their source to 16 bits. Destinations include a selected base plus a loaded signed halfword and a selected base plus twice a working value.

Neither byte order nor alignment handling is established. Plain-byte reads also occur later; their signedness is not resolved independently of the supplied representation.

### 4. Retained address and cross-writes

A separate word is read at offset 116 from a selected base. The function writes this value at offset 84 from the retained address, including a repeated write later in the sequence. It also writes the retained address at offset 84 from that separately loaded value.

These are established cross-writes. They do not establish ownership, reciprocal-link invariants, or the validity of treating either value as an object pointer.

## Acceptance examples

These are conditional static expectations, not executed tests.

1. **Initial narrowing.** If the initial index’s low byte is 0xAB and the destination is writable, the first write stores the 8-bit value 0xAB at initial-base offset 9, not the full index.

2. **Initial halfword.** If the initial base’s low halfword is 0x5678 and the computed destination is valid, the second write stores the 16-bit value 0x5678. Its byte order is unresolved.

3. **Early aliasing.** If either initial write overlaps the later word read at initial-index offset 68, that read must reflect the preceding write under the environment’s memory semantics.

4. **Signed displacement.** If a signed-halfword load yields −2, subsequent represented addition uses −2 rather than 65,534, subject to the unresolved machine arithmetic rules.

5. **Selection count.** A static accounting identifies sixteen global-derived base selections. Counting each selected symbol’s subsequent store-expression occurrence as another selection is incorrect.

6. **Post-call overwrite.** If F-indirect-01 returns after modifying stack offset 0x19C, the caller subsequently writes 0x08400E1C there. It also performs the four specified zero writes in the stated order; there is no fifth post-call zero assignment.

7. **Fresh global argument.** If the indirect dependency changes the later argument’s global slot, and no intervening effect changes it again, F-cdec09f5d432 receives the changed value.

8. **Non-returning dependency.** If the indirect call does not return, none of the five post-call stack writes or the direct call is reached. If the direct call does not return, the terminal operation is not reached.

9. **Unresolved bytes.** A requirement that either early unresolved-byte store always writes zero is unsupported. The static representation supplies no established value for that store.

10. **Terminal path.** If all accesses succeed and both ordinary calls return, execution reaches the non-returning terminal operation, not an ordinary successful return.
