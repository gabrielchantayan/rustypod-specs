# F-3b2936fe6771

## Purpose

F-3b2936fe6771 retrieves an uninterpreted 64-bit value through a two-stage memory lookup.

The caller supplies a 32-bit integer used as an address base. The function obtains a 32-bit address-bearing value from a field at byte offset 3840 (`0xF00`) from that base. It then retrieves eight bytes at byte offset 3096 (`0xC18`) from the resulting address and returns those bytes as a 64-bit result.

The established behavior is an indirect field read, not a calculation on the final value. The supplied evidence does not identify what the returned bits represent. They must not be described as a counter, timestamp, pointer, floating-point number, or particular application state without additional evidence.

“Inferred accessor” is a reasonable description of the function’s role. The existence of particular object types, ownership relationships, or invariants is not established.

Its observable use is as an address base. The function does not first read a pointer from that base address; its first read is from the base plus 3840 bytes. Consequently, the supplied evidence requires access to the field at that offset, not evidence of a readable field at offset zero.

## Behavior

### Lookup sequence

The function’s result depends on two memory reads in this order:

1. Read the 32-bit address-bearing field at the supplied base plus 3840 bytes.
2. Use that captured value as the secondary address and read the 64-bit field at secondary address plus 3096 bytes.

The second read depends on the value obtained by the first. The function does not establish a second read of the first field, a search, a retry, or a traversal beyond this single indirection.

The offsets are byte offsets. They are not counts of 32-bit or 64-bit elements. The final result is read from the secondary address, not directly from the supplied base plus the sum of both offsets.

There is no established arithmetic transformation of the final 64-bit value: no mask, increment, comparison, sign adjustment, or conversion to another semantic type appears in the supplied evidence.

### Width and address interpretation
