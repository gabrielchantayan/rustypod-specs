# F-2dc8aba47274

## Purpose

F-2dc8aba47274 coordinates an ordered sequence of dependency calls, transforms selected arguments and returned words, and performs four explicit data-read occurrences: one byte read, one two-byte read, and two separate 32-bit reads from the same global location. A signed-subtraction-overflow predicate selects an additional call and changes a subsequent call destination. Execution ends with an unresolved indirect transfer.

No application-level purpose is established. The supplied representation does not establish parsing, allocation, object management, or protocol semantics.

This contract distinguishes:

- **Established static evidence:** represented call order, argument dependencies, read occurrences, transformations, and branch selection.
- **Inferred interpretation:** modular 32-bit arithmetic and sign-extending right shifts where needed to interpret machine-oriented expressions.
- **Documented-only unknowns:** dependency behavior, physical calling conventions, memory validity, ownership, and unresolved transfer semantics.

No runtime tests have been performed.

Right shifts of signed quantities are interpreted below as arithmetic, sign-extending shifts. Results that depend on this interpretation are conditional on the execution environment implementing it.

The explicit signed-overflow predicate is separately established: it tests whether subtracting 62 from H exceeds signed 32-bit range. It is not an unsigned-borrow test.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. Unless an example specifies a fault, required accesses are valid and preceding dependencies return normally.

1. **Initial adjustment.** With first input 100, F-000000000001 receives 42. With fourth input 100, the branch destination receives 2 as its second argument.

2. **Negative shift.** With fourth input 59, its adjusted value is −1. If right shifts are arithmetic, F-000000000010 or F-000000000011 receives −1 as its second argument.

3. **Overflow boundary.** H equal to −2,147,483,587 requires F-000000000009 and then F-000000000011. H equal to −2,147,483,586 selects F-000000000010 and omits F-000000000009. F-000000000008 occurs in both cases.

4. **Narrow payloads.** A byte containing all one bits supplies an 8-bit payload of 0xFF. A two-byte read containing all one bits supplies a 16-bit payload of 0xFFFF. If the argument convention zero-extends these payloads, their wider numerical values are respectively 255 and 65,535; that widening convention is not independently established.

5. **XOR transformation.** If F-000000000014 returns low word 3 and high word 5, the first F-000000000015 occurrence receives 3 and 6.

6. **Different global-read values.** If the first global read yields 100 and the second yields 900, F-000000000019 receives 900 as its third argument. F-000000000021 later receives 40 as its third argument. Passing 840 to the latter would incorrectly substitute the second read for the first.

7. **Later global changes.** If G₁ is 100 and a subsequent dependency changes G to 900, F-000000000021 still receives 40. No later global read is represented for that argument.

8. **Final signed shift.** With R equal to zero, T is −62. Under arithmetic-right-shift semantics, F-000000000023 receives −1 as its third argument.

9. **Read-fault ordering.** If the byte read faults, F-000000000004 has already returned and F-000000000005 has not run. If the second global read faults, the first global read has completed but F-000000000019 has not run. Neither case requires rollback or subsequent calls.
