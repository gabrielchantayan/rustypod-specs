## Behavior

### Initial fields

The function reads a global 32-bit word and writes it to destination `0x04`. It then reads source `0x30` and writes that word to destination `0x08`, writes `0xFFFFFFFF` to destination `0x0C`, and reads source `0x30` again for destination `0x10`.

These source reads are separate accesses. Their values are equal only if the relevant storage remains unchanged between them. The global word’s meaning and value are not supplied.

### Flag-word construction

Next, the function captures the byte at source `0x48` and writes a constructed 32-bit value to destination `0x18`.

The result always contains `0x00000200`. Source mask `0x04` contributes destination mask `0x00000800`, and source mask `0x02` contributes destination mask `0x00000001`. No other source bits contribute to this word.

The possible assigned values are therefore:

| Source masks `0x04` and `0x02` | Destination `0x18` |
|---|---|
| Both clear | `0x00000200` |
| Only `0x02` set | `0x00000201` |
| Only `0x04` set | `0x00000A00` |
| Both set | `0x00000A01` |

Source mask `0x01` and masks `0x08`–`0x80` do not affect this assignment. A later read of source `0x48` does not revise this already-constructed word.

### Presence status and conditional data

After the flag-word write, the function reads source `0x34` as a full 32-bit value and tests it for inequality with zero. Any nonzero bit pattern satisfies the test, including one with only the highest bit set.

It writes one byte at destination `0x4C`: `0x00` for a zero test value or `0x01` for a nonzero test value.

The captured test result controls the two following word assignments:

- **Zero test value:** destination `0x50` receives zero, followed by destination `0x54` receiving zero. This stage does not read source `0x38` or reread source `0x34`.
- **Nonzero test value:** source `0x38` is read and written to destination `0x50`; source `0x34` is then read again and written to destination `0x54`.

The presence decision is not recomputed. In the nonzero branch, the second read of source `0x34` can differ from the value that selected the branch if intervening writes or external changes affect that storage.

The function subsequently rereads source `0x48` as a byte. If this later value has mask `0x01` set, it reads destination `0x4C`, sets mask `0x02`, and writes the resulting byte back. If the source mask is clear, there is no second direct write to destination `0x4C`.

With stable, disjoint storage, destination `0x4C` thus contains:

- Bit 0 indicating that the initial source `0x34` test was nonzero.
- Bit 1 reflecting mask `0x01` in the later source `0x48` read.
- No other set bits.

The optional update is a read-modify-write of the destination byte, not a reconstruction from the original presence decision. If that byte changes before the update, the update preserves its other bits.

Only one byte at `0x4C` is directly assigned. Bytes `0x4D`–`0x4F` are not directly cleared.
