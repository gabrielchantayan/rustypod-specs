# F-7a942ad521b9

## Purpose

F-7a942ad521b9 assigns a four-byte value to a field located 40 bytes beyond an indirectly obtained destination base.

An eight-bit control value determines the operation:

- A nonzero control selects the fixed value 21 and bypasses every dependency.
- A zero control selects a value obtained from one of two computation dependencies. The choice depends on a probe’s output byte and returned status.

The destination base is obtained when the final assignment is reached. On the computation path, this occurs after all dependency calls, so dependency-induced changes to the destination reference can affect where the assignment lands.

The meanings of the field, control, probe, and constant are not established. Descriptions such as “preparation,” “probe,” and “cleanup-like” identify observable roles, not application semantics or ownership guarantees.

This is a static behavioral contract. No runtime tests have been performed.

## Behavior

### Control-path distinction

The initial control decision is made once.

A nonzero narrowed control value produces the fixed-value assignment. This path invokes no dependency and does not visibly access the region beginning at `+4`. Its destination-base read precedes the assignment.

A zero narrowed control value enters the probe-and-compute path. Later changes to the control slot do not trigger another control decision.

### Probe information and computation choice

The probe receives a value returned by an initial preparation, an address for a separate four-byte local output region, and a literal zero argument. It returns a represented 32-bit integer status.

The output region has no visible initialization before the probe. Only its first byte is subsequently inspected by this function. The remaining three bytes do not directly participate in selection.

Inspection occurs after a cleanup-like call associated with the first preparation. Consequently, selection depends on the output byte as it exists at that later point, not necessarily on its contents at the instant the probe returned.

The computation choice is:

| Output byte when inspected | Saved probe status | Computation dependency |
|---|---|---|
| Zero | Any value | F-f13a263e790a |
| Nonzero | Nonzero | F-f13a263e790a |

The byte is evaluated before the status comparison. A zero byte settles the choice without requiring the status comparison. A known nonzero status does not eliminate the preceding byte evaluation.

The status is used only for its zero/nonzero distinction. A negative nonzero status and a positive nonzero status have the same selection effect. No status value causes an explicit early return, and the status itself is not the value assigned to the destination.
