# F-80cc4b045b6b

## Purpose

Its selection has two paths:

- A distinguished status value of −1 selects a fallback pair derived from shared state.
- Every other status selects a pair using a zero/nonzero discriminator and an unsigned category.

On every path that completes normally, the function returns the 32-bit value 1. This return value does not distinguish the selected path, report the indirect call’s result, or establish that a downstream operation succeeded.
