# F-9be658f7c3a0

## Purpose

F-9be658f7c3a0 examines up to fifteen consecutive 32-bit slots in increasing address order. A zero slot advances the scan. The first nonzero slot supplies a record address, leading to an optional invocation of F-8349c252c168 followed, if execution continues, by an invocation of F-feee9156a257. The supplied static representation marks F-feee9156a257 as non-returning.

If all fifteen slots are zero, the function reads an indirect-call target from a global pointer location and invokes that target with the original sequence base and the integer 60.

These are distinct represented outcomes:

- **Selected-record route:** inspect the first nonzero slot’s record, conditionally invoke F-8349c252c168, then invoke F-feee9156a257.
- **All-zero route:** finish the fifteen slot reads, read the global target pointer, and invoke the resulting target.

The global-pointer indirection is established behavior, not an unknown target-selection mechanism. The target’s identity, initialization, and contract remain unknown.

Resource-management interpretations are not established. Passing a value or address to a dependency does not demonstrate allocation ownership, release, destruction, or transfer.

## Behavior

### Ordered scan

The function begins with the first slot and advances by four bytes after each zero result.

Under the supplied non-returning annotation, each reached slot is read once directly by this function. The scan stops selecting slots as soon as it encounters a nonzero value. No later slot is read on that route.

If the first fourteen slots are zero, the fifteenth slot at offset 56 is still read. If that slot is also zero, the function takes the all-zero route. It does not read a sixteenth slot at offset 60.

The fixed scan offsets range from 0 through 56, and the sequence extent is 60 bytes. These small offset calculations do not themselves exceed a 32-bit integer range. Adding an offset to an arbitrary supplied base can still encounter invalid-address or address-overflow conditions; no portable behavior for those conditions is established.

### Selected-record route

A nonzero slot value becomes the selected record address. The function next reads the record’s 32-bit field at offset 8.

If that field is zero:

- The byte at offset 12 is not read.
- F-8349c252c168 is skipped.
- F-feee9156a257 is invoked with the selected record address.

If the field is nonzero, the function reads the byte at offset 12. This byte is converted to an unsigned value in the range 0 through 255.

- A value of `0x3A`, decimal 58, suppresses F-8349c252c168.
- Every other byte value causes F-8349c252c168 to be invoked with the previously read 32-bit field value as its first argument and zero as its second argument.

If execution continues after this optional call, F-feee9156a257 is invoked with the selected record address.

The comparison is exact byte equality. No character encoding, locale rule, range classification, or signed-byte interpretation is established.

The optional dependency receives the previously read field value. After it returns, this function does not reload the selected slot, the offset-8 field, or the discriminator before invoking F-feee9156a257. The latter invocation uses the already selected record address. Memory at that address may nevertheless have changed through dependency effects.
