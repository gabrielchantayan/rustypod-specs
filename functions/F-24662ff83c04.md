## Behavior

### Initial update and context-derived calls

The first represented memory operation stores **input** as 32 bits at context base plus `0x24`. The routine then reads an unsigned 32-bit field at context base plus `0x74`; its captured value is called **object base**.

The routine derives **scaled input** by shifting the signed input left three positions.

The first opaque call, **F-D01**, has four explicit arguments, in this order:

1. Object base.
2. Object base shifted left one position using unsigned 32-bit arithmetic.
3. Scaled input.
4. Object base masked with `0x7fffffff`, then shifted right two positions.

The mask in the fourth argument clears bit 31 before the shift. It cannot generally be omitted.

Calls **F-D02**, **F-D03**, **F-D04**, and **F-D05** follow in order, with no explicit arguments shown. After they return, the routine stores scaled input as 32 bits at object base plus `0x24`.

This destination uses the captured object-base value. The context field is not reread to obtain a replacement base.

Next, a 32-bit read at object base plus `0x74` supplies the sole explicit argument to **F-D06**. Calls **F-D07**, **F-D08**, and **F-D09** follow.

The initial input store precedes the context-field read. Later calls may change memory, including either context or object fields; no preservation guarantee is supplied.

### Wide results and indexed word stores

**4 × first upper half + `0x14`**

### Two payload-byte stores

**F-D22** produces an unsigned 32-bit result, called **packed result**. Shifting packed result left two positions is an unsigned 32-bit operation. That result is then represented in a signed 32-bit value, called **shifted packed result**.

If the unsigned shifted value exceeds the signed 32-bit range, the conversion requires target-level clarification. Under a bit-pattern-preserving interpretation, shifted packed result contains the low 32 bits of four times packed result.

After F-D22, the routine reads an unsigned byte at object base plus one. The first byte store targets that selector value plus `0x11`. Its payload is the low eight bits of shifted packed result.

Calls **F-D23** and **F-D24** follow. **F-D25** produces a represented signed 32-bit result, called **first scale operand**.

The routine then reads the byte at object base plus one **again**. The second byte store targets this newly read selector plus `0x11`. Its payload is the byte obtained by masking packed result with `0x3fffffff`, shifting right 20 positions, and retaining eight bits.

Consequently, this second payload consists of original packed-result bits 20 through 27. Bits 28 and 29 survive the mask and shift but are discarded by the byte conversion; bits 30 and 31 are removed by the mask.

The two selectors need not agree. Intervening dependencies may modify memory, and the first store may itself alias the selector location.

**F-D26** receives first scale operand shifted left two positions. Calls **F-D27**, **F-D28**, and **F-D29** follow.
