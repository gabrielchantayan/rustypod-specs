- **Retention:** later use of an already observed value.

Storage disjointness is not established. Selected destinations, external selectors, argument-associated storage, and calculated addresses can overlap. Consequently, repeated reads cannot generally be merged, and repeated writes cannot generally be reduced to their final value.

## Acceptance examples

These are conditional static deductions, not executed tests. Each assumes that preceding operations complete and that relevant accesses and arithmetic are admissible.

1. **First effect precedes argument reads.** With argument 4 equal to 0x26, the first visible write places 0x26 at entry-context offset 0x11. If that byte overlaps argument-1 offset-0x64 storage, the first word read occurs after the byte mutation.

2. **Two observations remain independent.** If intervening overlap makes the two argument-1 reads produce 0x44 and 0x66, their byte contributions use those respective values. Reusing 0x44 for both changes behavior.

3. **Signed halfwords remain signed.** A halfword value of −1 promotes to −1; its doubled and tripled values are −2 and −3. Accessibility of addresses derived from those values is not implied.

4. **Character interpretation remains conditional.** Character bits 0xff can promote to −1 under signed-character interpretation or 255 under unsigned-character interpretation. Character-relative destinations can therefore differ; neither interpretation is selected here.

5. **Retention survives overwrite.** If the anchor’s offset-0x04 observation is 0x35 and the entry-context address differs, its later byte contribution still derives from 0x35 after the temporary installation has been replaced.

6. **Traversal uses the previous field.** If a reached offset-0x14 word is retained before replacement, subsequent traversal follows the retained value, not the newly installed doubled context.

7. **Narrow overlap affects a reload.** If an intervening byte or halfword write changes an installed offset-0x44 word, the subsequent word read reflects the changed bytes, subject to the unresolved byte order.

8. **Context changes preserve both destinations.** If the old and new contexts differ, the premature byte use before a transition and the defined byte use afterward affect different offset-0x11 locations. The later definition does not determine the earlier stored byte.

9. **Dependencies can change the late argument.** If F-000000000001 changes the external word later supplied to F-cdec09f5d432, and intervening assignments leave it unchanged, the latter receives the changed word.

10. **Non-return prevents continuation.** If F-000000000001 does not return, the post-invocation storage assignments and later dependency invocations are not reached through this sequence.
