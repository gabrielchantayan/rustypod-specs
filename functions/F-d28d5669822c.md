## Behavior

### Initial capture and first read

Before invoking the dependency, the function captures the address-like value held in the global location.

It then reads the 32-bit field at offset +4 using the global-base expression for that access. The field’s value becomes the second argument of the first F-3805a25164a0 invocation. The first argument is the unchanged explicit input.

The first field value is obtained before the first invocation begins. It is passed as a value, not as the address of the field.

The distinction between the earlier base capture and the global-base expression used for this read is visible in the supplied representation. That distinction does not independently prove that the executable performs two separate physical loads of the global location.

### First result and short-circuiting

If the first dependency invocation returns zero, the function returns 1 immediately.

On this path:

- Exactly one dependency invocation occurs.
- The function does not perform the +8-byte field read.
- No second dependency invocation occurs.
- Accessibility of the +8-byte field is not a requirement arising from this function’s own accesses.

The first dependency may have its own memory accesses or other requirements; short-circuiting does not constrain its internals.

If the first result is nonzero, the function proceeds to the second field read.

### Conditional second read and call

After the first dependency invocation returns nonzero, the function reads a 32-bit value at offset +8 from the captured base. It then invokes F-3805a25164a0 with:

1. The original explicit input.
2. The value obtained by this post-call field read.

The second field is not snapshotted before the first call. Changes made before the conditional read can therefore affect the second argument.

A change to the global base during the first invocation does not, by itself, redirect this read. The function retains the earlier captured address-like value rather than selecting a replacement base from the global location after the call.

The required condition is accessibility at the time of the read. The first invocation could establish storage, restore access, or replace storage at the saved address before returning nonzero. The visible body does not require continuous accessibility or continuous identity of an allocation across that invocation.

Conversely, if the selected address is inaccessible when the conditional read occurs, the function has no visible validation or recovery mechanism for that condition.

If the second dependency result is zero, the function returns 1. If it is nonzero, the function returns 0.

For an ordinary two-call execution, the established sequence is:

1. Capture the global base.
2. Obtain the first field value at offset +4 using the applicable global-base expression.
3. Invoke F-3805a25164a0 with the original input and that value.
