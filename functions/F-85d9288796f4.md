# F-85d9288796f4

## Purpose

F-85d9288796f4 conditionally invokes an operation on a supplied context. It first asks F-4e6cefe281de to obtain a 32-bit value using an address derived from that context and a caller-supplied argument. A zero result from that dependency causes an immediate normal return of 3. Any nonzero result causes a call to F-7ded9e46c607, followed by a normal return of 0.

The established behavior is a two-way dispatch with fixed return values. Describing the first dependency as a “lookup” or the second as a “handler” would be inferred intent, not an established contract. In particular, the wrapper’s return of 0 establishes that the second call returned normally, not that its underlying operation succeeded.

- 3 when F-4e6cefe281de returns zero.

## Behavior

### Preparation and first dependency call

Before the first dependency call, the function initializes its private 32-bit output slot to zero.

It then invokes F-4e6cefe281de with three arguments, in this positional order:

1. The address-like value obtained from the context argument by adding 1004 bytes, equivalent to hexadecimal displacement 0x3EC.
2. The query argument, unchanged.
3. The address of the initialized output slot.

The displacement is in bytes, not a count of words or array elements. This address calculation does not itself establish that the wrapper reads a field at that offset. The derived address is passed to the dependency; any access through it is dependency behavior.

The supplied evidence establishes the call arguments and their preparation, but not the machine-level evaluation order of independent argument expressions.

### Zero-result branch

If F-4e6cefe281de returns an integer result equal to zero:

- F-7ded9e46c607 is not called.
- The wrapper returns the 32-bit value 3.
- Any value that the first dependency placed in the output slot does not affect this branch or the returned value.

A zero output-slot value does not select this branch. The branch depends exclusively on the first dependency’s return value.

Effects already performed by F-4e6cefe281de are not visibly rolled back. Thus, a return of 3 does not establish that the context or external state remained unchanged.

### Nonzero-result branch

If F-4e6cefe281de returns any nonzero integer result, the function invokes F-7ded9e46c607 with:

1. The original context argument, without the 1004-byte displacement.
2. The 32-bit value held in the private output slot after the first call.
3. The continuation argument, unchanged.

The nonzero predicate is not a positivity test. Negative results and positive results both select this branch under the recovered integer interpretation.

The output-slot value has no visible validation. Zero, a high-bit-set value, or any other 32-bit pattern is forwarded if present after the first call. If the first dependency returns nonzero without changing the slot, the initialized zero is forwarded.

After F-7ded9e46c607 returns normally, the wrapper returns 0. No returned value from that dependency is visibly inspected or propagated.

- Invoke F-4e6cefe281de.

- On the nonzero branch, obtain the resulting slot value and invoke F-7ded9e46c607.

There is one visible invocation of F-4e6cefe281de per wrapper invocation, and at most one visible invocation of F-7ded9e46c607. There is no visible loop or retry.
