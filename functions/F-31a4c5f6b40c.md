## Behavior

### Address derivation

Let \(x\) denote the third input, interpreted as a signed 32-bit integer.

The represented address calculation has these relationships:

1. An intermediate quantity \(q\) is obtained by right-shifting \(x\) by 11 positions.
2. The bit pattern of \(q\) is interpreted as an unsigned 32-bit value \(u\).
3. A second unsigned quantity is obtained by logically shifting \(u\) right by two positions.
4. The destination address value is the 32-bit unsigned sum
   \[
   A = \bigl(u + (u \mathbin{\text{ logical right shift }} 2)\bigr) \bmod 2^{32}.
   \]

The addition includes unsigned arithmetic under the represented types. It must not be substituted with unbounded signed arithmetic, especially for negative third inputs.

For nonnegative \(x\), the first shift has the unambiguous numeric interpretation
\[
q = \left\lfloor x / 2048 \right\rfloor.
\]
In this region, the address value is
\[
A = q + \left\lfloor q / 4 \right\rfloor.
\]
No 32-bit wraparound occurs for nonnegative signed 32-bit inputs.

For negative \(x\), the supplied representation does not independently establish the machine semantics of the signed right shift. If it is an arithmetic right shift, then \(q\) is the sign-extended result, equivalent numerically to rounding division by 2048 toward negative infinity. The negative examples below use that interpretation explicitly.

The displayed calculation contains two occurrences of the first shifted expression. Their evaluation order has no demonstrated memory effect: both use the same by-value input. This contract does not infer a machine instruction count from those occurrences.
