The first F-D065 second argument is necessarily zero because the initial shift state is at most 31. Under 32-bit bit-vector interpretation of the later shifts, subsequent second arguments depend on the low six bits of the preceding F-D074 result and need not be zero.

## Acceptance examples

These are conditional static criteria, not executed tests. Required accesses must be valid, preceding dependencies must return, and arithmetic must have the stated interpretation.

1. **Entry ordering.** With first argument 3, the first visible store writes the 32-bit value 3 at address 32. F-D001 occurs afterward.

2. **Separated overwrite.** If F-D028 returns 2, the first store at address 52 writes 8. After F-D029 through F-D033, a second store at address 52 writes 32, independently of F-D033’s result.

3. **Fresh selection.** If the primary selector index is zero and the byte at address 1 is 5, selection targets address 22. If a dependency changes that byte to 9, the next selection targets address 26.

4. **Byte truncation.** If the first byte-source word is hexadecimal 3AB00001, its first byte store writes hexadecimal 04. Its later masked-and-shifted store writes hexadecimal AB.

5. **Direct-address boundary.** Fourth-argument values zero through 127 direct the byte write to address 28. A value of 128 directs it to address 29.

6. **Immediate selector alias.** If the primary selector index is 27 and the fourth-argument index is zero, the direct write targets the selector at address 28. If that write deposits 4, the immediately following selector read obtains 4 and its zero store targets address 21, absent external interference.

7. **Loop-entry arguments.** If F-D062 returns hexadecimal FFFFFFFF, the initial shift state is 31, F-D063 receives 62, and the first F-D065 invocation receives zero as its second argument. Its target is F-T001.

8. **Target transition independent of returned data.** If the first iteration reaches its successor, that successor’s F-D065 invocation targets F-T002, not F-T001. Equal carried arguments or equal dependency results do not remove this distinction. The third and later invocations also target F-T002.

9. **Later nonzero loop argument.** Under 32-bit bit-vector shift semantics, an F-D074 result of 1 produces carried value 4 and shift state hexadecimal 04000000. The next F-D065 invocation targets F-T002 and receives hexadecimal 00040000 as its second argument.

10. **No finite completion.** If every dependency keeps returning and accesses remain valid, any finite number of completed iterations is followed by another iteration, not a normal return.
