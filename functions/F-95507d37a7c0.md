# F-95507d37a7c0

## Purpose

F-95507d37a7c0 dispatches a request to at most one specialized dependency, then uses a common fallback if no specialized dependency is selected or the selected dependency returns zero.

One request code, `0x3685`, bypasses dispatch and fallback: the function writes a zero result and returns one.

The return value and the value written through the output pointer are separate channels. A nonzero specialized return is propagated unchanged. A fallback return is written to the output location and converted to a zero-or-one return status.

This contract describes behavior established by the supplied static representation. It does not establish what the request codes mean, what the selector constants represent, or whether an output value denotes a handle, pointer, count, or other result.

## Behavior

### 1. Special request takes precedence

The request code is first compared with `0x3685`.

If equal:

1. The function writes the 32-bit integer zero to the output location.
2. It returns the unsigned value one.

No dispatch-state access, specialized call, context-field read, or fallback call is present on this path.

The output write precedes successful return. If the write cannot complete, the supplied evidence does not establish a normal return.

### 2. Dispatch uses four state words

For specification purposes, the four externally stored dispatch values are called **Adjustment**, **Bias**, **Pivot**, and **Delta**. These are descriptive labels, not established application meanings.

For requests other than `0x3685`, dependency selection follows the precedence below:

| Priority | Condition | Selected dependency |
|---|---|---|
| First | Selector plus Adjustment equals zero | F-a28b0c741827 |
| Second | Otherwise, Selector plus Adjustment plus Bias equals zero | F-6fbf1d0482e8 |
| Third | Otherwise, that combined value equals Pivot | F-8005289efd55 |
| Fourth | Otherwise, the combined value minus Pivot equals Delta | F-b4ddeaf855f2 |
| Unmatched | None of the preceding conditions holds | No specialized dependency |

The earlier condition wins if values would make multiple conditions true. In particular:

- A first-priority match prevents evaluation of later dispatch conditions.
- A second-priority zero match wins even when Pivot is also zero.
- A third-priority Pivot match wins even when Delta is zero.

The first condition contains a Selector-plus-Adjustment expression. The later combined expression contains another occurrence of Selector plus Adjustment, with Bias added. The supplied representation does not justify replacing those occurrences with a guaranteed single snapshot of shared state.

The conditions establish control-dependent use of the dispatch values. They do not establish machine-level load counts, atomicity, synchronization, or an exact operand-read order inside an arithmetic expression.

### 3. A selected specialized dependency is called once

Each specialized dependency receives the same four arguments, in this logical order:

1. Original context.
2. Original request code.
3. Original auxiliary value.
4. Original output location.

The selector is not an explicit argument to these dependencies.

Only the selected dependency is called. A zero return does not cause another specialized dependency to be tried.

The selected dependency’s return is treated as a 32-bit unsigned value:

- If nonzero, F-95507d37a7c0 returns that value unchanged.
- If zero, execution continues to fallback.

On the nonzero path, this function performs no direct output write after the dependency returns. The output contents depend on the dependency and any relevant aliases. A successful specialized return therefore does not, by itself, prove that the output was initialized.

### 4. Fallback is common to unmatched and zero-return cases

Fallback is reached in either of two situations:

- No specialized dispatch condition matched.
- A selected specialized dependency returned zero.

The function then reads the four-byte field at context offset `0x29C` and calls F-5710a8628cba with:

1. The field value read from that offset.
2. The original selector.
3. The original request code.

The context-field read occurs after a selected specialized dependency has returned zero. It must not be modeled as an entry-time cached field read. If the dependency changed that field, fallback can receive the changed value.

After F-5710a8628cba returns:

1. Its 32-bit integer result is written to the output location.
2. The function returns zero if that result is zero, or one otherwise.

A negative nonzero fallback result is written as that negative integer and produces return status one. It is not propagated as the function’s own unsigned return value.

## Side effects

- Fallback completion: writes the fallback result.

It performs no direct write to the output location after a nonzero specialized return.

No direct assignment to dispatch state or context fields appears in the supplied body.

If the output location aliases dispatch state, a special-request output write can alter that state without first consulting it. On a fallback path, the direct output write occurs after dispatch has already selected its path.
