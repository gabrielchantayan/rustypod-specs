Unsigned shifts operate within a 32-bit unsigned domain. In particular, an unsigned left shift by two discards bits shifted beyond bit 31. Unsigned right shifts introduce zeros.

Several calculations instead use signed 32-bit intermediates. Signed multiplication, signed addition, and signed left shifts are not assumed to wrap. Their behavior outside the representable or otherwise defined domain remains **documented_only**.

Two unsigned left-shift results are assigned to signed 32-bit intermediates before further use:

- The shifted result derived from F-U050 supplies the direct D-derived byte store and the later selector-address calculation.

For either conversion, a result from zero through 2,147,483,647 has the same signed numeric value. Conversion of a larger unsigned value is unresolved. This contract does not silently treat it as a bit-preserving reinterpretation. ## Acceptance examples

These are conditional static examples, not executed tests. Each assumes preceding operations complete.

1. **Initial address.** With A equal to three, the first explicit store writes the 32-bit value three at address thirty-two, before F-U001.

2. **Different word scales.** With R2 equal to five, W is twenty and its word-store destination is one hundred. Writing twenty at address forty would not match the displayed calculation.

3. **Overwrite ordering.** With R4 equal to two, P is thirty-two. The procedure writes eight at address fifty-two before F-U029 and writes thirty-two there after F-U033. Intervening dependencies may observe either state or modify it.

4. **Fresh selector reads.** If the first H-selector read yields four and the next yields nine, the corresponding byte-store destinations are twenty-one and twenty-six. Reusing the earlier destination would violate the read sequence.

5. **Representable signed conversion.** With Q equal to one, L and the signed Q-shift value both equal four. The first selector-based byte store writes four, and F-U039 receives three signed arguments each equal to four.

6. **Out-of-range signed conversion.** With Q equal to 536,870,912, unsigned L equals 2,147,483,648. The signed intermediate, its three F-U039 arguments, and its narrowed byte are not unconditionally established. Under an additional bit-preserving conversion assumption, the signed value would be −2,147,483,648 and the byte would be zero.

7. **Field truncation.** If Q has only bit 28 set, the field for the second selector-based store equals 256 before byte narrowing. That store writes zero.

8. **D boundary.** With T equal to one, the signed T-shift value is four. D equal to 127 selects address twenty-eight; D equal to 128 selects address twenty-nine. Either direct store writes four.

9. **Second selector arithmetic.** With T equal to one, V and its signed intermediate equal four, so J is 4,097. If V instead exceeds the signed range, that same address derivation cannot be accepted without specifying the conversion. Even an in-range signed value of 2,097,152 makes the multiplication by 1,024 exceed signed 32-bit range.

10. **Loop entry and nontermination.** For every U, the first F-U065 second argument is zero. If all later calls return and accesses complete, the loop repeats rather than returning normally.
