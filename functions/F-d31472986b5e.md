## Behavior

### Initial reads and copied fields

The function first reads the first object address from record offset `0x10`.

From that object, it reads the 32-bit word at offset `0x0c`. It then reads the word at object offset `0x10` and writes that word to record offset `0x28`. It subsequently writes the previously obtained word from object offset `0x0c` to record offset `0x2c`.

This sequencing matters if the record and object storage overlap: the source word at object offset `0x0c` is obtained before either destination write, while the source word at object offset `0x10` is obtained before the write to record offset `0x28`. The two destination writes occur in the order `0x28`, then `0x2c`.

These copies always use the object address initially obtained from record offset `0x10`; they do not depend on the selection flag.
