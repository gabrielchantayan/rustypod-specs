A recurring operation reads an unsigned byte and writes one byte at the absolute address equal to that lookup value plus 17. Other operations access fixed low addresses or addresses derived from dependency results. No argument-owned output buffer is identified.

## Behavior

### Entry and early argument flow

The first represented memory operation reads an unsigned byte at the first argument’s address plus 1. The function adds 17 to that byte and writes the incoming byte-sized machine-state value at the resulting absolute address.

The destination is therefore between addresses 17 and 272 inclusive. It is not an offset from the first argument. Both the read and the write precede the first invocation, with no visible null, range, or accessibility check.

The first invocation receives the fourth argument shifted left by two in its first and second positions, followed by the third explicit argument. Its target depends on incoming execution context.

After several intervening calls, another unsigned byte is read at the early address derived from sixteen times the fourth argument plus 1. The associated byte write targets the lookup value plus 17. Its value is obtained by retaining the fourth argument’s low 30 bits, shifting right by 20, and narrowing to a byte. Only original bits 20 through 27 reach memory.

Later calls receive a dependency result shifted left by two, sometimes together with the saved lookup byte. A subsequent invocation receives the unsigned difference between that byte and the fourth argument in both argument positions. Underflow wraps at 32 bits; no saturation or rejection is represented.

### Lookup-mediated byte writes
