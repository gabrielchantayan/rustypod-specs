### Retained-byte update

The function samples the unsigned byte at primary offset 0.

If the byte at primary offset 1 is smaller than that sampled value, it writes the sampled value to offset 1. Otherwise, it leaves offset 1 unchanged.

Under ordinary, nonconcurrent, nonaliased storage semantics, this makes the resulting retained byte the unsigned maximum of its previous value and the sampled selector. No arithmetic increment or wraparound is involved.

This update is independent of the later publication decision. It may occur even when publication is rejected.

### Publication eligibility

The sampled selector must equal exactly 1. Any other value causes normal return after the retained-byte handling, without the function’s direct publication write or indirect continuation invocation.

When the selector equals 1:

- Different four-byte values at primary offsets 8 and 12 permit publication.
- Equal values permit publication only if the byte at secondary offset 1 is nonzero.
- Equal values and a zero override cause normal return without publication or continuation invocation.

The equality comparison concerns the complete 32-bit values. No ordering relationship is used.

The override byte is inspected only when the comparison values are equal. A zero override does not block publication when they differ.

### Publication and continuation

It then invokes the indirect executable target. No explicit arguments are shown for that invocation, and no returned value is visibly consumed.
