## Behavior

### 1. Entry write loop

The initial counter is the explicit input shifted right by 21 bits without sign extension. Its range is 0–2047.

The loop executes at least once. Each iteration:

1. Captures the current running base.
2. Advances the running base by 74 bytes.
3. Adds 212 to the counter.
4. Shifts the current input left by two bits, retaining 32 bits.
5. Writes the advanced base’s low 16 bits at offset 28 from the captured base.
6. Writes the ambient value’s low 16 bits to that same address.

The two halfword stores are ordered, separate accesses. Although the second overwrites the first in ordinary memory, an access trace, memory-mapped device, or fault can distinguish them.

The loop continues if the updated counter is zero, or if its signed-negative predicate differs from the signed-overflow predicate for subtracting 67 from the ambient value.

That subtraction overflows exactly when the ambient value, interpreted as signed, is between \(-2^{31}\) and \(-2^{31}+66\), inclusive.

After the first increment, the counter is between 212 and 2259: nonzero and signed-positive. Thus:

- Without that subtraction overflow, the loop executes exactly once.
- With that overflow, execution continues beyond the first iteration.

There is no explicit iteration limit or validation of the advancing write addresses. After 16 left shifts, the shifted input is zero.

2. A replacement code-associated base is installed **before F-indirect-02 is invoked**.
