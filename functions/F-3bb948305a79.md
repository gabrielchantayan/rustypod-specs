# F-3bb948305a79

## Purpose

F-3bb948305a79 initializes or replaces two adjacent 32-bit storage slots with two caller-supplied values. The first value occupies the first slot; the second occupies the immediately following slot.

The established behavior is two direct assignments in source order. The function does not interpret the supplied values, combine them, or derive one from the other. Describing the destination as a two-field record is a useful interpretation, not an established data-model requirement.

1. It assigns the first supplied 32-bit value to the destination’s first slot.

Neither assignment depends on the prior contents of the destination. There is no explicit read of either destination slot before replacement.
