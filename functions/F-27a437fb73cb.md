## Acceptance examples

These examples are conditional static expectations, not executed tests.

1. **Early store distinction.**  
   With first argument 8 and valid destinations, the first explicit word store writes 8 at numeric address 52. After D-001 returns, the next explicit word store writes 8 at address 28. These are different addressing formulas.

2. **Third-argument shift.**  
   Original third arguments 16,383 and 16,384 produce fourth explicit arguments 0 and 1, respectively, for D-009’s initial call.

3. **Fresh selector reads.**  
   If successive selector reads yield 3 and 9, their respective byte writes target addresses 20 and 26. Reusing destination 20 for both would violate the visible sequence.

4. **Byte truncation.**  
   If the first byte source is 255, its first selector-mediated write stores 252: four times 255 is 1,020, whose low byte is 252.

5. **Shifted-byte extraction.**  
   If the first byte source is the word value 0x3AB00000, its later masked-and-shifted selector write stores 0xAB, not the full ten-bit shifted intermediate.

6. **Entry-word-derived values.**  
   For entry word 0x12345678, the visible right shifts by eight, fifteen, sixteen, and twenty-three bits yield 0x00123456, 0x00002468, 0x00001234, and 0x24. The direct byte destination is therefore numeric address 64.

7. **Repeated zero writes.**  
   Two selector-mediated zero writes remain two reads and two writes even if both reads return the same byte and the destination already contains zero.

8. **Loop transition.**  
   The first D-027 call receives zero as its second explicit argument. Under 32-bit word shifting, if D-028 then returns 1, the next iteration’s retained result is 4 and its second explicit argument is 0x00040000. The loop selector-read address remains based on D-022’s retained source.
