# F-e8f085ee1487

## Purpose

F-e8f085ee1487 performs an ordered sequence of indirect calls, integer transformations, computed memory accesses, and global assignments. Its established effects include:

- Writing bytes to low addresses selected by unsigned byte reads.
- Reading 8-, 16-, and 32-bit quantities from computed addresses.
- Writing 32-bit quantities to computed locations, frequently with displacement 0x14.
- Accessing two separately named global references, designated **G-A** and **G-B** here. Their aliasing and overlap are unresolved.

No application-level purpose is established. Object initialization, instruction interpretation, serialization, and operating-system service invocation are possible interpretations only, not contractual behavior.

This is a static behavioral contract. It does not establish successful completion, safe addresses, dependency purity, or preservation of memory across calls.

## Acceptance examples

These are conditional static consequences, not executed tests.

1. **Entry truncation.** With first argument 0x123456AB and initial selector seven, the first write stores 0xAB at address 0x18 before F-DEP-001.

2. **Fresh selector.** If the entry selector changes from seven to nine before its second read, that write targets 0x1A. For the same first argument, its written byte is 0x48.

3. **Selector boundary.** A selector of 255 selects 0x110. Only one selector byte is loaded.

4. **Different word addresses.** For the retained unsigned result one, the scaled 0x44-displacement read uses 0x48; the masked-and-right-shifted read uses 0x44.

5. **Three-read chain.** If the first byte is 0xFE, the second byte is read at 0xFF. Passing those two bytes to dependencies does not establish word stores of either. If the third byte is 0xA5, its explicit word store contains 0x000000A5.

6. **Independent field snapshots.** If a retained base’s 0x74 field changes between repeated reads, each byte copy reflects its own read.

7. **Global aliasing.** If G-A and G-B overlap, a G-B assignment may affect a later G-A snapshot. A contract requiring independent storage would incorrectly exclude this unresolved case.

8. **Double shift.** Any unsigned 32-bit snapshot shifted right by 23 twice yields zero after the second shift, without implying the original snapshot was zero.

9. **Terminal order.** If reached, the final byte clear precedes the packed G-B assignment, which precedes the halfword clear and then the zero-address call attempt. Successful return from that call is not established.
