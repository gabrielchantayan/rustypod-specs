## Behavior

If it is nonzero, the function obtains a dispatch base from the object’s first word, obtains a callable target at byte offset 256 from that base, and invokes that target with the object reference as its sole explicit argument.

The callback’s result is not used. Normal continuation depends on the callback returning.

The function does not establish that the callback preserves object contents, global state, allocation state, or memory ownership.

### Post-callback selector evaluation

After the optional indirect callback has returned—or immediately if it was skipped—the function reads the 32-bit object word at byte offset 80.

This ordering is significant. The selector is not sampled before the callback. If the callback changes that field and returns with the object still valid, the subsequent selection uses the field value present at the later read.

A zero selector skips F-dc842e45211e. Any nonzero 32-bit selector selects it. The field is used only for this zero/nonzero decision; its value is not itself forwarded as an argument.
