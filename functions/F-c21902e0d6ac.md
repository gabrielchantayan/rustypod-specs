# F-c21902e0d6ac

## Purpose

F-c21902e0d6ac selects and returns one 32-bit value through an ordered sequence of two dependency-controlled gates and, if neither gate selects an early result, two reads of a field in an input object.

The first gate uses a value obtained without arguments. The second uses a value obtained from an address 40 bytes beyond the input address. A zero result from either gate causes an immediate return of that gate’s associated stored result. Otherwise, the function returns either the first observed value of the field at byte offset 44 or a stored fallback, according to a second observation of that field.

The established behavior is selection by zero versus nonzero dependency results. Interpreting those results as string equality, configuration matching, or successful lookup is inferred intent, not an established contract.

## Behavior

### First gate

The function first calls F-3ad65987df9a with no visible arguments and retains its 32-bit result.

That result is then supplied as the first argument to a separate, unresolved dependency. This document assigns that dependency the local opaque identifier **F-000000000001**; the identifier is a reference within this contract, not a recovered identity.

The second argument to F-000000000001 is a fixed reference associated with the text “CntrlHistoryFn.” The function uses only whether the dependency returns zero or nonzero. It does not distinguish negative from positive nonzero results.

If the result is zero:

- The function reads the stored result associated with the first gate.
- That value is returned immediately.
- F-44362605ab79 is not called.
- The second gate is not evaluated.
- The input field at offset 44 is not read.
- The final fallback is not read.

The selected stored result is read after the first gate call. The visible function does not capture it before either preceding dependency call.

### Second gate

If the first gate returns nonzero, the function passes the address at input base plus 40 to F-44362605ab79.

It then supplies that dependency’s 32-bit result as the first argument to F-000000000001. The second argument is a 32-bit value read from a separate stored location associated with this gate.

The second gate’s stored argument is obtained after F-44362605ab79 returns. An implementation must not assume that it has the same value it held before that call unless an external contract establishes stability.

If this gate returns zero:

- The function reads the stored result associated with the second gate.
- That value is returned immediately.
- Neither read of the field at offset 44 occurs.
- The final fallback is not read.

The second gate’s result store is distinct in role from the store supplying its comparison argument. No equality, ownership, or type relationship between those values is established.

### Field-based selection

If both gates return nonzero, the function reads the 32-bit field at input base plus 44 twice.

The reads have different roles:

1. The first read captures a candidate return value.
2. The second read determines whether to select the fallback.

If the second read is zero, the function reads and returns the stored fallback. If the second read is nonzero, the function returns the value captured by the first read.

This is not a contract to read the field once and return that observation when nonzero. Where distinct observations are possible, the returned field value and the value governing fallback selection can differ.

For example:

- A first observation of zero followed by a nonzero observation returns zero from the first observation.
- A first observation of a nonzero value followed by zero returns the stored fallback.
- Two different nonzero observations return the first one.

There is no visible dependency call between the two field reads. The evidence does not establish atomicity, synchronization, or permission for concurrent mutation. The two-observation behavior is statically visible; whether differing observations can arise in a supported runtime environment remains unresolved.
