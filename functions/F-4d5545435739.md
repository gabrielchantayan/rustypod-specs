# F-4d5545435739

## Purpose

F-4d5545435739 dispatches a selector against state obtained from F-7fba0909c452. Depending on the selected operation, it:

- Copies one, two, or three 32-bit state words into caller-provided output storage.
- Writes one or two fixed 32-bit values into that storage.
- Passes a state-derived address or a temporary value to another dependency.
- Rejects the selector and conditionally records an error in the state.

Its explicit return is a 32-bit status: **1 for a recognized branch, 0 for rejection or unavailable state**. A return of 1 does not independently establish that a dependency completed successfully: dependency return values are not examined.

The selector is represented as a pointer-shaped argument, but this function uses it as a numeric dispatch token. It does not dereference the selector.

## Interface

### Inputs

**Selector**

A pointer-width token interpreted through equality comparisons, signed integer comparisons, and, in one branch, subtraction. The supplied representation uses 32-bit integers and a 32-bit address model.

Several dispatch values are numeric literals. Six others are loaded from external storage whose contents are not supplied. This contract names those six external selector values **A**, **B**, **C**, **D**, **E**, and **F**. These labels identify distinct source locations, not necessarily distinct numeric values.

Their numeric values and ordering are unknown. Consequently, a numeric selector mentioned below is accepted only when the enclosing dispatch conditions reach its branch.

**Output**

A pointer to caller-supplied 32-bit word storage.

- Scalar operations require one writable word.
- Pair operations require two consecutive writable words.
- Triple operations require three consecutive writable words.
- Dependency-only and rejection branches do not explicitly access this pointer.
- No output-pointer validation is present.
- Existing output contents are not initialized or cleared before dispatch.

The output pointer is not passed explicitly to any of the three processing dependencies. Whether those dependencies access output through another mechanism is unknown.

### State obtained internally

F-7fba0909c452 supplies the state base address. Offsets in this contract are byte offsets from that returned address.

The state is viewed primarily as 32-bit words, with one operation reading an unsigned byte at offset `0x95D`. Index-derived operations use the 32-bit word at offset `0x24C`.

No bounds, alignment, index-range, or object-lifetime checks appear before state accesses.

## Behavior

### State acquisition precedes dispatch

The first dependency call is F-7fba0909c452, with no explicit arguments.

If its result is null, the function immediately returns 0. It does not explicitly write output or inspect the state error word. Side effects of the provider itself remain possible.

For a non-null result, dispatch proceeds using that state address.

### Dispatch order and external selector values

Equality tests use token equality. Ordering tests use the selector and external values interpreted as signed 32-bit integers.

The following routing is significant: it determines whether a literal selector branch is reachable when the external values are unknown.

1. **Equality with A takes precedence.** It selects the computed-address operation using state offsets `0x004` and `0x008`.
2. Otherwise, selectors signed-less-than A enter the lower region:
   - Equality with B selects a two-word fixed-value result.
   - If not equal to B but signed-greater-than-or-equal-to B:
     - Equality with D selects the scalar at `0x8C4`.
     - Values signed-greater-than D are checked for `0x0B66` and then `0x0B70`; other values are rejected.
     - Remaining values are checked for `0x0B53`, `0x0B62`, and `0x0B63`; other values are rejected.
   - If signed-less-than B:
     - Equality with C selects a one-word fixed-value result.
     - Values signed-less-than C are checked for `0x0B00`, `0x0B02`, and `0x0B03`; other values are rejected.
     - Remaining values are checked for `0x0B12` and `0x0B21`; other values are rejected.
3. Selectors not signed-less-than A, after A equality has already failed, enter the upper region:
   - Equality with E selects the scalar at `0x8E4`.
   - Otherwise, values signed-less-than-or-equal-to E:
     - `0x2A00` selects its scalar result.
     - Other values signed-less-than `0x2A01` are checked for `0x0BA7`, `0x0BA8`, and `0x0C22`.
     - Remaining values are checked for `0x8038` and `0x80AA`.
     - Unmatched values are rejected.
   - For values signed-greater-than E:
     - Equality with F selects a three-word result.
     - Values signed-less-than F are checked for `0x8127` and `0x8128`.
     - Remaining values accept `0x846D` or a selector whose subtraction of `0x8400` produces `0x006E`; other values are rejected.

Under ordinary 32-bit address arithmetic, the last subtraction condition identifies `0x846E`. It must not be interpreted as accepting an entire selector range.

If external values coincide, the earlier reachable comparison controls behavior. For example, equality with A wins over any numeric operation or later external-value comparison.

### Byte-derived temporary operation

For selector `0x0B66`, when reachable:

1. One unsigned byte is read from state offset `0x95D`.
2. A 32-bit temporary is formed as **byte × 257 + floor(byte / 128)**.
3. The address of that temporary is passed to F-01be51f7fed7.
4. The function returns 1 after the dependency returns.

The multiplication duplicates the byte into the low two bytes; the additional term is 1 exactly when the original byte’s highest bit is set.

The result ranges from `0x00000000` to `0x00010000`. It is not a signed-byte extension, and the high-bit adjustment is not a full-width sign correction.

The temporary has local call-frame lifetime. No ownership transfer or right to retain its address is established.

### Unsupported selectors

Every dispatch rejection converges on the same error handling:

- Read the first 32-bit state word, at offset `0x000`.
- If it equals zero, write `0x00000500` there.
- Otherwise, preserve its existing nonzero value.
- Return 0.

The function does not explicitly modify output on this path.

This is a “record only if empty” transition, not an unconditional error replacement. The source does not establish the meaning of `0x500` beyond its use as the rejection marker.

## Acceptance examples

These are **conditional acceptance examples derived from static evidence**, not executed tests. Examples using literal selectors require the external selector values to route execution to the stated branch.

1. **Unavailable state**  
   If F-7fba0909c452 returns null, the result is 0. The dispatcher performs no explicit output write and no state error-word access.

2. **Three-word ordered copy**  
   For reachable selector `0x0B02`, with disjoint output and state words `11`, `22`, and `33` at offsets `0x210`, `0x214`, and `0x218`, output becomes those three values in order and the result is 1. A fourth output word remains unchanged.

3. **Aliasing exposes sequential copying**  
   For the same selector, let output begin at state offset `0x214`, and let the initial words at `0x210`, `0x214`, and `0x218` be `11`, `22`, and `33`. The first store replaces the source of the second copy with `11`; the second store replaces the source of the third copy with `11`. The three output words consequently become `11`, `11`, and `11`, assuming ordinary sequential memory behavior.

4. **Fixed pair**  
   A reachable `0x0B12` writes `0x10000` to the second output word and then the first. It returns 1 and does not explicitly write a third word.

5. **Preserving an existing error**  
   For a rejected selector and a state error word already equal to `0x1234`, the function returns 0 and leaves that word unchanged. With an initially zero error word, it writes `0x500`.

6. **Byte conversion boundary**  
   A reachable `0x0B66` passes a temporary containing:
   - `0x00007F7F` for byte `0x7F`;
   - `0x00008081` for byte `0x80`;
   - `0x00010000` for byte `0xFF`.

   These examples establish the high-bit adjustment, not any downstream interpretation.

7. **Indexed address**  
   For reachable `0x0B03` with selected index 2, F-e1bd00d0c4e2 receives the state address plus `0x24C`. This is the computed address; the dispatcher does not first copy data from it.

8. **Computed argument**  
   On the A branch, base value `0x1000` and index value 3 produce dependency argument `0x10CC`. If F-c84b65501927 returns normally, the dispatcher returns 1 regardless of the dependency’s returned value.

9. **Precedence over a literal selector**  
   If A equals `0x0B02`, that selector takes the A computed-address branch, not the three-word copy branch.

10. **No accepted range at the upper tail**  
    When the final upper-tail branch is reached, `0x846D` and the subtraction-matching value `0x846E` are accepted. A neighboring unmatched value is rejected rather than treated as part of a range.
