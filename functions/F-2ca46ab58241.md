# F-2ca46ab58241

## Purpose

F-2ca46ab58241 performs address-derived memory accesses, conditionally invokes an initialization dependency, and enters repeated indirect calls interleaved with further writes. The supplied representation contains no normal return path.

No higher-level purpose is established. Interrupt-labelled storage, reset-labelled storage, fixed addresses, and a software breakpoint suggest low-level state manipulation, but do not establish a device protocol or reset procedure.

This contract describes static behavior, conditional on successful memory accesses, returning dependencies, and continuation after the breakpoint. No runtime tests have been performed.

## Behavior

### Entry and initialization selection

The initial access order is:

1. Form the read cursor from the entry stack address shifted left by four.
2. Write one byte at the incoming address-like value plus 7. The value is the low byte of the entry stack address logically shifted right by 12.
3. Write halfword `0xed38` at that right-shifted stack address plus 6.
4. Read and retain a 32-bit word from `0x0897ede0`.
5. Form the accumulator by subtracting `0xf9` from the incoming address-like value.
6. Assign the pointer value referring to `0x97ed3800` to named storage at `0x97ed3800`. Its destination width remains qualified as above.

The retained read occurs after the two explicit stores. If those stores alias its location, their effects precede that read.

Initial state then uses:

- Address seed `0x97ed3800`.
- Scale selector zero.
- Address-producing value equal to the branch-selection value shifted left by 13.
- Descriptor base `0x000000a1`.

Initialization occurs exactly when the branch-selection value’s low 16 bits are nonzero. Upper bits do not affect this predicate, but the full value contributes to the shift used on the skipped path.

### Conditional initialization

When selected, initialization performs these accesses and the call in order:

1. Assign `0x18` to interrupt-labelled storage.
2. Assign the incoming 16-bit value to named storage at `0x225fb880`.
3. Reread the 32-bit word at `0x0897ede0`; write byte `0xce` at `0x97ed3800` plus that word.
4. Read named storage at `0x0ce00026` and convert its value into the accumulator.
5. Assign zero to named storage at `0x0ce00000`.
6. Invoke dependency role F-a9d37c105b42 with:
   - The branch-selection value’s low 16 bits, logically shifted right by two.
   - `0xc0`.
   - Address `0x0ce00000`.

The widths of the named-storage assignments and the read in step 4 are not established merely by their values or consumers.

The initialization call target is the incoming link value with its low two bits cleared, plus `0x8a4`.

After it returns:

2. Select seed `0x0897eca0`.
3. Read the 32-bit word at `0x0897eca4` and multiply it by `0x20`.
4. Write halfword `0xeca0` at four times an auxiliary post-call value.

6. Write halfword `0xeca0` at the product from step 3 plus 6.

The auxiliary value is exposed as post-call machine state, not an established formal return value.

### Common setup

1. Store the address-producing value’s low 16 bits at that value plus `0x30`.
2. Multiply the scale selector by `0x02000000`; store the resulting 32-bit value at that value plus `0x40`.
3. Write a zero byte at the descriptor base.
4. Write the accumulator as a 32-bit word at the descriptor base.
5. Write word `0x40` at descriptor offset `0x28`.
6. Write the descriptor-base address as a 32-bit word at descriptor offset `0x2c`.

The byte store and following word store are separate accesses, notwithstanding their overlap.

Next:

- Add the current read-cursor address, the incoming stack-associated pointer value, and 8.

### Repeating-region entry

Each arrival at this entry performs:

1. A zero-byte write at the data cursor.
2. A halfword write of the displacement’s low 16 bits at the same address.
3. A word write of the pending word at the same address.
4. Addition of the working word to the accumulator.
5. A word write of the updated accumulator through the second write cursor.

All four stores remain distinct operations, including when their destinations overlap.

Inner processing begins with call argument zero. Initially, the working word is seed-derived. Later arrivals use the working state established by extended processing.

### Inner processing

Each iteration performs the following sequence:

1. Retain the working word’s low byte.
2. Invoke F-67c083ed1a95 at control base plus `0xa1e`, passing the current argument.
3. Split its 64-bit result into low and high 32-bit halves.
4. Write the low half’s low 16 bits at the address represented by that low half.
5. Multiply the displacement by `0x40`; write the product as a word at the address equal to the product.
6. Fetch a word through the current read cursor, replacing the working word.
7. Write a halfword at displacement plus 4. Its value is the old read-cursor address plus 4, truncated to 16 bits—not the fetched data.
8. Read a word at the first call result’s high half plus `0x50`; replace the read cursor with that word.
9. Invoke F-c15bd8e06472 without an explicit argument.
10. Invoke F-8e4a237fd190 without an explicit argument.
11. Invoke F-50b6e2a79c43 with the fetched working word.
12. Invoke F-d3f049a8b671 with that word logically shifted right by three.

The last call is the fifth invocation in the iteration. Its 64-bit result supplies:

- High half: the new data cursor.
- Low half multiplied by `0x20`: the new pending word.

The pending word is written as a word at the address equal to its value before being compared unsigned with `0x14`.

If below `0x14`, inner processing restarts with argument zero and control base `0x0897edf1`. Repeating-entry stores are not repeated. The fetched working word remains loop-carried state; its low byte is retained at the start of the next iteration.

With 32-bit modular multiplication, the pending word is a multiple of 32. It is below `0x14` exactly when zero, which occurs whenever the returned low half’s low 27 bits are zero.

3. Replace the working word with displacement shifted left by two.

5. Invoke F-04e196b7ca28 with the read cursor logically shifted right by two.

2. Write the high half’s low byte at low-half address plus 8.
3. Write the current data cursor as a pointer-valued 32-bit access at twice the current accumulator, under the represented 32-bit pointer model.
4. Write the complete 64-bit result at the low-half address.

Then:

- Replace the accumulator with the data cursor shifted left by two.
- Replace displacement with the read cursor shifted left by eight.
