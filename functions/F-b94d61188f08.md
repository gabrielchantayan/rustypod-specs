# F-b94d61188f08

## Purpose

F-b94d61188f08 conditionally returns an address derived from a fixed internal anchor and a stored displacement.

A null second argument, or a second argument whose first character is zero, bypasses an external decision operation. Otherwise, that operation receives the second argument and the internal anchor. A nonzero result causes F-b94d61188f08 to return a null pointer. A zero result permits address construction.

This is an address-selection contract, not an established string-validation, lookup, or allocation contract. The meaning of the anchor, displacement, and external decision is unknown.

## Interface

### Inputs

1. **First argument:** an opaque 32-bit value.
   - The supplied body does not inspect this value, pass it to the dependency, or incorporate it into the result.
   - No pointer interpretation or ownership obligation is established for it.

2. **Second argument:** a nullable pointer to character storage.
   - Null is explicitly supported.
   - A nonnull pointer is dereferenced to inspect its first character.
   - If that character is nonzero, the pointer is also passed to the external dependency.
   - The visible body does not establish that the storage is a complete zero-terminated string, nor how much storage the dependency may access.

### Output

The function returns a pointer with no established object type or extent:

- A null pointer when the external decision operation returns nonzero.
- Otherwise, the address obtained by adding the stored displacement to the fixed internal anchor.

The second case is not independently guaranteed to produce a nonnull, valid, readable, writable, or suitably aligned pointer.

## Behavior

### 1. Classify the second argument

The function first determines whether the second argument is null.

- If null, it does not read through that pointer.
- If nonnull, it reads the first character from the pointed-to storage.

Only the first character is directly inspected by F-b94d61188f08. There is no visible traversal or direct read of a second character.

For a nonnull argument, readable storage for the first character is a precondition for this direct inspection. An invalid nonnull pointer is not converted into an ordinary rejection result.

### 2. Decide whether to call the dependency

The decision dependency is called exactly once if both conditions hold:

- The second argument is nonnull.
- Its inspected first character is nonzero.

The dependency receives, in order:

1. The second argument’s pointer value.
2. The fixed anchor address.

The dependency is not called for a null pointer or for a nonnull pointer whose first character is zero.

Any mutation of the first character by the dependency occurs after the character inspection that selected this branch. The visible body does not inspect that character again.

### 3. Handle the dependency result

When called, the dependency’s result is tested only for zero versus nonzero.

- **Nonzero:** return a null pointer immediately.
- **Zero:** continue to address construction.

The function exposes no distinction among different nonzero results. The exact result width and signedness are not established; the visible comparison does not depend on distinguishing positive from negative values.

If the dependency fails to return normally, the body supplies no visible recovery behavior. It does not establish exception handling, signal handling, fault translation, or cleanup.

### 4. Construct the accepted result

Address construction occurs on any of these paths:

- The second argument is null.
- Its first character is zero.
- Its first character is nonzero and the dependency returns zero.

On these paths, the function reads the stored displacement and adds it to the anchor address. It returns the resulting address without a visible bounds, alignment, nullness, or object-validity check.

For the dependency-call path, the displacement read occurs **after** the dependency returns zero. Its value must not be treated as a pre-call snapshot. If the dependency changes the displacement, the later read can observe that changed state.

On the dependency-rejection path, the visible body returns before reading the displacement.
