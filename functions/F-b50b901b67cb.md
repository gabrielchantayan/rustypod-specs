- The origin’s bit pattern participates as an unsigned value.
- Adding seven is modulo \(2^{32}\).
- The resulting start is always divisible by eight.
- An already aligned origin remains unchanged, except that interpretation of a negative origin as a signed address is not supplied by this function.
- Inputs near the top of the unsigned range can wrap to zero.

Thus, this is upward alignment in ordinary nonwrapping cases, not a guarantee that the unsigned result is numerically at least the input.

### 2. Derive the endpoint and span

The endpoint calculation first adds origin and extent, then clears the sum’s low three bits with 0xFFFFFFF8. The span is obtained by subtracting the previously calculated aligned start from that masked endpoint.

There is an important arithmetic distinction:

- The upward-alignment expression includes an unsigned constant in the addition.
- The endpoint expression presents the addition of two signed integer inputs before applying an unsigned mask.

Consequently, signed overflow in the endpoint addition cannot be assigned a portable meaning from the supplied representation alone. A wrapping machine implementation is possible, but it is not established here as a guaranteed contract.

Where the endpoint addition is defined, masking produces an unsigned value. The subsequent subtraction therefore has unsigned 32-bit behavior in the represented expression. If the endpoint is below the aligned start, the subtraction underflows modulo \(2^{32}\); there is no explicit clamp to zero.

The span is then stored in a slot represented as a signed integer. An unsigned result outside the signed range introduces a conversion question under a language-level interpretation. For such cases, this contract distinguishes the unsigned subtraction value from any unverified signed interpretation of the stored word.

For ordinary, nonwrapping inputs whose masked endpoint is at least the aligned start, the span is a nonnegative multiple of eight. It describes the distance between the two aligned boundaries. It does not include a leading or trailing partial eight-byte unit.
