## Acceptance examples

These are conditional static criteria, not executed tests. Later progression assumes returning dependencies and valid accessed storage.

1. **Distinct entry reads.** If the first entry-global read yields 10 and the second yields 20, input offset `0x00` receives 20 and offset `0xA4` receives 310. The entry gate is read afterward. Equal loaded values are permitted but not required.

2. **Entry rejection preserves prior writes.** A nonzero entry gate causes F-282eebd7c413, followed by F-feee9156a257 if the first call returns. Both entry writes precede this branch; the resolver is not reached.

3. **Later globals remain fresh.** If a dependency changes the intermediate-marker global before its assignment, that assignment uses the later read. If the service lookup changes the notification global, notification uses the value read after that lookup.

4. **Association table replacement.** If entry `0x80` returns the related object and changes the associated object’s table from T to U, entry `0x7C` resolves through U.

6. **Retained iteration output.** If one nonzero iteration result writes valid object X and the next nonzero result leaves the slot unchanged, X receives dispatch entry `0x04` on both iterations, provided it remains valid.

7. **Unestablished output is unresolved.** If the first nonzero iteration result occurs without any operation establishing the slot, neither a null skip nor valid dispatch is guaranteed.

8. **Null output is not termination.** A nonzero result with an established zero slot skips dispatch and repeats the call. A zero return ends iteration without slot inspection and leads to context finalization.

9. **Fresh service determines clearing.** If one service’s `0x24` field matches the related object but the next lookup returns another service, the second service receives the zero write.

11. **Final consistency check is gated by initial attachment.** An initially zero attachment skips the consistency check even if offset `0x08` is nonzero. An initially nonzero attachment that F-c719314a16bb clears skips dispatch but still reaches the consistency check.
