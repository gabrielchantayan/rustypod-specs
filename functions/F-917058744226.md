# F-917058744226

## Purpose

F-917058744226 performs a conditional dispatch based on two byte-sized observations obtained through dependencies.

The first observation is compared with a caller-supplied 32-bit unsigned selector. Only when that comparison succeeds does the function obtain and inspect the second observation. If the second byte is zero, the function invokes a final dependency and returns its 32-bit result. Otherwise, it returns the fixed 32-bit value 2.

A separate dependency is called with the address of a temporary four-byte storage slot before either normal return path completes. This establishes a common completion step, but does not establish that the dependency frees memory, releases a reference, or performs any particular cleanup operation.

The semantic meanings of the selector, the two observed bytes, and the value 2 are not established. Descriptions such as “lookup,” “secondary result,” and “completion” below distinguish observable roles without asserting application-level intent.

- **First argument:** an opaque 32-bit value. The visible body does not read it, forward it, or use it in a branch.
- **Selector:** a 32-bit unsigned integer. It is compared against the unsigned value of one byte read from an address-valued dependency result.

### Output

## Behavior

### Initial operation and first observation

The function first initializes the temporary slot to the four-byte value zero.

It then calls F-061d5c1fbc1d with:

- A literal zero as the first argument.
- The address of the temporary slot as the second argument.

After that call returns, the function reads the byte at offset 12 from the returned base address. There is no visible null check, result validation, or alternative path before this read.

The byte is treated as unsigned and compared numerically with the entire 32-bit unsigned selector. This is an equality comparison, not a masked comparison.

If the values differ:

- F-1ec05f1e044b is not called.
- No second-result byte is read.
- F-3e371ea4ac82 is called with the address of the temporary slot.
- After that call returns, the function returns 2.

Even an out-of-range selector does not bypass the initial dependency or the first byte read. The visible comparison occurs only after both have taken place.

### Conditional second operation

If the first byte equals the selector, the function calls F-1ec05f1e044b with:

- The original result from F-061d5c1fbc1d as its first argument.
- A literal zero as its second argument.

The subsequent byte read uses the result of F-1ec05f1e044b as its base address. The function does not instead assume that the original base remains the relevant address.

It reads the byte at offset 8 from this second base and tests whether the byte is zero. No visible validation precedes this read.

The zero test does not depend on whether the byte is interpreted as signed or unsigned: zero passes, and every nonzero byte fails.

If the byte is nonzero:

- F-3e371ea4ac82 is called with the address of the temporary slot.
- After that call returns, the function returns 2.
- F-a16e3cb9c0ab is not called.

### Final dispatch

If the first comparison succeeds and the second byte is zero:

1. F-3e371ea4ac82 is called with the address of the temporary slot.
2. Only after that call returns, F-a16e3cb9c0ab is called with one literal-zero argument.
3. The function returns the complete 32-bit result of F-a16e3cb9c0ab.

The ordering is material. Any state changes made by F-3e371ea4ac82 occur before the final dependency executes. The contract does not assume that this completion call preserves globals or other state visible to F-a16e3cb9c0ab.

### Normal-path invariants

Provided all required reads are valid and every invoked dependency returns normally:

- F-061d5c1fbc1d is called exactly once.
- The byte at offset 12 from its result is read exactly once by this body.
- F-1ec05f1e044b is called exactly once if, and only if, the first comparison succeeds.
- The byte at offset 8 from the secondary result is read exactly once if that secondary dependency returns.
- F-3e371ea4ac82 is called exactly once before returning.
