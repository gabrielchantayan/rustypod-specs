# F-6553396a9252

## Purpose

F-6553396a9252 defines a repeating interaction with unresolved external functions and memory. Its observable behavior consists of ordered calls, byte publications, 32-bit publications, two 32-bit reads, and replacement of state used by the next repetition.

The supplied static evidence does not establish an application-level purpose. Terms such as “selector,” “payload,” and “publication” below describe observable roles only. They do not imply objects, valid buffers, device registers, allocation, or ownership.

The central contract is **ordered, nontransactional publication**: reads and writes remain distinct events even when their addresses coincide. Calls occur between many of those events, so a later read cannot generally reuse an earlier value.

All arithmetic conclusions involving truncation are conditional on the 32-bit machine interpretation described below. No runtime tests have been performed.

## Interface

### Explicit arguments

| Argument position | Width | Role |
|---|---:|---|
| First | 32 bits | Passed to the entry dependency on every repetition; replaced by a dependency result at the repetition boundary. |
| Second | 32 bits | Passed with the first argument; later replaced by a dependency result, published in scaled form, and transformed for the next repetition. |
| Third | 32 bits | No explicit consumption in the supplied body. |
| Fourth | 32 bits | Determines an early word destination and an early dependency argument; replaced at the repetition boundary. |

The third argument’s lack of explicit use does not establish that unresolved machine-level callees cannot observe the surrounding argument state.

### Additional effective inputs

The initial repetition requires incoming state beyond those four arguments:

- A continuation-related value that determines the first indirect target.
- A 32-bit address-like base used for selector reads.
- A 32-bit state value used to construct payloads and call arguments.
- An eight-bit value used by the first byte publication.

A further value is obtained from an additional result register associated with an intervening call. Its production is not described by that call’s displayed return type. It must not be treated as an independently established entry argument.

The routine also consumes one global storage value as a 32-bit read. The supplied evidence warns that this storage overlaps smaller symbols; its relationship to other accesses is unresolved.

### Results, progress, and preconditions

There is no represented normal return, result value, completion status, or local error result. If every call returns and every memory access completes, repetition continues indefinitely.

Progress requires executable indirect targets and accessible memory for every actual address reached. There are no local checks establishing those conditions. Endianness, alignment requirements, memory permissions, and fault handling are documented_only.

No argument grants ownership of memory. No allocation, release, or ownership transfer is explicitly established.

### Width conventions

A byte is eight bits; a word is 32 bits. Selector reads are unsigned and therefore yield values from 0 through 255. Byte publications retain only eight bits. A displayed 64-bit result is consumed as separate low and high 32-bit halves where specified.

For the conditional machine interpretation, calculations retain their low 32 bits, including address calculations. This is not a claim that signed-looking operations in the representation have defined high-level-language behavior.

Two recurring address conventions are important:

- **Selector publication:** read one byte at a specified source address, then write at absolute address **selector + 17**. The destination is between 17 and 272; the source base is not added again.
- **Indexed word publication:** write four bytes beginning at an index-dependent address, usually **4 × index + 20** or **16 × index + 20**.

A selector retained for one later word publication instead selects absolute address **selector + 20**, between 20 and 275.

## Behavior

### Repetition-wide obligations

Each complete repetition contains, as explicitly represented:

- Ten selector-byte reads.
- Fourteen byte writes, including four direct clears that do not use selectors.
- Thirteen word writes.
- One indexed word read and one global word read.
- Numerous ordered external calls.

These counts exclude accesses performed inside dependencies. They apply only when execution reaches the repetition boundary without interruption.

The sections below specify publication order and the required call relationships. Calls described as intervening remain observable events even where their arguments or results have no further explicit use. They cannot be removed, combined, or assumed effect-free.

### Entry and initial payload

The entry dependency receives the current first and second arguments. Several additional calls precede the first publication.

The first selector source is the incoming address-like base plus 1. The incoming byte is written to the selected absolute destination. A dependency then receives four times a previously obtained 32-bit result.

The **initial payload** is the incoming 32-bit state shifted left by 12. Its first word publication starts at **4096 × fourth argument + 20**. A subsequent dependency receives the fourth argument shifted left by 14.

After an intervening call, a two-input dependency receives:

- The initial payload shifted left by 28.
- The additional call-result-register value described in the interface.

Under low-32-bit arithmetic, the first argument is zero: the payload already has its bottom 12 bits cleared, and the further shift discards every remaining bit.

After further calls, a returned index selects the initial payload’s second word publication at **4 × index + 20**. A dependency then receives that index multiplied by four.

The two publications remain separate writes if their addresses happen to coincide.

### Early selector publications and secondary payload

A later result supplies an **early index**. Its fourfold value is retained.

The original selector source is read again. The selected destination receives the low byte of the initial payload after masking to its bottom 30 bits and shifting right by 20. The intermediate extraction is ten bits wide, not eight; truncation occurs at the byte publication.

The following dependency relationships are established in order:

- One call receives the incoming state shifted left by 24.
- A returned 32-bit value is paired with the retained fourfold early index shifted left by 28.
- A later 64-bit result is passed onward as low-half and high-half arguments.

Following additional calls, the original selector source is read a third time and its selected destination receives zero. A dependency then receives four times another returned result.

A subsequent returned value, multiplied by four, becomes the **secondary payload**. Its first word publication begins at **4096 × retained fourfold early index + 20**.

The associated four-input dependency receives, in order:

| Position | Value |
|---|---|
| First | Retained fourfold early index multiplied by 1024 |
| Second | The same value |
| Third | Unscaled early index shifted left by 14 |
| Fourth | Secondary payload |

The first and third arguments are not equivalent: expressed from the unscaled early index, their multipliers are respectively 4096 and 16384.

After further calls, a fresh index selects the secondary payload’s second publication at **4 × index + 20**, followed by a call receiving four times that index.

### Two paired word-publication groups

Two successive groups publish independently obtained values. Each has these observable obligations:

- A result supplies an originating index.
- Four times that index is written at **16 × originating index + 20**.
- A dependency receives three copies of that fourfold value.
- Following intervening calls, a separate returned index selects another word destination at **4 × returned index + 20**.
- The same retained fourfold value is written there.
- A dependency receives four times the second index.

Neither the indices nor the values are shared between the two groups merely because the pattern repeats.

The originating index of the second group also determines a **high-region base**, equal to that index multiplied by \(2^{30}\) under the conditional 32-bit interpretation. Only its bottom two bits affect that base.

The second group’s later destination index is retained separately. Its parity determines a subsequent word value; it is not interchangeable with the originating index.

### Direct clears and indexed consumption

Following another returned result, two direct byte writes clear:

1. High-region base + 17.
2. High-region base + 1.

These are direct addresses, not selector-derived destinations. A dependency then receives the returned result multiplied by four. A subsequent returned value is forwarded through another call.

After intervening calls supply a fresh result, the same two direct clears occur again, in the same order. A dependency receives the fresh result multiplied by four.

A later result supplies a **late index**. The next word publication begins at **16 × late index + 20**. Its value is the retained second group’s later destination index shifted left by 31. Under 32-bit truncation, this publishes either zero or 0x80000000, according to that retained index’s parity.

Only after this store does the indexed word read occur. Its starting address is:

**20 + the bottom-30-bit portion of the result obtained before the first direct-clear pair, shifted right by 20.**

The extracted component is between 0 and 1023, giving starting addresses 20 through 1043. Word alignment is not guaranteed. Overlap with the immediately preceding store can affect the loaded value.

A dependency receives four times the late index. Another call replaces the current second argument. The loaded word is then used to supply a dependency argument obtained by shifting right by 22 and then left by 28. Under 32-bit truncation, only loaded bits 22 through 25 contribute.

After further calls, a fresh returned index selects a zero-word publication at **4 × index + 20**, followed by a call receiving that index multiplied by four.

### Retained selector and second-argument publication

A later 32-bit result supplies the next two selector-based publications:

| Publication | Selector source | Byte value |
|---|---|---|
| First | High-region base + 1 | Low byte of four times the result |
| Second | High-region base + 1, read again | Low byte of its bottom-30-bit portion shifted right by 20 |

Between these publications, a dependency receives the full fourfold result. A later returned value is paired with the original result shifted left by 30. Additional calls precede the second selector read.

The second selector is retained. After its byte publication and further calls, a word containing the current second argument shifted left by two is written at **retained selector + 20**. There is no new selector read for this word store.

The global 32-bit read follows that store and precedes the next call sequence. Therefore, if the store overlaps global storage, the global read observes memory after the store, subject to the unresolved target’s memory semantics.

### Global-derived byte and later payload

A dependency receives four times the retained late index. Following additional calls, a 64-bit result supplies:

- A **carried index**, equal to four times its low half.
- A high half that is passed to a dependency.

Before forwarding the high half, the routine rereads the selector at high-region base + 1. Its selected destination receives the low byte of the already-read global value shifted right by 22. Thus the publication uses global bits 22 through 29, not a fresh global read.

A subsequent returned value is paired with the carried index shifted left by 28.

After more calls, another read of the high-region selector selects a zero-byte publication. Further dependency activity includes a call receiving two copies of a returned value multiplied by four.

A later returned value, multiplied by four, becomes the **later payload**. Its two word publications are:

| Order | Destination | Associated subsequent call |
|---|---|---|
| First | 4096 × carried index + 20 | Carried index shifted left by 14 |
| Second | 4 × a fresh returned index + 20 | Four times that fresh index |

Intervening calls remain between these publications.

### Final publications and state transition

A subsequent 64-bit result supplies a **final scaled value**, equal to four times its low half.

A selector read at **16384 × carried index + 1** selects publication of the low byte of the later payload’s bottom-30-bit portion shifted right by 20. The 64-bit result’s high half is then passed to a dependency.

Further call relationships include forwarding a 32-bit result alone and forwarding another 64-bit result as its low and high halves.

The final scaled value determines a **final region base** by multiplication by \(2^{28}\). Equivalently, under 32-bit arithmetic, this is the original low half multiplied by \(2^{30}\). A selector read at final region base + 1 selects a zero-byte publication.

Following more calls, the boundary transition establishes:

| Next-repetition state | Established value |
|---|---|
| Incoming 32-bit state | Four times a newly returned result |
| Incoming address-like base | Four times the final scaled value |
| Fourth argument | The new incoming 32-bit state |
| First argument | Result of the final dependency call |
| Second argument | Current second argument shifted left by 28 |
| Incoming byte | Zero |

Before the final two dependency calls, the new address-like base plus 1 supplies a selector for another zero-byte publication. The penultimate call receives the final scaled value shifted left by 10; the last supplies the next first argument.

The continuation-related state is also replaced with a fixed represented value before repetition resumes. The next entry target therefore no longer depends on the original incoming continuation state.

## Side effects

All publications are partial, ordered effects, not a transaction. There is no rollback if a later call or access fails.

Aliasing is unrestricted by the supplied evidence:

- A byte publication can change a future selector.
- Word writes can overlap selector sources or byte destinations.
- Word destinations can overlap each other.
- Low absolute destinations can overlap the indexed read or global storage.

Repeated reads must remain fresh except for the explicitly retained selector and already-loaded word and global values. In particular, the direct clears do not prove that later selectors remain zero: intervening dependencies may modify them.

No hardware atomicity, synchronization, concurrency safety, or visibility barrier is established.

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Absolute selector addressing.** A selector value of 7 selects byte address 24, regardless of the selector source’s base.

2. **Fresh versus retained selectors.** If a dependency changes a selector from 7 to 9, a required reread selects address 26. A previously retained selector of 7 still selects word address 27.

3. **Byte and word widths.** A scaled result of 260 publishes byte value 4, while its full-width dependency argument remains 260.

4. **Ten-bit extraction.** An initial payload of 0x12345000 produces extraction 0x123 and publishes byte 0x23. Treating the intermediate result itself as eight bits would lose established width information.

5. **Distinct four-input arguments.** For early index 1, the four-input call’s first two arguments are 4096 each; its third is 16384.

6. **High-region bases.** Originating indices with bottom bits 0, 1, 2, and 3 select bases 0x00000000, 0x40000000, 0x80000000, and 0xC0000000.

7. **Parity publication.** An odd retained second-group destination index produces 0x80000000 at the late-index word destination. An even retained index produces zero.

8. **Loaded-word projection.** A loaded word of 0x00400000 produces dependency argument 0x10000000. A loaded word of 0x04000000 produces zero after the two shifts under 32-bit truncation.

9. **No implied stable global.** A dependency changing global storage after the global read does not replace the already-captured value used by the global-derived byte publication.

10. **Repetition boundary.** If the final 64-bit result’s low half is 3, the final scaled value is 12 and the next address-like base is 48. The boundary selector source is address 49.

11. **No finite success condition.** Completion of all publications in one repetition leads to another entry call, not normal return.
