### Selection after the first dependency returns

**When the original third input is nonzero:**

- The selected value is the original fourth input.
- A change to the temporary middle field does not alter that selection.
- A change to the temporary final field does not, by itself, replace the selected original fourth input.

**When the original third input is zero:**

- The selected value is the current 32-bit contents of the temporary field at offset 4.
- This field initially contains zero.
- If F-ccabec065f5e changes that field, the changed value is selected.
- If that field remains unchanged, zero is selected.
- The original fourth input is not used as a fallback when the middle field remains zero.

The zero comparison is an exact comparison against the original third input. Negative and positive nonzero values take the same branch.

This is not a rule that selects the middle field whenever its post-call contents are nonzero. The post-call contents do not determine the branch.
