## Acceptance examples

These are conditional static criteria, not observed execution results.

1. **Zero reduced index.** With first argument 168, the unsigned difference, halfword base, and reduced index are zero. The initial index-byte store carries zero. Successful execution is not implied; later operations include low-address accesses and unresolved destinations.

2. **Narrow versus full index.** With first argument 750, the unsigned difference is 582 and the reduced index is 0x123. Index-byte expressions carry 0x23, while full-width index stores carry 0x00000123, if reached.

3. **Offset-zero read.** With non-aliasing destinations and successful preceding accesses, halfword writes occur at offsets four, six, and two before the offset-zero read. Substituting 0xFFFF for that read is unjustified.

4. **Negative dependency value.** If the first dependency value is negative as signed 32-bit data, the secondary-base offset-four halfword store occurs before the early termination marker. The displayed nonnegative-path operations do not follow.

5. **Signed halfword propagation.** Assuming arithmetic right shift, a loaded halfword of 0x8000 produces 0xFFFFFFFF at secondary-base offset eight; 0x7FFF produces zero.

6. **Three-byte concatenation.** If the byte read for the incoming-pointer-phase composite is 0xAB, its numeric result is 0x000005AB, before any destination-width conversion.

7. **Scaled-pointer reread.** If the first indirect scaled-pointer store changes the scaled-pointer global to a different readable value, the subsequent index-store destination is derived from that new value plus four. Retaining the originally assigned scaled pointer for both writes would violate the displayed behavior.

8. **Late upper-halfword read.** If intervening writes change the upper-halfword global’s consumed 16-bit operand to 0x1234, the final composite expression is 0x1234EA70, regardless of the operand originally assigned there.

9. **Invalid incoming pointer.** No explicit validation rejects it. If its first dereference is reached, access failure follows environment rules rather than a visible error-return protocol.
