# F-118ba0cf6531

## Purpose

The Boolean contribution depends exclusively on whether the fourth argument is nonzero. A nonzero fourth argument forces bit 0 of the final first element to one. A zero fourth argument leaves the supplied first value unchanged. Neither case clears any bit already set.

## Behavior

### Final values

The fourth argument is compared with zero. This comparison contributes exactly:

- Zero when the fourth argument is zero.
- One when the fourth argument is nonzero.

The final value of destination element 0 is the bitwise inclusive OR of the second argument and that zero-or-one contribution. The final value of destination element 1 is the third argument.

The comparison applies to the fourth argument before its result participates in the bitwise combination. The combined result is not reduced to a Boolean value. Thus, a supplied first value of eight with a zero flag source produces eight, not one.

Every representable nonzero flag source has the same effect. Positive and negative nonzero values are not distinguished. Neither the magnitude nor the other bits of the flag source are copied into the destination.

Consequently:

- A zero flag source preserves every bit of the supplied first value.
- A nonzero flag source can change only bit 0.
- If bit 0 is already one, the final first element equals the supplied first value for either flag condition.
- The third argument does not participate in calculating the final first element.
- No addition, increment, carry propagation, or saturation occurs.
- A maximum representable unsigned first value remains unchanged for either flag condition.

### Assignment order and reads

1. Element 0 receives the second argument, the supplied first value.
2. Element 1 receives the third argument, the supplied second value.
