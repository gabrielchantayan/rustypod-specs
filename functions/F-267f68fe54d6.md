# F-267f68fe54d6

## Purpose

F-267f68fe54d6 selects an integer value using an input-associated field and, conditionally, two fields in a dependency-provided context.

For stable memory, the selection priority is:

1. The input-associated field at byte offset 4, if nonzero.
2. The context field at byte offset 0xF44, if nonzero.
3. The context field at byte offset 0xF48, if nonzero.
4. Zero.

That priority summary is not the complete access contract. The function always calls F-8ff48652068d before inspecting the input-associated field. It also reads the input-associated field again on paths that do not return a nonzero context value. Consequently, when memory changes during execution, the result need not equal the value from the first input-field read.

The established behavior is selection based on zero versus nonzero. The meanings of the fields—such as whether they represent status, configuration, identifiers, or addresses—are unknown.

## Interface

**Input:** One integer-valued argument used as the base address of an object. The function accesses an integer field beginning four bytes after that base address.

**Dependency result:** F-8ff48652068d supplies a value used as the base address of a context. Depending on the input-field value, the function may read integer fields beginning at context offsets 0xF44 and 0xF48.

**Output:** One integer value, taken from a field read during the invocation. There is no separate success indicator, error object, or out-parameter in the supplied evidence.

## Behavior

### 1. Invoke the dependency first

F-267f68fe54d6 invokes F-8ff48652068d once, with no explicit arguments.

This invocation precedes the first input-field read, including when the input field would otherwise provide a nonzero result. An implementation that skips the dependency because it expects the input field to be nonzero would not preserve the established call behavior.

The returned value is retained as the context base for any context accesses performed during this invocation. The function does not reacquire that base.

Because the dependency’s behavior is unavailable, the first input-field read must be understood as observing memory after the dependency returns. The contract does not assume that F-8ff48652068d preserves the input object, global state, or any previously existing context contents.

### 2. Read the input field to choose a path

After the dependency returns, the function reads the integer field at input offset 4 and compares it with zero.

If this first read is nonzero:

- Neither context candidate is read.
- Execution proceeds to a fresh read of the input field.
- That fresh read supplies the return value.

The initial nonzero value is therefore a branch condition, not necessarily the returned value.

If the first input-field read is zero, execution proceeds to the context candidates.

### 3. Consult the first context candidate

The function reads the integer field at context offset 0xF44.

If this value is nonzero, it is returned directly. On this path:

- The field at context offset 0xF48 is not read.
- The input field is not read again.
- The returned value is the captured first context candidate.

No comparison with the second candidate occurs.

### 4. Consult the second context candidate only if needed

If the first context candidate is zero, the function reads the integer field at context offset 0xF48.

If the second candidate is nonzero, it is returned directly. The input field is not read again on this path.

If both context candidates are zero, neither candidate supplies the result. Execution proceeds to the final input-field read.

### 5. Perform the final input-field read where required

A fresh read of the field at input offset 4 supplies the result in exactly two cases:

- The initial input-field read was nonzero.
- The initial input-field read and both context candidates were zero.

This final read is distinct from the initial input-field read in the supplied representation.

With stable memory, the first case returns the nonzero input value and the second returns zero. With permitted intervening changes, either case can return a different value. The final value is returned without another zero test or another attempt to consult the context.
