# F-6e4cfd15765d

## Purpose

F-6e4cfd15765d describes an ordered sequence of indirect calls, computed-address memory accesses, byte truncations, scaled-word writes, and clears. Four distinct word stores clear absolute address `0x00000024`.

The available static representation does not establish an application-level purpose. Initialization or reset is a possible interpretation of some writes, not an established contract.

The represented path ends at an invalid-instruction boundary. Ordinary return, successful completion, and a recoverable error result are not established.

Direct byte accesses are 8 bits. Loaded selector bytes are unsigned. Byte stores retain only the low eight bits of their value. Direct word accesses are 32 bits. F-D014 and F-D134 produce represented 64-bit results, separated numerically into low and high 32-bit halves.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. They assume the relevant execution prefix is reachable, dependencies return, accesses are permitted, and the stated arithmetic model applies.

1. **Upper-bit dependence.** Changing only the fourth argument’s low 25 bits leaves \(T\), \(A\), and their directly derived calculations unchanged. Whole-function equivalence is not established if dependencies observe other machine state.

2. **Word-to-byte truncation.** If the word read after F-D007 is `0x123456AB`, the following byte store writes `0xAB`, not four bytes.

3. **Preserved additional-output dependency.** If represented \(E=3\), the early word-store address is `0x20`; the store after F-D019 receives `0x18`. Intervening calls do not create a separately assigned represented value.

4. **Independent selectors.** If the reads after F-D034 and F-D039 yield `0x20` and `0x30`, their selected-byte destinations are `0x31` and `0x41`.

5. **Packed truncation and fresh forwarding.** If \(r_{34}=\texttt{0x3FF00000}\), the packed-byte write after F-D039 stores `0xFF`. If independently \(r_{39}=7\), F-D040 receives 28.

6. **Conditional arithmetic collapse.** For every permitted \(T\), the store preceding F-D025 writes zero at `0x14`, and F-D025 receives three zeros.

7. **Late call operands.** If \(r_{180}=5\), F-D181 receives 20. If \(r_{187}=9\), F-D188 receives 36 regardless of the packed value just stored. F-D200 similarly receives four times \(r_{199}\), not four times \(r_{192}\).

8. **Distinct absolute clears.** A dependency between two absolute clears may observe or modify `0x24`; the later clear still occurs if execution reaches it.

9. **No successful-return criterion.** Reaching the visible invalid-instruction boundary is not evidence of ordinary completion.
