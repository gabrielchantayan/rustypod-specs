# F-28fd04957d82

## Purpose

F-28fd04957d82 selects and returns one of two 32-bit values stored within a caller-supplied memory region. Selection depends exclusively on the least significant bit of a byte at a third location in that region.

The established behavior is a field-selection operation. The supplied evidence does not establish what the memory region represents, what either candidate value means, or why the selector chooses between them. In particular, neither candidate is established to be a pointer, handle, status code, signed number, or owned resource.

## Interface

The function accepts one argument that supplies the base address for three fixed-offset memory accesses:

| Offset from base | Access width | Role |
|---|---:|---|
| `0x5F8` | 8 bits | Selector byte; only bit 0 determines the branch |
| `0x5E8` | 32 bits | Candidate returned when selector bit 0 is clear |
| `0x2F0` | 32 bits | Candidate returned when selector bit 0 is set |

Offsets are byte offsets. The 32-bit fields occupy byte ranges `0x5E8`–`0x5EB` and `0x2F0`–`0x2F3`, respectively.

The supplied representation exposes the argument as an integer used to form addresses. It does not independently establish a portable pointer type, a calling convention, or the full address-width rules of the execution environment. Callers must supply a base for which the required address calculations and accesses are valid.

### Output

The function returns the complete 32-bit value read from the selected candidate location.

Selection does not truncate, mask, normalize, or otherwise transform that value. All 32 bits of the selected field contribute to the result. Signed interpretation and semantic type are not established.

No separate success indicator, error result, or output parameter is visible.

## Behavior

### Selection and read order

The established logical access sequence is:

1. Read the 8-bit selector at offset `0x5F8`.
2. Inspect its least significant bit.
3. Read exactly one of the two 32-bit candidate fields.
4. Return the value obtained from that selected read.

The selection rule is:

| Selector condition | Selected field |
|---|---|
| Bit 0 is clear | Offset `0x5E8` |
| Bit 0 is set | Offset `0x2F0` |

Bits 1 through 7 do not influence selection. The condition is not a test of whether the entire byte is zero: a nonzero byte with bit 0 clear still selects offset `0x5E8`.

The selector is not returned. Neither is it combined with the chosen value.

### Widths and arithmetic

The candidate operation concerns a four-byte, 32-bit value. The function does not perform arithmetic on that value.

The fixed offsets are nonnegative. Their numerical sizes are established, but behavior when base-plus-offset addressing overflows, wraps, or produces an invalid address is not. No portable wrapping-address guarantee can be derived from the supplied representation.
