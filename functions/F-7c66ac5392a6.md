# F-7c66ac5392a6

## Purpose

F-7c66ac5392a6 examines a linked collection, selects candidates by event selectors and context, excludes candidates already present in an active-frame chain, and invokes dependencies for each remaining candidate.

Its explicit return values are:

- **0:** traversal encountered a null candidate pointer, including an initially empty collection.
- **1:** selected-candidate processing encountered either a nonzero context flag or a nonzero result from F-efc2c252d6ce.

Returning 0 does not establish that a candidate matched or that downstream processing succeeded. Returning 1 does not distinguish its two causes.

Event dispatch, recursion suppression, and flag accumulation are inferred intent. The contract below establishes the visible selection, memory-access, call, and write behavior without assigning undocumented meanings to dependency operations.

## Behavior

### Entry and traversal

The routine first reads and retains the root address from argument 1. It initializes two local 32-bit unsigned accumulators to zero, then reads the initial candidate address from argument 5 at offset 0x20.

The accumulators occupy offsets 0x0C and 0x10 within the temporary active frame described below. They are initialized once per invocation, not once per selected candidate.

A null candidate leads directly to normal completion. Otherwise, the routine evaluates candidates in link order. Every non-early-exit outcome advances by reading the current candidate’s field at offset 0x28.

The next link is not captured before processing. Dependency changes to that field can therefore change subsequent traversal.

### Selector checks

The candidate’s byte at offset 0x08 is read first and compared with argument 2.

Only if it matches does the routine read the byte at offset 0x09 and compare it with argument 4. Failure of either comparison skips the remaining eligibility checks and selected-candidate processing.

Neither selector argument is dereferenced.

### Context check

After both selectors match, the routine reads the candidate’s words at offsets 0x1C and 0x20.

- Equal words pass the context check without further context-pointer traversal.
- Unequal words cause a read of the address at retained-root offset 0x08, followed by a 32-bit read at offset 0x2C of the referenced object. That value must equal the candidate’s word at offset 0x1C.

Failure skips the candidate. These are equality comparisons of 32-bit values; the candidate’s comparison words are not themselves dereferenced.

### Optional filter

Filtering is considered only when argument 2 numerically equals 100, after the selector and context checks have passed.

The routine then reads the candidate’s word at offset 0x10:

- Zero bypasses the filter.
- Nonzero causes F-53cdfd9c7606 to receive that word and argument 3.
- A zero low 32-bit component of the represented 64-bit result rejects the candidate.
- A nonzero low component permits further eligibility checking.

The high 32-bit component does not determine any subsequent selection or explicit output in the supplied body. Its representation does not establish that it is a usable address.

For other first-selector values, neither this filter-field check nor the filter call is performed.

### Active-candidate exclusion

The routine next reads the active-frame head from argument 1 at offset 0x188.

For each reachable nonnull frame, it compares the word at frame offset 0x1C with the current candidate’s address. Equality skips the candidate. Otherwise it follows the frame’s word at offset 0x20.

Exclusion uses address identity, not identifier or content equality. The optional filter runs before this scan, so it can have effects even when the candidate is subsequently excluded as active.

### Normal completion

1. If argument 10 is nonnull, read its 32-bit word, OR it with the accumulator at frame offset 0x10, and write the result.
2. If argument 11 is nonnull, read its 32-bit word, OR it with the accumulator at frame offset 0x0C, and write the result.

The second output read follows the first output write. If both pointers designate the same ordinary word, with no other relevant aliasing or intervening mutation, the final value is the original word OR both accumulators.

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Empty collection:** A null initial candidate returns 0 after the ordered optional output merges. With ordinary independent output words, both remain unchanged because both accumulators are zero.

2. **No selector truncation:** A candidate byte equal to 7 does not match argument 2 equal to 263. The second selector byte is not read on that path.

3. **Context shortcut:** Matching selectors and equal candidate words at offsets 0x1C and 0x20 pass context selection without following root offset 0x08.

4. **Filter rejection:** For selector 100 and nonzero filter input, a zero low result rejects the candidate before any active-frame scan, regardless of the high result component.

5. **Active identity:** An address match in the active chain prevents setup calls even if another candidate has the same identifier. Any preceding filter effects remain observable.

6. **Publication order:** At the routine’s head-publication write, frame offset 0x20 has been assigned the captured head, but the current candidate has not yet been assigned to frame offset 0x1C. The separate working-area first-word write precedes that candidate assignment.

7. **Flag-driven exit:** A nonzero root flag after setup suppresses F-efc2c252d6ce. The routine assigns the current frame link to the head, invokes F-841dc33ee157, and returns 1 without explicit output merges.

8. **Modified restoration link:** If a dependency validly replaces frame offset 0x20 with another address before either restoration assignment, that replacement is the assigned head value—not the originally captured address.

9. **Modified published head:** If a continuing-path dependency changes argument 1 offset 0x188, the contract does not require the temporary frame to remain head during later calls. The routine’s own restoration assignment still occurs after F-0b7a5bab86f2.

10. **Accumulator mapping:** Conditional on dependencies leaving offsets 0x0C and 0x10 equal to 0x04 and 0x20 respectively, normal completion ORs 0x20 into argument 10 and 0x04 into argument 11.

11. **Aliased outputs:** For one shared output word initially 0x01 and the accumulator values above, ordinary noninterfering memory ends at 0x25.

12. **Changed traversal link:** If processing validly changes the current candidate’s next pointer, traversal uses the changed value because the link is read afterward.
