# F-3b62d1544bb2

## Purpose

F-3b62d1544bb2 performs an ordered sequence of memory accesses, follows addresses obtained from word reads, and finishes with an unresolved indirect invocation.

The established behavior is a memory-access and invocation contract. The supplied static evidence does not establish an application-level purpose, object model, data format, or device protocol.

The initial phase contains one word store followed by exactly 25 repetitions of a four-store sequence: **101 represented stores in total**. Counts attributed to individual store expressions are not necessarily the total writes received by their addressed storage. Different expressions can address identical or overlapping bytes.

No explicit return value is established.

## Behavior

Exactly 25 repetitions then follow, each containing these four stores in this order:

| 2 | Secondary base + 0x19 | Byte | Low byte of primary base |
| 3 | Primary base + 0x11 | Byte | Low byte of secondary base |

There is no represented address progression between repetitions.

The **101-store total** comprises:

- One store attributable to the initial second-input store expression.
- Twenty-five stores attributable to each of the four repeated expressions.

Consequently, the expressions targeting secondary base + 0x34 account for **26 word stores**: the initial store and the fourth store of each repetition. Each other repeated expression accounts for 25 stores.

These are expression-attributable counts, not unconditional totals for the underlying storage. A word range can receive stores from multiple expressions, and byte destinations can overlap word destinations. Only when the four destination ranges are mutually nonoverlapping do these counts also describe the total initial-phase writes received by each range.

The phase ends with the fourth store of repetition 25. The second input has no subsequent captured-value use, but its initial write remains observable in access history and potentially in partial execution.

### Coincident word destinations

Let the primary base be **0x1000** and the secondary base be **0x2020**. Then:

- Doubled primary value + 0x54 is **0x2054**.
- Secondary base + 0x34 is also **0x2054**.
- The two byte destinations are **0x2039** and **0x1011**, outside that word range.

The word at 0x2054 therefore receives **51 initial-phase word stores**: one initial second-input store and two word stores per repetition.

Under ordinary memory semantics without external interference, each repetition writes the first input there and then writes 0x00002000 there. At the initial-phase boundary, the word contains 0x00002000. The total represented initial-phase store count remains 101.
