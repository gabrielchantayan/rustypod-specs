# F-d10f409786e9

It copies a shared 32-bit value into caller-supplied storage, clears two individual bytes, and passes an address eight bytes beyond the supplied base to the dependency. If the dependency returns normally, its result is used as the base address for three further 32-bit writes.

2. Stores a zero byte at input offset 4.
3. Stores a zero byte at input offset 5.
4. Calls F-48fbb57af1e7 with the address at input offset 8.

Assume:

- Input and result destinations do not overlap each other or either shared word.
- Shared word A equals `0x11223344` when initially accessed.
- The dependency preserves input offsets 0 through 5.
- Shared word B equals `0x55667788` **when accessed after the store of 2 at result offset 48**.

- Input offset 0 contains the 32-bit value `0x11223344`.
- Input offsets 4 and 5 contain zero bytes.

No byte-order claim follows from these value-level expectations.
