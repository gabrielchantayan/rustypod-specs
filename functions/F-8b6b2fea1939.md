The first phase invokes an external dependency with the ordered arguments zero and two whenever the observed integer is zero. The second phase invokes F-fceaba74ea88 with the current integer value plus twenty whenever F-28ec89c6f891 returns zero.

- A nonzero value ends the first phase immediately.
- A zero value causes a call to the unmapped external dependency, designated here by the local opaque label F-unmapped.
- That call receives two ordered integer arguments: zero, then two.
- After the call returns normally, the function reads the integer through the captured pointer again and repeats the decision.

### Second phase: query and conditional action

For each query:

- If the query result is nonzero, the function returns normally.
- If the query result is zero, the function reads the integer through the captured pointer.
- It adds twenty to that newly read value.
- It passes the sum as the sole visible argument to F-fceaba74ea88.
- After that call returns normally, it queries F-28ec89c6f891 again.

The first-phase observation is not reused as the arithmetic operand. In particular, F-28ec89c6f891 can change the pointed-to integer before the read used to prepare the action argument.

### Phase separation

Once the first phase has ended, the function never explicitly returns to it.
