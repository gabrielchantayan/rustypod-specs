## Behavior

### Entry and empty traversal

The first operation controlling traversal is an equality comparison between the initial traversal cursor and the endpoint.

If they are equal, the function:

- Makes no dependency invocation.
- Performs no cursor advancement.
- Returns the initial companion cursor unchanged.

No memory access through either cursor is visible on this path. In particular, this function’s visible behavior does not require either cursor to designate valid storage when the initial comparison is equal. Any additional calling-environment requirements are outside the supplied evidence.

### Processing sequence

When the traversal cursor differs from the endpoint, the function invokes F-00070b616dac using the current companion cursor as its first argument and the current traversal cursor as its second argument.

After that invocation returns normally, the companion cursor advances by 12. The traversal cursor then advances by 12. Only after those advancements does the next endpoint comparison occur.

Consequently:

- The endpoint comparison precedes every dependency invocation.
- A dependency invocation uses the cursors’ values before that iteration’s advancements.
- The companion cursor advances before the traversal cursor advances.
- The endpoint is tested by equality, not by ordering or distance.
- The dependency is not invoked with a traversal value that compares equal to the endpoint at the controlling comparison.

This ordering is established for the visible control flow. The cursor updates are local value changes, not demonstrated writes to caller-owned memory.
