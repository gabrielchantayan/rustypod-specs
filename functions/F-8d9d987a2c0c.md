# F-8d9d987a2c0c

## Purpose

F-8d9d987a2c0c selects between two behaviors according to two optional selector inputs:

- When either selector equals the sentinel −1, it can translate a zero-based ordinal among nonzero collection entries into the corresponding physical collection index.
- When both selectors differ from −1, it can obtain an intermediate value through F-17b952150bce and delegate the result to F-54a3df83e76a.

Several paths return the supplied ordinal unchanged. Consequently, a return value of −1 is not the only meaningful outcome, and an unchanged ordinal does not establish that a collection was inspected or that delegated resolution succeeded.

These behaviors are established by static inspection of the supplied representation. The interpretation of nonzero entries as “eligible,” and of the final two inputs as “selectors,” is descriptive terminology, not evidence of a particular application domain.

There is no separate status output. No local normalization limits the delegated result to nonnegative values or to −1.

Preconditions are path-dependent:

- Other ordinals require a valid object address for whichever flag fields the selected path reads.
- Collection search additionally requires valid receivers, dispatch tables, and callable entries returned through F-56a66efac853.
- Delegated resolution requires the object field at `0x2B4` to be readable and the dependencies to accept the supplied arguments.
- Successful return from a dependency is assumed when describing subsequent behavior; exceptions, faults, nonlocal exits, and nontermination are not handled locally.

## Behavior

### Immediate sentinel return

If the ordinal is −1, the result is −1 immediately.

Neither selector affects this outcome. No object field is read, and no dependency is called. Thus an otherwise unusable object address does not itself prevent this specific path from returning.

### Path selection

For every other ordinal, the initial candidate result is the original ordinal.

If either selector equals −1, the function takes the collection-search path. Otherwise, it takes the delegated-resolution path. A single missing selector is sufficient to choose collection search; the other selector is not used by that search.

### Collection-search path

The function first reads the primary flag at offset `0x2F0`.

If that flag is nonzero, it returns the original ordinal. It does not inspect the secondary flag, obtain a collection receiver, or invoke either indirect collection operation.

If the primary flag is zero, collection traversal proceeds:

1. F-56a66efac853 is called with the address at object offset `0x2F4`.
2. Its returned receiver is used for the indirect operation at dispatch-table offset `0x08`. That operation receives the receiver and the integer value 1.
3. The returned integer is retained as the traversal count.
4. Candidate indices are visited in increasing order, beginning with zero.
5. Before inspecting each candidate, F-56a66efac853 is called again with the same object-relative address.
6. The receiver returned for that particular candidate is used for the indirect operation at dispatch-table offset `0x18`. That operation receives the receiver and the current candidate index.
7. A zero result skips the candidate without consuming an ordinal position.
8. A nonzero result consumes an ordinal position. If the remaining ordinal is already zero, the current physical index is returned immediately. Otherwise, the remaining ordinal is decreased by one.

When the traversal ends without selecting an entry, the result is −1.

The ordinal is therefore a zero-based rank among entries whose inspection result is nonzero, not a physical index into all visited entries. Nonzero inspection results are not restricted to 1; negative results also qualify.

The count is obtained once. Collection receivers, however, are reacquired for every candidate. There is no requirement in the local implementation that the count receiver and later inspection receivers be identical.

The primary flag is not reread during traversal. A dependency changing that flag does not cause this function to reconsider the chosen path. Similarly, a dependency changing the collection’s size does not cause the saved count to be refreshed.

### Traversal arithmetic

The supplied representation expresses the loop bound as the current index being less than or equal to the saved count minus one.

For ordinary nonnegative counts with representable arithmetic:

- A count of zero causes no entry inspections.
- A positive count visits at most the indices zero through count minus one.
- A successful selection stops traversal before any later candidate is inspected.

Negative counts other than the minimum representable signed value also produce no entry inspections under ordinary signed arithmetic.

The minimum signed count requires special treatment: subtracting one is outside the signed 32-bit range. The supplied representation does not establish the resulting machine behavior. It is not justified to promise either an empty traversal or a wrapped, large traversal for that input.

An ordinal below −1 is not rejected. It cannot reach zero through ordinary, non-overflowing decrements. A sufficiently long sequence of qualifying entries could cause signed underflow. The contract does not assume wrapping arithmetic or define a selected index after that overflow.

### Delegated-resolution path

This path applies only when both selectors differ from −1.

The flag gate is evaluated in short-circuit order:

- The primary flag at `0x2F0` is read first.
- If the primary flag is zero, the secondary flag is not read, and resolution is permitted.
- If the primary flag is nonzero, the secondary flag at `0x2F1` is read. Resolution is permitted only if that secondary flag is nonzero.

If resolution is not permitted, the original ordinal is returned without calling F-17b952150bce or F-54a3df83e76a.

If resolution is permitted:

1. The four-byte field at `0x2B4` is read.
2. F-17b952150bce is called with the object address and that field value.
3. If its result is zero, the function returns the original ordinal.
4. If its result is nonzero, F-54a3df83e76a is called with the object address, that nonzero result, Selector A, and Selector B.
5. The result of F-54a3df83e76a is returned unchanged.

The original ordinal is not passed to either dependency on this path. Apart from the initial −1 check and the fallback return value, it does not participate in delegated resolution.

A nonzero result from F-17b952150bce is accepted without a sign or range check. Its semantic type—identifier, address, handle, or another integer-valued token—is unknown.

## Side effects

### Direct effects

No explicit write to object memory, collection storage, globals, or caller-provided output memory appears in the function.

Changes to the remaining ordinal and traversal index are internal calculation state. They do not constitute writes through the input object.

### Observable access and call order

For collection search, the significant order is:

- Primary flag read.
- Initial F-56a66efac853 call.
- Receiver dispatch-table access and count-operation call.
- For each visited index: another F-56a66efac853 call, receiver dispatch-table access, and entry-operation call.

For permitted delegated resolution, the significant order is:

- Primary flag read.
- Secondary flag read only if the primary flag is nonzero.
- Four-byte field read.
- F-17b952150bce call.
- F-54a3df83e76a call only if the preceding result is nonzero.

The representation establishes these control-dependent sequences. It does not establish additional hardware memory-ordering guarantees.

### Dependency effects and ownership

Dependencies and indirect operations may have side effects. There is no evidence here that they preserve globals, preserve object fields, return stable receivers, or leave collection contents unchanged.

The function performs no explicit allocation, release, retain, or ownership transfer. This absence does not establish that dependencies avoid such operations. It also does not establish that a returned receiver remains valid beyond the accesses and calls shown.

No local error is logged, translated, or caught. A zero result from F-17b952150bce produces an unchanged ordinal, whereas exhaustion of an enabled collection search produces −1. These outcomes must not be conflated into a single failure convention.

## Acceptance examples

These are conditional static expectations, not executed tests. Unless stated otherwise, dependencies return normally, all accessed memory is valid, and arithmetic remains representable.

1. **Immediate sentinel:** With ordinal −1, the result is −1 regardless of selector values. No object field or dependency is accessed.

2. **Disabled collection search:** With ordinal 4, either selector equal to −1, and a nonzero primary flag, the result is 4. No collection dependency is called.

3. **Rank differs from physical index:** With a zero primary flag, a saved count of five, and entry results of zero, nonzero, zero, nonzero, nonzero:
   - Ordinal 0 returns index 1.
   - Ordinal 1 returns index 3.
   - Ordinal 2 returns index 4.
   - Ordinal 3 returns −1 after all five entries are inspected.

4. **Negative inspection result qualifies:** With ordinal 0, count one, and the sole entry operation returning −7, the result is index 0.

5. **Empty traversal:** With enabled collection search and a count of zero, the result is −1. F-56a66efac853 is called for the count receiver, but no per-entry receiver is requested.

6. **Reacquisition is observable:** With count three and no qualifying entries, F-56a66efac853 is called four times: once for the count and once for each index. Its returned receivers may differ.

7. **Delegation blocked by flags:** With both selectors present, a nonzero primary flag, and a zero secondary flag, the original ordinal is returned. The four-byte resolution field is not read.

8. **Secondary flag unnecessary:** With both selectors present and a zero primary flag, resolution proceeds without reading the secondary flag.

9. **Zero intermediate result:** With resolution permitted and F-17b952150bce returning zero, the original ordinal is returned; F-54a3df83e76a is not called.

10. **Delegated result preserved:** With resolution permitted, a nonzero intermediate result, and F-54a3df83e76a returning −23, the final result is −23. No local result-range validation intervenes.

11. **Negative nonsentinel ordinal:** With ordinal −2, enabled collection search, and two qualifying entries, the result is −1. The negative ordinal is decremented rather than treated as an immediate rejection.
