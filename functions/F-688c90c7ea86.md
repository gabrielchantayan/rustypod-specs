- Compare the first components as unsigned integers.

## Behavior

### Stable-input result

The first comparison tests whether the second primary component is less than the first primary component, using unsigned ordering.

If that comparison is true, the function returns zero. It does not evaluate either secondary component or perform the later primary comparison.

If the first comparison is false, the function evaluates a second unsigned comparison of the primary components. This comparison tests whether the second primary component is less than or equal to the first.

For stable inputs, this produces two remaining cases:

- **Second primary greater than first:** the second comparison is false, the secondary comparison is skipped, and the result is one.
- **Primary components equal:** the second comparison is true, and both secondary components are evaluated and converted to the signed integer type.

When reached, the secondary comparison tests whether the converted second secondary is less than or equal to the converted first secondary:

- If true, the result is zero.
- If false, the result is one.

Consequently, primary differences always take precedence over secondary differences. Complete equality returns zero.
