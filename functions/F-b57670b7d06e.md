# F-b57670b7d06e

This contract distinguishes directly visible behavior from assumptions about the execution model. No runtime tests have been performed.

## Behavior

### Post-call comparison

After F-73c7c8fb1f4e returns normally, the function compares:

- The then-current value of the working temporary.
- The integer read from the base plus 164 bytes.

The read of the comparison value occurs after the dependency call. It is not a saved pre-call value. If the dependency changes that storage, the comparison uses its post-call contents.

The base input itself is passed to the dependency only through the derived address. Nevertheless, no assumption is made that the dependency preserves the base object, unrelated memory, or global state.

### Return selection

If the two values compare equal, the function replaces the working value with zero and returns zero. The adjustment by 20 is not performed on this branch.

If the values compare unequal, the function increases the post-call working value by 20 and returns that result.

Consequently:

- The initial working value is not necessarily the value compared or adjusted.
- Equality is checked before the adjustment.
- A nonmatching zero working value produces 20.
- A nonmatching working value of −20 produces zero when the integer model represents both values normally.
- A zero return therefore does not uniquely identify the equality branch.
- A nonmatching value can become equal to the sentinel after adjustment; there is no second comparison.

The function shows no retry, loop, fallback dependency call, or separate error-status branch.
