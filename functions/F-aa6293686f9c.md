# F-aa6293686f9c

## Purpose

F-aa6293686f9c describes a nontransactional memory-mutation sequence with two represented invalid-instruction boundaries. It discovers addresses through memory reads, publishes captured values, modifies overlapping storage, and conditionally continues according to a signed 32-bit decision.

The negative-decision path reaches its boundary after the common mutations. The nonnegative path performs additional pointer-related and fixed-storage mutations before reaching the other boundary. Neither path represents normal completion or a returned result.

This is a **documented_only**, static behavioral contract. It does not establish an application-level purpose, executable target semantics, or actual handling of either boundary.

## Interface

### Inputs

The explicit interface has four signed 32-bit integer inputs:

| Position | Behavioral role |
|---|---|
| First | Initial address calculation, selection displacement, and byte content |
| Second | Displacement for an early byte read |
| Third | Doubled address for the first word read |
| Fourth | Base for early word and byte publications |

The representation also consumes implicit incoming state:

- A 32-bit payload.
- A signed 32-bit address-bearing value.
- An incoming pointer whose target is accessed as both words and halfwords.
- The address of the incoming slot associated with that pointer.

The pointer value and slot address are distinct address sources. Their calling-convention provenance is unresolved.

### Widths and interpretation

A byte is 8 bits, a halfword 16 bits, and a word 32 bits. Offsets are measured in bytes.

Unsigned byte and halfword reads zero-extend. Signed halfword reads preserve their signed value when widened. Unsigned 32-bit arithmetic wraps modulo \(2^{32}\).

Signed overflow, signed left shifts, negative signed right shifts, signed narrowing, and integer–pointer conversions require target-specific interpretation. In particular, a signed 32-bit right shift by 32 has no portable numerical result. Two such expressions affect this contract.

Character publications occupy one byte, but conversion to the destination character representation is not unconditionally equivalent to retaining the low eight bits.

Explicit indirect accesses have the widths specified below. Fixed-storage declarations are incomplete: numerical assignments do not always establish physical access widths. The final pointer-typed publication also has an unresolved physical pointer width.

### Preconditions and outcomes

Every reached access requires a meaningful address conversion, accessible storage, and appropriate alignment and lifetime under the target model. No validation is represented.

The outcome is the completed prefix of reads and mutations before a fault or represented boundary. There is no established error result, rollback, recovery, ownership transfer, or process-termination guarantee.

## Behavior

### Ordering and aliasing model

The following sections describe successive phases. Within each phase, stated ordering is significant.

Calculated addresses, fixed storage, the pointer target, and slot-related storage are not established as disjoint. Earlier writes may therefore affect later reads. A captured scalar remains distinct from a subsequent fresh storage read.

Repeated or overlapping writes are separate effects even when their contents agree. No ordering between operands of one expression is established unless separately stated.

### Initial discovery and publications

The initial address discovery consists of a signed word read at twice the third input, followed by an unsigned halfword read at the first input plus that word. These address calculations use signed arithmetic.

Call the resulting zero-extended halfword the **anchor**. Its numerical range is 0 through 65535; it is subsequently used as an address.

Before the first write, the function captures:

- An unsigned byte at the incoming address-bearing value plus the second input.
- A signed halfword at the first input plus the anchor, with unsigned 32-bit arithmetic in that addition.

The initial publication sequence is:

| Destination | Width | Content |
|---|---:|---|
| Anchor + 8 | Word | Captured byte, zero-extended |
| Captured byte’s numerical value + 40 | Word | Captured halfword, sign-extended |
| Fourth input + 76 | Word | Complete payload |
| Anchor + 112 | Word | Anchor |

Three signed word reads then establish an **indirect base**, a **secondary base**, and a **remote base**. Their sources, in order, are anchor + 20, indirect base + 56, and incoming address-bearing value + 92.

All three reads precede these character publications, in order:

- Remote base at indirect base + 1.
- Payload at fourth input + 11.
- First input at indirect base + 21.
- Secondary base at remote base + 31.

Each publication converts its content to the destination character representation.

### Selection and downstream captures

Fixed storage at 0x0897eabc and 0x0897e9fc supplies two signed 32-bit bases, called **fixed base A** and **fixed base B**, respectively. After those captures, an unsigned byte at secondary base + 10 supplies a **byte-sized base**.

The **entry offset** is the unsigned 32-bit conversion of the first input after signed right shift by 23. The **selection offset** is the entry offset with mask 0x88 set. Under arithmetic right shift, the signed intermediate ranges from −256 through 255.

Before either selection read, the indirect base is converted to a halfword and written at:

\[
\text{indirect base}+(\text{indirect base shifted right as signed by }11).
\]

The selection then captures a signed word from fixed base B + selection offset and an unsigned byte from the signed-shifted indirect base + selection offset. Both additions incorporate unsigned arithmetic. These are the **selected word** and **selected byte**.

Their consumers are ordered as follows:

1. Selected word, as a word, at byte-sized base + 8.
2. Byte-sized base, as a word, at entry offset + 64.
3. Selected word, as a word, at fixed base A + 116.

Next, a signed word at byte-sized base + 40 supplies the **region source**, and a word at fixed base A + 92 supplies separate captured content. Both reads precede three byte publications:

| Destination | Content |
|---|---|
| Selected word + 3 | Character conversion of fixed base A |
| Fixed base A + 16 | Selected byte |
| Selected byte + 28 | Character conversion of the separately captured content |

The first destination depends on the selected word, not the region source.

### Region construction and unresolved destination

The following quantities use unsigned 32-bit arithmetic:

| Quantity | Definition |
|---|---|
| Difference | Entry offset minus 56 |
| Region displacement | Entry offset minus 224 |
| Masked quantity | Region displacement with bit 31 cleared |
| Half quantity | Masked quantity logically shifted right by one |
| Region base | Twice the region displacement, modulo \(2^{32}\) |

The half quantity cannot exceed 0x3fffffff.

A separate **unresolved destination** derives from the region source through signed left shift by two followed by signed right shift by 32. The left shift can already lack defined signed semantics; the width-sized right shift prevents a portable address interpretation.

Conditional on resolving that destination and reaching the accesses, the region effects have this order:

- The low unsigned byte of the half quantity is written at region source + 0x0897e8b8. Fixed storage at 0x0897e8c0 subsequently receives numerical value 0xb8.
- A character conversion of the difference is written at entry offset − 50. The complete difference is then written as a word through the unresolved destination.
- Halfwords 0xffff are written at region base + 4 and + 6, in that order.
- A byte 0xb8 is written at unresolved destination + 4, followed by a halfword 0xffff at region base + 2.
- Fixed storage at 0x0897ea28 receives the low 16 bits extracted from the represented four-byte region pointer.
- An unsigned halfword is freshly read at region base. Its zero-extended numerical value becomes the destination of a word containing the difference masked by 0x897e8b80.

The three region halfword writes do not directly initialize the halfword at offset zero. Its later value depends on existing storage and any aliasing effects.

### Decision and conditional continuation

Three separate references associated with F-e47d7b2e9c88 supply three consumers:

| Consumer | Interpretation |
|---|---|
| Decision | Converted to an unsigned 32-bit value, then tested as signed |
| Branch base | Converted to signed 32 bits and shifted right by 32 |
| Sign contribution | Converted to signed 32 bits, shifted right by 31, then converted to a halfword |

The references are not represented calls. Their equality, stability, and numerical relationship are unknown. The branch-base expression is the second unresolved width-sized signed shift.

The sign contribution is written as a halfword at branch base + 4 before testing the decision.

A negative signed decision reaches the first invalid-instruction boundary. No later phase belongs to that path.

For a nonnegative decision, a publication pair occurs twice: first a halfword sign contribution at branch base + 18, then a word containing the decision at the decision’s own numerical address. Between the two pairs, a signed halfword is captured from branch base + half quantity; that address addition incorporates unsigned arithmetic.

Both pairs are significant. The first may change the intervening read through aliasing. The second cannot retroactively alter the captured halfword.

After the second pair, the captured halfword is sign-extended, shifted right as signed by 16, and published as a word at branch base + 8. With arithmetic right shift, its content is zero for a nonnegative halfword and 0xffffffff for a negative halfword.

### Continuation state and pointer-target overlap

The continuation first assigns zero to prefetch-associated fixed storage.

A **selector** is 88 when decision bit 2 is clear and 92 when it is set. Before any direct pointer-target mutation, these publications occur in order:

| Destination | Numerical content |
|---|---|
| Selector + 4, word access | Branch base |
| Fixed storage at 0x00000006 | Masked quantity logically shifted right by 17, converted to unsigned halfword |
| Instruction-associated aggregate | Half quantity converted first to unsigned byte, then to unsigned halfword |
| Four times selector + 16, word access | Half quantity |
| Supervisor-associated storage | Half quantity |

The incoming pointer target then receives deliberately overlapping accesses:

- Its initial halfword receives the selector.
- Its initial word receives the branch base signed-left-shifted by eight.
- Its word at offset 20 receives the same shifted expression.
- Its initial word is replaced by the pointer’s signed 32-bit conversion.

A word read at twice that signed pointer conversion supplies the **retained word**. A halfword conversion of the retained word replaces the pointer target’s initial halfword. The complete retained word is then written through its own numerical address.

The next word publication uses the incoming slot address, not the pointer value, to determine its destination:

\[
32\times\text{signed conversion of slot address}+24.
\]

Its content is the pointer value’s signed 32-bit conversion shifted right by 31.

Only afterward is the byte associated with the instruction aggregate freshly read. The aggregate receives the concatenation of unsigned 16-bit value 5 above that byte: numerically, 0x000500 plus the observed byte. This numerical construction does not establish a three-byte physical store.

Finally, a pointer-typed destination at four times the pointer’s signed 32-bit conversion, plus 24, receives the incoming pointer. Pointer publication alone establishes no ownership transfer.

### Late publications and final precedence

Fixed storage at 0x0897ea50 supplies a signed 32-bit **late base**. A first reference associated with F-8afdaab91693 is captured for later multiplication by eight.

The **publication cell**, fixed storage at 0x0897ea80, next receives four times the incoming pointer’s signed 32-bit conversion. A second F-8afdaab91693 reference occurs after that assignment and supplies a separate left-shift-by-two consumer.

The publication cell is then read for both destination and content of a self-valued word publication. The order of those two reads is unresolved. A subsequent fresh read of the cell supplies the base for a word publication of the half quantity at offset 4. Consequently, aliasing during the self-valued publication may change that later destination.

The captured late base supplies two further word publications:

- Four times the late base receives that same scaled value.
- Late base plus its signed-left-shift-by-six, signed-right-shift-by-17 result receives the shifted second dependency reference.

The late base’s unsigned upper 16 bits are assigned to **reset-upper storage**. Interrupt-associated storage then receives zero.

Eight times the first F-8afdaab91693 capture determines another base. Its words at offsets zero and 4 are cleared, in that order. A character publication at offset 16 converts that base to character, adds eight after promotion, and converts again for storage. Under conventional low-byte conversion, the resulting byte is base + 8 modulo 256.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. Each requires sufficient target semantics and accessible memory to reach the relevant event.

- **Unsigned discovery and signed widening.** An initial halfword containing 0x8001 produces anchor 32769. A later signed halfword containing 0xff80 produces word content 0xffffff80. Payload 0x123456ab is published intact at fourth input + 76; its character publication is a separate conversion.

- **Selection destination identity.** A selected word of 0x1000 directs the fixed-base-A character publication to 0x1003, regardless of the region source. A selected byte of 0x21 directs the separately captured-content character publication to 0x3d.

- **Unsigned region boundary.** First input zero gives entry offset zero, difference 0xffffffc8, region displacement 0xffffff20, masked quantity 0x7fffff20, half quantity 0x3fffff90, and region base 0xfffffe40. These results do not resolve either shift by 32.

- **Uninitialized region start.** If the fresh halfword at region base contains 0x1234, the masked-difference word is directed to numerical address 0x1234. Halfwords written at offsets 2, 4, and 6 do not replace that read.

- **Negative decision.** The branch-base + 4 halfword publication precedes the first boundary. Neither repeated publication pair nor any pointer-target mutation is required on this path.

- **Independent decision references.** A nonnegative decision does not by itself establish a zero sign contribution: the contribution comes from a separate reference occurrence.

- **Read between repeated writes.** If the first publication pair changes the intervening halfword source, the changed value is captured. The second pair remains required but cannot alter that captured value.

- **Selector alternatives.** A clear decision bit 2 produces selector-derived word destinations 92 and 368. A set bit produces 96 and 384.

- **Aggregate width conversion.** For the zero-input region example, the early instruction aggregate receives numerical value 0x0090, not 0xff90. A subsequently observed byte 0xa7 produces numerical value 0x0005a7.

- **Pointer versus slot.** Equal pointer values associated with different slot addresses can produce different slot-derived destinations while leaving pointer-value-derived calculations unchanged.

- **Fresh-storage precedence.** A publication-cell change before its offset-4 consumer changes that consumer’s base. A reset-upper change before final concatenation changes the concatenated upper halfword.
