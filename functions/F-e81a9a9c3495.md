## Behavior

### Entry and overflow decision

The represented entry sequence:

1. Obtains the state global into \(G\).
2. Obtains the pointer-like global into \(B\).
3. Forms \(A\) and initializes \(X=0\).
4. Evaluates signed 32-bit subtraction overflow for \(H-J\).
5. Obtains the selector global into \(D\).

The condition tests **signed subtraction overflow**. It is not a test for a negative subtraction result, inequality, or zero.

If overflow is absent, execution proceeds to the preliminary word stores.

## Acceptance examples

These are conditional deductions from static evidence, not executed tests.

1. **Overflow absent.** If \(H=1\) and \(J=2\), subtraction is negative but does not overflow. Preparation, including the second selector reference, interrupt, and first three calls, is skipped. With \(X=0\), the first preliminary store writes the initially saved \(D\) at \(C\). The phase ends with \(Q=B\) and \(T=0\).

2. **Overflow present.** If \(H=0x80000000\) and \(J=1\), signed subtraction overflows and preparation is selected. This establishes branch selection only, not address validity.

3. **Selector references agree conditionally.** If the initial selector reference and preparation’s second selector reference both supply \(0x20\), the first byte-store address is \(A+0x20\). If the environment instead supplies \(0x30\) for the second reference, that address is \(A+0x30\), regardless of the initially saved selector. This does not assert two physical loads or a mechanism causing the difference.

4. **Preparation bypass.** If preparation completes and U02 returns zero, \(B=X=0\). Preliminary stores are skipped; \(Q=A\) and \(T=K\). The first shared store attempts a word write of \(G\) at address zero.

5. **Negative prepared address.** If U02 returns \(0x00800000\), then \(B=0x80000000\) and \(X=0\). The preliminary stores execute with \(H=0x0891111C\).

6. **Input truncation.** Inputs \(1\) and \(257\) both produce \(A=0x01000000\) under the 32-bit model. More generally, inputs differing by \(256\) produce the same \(A\). This is only an address-derivation equivalence.

7. **Split result and wraparound.** If U04 supplies \(L=0x10\) and \(M=0x20\), the first post-U04 store carries \(0x10\), the second carries \(0xFFFFFFFA\), and the fifth carries \(0x20\).

8. **Final references.** If both final global references supply \(0x1000\), the final assignment stores \(0x1000\) at \(0x1018\). If the destination reference supplies \(0x1000\) and the value reference supplies \(0x2000\), it instead stores \(0x2000\) at \(0x1018\). No evaluation order or physical load count is implied.

9. **Terminal behavior.** If all operations complete through the final assignment, no normal return follows. A required returned success value would contradict the visible terminal behavior.
