# F-52920411b76a

## Purpose

F-52920411b76a coordinates six dependency calls around a four-word, invocation-local record. It receives four 32-bit inputs, saves them in that record, invokes the dependencies in a fixed order, and constructs a 64-bit result from the record’s first two words after the calls return.

The first input also supplies a base value used directly as a dependency argument and to form an address-like value at byte displacement 196. Three dependencies receive access to the local record. Consequently, the returned words are not necessarily equal to the first two inputs.

This is a static behavioral contract derived from the supplied representation. It does not establish the application-level purpose of the operation, the validity of any address, or the behavior of an unavailable dependency.

### Output

- Bits 63–32 contain the final 32-bit contents of the record at offset 4.

**upper word × 2³² + lower word**

This composition does not sign-extend the lower word. A lower word with its highest bit set contributes exactly those 32 bits.
