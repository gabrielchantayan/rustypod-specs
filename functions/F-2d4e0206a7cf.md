### Bit extraction and output write

For a valid unsigned working word, the value explicitly written is therefore:

- 0 when bit 1 is clear.
- 1 when bit 1 is set.

No other bit contributes to that value. There is no addition, multiplication, signed conversion, or overflow-sensitive arithmetic in this transformation. The shift distance is one.

The destination write is a whole unsigned-word write, not a one-bit update and not an explicitly byte-sized write. Existing destination contents are overwritten. The wrapper does not preserve other destination bits.

This write occurs before F-7428d532c92b and F-729cacc3f7a4.
