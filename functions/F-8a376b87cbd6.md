# F-8a376b87cbd6

## Purpose

Three outcomes are established:

- A zero result from either of the first two acquisition calls produces the 32-bit return value `0xffffff94`.
- Completion of the final path writes the primary address to the caller’s slot and returns zero.
- A nonzero result from either of two later checks returns zero without that publication write.

A zero return therefore does not establish that the output slot was populated.

“Acquisition,” “object,” “configuration,” and “cleanup-like” describe roles inferred from the call sites. They do not establish concrete types, allocation semantics, or ownership transfer. This contract distinguishes direct behavior from effects that depend on unavailable dependency implementations.
