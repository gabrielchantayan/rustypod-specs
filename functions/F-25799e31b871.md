# F-25799e31b871

## Purpose

F-25799e31b871 classifies two input words into a small unsigned result using three observations:

- Whether the first word or the lowest 20 bits of the second word contain any nonzero bit.
- Whether bits 20 through 30 of the second word form a nonzero field.
- Whether that 11-bit field equals an externally stored comparison value.

The highest bit of the second word does not affect the result.

The established behavior is an integer classification operation. The input layout resembles the two words of a binary64 floating-point encoding, but that interpretation is inferred intent, not an interface requirement. The function does not perform floating-point arithmetic, validate a floating-point object, or establish named floating-point categories.

One result is explicitly normalized: a preliminary result of 1 becomes 5. That rule applies only when the entire preliminary result equals 1, not whenever its lowest bit is set.

## Behavior

For describing the classification, define three conditions:

- **Payload present:** the first word is nonzero, or the low payload field of the second word is nonzero.
- **Field present:** the 11-bit comparison field is nonzero.
- **Match:** the externally stored comparison value compares equal to the comparison field.

The complete result relationship is:

| Payload present | Field present | Match | Returned value |
|---|---|---|---:|
| No | No | No | 0 |
| No | No | Yes | 2 |
| No | Yes | No | 5 |
| No | Yes | Yes | 3 |
| Yes | No | No | 4 |
| Yes | No | Yes | 6 |
| Yes | Yes | No | 5 |
| Yes | Yes | Yes | 7 |

This table incorporates the final normalization and is the behavioral contract, rather than merely an interpretation of individual output bits.

### Classification order

The shown evaluation has the following order:

1. Determine whether a payload is present.
2. Determine whether the comparison field is nonzero.
3. Compare the external value with the comparison field.
4. Normalize a preliminary result of exactly 1 to 5.
5. Return the resulting unsigned value.

The first condition uses short-circuit disjunction: when the first word is nonzero, the low-payload test is not needed to decide payload presence. Both inputs are scalar argument values, so this does not imply any conditional dereference of caller memory.

The external comparison is not skipped for any input combination. A zero comparison field still participates in that comparison. Thus, all-zero input words do not guarantee a result of zero: they produce 2 if the external comparison matches zero.

### Meaning and limits of the result bits

Before normalization:

- Bit 2 records payload presence.
- Bit 0 records a nonzero comparison field.
- Bit 1 records a successful external comparison.

After normalization, bit 2 is no longer an exact indicator of payload presence. It is also set for the no-payload, nonzero-field, nonmatching case.

Consequently:

- Result 5 has two distinct causes: a present payload with a nonzero, nonmatching field; or an absent payload with a nonzero, nonmatching field.
- Result 3 identifies the absent-payload, nonzero-field, matching case.
- Result 7 requires payload presence, a nonzero comparison field, and a match.
- A match prevents the preliminary value 1 from arising, so the matching, absent-payload, nonzero-field case remains 3 rather than becoming 7.

Consumers must not reconstruct payload presence solely from bit 2 of the returned value.

### Arithmetic and boundaries

The extraction uses masking and a right shift of an unsigned value. The shift count is 20, within the analyzed 32-bit width.

There is no addition, subtraction, multiplication, division, or input-dependent shift count. The result construction uses only small bit values and cannot overflow under the analyzed width.

The low payload field ranges from 0 through `0xFFFFF`. Only zero versus nonzero matters. The comparison field ranges from 0 through `0x7FF`; its exact value matters for the external comparison, while only zero versus nonzero matters for bit 0.

Changing bit 31 of the second input alone leaves the result unchanged, provided the external comparison outcome is otherwise unchanged.
