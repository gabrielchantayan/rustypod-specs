# F-46f0b3cb316e

- Equal inputs cause no explicit memory read and no dependency invocation.
- Unequal inputs cause one explicit four-byte read at a byte offset of four from the address represented by the second input. The first input and the retrieved value are then passed to F-151ab4bfe553.
