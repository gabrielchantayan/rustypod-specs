# F-f0392a59c9a9

## Purpose

F-f0392a59c9a9 conditionally invokes dependencies for an object identified by a 32-bit address value. A zero object argument returns zero without accessing the object or invoking any dependency.

For a nonzero object argument, a preparatory dependency runs before classification. Classification uses a captured object discriminator, repeated observations of one shared comparison value, a retained comparison value, and conditional observations of two other shared values. Depending on those observations, the function either:

- Returns 21 immediately after classification.
- Performs an optional operation, a common operation, and a final call, then returns the optional operation’s result.
- Performs the common operation and final call without the optional operation, then returns zero.

When shared comparison values remain stable, this simplifies to three recognized classes: the first two select optional processing, while the third selects continuation without optional processing. That simplified classification is not the general contract when repeated observations of shared state differ.

“Preparatory,” “optional,” “common,” and “final” describe call positions only. They do not establish initialization, cleanup, locking, ownership transfer, or other dependency semantics.

## Behavior

### Entry and preparation

The zero test precedes every visible object-field access and dependency call. A zero object argument returns zero immediately.

For a nonzero argument, F-558af7087074 is called with no explicit arguments shown. Its result, if any, is unused.

Only after this call returns does the function capture the 32-bit discriminator at object offset +0x44. Classification uses that captured value throughout; no later discriminator reread is visible.

Preparation is not assumed to preserve the object, shared comparison data, or other global state. Consequently, classification concerns the discriminator and shared values observed after preparation, not necessarily their entry-state values.

### Ordered shared observations and retained comparison value

After capturing the discriminator, the function first observes A and retains that observed value as a comparison candidate.

It then observes A a second time. Equality between the discriminator and this second observation determines whether the candidate is replaced:

- If they are equal, the candidate remains the first observation of A.
- If they differ, B is read and its observed value replaces the candidate.

The second observation of A controls replacement; it is not itself saved as the candidate.

A third observation of A is then used in the later short-circuit condition. Equality with this third observation selects optional processing immediately. In that case, the retained candidate is not compared, even if B was already read.

If the discriminator differs from the third observation of A, it is compared with the retained candidate. Equality selects optional processing. Inequality causes C to be read and compared with the discriminator.

Thus, C is consulted only when the discriminator differs both from the third observation of A and from the retained candidate. Equality with C selects continuation without optional processing; inequality returns 21.

These are source-visible evaluation dependencies and ordering constraints. They are not merely an uncertainty about physical load counts. The representation establishes:

- Three ordered evaluations of A.
- A conditional evaluation of B after the second A evaluation and before the third.
- A conditional comparison against the retained candidate after the third A evaluation.
- A conditional evaluation of C only after both preceding comparisons fail.

The corresponding machine-level loads, atomicity, and defined behavior under concurrent modification remain unresolved. Different observed values are conditional cases of this contract, not a guarantee that unsynchronized concurrent writes are valid.

### Stable-value simplification

If A, B, and C remain stable throughout classification, the behavior simplifies to:

| Captured discriminator | Selection |
|---|---|
| Equal to A | Optional processing |
| Different from A, equal to B | Optional processing |
| Different from A and B, equal to C | Continuation without optional processing |
| Different from A, B, and C | Return 21 |

The shared values need not be distinct. Under this stability condition, an A or B match takes precedence over a C match.

Without stability, the ordered-observation rule above governs. In particular, B can be read without being compared, and equality with the second observation of A does not by itself guarantee optional processing.

### Optional processing

When selected, F-ff91b5d6bcbb is called with the original object argument and the literal value 1.

Its 32-bit result is retained for the eventual return. The function does not test that result before continuing. A zero, nonzero, or 21 result follows the same subsequent call sequence, assuming normal return.

When classification continues through a C match instead, optional processing is omitted and the retained result remains zero.

Classification rejection returns 21 before either continuation dependency is invoked.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. Unless otherwise stated, accessed memory is valid and dependencies return normally. Examples 2–6 assume shared comparison values remain stable during classification.

1. **Zero object.** The result is zero, with no object-field reads or dependency calls. Other explicit inputs do not change this path.

2. **A match.** Optional processing occurs once. If it returns 7, the common operation and final call still occur, and the function returns 7.

3. **B match without an A match.** B is read and retained, then compared after the third A observation differs. Optional processing occurs, followed by both continuation calls.

4. **C-only match.** The discriminator differs from A and B but equals C. Optional processing is omitted; the common operation and final call occur; the result is zero.

5. **Unrecognized discriminator.** The discriminator differs from A, B, and C. Preparation occurs, then the function returns 21. The fields at +0x48 and +0x4C are not visibly read.

6. **Overlapping stable classes.** A and C both equal the discriminator. Optional processing occurs, and C is not consulted.

7. **B read but not compared.** Let the discriminator be 10. The first two A observations are 20, B is observed as 30, and the third A observation is 10. B is read because the second A observation differs. Optional processing is nevertheless selected by the third A observation, without comparing the retained B value or reading C.

8. **First A observation retained.** Let the discriminator be 10. The first and second A observations are 10, while the third is 20. B is not read. The discriminator differs from the third A observation but equals the retained first observation, so optional processing occurs without consulting C.

9. **Equality with the second A observation is insufficient.** Let the discriminator be 10; the three A observations are 20, 10, and 30; C is 40. B is not read, and the retained candidate remains 20. The discriminator differs from both the third A observation and the candidate, then differs from C. The function returns 21.

10. **Post-preparation classification.** If preparation changes the discriminator, classification uses the changed value captured after preparation returns.

11. **Post-optional argument fields.** If optional processing changes the fields at +0x48 and +0x4C, the common operation receives arguments formed from those changed fields. The fourth explicit input is still forwarded unchanged.

12. **Optional result of 21.** Both continuation calls still occur, and the eventual result is 21. This return value alone does not prove classification rejection.

13. **Unused explicit inputs.** Changing only the second and third explicit inputs changes no visible decision or argument construction in this function. This does not resolve hidden calling-convention dependencies.
