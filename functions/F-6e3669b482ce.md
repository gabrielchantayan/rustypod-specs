There is no explicit read from or write through the input on this branch. In particular, the function does not attempt a store at address four when the input is zero.

The rejection result is established only for the zero-input condition. The function does not provide equivalent explicit handling for other invalid address-like values.

### Nonzero-input case

The store does not depend on the previous destination contents. No read of the previous field value is expressed. Consequently, the behavior is not a read-modify-write operation and does not inspect whether the destination was already zero.
