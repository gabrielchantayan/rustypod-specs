## Acceptance examples

These are conditional consequences of the static representation, not executed tests. Each assumes the relevant calls return and accesses complete unless failure is the subject of the example.

1. **Repeated reads are observably distinct.**  
   If P + 116 initially contains 0x12345678, the first byte write at P + 1 contains 0x78. If an intervening dependency changes the source word to 0xABCDEF90, the second write contains 0x90.

2. **Captured W is reused.**  
   If W is captured as 0x89ABCDEF, the byte written at R + 1 is 0xEF. Both later W word writes contain 0x89ABCDEF even if the original source location changes afterward.

3. **Destination strides differ.**  
   With D = E = 3 and non-overflowing arithmetic, the W destinations are addresses 68 and 32, respectively.

4. **Scaling may lose high bits.**  
   Under 32-bit modular arithmetic, B = 0x40000001 yields Q = 4. F-D024 receives 0x00010000, calculated from Q rather than an untruncated wider product.

5. **A selector value becomes an address component.**  
   With W = 0x01000000, the first selector is read at address 3. A selector value of 250 selects destination 267. If V = 0x123456AB, that destination receives 0xAB.

6. **The second output excludes V’s top two bits.**  
   V = 0xC0400000 produces a second output byte of 1. Its destination still depends on the selector derived from Klo, not on V.

7. **The global sample is retained.**  
   If the pointer-like global contains U₀ when sampled and F-D052 later changes it to U₁, the explicit word read still uses U₀ + 20. Successful execution requires that retained address to remain readable.

8. **Aliased selector destinations retain ordering.**  
   If both selectors choose the same destination, the second selected-byte write follows the first. Without intervening modifications, the second value replaces the first.

9. **Overlapping final clears remain separate events.**  
   If the auxiliary pointer equals the calculated halfword address, the byte zero is written first and the halfword zero second. F-D079 follows only if both complete.

10. **A fault leaves a completed prefix.**  
    If the second selector read faults, the first selected-byte write has already occurred. The second selected-byte write, supervisor-related assignment, final clears, and zero-address call have not been reached.
