# F-f36ad56f45e1

## Purpose

F-f36ad56f45e1 interleaves dependency calls with scaled-address word stores, byte-selected byte stores, and bit-field transformations. It invokes the identified dependency F-674e75a953e8 once.

An application-level purpose is not established. The repeated scaling and field extraction suggest encoded-state manipulation, but do not establish a data structure, protocol, device, or ownership model.

This contract separates:

- **Established static evidence:** represented accesses, calls, value reuse, and ordering.
- **Conditional arithmetic conclusions:** consequences of interpreting arithmetic and addresses as 32-bit machine operations.

The representation does not establish normal return.

## Behavior

A subsequent call receives A twice and the incoming general-purpose value shifted left by 10. Another call follows, after which:

1. A is stored at \(I(R0)\).
2. A dependency receives R0.
3. After intervening calls, a primary result supplies another index.
4. R0 is stored at that index’s indexed-word address.
5. A following dependency receives four times that later index.

The first store’s index, the argument in step 2, and the later stored payload all use the same represented R0. R0 is represented as a signed 32-bit quantity; its stored word preserves its 32-bit pattern. No fresh secondary-result observation is established at step 4.

These examples are conditional specifications, not executed tests.

1. **Byte truncation:** For B equal to 65, the first B-based update stores byte 4, not 260. Its destination still depends on its selector read.

2. **Selector range:** A selector of 255 selects address 272. A selector of zero selects address 17.

3. **Distinct global captures:** If G0 is `0x400` and G1 is 2, the masked global argument is 1, both G1-based selector addresses are 9, H is `0x20000000`, and the two large-shift-path word reads use `0x2000001c`. U is zero. Substituting G0 into the address formulas would not match the representation.

4. **Initial secondary reuse:** Under the represented value model, if R0 is 5 and the later primary index is 9, A is first stored at address 40, while word 5 is later stored at address 56. The later payload is not a newly sampled secondary value.

5. **Repeated selector mutation:** If two reads of one selector address yield 3 and 9, their stores target addresses 20 and 26. Reusing the first selector would be incorrect.

6. **Unsigned extraction:** For R1 or R2 equal to `0xffc00000`, the corresponding right-shift-by-22 byte payload is `0xff`.

7. **R4 reuse:** For represented R4 equal to 3, the call arguments are 3, 3, and 48; the later selector address is 49 and its byte payload is zero. Runtime acceptance additionally depends on the unresolved lifetime model.

8. **Combined-result halves:** With Q equal to 7 and P equal to 3, the first ensuing word store writes zero at address 48. The scaled P store writes `0x0c000000` at `0x30000014`.

9. **Captured word:** If a dependency changes the fourth scaled stage’s read location after capture, the later shifted payload still derives from the captured word.

10. **Partial effects and endpoint:** A later fault does not require earlier stores to be undone. Reaching the last call does not establish successful normal return.
