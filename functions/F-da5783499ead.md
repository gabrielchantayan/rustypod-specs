# F-da5783499ead

## Purpose

F-da5783499ead exposes a long, ordered sequence of indirect dependency calls and writes to addresses computed from incoming machine state, dependency results, and byte-valued memory selectors.

**Established static evidence:** the supplied representation contains byte reads, 32-bit reads, byte writes, 32-bit writes, repeated indirect calls, and a terminal bad-instruction indication. It does not establish a normal return.

This contract describes the visible sequence conditionally: each later operation is reached only if earlier calls and memory accesses complete and execution follows the supplied representation.

## Behavior

### Contract notation

The following names identify semantic values, not source identifiers:

- **Selector:** the byte read from incoming address-like state plus one.
- **Early scale:** four times a dependency result retained for later writes.
- **Descriptor:** a later 32-bit dependency result.
- **Half-index:** `(Descriptor & 0x3fffffff) >> 1`.
- **Clear base:** `Half-index × 0x400`.
- **Wide base:** `Half-index × 0x4000000`.
- **Packed offset:** `(Half-index & 0x3fffff) × 0x80`.

All address expressions use the width convention above.

For compactness, a **five-call group** means five distinct, consecutive indirect call occurrences. The first has the explicitly stated arguments; the following four have no explicit arguments in the supplied representation. When a result is named, it is the fifth call’s result.

Groups have opaque dependency IDs `F-U01-1` through `F-U30-5`, grouped by the corresponding two-digit number. Additional individual occurrences use `F-X01` through `F-X19`. These IDs identify occurrences only; they do not assert that targets are distinct functions. “No explicit arguments” does not establish an argument-free machine ABI.

## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Selector extremes.** If the initial selector read yields zero, the first byte destination is `0x11` and the first Selector-indexed word destination is `0x14`. If it yields 255, those destinations are `0x110` and `0x410`. The selector is unsigned, not sign-extended.

2. **Byte truncation.** If the unsigned value supplying the first byte payload is `0xffffffff`, shifting right by 22 produces `0x3ff`; the stored byte is `0xff`.

3. **Fresh versus cached reads.** If a dependency changes the byte at `16 × Descriptor + 1` between its two reads, the later zero-byte write follows the changed selector. Conversely, changing `Clear base + 1` during `F-U16` does not change the subsequent word-clear destination, which uses the already retained byte.

4. **Masked arithmetic.** If Descriptor is `0xffffffff`, Half-index is `0x1fffffff`, not `0x7fffffff`. Packed offset is then `0x1fffff80`.

5. **Split result.** If the represented 64-bit result has low half three and high half five, `F-X11` receives 12. The following word clear targets `0x4e`, subject to address validity and alignment behavior. Its destination is not derived from the low half.

6. **Aliasing.** If an explicit destination resolves to `0x24`, its write and any later explicit clear of `0x24` remain separate events. An intervening dependency may observe the earlier value.

7. **Interrupted execution.** If an early dependency does not return, later explicit writes are not required to occur. No rollback of earlier effects is established.
