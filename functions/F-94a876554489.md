# F-94a876554489

## Purpose

An application-level purpose is not established. The repeated shifts, masked fields, and writes at offsets 1, 17, and 20 suggest structured state manipulation, but the evidence does not establish a serializer, allocator, device driver, or other specific subsystem.

The contract below describes the visible execution sequence conditionally: each step is reached only if preceding dependency calls and memory accesses complete normally. It does not establish that the represented sequence is executable on any particular target.

### Preserved selector across calls

### Narrowing after extraction

If the captured global word is `0xFFFFFFFF`, the later global-derived byte store writes `0xFF`: shifting right by 22 produces `0x3FF`, then the byte store retains its low eight bits.

Similarly, \(E(\text{0x3fffffff})=\text{0xff}\), not `0x3FF`.

### Repeated zero stores
