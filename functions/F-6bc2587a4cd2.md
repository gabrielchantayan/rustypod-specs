## Behavior

### Observable ordering

1. The incoming value is written to destination offset 0.
2. If the optional source is non-null, its integer value is read. Otherwise, zero is selected without a source read.
3. That selected value is written to destination offset 4.
4. If the optional source is non-null, F-6bf88c96e2f7 is invoked once, with no explicit arguments.
5. After that call returns, the non-null source is read again. Its value is combined with four times the dependency’s returned integer.
6. The derived value is written to destination offset 8. On the null path, zero is written there instead.
7. The optional source pointer is written to destination offset 12.

The dependency’s internal reads and writes are not shown. They occur between the second destination store and the second source read.
