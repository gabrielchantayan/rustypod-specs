The initial effects preserve these ordering relationships:

**After those two consecutive byte writes, and before the byte write at fixed address 0x01, the function reads the byte at fixed address 0x05.** Its zero-extended value becomes the **fixed-byte base**, in the range 0–255.

The fixed-byte base is subsequently used for a byte write at +0x15, a word read at +0x54, and replacement of that word at +0x54. The byte write uses the small component’s low byte. The replacement word uses the earlier captured word from shifted base plus 0x14.

The fixed-address 0x01 write uses the small base’s low byte. Before the fixed-byte-base +0x54 read, further computed writes occur, including working-value propagation and a zero byte write at shifted base plus 0x11. Consequently, the +0x54 read is not an observation simultaneous with the 0x05 read.

Intervening writes either affect distinct bytes or write zero. A subsequent write using that captured zero as a base at +0x54 therefore reaches absolute address 0x54.
