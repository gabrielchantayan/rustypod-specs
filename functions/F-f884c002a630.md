# F-f884c002a630

## Purpose

F-f884c002a630 distributes an original integer and an adjusted integer among three caller-provided storage locations. The adjustment is four times an integer argument. Two destinations receive the adjusted value; the remaining destination receives the original value.

The order of the writes matters when destinations share storage. The original-value write occurs last and can replace an adjusted value written earlier. Consequently, the routine does not unconditionally leave the input/output location adjusted.

An interpretation as advancing a position while preserving its previous value is plausible but **inferred**, not established. The available evidence does not identify units, a containing data structure, an address range, or a sequence being traversed.

### Access ordering

The visible semantics contain one integer read and three integer writes. The read from the input/output location precedes every write. Among the writes, the adjusted-value output is written before the input/output location, and the original-value output is written last.

This order determines the routine’s own aliasing results. An earlier write to the input/output object does not replace the captured original value used by the last write.

### Exact aliasing

When argument locations identify the same valid integer object, the last applicable write determines that object’s final value.

| Storage relationship | Final contents |
|---|---|
| All three locations distinct | Both adjusted-value destinations contain the adjusted value; the original-value output contains the original value |
| First and second locations identical; third distinct | Shared first/second object contains the adjusted value; third contains the original value |
