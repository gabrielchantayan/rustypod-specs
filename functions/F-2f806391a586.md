# F-2f806391a586

## Purpose

F-2f806391a586 sequences indirect calls, indexed memory transfers, shared-word replacements, and a final call to numerical address zero. The represented interface has no explicit return value.

The established behavior is data movement and call ordering. Allocation, initialization, serialization, cleanup, and application-level purpose are not established.

All operations described below depend on preceding calls returning normally and preceding accesses succeeding. An unused ordinary return value does not make a call dispensable: dependency side effects and implicit outputs are unresolved.

## Interface

### Explicit inputs and outputs

The interface accepts three 32-bit inputs:

| Input | Established use |
|---|---|
| First | No direct use in the represented body. Possible implicit calling-convention significance remains unknown. |
| Second | Passed to F-A001. |
| Third | Logically shifted right by 23, producing an unsigned value from 0 through 511. That value is stored as a word and used to locate a selector byte. |

There is no explicit output buffer or represented return value. Observable results include calls, memory writes, shared-state changes, and any fault or termination.

### Implicit inputs and shared storage

Execution additionally depends on:

- An incoming link-register value determining the F-A001 target.
- An incoming 32-bit register value used by the first word store.
- Secondary outputs outside represented ordinary return values.
- The byte at absolute address 1.
- A 32-bit **supervisor-associated word**, replaced twice.
- A 32-bit **shared pointer word**, read as an address.
- A three-byte shared value beginning at absolute address 9.

These descriptive names do not establish application meaning. Static evidence warns that some shared-storage views overlap, but does not identify all overlaps or establish that the two named words overlap each other.

A **retained unsigned value** supplies three linked uses: phase A’s second word-store address, F-A013’s argument, and phase B’s masked word-read address. Its exact secondary-output producer is unresolved; its reuse without replacement is established.

### Width and arithmetic rules

Direct accesses are 8, 16, or 32 bits wide, apart from the terminal three-byte shared-value access. F-E002, F-G013, and F-H004 each provide a represented 64-bit result, separated into low and high 32-bit halves.

Logical right shifts insert zeroes. Byte stores retain eight bits; word stores retain 32 bits. The final halfword store writes sixteen zero bits.

Unsigned 32-bit arithmetic retains the low 32 bits. Some multiplications and left shifts have signed-looking 32-bit intermediates; their overflow semantics are not independently established. Mathematical address descriptions below do not resolve that uncertainty.

No bounds, null, alignment, or permission checks are visible. Successful execution requires the relevant memory accesses and indirect calls to be valid under the target’s execution model.

## Behavior

### Ordering conventions

Dependency IDs identify call sites, not necessarily distinct implementations. “No explicit arguments” does not mean no implicit inputs.

The phases below specify represented call and direct-access order. Retained values are distinguished from fresh reads. No disjointness is assumed between computed addresses, shared storage, or dependency-accessible memory. ### Phase A — Initial calls and word stores

F-A001 receives the second input. Its target is the incoming link-register value plus `0xF38`; target interpretation and signed-arithmetic behavior remain unresolved.

F-A002 produces a 32-bit result. The third input’s logical right shift by 23 is established before F-A003 receives the F-A002 result.

F-A004, F-A005, and F-A006 execute in order without explicit arguments. F-A007 produces an index. The incoming implicit 32-bit register value is stored at four times that index plus 20. F-A008 receives four times the same index.

F-A009 through F-A012 execute in order without explicit arguments. The retained unsigned secondary value supplies the next operations: a 32-bit zero is stored at four times that value plus 20, then F-A013 receives the value unchanged.

### Phase B — Input-derived word and first selector transfer

F-B001 produces a result consumed by F-B002. F-B003 through F-B005 execute without explicit arguments. F-B006 produces an index.

The third input logically shifted right by 23 is stored as a 32-bit word at four times that index plus 20.

Next, a word-read address is derived from the retained unsigned value already used in phase A: retain its low 29 bits, logically shift right by 19, then add 20. A 32-bit word is read and captured. The address ranges from 20 through 1043 and need not be aligned.

F-B007 receives four times the F-B006 index. F-B008 through F-B011 execute without explicit arguments.

The captured word is logically shifted right by 22. A selector byte is read at the extracted third-input value plus one. The shifted word’s low byte is stored at the selector value plus 17.

F-B012 receives three copies of another unresolved secondary output, followed by zero. The entire shifted word—not only its stored low byte—is retained for phase C.

### Phase C — Selector clears and secondary-value retention

F-C001 executes without explicit arguments. F-C002 receives zero derived from an established local zero, not from the third input. F-C003 through F-C005 execute; F-C006 then produces an index.

A selector byte is read at four times the retained phase-B shifted word plus one. Zero is stored at that selector plus 17. F-C007 receives the F-C006 index shifted left by two.

F-C008 through F-C010 execute. F-C011 produces an index, and F-C012 receives two copies of that index shifted left by two.

F-C013 produces a 32-bit value consumed by F-C014. F-C015 executes. The byte at absolute address 1 is read, and zero is stored at that byte’s value plus 17.

Another unresolved secondary output is retained for later shifted arguments. F-C016 receives three copies of it.

### Phase D — Retained byte base and first shared-word replacement

F-D001 produces a result. F-D002 receives it and the F-C013 value logically shifted right by 23. F-D003 through F-D005 execute; F-D006 produces an index.

The byte at absolute address 1 is read again and retained as a base. Zero is stored at that base plus 17. F-D007 receives the F-D006 index shifted left by two.

F-D008 through F-D010 execute. F-D011 produces an index; F-D012 receives two copies of that index shifted left by two.

F-D013 produces a 32-bit value. The supervisor-associated word is replaced with that value before F-D014 receives it. F-D015 then executes.

A 32-bit word is read at the retained byte-derived base plus 116. Its low byte is stored at that base plus one. The base is not refreshed after the intervening calls.

### Phase E — Repeated low-byte transfers

F-E001 receives the saved phase-C secondary value shifted left by 11.

F-E002 produces a represented 64-bit result. F-E003 receives its low half, its high half, and the F-D013 value logically shifted right by 23.

F-E004 through F-E006 execute. F-E007 produces an index; four times that index becomes a retained base. A 32-bit word is read at that base plus 116, and its low byte is stored at the base plus one.

F-E008 receives the base. F-E009 through F-E011 execute. F-E012 produces an index, whose left shift by two is retained for later phases.

The word at the earlier base plus 116 is read again, and its low byte is again stored at the base plus one. This is a fresh read after the intervening calls.

F-E013 receives, in order:

1. The saved phase-C secondary value shifted left by 12.
2. The retained shifted F-E012 index.
3. Another copy of that shifted index.
4. The F-E012 index shifted left by 18.

### Phase F — Captured-word propagation and indexed linking

F-F001 produces a result consumed by F-F002. F-F003 produces a result consumed by F-F004. F-F005 through F-F007 execute.

F-F008 produces an index. A 32-bit word is read at four times that index plus 116 and retained through the later phases. Its low byte is stored at four times the same index plus one.

F-F009 receives four times the index. F-F010 through F-F012 execute. F-F013 produces another index. The retained word is stored at **sixteen times** that index plus 20.

F-F014 receives the retained phase-E shifted index logically shifted right by two, then shifted left by 16. The represented sequence is therefore: original F-E012 index shifted left by two, retained as an unsigned 32-bit value, logically shifted right by two, then shifted left by 16.

**Under 32-bit wrapping arithmetic, this sequence has exactly the same low 32 bits as shifting the original F-E012 index left by 16.** The intermediate operations discard the original index’s top two bits; neither could survive the final left shift by 16. This equivalence does not establish the semantics or validity of the earlier signed-looking left shift.

F-F015 produces a result consumed by F-F016. F-F017 produces a result consumed by F-F018. F-F019 through F-F021 execute.

F-F022 produces an index. The retained word is stored at four times that index plus 20. F-F023 receives four times the index.

F-F024 through F-F026 execute. F-F027 produces an index. That index shifted left by two is stored as a 32-bit word at the retained phase-E shifted index, with its low two bits cleared, plus 20. F-F028 receives two copies of the newly shifted value.

### Phase G — Zero store, paired result, and pointer capture

F-G001 produces a result consumed by F-G002. F-G003 produces a result consumed by F-G004. F-G005 through F-G007 execute.

F-G008 produces an index. A 32-bit zero is stored at four times that index plus 20. F-G009 receives four times the index. F-G010 through F-G012 execute.

F-G013 produces a represented 64-bit result. Its low half shifted left by two is stored as a 32-bit word at four times its high half plus 20.

The shared pointer word is read **after that store** and captured. F-G014 receives the shifted low half, the high half, and two further copies of the shifted low half.

F-G015 through F-G017 execute. F-G018 produces an index. The same shifted low half is stored at four times that index plus 20.

A 32-bit word is read at the captured pointer plus 20. F-G019 receives four times the F-G018 index.

Pointer capture and pointee read are separate events, separated by calls and a direct store. The pointer is not refreshed before the pointee read.

### Phase H — Final transfers and terminal sequence

F-H001 through F-H003 execute. F-H004 produces a represented 64-bit result.

A selector byte is read at one plus the phase-F retained word logically shifted right by 23. The phase-G pointee word’s low byte is stored at that selector plus 17.

F-H005 receives three copies of the F-H004 high half, followed by its low half shifted left by two.

F-H006 produces a result consumed by F-H007. F-H008 through F-H010 execute. F-H011 produces an index.

Another selector byte is read at one plus the F-H004 low half masked to 30 bits and logically shifted right by 21. The low byte of the phase-G pointee word logically shifted right by 22 is stored at that selector plus 17.

F-H012 receives the F-H011 index shifted left by two. F-H013 through F-H015 execute. F-H016 produces an index; F-H017 receives two copies of that index shifted left by two.

F-H018 executes. F-H019 produces a result consumed by F-H020. F-H021 produces an 8-bit result and an unresolved secondary pointer output.

The terminal operations occur in this order:

1. Store one zero byte through the secondary pointer.
2. Replace the supervisor-associated word with a composite: the three-byte shared value beginning at absolute address 9 supplies the upper 24 bits, and the F-H021 result supplies the low eight bits.
3. Store a 16-bit zero at the F-H004 low half masked to 30 bits and logically shifted right by seven.
4. Invoke F-Z001 at numerical address zero with three explicit zero arguments.

The secondary-pointer store precedes use of the three-byte shared value, so aliasing may affect the composite. The internal byte-read order of the three-byte access is not established.

No normal-path condition guards the final call. The function reaches its represented return only if that call returns normally.

## Acceptance examples

These are conditional static obligations, not executed tests. Required accesses must succeed and preceding dependencies must return normally.

1. **Call ordering.** F-A004, F-A005, and F-A006 execute in that order after F-A003 and before F-A007. Omitting a call is not equivalent when its effects are unknown.

2. **Cross-phase retained value.** For retained unsigned value `0x00080003`, phase A’s second word store targets `0x00200020`, and F-A013 receives `0x00080003`. Phase B’s masked word-read address is 21, using the same captured value.

3. **Read timing.** That phase-B read occurs after its extracted-input word store. If an earlier operation changes the bytes at address 21, the read reflects their value at read time, not at phase-A capture time.

4. **Third-input boundaries.** Third inputs `0x007FFFFF`, `0x00800000`, and `0xFFFFFFFF` yield extracted values 0, 1, and 511. Phase B stores those word values and reads selectors at addresses 1, 2, and 512.

5. **Full shifted-word retention.** A phase-B captured word of `0xFFC00000` becomes `0x000003FF` after the logical shift by 22. Its byte store writes `0xFF`, but phase C reads its selector at address 4093.

6. **Fresh repeated read.** If phase E’s first source read has low byte `0x12`, and an intervening dependency changes it to `0x34`, the two byte stores write `0x12` and `0x34`.

7. **Retained byte-derived base.** If phase D reads 7 at absolute address 1, its clear targets 24. Its later word read and byte store use addresses 123 and 8, even if an intervening call changes address 1.

8. **Different strides.** A phase-F index of 3 gives address 68 for the sixteen-times-index store. A four-times-index store with index 3 targets address 32.

9. **F-F014 wrapping equivalence.** Under a 32-bit wrapping interpretation, an original F-E012 index with bit pattern `0xC0001234` gives retained shifted value `0x000048D0`. Logical right shift by two gives `0x00001234`; the final left shift by 16 gives `0x12340000`. Directly shifting the original pattern left by 16 gives the same low 32 bits. This example does not resolve signed-shift validity.

10. **Captured pointer, later pointee.** If phase G captures pointer value 256, its later pointee read addresses 276. Replacing the shared pointer with 512 does not redirect that read; changing memory at 276 can change the captured word.

11. **Terminal width and failure.** An F-H004 low half of `0xFFFFFFFF` gives halfword address `0x007FFFFF`, without alignment correction. If the earlier secondary-pointer byte store faults, the later terminal operations are not reached on the normal path.

12. **Composite significance.** If the three-byte shared value is numerically `0x123456` when used, and F-H021 returns `0xAB`, the replacement word is `0x123456AB`. This specifies numerical significance, not physical byte order.
