## Behavior

### Initial state and entry decision

The function first initializes the local mutable slot from the second input. It then tests the original second input against zero.

If that input is zero:

- F-d3922c7fe0ec is not called.
- F-008d77a63c85 is not called.
- The function returns the first input.

A nonzero second input enables the loop. There is no visible positive-range requirement: the entry condition distinguishes zero from nonzero, not positive from negative.

### Loop interaction

For an enabled invocation, the function calls F-d3922c7fe0ec with the address of the local mutable slot. This call occurs before any processing call and before each later decision to process another result.

If F-d3922c7fe0ec returns zero, the function exits the loop without calling F-008d77a63c85 for that result.

If F-d3922c7fe0ec returns nonzero, the function calls F-008d77a63c85 with these arguments, in order:

1. The original first input.
2. The nonzero integer result just obtained from F-d3922c7fe0ec.
3. The fixed integer value one.

If that processing call returns normally, the function calls F-d3922c7fe0ec again using the same local slot address.

The return value of F-008d77a63c85 is discarded. No visible condition based on that return value stops the loop, changes the next arguments, or changes the final return value.

### Mutable state versus termination

The local state’s current value is not itself tested as the loop’s continuation condition. Only the returned integer from F-d3922c7fe0ec controls whether a processing call occurs.

Consequently:

- A dependency may write zero to the local slot yet return nonzero; the function still performs the processing call.
- A dependency may leave the slot nonzero yet return zero; the function stops.
- After a processing call returns, the next F-d3922c7fe0ec call occurs without an intervening visible test of the local slot.

The function does not visibly reset the slot between dependency calls. Mutations made through its address can therefore affect later calls. The meaning of those mutations is not established.

### Ordering guarantees

- Each nonzero result-producing call completes before its corresponding processing call begins.
- That processing call completes before the next result-producing call begins.
- A zero result-producing call has no corresponding processing call.

If there are exactly \(n\) nonzero results followed by a zero result, with every call returning normally, the function makes \(n+1\) calls to F-d3922c7fe0ec and \(n\) calls to F-008d77a63c85.

## Acceptance examples

These examples are conditional on the dependencies accepting the supplied arguments and returning as described. They are specification cases, not executed tests.

### Initially zero state

Given any first input and a zero second input, the function returns the first input without calling either dependency.

This remains true even if the first input would be invalid for F-008d77a63c85, because that dependency is not reached.

### Immediate stop after entering

Given a nonzero second input, suppose the first F-d3922c7fe0ec call returns zero.

The function makes one result-producing call, makes no processing calls, and returns the first input. Any mutation of the local slot during that call does not alter this decision.

### Two processed results

Given an enabled invocation, suppose successive F-d3922c7fe0ec results are 12, 29, and zero.

The function processes 12 before requesting 29, processes 29 before requesting the terminating zero, and makes no processing call for zero. Both processing calls receive the original first input and the final argument one.

### Zero state with a nonzero result

Suppose F-d3922c7fe0ec writes zero into the local slot but returns 7.

The function still processes 7. If processing returns normally, it then calls F-d3922c7fe0ec again with the same slot address, now containing zero unless intervening dependency effects changed it.

### Nonzero state with a zero result

Suppose F-d3922c7fe0ec leaves a nonzero value in the local slot but returns zero.

The function stops without processing that slot value. The state value is not substituted for the dependency’s result.

### Negative result

That value is nonzero, so it is forwarded as the second processing argument. The function does not treat it as an error sentinel.

### Processing return does not terminate
