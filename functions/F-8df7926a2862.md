## Acceptance examples

These are conditional static acceptance examples, not test results. Each assumes all preceding operations are reachable and complete.

1. **Shifted initial read.** If the word read at the second implicit address plus `0x14` is `0x0000001f`, the first explicit argument to F-e00000000001 is three.

2. **Seed masking.** A seed of `0xc0000000` produces a reduced seed of zero and an upper fragment of zero. Under the 32-bit address model, the primary base is also zero. This does not establish that the resulting low-address accesses are valid.

3. **Byte-selected destination.** A byte read of `0xff` selects byte address `0x110` after adding `0x11`. If retained for the later word clear, it selects word address `0x143`, which may be unaligned.

4. **Upper-fragment truncation.** For `0x3fffffff`, masking and shifting yield `0x3ff`; the one-byte store writes `0xff`.

5. **Low-byte scaling.** A late word of `0x00000041` produces a byte value of `0x04` when multiplied by four and truncated. That stored byte does not replace the full word retained for later calculations.

6. **Intervening mutation.** If a dependency changes `byte[primary base + 1]` between its two reads, the nonzero-fragment write and subsequent zero write may target different addresses.

7. **Retained selector.** If a dependency changes `byte[secondary base + 1]` after its retained read, the later word clear still uses the earlier byte value.

8. **Non-returning dependency.** If F-e00000000045 does not return, no later direct effect is required. Earlier writes are not rolled back by any visible mechanism.

9. **Terminal boundary.** Reaching the final represented boundary does not satisfy an acceptance condition requiring successful return; such behavior is undocumented.
