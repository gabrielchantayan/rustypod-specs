## Behavior

Relationships include low words shifted left by 8, high words passed unchanged or shifted, repeated argument values, masks, logical right shifts, and explicit zeros. ### Descriptive quantities

The following terms describe value relationships, not recovered fields:

- **Scaling result:** a scalar dependency result used for later scaling.
- **Scaled base:** the scaling result multiplied by 2²⁵.
- **High-shift base:** a different dependency result shifted left by 25.
- **Small index:** a later scalar result shifted left by 8, masked to 15 bits, then logically shifted right by 6.
- **Doubled index:** twice the small index.
- **Retained shifted argument:** an earlier scalar result shifted left by 8 and retained across subsequent calls.
- **Terminal result:** the combined result returned immediately before explicit stores.

Under bit-vector arithmetic, the small index ranges from 0 to 508 in multiples of 4; the doubled index ranges from 0 to 1016 in multiples of 8.

### Initial updates and the 0x05 observation

The first explicit word store places the high-shift base at the terminal high word plus 0x14. An explicit byte at high-shift base plus 9 receives the terminal high word’s low byte. Before that byte is replaced with the high-shift base’s low byte, an explicit word destination at terminal low word multiplied by 256, plus 0x54, receives the scaled base.

The word at scaled base plus 0x14 is cleared. An explicit unsigned byte is then read at scaled base plus 5. Before its widened value is stored as a word at scaled base plus 0x34, the word at doubled index plus 0x14 is cleared.

The word at scaled base plus 0x14 is subsequently read. The doubled-index offset-0x14 word is cleared again, followed by two explicit byte stores of the read word’s low byte at doubled index plus 0x15. The word read cannot automatically be replaced with zero because preceding accesses can alias it.

Next, the named global at 0x05 is observed and converted to an unsigned 32-bit value. Call that converted value the **fixed-source base**. Its range is not established as byte-sized.

Only after that observation is the named global at 0x01 assigned an explicitly reduced 8-bit doubled index. An explicit byte at fixed-source base plus 0x15 then receives the small index’s low byte. The 0x01 assignment’s storage width remains unresolved.

An explicit byte at scaled base plus 0x11 receives the retained shifted argument’s low byte. The retained shifted argument is then stored as a word at the previously read word plus 0x54, after which the scaled-base offset-0x11 byte is cleared.

## Acceptance examples

These are conditional static consequences, not executed tests.

- **Logical extraction:** A combined result with high word 0x80000010 yields 0x08000001 when logically shifted right by 36 bits and reduced to a working word.

- **Index boundary:** Under bit-vector arithmetic, index-source 0x7f produces small index 508 and doubled index 1016; source 0x80 produces zero. For the first case, the values supplied to the named 0x01 and 0x15 assignments are 0xf8. Their storage widths remain unresolved.

- **No byte-bound inference:** If the 0x05 observation converts to unsigned 32-bit value 0x1234, the fixed-source base is 0x1234, not 0x34. The representation does not require rejecting or truncating it to a byte.

- **Doubled retained value:** Retained word 0x12345678 produces assignment value 0x2468acf0 for the named global at 0x54 under bit-vector arithmetic. This does not prove a four-byte store there.

- **Captured publication base:** If the later 0x60 assignment changes the publication-base source storage, publication still uses the already captured working value.

- **Tail interleaving:** If the actual 0x3a assignment footprint overlaps tail base plus 0x14, that explicit word capture occurs afterward. Its value depends on the actual store conversion, footprint, byte order, and surrounding bytes.

- **Fresh named observations:** If an intervening computed store changes the storage read through 0x67, a later explicit byte destination receives the current observation after applicable conversion, not necessarily the initially assigned value.

- **Established destination width:** The explicit halfword store of 0x65 writes 16 bits. An explicit byte store from 0x123456ab writes 0xab.

- **Interrupted execution:** If an early dependency does not return, subsequent stores and the final transfer need not occur. No compensating rollback is established.
