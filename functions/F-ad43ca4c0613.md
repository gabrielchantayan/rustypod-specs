# F-ad43ca4c0613

## Purpose

F-ad43ca4c0613 describes an operation that combines ordered external invocations with narrow memory accesses and retained execution-state values. Its directly represented effects include byte writes, two halfword reads, a word write through a retained pointer, and an assignment to a distinguished global location.

No application-level purpose is established. Initialization, clearing, resource release, decoding, and device configuration are possible interpretations, not contractual behavior. In particular, the operation is not generally a zeroing operation: different write regions use an incoming byte, explicit zero, an address-derived byte, and several distinct portions of retained values.

This specification distinguishes:

- **Established static evidence:** explicitly represented access widths, value provenance, argument relationships, and ordering.
- **[INFERENCE]:** conclusions that require an additional execution-model assumption.
- **documented_only:** unresolved behavior that must not be replaced with an assumed implementation.

All requirements for a later event are conditional on execution reaching that event. No runtime tests have been performed.

## Behavior

### Ordering and dependency boundaries

The operation has an ordered, non-transactional progression. Direct memory effects occur between external invocations; the calls are not interchangeable placeholders.

The opening target depends on the incoming control-link value displaced by 4,094. Most later targets instead depend on embedded control-location values with the same displacement. F-U003 uses a distinct calculation that clears the lowest two bits of an embedded control-location value before adding 1,536.

Dependency interactions include:

- Passing a newly obtained primary result scaled by four.
- Passing a primary result unchanged.
- Forwarding a result from an interaction that received a scaled argument.
- Passing equal arguments derived from one value.
- Passing secondary outputs rather than primary results.
- Invocations with no displayed explicit arguments.

One interaction in the later retained-byte region uses a primary result scaled by two rather than four. Calls with unused results and calls without explicit arguments still occur. Neither form establishes absence of side effects or implicit inputs.

The following regions describe observable memory behavior and significant argument relationships. They do not constitute a complete per-invocation trace or identify dependency implementations.

### Incoming-byte region

Twenty represented byte writes use the incoming byte. Its value is not refreshed from memory between those writes.

Ordinary writes in this region use a primary result scaled by eight as the destination. The immediately associated dependency receives two equal arguments, each formed by scaling that originating result by 16,384. Scaling the destination does not enlarge the access: each event writes one byte.

Three exceptions affect acceptance:

- The write following F-U003 uses twice F-U003’s primary result as its destination. The associated equal arguments use a factor of 4,096. F-U003 itself receives four times a preceding primary result.
- One eight-scaled destination is followed by a four-argument interaction. Arguments one, two, and four are the originating result scaled by 16,384. Argument three is the incoming 32-bit value scaled by 1,024. The following interaction consumes a secondary output scaled by eight.
- The last incoming-byte write still uses an eight-scaled destination, but its associated equal arguments use a factor of four.

At several boundaries, the result of the equal-argument interaction is subsequently scaled by four and passed onward. That returned value is distinct from the earlier result that selected the byte destination.

### Composite-result handling

Three dependency results are represented as 64-bit quantities. Each is consumed as low and high numerical 32-bit portions.

The first two receivers obtain three arguments in the order **low portion, high portion, high portion**. These occur during the incoming-byte region. The third receiver, later in the reduced-byte region, obtains only **low portion, high portion**.

These relationships do not establish a memory serialization format, endianness, or a language-level 64-bit return convention. Repeating the high portion is significant; replacing either three-argument receiver with a two-argument receiver changes the represented interaction.

### Explicit-zero and address-derived regions

After the incoming-byte region, six byte-write events explicitly store zero. Each destination is an originating result scaled by eight; each associated equal-argument interaction uses a factor of 16,384.

A subsequent event instead stores an address-derived byte at an eight-scaled destination. The supplied value is obtained by narrowing that destination to a character-sized value. Under ordinary low-eight-bit storage interpretation, the stored pattern is the destination modulo 256.

Its associated dependency receives three arguments: two copies of the originating result scaled by 16,384, followed by the calculated destination itself.

The character conversion’s treatment of out-of-range values remains **documented_only**. This event must not be classified as an explicit-zero write.

### Retained-byte region

A later unsigned 32-bit primary output establishes a new retained byte: the low eight bits of that output scaled by eight. Its first destination is the same unsigned output scaled by sixteen. The associated dependency receives two equal values formed with a factor of 32,768.

This byte is then reused across later destinations. It is not recomputed from each new primary result.

The destination and argument relationships include:

| Destination basis | Byte destination factor | Associated equal-argument factor |
|---|---:|---:|
| An earlier retained scaled result | 65,536 | 134,217,728 |
| Later primary results at several boundaries | 8,192 | 16,777,216 |
| A second retained intermediate | 4,096 | 8,388,608 |
| Later primary results in ordinary byte boundaries | 8 | 16,384 |
| The final ordinary retained-byte boundary | 8 | 4 |

The earlier retained scaled result originates at a preceding incoming-byte boundary, where a primary result was scaled by 16,384. Before using its 65,536-scaled destination, the operation also derives the second retained intermediate by multiplying that retained scaled result by 32,768.

The second intermediate later supplies both the 4,096-scaled destination and a saved high byte. Neither is derived from the then-current primary result. Combining all these factors into one mathematical product is justified only after specifying intermediate widths and overflow behavior.

### First halfword read and global assignment

A retained-byte write to a primary result scaled by 8,192 is followed by the first halfword read. The read begins 56 bytes beyond that same result scaled by 4,096. No external invocation intervenes between the byte write and the read.

The following dependency receives the calculated 4,096-scaled base first and the freshly read 16-bit quantity second. The representation does not independently establish the ABI’s extension of that quantity into an argument slot.

Under ordinary byte addressing with exact arithmetic, or with 32-bit modular address arithmetic, this byte destination cannot overlap the two-byte read region. The relevant address difference cannot equal zero or one because of the 56-byte displacement. Unusual memory aliases remain unresolved.

After additional external interactions, the retained byte is assigned to the distinguished global location. The next invocation has two explicit zero arguments.

This establishes an assignment event, not a persistent final value. Later dependencies may modify the global. Additional retained-byte writes occur after this assignment.

### Separate unsigned bit slice

After the ordinary retained-byte writes, a different byte is derived from the unsigned output that originally established the retained byte.

This value selects original bit positions 19 through 26. The represented calculation first excludes bits above bit 28 and then shifts right by nineteen; narrowing to one byte excludes original bits 27 and 28 as well.

The byte is written at a later primary result scaled by eight. Its associated dependency receives two equal arguments formed by scaling that later result by four.

This value must remain distinct from both the retained low byte and the saved-high-byte reduction used subsequently.

### Saved-high-byte and reduced-byte region

The saved high byte is the unsigned highest byte of the second retained 32-bit intermediate. Its capture occurs after the interaction associated with that intermediate’s 4,096-scaled byte write.

Later byte writes use the saved high byte reduced by an unsigned right shift of five. The resulting byte is between zero and seven. This is not a signed-byte operation and is not a repeated reduction of an already reduced value.

Most destinations in this region are primary results scaled by eight. Many are followed by equal arguments using a factor of 16,384, but that is not universal: some writes are followed by calls without displayed explicit arguments, and one is followed by the second halfword-read interaction.

One intervening destination depends on the unresolved right shift by 32. Before that shift, its primary result has already been scaled by four. The unresolved result supplies a doubled byte destination and equal arguments scaled by 4,096. The byte value remains the reduced saved high byte; the destination and argument values are **documented_only**.

### Secondary pointer and retained scalar state

A secondary pointer-valued output supplies three distinct later uses:

- Its represented numerical value scaled by 256 selects a reduced-byte destination. The associated equal arguments use a factor of 524,288.
- Its numerical value scaled by 128, plus 32 bytes, selects the second halfword-read location.
- The pointer itself is the destination of the eventual 32-bit indirect write.

These uses do not establish pointer ownership or lifetime preservation.

The second halfword read occurs after another reduced-byte write, without an intervening external invocation. The receiver obtains the freshly read halfword as its sole displayed explicit argument. Unlike the first read’s receiver, it does not also receive the calculated base.

A separately retained secondary 32-bit value selects a reduced-byte destination using a factor of 2,048 and equal arguments using a factor of 4,194,304. Several later two-argument interactions combine a fresh primary result scaled by four with that retained secondary value. The two arguments have different provenance and need not be equal.

Other secondary word outputs are passed onward individually. A primary result must not be substituted merely because it is the most recently displayed return value.

### Indirect word write and tail

Near the tail, one primary result determines an eight-scaled byte destination and a word value equal to four times that result.

The reduced saved-high-byte value is written to the byte destination first. The scaled word is then written through the retained pointer. No external invocation occurs between those writes. The following dependency receives three copies of the scaled word.

The destinations have no established non-aliasing guarantee. If they overlap, the word write can overwrite the earlier byte. Its byte-level effect depends on memory representation.

A later interaction receives two copies of a newly returned, unscaled word. Another later interaction combines a fresh result scaled by four with the retained word used by the indirect write.

Further reduced-byte writes and dependency interactions follow the indirect write. Eventually, F-U005 is supplied with zero and an embedded control-location marker, and the resulting target is invoked through F-U004. Exception delivery, termination, handler transfer, and any return behavior are **documented_only**.

## Acceptance examples

These are conditional static review criteria, not executed tests. Each assumes that execution reaches the boundary, accesses are valid, and the stated arithmetic interpretation applies.

1. **Ordinary incoming byte.** An originating result of 5 with incoming byte 0xA6 gives destination 40 and equal arguments of 81,920. Exactly one byte is written.

2. **Exceptional final incoming-byte boundary.** An originating result of 5 still gives destination 40, but equal arguments are 20. The ordinary factor of 16,384 is incorrect here.

3. **Address-derived byte.** An originating result of 35 gives destination 280 and, under low-eight-bit narrowing, stored value 24. The third associated argument is 280, not 24 or zero.

4. **Retained unsigned byte.** An unsigned output of 33 establishes retained byte 8, immediate destination 528, and equal arguments of 1,081,344. Later retained-byte writes still use 8 even when subsequent primary results differ.

5. **Independent bit slice.** Unsigned output 0x08480021 establishes retained byte 8 but supplies byte 9 at the separate bit-slice boundary. The pre-narrowing slice is 265; storing 265 is not an 8-bit write.

6. **Unsigned high-byte reduction.** A saved high byte of 0xE0 supplies reduced value 7; 0x20 supplies 1. Later reuse must not shift either reduced value by five again.

7. **Composite argument order.** Low portion 0x11223344 and high portion 0x55667788 require low, high, high at either three-argument receiver, and low, high at the two-argument receiver.

8. **First read.** An originating result of 1 gives byte destination 8,192 and halfword-read address 4,152. The next dependency receives base 4,096 and the read quantity. These accesses do not overlap under ordinary addressing.

9. **Global mutation.** A later dependency may change the global after its direct assignment. Restoration is not required; omission of the assignment is not equivalent behavior.

10. **Second read.** For a retained pointer with numerical value 16, the calculated read address is 2,080. The receiver is supplied the read halfword alone, not an additional base argument.

11. **Overlapping stores.** If the indirect word destination overlaps the preceding byte destination, both writes remain required in byte-then-word order. The following three arguments remain copies of the scaled word.

12. **Width-sensitive retained addresses.** Under an explicitly adopted 32-bit modular model, scaling the earlier retained 16,384-multiple by 65,536 produces zero. The second retained intermediate is a multiple of 536,870,912, whose later 4,096 scaling also produces zero. These consequences are not unconditional signed-arithmetic guarantees.

13. **Interrupted progression.** If a dependency does not return, later accesses are not required. Earlier writes do not prove ordinary completion.

14. **Unresolved terminal behavior.** Reaching F-U005 does not establish a specific exception or successful return. A concrete destination for the shift-by-32 boundary likewise requires additional execution-semantics evidence.
