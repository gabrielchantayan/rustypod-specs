# F-e58a9056da68

## Purpose

The supplied static representation establishes no normal return path. Every iteration that reaches its end starts another iteration. Execution can nevertheless stop earlier through a fault, breakpoint handling, or behavior of an unknown dependency.

No application-level purpose is established. In particular, the available evidence does not justify describing this function as initialization, decoding, allocation, device control, or data-structure maintenance.

## Behavior

### Initial writes

Before entering the repeated sequence, the function forms a destination from the sum of the second and third inputs.

It then performs, in order:

1. A 32-bit write of the second input to that destination.
2. A 32-bit write of the third input to the same destination.

There is no intervening visible call or read.

If both writes complete to ordinary memory and nothing independently modifies that location, the second write determines its resulting contents. The first write is nevertheless part of the represented access sequence. It must not be discarded when describing potentially observable memory, such as memory-mapped registers.

The destination is not recomputed or written again by this initial sequence on later iterations.

2. Invoke F-U02, then F-U03.
3. Read global slot A and retain the resulting 32-bit value as the **first object base**.
4. Invoke F-U04.
5. Invoke F-U05 and split its represented 64-bit result into low and high 32-bit components.

8. Invoke F-U07.
9. Write a zero byte to first object base + 0x15.

The first object base is captured before F-U04 and reused after several calls. There is no visible reload of global slot A for either byte write. Changes made by those intervening calls to the global slot therefore do not, by themselves, change the retained destination base.

The auxiliary destination used after F-U08 is not established to be the same object as the first object base.

3. Write a 32-bit value to context base + 0x26c. The value is the low component shifted right logically by 26 bits.
4. Establish the constant value 0x21c48960 for subsequent operations.
5. Invoke F-U10.
6. Read a 32-bit pointer/value from context base + 0x320 and retain it as the **second object base**.

2. Write the field value as a 32-bit word to third object base + 0x54.
3. Invoke F-U30.
4. Write the same retained field value as a 32-bit word to third object base + 0x64.

## Acceptance examples

These are conditional static acceptance cases, not executed tests.

- **Initial overwrite:** If the second input is 0x1000 and the third input is 0x20, with valid address arithmetic and writable ordinary memory, the initial destination is 0x1020. The represented writes store 0x1000 first and 0x20 second.

- **Paired-result shifts:** If F-U09 provides low component 0xfc000003, the context-relative write at offset 0x26c stores 63. Under 32-bit bit-vector left-shift semantics, the later write at second object base + 0x54 stores 0xf000000c.

- **Global-slot mutation:** If global slot A initially supplies address P, and F-U04 changes the slot to Q, the later byte writes still target P + 0x11 and P + 0x15, subject to valid retention of the represented value.

- **Zero-extension:** If the halfword read from the F-U28 high component + 0x14 is 0xffff, the two later 32-bit field writes contain 0x0000ffff, not 0xffffffff.

- **Maximum index arithmetic:** An index value of 0xffff produces scaled index 0x3fffc, a word destination of 0x40070, and a byte-read address of 0x4fffb. These calculations do not overflow 32 bits; their memory validity is a separate requirement.

- **Breakpoint termination:** If the breakpoint handler does not resume execution, none of the operations after that breakpoint occur. Earlier writes and dependency effects remain possible.

- **Repetition:** If the breakpoint resumes, all dependencies return, and all memory accesses succeed, completing an iteration does not return to the caller. The sequence repeats using the updated represented context state.
