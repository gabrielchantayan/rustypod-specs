# F-8d6bb237655f

## Purpose

F-8d6bb237655f is a status-gated operation that compares two differently sized fields, conditionally invokes a dependency, and writes selected one-byte destinations.

Its established behavior has three principal paths:

- A nonzero incoming status causes a call to F-b0f922796692 and is returned unchanged.
- A zero incoming status with matching comparison fields causes a call to F-0bbf0f39df9a. A nonzero status from that dependency causes a call to F-b0f922796692; a zero status causes a one-byte write.
- A zero incoming status with different comparison fields causes one mandatory one-byte write and, depending on two additional inputs, a second one-byte write. This path returns zero.

The role of F-b0f922796692 is not established. Its placement suggests an error-associated action, but the supplied evidence does not establish cleanup, deallocation, rollback, logging, or ownership transfer.

## Behavior

### 1. Incoming-status gate

The signed 16-bit explicit status is sign-extended to 32 bits.

If that value is nonzero:

1. F-b0f922796692 is called with the descriptor address.
2. If the dependency returns normally, the function returns the sign-extended incoming status.

This path does not directly read either comparison field, read the dependency-value slot, inspect the gate record, or write any of the three destination bytes.

The call’s return value is not used to choose the function’s result.

### 2. Comparison when the incoming status is zero

For a zero incoming status, the function obtains:

- The unsigned byte at offset 9 of the record identified through the source-address slot.
- The unsigned 16-bit field at offset 2 of the descriptor.

The byte is compared numerically with the full unsigned 16-bit descriptor field. The byte is zero-extended; it is not treated as a signed 8-bit value.

Consequently:

- A source byte of 255 can equal a descriptor field of 255.
- A descriptor field greater than 255 cannot equal any source byte.
- Equality is not a comparison of only the low byte of the descriptor field.

Loading the source record’s base address necessarily precedes accessing its byte field. Both comparison values are obtained before choosing the matching or differing path. The supplied representation does not independently establish a hardware-level order between the two comparison operands’ reads.

### 3. Matching comparison fields

If the two values are equal:

1. The function reads the 32-bit value from the dependency-value slot.
2. It calls F-0bbf0f39df9a with:
   - The descriptor address.
   - That loaded 32-bit value.
3. It interprets the returned status as signed 16-bit and sign-extends it to 32 bits.

The returned status selects one of two outcomes.

**Nonzero dependency status**

F-b0f922796692 is called with the descriptor address. If it returns normally, the function returns the sign-extended dependency status.

There is no direct write to the match destination, difference destination, or additional destination on this branch.

**Zero dependency status**

The marker is written as one byte to the match destination. The function returns zero.

There is no direct write to the other two destinations on this branch.

The match write occurs after F-0bbf0f39df9a returns. The function does not repeat the field comparison after that call. Changes made by the dependency to the compared records therefore do not trigger a new matching decision within this operation.

### 4. Differing comparison fields

If the two comparison values differ, the function first writes the marker to the difference destination.

Only after that write does it inspect the gate record’s byte at offset 12.

**Nonzero gate byte**

The marker is written to the additional destination. The function returns zero.

The mode and auxiliary selector do not affect this outcome.

**Zero gate byte**

The mode and auxiliary selector determine whether the additional write occurs:

| Unsigned 16-bit mode | Auxiliary selector | Additional destination |
|---|---|---|
| 0 or 1 | Zero | Not written |
| 0 or 1 | Nonzero | Marker written |
| 2 through 65535 | Any value | Marker written |

Thus, the additional write is omitted only when all three conditions hold:

- The gate byte is zero.
- The mode is less than 2.
- The auxiliary selector is zero.

Mode 1 has no special outcome distinct from mode 0. Both are governed by the auxiliary selector when the gate byte is zero.

This entire differing-field path returns zero. It makes neither dependency call.

## Side effects

### Direct memory effects

The function directly performs only the destination writes described above:

- One match-destination write after a matching comparison and a zero dependency status.
- One mandatory difference-destination write after a differing comparison.
- At most one additional-destination write following that difference write.

It does not directly modify the explicit status input, the dependency-value slot, or either comparison field.

That statement concerns addressed writes, not non-aliasing. The supplied evidence establishes no disjointness guarantee between inputs and destinations.

For example, if the difference destination aliases the gate byte, the mandatory marker write occurs before the gate read. The write can therefore change the gate value used by the subsequent decision.
