# F-d8b7e596d53f

## Purpose

F-d8b7e596d53f issues three ordered indirect notifications to a supplied receiver. Each notification carries a Boolean derived from a different two-bit field in a 32-bit control word associated with the first input.

The three predicates are exact masked equalities, not general tests for whether any masked bit is set. Each is true only when the lower bit of its selected pair is set and the upper bit is clear.

The supplied static representation establishes the selected offsets, predicates, receiver argument, and notification order. It does not establish the application-level meaning of the flags or notifications. Interpreting the notifications as enabling particular features is inferred intent, not part of the established contract.

## Behavior

### First notification

The function selects the indirect target at dispatch-table byte offset `0xC4`.

It reads the control word at control-record offset `0x48` and applies mask `0x00000600`. The Boolean argument is true exactly when the masked value equals `0x00000200`.

Equivalently:

- Bit 9 must be set.
- Bit 10 must be clear.
- Other bits do not affect this predicate.

The selected target receives the receiver address followed by this Boolean.

### Second notification

If execution continues after the first invocation, the function selects the indirect target at dispatch-table byte offset `0xB8`.

It reads the control word again and applies mask `0x00006000`. The Boolean argument is true exactly when the masked value equals `0x00002000`.

Equivalently:

- Bit 13 must be set.
- Bit 14 must be clear.
- Other bits do not affect this predicate.

The selected target receives the same receiver address followed by this Boolean.

### Third notification

If execution continues after the second invocation, the function selects the indirect target at dispatch-table byte offset `0xA4`.

It reads the control word again and applies mask `0x00001800`. The Boolean argument is true exactly when the masked value equals `0x00000800`.

Equivalently:

- Bit 11 must be set.
- Bit 12 must be clear.
- Other bits do not affect this predicate.

The selected target receives the same receiver address followed by this Boolean.

The supplied representation models this final indirect transfer as a call followed by return. That model does not resolve the underlying transfer mechanism.

### Predicate boundaries

For each selected two-bit field, the four possible patterns have the same interpretation:

| Selected pair, upper bit then lower bit | Boolean |
|---|---|
| `00` | False |
| `01` | True |
| `10` | False |
| `11` | False |

In particular, setting both bits does not produce true. Bits outside the applicable mask are irrelevant to that individual calculation.

All three calculations operate on the represented unsigned 32-bit word. There is no signed comparison, shift, multiplication, or arithmetic accumulation in these predicates. A set high bit outside the masks does not alter their results.

### Ordering and repeated observations

The invocation order is established:

1. Dispatch offset `0xC4`.
2. Dispatch offset `0xB8`.
3. Dispatch offset `0xA4`.

There is no branch that intentionally skips a notification when its Boolean is false. False is passed to the selected target.

The control word is represented as a separate read for each notification. It is not captured once at entry for all three decisions. Consequently, effects of an earlier invocation can influence a later predicate if they modify the control word and execution remains valid.

The receiver’s dispatch-table address is likewise re-evaluated for each represented invocation. An earlier target can therefore affect a later target selection if it changes the receiver’s table pointer or relevant table entries.

For a single invocation, both target selection and Boolean calculation must be completed before the target is entered. The supplied representation does not establish the relative order of the receiver/table reads and the control-word read within that invocation. It therefore does not justify a finer-grained memory-access trace.
