# F-f3e5a887c66a

## Purpose

F-f3e5a887c66a selects a destination associated with a descriptor and invokes one of several callback paths. It either:

- Invokes a descriptor-provided callback and returns a subsequently read parser-state word.
- Selects a destination and passes its address through a parser-provided callback, returning that callback’s result.
- Reports an invalid context selection through F-4457a9a44a68 and returns the 32-bit value `0x000000A0`.

**Established behavior:** selection depends on two descriptor bytes and, on one path, a signed parser-state index.

**Inferred intent:** the descriptor bytes appear to classify destination scope and processing mode. This contract does not assign domain-specific meanings to their numeric values.

## Interface

### Inputs

The interface has four arguments, represented as 32-bit quantities in the supplied static evidence:

| Argument | Contract name | Role |
|---|---|---|
| First | Context | Address used to derive embedded destinations and read an indexed-region base |
| Second | Parser | Address of state containing callback pointers, a result word, and an index |
| Third | Descriptor | Address of a record containing a diagnostic word, selector bytes, and a callback pointer |
| Fourth | Auxiliary value | A 32-bit value assigned to temporary storage on paths that do not pass that storage to a selected callback |

The address-bearing arguments are not validated. Their validity requirements depend on the selected path.

### Referenced layouts

Offsets below are byte offsets from the corresponding input address. They describe only fields used by this function, not complete object layouts.

**Descriptor:**

| Offset | Width | Use |
|---|---:|---|
| `+0x00` | 32 bits | First descriptor word, passed to F-4457a9a44a68 on the error path |
| `+0x04` | 8 bits | Destination selector |
| `+0x05` | 8 bits | Processing-mode selector |
| `+0x08` | 32 bits | Descriptor callback pointer, used only for mode `0x0A` |

**Parser:**

| Offset | Width | Use |
|---|---:|---|
| `+0x0C` | 32 bits | Result word read after the descriptor callback returns |
| `+0x40` | 32 bits | General processing callback pointer |
| `+0x44` | 32 bits | Alternate processing callback pointer |
| `+0x60` | Signed 32 bits | Index used for indexed destination selection |

**Context:**

| Offset | Use |
|---|---|
| `+0x8C` | Default destination address |
| `+0xA4` | Destination address for selector `0x02` |
| `+0xC4` | Destination address for selector `0x04` |

Computing a destination address does not itself read the memory at that destination. In particular, choosing Context plus `0x8C`, `0xA4`, or `0xC4` does not establish that those regions are accessible to a later callback.

### Output

The output is a 32-bit word. Its source is path-dependent:

- Mode `0x0A`: the word at Parser plus `0x0C`, read after the descriptor callback returns.
- Invalid indexed selection: `0x000000A0`, after F-4457a9a44a68 returns.
- All other completed paths: the return word from the selected parser callback.

No common interpretation of these three output sources is established.

## Behavior

### 1. Initial mode read

The function first reads the 8-bit processing-mode selector at Descriptor plus `0x05`. It also establishes a temporary destination value equal to Context plus `0x8C`.

The mode read occurs before any descriptor destination-selector read or dependency invocation.

### 2. Descriptor-callback mode

If the saved mode byte equals `0x0A`, this path takes precedence over every destination-selector rule.

On this path:

1. The temporary destination value is replaced by the Auxiliary value.
2. The callback pointer at Descriptor plus `0x08` is read.
3. That callback is invoked with two arguments, in order: Context and Parser.
4. After the callback returns, the function reads the 32-bit word at Parser plus `0x0C`.
5. That newly read word is returned.

The descriptor callback’s own return value is not used.

The function does not read the destination-selector byte, the parser index, either parser callback slot, or the indexed-region base on this path. The assignment of the Auxiliary value is not passed as an argument to the descriptor callback.

The result read is explicitly after the callback. Consequently, if the callback changes Parser plus `0x0C`, the returned word reflects the value present at the subsequent read, not a value captured before the call.

### 3. Destination selection for other modes

For any mode other than `0x0A`, the function reads the 8-bit destination selector at Descriptor plus `0x04`.

The saved selector determines the destination:

| Selector byte | Destination |
|---|---|
| `0x00` | Context plus `0x8C` |
| `0x02` | Context plus `0xA4` |
| `0x04` | Context plus `0xC4` |
| Any other value | Indexed selection, subject to a signed-index check |

The first three cases do not inspect the parser index. A negative index therefore does not cause rejection when the destination selector is `0x00`, `0x02`, or `0x04`.

### 4. Indexed selection and rejection

For every destination-selector byte other than `0x00`, `0x02`, and `0x04`, the function reads the signed 32-bit index at Parser plus `0x60`.

If that read is negative:

- The function retains the default destination address, Context plus `0x8C`, for the diagnostic call.
- Its temporary destination storage is replaced by the Auxiliary value.
- F-4457a9a44a68 is invoked with five arguments, in this order:
  1. A fixed diagnostic-message address associated with invalid use.
  2. The 32-bit word read from Descriptor plus `0x00`.
  3. The default destination address, Context plus `0x8C`.
  4. The saved destination-selector byte, promoted to the dependency’s argument width.
  5. Descriptor.
- If that dependency returns normally, F-f3e5a887c66a returns `0x000000A0`.

No parser callback is invoked on this rejection path. The return value of F-4457a9a44a68, if any, is ignored.

If the checked index is nonnegative, indexed destination selection proceeds. The function reads:

- The 32-bit indexed-region base from Context plus `0x130`.
- The signed 32-bit index from Parser plus `0x60` again.

The selected destination is the indexed-region base plus the second index value multiplied by `0xFC`, or 252 bytes.

**The check and the calculation use separate index reads.** The function does not preserve the checked index for the calculation and does not check the second read again. Under stable-memory conditions the two reads agree. If the memory changes between reads, the arithmetic uses the second value, even if it differs from the value that passed the check.

The supplied evidence does not establish the relative order of the indexed-region-base read and this second index read.

### 5. Parser-callback selection

After successful destination selection, the saved processing-mode byte selects the parser callback:

| Saved mode byte | Callback-pointer location |
|---|---|
| `0x08` or `0x09` | Parser plus `0x44` |
| Any other value except the already-handled `0x0A` | Parser plus `0x40` |

The function reads the selected callback pointer after destination selection. It does not first read both slots.

The callback receives five arguments, in order:

1. Parser.
2. Descriptor.
3. The address of the function’s temporary destination storage.
4. Zero.
5. Zero.

The third argument points to storage containing the selected 32-bit destination address. It is not the destination address passed directly.

The callback may inspect or replace that temporary value during the invocation. The caller performs no subsequent read of it in the supplied behavior. After the callback returns, its 32-bit return word is returned directly.

The mode byte is not reread when selecting the callback. Likewise, the destination-selector byte is a saved value rather than a later reread.

### 6. Arithmetic boundaries

Destination calculations use the 32-bit address and integer representations shown in the evidence:

- Context-relative additions use offsets `0x8C`, `0xA4`, and `0xC4`.
- Indexed selection uses a signed 32-bit index, a stride of 252 bytes, and a 32-bit base address.
- There is no explicit upper-bound check, multiplication-overflow check, addition-overflow check, or indexed-region-length check.

For an unambiguous, valid-address invocation, the computed addresses must be representable in the applicable target execution model and identify suitable storage for the selected callback.

The supplied representation does not establish portable behavior for overflowing signed arithmetic or address-space overflow. This contract therefore does not promise mathematical unbounded arithmetic or a particular wraparound result.

## Side effects

### Direct effects

The function directly:

- Reads selected descriptor and parser fields.
- Reads the indexed-region base only when indexed selection passes its negative-index check.
- Writes its own temporary destination storage.
- Invokes one dependency on each normally progressing path.

No direct write to the Context, Parser, or Descriptor records is shown.

That absence of direct writes is not a guarantee that those records remain unchanged: invoked dependencies receive addresses and may mutate accessible state.

### Dependency-mediated effects

The descriptor callback may affect the result subsequently read from Parser plus `0x0C`.

The parser callbacks receive Parser, Descriptor, and the address of temporary destination storage. Their writes, allocations, releases, global-state changes, or external effects are not established by this function.

F-4457a9a44a68 receives diagnostic-related arguments, but its actual output mechanism and state changes are unknown. A visible log message is not guaranteed by the supplied evidence.

### Ownership and lifetime

No allocation, deallocation, ownership transfer, reference-count operation, or cleanup is directly shown.

The temporary destination storage belongs to this invocation. Its address is exposed only during a parser callback. It must not be treated as valid after F-f3e5a887c66a returns.

No assumption is made that dependencies preserve global state, preserve pointed-to records, or refrain from owning or releasing memory. In particular, the descriptor-callback path requires Parser plus `0x0C` to remain valid for the post-callback read.

## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not executed tests. Unless stated otherwise, memory is stable, accessed fields and callback targets are valid, arithmetic is representable, and dependencies return normally.

### Descriptor mode overrides destination selection

Given mode `0x0A`, any destination-selector byte, and any parser index:

- F-unresolved-01 receives Context and Parser.
- Neither parser callback is invoked.
- The destination-selector byte and parser index are not read by this function.
- If the descriptor callback leaves Parser plus `0x0C` holding `0x12345678`, the function returns `0x12345678`, regardless of the callback’s own return value.

### Default destination with alternate processing

Given mode `0x08` and destination selector `0x00`:

- The callback is selected from Parser plus `0x44`.
- Its third argument points to temporary storage holding Context plus `0x8C`.
- Its last two arguments are zero.
- The function returns the callback’s return word.

Mode `0x09` has the same callback-slot selection.

### Fixed destination bypasses index rejection

Given destination selector `0x02`, mode `0x07`, and a negative value at Parser plus `0x60`:

- The index is not read.
- The selected destination is Context plus `0xA4`.
- The callback is selected from Parser plus `0x40`.
- F-4457a9a44a68 is not invoked.

With selector `0x04`, the destination instead becomes Context plus `0xC4`.

### Successful indexed selection

Given destination selector `0x01`, mode `0x09`, a stable index of 3, and indexed-region base B:

- The negative-index check passes.
- The index is read again for destination calculation.
- The destination is B plus 756 bytes.
- The callback is selected from Parser plus `0x44`.
- Its return word becomes the function’s return word.

An index of zero selects B itself; it is not rejected.

### Negative indexed selection

Given destination selector `0x03` and a checked index of −1:

- F-4457a9a44a68 receives the specified diagnostic arguments, including Context plus `0x8C`.
- Neither parser callback is invoked.
- The indexed-region base is not read.
- If the diagnostic dependency returns normally, the result is `0x000000A0`.

### Callback replacement of temporary storage

Given a successful parser-callback path, if the callback replaces the temporary destination value and returns `0x00000037`:

- The function returns `0x00000037`.
- It performs no shown post-callback action based on the replacement destination.

This does not establish that any memory reachable through the original or replacement destination is unchanged.
