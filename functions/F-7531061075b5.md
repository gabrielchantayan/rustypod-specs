# F-7531061075b5

## Purpose

F-7531061075b5 reads a value from a global data location and writes that value into the first four bytes of caller-supplied storage. It then selects a control-flow path using a one-byte field within that storage:

- A zero flag causes a dependency call with an interior address, followed by subtraction of 28 from the dependency’s integer result.
- A nonzero flag causes two dependency calls in sequence, the second marked as non-returning.

The global read is part of the established behavior. The written value is not established to be a constant, and its concrete value is not supplied. Replacing the global read with a hardcoded value would require evidence absent from the supplied material.

The function’s application-level purpose is unknown. Initialization, lifecycle management, and adjustment of an address-like result are possible interpretations, not established semantics.

## Behavior

1. Evaluate the global source value.
2. Write the resulting value into the four-byte destination.

4. Enter the selected dependency-call path.
