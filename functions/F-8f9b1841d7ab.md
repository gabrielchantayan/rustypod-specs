## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Initial shift.** Under 32-bit bit-vector semantics, fourth argument 1 supplies `0x02000000` as the initial second operand; fourth argument 128 supplies zero. The first operand remains the first argument.

2. **Unsigned widening.** An offset-5 byte read yielding `0xFE` becomes word value 254 where widened, not −2.

3. **Observable overwrite.** An access observer sees all four offset-`0x20` word writes, with the intervening offset-4 byte read. A final value of `0x20` alone does not prove equivalence.

4. **Final capture order.** If the `0x3A` byte destination overlaps the doubled-base offset-`0x14` word, that word is captured after the byte write. Capturing it before that write violates the represented order.

5. **Independent fixed-byte reads.** If the three reads at `0x67` return `0x12`, `0x34`, and `0x56`, the dependent writes carry those respective bytes to `0x21` and the two scaled-base offset-9 destinations. The original byte assignment does not replace those reads.

7. **Saved versus fresh word.** Later mutation of the earlier captured offset-`0x14` location does not replace the saved third operand. Conversely, the later scaled-base offset-`0x14` read remains a fresh access.

8. **Failure and transfer.** A nonreturning dependency prevents later obligations from being reached. If terminal invocation is reached, its first explicit operand is `0x72` and preceding reached mutations have occurred; normal return is not guaranteed.
