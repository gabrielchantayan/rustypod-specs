# F-9e6f3623406e

## Purpose

F-9e6f3623406e processes an indexed context location if its selected object reference is nonzero. It first invokes a workspace dependency, captures a shared value, and reads four descriptor words. These operations occur even when the selected object reference is zero.

For a nonzero reference, the function optionally invokes one of two preparation dependencies, executes a common processing sequence, stores a returned 32-bit value, invokes a final dependency, and writes a one-byte marker.

This contract describes the supplied static representation. “Context,” “descriptor,” “object,” “workspace,” and “marker” are neutral labels. Their application-specific meanings are not established. The four-word working structure has coordinate-like arithmetic, but geometric or rendering semantics remain inferred rather than established.

## Behavior

### Unconditional setup

The first operation calls F-abc658b0bf5e with the address of a local 64-byte workspace. No explicit workspace initialization precedes that call. The dependency’s initialization coverage and other effects are unknown.

After it returns, the function:

1. Obtains the shared global’s value and assigns it to the unsigned 32-bit capture.
2. Reads descriptor words at offsets 0x98, 0x9C, 0xA0, and 0xA4, in that order.
3. Forms the slot anchor.
4. Reads the selected object reference at slot anchor + 0x24.
5. Tests that reference against zero.

The four descriptor snapshot words have no visible subsequent consumer. They are not passed to a dependency or used in later expressions. Their reads nevertheless precede the object-presence decision in the supplied representation.

The first dependency’s effects precede all these reads. It is not established to preserve the context, descriptor, or shared global.

### Empty selected object

If the selected object reference is zero, the function returns after the unconditional setup.

On this path, the function itself does not:

- Read the descriptor selector or auxiliary value.
- Read an object-associated value.
- Invoke any dependency after F-abc658b0bf5e.
- Store the result field.
- Write or clear the marker.

An empty selected object therefore does not mean that the descriptor is unused, that no dependency runs, or that external state remains unchanged.

### Conditional preparation

The function reads the descriptor’s unsigned 16-bit selector and compares it with 0x0565.

- If equal, it calls F-a7562a402053.
- Otherwise, it reads the unsigned 16-bit selector again and compares that value with a direct reference to the shared global.
- If the second comparison is equal, it calls F-08741ff22c05.
- If neither comparison is equal, it skips preparation.

Each preparation dependency receives these ordered arguments:

1. Context.
2. Index.
3. The 32-bit auxiliary value read from descriptor + 0x04.
4. Cached object-associated value.
5. Integer 6.
6. Integer 154, equivalent to 0x9A.

The auxiliary read occurs only for the selected preparation call.

The fixed comparison has precedence: if the first selector read is 0x0565, F-a7562a402053 is selected without evaluating the alternate comparison.

The alternate comparison does not use the early unsigned capture. Its conversion rules depend on the missing global declaration. Consequently, the excerpt alone does not establish whether values outside the unsigned 16-bit range can match after conversion, or what width and signedness govern this comparison.

Under that explicit assumption, a global value greater than 65535 cannot equal the selector. This is a conditional consequence, not an unconditional property of the supplied excerpt.

The two selector reads are distinct. The early capture and later global reference are also distinct. No synchronization or stable-value guarantee is visible. The precise operand-read order inside the alternate comparison is not established.
