# F-20a4fd8b9055

## Purpose

On normal completion, it returns the final delegate’s 32-bit result after two cleanup-shaped calls.

**Established static behavior:** the routine imposes the call order and data transfers described below. The optional operation depends on a signed index comparison; the notification choice depends on whether a separate predicate result is zero.

**Inferred intent:** the compound working value may represent a selection or another object-associated value, and the notification may report that value or an alternative condition. Neither interpretation is required by this contract.
