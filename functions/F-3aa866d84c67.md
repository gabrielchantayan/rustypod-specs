## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Separate initial reads.** If the first primary-base `+0x74` read yields one region and the second yields another, initial displacement comes from the first region’s `+0x64`; linked base comes from the second region’s `+0x44`.

2. **Primary-byte chronology.** Without overlapping writes to the same byte, primary base `+0x11` receives the working base’s low byte, then linked base’s low byte, then the third input’s low byte. An implementation retaining only the final store does not preserve the specified access sequence.

3. **Truncation and width.** If working extent ends in `ABCD`, the halfword store at working extent plus linked base retains `ABCD`. By contrast, the later doubled-shifted `+0x14` store writes only one byte.

4. **Zero extension.** If first payload byte is `0xFE`, the word stored at second child `+0x44` has numeric value 254, not a sign-extended negative value.

5. **Low-address reload.** If address byte is `0x20`, its word destination is absolute address `0x84`. If the intervening wide-shift-value `+0x30` store aliases that location, the subsequent reload must observe memory after that store under the applicable memory model.

6. **First fixed observation.** If first fixed value is a usable address, it is stored at saved link `+0x14`; subsequently, its `+0x54` destination receives reloaded base. The second absolute `0x44` read cannot replace this capture.

7. **Closing alias dependence.** If storing incremented fixed changes chain base `+0x64` through aliasing, closing byte base comes from the changed location. Likewise, the final destination read occurs after the third-child `+0x14` store.

8. **Unresolved shift.** An example requiring a particular numeric result for the product shifted right by 32 remains documented-only until target semantics are established.

9. **Failure.** If a reached access is invalid, the contract supplies neither an error code nor a guarantee that indirect invocation occurs.
