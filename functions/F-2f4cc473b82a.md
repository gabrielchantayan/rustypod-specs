# F-2f4cc473b82a

## Purpose

F-2f4cc473b82a selects one of three highlight-related resources, obtains a value associated with that selection, and passes the value to an indirect operation on the supplied object. It also writes a one-byte marker in the object and invokes a final operation on a temporary, addressable copy of the fourth argument.

The selection distinguishes three cases:

1. A first query returns zero.
2. The first query returns nonzero, and a second query returns zero.
3. Both queries return nonzero.

The resource labels suggest empty-playlist, playlist-without-art, and media-content highlight states, respectively. Those meanings are **inferred intent**, not established dependency semantics. The supplied material does not establish the resources’ actual byte contents, the queries’ domain meanings, or the indirect operation’s user-visible effect.

This contract describes normal execution supported by the supplied static evidence. No runtime tests have been performed.
