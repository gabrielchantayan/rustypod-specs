### Returned-object field preparation

### Shared-slot decision

- If the value is nonzero, it skips the shared-initialization branch.
- If the value is zero, it executes the branch described below.

The shared-slot address itself is retained for subsequent accesses. The visible behavior does not reacquire that address after later dependencies execute.
