# F-d5aed6d90713

## Purpose

The visible behavior is not a conventional, uniformly usable error-message lookup. Some inputs select a diagnostic storage reference; others return a small numeric value represented as a pointer, including a null pointer. All remaining inputs select a common unknown-error reference.

The apparent intent is to associate selected status values with diagnostic messages. That intent does not justify treating every result as a readable string. In particular, the small pointer-valued results are part of the supplied static representation and must remain visible in this contract.

This specification describes static evidence only. No runtime tests have been performed.
