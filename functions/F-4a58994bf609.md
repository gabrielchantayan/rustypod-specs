# F-4a58994bf609

## Purpose

F-4a58994bf609 invokes one dependency twice, then assigns selected fixed-width fields from a source-relative region to matching offsets in a destination-relative region. It returns no value.

The visible layout is consistent with a structured-record transfer, but that purpose is **inferred intent**. Neither the complete object layout nor the dependency’s behavior is supplied. This is therefore not a contract for copying an entire 32-byte object.

The supplied representation includes two assignments of the 16-bit field at offset 20. That duplication is established static evidence. It does **not**, by itself, establish two separately observable hardware reads or writes: the accesses are non-volatile, and no execution model requiring preservation of every individual access is supplied.
