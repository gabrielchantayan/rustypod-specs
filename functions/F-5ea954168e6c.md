# F-5ea954168e6c

## Purpose

F-5ea954168e6c performs fourteen ordered byte and halfword stores, interleaved with twelve reads from seven external data slots, and then transfers control through an unresolved target.

The stored data comes from an explicit 16-bit payload, an implicit 16-bit state value, external-slot values, and narrowed representations of the transfer target. Destinations combine explicit integer inputs and external-slot values. Several destinations have no explicit base input.

The established behavior is a sequence of memory accesses and an indirect transfer, not a conventional object initialization, serialization, or buffer-processing interface. No application-level purpose, valid allocation layout, or memory-safety guarantee is established.

This contract describes the supplied static representation. Execution is conditional on valid accesses, supported arithmetic and conversions, and a usable transfer target. Four explicit arguments alone do not establish those prerequisites.

## Behavior

### Ordered access contract

The following is the normal-path order in the supplied representation. Read results retain their captured meaning when reused later, even if intervening writes alter the corresponding slot.

“Byte-narrowed” and “halfword-narrowed” describe the represented conversions to one-byte and two-byte values. Their exact conversion semantics are qualified below.

1. Store the full 16-bit State at **Base + Offset**.
2. Read A, producing **A₁**.
3. Read A again, producing **A₂**.
4. Store byte-narrowed State at **Base + A₂**.
5. Read B, producing **B₁**.
6. Read B again, producing **B₂**.
7. Store byte-narrowed State at **twice B₂**.
8. Store the full 16-bit State at **Base + A₁**.
9. Store byte-narrowed A₁ at **Base + B₁**.
10. Store halfword-narrowed B₁ at **B₁ + A₁**.
11. Store byte-narrowed State at **B₁ + A₁**.
12. Read C, producing **C₁**.
13. Store the halfword-narrowed representation of Transfer target at **twice B₁**.
14. Store byte-narrowed Payload at **Alternate base + B₁**.
15. Read D, producing **D₁**.
16. Read D again, producing **D₂**.
17. Store byte-narrowed Payload at **Base + D₂**.
18. Store the byte-narrowed representation of Transfer target at **D₁ + A₁**.
19. Read E, producing **E₁**.
20. Read C again, producing **C₂**.
21. Read E again, producing **E₂**.
22. Store halfword-narrowed C₁ at **Alternate base + E₂**.
23. Form the represented 32-bit integer product **P = C₂ × E₁**.
24. Store the full 16-bit Payload at **twice P**.
25. Read F.
26. Store byte-narrowed F at **P + A₁**.
27. Read G.
28. Invoke Transfer target with two observed arguments, in order: **C₂**, then the value read from **G**.

If the invocation returns normally, the represented routine returns without an explicit result.

The external-slot read sequence is exactly:

**A, A, B, B, C, D, D, E, C, E, F, G.**

In particular:

- The first A result is not substituted for the second A read.
- The first B result is not substituted for the second B read.
- The byte Payload store relative to Base uses D₂, not D₁.
- The halfword C₁ store relative to Alternate base uses E₂, not E₁.
- E₂ is read after C₂.
- The product uses C₂ and E₁, not C₁ or E₂.

Exact out-of-range signed conversions and target-to-integer conversions are not fully established; examples relying on low-bit behavior state that assumption.
