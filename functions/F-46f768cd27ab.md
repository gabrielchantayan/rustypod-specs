# F-46f768cd27ab

## Purpose

F-46f768cd27ab routes a nullable text pointer through one of three paths:

- A compact-value path selected by a preliminary dependency.
- A two-word integer path selected by local decimal-prefix inspection and, for a 19-digit prefix, a boundary dependency.
- Alternate processing that receives all five original arguments.

Null text causes an immediate return without dependency calls.

**Established static behavior:** the function performs preliminary classification, conditionally measures a decimal prefix, conditionally negates a dependency-produced value, and invokes the selected output or alternate-processing dependencies.

**Inferred intent:** the paths appear to distinguish a compact numeric representation, a wider integer representation, and inputs requiring other processing. Complete numeric syntax, numerical range validation, and output-format semantics are not established.

This contract describes static evidence. No runtime tests have been performed.

## Behavior

### 1. Null handling and preliminary classification

If Text is null, return without reading text or calling any dependency.

Otherwise, first call F-9647f90132cc with:

1. The original Text pointer.
2. Writable storage for the compact signed 32-bit value.

Its signed 32-bit return is tested only for zero versus nonzero.

This function performs no direct text-byte read before that call. Subsequent inspection, if reached, observes memory after the dependency returns—not necessarily the text contents present on entry.

### 2. Compact-value path

Any nonzero return from F-9647f90132cc selects the compact path, regardless of its sign or magnitude.

If Negation control is nonzero, apply signed 32-bit unary negation to the compact value. Otherwise, leave it unchanged.

Then call F-887ba2404a49 with:

1. Context.
2. The constant `0x2F`.
3. The resulting compact value.
4. Output metadata.

Return after that call returns.

This path performs no local text inspection, boundary call, or two-word conversion. Auxiliary value is unused.

Negating the minimum signed 32-bit value is not established to wrap. That case remains unresolved at the supplied signed-expression level.

### 3. Sign inspection and prefix measurement

A zero return from F-9647f90132cc selects local inspection.

First, read the initial text byte. Derive a sign indicator of one if that byte is `-`, and zero otherwise.

Skip exactly one initial byte if it is `-` or `+`. Otherwise, begin scanning at the original pointer.

If Negation control is nonzero, invert the sign indicator:

| Initial byte | Zero Negation control | Nonzero Negation control |
|---|---:|---:|
| `-` | 1 | 0 |
| Anything else, including `+` | 0 | 1 |

From the selected scan position:

- Skip consecutive bytes equal to `0x30`.
- Count the following consecutive bytes in the inclusive unsigned range `0x30` through `0x39`.
- Stop counting at the first byte outside that range.

The count excludes the skipped leading zeros. Consequently:

- Whitespace is not skipped.
- Only one initial sign is skipped.
- No digit is required after a sign.
- Empty text, sign-only text, and all-zero text can produce count zero.
- A suffix after the digit run is not locally rejected.
- Bytes with the high bit set are not decimal digits.

The digit condition performs a lower-bound check followed, only if that succeeds, by an upper-bound check. The evidence does not establish an atomic or single-read snapshot of each inspected position. Count-based descriptions assume stable readable bytes during inspection.

Neither the skipped-sign position nor the post-zero position replaces the original Text pointer supplied to later dependencies.

The original pointer is passed onward, but its then-current contents and validity are not guaranteed by this function.

### 5. Two-word conversion and conditional negation

Call F-1e06ba66d3c3 with:

1. The original Text pointer.
2. The address of the low word of the two-word temporary.

Ignore any return value. Continue using the temporary without checking conversion success.

This function does not directly rewrite Text and does not pass an advanced scan pointer to conversion. That is narrower than preserving text contents:

- F-9647f90132cc has already run before inspection.
- For count 19, F-b553d13469e5 has run between inspection and conversion.
- Either dependency’s effects on text and memory lifetime are unknown.

Thus, a sign or leading zeros observed during inspection need not still be present when conversion begins. If the contents are preserved, conversion receives those contents through the original pointer; preservation is a condition, not a guarantee.

If Negation control is zero, perform no local negation.

If it is nonzero, the observable temporary-update order is:

1. Determine whether the old low word is nonzero.
2. Apply signed 32-bit unary negation to the low word and store it.
3. Compute and store the replacement high word.

Let \(L\) and \(H\) denote the old word values interpreted modulo \(2^{32}\). Let \(\delta\) be one when the old low word is nonzero, and zero otherwise. The modular results corresponding to the transformation are:

\[
L' \equiv -L \pmod{2^{32}},
\qquad
H' \equiv -H-\delta \pmod{2^{32}}.
\]

The low-word operation is expressed as signed negation. Its minimum signed value therefore remains an unresolved arithmetic case; the modular equation does not establish wrapping for that case.

The high-word computation first adds the unsigned 32-bit indicator to the old high word and then negates the sum. The unsigned operand makes both operations unsigned 32-bit arithmetic, wrapping modulo \(2^{32}\). In particular, the transformation **subtracts** the nonzero-low indicator from the negated high word.

Storing that unsigned result into signed 32-bit storage is a separate conversion. Results above the signed maximum have target-dependent conversion behavior not established here.

Subject to defined low-word negation and preservation of the high-word result’s bit pattern on assignment, the combined result is two’s-complement negation modulo \(2^{64}\).

## Acceptance examples

These are conditional static cases, not executed tests. Unless stated otherwise, inspection examples assume preliminary classification returns zero and the stated bytes are readable and stable during local inspection. Conversion examples additionally require initialized temporary words.

1. **Null Text.** No dependency is called, regardless of the other arguments.

2. **Compact negation.** If preliminary classification returns any nonzero value and writes 7, nonzero Negation control causes F-887ba2404a49 to receive −7. No local text inspection occurs.

3. **Leading zeros.** If the inspected text is `+000123` followed by a zero byte, the count is 3. Conversion is selected without a boundary call and receives the original pointer. If no dependency has changed the contents, that pointer still addresses the sign and leading zeros.

4. **Empty counted run.** Empty text, sign-only text, and `0000` followed by a zero byte each produce count zero and select conversion. Successful numerical interpretation is not established.

5. **Suffix.** Inspected text `123x` produces count 3 and selects conversion. Local routing does not establish whether conversion accepts the suffix.

6. **Boundary with indicator zero.** A 19-digit run without an initial minus and with zero Negation control selects conversion for boundary return −1, but alternate processing for return zero.

7. **Boundary with indicator one.** A 19-digit run with an initial minus and zero Negation control selects conversion for boundary return zero, but alternate processing for return one.

8. **Inverted boundary.** For the same initially negative 19-digit input, changing Negation control from zero to nonzero changes the indicator from one to zero. With boundary return zero, routing changes from conversion to alternate processing.

9. **Boundary mutation.** Suppose inspection counts 19 digits, the boundary dependency changes the text while leaving the original pointer valid, and its return selects conversion. Conversion receives that same pointer to the changed contents. The function does not rescan or restore the inspected bytes.

10. **Twenty digits.** A stable 20-digit run beginning with a nonzero digit selects alternate processing without a boundary call. All five original argument values are forwarded.

11. **Nonzero low word.** If conversion supplies low word 1 and high word 0, enabled negation stores low word −1 and computes unsigned high-word result `0xFFFFFFFF`. If signed assignment preserves its bit pattern, both stored words have that pattern.

12. **Zero low word.** If conversion supplies low word 0 and high word 1, enabled negation leaves the low word zero and computes unsigned high-word result `0xFFFFFFFF`.

13. **Minimum signed low word.** Enabled negation of a low word equal to the minimum signed 32-bit value has no unconditional wrapped-result requirement under the supplied evidence.
