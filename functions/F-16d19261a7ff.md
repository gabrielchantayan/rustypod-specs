## Acceptance examples

These are conditional acceptance criteria, not executed tests.

1. **Nibble preservation.** If the addressed byte is `0xab` immediately before the mask operation, the operation writes `0xa0`. Later preservation is not implied.

2. **Captured selector.** If the captured selector is `7`, the selector arguments are `7`, `6`, `7`, `6`, even if a dependency changes the selector global between calls.

3. **Independent call results.** Four different F-4100b60c14d9 results must be written respectively at header offsets `0xf4`, `0xf8`, `0x104`, and `0x108`. Reusing the first pair instead of making the second pair of calls does not satisfy the contract.

Destination offsets `0x158`, `0x15c`, `0x160`, and `0x164` receive the words from R + `0x08`, Q + `0x0c`, P + `0x10`, and P + `0x14`, respectively.

5. **Stable table storage.** With valid, stable pointer fields and no interfering mutation, each table has index 0 equal to `3`, index 62 equal to `127`, and index 63 equal to `0xffffffff`. Index 63 is first written as `129`, then overwritten.

6. **Returned-address authority.** If a nested dependency returns a different address from its destination argument, subsequent result-relative operations use the returned address.

7. **No blanket clearing.** With no aliasing or dependency mutation of the byte, settings offset `0x67` retains its previous value. Only `0x58` through `0x66` are explicitly cleared in that interval.

8. **Late terminal argument.** If F-82c94237746a changes the final global argument, F-e4e2db384d33 receives the value read afterward.

9. **Unusable storage result.** No graceful local failure response is specified. The body consumes the result without checking it; the outcome remains environment-dependent.
