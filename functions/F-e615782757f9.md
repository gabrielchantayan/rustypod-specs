## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

### Equal initial read results

Given valid initial storage, and provided that both ordered reads of the external location yield 4096, the first three explicit writes must be:

- 4096 at initial-storage offset 0.
- 4352 at initial-storage offset 28.
- 4364 at initial-storage offset 40.

Both reads must precede the first write. All three writes must precede F-04976dfeee8a.

### Different initial read results

If the first read yields 4096 and the second yields 8192, with valid storage and unambiguous arithmetic, the writes must instead be:

- 8192 at offset 0.
- 4352 at offset 28.
- 4364 at offset 40.

Using 8192 as the basis for the two additions would violate the established behavior. Reusing the first-read value for offset 0 would also violate it when the reads differ.

These criteria concern the writes when performed, not guaranteed final contents after later dependency activity.
