## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Input transformation.** With third input 1 and normal dependency returns, the early invocation receiving two copies of that input shifted by 11 receives `0x800` in both positions.

2. **Small-value boundary.** Under truncating 32-bit arithmetic, a contributing result of `0x7f` yields small value 508 and doubled-small base 1016. A result of `0x80` yields zero.

3. **Zero-extension.** An offset-`0x05` byte value of `0xff` produces `0x000000ff` in the corresponding offset-`0x34` word store.

4. **Initial fixed-state ordering.** If a later derived write changes `0x00000005`, that does not retroactively change the address base captured before the fixed write at `0x00000001`. Later loads still observe intervening writes at their own positions.

5. **Publication capture.** If the publication-base read returns a particular address, a subsequent fixed word write at `0x00000060` does not cause that base to be reloaded. The read occurs after the final offset-`0x20` store and before the fixed write.

6. **Terminal access ordering.** The fixed word read at `0x000000a9` precedes the fourfold-link offset-`0x74` read. The computed fixed byte write at `0x0000003a` separates that derived read from the terminal-link offset-`0x14` and scaled-publication offset-`0x04` reads.

9. **Final invocation.** If all preceding operations complete, F-unknown-003 receives `0x72` followed by the specified loaded, retained, and loaded words. Their application meanings remain unresolved.
