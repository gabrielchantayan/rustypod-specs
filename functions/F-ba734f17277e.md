### Byte-controlled dependency invocation

- A zero byte causes F-47f33f8d1eca to be called with the original object base value.
- Any nonzero byte skips that call.

The byte is not visibly reread after F-47f33f8d1eca. Changes made by that dependency do not cause the branch decision to be repeated.

### Pointer and destination inspection

This timing matters. The inspected pointer is the value present after the preceding calls, not necessarily the value present when F-ba734f17277e was entered.

- No destination integer is read.
- The indirect callable is not invoked.
- The function returns normally.

If the pointer is non-null, the function reads the first 32-bit integer at that destination.

The condition does not require a positive value. A negative value, under the shown signed 32-bit interpretation, is nonzero and therefore enables dispatch.

The destination integer is only tested for zero. There is no visible increment, decrement, range comparison, mask, or conversion affecting the decision.
