## Acceptance examples

These are conditional criteria derived from static evidence, not executed tests.

1. **Initial arguments.** With first input 1, the initial invocation receives 1, the unchanged second input, 0x4000, and 0x40.

2. **Zero input.** With first input zero, its two shifted arguments are zero. No visible branch skips the remaining operations on that basis.

3. **Masked extraction.** At a bits-8–23 extraction point, a retained word of 0x12345678 yields 0x3456.

4. **Store widths.** A byte store of a value ending in 0xABCD supplies 0xCD and does not itself write adjacent bytes. The three constant 0x3A stores remain distinct byte, halfword, and word accesses.

5. **Ordered overwrite.** The constant-group word destination receives 0x20, 0x2F, the freshly loaded unsigned byte, and 0x20 in that order. Matching only the final value is insufficient.

6. **Final capture order.** A final-phase access observer must see the 0xA9 word capture before the derived 0x74 read, then the 0x3A byte write, then the two further word captures.

7. **Stable ordinary-memory case.** If the 0xA9 capture ends in 0xAB, all accesses complete, no intervening write overlaps 0x67, and reads behave as stable ordinary memory, the write to 0x21 and both later 0x67-fed derived byte stores receive 0xAB.

8. **Fresh-read distinction.** If the three fresh reads of 0x67 return 0x11, 0x22, and 0x33, the write to 0x21 receives 0x11 and the two corresponding stores at adjusted base plus 9 receive 0x22 and 0x33. The captured 0xA9 low byte does not replace these reads.

9. **Conditional completion.** If all preceding operations complete, F-U03 is invoked with first argument 0x72 and the specified retained words. Completion still requires F-U03 to return.
