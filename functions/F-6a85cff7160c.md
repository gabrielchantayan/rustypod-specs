## Behavior

Subsequent calls receive the address of this slot, not an explicit pointer to the caller’s original argument storage. The supplied body does not write the slot’s eventual contents back to the caller.

The slot remains live through descriptor processing, the receiver operation, and the cleanup call.

### 2. Obtain a two-word result

The function calls F-938c950e5046 without explicit arguments.

It then reads the returned object’s dispatch-table address and invokes the entry at byte offset `0x168`. No explicit argument is shown for this indirect call. In particular, the static representation does not show the returned object being passed as an explicit receiver argument.

The result is represented as 64 bits. The function uses:

- The low 32-bit word as the selector.
- The high 32-bit word as an additional argument on the non-special branch.

For purposes of descriptor selection, the selector is tested for equality with 1.

### 3. Select the special descriptor when the selector is 1

If the selector equals 1, the function chooses the descriptor reference labeled `TimerHilited`.

On this branch, the function does not:

- Call F-df3f6f4fe2dc.
- Read the secondary object’s field at `0x50`.
- Invoke the secondary object’s indexed operation.

The high word of the 64-bit result has no further explicit use on this branch.

### 4. Otherwise, resolve a secondary object and conditionally invoke it

For every selector other than 1, the function calls F-df3f6f4fe2dc with two explicit 32-bit arguments, in this order:

1. The low word of the earlier result.
2. The high word of that result.

Both words are represented as signed 32-bit arguments at this call boundary. This interpretation does not discard their underlying bit patterns.

After F-df3f6f4fe2dc returns, the function reads the secondary object’s 32-bit field at byte offset `0x50`.

It compares that field, interpreted as unsigned, against the selector minus 2 using unsigned 32-bit arithmetic. Thus the subtraction used for the comparison wraps modulo \(2^{32}\).

If the unsigned selector-minus-two value is strictly less than the unsigned field value, the function:

1. Reads the secondary object’s dispatch-table address.
2. Resolves its entry at byte offset `0xb4`.
3. Invokes that entry with the secondary object as the first explicit argument and selector minus 2 as the second explicit argument.

The return value of this operation is not used by the surrounding function.

If the comparison is false, no such dispatch occurs.

After this conditional operation, the function chooses the descriptor reference labeled `AlarmHilited`. This selection is independent of whether the bound comparison succeeded. An out-of-range selector does not cause an early return or select the other descriptor.

The comparison’s unsigned arithmetic is explicit. The second dispatch argument is expressed separately as signed selector-minus-two arithmetic; behavior at signed-overflow boundaries is discussed under **Uncertainties**.
