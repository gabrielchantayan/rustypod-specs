# F-e0774d741a68

- When an entry-state byte is nonzero, it records a supplied 32-bit value in the target object and returns without invoking dependencies.

The dependency semantics are not supplied. Descriptions such as “resolve,” “temporary,” and “cleanup” identify roles in this function’s call sequence, not independently established resource-management contracts.

## Behavior

### 1. Entry-state test and short path

The function first reads the byte at target offset `0xe8`.

If that byte is nonzero, it writes Value as a 32-bit quantity at target offset `0xe0` and returns. No dependency is invoked. The function does not write Stored byte to offset `0xe4` on this path.

All nonzero byte patterns select this path. Signedness of the byte does not affect the zero/nonzero decision.

The entry byte is not read again. Changes to it during the active path do not cause this function to reconsider the selected path.

### 2. Active-path byte write and handle resolution

If the entry byte is zero, the function writes Stored byte at target offset `0xe4`.

It then invokes F-1f46730b1ced with:

1. The address at target offset `0xb0`.
2. Value, unchanged as a 32-bit quantity.

If the result is zero, the function invokes F-a817d8d58c10. That dependency is identified in the supplied static evidence as non-returning. Accordingly, this path has no established normal continuation.

The write at offset `0xe4` precedes this failure path. There is no direct write to offset `0xe0` before the failure dependency is invoked.

If the result is nonzero, it becomes the handle used by the remainder of the active path. No further validity check is performed.

### 3. Handle-dependent calls

1. F-d2f99870cc43 receives the handle and produces an opaque 32-bit result.
2. F-bf557f07179f receives the target and that result.
3. F-fa8898fa75ae receives the handle.

The function does not inspect a result from either of the latter two calls.

The same handle value is retained for possible later use by F-818c773e8c8a. It is not resolved again after F-fa8898fa75ae.
