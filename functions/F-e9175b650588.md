### Aliasing and read timing

No non-overlap condition is checked. The destination may overlap the source or the global location unless a surrounding contract prohibits that.

Where overlap exists, earlier writes can affect later reads. The four transferred source values therefore need not equal the four values present at function entry, or even those present immediately after the dependency returns.

Likewise, the initial write at destination offset zero can affect any later source read if its address overlaps that source word. The function does not protect against this by buffering the input words.

The global value is fetched for the initial assignment. The supplied body does not fetch that global again for the remaining four assignments.
