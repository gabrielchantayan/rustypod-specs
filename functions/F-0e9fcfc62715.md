## Behavior

### Acceptance rule

The comparison of the third input against 8 is unsigned. Its outcome selects a numeric threshold:

- A third input below 8 selects threshold 1.
- A third input of 8 or greater selects threshold 0.

The threshold is then compared with the fourth input as a signed value. Acceptance occurs when the fourth input is greater than or equal to that threshold.

Consequently:

- Every negative fourth input is rejected, regardless of the third input.
- A fourth input of zero is accepted exactly when the third input is at least 8.
- Every positive fourth input is accepted, regardless of the third input.
- There is no upper-bound rejection for either value within its respective input width.

The threshold is not obtained by narrowing the third input or interpreting it as signed. In particular, third-input values with their highest bit set remain in the “8 or greater” category.
