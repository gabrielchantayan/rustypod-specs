# F-d267c9402e56

## Purpose

F-d267c9402e56 performs a fixed sequence of unresolved dependency calls, packed-field extractions, memory lookups, and mixed-width writes. Its direct effects include publishing scaled values into word storage, modifying selected low-address bytes, copying word-derived bytes, and updating two represented global words. Its last operation before a possible return is a call to address zero.

No application-level purpose is established. Structural linking or field publication is **inferred intent**, not evidence of allocation, initialization, decoding, cleanup, or supervisory control.

This contract describes **established static behavior**, conditional on reaching each operation. It does not establish executable call targets, valid memory mappings, or normal completion.

## Behavior

### Ordering and observation rules

The represented body has no explicit loop, conditional branch, bounds check, or error branch. Dependencies may nevertheless branch, modify memory, fail, or not return.

Each selected-byte write performs a fresh selector read. Intervening calls remain observable boundaries; they cannot be removed, merged, or assumed to preserve memory. Retained values are not fresh memory observations. Repeated clears and copies remain separate effects.

Direct writes can alias subsequent reads, globals, or smaller overlapping storage. Passing a value or address to a dependency does not establish a corresponding dependency write.

The phases below describe the ordered behavior without assigning semantics to unresolved calls.

F-000000000001 receives the second input. Several calls precede a selected-byte clear using the incoming implicit selector base.

Further calls receive primary results scaled by four, sometimes in repeated argument positions. One call receives four explicit zeros.

The initial word effects are ordered as follows:

1. A secondary result is stored into the indexed word selected by that result.
2. A word is read at 0x14 + 0x400 × an earlier unsigned primary result shifted right by 18. A dependency receives the secondary result and the loaded word shifted right by 19.
3. A secondary result is stored into an indexed word selected by a later primary result.
4. For a new index, its fourfold value is stored at scaled-record offset 0x14.
5. A different word is read at 0x14 plus that retained fourfold value. A dependency receives, in order, the fourfold value, the loaded word shifted right by 19, zero, and the fourfold value again.
6. After calls, the retained fourfold value is stored into another selected indexed word.

The scaled-record store and the lookup using the fourfold value have different address formulas.

### First packed-result phase

3. **Offset-D order:** A dependency receiving the first offset-0x44 lookup may observe the initial offset-0xD byte before its overwrite with 4.

4. **Stores versus arguments:** For link index 1, scaled-record offset 0x14 receives 4 at address 0x24. Shift-by-24 and shift-by-22 argument values are 0x01000000 and 0x00400000; neither establishes a direct store of those values.

5. **Byte-chain ordering and aliasing:** Suppose the retained primary result is 0x1000, the first chain byte observed at 0x1001 is 0x20, and the selector read at address 1 for the intervening packed publication is 0x10. That publication writes 1 at 0x21. If no subsequent operation changes 0x21 before the second chain read, that read returns 1. It occurs after the publication, not before it.

6. **Retained byte versus reread memory:** The preceding example still uses retained first byte 0x20 to select the second read address 0x21. The later field derived from the first byte is zero regardless of the second read’s value, and its destination requires another selector read.

7. **Word chain:** First chain word 0x00800000 selects address 0x16. Second chain word 0x40 selects indexed-store address 0x94 and subsequent unhalved read address 0x54.
