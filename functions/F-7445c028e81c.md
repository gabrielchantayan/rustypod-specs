# F-7445c028e81c

## Purpose

The delegation receives a derived first argument, a second word obtained from an input record, an opaque 32-bit value, and the unsigned-word pointer unchanged. The post-call transformation uses the word’s value **after the dependency returns**, not a saved entry value.

**Established static evidence:** The supplied representation contains one dependency invocation followed by a conditional read-modify-write through the supplied pointer. There is no explicit return value.

**Inferred intent:** The post-call transformation may convert an output into half-sized units. Neither the meaning of those units nor the dependency’s operation is established. Such an interpretation is not part of this contract.

## Behavior

2. The record’s offset-52 word.

### Post-call transformation

After the dependency returns normally:

- If the optional word pointer is null, the function performs no explicit access through that pointer.
- If it is non-null, the function reads its current 32-bit unsigned value, shifts that value right by one bit with zero filling, and stores the result back to the same location.

For an unsigned value in the range 0 through 4,294,967,295, this transformation equals division by two with any fractional part discarded. Its result lies in the range 0 through 2,147,483,647.

The least-significant input bit is discarded. The highest output bit is zero. The operation is neither a signed arithmetic shift nor rounding to the nearest integer.

The value being transformed may have been written by the dependency. The function does not explicitly read or save the pointed-to word before delegation, and it does not restore an entry value.

The read and write constitute a represented read-modify-write operation. Nothing establishes atomicity, synchronization, or suitability for concurrent access.

The addition of 456 is distinct from the unsigned shift. The supplied representation expresses the addition using a signed integer word, while the post-call shift operates on an unsigned word.

For an ordinary signed 32-bit interpretation, adding 456 is representable when the original word is at most 2,147,483,191. The constant is positive, so this addition does not create lower-bound signed overflow.

These are conditional behavioral criteria, not observed executions. Unless stated otherwise, assume readable record fields, valid arithmetic, a normally returning dependency, and valid post-call word storage.

5. **Entry value is not authoritative.**

6. **Unchanged word still receives postprocessing.**  
   If the dependency leaves a word containing 12 unchanged, the function stores 6. A dependency write is not required to trigger the shift.

11. **No normal dependency return.**  
    If the dependency never returns normally, the post-call shift is not reached through the shown path.

12. **Signed-addition boundary.**
