## Behavior

### Observable access rules

The visible body performs stores, not destination read-modify-write operations. In particular, writing a value derived from a destination address does not imply reading the destination first.

Two consecutive identical stores remain two ordered write events. They must not be collapsed in a behavioral model that observes memory-mapped I/O, write tracing, faults, or intervening external effects.

Dependency calls separate write groups. A later explicit write is established, but preservation of memory or global values across any dependency call is not.

### Initial write group

Before the first dependency call, the function issues these writes in order:

1. A 16-bit write of the low 16 bits of **P** at address **P**.
2. A second identical 16-bit write at **P**.
3. A 16-bit write of the same value at the address obtained by doubling **P**.
4. A 32-bit write of **X** at **B + 0x14**.

Doubling is an arithmetic address calculation, not an additional 16-bit element offset from **P**.

The initial dependency, **F-D01**, is then invoked at the target formed from **L + 0xFFE**. No explicit arguments are represented. This does not establish that all physical argument registers are zero or irrelevant.

After that invocation returns, **F-D02** supplies \(R_1\).

### Result-derived write forms

Each of the thirteen result stages begins with two identical 16-bit writes derived from that stage’s result.

**Form A**

- Destination: \(W_j \mathbin{\text{logical-right-shift}} 8\).
- Payload: bits 8 through 23 of \(R_j\), interpreted as a 16-bit value.
- The payload is also the low 16 bits of the calculated destination.
- Two consecutive 16-bit writes target that destination.

The destination lies between zero and `0x00FFFFFF`.

**Form B**

- Destination: \((W_j \mathbin{\&} \texttt{0x07FFFFFF}) \mathbin{\text{logical-right-shift}} 3\).
- Payload: truncate \(W_j\) shifted left by five to 32 bits, logically shift right by eight, then retain 16 bits.
- Equivalently, the payload is bits 3 through 18 of \(W_j\).

This destination also lies between zero and `0x00FFFFFF`. The payload again equals its low 16 bits.

Neither form guarantees an even destination address. An odd address is not rejected before the 16-bit writes.
