# F-0194b051f9cb

## Purpose

The apparent intent is wrapped text output within a rectangular region, with an alternate output mode near a boundary. That interpretation is inferred. The established behavior is defined by indexed state words, comparisons, decoder results, and dependency calls; coordinate names, units, encoding, and rendering semantics are not established.

The function has no explicit return value. Its externally visible results are mutations of caller-supplied state, dependency side effects, and the ordering and arguments of dependency calls.

## Behavior

The function then performs these operations in order:

1. Calls F-4439a539b76a with the original input value. Its result is narrowed to signed 16 bits and used as the initial remaining count.
2. Calls F-7ec5c59748e6 with the state address and saves its result as the base advance.
3. Reads bounds word 1 and saves that value for the initial assignment to state word 0.
4. Calls F-f445983e29a8 with the address of state word 8.
5. Writes state word 1 as that dependency’s result plus a newly read bounds word 0.
6. Writes state word 0 using the previously saved bounds word 1.
7. Calls F-42388505f940 with the address represented by state word 7 plus four bytes.

These reads are not a single bounds snapshot. For example, a change to bounds word 1 during F-f445983e29a8 does not alter the value already saved for the initial state-word-0 assignment. A change to bounds word 0 during that call can affect the subsequent state-word-1 assignment.

Both initialization writes and the F-42388505f940 call occur even when the initial remaining count is zero or negative.

### Segment admission

Processing continues only while the remaining count, interpreted as signed, is positive.

At the start of each iteration, the function compares bounds word 2 with state word 1 using a signed comparison. If bounds word 2 is strictly less, processing stops. Equality does not stop processing.

Otherwise, the function captures a boundary condition: whether bounds word 2 is strictly less than the sum of state word 1, the saved base advance, and the additional advance.

This condition is computed before measurement, decoding, or output for that segment. It is not recomputed if a dependency changes state or bounds later in the iteration.

The function calls F-40859ed81aa5 with:

- the state address;
- the current input position;
- the low 16 bits of the remaining count;
- the initially captured span;
- zero.

A zero result stops processing immediately, without decoding, output, or the iteration’s position advance. A nonzero result is treated as the candidate segment count. There is no local check that this count is no greater than the remaining count or otherwise valid.

### Scanning and break selection

For a nonzero candidate count, the function saves the segment’s starting input position. It initially selects the entire candidate count for output and clears a saved break-position slot to numeric zero.

It then scans using F-2be305f439e7. Each call receives the address of the current cursor, allowing that dependency to advance or otherwise modify it. Immediately before each call, the function saves the current cursor value.

Decoder results have two special meanings:

- **10:** Select the cursor position from before that decoder call as the break position, select the number of preceding scanned units as the output count, and stop scanning immediately.
- **32:** If the candidate count differs from the remaining count, record this position and preceding-unit count as a possible break. Scanning continues, so a later qualifying space replaces an earlier one.

Other decoder results have no locally defined special treatment. There is no explicit end-of-input or decoder-error branch.

The selected delimiter is excluded from the output count. A line-feed result always takes precedence by stopping scanning. A space is eligible only when the candidate count differs from the full remaining count; this is an inequality test, not a test that the candidate is smaller.

If the saved break-position slot is still numeric zero after scanning, the function substitutes the current cursor. Zero therefore acts as a sentinel. A genuine input position numerically equal to zero cannot reliably represent a saved break.

The scan counter starts at zero. Its increment adds one and applies the 32-bit mask `0xFFFEFFFF`, which clears bit 16 rather than retaining only the low 16 bits. Starting from zero, this counter cycles through 0–65,535. If a dependency returns a candidate count greater than 65,535 and decoding never produces 10, the loop’s counter alone cannot reach that candidate count. Termination may then depend on decoder behavior or external failure.

- If the captured boundary condition is true and the alternate-mode value is nonzero, the function calls F-4a510ca8d13f.

There is no local success check after either output call. The excerpt does not establish how the alternate dependency determines how much input to process.

### Delimiter consumption and advancement

After the optional output call, if the selected count is less than the candidate count, the function:

- increments the consumed count using addition followed by the mask `0xFFFEFFFF`;
- calls F-2be305f439e7 with the address of the saved break position;
- ignores that decoder result.

Under ordinary break selection, this extra call advances past the selected space or line feed. The delimiter was already encountered during scanning; this call decodes again from its saved starting position. For spaces, scanning may have advanced beyond that position before output, but the next iteration resumes from the saved break position after this extra decoding call.

The extra call occurs after output. Any dependency effects between the two decodes can therefore matter.

The function then:

1. Writes state word 0 from a fresh read of bounds word 1.
2. Reads the current state word 1 and adds the saved base advance and additional advance, then writes the result back.
3. Makes the saved break position the next iteration’s input position.
4. Subtracts the consumed count from the remaining count and normalizes the result through a signed 16-bit-style operation.

State word 1 is not advanced from a preserved pre-output value. If an output dependency changes it, that changed value becomes the basis for the explicit advance.

The remaining-count update retains the low 16-bit result and interprets it as signed. It is not clamped at zero. Invalid or excessive dependency counts can consequently produce a negative remainder, wrap to another positive remainder, or otherwise depart from ordinary length accounting.

The value of state word 7 is read again for this final call. If a dependency changes it, the final address can differ from the address passed to F-42388505f940.

## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not executed tests. Unless specified otherwise, assume valid storage, conventional decoder advancement, no relevant dependency mutations, nonzero cursor positions, and arithmetic within signed 32-bit range.

1. **No positive initial count.**

2. **Already beyond the boundary.**

3. **Measurement declines a segment.**  
   If F-40859ed81aa5 returns zero, there is no decoder or output call for that iteration and no iteration advance. Finalization still occurs.

4. **Ordinary complete candidate.**  
   Given remaining count five, candidate count five, and five decoder results other than 10, all five units are selected. Spaces do not establish breaks because candidate and remaining counts are equal.

5. **Last eligible space wins.**  
   Given remaining count eight, candidate count five, and decoder results corresponding to two ordinary units, a space, and two further ordinary units, output selects the first two units. The saved space is decoded again after output, consumed count becomes three, and the next iteration resumes immediately after that space.

6. **Leading line feed.**  
   If the first decoder result is 10, selected output count is zero. Neither output dependency is invoked. The line feed is decoded again through the saved position, consumed count becomes one, and state still advances by one segment step.

7. **Alternate-path threshold.**
