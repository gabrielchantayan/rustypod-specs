## Behavior

### Sentinel decision

If this first observed value equals −1, the default result is returned. The supplied representation expresses no second field read on this branch.

If the first observed value differs from −1, the routine obtains the return value through another read of the signed short at the same offset. It returns that value without another sentinel comparison.

This distinction matters: the representation does not express a single read whose value is both tested and returned.

### Stable-storage behavior

When the field remains unchanged during the call, the behavior is a simple sentinel substitution. Every representable signed-short value other than −1 is returned unchanged.

Negative values are not generally rejected or replaced. For example, −2 remains −2. Only equality with −1 selects the default result.

A stored zero takes the non-sentinel branch but still produces zero. Its result is indistinguishable from the sentinel branch’s result.

Consequently, if the environment permits defined changes between these accesses, an initial non-sentinel observation followed by a second observation of −1 can produce a returned −1. The routine does not apply sentinel substitution a second time.
