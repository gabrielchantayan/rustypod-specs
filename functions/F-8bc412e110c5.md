# F-8bc412e110c5

## Purpose

**Established static evidence:** Each iteration contains 37 indirect call sites, an unconditional software breakpoint with immediate `0x92`, and 15 explicit memory stores if execution reaches the end. Call results, secondary call-output state, shared pointer-bearing cells, and incoming machine state determine the addresses and values used.

**Inferred intent:** The function may coordinate multiple shared structures or device-facing locations. No application-level purpose, ownership model, or distinction between ordinary memory and mapped hardware is established.

This contract describes the represented execution and its observable ordering. It does not imply that the execution is safe, that all addresses are valid, or that the breakpoint normally resumes.

### Widths and arithmetic

The represented accesses distinguish 8-bit bytes, 16-bit halfwords, and 32-bit words. Paired results are represented as 64 bits, divided into low and high 32-bit words. This does not establish the physical return convention.

Unsigned halfword reads are zero-extended. Byte and halfword stores use the corresponding low-width representation. Endianness and alignment requirements are unknown.

The following arithmetic is established independently of uncertain signed-overflow behavior:

- The second paired result’s low word is treated as unsigned 32-bit data for both its right shift by 26 and its left shift by two. The right shift yields 0–63. The left shift discards bits above bit 31.
- Unsigned calculation from `0x21C48960` produces `(0x21C48960 >> 18) × 4 = 0x21C4`.
- A zero-extended 16-bit selector multiplied by four is at most `0x3FFFC`; its subsequent represented signed storage is within range.

- The late byte-store address combines the unsigned sampled halfword, the auxiliary base converted to unsigned 32-bit form, and `0x19` using unsigned 32-bit addition. Its numeric result is modulo \(2^{32}\); conversion of that result to a usable address remains platform-dependent.

Other operations include signed 32-bit additions, shifts, multiplications, and conversions between numeric values and addresses. Their behavior outside representable ranges is **documented_only**. In particular, signed scaling of the result from F-000000000013 and of the final paired result must not be assigned unconditional unsigned-wraparound semantics.
