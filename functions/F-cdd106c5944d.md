# F-cdd106c5944d

## Purpose

F-cdd106c5944d performs two 32-bit stores using values read from two distinct global data references, invokes two dependencies in sequence, and returns an address derived from the first dependency’s result.

The global data references are not established constants. Their values may differ between invocations or change during an invocation. In particular, the second global value is read only after the first dependency returns; it must not be replaced with a value captured before that call.

**Established behavior:** An initial global read supplies a store to the caller’s destination. The first dependency receives an interior address relative to that destination. Its result determines a second store location, a field-read location, and the eventual return value. A later global read supplies the second store. The field value determines one argument to the second dependency.

**Inferred intent:** This sequence is consistent with initialization of layout-sensitive storage. The supplied representation does not establish an object type, constructor role, dispatch-table interpretation, or ownership policy.

## Behavior

The read supplies the value for this store. Both occur before the first dependency call. The function does not visibly check Destination, inspect its previous contents, allocate storage, or branch on the global value.

### Derived base and second global read

The function then reads the 32-bit value supplied by the second global reference and stores that value at the derived base.

The important observable ordering is:

1. Read the first global value.
2. Store that value at Destination.
3. Call F-912a0b030d71 and obtain its result.
4. Read the second global value.
5. Store that value at the derived base.
6. Read the field used for the second dependency call.

The second global read observes the value available at that later read, subject to the actual memory model. It is not a snapshot taken at entry. Changes caused by the initial store’s aliasing or by F-912a0b030d71 can therefore affect the value stored at the derived base.

The two global references are distinct, but their numerical contents are not known. Neither equality nor inequality of the two stored values is established.

There is no visible copy of a destination region. If the derived base differs from Destination, the two stores target different starting addresses, although overlap and aliasing with other relevant storage remain possible.
