Important arithmetic distinctions include:

- A full-word shift differs from masking before shifting.

## Acceptance examples

These are conditional static scenarios, not executed tests.

### Truncating shift

A primary word of 0x12345678 shifted left by eight produces 0x34567800 under truncating 32-bit semantics. Retaining discarded high bits changes the argument.

### Index boundary and fixed byte

A relevant primary word of 0x7f produces small index 508 and doubled index 1016. The fixed-address-1 byte store therefore contains 0xf8 under those semantics, and occurs after the byte read at address 5 but before the subsequent calculated accesses.

### Early fixed word placement

If the retained link is 0x12345678, its one-bit left-shift value is 0x2468acf0 under truncating 32-bit semantics. That word reaches address 0x54 between the first and following doubled-index offset-0x14 replacements.

### Captured global base

If the global load returns address A and writing word 0x20 at address 0x60 changes the global’s storage to B, repeated stores still use captured A. Reloading B after the fixed write is not equivalent.

### Distinct final byte reads

If address 0x67 returns different bytes on its successive reads, address 0x21 receives its own read’s value. The two later calculated offset-9 stores each receive their respective later read’s value. Reusing the saved address-0xa9 low byte for all three violates those dependencies.

### Saved-word read timing

If the byte write at address 0x3a changes storage overlapping the later calculated offset-0x14 or offset-4 word reads, those saved words reflect the post-write accesses. The address-0xa9 word was captured earlier.

### Interrupted execution

If a late write faults, this contract requires neither restoration of earlier effects nor execution of the final transfer.
