# F-3ae1450e35fb

## Purpose

Two selector values choose between a no-argument operation and a four-argument operation by comparing an input against a shared comparison value. Two other selector values unconditionally choose a second no-argument operation.

This dispatch behavior is established by the supplied static evidence. The application meaning of the selectors, comparison value, arguments, and results is unknown. Descriptions such as initialization, cleanup, lookup, or error handling would be inferred intent, not established behavior.

### Equality-dependent selectors

For selectors `0x4184` and `0x418A`, the wrapper evaluates one equality comparison against the shared comparison value.

If the values are equal, it calls F-a987cce36382 without explicit arguments. None of the five inputs is explicitly passed to that dependency.

If the values differ, it calls F-a8353143ddb7 with this argument sequence:

1. First payload.
2. Comparison input.
3. Second payload.
4. Third payload.

The selector is not forwarded. The other arguments are forwarded without an explicit transformation in the wrapper.

The dependency result becomes the wrapper’s result without an explicit status conversion, normalization, or additional dispatch decision.

### Unconditional dependency selectors

For selectors `0x4185` and `0x418B`, the wrapper calls F-b1fed31c21cd without explicit arguments and returns its result.

The shared comparison value is not consulted on these paths. The payload inputs and comparison input do not participate in the wrapper’s decision.

“No explicit arguments” does not establish that the dependency is independent of shared state, thread-local state, external resources, or other execution context.

### Unrecognized selectors

Every other selector returns the four-byte zero result. This includes zero, adjacent unrecognized values, and any representable negative selector.

- Consult the shared comparison value.

- Validate the payload inputs.
