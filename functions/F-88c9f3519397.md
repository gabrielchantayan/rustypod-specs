## Behavior

For an input equal to 6, the function reads Selection-6 storage and returns that value. The visible path terminates without reading Selection-5, Selection-7, or Default storage.

For all remaining inputs, the function first reads Default storage.

- If the input equals 7, it subsequently reads Selection-7 storage and returns that second value. The previously obtained default value does not contribute to the result.
- If the input does not equal 7, it returns the value obtained from Default storage.

| Selector condition | Returned payload |
