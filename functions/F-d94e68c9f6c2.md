# F-d94e68c9f6c2

## Purpose

- The supplied pointer is non-null.
- The record’s first 32-bit word equals a global reference word.
- The record’s thirteenth 32-bit word is nonzero.

It returns a 32-bit zero otherwise.

The interpretation of these checks as a validity, identity, initialization, or readiness test is **inferred intent**, not established behavior. The function checks only the two identified words and their relationship to the global reference.

## Behavior

### Conditional evaluation and observable reads

The function first determines whether the supplied pointer is null.

If it is null, the function returns zero. Neither record word nor the global reference is needed on this path.

If the pointer is non-null, the function compares the first record word with the global reference word. Both values participate in this equality test. The supplied evidence does not establish which operand’s load occurs first, so the contract does not impose an order between those two reads.

If the comparison fails, the function returns zero without evaluating the later record-word condition. In particular, it does not read the word at byte offset 48 on that path.

If the comparison succeeds, the function reads the word at byte offset 48 and tests it against zero:

- A zero value produces a zero result.
- Any nonzero value produces a one result.

The later read is conditional on the earlier comparison succeeding. There is no retry, second comparison, or final revalidation of the first word or global reference.

This describes evaluation of the supplied expression. It does not establish hardware-level speculative-access behavior or synchronization guarantees.

The first comparison is an equality test, not an ordering test, mask test, range test, or comparison against a fixed literal embedded in the function.

The later test distinguishes only zero from nonzero. It does not require the stored value to equal one. Under the represented signed-integer interpretation, negative values qualify just as positive nonzero values do.
