# F-dd92cb67a560

## Purpose

F-dd92cb67a560 selects one of two construction modes, invokes F-793a94891814, and modifies specific fields in the storage returned by that dependency.

The mode decision depends only on whether the second input is zero. The original second input is also forwarded unchanged to the dependency. After the dependency returns, this function performs seven 32-bit writes and four 8-bit writes at fixed byte offsets from the returned address.

This is a static behavioral contract. No runtime tests have been performed. The supplied evidence establishes the branch, call arguments, field offsets, access widths, and visible ordering. It does not establish the meanings of the global words, the returned object’s full layout, allocation ownership, or dependency behavior.
