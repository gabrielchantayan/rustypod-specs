## Acceptance examples

These are conditional static criteria, not executed tests.

- **Root capture:** If the primary-base `0x34` store aliases global-root storage, traversal still uses the root captured before that store.
- **Byte-derived address:** A first byte-derived base of `0xa5` makes its word-`0x65` store target `0x10a`.
- **Interleaved capture:** If the retained-middle-payload location aliases the doubled first operand, its read observes memory after the downstream-payload byte store and before restoration of the operand’s low byte.
- **Threshold equality:** A threshold word of `0x4e` contributes zero to the second doubled result; `0x4f` contributes one.
- **Separate carries:** A carry operand of `0x80000000` produces doubling carry even when its reduced doubled result is zero. A carry operand of `0x7fffffff` with comparison bit one produces `0xffffffff` without carry.
- **Absolute capture:** If absolute address `0xdb` aliases the consecutive `0x09` destination, its capture follows both stores. Later source-memory changes do not replace the captured absolute payload.
- **Terminal character:** If conversion yields `0x21`, the terminal word store targets `0x66`, the byte store targets `0x65`, and the first invocation argument is `0x65`.
- **Partial failure:** An invalid later access establishes neither a structured failure return nor reversal of earlier mutations.
