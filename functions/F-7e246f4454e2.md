### Retained base before address 96

### Address 58 mutation

If A is 27, the address-58 byte is 8: eight times 27 plus 48 is 264, narrowed to eight bits.

If D + 20 equals 58, J is read after that byte mutation and must reflect it according to the target word layout. H and the retained Q + 116 word are read before the mutation.

### Independent address-103 observations

Suppose the copy read observes byte 7. If an intervening computed store changes address 103 to 9 before the first computed-store read, that read supplies 9, not 7. A further intervening aliasing write may similarly change the third read. Final-state equality alone does not satisfy these read-order obligations.

### Partial execution
