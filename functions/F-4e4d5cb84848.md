# F-4e4d5cb84848

## Purpose

No application-level purpose is established. The supplied representation does not establish an initialization protocol, supervisor operation, allocator, or particular data structure. This contract describes observable operations and retained data dependencies, without assigning those meanings.

All established behavior below is conditional on execution reaching the relevant operation. A dependency may fail to return, and a memory access may fault. The representation contains no explicit recovery path.

The initial dependency receives, in positional order:

2. Declared argument 4 logically shifted right by 22.

After four further calls, the routine reads a byte at the incoming address base plus 1. It zero-extends that byte, adds 17, and clears the selected byte. The destination lies between addresses 17 and 272; the incoming base determines the read location, not the final destination range.

The next call receives the immediately preceding primary result shifted left by two.

A later primary result is shifted left by two and retained as a scaled value. That scaled value is passed to a dependency. A subsequent 32-bit result is retained and passed onward. Another result supplies an object-like base; “object-like” describes its use as an address base, not an established object type.

The next explicit argument group is ordered as:

1. Object-like base.
2. Retained 32-bit result logically shifted right by 22.
3. That retained result without shifting.

### 2. Base-relative update and initial indexed words

The next explicit call receives:

1. Low half of the 64-bit result shifted left by two.
2. High half of that result.
3. The word read at the base plus 52.

After further calls, a secondary register result supplies an address/index value. The routine first stores the object-like base as a word at four times that secondary value plus 20. It then reads a word at the **unscaled** secondary value plus 20. The secondary value is passed to the following dependency.

A later primary result selects another word destination at four times that result plus 20, where the object-like base is stored again. Next, the routine reads a word at the previously loaded word’s logical right shift by 22, plus 20. The next explicit call receives four times the primary result that selected the preceding store.

Another primary result is shifted left by two and retained. The latest loaded word, logically shifted right by one, selects a destination at four times that shifted value plus 20; the retained scaled result is stored there.

2. Secondary result again.

## Acceptance examples

These are conditional static consequences, not executed tests. Each assumes that preceding calls and accesses complete and that the stated values exist at the specified observation points.

1. **Initial shift boundaries.** Fourth arguments 0x003FFFFF, 0x00400000, and 0xFFFFFFFF produce initial call argument pairs of respectively (0, 0), (1, 1), and (1023, 1023).

2. **Byte-selected clear.** A first indexed byte value of 255 selects address 272 for clearing, regardless of the magnitude of the incoming read base.

3. **Store-before-read overlap.** If the first secondary index in phase 2 is zero, its immediate word store and word read both address 20. With coherent writable memory and no intervening external mutation, the read observes the stored object-like base.

4. **Phase-3 positional distinction.** If the relevant secondary result is 7, the retained shared observation shifted right by 23 is 5, and the previously loaded word shifted right by 22 is 9, the explicit call arguments are (7, 7, 5, 9), not (7, 7, 9, 5).

5. **Sequential shifts yield zero.** A shared observation of 0xFFFFFFFF becomes 511 after the first right shift by 23 and zero after the second. The corresponding later word store therefore writes zero.

6. **Fresh observations matter.** If a dependency changes address 1 between its later reads, the next clear uses the new byte. Likewise, changing the repeated word at the phase-5 base plus 116 changes the second copied byte.

7. **Payload width.** A retained payload of 0x123456AB produces byte 0xAB in its immediate byte copy, while its later payload stores write the full 32-bit value.

8. **Phase-7 positional distinction.** For a shifted low half of 12 and a high half of 9, the first explicit four-argument call in phase 7 receives (12, 9, 12, 12).

9. **Terminal composition.** If the terminal byte is 0x5A and the three-byte observation after the pointer clear has value 0x123456, the output write stores value 0x1234565A. This establishes neither output address nor memory byte order.

10. **Terminal failure boundary.** If address zero is not callable, no normal return is promised. No visible mechanism rolls back earlier effects.
