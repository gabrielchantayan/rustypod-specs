## Behavior

### Dispatch sequence

The established sequence of relevant operations is:

1. Read the integer value stored at the input address.
2. Add 292 to that value.
3. Treat the computed result as the address of a function-pointer slot and read that slot.
4. Invoke the retrieved function pointer without explicit arguments.
5. If the invocation returns normally, return without producing an explicit result.

These are two distinct memory reads: an initial integer read through the input, followed by a function-pointer read through the derived address. The first read determines where the second occurs.

The first integer value is used directly in the address calculation. The representation does not show another dereference to obtain a table base before adding the displacement.

There is exactly one explicit indirect-call expression. No loop, alternative target selection, retry, fallback target, or error branch is present.
