## Behavior

The represented body contains no explicit conditional branch or loop. Every later operation is conditional on earlier accesses completing and earlier calls returning.

Dependency calls are observable ordering boundaries with unknown memory effects. A captured value remains the value already obtained; a later memory read is a fresh observation. Repeated stores remain separate effects even when their values or destinations coincide.

A recurring selector-directed store has two accesses:

1. Read an unsigned byte from a computed selector address.
2. Store a byte at the selector’s numeric value plus `0x11`.

The destination therefore lies between `0x11` and `0x110`, inclusive. It is not the selector-read address plus `0x11`. Separate selector occurrences perform separate reads. Dependencies and aliased stores may change the selector between occurrences.
