# F-7269c179a03c

## Purpose

F-7269c179a03c returns a directional change between two adjacent signed-integer values, reduced to a resolution of four input units. The first value is the reference; the second is the comparison.

For a representable nonnegative change, the result counts complete groups of four. Equality and increases smaller than four produce zero. The operation does not measure absolute distance and does not round to the nearest group.

For a representable negative change, the exact result depends on the environment’s rule for right-shifting negative signed values. Under an arithmetic, sign-preserving rule, the result is the change divided by four and rounded toward negative infinity. That rule is a conditional premise, not an established property of the target environment.

**Inferred intent:** The function may convert a difference into coarser units. The application, input units, and reason for the four-unit resolution are unknown.

## Behavior

### Nonnegative changes

For valid, stable input with a representable change of zero or greater, the result is the number of complete four-unit groups in that change.

| Complete change | Required result |
|---:|---:|
| 0–3 | 0 |
| 4–7 | 1 |
| 8–11 | 2 |
| 12–15 | 3 |
| 16–19 | 4 |

An increase of seven returns one, not two. Any remainder smaller than four is discarded.

The signs of the stored values do not independently determine the result. Moving from a more negative reference to a less negative comparison is an increase. Crossing zero introduces no special case, provided the complete difference remains representable.

Within this supported domain:

- Increasing the comparison while holding the reference fixed cannot decrease the result.
- Distinct input pairs can produce the same result.
- Adding the same mathematical offset to both values preserves the result when the adjusted values and complete difference remain representable.

These properties do not permit overflowing arithmetic or invalid storage.

### Negative changes

A comparison below its reference is not rejected, converted to an absolute magnitude, or explicitly clamped to zero.

The exact result is **documented_only** without the applicable negative signed-shift rule. A negative mathematical change does not, by itself, establish a negative returned value under every possible environment.

Under an arithmetic, sign-preserving right-shift rule, negative changes round toward negative infinity after scaling:

| Change | Required result under that premise |
|---:|---:|
| −1 through −4 | −1 |
| −5 through −8 | −2 |
| −9 through −12 | −3 |
| −13 through −16 | −4 |

This creates directional asymmetry. Under that premise, a one-unit increase returns zero, while a one-unit decrease returns negative one. A seven-unit increase returns one, while a seven-unit decrease returns negative two.

Exchanging the inputs therefore need not negate the result, even when both directional differences are representable. Rounding negative changes toward zero would violate the arithmetic-shift interpretation whenever the change is not divisible by four.
