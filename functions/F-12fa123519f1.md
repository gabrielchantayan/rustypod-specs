# F-12fa123519f1

## Purpose

F-12fa123519f1 conditionally delegates an event, performs a global bit toggle with two notifications, or dispatches one of two object callbacks after matching event fields against object state.

The established behavior is driven by a 32-bit event discriminator with two recognized values: 15 and 19. Value 15 can invoke an early delegate and, if execution continues and the discriminator still has that value, trigger the toggle-and-notify sequence. Value 19 selects a matching procedure with a primary route and a gated secondary route.

The apparent intent is event handling, but the meanings of the discriminator values, coordinates or identifiers, global state, and callbacks are not established. In particular, the two event payload fields must not be assumed to represent coordinates merely because they are compared as a pair.

The result distinguishes a nonzero early-delegate result, successful callback dispatch, and ordinary fallthrough. It does not consistently report whether side effects occurred: the toggle-and-notify sequence can complete and still produce a zero result.

## Interface

### Inputs

The function receives two address-like arguments:

- **Object:** a pointer to mutable storage, accessed through 32-bit fields and an indirect dispatch table.
- **Event:** an address from which the discriminator and payload fields are read.

The supplied representation uses 32-bit integers for the relevant object and event fields. The event address is represented as an integer rather than a typed pointer. Its treatment as an address, together with the dispatch-table representation, indicates a 32-bit target model; a portable calling convention or a wider-pointer adaptation is not established.

The function does not perform null checks, bounds checks, address validation, or dispatch-target validation.

### Relevant object layout

Offsets are in bytes from the object address.

| Offset | Access | Established role |
|---|---|---|
| 0 | Read | Dispatch-table address used for indirect callbacks. |
| 64 | Read, 32 bits | Primary comparison value for the event field at offset 8. |
| 68 | Read, 32 bits | Primary comparison value for the event field at offset 12. |
| 152 | Read, 32 bits | Secondary comparison value for the event field at offset 12. |
| 156 | Read, 32 bits | Secondary-route enable field; any nonzero value enables consideration. |
| 500 | Address formed | Location passed to F-ec4cfa552cce; no field value is read there directly by this function. |

The offset of 500 bytes follows from advancing the object pointer by 125 elements of four bytes each. This is an interior address, not a separately loaded pointer.

The indirect dispatch table has relevant entries at byte offsets 160 and 212. The names and wider interface of that table are unknown.

### Relevant event layout

| Offset | Access | Established role |
|---|---|---|
| 4 | Read, 32 bits | Discriminator, evaluated at multiple points. |
| 8 | Read, 32 bits | First matching payload field. |
| 12 | Read, 32 bits | Second matching payload field. |

There is no direct access to event offset 0.

### Results

The function returns a 32-bit integer:

- The exact nonzero result from F-a4e66de5f407, when the early-delegation branch returns immediately.
- Exactly 1 after either indirect callback is invoked by the value-19 matching procedure.
- Exactly 0 on ordinary fallthrough or a failed value-19 match.

Negative nonzero results from the early delegate are returned unchanged. The interface does not establish whether such values signify errors.

## Behavior

### Discriminator evaluation and early delegation

The function first evaluates the event discriminator at offset 4.

If it equals 15, F-a4e66de5f407 is called with the object and event addresses, in that order. A nonzero result causes an immediate return of that exact result. No subsequent action by F-12fa123519f1 occurs on this path.

A zero result allows processing to continue. The delegate is not known to preserve the event, object, globals, dispatch table, or any other reachable state.

The discriminator is evaluated again for the toggle-and-notify stage. Consequently, the initial discriminator value is not a durable classification of the entire invocation. In particular, a delegate that returns zero may have changed which subsequent branch is taken.

### Toggle-and-notify stage

If the discriminator evaluated at this stage equals 15, the function performs these actions in order:

1. Read the value in a globally designated storage location and write back that value XOR 1.
2. Call F-92bea7c30bd6 with the object address.
3. Call F-ec4cfa552cce with the address 500 bytes into the object.

The XOR operation changes only the least significant bit of the stored value. It is not a conversion to a normalized Boolean and is not equivalent to logical negation for arbitrary stored values.

The supplied material does not declare the pointed-to global storage type, so its access width is not established. The bit-level transformation is established independently of that missing declaration.

The result of either notification call is not used by this function. The second call follows the first when the first returns normally, regardless of an ordinary returned status.

This stage does not itself return a handled result. Processing continues to another discriminator evaluation.

### Value-19 matching procedure

After the preceding stages, the function evaluates the discriminator again. If it is not 19, the function returns 0.

If it is 19, the event field at offset 12 is read into a retained 32-bit value. That retained value is used for both the primary comparison and, if needed, the secondary comparison. The function does not independently reread that field for the secondary comparison.

#### Primary route

The retained event value is first compared with the object field at offset 68.

If these are unequal, the primary route does not read the event field at offset 8, the object field at offset 64, or the primary global alternate as part of this comparison.

If they are equal:

- The event field at offset 8 is read.
- The object field at offset 64 is read.
- Equality between these values accepts the primary route.
- If they differ, a 32-bit primary global alternate is read. Equality between the previously read event value at offset 8 and this alternate also accepts the primary route.

Thus the primary route requires the offset-12 match, plus either the object-specific or global-alternate offset-8 match.

On acceptance, the function obtains the object’s dispatch table and invokes its entry at byte offset 212 with the object as its sole explicit argument. After that callback returns normally, F-12fa123519f1 returns 1. The callback’s return value, if any, is not used.

The primary route has precedence over the secondary route. An accepted primary route prevents evaluation of the secondary enable field and prevents the secondary dependency and callback from being invoked by this function.

#### Secondary route

If the primary route did not accept, the function reads the object field at offset 156.

If that field is zero, the function returns 0 without performing the secondary payload comparison.

If it is nonzero, the retained event value from offset 12 is compared with the object field at offset 152. If these values differ, the function returns 0 without reading the secondary global alternate.

If they match:

- The event field at offset 8 is read for this secondary route.
- A 32-bit secondary global alternate is then read.
- These two values are compared.

The secondary route uses the global alternate as its offset-8 criterion. It does not compare against an additional object-specific value at that stage.

If the comparison fails, the function returns 0.

If it succeeds, F-5710a8628cba is called without explicit arguments. A one-byte value from its result is retained. Only after that call returns does this function obtain the object’s dispatch table and invoke the entry at byte offset 160, passing the object and that retained byte value.

The ordering matters: F-5710a8628cba may change the object’s dispatch-table address or table contents before the callback target is obtained. Preservation must not be assumed.

After the callback returns normally, the function returns 1. The callback’s result is not used.

## Side effects

The sole explicit data write visible in this function is the XOR-with-1 update of the globally designated storage location. No object or event field is directly written by the visible body.

Additional effects may occur through:

- The early delegate.
- Either notification dependency.
- The secondary value-producing dependency.
- Either indirect callback.

Those effects are undocumented here. In particular, none of these calls is established to preserve globals, object fields, event fields, or allocation state.

The function explicitly performs no allocation, deallocation, ownership transfer, or reference-count operation. Passing the object, event, or object-interior address to a dependency does not establish what that dependency may retain, release, or modify.

There is no visible rollback. For example, the global toggle has already occurred before the first notification is called.

No synchronization or atomic read-modify-write guarantee is established for the global toggle. No behavior is specified for concurrent mutation of the event, object, dispatch table, or globals.

Invalid addresses or invalid callback entries are not translated into an ordinary zero result. Their effects depend on the execution environment. Likewise, the described continuation after a call is conditional on that call returning normally.

## Acceptance examples

These are conditional contract examples, not executed tests. Unless stated otherwise, assume valid accessible storage, normally returning dependencies, and no intervening mutation beyond what each example specifies.

1. **Immediate delegated result.**  
   The initial discriminator is 15 and F-a4e66de5f407 returns −3. The function returns −3. It does not perform its toggle, notifications, or matching callbacks.

2. **Toggle without a handled result.**  
   The discriminator remains 15 throughout, and the early delegate returns zero. The function toggles the global least significant bit, calls F-92bea7c30bd6, then calls F-ec4cfa552cce with the interior address. The final discriminator evaluation is not 19, so the result is 0.

3. **Bit toggle is not Boolean normalization.**  
   On a toggle-stage execution, an initially stored value of 2 becomes 3; an initially stored value of 3 becomes 2. These examples do not require an assumption about the storage width beyond its ability to represent those values.

4. **Delegate changes the event classification.**  
   The initial discriminator is 15. The early delegate changes it to 19 and returns zero. The toggle stage is skipped, and the value-19 matching procedure runs against the subsequently read state.

5. **Notification changes the event classification.**  
   The toggle stage runs, and a notification changes the discriminator to 19. After both notifications return, the matching procedure runs. The invocation can therefore both toggle global state and return 1 after a successful matching callback.

6. **Primary object-specific match.**  
   The value-19 procedure reads equal values at event offset 12 and object offset 68. The values at event offset 8 and object offset 64 also match. The primary global alternate is not needed or read by this route. The callback at dispatch offset 212 is called, followed by a result of 1.

7. **Primary alternate match takes precedence.**  
   The primary offset-12 values match; the offset-8 object comparison fails; the primary global alternate matches the event value. The primary callback is invoked. Even if the secondary route would also match, it is not evaluated.

8. **Disabled secondary route.**  
   The primary route fails and the object field at offset 156 is zero. The result is 0. F-5710a8628cba and the secondary callback are not invoked.

9. **Successful secondary route.**  
   The primary route fails, the secondary enable field is nonzero, the retained offset-12 event value matches object offset 152, and the newly read event offset-8 value matches the secondary global alternate. F-5710a8628cba runs first. Its byte result is then passed to the callback selected from the object’s dispatch table after that dependency returns. The result is 1.

10. **Unrecognized discriminator.**  
    With a stable discriminator other than 15 or 19, the function returns 0 without invoking a dependency or callback and without performing the explicit global write.

## Uncertainties

The following remain **documented_only**:

- Semantic names and units for the discriminator and matching fields.
- The global toggle storage width, its ownership, and the validity of its backing pointer.
- Values, initialization rules, and ownership of the two global alternates.
- Dependency and callback effects, including mutation, retention, release, failure, and non-returning behavior.
- Concrete object type, total allocation size, and validity rules for the interior address.
- Exact dispatch-table ABI and byte-argument extension rules.
- Thread-safety and asynchronous-mutation behavior.
- Whether nonzero early-delegate results are statuses, handled indicators, errors, or a mixture.

The event-handler interpretation is inferred intent, not an established semantic contract.
