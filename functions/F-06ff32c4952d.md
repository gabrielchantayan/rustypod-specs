## Behavior

### 1. Capture the parameter inputs

The function copies the six global words into the parameter block in their listed order. Denote their captured values by \(W_0\) through \(W_5\), where each value is an unsigned 32-bit quantity.

All six explicit global-word reads occur before any dependency call. The parameter values therefore reflect these early reads, not any subsequent changes a dependency might make to the original globals.

The reads are ordered; no atomic snapshot or synchronization mechanism is established.

### 2. Apply unsigned halving

Each of the six words receives a logical right shift by one bit:

\[
H_i = \left\lfloor \frac{W_i}{2} \right\rfloor,\qquad 0 \leq i \leq 5.
\]

Consequences:

- The original least-significant bit is discarded.
- The newly introduced most-significant bit is zero.
- There is no sign extension.
- Odd values round down.
- Each shifted word lies between \(0\) and \(2^{31}-1\), inclusive.

The in-place transformations proceed from the last word toward the first: \(W_5\), then \(W_4\), through \(W_0\). The loop covers exactly the six initialized words; it does not transform a seventh word beyond the block.

No dependency receives the block until these transformations are complete.

### 3. Narrow part of the final word

After the six shifts, the function performs an additional update on the three-byte subobject occupying part of the final word.

The supplied representation establishes this operation:

- Read that 24-bit subobject.
- Convert its value to an unsigned 16-bit value.
- Assign that value back into the 24-bit subobject.

The resulting 24-bit value therefore has its highest eight bits cleared and retains its lowest sixteen bits. The adjacent one-byte subobject is not part of this assignment.

This is **not** an assignment of a 16-bit value to the entire final 32-bit word. Treating it as such would incorrectly discard the adjacent byte.

Under a little-endian interpretation, where the three-byte subobject occupies the low 24 bits of the final word, the resulting final word is:

\[
P_5 =
\bigl(H_5 \mathbin{\&} \text{0xFF000000}\bigr)
\mathbin{|}
\bigl(H_5 \mathbin{\&} \text{0x0000FFFF}\bigr).
\]

Thus bits 16–23 are cleared, bits 0–15 are retained, and bits 24–31 remain as produced by the shift. The supplied excerpt does not independently establish target endianness; this whole-word formula is conditional on that layout.

The first five words receive no comparable narrowing.

### Final-word subobject update

Assuming the little-endian layout described above:

- A final input word of 0xFFFFFFFF first becomes 0x7FFFFFFF, then becomes 0x7F00FFFF.
- A final input word of 0x00020000 first becomes 0x00010000, then becomes zero.
- A final input word of 0x80000000 becomes 0x40000000 and retains that value after the subobject update.

These cases distinguish clearing the middle byte from truncating the entire word to sixteen bits.
