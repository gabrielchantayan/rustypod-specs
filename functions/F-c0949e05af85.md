## Acceptance examples

These are conditional static acceptance examples, not executed tests.

- **Initial selector:** If the entry-base byte is `0x7f` and the entry byte is `0xab`, the first visible store writes one byte, `0xab`, at address `0x90`.

- **Early scaling:** If the fourth argument is 2 and the entry quantity is 3, the early word store targets `0x2014` and writes `0x00003000`, assuming execution reaches it.

- **Discarded high shift:** Under the stated 32-bit model, shifting the initial word left twenty-eight bits yields zero for every entry quantity. A nonzero argument at that site would contradict this model.

- **Selector rereading:** If a dependency changes the entry-base selector between two reads, the subsequent byte-selected store must use the new selector. Reusing the original selector is not equivalent.

- **Retained selector:** Conversely, the word store following retention of the clearing-base selector uses that retained value even if dependencies subsequently change the byte in memory.

- **Clearing-base range:** Under modulo-32-bit multiplication, an index multiplied by `0x40000000` yields only `0`, `0x40000000`, `0x80000000`, or `0xc0000000`. The two direct zero stores use offsets `0x11` and `0x01` from that result, in that order.

- **No completion:** If every operation succeeds and every dependency returns, completing one iteration starts another. There is no finite successful-return case in the visible control flow.
