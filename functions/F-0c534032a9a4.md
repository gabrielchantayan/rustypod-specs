# F-0c534032a9a4

## Purpose

It dispatches among operations that retain arguments, calculate arithmetic predicates, obtain a pointer-valued result from a dependency, write selected fields, invoke dependencies with interior addresses, publish a pointer, and call a release-shaped dependency.

**Inferred intent:** construction and publication of an opaque object, possibly with associated data and cleanup.

**Established limits:** the dependency receiving 36 is allocator-shaped, but its absent contract does not establish an allocation request or an allocation extent. Similarly, the external dependency receiving an interior pointer, retained A, and 24 is transfer-shaped, but neither a 24-byte access nor a byte-count argument is established.

Missing global values prevent determining a unique operation sequence. They do not obscure the operation-specific computations described below.

All examples are conditional static criteria. No runtime tests have been performed. Unresolved behavior is marked **documented_only**.

## Acceptance examples

These are conditional specifications, not executed tests.

1. **Immediate return:** Initial selection of alternative 13 returns zero, while still performing entry and pre-selection global reads.

2. **Pointer-producing call:** Reaching alternative 3 passes 36 to F-d33f6d597e5d. Both pointer-branch reads occur after the call. This alone does not establish an allocation.

3. **Conversion history:** Capture followed by conversion without a shared-word overwrite converts C. If alternative 0, 7, or 14 first replaces the shared word, conversion instead uses that replacement.

4. **Field before conversion:** Before any conversion, a valid offset-0 field write stores exactly zero, independent of K.

5. **Separate retained states:** Alternative 7 changes the extra D product; alternative 0 does not. Alternative 14 consumes the previous auxiliary word before replacing it. Substituting the result word for that prior auxiliary value is not equivalent.

6. **Paired-field order:** The offset-28 value is calculated first. Offset 0 is written first. An offset-0 write cannot change which K value was already used for offset 28.

7. **A predicate:** Zero A selects the first iteration snapshot after paired fields. A equal to one, two, 256, or any other nonzero unsigned word selects that snapshot minus fourteen.

8. **External-call extent:** Reaching the unmapped call establishes its three arguments, not a 24-byte read or write.

9. **Limited zeroing:** Alternative 15 writes offsets 4–7 only; it does not establish initialization beyond them.

10. **Callback branching:** A zero extracted bit selects the later callback-branch read minus eight; a one selects the earlier read. The original second iteration snapshot is not used.

11. **Result loads:** Alternatives 10 and 11 have identical result-load behavior and do not update the auxiliary word. Scaling alternatives do update it.

12. **Post-call globals:** Callback and release computations use their specified post-call reads. Replacing these with pre-call snapshots is not equivalent if dependencies modify globals.

13. **Publication:** A valid output slot receives the current working pointer. A final zero return additionally requires subsequent operations to preserve zero and reach return.
