# F-37e7c133a886

## Purpose

F-37e7c133a886 updates a destination subobject within a caller-supplied object. It first performs a common initialization or reset-like operation on that destination, optionally obtains and converts a value according to a selector, applies the converted value, and finally invokes a common destination operation.

The established behavior is the sequence of dependency calls, the addresses and arguments supplied to them, the unsigned comparison used by selector 0, and the branch-specific temporary-storage lifetimes. The meanings of the values being obtained and the resulting destination contents are not established.

Inferred intent: this is a selector-driven value-to-destination update, with several source-value representations converted into a common representation. Terms such as “reset,” “conversion,” and “cleanup” describe apparent roles; they do not establish dependency semantics.

## Interface

### Object layout used directly

The destination’s size, internal representation, alignment, and valid construction states are unknown. The pointer field and destination address are distinct locations, but the evidence does not establish the complete containing-object layout.

## Behavior

The following ordering applies when dependencies return normally. Dependencies can themselves have effects not described here.

### Common prefix

Every selector, including an unrecognized selector, begins with the same three operations:

1. F-5b24edfb22c0 receives the address of an 8-byte temporary region.
2. The returned 32-bit value is supplied as the second argument to F-46f0b3cb316e. Its first argument is the destination address at object offset `0x10`.

Only after these operations does selector-specific work begin. Consequently, even an unrecognized selector can change the destination or cause other dependency effects.

### Selector 0: comparison-controlled source selection

This branch performs the following operations in order:

1. Read the source-object pointer from object offset `0x0C`, then read its callable-table pointer.
2. Invoke the callable entry at table offset `0x1AC`. No explicit argument is visible in the supplied call representation.
3. Interpret the result as an unsigned 32-bit comparison value.
4. Compare the third input against that result using strict unsigned less-than.
5. Read the source-object and table pointers again, then select:
   - table offset `0x27C` if the third input is less than the comparison value;
   - table offset `0x28C` otherwise.
6. Invoke the selected entry with the address of a 20-byte temporary region as its visible argument.
7. Invoke F-5fb92c16ae07 with an 8-byte conversion-output region and the 20-byte temporary region.
8. Invoke F-46f0b3cb316e with the destination address and the 8-byte conversion-output address.
9. Invoke F-289ec4311c64 on the 8-byte conversion-output region.
10. Invoke F-c1466ea05103 on the 20-byte temporary region.
11. Continue to the common suffix.

Equality takes the `0x28C` path. Neither selected producer receives the third input as a visible argument.

The pointer reread after the comparison-producing call is significant. The selected producer is resolved from the object pointer and table available after that call, not necessarily from the same table used to obtain the comparison result. No assumption that the first dependency preserves this state is required.

### Other selectors

The common prefix has already occurred. Execution proceeds directly to the common suffix. This path does not directly read the source pointer at object offset `0x0C`.

For selectors 0 through 6, this operation follows both application of the branch-specific converted value and the visible temporary cleanup calls. For all other selectors, it follows the common prefix without a branch-specific application.

## Side effects

### Destination operations

F-44362605ab79 is called once on every normally completing invocation, after all branch-specific work.

These calls receive a mutable-looking destination address, but their exact writes are unknown. The evidence does not establish that the prefix clears the destination, that the second application replaces rather than appends, or that the suffix publishes, commits, or validates anything.

## Acceptance examples

These are conditional acceptance scenarios derived from static evidence, not executed tests.

1. **Unrecognized selector.** Given valid prefix and suffix dependencies and selector 7, the prefix operations occur, followed by F-44362605ab79. No branch-specific indirect producer or converter is invoked.

2. **Unsigned comparison below the boundary.** Given selector 0, third input 4, and a comparison result of 5, the entry at `0x27C` is selected. The 20-byte result is converted and applied before its cleanup-role call and the common suffix.

3. **Equality at the boundary.** Given selector 0, third input 5, and comparison result 5, the entry at `0x28C` is selected. Equality does not select `0x27C`.

4. **High-bit operand.** Given selector 0, third input `0xFFFFFFFF`, and comparison result 1, the entry at `0x28C` is selected because the comparison is unsigned.

5. **Changed source pointer during comparison.** If the `0x1AC` dependency changes the source pointer stored at object offset `0x0C` and returns normally, subsequent producer selection uses the newly read pointer and its table. The function does not require the old table to remain the selection source.

6. **Selector-specific dispatch.** Given selector 2 and third input `0xFFFFFFFF`, the entry at `0x138` receives that unchanged 32-bit input. No local range rejection occurs. Whether the indirect dependency accepts it is outside this contract.

7. **Equivalent selector paths.** Given otherwise equivalent dependency state, selectors 5 and 6 select the same table entry and the same sequence of converter, destination, cleanup-role, and suffix dependencies. External dependencies can still make separate invocations produce different results.

8. **Cleanup ordering.** Given selector 3 and normal returns, F-289ec4311c64 on the conversion output precedes F-ee5919ca4be6 on the source result; both precede F-44362605ab79.
