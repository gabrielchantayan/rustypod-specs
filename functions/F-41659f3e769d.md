# F-41659f3e769d

## Behavior

### Initial writes

The function first obtains the value associated with data source A and writes four bytes at the base address.

It then obtains the value associated with data source B and writes four bytes to the same destination.

The second write is not conditional. There is no intervening dependency call or other explicit operation between these writes.

Both writes are part of the established sequence. The first must not be discarded from the behavioral contract merely because the second targets the same location. Whether another observer can detect the intermediate value depends on memory characteristics and the execution environment; synchronization and volatile-access semantics are not established.

The second value is obtained after the first write in the supplied sequence. Consequently, if the destination aliases data source B, the first write may affect the value subsequently obtained from that source. No non-aliasing guarantee is supplied.

Immediately after the second write, the destination contains the value used for that write, assuming ordinary successful storage. This is not necessarily its value when the function returns: later callees may modify the destination or related state.

### Dependency invocation

### Conditional indirect invocation

If that value is null, the indirect invocation is skipped.

If that value is non-null, the function performs a fresh read from R − 4. This second read is used to select the call target; it is not established to reuse the value tested by the condition.
