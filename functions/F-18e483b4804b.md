**Established static evidence:** the represented interface has no explicit parameters or explicit result. Observable behavior consists of dependency invocations, memory reads and writes, and control transfer. Completion depends on all reached calls and memory accesses completing.

The evidence does not establish an application-level purpose such as parsing, formatting, allocation, or device control. Character-like constants do not establish text output.

Under the bit-vector model, the small index is a multiple of four between zero and 508 inclusive. Its doubled form is therefore between zero and 1016 inclusive.

The opening mutation region has these established ordering constraints:

- That byte first receives the low byte of the final high word. A word store through an address derived from the final low word intervenes before the byte is replaced with the low byte of the shifted token.

### Literal-valued stores and shared-base capture

- An 8-bit store at a fourfold-scaled address.
- A 16-bit store at an eightfold-scaled address.
- A 32-bit store at offset 0x20 from the fourfold-scaled address.

The operation also forms an **adjusted base** by subtracting 0x96 from four times the saved pointer value. Four times this adjusted base is the **literal-region base**.

At literal-region-relative offset 0x20, the represented word-store sequence is 0x20, 0x2F, a zero-extended byte loaded from literal-region-relative offset 4, and 0x20 again. The byte is loaded after the 0x2F store and before the final 0x20 store.

**The shared-base capture occurs after that final computed-offset 0x20 store and before the fixed-address word store of 0x20 at address 0x60.** The shared 32-bit value is read once at this boundary and retained as the **captured shared base**.

This ordering has two consequences:

- Earlier computed-address writes may affect the captured value if they alias its storage.
- The subsequent store at address 0x60 does not cause the retained value to be reloaded or replaced.

The shared cell is not assumed to be disjoint from calculated destinations or fixed-address storage. Conversely, overlap is not asserted. Where aliasing is possible, the required observation point remains between the two specified stores.

## Acceptance examples

These are conditional static examples, not executed tests.

### Word-width scaling

Under the 32-bit bit-vector model, shifting 0x01000001 left by eight bits yields 0x00000100. Retaining a wider mathematical result would change the represented argument.

### Masked extraction

For an unsigned word of 0xABCDEF12, selecting the low 24 bits and then shifting right by 20 yields 0xC. Omitting the mask changes the result.

### Small-index boundary

Under the stated model, the small-index extraction produces only multiples of four and cannot exceed 508. Its doubled form cannot exceed 1016. Treating every integer through 511 as attainable would admit unsupported values.

### Capture timing around address 0x60

Suppose the final literal-region-relative 0x20 store has completed, and the shared cell contains an address value at the ensuing read. That value becomes the captured shared base before address 0x60 receives its word-sized 0x20 store.

If the later fixed-address store changes the shared cell through overlap, propagation still uses the earlier captured address. Moving the shared read after that store, or reloading the cell for each group, changes the specified behavior.

### Earlier alias affecting capture

If an earlier literal-region store overlaps the shared cell, the subsequent shared-base read observes memory after that store, subject to the actual environment’s access semantics. Hoisting the read before the literal-store sequence is not equivalent.

### Duplicate writes

If the two matching byte stores at doubled-index-relative offset 0x15 are externally observable, both occur in order. One final-state write is insufficient.

### Read after clear

If no intervening write aliases scaled-base-relative offset 0x14 and no external agent changes it, its later word load yields zero. Without those conditions, zero is not an unconditional postcondition.

### Interruption and completion

If F-D001 never returns, no later caller-side effects are required. If all preceding operations complete and F-D003 returns normally, execution reaches the represented return without an explicit result value.
