# F-1ea2f518fc81

## Purpose

F-1ea2f518fc81 conditionally performs a fixed-length integer square-root calculation on a 32-bit input, then reaches an unresolved indirect control transfer.

For inputs whose signed 32-bit interpretation is positive, the established arithmetic result is:

- An integer root equal to the floor of the square root of the input multiplied by \(2^{16}\).
- A nonnegative remainder equal to that scaled input minus the square of the computed root.

Equivalently, the root is \(\lfloor 256\sqrt{n}\rfloor\), where \(n\) is the unsigned numerical value of the accepted input.

These are internal arithmetic results. The supplied evidence does **not** establish that either result is returned, stored in caller-accessible memory, or passed to the unresolved destination.

Inputs whose signed 32-bit interpretation is zero or negative take the direct return path without performing the calculation or reaching the unresolved transfer.

## Behavior

### Entry decision

The signed interpretation of the argument is tested before any square-root work occurs.

If that interpretation is not strictly positive, execution returns directly. In particular, an input with its high bit set is not processed as a large positive unsigned number.

If the interpretation is positive, the function initializes an internal root and remainder to zero and performs exactly 24 arithmetic rounds.

### Meaning of the calculation

The rounds consume two input bits at a time, starting with the most significant pair of the 32-bit argument.

There are only 16 such pairs in the original argument. The working input is shifted left by two bits after each round, with bits shifted beyond the 32-bit width discarded. Consequently:

- The first 16 rounds consume the original argument’s bit pairs in most-significant-first order.
- The final eight rounds consume zero pairs.
- The complete calculation therefore acts on a 48-bit mathematical radicand consisting of the original 32 bits followed by 16 zero bits.

That radicand is \(n \times 2^{16}\). It is a mathematical description of the bit stream; the supplied body does not construct it in a 48-bit memory object.

For every completed round, the internal root is the integer square root of the bit-pair prefix consumed so far. The remainder is the difference between that prefix and the square of the root.

After all 24 rounds, the following relationships hold:

\[
q=\left\lfloor\sqrt{n \times 2^{16}}\right\rfloor
\]

\[
r=n \times 2^{16}-q^2
\]

\[
0\leq r<2q+1
\]

The final inequality characterizes a floor square root: the next larger integer root would exceed the radicand.

### Round ordering and comparison

Each round first incorporates the next two input bits into the remainder. It then compares that accumulated quantity against a trial value determined by the root from the preceding round.

The comparison is unsigned and includes equality. Equality selects the subtracting branch and produces a zero remainder for that round.

The root advances by one binary digit per round. The chosen digit is one when the accumulated remainder is at least the trial value, and zero otherwise. A successful trial subtracts its value from the accumulated remainder.

The input working copy is shifted only after the current pair has been incorporated. Thus the first round uses the original most significant pair, not the pair exposed by an initial shift.

The number of rounds does not depend on the input magnitude or on whether intermediate remainders become zero. There is no early exit for perfect squares.

### Widths and arithmetic safety

The input working value and remainder operate as 32-bit unsigned quantities. Right shifts of the input therefore introduce zero bits. Left shifts of that working input retain only the low 32 bits.

The root and round counter are represented as signed integers in the supplied body. For eligible inputs, their arithmetic stays within signed 32-bit range:

- Exactly 24 root digits are produced, so the root remains below \(2^{24}\).
- Before the final round, the root remains below \(2^{23}\); multiplying it by four and adding one remains below \(2^{25}\).
- The remainder and its two-bit expansion also remain well below the 32-bit limits.
- The counter starts at 24 and reaches zero after exactly 24 decrements.

Thus the positive-input calculation does not require signed overflow or overflow of the unsigned remainder to obtain the stated result. Truncation of the shifted input is intentional to the observed bit-consumption behavior.

The mathematical product \(n \times 2^{16}\) can exceed 32 bits. Acceptance calculations must use sufficient precision rather than truncating that product to 32 bits.
