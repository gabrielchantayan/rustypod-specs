# F-8693ded0dc82

The established behavior is an ordered sequence of three assignments, not a snapshot of all inputs followed by a bulk copy. This distinction matters when the destination overlaps either input: an earlier destination write can change a value read by a later assignment.

1. A four-byte value is read from word-source byte offset 0 and assigned to destination byte offset 0.
2. A four-byte value is read from word-source byte offset 4 and assigned to destination byte offset 4.
3. A one-byte value is read from the byte source and assigned to destination byte offset 8.

Each assignment uses the source value available at that point in the sequence. In particular, the second source value is not visibly saved before the first destination write, and the byte-source value is not visibly saved before the two four-byte destination writes.

### Overlap and aliasing

Aliasing affects which values later reads observe.

If the first destination write changes the storage used by the second word-source read, the second assignment uses that changed value. The function therefore must not be specified as always copying the original eight-byte word-source contents.

Likewise, if the byte source points into destination offsets 0–7, the final byte read observes the location after the preceding destination assignments, under ordinary sequential memory semantics.

If the byte source points exactly to destination offset 8, the final assignment reads and writes that same byte. The earlier destination writes cover offsets 0–7, so they do not themselves change offset 8.

If the destination and word source identify the same two-word region, the first two assignments are self-assignments. With stable ordinary memory, their values remain unchanged. The final byte assignment still occurs.
