## Behavior

### Established decision rule

The function forms the integer immediately preceding the input, intersects its set bits with those of the original input, and returns whether that intersection is empty.

For any positive unsigned integer, decrementing it clears its least significant set bit and turns the lower zero bits into ones. Intersecting the decremented value with the original value therefore removes exactly that least significant set bit while retaining any set bits above it.

Consequently:

- An input with exactly one set bit leaves no shared set bits and returns true.
- An input with at least two set bits leaves at least one shared set bit and returns false.

This explanation establishes the result for all positive representable inputs, not only for small example values.
