# F-eb53a434010d

## Purpose

F-eb53a434010d classifies whether two unsigned input words agree at the bit positions selected by a shared mask.

It returns the four-byte value **0** when the masked values are equal and **3** when they differ. These are literal result values, not a conventional false/true pair. Their meaning to callers is not established.

The first argument does not participate in the comparison. No validation, allocation, callback, or explicit state update is shown.

This contract distinguishes the comparison established by the supplied static evidence from assumptions about integer widths, mask stability, and the execution environment.

## Behavior

### Comparison rule

For a stable effective mask, the function applies that mask independently to the second and third arguments using bitwise AND. It compares the two masked results for equality.

- Equal masked results produce **0**.
- Unequal masked results produce **3**.

Only positions selected by the mask affect this classification. Differences in unselected positions do not affect the result.

An equivalent description is that the result is 3 precisely when at least one selected bit differs between the two comparison inputs. This describes the same relation; it does not establish that the implementation performs any additional exclusive-OR operation.
