### Final-region interleaving

A conforming reached trace reads fixed word 0xA9, reads the computed offset-0x74 word, writes fixed byte 0x3A, then reads the computed offset-0x14 and offset-four words.

If the offset-0x14 read covers address 0x3A, its result incorporates the preceding byte write according to the actual byte order. The same condition applies independently to the offset-four read. Hoisting either read before the byte write is not accepted on an aliasing execution.

The retained 0xA9 and earlier offset-0x74 values are not recomputed after that write.
