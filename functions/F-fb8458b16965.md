# F-fb8458b16965

## Purpose

F-fb8458b16965 performs a guarded, index-directed operation on a mutable object. It accepts an object reference and a signed integer selector, optionally consults a preliminary guard, resolves or validates the selector, and conditionally invokes two object-dispatched operations followed by a final dependency.

The established contract concerns branching, argument values, observable access stages, call order, and return handling. The supplied evidence does not establish that this function removes an element, truncates a sequence, or destroys a resource.

Two selector values receive special treatment:

- **2,147,483,647** selects the count-like field minus one when the positive-count test succeeds. This bypasses the normal validation dependency, but not the preliminary guard.
- **−1**, when accepted by normal validation, returns immediately without either dispatch call or the final dependency.

Rejection also returns −1. The return value alone therefore cannot distinguish rejection from an accepted negative-one selector.

## Behavior

If that value is zero, F-07032ba1c514 is skipped and processing continues.

1. The object reference.
2. The original selector, before any maximum-selector resolution.

### Selector resolution and validation

After the guard permits continuation, the function checks whether the selector is 2,147,483,647.

For that selector only, it tests whether the signed count-like field is greater than zero:

- If positive, it obtains the count-like field for the subtraction and selects that value minus one. F-402eef64af83 is skipped.
- If zero or negative, it invokes normal validation with the unchanged maximum selector.

Every other selector goes directly to normal validation.

Normal validation calls F-402eef64af83 with the object reference and current selector:

- Any nonzero result permits continuation without changing the selected index.

Only zero versus nonzero matters. Neither the sign nor magnitude of a nonzero validation result has further visible significance.

### Negative-one selection
