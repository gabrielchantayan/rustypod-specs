### Width and address conventions

The following notation describes the represented fixed-width behavior:

- `W(x)` is the low 32 bits of a value.
- `B(x)` is the low 8 bits.
- Left shifts and address arithmetic are described using 32-bit truncation.
- Right shifts of unsigned words are logical.
- A 64-bit dependency result is split into its low and high 32-bit halves.
- A byte selector is zero-extended before use as an address component.

These conventions capture the apparent machine-width operations. They do not assert portable language semantics for signed overflow or signed left shifts.

Two recurring memory operations are important:

1. **Selected-byte write:** read one byte at address `base + 1`, then write one byte at address `selector + 17`.
2. **Word write:** write four bytes at the computed address stated for that operation.

A selected-byte destination therefore lies between addresses 17 and 272 inclusive. It is not represented as an offset from the original base.

The byte order of word accesses, required alignment, and address-space interpretation are not established.

These examples are conditional static expectations, not executed tests.

1. **Initialization selector.** If the initial selector byte is 5 when read and the payload is 171, initialization writes byte 171 at address 22. It does not write at the initial state base plus 22.

2. **Byte truncation.** If the packed word is `0x3ff00000`, the early-cycle selected-byte write stores 255. The extracted ten-bit value is truncated to eight bits.

3. **Scaled word destination.** If the cycle-start word is 2 and the relevant dependency result is 3, the early propagation write stores 12 at address 32788, assuming preceding operations complete.

4. **Lookup range.** If the lookup-driving word is `0x3ff00000`, the computed word read begins at address 1043. No alignment correction or bounds check is represented.

5. **Captured selector.** If the captured selector is 7 and an intervening dependency changes its source byte to 9, the later captured-selector word write still begins at address 27, not 29.

6. **Narrowed shift operand.** If the lookup word is `0x00c00000`, its derived dependency argument is `0x30000000`. Bits outside the surviving four-bit field do not contribute.

7. **Global sampling.** If the sampled global word is `0x3fc00000`, the later byte write stores 255. A dependency changing the global after the sample does not change that already captured value.

8. **No normal completion.** If every call returns and every access succeeds, the represented function begins another cycle rather than returning a status.
