# F-f3a2a208c61a

## Purpose

F-f3a2a208c61a repeatedly performs an ordered sequence of indirect dependency calls, memory reads and writes, a software breakpoint, and changes to implicit execution state.

The established behavior is this sequence and its data dependencies. No application-level purpose, object model, device protocol, or intended safety property is established.

There is no represented normal return or conditional loop exit. Progress requires dependencies to return, memory operations to succeed, and execution to resume after the breakpoint. None of those conditions is guaranteed.

## Behavior

### Dependency notation

F-unknown-01 through F-unknown-32 are opaque dependency IDs local to this contract. Repeated IDs denote matching target expressions in the supplied representation, not independently established callable identities or contracts.

F-unknown-01 is exceptional: its target initially depends on incoming link-derived state and later on the represented assignment to that state.

### 1. Opening calls and first global capture

Each iteration begins in this order:

1. Initialize a first byte-valued working quantity to zero.
2. Call **F-unknown-01** with two explicit zero arguments.
3. Initialize a second byte-valued working quantity to zero.
4. Call **F-unknown-02**, then **F-unknown-03**, without explicit arguments.
5. Read the first global word, retaining it as **A**.
6. Call **F-unknown-04**.
7. Call **F-unknown-05**, retaining its 64-bit result as **L₁** and **H₁**.
8. Call **F-unknown-05** again with **L₁** as the first word argument and **H₁ + L₁ + 0** as the second. The zero addend comes from the second byte-valued quantity.
9. Write an 8-bit secondary register output from that second call at **A + 0x11**.
10. Call **F-unknown-06**.
11. Write the first byte-valued quantity, represented as zero, at **A + 0x15**.
12. Call **F-unknown-07**.
13. Write its 16-bit primary result at an address equal to its secondary register output plus **0x0C**.

The two byte initializations lie on opposite sides of the opening call. Both byte-store destinations use captured **A**; neither explicitly rereads the first global.

The secondary outputs are used as represented. Whether they are intended return channels, retained register contents, or representation artifacts is unresolved.

### 2. First two accesses based on S

The routine next:

1. Calls **F-unknown-08**, retaining its 64-bit result as **L₂** and **H₂**.
2. Writes a zero halfword at **H₂ + 0x2C**.
3. Writes **L₂ logically shifted right by 26 bits** as a word at **S + 0x26C**.
4. Establishes **0x21C48960** for later calculations.
5. Calls **F-unknown-09**.
6. Reads a word at **S + 0x320**, retaining it as address **P**.
7. Calls **F-unknown-10**, then **F-unknown-11**.
8. Writes the low 32 bits of **L₂ shifted left by two bits** at **P + 0x54**.
9. Calls **F-unknown-08** again.
10. Calls **F-unknown-12**, **F-unknown-13**, **F-unknown-14**, and **F-unknown-15**, in that order.

The second F-unknown-08 result is not consumed by the represented caller. It does not replace retained **L₂** or **H₂**.

Both shifts of **L₂** here are unsigned. The write at **S + 0x26C** therefore stores a value from 0 through 63. The write at **P + 0x54** stores a word whose lowest two bits are zero.

These are the first and second of the four explicit accesses based on **S**.

### 3. Third S-relative access and breakpoint

The next operations are:

1. Read an unsigned halfword at **0x21C48994**, retaining it as **Q**.
2. Call **F-unknown-16**.
3. Read a word at **S + 0x280**.
4. Pass that word to **F-unknown-17**, retaining its returned word as **J**.
5. Execute software breakpoint **0x92**.

The word read is the third explicit access based on **S**. The breakpoint precedes every operation described below.

If execution resumes:

- Derive **I** by shifting **J** left by two bits.
- Derive **T** by logically shifting **0x21C48960** right by 18 bits and multiplying by four. This yields **0x21C4**.
- Read a word at **Q + 0x44**, retaining it as **C**.

Because **Q** is zero-extended from 16 bits, **Q + 0x44** ranges from **0x44** through **0x10043**. No address validation intervenes.

### 4. Second global capture and halfword writes

After reading **C**, the routine:

1. Calls **F-unknown-18**.
2. Calls **F-unknown-19**, retaining its word result as **V**.
3. Reads a word at **Q + 0x04**.
4. Calls **F-unknown-20** with **V** and that loaded word.
5. Reads the second global word, retaining it as **B**.
6. Calls **F-unknown-21**.
7. Writes the low 16 bits of **B** at **I + B**.
8. Calls **F-unknown-15**.
9. Reads a word at **T + 0x54**, equivalently **0x2218**, retaining it as **D**.
10. Calls **F-unknown-22**, retaining its returned word as address **E**.
11. Writes halfword **0x21C4**, the low 16 bits of **T**, at **E + 0x04**.
12. Calls **F-unknown-23**, then **F-unknown-24**.
13. Reads an unsigned halfword at **D + 0x34**, retaining it as **U**.

The write at **I + B** stores a truncated portion of captured **B** itself, not data read through **B**. Changes to the second global after capture do not cause an explicit reread.

### 5. Fourth S-relative access and base reduction

The routine calls **F-unknown-25**, retaining its 64-bit result as **L₃** and **H₃**, then:

1. Writes **L₃** as a word at **S + 0x258**.
2. Reads an unsigned halfword at **H₃ + 0x14**, retaining it as **N**.
3. Derives **X** by shifting **L₃** left by six bits.
4. Derives **Y** by multiplying **H₃** by four.
5. Replaces **S** with **S − 0xF4**.
6. Derives **Z** as **U multiplied by four**.
7. Writes **L₃** as a word at **Z + 0x74**.

The write at **S + 0x258** is the fourth explicit **S**-relative access. It precedes the reduction, as do the earlier write at **S + 0x26C** and reads at **S + 0x320** and **S + 0x280**.

There is no represented restoration of **S** before repetition.

Since **U** is a zero-extended halfword, **Z** ranges from zero through **0x3FFFC** without 32-bit overflow. The calculations of **X** and **Y** retain the signed-arithmetic qualifications stated above.

### 6. Final interleaved effects and repetition

The remainder of the iteration is:

1. Call **F-unknown-26**.
2. Write **N**, zero-extended to a word, at **C + 0x54**.
3. Call **F-unknown-27**.
4. Write the same retained **N** as a word at **C + 0x64**.
5. Call **F-unknown-17**, this time without explicit arguments.
6. Write the low 16 bits of **C** at **X** plus a secondary register output from that call.
7. Call **F-unknown-22**, without consuming its primary result.
8. Call **F-unknown-28**.
9. Read one byte at **U + Z**, equivalently **5 × U**, retaining it.
10. Call **F-unknown-29**.
11. Write that retained byte at **N + R + 0x19**.
12. Call **F-unknown-30**.
13. Write **Y** as a word at **C + 0x44**.
14. Call **F-unknown-31**.
15. Assign a fixed value to the link-derived state used for the next opening target.
16. Read a word at **Y + 0x44**.
17. Call **F-unknown-32** with that word.
18. Repeat unconditionally if the call returns.

There is no reload of **N** between its two word writes. The byte-read address ranges from zero through **0x4FFFB** and is not an access through **D** or **C**.

The write at **C + 0x44** and later read at **Y + 0x44** use different retained bases. Their addresses coincide only when the values and applicable arithmetic make them coincide.

## Acceptance examples

These are conditional static consequences, not executed tests. Each assumes the relevant operations are reached and their accesses and arithmetic are permitted.

1. **Initialization boundary.** The first byte quantity is initialized before F-unknown-01; the second is initialized after it returns. Placing both initializations before that call changes the represented order.

2. **Four pre-reduction base accesses.** If **S** retains value **S₀** through these accesses, their addresses are, in order, **S₀ + 0x26C**, **S₀ + 0x320**, **S₀ + 0x280**, and **S₀ + 0x258**. Their operation kinds are write, read, read, write. All precede the represented change to **S₀ − 0xF4**.

3. **Unsigned shifts.** If **L₂ = 0xFC000001**, the word write at **S + 0x26C** stores **63**, and the later write at **P + 0x54** stores **0xF0000004**.

4. **Captured first global.** If **A** was captured as **A₀**, later changes to its global location do not redirect the two represented byte writes from **A₀ + 0x11** and **A₀ + 0x15**.

5. **Zero extension.** If **Q = 0xFFFF**, its two subsequent word-read addresses are **0x10043** and **0x10003**, not addresses based on a sign-extended negative value.

6. **Breakpoint stop.** If breakpoint **0x92** permanently stops execution, preceding effects may have occurred, but no subsequent operation is required through this control flow.

7. **Captured-word truncation.** If **B = 0x12345678**, the halfword write at **I + B** stores **0x5678**, not the full word or a value loaded through **B**.

8. **Constant halfword.** If the first F-unknown-22 call returns **E₀**, the halfword at **E₀ + 4** receives **0x21C4**. Individual byte placement remains endianness-dependent.

9. **Retained halfword.** If **N = 0xABCD**, both word writes at **C + 0x54** and **C + 0x64** store **0x0000ABCD**, even if an intervening dependency modifies the original halfword location.

10. **Numeric byte address.** If **U = 3**, then **Z = 12**, the word write based on **Z** uses address **0x80**, and the later byte read uses address **15**.

11. **Operation count despite aliasing.** Reaching repetition entails 15 explicit writes, including seven word writes, even if multiple destinations alias.
