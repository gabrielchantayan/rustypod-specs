# F-164254d7acb6

## Purpose

F-164254d7acb6 conditionally invokes an operation on a supplied object, with entry and exit dependency calls surrounding its normal branch processing.

The established protocol is:

- Call an entry dependency with an interior context address.
- Read a context byte and select a branch according to whether it is zero.
- On the zero-byte branch, optionally consult F-8e09c1ebc410.
- When dispatch is enabled, invoke an indirect operation using the **original object argument**.
- Call an exit dependency and return a 32-bit value of zero or one.

When F-8e09c1ebc410 is called, its result’s nullness determines **both** whether indirect dispatch occurs and which normal result is returned: null selects one without dispatch; non-null selects zero with dispatch.

Neither result has an established success or failure meaning. In particular, zero can be returned without any indirect operation.

The paired entry and exit calls suggest synchronization or another lifecycle protocol. That interpretation is inferred intent, not an established dependency contract.

## Interface

### Inputs

The function accepts two arguments:

| Input | Established use |
|---|---|
| Context | An address-bearing value used to form addresses at byte offsets `0x114` and `0x16c`. The original value is also passed to F-8e09c1ebc410 when that dependency is selected. |
| Object | A nullable pointer. When non-null, it may be passed to F-8e09c1ebc410 and may supply the receiver and dispatch table for an indirect operation. |

The supplied representation uses 32-bit address and integer slots. The relevant object layout is therefore:

| Location | Width and interpretation |
|---|---|
| Object byte offset zero | A 32-bit dispatch-table address |
| Dispatch-table byte offset four | A 32-bit callable address |

The context decision field is one byte at offset `0x16c`. Its signedness does not affect the decision: zero and nonzero are the only distinguished cases.

The offsets are byte displacements. They do not establish the complete size, alignment, or semantic type of either input.

### Output

On normal completion, the result is a 32-bit value with this exact classification:

| Context byte observed after entry | Additional condition | Result |
|---|---|---|
| Zero | Object is null | `1` |
| Zero | Object is non-null and F-8e09c1ebc410 returns null | `1` |
| Zero | Object is non-null and F-8e09c1ebc410 returns non-null | `0` |
| Nonzero | Object is null or non-null | `0` |

The entry, exit, and indirect dependencies do not supply the returned value. Their return values, if any, are not consumed by this function.

F-8e09c1ebc410 supplies a pointer-shaped result. This function examines only its nullness. On the branch where it is called, that decision controls both dispatch and the selected zero-or-one result.

### Preconditions for normal execution

The function performs no explicit validation of these requirements:

- The entry and exit dependencies must accept the context address displaced by `0x114`.
- The byte at context offset `0x16c` must be readable after entry returns.
- If dispatch occurs, the original object must support a 32-bit read at offset zero.
- The resulting table must support a 32-bit callable-address read at byte offset four.
- The selected callable must be invocable with the original object as its explicit argument.

A null object is handled explicitly. A null context is not given comparable handling.

Address calculations have no visible bounds or overflow checks. The supplied representation does not establish portable behavior for arithmetic outside usable address ranges; such behavior remains documented_only.

## Behavior

### Entry and decision read

The first established external action is a call to F-unmapped-01 with the context address displaced by `0x114`.

Only after that dependency returns does the function read the byte at context offset `0x16c`. Consequently, changes made by the entry dependency can affect the branch decision.

There is one explicit read of this decision byte. The function does not reread it after delegated processing or indirect dispatch. Every nonzero byte value, including a value with its high bit set, selects the same branch.

Forming the interior address passed to the entry dependency is not itself evidence of a direct memory read or write at that location.

### Zero-byte branch

If the observed byte is zero, the selected result begins as one.

If the object is null:

- F-8e09c1ebc410 is not called.
- No object or dispatch-table read occurs.
- No indirect operation occurs.
- Processing proceeds to the exit dependency with result one selected.

If the object is non-null, F-8e09c1ebc410 is called with the original context and original object, in that order.

Its result then determines both dispatch and the normal result:

- **Null result:** suppress indirect dispatch and retain result one.
- **Non-null result:** select result zero and perform indirect dispatch using the original object.

The returned pointer is not dereferenced, used as a dispatch receiver, or explicitly released by this function. It need not equal the original object to enable dispatch. Its relationship to the object, beyond the nullness decision, is not established.

A change to the context decision byte during this dependency call does not select a different branch: the decision byte has already been read.

### Nonzero-byte branch

If the observed byte is nonzero:

- F-8e09c1ebc410 is not called.
- Result zero is selected.
- A null object suppresses indirect dispatch.
- A non-null object enables indirect dispatch.

Thus, a nonzero decision byte and a null object produce normal result zero after the exit dependency, without either the delegated call or the indirect operation.

### Indirect dispatch

Whenever dispatch is enabled, the function obtains the callable through the original object:

1. Read the 32-bit dispatch-table address at object offset zero.
2. Read the callable address at byte offset four within that table.
3. Invoke that callable with the original object as its explicit argument.

The table address must be obtained before its callable slot can be read, and both reads precede invocation.

On the zero-byte branch, these reads occur after F-8e09c1ebc410 returns non-null. No earlier table snapshot is visible. If that dependency changes the original object’s table address or the selected table entry, those changes can affect dispatch.

The delegated result never replaces the original object for these reads or for the call argument.

The function does not explicitly check the table address or callable address for nullness or validity. Its branch logic establishes that the original object is non-null whenever dispatch is reached; it does not establish that the object is live or structurally valid.

Result zero is selected before the indirect call. A normally returned value from that call does not replace or otherwise influence the selected result.

### Exit and completion

After normal branch processing, F-unmapped-02 is called with the context address displaced by `0x114`. This occurs on every normal path, including paths that skip both the delegated call and indirect dispatch.

Where dispatch occurs, the exit call follows it. The selected result is returned only after the exit dependency returns normally.

This ordering is not an exception-safety guarantee. No visible cleanup mechanism ensures that the exit dependency runs after an earlier dependency fails to return, performs a nonlocal transfer, or encounters an invalid access.

## Side effects

### Direct effects

The function explicitly performs:

- One context-byte read.
- Conditional reads of the original object’s table address and the selected callable address.
- Dependency calls in the order described above.

No direct write to the context, object, or dispatch table is visible. No direct allocation or deallocation is visible.

These observations do not establish that the overall invocation is read-only or allocation-free. Called dependencies may have effects not shown in this function.

## Acceptance examples

These examples are conditional acceptance criteria derived from static evidence, not executed tests. Normal results assume that all required accesses are valid and every invoked dependency returns normally.

| Observed byte | Object | F-8e09c1ebc410 result | Required normal sequence | Result |
|---|---|---|---|---|
| Zero | Null | Not requested | Entry; byte read; exit | `1` |
| Zero | Non-null | Null | Entry; byte read; delegated call; exit | `1` |
| Zero | Non-null | Non-null | Entry; byte read; delegated call; dispatch through original object; exit | `0` |
| Nonzero | Null | Not requested | Entry; byte read; exit | `0` |
| Nonzero | Non-null | Not requested | Entry; byte read; dispatch through original object; exit | `0` |

Additional distinguishing cases:

- **Entry changes the decision byte:** If it was initially zero but entry makes it nonzero before returning, the nonzero-byte branch applies. The initial value does not determine behavior.
- **Delegated nullness changes:** With a zero observed byte and a valid non-null object, a null delegated result requires result one without dispatch; a non-null delegated result requires result zero with dispatch. Both consequences must change together.
- **Delegated pointer differs from the object:** A different non-null returned address still enables dispatch through the original object. No dispatch read through the returned address is required.
- **Delegated call changes the table:** If it installs a different valid table in the original object and returns non-null, dispatch uses the subsequently read table, not a pre-call snapshot.
- **Delegated call changes the decision byte:** The byte is not reread. The delegated result still controls dispatch and the selected result on this already-entered branch.
- **High-bit nonzero byte:** It behaves like every other nonzero byte; it does not introduce a separate signed-value case.
- **Indirect operation returns an arbitrary value:** The function still returns zero after a normally completing exit call.
- **An earlier dependency does not return:** No subsequent exit call or normal result is promised.
- **Exit does not return:** Earlier branch actions may already have occurred, but no normal function result is produced.
