# F-4880cbc6b8c4

## Purpose

The routine performs an initial sequence of memory writes, then repeatedly executes indirect calls, memory accesses, and a software breakpoint. The supplied static representation contains an unconditional back edge and no normal return.

No application-level purpose is established. The accesses may represent ongoing state manipulation, but identifying a protocol, device, object model, or intended algorithm would exceed the evidence.

This contract distinguishes:

- **Established static evidence:** represented access widths, ordering, values, target calculations, and control flow.
- **Inferred interpretation:** a 32-bit machine-level execution model for address arithmetic and register-associated state.
- **documented_only:** matters not established by the representation, including memory validity, dependency behavior, ABI details, and some arithmetic semantics.

Completion of any described phase is conditional on preceding calls returning, accesses succeeding, and traps permitting continuation.

These are conditional obligations derived from static evidence, not executed tests.

   Suppose the captured initialization read yields `0x1000`, the destination-side read yields `0x2000`, and the value-side read yields `0x3000`. The subsequent pair remains relative to `0x1000`, and its second value is `0x1000`. This example imposes no order between the destination-side and value-side reads.

2. **Both overwritten values matter.**  
   If individual writes are observable, initialization exposes both writes at each repeated destination. The first pair stores the scaled second argument and then the dependency address. The later pair stores the dependency address multiplied by 512 and then the captured initialization base.

3. **Zero does not bypass initialization.**  
   If the second argument is zero and accesses are valid, the first destination is the dependency address itself. It receives zero and then the dependency address.

4. **Logical extraction has a six-bit range.**  
   If F-I09 supplies low word `0xFC000000`, the state-field write at offset 620 carries 63. Low word `0x03FFFFFF` produces zero.

5. **Unsigned halfwords are not negative addresses.**  
   If the fixed-address halfword read yields `0xFFFF`, the subsequent offsets use 65,535, not negative one.

6. **Stopping at the breakpoint prevents later effects.**  
   If execution stops at breakpoint `0x92`, no post-breakpoint call, access, or state-base decrement occurs.

7. **Equal target does not mean interchangeable calls.**  
   F-I05 and F-I06 have the same calculated target, but F-I06 still occurs later and receives the explicitly described arguments. Their effects cannot be collapsed into one invocation.

8. **Late stores reuse captured data.**

9. **The final call leads to another cycle.**
