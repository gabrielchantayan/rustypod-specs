### 3. Write the seed’s low byte at Base

Under the 32-bit modular model, Base depends exactly on Seed’s low 22 bits. Consequently, two seeds produce the same Base if and only if their low 22 bits are equal. Such seeds necessarily have equal low eight bits and therefore produce the same payload for this write.

Different seeds can collide at Base, but those collisions do **not** produce different seed-addressed byte values.

Base is a multiple of 1,024 in the modular model. This arithmetic property does not establish that Base is accessible or identifies a valid object.

### 4. Follow two reads and write a derived byte

The location of the first read is obtained by retaining Seed’s low 22 bits, logically shifting that value right by two, and adding 104.

The first read’s 32-bit result is treated as an address basis. The second four-byte read occurs at that result plus 96.

The second read’s 32-bit result is logically shifted right by two. Adding 4 to the shifted value gives the byte-write destination.

The payload is Derived’s low eight bits. Because Base is a multiple of 1,024, this payload is always 158 under the stated arithmetic model.

The shifts operate on integer values. No additional element-size multiplication is represented. In particular, the final destination is the shifted second read value plus 4, not the unshifted value plus 4.
