# F-401062e9ec7c

## Purpose

F-401062e9ec7c performs an ordered initialization sequence using two dependency results as addresses. It obtains a base address, copies a global four-byte value to that address, invokes a second dependency with an address displaced from the base, and clears five regions relative to the second result.

The established behavior is limited to the visible calls, address calculations, read, and writes. Neither result is established to identify a newly allocated object. The two results may refer to overlapping storage.

**Inferred intent:** the sequence resembles initialization of an object and an associated structure. This interpretation does not establish object types, containment, allocation, ownership, or lifecycle requirements.

This contract distinguishes the initial base-address write from the five subsequent zero writes. In particular, byte ranges excluded from the zero writes are not necessarily untouched by the function as a whole: the initial write may overlap them.

### Boundaries of the five zero writes

- Bytes 12–15.
- Byte 16.
- Bytes 20–23.
- Bytes 24–27.
- Bytes 28–31.

This exclusion is not a whole-function preservation guarantee. The earlier four-byte base-address write can overlap any of these otherwise excluded ranges when the addresses have a suitable relationship. Either dependency may also modify them.

In the absence of intervening modifications, bytes 17–19 retain the corresponding bytes of the copied global value, not necessarily their function-entry values.

The final four-byte zero write reaches byte 31 relative to the field address. The evidence establishes the accessed ranges, not the beginning, end, or total size of any allocation.
