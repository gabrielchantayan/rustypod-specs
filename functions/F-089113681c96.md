# F-089113681c96

## Purpose

F-089113681c96 performs an ordered sequence of indirect calls, computed-address memory transfers, and **two explicit writes to global B**. Global A is read twice; the representation does not show an explicit write to global A. Computed-address stores may alias global storage, but that possibility does not establish another global destination.

The visible operations include indexed word stores, byte-selected writes, word-to-byte copies, and a terminal halfword clear followed by a call to address zero. Their application-level purpose is unknown.

This contract describes established static behavior in the supplied representation. Each operation is conditional on execution reaching it, earlier dependencies returning, and preceding memory accesses completing. No runtime tests have been performed.

## Behavior

### Entry and initial word transfers

F-D001 is called at the incoming link-register value plus 3896 and receives the second explicit argument.

A producer/forwarder pair follows: one dependency returns a word, and another receives it. Three further calls precede a fourth call returning a destination index.

The incoming payload is stored in that index’s ordinary word slot. Only afterward is a word read at the incoming unsigned selector logically shifted right by 22, plus 20. This read supplies the **initial loaded word**.

A dependency receives four times the destination index. Three calls then precede another index-producing call.

The initial loaded word shifted right by one selects the next ordinary word slot. The newly returned index shifted left by two is stored there. A second word is then read at the initial loaded word plus 20. This source address uses the unreduced initial loaded word, not the value shifted right by one.

### Replication and first global A snapshot

A dependency receives the initial loaded word shifted right by one. A producer/forwarder pair follows, then three calls and an index-producing call.

The previously stored shifted-index value is copied into this new index’s ordinary word slot. Global A is then read and retained as the **first global snapshot**.

A dependency receives four times the new index. Four further calls follow. An additional-register result associated with the last supplies another destination index.

The second loaded word is logically shifted right by 22, forming the **reduced second word**. That value is stored in the additional-register index’s ordinary word slot.

The next dependency receives, in order:

1. The additional-register index.
2. The same index again.
3. The first global snapshot logically shifted right by 23.
4. The reduced second word.

### Repeated reduced-word store and zero stores

A word-producing call follows. Before its result is forwarded, the already reduced first global snapshot is logically shifted right by another 23 bits.

For any unsigned 32-bit input, two successive logical right shifts by 23 yield zero. The first leaves at most nine significant bits. The resulting zero does not depend on global A’s contents.

After the forwarding call, three calls precede an index-producing call. The reduced second word is stored in that index’s ordinary word slot.

A dependency receives four times the index. Four calls follow; an additional-register result associated with the last supplies another index. Its ordinary word slot is cleared to zero, and that index is passed to a dependency.

A producer/forwarder pair and four further calls supply another destination index. Zero, derived from the twice-reduced global snapshot, is stored in its ordinary word slot.

A word is then read at the earlier additional-register index masked with `0x1fffffff`, logically shifted right by 19, plus 20. A dependency receives four times the latest destination index, and four calls follow.

### Initial byte-selected writes

The newly loaded word is logically shifted right by 22, producing the **reduced masked-load word**.

The function reads the unsigned byte at absolute address 1 and writes the low byte of the reduced masked-load word at the byte-read value plus 17. The selector for this read is the zero derived from the first global snapshot.

The next dependency receives a separate additional-register word in its first three argument positions and zero in its fourth. One call follows, then another dependency receives zero. Three calls precede an index-producing call.

The function next reads a byte at four times the reduced masked-load word plus 1 and writes zero at the byte-read value plus 17.

A dependency receives the latest index shifted left by two. Three calls precede another index-producing call, whose result shifted left by two is passed twice to a dependency.

A producer/forwarder pair and one further call follow. The byte at absolute address 1 is read again, and zero is written at its value plus 17.

A further additional-register word is retained as the **shift source** and passed three times to the next dependency. This value is distinct from the earlier additional-register results.

### First global B write and retained byte-derived base

A dependency produces a word. The following dependency receives that word and the preceding phase’s producer result logically shifted right by 23. Three calls precede an index-producing call.

The byte at absolute address 1 is freshly read. Its unsigned value is retained as the **byte-derived base**, and zero is stored at that base plus 17.

A dependency receives the latest index shifted left by two. Three calls precede another index-producing call, whose shifted result is passed twice onward.

The next dependency produces the **first B-write value**. This word is explicitly written to global B before being forwarded to another dependency. One additional call follows.

The function then reads a word at the retained byte-derived base plus 116 and writes its low byte at that base plus 1. The base remains the earlier byte snapshot; address 1 is not reread for this copy.

### Repeated word-to-byte copies

A dependency receives the shift source shifted left by 11. The following call supplies a represented 64-bit result. Another dependency receives its low half, its high half, and the first B-write value logically shifted right by 23, in that order.

Three calls precede an index-producing call. Four times its result becomes a base. A word is read at base plus 116, and its low byte is written at base plus 1.

A dependency receives that base. Three calls precede another index-producing call. Its result shifted left by two is retained as the **scaled intermediate**.

The word at the preceding base plus 116 is freshly read, and its low byte is again written at that base plus 1. Calls intervene between these copies, so the earlier source read cannot substitute for the later one.

A dependency then receives:

1. The shift source shifted left by 12.
2. The scaled intermediate.
3. The scaled intermediate again.
4. The latest unscaled index shifted left by 18.

Two producer/forwarder pairs follow, totaling four calls. Four further calls culminate in a new index.

### Full-word retention and linked stores

Four times the new index becomes a base. The word at base plus 116 is retained in full as the **retained full word**, and its low byte is written at base plus 1.

A dependency receives the base. Three calls precede an index-producing call. The retained full word is stored at sixteen times that index plus 20. This is a sixteen-byte-stride destination, not an ordinary word slot.

The next dependency receives the scaled intermediate logically shifted right by two and then shifted left by 16. These transformations must remain distinct: the right shift does not recover bits discarded when the scaled intermediate was formed.

Two producer/forwarder pairs follow, then four calls culminating in an index. The retained full word is stored in that index’s ordinary word slot.

A dependency receives four times that index. Three calls precede another index-producing call. Its result shifted left by two is stored at the scaled intermediate masked with `0xfffffffc`, plus 20. The shifted result is then passed twice to a dependency.

After that duplicated-argument call, two consecutive producer/forwarder pairs occur. Four additional calls culminate in another index-producing call. Only then is the resulting index’s ordinary word slot cleared to zero.

These four producer/forwarder calls cannot be omitted merely because their results do not directly supply the clear value; their effects are unknown.

### Paired result and second global A snapshot

A dependency receives four times the cleared index. Three calls precede a represented 64-bit result.

Its low half shifted left by two is stored in the ordinary word slot selected by its high half. Global A is then read again, yielding the **second global snapshot**.

The next dependency receives the shifted low half in its first, third, and fourth positions, and the high half in its second position.

Three calls precede another index-producing call. The same shifted low half is stored in that index’s ordinary word slot. A word is then read at the second global snapshot plus 20 and retained as the **global-derived word**.

A dependency receives four times the latest index. Three calls precede another represented 64-bit result, the **final paired result**. Its halves remain distinct from those of earlier paired results.

### Final byte-selected updates

The retained full word logically shifted right by 23 supplies a selector. A byte is read at selector plus 1, and the low byte of the global-derived word is written at the byte-read value plus 17.

The next dependency receives the final paired result’s high half three times, followed by its low half shifted left by two.

A producer/forwarder pair and four further calls supply another index. Before that index shifted left by two is passed onward, another byte-selected write occurs:

- Its selector is the final paired result’s low half masked with `0x3fffffff`, then logically shifted right by 21.
- The selector byte is read at selector plus 1.
- The stored byte is the low eight bits of the global-derived word logically shifted right by 22.
- The destination is the selector byte’s unsigned value plus 17.

After the shifted index is passed onward, three calls precede another index-producing call. Its result shifted left by two is passed twice to a dependency.

### Terminal sequence

Exactly one further call occurs between the final duplicated shifted-index call and F-D003, the dependency reached using the distinct target offset of 176.

F-D003 produces a word that is forwarded to another dependency. F-D004 then produces an 8-bit result and is associated with an additional-register byte pointer.

The terminal effects occur in this order:

1. Zero is written through the byte pointer.
2. The three-byte global view is read, and global B receives a 32-bit concatenation with that view supplying bits 31–8 and F-D004’s byte supplying bits 7–0.
3. A zero halfword is stored at the final paired result’s low half masked with `0x3fffffff`, then logically shifted right by 7.
4. F-D005 is called at address zero with three explicit zero arguments.
5. The function returns if F-D005 returns.

The three-byte view is read after the pointer-directed zero store. Aliasing can therefore change the value assembled for the second explicit global B write.

## Acceptance examples

These are conditional static examples, not executed tests. Each assumes that preceding calls return and all required accesses and arithmetic are valid.

- **Initial ordering:** Payload `0x12345678` and initial destination index 3 produce a word store at address 32 before the selector-derived source-word read.

- **Unreduced source address:** Initial loaded word 8 selects destination address 36 after its right shift by one. The following source-word read is at address 28, not 24.

- **Forced zero:** First global snapshot `0xffffffff` becomes `0x000001ff` after one logical right shift by 23 and zero after the second. The same final zero holds for every unsigned 32-bit snapshot.

- **Byte-selected destination:** Selector 2 with byte value 9 at address 3 produces destination address 26. It does not produce destination address 19.

- **Narrow destination write:** A copied source word of `0x89abcdef` contributes byte `0xef`; the destination write is one byte, not four.

- **Fresh repeated read:** If an intervening dependency changes a repeated source word from `0x11223344` to `0xaabbccdd`, the second copy writes `0xdd`, not the earlier `0x44`.

- **Stride distinction:** Index 3 selects address 32 for an ordinary word slot and address 68 for the sixteen-byte-stride store.

- **Required intervening calls:** Both producer/forwarder pairs after the linked-store duplicated-argument call occur before the following four-call group and zero store.

- **Paired-half order:** Low half 5 and high half 7 in the first phase-eight paired result cause value 20 to be stored at address 48. Swapping the halves changes the behavior.

- **Global A reload:** If dependencies change global A between its two reads, the global-derived source word uses the second snapshot plus 20. Neither read constitutes an explicit write to global A.

- **Global B writes:** The first B-write value is stored before its forwarding call. The terminal concatenation supplies the second explicit global B write; dependencies may independently modify that storage between or after these writes.

- **Terminal call count:** One call, not two, intervenes between the final duplicated shifted-index call and F-D003.

- **Terminal aliasing:** If the final byte pointer aliases the three-byte global view, the subsequent global B concatenation uses the view after the zero-byte store.

- **Halfword boundary:** Final low half `0xffffffff` selects halfword-clear address `0x007fffff` after masking and shifting. Completion requires that access to be valid under the actual alignment rules.
