### Width preservation

A byte store supplied 0x123456AB stores 0xAB. Widening an unsigned byte read of 0xAB and publishing it as a word stores numeric value 171.

Under 32-bit bitvector semantics, a left shift by 28 followed by another left shift by 28 yields zero. Unbounded arithmetic shifted by 56 is not equivalent.

### Capture boundary at address 58

If the doubled-base offset-20 word overlaps address 58, its capture must reflect the preceding address-58 byte store. Moving that word read ahead of the byte store can change the saved word, its later restoration, and the third final-transfer argument.

Conversely, the address-169 and computed offset-116 word captures retain their earlier observations.

### Repeated reads of address 103

Suppose the initial address-103 store publishes 0xAB and the read used for address 33 observes 0xAB. If a reached intervening computed store changes address 103 to 0xCD, the next offset-9 publication must use the value read then, potentially 0xCD.

If another intervening store changes that byte to 0xEF before the second later read, the second publication can use 0xEF. Equal values are required only when the actual intervening memory effects leave the observations equal.

### Captured pointer and repeated stores

An observer of the offset-32 constant-write group can encounter 0x20, 0x2F, the widened byte, and 0x20 in that order. Publishing only the final value omits intermediate effects.
