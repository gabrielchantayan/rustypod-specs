### Non-null dispatch

If F-e6c2a72b1331 returns a non-null reference, the visible dispatch sequence is:

1. Read the first 32-bit word of the returned object.
2. Interpret that word as the base address of a dispatch table.
3. Read the callable address stored 344 bytes beyond that table base.
4. Invoke the selected callable with two explicit arguments: the returned object reference first, and the original second input second.
5. Return the selected callable’s 32-bit result if it returns normally.

This is a contract for the visible data dependencies and invocation order, not a guarantee about instruction-level scheduling or bus transactions.

The displacement is a byte offset. It is not an offset into the object itself: the object supplies the table base, and the displacement applies to that base. With four-byte entries, 344 bytes corresponds arithmetically to entry index 86 when counted from zero. The object reference supplied to the selected callable is the reference returned by F-e6c2a72b1331. It is not replaced by the first public input.
