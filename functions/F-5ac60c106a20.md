## Acceptance examples

These are conditional static examples, not executed tests.

1. **Selector bounds.** A selector of 0 selects byte address 17; a selector of 255 selects address 272. The first write stores the incoming byte, not the selector.

2. **Distinct global observations.** Suppose the first global read observes 1024 and the second observes 2. The masked-and-right-shifted call argument is 1. The second-observation scaled value is 8, so the corresponding selector reads use address 9. Deriving that base from the first observation would violate the represented relationship.

3. **No call needed between differing reads.** Different values in those two consecutive global reads are not excluded merely because no dependency runs between them.

4. **Unsigned extraction.** A first retained result of `0xABCDEF12` produces selector-read address `0x000ABCDF` after logical right shift by 12 and addition of 1.

5. **Byte truncation.** Multiplying unsigned `0xFFFFFFFF` by four supplies byte `0xFC` to a byte write.

6. **Conditional zero product.** Under low-32-bit wrapping semantics, the transformed second-observation value multiplied by 1024 is zero. The preceding duplicate word loads still address the transformed value plus 28, not address 28 solely because the product is zero.

7. **Split-result order.** An upper half of 3 makes the first post-split word write store zero at address 32. A later dependency-selected word destination receives 3.

8. **Lower-half mask.** A lower half of `0xFFFFFFFF`, masked to 29 bits and shifted right by 9, produces `0x000FFFFF`.

9. **Fresh selectors and saved words.** A changed selector between reads changes the later byte destination. Conversely, changing the fourth scaled-index stage’s source word after its explicit save does not replace the saved value used for the subsequent right-shifted store.
