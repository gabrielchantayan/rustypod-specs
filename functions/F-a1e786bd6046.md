## Behavior

For valid inputs with stable designated values, the second argument supplies the left value and the third supplies the right value. The result is true precisely when the left value is strictly smaller in the unsigned ordering.

The following consequences are part of the contract:

- Equal values produce false, regardless of whether the pointers are equal.
- A larger left value produces false.
- Zero is smaller than every nonzero representable value.
- The maximum representable value is not smaller than any representable value.
- A set high-order bit does not give an operand a negative interpretation.
- Changing only the first argument does not change the comparison result.

This is a Boolean predicate, not a three-way comparator. A false result does not distinguish equality from a greater left value.

No difference or distance is calculated. There is no arithmetic operation whose overflow, underflow, or modular wraparound determines the answer. In particular, comparison across the unsigned range boundary is ordinary magnitude comparison, not circular ordering.
