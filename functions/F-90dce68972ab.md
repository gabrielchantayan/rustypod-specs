# F-90dce68972ab

## Purpose

F-90dce68972ab has a partially recoverable behavior: it gates an unresolved invocation on whether its second explicit input is zero. On the zero-input path, it derives four arguments from an apparent incoming 32-bit stack value, including one argument obtained by reading a byte from a computed address.

Neither visible path establishes a normal return. The nonzero-input path ends at an invalid-instruction boundary. The zero-input path invokes an unresolved target and, if that invocation returns normally, reaches another invalid-instruction boundary.

This is a contract for the behavior supported by the supplied static representation, not a claim about the intended purpose of the original routine. In particular, the evidence does not establish that either invalid-instruction boundary is a deliberate trap, validation mechanism, or application-level error.

## Behavior

### 1. Branch selection

The visible behavior first distinguishes whether the second explicit input is zero.

For a nonzero input:

- The recovered path ends at an invalid-instruction boundary.
- No computed-address byte read is visible on that path.
- No invocation of the unresolved target is visible on that path.

For a zero input, the recovered path proceeds to use W and prepare the unresolved invocation.

These are statements about recovered control flow. They do not establish which exception, signal, processor state, or externally reported failure an execution would produce at an invalid instruction.

### 2. Derived values

Under the unsigned 32-bit interpretation of W, define:

| Designation | Meaning | Range or invariant |
|---|---|---|
| **Q** | W shifted right by two bits, with zero fill | 0 through 1,073,741,823 |
| **A** | Q plus one, used as a byte-read address | 1 through 1,073,741,824 |
| **L** | W shifted left by 17 bits, retaining only the low 32 result bits | Low 17 bits are zero |
| **R** | W shifted right by four bits, with zero fill | 0 through 268,435,455 |

The right shifts are unsigned, not sign-extending. No shift count reaches or exceeds the modeled 32-bit width.

The addition forming A cannot overflow a 32-bit unsigned value: Q is at most 1,073,741,823, so A is at most 1,073,741,824. This arithmetic bound does not establish that A is a valid or accessible address.

L discards the upper 17 bits of W. Only W’s low 15 bits contribute to L. Its maximum possible value is 4,294,836,224, or hexadecimal FFFE0000.

The representation gives no basis for interpreting A as an index into an array, an offset relative to an object, or an address adjusted by a hidden base.

### 3. Byte read and argument construction

On the zero-input path, the visible computation reads one byte at A. Call the resulting eight-bit value **B**.

The unresolved invocation receives four arguments in this order:

1. B, the byte read at A.
2. L, the 32-bit left-shift result.
3. Q, the 32-bit right-shift-by-two result.
4. R, the 32-bit right-shift-by-four result.

Argument position is established; evaluation order among the argument expressions is not. The byte must be obtained before the invocation can receive the first argument, but the representation does not establish an instruction-by-instruction ordering between that read and the other arithmetic.

The first argument originates from an eight-bit read. Its machine-level passing width, extension behavior, register placement, and stack placement are unknown because the target has no established prototype. In particular, the evidence does not justify claiming that the byte is passed specifically as a signed integer, unsigned integer, or unchanged eight-bit ABI argument.

The representation expresses the derivations through the same W. Whether the machine code loads its stack-associated storage once or multiple times is not established. A snapshot guarantee in the presence of concurrent or asynchronous modification is therefore outside this contract.

### 4. Invocation and subsequent boundary

If the byte read completes and execution reaches the call, the recovered path invokes the unresolved target with the four arguments above.

If that invocation returns normally, the next visible endpoint is an invalid-instruction boundary. There is no visible normal-return path, subsequent data transformation, or result handling between the invocation and that boundary.

If the target does not return normally, subsequent behavior is controlled by that target and the execution environment. This function’s representation does not establish the target’s termination, exception, or nonlocal-control-transfer behavior.

## Acceptance examples

These are conditional static acceptance examples, not executed tests. Each zero-input example assumes the modeled value of W is available, the byte read completes, and execution reaches the invocation.

### Nonzero gate

Given any nonzero second input, the visible path reaches the first invalid-instruction boundary without the computed-address byte read or invocation of F-UNRESOLVED-01.

The same visible branch applies to positive and negative nonzero values under the integer interpretation. No sign-specific behavior is shown.

### Zero implicit value

Given a zero second input and W equal to zero:

- A is 1.
- L, Q, and R are all zero.
- If address 1 supplies byte B, the invocation receives B, 0, 0, 0.

The nonzero address does not imply accessibility. An execution in which address 1 cannot be read may fail before the invocation.

### Low-bit contribution

Given a zero second input and W equal to 3:

- A is 1.
- L is 393,216.
- Q and R are zero.
- If the byte read yields B, the invocation receives B, 393,216, 0, 0.

This distinguishes the left-shift argument from the arguments derived by right shifts.

### Upper-bit truncation

Given a zero second input and W equal to 32,768:

- A is 8,193.
- L is zero because the shifted contribution falls beyond the retained 32 bits.
- Q is 8,192.
- R is 2,048.

If the byte read yields B, those are the four argument values in order: B, 0, 8,192, 2,048.

### Maximum modeled value

Given a zero second input and W equal to 4,294,967,295:

- A is 1,073,741,824.
- L is 4,294,836,224.
- Q is 1,073,741,823.
- R is 268,435,455.

The address addition remains within 32 bits. Whether the address can be read remains a separate environmental condition.

### Returning target

If F-UNRESOLVED-01 returns normally, the recovered path reaches the later invalid-instruction boundary. An expectation of a normal function return is not supported.
