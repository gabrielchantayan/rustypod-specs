# F-03c603ec2c14

## Purpose

F-03c603ec2c14 repeatedly invokes indirect dependencies and performs interleaved byte, halfword, and word memory operations. Its established contract is the ordering and data dependence of those operations, a software breakpoint, and updates to ambient execution state.

The supplied static evidence does not establish a domain-level purpose such as initialization, message processing, or buffer management.

Each iteration that completes the displayed path:

- Obtains primary and auxiliary values from dependencies.
- Writes through independently captured and computed addresses.
- Uses zero-extended halfwords directly as address components.
- Subtracts 244 bytes from an ambient context base.
- Transfers a captured byte between computed addresses.
- Reads a word for a final dependency invocation.
- Returns to the beginning without testing a termination condition.

The initial first-call target uses the incoming link-like value. Subsequent iterations use an internally assigned link-like value. These targets **need not differ**: the incoming value is unconstrained and may already equal the assigned value.

There is no explicit ordinary return, success result, error result, or loop-exit condition. Dependencies, memory faults, and breakpoint handling can nevertheless prevent further execution.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. Each assumes execution reaches the relevant operations, accesses are valid, and required calls return.

1. **Unsigned Q-low shifts.** If Q-low is 0xfc000003, the direct context base + 0x26c store writes word 63. The B + 0x54 store writes word 0xf000000c.

2. **Separate byte writes.** If F-000000000006 exposes auxiliary byte 0xab, the direct A + 0x11 write contains 0xab. After F-000000000007, the direct A + 0x15 write contains zero. This does not require dependencies to preserve either location.

3. **Halfword widened to word.** If the halfword read at R-high + 0x14 is 0xffff, each direct U field store writes word 0x0000ffff, not a halfword and not 0xffffffff.

4. **Low-address arithmetic.** If T is 3, the direct R-low store uses address 0x80, and the later byte read uses address 15. No implicit buffer base is added.

5. **Captured byte.** If the read at 5 × T yields 0x7e and F-000000000034 changes that source location, the subsequent direct byte store still writes the captured 0x7e.

6. **Context update order.** If the context base is 0x1000 at the R-low context store and remains so until the explicit subtraction, the store is at 0x1258 and the subtraction produces 0x0f0c. Later uses observe that value only absent intervening changes to the ambient base.

7. **Breakpoint interruption.** If breakpoint 0x92 permanently stops execution, that iteration performs no downstream indexed halfword store, context subtraction, or final call.

8. **Fresh final argument.** If F-000000000036 changes the word at G + 0x44, F-000000000037 receives the subsequently read value.

9. **Equal-target call sites.** A call-target trace reaching both F-000000000005 and F-000000000006 must show equal targets despite their different displayed interfaces. The same requirement applies to each other listed pair.

10. **Initial and later targets may match.** With incoming entry link 0x08712031, both the initial first call and subsequent first calls target 0x0871302f. Target inequality is not an acceptance requirement.
