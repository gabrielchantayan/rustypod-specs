## Acceptance examples

These are conditional static expectations, not executed tests.

1. **Initial byte truncation.** If the initial character-sized result is interpreted as unsigned 255 and its shift is defined, shifting left by two and narrowing to eight bits stores 252. If that character is interpreted as signed negative, this example does not resolve its shift semantics.

2. **Fourth-input extraction.** A fourth input of 4,294,967,295 yields 1023 after logical right shift by 22. The associated selection-byte read is at address 1024.

3. **Single derived-zero word store.** Every unsigned 32-bit first G-A capture becomes zero after two successive right shifts by 23. Exactly one phase-3 word store uses that twice-shifted capture. The preceding zero-word store uses literal zero independently of G-A. Aliasing destinations does not merge those origins.

4. **Fresh address-one selection.** If an intervening dependency changes address 1 from 3 to 7 before a later reread, that reread selects destination 24 rather than 20.

5. **Repeated field copy.** If a dependency changes the phase-5 retained base-plus-116 word between its two reads, the second base-plus-one store uses the changed word’s low byte.

6. **Captured global addressing.** If the two G-A captures differ, the later offset-20 word read uses the second capture. A subsequent change to G-A does not itself replace that captured base.

7. **Width-limited intermediate.** Under defined low-32-bit left-shift semantics, shifting 1,073,741,825 left by two produces 4. Logically shifting that retained value right by two and then left by 16 produces 65,536. Recovering the original value after the first shift would be incorrect.

8. **Final aliasing and ordering.** If the final pointer-based byte clear changes the three-byte region at address 9, the following G-B composition consumes the changed region. A later overlapping halfword clear does not retroactively change the value already read.

9. **Failure and termination.** A later fault does not trigger any represented rollback of earlier stores. If address zero is not callable, normal return is not established; replacing the final call with an early return changes behavior.
