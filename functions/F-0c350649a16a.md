# F-0c350649a16a

## Purpose

F-0c350649a16a conditionally invokes dependencies and, on its zero-result completion path, writes one four-byte value to a caller-provided destination.

A selector byte determines whether the first dependency is called. A nonzero result from that dependency bypasses the destination-producing body and is returned to the caller. Otherwise, a fresh selector read determines whether the destination receives zero or a four-byte value from the object.

When the second selector read is nonzero, a two-byte field controls an additional dependency call. After that call returns normally, the function writes a one-byte marker before reading the value to copy.

These are established control-flow relationships. Descriptions such as “initialize,” “prepare,” “ready,” or “cached” would assign meanings not established by the supplied representation.

The function accepts two arguments:

1. **Object address:** identifies storage containing the fields listed below.
2. **Destination address:** identifies storage to which the function may write exactly four bytes.

The supplied representation expresses the object address as an integer-typed argument and the destination as a pointer to a four-byte unit. It does not independently establish the machine width of the object address, destination pointer, or integer return value. The explicitly sized memory accesses do establish their respective widths.

### Return and output contract

On ordinary completion, the function returns:

- Zero if the preliminary dependency is skipped or returns zero.
- The nonzero result of F-f2de7328b737 if that dependency returns nonzero.

A zero return entails one direct four-byte destination write, provided all reached accesses and calls complete normally.

A nonzero return entails no direct destination write by this function. It does not guarantee that the destination is unchanged: a dependency may access it through aliases or other unknown means.

## Behavior

### Preliminary decision

The function first reads the byte at `0x43` and compares its unsigned value with two.

- Values zero and one skip F-f2de7328b737 and select a zero result.
- Values two through 255 call F-f2de7328b737 with the object address.

If the dependency returns nonzero, the function returns that result. On this path, it performs no second selector read, no two-byte field read, no marker write, no payload read, and no destination write.

If the dependency returns zero, processing continues. Its result does not substitute for the selector, and the function does not reuse the initial selector value for the next decision.

### Zero-result destination selection

On the zero-result path, the destination value initially corresponds to four-byte zero. The function then reads the selector at `0x43` again.

This is a distinct read in the supplied representation, including when the preliminary dependency was skipped.

If the second selector is zero, the function writes four-byte zero to the destination and returns zero. It does not directly:

- Read the two-byte field at `0x3e`.
- Read either four-byte argument field.
- Call F-4aa9d52845df.
- Write the marker at `0x42`.
- Read the payload at `0x30`.

If the second selector is nonzero, the function reads the two-byte field at `0x3e`.

When that field is nonzero, F-4aa9d52845df and the marker write are skipped. The function reads four bytes at `0x30`, writes that value to the destination, and returns zero.

When that field is zero, the following ordering applies:

1. The values at `0x18` and `0x1c`, each four bytes wide, are obtained for the dependency call.
2. F-4aa9d52845df is called with those values as its first and second arguments and the address of `0x20` as its third argument.
3. After normal return, the function writes the one-byte value one at `0x42`.
4. It reads the four-byte payload at `0x30`.
5. It writes that payload to the destination and returns zero.

The relative order of the two four-byte argument reads is not established. Both supply the same call. Argument-position order does not establish memory-read order.

No return value from F-4aa9d52845df is used to select the continuation or determine this function’s return value. A normal return is followed by the marker write and payload read even if the dependency’s own result would be interpreted elsewhere as an error.

### Changes made by dependencies

The second selector read observes the value present after F-f2de7328b737 returns, if that dependency was called. Thus an initial selector of two does not guarantee a nonzero second selector.

For example, if F-f2de7328b737 changes the selector to zero and returns zero, the function writes zero without reading the two-byte field or payload.

The payload read occurs after F-4aa9d52845df returns and after the marker write. A payload change made by that dependency can therefore affect the copied value.

Once the preparation-call path has been selected, neither the selector nor the two-byte field is checked again. Changes to those fields during F-4aa9d52845df do not cancel the subsequent marker write or payload read.

These observations do not establish that either dependency preserves other fields, globals, ownership, or storage validity.

### Repeated invocations

The byte at `0x42` is not read as a guard by this function.

A subsequent invocation calls F-4aa9d52845df only if that invocation:

- Reaches the zero-result path, either by skipping F-f2de7328b737 or receiving zero from it.
- Reads a nonzero selector on its second selector access.
- Reads zero from the two-byte field at `0x3e`.

A selector that remains nonzero and a two-byte field that remains zero are not sufficient by themselves. If the initial selector is at least two, F-f2de7328b737 may return nonzero and bypass the entire destination-producing body.
