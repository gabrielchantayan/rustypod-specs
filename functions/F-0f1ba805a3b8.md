# F-0f1ba805a3b8

## Purpose

The transfer is ordered: the first unit is read and written before the second unit is read and written. It is not established as a snapshot copy of the original eight-byte source region. When the regions overlap, the first destination write can change the value subsequently read for the second transfer.

The apparent intent is a small, fixed-size copy. No interpretation of the transferred values as signed integers, unsigned integers, floating-point values, addresses, or structured fields is established.
