# F-c4290d3b80f6

## Purpose

F-c4290d3b80f6 derives a 32-bit difference from two fields of an input record and returns a quotient/remainder pair for division by 24. The pair occupies one 64-bit return value: quotient in the low word, remainder in the high word.

For a difference with bit 31 clear, the established arithmetic behavior is unsigned division by 24.

For a difference with bit 31 set, the represented calculation divides its unsigned two’s-complement magnitude by 24, then applies separate sign adjustments to the quotient and remainder. The operation supplying those adjustments has unresolved full-width shift semantics. Consequently, ordinary signed division with truncation toward zero is a conditional interpretation, not an unconditional guarantee.

The function does not validate an address range, count objects, advance a cursor, or modify the input record. Interpreting the input fields as endpoints of a collection is inferred intent only.

### Differences with bit 31 clear

For a difference word \(D\) in the range 0 through 2,147,483,647, the returned components satisfy:

\[
Q=\left\lfloor \frac{D}{24}\right\rfloor,\qquad
R=D-24Q.
\]

The quotient word contains \(Q\), and the remainder word contains \(R\). In particular:

- \(0\le R\le23\).
- \(24Q+R=D\).
- \(0\le Q\le89{,}478{,}485\).

Zero returns an all-zero pair. Exact multiples of 24 return a zero remainder. Nonmultiples are accepted; a nonzero remainder is a result, not a validation failure.

These guarantees apply across the full sign-clear range. Changes in the internal arithmetic path do not change the divisor, packing, or interpretation of either result word.

### Differences with bit 31 set

For a difference word \(D\) in the range 2,147,483,648 through 4,294,967,295, define its unsigned two’s-complement magnitude:

\[
M=2^{32}-D.
\]

The magnitude ranges from 1 through 2,147,483,648. The upper endpoint is representable as an unsigned 32-bit value even though it is not a positive signed 32-bit value.

The represented magnitude calculation produces:

\[
Q_m=\left\lfloor \frac{M}{24}\right\rfloor,\qquad
R_m=M-24Q_m.
\]

Thus \(Q_m\) is at most 89,478,485, and \(R_m\) is between 0 and 23.

The final result permits separate negation of these two magnitudes. In the represented sign-control value, bit 31 selects quotient negation and bit 30 selects remainder negation. Each negation is confined to its own 32-bit word.

The resulting conditional behavior is:

| Quotient negation selected | Remainder negation selected | Quotient word | Remainder word |
|---|---|---|---|
| No | No | \(Q_m\) | \(R_m\) |
| Yes | No | \((-Q_m)\bmod2^{32}\) | \(R_m\) |
| No | Yes | \(Q_m\) | \((-R_m)\bmod2^{32}\) |
| Yes | Yes | \((-Q_m)\bmod2^{32}\) | \((-R_m)\bmod2^{32}\) |

This table describes the downstream effect of each setting. It does not establish that all four settings are reachable.

The sign-control construction involves a right shift by 32 of a signed 32-bit quantity. Its meaning is not established by the supplied representation. The table therefore does not resolve which result is produced for a particular sign-set input, nor does it promise defined execution under language rules that reject that shift.

If the execution environment gives the construction a sign-filled result for sign-set differences, both components are negated. Under that condition, interpreting the difference word as a signed two’s-complement value yields division by 24 truncated toward zero, with a remainder of the dividend’s sign or zero.

Negating a zero component leaves it zero. In particular, an exact multiple of 24 has a zero remainder regardless of the unresolved remainder-sign selection.
