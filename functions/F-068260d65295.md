### 2. Arithmetic and extraction constraints

Word-width bit operations are significant both for arguments and for later memory destinations.

The supplied body includes low-bit retention at several widths, including 24, 22, 21, 20, 19, 18, 17, 16, 14, 13, 12, and 11 bits. Some masks operate on an already shifted value rather than on the original result.

Other established operations include:

Masking before shifting is not interchangeable with masking afterward. Extracting a high portion of a 64-bit result is not an operation on its low word.

Examples involving those expressions assume non-overflowing operands or an independently supplied machine-width interpretation.

The supplied material reports overlapping fixed-location symbols. That report does not identify every alias relationship, but it prevents assuming that named locations are independent.

Consequently:

- Narrow writes may change portions of later word reads.

## Acceptance examples

These examples are conditional static criteria, not executed tests.

### Unsigned offset-5 read

If a reached offset-5 byte read yields 0xfe and its value is widened for an offset-0x34 word write, the written word is 254, not a sign-extended negative value.

The access at offset 5 remains a read. No offset-5 byte write may be introduced as a supposed corresponding field update.

### Cross-linked byte addressing

If an offset-5 unsigned read yields 0x80, its subsequent address-component use contributes 128, not a negative signed-byte value. Address validity remains a precondition.

### Base capture before the fixed write

Suppose the read at 0x087fbbbc yields a valid base, and the subsequent word write of 0x20 at 0x60 changes how a later read of 0x087fbbbc would behave.

The repeated region still uses the value captured before the 0x60 write. Reloading after that write is not equivalent.

The first repeated-region offset-0x54 write must occur after the 0x60 word write, not before it.

### Narrow truncation

If a byte-write source has low 32 bits 0x123456ab, the byte written is 0xab. A word write of the full value is not equivalent.

### Ordered constant writes

If the calculated offset-0x20 sequence is reached, it writes 0x20, then 0x2f, then the widened intervening offset-4 byte read, then 0x20. Keeping only the final write fails an access-trace-sensitive contract.

### Width-sensitive constants

The three 0x3a updates retain their respective 8-, 16-, and 32-bit widths. Three byte writes do not satisfy that requirement.

### Masked extraction

For the unsigned word 0xffffffff, retaining its low 20 bits and shifting right by 10 yields 0x3ff. An unmasked right shift is different.

### Overlapping writes

If the later offset-0x10 word write completes in ordinary writable memory, it replaces the earlier byte at that same starting address as part of its four-byte update. Exact byte values depend on byte order.

### Dependency effects and final transfer

If an indirect callee mutates memory later read by this function, no global-preservation guarantee justifies substituting an earlier snapshot.

If the final transfer is reached, its first represented argument is 0x72. That constant does not establish successful completion or a return status.
