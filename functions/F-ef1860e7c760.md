These are conditional review examples, not executed tests.

1. **Opening truncation.** Under 32-bit bit-vector semantics, input 1 shifted left by 22 produces 0x00400000; input 0x400 produces zero.

2. **Paired separation.** Where a shifted low word and unchanged high word are forwarded, low 0x12345678 and high 0x9ABCDEF0 produce 0x34567800 and 0x9ABCDEF0.

4. **Delayed 0x05 input.** If an earlier computed store changes the underlying named input, its later evaluation consumes the changed input through the represented unsigned conversion. No eight-bit range is required. If authoritative typing establishes a signed input value of −1 and ordinary unsigned conversion, the captured value is 0xFFFFFFFF, not 255.

5. **Publication capture.** If the last adjusted-base offset-0x20 store changes the underlying publication-base storage, the subsequent capture reflects that change according to the actual declaration and memory interpretation. A later change does not replace the capture.

6. **Stable 0x67 storage.** If ordinary storage remains stable and no intervening access changes it, the three evaluations read its stored value. This does not establish byte-sized storage or identity between that value and the original narrowed assignment value.

7. **Changed 0x67 storage.** If intervening computed stores change the underlying global before its second and third evaluations, each evaluation uses the then-current value. Their computed byte destinations retain eight bits after applicable conversion.

8. **Computed-width overlap and failure.** A word store at adjusted-base offset 0x10 overwrites the preceding byte contribution there according to endianness. A fault before that store prevents guaranteeing later effects; earlier effects are not promised to roll back.
