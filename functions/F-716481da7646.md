# F-716481da7646

## Purpose

- The selected object pointer is non-null.
- The low-order eight bits of a 32-bit object field are nonzero.
- F-2a46346d8b6e returns a nonzero result when called with that object.

Once accepted, the function writes an object byte, invokes a dependency using a separately obtained global value, obtains a 32-bit value from another dependency, passes that value to an indirect object operation, passes a local-slot address to another dependency, writes 33 into an object word, and invokes a final dependency with 250.

## Behavior

### Object selection and field gate

The function first obtains the selected object pointer from offset 4 of the initial global base.

If the pointer is null, it returns immediately. It does not read an object field, call a dependency, or perform an explicit object write.

Otherwise, it reads the word at object offset 176 and tests the low-order eight bits for zero. Only those eight bits control this gate:

- Zero skips the transition and returns.
- Any nonzero eight-bit value permits evaluation of the next gate.

Bits 8 through 31 do not affect this decision. Interpreting the narrowed byte as signed or unsigned does not change the zero/nonzero result.

After the field gate passes, the third argument is copied into one local 32-bit slot and the fourth argument into another. These copies occur before F-2a46346d8b6e is called.

### Dependency gate

F-2a46346d8b6e receives the captured object pointer. Its result is tested against zero.

A zero result ends the function without either explicit transition write and without any subsequent call in this body. This does not guarantee unchanged object or global state: F-2a46346d8b6e has already executed, and its side effects are unknown.

Any nonzero result accepts the transition. Acceptance is not restricted to 1 or to positive results.

The object pointer and field gate are not explicitly rechecked after this call. If the dependency changes global selection or object fields, the function still follows the already-selected path using the captured pointer.
