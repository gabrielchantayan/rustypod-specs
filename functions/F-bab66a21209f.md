# F-bab66a21209f

## Purpose

F-bab66a21209f selects the address of one 32-bit integer, reads that integer, and returns both the selected address and the captured value through a caller-supplied two-word output region.

Selection has two modes. A zero selector chooses an element in an indexed sequence. Any nonzero selector chooses an address stored directly in the descriptor. The function does not advance the index, change modes, or explicitly update the descriptor.

This is a static behavioral contract. No runtime tests have been performed.

## Behavior

### Mode selection

The first relevant descriptor access is a 32-bit read at offset `+0x20`.

A value of zero selects indexed mode. Every nonzero 32-bit value selects direct mode; the selector is not restricted to a particular positive value. Under the supplied signed-integer interpretation, negative selector values also select direct mode.

The selector is read once in the visible behavior. Later changes to that field do not trigger another selection.

### Indexed mode

When the selector is zero, the function obtains the base-address word at offset `+0x14` and the index word at offset `+0x18`.

The selected address is the base address displaced by four times the index, measured in bytes. The factor of four corresponds to the width of each selected integer.

There is no visible check that:

- The index is nonnegative.
- The index falls within a sequence length.
- The multiplication is representable.
- The address addition is representable.
- The resulting address is aligned or mapped.

The supplied expression treats the base and index as integer values before converting the resulting address into a pointer. This supports the four-byte displacement rule, but does not establish portable behavior for signed overflow or invalid integer-to-address conversions.

For a negative index whose arithmetic remains valid, the calculated address is below the base. The function contains no explicit rejection of that case.

The direct-address field at offset `+0x1c` is not used in this branch.

The relative order of the base-field and index-field reads is not established by the supplied expression. Both contribute to address selection before the selected integer is read.

### Direct mode

When the selector is nonzero, the selected address is obtained from the pointer field at offset `+0x1c`.

The base-address and index fields are not used in this branch. Their contents do not affect the selected address.

There is no explicit check for a null pointer, alignment, allocation bounds, or accessibility.

### Capture and publication

After either branch selects an address, the function performs these observable actions in order:

1. Reads one 32-bit integer from the selected address.
2. Writes the selected address, converted to an integer representation, to the first output word.
3. Writes the previously captured integer to the second output word.

The selected integer is read before either output write. The second output write uses that captured value; it does not reread the selected address after publishing the address.

Consequently, the two output words describe the address and value selected during this invocation. They do not guarantee that the selected location still contains the captured value when the function returns.

If execution reaches the end normally, there is no additional explicit result, status code, or error indicator.
