## Behavior

| Byte offset from destination | Input bits represented | Numeric byte range |
|---|---|---|
| 0 | 31–24 | 0–255 |
| 1 | 23–16 | 0–255 |
| 2 | 15–8 | 0–255 |

Each output is the eight-bit portion identified in the table. Higher bits remaining after a shift do not become part of the stored byte.

For example, the 32-bit value `0x12345678` produces the consecutive bytes `0x12`, `0x34`, `0x56`, and `0x78`.

This ordering is explicitly constructed from the value. It is not a copy of that value’s native in-memory representation and therefore does not depend on native integer byte order.
