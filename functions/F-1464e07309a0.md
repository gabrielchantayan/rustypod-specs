## Acceptance examples

These examples are conditional static criteria, not executed tests.

1. **Second-input high bit.** For second-input bit patterns `0x00000000` and `0x7FFFFFFF`, F-U03 receives zero. For `0x80000000` and `0xFFFFFFFF`, it receives one. Other behavior may still differ through hidden state.

2. **Retained 64-bit high bit.** If F-U08 produces `0x8000000000000005`, F-U09 receives low-word pattern `0x00000005`, and F-U11 later receives one.

3. **Bit 22 extraction.** If F-U18 produces `0x00400000`, F-U21 receives one. If it produces `0x00800000`, F-U21 receives zero.

4. **Unsigned subtraction before shifting.** If the second hidden register contains `0x00000032`, subtracting `0x33` wraps to `0xFFFFFFFF`; the source-read base is `0xFF`. The four read addresses are consequently `0xFF`, `0x103`, `0x107`, and `0x10F`, provided those reads are supported.

5. **High-nibble argument.** If F-U29 produces `0xA1234567`, F-2cc1255261f3 receives ten.

6. **Read-before-write ordering.** If the source region overlaps `0xC3` through `0xD2`, the four represented source reads still precede the fixed-address stores. Those stores cannot retroactively change the already read word values.

7. **Selector eight.** A saved selector of eight reaches F-U37. The byte write stores eight, and the later halfword destination is `0x30`.

8. **Selector nine.** A saved selector of nine still permits the word write at saved base plus `0x68`, then reaches the first invalid-instruction boundary. F-U37, the byte write, and F-U38 are not reached.

9. **Maximum unsigned selector.** A selector of `0xFFFFFFFF` takes the same greater-than-eight branch. It does not produce a wrapped halfword destination through the accepted path.

10. **Mutation during F-U37.** If F-U37 changes the global selector cell, the subsequent byte and halfword destinations still use the selector saved before that call, according to the represented data flow.
