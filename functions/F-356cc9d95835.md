# F-356cc9d95835

## Purpose

F-356cc9d95835 conditionally assigns a proposed integer value to a caller-supplied integer slot. An already matching value causes an immediate return. A differing value may be assigned directly only when a subsequent read of the slot yields zero. A differing value followed by a nonzero second read instead causes two dependency calls, with the second call identified in the supplied static material as nonreturning.

The apparent intent is to permit initialization from zero and repeated requests for an existing value while rejecting replacement of a nonzero value. This is **inferred intent**, not an additional rule: the observable decision uses two separate source-level reads, whose results need not agree if some external agent changes the slot.

## Behavior

### Matching value

The first observable source-level memory action is a read of the integer slot. That value is compared with the proposed value.

If they compare equal, the function returns immediately:

- There is no second explicit slot read.
- There is no explicit slot write.
- Neither listed dependency is called.

This applies to zero as well as nonzero values. A request that matches an existing nonzero value is therefore distinct from a request to replace it.

### Differing value followed by zero

If the first read differs from the proposed value, the function evaluates a second read of the same slot. It compares this second value with zero.

When that second read yields zero, the proposed value is written to the slot and the function returns normally. Neither dependency is called on this path.

The write is controlled by the second read, not by a retained copy of the first read. No further validation or explicit slot read is shown between the zero decision and the assignment.

For a stable slot, this path initializes zero to a nonzero proposed value. A stable zero slot with a zero proposal instead takes the earlier matching-value return and performs no write.

### Differing value followed by nonzero

1. Calls F-7a087e4b9f5b with no explicit arguments.

The second dependency is identified by the supplied static annotation as nonreturning. Under that model, this path does not reach the assignment or a normal return from F-356cc9d95835.

There is no explicit slot write before either call. This does **not** guarantee that the slot remains unchanged: either dependency may have effects not established here. In particular, no preservation of globals, shared storage, or allocation state may be assumed.
