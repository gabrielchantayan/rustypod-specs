## Behavior

The distinction between the two reads matters. Under ordinary stable-memory conditions, both reads yield the same value, so the result equals the nonzero value that selected this path. The supplied representation nevertheless contains two field reads rather than one read whose value is reused.

If the field can change between reads, the second value controls the return. In particular, a first value of `5` followed by a second value of `0` results in a return of `0`, with no dependency call, provided such changing-memory behavior is meaningful in the execution environment. This observation does not establish atomicity, synchronization, or defined behavior for unsynchronized concurrent access.

If the first read is zero, the function calls F-789428e94bf4 exactly once with no explicit arguments. It then selects its return value solely from that call’s integer result.

There is no further direct read of the object field on the zero-field path. A change to the field during the dependency call therefore does not replace the mapped return value.
