## Behavior

### Established operation order

For an execution in which address formation, memory access, and signed addition are valid, the function has the following ordered behavior:

1. It reads the four-byte signed state at base address plus 140.
2. It adds 1 to the value read.
3. It writes that incremented value back to the same four-byte field.
4. It compares the incremented value with the signed value 3.
5. If the incremented value is greater than 3, it writes four-byte zero to the field.
6. It invokes F-5fef27ef670e with no explicit arguments.
7. If that invocation returns normally, it returns four-byte 1.

The incremented value is written **before** the conditional reset. When the reset condition holds, there are two ordered writes to the same field: the incremented value, then zero.

The comparison uses the value already computed for the increment. No second read of the field is shown between the first write and the comparison. Consequently, a change to the field by some external agent during that interval is not shown as affecting the reset decision.

This is an ordering contract for the supplied behavior. It does not establish atomicity, cross-thread visibility, memory barriers, or guarantees about which intermediate value another observer can detect.
