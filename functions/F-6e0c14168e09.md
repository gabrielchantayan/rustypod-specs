# F-6e0c14168e09

## Purpose

The established behavior is a straight-line sequence of dependency calls and coprocessor operations, followed by a computed-address 16-bit memory write and an invalid-instruction boundary. No normal return is represented.

An application-level purpose is not established. Descriptions such as initialization, decoding, device configuration, allocation, or cleanup would require evidence beyond the supplied representation.

This contract distinguishes:

- **Established static evidence:** displayed calls, operand routing, operation order, result widths, and the final store.
- **Conditional arithmetic conclusions:** consequences of interpreting ordinary-word operations as 32-bit, truncating machine arithmetic, with arithmetic right shift for signed operands.
- **Documented-only unknowns:** dependency behavior, hardware interpretation, executable validity, and behavior beyond the invalid-instruction boundary.

No runtime tests have been performed.

- Its high word consists of bits 32–63.

These are numeric bit selections, not evidence of a memory structure or byte ordering.

Unless explicitly described otherwise, left-shift conclusions retain only the low 32 bits. Right shifts of unsigned values insert zeros. The signed right shift used in the **F-U31** argument is treated as arithmetic under the conditional model.

### Final memory write and endpoint

After **F-U68**, the retained 23-bit value is shifted right by 11. Call the resulting unsigned quantity \(q\). It consists of bits 52–63 of the **F-U64** result and lies between 0 and 4095.

The final address is:

\[
a=q+\left\lfloor q/4\right\rfloor.
\]

The function uses this sum directly as an address and stores the 16-bit pattern **0x00CD** there. No buffer base is added. The address ranges from **0 through 5118**, without arithmetic overflow under the stated model.

No null, mapping, bounds, or alignment check is displayed. Odd addresses are possible. Successful execution therefore depends on the environment permitting the particular halfword access.

After the store, the representation reaches an invalid-instruction boundary and truncates control flow. This is not a successful-return guarantee.

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Initial truncation:** With first input **0x10000000**, the first argument of **F-U01** is zero under 32-bit truncation. Its second argument still equals the second input.

2. **Fourth-input selection:** Fourth input **1** produces **0x00020000** at **F-U01** and **0x80000000** at **F-U07**. Fourth input **2** produces zero for the latter argument.

3. **Signed reconstruction differs:** If **F-U23** returns **0x04000000**, its retained left-by-5 pattern is **0x80000000**. The signed right-by-5 argument to **F-U31** is **0xFC000000**, not the original result.

4. **State-routing distinction:** If S6 and S15 carry distinguishable incoming patterns, CP-03 routes S6 then S15, while CP-04 routes S15 twice. Equal payloads and selectors do not make those operand tuples interchangeable.

5. **Shared selectors, different state:** CP-07 uses selector triple **(0, 6, 7)** with S9 and S15. Substituting the S3 routing used by CP-01 and CP-02 would disagree with the static representation.

6. **Forced-zero payload remains an operation:** For every possible **F-U36** result, CP-06 has zero payload under the arithmetic model, but retains selectors **(0, 5, 7)** and state operands S5, S15.

7. **Minimum final address:** If retained bits 41–63 of the **F-U64** result are zero, the final store targets address zero. Writability is not established.

8. **Odd final address:** If the retained 23-bit value is **2048**, then \(q=1\) and the store targets address **1**. Alignment-dependent success remains unknown.

9. **Maximum final address:** If the retained value is **0x7FFFFF**, then \(q=4095\), the address is **5118**, and the stored halfword is **0x00CD**.

10. **Interrupted execution:** If **F-U49** does not return, CP-07, later calls, and the final write need not occur. Prior effects are not shown to be undone.
