## Acceptance examples

These are conditional acceptance criteria, not executed tests.

### Bounded values and absolute `0x15`

Under 32-bit arithmetic, a supplying result whose low seven bits are 3 produces bounded quantity 12 and doubled bounded base 24.

If instead the doubled bounded base is zero and the fourfold retained base’s low byte is `0x40`, the later consecutive calculated stores write `0x40` twice to absolute `0x15`. The following absolute store writes `0x00` there, before the next fourfold-retained-base offset-`0x54` word store. Retaining only the two `0x40` writes is insufficient.

### Capture boundaries

If the absolute `0x60` word write modifies fixed publication-base storage, repeated groups still use the earlier captured base.

If restoration at doubled-traversal-base offset `0x54` overlaps publication-area offset `0x14`, the fresh capture must observe memory after restoration. If the subsequent offset-`0x11` byte store overlaps that capture location, it must not affect the already captured value.

### Fresh-capture consumption

Publication-area offset `9` separately receives the further base’s low byte before its offset-`0x44` word replacement.

### Live observations and partial execution
