### Conditional modular shift

### Unsigned extraction

For unsigned 0xffffffff, retaining the low 20 bits and shifting right by ten produces 0x3ff. Sign extension does not satisfy that operation.

### Early fixed-address ordering

An access trace placing the 0x01 byte write before the 0x05 byte read is unacceptable. A trace moving the later absolute 0x54 word write ahead of the intervening calculated accesses also violates the established order.

### Anchor snapshot

If the 0x60 word write can affect the anchor’s storage through the environment’s memory mapping, publications still use the anchor value loaded before that write. Loading the anchor afterward is not equivalent.

### Late alias-sensitive publication

Suppose ordinary memory initially receives 0xab at 0x67 from the retained 0xa9 word, and a calculated store before the second reread changes 0x67 to 0x42. The second publication-base offset-9 store must use 0x42, not the retained 0xab. The third publication uses its own later reread and may differ again.

### Overlap and interruption
