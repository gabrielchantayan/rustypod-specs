# F-760188d65f83

## Purpose

F-760188d65f83 performs an order-sensitive mutation of caller-accessible memory, prepares selected locations in invocation-local storage, invokes two dependencies, and reaches a terminal instruction mechanism if both calls return.

**Established static evidence:** memory destinations depend on explicit arguments, four ambient entry values, static-storage values, signed 16-bit selectors, and products of previously obtained values. Accesses include 8-bit writes, 16-bit reads and writes, and 32-bit reads and writes.

**Inferred intent:** recurring offsets suggest relationships among structured records. No application-level interpretation—such as construction, allocation, serialization, or collection maintenance—is established.

This contract describes the represented execution path. It does not establish that the addresses encountered on that path are valid or that execution reaches either dependency.

## Behavior

### Ordering model

The supplied representation establishes an order of memory operations, not a concurrency or processor-ordering guarantee.

No separation is established among the root, destination, ambient addresses, static storage, computed addresses, or invocation storage. Consequently:

- Earlier writes can change later reads, including reads used to select addresses.
- Values already obtained are distinct from later observations of the same location.
- Repeated stores and repeated reads remain part of the behavior.
- A full-word read followed by byte narrowing is not interchangeable with a byte read.

The descriptions below group effects by behavioral role. Ordering constraints within and between those groups are part of the contract.

### Initial mutation and first anchor

The first memory observation is a signed 16-bit selector at the sum of entry base and entry link. It precedes the byte write at destination offset 21, whose value is entry link’s low byte. A subsequent word store places the complete destination value at entry link offset 68.

Only after those writes does entry primary offset 116 supply an initial reference. The selector determines a short-sized destination relative to that reference; entry primary’s low 16 bits are stored there. The reference’s offset-68 word is obtained afterward. Call this obtained value the **initial incoming word**. An overlap with the preceding short store can affect it.

Before the first root offset-100 observation, these additional effects occur in order:

- Entry base receives its own value at offset 84.
- The first static source supplies the retained **first anchor**.
- Entry primary offset 68 receives another evaluation of that static source.
- First anchor offset 20 receives the initial incoming word.
- Entry base offset 17 receives the low byte of entry base shifted left once.

The retained anchor and the value subsequently written into the upstream link come from separate static-source appearances. Their equality is not guaranteed by an assumption that static storage is immutable. The same distinction applies when selecting the second and third anchors.

### Anchor-mediated transformations

Two transformations share a field-access pattern but have different timing.

| Role | First transformation | Second transformation |
|---|---|---|
| Selected base | Entry base | Reference selected by the first transformation |
| Active anchor | First anchor | Second anchor |
| Relay | Word obtained at selected-base offset 68 | Word obtained at selected-base offset 68 |
| Signed selector | Short obtained at selected base plus active anchor | Short obtained at selected base plus active anchor |
| Selected reference | Word obtained at signed selector plus 20 | Word obtained at signed selector plus 20 |
| Incoming word | Initial incoming word | Word obtained at first anchor offset 68 after the first transformation |

For each transformation, once the selected reference has been obtained, the following externally visible effects occur in this order:

| Destination | Value |
|---|---|
| Relay offset 84, word | Relay itself |
| Active anchor plus incoming word, word | Entry payload |
| Active anchor offset 20, word | Relay |
| Active anchor offset 13, byte | Low byte of a fresh **word** read at entry payload offset 68 |
| Selected-reference offset 13, byte | Relay’s low byte |
| Signed selector plus active anchor, short | Relay’s low 16 bits |

The word read supplying the anchor’s offset-13 byte occurs after the anchor’s offset-20 write. An overlapping write can therefore change that byte’s source.

For the first transformation, the relay, selector, and selected reference are obtained consecutively before these effects. For the second, transition writes intervene between obtaining its selector and obtaining its selected reference. The two transformations are not interchangeable.

### Transitions and the two root observations

The first root offset-100 word is obtained immediately before the first transformation’s relay and selector observations.

After that transformation:

- First anchor offset 68 supplies the next incoming word.
- The first selected reference receives its own value at offset 84.
- The second static source selects the retained second anchor.
- The first relay’s offset 68 receives a further evaluation of that static source.
- Second anchor offset 20 receives the saved incoming word.
- The first selected reference’s offset 17 receives the low byte from the first root offset-100 observation.

Root offset 100 is then read again. This second observation is not a reuse of the first.

The second relay and signed selector are obtained next. Before obtaining the second selected reference, three writes intervene: the incoming word’s offset 84 receives the first selected reference; the first selected reference’s offset 17 receives the second root observation’s low byte; and the second relay’s offset 68 receives the retained second anchor.

The second selected reference is then obtained, followed by the second transformation’s common effects.

Afterward, second anchor offset 68 supplies a saved transition word. The second selected reference receives its own value at offset 84. The third static source selects the retained **third anchor**, and a further evaluation of that source supplies the second relay’s offset-68 replacement. Third anchor offset 20 receives the saved transition word.

Finally, the second selected reference’s offset 17 receives the retained low byte of the second root offset-100 observation. It does not obtain that byte from another root read.

### Product-addressed transformation

Call the second selected reference the **final reference**. Two observations establish the product operands: its offset-68 word, followed by a signed short at final reference plus third anchor. Call the extended short the **product selector**.

Before any product-dependent lookup, a two-store pattern occurs twice consecutively:

- Product-selector offset 84 receives the product selector as a word.
- Third anchor offset 17 receives the final reference’s low byte.

There is no intervening explicit read or call between those two occurrences.

The initial address product combines the product selector with the previously obtained final-reference offset-68 word. From that product, the lookup follows three successive word observations: offset 68, then offset 116 relative to that result, then offset 20 relative to the next result. The last result identifies a **replacement base**.

The existing word at replacement-base offset 20 is preserved as the **saved reference**, and that location is replaced by final reference shifted left once. Only afterward is saved-reference offset 20 read. If that read overlaps the replaced word, it observes the replacement subject to the target’s memory semantics.

Two further address products are distinguished:

- **First derived product:** product selector multiplied by the newly obtained saved-reference offset-20 word.
- **Second derived product:** product selector multiplied by the first derived product.

Between computing the first derived product and observing its offset-116 word, another self-valued word store occurs at product-selector offset 84, followed by a byte store of the saved reference’s low byte at third anchor offset 17.

The first derived product’s offset-116 word becomes the **retained reference** and is assigned to invocation-storage offset hexadecimal 108. After forming the second derived product, the self-valued store is repeated, and third anchor offset 17 receives the retained reference’s low byte.

These products are address components. No element size, array interpretation, or permitted index range is established.

### Final external-memory effects

The final phase distinguishes multiple observations that can differ through aliasing.

First, second-derived-product offset 68 is read as a word. Root offset 116 is read next. Third anchor offset 100 then receives the retained reference as a word, and third anchor offset 9 receives the low byte of the earlier product-offset-68 observation.

A **fresh word read** at second-derived-product offset 68 supplies the byte written at that product’s offset 17. The intervening third-anchor writes may change the fresh observation.

Another self-valued word store at product-selector offset 84 precedes a byte store at twice the second derived product plus 17. This byte is the retained reference’s low byte.

The routine then obtains:

1. A word at product selector multiplied by second derived product, plus 68.
2. A word at root offset 20, called the **last selected reference**.

Three byte writes complete the visible external-memory mutation, in this order:

| Destination | Byte value |
|---|---|
| Retained reference plus 1 | Low byte of the earlier root offset-116 observation |
| Last selected reference offset 17 | Low byte of the last product-addressed word observation |
| Last selected reference offset 9 | Low byte of twice the second derived product |

The last selected reference is obtained before all three writes. The first write can overlap root storage without retroactively changing that obtained address.

## Acceptance examples

These are conditional static criteria, not executed tests. Unless stated otherwise, assume valid accesses, compatible calls, and arithmetic with established target meaning.

1. **Narrow and full-width effects differ.** If entry link ends in hexadecimal AB, destination offset 21 receives byte AB. Entry link offset 68 separately receives all 32 bits of destination.

2. **Selectors are signed.** A short containing hexadecimal FFFF contributes −1, not 65535, to selector-based addressing. In the product phase, that sign extension also affects multiplication.

3. **Separate root observations remain separate.** If the first and second root offset-100 reads end in 12 and 34 because intervening stores overlap that location, the first transition uses 12. Subsequent uses of the retained second byte use 34.

4. **Narrow output does not narrow input access.** If only one readable byte exists at entry payload offset 68, that does not satisfy the represented 32-bit read, even though only its low byte is stored.

5. **Second-transformation timing matters.** If its intervening relay-offset-68 write overlaps the selector-plus-20 location, the selected-reference read occurs after that write. Moving the read earlier is not equivalent.

6. **Repeated writes remain observable.** Where memory exposes individual write transactions, the repeated initial product-phase pattern produces four stores, not two.

7. **Replacement precedes dependent observation.** If saved-reference offset 20 is the replacement destination, the later read obtains the replacement value rather than a value prefetched before replacement.

8. **Repeated product observation is fresh.** If a third-anchor write changes second-derived-product offset 68, its later offset-17 byte store uses the new word observation.

9. **Partial initialization is insufficient for stronger consumers.** Without overlap, listed stack locations have their assigned values when passed to F-opaque-01. A consumer requiring the entire surrounding region to be initialized has an unestablished precondition.

10. **Calls can change later inputs.** If F-opaque-01 changes the static source used by F-cdec09f5d432, the later static-derived argument must reflect the represented post-call selection rather than an assumed pre-call snapshot.

11. **Failure does not imply rollback.** If the initial destination byte write succeeds and a later access faults, no restoration of that byte is supplied.

12. **Completion is not ordinary success.** If all accesses succeed and both main calls return, terminal handling follows them. An ordinary successful function return is not supported.
