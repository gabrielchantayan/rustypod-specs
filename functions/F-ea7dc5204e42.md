# F-ea7dc5204e42

Each entry operation receives the same shared value. After normal iteration, a final helper receives the address of a local state slot.

## Acceptance examples

These are conditional static acceptance cases, not runtime test results.

1. **Zero extent.** If the captured extent fields are equal and prerequisite calls return normally, no selector or per-entry operation occurs. Preparation, shared-value acquisition, object acquisition, and finalization still occur.

2. **Three ordinary iterations.** If the representable signed extent difference is 12, selectors receive indices 0, 1, and 2 in order. Assuming all calls return normally, each per-entry chain completes before the next selection. All three indirect operations receive the same shared value.

3. **Positive remainder.** A representable difference of 10 produces a bound of 2. No rejection or rounding up is visible.

4. **Changed selection object.** Suppose the captured difference is 12 and the first selection uses the acquired object. If an intervening dependency validly changes the first slot through a retained alias, the next selector receives the changed slot value. The invocation still has the original three-iteration bound; it does not read replacement extent fields.

5. **Changed extent fields only.** If a dependency modifies the acquired object’s extent fields without changing the first slot, later selectors still receive that slot’s value, and the bound remains derived from the earlier snapshots.

6. **Changed finalization contents.** If an intervening dependency changes the first slot and execution completes normally, F-5d38327d98c6 receives the same slot address with those changed contents. Restoring or substituting the original acquisition result would add behavior not shown.

7. **Signed-index boundary.** Under low-16-bit signed narrowing, a bound of at least 32,769 reaches selector index −32,768 after index 32,767. A bound exceeding 65,536 reaches index 0 again at counter 65,536.

8. **Tagged dispatch address.** If preparation leaves a valid dispatch-object address with bit 0 set, lookup uses the address with that bit cleared. The function does not directly clear the stored slot value.

9. **Payload mutation.** If either intervening payload-processing dependency changes the second payload word while keeping the retained pointer valid, the per-entry dispatch receives the later-read value.

10. **Abnormal termination.** If an entry dependency does not return normally, the visible body does not guarantee subsequent selection or the final helper.
