### Argument derivation

For each offset that passes the comparison, the function derives one dependency argument in this order:

1. Combine the base bit pattern with the current unsigned offset using addition.
2. Apply the alignment mask to the resulting sum, clearing its lowest five bits.
3. Invoke F-b89986be5378 with that aligned value.

In the 32-bit interpretation, conversion to unsigned arithmetic occurs before the addition is evaluated. A negative signed base therefore participates through its corresponding unsigned 32-bit bit pattern. This is not signed-overflow arithmetic.

Alignment applies to the sum, not to the offset alone. For example, a base of 4,099 and an offset of zero produce an argument of 4,096.

Every offset reached by the iteration is a multiple of 32. Consequently, the sequence of arguments can also be described mathematically as the aligned-down base followed by successive increments of 32, with 32-bit wraparound. This equivalence describes the argument sequence; the observed derivation still adds the offset before applying the mask.

A wrapped sum is not rejected. Argument values can move from the high end of the 32-bit range to zero.
