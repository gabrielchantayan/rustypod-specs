The value obtained there supplies the base address for the second lookup. The second lookup selects the function to invoke.

## Behavior

### Observable ordering

The established dispatch sequence is:

1. Obtain the entry base from implicit incoming machine state.
2. Read the integer-valued field at entry base plus 8.
3. Use that value as the intermediate base and read the function-pointer field at intermediate base plus 8.
4. Invoke the selected target.
5. Return if the target returns normally.

The second memory address depends on the value obtained by the first read. Target selection therefore requires the first read before the second.

There are two dispatch-data reads in the supplied representation. The expression’s function-designation dereference does not establish a third pointer-table lookup. Instruction fetching and any additional activity required by the platform’s call mechanism are outside that two-read count.
