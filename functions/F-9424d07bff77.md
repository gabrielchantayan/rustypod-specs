# F-9424d07bff77

1. Conditionally invokes F-a47f88e3d6eb, depending on a byte-narrowed object field.
2. Invokes F-cd3611b288cc using another object field.

## Behavior

### 1. Evaluate the conditional-control field

The first visible operation reads the integer word at index 0x221 and converts that value to the representation’s character type. The branch is taken when the converted value is nonzero.

This is a test of the converted value, not an unrestricted whole-word nonzero test. On a target with conventional 8-bit narrowing, only the low eight bits determine whether the branch is taken. A word containing nonzero bits exclusively above those eight bits therefore does not necessarily enable the optional call.

The evidence does not identify plain-character signedness or all target conversion rules. With conventional 8-bit narrowing, signedness does not change the zero-versus-nonzero outcome: a converted bit pattern with its high bit set is still nonzero.

The function does not visibly clear or normalize the control field. It evaluates this condition once; no later recheck is shown.

### 2. Optionally invoke F-a47f88e3d6eb

When the converted control value is nonzero, the function reads the integer word at index 0x1cd and invokes F-a47f88e3d6eb with:

1. The original object-address argument.
2. The value obtained from word index 0x1cd.

When the converted control value is zero, this call and its associated field read are skipped.

The object-address argument itself remains the same address supplied by the caller. Its contents need not remain unchanged. F-a47f88e3d6eb may modify accessible object storage or other state; the excerpt provides no preservation guarantee.

If this dependency does not return normally, the subsequent operations are not established as occurring.

### 3. Invoke F-cd3611b288cc

After the optional stage completes, the function reads the integer word at index 0x1d2 and passes that value as the sole explicit argument to F-cd3611b288cc.

The timing of this read is significant. If F-a47f88e3d6eb ran and changed this field before returning, F-cd3611b288cc receives the later value, not a value cached before the optional call.

This invocation is unconditional with respect to the control field, but it is conditional on execution reaching this stage. A nonreturning optional dependency prevents it from being reached.

No returned status is visibly tested. Normal return from F-cd3611b288cc leads to the final dispatch regardless of any ordinary result it might produce.

### 4. Perform object-selected indirect dispatch

After F-cd3611b288cc returns, the function reads the dispatch-table address representation from word index 0 of the object. It selects the callable entry at byte displacement 0x58 from that table address.

The selected target receives:

1. The original object-address argument.
2. Dispatch value A.
3. Dispatch value B.

The table displacement is a byte offset. It is not an entry number. If entries were four bytes wide, this displacement would correspond to zero-based entry 22, but the excerpt does not independently establish that entry width.

The dispatch lookup occurs after both preceding stages. A dependency that changes the object’s first word can therefore change the final target.

The external argument values are used at this final stage rather than visibly captured before the earlier calls. No assumption is made that either preceding dependency preserves their backing storage. The excerpt does not establish the relative evaluation order of dispatch-target selection and the two external-value reads within the final call expression.

After a normally returning final dispatch, no further explicit action is shown before return.
