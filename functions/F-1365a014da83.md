# F-1365a014da83

## Purpose

F-1365a014da83 invokes a dependency using a value obtained through a caller-supplied object, then conditionally initializes a record selected through a shared global slot.

The function clears a caller-supplied output location before invoking the dependency. If the dependency’s full-width result is exactly zero, the function writes two 32-bit fields and two one-byte fields into the selected record, then publishes that record’s address through the output location. Otherwise, it performs none of those success-path writes.

The returned status is the dependency result narrowed to a signed 16-bit value and then represented as a signed 32-bit value. Consequently, a returned zero does not, by itself, establish that the success path ran.

The apparent intent is to associate a selected record with an input object and a supplied value. The meanings of that association, the byte fields, and the dependency operation are not established.

### Success-path writes
