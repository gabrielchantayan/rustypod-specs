For examples below, the **conditional 32-bit bit-vector model** means that transformed values retain their low 32 bits, with those bits subsequently used as argument or address inputs. This model specifies conditional numerical relationships; it is not a blanket guarantee that signed overflow, signed shifts, or integer-to-target conversions are executable as represented.

Important distinctions are:

- Entry-target formation uses signed 32-bit addition before conversion to a call target.
- Scaled-transfer producers return signed 32-bit values. Their two-bit left shifts require care for negative inputs or results outside the signed range.
- The first boundary initially shifts an unsigned 32-bit result left by two bits. That unsigned shift discards bits above bit 31; subsequent interpretation as a signed intermediate introduces a separate conversion question.
- The alternative first-boundary calculation shifts the signed entry selector word left by ten bits.

### First byte store: conditional selection

The first write-boundary producer supplies an unsigned 32-bit selection word. Bit 30 determines which value is selected:

- If bit 30 is set, the selection word shifted left by two bits supplies the selected intermediate.
- If bit 30 is clear, the signed entry selector word shifted left by ten bits supplies the selected intermediate.

The routine writes the low payload byte to the address formed by multiplying the selected intermediate by two.

The immediately following call receives the selected intermediate in both explicit argument positions. It does **not** receive the doubled store address.

Only bit 30 controls this selection. There is no separate visible test of bit 31, sign, zero, address validity, or range. The two outcomes rejoin before the store and following call.

The byte store precedes that call, which may therefore observe or overwrite the stored byte.

### Second byte store: payload extraction

This does not establish behavioral independence. Earlier calls may change memory or other state that influences this producer, including state derived from the first boundary.
