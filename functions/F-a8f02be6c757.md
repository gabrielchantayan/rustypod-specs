## Behavior

1. It first checks whether the selector is 0.
2. If that comparison does not match, it checks whether the selector is 1.
3. If neither earlier comparison matches, it checks whether the selector is 2.
4. Any remaining value returns without an assignment.

Exactly one mapping applies to an accepted selector. There is no fallthrough into another assignment and no sequence of intermediate destination values.

For selector 0, the function assigns 1024 to the designated destination and returns.

For selector 1, the function assigns 1536 to the designated destination and returns.

For selector 2, the function assigns zero to the designated destination and returns. Selector 2 is therefore an accepted input with a state-changing action, not another spelling of the unsupported-input path.
