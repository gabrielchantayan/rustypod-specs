# F-fe9f99546e30

## Purpose

F-fe9f99546e30 conditionally performs memory transfers derived from incoming machine state, then enters an unconditional dispatch cycle. The supplied representation does not establish an application-level purpose.

Under the stated 32-bit address interpretation, the executable prefix has at most two memory-writing phases:

- A halfword transfer selected by a scaled argument becoming zero.
- A more restrictive, data-addressed halfword mutation.

The second phase necessarily causes a subsequent gate to fail. The later arithmetic, pointer reads, and paired 32-bit stores shown in the representation are therefore unreachable under that interpretation. They are not possible executed side effects of this contract.

The dispatch cycle attempts two calls and a software interrupt in that order. If all return, it repeats using a fixed base address. No normal return is represented.

This contract separates established static evidence, arithmetic conclusions under explicit width assumptions, and **documented_only** architectural unknowns. No runtime tests have been performed.

## Behavior

### Prefix selection

Define **Q** as the low 32 bits of P multiplied by 256.

Q is zero exactly when P’s low 24 bits are zero. P itself may be nonzero.

If Q is nonzero, the function performs no explicit prefix data-memory access and proceeds to dispatch using L.

The representation also extracts bit 22 of P. Whenever Q is zero, that bit is necessarily clear. It consequently contributes zero to the reachable prefix calculations.

### Mandatory halfword transfer

When Q is zero, the function performs a halfword transfer before deciding whether deeper prefix processing is enabled.

The observable data-memory order is:

1. Read 16 bits at M.
2. Write that value as 16 bits at M plus B.

The write destination uses B as a **byte** offset.

Between the read and write, the working source address is replaced by M plus B minus D. Call this adjusted address **M′**. Computing M′ does not itself dereference it.

There is no visible check for a null, unmapped, misaligned, read-only, or out-of-bounds address. An identical source and destination does not eliminate the represented write. If the read cannot complete, the write and dispatch are not reached through ordinary continuation.

### Conditions for the address-derived mutation

After the transfer, successive zero gates determine whether the mutation is entered. Failure of any gate suppresses the remaining conditional prefix but does not introduce a return or retry.

For the 32-bit interpretation, the conditions reduce to:

- L is zero.
- L plus the logical right shift of S by one is zero.
- A equals B.
- M′ equals D.
- T is zero.
- S plus twice B is zero modulo \(2^{32}\).

These reductions follow from preceding zero tests, not from assuming arbitrary shift counts are harmless. Each reached shift in this gate chain has a count taken from a value already known to be zero. Its count is therefore zero.

The other scaled operand, P multiplied by 512, is also zero whenever Q is zero. The carry entering the T addition is zero, and the contribution from P’s low 24 bits is zero. Thus that gate requires T itself to be zero.

There are two further useful consequences:

- Because L is zero, the S-derived gate requires S logically shifted right by one to be zero. Hence S is either 0 or 1.
- Twice B is even in 32-bit arithmetic. The final zero sum cannot hold for S equal to 1. Mutation entry therefore requires **S = 0**, with **B equal to 0 or 0x80000000**.

These are numeric reachability conditions, not evidence that address zero can actually hold the fifth argument’s storage. In an environment where that placement is impossible, the mutation cannot be reached.

### Address-derived mutation

If all entry gates succeed and execution continues through the accesses, the mutation:

- Assigns special machine state a value derived from S multiplied by 64.
- Computes an adjusted L value equal to L plus S multiplied by 64.
- Performs a data-addressed 16-bit store using halfword expressions read at the previous L address.
- Changes another working address from Q to Q plus two bytes.
- Clears the carry used by the next gate chain.

The data-addressed store has two roles for the halfword expressions at the previous L:

- One supplies a zero-extended numeric destination address in the range 0 through 65535.
- The other supplies a value increased by 15 and truncated to 16 bits for storage.

The representation contains two read expressions at that same source address. Their relative evaluation order and correspondence to separate hardware reads are not established. They must not be assumed to return identical data for device memory or externally changing memory. Under a stable-memory interpretation, a source value of 0xFFFF selects destination 65535 and produces stored value 0x000E.

The special-state assignment precedes this memory operation in the representation. The adjusted L replaces the working L after the store.

Under the entry constraints already proved, both S and L are zero. Thus the special-state assignment receives zero, the adjusted L remains zero, and the halfword source is numeric address zero. Completing the phase requires an execution environment in which those operations can continue.

### Deterministic failure after the mutation

The mutation cannot enable the remaining conditional prefix.

The decisive invariants are:

- Q is zero.
- The earlier S-derived working candidate is zero.
- The newly advanced working address is Q plus two, hence **2**.

Structurally, a nonzero adjusted L would stop progression immediately. If the adjusted L is zero, the next zero-count expression combines the zero candidate with zero and produces zero. The following expression then combines the advanced address with the zero candidate:

**2 XOR 0 = 2.**

That result is nonzero, so the next enabling flag is false. Subsequent conditional blocks remain disabled.

For the fully reduced 32-bit entry conditions, adjusted L is necessarily zero, so the latter case is the actual numeric path: one zero result followed by the nonzero result 2.

This is a determined gate failure. It is not merely uncertainty about whether an unusual argument-storage address is attainable.

The same downstream blocks are disabled if the mutation is not entered, because their initial enabling flag is false.

### Dispatch cycle

Whenever the prefix completes, the initial dispatch base is L.

Without mutation, the working dispatch address remains L. With mutation, the adjusted address is L plus 64 times S, but mutation entry forces S to zero. The unreachable blocks cannot install any other initial base.

For a current base **J**, the cycle attempts:

1. **F-unknown-01** at J plus 0xEB6, with three displayed 32-bit argument words: 0, 0, and 0xFFFFFFA5.

3. **F-unknown-03**, the software-interrupt service selected by 0x5B.
4. Replacement of J with 0x083D4CC2.

The third argument word has unsigned value 4,294,967,205 and two’s-complement signed interpretation −91. Its interpretation by the callee is unknown.

## Acceptance examples

These are conditional static expectations, not executed tests.

1. **Prefix bypass.**  
   With P equal to 1, Q is 0x100. No explicit prefix data-memory access occurs. The first dispatch target is L plus 0xEB6.

2. **Nonzero argument selecting the transfer.**  
   With P equal to 0x01000000, Q wraps to zero. The halfword transfer precedes the L gate. Selecting solely on whether P itself is zero would be incorrect.

3. **Transfer followed by dispatch.**  
   With Q zero, L nonzero, and accessible memory, a halfword value 0xBEEF at M is written at M plus B. Deeper prefix processing is disabled; the initial dispatch base is L.

4. **Byte-offset boundary.**  
   With Q zero and B equal to 2, the transfer destination is two bytes after M, not four.

5. **Failure before dispatch.**  
   With Q zero and an unreadable M, the halfword read is attempted before either dispatch call. No ordinary error result or recovery behavior is established.

6. **Odd storage-address candidate cannot enter mutation.**  
   If earlier gates yield S equal to 1, no value of B makes S plus twice B zero in 32-bit arithmetic. The mutation is disabled.

7. **Mutation does not reach the later stores.**  
   If mutation entry and its accesses complete under the numeric model, Q is zero and the advanced address is 2. The subsequent gate produces 2 XOR 0, disabling every later conditional prefix block. No descriptor-like or final paired store occurs.

8. **Stable-memory mutation value.**  
   Conditional on legal mutation entry, a stable source halfword 0x0100 selects numeric destination 0x100 and stores 0x010F there. This example does not assert that the required zero-address storage or special-state operation is realizable.

9. **Dispatch ordering and nonreturn.**  
   If all dependencies return, their order is F-unknown-01, F-unknown-02, then F-unknown-03, followed by installation of the fixed base. If F-unknown-01 does not return, the other two operations are not reached in that cycle.
