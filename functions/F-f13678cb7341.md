# F-f13678cb7341

## Purpose

F-f13678cb7341 processes an encoding declaration using a mutable parser record and records results in a caller-supplied context.

The visible control flow supports predefined-encoding selection and custom-table processing. Custom processing obtains a count, makes two storage-related requests, initializes a table, supplies default entries, and processes indexed or sequential names until a terminator, input exhaustion, or an error path.

This is a static behavioral contract. Established behavior consists of visible reads, writes, calls, conditions, and ordering. Describing dependencies as classifiers, comparisons, storage requests, or table operations expresses their apparent roles; their implementations and broader semantics are not established.

The function has no explicit return value. Its results are state mutations and dependency effects. Returning without assigning an error does not establish that the declaration was consumed completely or that all dependency operations succeeded.

## Behavior

### Entry snapshots and mutation-sensitive selection

Before the first callback, the function captures the input limit and the provider-object address. It then invokes F-indirect-01 with the parser address and reads the resulting cursor.

All explicit limit comparisons use the captured limit. Later changes to the parser's limit field do not replace it.

If the cursor is at or beyond that limit, F-4457a9a44a68 receives an out-of-bounds diagnostic argument. After that call returns, the parser error field is assigned `3`, and the function returns.

Otherwise, selection uses separate byte reads at the captured cursor address:

1. Read a byte and pass it to F-cfad0582408b.
2. If that result is zero, reread the byte to decide whether it is `[`. A nonzero result enters custom handling without this conditional reread.
3. After entering custom handling, independently reread the byte to select the mode: `[` selects bracketed mode; any other value selects numeric mode.

Consequently, an opening bracket observed for the classifier argument does not guarantee bracketed mode. A nonzero classifier result does not guarantee numeric mode. F-cfad0582408b may change the input between these reads.

If its result is zero and the conditional reread is not `[`, predefined selection is attempted. These byte reads use the captured cursor address, not a newly loaded parser cursor; callback changes to the cursor field are a separate effect.

The one-byte character type has unspecified signedness in the supplied representation. Promotion of high-bit bytes to dependency arguments is therefore unresolved.

### Custom count and setup

F-indirect-01 is invoked again. If the resulting cursor is at or beyond the captured limit, the function returns without performing the following setup or explicitly assigning a tag or error.

Otherwise, operations occur in this order:

2. Write the count to parser offset `0x58`.
3. Call F-6dd003795db7 with the captured handle, `2`, `0`, count, `0`, and a writable 32-bit status-output address.
4. Store its 32-bit return value at context offset `0x17c`.
5. If the status is zero, call F-6dd003795db7 with the same argument pattern except that the second argument is `4`.

### Declaration processing and saved continuation

A separate unsigned 32-bit successful-insertion counter starts at zero. It counts declaration-specific insertions returning zero, not default entries, visited tokens, or the highest explicit index.

A saved continuation initially holds the captured address used for initial selection. Each iteration begins with F-indirect-01 and then reads the parser cursor.

If that cursor is at or beyond the captured limit, the function writes custom tag `1`, replaces the parser cursor with the saved continuation, and returns. Completion can therefore move the cursor backward. This exhaustion path does not perform the explicit-terminator diagnostic-level check.

## Acceptance examples

These are conditional static consequences, not executed tests. Unmentioned dependency effects are excluded from each example.

1. **Predefined zero result.** With at least 18 bytes remaining, if the first eligible F-fca51b715561 call returns zero, tag `2` is written. Merely presenting the expected spelling does not establish that return value.

2. **Insufficient predefined span.** With exactly 16 bytes remaining, the standard-associated attempt is skipped. If no other eligible attempt returns zero, a diagnostic is called and error becomes `3`.

3. **Mutation changes mode.** If the first byte read is `[`, F-cfad0582408b returns nonzero, and it changes that byte to a non-bracket before mode selection, numeric mode is selected.

4. **Conditional reread permits custom handling.** If the classifier returns zero, the conditional reread observes `[`, and the later mode reread observes another byte, custom handling uses numeric mode.

5. **Nonzero classification permits bracketed mode.** If the classifier returns nonzero and the mode reread observes `[`, the count is `256`; F-indirect-03 is not used for the count.

6. **Early exhaustion.** If the skip after obtaining the count reaches the captured limit, no storage requests or explicit custom-tag assignment occur.

7. **First request failure.** If the first request reports status `9`, its return value is stored at `0x17c`, error becomes `9`, and neither the second request nor initialization occurs.

8. **Late provider lookup.** If a successful storage request changes the captured provider object's first word, initialization uses that word's later value when resolving the dispatch table.

9. **Outlying explicit index.** With count `2` and fewer than two successful insertions, index `7` is not locally rejected. Valid insertion and subsequent pointer-array access still require dependency guarantees.

10. **Saved name continuation.** If an eligible slash is at address A, skipping ends at B, insertion succeeds, and the next iteration exhausts input, the final cursor is A plus one, not A or B.

11. **Insertion failure.** A nonzero declaration-specific insertion result becomes the parser error. That path performs no explicit buffer-zero write or custom-completion tag assignment.

12. **Diagnostic-state mutation.** If F-402c86044576 accepts termination and changes the external diagnostic pointer, the subsequent level read uses the changed pointer.

13. **Ignored default return.** A default insertion returning nonzero does not itself stop default population or assign that value to the parser error.
