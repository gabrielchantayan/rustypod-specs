### Early captures and fixed-address effects

After the repeated region, the function captures a word from fixed address 0xA9, then a word from Payload plus 0x74. These are separate saved values.

It next writes one byte at fixed address 0x3A. Its bit pattern is twice Base A’s low byte plus 0x30, reduced to eight bits. Signed versus unsigned interpretation of the intermediate byte does not change this final eight-bit result.

The following two captures occur after that fixed-address store: first a word from Base C plus 0x14, then a word from Base A plus 0x04.

A subsequent store sequence places:

- The constant byte 0x6C at Base A plus 0x08.
- Base B’s low byte at Base A plus 0x0D, then at Base A plus 0x09.

The function then captures a signed 32-bit word from Base C plus 0x44, called the **shift source**. After that capture, it reads the byte at fixed address 0x67 and writes that byte to fixed address 0x21. The copy uses a memory read at this point, rather than simply reusing the earlier captured word.
