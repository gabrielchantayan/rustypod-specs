# F-a7562a402053

## Purpose

F-a7562a402053 reads selected 32-bit source words and produces two 32-bit destination words per source word. Each output has its most significant byte set to 255. The remaining bytes are assembled from masked, shifted portions of the source word.

The caller selects a row interval. Within each selected row, the function processes source columns 3 through 76 inclusive. A mode argument selects one of two destination mappings without changing the value transformation.

The ordinary mapping depends on an external row-offset value captured separately for each processed row. The alternate mapping does not access that value. Consequently, the ordinary mapping is not established as a fixed-stride destination layout unless the captured offset remains constant.

Packed-pixel expansion and orientation-dependent placement are inferred intent, not established format guarantees. The external mask values and surrounding application contract are unavailable.

No runtime tests have been performed.

## Interface

The function accepts six arguments and returns an unsigned 32-bit value.

| Argument | Width and interpretation | Role |
|---|---|---|
| First argument | Opaque 32-bit value | Unused by the supplied body. |
| Mode | Signed 32-bit integer | Values 2 and 3 select the alternate mapping; all other values select the ordinary mapping. |
| Source base | 32-bit address-bearing value | Base for source-word reads. |
| Destination base | 32-bit address-bearing value | Base for destination-word writes. |
| Starting row | Signed 32-bit integer | Inclusive first row. |
| Ending row | Unsigned 32-bit value | Its signed 32-bit interpretation is the exclusive row limit. Its original unsigned bit pattern is returned after nonempty processing. |

Three external 32-bit storage values participate:

| Contract label | Role | Access timing |
|---|---|---|
| \(L\), low mask | Supplies the entry-derived high mask and later low-channel mixtures | Referenced at entry and during each source-word conversion |
| \(M\), middle mask | Supplies middle-channel mixtures and the empty-interval return value | Referenced on an empty return or during each source-word conversion |
| \(K\), ordinary row offset | Adjusts ordinary destination word indices | Read once at the start of each ordinary-path row, before that row’s first source-word read |

The labels describe roles, not known values. In particular, \(K\) is not established to be zero, constant, nonnegative, or measured in bytes. Its role in the destination equations is a **word-index offset**.

Let \(s\) denote the signed starting row and \(e\) the signed interpretation of the ending-row bit pattern. The return value is:

- The value obtained from \(M\) for the empty return, when \(e \leq s\).
- The original unsigned ending-row argument, when \(e > s\) and processing completes.

The return value is therefore not uniformly a status, row count, or final row index.

## Behavior

### Entry and row selection

Before deciding whether the row interval is empty, the function reads \(L\) and derives a 32-bit high mask:

\[
H=(L\ll 11)\bmod 2^{32}.
\]

This derived value is retained for the operation. Subsequent references to \(L\) do not refresh \(H\).

If \(e\leq s\), the function returns a value read from \(M\). It performs no source-word reads, destination-word writes, or \(K\) reads. An empty interval therefore still accesses external mask state.

Otherwise, rows are processed in increasing order:

\[
s,\ s+1,\ \ldots,\ e-1.
\]

Each row processes exactly 74 source columns, in increasing order from 3 through 76. Columns 0 through 2 and 77 through 79 are not selected.

### Source layout and access order

The source row stride is 80 words, or 320 bytes. For row \(r\) and selected column \(c\), the source address is:

\[
S+4(80r+c),
\]

where \(S\) is the source base.

One 32-bit source-word read supplies both outputs for that position. The function does not snapshot a row or the entire source interval.

For each position, the source word is read, the channel mixtures are formed, and the two destination writes occur before the next source word is read.

On the ordinary path, the row’s \(K\) capture precedes its first source-word read. On the alternate path, there is no \(K\) capture.

### Value transformation

Let \(x\) be the current unsigned 32-bit source word. Right shifts in the following formulas are logical. Left shifts and unsigned intermediate values are limited to 32 bits.

For stable masks, define:

\[
R=((x\mathbin{\&}H)\gg8)
  \mathbin{|}
  ((x\mathbin{\&}H)\gg13),
\]

\[
G=((x\mathbin{\&}M)\gg3)
  \mathbin{|}
  ((x\mathbin{\&}M)\gg9),
\]

\[
B=((x\mathbin{\&}L)\ll3)
  \mathbin{|}
  ((x\mathbin{\&}L)\gg2).
\]

Define the byte selectors:

\[
b_0(v)=v\mathbin{\&}255,
\qquad
b_2(v)=(v\gg16)\mathbin{\&}255.
\]

The first output word is:

\[
P_0=\texttt{0xFF000000}
 \mathbin{|}(b_0(R)\ll16)
 \mathbin{|}(b_0(G)\ll8)
 \mathbin{|}b_0(B).
\]

The second output word is:

\[
P_1=\texttt{0xFF000000}
 \mathbin{|}(b_2(R)\ll16)
 \mathbin{|}(b_2(G)\ll8)
 \mathbin{|}b_2(B).
\]

These are numeric 32-bit layouts. Their byte sequence in memory depends on target endianness, which is not established.

The operation combines bits using masks, shifts, and bitwise OR. It does not perform arithmetic averaging, saturation, or additive channel blending.

The formulas using a single \(L\) or \(M\) are directly applicable when those values remain stable. The supplied body contains separate external-mask references within the mixtures; it does not establish that all such references observe one immutable snapshot. Operand-level physical load counts and ordering are not established.

The source word and channel mixtures are retained for the current pair. A first destination write that changes source or mask storage does not cause the second output to reread that source word or recompute the mixtures.

### Ordinary destination mapping

For any mode other than 2 or 3, the function captures \(K\) once at the beginning of each processed row. Denote the value captured for row \(r\) by \(K_r\).

The destination word indices, relative to destination base \(D\), are:

\[
d_0=K_r+180r+2c+10,
\qquad
d_1=d_0+1.
\]

The byte addresses are \(D+4d_0\) and \(D+4d_1\). The function writes \(P_0\) first and \(P_1\) second.

For a fixed row, the writes cover the contiguous word-index interval:

\[
K_r+180r+16
\quad\text{through}\quad
K_r+180r+163.
\]

This is 148 words, or 592 bytes. No positions outside that interval are explicitly written for that row.

The captured row base is reused for all 74 source words. If a destination write changes the storage containing \(K\), the current row continues to use its already-captured value. A subsequent ordinary row captures the then-current value.

The \(180r\) term contributes a nominal 180-word, 720-byte row displacement. It does **not** establish an unconditional destination-row stride. Between consecutive rows, the displacement between corresponding destination indices is:

\[
180+K_{r+1}-K_r.
\]

Only when the captured offsets are equal is that displacement exactly 180 words. Changing offsets can move, overlap, or reverse the relative placement of rows, subject to valid arithmetic and memory.

### Alternate destination mapping

For mode 2 or 3, the destination word indices are:

\[
d_0=180(2c+11)-r-11,
\qquad
d_1=d_0+180.
\]

The byte addresses are again \(D+4d_0\) and \(D+4d_1\). The first output is written before the second.

This path never reads \(K\). Its mapping therefore does not depend on the stored value of \(K\), although destination writes may still overlap that storage.

For each source word, the outputs are separated by 180 words, or 720 bytes. Within one source row, advancing the source column increases each corresponding destination index by 360 words. Advancing the source row decreases each corresponding destination index by one word.

Modes 2 and 3 have identical behavior in the supplied body.

### Completion and errors

After column 76, the function advances to the next selected row. Once all selected rows have completed, it returns the original unsigned ending-row argument.

There is no explicit error result, recovery branch, rollback, or bounds failure report. If execution is interrupted by an invalid access or another target-level fault, earlier writes may already have occurred. Fault handling itself is outside the established contract.

## Side effects

For a nonempty interval of \(N=e-s\) rows, with valid arithmetic and accesses, the body performs:

- \(74N\) selected 32-bit source-word reads.
- \(148N\) 32-bit destination-word writes.
- One entry-time derivation of \(H\) from \(L\).
- Per-conversion external references to \(L\) and \(M\).
- Exactly \(N\) row-offset captures on the ordinary path.
- No row-offset captures on the alternate path.

The selected source payload totals \(296N\) bytes; the destination payload totals \(592N\) bytes. These figures exclude external-state accesses and do not imply disjoint storage or a count of distinct physical bytes.

The established sequence is:

1. Derive \(H\) from the entry-time low-mask value.
2. Decide whether the row interval is empty.
3. For each nonempty ordinary row, capture its row offset before its first source read.
4. For each selected source position, read the source word and form its mixtures.
5. Write the first output, then the second.
6. Continue to the next column or row.

The body has no explicit assignment to external-mask or row-offset storage. Nevertheless, destination writes may change any of these values if their addresses overlap.

Aliasing consequences include:

- Writes overlapping later source locations can change later source words.
- Writes overlapping \(L\) can affect later low-mask references but not the retained \(H\).
- Writes overlapping \(M\) can affect later middle-mask references.
- Writes overlapping \(K\) can affect later ordinary rows, but not the current row’s captured mapping.
- Source and destination overlap is not handled as a snapshot or overlap-safe copy.

No synchronization, atomicity, or inter-thread visibility guarantee is established.

## Acceptance examples

These are conditional static consequences, not executed tests. Unless stated otherwise, they assume stable masks, valid arithmetic, valid memory, and no interfering concurrent access.

### Empty interval

With starting row 5 and ending row 5:

- No source or destination payload is accessed.
- \(K\) is not read, regardless of mode.
- \(H\) is still derived from \(L\).
- The return value is read from \(M\), not necessarily 5.

An ending row whose signed interpretation is below the starting row has the same empty behavior.

### One ordinary row with an unknown offset

With mode 0, starting row 0, ending row 1, and captured offset \(K_0=k\):

- Source word indices 3 through 76 are read.
- Destination word indices \(k+16\) through \(k+163\) are written.
- Source index 3 produces destination indices \(k+16\) and \(k+17\), in that order.
- Source index 76 produces destination indices \(k+162\) and \(k+163\), in that order.
- The return value is 1.

The specific destination interval 16 through 163 follows only if \(k=0\). The supplied body does not establish that condition.

### Offset changed during an ordinary row

Suppose rows 0 and 1 are selected. Row 0 captures \(K_0=0\). A row-0 destination write overlaps the offset storage, leaving its value equal to 7 before row 1 begins.

Then, provided all accesses and arithmetic remain valid:

- Every row-0 destination index still uses \(K_0=0\).
- Row 1 captures \(K_1=7\).
- Row 1 writes indices 203 through 350.
- Corresponding row starts differ by 187 words, not 180.

If later writes change the offset again, subsequent rows capture those later values.

### One alternate row

With mode 2, starting row 0, and ending row 1:

- Source indices 3 through 76 are selected.
- Source index 3 produces destination indices 3049 and 3229.
- Source index 4 produces destination indices 3409 and 3589.
- Each pair is written in the listed order.
- \(K\) is not read.
- The return value is 1.

Mode 3 has the same mapping for identical remaining inputs and state.

### Zero source word

For a selected source word equal to zero, both outputs are:

\[
P_0=P_1=\texttt{0xFF000000}.
\]

This holds for any mask values whose required accesses complete, because masking and shifting zero contributes no lower bits.

### Exclusive upper bound

With starting row 7 and ending row 9:

- Only rows 7 and 8 are processed.
- There are 148 selected source reads and 296 destination writes.
- The ordinary path captures two row offsets; the alternate path captures none.
- The return value is 9.

### Signed ending-row interpretation

With starting row 0 and ending-row bits \(\texttt{0xFFFFFFFF}\), the signed limit is \(-1\). The interval is empty, and the return value comes from \(M\), not from the ending-row argument.
