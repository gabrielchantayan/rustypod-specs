1. Clear a four-byte field in a caller-supplied object.
2. Read another four-byte field and pass its value to F-abc25a3398a2.
3. Call F-06b9f1d74ffc with zero.
4. Call F-693922d6b567 with zero.
5. Return a four-byte zero if execution reaches the normal return.
