# F-426024df2dcc

## Purpose

F-426024df2dcc is a two-way dispatch operation. It chooses a dependency according to a comparison with a global value and a fixed discriminator, forwards selected arguments, and returns the one-byte value 1 after the selected dependency returns normally.

The established behavior is dispatch and argument forwarding. The available evidence does not establish an application-level meaning for the discriminator, the global value, the object field, or the return value. In particular, the returned 1 is not evidence that the selected dependency succeeded.

This contract distinguishes:

- **Established static evidence:** behavior directly represented in the supplied function.
- **Inferred intent:** plausible interpretation that is not required for conformance.
- **Unknown / documented_only:** behavior for which the supplied evidence is insufficient.

No runtime tests have been performed.

## Interface

### Inputs

The function accepts five positional inputs:

| Position | Contract name | Represented width | Established use |
|---|---|---:|---|
| 1 | Context address | 32 bits | Forwarded unchanged on the special route; used as the base of a memory access on the ordinary route. |
| 2 | Selector | 32 bits | Compared with a global comparison value; forwarded unchanged on the ordinary route. |
| 3 | Discriminator | 32 bits | Compared with hexadecimal 0x36DD; forwarded unchanged on the ordinary route. |
| 4 | Payload word | 32 bits | Forwarded three times on the special route, and once on the ordinary route. |
| 5 | Auxiliary word | 32 bits | Forwarded only on the ordinary route. |

The supplied representation treats the first three inputs as integer-valued and the last two as uninterpreted four-byte values. The context address nevertheless participates in a memory-address calculation on the ordinary route. Its integer representation does not establish that arbitrary numeric values are safe addresses.

The selector and discriminator are used only in equality comparisons. Signed ordering is therefore irrelevant to the branch decision. The fixed discriminator is 0x36DD, or decimal 14045, which is representable as a positive signed 32-bit integer.

The payload and auxiliary words have no established interpretation. They may encode integers, addresses, handles, or other data. This function does not establish their validity, ownership, or lifetime requirements.

### Global input

The branch decision also depends on one global comparison value. The supplied representation exposes it as compatible with the selector comparison, but does not independently establish the global object's storage width, volatility, initialization rules, or synchronization requirements.

For describing a single invocation, “the observed global value” means the value used by that invocation's comparison, not an assumed immutable configuration constant.

### Output

On normal completion, the function returns the one-byte value 1.

The evidence establishes an eight-bit result, not a signedness convention or the treatment of any wider return-register bits. Any dependency result is ignored; it is neither forwarded nor examined.

### Preconditions

For the ordinary route, the caller must supply a context address for which a four-byte access at byte offset 0x29C, decimal 668, is valid under the execution environment.

For the special route, this function performs no such context-field access. However, the selected dependency receives the context address directly and may impose its own requirements.

Both routes also require that their selected dependency can be invoked with the supplied argument values. The evidence does not expose those dependencies' complete preconditions.

## Behavior

### Route selection

The special route is selected only when both conditions hold:

1. The selector equals the observed global comparison value.
2. The discriminator equals 0x36DD.

All other combinations select the ordinary route.

The selector/global comparison is the first condition. The discriminator comparison is required only if that first condition succeeds. This ordering establishes the logical decision sequence; it does not establish a machine-level schedule for fetching already-supplied arguments.

The function makes one route decision. There is no visible loop, retry, fallback route, or reconsideration after a dependency call.

### Special route

When both conditions hold, the function invokes **F-45241221fad8** with five arguments in this positional order:

| Dependency position | Supplied value |
|---|---|
| 1 | Original context address |
| 2 | Original payload word |
| 3 | Fixed value 0x36DD |
| 4 | Original payload word |
| 5 | Original payload word |

The three payload positions receive the same original 32-bit value. The wrapper neither dereferences that word nor creates a copy of any object it might designate.

The original selector and auxiliary word are not forwarded on this route. The dependency's third argument is the fixed discriminator value. Although it equals the input discriminator whenever this route is selected, the established call interface uses the fixed value.

This route does not access the four-byte context field at offset 0x29C. It also does not invoke F-ca0f66276073.

After F-45241221fad8 returns normally, the function returns the one-byte value 1 without examining the dependency's result.

### Ordinary route

If either selection condition fails, the function obtains one four-byte value from the address formed by adding byte offset 0x29C to the context address.

It then invokes **F-ca0f66276073** with five arguments in this positional order:

| Dependency position | Supplied value |
|---|---|
| 1 | Four-byte value read from context offset 0x29C |
| 2 | Original selector |
| 3 | Original discriminator |
| 4 | Original payload word |
| 5 | Original auxiliary word |

The field value itself is forwarded. The function does not instead forward the address of that field, and no second-level dereference is visible.

The context-field read must occur before the dependency can receive its first argument. The ordinary route does not invoke F-45241221fad8.

After F-ca0f66276073 returns normally, the function returns the one-byte value 1 without examining the dependency's result.

### Address arithmetic and layout boundaries

The only established context layout fact is a four-byte field beginning at byte offset 668. Its byte positions are therefore offsets 668 through 671 inclusive.

No surrounding structure layout, field name, type meaning, or total object size is established. The evidence does not justify imposing a particular alignment rule or byte order independently of the target environment.

The source representation uses a 32-bit context-address value. Address formation near the end of the address space is not specified sufficiently to promise portable wrapping behavior. A valid-call precondition is that the required field address be representable and accessible under the actual target's addressing rules.

There is no visible bounds, alignment, null-address, or overflow check before the ordinary-route field access.

### Completion and failures

There is no explicit error-return path. The function returns 1 only after the selected dependency returns normally.

If the field access cannot complete, or if a dependency faults, terminates execution, transfers control elsewhere, or does not return, the evidence does not establish a normal return from this function. It also establishes no recovery, cleanup, or fallback in those cases.

A dependency's ordinary return value cannot change this function's returned value.

## Side effects

The wrapper's directly visible memory activity consists of:

- Accessing the global value for route selection.
- On the ordinary route only, reading four bytes from the context-relative field.

No direct memory write, allocation, release, ownership transfer, reference-count update, logging operation, or persistent state update is visible in the wrapper.

That absence does **not** establish that the complete invocation is side-effect-free. Either dependency may modify memory, global state, external resources, or objects represented by the arguments. Those effects are unknown.

The ordering constraints established here are:

1. Route selection precedes the selected dependency invocation.
2. The ordinary-route field read precedes F-ca0f66276073's invocation.
3. The selected dependency's normal return precedes the wrapper's return of 1.

The wrapper does not recheck the global value or reload the context field after the dependency returns. Consequently, later dependency mutations do not cause this invocation to switch routes.

No ownership guarantee can be derived from forwarding values. In particular:

- Passing a context address does not prove that the dependency merely borrows it.
- Passing the context-field value does not prove that it is a pointer.
- Repeating the payload word does not establish three distinct resources or three independent ownership transfers.
- The absence of a visible release in this wrapper does not prove that no release occurs inside a dependency.

## Acceptance examples

These examples are conditional specifications, not recorded executions. Each assumes that the selected dependency returns normally and that any required memory access is valid.

### Both conditions match

Given a selector equal to the observed global value and discriminator 14045:

- F-45241221fad8 is called once.
- Its argument sequence is: context address, payload word, 14045, payload word, payload word.
- The context field at offset 668 is not read by this wrapper.
- F-ca0f66276073 is not called.
- The wrapper returns the one-byte value 1.

### Selector mismatch with matching discriminator

Given a selector different from the observed global value, even when the discriminator is 14045:

- The ordinary route is selected.
- The four-byte context field is read.
- F-ca0f66276073 receives that field value and the original selector, discriminator, payload word, and auxiliary word.
- The wrapper returns 1 after the dependency returns.

Matching the discriminator alone is insufficient for special routing.

### Selector match with nonmatching discriminator

Given a matching selector and discriminator 14044 or 14046, the ordinary route is selected. No tolerance, range, or masked discriminator comparison is established.

### Ordinary dependency returns a failure-like value

If F-ca0f66276073 returns normally with a value its own interface interprets as failure, this wrapper still returns 1. This example is conditional because the dependency's result semantics are unknown.

### Context field changes during the dependency call

If F-ca0f66276073 changes the context field after receiving its arguments, this wrapper performs no subsequent field read. The first argument already supplied remains the value obtained before the call.

### Inaccessible ordinary-route field

If ordinary routing is selected but the four-byte field cannot be accessed, the evidence supplies no successful-return guarantee. Returning 1 must not be promised merely because the wrapper has a constant normal return value.
