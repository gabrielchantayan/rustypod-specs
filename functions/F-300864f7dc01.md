# F-300864f7dc01

## Purpose

F-300864f7dc01 performs an ordered sequence of calls, extracts selected bits from returned values, reads sparse fields from a source record, constructs a four-word record at fixed addresses, and conditionally performs a final sequence of stores and calls.

**Established static evidence:** The supplied representation has one explicit 32-bit input, additional incoming machine-state dependencies, explicit memory accesses of several widths, and two endpoints marked as bad-instruction termination. No normal return is represented.

**Inferred intent:** Some dependencies appear to produce or consume transformed values. No application-level purpose, success result, or interpretation of the record fields is established. Bit extraction does not establish a floating-point interpretation.

The contract below describes the represented behavior, conditional on calls returning and accesses completing. It does not establish that the represented instruction stream is executable or complete.

The base and count are sampled at different times. Changing the word at 0x08400240 during F-U43 does not itself replace the already retained base. Changing 0x08400198 during that call can affect the subsequent count sample.

### Tail for counts zero through eight

If the unsigned count is at most eight:

1. F-U44 produces a retained 64-bit result.
2. The count’s low byte is stored at retained destination base plus 0x0F.
3. A halfword is stored at numerical address count plus 0x28.
4. A local 32-bit slot is assigned record address 0xC3 logically shifted right by 14, yielding zero.
5. Another local 32-bit slot is assigned the source word previously sampled at offset 16.
6. F-U45 receives the low 32 bits of the F-U44 result, its upper 32 bits, and 0x74.
7. Execution reaches the second bad-instruction endpoint.

The halfword’s value is the low 16 bits of the first local slot’s address plus 0x398, retaining the low 16 bits of that sum. The address is used before the slot is assigned zero.

The halfword destination ranges from 0x28 through 0x30 inclusive. The count is a byte offset, not a halfword index. No subsequent global count read is represented.

These are conditional static examples, not runtime test results. Each assumes preceding calls return and required accesses complete.

8. **Rejected count:** A post-F-U43 count of nine still permits the preceding base-plus-0x68 store. The represented continuation does not reach F-U44 or the tail stores.

9. **Accepted upper boundary:** Count eight reaches F-U44, writes byte eight at base plus 0x0F, and selects halfword destination 0x30.

10. **Count aliasing:** If base plus 0x68 equals 0x08400198, the unconditional store changes the count’s backing location only after sampling. The comparison uses the sampled value. Similarly, changing that global during F-U44 does not itself cause a resample.
