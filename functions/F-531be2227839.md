## Acceptance examples

These are conditional static obligations, not executed tests.

1. **First-write source.** With second argument `0x1000`, the first destination is `0x2000`; the 16-bit value is the ambient halfword, not the fourth argument.

2. **Comparison boundary.** A captured threshold word of `0x4e` adds zero to the doubled third argument; `0x4f` adds one.

3. **Literal-`0x59` ordering.** If the global-derived destination plus `0x59` overlaps a subsequently read global, the later read must observe the resulting storage state under the target’s memory semantics. An entry-snapshot substitution is not equivalent.

4. **Pre-carry aliasing.** If the halfword write at currently read doubling-global value plus `0x54` overlaps the later halfword-arithmetic source, the later capture uses the post-write storage. The already captured doubling word remains unchanged.

5. **Preserved displacement captures.** If the pointer-derived byte write of `0x45` changes the destination-base global, the displacement-`0x45` update still uses the base captured before that write. The same rule applies to its captured second halfword operand.

6. **Reload after overwrite.** If a halfword overwrite changes the pointer-producing word, the later word write at reloaded value plus `0x45` uses the changed full-word value, subject to byte order.

7. **Signed terminal byte.** A terminal byte interpreted as −1 produces `0xffffffff`; OR with `0x44` remains `0xffffffff`. Derived memory accesses still require supported address semantics.

8. **OR, not addition.** Terminal byte-derived values zero and `0x44` both produce first call argument `0x44`, not respectively `0x44` and `0x88`.

9. **Repeated stores.** Observable storage receiving `0x79` and later `0x68` requires both byte writes in order, not merely final byte `0x68`.

10. **Failure or nonreturn.** An inaccessible first destination has no visible validation path. A nonreturning indirect dependency prevents the visible return; no cleanup path is established.
