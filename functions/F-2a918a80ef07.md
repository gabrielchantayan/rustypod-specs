## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Unsigned extraction.** Incoming word 0xffffffff yields 0x1ffff for bits 2–18 and 0x1fff8 for its low 14 bits shifted left by three.

2. **Small-index boundary.** Under 32-bit bit-vector semantics, a producing word with its low seven bits set yields small index 508, not 511. Doubled index + 0x14 is then 0x40c.

3. **Fixed-input conversion.** If the observation associated with 0x05 converts to unsigned 32-bit value 0x80, explicit destinations are 0x95 and 0xd4. This does not establish an 8-bit input read. Conditionally, a signed observation of −128 would convert to 0xffffff80, not 0x80.

4. **Fixed publications.** With retained link 0x1234, the expression assigned to named storage associated with 0x54 is 0x2468. Its physical store width is unknown. With small index 0x84, the eight-bit-converted doubled index supplied to the later 0x15 assignment is 0x08.

5. **Independent scaling.** Under wrapping 32-bit arithmetic, scaling observation 0x40000000 yields twice-scaled base 0x80000000 and constant base zero. The retained offset-0x14 argument comes from 0x80000014, not 0x14.

6. **Retained publication base.** If the assignment associated with 0x60 alters publication-base storage through aliasing, subsequent groups still use the already retained converted base, not a new global read.

7. **Final ordering.** The 0xa9 observation precedes the constant-base offset-0x74 word read. Both precede the 0x3a assignment, which precedes the twice-scaled-base offset-0x14 word read.

8. **Fresh global observations.** If intervening aliases change 0x67, the value assigned to 0x21 and values narrowed into the two later explicit byte stores may differ. Their originating read widths remain unresolved.

9. **Ordered overwrites.** Publication address + 0x20 receives four word stores: 0x20, 0x2f, a widened explicit byte observation, and 0x20. External visibility of all four intermediate states is not required.

10. **Established byte widening.** An explicit unsigned byte observation of 0xff becomes 0x000000ff when widened to a word. This rule does not establish the conversion behavior of declaration-less named-global reads.

11. **Shift boundary.** A final shift count of 32 or more has no established portable result. Masking or saturation is not supplied by this contract.
