### Beginning of direct memory updates

A 32-bit store through the high result component plus 0x14 precedes a byte store through an earlier derived base plus 9. A 32-bit store through the low result component scaled by 256 plus 0x54 follows. The earlier byte destination is then written again, using a retained value’s low byte.

A derived base’s 32-bit field at 0x14 is cleared before its byte at displacement 5 is sampled. ### Displacement 4 and zero extension

If the later 32-bit capture at peer-base displacement 4 yields 0x123456FE, that full word is retained for its later propagation. It is not restricted to 254 merely because an earlier access used the same displacement.

These expectations require the stated values at the respective sampling points; intervening aliasing may change memory.

### Overlapping stores

If a byte store at displacement 0x15 overlaps an earlier word clear beginning at 0x14, the word need not remain zero. Its resulting numeric interpretation depends on byte order.

### Global sampling boundary

If a preceding computed store changes the global pointer-value slot before its specified read, the repeated group uses the newly sampled value. If a later repetition overwrites that slot, subsequent repetitions still use the retained sample, provided execution remains valid.

### Captured word versus current byte

The later 32-bit store of the captured 0xA9 word still uses the captured word, not a reconstruction from current 0x67.
