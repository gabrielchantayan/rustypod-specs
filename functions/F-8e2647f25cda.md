# F-8e2647f25cda

## Purpose

F-8e2647f25cda selects between two externally implemented operations using the result of a classification dependency.

An exactly zero classification result selects a local-buffer path: the function provides a 32-byte automatic buffer to one dependency, then passes that same buffer and the same size to another dependency together with the first input.

Any nonzero classification result selects an indirect-dispatch path: the function obtains a receiver, resolves a callable through a table associated with that receiver, and invokes it with the first input and the receiver.

The established behavior is this selection and call protocol. The source does not establish what is classified, what the local buffer represents, whether either path produces output, or whether either path succeeds. Descriptions such as “initialize,” “send,” or “fallback” would imply dependency semantics not supplied by the evidence.
