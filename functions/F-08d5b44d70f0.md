# F-08d5b44d70f0

## Purpose

F-08d5b44d70f0 performs a state-dependent halfword copy, can select one additional indirect halfword write, and then enters a non-returning dispatch loop containing two indirect calls and a software interrupt.

The supplied static representation establishes no application-level purpose. It does not establish a conventional buffer operation, constructor, decoder, or error handler.

A substantial later arithmetic and memory-access region is syntactically present but unreachable under the represented 32-bit arithmetic and branch conditions. Its pointer load and paired stores are therefore not potential effects of executing this representation. Whether the representation faithfully captures the original machine instructions is a separate, unresolved question.

## Behavior

### Initial selection and halfword copy

The initial selector is the second argument multiplied by `0x01000000`, truncated to 32 bits. It is zero exactly when that argument’s low byte is zero.

When the low byte is nonzero:

- The initial copy is skipped.
- The conditional chains cannot select the special transition or any subsequent memory-update stage.
- The incoming continuation address remains the base used for the first dispatch.

When the low byte is zero, the following operations are represented in order:

1. Form an initial derived address from the incoming continuation address, the bit-6 indicator of the second argument, and the fifth argument’s storage address shifted right by one.
2. Form a second shifted argument word by multiplying the second argument by `0x02000000`, with 32-bit truncation.
3. Form the copy destination by adding the first auxiliary arithmetic word to the incoming source address.
4. Read one halfword from the incoming source address.
5. Replace the working source address with the copy destination minus the address-adjustment word.
6. Write the sampled halfword to the copy destination.
7. Use the incoming continuation address as the next arithmetic gate’s result.

On this branch, bit 6 is necessarily clear. Both shifted argument words are also zero. Consequently, the initial derived address is simply the incoming continuation address plus the fifth argument’s storage address shifted right by one, with 32-bit address arithmetic.

The source read precedes the destination write. If source and destination coincide, the representation still contains a read followed by a write of the sampled halfword. It does not specify an elided operation.

### Gates selecting the special transition

After the copy, a sequence of zero-result gates determines whether the special transition executes. A failed gate suppresses the remaining stages in this chain but does not return from the routine.

In execution order, the chain requires:

1. The initial selector and incoming continuation address to be zero.
2. The initial derived address to compare equal to that zero continuation value.
3. The initial shifted argument word to compare equal to the initial derived address.
4. The two shifted argument words to compare equal.
5. The same shifted-word comparison to pass again.
6. The two auxiliary arithmetic words to compare equal.
7. The address-adjustment word to equal the adjusted source address produced by the copy stage.
8. A scratch-word addition to produce zero.
9. An addition involving the fifth argument’s storage address and twice the first auxiliary arithmetic word to produce zero.

The repeated shifted-word comparisons are distinct displayed gates, even though both succeed once the preceding conditions establish that the compared words are zero.

The comparisons use exclusive-or expressions with right shifts. Every such shift that can execute here takes its count from a preceding result already known to be zero. Their effective shift counts are therefore zero, not arbitrary input-dependent counts.

The scratch-word addition includes the second argument’s low byte multiplied by `0x00800000` and a one-bit carry. On this path the low byte and incoming carry are zero, so this gate requires the scratch word itself to be zero. Its resulting carry is also zero.

The final addition combines the fifth argument’s storage address, twice the first auxiliary word, and that carry. Doubling is 32-bit arithmetic. The representation separately computes unsigned overflow from the addition and from adding the carry; these are not signed-overflow tests.

These conditions describe represented control flow. They do not promise that an ordinary calling convention can supply storage and accessible memory satisfying them.

### Special transition and indirect halfword write

If the final zero-result gate passes, the routine:

- Assigns the separately represented machine-state base the fifth argument’s storage address multiplied by 64.
- Computes an updated continuation address by adding that same byte displacement to the old continuation address.
- Performs an indirect halfword write involving two dereference occurrences of the old continuation address.
- Advances the initially zero shifted-argument address by one halfword, producing byte address 2.
- Clears the represented carry state.
- Adopts the updated continuation address.

The indirect write must not be specified as one sampled halfword reused twice.

One dereference of the old continuation supplies a 16-bit unsigned value used as the destination address. The other dereference supplies the halfword value to which 15 is added. The destination receives the latter sum truncated to 16 bits.

The representation does not establish:

- An evaluation order between those two dereferences.
- A single shared sample.
- Equality of the two sampled values.
- A particular number of underlying machine read transactions.

If the samples differ, the destination follows the address-producing sample and the stored data follows the value-producing sample. The resulting destination lies in the unsigned 16-bit address range; no validation is shown.

The base assignment and updated-continuation calculation precede this displayed write. Adoption of the updated continuation and the halfword-address increment follow it. Failure during the write does not establish completion of those later state changes.

### Why the later memory region is unreachable

The later region is not merely of uncertain reachability. Its entry gates are contradictory under the represented arithmetic.

Reaching the special transition requires:

- The initial derived address to be zero.
- Both shifted argument words to be zero.

The transition changes one shifted-argument address from zero to byte address 2. It does not change the still-zero initial derived address.

There are then two cases:

- **Updated continuation nonzero:** the first post-transition gate fails immediately.
- **Updated continuation zero:** the first comparison combines that zero continuation with the zero derived address and passes. The next comparison combines byte address 2 with the still-zero derived address. Its shift count is zero, so its result is 2, not zero. That gate fails.

Without the special transition, the post-transition chain is not enabled at all.

Therefore no execution through the supplied control flow reaches the later self-selected left shift, pointer load, paired stores, or final signed-data stores. This conclusion does not depend on rejecting address zero as inaccessible.

### Repeating dispatch

After the conditional regions, execution enters an unconditional loop. Each iteration performs:

1. F-08d5b44d70f0-D01 through the current continuation-derived address plus 3,766 bytes, with explicit 32-bit arguments `0`, `0`, and `0xffffffa5`.
2. F-08d5b44d70f0-D02 through the constant-derived target `0x08579c95 + 0x0cb6`, with no explicit arguments shown.
3. F-08d5b44d70f0-D03, software interrupt `0x5b`.
4. Replacement of the loop’s continuation base with `0x083d4cc2`.
5. Repetition.

The 3,766-byte displacement comes from a halfword-pointer offset of `0x075b`. The third argument’s bit pattern represents unsigned 4,294,967,205 or signed −91.

The first iteration uses the incoming continuation address unless the special transition updates it. The unreachable region cannot introduce further changes.

After an iteration completes through the fixed-base assignment, the next first-call target expression is `0x083d5b78`. These are represented address expressions, not validated executable entry points.

## Acceptance examples

These are conditional static expectations, not runtime results.

### Nonzero low byte

With second-argument low byte `0x01`:

- The initial copy is skipped.
- The special transition and later memory region are skipped.
- The first dispatch target is the incoming continuation address plus 3,766 bytes.
- If dependencies return or resume, the second call, interrupt, fixed-base assignment, and repetition follow in that order.

Low byte `0xff` selects the same branch category.

### Zero low byte, nonzero incoming continuation

Provided the copy addresses are accessible:

- A halfword is read from the incoming source.
- That sample is written at source plus the first auxiliary arithmetic word.
- The adjusted source becomes destination minus the address-adjustment word.
- The nonzero continuation prevents further entry into the initial zero-gated chain.
- Dispatch follows using the incoming continuation.

Higher argument bits do not change either truncated shifted product on this branch.

### Aliased initial copy

If the first auxiliary arithmetic word is zero, source and destination coincide. The represented observable sequence remains a halfword read followed by a halfword write of that sample.

### Distinct samples in the special write

Assume all special-transition gates pass and its memory accesses complete. If the address-producing dereference supplies `0x0010` and the value-producing dereference supplies `0x0020`, the halfword destination is byte address `0x0010`, and the stored value is `0x002f`.

This expectation does not prescribe which dereference occurs first or require that distinct samples be possible in ordinary stable memory.

### Rejection of the later stores

Even if hypothetical memory for the unreachable signed-halfword stage contains `0xffff`, no sign-extended `0xffffffff` store is selected by this representation.

After the special transition, either the updated continuation immediately fails its zero gate or the following address-2 comparison fails. Supplying accessible destinations cannot bypass that control-flow obstruction.

### Dependency does not return

If F-08d5b44d70f0-D01 does not return, the second call and interrupt are not reached during that iteration. If the interrupt does not resume, the fixed-base assignment and next iteration are not reached.
