## Behavior

1. It reads the 32-bit word at the input address.
2. It interprets that word as an address and reads a 32-bit value from the resulting location.
3. It adds the fixed byte displacement 56 to the second value to locate a target entry.
4. It reads the callable target from that entry.
5. It transfers control to the selected target.

Each address calculation depends on a preceding read. This establishes the logical dependency order, not an exact processor-level bus transaction sequence or a guarantee about speculative accesses.
