# F-f7b4970b2fc0

## Purpose

F-f7b4970b2fc0 performs preparation, measurement, conditionally repeated operations around an excluded central index, and finalization for a caller-supplied object.

A nonzero primary resource enables the measurement-and-traversal branch. Within that branch, the function computes an initial position, performs repeated operations before the central index, optionally operates on a separate central resource, advances past the central slot, and performs repeated operations after it.

**Inferred intent:** the arithmetic resembles positioning repeated elements within an available extent, with a distinguished central slot. Drawing, coordinate axes, and resource meanings are not established.

The function produces no explicit return value. Its observable behavior consists of dependency calls, their effects, object-field reads, and temporary-storage accesses. It makes no explicit assignment to the supplied object's fields.

## Behavior

### Unconditional preparation and position seed

Preparation occurs in this order:

1. F-bc9f8e2b0615 receives no explicit arguments.
2. F-a4c26c2b4842 receives the workspace address.
3. F-88dd67d704e5 receives the object address and workspace address.
4. F-412e4635fdb0 receives the object address and first measurement-region address.

After the fourth call returns, the function reads the first measurement region's signed value at `+4` and copies it into the first position element. This is the **position seed**.

Only then does the function test the primary resource against zero.

A zero primary resource skips the second measurement, centering, both traversals, the optional central operation, and every spacing advance. It does not skip preparation, the seed copy, or normal finalization.

### Initial centering

When the primary resource is nonzero at the gate, F-c24767c70ad0 receives the second measurement-region address.

After that call returns, centering uses these operands:

- **Index span:** the current last index minus the current first index.
- **Available extent:** the first measurement region's current `+12` value minus its current `+4` value.
- **Element extent for centering:** the second measurement region's current `+12` value minus its current `+4` value.
- **Nominal occupied extent:** the current gap multiplied by the index span, plus one more than the index span multiplied by the element extent for centering.

The adjustment is half of the available extent minus the nominal occupied extent. The function adds that adjustment to the first position element.

The position seed and the first measurement operands are read at different times. The seed is copied **before** F-c24767c70ad0. Both first-measurement operands used for centering are read **after** it. If that dependency changes the first measurement through an alias retained by an earlier dependency, the copied seed need not equal the later `+4` operand.

Consequently, the starting position is not unconditionally “the current lower extent plus the adjustment.” It is the earlier copied seed plus an adjustment calculated from the later measurement values.

The index span is a centering operand, not a calculated count of operations. No check establishes that the first, central, and last indices form an ordered interval. The first index is read again when the first traversal begins.

The source establishes sequencing across dependency calls and separate calculations. It does not establish a left-to-right order for individual operand reads within one arithmetic expression.

### Traversal before the central index

The function initializes a local traversal index from the first-index field.

While that signed index is less than the currently read central-index field, it:

- Calls F-bda93122a121 with the currently read primary resource, workspace address, and position-region address.
- Advances the first position element using measurement and gap values read after that call returns.
- Increments the local traversal index by one.

The central-index field is reread for every condition. The primary resource is separately read for every operation; passing the initial nonzero gate does not freeze its value. A later operation can therefore receive zero if the field changes.

Each advance uses the second measurement region's current `+12` value minus its current `+4` value, plus the current gap, added to the current first position element. Neither measurement operand nor their difference is explicitly cached across calls.

A repeated operation can therefore affect the immediately following advance by changing:

- The gap in the object.
- Either second-measurement operand through a retained alias.
- The first position element through the supplied position address.

The increment and the next condition follow the advance.

### Optional central operation and mandatory advance

After the first traversal ends, the function tests the current central resource.

If nonzero, it calls F-bda93122a121 with **two explicit arguments**: the central resource and workspace address. The resource argument is a separate field access from the zero/nonzero test. The supplied representation does not establish an explicit position argument for this call.

Whether or not the central operation occurs, the function then advances the first position element once. This advance rereads both second-measurement operands and the gap. If the central operation changes those values, the immediately following advance uses the changed values.

Thus, inside the enabled branch, an absent central resource omits the operation but does not remove the central slot's spacing advance.

No such advance occurs when the primary resource was zero at the initial gate.

### Traversal after the central index

After the mandatory advance, the function reads the central-index field into the local traversal index. This is a fresh read, not necessarily the value that ended the first traversal.

The local index is incremented before each upper-bound test. If the incremented signed index is less than or equal to the currently read last index, the function:

- Calls F-bda93122a121 with the current primary resource, workspace address, and position-region address.
- Advances the first position element using freshly read second-measurement operands and the current gap.

This repeats with another increment before the next test. The last-index field is reread for each condition. The final successful operation is followed by an advance even when no further operation occurs.

- All four preparation calls occur.
- The first measurement's `+4` value is copied into the position.
- F-c24767c70ad0 and F-bda93122a121 are not called.

### Ordered interval with a central resource

Assume a nonzero primary resource at the gate, first index `2`, central index `4`, last index `6`, first-measurement values `10` and `110`, second-measurement extent `10`, gap `2`, and nonzero central resource.

The index span is `4`. Nominal occupied extent is `58`, so the initial position is `31`.

Three-argument operations occur at positions `31` and `43` before the central operation. The two-argument central operation follows. After the mandatory advance, three-argument operations occur at `67` and `79`.

The position reaches `55` before the central operation, but that value is not established as an explicit argument to it.

### Same interval without a central resource

With the preceding inputs but a zero central resource, the two-argument operation is absent. The repeated-operation positions remain `31`, `43`, `67`, and `79`: the mandatory central-slot advance remains.

### Singleton interval

Assume the primary resource is nonzero at the gate, all three indices are equal, and the increment needed for the second traversal's initial test is representable.

Neither repeated traversal performs an operation. The optional central operation occurs if its resource is nonzero. The mandatory advance still occurs, and normal finalization follows.

With a zero primary resource at the gate, neither the central operation nor that advance occurs.

### First-measurement mutation after the seed copy

Suppose the seed is copied as `10`. During F-c24767c70ad0, the first measurement values become `20` and `110` through an available alias. Let the index span be `4`, gap `2`, and second-measurement extent `10`.

The later available extent is `90`; nominal occupied extent is `58`; the adjustment is `16`. The starting position is therefore `26`, using the earlier seed. It is not `36`, which would incorrectly substitute the later `+4` value for the seed.
