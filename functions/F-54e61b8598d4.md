## Acceptance examples

These are conditional static examples, not executed tests. They assume accessible memory, valid returning dependencies, and an address interpretation supporting the stated numeric addresses. Cases requiring low-32-bit arithmetic say so explicitly.

1. **Payload publication precedes consumption.** If F-0002 returns 3, address `0x20` receives the entry payload before F-0003 receives 12.

2. **Unsigned multiplication wraps.** For entry input `0x40`, the input-derived write targets `0x14` and stores zero. The later masked-input publication also stores zero.

3. **Masking excludes the high three bits.** For entry input `0x20000000`, the masked-input publication stores zero. It does not store the value obtained by simply shifting the unmasked input right by nine.

4. **Scaled write and reads differ.** If F-0017 returns 2, the write stores 8 at `0x34`, while both F-0018-associated reads address `0x1c`.

5. **Distinct reads need not agree.** If the read supplying F-0018’s first argument observes `0x12345000` and the read supplying its third observes 3, those arguments are `0x12345` and 12. This does not establish which read occurred first.

6. **Capture survives later memory changes.** If the pre-F-0048 read captures `0xabcdefff`, the F-0052-associated write stores `0x000abcde`, even if an intervening dependency changes the original memory.

7. **F-0058 uses two different projections.** If F-0052 returns 3, its retained fourfold value is 12 and F-0058’s first argument is `0x00030000`. Its third argument is `0xc0000000` only under a low-32-bit interpretation of the signed left shift; that result is not unconditional.

8. **Byte writes truncate independently.** If F-0067 returns `0x3ab00003`, the first byte write stores `0x0c` and the second stores `0xab`.

9. **Fresh selection and retained argument.** If the byte reads return 4 and 9 respectively, the writes target `0x15` and `0x1a`. F-0080’s second argument is 9, regardless of later changes to the byte source.

10. **Terminal boundary is not success.** Completing all displayed calls and reaching the invalid-instruction boundary does not satisfy a requirement for normal return or a success status.
