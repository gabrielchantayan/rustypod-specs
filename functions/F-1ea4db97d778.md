## Behavior

### Initial argument-dependent writes

Let \(n\) be the second argument’s 32-bit pattern. Define:

\[
p=W(n+7)
\]

\[
q=\operatorname{LSR}\!\left(W(\operatorname{ASR}(p,4)+5),25\right)
\]

\[
v=\operatorname{LSR}\!\left(W(q+p+n),25\right)
\]

The reduction before the final logical shift is significant: the calculation is not an unbounded-integer sum. The resulting \(v\) lies between 0 and 127.

The first stored word is:

\[
w=W\!\left(v-\operatorname{LSR}(p,19)\cdot2^{31}\right)
\]

The first observable memory operation is a 32-bit write of \(w\) at:

\[
W\!\left(\operatorname{ASR}(W(v\cdot512),11)+20\right)
=20+\left\lfloor v/4\right\rfloor
\]

Its starting address is therefore between `0x14` and `0x33`, inclusive. Alignment is not enforced.

Define the sign mask:

\[
m=W(\operatorname{ASR}(w,31))
\]

It is either zero or `0xFFFFFFFF`. The second observable memory operation writes the 32-bit value 13 at:

\[
W\!\left(\operatorname{ASR}(W(m\cdot2^{26}),21)+13\right)
\]

This destination is:

- `0x0000000D` when \(m=0\).
- `0xFFFFFFED` when \(m=\texttt{0xFFFFFFFF}\).

The sign of \(w\) is determined by bit 19 of \(p\). Multiplication by \(2^{31}\), reduced to 32 bits, retains only the parity of \(\operatorname{LSR}(p,19)\). Neither initial write is guarded by a validity, alignment, or range check.

### Fixed-word snapshots and displacement-based writes

After both initial writes, the function reads A, B, and C, in that order, as 32-bit values. Denote those snapshots by \(A_0,B_0,C_0\).

The shared displacement is:

\[

2\cdot\operatorname{ASR}
\left(W((\operatorname{LSR}(m,12)-83)\cdot64),1\right)-114
\right)
\]

\[
d=\operatorname{ROR}(t,t\bmod32)
\]

The two possible results are:

| Sign mask \(m\) | Intermediate \(t\) | Rotation count | Displacement \(d\) |
|---|---:|---:|---:|
| `0x00000000` | `0xFFFFEACE` | 14 | `0xAB3BFFFF` |
| `0xFFFFFFFF` | `0x03FFEA8E` | 14 | `0xAA380FFF` |

For the negative-sign case, the arithmetic is specifically:

\[
\operatorname{LSR}(\texttt{0xFFFFFFFF},12)=\texttt{0x000FFFFF}
\]

Subtracting 83 gives `0x000FFFAC`; multiplying by 64 gives `0x03FFEB00`. Arithmetic right shift by one followed by multiplication by two leaves this even value unchanged. Subtracting 114 gives `0x03FFEA8E`.

Both branches use rotation count 14, but their rotated displacements differ. No zero-count rotation case is reached.

The next memory effects are:

1. Read B again, then write that newly observed 32-bit value at \(W(r12+0x380+d)\).
2. Write the low 16 bits of \(C_0\) at \(W(d+B_0)\).

The second B read supplies the first write’s value; the earlier snapshot \(B_0\) supplies the second write’s address. These observations are not interchangeable if B changes between reads.
