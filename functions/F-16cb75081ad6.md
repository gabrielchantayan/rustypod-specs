# F-16cb75081ad6

## Purpose

F-16cb75081ad6 selects one of two fixed byte values according to whether its second input is zero, writes that value at a fixed displacement from the address represented by its first input, and returns the fixed value 1.

The established behavior is a single-byte state update. The meaning of that state, the identity of the surrounding object, and the interpretation of the return value are not established. In particular, describing the stored values as named modes or interpreting the return as a success indicator would be inferred intent rather than demonstrated behavior.

The function has two integer-valued inputs and a four-byte return value.

| Component | Contract |

| First input | Represents a base address used to locate the destination byte. It is not dereferenced at the base itself. |
| Second input | A selector tested for equality with zero. Zero and nonzero are the only distinguished classes. |
| Destination | The byte at displacement 116 decimal, or 0x74, from the represented base address. |
| Stored value | 5 when the selector is zero; 6 otherwise. |

The supplied representation declares both inputs using an integer type but does not independently establish that type’s width, the pointer width, or the calling convention. A 32-bit input ABI is plausible, but is not a portable requirement established by this fragment alone.

The first input is an address carrier, not an ordinary numerical identifier. For normal completion, its use in the address calculation must produce a valid writable byte location under the target execution model.

## Behavior

### Selection

The function compares the second input with zero.

- A selector equal to zero selects the byte value 5.
- Every selector unequal to zero selects the byte value 6.

There is no separate treatment for positive versus negative selectors, no recognized range of nonzero values, and no validation branch for an unsupported selector.

The comparison is against the integer input as represented by the interface. No narrowing to the low byte is shown. Consequently, a nonzero selector whose low byte happens to be zero still selects 6, provided that selector is representable by the input type.

### Destination calculation and write

The destination is formed by adding 116 to the first input’s address-bearing value and treating the result as the address of a one-byte writable location.

Exactly one direct memory write is shown. It replaces the destination byte with the selected value. The prior byte value is not read, compared, merged, incremented, or otherwise used.

The write is unconditional with respect to the prior state. Even when the destination already contains the selected value, the represented behavior still includes the write. The function is therefore value-idempotent for repeated calls with the same valid address and selector class, but that does not establish that repeated writes are unobservable in every execution environment.

The represented access does not update adjacent bytes. No larger object layout is supplied, and no meaning can be assigned to other displacements.

### Completion

After the destination write, the function returns 1 in its four-byte result.

The result does not vary with:

- Which selector class was used.
- The previous destination value.
- Whether the selected value differs from the previous value.

There is no represented alternate return, explicit error code, exception handler, or recovery path.

The fixed return does not guarantee completion for an invalid address. If address calculation or the write cannot execute normally, the fragment does not establish a returned value.
