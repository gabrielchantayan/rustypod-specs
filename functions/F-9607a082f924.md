## Behavior

1. The wrapper stores the third argument in the first temporary word.
2. It stores the fourth argument in the following temporary word.
3. It invokes F-9d500e3cf762 with the address of the first temporary word and a fixed static reference.
4. It takes the 32-bit result of that invocation and invokes F-bd3e46af741a with that result as the first argument and a 32-bit zero as the second argument.
5. It saves the 32-bit result of F-bd3e46af741a.
