# F-4252a04930ed

## Purpose

No application-level purpose is established. The supplied representation does not support identifying this routine as a parser, allocator, serializer, or conventional returning API.

## Behavior

### Initial path selection

When the low nibble of \(A\) is nonzero, the routine skips both the initial transfer and the exceptional prefix. It proceeds toward the repeating tail with \(L\) as the initial call-target base.

When the low nibble is zero, it performs the initial halfword transfer before evaluating the remaining exceptional-path gates.

Skipping the prefix does not make the routine effect-free: its tail still invokes dependencies and issues an interrupt.

### Initial halfword transfer

The represented memory-access order is:

1. Read a 16-bit value from \(B\).
2. Write that value as 16 bits at \(B+Y\).

The displacement \(Y\) is in **bytes**, not halfword elements.

Between the represented read and write, the routine computes an updated internal address:

\[
B' = B+Y-Z \pmod{2^{32}}.
\]

This computation does not dereference \(B'\), and it does not change the pending store destination. The destination remains \(B+Y\).

The source and destination may coincide. If \(Y=0\), the represented operation remains a read followed by a write to the same location. This contract does not authorize dropping the write when access events are observable.

No bounds, null-address, alignment, or permission checks are represented. Completion requires a readable halfword at \(B\) and a writable halfword at \(B+Y\), subject to the environment’s access rules.

### Exceptional-prefix eligibility

After the initial transfer, a chain of gates controls an additional prefix containing both a machine-state assignment and a halfword store.

Under the 32-bit modular model, reaching that prefix requires:

\[
\begin{aligned}
&A \mathbin{\&} 15=0,\\
&L=0,\\
&S \mathbin{\gg} 1=0,\\
&X=Y,\\
&B'=Z,\\
&T=0,\\
&S+2Y=0 \pmod{2^{32}}.
\end{aligned}
\]

The shift of \(S\) is logical. Multiplication by two retains only 32 bits before its result participates in the final addition. A high bit discarded by that multiplication is not an additional carry input.

The earlier zero-result gates eliminate the incoming carry contribution to the addition involving \(T\), so the relevant condition is \(T=0\).

The stack-address conditions imply:

\[
S=0,\qquad Y\in\{0,\;0x80000000\}.
\]

Specifically, \(S\mathbin{\gg}1=0\) restricts \(S\) to zero or one, while \(2Y\) is even; their modular sum cannot be zero when \(S=1\).

These are arithmetic eligibility conditions, not evidence that a real execution environment permits this path. An ordinary nonzero stack address would exclude it.

### Exceptional machine-state assignment

The exceptional prefix first assigns the value

\[
64S \pmod{2^{32}}
\]

to \(Q_{54}\), the special slot identified by offset `0x54`.

Because eligibility forces \(S=0\), the assigned value is zero under the working model.

This is an **explicit machine-state mutation**. It must not be omitted from the contract merely because the value is statically determined, or because the slot might already contain zero. No read of the previous slot value is represented.

The assignment is ordered:

- After the initial halfword transfer and the successful eligibility gates.
- Before the exceptional halfword expression’s address-producing and value-producing evaluations.
- Before the exceptional halfword store and the repeating tail.

The slot’s architectural identity is unresolved. The representation does not establish whether this is an ordinary register update, a privileged operation, an address-space change, or another special-state operation. It also does not establish whether assigning zero permits execution to continue normally. All later exceptional-path behavior is conditional on continuation after this assignment.

### Exceptional halfword store

After the special-slot assignment, the represented prefix computes a replacement link-associated base:

\[
L' = L+64S \pmod{2^{32}}.
\]

The factor of 64 accounts for both the displayed element offset and the two-byte halfword element size. Eligibility makes \(L'=0\).

The additional memory expression uses:

- A halfword evaluated at the incoming address \(L\) to form the destination address.
- A halfword evaluated at that same incoming address \(L\) to form the stored value.

The address-producing halfword is zero-extended to 32 bits. The value-producing halfword has 15 added, with the stored result reduced to 16 bits.

The representation contains two halfword evaluations but does not establish their relative evaluation order or the number of distinct machine loads. For changing or memory-mapped storage, the contract must not assume they observe the same value.

If the evaluations produce \(h_{\mathrm{address}}\) and \(h_{\mathrm{value}}\), respectively, the effect is a 16-bit store at numeric address \(h_{\mathrm{address}}\) of:

\[
(h_{\mathrm{value}}+15)\bmod 2^{16}.
\]

For stable memory containing \(h\), this simplifies to storing \((h+15)\bmod 2^{16}\) at address \(h\).

Since eligibility requires \(L=0\), these source evaluations refer to address zero. The destination need not be halfword-aligned. A halfword with its high bit set becomes an address in the range 32768–65535; it is not sign-extended.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

### Prefix bypass

Given \(A=\texttt{0x00000001}\):

- No initial halfword transfer occurs.
- No exceptional write to \(Q_{54}\) occurs.
- No exceptional halfword store occurs.
- The first indirect target is \(L+\texttt{0xEB6}\), modulo \(2^{32}\).
- If the iteration completes, the next iteration’s first target is `0x083D5B78`.

### Byte-displaced transfer

Given \(A=\texttt{0x00000010}\), \(B=\texttt{0x2000}\), \(Y=4\), and \(L\ne0\), with valid accesses:

- A halfword is read at `0x2000`.
- The read value is written at `0x2004`, not `0x2008`.
- The exceptional machine-state assignment and store are excluded by \(L\ne0\).

### Source and destination alias

Given a zero low nibble and \(Y=0\), the initial transfer reads and writes \(B\). For an observable memory region, suppressing the write would not preserve the represented access behavior.

### Exceptional state write followed by store

Given:

- \(A=0\).
- \(L=S=X=Y=T=0\).
- \(B=\texttt{0x2000}\).
- \(Z=\texttt{0x1000}\).
- Successful initial transfer.
- A special-slot assignment that permits normal continuation.
- Stable readable halfword `0x1234` at address zero.
- Writable halfword storage at `0x1234`.

Then \(B'=Z\), and the exceptional gates succeed. The required order is:

1. Complete the initial transfer.
2. Assign zero to \(Q_{54}\).
3. Evaluate the exceptional halfwords at address zero.
4. Store `0x1243` at `0x1234`.
5. Reach the first loop call at numeric target `0x00000EB6`, provided intervening execution succeeds.

This example neither assumes an ordinary process permits address-zero access nor resolves the special slot’s architecture.

### Halfword wraparound

Under the same gates and continuation assumptions, stable halfword `0xFFFA` at address zero produces a store of `0x0009` at address `0x0000FFFA`.

The preceding assignment of zero to \(Q_{54}\) remains required.

### Interrupted exceptional progress

If the special-slot assignment prevents continuation, the later exceptional memory expression and loop are not required to occur. The earlier initial transfer has already been represented as complete.

If F-UNKNOWN-01 does not return, the second call and interrupt of that iteration are not reached. No status return is required.
