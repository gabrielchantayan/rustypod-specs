Register-based arguments, an implicit receiver, or imperfect recovery of the calling convention remain unknown. No such argument should be added to the established contract without further evidence.

The final read occurs after the call. If the callee initializes or modifies the returned storage before returning, the function reads the storage as it exists at the subsequent read. The evidence does not establish synchronization with other threads or protection against concurrent modification.

## Acceptance examples

These examples are conditional contract checks, not executed tests.

1. **Successful value extraction.** Given valid input storage, a valid selected callable, and a normal return pointing to storage containing the 32-bit value 42, the function returns 42.

2. **Returned address differs from returned contents.** Given a callee result that points to readable storage containing zero, the function returns zero. It does not return the address of that storage.

3. **Exact displacement selection.** Given distinct callable entries at nearby table locations, the entry beginning 64 bytes from the recovered base is selected. Entries before or after that location are not substitutes.

4. **Callee writes before returning.** Given a callee that writes a four-byte value into valid storage and then returns that storage’s address, the final read obtains that value, provided no intervening modification changes it.

5. **Lookup mutation during the call.** Given a callee that changes the original input storage or table entry and then returns a valid result address, the visible function proceeds to read that returned address. It does not perform another lookup or invocation.

6. **Uninterpreted high bit.** Given readable result storage containing a bit pattern with its most significant bit set, the function returns that four-byte pattern without a visible sign check or error classification.

7. **Invalid returned address.** Given a normal callee return that cannot be dereferenced for four bytes, the successful-return preconditions are not met. No particular recovery behavior is specified.
