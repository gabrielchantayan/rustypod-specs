### Unchanged input

### Unbounded-by-byte E

If the undeclared 0x05 global has a 32-bit unsigned value of 0x00000100, E is 0x00000100 and the subsequent explicit byte store uses address 0x00000115, assuming valid arithmetic and mapping.

If that global instead has a signed 8-bit value of −1, its unsigned 32-bit conversion yields 0xFFFFFFFF under the represented integer conversion model—not 255. The supplied material does not select either declaration.

### Assignment value versus access width

Conversely, the explicit store at E + 0x15 is byte-wide regardless of the width used to obtain E.

### Rereads and aliasing

If an intervening computed store changes the 0x67 global’s storage, a later evaluation must use the then-current object value. Explicit byte destinations receive its narrowed value, not an assumed cached copy of G.

### Retained arguments

If N + 0x74 overlaps R + 0x54, Z reflects the read after the decimal-100 store, subject to byte order and access semantics.

### Partial failure
