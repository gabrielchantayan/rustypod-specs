# F-58391f1bdb4e

## Purpose

F-58391f1bdb4e coordinates a fixed sequence of indirect dependency calls, transfers selected values between memory locations, updates shared state, and finally attempts an invocation at address zero.

The established behavior is the ordering of those effects and the distinction between retained values and later memory observations. No application-level purpose is established. In particular, the visible operations do not establish allocation, object construction, serialization, resource release, or successful shutdown.

This contract describes the supplied static representation. Every later effect is conditional on execution reaching it: a nonreturning dependency, invalid access, or calculation outside the represented arithmetic’s defined domain can prevent subsequent effects. No runtime tests have been performed.

## Acceptance examples

These are conditional static examples, not executed tests. Unless an example explicitly isolates a calculation, preceding dependencies must return, accesses must be valid, and preceding arithmetic must be defined.

1. **Fourth-input extraction.** A fourth input of `0xFF800000` supplies 511 as F-003’s third argument. A fourth input of `0x007FFFFF` supplies zero.

2. **Fresh repeated observation.** If the first-base source word initially has low byte `0x12`, and an intervening dependency changes that source to have low byte `0xA5`, the two corresponding byte stores contain `0x12` and then `0xA5`.

3. **Full-word retention.** With saved word `0x12345678`, its immediate byte store contains `0x78`. Both subsequent saved-word stores contain `0x12345678`, even if the original source changes after capture.

4. **Distinct destination strides.** A result of 3 from F-026 selects address 68 for its saved-word store. A result of 3 from F-035 selects address 32 for the later saved-word store.

5. **Index-derived argument.** With index 5, scaled index is 20 and F-027 receives `0x00050000`. In isolation, index 32768 produces scaled index 131072 and an F-027 argument of `0x80000000`. A signed left shift by 16 is not a valid substitute for that unsigned calculation. The latter example is not a defined end-to-end execution: F-013’s earlier signed shift by 18 exceeds the represented signed range.

6. **Captured address, delayed contents.** If the address-slot observation yields 1000, the later payload read uses address 1020 regardless of subsequent slot changes. Changes to memory at 1020 before the payload read can change payload word.

7. **Byte-selected destination.** If saved word logically shifted right 23 bits equals 5, and address 6 contains byte 9 when observed, the first payload-derived byte is written at address 26.

8. **Non-byte-aligned extraction.** Payload word `0x3FC00000` supplies `0xFF` for the second payload-derived store. This is extraction of bits 22 through 29, not an ordinary byte-aligned field.

9. **Selector aliasing.** If both selector observations choose the same destination, the second payload-derived store is the later direct store there. Additional dependency writes may occur between them.

10. **Terminal interruption.** A fault at the implicit-pointer byte clear occurs after the result-slot assignment but prevents the subsequent halfword clear and F-082 from being reached through this sequence.
