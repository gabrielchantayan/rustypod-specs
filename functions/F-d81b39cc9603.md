# F-d81b39cc9603

## Purpose

F-d81b39cc9603 calls an initial dependency, conditionally invokes a second dependency for a non-null object, and returns an unsigned 32-bit bitwise intersection.

Its result has three forms:

- **Null object:** the initial dependency’s result masked to its lowest eight bits.
- **Non-null object, zero indicator byte:** the initial dependency’s result masked by a 32-bit object field.
- **Non-null object, nonzero indicator byte:** the constant 7 masked by that object field, after the second dependency returns and the indicator byte is cleared.

The object field is read after the conditional processing. In particular, the active-indicator path clears the byte at offset 30 **before** reading the 32-bit field at offset 24.

**Readiness: documented_only.** The local control flow, access widths, call arguments, and return calculation are statically established. Dependency semantics, complete object requirements, and the provenance of two additional dependency arguments remain unresolved. No runtime tests have been performed.

## Behavior

### Initial call

F-8685dec604a9 is called once before the local null-object decision and before any direct object-field access.

It receives the first five explicit inputs in their original order. Its 32-bit return becomes the initial result.

The function does not inspect the indicator or cache the mask field before this call. Consequently, changes that the dependency makes to valid object storage can affect both the subsequent branch decision and the eventual mask value.

### Null-object path

If the first input is zero, the function uses 255 as the mask and returns the initial result intersected with that mask.

On this path:

- F-a061acf353ed is not called.
- There is no direct read or write through the object reference.
- Bits 8 through 31 of the returned value are zero.

These statements describe the function’s own accesses. They do not constrain accesses or side effects performed by F-8685dec604a9.

### Non-null object with a zero indicator

After the initial dependency returns, the function reads the byte at offset 30.

If the byte is zero:

1. The second dependency is skipped.
2. The function reads the 32-bit field at offset 24.
3. It returns the intersection of that field and the initial result.

There is no direct write to the indicator on this path. The mask field is not restricted to its lowest byte or lowest three bits.

### Non-null object with a nonzero indicator

Every nonzero byte selects the active path; the byte need not equal 1.

The function calls F-a061acf353ed with six arguments, in this order:

| Position | Supplied value |
|---|---|
| First | The object reference |
| Second | The 32-bit constant 7 |
| Third | The 32-bit constant 0 |
| Fourth | The sixth explicit input to F-d81b39cc9603 |
| Fifth | An additional 32-bit ambient value whose origin is not established |
| Sixth | Another additional 32-bit ambient value whose origin is not established |

The dependency’s return value, if any, is not used in the local return calculation.

Following normal return from that call, the locally established sequence is:

1. The result contribution becomes the constant 7 instead of the initial result.
2. The function writes zero to the one-byte indicator at offset 30.
3. The function reads the 32-bit mask field at offset 24.
4. It returns the mask field intersected with 7.

The observable object-access order is therefore **second dependency call, indicator clear, mask-field read**. There is no local mask-field read between that dependency call and the clear.

The second dependency executes before the explicit clear. It is not established that the dependency sees the same indicator value that selected the branch: its own behavior and any external mutation remain unknown. If it changes the indicator and returns normally with valid storage, the subsequent local write still stores zero.

Likewise, a mask-field change by the second dependency can affect the result because the function reads that field afterward. This does not imply that every dependency-side change survives other activity before the read.
