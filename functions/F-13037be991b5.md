# F-13037be991b5

## Behavior

### Required observable ordering

On a normally completing invocation, the function performs these operations in order:

1. Calls F-338d16f9ce72 with the address 20 bytes beyond the base.
2. Reads the integer field beginning 16 bytes beyond the base.
3. Calls F-1333331b2da1 with the address 20 bytes beyond the base.
4. Returns whether the value captured by the read was nonzero.

There is one explicit field read. There is no explicit field write and no second read after F-1333331b2da1 returns.

Both dependency calls receive the same derived address value. Their order is fixed, and the read lies between them.

### Captured-value semantics

The Boolean result depends on the value obtained at the intervening read, not necessarily the field’s value at function entry or function return.

If F-338d16f9ce72 changes the field before returning, that change may affect the subsequent read.

If F-1333331b2da1 changes the field after the read, that change does not alter the already captured value used for the result. Consequently, the returned Boolean may disagree with a later observation of the field without violating this function’s established behavior.

These statements describe the explicit value flow. They do not establish that either dependency actually changes the field or that concurrent access is valid.

- A positive nonzero value produces true.
