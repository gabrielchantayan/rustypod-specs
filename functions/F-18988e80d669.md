# F-18988e80d669

## Purpose

F-18988e80d669 performs a straight-line sequence of indirect calls, indexed word writes, byte-selected writes, field copies, and shared-state updates. Its final operations clear a dependency-supplied byte, replace a shared word, clear a computed halfword, and attempt a call to address zero.

No application-level purpose is established. Indexed-storage and field-propagation interpretations are plausible, but the available evidence does not establish an initializer, allocator, serializer, dispatcher, or cleanup operation.

This contract describes static behavior only. Completion requires all reached calls to return and all reached memory accesses to succeed. Low-address accesses, unresolved calling conventions, and implicit incoming machine state prevent an unconditional successful-return guarantee.

## Interface

### Explicit input and output

The represented interface accepts one 32-bit input word. Its first dependency receives that word.

The represented return type is void. There is no explicit returned value. A return follows the final zero-address call and is reached only if that call returns.

### Implicit inputs

Behavior also depends on:

- An incoming link-related value that determines the first call target by addition of 3896.
- An incoming unsigned 32-bit selector used in an early address calculation.
- An incoming saved 32-bit payload used by the first explicit store.
- Primary and secondary results from dependencies, including indices, words, paired result words, a byte, and a byte pointer.
- **Shared word A**, read twice at separate execution points.
- **Shared word B**, written twice.
- **Shared upper bytes C**, supplying 24 bits for the final replacement of shared word B.
- Memory at computed addresses, including repeated reads of the byte at absolute address 1.

Initialization, accessibility, and validity of these inputs are not established.

## Behavior

### Execution and dependency ordering

The visible body has no conditional branches or loops. The following sequence applies while execution continues normally.

“Ordinary call” means a call in dependency family F-00000002. A call with no represented arguments is still observable; it is not assumed argument-free at the machine interface or free of side effects.

A “result-forwarding pair” means two ordinary calls: the first produces a word, and the second receives that word. Additional arguments are identified where present. Call counts below exclude calls already described immediately before them unless expressly included.

Dependencies can modify memory between explicit operations. Captured values remain the values used by the represented subsequent expressions; later reads are separate observations.

### 1. Initial indexed write

F-00000001 receives the explicit input.

A result-forwarding pair follows, then four ordinary calls; the fourth returns an index. The function:

1. Writes the incoming saved payload to that index’s indexed slot.
2. Reads a word at \(20 + (\text{incoming selector} \gg 22)\).
3. Makes an ordinary call receiving four times the returned index.

The read offset is not multiplied by four. It ranges from 0 through 1023 and may produce an unaligned word address.

### 2. Initial word propagation and first shared read

Four additional ordinary calls follow; the fourth returns a second index.

The function retains the early loaded word shifted right by one. It writes the second index shifted left by two into the indexed slot selected by that shifted word. It then reads another word at 20 plus the original, unshifted early word.

F-00000003 receives the right-shifted selector.

A result-forwarding pair and four additional ordinary calls follow; the fourth returns a third index. The function:

1. Writes the second index shifted left by two into the third index’s indexed slot.
2. Reads shared word A.
3. Makes an ordinary call receiving four times the third index.

The newly loaded word and captured shared word A are retained for subsequent extraction. The read following the first store in this stage must occur after that store, including when addresses overlap.

### 3. Upper-bit extraction and zero stores

Exactly **four additional ordinary calls** follow the index-consuming call at the end of stage 2.

The function then:

1. Shifts the second loaded word right by 22, obtaining a retained value in 0–1023.
2. Shifts the captured shared word A right by 23, obtaining a retained value in 0–511.
3. Writes the 0–1023 value into the indexed slot selected by a secondary dependency result.
4. Calls F-00000003 with that secondary result twice, the 0–511 value, and the 0–1023 value.

An ordinary call produces a word. Before forwarding it to the next ordinary call, the function shifts the 0–511 value right by another 23 bits. This produces zero under the represented unsigned 32-bit arithmetic.

Four more ordinary calls follow the forwarding call; the fourth returns an index. The retained 0–1023 value is written into its indexed slot.

Next, an ordinary call receives four times that index, followed by four additional ordinary calls. A secondary result selects an indexed slot that is cleared with a zero word. F-00000003 then receives that secondary result.

The four-call interval at the beginning of this stage does not include the index-consuming call already described in stage 2.

### 4. First byte-selected update

A result-forwarding pair and four additional ordinary calls follow; the fourth returns an index.

The function writes zero into its indexed slot. The written expression is the retained 0–511 value shifted right by another 23 bits.

It then reads a word at:

\[
20 + ((\text{secondary index retained in stage 3}
\mathbin{\&} \texttt{0x1fffffff}) \gg 19).
\]

An ordinary call receives four times the newest index, followed by four additional ordinary calls.

The newly read word is shifted right by 22, producing another retained value in 0–1023. The function reads the byte at absolute address 1 and writes the low byte of that shifted value at address 17 plus the byte read.

F-00000004 receives a secondary result three times and a fourth argument of zero.

The byte store truncates the 0–1023 value to eight bits. Subsequent address calculations retain its full value.

### 5. Byte clearing and saved intermediate results

One ordinary call follows, then an ordinary call receiving zero, then four additional ordinary calls; the fourth returns an index.

The function reads a byte at:

\[
1 + 4 \times \text{the retained 0–1023 value from stage 4}
\]

and clears the byte at address 17 plus the byte read.

An ordinary call receives the newest index shifted left by two. Four additional ordinary calls produce another index, and the next ordinary call receives that index shifted left by two twice.

An ordinary call then returns a word, which is forwarded to another ordinary call. One additional ordinary call follows.

The function rereads the byte at absolute address 1 and clears the byte at address 17 plus its value. A secondary result is retained, and F-00000004 receives that result three times.

Each byte-selected destination is in the inclusive range 17–272. The byte value is used directly as an address offset; it is not a word-sized pointer read.

### 6. First shared publication and repeated field copies

A result-forwarding pair follows. Its second call additionally receives the stage-5 returned word shifted right by 23.

Four additional ordinary calls produce an index. The function reads the byte at absolute address 1, retains it as a base, and clears the byte at base plus 17. An ordinary call receives the index shifted left by two.

Four additional ordinary calls produce another index. The next ordinary call receives that index shifted left by two twice.

A following ordinary call returns a 32-bit word. The function writes it to shared word B **before** forwarding it to another ordinary call. One additional ordinary call follows.

The function reads a word at retained base plus 116 and writes its low byte at retained base plus 1.

F-00000005 receives the stage-5 saved secondary result shifted left by 11. An ordinary call returns a paired result; the next ordinary call receives its low word, its high word, and the word previously published to shared word B shifted right by 23. That last argument uses the captured word, not a fresh read of shared word B.

Four additional ordinary calls produce an index. Four times that index becomes a new retained base. A word at base plus 116 is read, and its low byte is written at base plus 1.

An ordinary call receives this base. Four additional ordinary calls produce another index, whose value shifted left by two is retained as a 32-bit quantity.

The preceding base’s word at offset 116 is read again, and its low byte is written again at offset 1. Intervening calls separate these two copies; they are not one read reused twice.

F-00000006 receives:

- The stage-5 saved secondary result shifted left by 12.
- The newest retained scaled index twice.
- The newest unscaled index shifted left by 18.

### 7. Complete-word propagation and slot clearing

An ordinary result-producing call is followed by F-00000007 receiving that result.

A result-forwarding pair and four additional ordinary calls produce an index. At four times that index, the function reads the word at offset 116, retains the complete word, and writes its low byte at offset 1.

An ordinary call receives this scaled base, followed by four additional ordinary calls producing another index. The complete retained word is written to that index’s wide-stride slot.

F-00000008 receives the stage-6 retained scaled index logically shifted right by two, then left by 16. The earlier left shift may already have discarded high bits; an equivalent interpretation must retain that width constraint.

An ordinary call produces a result consumed by F-00000009. A result-forwarding pair and four additional ordinary calls produce an index. The retained complete word is written into its indexed slot.

An ordinary call receives four times that index. Four additional ordinary calls produce another index. Its value shifted left by two is written at:

\[
20 + (\text{stage-6 retained scaled index}
\mathbin{\&} \texttt{0xfffffffc}).
\]

F-00000008 receives the newly shifted index twice.

Another ordinary result is consumed by F-00000009. A result-forwarding pair and four additional ordinary calls produce an index whose indexed slot is cleared.

### 8. Paired-result propagation and final byte-selected writes

An ordinary call receives four times the just-cleared slot’s index. Four additional ordinary calls follow; the fourth returns a paired result.

Its low word shifted left by two becomes a retained payload. Its high word selects an indexed slot, into which the payload is written.

The function rereads shared word A. An ordinary call then receives the payload, the paired result’s high word, the payload, and the payload.

Exactly **four additional ordinary calls** follow that four-argument call; the fourth returns another index. The same payload is written into its indexed slot. The function then reads a word at 20 plus the newly captured shared word A.

An ordinary call receives four times the newest index. Four additional ordinary calls follow; the fourth returns another paired result.

The function:

1. Reads a byte at \(1 + (\text{complete word retained in stage 7} \gg 23)\).
2. Writes the low byte of the word most recently read through shared word A at address 17 plus that byte.
3. Calls F-00000004 with the latest paired result’s high word three times and its low word shifted left by two.

A result-forwarding pair and four additional ordinary calls produce another index.

The function reads a byte at:

\[
1 + ((\text{latest paired result’s low word}
\mathbin{\&} \texttt{0x3fffffff}) \gg 21).
\]

At address 17 plus that byte, it writes the low byte of the word loaded through shared word A shifted right by 22.

### 9. Final publication, clearing, and terminal call

An ordinary call receives the newest index shifted left by two. Four additional ordinary calls produce another index, whose value shifted left by two is passed twice to an ordinary call.

One further ordinary call follows. F-00000010 then produces a word, which an ordinary call receives. The next ordinary call returns a byte and exposes a secondary byte pointer.

The explicit final effects occur in this order:

1. Zero is written through the secondary byte pointer.
2. Shared upper bytes C are used with the returned byte to replace shared word B: the byte occupies bits 0–7 and C supplies bits 8–31.
3. A zero halfword is written at
   \[
   (\text{stage-8 latest paired result’s low word}
   \mathbin{\&} \texttt{0x3fffffff}) \gg 7.
   \]
4. F-00000011 is called at address zero with three zero arguments.
5. The function returns only if that call returns.

The halfword address ranges from 0 through 8,388,607 and need not be aligned. If the pointer clear overlaps C, the subsequent composition uses C after that clear.

## Acceptance examples

These are conditional static consequences, not runtime tests.

1. **Unscaled early offset:** With incoming selector `0xFFC00000`, the early word read is at address 1043, not 4112.

2. **First corrected call boundary:** After the ordinary call consuming four times the third index in stage 2, exactly four additional ordinary calls precede stage 3’s extraction and secondary-indexed store. Requiring five additional calls would change the observable sequence.

3. **Guaranteed zero:** Any unsigned 32-bit shared word A, shifted right by 23 and then by 23 again, yields zero.

4. **Truncation versus retained width:** If stage 4’s extracted value is `0x3AB`, its byte store writes `0xAB`; the subsequent byte-read address is \(1 + 4 \times \texttt{0x3AB} = 3757\).

5. **Fresh field read:** If an intervening dependency changes the retained base’s offset-116 word, stage 6’s second copy uses the changed word’s low byte.

6. **Second corrected call boundary:** After the stage-8 call receiving payload, high word, payload, and payload, exactly four additional ordinary calls precede the next indexed payload store.

7. **Final composition and aliasing:** If the returned byte is `0x5A` and C supplies `0x123456` when sampled after the pointer clear, shared word B receives `0x1234565A`. C’s value before that clear is insufficient if the storage overlaps.

8. **Terminal fault:** If address zero cannot be called, normal return is not established. No represented recovery reverses preceding writes.
