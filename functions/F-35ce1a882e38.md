## Behavior

The function first evaluates the integer stored at the input pointer.

If that value is zero, the function returns zero. In this case:

- No indirect field is read through that zero base.
- F-cd52fcefba54 is not called.
- No explicit memory write occurs.

This short-circuit behavior is part of the contract. In particular, callers cannot rely on the dependency being invoked for every call.

### Indirect argument acquisition

If the initial comparison finds a nonzero value, the function proceeds to obtain the dependency argument.

The supplied expression accesses the input pointer’s target again when forming the indirect address. It does not explicitly save the first observed base value for later use. At the source-expression level, the sequence therefore includes an initial base evaluation for the condition and another base evaluation for the address calculation.
