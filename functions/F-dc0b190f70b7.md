# F-dc0b190f70b7

## Purpose

Its observable behavior includes propagating input values, retaining selected call results, computing scaled addresses, extracting bit fields, and performing two byte stores whose destinations depend on bytes read from memory.

The supplied static representation does not establish an application-level purpose. In particular, it does not establish that the function allocates objects, serializes data, manages references, or constructs a particular data structure.

## Acceptance examples

These are conditional static criteria, not executed tests. Required calls must return, addresses must be valid, and signed calculations must have defined behavior or an explicitly adopted machine interpretation.

1. **Initial propagation.** With first input `0x12345678` and \(T_1=3\), the first word store writes `0x12345678` at address 32. F-ext-003 subsequently receives 3.

2. **Unsigned payload scaling.** With \(P=1\), the payload-derived store writes `0x04000000` at address `0x10000014`; F-ext-013 receives `0x04000000`.

3. **Mask before extraction.** With \(P=\texttt{0xffffffff}\), the word stored at \(W(T_3)\) is `0x000fffff`, not `0x007fffff`.

4. **Distinct locations.** With \(T_4=2\), the wide-slot store writes 8 at address 52. Both reads for F-ext-023 address 28. The stored 8 is not a substitute for those reads.

5. **Independent reads.** If the read supplying F-ext-023’s first argument observes `0x12345000`, that argument is `0x00012345`. If the separate third-argument read observes `0x40000001`, its shifted value is 4. This criterion imposes no order between the two reads.

6. **Retained sample.** A sampled word of `0xabcdefff` produces `0x000abcde` at \(W(T_{11})\), even if F-ext-053 later changes the sampled memory.

7. **Byte selection.** Given a first selector of 5 and final word `0x02b00003`, the first byte store writes `0x0c` at address 22. If the fresh second selector is 9, the second byte store writes `0x2b` at address 26. F-ext-085 receives 9 as its second argument.

8. **Complete-path effects.** If the entire represented path completes through its terminal marker, it includes fourteen explicit word stores and two byte stores. A thirteen-word-store trace omits an established effect.

9. **Interrupted execution.** If any dependency fails to return or a memory access faults, subsequent events are not required. Earlier completed effects are not specified to be undone.
