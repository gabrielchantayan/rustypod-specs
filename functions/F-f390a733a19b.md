## Acceptance examples

### Global conversion is not a byte load

If the declared global at 0x05 evaluates to a value whose unsigned 32-bit conversion is 0x1234, the global-derived base is 0x1234, not 0x34. Its +0x54 access is explicitly 32-bit even though the source global’s access width remains unresolved.

### Promoted arithmetic at 0x3A

If the character conversion of the adjusted seed yields 0x20, the assignment expression yields 0x130. An eight-bit global declaration could narrow that to 0x30; a compatible wider declaration could retain 0x130. The supplied material does not select between them.

If the declared anchor source overlaps storage modified by the 0x60 assignment, anchor capture still occurs first.

If the declared 0x3A destination overlaps secondary base +0x14, the retained word read follows that assignment. Exact changed bytes require the missing declaration and byte order.

### Independent 0x67 evaluations

If intervening effects change the 0x67 global, each subsequent evaluation uses its own observed value. The first follows the secondary-base +0x44 word read and supplies the 0x21 assignment. The second and third separately supply eight-bit adjusted-base +9 stores.
