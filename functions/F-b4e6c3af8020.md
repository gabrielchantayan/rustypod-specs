When that input is zero, the operation returns without performing the indirect transfer shown in the supplied representation. When it is nonzero, the operation transfers control through an unresolved indirect destination, supplying the second input, the third input, and the fixed numeric value 24, in that logical argument order.

This contract describes the supplied static representation, not verified machine-level behavior.
