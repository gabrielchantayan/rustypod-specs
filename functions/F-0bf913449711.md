# F-0bf913449711

## Purpose

F-0bf913449711 transforms three integer coordinate pairs into five pairs within the same supplied storage. It preserves the first pair, replaces the second and third pairs, and fills two additional pairs.

The established behavior is an ordered sequence of integer reads, additions, divisions by two, and writes. Each coordinate is processed independently, and the first coordinate is fully processed before the second.

The result resembles midpoint subdivision of three control points. That geometric interpretation is **inferred intent**, not an input requirement. The function does not check whether the integers describe coordinates, a curve, or any other geometric object.

Integer rounding is part of the behavior. The central output pair is calculated from two intermediate pairs that have already undergone integer division; it is not calculated by rounding a single weighted expression over the original inputs.
