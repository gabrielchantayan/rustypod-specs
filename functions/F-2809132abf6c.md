## Behavior

### First iteration

The routine begins the loop immediately; there is no preliminary condition that can skip the first iteration.

The visible ordering is:

1. Obtain the shifted value from the current unsigned 32-bit register-associated state.
2. Set that associated state to zero.
3. Issue the coprocessor-related operation using the already-derived value.

The reset therefore precedes the operation attempt. The payload is nevertheless derived from the state that existed before the reset. An implementation that resets the state before deriving the first payload would not match the represented behavior for inputs whose upper 21 bits are nonzero.

The right shift removes the low 11 bits. Its arithmetic interpretation is unsigned division by 2,048 with the fractional part discarded. Because the input is unsigned and the shift count is 11, the result lies between zero and 2,097,151 inclusive.

Consequences include:

- Input bits 0 through 10 do not affect the first payload.
- Input bits 11 through 31 become payload bits 0 through 20.
- Payload bits 21 through 31 are zero.
- A set input bit 31 does not cause sign extension.
- There is no rounding, saturation, or multiplication.
- The shift count is within the width of the represented input.

The derived value remains represented as a 32-bit unsigned quantity even though at most 21 bits are significant.
