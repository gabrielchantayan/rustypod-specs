## Purpose

Four explicit 32-bit arguments are insufficient to determine its behavior: incoming execution state, external storage, and repeatedly sampled memory also supply addresses and data.

**Established static evidence:** The supplied representation contains byte, halfword, and word accesses; truncated address fragments; signed-byte conversions; carry-dependent arithmetic; and a final indirect transfer with three arguments. It establishes no explicit return value, validation path, or rollback.

**Inferred intent:** Repeated offsets and linked addresses suggest interconnected records. They do not establish a particular data structure, ownership model, or application purpose. Some accesses instead use zero-extended bytes, signed-byte-derived values, or executable addresses as numeric address components.

This contract specifies observable effects and ordering where described. It is not an exhaustive access-by-access trace of the entire body. ## Behavior

### Widths and arithmetic

Bytes are 8 bits, halfwords 16 bits, and words and represented address values 32 bits. Narrow stores retain only the corresponding low-order bits.

Unsigned-byte reads yield values from 0 through 255. Signed-byte reads are sign-extended before subsequent conversions or arithmetic. Converting a negative signed byte to unsigned 32-bit form produces a large unsigned value; it does not zero-extend the original byte.

Unsigned 32-bit arithmetic and explicit carry detection must retain their width. Unsigned expression results wrap modulo \(2^{32}\). The actual target’s effective-address formation, alignment rules, and fault behavior are not established. Expressions presented as signed arithmetic must not be replaced silently with unbounded integer arithmetic or an invented overflow policy.

The initial right shift uses the low eight bits of the first-context base as its count. A later shift uses a loaded word both as the signed shifted operand and as the source of a low-eight-bit count. Another shift operates on a sign-extended byte. Counts can therefore exceed 31. The target behavior for such counts and the exact signed-right-shift semantics remain `documented_only`; masking counts to five bits is not established.
