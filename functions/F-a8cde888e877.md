# F-a8cde888e877

## Purpose

The supplied static representation describes a state-mutating routine that passes 32-bit values through unresolved calls, computes addresses from returned values, and performs interleaved byte and word writes. Its application-level purpose is **documented_only**: the evidence does not establish initialization, allocation, serialization, cleanup, or any other named operation.

The observable shape is a long, apparently straight-line sequence. It includes repeated writes at offsets `0x14`, `0x24`, and `0x44`, byte-selected writes at offset `0x11`, and four explicit zero writes to address `0x24`. These patterns do not establish a conventional object layout.

This contract describes the behavior represented by the supplied material, conditional on that representation being accurate. The material reports invalid instruction data and overlapping global symbols; consequently, it does not establish a complete executable function or a valid normal return.

\]

It stores \(S\) at \(W(16 \times \text{second index} + 0x14)\), then passes \(S\) to another unresolved call.

A following no-argument call produces a word that is forwarded to another call. Four no-argument calls then produce a third index.

Define:

### 2. Publish and dereference another scaled index

### 3. Store the third input and establish retained state

### 4. Perform byte-selected writes and clears

Four no-argument calls produce a retained result \(R\).

The routine reads a byte at \(W(B+1)\), adds `0x11` to that zero-extended byte, and writes:

\[
L((U \mathbin{\&} 0x3FFFFFFF) \mathbin{\gg} 20)
\]

to the selected byte address.

The mask and shift can produce ten bits; the byte write retains only eight. Thus bits 20–27 of \(U\) determine the stored byte. Bits 28–29 do not survive the narrowing.

It then:

- Calls a dependency with \(W(4R)\).
- Obtains a result from a no-argument call and forwards it.
- Executes four no-argument calls, retaining the last result.
- **Rereads** the byte at \(W(B+1)\), then writes zero at the newly selected address plus `0x11`.
- Calls a dependency with four times the retained result.
- Executes four no-argument calls.

The reread matters: intervening calls may change which byte address receives zero.

Next it writes zero at \(W(Q+0x0F)\). Define:

\[
C = W(1024Q)
\]

It reads a byte at \(W(C+1)\) and writes zero at that byte’s value plus `0x11`.

A call then receives four arguments: three copies of \(W(R \ll 23)\), followed by \(W(R \ll 25)\). A no-argument result is forwarded to another call, after which four no-argument calls produce another index.

The routine rereads the byte at \(W(C+1)\), retains this byte value, and writes zero at its value plus `0x11`. After a call with four times the latest index and four further no-argument calls, it uses the **retained byte**, without another explicit read, to select a word-store address:

- Zero word at retained-byte value plus `0x44`.

All byte-selected addresses plus `0x11` lie between `0x11` and `0x110`. Those selected plus `0x44` lie between `0x44` and `0x143`. This range does not imply that the addresses are valid or aligned.

## Acceptance examples

These examples are conditional static acceptance criteria, not runtime observations.

1. **Second-input preservation.** If the first result used as an index is `3`, the corresponding word store targets `0x20` and contains the second input’s complete 32-bit pattern.

2. **Different scaling formulas remain distinct.** If the fourth index is `2`, the routine writes `8` at `0x34`, then reads a word at `0x1C`. Reusing the stored value in place of the read would not match the represented behavior.

3. **Masked value calculation.** If \(S=0xFFFFFFFC\), the value stored as \(H\) is `0x1FFFFFFE`, not the result of shifting the unmasked word.

4. **Narrowing after a high-bit extraction.** If \(U=0x3FF00000\), the first high-bit byte write stores `0xFF`, not a ten-bit quantity.

5. **Fresh selection after calls.** If the byte at \(B+1\) initially equals `2` but an intervening dependency changes it to `7`, the first selected write targets `0x13`; the later zero write targets `0x18`.

6. **Retained selection remains retained.** If the byte retained from \(C+1\) is `5`, the later zero-word store targets `0x49`, even if a dependency changes memory at \(C+1\) before that store.

7. **Repeated clears remain observable.** For volatile or externally observed memory, the four explicit zero stores to `0x24` are four ordered events. Replacing them with one store is not justified.

8. **Low-byte multiplication.** If \(V=0x41\), the associated byte write stores `0x04`, while the call argument \(W(4V)\) is `0x104`.

9. **Partial failure.** If an unresolved dependency fails after the second-input store, the contract does not require that store to be undone or any later store to occur.
