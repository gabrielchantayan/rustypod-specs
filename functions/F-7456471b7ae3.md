## Acceptance examples

These examples are conditional requirements, not executed tests.

- **Entry:** For input 1, where the entry invocation is valid, F-D001 receives 256. Input zero supplies zero but does not visibly bypass later operations.
- **Paired results:** A result with low word 1 and high word 0x12345678 supplies 0x100 and 0x12345678 where the next pattern shifts the low word eight and retains the high word.
- **Width:** An explicit byte read returning 0xff becomes word value 255 when zero-extended. A byte store supplied 0x12345678 writes only 0x78.
- **Fixed base retention:** If the read at 0x05 yields 0x80, subsequent accesses based on that retained value use offsets from 0x80 even if an intervening overlapping store changes storage at 0x05.
- **Global ordering:** If the global read yields one base and the later address-0x60 store overlaps its storage, the repeated region still uses the retained base, not a reload after the overlap.
- **Final read placement:** If the write at address 0x3a overlaps a subsequently read word at doubled-table offset 0x14, that read observes the post-write storage under the target memory model.
- **Fresh 0x67 reads:** With ordinary stable storage and no overlap, writing low byte 0xab from the retained 0xa9 word makes the following 0x67 read supply 0xab to address 0x21. If an intervening derived store later changes 0x67 to 0xcd, the subsequent offset-9 store uses the later read’s value, not necessarily 0xab.
- **Failure:** A nonreturning dependency prevents later operations. An invalid address that faults after successful stores provides neither rollback nor a returned failure status.
