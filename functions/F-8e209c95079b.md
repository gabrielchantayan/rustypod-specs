# F-8e209c95079b

## Purpose

F-8e209c95079b dispatches an operation using a descriptor containing a 32-bit object reference and an 8-bit selector. It returns a 32-bit unsigned result.

The established operations are:

- **Selector 1:** subtract two 32-bit fields in the referenced object and derive a quotient using a scale of 40.
- **Selector 2:** call F-e84094e554a6 without explicit arguments and return its unsigned 32-bit result logically shifted right by one bit.
- **Other selectors, or a zero object reference:** return zero without calling either dependency.

For selector 1, differences with a clear high bit produce the unsigned quotient divided by 40, rounded down. Differences with a set high bit undergo magnitude conversion and quotient calculation, followed by sign handling whose exact meaning is unresolved because the supplied representation contains a signed 32-bit value shifted by 32 positions.

This contract distinguishes established static behavior from inferred intent and unresolved details. No runtime tests have been performed.
