# F-81533b18b43b

## Purpose

F-81533b18b43b rearranges twelve bytes in place within a sixteen-byte region identified by a caller-supplied base address. It performs a fixed permutation of three consecutive four-byte groups:

- Offsets 4–7 rotate left by one byte.
- Offsets 8–11 rotate left by two bytes.
- Offsets 12–15 rotate right by one byte.

Offsets 0–3 are not accessed by the supplied function body. All offsets in this contract are decimal and relative to the supplied base address.

The established behavior is a byte permutation, not a numeric transformation. Byte values are copied without arithmetic modification. The supplied evidence does not establish an application-level purpose, data format, or algorithm to which this permutation belongs.

### Intermediate states

The transformation is incremental, not transactional. For example, immediately after the first write, offset 4 contains the value read from offset 5, while offset 5 has not yet been overwritten. At that point, the original offset-4 value is retained temporarily rather than remaining in the addressed region.

After the first rotation completes, offsets 4–7 have their final values while offsets 8–15 have not yet been accessed. After the two exchanges complete, offsets 4–11 have their final values, and the final rotation is still pending.

The final-state table assumes that reads return the corresponding original bytes. If another actor changes storage during execution, later reads can observe those changes; the body does not provide a whole-region snapshot.
