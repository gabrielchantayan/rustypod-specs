# F-f5fe2123a01b

## Purpose

F-f5fe2123a01b repeatedly invokes unresolved indirect dependencies and performs ordered byte and 32-bit memory accesses. Dependency results determine addresses, published values, control bytes, and state retained for the next traversal.

The established behavior is this invocation-and-memory schedule. A device-control or transfer-management purpose is plausible but unproved.

The represented body has no normal return, error result, or loop-exit condition. If every dependency returns and every access succeeds, execution continues indefinitely.

## Interface

### Inputs and outputs

The represented declaration has no explicit arguments or result. Nevertheless, execution consumes implicit entry state:

- An incoming return-link value used to construct the first setup call target.
- A 32-bit control word.
- An address-like value used for selector-byte reads.
- A 32-bit carried word used in the opening dependency argument.
- Additional return-register state consumed late in each traversal.
- A directly referenced global 32-bit word.
- Dependency results, including 32-bit words and paired 32-bit halves.

An ordinary no-argument invocation is not established as sufficient to provide this context.

Outputs comprise indirect invocations, byte stores, 32-bit stores, and retained state. Dependency effects are additional, unknown outputs. There is no explicit output object.

### Widths and notation

A **word** is a 32-bit bit pattern. A **selector** is an unsigned byte, zero-extended for address formation. A **paired result** supplies low and high 32-bit halves of a represented 64-bit result.

The following descriptive terms identify data roles, not implementation identifiers:

- **Seed**, **control word**, **carried word**, and **selector base** are traversal-entry state.
- **Extraction** means masking a word with 0x3FFFFFFF and shifting it right by 20: bits 20–29.
- **Control destination** means selector + 0x11.
- **Word slot** for a selector word means four times that word + 0x14.

Narrowing an extraction to a byte retains original bits 20–27, not all ten extracted bits. A control destination lies between 0x11 and 0x110 inclusive. A byte-selected word destination, selector + 0x14, lies between 0x14 and 0x113 inclusive.

All formulas below describe represented arithmetic. Conclusions requiring overflow or discarded high bits are conditional on 32-bit truncating machine arithmetic. The representation also contains signed arithmetic and signed left shifts; portable signed-overflow semantics are not established.

### Preconditions and failures

Uninterrupted execution requires valid executable indirect targets, sufficient calling-context state, and accessible storage for each indicated width. Some word accesses can be unaligned; the body supplies no alignment correction or validation.

No local error reporting, recovery, rollback, timeout, or cleanup path is visible. A nonreturning dependency prevents subsequent local operations. After a fault, later operations cannot be assumed.

Computed addresses may alias. Word stores may overlap control bytes, selectors, or global storage. Dependencies may modify any of these between accesses. Consequently:

- Fresh selector reads cannot be replaced by earlier values.
- Captured selectors and the global snapshot remain captured where specified.
- Repeated stores remain observable even when writing the same value.

## Acceptance examples

These are conditional criteria, not executed tests.

1. **Opening target transition.** If setup and one complete traversal return normally, the first F-c001 uses the setup continuation plus 0xFC4. The second uses the retained terminal continuation plus 0xFC4. Target equivalence must not be assumed.

2. **Invocation preservation.** Between the first payload’s initial store and its second store, the sequence is F-c013 with four arguments, then F-c014, F-c015, F-c016, and result-producing F-c017. None may be omitted because its effects are unknown.

3. **Complete schedule.** An uninterrupted first traversal is preceded by three setup invocations and contains 146 traversal invocations. Later traversals repeat the 146-position schedule without repeating setup.

4. **Control narrowing and fresh selection.** If the opening selector is 0x20 and the control word is 0x3FF00000, the byte store writes 0xFF at 0x31. If dependencies change the selector to 0x40 before the opening clear, that clear targets 0x51.

5. **First publication.** If the seed is two and F-c012 returns three, the first payload is twelve and its initial destination is 0x8014. This arithmetic does not overflow.

6. **Captured selection.** If the captured selector is 0x30, the deferred word publication targets 0x44 even if intervening calls change the selector in memory.

7. **Unaligned extracted read.** If extraction of the extraction source is one, the word read targets 0x15. No represented operation rounds it to an aligned address.

8. **Clear order and parity.** Each retained-base clear pair writes offset 0x11 before offset 1. Under truncating arithmetic, the parity-derived word publication is zero for an even parity selector and 0x80000000 for an odd one.

9. **Interruption and continuation.** A dependency that never returns prevents later local operations. If all calls return and accesses succeed, the final schedule proceeds into another traversal rather than returning normally.
