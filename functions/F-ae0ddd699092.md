## Behavior

Narrow stores retain the relevant low-order bits:

The following order is established by the supplied body. It describes the visible access sequence, not independently verified hardware transaction ordering or volatile semantics.

   Write the low 8 bits of the record base. There is no preceding read of the destination byte.

    Read its 32-bit value after the preceding constant store. An overlap with that store can therefore affect the captured value.

    Read its 32-bit value after the second external word has been captured.

13. **Store the byte 0x44 at byte-derived value plus 0x44.**

15. **Store a halfword at fourth explicit argument plus second external word.**

    The three visible outgoing argument values, in order, are:
    - The byte-derived value bitwise-ORed with 0x44.
