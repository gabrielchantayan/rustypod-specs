## Behavior

### Traversal gate

The traversal begins at the captured base and advances numerically by four until its current value equals the traversal endpoint. Equality is tested before an increment, so equal base and endpoint values require no increments.

The traversal body has no operations. In particular:

- No represented element is dereferenced.
- No callback is made for an element.
- No element is destroyed or initialized.
- No field is cleared or advanced.
- The number of traversal steps is not supplied to the dependency.

For a stable endpoint and representable arithmetic, the traversal terminates when the endpoint is reachable from the base by a nonnegative number of increments of four. In a 32-bit signed model, every increment taken must remain within the signed 32-bit range.

A smaller endpoint is not reached by ordinary increasing signed arithmetic without overflow. An endpoint whose difference from the base is not a multiple of four is likewise not reached before overflow. These cases have no established successful result. Because the represented operations are signed, wrapping must not be assumed as a recovery mechanism.

The traversal does not compare its current value with the extent endpoint. It therefore does not establish that the traversal endpoint lies inside the extent used for the dependency call.

### Dependency argument construction

Once traversal completes, the extent endpoint is read and the retained base is subtracted from it. The subtraction result is then shifted right by two bit positions.

The resulting arguments to F-ff1bdc376dcd, in order, are:

1. The retained base value.
2. The extent-minus-base result after the right shift.
3. The integer value zero.

For a nonnegative, representable difference, the second argument is the integer quotient obtained by division by four, discarding any remainder. The function performs no divisibility check. Thus a difference of 18 produces a quantity of 4 under the ordinary signed integer model.

The function does not first widen the subtraction in the supplied representation. Overflow cannot be made safe merely because a later shift would reduce the result’s magnitude.

For a negative difference, signed right-shift behavior depends on the target’s arithmetic semantics. An arithmetic right shift would round toward negative infinity in the corresponding division interpretation, rather than toward zero for negative values not divisible by four. The supplied evidence does not independently establish that target rule.

The dependency is called even when the derived quantity is zero. There is no local special case for an empty extent, a zero base value, or equal descriptor fields.
