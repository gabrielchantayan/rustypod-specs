# F-dc499b746c92

## Purpose

F-dc499b746c92 computes a start-and-count pair from two supplied signed integers and two conditionally available boundary values stored in an input object. It writes the result through two caller-provided output addresses and has no explicit return value.

The established behavior is asymmetric. Depending on the stored boundaries and the supplied start, the function can:

- Return the supplied interval unchanged as an inclusive start-and-count pair.
- Return a portion preceding one stored boundary.
- Return a portion following another stored boundary.
- Return the sentinel pair **start = −1, count = 0**.

**Inferred intent:** the function appears to select a portion of an inclusive interval relative to an existing interval or occupied region. That interpretation is not required by the contract. In particular, the function neither verifies boundary ordering nor consistently rejects reversed supplied intervals. Its count can be negative.

## Behavior

### Input reads and boundary availability

The function first reads B from object offset 0x2D4.

Only if B is nonnegative does it read A from offset 0x2CC. If B is negative, the A field is not accessed.

Stored boundaries are considered available for the conditional selection behavior only when **both B and A are nonnegative**. If either is negative, the function uses the fallback calculation described below.

There is no requirement or check that A be less than or equal to B.

### Selection rules

The following rules are ordered. The first applicable rule determines both outputs.

| Condition | Selected start | Selected count |
|---|---:|---:|
| B is negative | S | (E − S) + 1 |
| B is nonnegative and A is negative | S | (E − S) + 1 |
| A and B are nonnegative, and S or E is negative | −1 | 0 |
| A and B are nonnegative, S and E are nonnegative, and S = A | −1 | 0 |
| A and B are nonnegative, S and E are nonnegative, and A < S ≤ B | B + 1 | E − B |
| A and B are nonnegative, S and E are nonnegative, and S < A ≤ E | S | A − S |
| Any remaining case | S | (E − S) + 1 |

The final row includes two important cases with nonnegative boundaries and endpoints:

- S is greater than A and also greater than B.
- S is less than A, but E is also less than A.

### Fallback calculation

The fallback result is:

- Selected start: S.
- Selected count: (E − S) + 1.

This treats E as an inclusive endpoint when ordinary interval arithmetic is meaningful. It does not check that E is at least S.

When stored boundaries are unavailable, the fallback applies even if S or E is negative. Negative endpoints are rejected only when both stored boundaries are nonnegative.

The subtraction is performed before the addition of one. Representability of the final mathematical count alone is therefore insufficient to establish defined signed arithmetic: the intermediate E − S must also be representable.

### Selection after B

When A < S ≤ B, with both boundaries and both supplied endpoints nonnegative, the result is:

- Selected start: B + 1.
- Selected count: E − B.

There is no additional requirement that E exceed B or even that E be at least S.

Consequences include:

- E = B produces count zero.
- E < B produces a negative count.
- E > B produces a positive count.
- B at the maximum signed value makes B + 1 overflow under the signed 32-bit model.

The function does not replace a zero or negative count from this branch with the sentinel pair.

### Selection before A

When S < A ≤ E, with both boundaries and both supplied endpoints nonnegative, the result is:

- Selected start: S.
- Selected count: A − S.

This count is strictly positive and representable under the signed 32-bit model: both operands are nonnegative, and A is strictly greater than S.

If S < A but E < A, the function instead returns the fallback result. It does not return a zero count simply because the requested endpoint lies before A.

### Sentinel result

The pair **(−1, 0)** is selected when both stored boundaries are nonnegative and either:

- At least one supplied endpoint is negative; or
- The supplied start equals A.

The equality case does not depend on whether E reaches A, provided E has already passed the nonnegative-endpoint check.

The supplied material does not establish any external meaning for this sentinel. Consumers must not assume that every zero count uses this pair, or that every negative start indicates this branch: fallback processing can also return a negative start.

### Output order

After selecting the two result values, the function:

1. Writes the selected start to the start-output address.
2. Writes the selected count to the count-output address.

All object reads and result calculations precede these writes. The function has no explicit return value.
