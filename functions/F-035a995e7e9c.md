## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Early byte publication.** With argument 4 equal to 171, successful execution through its early publication writes 171 to C’s offset-17 byte. Later overwrites do not remove that event from the required behavior.

2. **Captured payload narrowing.** If the initial argument-1 offset-100 read yields `0x123456AB`, the associated early anchor offset-13 write stores `0xAB`. A later change to the original word does not change that already captured payload.

3. **Fresh reads remain fresh.** If an intervening write changes a later offset-100 source through aliasing, the later read uses its then-current contents. Reusing the first captured value is not generally acceptable.

4. **Signed-short addressing.** A short bit pattern of `0xFFFF` contributes minus one to an address sum. Successful access still requires that resulting address to be valid.

5. **Byte-derived ambiguity.** For a loaded byte with bit pattern `0xFF`, address formation remains conditional on plain-byte signedness. This contract does not select either minus one or 255 without additional evidence.

6. **Partial-word overlap.** An offset-21 byte store changes only that byte of overlapping storage. It can affect a later offset-20 word read; the resulting numeric word depends on byte order.

7. **Transient replacement.** If C’s offset-84 field temporarily receives a word captured from another region’s offset 4, observing that intermediate value is compatible with the contract even when a later store restores C’s own address.

8. **Unknown early byte.** Two invocations with otherwise identical established inputs are not required to publish the same pre-assignment byte unless their unexplained entry state also agrees.

9. **Indirect dependency does not return.** F-cdec09f5d432 and the terminal operation are not reached through the visible path. Earlier mutations are not promised to be reversed.

10. **Both calls return.** If all earlier accesses succeed, the indirect dependency precedes F-cdec09f5d432, followed by the terminal non-returning operation. A normal return is not an accepted completion of this represented path.

11. **Inaccessible derived address.** No error result or rollback is specified. The actual failure mechanism belongs to the execution environment.
