### 3. First context-selected byte store

Next, the function:

2. Adds 17 to that byte’s numeric value.
3. Writes the low byte of the scaled value at the resulting address.

The read byte is an address component, not the contents of a pointer-sized field. The resulting write address is between 17 and 272 inclusive, before any platform-specific address translation.

Under 32-bit arithmetic, the byte written is four times the packed value’s low six bits, reduced to eight bits. It is therefore one of 0, 4, 8, …, 252.

### 4. Second context-selected byte store

F-dep-13 and F-dep-14 are invoked, followed by F-dep-15. The result of F-dep-15 supplies the first scale operand.

The function then performs a fresh unsigned-byte read at context base plus 1. It adds 17 to that newly read value and writes a byte derived from the original packed value.

The written byte is obtained by:

- Clearing the packed value’s highest two bits.
- Shifting the remaining value right by 20.
- Retaining the lowest eight bits.

Consequently, the stored byte contains bits 20 through 27 of the packed value. Bits 28 and 29 can survive the shift but are discarded by the byte-sized store; bits 30 and 31 are removed before the shift.

The context byte is reread rather than reused. The two context-selected writes need not target the same address: intervening dependencies may modify the context byte or relevant memory.
