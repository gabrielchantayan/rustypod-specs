2. **Third-argument width.** For third argument `0xffffffff`, the later four-argument call receives `0x0003ffff` as its fourth argument. This follows from two logical shifts by seven, not a signed shift.

3. **Word-record arithmetic.** If a record-producing dependency returns 3, recording it writes the 32-bit value 12 at numeric address `0x44`, provided that access is valid. This does not establish a structure at that address.

4. **Selector addressing.** If the byte loaded from selector index plus one is `0xa0`, the corresponding byte-store destination is `0xb1`. It is not selector index plus `0xb1`.

5. **Byte truncation.** If first byte-phase result is `0x00000043`, its shift-left-by-two value is `0x0000010c`; the first byte-phase store writes `0x0c`.
