# F-f33c4b5d095a

The sequence then proceeds as follows:

### 2. Distribution of the next paired result

The following explicit accesses occur in order:

2. Store a word at the current ambient base plus `0x26C`. Its value is the low word logically shifted right by 26 bits.

### 3. Fixed halfword read and breakpoint

## Acceptance examples

These are conditional static acceptance requirements, not executed tests. Each assumes the relevant operations are reached and that the stated values apply.

1. **Shared target, different interaction.** If **F-d05** returns low word `0x10` and high word `0x20`, **F-d06** calls the same target address with explicit arguments `0x10` and `0x30`. Shared target identity does not permit merging these occurrences.

2. **Paired-word shifts.** If **F-d09** returns low word `0xFC000001`, the ambient-relative word store at offset `0x26C` writes `63`. The later captured-pointer-relative store at offset `0x54` writes `0xF0000004`.

3. **Breakpoint boundary.** If execution stops at breakpoint `0x92`, the preceding explicit operations have occurred, assuming no earlier interruption. The record-address read and later stores have not occurred in that iteration. Persistence of earlier stored values is not implied.

4. **Fixed pointer read.** After continuation, the second-pointer read uses `0x2218`, regardless of the retained record address.

5. **Table address and contents.** With captured table base `0x12345678` and **F-d19** result `3`, the table write targets `0x12345684` and writes halfword `0x5678`, not `3` or `12`.

6. **Zero-extension.** A copied halfword of `0xABCD` produces word stores of `0x0000ABCD` at record offsets `0x54` and `0x64`. Intervening calls prevent an unconditional claim that both values subsequently coexist unchanged.

7. **Selector-derived accesses.** A record selector of `3` gives the low-word store address `0x80` and byte-source address `15`. With copied halfword `7` and byte-destination base `0x1000`, the byte destination is `0x1020`.

8. **Ambient-base transition.** If the ambient base is `0x1000` at the phase-5 store and remains unchanged until the explicit reduction, that store targets `0x1258`, and the reduction produces `0x0F0C`.

9. **Repetition.** If every call returns, all accesses complete, and the breakpoint resumes, **F-d37** is followed by another iteration rather than a normal return.
