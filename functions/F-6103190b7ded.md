# F-6103190b7ded

## Purpose

F-6103190b7ded compares selected bits of a caller-supplied 32-bit value with selected bits of a 32-bit value obtained indirectly through the first argument. A shared mask selects the bits participating in the comparison.

The function returns the 32-bit numeric value **0** when the masked values are equal and **3** when they differ.

The established behavior is a masked comparison. Any higher-level meaning—such as compatibility, permission, validity, or success—is unknown. In particular, the return value 3 is not established as a conventional error code.

## Behavior

### Established comparison rule

Let:

- **C** be the candidate value.
- **S** be the unsigned 32-bit value read from the field at offset 56.
- **M₁** be the mask value used with C.
- **M₂** be the mask value used with S.

The function returns 0 when **(C AND M₁) = (S AND M₂)**. Otherwise, it returns 3.

When the shared mask is stable throughout evaluation, M₁ and M₂ are the same value, M. Under that condition, the rule simplifies to:

**Return 0 exactly when C and S agree at every bit position selected by M; otherwise return 3.**

Bits not selected by a stable mask cannot affect the result. Equality of the complete inputs is therefore sufficient but not necessary for a return value of 0.
