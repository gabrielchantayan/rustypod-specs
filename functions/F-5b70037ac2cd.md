### 3. Pending mode: remembered-pair check

When the entry pending byte is nonzero, the function reads offset 0xA3.

If that byte equals the captured entry pending byte, it reads the current input byte and offset 0xA4 and compares them. If the first comparison fails, this second comparison is not needed.

A remembered-pair match therefore requires:

- The captured entry pending byte equals the observed byte at offset 0xA3.
- The observed input byte equals the observed byte at offset 0xA4.

On a match, the function writes zero to offset 0xA3, then zero to offset 0xA4, then zero to offset 0xA2, and returns. No dependency is called on this path.

The input and remembered second byte are both unsigned 8-bit values for this comparison. The caller’s third input cannot alter the outcome.

- Offset 0xA2 receives a freshly read input byte when the no-pending classifier sequence accepts it.
