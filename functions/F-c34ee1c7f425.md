# F-c34ee1c7f425

## Purpose

F-c34ee1c7f425 describes a fixed sequence of twelve indirect calls, with one explicit byte read and one explicit byte write between the fifth and sixth calls. Two call results are transformed into arguments for later calls. The byte read also becomes an argument to the eleventh call.

No higher-level purpose is established. The available representation does not justify classifying this operation as initialization, dispatch, decoding, device access, or memory management.

The supplied static representation carries an invalid-instruction warning and ends at a truncated control-flow boundary. Consequently, this contract distinguishes behavior represented before that boundary from behavior of the underlying executable, which has not been verified. A successful ordinary return is not established.

### Explicit byte read

The read has width one byte. Its address is the implicit address-bearing value plus one.

The byte is interpreted as unsigned, so its numerical value is in the inclusive range 0 through 255. There is no visible multibyte decoding, sign extension, indexing scale, or alignment requirement beyond what the platform imposes for a byte access.

The representation shows one such read. It does not show another read of that location before F-indirect-11. The later argument to F-indirect-11 therefore uses the retained byte value, rather than a visibly refreshed value.

### Explicit byte write

The write destination is the byte’s numerical value plus 17. It is not shown as an offset from the read address or from the explicit input.

The destination range is therefore 17 through 272 inclusive, or 0x11 through 0x110. This addition cannot overflow a 32-bit integer because its largest result is 272.

The stored bit pattern consists of bits 22 through 29 of the implicit 32-bit unsigned value:

- The value is shifted right logically by 22 positions.
- The resulting value is narrowed to one byte.
- Original bits 30 and 31 do not survive that narrowing.
- Original bits 0 through 21 do not contribute.

The intermediate narrowing is represented using a character-sized type whose signedness is unspecified. That uncertainty does not change the low eight bits written.

The read precedes the write. If the write destination aliases the read location, the destination is still selected using the byte obtained before the write.

The unusually low destination range is a property of the supplied representation, not proof that those addresses are mapped, writable, or intended device registers.

### Shifted call arguments

The results of F-indirect-05 and F-indirect-10 are each represented as 32-bit signed integers and shifted left by two positions before use as call arguments.

For a nonnegative result no greater than 536,870,911, the shift corresponds to multiplication by four without exceeding the positive range of a signed 32-bit integer.

For negative results or larger positive results, a portable signed-arithmetic interpretation is not established. A fixed-width machine instruction might retain only the low 32 bits, but the supplied representation alone does not prove that interpretation. Overflowing or negative-result cases are therefore **documented_only**, not assigned a guessed wrapping contract.

The byte argument to F-indirect-11 is widened without sign extension. For example, a retained byte of 255 becomes the unsigned numerical argument 255, not −1.

## Acceptance examples

These examples are conditional specification checks, not reports of execution.

### Defined positive-result path

Assume every call returns normally, all accesses are permitted, the implicit unsigned value is 0x00400000, and the explicit byte read yields 3. Assume F-indirect-05 returns 7 and F-indirect-10 returns 9.

The represented behavior requires:

- F-indirect-01 receives the original input unchanged.
- After F-indirect-05, the byte value 1 is written to address 20.
- F-indirect-06 receives 28.
- F-indirect-11 receives 36 as its first argument and unsigned 3 as its second argument.
- F-indirect-12 is reached after F-indirect-11 returns.
- No conclusion about ordinary completion follows from reaching the final boundary.

### Byte endpoints

If the read byte is 0, the write destination is 17 and F-indirect-11’s second argument is 0.

If the read byte is 255, the write destination is 272 and F-indirect-11’s second argument is 255.

These conclusions require reaching the relevant operations, but do not depend on signed-character interpretation.

### Stored-bit selection

With implicit unsigned value 0x3FC00000, the stored byte is 255.

With implicit unsigned value 0xC0000000, the stored byte is 0. Its set bits occupy positions discarded by narrowing after the right shift.

These examples distinguish extraction of bits 22–29 from extraction of the most significant byte.

### Retained byte and aliasing

Assume the read address is 20 and the read obtains 3. The selected write destination is also 20.

If the write succeeds, it may replace the byte just read. Nevertheless, F-indirect-11’s second explicit argument remains 3 in the represented data flow, even if the stored byte differs. No intervening reread is shown.

### Failure before continuation

If F-indirect-05 does not return, the wrapper does not reach its explicit byte read.

If the explicit read faults without resuming, the write and later calls are not reached. If the write faults without resuming, F-indirect-06 is not reached.

No error return value or recovery sequence is specified for these cases.
