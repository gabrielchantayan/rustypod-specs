# F-1a67aaf8a529

## Purpose

F-1a67aaf8a529 specifies an ordered sequence of memory accesses involving four explicit inputs, an implicit pointer, fixed storage, and the address values of two dependencies.

**Established static evidence:** the supplied representation contains no ordinary dependency call and no normal return. A sign-dependent branch and the end of the continuing path reach invalid-instruction markers. The representation also reports invalid instruction data and overlapping global storage.

The contract describes represented accesses and their partial effects. It does not establish that every access can execute successfully or that the entire sequence corresponds to valid machine instructions.

**Inferred intent:** some stores resemble initialization and construction of self-addressing records. That resemblance does not establish a supported object layout, application operation, or hardware purpose.

The raw address of F-e47d7b2e9c88 and a shift-derived base calculated from that address are distinct quantities throughout this contract. In particular, the two function-address self-stores target the **raw function address**, not the shift-derived base plus an offset.

### 1. Initial accesses

The following effects are represented in order:

1. Write the reduced index’s low byte at `0x0897E8B8` plus the displacement input.
2. Assign `0xB8` to global storage at `0x0897E8C0`; its destination width is unresolved.
3. Write the address seed’s low byte at the address seed plus six.
4. Write the unchanged index input as 32 bits at the displacement-derived destination.
5. Write `0xFFFF` as 16 bits at the halfword base plus four.
6. Write `0xFFFF` as 16 bits at the halfword base plus six.
7. Write byte `0xB8` at the displacement-derived destination plus four.
8. Write `0xFFFF` as 16 bits at the halfword base plus two.
9. Assign the halfword base’s low 16 bits to global storage at `0x0897EA28`.
10. Read an unsigned 16-bit value at the halfword base.
11. Zero-extend that loaded value to an address and write the 32-bit value obtained by masking the address seed with `0x897E8B80`.

The indirect destination in the last step is obtained from the halfword read, not directly from an input. That read follows all earlier writes, including the assignment at `0x0897EA28`; aliasing may therefore affect its result.

The three sentinel stores occur at offsets four, six, and two, in that order. They are separate effects, not an aggregate initialization.

### 2. First function-address branch

The address of F-e47d7b2e9c88 is used as data. No invocation is represented.

The representation captures its raw 32-bit address, derives the unresolved first function base, and derives the 16-bit sign marker. Under arithmetic right-shift semantics, the marker is zero for a nonnegative signed address and `0xFFFF` for a negative signed address.

A 16-bit sign-marker store at first function base plus four occurs **before** testing the signed raw address:

- A negative interpretation reaches an invalid-instruction marker.
- A nonnegative interpretation continues.

The early terminal path retains any completed preceding writes, including the offset-four marker store. It performs none of the continuing-path accesses below.

### 3. Continuing function-address accesses

On the continuing path, the represented order is:

1. Write the sign marker as 16 bits at first function base plus `0x12`.
2. Write the captured raw first-function address as 32 bits **through that raw address itself**. The destination and stored value are both the raw address of F-e47d7b2e9c88.
3. Read a signed 16-bit value at first function base plus the reduced index.
4. Repeat the 16-bit sign-marker store at first function base plus `0x12`.
5. Repeat the same 32-bit raw-address self-store: destination and value are again the captured raw first-function address.
6. Sign-extend the previously loaded halfword to 32 bits, shift it right by 16, and write the result as 32 bits at first function base plus eight.

Neither self-store targets first function base plus `0x12`. The unresolved base does not replace the raw function-address destination.

The signed halfword read occurs between the two self-stores and can observe effects of the first if its destination overlaps the read location. The last operation uses that captured halfword; it does not reload it after the second self-store.

Under arithmetic right shift, the final stored result is zero for a nonnegative halfword and `0xFFFFFFFF` for a negative halfword. Repeated stores remain separate represented effects.

### 5. Implicit-pointer accesses

2. Overwrites the first 32 bits there with the first function base shifted left by eight.

5. Reads 32 bits at twice the pointer’s address value.

\[

## Acceptance examples

These are conditional static criteria, not executed tests. Each assumes that preceding accesses complete and that any required target-specific arithmetic interpretation has been supplied.

1. **Subtraction boundary.** Index `0xA8` produces zero for the wrapped difference, halfword base, masked index, and reduced index. Sentinel halfword destinations are four, six, and two, in that order.

2. **Unsigned wrapping.** Index `0xA7` produces wrapped difference `0xFFFFFFFF`, halfword base `0xFFFFFFFE`, masked index `0x7FFFFFFF`, and reduced index `0x3FFFFFFF`. Clamping the subtraction is inconsistent with the represented arithmetic.

3. **Different bases despite equal reduced index.** Indices `0xA8` and `0xA9` both produce reduced index zero, but halfword bases zero and two respectively.

4. **Byte truncation.** Reduced index `0x123` supplies byte `0x23` to the initial byte store. Explicit 32-bit reduced-index stores retain `0x123`.

5. **Early termination.** A negative signed first-function address reaches the early terminal marker only after the sign-marker store at first function base plus four. The later raw-address self-stores are absent.

6. **Distinct marker and self-store destinations.** If an environmental interpretation supplies first function base \(B\) and captured raw first-function address \(A\), the continuing sequence includes a 16-bit marker store at \(B+\texttt{0x12}\), then a 32-bit store of \(A\) at \(A\). After the intervening halfword read, both stores repeat in that order. A 32-bit store of \(A\) at \(B+\texttt{0x12}\) is not a substitute.

7. **Captured signed halfword.** Under arithmetic right shift, a loaded halfword `0x7FFF` produces zero at first function base plus eight; `0x8000` produces `0xFFFFFFFF`. A later overlapping write does not cause a second halfword load.

8. **Current byte.** If an earlier byte assignment supplied `0x23` but an intervening aliased write changes the byte global to `0x7E`, the concatenation constructs `0x57E`, subject to the unresolved destination width.

9. **Fresh scaled-pointer-global read.** If the scaled-pointer self-store changes that global through overlap, the following reduced-index destination uses its changed contents plus four, not its initial assigned value.

10. **Current final halfword.** If the final-concatenation halfword was assigned `0x1234` but intervening writes change it to `0xABCD`, the constructed value is `0xABCDEA70`.

11. **Stack location versus pointer.** The sign-derived store targets 32 times the stack location’s address plus `0x18`. Substituting 32 times the pointer held there changes the contract.
