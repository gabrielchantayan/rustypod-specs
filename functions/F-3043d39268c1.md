# F-3043d39268c1

## Purpose

F-3043d39268c1 dispatches an input record through a conditional preliminary handler, one mandatory dynamically selected handler, and a conditional final handler.

The dispatch stages execute in that order. A handler result other than zero terminates processing immediately and becomes the function’s result. A zero result permits processing to continue. If no executed handler returns a nonzero result, the function returns zero.

Two conditions determine the optional stages:

- The preliminary stage requires a record discriminator of 15 and a record-associated address equal to an address embedded within the context.
- The final stage requires a record discriminator of 15 and a record-associated address equal to an address stored in the context.

The mandatory stage selects between two dispatch-table entries. It uses one entry only when the record discriminator is 22 and a referenced object contains the value 42 at a specified offset; otherwise, it uses the other entry.

These are established dispatch relationships. The semantic meanings of the discriminator values, the referenced object, and the handler results are not established.

## Interface

### Inputs

The function accepts two addresses:

1. **Context address**: identifies a structure containing a dispatch-table address, an address-valued field, and an embedded location used for address comparison.
2. **Record address**: identifies a record containing a discriminator and an associated value that is interpreted as an address on particular branches.

Both addresses are passed unchanged to every handler invoked by this function.

### Output

The function returns:

- The exact nonzero result from the first executed handler that returns nonzero; or
- Zero if every executed handler returns zero.

It does not normalize results to a Boolean. Positive and negative nonzero results both terminate dispatch and are returned unchanged.

## Behavior

### 1. Evaluate the preliminary-handler condition

The function first reads the record discriminator.

If it is not 15, the preliminary handler is skipped. The record-associated word is not read by this stage.

If it is 15, the function reads the associated address from record offset 8 and compares it with the address located 176 bytes after the context address.

This is an address comparison. The function does not read the contents at context offset 176 to determine whether the preliminary stage applies.

If the addresses differ, the preliminary handler is skipped.

If the addresses are equal, F-3faaf6d7241a is called with the original context and record addresses.

- A nonzero result is returned immediately.
- A zero result allows mandatory-handler selection to proceed.

No later dispatch-table entry is loaded or invoked after a nonzero preliminary result.

### 2. Select and invoke the mandatory handler

After the preliminary stage has either been skipped or returned zero, the function reads the record discriminator again.

This is a fresh read. A discriminator observed before a preliminary-handler call does not govern this stage if that call changes the record.

If the current discriminator is 22:

1. Read the associated address from record offset 8.
2. Read the four-byte value at offset 4 from the object at that address.
3. Compare the value with 42.

When this comparison succeeds, select the callable entry at dispatch-table offset 268.

For every other case, select the callable entry at dispatch-table offset 272. This includes:

- Any discriminator other than 22.
- Discriminator 22 with a referenced value other than 42.

For a discriminator other than 22, this stage does not read record offset 8 or dereference an associated object.

After determining the entry offset, the function reads the dispatch-table address from context offset 0 and loads the selected callable address from that table. It invokes the resulting handler with the original context and record addresses.

A nonzero result is returned immediately. A zero result permits evaluation of the final-handler condition.

Exactly one mandatory handler is invoked whenever this stage is reached. The function does not try the other mandatory entry when the selected handler returns zero.

### 3. Evaluate and optionally invoke the final handler

After a zero mandatory-handler result, the function reads the record discriminator again.

If it is not 15, the function returns zero without invoking a final handler. This stage does not then read record offset 8 or context offset 80.

If the discriminator is 15, the function:

1. Reads the associated address from record offset 8.
2. Reads the address-valued word at context offset 80.
3. Compares those two address values.

Unlike the preliminary condition, this comparison uses a value stored in the context. It does not compare against the address of context offset 80.

If the addresses differ, the function returns zero.

If they are equal, the function reads the current dispatch-table address from context offset 0, loads the callable entry at table offset 224, and invokes that handler with the original context and record addresses.

- A nonzero result becomes the function result.
- A zero result produces a final result of zero.

No additional dispatch stage follows this call.

### Cross-stage state and ordering

The function does not take a persistent snapshot of either input structure.

Consequently:

- A preliminary handler that returns zero can change the discriminator or associated address used by mandatory selection.
- It can also change the context’s dispatch-table address used for the mandatory call.
- A mandatory handler that returns zero can change the discriminator, associated address, or context offset-80 value used by the final condition.
- It can change the dispatch-table address used to resolve the final handler.

The preliminary address condition and final address condition are independent. Passing or failing one does not establish the outcome of the other.

Without recursion or other calls initiated inside handlers, this function itself makes at most three handler calls: preliminary, mandatory, and final.
