# F-2b2975f48b21

## Purpose

F-2b2975f48b21 conditionally performs a fixed sequence of four dependency calls. Selection depends on a 32-bit event selector and, for two selectors, bit 8 of a 32-bit flags word.

Three selector values are accepted:

- `0x00040001`, regardless of the flags word.
- `0x00010005`, only when flags mask `0x00000100` is nonzero.
- `0x00010002`, only when flags mask `0x00000100` is nonzero.

Accepted inputs follow the same call sequence but select one of two global 32-bit values for the third call. Rejected inputs return without calling any dependency.

The function has no explicit result value. Its operational result is the work performed by its dependencies. The supplied static evidence does not establish what that work represents: event dispatch, object construction, notification, and similar interpretations remain unproven.

## Behavior

### Entry and rejection

The function first captures the pointer held in the target-pointer slot. This precedes selector filtering in the supplied listing.

Selector `0x00040001` takes the primary path directly. No flags bit is required.

Other selectors are considered for the alternate path:

- Selector `0x00010005` is accepted by the selector check without evaluating the selector-minus-`0x00010000` expression.
- For other values, the listing forms that difference and requires it to equal `2`.
- A selector passing this check must also have bit 8 set in the flags word.

Consequently, the represented 32-bit selector comparison accepts `0x00010002` as the second alternate selector. Integer-overflow interpretation for other selectors is qualified under **Uncertainties**.

An input rejected by the selector check returns before checking flags. An input accepted by the alternate selector check but lacking flags bit 8 also returns.

On either rejection path:

- No dependency is called.
- Neither selected-value slot is read.
- The captured target pointer is not dereferenced.
- No explicit store is performed.

The entry-time pointer capture still precedes rejection in the supplied listing. Rejection therefore does not establish that the function is entirely free of global reads.

### Read timing and mutable state

The placement of the reads is part of the contract.

The selected global value is not captured before the first two calls. If either F-a66a9be680df or F-c5a232e4455b changes the relevant slot, the subsequent read obtains the value present after those calls.

The target pointer and its pointed-to word have different capture times:

- Pointer identity is captured before selector filtering.
- Pointed-to contents are read after F-afb630a7107c returns.

Changing the target-pointer slot during a dependency call does not redirect the later read to a newly stored pointer. Changing the contents of the originally captured target can affect the value passed to F-9a5c97dc580d.

No assumption is made that dependencies preserve globals, target contents, or target lifetime.
