## Acceptance examples

These examples are conditional static expectations, not executed tests.

1. **Third-input parity.** Under 32-bit bit-vector semantics and identical prior execution state, third inputs 2 and 4 contribute zero to the identified shifted argument; inputs 1 and 3 contribute `0x80000000`. Whole-execution equivalence is not asserted.

2. **Selector bounds.** If a selector read yields `0xff`, its byte-selected write targets `0x110`. If it yields zero, the destination is `0x11`. The selector is not a pointer-sized load.

3. **Byte truncation.** If a byte store receives the low byte of four times `0x43`, it writes `0x0c`, not the full scaled value `0x10c`.

4. **Distinct slot formulas.** With a dependency result of 3, its expanded slot is at `0x44`, while its word slot is at `0x20`. These formulas must not be interchanged.

5. **Global interference.** If a dependency modifies G-A after its explicit zero assignment, a later G-A read observes the then-current storage. Substitution of zero is not justified.

6. **Repeated selector reads.** If an intervening dependency changes a selector byte, the later zero write may target a different address from an earlier nonzero write.

7. **Terminal failure.** If address zero is not callable, reaching the terminal call does not establish normal return. Earlier effects, including the terminal halfword store, have already been attempted in order.

8. **Final publication.** If the final dependency byte is `0x7a`, G-B’s low eight bits become `0x7a`; its upper 24 bits come from the separately represented three-byte source, not necessarily from G-B’s previous value.
