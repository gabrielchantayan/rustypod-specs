# F-0fc21bc15241

## Purpose

F-0fc21bc15241 performs an ordered sequence of indirect calls and memory updates, then reaches a region where the supplied static representation cannot recover valid continuation instructions.

The established behavior is structural: it saves an incoming word, obtains another word from an implicit context, transforms returned values, writes several word-sized and byte-sized destinations, and invokes 40 indirect dependencies. No application-level purpose—such as allocation, serialization, device control, or object initialization—is established.

This is a partial behavioral contract. It describes the recovered path and its ordering, conditional on each preceding call returning normally and each memory access succeeding. It does not establish a normal return, a successful completion state, or the behavior beyond the final recoverable call.

Subsequent use treats its left shift by three as a word-sized transformation. Signed overflow and shifts of negative values cannot safely be interpreted using portable high-level signed arithmetic. Where examples below use wraparound, they explicitly assume 32-bit machine-word semantics.

## Acceptance examples

These are conditional acceptance examples, not execution results. Each assumes valid addresses, compatible call behavior, and no earlier interruption.

1. **Original and shifted input remain distinguishable.**  
   With original input 5, the first store writes 5 at context offset 36. The later root-relative store writes 40. The third argument of F-100000000001 is also 40.

2. **The initial mask precedes the right shift.**  
   With root word `0x8000000C`, the fourth argument of F-100000000001 is 3. Under 32-bit word semantics, its second argument is `0x00000018`.

3. **Pair halves serve different roles.**  
   If F-100000000010 supplies low half 3 and high half 8, the first scaled word is 12. The payload store targets address 52. F-100000000011 receives 12, 12, 12, and 1.

4. **The first scaled word survives intervening calls in the recovered data flow.**  
   If the preceding example applies and F-100000000017 returns 9, the later word store writes 12 at address 56. F-100000000018 receives 36. This example additionally requires the actual calling convention to support the recovered value flow.

5. **Byte writes truncate independently of intermediate width.**  
   If the late word is `0x12345678`, the first late byte write stores `0xE0`, and the second stores `0x23`, under 32-bit shift semantics.

6. **Selector reads must not be collapsed.**  
   If the byte at root word + 1 is 2 on its first read and 7 on its second, the two writes target addresses 19 and 24 respectively. A contract requiring both writes to address 19 would be incorrect.

7. **Repeated zero writes can select different destinations.**  
   If the first late-derived selector read returns 0 and the second returns 255, zero is written at addresses 17 and 272 respectively.

8. **Normal return is not an acceptance requirement established here.**  
   Observing all 40 calls does not establish successful completion. The recovered continuation remains unknown.
