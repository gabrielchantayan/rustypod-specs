# F-34929f581ad0

## Purpose

F-34929f581ad0 is a stateful routine that transforms entry arguments, invokes unresolved dependencies, performs conditional memory writes, and either returns a packed 64-bit value or continues through another processing cycle.

Two processing stages are visible:

- A **common stage**, which invokes three dependencies and either returns or prepares an extended-stage visit.
- An **extended stage**, which performs additional calls and memory accesses, may return early, and otherwise enters the common stage.

An initial routing decision can enter either stage. No application-level purpose, such as parsing, allocation, or device control, is established.

The visible behavior is not a self-contained four-argument interface. It also consumes incoming register state, an incoming return-address-like value, globals, and secondary register values exposed after dependency calls.

### Return value

Every visible normal return constructs a 64-bit result from two 32-bit components:

- **Low component:** a path-specific value shifted left by one, retaining 32 bits.
- **High component:** the current 32-bit return-component global minus `0x54`, retaining 32 bits.

The high component is obtained at the shared exit, not cached at entry.

The low component has two possible origins:

1. On an extended-stage early return, it is twice the low 32 bits returned by F-U03.
2. On a common-stage return, it is the final call’s secondary register value, arithmetic-right-shifted by 9 and then shifted left by one.

No success convention, error-code interpretation, ownership meaning, or pointer interpretation is established for the result.

- Signed conditions interpret the resulting 32-bit pattern as signed.
- A 16-bit write stores the low 16 bits.

This is a machine-width account of the supplied operations, not a claim that equivalent signed expressions are portable in a high-level language.

## Behavior

### Initial invocation and routing

Before F-U01, the routine determines whether unsigned B is greater than `0xFFFFFFBE`.

F-U01’s target is the incoming return-address-like value plus `0xECA`. Its arguments, in order, are:

1. A.
2. B plus `0x41`, modulo \(2^{32}\).
3. D arithmetic-right-shifted by 20.

Its 64-bit result supplies a current pair: **L**, the low 32 bits, and **U**, the high 32 bits.

If B is at most `0xFFFFFFBE`, execution enters the common stage directly.

Otherwise, the routine first writes the low 16 bits of H1 to address L plus `0x2A`. This write precedes the next routing decision and is not contingent on entering the extended stage.

The next decision compares these two Boolean conditions:

- H1 is negative under signed 32-bit interpretation.
- Subtracting `0x2F` from U incurs signed 32-bit subtraction overflow.

If they are equal, execution enters the common stage. If they differ, execution enters the extended stage with:

- **Difference:** H2 minus H1, retaining 32 bits.
- **Working value:** L logically shifted right by 25.
- **Base:** U.

The predicate is not an ordinary signed comparison between H1 and U minus `0x2F`. Its sign condition concerns H1, while its overflow condition concerns U. The subtraction overflows for U bit patterns from `0x80000000` through `0x8000002E`, inclusive.

### Extended stage: entry-path-dependent first call

F-U02 receives:

1. The working value.
2. The base.
3. An address into the routine’s stack region.

Its target depends on the immediately preceding control-flow path:

- **Direct entry from the preliminary branch:** target address `0x085737FC`.
- **Entry after a non-returning common stage:** target address `0x08573900`.

Here, “non-returning common stage” means that the common stage chooses continuation rather than the routine’s shared return; it does not mean that one of its dependencies fails to return.

This distinction is not a first-visit/subsequent-visit rule. The first extended-stage visit uses `0x08573900` if the initial routing entered the common stage and that stage then continued.

Passing the stack address exposes that region before the remaining operations. The dependency’s access, retention, or modification of it is unknown.

### Extended stage: mandatory write and early return

After F-U02 returns, F-U03 is invoked with no explicit arguments shown. Its result is treated as 64 bits.

The routine then:

- Forms an incremented base by adding decimal 10 to the base.
- Writes the 32-bit difference to the original base plus `0x3E`.
- Tests whether the incremented base, shifted left by 16 with 32-bit truncation, is negative.

The write occurs before the test takes effect. It is addressed from the original base, not the incremented base.

The condition tests bit 15 of the incremented base. It does not test the incremented base’s own sign bit.

If the condition is true, execution reaches the shared return. The low return component is twice F-U03’s low 32 bits. None of the remaining extended-stage calls or writes occurs.

### Extended stage: remaining operations

If the early-return condition is false, the following observable operations occur in order:

1. Write F-U03’s low 16 result bits to its high 32-bit result component plus `0x3C`.
2. Invoke F-U04 with no explicit arguments shown.
3. Invoke F-U05 with no explicit arguments shown.
4. Treat F-U05’s 32-bit result as an address and write the 16-bit value `0x0026` at that address plus 2.

A signed displacement is then formed by shifting the incremented base left by 28, retaining 32 bits, and arithmetic-right-shifting by 9. Only the incremented base’s low four bits contribute. Those four bits act as a signed four-bit value scaled by \(2^{19}\).

The routine adds this displacement to the incremented base to form an address candidate and reads the 32-bit mask global.

F-U06 is then invoked with:

1. F-U05’s address-producing result shifted left by one.
2. The incremented base shifted left by 16, then reduced by `0x51`.

After F-U06 returns, the candidate is XORed with the previously read mask to obtain the **derived address**. Thus, a change to the mask global during F-U06 does not replace the mask already selected for this calculation.

The displacement is increased by `0x2F`. The derived address is recorded as 32 bits in the represented stack slot at offset `0x130`.

F-U07 receives:

1. The fixed address-valued constant `0x085734E8`.
2. The eight-bit value read at the derived address plus 1.
3. The adjusted displacement.
4. An additional register-derived value exposed by an earlier call.

The byte read occurs before F-U07 is invoked. The load width is established, but the argument’s signed or unsigned extension at the dependency boundary is not.

After F-U07 returns, the routine writes the adjusted displacement as 32 bits at the derived address plus `0x24`.

F-U08 is then invoked with no explicit arguments shown. Its post-call secondary register value, increased by `0x30`, becomes U; the derived address becomes L. Execution enters the common stage.

### Common stage

Before its calls, the common stage computes and retains:

- A next working value equal to L shifted left by one.
- A doubled U.
- A next difference equal to the square of doubled U, retaining 32 bits.

It then invokes, in order:

1. F-U09, receiving L plus H3.
2. F-U10, receiving the current 32-bit contents of an argument global.
3. F-U11, with no explicit arguments shown.

F-U09 has different target expressions for direct entry from initial routing and entry after the extended stage.

The argument global is read after F-U09. A value read before that call cannot substitute for this access, because F-U09’s effects on globals are unknown.

After F-U11 returns, the routine reads a condition global and compares it with zero. **The access width of this condition global is unknown:** the supplied body contains neither its declaration nor an explicit width-qualified access.

If the condition equals zero:

- F-U11’s secondary register value is arithmetic-right-shifted by 9.
- That result is shifted left by one for the low return component.
- Execution reaches the shared return.

If the condition is nonzero:

- The retained square is written as 32 bits at doubled U plus `0x34`.
- F-U11’s secondary register value becomes the next base.
- Execution enters the extended stage with the retained doubled L and square.
- F-U02 uses target `0x08573900`, regardless of whether any earlier extended-stage visit occurred.

No visible iteration bound or independent termination guarantee exists.

## Acceptance examples

These are conditional static expectations, not observed executions. They assume valid accesses and dependencies that return with the stated state.

1. **Unsigned threshold boundary.** With B equal to `0xFFFFFFBE`, F-U01 receives `0xFFFFFFFF` as its second argument. Initial routing enters the common stage without the preliminary 16-bit write.

2. **First value above the boundary.** With B equal to `0xFFFFFFBF`, F-U01 receives zero as its second argument. H1’s low 16 bits are written at initial L plus `0x2A` before the sign/overflow routing decision.

3. **Maximum B.** With B equal to `0xFFFFFFFF`, F-U01’s second argument is `0x40`. The preliminary write occurs; the following route still depends on H1 and U.

4. **Preliminary predicate.** If the preliminary-write path is enabled and U is zero, subtraction of `0x2F` does not overflow. Nonnegative H1 selects the common stage; negative H1 selects the extended stage. The latter invokes F-U02 at `0x085737FC`.

5. **First extended visit after common processing.** Suppose initial routing enters the common stage and its condition global is nonzero after F-U11. The continuation write occurs, and the first extended-stage visit invokes F-U02 at `0x08573900`, not `0x085737FC`.

6. **Early-return bit boundary.** If the extended-stage base is `0x00007FF6`, adding 10 yields `0x00008000`. The routine writes the difference at the original base plus `0x3E` and then returns early. It omits the subsequent result-derived 16-bit write and all later calls in that iteration.

7. **Cached mask.** If F-U06 changes the mask global, the current derived address still uses the mask read before F-U06. A later iteration may read the changed value.

8. **Zero condition.** If the condition global compares equal to zero after F-U11 and that call’s secondary register value is `0x00000400`, the low return component is 4. The continuation write is omitted. This expectation does not require or establish a particular condition-global access width.

9. **Nonzero condition.** If the condition global compares nonzero, the retained square is written before F-U02. The next base comes from F-U11’s secondary register value, not from the earlier U.

10. **Return-global timing.** If a dependency changes the return-component global and the routine subsequently returns, the high component uses that global’s value at the shared exit, minus `0x54`, rather than an entry-time value.

## Evidence
