# F-d80d71162f57

## Purpose

F-d80d71162f57 returns a Boolean comparison of selected values in two input storage regions. It first compares the signed integers at the input addresses. Only when those values match does it read the next integer in each region, convert each of those integers to a pointer to the input integer type, and compare the resulting pointers.

The result is true exactly when the captured first integers compare equal and the converted second integers produce pointers that compare equal.

This is not a comparison of entire storage regions or of the contents of objects identified by the converted pointers. The converted pointers are never dereferenced. Equality of the original input addresses is neither required nor used as a shortcut.

**Inferred intent:** The operation resembles equality for an integer paired with an address-like identity. The source does not establish the application meaning of either stored value.
