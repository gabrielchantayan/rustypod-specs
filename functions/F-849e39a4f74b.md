# F-849e39a4f74b

## Purpose

F-849e39a4f74b returns a four-byte value obtained through an indirect memory lookup. A globally referenced base identifies a location containing an intermediate address; a fixed offset from that intermediate address identifies the value returned.

The established behavior is an accessor, not a calculation on the final value. The function does not explicitly modify the retrieved bits, validate them, or interpret their meaning.

The purpose of the surrounding data structure is unknown. In particular, the available evidence does not establish whether the returned value represents a number, flags, a handle, an address, or another four-byte representation.

## Behavior

### Dependent lookup

The function obtains the globally supplied base B and accesses the four-byte location at B + 4. It treats the contents of that location as the intermediate address P.

It then accesses the four-byte location at P + 56. The four-byte contents of that second location become V, which is returned without an explicit transformation.

The second address depends on the contents of the first location. This is therefore not equivalent to reading a single fixed offset of 60 bytes from B. The first offset selects an address-bearing location; the second offset is applied to the address read from that location.

### Observable ordering

The established order of the two explicit dependent reads is:

1. Read the intermediate address from the location at B + 4.
2. Read the return value from the location at P + 56, using the intermediate address obtained by the first read.

The final value cannot be selected until the intermediate address has been obtained. There is no explicit re-read of that intermediate address before returning.

The global reference must also supply B. The supplied representation does not establish whether obtaining B entails a separately observable memory read, a literal-derived value, or another machine-level mechanism. Consequently, this contract does not assert an exact total number of bus transactions or global-storage reads.

### Returned bits

The final read supplies the entire result. There is no explicit mask, shift, comparison, increment, sign conversion, normalization, or special handling of any bit pattern.

A four-byte zero value is returned as zero. A value with its highest bit set retains that bit. An all-ones value retains all 32 one bits. Such values do not select an explicit error path.

The intermediate value is different: its bits determine a memory address rather than being returned directly.

### Arithmetic and boundaries
