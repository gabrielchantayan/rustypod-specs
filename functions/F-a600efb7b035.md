# F-a600efb7b035

- An initial value of zero skips the dependency and proceeds to the zero store.
- An initial nonzero value causes one invocation of F-6ceb050679ad. If that invocation returns normally and the destination remains writable, the function then stores zero.

The comparison uses the initial read. There is no visible second read of the target to reconsider the branch after the dependency has run.

### Initially zero

The function nevertheless reaches an explicit store of zero to the target. The operation is therefore not specified merely as “leave an already-zero object unchanged”: the supplied source contains a store on this path.

2. Conditionally invoke F-6ceb050679ad when the read value is nonzero.
