## Behavior

- **Zero:** return 0.
- **Nonzero:** invoke F-d3922c7fe0ec and, if it returns normally, store its captured 16-bit result and return 1.

### Zero-byte path

- No explicit destination write occurs.

- The function returns the 32-bit value 0.

### Nonzero-byte path

If the dependency returns normally, this function captures a 16-bit result and writes that result to the destination identified by the second argument. It then returns the 32-bit value 1.

No additional check is made between the dependency call and the destination store. In particular:
