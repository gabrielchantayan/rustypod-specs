# F-1a54223b095b

## Purpose

F-1a54223b095b selects one of two construction variants, delegates construction or lookup to F-793a94891814, and writes a fixed set of word-sized values and byte-sized markers into the returned storage.

The selection depends only on whether the second input equals zero. After the dependency returns, both variants receive the same sequence of explicit initialization writes. The contents of the word-sized writes come from external data slots whose values are not supplied.

The established behavior is a dependency call followed by sparse initialization. Describing the result as a particular object type, assigning meanings to its fields, or identifying the markers as type tags would be inferred intent rather than established behavior.

## Behavior

### 1. Select the dependency arguments

When the second input is zero, the function selects numeric selector 10 and reads one external 32-bit data slot for the third dependency argument.

When the second input is nonzero, it selects numeric selector 11 and reads a different external 32-bit data slot for that argument.

Only the selected branch’s data read is established. The supplied body does not show an unconditional read of both slots.

The selected value is read before invoking F-793a94891814. Consequently, the third argument is the value obtained by that pre-call read, not a fresh read performed after the dependency returns. If the dependency changes the selected external slot, that does not retroactively change the argument already passed.

### 2. Invoke the dependency

The function invokes F-793a94891814 once with the six arguments specified above.

The call occurs before any of this function’s explicit writes through the returned address. There is no alternate dependency, retry path, or visible early return.

The dependency is opaque. It may allocate storage, return existing storage, mutate external state, or perform other actions; none of those possibilities is established here. Its argument values do not by themselves establish ownership or allocation semantics.

### 3. Obtain the first two initialization values

After the dependency returns, the function first reads the external 32-bit value intended for offset 24.

It then reads the external 32-bit value intended for offset 0 and writes that value at offset 0.

Only after the offset-0 write does it write the previously captured value at offset 24.

This order is significant:

- The value for offset 24 is read before the offset-0 write.
- The value for offset 0 is read after the value for offset 24.
- The offset-0 write precedes the offset-24 write.
- Both external reads occur after the dependency call returns.

If storage aliases an external data slot, these distinctions can affect the result. In particular, the offset-24 value is not reread after the offset-0 write.
