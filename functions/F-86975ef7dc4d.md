# F-86975ef7dc4d

## Purpose

The established outcomes are:

- **Zero result:** call a no-argument dependency, copy the retained pair into the object, and replace two control fields with fixed values.
- **Nonzero result:** preserve the upper eleven bits of a 16-bit field, replace its lower five bits with the value one, and replace an adjacent 8-bit field with a different fixed value.

The meanings of the pair, decision result, and object fields are not established. In particular, zero and nonzero are branch conditions, not evidence of success and failure.

This contract describes direct operations and dependency-call order visible in the supplied static representation. It does not assume that dependencies preserve object storage, source storage, globals, or ownership.

### Nonzero-result path

For the 16-bit value \(S\) observed by that read, the replacement is:

\[
(S \mathbin{\&} \texttt{0xFFE0}) \mathbin{|} \texttt{0x0001}.
\]

This operation:

- Preserves bits 5 through 15.
- Clears bits 1 through 4.
- Sets bit 0.

Equivalently, the lower five bits become the five-bit representation of one. The stored result remains within 16 bits. This is a bit-mask operation, not addition; it introduces no carry into the preserved bits.

The field read occurs after the decision dependency returns. The preserved upper bits are therefore the bits present at that read, not necessarily those present at function entry.
