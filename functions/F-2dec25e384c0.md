### Ordered read and calls

On the normal path, the observable operation order established by the supplied representation is:

1. F-338d16f9ce72 is invoked with the address at base plus 16 bytes.
2. After that invocation returns, the byte at the base address is read.
3. The byte value is retained across the next call.
4. F-1333331b2da1 is invoked with the address at base plus 16 bytes.

No visible condition chooses between alternative paths. There is no loop, retry, comparison, masking, conversion to a truth value, or validation of the byte’s contents.
