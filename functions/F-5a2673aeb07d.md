# F-5a2673aeb07d

## Purpose

F-5a2673aeb07d selects a preparation dependency using a 32-bit selector, limits the resulting low-byte count by a caller-supplied unsigned limit, and invokes an operation through a caller-supplied object. Unsupported selectors and unequal operation results cause a separate status-reporting call.

The function has no explicit return value. Its observable behavior consists of dependency calls, an indirect object operation, and access to local storage passed to dependencies.

**Established static evidence:** selection rules, argument forwarding, count reduction, result comparison, and the ordering of reporting and finalization are visible.

**Inferred intent:** the selected dependencies appear to prepare something that the object operation subsequently consumes. The first and last dependency calls appear to bracket the operation, while a reporting dependency receives a fixed status value on failure. These interpretations do not establish resource ownership, data format, or the meaning of that status.

**Important limitation:** two 32-bit values used as preparation arguments and descriptor contents have no visible initialization in the supplied representation. Consequently, a deterministic successful data path cannot be specified from this evidence alone.

### 2. Selector dispatch

|---|---|---|

The range check is equivalent to testing whether unsigned 32-bit subtraction of `0xC0` from the selector yields a value less than `0x40`.

Consequences include:

- `0xC0` is included.
- `0xFF` is included.
- `0xBF` and `0x100` are excluded.
- Negative signed selector values do not qualify merely because subtraction wraps.
- No selector outside the listed range and individual values is accepted.

The range check precedes the individual equality checks. The cases do not overlap.

An unsupported selector bypasses all preparation dependencies and the indirect operation, then reaches the reporting step.

### 3. Descriptor preparation and count calculation

After a selected preparation dependency returns, the two source words are copied into the local descriptor.

The preparation dependency’s result is treated as a 32-bit value. Only its lowest eight bits contribute to the operation count:

- Extract the result modulo 256.
- Compare that value with the unsigned 32-bit limit.
- Use the smaller value as the requested count.

Thus the requested count is always between zero and 255 inclusive and never exceeds the limit.

High result bits are discarded for this calculation. A preparation result with nonzero high bits is not, by itself, treated as an error. A result whose low byte is zero requests a zero-count operation.

The visible comparison uses “limit less than or equal to low-byte value.” Equality therefore selects the limit, but produces the same numerical count as selecting the low-byte value.

The full original limit, not its low byte and not the capped count, was previously passed to the preparation dependency.

### 4. Indirect operation

The function resolves and calls the object operation after the selected preparation dependency has returned and after the local descriptor has been populated.

The operation receives:

1. The operation object.
2. The requested count.
3. The address of the local descriptor.

This call still occurs when the requested count is zero. There is no visible zero-count shortcut.

The operation’s 32-bit return value is compared with the requested count without low-byte masking:

- Exact equality bypasses reporting.
- Any inequality reaches reporting.

For example, a return value whose low byte matches the count but whose high bits are nonzero is not accepted as equal.

No retry, secondary preparation, alternate operation, or partial-result handling is visible.

### 5. Reporting and finalization

On an unsupported selector or an unequal operation result, the function calls F-7f008c1060db with:

- The retained result from F-603a53835f04.
- The constant `2`.

After reporting returns, control reaches finalization.

On an exact operation result, reporting is skipped and control reaches the same finalization step.

Finalization calls F-ffa7163332aa with the address of the same four-byte scratch region previously passed to F-9b3ee6b2bfa6. The function then returns without an explicit value.

These ordering guarantees apply to normal returns from the dependencies. The evidence does not establish behavior after a fault, nonlocal exit, exception, termination, or a dependency that does not return.
