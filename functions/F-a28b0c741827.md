# F-a28b0c741827

## Purpose

F-a28b0c741827 handles two recognized selector values and, for either recognized selector, writes one 32-bit result to a caller-provided destination. Its return value reports selector recognition, not necessarily operational success.

The two supported selectors are:

- **0x36A4:** obtain a value from a dependency, compare that value plus two against a signed input, and invoke a second dependency only when the comparison does not take the zero-result path.
- **0x36E1:** invoke a decision dependency and invoke the second dependency only if that decision result is nonzero.

An unsupported selector returns zero without writing the destination. A recognized selector returns one after writing the destination, provided all required accesses and dependency calls complete normally.

The apparent purpose is to gate an operation and optionally produce a result or diagnostic value. That interpretation is **inferred intent**. The meanings of the selectors, context fields, configuration words, and dependency results are not established.

## Interface

### Inputs

The function has four inputs:

1. **Context operand.** Used to locate two 32-bit fields at byte offsets **0x14** and **0xBC** from a supplied base. It is also passed directly to F-1e2086823720 for selector 0x36E1.
2. **Selector.** A signed 32-bit input compared for equality against 0x36A4 and 0x36E1.
3. **Comparison or decision input.** A signed 32-bit input. For selector 0x36A4 it is the right-hand operand of a signed comparison. For selector 0x36E1 it is passed unchanged to F-1e2086823720.
4. **Output destination.** A location at which the function stores one 32-bit word on every normally completing recognized-selector path.

The supplied representation treats the context operand as an integer used for address calculation. This supports describing the accessed offsets, but does not independently establish the complete pointer model, address-space width, alignment rules, or context object type.

### Result

The direct return value is a 32-bit word with these normal-completion values:

| Selector | Direct return | Destination write |
|---|---:|---|
| 0x36A4 | 1 | Exactly one explicit 32-bit store |
| 0x36E1 | 1 | Exactly one explicit 32-bit store |
| Any other value | 0 | No explicit store |

For a recognized selector, the stored word is either zero or the 32-bit result returned by F-5710a8628cba. A zero stored result does not uniquely identify which path ran: the function can select zero directly, or F-5710a8628cba can return zero.

### Referenced storage

Two externally stored 32-bit words are relevant:

- **Configuration word A:** read at function entry, before selector dispatch. Its captured value can later become the second argument to F-5710a8628cba.
- **Configuration word B:** read only on the fallback path for selector 0x36A4. Its value becomes the third argument to F-5710a8628cba.

Their values, semantic types, mutability, and relationship to other storage are unknown.

The context fields have these established uses:

|---|---:|---|

### Preconditions

Normal completion requires all accesses actually reached by the selected path to be valid, together with satisfaction of the invoked dependencies’ own preconditions.

The function performs no explicit null, bounds, alignment, lifetime, or destination-capacity validation. In particular:

- Configuration word A is read even for an unsupported selector.
- Selector 0x36A4 requires access to the context field at offset 0xBC.
- Either recognized selector can require access to the context field at offset 0x14.
- Every normally completing recognized-selector path requires a writable 32-bit destination.

No non-aliasing requirement is established by the supplied evidence.

## Behavior

### Entry and dispatch

The function first reads configuration word A and retains that value for possible later use. This occurs before deciding whether the selector is supported.

It then selects one of the two recognized behaviors. For any other selector, it returns zero immediately, without an explicit destination write and without calling any of the listed dependencies.

The unsupported-selector case therefore does not require an explicit context-field read or destination dereference by this function. It still includes the initial configuration read.

### Selector 0x36A4

The function reads the 32-bit context field at byte offset 0xBC and passes that value to F-5fca8e42aa3d.

The returned value is treated as a signed 32-bit integer for the subsequent arithmetic and comparison. The function compares that value plus two against the third input, using a signed less-than-or-equal comparison.

If the sum is less than or equal to the third input:

- The selected output word is zero.
- The function does not explicitly read the context field at offset 0x14.
- It does not read configuration word B.
- It does not call F-5710a8628cba.
- It stores zero at the output destination and returns one.

If the comparison is false:

1. The function reads the 32-bit context field at offset 0x14.
2. It reads configuration word B.
3. It calls F-5710a8628cba with three arguments, in this logical argument order:
   - The newly read context field at offset 0x14.
   - The entry-time captured value of configuration word A.
   - The value read from configuration word B.
4. It stores the returned 32-bit word at the output destination.
5. It returns one.

The third argument to F-5710a8628cba on this path is configuration word B, **not** the result from F-5fca8e42aa3d and not that result plus two.

The context field at offset 0x14 and configuration word B are read after F-5fca8e42aa3d returns. Their values must not be assumed to match values that existed before that call.

### Selector 0x36E1

The function calls F-1e2086823720 with:

1. The context operand.
2. The third input, unchanged.

Its return is interpreted as a signed 32-bit integer, but the only direct test is equality with zero.

If the dependency returns zero:

- The selected output word is zero.
- There is no explicit read of the context field at offset 0x14.
- Neither F-5fca8e42aa3d nor F-5710a8628cba is called.
- Configuration word B is not read.
- The function stores zero at the destination and returns one.

If the dependency returns any nonzero value:

1. The function reads the 32-bit context field at offset 0x14.
2. It calls F-5710a8628cba with:
   - That context field value.
   - The entry-time captured value of configuration word A.
   - The nonzero result from F-1e2086823720.
3. It stores the returned 32-bit word at the destination.
4. It returns one.

Negative dependency results are nonzero and therefore take the same invocation path as positive results. There is no explicit negative-result rejection or conversion into a direct error return.

### Integer boundaries

The selector and comparison input are represented as signed 32-bit integers. The decision results from F-5fca8e42aa3d and F-1e2086823720 are likewise represented as signed 32-bit integers.

For selector 0x36A4, addition of two remains within signed 32-bit range when the dependency result is at most **2,147,483,645**. The lowest signed 32-bit result does not cause underflow when two is added.

For dependency results **2,147,483,646** and **2,147,483,647**, the mathematical sum exceeds signed 32-bit range. The supplied representation does not establish the relevant machine arithmetic or language overflow contract. Behavior at those two values is **documented_only**; this contract does not choose wrapping, trapping, saturation, or an unbounded mathematical interpretation.

No arithmetic is explicitly applied to the nonzero result from F-1e2086823720 before it is passed onward.

## Side effects

### Explicit reads and writes

The function’s own observable storage sequence is:

- **All selectors:** read configuration word A.
- **Unsupported selector:** return without further explicit storage access.
- **0x36A4, direct-zero path:** read context offset 0xBC, call F-5fca8e42aa3d, then write the destination.
- **0x36A4, fallback path:** read context offset 0xBC, call F-5fca8e42aa3d, read context offset 0x14, read configuration word B, call F-5710a8628cba, then write the destination.
- **0x36E1, direct-zero path:** call F-1e2086823720, then write the destination.

## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not runtime test results. All assume valid reached accesses and normally returning dependencies.

1. **Unsupported selector preserves the destination absent external interference.**  
   With selector 0x1234 and an initial destination word of 0xA5A5A5A5, the function reads configuration word A, calls none of the listed dependencies, returns zero, and makes no explicit destination write.

2. **Equality takes the direct-zero path.**  
   For selector 0x36A4, if F-5fca8e42aa3d returns 8 and the third input is 10, the destination receives zero and the direct return is one. F-5710a8628cba is not called.

3. **A smaller comparison input invokes the fallback.**  
   For selector 0x36A4, if F-5fca8e42aa3d returns 8 and the third input is 9, F-5710a8628cba is called. Its third argument is the subsequently read configuration word B. If it returns 0x11223344, that word is stored and the direct return is one.

4. **Signed negative values participate in the comparison.**  
   For selector 0x36A4, if F-5fca8e42aa3d returns −3 and the third input is −1, the sum equals −1 and the destination receives zero. With the same dependency result and third input −2, the fallback is taken.

5. **A zero decision bypasses the final dependency.**  
   For selector 0x36E1, if F-1e2086823720 returns zero, the destination receives zero and the direct return is one, irrespective of the semantic meaning of the third input.

6. **A negative decision is forwarded.**  
   For selector 0x36E1, if F-1e2086823720 returns −7, F-5710a8628cba receives that value as its third argument. The function stores its returned word and returns one.

7. **Entry-time and post-call values remain distinct.**  
   Suppose configuration word A contains 11 on entry. If the first dependency changes its backing storage to 22 and changes the context field at offset 0x14 to 33, a subsequent F-5710a8628cba call receives 11 as its second argument and 33 as its first argument, provided the later context read is valid.

8. **Zero output does not prove bypass.**  
   If F-5710a8628cba is invoked and returns zero, the destination still receives zero and the direct return remains one.

9. **Overflow-edge outcomes are not prescribed.**  
   If F-5fca8e42aa3d returns either of the two highest signed 32-bit values, acceptance must not require a particular comparison outcome without additional arithmetic evidence.
