6. **Store-before-read alias.** If Scale4(I) equals captured base and no exceptional memory behavior intervenes, the H-scaled word store precedes the captured-word read at the same address. For ordinary readable and writable memory, that read observes the stored word.

7. **Byte-derived destination and extraction.** A first lookup byte of 0x20 selects destination 0x31. With captured word 0xABCDEF12, the first indirect byte write stores 0x12. The second stores 0xAF, the captured word’s bits 22–29, at its independently selected destination.
