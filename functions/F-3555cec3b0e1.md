# F-3555cec3b0e1

## Purpose

F-3555cec3b0e1 conditionally performs a stateful operation using an object anchor, a signed selection, a one-byte setting, and two unsigned position-like values.

It returns a 32-bit zero when an initial eligibility check rejects the request. It returns a 32-bit one when an admitted request reaches normal completion. The successful return does not establish semantic success of the dependencies it invokes.

The admitted path chooses between **change-required** and **same-state** modes. This decision uses the original selection, before any replacement of the special value −1. The mode controls explicit object-byte writes, how the positions are forwarded, and whether an additional late indirect call occurs.

“Selection,” “position,” and “notification” are descriptive roles inferred from use, not established application semantics. The contract below distinguishes visible operations from unknown dependency behavior.

### 2. Mode selection

### 5. Independent position normalization

- An input position of zero remains zero.

## Acceptance examples

The following are conditional static examples, not executed tests. Each assumes valid memory and normal returns from every reached dependency.

1. **Immediate rejection.** If F-b7abcf60c990 returns zero, return zero without calling F-d5511c118375 or any admitted-path dependency.

2. **Short-circuited secondary rejection.** If the first eligibility query is nonzero and the first F-d5511c118375 result is zero, return zero without its second invocation.

3. **Strict signed eligibility.** With selection 7 and the earlier checks nonzero, a second F-d5511c118375 result of 7 rejects; a result of 8 admits.

4. **Negative selection.** With selection −1, a nonzero first F-d5511c118375 result followed by a second result of zero passes eligibility. Zero is greater than −1 under the signed comparison. Replacement happens later.

5. **Mode precedes replacement.** For original selection −1, an initial U-01 result of 4 selects change-required mode and skips U-02. A replacement U-01 result of 6 makes F-6542ebfeed7d receive 6 without changing that mode.

6. **Same-state activity.** If U-01 equals the original selection and U-02 returns zero, there are no explicit setting-byte writes. A normalized first position of 5 is passed to U-05; zero skips U-05. U-06 still occurs in either case.

7. **Independent bounds.** For positions 10 and 11, normalization results 10 and 9 produce positions 10 and zero. Change-required mode forwards that pair to F-0edcc41cb6b7.

8. **Unsigned boundary.** A position of `0xFFFFFFFF` is retained only when its corresponding unsigned result is also `0xFFFFFFFF`; a result of `0x7FFFFFFF` replaces it with zero.

9. **Low-byte decision.** With F-6e482452607b nonzero, a field value of `0x00000100` selects the ordinary branch; `0x00000101` selects the alternate branch. A zero dependency result avoids evaluating the field.

10. **Equal global evaluations.** If both global evaluations yield 12, F-069a1d444a2d receives 12. Change-required mode later invokes U-09 with 9, then with 12 and zero. Same-state mode performs only the latter invocation. These equal values do not erase the two source-level evaluations.
