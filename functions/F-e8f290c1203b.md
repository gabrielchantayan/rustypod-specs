# F-e8f290c1203b

Normal completion produces a 64-bit result assembled from two 32-bit components.

The supplied static representation establishes the operations and their ordering, but not their application-level meaning. It does not establish that calculated addresses identify valid objects, that dependencies implement a particular protocol, or that execution terminates.

## Behavior

### Arithmetic and address interpretation

The relevant arithmetic operands and address expressions are represented at 32-bit width. This contract describes wrapping consequences conditionally: when 32-bit machine arithmetic applies, additions, multiplications, and left shifts retain their low 32 bits.

### Initial calculation and first dependency

At the beginning of each iteration, an intermediate **S** is formed by shifting A left by 28 bits and then arithmetically right by 9 bits. Truncation at 32-bit width precedes the right shift under the conditional machine interpretation.

A preliminary address value is formed from A plus S. G-mix is then read and retained for the current calculation.

The first dependency, **F-000000000001**, is called through the target calculated from L plus `0xEC0`. Its two represented arguments are:

1. P shifted left by one bit.
2. B minus `0x51`.

After that call returns, the preliminary address value is combined with the previously sampled G-mix value by bitwise exclusive-or. The resulting 32-bit address is **X**.

The shared-word read therefore precedes the first call, while the exclusive-or follows it. A modification of G-mix during the call does not itself cause a second read for this iteration’s X.

An adjusted value **T** is S plus `0x2F`.

### Second dependency and first external word write

A one-byte value is read from X plus 1. The second dependency, **F-000000000002**, receives:

1. The fixed address value `0x085734E8`.

4. An auxiliary register output associated with the first dependency.

### Third through sixth dependencies

Under modular 32-bit arithmetic, W has the bit pattern of four times Q squared. This equivalence does not establish wider intermediate precision or overflow checking.

### Zero-control exit

If G-control reads as zero, execution leaves the loop without performing the continuation-path stores or calls.

The lower return component is formed by:

- Arithmetically shifting R right by 9 bits.
- Shifting the resulting 32-bit value left by one bit.

Execution then reaches the common return construction.

This branch does not execute the seventh through tenth dependencies. It also does not execute the W stores or the two halfword stores described below. This exclusion concerns this function’s represented operations; it does not restrict earlier dependencies from accessing the same locations.

The seventh dependency, **F-000000000007**, then receives:

### Negative-product exit

If B is negative as a signed 32-bit value, execution transfers directly to the common return construction.

On this path, the lower return component is the low 32 bits of V shifted left by one bit.

The store at R plus `0x3E` precedes the branch. The subsequent V-derived halfword store and the ninth and tenth dependency calls are not executed.

Under modular 32-bit multiplication, the sign of B is determined by bit 15 of the updated A: multiplication by `0x10000` moves that bit to bit 31. This is not a test of A’s own sign.

The ninth dependency, **F-000000000009**, is then called with no represented explicit arguments.

The tenth dependency, **F-00000000000A**, is called with no represented explicit arguments. Its represented 32-bit result replaces P.

The function writes the 16-bit value `0x0026` at P plus 2, then repeats.

### Common return construction

- Negative-product exit: twice the low 32 bits of V.

This shared-word read is late, not an entry snapshot. Changes made before the read may affect the returned upper component.

## Acceptance examples

These are conditional static consequences, not executed tests. They assume valid executed accesses and returning dependencies where necessary.

1. **Zero control excludes continuation operations.**  
   If G-control reads as zero after the sixth call, this function does not perform the W store at twice Q plus `0x34` or invoke dependencies seven through ten in that iteration.

2. **Arithmetic right shift affects the zero-control return.**  
   If the applicable R bit pattern is `0xFFFFFE00`, arithmetic right shift by 9 produces `0xFFFFFFFF`. The lower result component is `0xFFFFFFFE`. A logical right shift would produce a different result.

3. **The product sign test follows the continuation store.**  
   If updated A is `0x00008000`, modular multiplication by `0x10000` yields `0x80000000`. The store at R plus `0x3E` occurs before the negative-product exit. The V-derived halfword store and final two calls are skipped.

4. **Negative A does not imply negative B.**  
   If updated A is `0xFFFF0000`, the product’s low 32 bits are zero. This does not trigger the negative-product exit.

5. **V contributes different fields to address and stored data.**  
   If B is nonnegative, V’s high word is `0x00001000`, and its low word is `0x12345678`, the V-derived store writes `0x5678` as 16 bits at `0x0000103C`.

6. **The upper result uses the late shared read.**  
   If G-result reads as `0x54` during return construction, the upper return component is zero, regardless of its earlier values.

7. **Mixing uses the earlier sample.**  
   If the first dependency changes G-mix, X still uses the value sampled before that call. A later iteration performs a new read.

8. **A completed write need not remain visible indefinitely.**  
   If the second dependency returns, this function writes T at X plus `0x24`. If a later dependency overwrites or restores that storage, the contract does not require T to remain there. No explicit rollback by this function is implied.
