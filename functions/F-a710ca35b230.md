# F-a710ca35b230

## Purpose

The established behavior is initialization-like: the function obtains a destination from one dependency, installs two externally supplied words at different stages, delegates additional processing, copies two words from an input region, records the fourth input, clears two fields, and stores another dependency’s result increased by 20.

An object-construction or embedded-object initialization role is **inferred intent**, not an established interface guarantee. In particular, the returned result is calculated from the last dependency-produced destination. It is not demonstrably the same address obtained from the first dependency.

### Read timing and aliasing

- The first external word is read after the first dependency returns.
- The second external word is read after the second dependency returns.
- Both source words are read after F-b9acea4b06ad returns.
