## Behavior

1. Assign the 32-bit value zero to the element at the supplied address.
2. Assign the 32-bit value zero to the next element, four bytes later.
3. Return without a value.

Both assignments are unconditional. There is no branch based on the address, an initial element value, or another visible state.

The old contents are not read by the function before being overwritten. The function therefore does not need either element to contain an initialized value, provided the writes themselves are valid.

That ordering is not a promise about a particular machine instruction sequence, bus transaction sequence, or what an unsynchronized observer can see. The evidence does not establish volatile access semantics, atomic operations, memory barriers, or a synchronization protocol.
