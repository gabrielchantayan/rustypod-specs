# F-172dbaa51f04

## Purpose

F-172dbaa51f04 performs an ordered sequence of memory writes and indirect calls. Its first visible action stores the third explicit argument into a four-byte field of the object identified by the first argument. It then passes an interior address of that object to an indirect dependency, transforms returned and ambient values into later call arguments, writes a byte through another dependency’s result, and updates two fixed-address memory locations.

The final visible operation invokes an unresolved indirect target. The supplied representation shows a return afterward, but explicitly identifies the final control transfer as unrecovered. Normal completion is therefore not established.

No application-level purpose—such as initialization, decoding, device control, or scheduling—is established. This contract describes the visible effects and data dependencies without assigning those operations an unsupported semantic role.

3. **Capture Ambient A and call F-unknown-02.**

## Acceptance examples

These are conditional contract examples, not executed tests.

1. **Initial write precedes callee observation.**  
   Given a valid object destination and a stored value of `0x12345678`, the first visible write carries that 32-bit value at offset `0x4e`. It precedes entry to F-unknown-01. Its byte sequence depends on target endianness.

2. **Unsigned arithmetic wraps.**  
   If F-unknown-01 supplies low bits `0xffffffff` and Ambient B is zero at the transformation, F-unknown-02 receives `0x00000031` as its first argument. A wider, non-wrapping sum would not match the visible 32-bit operation.

3. **Byte write truncates.**  
   If Ambient A has value `0x123456ab` at the byte-write step and the returned destination is valid, the write at result plus five stores `0xab`. It does not write the remaining three bytes.

4. **Saved and live values are distinguishable.**  
   If Saved A is captured as `0x11223344`, the later write at `0x41` uses that captured value. The byte write is expressed using Ambient A at its own use point; equality between the two must not be assumed without a preservation contract.

5. **Unsigned shift discards upper position, not sign.**  
   If the secondary output from F-unknown-04 is `0xffffffff`, F-unknown-05 receives `0x00007fff`.

6. **Signed arithmetic differs for negative values.**  
   Conditional on sign-propagating right shifts, a result of −1 from F-unknown-09 makes both arguments to F-unknown-10 equal −1. For a result of `0x00004000`, its second argument is 1.

7. **A failed destination does not imply rollback.**  
   If the byte destination from F-unknown-03 faults, the initial object write and preceding calls have already been attempted in order. The later fixed-address writes are not yet reached on that path.

8. **The final transfer may prevent completion.**  
   If F-unknown-14 does not return, F-172dbaa51f04 has no established normal return despite the trailing return shown in the representation.
