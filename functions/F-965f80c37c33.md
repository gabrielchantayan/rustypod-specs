# F-965f80c37c33

## Purpose

F-965f80c37c33 partially initializes a caller-supplied destination using context fields, writable temporary argument storage, and four external data locations. It calls two dependencies before performing its own destination writes.

The function does not construct or clear an entire object. It always writes eight destination fields after both dependencies return normally. It writes two additional fields only when the mode read from the context is 0, 1, or 2.

Unsupported modes still cause external-data reads, including a read of the mode-two source, but cause no direct write to destination +104 or +108. There is no explicit error result or rollback.

**Inferred intent:** the destination resembles a structured record with a fixed leading discriminator, dependency-adjusted arguments, context-derived fields, and a mode-dependent pair. The semantic meanings of the record, discriminator, and modes are not established.

### Mode acquisition and external reads

1. Reads and captures the pair source.
2. Reads and captures the 32-bit mode at context +108.
3. Reads and captures the mode-zero source.

These reads occur regardless of which mode was captured. In particular, the mode-zero source is read for mode 1, mode 2, and unsupported modes, even though those paths do not use its captured value for a destination write.

Subsequent reads depend on the captured mode:

- **Mode 0:** no additional external read is shown before writing the mode-dependent pair.
- **Mode 1:** the pair source is read a second time.
- **Any mode other than 0 or 1:** the mode-two source is read. Only after this read does the function distinguish mode 2 from unsupported modes.

Thus, reading the mode-two source does not imply that the mode is 2 or that either mode-dependent destination field will be written.

The mode is compared for exact equality with 0, 1, and 2. Although represented as a signed 32-bit integer in the supplied source, the recognized cases are the same three bit patterns under either signed or unsigned interpretation. All other 32-bit patterns are unsupported.

| 0 | None | Captured mode-zero value | Zero |
