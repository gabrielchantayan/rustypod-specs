# F-c62c725e64ae

## Purpose

F-c62c725e64ae is a globally configured dispatcher. It can capture its four arguments, invoke either of two dependencies, transform integer results, select configured values, and return a retained unsigned result.

The arguments alone do not determine its behavior. Global words supply the initial selector, dispatch origin, destinations, multipliers, dependency options, and fallback values. Depending on those words, execution can return without capturing arguments, call dependencies with zero-initialized retained values, revisit states, or continue indefinitely.

No higher-level purpose—such as allocation, transfer, validation, or resource management—is established. The contract below describes the supplied static representation, not an inferred domain operation.

## Behavior

### Entry and retained state

The entry global reads occur in this order:

1. Multiplier B, retained for the invocation.
2. Multiplier A, retained for the invocation.
3. Entry selector, reduced by 11 and retained as the fallback selector.
4. Entry selector again, retained as the initial current selector.

The two entry-selector reads are independent. The fallback selector need not equal the initial selector minus 11 if the source changes between reads.

Before dispatch, the following retained values are zero:

- Return accumulator.
- Captured first, second, and fourth arguments.
- Saved first-argument value.
- Working operand.
- Secondary operand.
- Current arithmetic value.
- Retained, A-multiplied result of F-f0c4ba604fa0.

Arguments are captured only at index 13. Reaching another state first uses the zero-initialized values where applicable.

Each dispatch reads the dispatch origin anew and selects an index by subtracting it from the current selector. No iteration limit or automatic escape is established.

### Destination sampling rule

Every two-candidate routing state reads its destination slot **twice**, whether or not both candidate values will be selected:

- The first read supplies the **adjusted** candidate.
- The second read supplies the **unadjusted** candidate.
- The condition selects between those independently sampled candidates.

This applies to indices **0, 1, 8, 9, 12, 16, and the default-handled states, including index 4**. It is not a single destination read followed by an optional adjustment.

Index 1 has an additional ordering constraint: its Mix multiplier read occurs **between** the adjusted-candidate and unadjusted-candidate destination reads.

The saved first-argument value is not updated here. Recapturing arguments therefore does not itself refresh the value later supplied in the fourth position to F-f0c4ba604fa0.

## Acceptance examples

These are conditional static consequences, not executed tests. They assume 32-bit words, defined arithmetic for the values involved, and normal dependency return where applicable.

### Immediate return

If the initial selector minus the sampled dispatch origin is 17, the function returns zero without calling either dependency. Incoming nonzero arguments do not alter that result.

### Captured unsigned operand reaches the accumulator

Assume stable configuration routes through indices 13, 1, 2, and 17, with \(B=3\), third argument 5, and Mix multiplier zero.

The working operand becomes 15. Index 1 produces 15. Index 2 sets the accumulator to 45. Index 17 returns 45. The route is a configuration precondition, not an intrinsic sequence.

### Saved first argument remains independently retained

If the first argument is 9 and execution visits index 13 followed by index 0 without visiting index 9, F-f0c4ba604fa0 receives zero in its fourth position.

If index 9 executes after capture and before the call, that position receives 9. A later argument-capture state alone would not refresh the saved value.

### Index 1 uses the earlier sample for its adjusted route

Suppose the first Destination 1 read yields 100, the intervening Mix multiplier read yields zero, and the second Destination 1 read yields 200.

If the working operand has bit 31 clear, the computed value also has bit 31 clear and the next selector is **105**, not 205. Both destination reads still occur.

If the working operand instead has only bit 31 set, the next selector is **200**. The first sample is not reused for that route. These are selector values; the next dispatch still subtracts a newly read origin.

### Index 0 samples both destinations after mixing

Suppose index 0 completes mixing, then its first Destination 0 read yields 100 and its second yields 200.

- Clear bit 31 selects **88**.
- Set bit 31 selects **200**.

Neither destination sample precedes that state's Mix multiplier read. The unselected candidate is nevertheless sampled.

### Complement changes the high-bit decision

At index 8, let both cached multipliers be 1 and the Mix multiplier be zero.

- A dependency result of zero produces an all-one current value and selects the second, unadjusted Destination 8 sample.
- A dependency result of 1 produces a current value with bit 31 set as well.

The route is determined by the transformed value, not by a presumed dependency success convention.

### Unsigned accumulator multiplication wraps

If index 2 executes with \(B=2\) and current value \(2^{31}+1\), its unsigned multiplication sets the accumulator to 2 modulo \(2^{32}\). A subsequent index 17 returns 2.

### Configuration can prevent termination

If a default-handled state has a nonzero captured fourth argument and each selected unadjusted destination leads back to the same default-handled index, execution continues indefinitely. No timeout, error return, or loop escape is shown.
