# F-2bbb9559ca78

## Purpose

F-2bbb9559ca78 performs a short, ordered initialization sequence involving two dependencies and two externally stored 32-bit values.

On the normal path, it obtains a base address from F-da04303b789f, writes one externally supplied word at that address, and passes an address 232 bytes beyond that base to F-e194f3fbdfaa. It then uses the second dependency’s result as another base address, clears four selected 32-bit fields, and writes a second externally supplied word into a fifth field.

This is a description of the operations established by the supplied static evidence. An object-initialization or construction role is plausible, but neither the object type nor either dependency’s semantic role is established. In particular, the first stored word must not be classified as a dispatch pointer, type identifier, or ownership marker without additional evidence.

## Behavior

1. Invoke F-da04303b789f without explicit arguments and retain its returned address as the primary base.
2. Read external word A and store that 32-bit value at primary-base offset 0.
3. Form the interior address, 232 bytes beyond the primary base.
4. Invoke F-e194f3fbdfaa with that interior address as its sole explicit argument.
5. Interpret the returned result as the secondary base.
6. Store a 32-bit zero at secondary-base offset 16.
7. Store a 32-bit zero at secondary-base offset 20.
8. Store a 32-bit zero at secondary-base offset 24.
9. Store a 32-bit zero at secondary-base offset 32.
10. Read external word B and store that 32-bit value at secondary-base offset 28.
11. Return without an explicit value.

The directly visible body contains no conditionals, loops, retries, or alternative successful paths.

### Timing of external reads

External word A is read after F-da04303b789f returns. Therefore, its stored value is not necessarily the value that existed when F-2bbb9559ca78 was entered.

External word B is read after F-e194f3fbdfaa returns and after all four zero stores. Its value is not captured before the dependency calls.

Neither dependency is known to preserve these external locations. Consequently, a specification that substitutes entry-time snapshots for either external read would be stronger than the evidence supports.

The four zero stores also precede the read of external word B. If one of those stores aliases B’s storage, the final read can observe the overwritten value. No non-aliasing guarantee is available.
