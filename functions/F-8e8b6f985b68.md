## Behavior

1. Read the integer stored at the caller-supplied address.
2. Add 292 to the value obtained from that read.
3. Interpret the resulting value as the location of a callable-pointer slot and read that slot.
4. Invoke the callable pointer obtained from the slot.
5. Return without a value if the invocation returns normally.

The dispatch decision therefore depends on two successive memory reads. The first supplies the base-like integer; the second supplies the actual call target.
