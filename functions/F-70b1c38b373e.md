# F-70b1c38b373e

## Purpose

The first argument has no effect on the established behavior. The second and third arguments independently enable writes: a non-null second argument receives one, and a non-null third argument receives zero. The second-argument write precedes the third-argument write.

## Behavior

### Normal execution

The observable memory operations have the following order:

1. If the second argument is non-null, the function writes the 32-bit value one to its destination.
2. After that conditional write, if the third argument is non-null, the function writes the 32-bit value zero to its destination.
3. After both conditional operations complete, the function returns the 32-bit value one.

These operations are independent in their selection. A null second argument does not prevent the third-argument write. A null third argument does not prevent the second-argument write. Supplying two null pointers suppresses both writes but does not change the return value.

No prior destination value is needed. The visible behavior contains no read of either destination’s existing contents, no comparison with those contents, and no read-modify-write operation. The function does not preserve or merge any part of a previous 32-bit destination value.

The first argument is not used to select a branch, calculate a result, locate memory, or supply either stored value. Even if its bits could be interpreted elsewhere as an address or handle, this function does not use it in that way.

### Aliasing and ordering

If the two pointer arguments identify the same valid 32-bit destination, the function first writes one and then writes zero to that destination. After normal completion, the destination contains zero and the return value is one.

This is not equivalent to omitting the first write merely because the final value is zero. The supplied behavior includes both writes in the stated order. That distinction matters wherever individual writes are externally observable.
