# F-c72f213c7782

## Purpose

F-c72f213c7782 conditionally updates an object and invokes a sequence of external operations when a linked 32-bit value differs from the object’s cached value.

The established behavior is change detection, an early cache update, selection of an operation based on a scaled version of the new value, and two trailing dependency calls. Every normally completing path returns the 32-bit value 1.

An inferred interpretation is a graphical update involving a displacement, an optional region operation, and subsequent presentation or synchronization. The available evidence does not establish those meanings. The dependency arguments and object offsets, rather than graphical terminology, define this contract.

## Interface

### Input

The function takes one address identifying a mutable object. The observed accesses require these fields:

| Object offset | Width | Observed use |
|---|---:|---|
| +0x10 | 32 bits | Second argument of the first trailing F-1d891874186d call |
| +0x1c | 32 bits | Second argument of the second trailing F-1d891874186d call |
| +0x20 | 32 bits | First argument of the second trailing F-1d891874186d call |
| +0x24 | 32 bits | First argument of F-a05963f65233 and F-460b2abbbbbe, and of the first trailing F-1d891874186d call |
| +0x28 | 32 bits, used as signed | Dimension-like value used in branch selection and span calculation |
| +0x2c | 32 bits | Extent-like argument supplied twice to F-a05963f65233 |
| +0x44 | 32-bit address-like value | Identifies a linked record |
| +0x48 | 32 bits | Cached value; compared and conditionally overwritten |

The linked record must expose a readable 32-bit signed value at offset +4.

These offsets establish required accesses, not a complete object layout. Field names, allocation sizes, alignment guarantees, and the validity rules for dependency arguments are not provided.

### Output

On normal completion, the function returns a 32-bit value of 1:

- when the linked value equals the cached value;
- when a changed value takes the zero-displacement operation path;
- when a changed value takes the positive-displacement operation path;
- when a changed value bypasses that operation.

No observed dependency return value affects this result.

### Preconditions

The input object and linked record must support the accesses taken by the selected path. The object’s cache field must be writable on changed-value paths.

The values passed to dependencies must satisfy those dependencies’ contracts. Those contracts are unavailable here; this function performs no visible validation of them.

No ownership transfer is established. The function itself performs no explicit allocation or release, but the dependencies’ memory and ownership effects are unknown.

## Behavior

### 1. Read the linked value and detect a change

The function first reads the address-like field at object offset +0x44, then reads the 32-bit value at offset +4 in that linked record. It compares this captured value against the object’s 32-bit cache at +0x48.

If the values are equal, it immediately returns 1. On this path:

- no object field is written by the function;
- none of the three dependencies is called;
- the fields used only for operation selection and trailing calls are not explicitly read.

The linked value is captured once. Later changes to the linked record do not cause this invocation to refresh that captured value.

### 2. Derive the selection value

For a changed linked value, the function derives a signed selection value by adding 65,535 to the captured value and then shifting the result right by 16 bits with signed interpretation. It then raises any result below 8 to 8.

Where the addition is representable and the right shift behaves as an arithmetic signed shift, the pre-clamp value is:

\[
\left\lfloor\frac{V+65{,}535}{65{,}536}\right\rfloor
\]

where \(V\) is the captured signed linked value.

For nonnegative values that do not overflow the addition, this is upward rounding in units of 65,536. After the minimum is applied, the selection value is never less than 8.

The addition is a 32-bit signed operation in the supplied representation. Behavior at signed overflow is not independently established. The mathematical formula must not be extended across overflow without an explicit machine-arithmetic assumption.

### 3. Update the cache before making external calls

The function writes the captured linked value to object offset +0x48 before reading the dimension and extent fields used for the selected operation, and before invoking any dependency.

This ordering is observable. In particular:

- dependencies may observe the new cached value;
- the cache records the linked value, not the scaled selection value;
- there is no explicit rollback if a later operation fails or does not return normally.

A cache update therefore establishes that this invocation detected a change, not that all subsequent work completed successfully.

### 4. Select the optional operation

There are three cases.

#### Selection value is 8

Because the selection value has already been clamped to at least 8, the branch testing whether it is below 9 selects exactly the value 8.

The function:

1. Reads the dimension-like field at +0x28 as the operation span.
2. Reads the extent-like field at +0x2c.
3. Sets the operation displacement to zero.
4. Reads the operation target at +0x24.
5. Calls F-a05963f65233 with nine 32-bit arguments, in this positional order:

| Position | Value |
|---|---|
| 1 | Captured operation target |
| 2 | 0 |
| 3 | 0 |
| 4 | 0 |
| 5 | 0 |
| 6 | Captured span |
| 7 | Captured extent |
| 8 | The same captured span |
| 9 | The same captured extent |

This case still invokes F-a05963f65233. A zero displacement is not treated as grounds to skip the call.

No positivity or range check is applied to the span or extent on this path.

#### Selection value is at least 9, and dimension minus 4 is no greater than it

The function first reads the signed dimension-like field at +0x28 and compares the selection value against that dimension minus 4.

When the signed relation

\[
\text{dimension}-4 \leq \text{selection value}
\]

holds, it:

1. Reads the operation target at +0x24.
2. Skips F-a05963f65233.
3. Calls F-460b2abbbbbe with that target and a second argument of 0.

The extent field at +0x2c is not explicitly read on this path.

The subtraction is also a 32-bit signed operation whose overflow behavior is not established by independent execution evidence.

#### Selection value is at least 9, and dimension minus 4 is greater than it

When the preceding relation is false, the function:

1. Reads the extent-like field at +0x2c.
2. Reads the dimension-like field at +0x28 again.
3. Subtracts the selection value from this second dimension read to obtain the span.
4. Reads the operation target at +0x24.
5. Calls F-a05963f65233 with nine 32-bit arguments:

| Position | Value |
|---|---|
| 1 | Captured operation target |
| 2 | Selection value |
| 3 | 0 |
| 4 | 0 |
| 5 | Selection value |
| 6 | Calculated span |
| 7 | Captured extent |
| 8 | The same calculated span |
| 9 | The same captured extent |

The dimension read used for the comparison and the dimension read used for the span are distinct explicit accesses. They must not be treated as an established single snapshot.

If the dimension remains stable and arithmetic is representable, the selected branch implies a span greater than 4. That implication does not establish a validation guarantee in the presence of intervening memory changes.

### 5. Complete the changed-value path

After either path that calls F-a05963f65233, the function reads +0x24 again and calls F-460b2abbbbbe with that newly read target and a second argument of 255.

Consequently, the target passed to F-460b2abbbbbe is not necessarily the target previously passed to F-a05963f65233. The latter dependency’s effects on the object or related state are unknown.

After F-460b2abbbbbe returns, all changed-value paths make two F-1d891874186d calls in this order:

1. Arguments read from object offsets +0x24 and +0x10.
2. Arguments read from object offsets +0x20 and +0x1c.

The fields for the second call are read after the first call returns. The function therefore does not establish one shared snapshot for these trailing calls. Within an individual call, the evidence does not establish an order between fetching its two argument fields.

After the second trailing call returns, the function returns 1.

## Side effects

The sole explicit object write is the 32-bit cache update at +0x48 on a changed-value path.

External side effects can arise from:

- zero or one call to F-a05963f65233;
- exactly one call to F-460b2abbbbbe on a changed-value path;
- exactly two calls to F-1d891874186d on a changed-value path.

Those counts assume the earlier calls return normally. An unchanged-value path makes no dependency calls.

The function does not explicitly allocate, free, acquire, or release anything. This observation does not constrain what a dependency may do. In particular, dependencies must not be assumed to preserve globals, preserve the input object, or retain the validity of memory needed by later accesses.

There is no explicit error reporting, retry, compensating action, or rollback. Invalid memory, invalid dependency arguments, and dependency failures have no specified recovery behavior in the supplied evidence.

## Acceptance examples

These are conditional contract examples, not executed tests. Unless noted otherwise, they assume valid storage, stable object fields except for the explicit cache write, representable arithmetic, arithmetic signed right shift, and dependencies that return normally without modifying the object.

### Unchanged linked value

If the linked value and cache both contain 700,000:

- the result is 1;
- the cache is not rewritten;
- no dependency is called;
- the dimension and extent fields are not needed by this path.

### Minimum selection takes the zero-displacement operation

If the linked value changes to 0, the derived value before clamping is 0 and the selection value becomes 8.

For a dimension of 100 and an extent of 20:

- the cache is written with 0;
- F-a05963f65233 receives arguments corresponding to target, 0, 0, 0, 0, 100, 20, 100, 20;
- F-460b2abbbbbe receives the subsequently read target and 255;
- the two trailing calls occur in their specified order;
- the result is 1.

### Boundary between the minimum and positive-displacement cases

A changed linked value of 524,288 produces a selection value of 8. A changed value of 524,289 produces 9.

The former takes the zero-displacement operation path regardless of the dimension threshold. The latter uses the dimension-minus-4 comparison.

### Positive displacement with sufficient span

For a changed linked value of 524,289 and a stable dimension of 20, the selection value is 9. Since 16 is greater than 9, the optional operation occurs with displacement 9 and span 11.

F-460b2abbbbbe then receives a second argument of 255.

### Exact skip threshold

For that same linked value and a dimension of 13, dimension minus 4 equals 9.

Equality takes the skip path:

- F-a05963f65233 is not called;
- F-460b2abbbbbe receives a second argument of 0;
- both trailing calls still occur.

### Dependency changes the target

If F-a05963f65233 returns after changing the object’s +0x24 field, F-460b2abbbbbe receives the replacement field value because the target is explicitly reread.

No analogous preservation assumption is permitted for fields read after either trailing dependency call.

## Evidence

The supplied static representation establishes:

- the explicit 32-bit field accesses and cache write;
- equality-based early return;
- signed scaling and minimum selection;
- the three operation-selection cases;
- dependency argument positions and call order;
- target rereads after dependency boundaries;
- unconditional return of 1 on every normally completing path.

It does not supply dependency implementations, runtime observations, allocation contracts, concurrency guarantees, or machine-level confirmation of arithmetic edge behavior. The contract therefore separates directly established accesses and control flow from conditional arithmetic conclusions and unknown external semantics.
