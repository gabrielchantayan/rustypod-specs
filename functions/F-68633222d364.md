### 2. Apply unsigned shifts in reverse word order

The function processes the temporary words from the fourth word back through the first word. Each receives an unsigned right shift by one bit.

For an original 32-bit value \(x\), the transformed value is:

\[
\left\lfloor x / 2 \right\rfloor
\]

The incoming high bit is zero. This is not a sign-preserving shift. The low bit is discarded.

The observable order of temporary-word updates is therefore:

1. Fourth word.
2. Third word.
3. Second word.
4. First word.

Each word is shifted exactly once. No dependency call occurs between these updates.

### 3. Modify the low half of the fourth word

After all four shifts, the function performs an additional narrowing operation on the fourth word.

Its low 16 bits are replaced with the zero-extended value of its low eight bits. Its upper 16 bits remain unchanged. Consequently:

- Bits 0–7 retain their values from the shifted word.
- Bits 8–15 become zero.
- Bits 16–31 retain their values from the shifted word.

If \(q\) is the fourth word after its unsigned shift, the resulting word is:

\[
(q \mathbin{\&} \text{0xFFFF0000})
\mathbin{|}
(q \mathbin{\&} \text{0x000000FF})
\]

This does **not** truncate the entire fourth word to eight bits or 16 bits.

This description concerns numeric bit positions. The supplied material does not independently establish byte order, so a portable memory-byte encoding of the four words is not part of the established contract.
