## Behavior

1. Evaluate whether the third input equals the integer value one.
2. Select zero when that equality holds; otherwise retain the supplied third-input value.
3. Invoke F-f2d9a0ba537a once with the seven ordered arguments described above.
4. If the dependency returns normally, complete the wrapper without exposing a return value.

There is no visible branch that skips the dependency call. A third input of one changes the value passed to the dependency; it does not suppress invocation. A third input of zero also results in an invocation.

The normalization is many-to-one: original third-input values zero and one both produce zero in the third dependency argument. Consequently, with all other inputs equal, the dependency receives the same argument tuple for those two cases. This establishes equivalence of the arguments supplied by the wrapper, not equivalence of whole-program behavior under different external state.

All third-input values other than one are preserved. Negative values are not rejected or clamped. Values greater than one are not reduced to a Boolean value. The wrapper performs no visible range validation beyond the equality test.
