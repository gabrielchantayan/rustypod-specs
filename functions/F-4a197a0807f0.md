# F-4a197a0807f0

## Purpose

F-4a197a0807f0 compares two records whose relevant fields are unsigned 32-bit words. It returns a 32-bit indicator of whether the record supplied through the third argument is lexicographically greater than the record supplied through the second argument.

The first word is the primary comparison field. The second word breaks a primary-field tie. For stable input memory:

- Return **1** when the third-argument record has a greater primary field.
- Return **1** when the primary fields are equal and the third-argument record has a greater secondary field.
- Return **0** otherwise, including complete equality.

This is a two-valued predicate, not a three-way comparison. A return value of 0 does not distinguish equality from a lesser third-argument record.

The apparent intent is an unsigned comparison of two-part ordered values. The source does not establish whether those values represent a larger integer, a timestamp, a key, or another domain-specific object.

## Behavior

### Comparison rule

The candidate is compared against the reference, not the reverse.

A greater candidate primary word produces 1 regardless of either secondary word. A lesser candidate primary word produces 0 regardless of either secondary word. Equal primary words cause an unsigned comparison of the secondary words: a greater candidate secondary word produces 1; an equal or lesser candidate secondary word produces 0.

All comparisons are unsigned. In particular, a word with its most significant bit set is not treated as negative.

There is no addition, subtraction, carry propagation, concatenation, or arithmetic normalization. Consequently, the comparison itself has no integer-overflow boundary. Values from 0 through 4,294,967,295 participate directly in the unsigned ordering.

### Conditional evaluation and reads

The supplied expression uses short-circuit evaluation. Its source-level evaluation has these stages:

1. It evaluates whether the candidate primary word is less than or equal to the reference primary word.
2. If that condition is false, it returns 1 without evaluating the later comparisons.
3. If that condition is true, it evaluates whether the primary words differ.
4. If they differ, it returns 0 without evaluating either secondary word.
5. If they do not differ, it evaluates whether the candidate secondary word is less than or equal to the reference secondary word. That condition produces 0 when true and 1 when false.

These stages establish conditional evaluation, but not an exact physical load trace.
