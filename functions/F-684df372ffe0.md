# F-684df372ffe0

## Purpose

F-684df372ffe0 partially updates a caller-supplied record using a descriptor, two unsigned calculation inputs, retained destination contents, and a global expression evaluated near the end of the operation.

The update copies metadata and selectors, conditionally replaces two scaling fields, stores two calculated results, and finally assigns the global expression’s value to a 32-bit destination field.

This is not a complete initializer. Unrecognized selectors preserve existing scaling fields, whose contents then influence the calculations. No explicit rejection or default assignment accompanies those selectors.

The calculations are consistent with a linear offset and an offset within 8-by-8 groups. This is **inferred intent**, not an established application-level interpretation. Units, resource types, valid ranges, and coordinate meanings are unknown.

Two representation details are essential:

- The first scaling count comes from a **32-bit read spanning both scaling fields**, followed by narrowing. A direct 16-bit read of the first field is not generally equivalent.
- The final destination store is 32 bits, but the global expression’s type, read width, and assignment conversion are not established. The destination width does not establish the global’s representation.

## Behavior

### Metadata observations and updates

The metadata updates precede selector handling, in this order:

1. The first observation of descriptor `0x94` is narrowed to signed 16-bit form and stored at destination `0x08`.
2. Descriptor `0x98` is read as a 32-bit quantity, narrowed to signed 16-bit form, and stored at destination `0x0A`.
3. Descriptor `0x94` is observed again and copied to the 32-bit field at destination `0x0C`.
4. Descriptor `0x94` is observed a third time, as unsigned 32-bit W, which is retained for both calculations.

These are logical source-level observations and updates, not guarantees about physical bus transactions.

Under conventional low-bit-preserving narrowing, each 16-bit metadata store receives the source’s low 16 bits. Exact conversion behavior outside the signed 16-bit range is environment-dependent and remains **documented_only**.

Once captured, W is reused. A subsequent change to its descriptor location does not replace the captured operand.

### Selector handling

Selector B is read from descriptor `0x65` only after the selector-A stage. It is copied to destination `0x15` before its conditional scaling update.
