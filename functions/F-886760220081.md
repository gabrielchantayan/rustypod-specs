# F-886760220081

## Purpose

1. A signed subtraction of two dependency results must produce a value greater than −1.
2. A conditionally invoked final dependency must return a value other than −1.

On normal completion, the function returns exactly 1 when both gates pass and exactly 0 otherwise.

**Established static evidence:** the function obtains a base value from a global location, reads a 32-bit slot through that base, reads a 32-bit field through its second argument, and invokes dependencies in a fixed order. The final dependency is conditional.

**Inferred intent:** the function appears to compare two quantities before attempting an operation involving the second argument and the captured slot value. 6. Invoke F-1cb585febd84 with the captured slot value.
7. Subtract the result of F-1cb585febd84 from the result of F-d8cbf9aa79a9 and test whether the signed difference is greater than −1.

### Final sentinel gate

F-0d3d19f29b0f is called only when the subtraction-based gate passes.

- Exactly −1 produces a function result of 0.
