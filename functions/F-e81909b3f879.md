# F-e81909b3f879

The established behavior is structural rather than semantic: request storage using the value 240, pass the result and the first input to an initialization dependency, overwrite the first 32-bit word of the resulting object with a value read from static storage, invoke another dependency using an address 180 bytes into that object, and populate three fields relative to its result.
