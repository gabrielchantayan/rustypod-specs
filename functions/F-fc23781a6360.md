# F-fc23781a6360

## Purpose

F-fc23781a6360 transforms state at a supplied address, optionally processing input bytes through one of two paths selected by a state field. It returns no value.

The established behavior includes a four-component, four-region compression path and a five-component, four-region compression path. Their resemblance to familiar 64-step and 80-step compression algorithms is **inferred intent**, not an established compatibility guarantee. Byte decoding, configuration values, table contents, and arithmetic semantics affect the result.

An unsupported selector bypasses input processing but still reaches four state updates. It is neither an explicit error nor a guaranteed no-op.

## Behavior

### Arithmetic model and qualifications

Unless otherwise qualified, arithmetic equations describe 32-bit bit patterns, with addition, subtraction, multiplication, and complement reduced modulo \(2^{32}\). Comparisons controlling the described loops use unsigned 32-bit indices.

This model does not establish portable signed-overflow semantics for every expression in the supplied representation. Signed shifts and exceptional shift counts are addressed separately.

**Normalized working-state equations require configuration stability across the reads they combine.** In particular, a subtraction of one read of \(\beta\) cannot be cancelled against a later, potentially different read. The same limitation applies to counter increments, schedule decoding, and final writeback.

Each input byte \(x\), interpreted as unsigned, is decoded as:

\[
d(x)=(181x-220)\bmod256.
\]

Thus \(d(0)=36\), \(d(1)=217\), and \(d(255)=111\). Assembly of decoded bytes is explicit numerical assembly, not a host-endian word load.

### Common initialization and dispatch

The initial state-access sequence is H1, H0, H2, H3. Each is multiplied by a read of \(S\); H0’s product additionally has a read of \(\beta\) subtracted.

Let \(\alpha\) denote the stored, bias-adjusted first working component. The initial working values are therefore:

\[
\alpha=S_0H0-\beta_{\mathrm{initial}},\qquad
B_w=S_1H1,\qquad C=S_2H2,\qquad D_w=S_3H3.
\]

Subscripts distinguish read occurrences, not separate configuration locations.

After these operations, the function reads the selector word. **Before branching, it also reads \(S\) for a right shift by 31 and reads \(\beta\), forming an input-loop seed from their difference.** These additional configuration reads occur for selector 1 and unsupported selectors too, even though those paths do not use that seed.

Dispatch uses only the selector’s low byte:

- 1: first path.
- 2: second path.
- Any other value: skip both paths and enter common writeback.

H4 is not accessed during common initialization.

Under stable configuration, the normalized first component is \(A=\alpha+\beta=SH0\). Without stability, restoring the bias produces \(S_0H0-\beta_{\mathrm{initial}}+\beta_{\mathrm{restore}}\), not necessarily \(S_0H0\).

### Selector 1: input construction

The path forms a correction \(Q\) by XORing a read of \(Z\) with the result of converting another read of \(Z\) to signed 32-bit form and shifting it right by 29. The two occurrences are separate reads. Negative signed-right-shift behavior depends on the execution model.

A further read of \(Z\) seeds input construction. The first tested byte position is that seed plus \(Q\), modulo \(2^{32}\). Because \(Q\) is retained locally, subsequent tested positions advance by four without further configuration reads for that advancement.

A position \(p\) is accepted only when its unsigned value is below 64. The path stores:

\[
L_{\lfloor p/4\rfloor}
=
d(input[p])
+2^8d(input[p+1])
+2^{16}d(input[p+2])
+2^{24}d(input[p+3])
-Q.
\]

The four byte contributions occupy disjoint bit fields; the expression is little-endian numerical assembly. The first byte is read and decoded in a separate preceding operation; the remaining byte reads occur within the assembly expression.

Starting at zero initializes 16 words from bytes 0 through 63. An unaligned start changes both the bytes consumed and the workspace slots initialized. Accepted positions 61–63 read beyond byte 63. Skipped slots remain uninitialized unless otherwise written within this invocation.

After input construction, **the function captures \(T-64\)** as the message-selector-table base. Later round-constant accesses reread \(T\); they do not use that captured base.

### Selector 1: rounds

A fresh read of \(Z\) seeds the round counter. Each condition adds a fresh read of \(\beta\) to its retained counter representation. Successful rounds prepare the next representation by subtracting another read of \(\beta\) from the current index plus one.

Consequently, indices advance by one only when the relevant bias reads agree. Failed conditions also read \(\beta\). The four successive unsigned bounds are 16, 32, 48, and 64.

For an accepted index \(t\):

- A byte at captured selector base plus \(t\) is multiplied by 247 and reduced modulo 256. This directly indexes the local workspace.
- A 32-bit constant at a newly read \(T+4t\) is multiplied by a read of \(P\).
- A byte at a newly read \(V+t\) is multiplied by 95 and reduced modulo 256.
- The right-shift count is \((32-\text{decoded rotation})\mathbin{\&}31\).

There is no additional reduction of the message selector to 16 or even to the workspace capacity of 80 words.

With stable configuration and initialized selected entries, define \(W_t=L_{\text{selected}}+\beta\) and \(A=\alpha+\beta\). The regions use:

| Region | Boolean contribution \(f\) |
|---|---|
| Indices below 16 | \((B_w\land C)\lor(D_w\land\neg B_w)\) |
| 16–31 | \((B_w\land D_w)\lor(C\land\neg D_w)\) |
| 32–47 | \(B_w\oplus C\oplus D_w\) |
| 48–63 | \(C\oplus(B_w\lor\neg D_w)\) |

For a nonzero right-shift count \(r\), the normalized round is:

\[
N=B_w+\operatorname{ROR}_r(A+f+W_t+PK_t),
\qquad
(A,B_w,C,D_w)\leftarrow(D_w,N,B_w,C).
\]

This is a conditional mathematical summary, not an unconditional changing-configuration model. The underlying operations restore and subtract bias through separate reads. The first region reads bias separately for the first component and message contribution; later regions use twice one bias read in the combined sum. The first region also performs an additional bias-restoration computation whose result is not subsequently consumed.

If \(r=0\), the literal shift expression includes a complementary shift by 32. Its exact behavior is unresolved; treating it as a defined rotate by zero would add an unsupported assumption.

### Selector 2: input construction

H4 is read after selecting this path and before input processing. Its saved value is multiplied by a later read of \(S\), after initial input construction, to initialize the fifth working component \(E\).

Each input-loop condition adds a fresh \(\beta\) read to the seed or counter retained from the preceding operation. Under bias stability, the first tested position equals the earlier \(S\)-shift result, and subsequent positions advance by four. Without that stability, neither cancellation nor stride is guaranteed.

For each accepted unsigned position \(p<64\), the path stores:

\[
L_{\lfloor p/4\rfloor}
=
2^{24}d(input[p])
+2^{16}d(input[p+1])
+2^8d(input[p+2])
+d(input[p+3])
-\beta_{\mathrm{store}}.
\]

This is big-endian numerical assembly. The next counter representation is prepared before the input assembly operation, using a separate bias read. The byte-read order within the assembly expression is not established.

Starting at zero produces the conventional 16 initial words. The same unaligned-position and trailing-byte risks as in the first path apply.

### Selector 2: schedule expansion

The local workspace contains 80 32-bit words. Expansion begins from a read of \(J\), with a fresh bias read added during each condition evaluation.

**Every expansion condition also reads \(Z\), before deciding whether the unsigned index is below 80. This includes the terminating evaluation.** The terminating read supplies the retained seed for compression; an earlier \(Z\) value is not substituted.

An accepted expansion index combines entries at offsets −3, −8, −14, and −16. Each entry has a separate bias read added before the four results are XORed. The XOR is rotated left by one, then a further bias read is subtracted for storage. Counter preparation subtracts another bias read.

Under stable bias, decoded words \(W_t=L_t+\beta\) satisfy:

\[
W_t=\operatorname{ROL}_1
(W_{t-3}\oplus W_{t-8}\oplus W_{t-14}\oplus W_{t-16}).
\]

Conventional expansion requires \(J+\beta=16\). Earlier starts can reference preceding or uninitialized storage; later starts can leave gaps.

### Selector 2: rounds

The initial tested compression index is the terminating expansion-condition read of \(Z\), plus a new bias read. Subsequent conditions and counter updates use separate bias reads. Stable bias is required for unit advancement.

The four unsigned region bounds are 20, 40, 60, and 80. Each executed round rereads \(U\) and \(M\), selecting constant-table entry 0, 1, 2, or 3 according to its region. Constants are not captured once per region.

Under stable configuration and valid schedule entries:

| Region | Boolean contribution \(f\) |
|---|---|
| Below 20 | \((B_w\land C)\lor(D_w\land\neg B_w)\) |
| 20–39 | \(B_w\oplus C\oplus D_w\) |
| 40–59 | \((B_w\land(C\lor D_w))\lor(C\land D_w)\) |
| 60–79 | \(B_w\oplus C\oplus D_w\) |

The normalized transition is:

\[
A'=\operatorname{ROL}_5(A)+f+E+W_t+MK_{\mathrm{region}},
\]

\[
(B_w',C',D_w',E')=(A,\operatorname{ROR}_2(B_w),C,D_w).
\]

The stored first component remains bias-adjusted under these stability assumptions.

### Writeback and configuration captures

Selector 2 first updates H4:

\[
H4\leftarrow R_h(S_hH4_{\mathrm{current}}+E).
\]

This rereads H4 and uses its own reads of \(R\) and \(S\). It occurs before the common captures below.

On every path, common writeback then **captures \(R\), followed by \(S\)**. Denote these captured values \(R_c,S_c\).

H0 does **not** use those captures. It uses separate fresh reads:

\[
H0\leftarrow
R_0(S_0H0_{\mathrm{current}}+\alpha+\beta_0).
\]

H1, H2, and H3 then use the captured values:

\[
H1\leftarrow R_c(S_cH1_{\mathrm{current}}+B_w),
\]

\[
H2\leftarrow R_c(S_cH2_{\mathrm{current}}+C),
\qquad
H3\leftarrow R_c(S_cH3_{\mathrm{current}}+D_w).
\]

The write order is H0, H1, H2, H3, preceded by H4 only for selector 2. Each destination is reread during its own update.

Thus configuration changes between capture and H0 evaluation can affect H0 differently from H1–H3. The order of reads within an individual writeback expression is not established.

For an unsupported selector, stable configuration and unchanged state reduce common writeback to:

\[
H_i\leftarrow R(2SH_i),\qquad i=0,1,2,3.
\]

Without bias stability, even the unsupported path’s H0 update can retain a difference between its initial and final bias reads.

## Acceptance examples

These are conditional static acceptance criteria, not executed results.

1. **Low-byte dispatch.** With equivalent surrounding memory and configuration, selector words `0x00000001` and `0xA5000001` select the same path. Both require a full selector-word read.

2. **Unsupported selector.** With selector low byte zero, stable \(S=R=1\), stable bias, and unchanged valid state, H0–H3 double modulo \(2^{32}\). No input bytes or H4 are accessed. The common post-selector shift/bias initialization still occurs.

3. **Fresh versus captured multipliers.** If common writeback captures \(R_c=3,S_c=5\), but H0 subsequently observes \(R_0=7,S_0=11\), H0 uses 7 and 11. H1–H3 use 3 and 5. H4, if selected, was already updated using its own observations.

4. **Bias does not unconditionally cancel.** On an unsupported path with unchanged H0 and stable \(S,R\), initial bias 4 and final H0 bias 9 produce the H0 expression \(R(2SH0+5)\), not \(R(2SH0)\).

5. **Byte order.** Bytes 0, 1, 0, 1 decode to 36, 217, 36, 217. Before correction, selector 1 assembles `0xD924D924`; selector 2 assembles `0x24D924D9`.

6. **Normal first-path extent.** Given input start zero, stable round-counter bias, round start zero, initialized selected words, valid tables, and defined rotation counts, selector 1 processes 64 input bytes and 64 rounds. It never accesses H4.

7. **Normal second-path extent.** Given input start zero, stable bias, expansion start 16, and compression start zero, selector 2 builds 16 input words, expands through word 79, and executes 80 rounds. The terminating expansion condition reads \(Z\); that observation seeds compression.

8. **Captured selector base.** If \(T\) changes after its selector-base capture, selector-byte accesses retain the captured base, while later round-constant accesses use newly read table bases.

9. **No invented rejection.** A decoded message selector outside initialized workspace has no explicit rejection result. A safe error return is not part of the established contract.
