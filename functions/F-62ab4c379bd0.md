# F-62ab4c379bd0

## Purpose

F-62ab4c379bd0 invokes a dependency to obtain a position-like result, then conditionally records the difference between that result and an input baseline as one byte in mutable state. Depending on the state and dependency results, it returns immediately, sets a status bit, or recursively repeats processing using the latest result as the next baseline.

The position-like interpretation and the purpose of the recorded byte are inferred intent, not established semantics. Established behavior is expressed below in terms of integer results, byte writes, state fields, dependency calls, and their ordering.

The function is not demonstrably transactional. Its initial dependency is always called, and a byte may be committed before later processing determines whether recursion occurs. No rollback is visible.

## Interface

### Inputs

The function takes two arguments:

- **State address:** a pointer to writable state organized as 32-bit words, with certain locations also interpreted as bytes or pointer-valued words.
- **Baseline:** a signed 32-bit integer used both as an argument to the initial dependency and as the subtrahend in the subsequent difference calculation.

The supplied representation uses 32-bit address-bearing values. Behavior on a different pointer-width model is not established.

The state address must be valid for every access reached on the selected path. In addition, the dependencies may require a larger or more constrained state object than the directly accessed locations establish. A non-null address alone is not a sufficient validity condition.

### Directly accessed layout

Offsets are measured in bytes from the state address.

| Offset | Width | Directly established use |
|---|---:|---|
| 0x00 | 32 bits | Status word. Selected paths read it, set a bit with a bitwise OR, and write it back. |
| 0x6C | 32 bits | Argument supplied to two dependencies. Its resource type is unknown. |
| 0x78 | 32 bits | Read and reduced to its low eight bits for a comparison. |
| 0xA1 | Address only | Distinguished address compared with the cursor value. No direct read or write at this offset is implied merely by the comparison. |

On the byte-recording path, the original cursor address must designate writable storage for one byte. Its relationship to the state object or any allocation boundary is unknown.

The comparison value at offset 0x78 is the low eight bits of a 32-bit value. This does not establish that it is stored as a byte at offset 0x78 on every byte order.

### Output

The function returns a signed 32-bit integer.

For every nonrecursive completion path, the return value is exactly the result obtained from F-df6609bc8e2d at the beginning of that invocation. When recursion occurs, the function instead returns the recursive invocation’s result, propagated unchanged through the waiting invocations.

There is no separately established error return. Status bits, dependency results, and early returns affect control flow, but the function does not directly replace its result with a failure sentinel.

## Behavior

### 1. Initial dependency and state observation

Every invocation first calls F-df6609bc8e2d with:

1. The state address.
2. The invocation’s baseline.
3. An integer zero.

The returned signed 32-bit integer becomes the invocation’s initial result.

Only after this call returns does the function read the cursor word at offset 0xA4. Consequently, cursor changes made by F-df6609bc8e2d are observed. There is no visible pre-call snapshot of the cursor, status word, or other state fields.

### 2. Distinguished-cursor path

The observed cursor address is compared with the address exactly 0xA1 bytes after the state address.

If the addresses are equal:

- The function reads the status word at offset 0x00.
- It sets bit 2, using the mask 0x00000004.
- It writes the resulting 32-bit status word back.
- It returns the initial result.

This path does not calculate the difference, advance the cursor, write a payload byte, or call the three later dependencies.

The comparison is address equality. The supplied evidence does not establish a broader range check, an end-of-buffer comparison, or validation of the cursor.

### 3. Difference classification

If the cursor does not equal the distinguished address, the function subtracts the baseline from the initial result and treats the difference as a signed 32-bit integer.

The first threshold test is whether this signed difference is less than 255.

If the difference is 255 or greater:

- The function reads the status word.
- It sets bit 3, using the mask 0x00000008.
- It writes the status word back.
- It returns the initial result.

No cursor update or payload-byte write occurs on this path.

If the difference is less than 255, the function next tests whether it is exactly zero. A zero difference causes an immediate return of the initial result, with no further direct state write and no later dependency call.

The signed threshold matters: a negative difference is less than 255 and is not rejected by this test. Except for zero, it proceeds to byte recording.

### 4. Cursor advance and byte recording

For a nonzero signed difference less than 255, the function performs these writes in the following order:

1. It writes the original cursor address advanced by one byte into the cursor field at offset 0xA4.
2. It writes the low eight bits of the difference to the original cursor address.

The second operation writes exactly one byte. A negative difference is therefore represented by its low eight bits. In particular, a nonzero difference can produce a zero-valued byte; the earlier zero check applies to the full signed difference, not to the byte that will be stored.

The order is observable if the cursor targets the state object, the cursor field itself, or another aliased location. The evidence provides no exclusion of such aliasing. It also does not establish that either write is atomic, synchronized, or safe for concurrent observation.

After both writes, the function calls F-8ff6310c8504 with the state address.

If that dependency returns any nonzero integer, the function returns the initial result. The cursor advance and byte write have already occurred and are not undone.

### 5. Comparison after a zero dependency result

If F-8ff6310c8504 returns zero, the function:

1. Reads the 32-bit field at offset 0x6C.
2. Calls F-a3abf174e781 with that value.
3. Reads the 32-bit field at offset 0x78 and reduces it to its low eight bits.
4. Compares the dependency’s full 32-bit unsigned result with that eight-bit value, numerically extended for comparison.

The dependency result is not itself reduced to eight bits. Thus, a return of 0x0000012A does not compare equal to a state value whose low byte is 0x2A.

If the values differ, the function returns the initial result. It performs no additional direct write on this path.

The comparison field is read after F-a3abf174e781 returns. Changes that dependency makes to offset 0x78 can therefore affect the comparison.

### 6. Matching comparison and recursion

If the comparison matches, the function:

1. Reads offset 0x6C again.
2. Calls F-1c4d822fa26c with that newly read value.
3. Calls F-62ab4c379bd0 recursively with the same state address and the current invocation’s initial result as the new baseline.
4. Returns the recursive result.

The second read at offset 0x6C is significant. F-a3abf174e781 may have changed that field, so the two dependencies are not guaranteed to receive the same argument.

The result of F-1c4d822fa26c is not used for a branch or as the function’s return value. Its side effects are not known, and recursion occurs only after it returns.

Each recursive invocation starts again with F-df6609bc8e2d. No termination bound, recursion-depth limit, or guaranteed progress condition is established.

## Side effects

Direct effects are limited to the following reachable operations:

- Setting status bit 2 when the observed cursor equals the distinguished address.
- Setting status bit 3 when the cursor differs and the signed difference is at least 255.
- Advancing the cursor field by one byte.
- Writing a single byte at the prior cursor address.

Each status update preserves other bits as observed by that particular status-word read. Neither update visibly clears any bit. These are read-modify-write operations, not established atomic flag updates.

All dependency calls may have additional effects. Their contracts are unavailable; they must not be assumed to preserve the state, global variables, external resources, or memory ownership.

These are conditional acceptance criteria derived from static evidence, not executed tests. Unless stated otherwise, arithmetic is representable, addressed storage is valid, and dependencies return normally.

1. **Distinguished cursor takes precedence over the difference.**

3. **Zero difference stops without recording.**

4. **A difference of 254 is recordable.**

5. **Negative differences are not rejected by the threshold.**

6. **A zero byte does not imply a zero difference.**  
   With baseline 300 and initial result 44, the difference is −256. The function advances a nondistinguished cursor and writes 0x00. It then calls F-8ff6310c8504 rather than taking the zero-difference return.
