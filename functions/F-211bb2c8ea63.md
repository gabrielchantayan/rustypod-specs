## Behavior

This address is not the first input word interpreted as an address. It points to a local cell initialized with that word.

The same first-input local cell is used for successive F-927fe5381082 invocations. There is no visible restoration of that cell between calls. If the first invocation changes it through the supplied address, the second invocation receives the address of the changed cell.

### Branch selection

The function first distinguishes a null destination from a nonnull destination.

- For a null destination, no destination-cell read occurs during branch selection.
- For a nonnull destination, the function reads the cell and compares it with zero.
- A nonzero value selects the direct path.
- A zero value selects the two-stage path.

This is an entry-time decision. The function does not explicitly reread the destination to reconsider that decision later.

### Direct path

This path applies when the destination is null or initially contains any nonzero 32-bit value.

The function invokes F-927fe5381082 once, supplying these five arguments in order:

1. The address of the local first-input cell.
2. The caller’s destination, unchanged, including null when applicable.

It returns the signed result of that invocation without an explicit transformation.

There is no direct destination write by F-211bb2c8ea63 on this path. A nonnull destination is nevertheless exposed to F-927fe5381082, so dependency-originated reads and writes remain possible.

All nonzero initial cell values select this same path. The branch makes no distinction between positive values, negative values, and values that might represent valid resources under an external convention.

This path applies only when the destination is nonnull and its initial cell value is zero.

The function invokes F-927fe5381082 with the same argument pattern as above, except that the second argument is null rather than the caller’s destination.

### Two-stage path: acquisition decision
