### Zero-result branch

On this branch, the function does not read the object field at byte offset 4 and does not read the payload at the address derived from that field. Consequently, validity of those conditional locations is not a requirement imposed by this caller’s zero-result path.

### Nonzero-result branch

That payload becomes the return value without a visible transformation.
