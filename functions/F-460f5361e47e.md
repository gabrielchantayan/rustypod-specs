# F-460f5361e47e

## Behavior

The first direct object access reads the byte at offset `+0x10`.

If that byte is zero, the function returns immediately:

- The count field is not read.
- No examination is requested.
- Neither escalation dependency is called.

If the byte is nonzero, processing continues. The function does not directly read the gate again during that invocation. A subsequent change to the gate therefore does not, by itself, disable remaining examinations.
