# F-606dcbb67768

## Purpose

F-606dcbb67768 conditionally recognizes a record associated with a primary object. Recognition requires two checks: a 32-bit field in the record must equal a 32-bit field in the primary object, and a second record field combined with a global value must produce zero.

A recognized record causes a call to F-3fac671648b8. A nonzero result from that dependency causes a further call to F-c5463d64be18 with the primary object and a difference calculated from two fields.

The function returns a 32-bit value of one for a recognized record and zero otherwise. One means that the recognition checks passed; it does not establish that the second dependency ran or that any downstream operation succeeded.

These are structural observations. The application meaning of the objects, fields, global value, and dependency operations is unknown.

## Behavior

### Recognition

The function first compares the record’s 32-bit field at +0x0C with the primary object’s 32-bit field at +0x44.

If they differ, the function returns zero. It does not proceed to the record field at +0x08, the global scalar, or either dependency.

If they are equal, the function tests whether the sum of the record’s 32-bit field at +0x08 and the global scalar equals zero.

If that zero test fails, the function returns zero and invokes neither dependency.

The second check is therefore conditional on the first. An implementation conforming to the established access structure must not make the second field or global read unconditional.

The first comparison is equality, not ordering. No signed less-than, greater-than, range, or magnitude interpretation is established.

### Recognized path

When both checks pass, the function calls F-3fac671648b8 with the primary object address.

If that dependency returns zero, F-c5463d64be18 is skipped and the function returns one. On this path, the function does not directly read the record field at +0x10 or the primary-object field at +0xAC.

If F-3fac671648b8 returns any nonzero value, the function obtains:

- The 32-bit field at record offset +0x10.
- The 32-bit field at primary-object offset +0xAC.

It forms a difference with the record field as the minuend and the primary-object field as the subtrahend. It then calls F-c5463d64be18 with:

1. The primary object address.
2. That difference.

After this call returns normally, the function returns one.

The condition on the first dependency’s result is zero versus nonzero. It is not restricted to a particular positive success value. A negative result also selects the second call.
