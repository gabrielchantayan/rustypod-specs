## Behavior

### Reset selection

The reset branch is selected when either of the following is true:

- Bit 21 of the control word is clear.
- All bits from 22 through 31 of the control word are clear.

Equivalently, reset is avoided only when bit 21 is set and at least one of bits 22 through 31 is set.

Bits are numbered from zero at the least significant bit. Control bits 0 through 20 do not influence this selection.

The upper-field condition includes bit 22. It must not be narrowed to bits 23 through 31 merely because the later payload shift discards bits 0 through 22.

### Base selection and first write

When reset is selected, the overflow indicator is examined:

- If it is nonzero, the implicit state base is replaced with the recovered stack-relative address eight bytes from a stack reference.
- If it is zero, the incoming state base remains in use.

The effective payload is then made zero. A four-byte zero is written at offset `0x180` from the resulting base.

When reset is not selected:

- The incoming state base remains in use, regardless of the overflow indicator.
- The incoming payload remains the effective payload.
- No write at offset `0x180` is shown.

The base replacement is a state change, not merely a choice between addresses for one store. The subsequent write at offset `0x188` uses that same selected base. No restoration of the earlier base is shown.

The stack-relative expression is evidence of the recovered address source, not proof of a particular stack-frame layout, writable buffer size, or ownership relationship.

### Second write

After the conditional reset work, the effective payload is logically shifted right by 23 bits. The result is written as a four-byte value at offset `0x188` from the selected base.

For a 32-bit unsigned payload:

- Only original payload bits 23 through 31 contribute to the result.
- The stored value is between 0 and 511 inclusive.
- The upper 23 bits of the stored four-byte value are zero.
- A reset always produces a stored value of zero.
- Without reset, a payload below `0x00800000` also produces zero.

The control word and payload word are separate inputs. Passing the control-word gate does not establish that the shifted payload is nonzero.

On the reset path, the recovered order is:

1. Conditional base replacement.
2. Effective-payload clearing.
3. Four-byte zero write at offset `0x180`.
4. Four-byte zero write at offset `0x188`.

On the non-reset path, only the write at offset `0x188` is shown. The recovered fragment contains no explicit memory reads of either destination field.

These are logical access-order observations. Hardware atomicity, bus ordering, and synchronization guarantees are unknown.
