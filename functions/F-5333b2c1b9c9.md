# F-5333b2c1b9c9

## Behavior

### Selection arithmetic

Negative inputs are not rejected by the visible operation. They select locations below the table base if the applicable address arithmetic permits that result. Whether those locations belong to valid storage is an external condition.

The stride multiplication is not narrowed back to 16 bits. Across the declared input range, its mathematical result ranges from −12,976,128 through 12,975,732 bytes. Both endpoints fit within a signed 32-bit integer, so that multiplication does not itself require signed 32-bit overflow.

This does not establish the safety of either complete address calculation. Adding the signed displacement to the table base can exceed an address range or violate allocation constraints. Adding 2,116 to the selected address-bearing value raises a separate arithmetic and address-validity question. Intended wraparound behavior is not established.

### Read and write dependency

The function obtains the table-base value needed for selection, reads the four-byte address-bearing field at the selected location, and uses that value to determine the destination. The destination assignment depends on that selected-field read. No function call intervenes.

There is no independent read of the destination’s prior value to determine the replacement value. The replacement value is always numeric 1.

Source and destination are not required to be disjoint by the visible body. If the selected field overlaps the destination, bytes previously occupying the destination can participate in determining the destination address through the selected-field read. Those bytes do not alter the replacement value.

The required dependency is therefore:

- The selected-field value supplies the address used for the assignment.
- That value is obtained before the dependent assignment.
- The assignment replaces four bytes at the resulting destination.

This describes the expressed operation, not an exact processor-instruction sequence. It does not establish memory barriers, inter-thread visibility, or all accesses involved in obtaining the table base, whose declaration is unknown.

### Field replacement

The destination receives numeric value 1 across its four-byte width.

There is no separate destination-value read for computing that replacement. This does not mean prior destination bytes are irrelevant to address selection when source and destination overlap.
