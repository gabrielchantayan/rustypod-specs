## Behavior

Byte conversion retains the low eight bits. For example, the byte derived from a word with value `0x12345678` is `0x78`.

The repeated address derived from A is mathematically twice A plus `0x54`. A is represented as unsigned, so its doubling has 32-bit unsigned arithmetic in the supplied representation. Translating the resulting value into an effective address still depends on the execution environment.

Other address expressions involve values represented as signed, including doubling a subsequently loaded word. Their behavior at signed overflow is **documented_only**. A portable signed-arithmetic interpretation must not be substituted for unknown machine behavior.

One shift uses a count equal to the low eight bits of A. Counts of 32 or greater, and right shifts of negative signed values, require target-specific interpretation. The evidence does not establish a uniform result for those cases.

|---|---|---:|---|
| First | B plus `0x19` | 8 bits | a |

## Acceptance examples

These are conditional specification examples, not executed tests.

### Repeated writes remain distinguishable

Given valid, nonoverlapping destinations and an observer that records each represented store, the initial region records sixteen byte writes at B plus `0x19`, sixteen at A plus `0x11`, sixteen word writes at B plus `0x34`, and fifteen word writes at twice A plus `0x54`.

If Q differs from twice A, the observer sees Q first at B plus `0x34`, followed by fifteen replacements with twice A. A single final-value assignment does not satisfy that observation model.

### Byte arithmetic wraps at eight bits

If a is `0xF0`, the byte written to fixed address `0x0000003A` is `0x10`: twice `0xF0` plus `0x30`, retaining only eight bits.

This does not imply an ASCII digit or a bounded decimal value.

### The indirect argument uses a snapshot

Suppose the word read from C plus `0x14` is `0x12345678`. If all accesses complete and the indirect invocation is reached, its third visible argument is that captured value, even if subsequent writes change the original storage.

### Halfword width is preserved

If J is 1000 and address 2000 supports the required write, the final address-chain region writes the 16-bit value `0x0065` at address 2000 before reading K.

The mapping of `0x65` and `0x00` to individual byte addresses depends on endianness. The contract does not substitute a byte write or a word write.

### Aliasing changes a later read

Suppose doubling J produces exactly the address J plus `0x64`, and execution permits that access. The halfword write then overlaps the word read that produces K. K must be interpreted from the post-write memory state, not from an earlier assumed value.

### A valid-looking pointer is insufficient

Even if P, A, B, and C each designate readable and writable storage, execution can still fail when E, J, K, or M produces an invalid derived destination. No visible check prevents that access, and no clean error result is established.
