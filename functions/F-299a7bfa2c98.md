These are conditional static acceptance examples. **No runtime tests have been performed.**

1. **Second-argument storage.** If first index is `3`, its calculated destination is writable, and earlier calls return, the first direct word store writes the second argument at address `0x20`. It does not write the first argument.

2. **Scaling distinction.** If second index is `5`, the corresponding store writes `20` at address `0x64`. The destination uses sixteen times the index; the stored value uses four times the index.

3. **Unsigned shifted read.** If the word read for the right-shift-by-three call is `0x80000000`, that dependency receives `0x10000000`. An arithmetic sign-extending shift would not match the represented operation.

8. **Byte multiplication.** If second final word is `0x43`, its multiply-by-four byte store writes `0x0c`, subject to the stated low-eight-bit interpretation.
