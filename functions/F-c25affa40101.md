# F-c25affa40101

## Purpose

The established behavior has three outcomes:

- If the preliminary operation returns zero, return zero without directly inspecting either input-associated record.
- If the preliminary operation returns nonzero and the first record’s field at byte offset 12 is zero, return one without dispatching.
- Otherwise, select an indirect target according to the third record’s field at byte offset 12, invoke that target with three arguments, and return its result.

The meanings of the records, their fields, and the preliminary operation are unknown. Interpreting the offset-12 fields as flags, presence indicators, or dispatch classifications is inferred intent, not an established semantic contract. Likewise, the zero and one results must not be labeled “failure” and “success” without additional evidence.
