The sequence below describes the represented accesses, not merely final memory contents.

All roots and derived regions may alias. Therefore, intermediate stores, repeated stores, read-and-write-back operations, and distinct reads must remain distinguishable. A byte write can affect a later word read or traversal. Byte order determines which word bits overlap a byte address; it is not established here.

## Acceptance examples

These are conditional static criteria, not executed tests. Each assumes the relevant addresses and arithmetic are valid.

1. **Truncation:** A third argument ending in `0xab` causes the first store to write byte `0xab`. Its later self-address store uses all 32 bits.

2. **Temporary values:** With nonoverlapping relevant storage, initial-child word `0x10` receives the first argument, then `0x6e`, then the captured child `0x50` word. Final contents alone do not validate this sequence.

3. **Read/store/read aliasing:** If selected-record `0x20` exactly aliases main `0x64`, an initial value `0x12345678` produces before-store snapshot `0x12345678` and after-store snapshot `0x00000073`. The former feeds main `0x44` and main byte `0x19`; the latter feeds selected-record byte `0x09`, further-record word `0x24`, and both consecutive main `0x0d` stores.

4. **Cached address:** If an intervening mutation changes main `0x74` after the cached traversal target was read, subsequent cached-target traversals still use the saved address. A fresh main `0x74` read at either traversal would violate the contract.

5. **Fresh field reads:** If intervening writes change cached-target `0x04`, its first result selects the recipient of word `0x74` at `0x30`; its second result supplies the address whose `0x74` selects the late record. Reusing the first field result would violate the contract.

6. **Halfword width:** A final main-link snapshot of `0x12345678` supplies halfword `0x5678` to its three specified halfword stores.

7. **Character boundary:** Character byte `0x80` can produce unsigned value `0x00000080` or `0xffffff80`. Word-store addresses after adding `0x45` are respectively `0x000000c5` and `0xffffffc5`. Selecting one interpretation is **documented_only**.
