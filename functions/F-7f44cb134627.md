# F-7f44cb134627

## Purpose

F-7f44cb134627 prepares two related memory regions, writes selected state into them, stores the second region’s address in the first, and invokes an operation selected through a supplied receiver. On normal completion, it returns the first region’s address.

The established contract is the ordering of calls, memory accesses, and returned-address use. “Primary object,” “secondary object,” “allocation,” and “initialization” are descriptive roles, not proof of the dependencies’ allocation, ownership, or object-model semantics.

The third and fourth incoming values do not provide the values passed by reference to secondary initialization. Their local copies are overwritten with zero before that call.

## Behavior

### Primary preparation

Before the first dependency call, the function copies the third and fourth incoming values into their respective local words.

It then calls F-8157a180d901 with the integer 24. Its result is passed to F-d148608394ce together with the second incoming argument.

The address returned by F-d148608394ce becomes the primary address for the rest of this function. After that call returns, the function reads a 32-bit value from a global source and writes it at primary offset 0.

Consequently:

- Primary initialization precedes the offset-0 overwrite.
- The global value is obtained after initialization, not cached before it.
- Any value previously occupying those four bytes is overwritten by this function.
- No preservation of the global source across F-d148608394ce is assumed.

The global value’s semantic role is unknown. Placement at the beginning of a region may suggest descriptor or dispatch state, but that is inferred intent rather than an established field type.

### Secondary preparation

After the primary offset-0 write, the function calls F-8157a180d901 with the integer 36.

Once that call returns, the function clears the local word associated with the fourth incoming argument, then clears the local word associated with the third incoming argument.

F-c990b942cc8c is then called with:

1. The result of the 36-byte request.
2. The address of the cleared fourth-argument local word.
3. The address of the cleared third-argument local word.

Both local words contain zero at this point in the visible sequence. The original auxiliary input values are not passed as their contents.

F-c990b942cc8c returns the secondary address used by all subsequent secondary accesses. It is not required by the visible caller to equal the request result.

The dependency receives addresses, not merely two zero values. It may access or modify the pointed-to local storage according to its unknown contract. This function does not subsequently read those local words. Whether the dependency retains either address is unresolved; the function supplies no persistent allocation for them.
