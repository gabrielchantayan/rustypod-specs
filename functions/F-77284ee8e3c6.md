# F-77284ee8e3c6

The address used for the final write comes from a separate lookup performed after the intervening dependency operations. Those results need not identify the same object.

### Independent destination selection

- Equal lookup results are permitted.
- Different lookup results are permitted.
- The initial result need not itself be suitable as a write address for this function.
- A valid initial result does not establish validity of the later destination.
