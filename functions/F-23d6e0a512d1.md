# F-23d6e0a512d1

## Behavior

The established order of operations is:

1. A one-byte zero value is written at the base address.
2. A four-byte zero value is written beginning at offset 4.
3. F-b00260d1087a is invoked with the address at offset 8.
4. If that invocation returns normally, the original base address is returned.

This is the observable ordering represented by the supplied static material. It does not establish hardware-level atomicity, inter-thread synchronization, or a particular machine-instruction sequence.

### Writes and reads

Both direct writes are unconditional on the represented normal path. Neither depends on the previous contents of the target storage.

There is no explicit read of the prior contents of either written region. There is also no explicit direct read or write of offsets 1–3.

The second write has a width of 32 bits, not a pointer-sized width and not an eight-byte width. Its value is zero. Endianness does not change the resulting byte contents of that zero value, although it would matter for other values.
