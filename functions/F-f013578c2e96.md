### Dependency invocation

On the nonzero path, the function reads the shared value used for the first argument and invokes F-bbc5977ee4f2 once with the five arguments listed above.

1. The supplied integer is read.
2. That value determines whether the dependency path is taken.
3. On that path, the shared argument value is read and supplied to the dependency.
4. The dependency returns a result, if it returns normally.

The function does not re-read the supplied integer after the dependency call. Consequently, the clearing decision depends on the initial nonzero observation and the returned result, not on the supplied object’s value at the end of the call.

### Result handling

If F-bbc5977ee4f2 returns a signed value less than one, the function writes zero to the original supplied address.

This includes:

- Zero.
- Negative one.
- Every other representable negative result.
