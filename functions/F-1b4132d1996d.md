# F-1b4132d1996d

The supplied static representation establishes a pointer-resolution chain and a transfer to the resulting executable target. It does not establish the target’s identity or application-level purpose.

The dispatch accesses a field at byte offset 0x888 from the input address, follows the pointer stored there, reads a further pointer from the resulting location, and selects an executable address at byte offset 0xFC from that second pointer.

This resembles dispatch through an object and a function table. That interpretation is inferred intent, not an established object model. The contract therefore uses neutral terms: input address, intermediate address, table address, and target.

These reads are causally ordered: the second address depends on the first read’s result, the third address depends on the second read’s result, and the control transfer depends on the third read’s result. The representation contains no alternative target-selection branch and no visible retry.
