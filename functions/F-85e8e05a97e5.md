# F-85e8e05a97e5

## Purpose

The supplied static representation describes a routine that performs 32 ordered indirect calls, interleaves seven coprocessor-transfer operations, derives values through fixed-width shifts and masks, and attempts a final 16-bit memory write. The represented path then reaches an invalid-instruction boundary; no normal return is shown.

The routine’s application-level purpose is unknown. Hardware initialization, protocol processing, memory management, and other higher-level interpretations are not established.

This contract describes the represented behavior, conditional on execution reaching each operation. The supplied representation warns of invalid instruction data and truncated control flow, so its fidelity to executable behavior remains unresolved.

### Opening phase

The routine first forms the **initial shifted value** by shifting the second explicit input left by 11 bits.

It calls **F-D01** with four arguments:

1. The first inherited value shifted left by 21.
2. The second explicit input, unchanged.
3. The third explicit input, unchanged.

Calls **F-D02** through **F-D06** follow in order, without explicit arguments or consumed results. **F-D07** then supplies a 32-bit result to coprocessor transfer 1.

After **F-D08**, **F-D09**, and **F-D10**, all without explicit arguments, transfer 2 receives the third explicit input shifted left by 24. Only that input’s lowest eight bits contribute.

**F-D11** receives that same shifted third-input value and the second inherited value shifted left by four. **F-D12** follows without explicit arguments. The 32-bit result of **F-D13** becomes transfer 3’s payload. **F-D14** then executes without explicit arguments.

### Derived-value phase

**F-D15** receives:

- The initial shifted value shifted left by another 22.
- The initial shifted value shifted left by another 11.
- Zero.

With 32-bit truncation, the first argument is always zero: the two successive shifts discard all original bits. The second argument equals the original second input shifted left by 22.

The 32-bit result of **F-D15** is the **primary result**. Transfer 4 receives the primary result shifted left by one. The routine also forms the **scaled result** by shifting the primary result left by four.

**F-D16** receives four arguments:

1. The primary result shifted left by one.
2. The third explicit input masked to its lowest 23 bits, then shifted left by four.
3. The scaled result.
4. Zero.

The second argument ranges from zero through `0x07fffff0`. Original input bits 23–31 have no effect on it.

**F-D17** and **F-D18** follow without explicit arguments. Transfer 5 receives zero.

The routine then forms an **auxiliary value** from the scaled result’s lowest two bits, shifted left by 16. Because the scaled result has four low zero bits, the auxiliary value is always zero under the stated width interpretation.

Transfer 6 receives zero. **F-D19** receives one explicit zero argument and produces a 32-bit result. Transfer 7 then receives the scaled result shifted left by eight.

**F-D20** receives:

- The scaled result shifted left by eight.
- The scaled result shifted left by 12.
- The result of **F-D19** shifted left by nine.

The first two values equal the primary result shifted left by 12 and 16, respectively. These value identities do not remove the intervening calls or transfers from the behavioral contract.

### Wide-result and trailing phases

**F-D21** returns a represented 64-bit result. **F-D22** receives its lower word, its upper word, and its lower word shifted left by one, in that order.

**F-D23** receives the auxiliary value shifted left by eight, which is zero. Its 32-bit result is passed to **F-D24**. The 32-bit result of **F-D24** is passed to **F-D25**. **F-D26** follows without explicit arguments.

**F-D27** produces another represented 64-bit result. **F-D28** receives:

1. Its lower word.
2. Its upper word.
3. Its upper word shifted left by 11.

The 64-bit result of **F-D28** is the **final wide result**.

Before the remaining calls, the routine extracts bits 41–63 of the final wide result by an unsigned right shift of 41. This produces a 23-bit value. It also shifts the auxiliary value left by 25; that result remains zero.

**F-D29** receives the lower word of the final wide result. **F-D30**, called without explicit arguments, supplies a 32-bit result to **F-D31**. The second argument to **F-D31** is the auxiliary value shifted left by 25, hence zero. **F-D32** then executes without explicit arguments.

### Final store and boundary

After **F-D32** returns, the destination is calculated from the previously captured final wide result.

Let the **destination index** be bits 52–63 of that result, interpreted as an unsigned integer. The destination address is the destination index plus its integer quotient on division by four.

The represented calculation first extracts a 23-bit value and then applies a signed right shift by 11. That value cannot be negative as a signed 32-bit integer, so the shift yields precisely the highest 12 bits of the final wide result. No sign-extension ambiguity affects this calculation.

Consequently:

- The destination index ranges from zero through `0x0fff`.
- The address ranges from zero through `0x13fe`.
- No base address is added.
- Odd addresses are possible.
- No explicit null, alignment, range, or permission check precedes the store.

The routine attempts to write the 16-bit value `0x00cd` at that numeric address. The subsequent represented boundary is invalid instruction data, not a normal return.
