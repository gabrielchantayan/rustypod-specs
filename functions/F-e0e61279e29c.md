## Behavior

- A zero byte selects mode three.
- Any nonzero byte selects mode two.

This is a zero-versus-nonzero test, not a test for a particular affirmative value. Byte values such as one, two, 128, and 255 all select mode two. Whether a byte with its high bit set would otherwise be interpreted as signed does not change this comparison.

The visible body contains one flag-byte read and one selection. It does not poll, retry, reread the flag before invocation, or retain the selected mode for a later invocation.
