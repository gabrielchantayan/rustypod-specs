For conditional arithmetic examples, 32-bit modular semantics mean retaining only the low 32 bits after an operation. This is not a claim that all signed-looking expressions have independently established overflow semantics.

Under that condition:

- Left shift by eight discards the original high byte.
- Two successive left shifts by 28 produce zero.
- Multiplication by 2²⁵ produces a zero low byte.
- The compact component is divisible by four and ranges from 0 through 508; its doubled base ranges from 0 through 1016 in multiples of eight.
- Masks applied before shifts remain significant. A 24-bit mask followed by a six-bit shift is not interchangeable with an unrestricted shift.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Width-sensitive transformation.** Under 32-bit modular semantics, shifting 0xAB123456 left by eight and logically right by eight yields 0x00123456. Restoring the discarded high byte is unacceptable.

2. **Compact boundary.** The compact component cannot equal 511 under those semantics. Its maximum is 508, and every possible value is divisible by four.

3. **Fixed-address access order.** With observable memory, the read at 0x05 must precede the byte write at 0x01. Moving that write ahead of the read changes the contract even if ordinary disjoint RAM would produce the same final contents.

4. **Global capture before mutation.** If the fixed word store at 0x60 overlaps the separate global word, the cross-write region still uses the global base captured before that store.

5. **Fresh fixed-byte samples.** Suppose the 0xA9 capture has low byte 0xA5, but memory behavior changes 0x67 to 0xB6 during the intervening computed word read. The byte stored at 0x21 is then 0xB6, not necessarily 0xA5. Later computed publications likewise use their own 0x67 reads.

6. **Captured terminal argument.** If a final store changes the memory from which the terminal second argument was read, the call still receives the captured word. Reloading that memory for the argument is unacceptable.

7. **Final direct mutation.** If the terminal second argument is 0x100 and the later destination base is 0x300, modular arithmetic places the final word store at 0x200 with value 0x300, before the call.

8. **Large shift count.** For a variable shift count of 40, the result remains documented_only. Neither five-bit count masking nor a zero result is established.

9. **Partial execution.** A fault after earlier stores provides no rollback guarantee or requirement to reach the terminal invocation.
