# F-212e733e4403

## Purpose

F-212e733e4403 performs computed-address word writes, byte writes, memory reads, and an ordered sequence of indirect dependency calls. If execution reaches its final represented region and dependencies continue returning, that region repeats without a represented exit.

No application-level purpose is established. The address calculations do not establish object layouts, allocation boundaries, device registers, a serialization format, or a protocol.

This contract separates:

- **Established static evidence:** accesses, displayed call arguments, saved-value use, and control flow present in the supplied representation.
- **Inferred arithmetic model:** 32-bit machine-word arithmetic with truncation or wrapping where applicable.
- **documented_only:** unresolved machine semantics, dependency behavior, ownership, and execution validity.

Every later operation is conditional on preceding accesses and calls completing.

## Acceptance examples

These examples are conditional static consequences, not executed tests.

1. **Initial access ordering.** If \(A=0x100\), the first explicit write stores word `2` at address `0x414`, before D-001.

2. **Byte truncation versus dependency input.** If \(R_{10}=0x12345678\), the first selected byte payload is `0xe0`, while D-011 receives full word `0x48d159e0`. The later saved-result byte payload is `0x23`. Fresh selector reads can select different destinations.

3. **Saved global conversion.** If \(C=0x80\) and the converted global value is `0x89abcdef`, both explicit global-snapshot writes target `0x18` with that word. An intervening global change does not itself change the retained payload.

4. **Newer return after repeated write.** If \(R_{39}=7\), D-040 receives `28`, regardless of the earlier \(R_{30}\) used by the immediately preceding repeated wide-stride write.

5. **No byte mask in the derived base.** If \(S=0x12345678\), then \(B=0x0091a2b0\), not `0x2b0`. The writes using \(B+0x14\) must retain this larger basis.

6. **Final selector freshness and full-word call input.** If the two zero-writing selector reads at \(Q+1\) yield `3` and `9`, their destinations are `0x14` and `0x1a`. If \(R_{173}=0x40000003\), D-174 receives `0x0000000c` under wrapping arithmetic, not zero.

7. **Loop entry and continuation.** If the loop is reached, its first leading call receives \(R_{180}\) and zero. If an iteration’s \(R_{190}=1\), the next leading call receives `4` and `0x00040000` under the stated arithmetic model. No fixed iteration count permits a normal return.
