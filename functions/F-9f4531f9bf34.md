### First source-field observation

This read occurs for both zero and nonzero modes. A zero mode does not bypass the source access or make an unreadable object address safe.

- A nonzero value from this source-field read.
- A nonzero original mode.

The source-field comparison precedes the mode comparison in this compound condition. If the source field is zero, the remaining condition is not evaluated and no destination retrieval occurs.

Only the outcomes of the mode comparisons are necessarily shared by all nonzero modes. The source-field outcome is not: F-61ed12ce28af receives the actual mode and may have changed the field differently for different nonzero values.

### Destination-field observation

It uses this invocation’s result as an address base and reads the 16-bit field at offset `0x80`.

- If the field is nonzero, the function performs no explicit write.
- If the field is zero, the function proceeds to the write path.

The initial F-fdd8589eca2d result is not reused for this check. No equality relationship between the first and second results is established.

### Conditional write

On the write path, the function calls F-fdd8589eca2d a third time.

After that call returns, it reads the caller-object field at offset `0xEA` again and writes that 16-bit value to offset `0x80` of the address returned by the third invocation.

The following distinctions are observable:

- The second invocation supplies the address whose field is tested.
- The third invocation supplies the address whose field is written.
- The first source read determines whether the conditional-copy path may proceed.
- The second source read supplies the value actually written.

There is no check that the two destination addresses match. There is no zero check on the final destination field. There is no renewed nonzero check on the final source value.
