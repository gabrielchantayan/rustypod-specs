## Acceptance examples

These are conditional static cases, not runtime observations. Each assumes prior operations complete and unresolved semantics permit the stated calculations.

### Initial arithmetic prevents every write

If evaluating the fourth-input destination prevents progress, the initial index-byte store has not occurred. Neither the fixed `0xB8` assignment nor the first-input-derived byte store has occurred.

An account that permits these three writes before evaluating that destination fails the required ordering.

### Zero and wrapped displacement

For second input `0xA8`, displacement, halfword base, and index are zero. After initial destination evaluation succeeds, the all-ones halfword stores target four, six, and two, in that order; the later unsigned-halfword read targets zero.

For second input `0xA7`, displacement is `0xFFFFFFFF`, halfword base is `0xFFFFFFFE`, and index is `0x3FFFFFFF`. The unsigned calculation does not reject or clamp the underflow.

Neither case establishes low-memory accessibility.

### Early termination and halfword sign

If the first dependency address has bit 31 set, the sign-fill halfword store at dependency base plus four precedes termination. The later signed-halfword read does not occur.

On the continuing branch, a signed-halfword read of `0x7FFF` produces a zero word at dependency base plus eight; `0x8000` produces `0xFFFFFFFF`, assuming ordinary sign extension and arithmetic right shift.

### Fresh overlapping-byte read

If the overlapping byte view contains `0xA3` immediately before concatenation, the constructed value is `0x0005A3`, regardless of its earlier assignment. The physical assignment footprint remains unresolved.

### Early second-dependency shift

If the signed left shift of the second dependency address prevents progress, the quadrupled-pointer field has already been assigned. Its self-address store, its subsequent reload and index store, and the late-captured-value self-address store have not occurred.

Deferring that evaluation until the later adjusted-address store would permit an incorrect mutation prefix.

### Fresh quadrupled-pointer-field read

### Final write layout and unused input
