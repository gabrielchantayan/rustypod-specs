For a zero selector, the function reads a 32-bit value at byte offset 28 from the address returned by F-3fdd14ecd250. This read occurs after local-record preparation. It then invokes F-fc918c3355aa with four explicit arguments:

1. The word just read from the returned context at byte offset 28.
2. The word captured through the first argument before context acquisition.
3. The address of the local record.

For any nonzero selector, the function instead invokes F-8801c242b41b with no explicit arguments. It does not explicitly pass the record address, the captured value, or the fifth argument to that dependency. It also does not perform the context-result read at byte offset 28 on this path.

Consequently, a nonzero selector whose low byte is zero still takes the nonzero path. Negative selectors also take the nonzero path; their stored byte is determined by the same low-eight-bit conversion.
