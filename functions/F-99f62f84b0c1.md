## Acceptance examples

### Duplicate input delivery

### Result forwarding

### Global publication before clearing

If F-U05 returns and its result is successfully assigned, that assignment occurs before the one-byte clear and the two-byte clear. A later store failure does not introduce any represented undo operation.

### Shifted-address boundaries

If the unsigned quantity used for address formation is 511, the two-byte store starts at address zero.

If it is 512, the store starts at address one. The function does not visibly correct that address for two-byte alignment.

If it is `0xFFFFFFFF`, the store starts at address `0x007FFFFF`.

Each example remains conditional on the value actually used at the store and on the environment permitting the access.

### Overlapping clears

If the byte-store pointer equals the calculated two-byte destination and both stores succeed, the function first clears one byte and then clears two bytes starting at the same address. Aliasing does not remove either represented operation.

### Failure before the terminal call

If the one-byte store faults, the two-byte store and F-U06 are not reached normally. The preceding calls and global assignment have already been attempted.

### Returning from address zero

If all earlier operations succeed and address zero is callable, F-U06 receives three explicit zero arguments. If it returns normally, the function reaches its final return. A trap or non-returning transfer at address zero is not converted into a normal return.
