## Behavior

1. Reads **G**.
2. Reads **P₀**.
3. Establishes a zero working offset.
4. Determines whether signed **B − D** overflows.
5. Reads **H₀**.

Overflow means that the mathematical difference of the signed interpretations cannot fit in the range −2,147,483,648 through 2,147,483,647. It is not unsigned borrow and is not simply **B < D**.

- **Q = 0**.
- **H = H₀**.
- **W = G**.
- **B′ = B**.

If it overflows, perform these accesses in order:

2. Write the low byte of **B** at address **B**.
3. Read a word at **B**, capturing **J**.
4. Invoke software interrupt selector **222**, hexadecimal **0xDE**.
5. If execution continues, write **P₀** at **A + 20**, three separate times.
6. Write captured **G** at **A + 60**.
7. Write **J** at **A + 84**, twice.
8. Read a word at **J + 20**, capturing **X**.
9. Read a word at **J + 116**, capturing address **Y**.
10. Read a word at **G + 108** and write its low byte at **Y + 23**.
11. Write the low byte of **J** at **G + 21**.
12. Read a byte at **G + 5**, capturing zero-extended **Z₀**.
13. Read a byte at **Y + 7**, making its zero-extended value **W**.

The word read at **B** follows the byte write at that same address and precedes the interrupt. Aliasing can affect subsequent reads throughout this sequence.

Then:

- Let **T = X >> 8**.
- Call **F-7aee1fc5f275** with **T << 12**, **X**, and **T << 24**. Capture its represented 32-bit result as **R**.

- **Q = V << 12**.

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **No overflow.** With **B = 256** and **D = 0**, omit the overflow-only accesses, interrupt, and first three calls. The preparatory group begins by storing **H₀** at **A**, then **B** at **P₀**, then **B** at **H₀**. Its fourth store writes zero at **B**.

2. **Signed overflow, not unsigned borrow.** With **B = 0x7FFFFFFF** and **D = 0xFFFFFFFF**, the signed subtraction is maximum signed integer minus negative one. Select the overflow path.

3. **Bypass with zero result.** If the overflow path reaches **F-indirect-02** and it yields **V = 0**, then **P = Q = 0**. Skip the preparatory group, retain incoming **C**, and use the captured byte **Z₀**. Zero-derived addresses are still accessed if execution continues.

4. **Truncated shifts and the fixed operand.** If **V = 0x00800000**, then **P = 0x80000000** and **Q = 0**. Execute the preparatory group with **B′ = 0x0891111C** and **H = 0x007F8000**. Its fourth store writes zero at **0x0891111C**.

5. **Feasible overlap between independent bases.** If **Y = G + 14** modulo **2³²**, then **Y + 7 = G + 21**. Absent intervening external modification, the read supplying **W** observes the byte just written from **J**. By contrast, **G + 21** and **G + 5** differ by 16 modulo **2³²** and cannot coincide through wraparound alone.

6. **Wrapping subtraction.** If **Low = 0**, the second split-result store writes **0xFFFFFFEA**, decimal **4,294,967,274**, at **2 × N**. Later overwrites do not remove that earlier access.

7. **Independent final references.** If the final destination-base reference yields **X₁** and the value reference yields **X₂**, the final assignment writes **X₂** at **X₁ + 24**. Requiring **X₁ = X₂** would add an unsupported coherence guarantee.

8. **Termination behavior.** If every access succeeds and every dependency continues, execution loops indefinitely after the final assignment. A normal return would not match the represented control flow.
