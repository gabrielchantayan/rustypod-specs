## Acceptance examples

These examples require the stated reachability and defined arithmetic. They are not executed tests.

1. **Immediate return.**  
   If the first dispatch selects state 11, the result is zero and neither dependency is called.

2. **Captured multiplier remains captured.**  
   Suppose a candidate-loading state obtains 9, the captured multiplier is 3, and execution next reaches state 0 followed by state 11. The result is 27. A later change to the multiplier global does not refresh the captured value.

3. **Base stability matters.**  
   A candidate-loading state copying base value 100 into dispatch reaches state 0 if the next base read is also 100. If that read is 99, the next dispatch selects state 1 instead.

4. **High-bit predicate with unequal transition reads.**  
   In state 5, suppose the first transition read is 100 and the second is 200. An OR result of 1 sets predicate zero and selects dispatch value 99. An OR result of hexadecimal 80000000 sets predicate one and selects dispatch value 200. Both transition reads occur in either case.

5. **The marker is independent of the predicate.**  
   In state 4, suppose the transition reads are 100 and 200. Before argument capture, marker zero selects dispatch value 88, even if the current predicate is one. After capture, marker one selects 200, even if the predicate is zero.

6. **Default behavior retains both reads.**  
   For an unmatched dispatch difference, first transition read 100 and second read 200 produce dispatch value 110 when the newly computed predicate is zero, or 200 when it is one.

7. **State 7's offset uses the first read.**  
   With transition reads 100 and 200, predicate zero selects dispatch value 111; predicate one selects 200. Neither outcome permits replacing the two reads with one assumed transition value.

8. **Complemented high-bit behavior.**  
   In state 9, if both computed products have clear high bits, the predicate is one even if either product is nonzero. With transition reads 100 and 200, this selects 200. If either product has its high bit set, the predicate is zero and selects 88.

9. **Uncaptured saved arguments remain zero.**  
   If state 14 executes before states 3 and 7, its saved third, fifth, and sixth arguments are zero. It does not substitute the original arguments automatically. Whether the dependency accepts these values is unknown.

10. **Scratch candidate affects return.**  
    If state 5 leaves candidate value 1, the captured multiplier is 3, and execution reaches state 0 then state 11 without another candidate update, the result is 3.

11. **Zero dependency result is not an established failure.**  
    If state 14's dependency returns zero and all relevant arithmetic is defined, its candidate and dependency-result words become zero. The eventual return and its meaning still depend on subsequent dispatch.

12. **Nontermination remains possible.**  
    If the configured transitions keep execution away from state 11, the routine has no visible iteration-limit return.
