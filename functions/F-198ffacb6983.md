# F-198ffacb6983

## Purpose

F-198ffacb6983 conditionally invokes a dependency with a caller-supplied 32-bit value and a reference to temporary, mode-dependent state.

Two selector values are recognized: 1 and 2. Each selects a different set of automatic-storage objects, initializes a small subset of that storage, and invokes F-8fbbf5288d61 once. Every other selector value causes an immediate return without that invocation.

The established behavior is preparation and dispatch. The supplied material does not establish the application-level meaning of either mode, the contents expected in the temporary buffers, or what the dependency does with the prepared state. In particular, the function does not visibly initialize a complete buffer or pointer vector.

## Behavior

### Unsupported selectors

If the selector is neither 1 nor 2, the function returns.

On this path:

- F-8fbbf5288d61 is not called.
- None of the mode-specific initialization assignments is performed.
- The first and third inputs are not interpreted or dereferenced by the visible body.
- No status value is returned to distinguish this path from a completed supported-mode call.

This includes zero, negative selector values, and positive values other than 1 and 2, within the recovered integer domain.

### Selector 1

For selector 1, the function selects the larger pointer vector and the 20-byte temporary region.

The established assignment order is:

1. Store the address of the selected pointer vector in the pointer-valued location adjacent to the selector location.
2. Store the address of the 20-byte temporary region into the first entry of that vector.
3. Store the third input in the separate 32-bit location immediately following that region in the recovered layout.
4. Store 1 in the selector location.
5. Invoke F-8fbbf5288d61 with the original first input and the address of the selector location.

No assignment initializes the 20 bytes of the temporary region. No assignment initializes the remaining 20 entries of the selected pointer vector.

Consequently, immediately before the call, the explicitly prepared state consists of a selector, a vector address, the vector’s first pointer, and the stored third input. It does not consist of a fully initialized 20-byte payload or a fully initialized 21-entry vector.

If the dependency returns normally, this function returns without performing another visible assignment, dependency call, or result conversion.

### Selector 2

For selector 2, the function selects the smaller pointer vector and the 8-byte temporary region.

The established assignment order is:

1. Store the address of the selected pointer vector in the pointer-valued location adjacent to the selector location.
2. Store the address of the 8-byte temporary region into the first entry of that vector.
3. Store the third input in the separate 32-bit location immediately following that region in the recovered layout.
4. Store 2 in the selector location.
5. Invoke F-8fbbf5288d61 with the original first input and the address of the selector location.

If the dependency returns normally, this function returns without any further visible work.
