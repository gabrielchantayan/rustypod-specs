# F-551f87588d1d

## Purpose

F-551f87588d1d invokes two dependencies in a fixed order, then returns one signed integer read from caller-supplied storage. The second dependency’s result selects either:

- The element at index 79.
- An element whose index is calculated from the difference between elements 2 and 0, followed by unsigned conversion, a 12-bit right shift, and addition of 13.

The established behavior is dependency invocation, selection, and retrieval. The supplied evidence does not establish the application meaning of the stored values, the reason for either dependency call, or the meaning of the returned integer.

## Behavior

### Ordered dependency calls

The function first invokes F-680bd70ebd5c without explicit arguments. Its return value is not used.

If that call returns normally, the function invokes F-50328f2e60da without explicit arguments. The integer returned by this second dependency determines the path:

- Zero selects the computed-index path.
- Any nonzero value selects the fixed-index path.

Positive and negative nonzero values have the same effect on selection. The dependency’s result is not itself the function’s output.

The supplied body performs no explicit reads through the input pointer before these calls. Consequently, later reads are not an entry-time snapshot. Either dependency could affect the storage through shared state or aliases, despite receiving no explicit pointer argument.

If either dependency does not return normally, the supplied body establishes no subsequent storage read or successful return. It specifies no recovery path for that condition.

### Fixed-index path

When F-50328f2e60da returns nonzero, the function reads element 79 and returns its signed integer value.

The visible calculation on this path does not read elements 0 or 2 and does not calculate the alternative index. Under the four-byte model, the selected read starts 316 bytes from the supplied base.

There is no explicit sign check, range check, decoding step, or sentinel interpretation applied to the retrieved value.

### Computed-index path

When F-50328f2e60da returns zero, the function obtains elements 2 and 0 and forms their signed difference:

\[
D = \text{element }2 - \text{element }0.
\]

The subtraction precedes conversion of its result to the unsigned integer type. The evidence does not support replacing this with subtraction of two already-unsigned operands.

For a defined signed subtraction, let \(U\) be the converted unsigned result. The selected element index is:

\[
I = 13 + (U \mathbin{\text{ shifted right by }} 12)
  = 13 + \left\lfloor \frac{U}{4096} \right\rfloor.
\]

The function then reads element \(I\) and returns its signed integer value without further transformation.

The supplied expression does not establish whether element 0 or element 2 is read first. Both supply the calculation, and the selected-element retrieval follows determination of the index. This describes source-level access dependencies; it does not establish a particular machine-instruction count or guarantee separate physical reads when accesses overlap.

If the selected index is 79, the returned element is the same one used by the fixed path. The computed path nevertheless depends on elements 0 and 2. Equal selected addresses do not make the two paths equivalent in required storage or arithmetic preconditions.

### Width-sensitive arithmetic

Under the conditional 32-bit model, conversion of a representable signed result to unsigned produces its value modulo \(2^{32}\). A negative difference therefore does not imply an index below 13.

For example, a signed difference of −1 converts to 4,294,967,295. After the shift and addition, it selects element 1,048,588.

For any 32-bit unsigned converted difference:

- The shifted value is between 0 and 1,048,575 inclusive.
- The final index is between 13 and 1,048,588 inclusive.
- Adding 13 does not overflow a 32-bit unsigned integer.
- With four-byte elements, the largest selected starting offset is 4,194,352 bytes.

These bounds do not prove that any selected address belongs to a valid object. In particular, a numerically representable index can still exceed the available storage.

For nonnegative, representable signed differences, selection uses consecutive groups of 4,096 values. Differences from 0 through 4,095 select element 13; differences from 4,096 through 8,191 select element 14. The grouping rounds down, not up.

Signed subtraction overflow is separate from unsigned conversion. Conversion after subtraction does not by itself establish defined wrapping for an unrepresentable signed difference. The supplied representation is insufficient to promise a portable selected index or machine-level result in that case.

## Acceptance examples

These are conditional acceptance criteria, not observed runtime results. Unless an example says otherwise, both dependencies return normally, required storage remains valid through the reads, the subtraction is representable, and the 32-bit model applies. Stated element contents refer to values available when the relevant reads occur.

1. **Positive nonzero selection.** If F-50328f2e60da returns 7 and element 79 contains −23, F-551f87588d1d returns −23. Elements 0 and 2 do not determine selection.

3. **Zero difference.** If the second dependency returns zero and elements 2 and 0 are equal, the selected index is 13. The result is the value read from that element.

4. **First grouping boundary.** With a zero dependency result, a difference of 4,095 selects element 13. A difference of 4,096 selects element 14. Neither case rounds upward within its group.

7. **Storage changed by a dependency.** Suppose element 79 contains 10 at entry, a dependency changes it to 20, and the second dependency returns nonzero. If the allocation remains valid and no later change intervenes, the result is 20, not an entry-time snapshot.

10. **Dependency does not return normally.** If the first dependency does not return normally, the supplied body establishes no invocation of the second dependency or subsequent selected read. If the second does not return normally, no subsequent selected read is established.
