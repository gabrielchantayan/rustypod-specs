## Behavior

On the null-descriptor path, there is a **second evaluation of the global descriptor pointer**. The function dereferences the pointer obtained by this second evaluation to obtain the preliminary word written to the original working storage.

These evaluations have distinct roles:

- The **initially captured pointer** becomes the effective descriptor used after preparation.
- The **secondly evaluated pointer** supplies the address from which the preliminary word is read.

The body does not obtain the preliminary word through the initially captured pointer. Without an established stability guarantee, the two pointer evaluations must not be assumed to produce the same address.

These are source-level evaluations. The supplied representation alone does not establish the exact number of physical machine loads, atomicity, synchronization, or which concurrent changes could be observed.

2. Read the first 32-bit word through the pointer obtained by that second evaluation.
3. Write that word at the original working pointer.
4. Call F-af167f4d7e19 with the address 176 bytes beyond the original working pointer.
