## Behavior

### Record transformation

The function processes the record in descending address order:

1. Fifth word, at offset 16.
2. Fourth word, at offset 12.
3. Third word, at offset 8.
4. Second word, at offset 4.
5. First word, at offset 0.

For each word, it reads the current 32-bit value, performs an unsigned right shift by one bit, and writes the result back to that same word.

Consequently:

- The original least significant bit is discarded.
- Zero enters the most significant bit position.
- A source word with its high bit set does not receive sign extension.
- Every shifted word initially lies between 0 and 2,147,483,647 inclusive.

After all five shifts, the function reads the fifth word again, clears its upper eight bits using a 24-bit mask, and writes it back.

The fifth word therefore contains only original bit positions 1 through 24, moved into result positions 0 through 23. Original bit position 0 and original positions 25 through 31 do not contribute to that final word.

\[
\left\lfloor x / 2 \right\rfloor
\]

For the fifth word, the value is:

\[
\left\lfloor x / 2 \right\rfloor \bmod 2^{24}

The fifth result lies between 0 and 16,777,215 inclusive. No addition, multiplication, saturation, or signed overflow is involved in these record transformations.
