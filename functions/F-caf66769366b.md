## Acceptance examples

These examples are conditional consequences of the static representation, not observed executions.

1. **Early write and halt:** If F-000000000001 returns 7, the following direct store writes the word 7 at S + 116. If the halt prevents continuation, later direct stores are not reached.

2. **Unsigned narrow address:** If the first unsigned halfword read yields 65,535, H is 65,535, not −1. A subsequent word store targets H + 52, subject to the platform’s access rules.

3. **Intermediate overwrite:** If T differs from H, the first store at H + 52 contains T and a later store contains H. Intervening calls can observe the intermediate value.

4. **Signed-byte reread:** If the stored byte at P + J is 255 and remains unchanged until the signed reread, its consuming argument is −1. If the intervening call changes it, the reread supplies the changed value instead.

5. **Distinct signed-halfword reads:** If an intervening call changes the halfword at H + J from 1 to 65,535, the two consuming invocations receive 1 and −1 under the represented signed interpretation.

6. **Narrowed address:** If V + 12 has low 16 bits equal to 4, the corresponding overflow-path halfword store writes 4, irrespective of upper address bits.

7. **Skipped loop:** If the loop exits without executing its body and G’s low byte is 171, the later direct stores at W + 13 and W + 9 each write 171.

8. **Entered loop with conditional exit:** If one or more loop iterations execute, execution subsequently exits, and both saved-byte stores are reached, W + 13 and W + 9 each receive **96**. This does not assert that the recovered condition handling permits such an exit.

9. **No guaranteed termination:** If the exposed zero condition remains clear, no finite iteration bound is established.
