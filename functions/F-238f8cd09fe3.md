# F-238f8cd09fe3

## Purpose

F-238f8cd09fe3 selects a processing path using a 32-bit discriminator in a caller-supplied object, conditionally invokes an output-related dependency, invokes a final dependency on local scratch storage, and returns the 32-bit value `1` on normal completion.

The established behavior is a dispatch-and-call sequence. The available evidence does not establish that the function copies an object, transfers ownership, releases a resource, or reports successful output construction. Those interpretations depend on unavailable dependency contracts.

The discriminator has three relevant classes:

- Unsigned values `0` and `1` select F-1c4c21f03254.
- A value of `2`, confirmed by a second read, selects direct scratch initialization.
- Values greater than `2` reach a second discriminator read and may invoke F-a817d8d58c10.

The second read matters: the function does not retain the first discriminator value for the subsequent comparison.

## Interface

### Inputs

The function receives four arguments:

| Argument | Established representation and use |
|---|---|
| Object address | A 32-bit address-bearing argument. The function reads a 32-bit unsigned discriminator at byte offset `8` and may pass the address at byte offset `20` to a dependency. |
| Destination address | An address represented as a pointer to 32-bit storage. The function does not directly dereference it; it may forward it to F-151ab4bfe553. |
| First initial value | An opaque 32-bit value copied into the first local scratch word. |
| Second initial value | An opaque 32-bit value copied into the second local scratch word. |

The two initial values have no established signedness or semantic type beyond their 32-bit representation.

The object address is not itself validated. For ordinary defined execution, the discriminator location must be readable. If the first discriminator read is below `2`, the address at byte offset `20` must also satisfy whatever requirements F-1c4c21f03254 imposes.

The destination’s validity requirements depend on F-151ab4bfe553. This function supplies no independent null check, capacity check, or alignment check.

### Return value

Every normal path returns the 32-bit value `1`.

There is no established normal return of `0`, no exposed error code, and no propagation of dependency return values. The value `1` therefore proves only that execution reached the final return, not that an unknown dependency achieved a particular semantic result.

### Internal storage and shared state

The function uses:

- A saved 32-bit snapshot of a shared global word.
- A first local 32-bit scratch word, whose address is passed to dependencies.
- A second local 32-bit scratch word, whose value is passed to the output-related dependency.

The available representation does not establish a public two-word structure or a caller-visible layout for this local storage. In particular, passing the first scratch word’s address does not by itself establish a contract granting a dependency access to the second word.

The shared global word is read directly but is not directly written by this function.

## Behavior

### Entry and initial reads

The function first reads the shared global word and retains that 32-bit value for later use. It then initializes the two local scratch words from the third and fourth arguments, respectively.

It next reads the object’s discriminator at byte offset `8`. This read is interpreted as unsigned 32-bit data.

The initial global snapshot therefore precedes discriminator dispatch and every dependency call.

### First discriminator read below `2`

If the first discriminator read is `0` or `1`, the function invokes F-1c4c21f03254 with:

1. The address of the first scratch word.
2. The object address advanced by `20` bytes.

There is no second discriminator read on this path. The enclosing function does not directly read the payload at byte offset `20`; it only computes and passes that address.

The dependency’s return value, if any, is not used. Its effects are not supplied. It may affect the addressed scratch storage or shared state according to its own contract. No preservation of the global word or other reachable state may be assumed.

After this call returns normally, processing continues to the destination-address comparison.

### First discriminator read at least `2`

If the first discriminator read is at least `2`, the function reads the same discriminator location again and compares the new unsigned 32-bit value with `2`.

If the second read equals `2`, no call to F-a817d8d58c10 occurs.

If the second read does not equal `2`, the function invokes F-a817d8d58c10 without explicit arguments. The supplied representation marks that dependency as non-returning. Consequently, the evidenced path ends at that call; no subsequent output call, final call, or return should be promised for it.

When the second read equals `2`, the function then:

1. Writes zero into the second scratch word.
2. Reads the shared global word again.
3. Writes that newly read value into the first scratch word.

This second global read is distinct from the entry snapshot. Equality between the two values is not guaranteed.

The two discriminator reads are also distinct. If the first read is greater than `2` but the second is exactly `2`, the direct-initialization path is selected without invoking F-a817d8d58c10. Conversely, if the first read is `2` but the second is `0` or `1`, F-a817d8d58c10 is invoked.

### Conditional destination call

After either continuing dispatch path, the function compares the destination address with the address of the first scratch word.

If the addresses differ, it invokes F-151ab4bfe553 with:

1. The destination address.
2. The current 32-bit value of the second scratch word.

It does not pass the first scratch word’s contents as an explicit argument.

If the addresses are equal, the call is skipped. This is an exact address-equality condition, not a general overlap check and not a test of pointed-to values.

For an ordinary external caller, the private scratch address is not exposed by this interface. Nevertheless, the equality branch is present and must be preserved in a source-facing contract rather than treated as impossible without additional calling-context evidence.

Any return value from F-151ab4bfe553 is ignored. No assumptions are established about its writes, allocation behavior, ownership effects, or preservation of shared globals.

### Final scratch replacement and call

After the destination call returns, or after it is skipped, the function overwrites the first scratch word with the global value saved at entry.

It then invokes F-22abefe7f288 with the address of that first scratch word.

Thus, at the point of this call, the first scratch word contains the entry snapshot—not necessarily the current global value and not the value left by the earlier dispatch path. The function does not restore the shared global itself.

If F-22abefe7f288 returns normally, F-238f8cd09fe3 returns `1`.

## Side effects

### Direct effects

The function directly performs:

- One entry read of a shared 32-bit global word.
- One discriminator read on the below-`2` path.
- Two discriminator reads on the at-least-`2` path.
- An additional global read when the second discriminator read equals `2`.
- Writes to its local scratch storage.

It performs no explicit store to the caller’s object, destination, or shared global word.

This does not establish that those locations remain unchanged. Dependencies receive addresses or may access shared state independently.

### Indirect effects and ownership

All externally visible writes, allocations, deallocations, ownership transfers, and other effects of the dependencies remain unspecified.

The final dependency’s position in the sequence may suggest a cleanup role, but that is inferred intent, not an established release contract. Likewise, the destination-related dependency must not be described as copying or assigning a value without its own evidence.

The scratch address supplied to dependencies is local to this invocation. The interface does not establish a lifetime extending beyond the invocation. Whether any dependency retains that address is unknown.

### Errors and interruption

There are no explicit recovery paths or propagated status values. A dependency that fails to return prevents the remaining sequence from completing.

Invalid addresses, unsuitable payload storage, and invalid destination storage are not handled by explicit checks in this function. Their consequences are not specified by the supplied evidence.

## Acceptance examples

These are conditional static acceptance examples, not executed tests. Except where stated otherwise, destination and scratch addresses differ, supplied addresses satisfy dependency requirements, and continuing dependencies return normally.

### Stable discriminator `0` or `1`

The function must call F-1c4c21f03254 with the scratch address and the object address plus `20` bytes. It must not perform the second discriminator read or the direct-initialization global reread.

It then calls F-151ab4bfe553 with the destination and the second scratch value as it exists after F-1c4c21f03254. Before calling F-22abefe7f288, it replaces the first scratch word with the entry global snapshot. Normal return is `1`.

### Stable discriminator `2`

Both discriminator reads produce `2`. Neither F-1c4c21f03254 nor F-a817d8d58c10 is invoked.

F-151ab4bfe553 receives the destination and the 32-bit value zero. F-22abefe7f288 receives the scratch address after its first word has been replaced with the entry global snapshot.

### Stable discriminator `3`

Both reads produce `3`. F-a817d8d58c10 is invoked. Under the supplied non-returning annotation, no later dependency call or normal return occurs.

### High-bit discriminator

A first read of `0xFFFFFFFF` follows the at-least-`2` path because the comparison is unsigned. It does not qualify as a negative value below `2`.

### Changing discriminator

If the first read is `3` and the second is `2`, direct scratch initialization proceeds.

If the first read is `2` and the second is `1`, F-a817d8d58c10 is invoked. The function does not reconsider the below-`2` branch using the second value.

These examples specify consequences of observed reads; they do not establish that unsynchronized concurrent modification is supported.

### Different global observations

Suppose the entry global read produces `0x11111111`, while the later global read on the discriminator-`2` path produces `0x22222222`.

The first scratch word temporarily receives the latter value. Before F-22abefe7f288 is called, it receives `0x11111111` instead. No direct write restores the shared global.

### Exact destination equality

If the destination equals the first scratch word’s address, F-151ab4bfe553 is skipped. The final scratch replacement and F-22abefe7f288 call still occur.
