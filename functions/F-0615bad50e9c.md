## Acceptance examples

These examples are conditional static expectations, not executed tests.

1. **Entry write precedes calls.**  
   If the inherited selector read yields 0x20 and the inherited byte is 0xA5, the entry write places 0xA5 at address 0x31 before D-001 is invoked.

2. **Clearing follows the current selector.**  
   If an intervening dependency changes that selector from 0x20 to 0x21, the later zero write targets 0x32. It does not necessarily clear 0x31.

3. **Byte truncation preserves only eight bits.**  
   If a retained result is 0x00000041, shifting it left by two produces 0x00000104. A byte store of that result writes 0x04.

4. **A high-bit shift is not general multiplication.**  
   Under 32-bit modular arithmetic, shifting an unsigned quantity left by 31 produces zero for an even value and 0x80000000 for an odd value. Address calculations using that term must retain this distinction.

5. **Scaled slots are distinct access formulas.**  
   For index 3, the four-scaled slot is at 0x20, while the sixteen-scaled slot is at 0x44. A store through one formula does not establish a store through the other.

6. **Shared state is reread.**  
   Even after the explicit zero write to shared slot A, a later dependency may change it. A subsequent read uses the changed value.

7. **Repeated copies reread their source.**  
   If a dependency changes the word at a retained base plus 0x74 between two low-byte copies, the second copy uses the new word.

8. **Finalization is not a successful-return guarantee.**  
   If the final address-zero call faults, preceding byte, shared-slot, and 16-bit writes have already occurred. No normal return is established.
