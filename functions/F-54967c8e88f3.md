# F-54967c8e88f3

## Purpose

F-54967c8e88f3 describes an operation whose observable behavior is an ordered series of memory accesses, with an early conditional invalid-instruction termination and an unconditional invalid-instruction termination at the end.

No application-level purpose is established. The operation is not demonstrated to initialize a valid object, allocate storage, dispatch a request, or complete a transaction. Exception-related annotations identify storage in the supplied material; they do not establish exception-handling behavior.

This is a conditional, source-facing contract. The supplied representation warns of invalid instruction data and overlapping global storage. Reaching any described access therefore depends on earlier accesses succeeding and on the target providing an interpretation for the represented arithmetic.

## Behavior

### Derived values and access conventions

The **adjusted word** is the input word minus `0xA8`, reduced to 32 bits. Clearing its highest bit gives the **masked word**. Halving the masked word by an unsigned right shift gives the **half index**.

Consequently:

- The masked word ranges from zero to `0x7FFFFFFF`.
- The half index ranges from zero to `0x3FFFFFFF`.
- The masked word shifted right by 17 ranges from zero to `0x3FFF`.

The **halfword base** is the address represented by twice the adjusted word, reduced to 32 bits. It uses the adjusted word before masking.

The **shift-derived base** comes from the fourth argument shifted left by two and then right by 32. Both the signed left shift and the full-width right shift prevent an unconditional numerical interpretation.

References below to a byte, halfword, or word access establish an 8-, 16-, or 32-bit transfer where the supplied representation explicitly types that access. For symbolic globals whose declarations are absent, an assigned expression’s width does not by itself establish the destination’s transfer width.

The chronological phases below preserve separate represented accesses. They do not promise that accesses are nonoverlapping. Byte order and alignment requirements remain unspecified.

### Prefix preceding the conditional termination

The first observable write is a byte containing the low eight bits of the half index, at `0x0897E8B8` plus the fourth argument. Storage annotated at `0x0897E8C0` then receives `0xB8`; its transfer width is not established.

The next part establishes several potentially unrelated memory changes. A byte at input-word-plus-six receives the low byte of the input word, followed by a word containing the entire input word at the shift-derived base. Halfword locations at halfword-base-plus-four and halfword-base-plus-six receive `0xFFFF`, in that order. A byte at shift-derived-base-plus-four then receives `0xB8`, before a halfword at halfword-base-plus-two receives `0xFFFF`.

Storage annotated at `0x0897EA28` receives the low 16 bits of the numeric halfword base. The operation subsequently reads an unsigned halfword at the halfword base. That halfword is zero-extended into a destination address for a word write containing the input word AND `0x897E8B80`.

This last address depends on memory contents at the time of the read, not solely on an input calculation. Earlier writes may affect those contents if addresses overlap.

The reference associated with F-e47d7b2e9c88 supplies the **first reference word**. Its signed interpretation, shifted right by 32, supplies a **companion base** whose value remains unresolved. A separate right shift of the signed reference word by 31, narrowed to 16 bits, supplies a **sign halfword**. With conventional arithmetic right shift, that halfword is zero for a nonnegative reference word and `0xFFFF` for a negative one.

A halfword write of the sign halfword at companion-base-plus-four precedes the sign test. If the first reference word is negative as a signed 32-bit value, the represented path terminates at the first invalid-instruction boundary.

All prefix accesses precede that termination. No rollback is represented.

### Continuation after the sign test

On the nonnegative path, the dependency-derived memory traffic has a significant repeated-access pattern: a sign-halfword write at companion-base-plus-`0x12`, then a self-addressed word write of the first reference word, then a signed halfword read at companion-base-plus-half-index. The same halfword write and self-addressed word write follow the read.

These repeated writes are distinct observable operations. Combining them would lose behavior when memory aliases, is externally observed, or has access-triggered effects.

The fetched signed halfword is sign-extended to 32 bits and shifted right by 16. The result is written as a word at companion-base-plus-eight. Under conventional arithmetic right shift, the result is zero for a nonnegative halfword and `0xFFFFFFFF` for a negative halfword.

The next group concerns annotated storage and low addresses. Prefetch-abort-related storage is cleared before the **selector** is formed. The selector is `0x58` when bit 2 of the first reference word is clear and `0x5C` when it is set.

A word containing the companion base is written at selector-plus-four, selecting address `0x5C` or `0x60`. Next, the masked word shifted right by 17 is narrowed to 16 bits and assigned to storage annotated at `0x00000006`. Undefined-instruction-related storage then receives the low byte of the half index widened to 16 bits.

A word containing the half index is subsequently written at four-times-selector-plus-`0x10`, selecting `0x170` or `0x180`. Supervisor-call-related storage receives the half index afterward. Declarations needed to determine the transfer widths of these symbolic global assignments are absent.

### Stack-associated state

The following phase uses the stack-associated pointer as a destination and as an integer address source.

At its target, a halfword containing the selector is followed by a word containing the companion base shifted left by eight. That shifted value is also written as a word at pointer-plus-`0x14`. A subsequent word write at the pointer target contains the numeric pointer itself.

A word is then read from twice the numeric pointer. Its low halfword is written at the pointer target; afterward, the complete fetched word is used both as an address and as the word stored at that address.

The next destination depends on the **address of the stack-associated location**, not on the pointer stored there: that location’s address is multiplied by `0x20`, then increased by `0x18`. A word written there contains the signed numeric pointer shifted right by 31.

Undefined-instruction-related storage is next assigned a concatenated value consisting of a 16-bit value of five above the currently referenced low byte. The constructed bit pattern is therefore `0x000500` through `0x0005FF`, before any destination-width conversion. This does not establish a three-byte transfer or the exact overlap between that byte and earlier annotated writes.

A pointer-valued, represented 32-bit write follows at four-times-pointer-plus-`0x18`, containing the pointer value.

The source representation repeatedly refers to the stack-associated pointer but does not establish its machine-level loading schedule. If writes can affect its backing location, a single stable pointer value throughout this phase must not be assumed without additional evidence.

## Acceptance examples

These are conditional static examples, not executed tests. Unless stated otherwise, they assume that preceding accesses succeed, relevant arithmetic has the indicated interpretation, and aliasing does not change the illustrated values.

1. **Zero adjusted word.** An input word of `0x000000A8` yields an adjusted word, masked word, half index, and halfword base of zero. The initial indexed byte is zero. The three initial `0xFFFF` halfword writes target addresses four, six, and two, in that order. A fault at one of those addresses is compatible with the absence of validation.

2. **Unsigned wraparound.** An input word of zero yields adjusted word `0xFFFFFF58`, masked word `0x7FFFFF58`, half index `0x3FFFFFAC`, and halfword base `0xFFFFFEB0`. The initial indexed byte is `0xAC`. None of these values resolves the unrelated full-width shift used for the shift-derived base.

3. **Memory-dependent destination.** If the halfword read at the halfword base returns `0x1234`, the subsequent word destination is `0x00001234`. For input word `0x000000A8`, the payload is `0x00000080`, from the exact mask `0x897E8B80`.

4. **Signed halfword propagation.** Under arithmetic right shift, a fetched signed halfword represented by `0x8000` produces a word payload of `0xFFFFFFFF`; `0x7FFF` produces zero.

5. **Selector alternatives.** A clear bit 2 in the first reference word selects writes at `0x5C` and `0x170`. A set bit selects `0x60` and `0x180`.

6. **Early termination preserves the prefix.** A negative first reference word reaches the first invalid-instruction boundary only after the sign-halfword write at companion-base-plus-four. Later selector and stack-associated accesses do not belong to that path.

7. **Overwrites remain observable.** With a stable, accessible stack-associated pointer, the selector halfword write precedes the overlapping shifted-companion word write. An observer that records accesses must retain both, even if the final bytes contain neither original value.

8. **Late signed address calculation.** If the captured global is `0x02000000`, the left shift uses 32-bit wraparound, and right shift is arithmetic, its shifted intermediate is `0x80000000`. The later destination is `0x01FFC000`, not the `0x02004000` obtained with a logical right shift. This example does not establish that signed wrapping is the actual target rule.

9. **Terminal outcome.** Reaching the final invalid-instruction boundary after the represented writes matches the visible terminal path. A normal return is not required or established.
