# F-9d0f947180b8

## Purpose

F-9d0f947180b8 initializes four 32-bit fields in a caller-supplied context from an associated owner and descriptor. A zero/nonzero selector chooses between two descriptor fields.

A nonzero selected value produces a 64-bit result combining that value with the context address. A zero selected value triggers three dependency calls after initialization. If those calls return normally, the function returns the final dependency result’s low 32 bits, zero-extended.

The supplied static representation also contains a resource-processing continuation. Its entry conditions contradict the preceding ordinary control flow. Its operations are therefore described as **documented_only**, not as reachable recovery behavior.

## Interface

### Inputs and widths

The function receives:

- A context address represented by 32 bits.
- A 32-bit selector. Zero selects one descriptor field; every nonzero bit pattern selects the other.

The result is 64 bits. Object addresses, copied fields, and exposed status storage are 32 bits.

### Results

For a nonzero selected value:

- Bits `31:0` contain the context address.
- Bits `63:32` contain the selected value.

The selected value’s complete bit pattern is preserved, including its top bit.

For a zero selected value, if all three dependencies return normally:

- Bits `31:0` contain the low 32 bits returned by F-413e9e177c2e.
- Bits `63:32` are zero.

Neither result construction establishes a conventional success/error meaning.

## Behavior

### Reachable initialization

The established access order is:

1. Read the owner address from context offset `0x00`.
2. Read the descriptor address from owner offset `0x1E0`.
3. Read owner offset `0x19C`, then write the value to context offset `0x18`.
4. Read owner offset `0x1A0`, then write the value to context offset `0x1C`.
5. Read descriptor offset `0x14`, then write the value to context offset `0x14`.
6. Read descriptor offset `0x18` if the selector is zero, or offset `0x1C` otherwise.
7. Compute whether the selected value is zero.
8. Write the selected value to context offset `0x10`.
9. Branch using the retained zero predicate.

The predicate is computed before the selected-value write, but the branch occurs afterward. All four context writes precede any dependency call or ordinary return.

The owner and descriptor addresses are captured before those writes. Later changes to the original address-bearing fields do not cause these addresses to be fetched again. Conversely, each source value is read at its stated position in the sequence. An earlier destination write can therefore affect a later source read through aliasing.

### Nonzero selection

This path has no visible dependency calls, global reads, allocation, scanning, or cleanup. Its explicit writes are the four context-field writes.
