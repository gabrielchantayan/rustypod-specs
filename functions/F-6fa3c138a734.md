# F-6fa3c138a734

## Purpose

F-6fa3c138a734 reverses the order of the four bytes within each of two consecutive unsigned words, replacing both words in place. It preserves the order of the two words: the first word is transformed at its existing location, followed by the second word at its existing location.

This description uses a **32-bit unsigned-word model**. The supplied source establishes an unsigned type and a transformation expressed using shifts by 8 and 24 bits, but it does not include the type definition or target ABI that independently confirms the word width. The four-byte interpretation and the examples below are therefore conditional on that type being exactly 32 bits.

The operation is a byte-order reversal, not a complete bit reversal. Within each byte, bit order is unchanged. No mode, direction, or host-byte-order parameter selects whether the transformation occurs.

## Behavior

### Per-word transformation

Under the 32-bit model, each word is divided into four eight-bit groups. Their positions are reversed.

If a word’s bytes are written from most significant to least significant as **A B C D**, its replacement is **D C B A**.

The mapping is:

| Original bit positions | Replacement bit positions |
|---|---|
| 0–7 | 24–31 |
| 8–15 | 16–23 |
| 16–23 | 8–15 |
| 24–31 | 0–7 |

Each group preserves its internal bit pattern. Every input bit contributes to exactly one output bit under the 32-bit model.

There is no arithmetic carry between groups. Unsigned shifts, masks, and bitwise combination determine the replacement. Left-shifted bits outside the 32-bit result width are discarded; unsigned right shifts introduce zero bits.

The transformation applies unconditionally to both words. It does not inspect a byte-order marker, recognize already converted values, or skip values with particular patterns.

### Layout and byte order

The two word positions are independent destinations. This is not a reversal of the entire eight-byte region.

This byte-sequence example applies to conventional little-endian and big-endian word layouts: reversing the byte positions of each numerical word reverses its four stored bytes in either layout. Other representation details are not established by the supplied source.
