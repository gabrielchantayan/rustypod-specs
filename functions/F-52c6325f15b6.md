### Zero path

If the initial field read is zero:

- F-cbbcd34aa18f is not invoked.
- Neither caller-supplied value is otherwise used by the visible logic.
- No second field read is performed by the visible body.
- The function returns normally, provided the preceding call and read completed normally.

1. Call F-62673223987f.
2. Read the addressed field for the condition.
3. If that read is nonzero, read the same addressed field again for the subordinate call.
4. Invoke F-cbbcd34aa18f, if selected.
