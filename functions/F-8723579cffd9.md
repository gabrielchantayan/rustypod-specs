# F-8723579cffd9

## Purpose

F-8723579cffd9 retrieves one 32-bit value from a selected entry in a caller-supplied structure. A selector value of −1 suppresses the lookup and produces a zero result.

The established behavior is a conditional memory read, not a validated collection access. The function does not establish that the selector is within bounds, that either address is valid, or that the returned value identifies an existing object.

**Inferred intent:** the structure appears to describe a selection within a collection of fixed-size entries, with −1 representing “no selection.” The source establishes the sentinel behavior and address calculation, but not those application-level meanings.

## Behavior

### Sentinel decision

The function first obtains the signed 32-bit selector from A + 8 and compares it with −1.

If that comparison succeeds, the function returns a 32-bit zero. It does not evaluate the entry lookup. In particular, the displayed behavior does not read the base-address field at A + 4 or dereference an entry address.

The sentinel is exactly −1. Zero is an ordinary selector, not an empty-state marker. Other negative selector values are not rejected by the displayed logic.

### Entry lookup

If the initial selector is not −1, the function obtains the entry-storage base address and uses a selector value from A + 8 to locate the returned field.

For a stable selector **S** and base address **B**, the intended address relationship is:

**B + 20 × S + 4 bytes**

The function reads four bytes at that address and returns their 32-bit value unchanged.

The stride is 20 bytes, not 20 four-byte units. The additional four-byte displacement selects a field within the entry rather than the beginning of the entry itself.

There is no visible check against an entry count, capacity, allocation extent, or permitted selector range. The selector need not be nonnegative to pass the sentinel comparison. Any validity requirement beyond “not −1” is therefore a caller or environment responsibility, not an implemented validation rule.
