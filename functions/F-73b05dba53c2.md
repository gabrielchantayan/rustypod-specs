# F-73b05dba53c2

## Behavior

### Initial capture and field inspection

The ordinary value is obtained before the gate field is examined. The function retains this captured value as its initial result.

The base reference is then used to read the gate field at byte offset 12. The offset is a byte displacement, not an index of twelve integer elements. No neighboring field is inspected in the supplied body.

The field comparison is a zero/nonzero test:

- A zero field permits evaluation of the first dependency.
- Any nonzero field prevents both dependency calls and causes the captured ordinary value to be returned.

There is no special handling for a negative field value. Under the modeled integer representation, every nonzero bit pattern follows the same branch.

### First dependency

If, and only if, the inspected field is zero, the function invokes F-a29c445f6d1c with no explicit arguments.

A zero result from this dependency ends selection. The function returns the ordinary value captured before the field read and before this call. It does not obtain a fresh ordinary value after the dependency returns.

Any nonzero result permits the second dependency call. The exact nonzero value is not otherwise interpreted or returned. A result of four from this first dependency has no special meaning: like every other nonzero result, it enables the next step.

### Second dependency and final selection

If the field was zero and F-a29c445f6d1c returned nonzero, the function invokes F-d69481fd28f0 with no explicit arguments.

After that dependency returns, the supplied representation obtains the alternate value and makes it the selected result.

The second dependency’s result is compared with exactly four:

- If it is not four, the alternate value is returned.
- If it is four, the special value is obtained and replaces the alternate value as the returned result.

Zero from the second dependency therefore selects the alternate value. It does not restore the ordinary result. The first dependency’s zero test and the second dependency’s equality-to-four test have distinct roles.
