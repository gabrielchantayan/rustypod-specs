# F-b816506d7dc7

## Purpose

F-b816506d7dc7 performs a finite sequence of indirect calls and computed-address memory writes, then enters an unconditional loop containing further indirect calls and byte writes.

No application-level purpose is established. In particular, the available evidence does not identify an object format, device protocol, allocation operation, or decoding task.

This contract distinguishes:

- **Established static evidence:** displayed operations, argument relationships, call-target selection, and ordering.
- **Conditional arithmetic interpretation:** consequences under a 32-bit wrapping machine model.
- **documented_only:** unresolved execution semantics, dependency behavior, and environmental requirements.

The supplied representation reports invalid instruction data and removal of unreachable regions. Its displayed reachable behavior is the subject of this contract; correspondence to executable behavior is not independently established.

## Acceptance examples

These are conditional static expectations, not runtime observations. Each assumes preceding operations complete.

### Initial write and wrapping

For \(P=3\), the first operation stores word value 3 at address 32, before any dependency call.

Under 32-bit wrapping, \(P=\text{0x40000000}\) instead selects address 20 and stores the unchanged bit pattern 0x40000000.

### Entry-dependent target

If \(N=\text{0x1001}\), the first call target is 0x1fff under the stated arithmetic. Replacing it with a fixed target would not preserve the displayed relationship. Executability of that target is a separate precondition.

### Secondary-register scaling

For \(S=1\), the corresponding store writes 0x01000000 at 0x04000014.

For \(S=256\), both scaled contributions wrap to zero, so it writes zero at address 20.

### Fresh selectors and truncation

If the first selector byte at \(W(Q+1)\) is 5, write 1 targets address 22. If intervening calls change that byte to 9, write 2 targets address 26.

For \(V=\text{0x0ab00000}\), write 2 stores byte 0xab. For \(X=65\), the direct byte store writes 4 because \(B(4X)=4\).

### Loop target and state transition

The first loop iteration starts F-000000000015 at target 0x08833787 and passes zero as its second explicit argument.

If that iteration’s F-000000000016 returns \(Z=3\), the next iteration starts at target 0x088337c5, passes 12 as its first argument, and passes 0x000c0000 as its second argument. Later iterations continue using target 0x088337c5.

### Partial progress

If the initial word store faults, no dependency call is reached. If the first dependency call does not return, the initial word store precedes it, but no subsequent displayed store is reached.
