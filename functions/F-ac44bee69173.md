## Behavior

### Byte transformation

Each input byte is transformed independently. For a byte value \(b\) in the range 0 through 255, define:

\[
T(b) = (-99b - 20) \bmod 256
\]

The result is an eight-bit value. An equivalent expression using a nonnegative multiplier and offset is:

\[
T(b) = (157b + 236) \bmod 256
\]

Only the low eight bits of each result contribute to the constructed object. Carries or borrows from one byte’s arithmetic do not affect another byte.

The visible character conversions may interpret a byte from 128 through 255 as negative on a signed-character target. That interpretation does not change the final eight-bit result: signed and unsigned interpretations differ by 256, whose product with the multiplier is still a multiple of 256.

The visible arithmetic does not require an overflowing 32-bit intermediate. For unsigned byte interpretations, the expression ranges from −25,265 through −20. For signed eight-bit interpretations, it ranges from −12,593 through 12,652. Both ranges fit within a signed 32-bit integer. Reduction to eight bits is therefore the relevant narrowing operation.

### Constructed value

This is a significance-order relationship. It must not be confused with an unconditional statement about increasing memory addresses.
