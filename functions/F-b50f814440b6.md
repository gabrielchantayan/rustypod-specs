These are conditional static expectations, not executed tests.

1. **Truncation:** If the second argument’s low 16 bits are `0x5678`, the first store writes halfword `0x5678` at the incoming base plus that argument. Byte order remains unspecified.

2. **Unsigned wrapping:** With first argument zero, subtraction by `0xe0` produces `0xffffff20`; masking produces `0x7fffff20`; shifting right once produces `0x3fffff90`. The corresponding truncated byte is `0x90`.

3. **Byte-derived address:** If the initial byte read is `0xff`, the later byte-derived destination is numeric address `0x11b`, not the context plus that offset.

4. **Sentinel order:** If reached, the halfword sentinel writes occur at offsets `+4`, `+6`, then `+2`. The subsequent offset-zero read remains separate.

5. **Negative first dependency address:** If its signed interpretation is negative, the halfword write at unresolved base plus `4` precedes termination. The later dependency self-writes are not reached.

6. **Global-slot reread:** If the self-address write changes the global address slot to a different readable value, the following shifted-value write uses that new value plus `4`. Without such aliasing, it uses the unchanged value plus `4`.

7. **Independent arithmetic-base destination:** If the captured arithmetic base is `0x100` and the arithmetic is valid, its self-write stores `0x400` at address `0x400`, regardless of the slot-derived destinations.

8. **Final overlapping read:** If intervening writes change the upper-halfword view to `0x1234`, the reset combination assigns `0x1234ea70`. The `0x5c` assignment follows it.

9. **Termination:** Completion of every represented access still leads to a bad-instruction marker, not an established successful return.
