# F-1ae970f9f82f

## Purpose

F-1ae970f9f82f transfers four consecutive 32-bit values from a fixed-offset region of a source object into the beginning of a destination region.

The source region starts 28 bytes after the supplied source base. The destination receives 16 bytes in total. The values retain their order: the source value at offset 28 becomes the first destination value, followed by the source values at offsets 32, 36, and 40.

All four source values are obtained before any destination value is written. Consequently, for valid ordinary memory, overlap between the source and destination does not cause an earlier destination write to alter a source value that this invocation has yet to read.

No semantic interpretation of the values is established. They may represent numbers, addresses, flags, or opaque data; this function treats them as four independent 32-bit quantities.

1. Write the value acquired from source offset 28 to destination offset 0.
2. Write the value acquired from source offset 32 to destination offset 4.

Because every source value is acquired before any destination write, valid overlapping regions behave as a four-value snapshot followed by four ordered writes. This is a property of the supplied access sequence, not a general claim about arbitrary overlapping copies.
