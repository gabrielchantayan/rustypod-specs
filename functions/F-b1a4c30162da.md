The branch depends on a zero comparison against an integer slot reached through the global pointer:

- A nonzero tested value causes a zero return, without either dependency call or a direct write to the slot.
- A zero tested value causes F-8157a180d901 to be called with 48, followed by F-bb44cd4171b6 with no explicit arguments. The second dependency’s result is stored through the retained pointer and returned.

### Destination retention and global redirection

A dependency may change the global pointer. Such a change does not by itself redirect the final explicit store: that store uses the pointer retained before either dependency was invoked.

For example, if the retained destination is slot A and a dependency redirects the global pointer to slot B, ordinary completion still writes the second dependency’s result into A, provided A remains valid and writable. No direct store into B follows merely from the redirection.

This retention does not establish ownership or lifetime protection. If a dependency invalidates A, the function has no visible check that makes the final store safe.

The distinction also affects subsequent invocations. A prior invocation’s retained destination does not determine which slot a later invocation selects or tests.

### Repeated invocations

The following implications require that the later invocation selects and tests the same slot that received the earlier result, with that slot’s contents unchanged since the earlier store:

- If the earlier stored result was nonzero, the later invocation skips both dependencies and returns zero.
- If the earlier stored result was zero, the later invocation calls both dependencies again, assuming ordinary execution reaches those calls.

Merely requiring no state changes **between** invocations is insufficient. Either dependency may already have redirected the global pointer during the earlier invocation.

Consequently:

- An earlier invocation may store a nonzero result into retained slot A while leaving the global pointer directed to zero-valued slot B. A later invocation selecting and testing B takes the zero path.
- An earlier invocation may store zero into retained slot A while leaving the global pointer directed to nonzero-valued slot B. A later invocation selecting and testing B takes the nonzero path.

A prior stored result therefore predicts a later branch only when the later selection and tested contents satisfy the stated conditions. The function provides no independent completed or in-progress flag.
