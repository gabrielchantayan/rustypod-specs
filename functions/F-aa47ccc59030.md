## Behavior

### Initial selection and transfer

The selection value is the low 32 bits of the input word multiplied by `0x20000000`. It is zero exactly when the input is divisible by eight.

If the input is not divisible by eight:

- The initial 16-bit transfer is skipped.
- The subsequent conditional chains do not reach the exceptional state assignment or data-memory accesses.
- The initial recurring-call base remains **L**.

If the input is divisible by eight, the represented order is:

1. Form the destination address **C + B**, with 32-bit wrapping.
2. Read an unsigned 16-bit value from **C**.
3. Update the auxiliary address state to **C + B − D**, with 32-bit wrapping.
4. Write the previously read 16-bit value to **C + B**.

The source read therefore precedes the destination write, and the auxiliary address update occurs between them in the representation.

There is no bounds, null, alignment, or permission check. If **B = 0**, the source and destination coincide, but a read followed by a write is still represented. Such an operation need not be externally invisible for device-backed or otherwise effectful memory.

### Gates leading to the exceptional stage

The conditional chains advance only while successive 32-bit results are zero.

For a divisible-by-eight input, the relevant early conditions reduce to:

- **L = 0**.
- **L + (S logically shifted right by one) = 0**, modulo \(2^{32}\).
- **A = B**.
- **D = C + B − D**, modulo \(2^{32}\).
- **E = 0**.
- **S + 2B = 0**, modulo \(2^{32}\).

The variable shift counts on this successful chain are zero. Large-count shift behavior is therefore not needed to derive these conditions.

Because **L = 0**, the stack-address condition requires **S** to be either zero or one. The final condition requires **S** to be even, so **S = 0**. Consequently, **2B = 0** modulo \(2^{32}\), giving exactly two possibilities for **B**.

The exceptional stage is thus reached in the represented dataflow only when all of the following hold:

- The input word is divisible by eight.
- **L = 0**.
- **S = 0**.
- **A = B**.
- **B** is `0x00000000` or `0x80000000`.
- **D = C + B − D**, modulo \(2^{32}\).
- **E = 0**.
- The initial transfer has completed without preventing continuation.

These conditions do not establish that such an incoming state is legitimate or attainable on the original platform.

### Exceptional machine-state assignment

The exceptional stage begins with an explicit assignment to **M54**.

The assigned value is **S × `0x40`**, retaining the low 32 bits under the stated model. Since entry to this stage requires **S = 0**, the assigned value is zero.

This assignment occurs:

- After the initial transfer’s destination write.
- Before the exceptional 16-bit source accesses and destination store.
- Before any recurring call or software interrupt.

The representation next forms an adjusted link-derived address equal to **L + `0x40`S**, modulo \(2^{32}\). This is also zero under the exceptional-stage conditions.

In particular, the available material does not establish whether it controls a stack, an address space, execution context, or some other machine facility. It also does not establish whether writing zero permits subsequent accesses and calls to execute normally.

The represented continuation below is conditional on that assignment allowing execution to proceed. Its explicit presence and ordering remain part of the contract even if a later access faults.

### Exceptional zero-address operation

After the **M54** assignment, the routine uses the unsigned 16-bit contents at **L** in two roles:

- As a zero-extended numeric destination address.
- As the value to which `0x000F` is added before a 16-bit store.

Since **L = 0** on this path, the source address is zero. The stored value is the low 16 bits of the value-side read plus `0x000F`.

The representation contains two source-value uses. It does not establish the evaluation order between them or whether the original execution performs one observable read or two. For stable ordinary memory, both uses can be described by the same value. For changing or effectful memory, they must not be assumed equal.

There is no scaling of the destination value: a loaded value of `0x0020` denotes byte address `0x00000020`.

The destination store follows the source evaluations needed to determine its address and value. No local handling is provided if address zero or the resulting destination is inaccessible.

After the represented store completes, the link-derived state is updated to the adjusted address, zero on this path. The earlier **M54** assignment is not represented as being undone.

### Reachability of the remaining conditional body

Under the stated arithmetic and represented dataflow, the later conditional body cannot be reached.

After the exceptional operation, progression first requires a retained auxiliary address to be zero. The next gate combines that zero address with an address advanced by one 16-bit element from zero. That advanced address is numerically two. The gate therefore produces a nonzero result and stops the chain.

If the exceptional stage was not entered, the enabling condition for this later chain is already false.

Consequently, the later pointer loads, signed 16-bit loads, paired wider stores, auxiliary increments, and derived-address stores are not established reachable effects under this model.

This conclusion does not erase the earlier **M54** assignment. That assignment precedes the contradiction and is reachable under the exceptional conditions. Nor does the contradiction establish that an architecturally significant state assignment is harmless.
