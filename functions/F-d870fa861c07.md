# F-d870fa861c07

## Purpose

F-d870fa861c07 conditionally splits caller-owned mutable bytes into an initial token and a remainder. A nonempty initial token is submitted to a lookup dependency. If that lookup resolves a nonzero descriptor address, the descriptor must have classification value 1 for splitting to proceed. A lookup miss does not reject the input.

On acceptance, the function terminates the initial token in place, skips spaces and horizontal tabs before the remainder, optionally advances past one opening double quote, and trims trailing spaces, tabs, and at most one final double quote relative to a caller-derived endpoint.

This is not a general quoted-string parser. Quotes do not protect whitespace in the initial token. Opening and closing quotes are handled independently, without matching or escape processing. The supplied extent bounds neither the initial scan nor the search for the remainder.

The contract below distinguishes established static behavior from inferred intent and unresolved dependency or caller requirements. No runtime tests have been performed.

## Interface

The function takes five inputs and returns a 32-bit result.

| Input | Width and role |
|---|---|
| Buffer address | A 32-bit address identifying the first byte of mutable storage. Elements are 8-bit bytes. |
| Extent | A signed 32-bit integer added to the original buffer address to form the trimming endpoint. |
| Token-output address | Address of a writable 32-bit slot that receives the original buffer address. |
| Remainder-output address | Address of a writable 32-bit slot that receives the selected remainder address on acceptance. |
| Context address | A 32-bit address used to derive the lookup context and, for high lookup indices, locate a descriptor-table base. |

The normal return values are:

- **0:** A nonzero descriptor address was resolved and its 32-bit classification field was not 1.
- **1:** No nonzero descriptor address was resolved, or the resolved descriptor’s classification was 1, and the accepting path completed.

There is no separate error result for invalid storage, dependency failure, an unbounded scan, or a faulting memory access.

### Memory preconditions

Defined ordinary use requires:

- A writable token-output slot before scanning begins.
- Accessible bytes through the initial scan’s first NUL, space, or horizontal tab.
- A writable scan-stopping byte whenever temporary or permanent termination occurs.
- On acceptance, accessible storage beginning one byte after the scan-stopping address and continuing through the remainder search.
- A writable remainder-output slot on acceptance.
- Valid readable and writable storage for endpoint-based trimming.
- Valid record, context, table, and descriptor storage whenever the selected lookup path reads them.
- Storage and alignment suitable for the represented 32-bit accesses.

The buffer cannot safely be null merely because a later condition checks for null: the initial scan dereferences the buffer first.

The extent is not validated and is not a buffer-capacity guarantee. Even an extent of zero does not suppress scanning.

Outputs are addresses into the original storage, not copied strings. Neither output includes a length.

## Behavior

### Initial publication and scanning

The first explicit memory operation is a 32-bit write of the original buffer address into the token-output slot.

The function then examines successive bytes from that address until it encounters:

- NUL: byte value 0;
- space: byte value 32;
- horizontal tab: byte value 9.

Other bytes, including double quotes, carriage returns, and line feeds, do not end the initial token.

The stopping byte is read again to determine whether temporary termination is needed. If that reread is nonzero, the function writes NUL there and schedules restoration using the byte value observed when the scan stopped. If the reread is zero, it makes no temporary write and schedules no restoration.

For stable storage, this means that a stopping space or tab is temporarily replaced with NUL. This applies equally to a separator at the first buffer byte: temporary termination does **not** require a nonempty token.

The distinction between the scan observation and the subsequent reread matters if memory changes between accesses. No atomic snapshot or synchronization is established.

### Lookup eligibility

After any temporary termination, the function rereads the first buffer byte when the buffer address is nonzero.

Lookup is skipped if the address is zero or that first byte is NUL. In ordinary valid use, lookup is therefore skipped for:

- an initially empty buffer;
- a buffer beginning with space or tab, because that separator has just been temporarily replaced by NUL.

Otherwise, F-a19afa5473aa is called with:

1. the original buffer address, identifying the temporarily terminated token;
2. the context address plus 16,532 bytes.

A zero lookup result leaves the resolved descriptor address zero and permits the later accepting path. A nonzero lookup result is interpreted as a record address.

### Descriptor resolution

For a nonzero lookup result, the function reads an **unsigned 32-bit index** at record offset 4.

It next reads a global primary-table base. This read occurs even when the index selects the high-index path and that base is subsequently replaced.

Descriptor selection uses 16-byte entries:

| Unsigned index | Selected base | Displacement from that base |
|---|---|---|
| 0 through 82 | Current global primary-table base | 16 × index |
| 83 through 4,294,967,295 | A 32-bit base read at the context address plus the current value of a global offset | 16 × index − 1,328 |

For the high-index path, the displacement is equivalently **16 × (index − 83)** under 32-bit arithmetic. In particular, index 83 has displacement zero. The base-field location is not established as context offset zero: it depends on the global offset’s value when read.

The represented high-index calculation adds 16 times the index to the selected base and then subtracts 1,328. Address calculations use the represented 32-bit width; multiplication, addition, and subtraction have no accompanying overflow rejection. Large indices can therefore produce wrapped address calculations. No table-capacity check is shown.

A nonzero lookup result can still yield a zero descriptor address after address calculation. That case is treated like other zero descriptor addresses, not like a classification failure.

### Restoration and classification gate

If temporary restoration was scheduled, the saved byte is written back to the original scan-stopping address after lookup and descriptor-address calculation.

This restoration precedes the descriptor classification read. It occurs even if the dependency changed the stopping byte. It does not restore other bytes, global state, context state, or output storage changed by the dependency.

For a nonzero resolved descriptor address, the function reads a 32-bit classification field at descriptor offset 4:

- Classification exactly 1 permits acceptance.
- Any other value returns 0 immediately.

For a zero descriptor address, no classification field is read and acceptance proceeds.

On rejection, the function has already published the token address and performed any scheduled temporary termination and restoration. It has not itself written the remainder-output slot or performed accepting-path splitting or trimming. Dependency effects remain.

### Permanent split and remainder selection

On acceptance, the function forms the endpoint by adding the signed extent to the original buffer address. It then writes NUL at the original scan-stopping address, including when that location already contained NUL.

The remainder search starts **one byte after** that address. Its first byte read is not conditional on the endpoint.

The search skips spaces and horizontal tabs. It stops at NUL or any other byte.

- If it stops at NUL, that NUL’s address becomes the remainder address.
- Otherwise, the stopping location is checked again for a double quote, byte value 34.
- If that check finds a double quote, the remainder address is one byte after it.
- Otherwise, the remainder address is the stopping location.

Skipping an opening quote does not overwrite the quote. The function does not validate the byte after it, search for a matching quote, or interpret escapes.

The selected address is then written as a 32-bit value to the remainder-output slot.

An initial token ending directly at NUL has a significant consequence: the function does not choose that terminating NUL as the remainder. It reads the following byte and searches from there. Even an initially empty buffer requires accessible storage beyond its first NUL on the accepting path.

### Endpoint-based trailing trimming

Trimming uses the caller-derived endpoint, independently of any NUL encountered during remainder selection.

While the remainder address is strictly below the endpoint, the function examines the byte immediately preceding the endpoint. If it is space or tab, that byte is overwritten with NUL and the endpoint retreats by one byte. Trimming continues backward until it reaches the remainder address or encounters another byte.

After whitespace trimming, the function performs one final check. If the remainder address is still strictly below the endpoint and the preceding byte is a double quote, that quote is overwritten with NUL.

There is no further whitespace pass after quote removal. The function then returns 1.

Consequences:

- A closing quote may be removed without an opening quote.
- An opening quote may be skipped without a closing quote.
- Whitespace immediately before a removed closing quote remains.
- Only one final quote is removed.
- Embedded NUL bytes do not independently limit endpoint-based trimming.
- When the remainder address is equal to or above the endpoint, no trailing byte is inspected.
- The adjusted endpoint is not returned.

## Side effects

The function’s own writes occur in this order, omitting inapplicable steps:

1. Publish the original buffer address to the token-output slot.
2. Temporarily write NUL at the scan-stopping location if its reread is nonzero, including a leading space or tab that produces an empty token.
3. After lookup and descriptor resolution, restore the saved stopping byte.
4. On acceptance, write NUL permanently at the scan-stopping location.
5. Publish the selected remainder address.
6. Overwrite trailing spaces and tabs with NUL, moving backward.
7. Optionally overwrite one trailing double quote with NUL.

Dependency effects occur during the lookup call, between temporary termination and scheduled restoration.

A rejected call can therefore perform buffer writes even when the buffer ultimately retains its original separator. “Remainder output unchanged” means only that this function performs no direct write to that slot on rejection; aliasing or dependency effects may still change it.

No direct allocation, copying of token contents, or memory release is shown. Returned addresses borrow caller-provided storage. No ownership transfer, retention policy, or release behavior is established for the dependency.

### Aliasing and external mutation

No overlap checks are present. The buffer, output slots, context, lookup record, descriptors, and global storage are not proven disjoint.

Observable order matters when they overlap:

- The initial output write can change bytes subsequently scanned.
- Separator restoration can change a classification field before it is read.
- Publishing the remainder address can change bytes subsequently examined by trimming.
- If both output slots are the same location, acceptance writes the remainder address after the original buffer address; rejection performs only the initial direct output write.

The ordinary splitting interpretation assumes these accesses do not unintentionally interfere. The function does not provide synchronization or a consistent snapshot under concurrent mutation.

## Acceptance examples

These are conditional static criteria, not observed test results. Unless stated otherwise, storage is valid and noninterfering, bytes remain stable outside the documented writes, and lookup either misses or resolves a descriptor classified as 1.

1. **Basic split.** For `verb alpha  ` followed by NUL, with the endpoint immediately before that NUL, return 1. The token output identifies `verb`, terminated in place. The remainder identifies `alpha`; both trailing spaces become NUL.

2. **Leading separator and empty token.** For a leading space followed by `alpha` and NUL, the leading space is temporarily overwritten, lookup is skipped, and the space is restored before the accepting path permanently replaces it with NUL. The remainder identifies `alpha`. A leading tab behaves equivalently.

3. **Whitespace after the separator.** For `verb`, tab, space, tab, `alpha`, the first tab ends the token. The following space and tab are skipped before choosing the remainder.

4. **Independent quote handling.** For `verb "alpha"` with the endpoint immediately after the closing quote, the remainder starts at `a`, and the final quote becomes NUL.

5. **No second whitespace pass.** For `verb "alpha "` with the endpoint after the closing quote, that quote becomes NUL, but the space before it remains.

6. **Unmatched quotes.** For `verb "alpha`, the opening quote is skipped without requiring a closing quote. For `verb alpha"` with the endpoint after the quote, the final quote is removed without requiring an opening quote.

7. **Descriptor rejection.** If lookup resolves a nonzero descriptor classified as 2, return 0. Restore any temporarily replaced separator, perform no accepting split or trimming, and make no direct remainder-output write.

8. **Lookup miss or zero computed descriptor.** A zero lookup result permits acceptance. A nonzero lookup result whose descriptor-address calculation yields zero also permits acceptance without a classification read.

9. **No separator before NUL.** Given the bytes for `verb`, NUL, `x`, NUL, with extent 4, lookup receives `verb`. On acceptance, the remainder identifies `x`, not the first NUL. Trimming is skipped because the remainder lies beyond the endpoint.

10. **Endpoint does not bound scanning.** An extent shorter than the initial token does not stop either scan. If the chosen remainder is at or above the resulting endpoint, no trailing trimming occurs.

11. **Table boundary.** Index 82 selects displacement 1,312 from the primary base. Index 83 selects displacement zero from the base read at context plus the current global offset. Index 84 selects displacement 16 from that same selected base.

12. **Shared output slot.** If both output addresses identify one otherwise noninterfering slot, acceptance leaves the remainder address there. Rejection leaves the original buffer address there, absent dependency changes.
