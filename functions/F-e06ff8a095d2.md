# F-e06ff8a095d2

## Purpose

F-e06ff8a095d2 conditionally updates a single byte at displacement 44 from a supplied base address and returns a four-byte result.

The second argument selects one of four behaviors:

| Second argument | Byte written at base + 44 | Return value |
|---|---:|---:|
| 2 | 3 | 2 |
| 3 | No write | 12 |
| 4 | 6 | 2 |
| Any other value | 7 | 12 |

This table describes the established behavior. The meanings of the selector values, stored bytes, and return values are unknown. In particular, neither return value is established as a success or failure indication.

## Interface

**Inputs**

1. **Base-address argument.** The supplied representation declares this argument as an integer and uses it to form a memory address. The only displacement used is 44 bytes, equivalently hexadecimal 0x2C.
2. **Selector argument.** An integer compared for exact equality with 2, 3, and 4. It is not treated as a bit mask, range, or low-byte selector.

**Output**

A four-byte return quantity whose value, on ordinary completion, is either:

- Decimal 2, hexadecimal 0x00000002.
- Decimal 12, hexadecimal 0x0000000C.

There is no returned pointer or separately exposed output structure.
