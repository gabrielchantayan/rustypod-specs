# F-1c42088cebb5

## Purpose

F-1c42088cebb5 obtains an object-like reference from F-23e8d37d5f69, invokes an indirectly selected operation on that reference, and derives an unsigned eight-bit value from the first integer stored at the operation’s returned address.

The observable result is the low eight bits of that integer plus 166. The function does not expose the returned address to its caller.

This describes the behavior supported by the supplied static evidence. The meanings of the object, operation, fixed arguments, and returned integer are unknown. Interpreting the dispatch structure as a conventional virtual-method table is plausible, but not required for the contract.

### Producing the return value

The final integer is combined with the unsigned constant 166, then masked with 255.

Equivalently, if the integer read is \(x\), the returned value is:

\[

The operation is not saturation, clamping, or range validation. Larger values wrap in their low eight bits. Integer bits above the low byte cannot affect the final result.

There is no visible branch between reading the result integer and returning the transformed value.
