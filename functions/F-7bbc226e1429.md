2. Add 292 to that integer.
3. Interpret the result as the location of a callable-pointer entry and read that entry.
4. Invoke the callable address obtained from the entry, supplying no explicit arguments.
5. If the invocation returns normally, return without an explicit result.

The second read depends on the first read and the arithmetic result. The call depends on the callable-pointer value obtained by the second read. No explicit wrapper operation intervenes to validate or replace either value.
