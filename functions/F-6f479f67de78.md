- Every nonzero value selects the skipped path.

### Enabled path

Only after that call returns normally does it call F-1bf9985dc121 with the original input plus 52. The second operation is not conditional on a returned status from the first: no such status is inspected.

The two arguments are independently based on the original input value. The second argument is not derived from the first operation’s return value, from a field read at the first location, or from a potentially updated memory representation of the base.

The visible order is therefore:

1. Completion of the condition call with a zero result.
2. Invocation and normal return of F-a600efb7b035.
3. Invocation and normal return of F-1bf9985dc121.
4. Return of the original input.
