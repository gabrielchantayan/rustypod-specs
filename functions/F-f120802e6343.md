## Behavior

### Established construction

The function combines the five incoming components into a packed intermediate field. Their respective contributions begin at intermediate bit positions four, three, two, one, and zero.

The combination is bitwise, not arithmetic addition. Overlapping contributions therefore set a bit once; they do not produce carries.

The combined field is narrowed to eight bits. It is then treated as a 32-bit unsigned value and shifted left by 27 positions. With 32-bit unsigned arithmetic, only the lowest five bits of the narrowed field can survive this shift. Any contribution originally occupying intermediate bits five through seven is discarded by the 32-bit result width.

The resulting 32-bit value is combined with the fixed value `0x000000C0`. There is no overlap between the surviving variable field, which occupies bits 31–27 of this intermediate result, and the fixed bits, which occupy bits seven and six.

That 32-bit result is widened to 64 bits before being shifted left by 32 positions. This ordering is significant: it places the entire constructed word in the upper half of the result and leaves the lower half zero. The final placement is not a 32-bit shift by its own width.

### Boolean-input behavior

When every input is zero or one:

- The negative indicator controls return bit 63.
- The zero indicator controls return bit 62.
- The carry indicator controls return bit 61.
- The overflow indicator controls return bit 60.
- The Q indicator controls return bit 59.
- No input affects bits 39 or 38; both are fixed at one.
- No other return bit can become set.

There are 32 possible return bit patterns under this Boolean precondition.

A set input is not converted into a Boolean by comparison with zero. The one-bit interpretation works because of the input restriction, not because the function performs normalization.

### Non-Boolean inputs

For nonnegative incoming values whose promoted shifts are defined, the function retains raw low-order bit contributions.

Consequences include:

- A component with value two can affect a neighboring, higher-positioned status bit rather than its nominal Boolean position.
- Multiple components can contribute to the same output bit.
- The Q input can contribute to any of the five variable output bits through its lowest five bits.
- Bits five through seven of the Q input do not survive the later 32-bit shift.
- A nonzero input can produce no variable output bits if all of its contributions fall outside the surviving five-bit intermediate field.

For example, a Q value of `0x10` contributes to return bit 63, not bit 59. A Q value of `0x20` contributes nothing to the return value. These are consequences of raw bit packing and truncation, not evidence that such values are valid status inputs.

The first four inputs have character-like types whose signedness is not established here. If one can hold a negative value, its promoted left shift may lack a defined source-language result. The subsequent eight-bit narrowing does not by itself establish defined semantics for an earlier invalid shift.
