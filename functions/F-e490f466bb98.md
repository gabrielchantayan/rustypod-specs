## Behavior

### Ordered execution

For each invocation that proceeds normally:

1. The fourth input is copied into the 32-bit temporary.
2. F-7976f2030437 is called once with the temporary’s address.
3. After that call returns, its integer result is compared with zero.
4. A zero result causes one call to F-2786b076516f.
5. A nonzero result causes that second call to be skipped.
6. After the selected path completes, the function returns without a value.

There is no visible loop, retry, alternate dependency, or additional condition.

The second dependency is never called before the first dependency has returned. If the first dependency does not return normally, the supplied body does not establish that execution reaches either the comparison or the second call.
