# F-4a5c45c1e447

## Purpose

F-4a5c45c1e447 computes an unsigned bit-field transformation from one input value and returns the result. It combines an eight-bit left shift with an eight-bit right shift using inclusive bitwise OR, then applies the mask `0xFF00FFFF`.

Under a 32-bit unsigned interpretation, the transformation has three defining properties:

- The second-lowest input byte becomes the lowest result byte.
- The lowest and third-lowest input bytes are OR-combined into the second-lowest result byte.
- The third-lowest input byte also becomes the highest result byte, while the third-lowest result byte is zero.

This is not an ordinary byte swap or an eight-bit rotation. In particular, the OR operation merges two input bytes, and the mask discards an entire result byte.

### Result constraints and information loss

Every result has bits 16–23 clear. Equivalently, AND-ing the result with `0x00FF0000` yields zero.

Every set bit in the highest result byte must also be set in the second-lowest result byte. This follows because the latter contains an OR combination that includes the former’s source byte.

The transformation is not invertible over all 32-bit inputs:

- Changing only the highest input byte never changes the output.
- In the OR-combined byte, a set bit supplied by input byte 2 obscures whether the corresponding bit of input byte 0 was also set.
