These are conditional static acceptance cases, not executed tests.

1. **Byte-directed destination range.** If the first selector read yields 255 and the ambient byte is `0xab`, the explicit store writes `0xab` at numeric address 272. It does not write 17 bytes beyond the selector’s source address.

2. **Byte truncation.** If a captured word multiplied by four has low byte `0xfc`, the corresponding byte store writes `0xfc`, regardless of higher bits.

3. **Selector re-read.** If an intervening call changes a selector byte from 3 to 9, two successive byte-directed writes using that source may target addresses 20 and 26 respectively. Caching the first selector would violate the represented access sequence.

4. **Independent global reads.** If the two global reads observe different values, later masked argument construction uses the first captured value, while the scaled address path uses the second.

5. **Word-index arithmetic.** Under the 32-bit model, an indexed word store with index 3 targets address 32. This does not establish that the address is accessible or suitably aligned.

6. **Modular collapse.** Under the 32-bit model, multiplying by four, shifting left by 26, then multiplying by 1024 produces zero. The corresponding later selector source is address one, subject to the representation’s reliability limits.

7. **Distinct repeated word loads.** If memory changes between two displayed reads supplied as arguments to one call, the call may receive differently derived values. The available evidence does not determine which read occurs first.
