# F-47c987e17054

## Purpose

F-47c987e17054 selects one of two lookup mechanisms using a flag in a caller-supplied object, obtains an optional pointer to a four-byte value, copies that value when present, performs a branch-specific final dependency call, and returns the copied value.

A null lookup result produces a return value of zero. A non-null result whose first four bytes represent zero also produces zero. The interface therefore does not distinguish “no result” from “result containing zero.”

This contract describes behavior supported by the supplied static representation. The semantic meaning of the object, the lookup argument, and the returned value is not established. Describing the operation as a “lookup” is inferred intent, not evidence that it searches a particular collection or implements a particular resource protocol.

## Behavior

### Branch selection

The function first reads the byte at object offset `0x5F8` and tests its least significant bit.

- If bit 0 is set, it selects the direct branch.
- If bit 0 is clear, it selects the indirect branch.
- Other bits in that byte do not affect the branch decision.

Selection occurs before the initial dependency call. There is no explicit second read of the selector byte. Consequently, a dependency changing that byte after selection does not change the branch already chosen by this invocation.

### Shared return behavior

The value is copied before F-d49b39475920 is invoked. There is no explicit reread of the result storage after that call. If the final dependency modifies that storage but otherwise completes normally without invalidating execution, the return remains the previously copied value.

The final dependency is invoked for both null and non-null lookup results, provided execution reaches that point normally. A null result does not skip the final call.

Neither the initial dependency’s return value nor the final dependency’s return value is used to select the returned value.
