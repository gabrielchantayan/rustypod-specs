# F-ef87a0295e66

## Purpose

F-ef87a0295e66 selects between two ways of forwarding information to a dependency, based on the zero-versus-nonzero result of an indirect operation on an input object.

- A zero result selects F-438680ffebfe, which receives an opaque caller-supplied value and the address of a fixed data object.
- A nonzero result selects a two-stage path: F-d84a46f01e0d receives a field from the input object and a pointer to local scratch storage; F-b287fa5e8a41 then receives the opaque caller-supplied value, the address of a local byte area, and a 16-bit value read from the scratch storage.

This selection and argument flow are established by the supplied static evidence. Interpreting the fixed data as a default message, the byte area as text, or the 16-bit value as a length would require information not supplied here.

## Interface

### Inputs

The function accepts two arguments:

1. **Object pointer.** A pointer to an object accessed using a 32-bit word layout in the supplied representation. The function uses:
   - The word at object byte offset 0 as the base address of an indirect-call table.
   - The callable entry at table byte offset 8.
   - On the nonzero branch only, the word at object byte offset 8.

   The object’s full layout, allocation size, dynamic type, and ownership are not established.

2. **Opaque value.** A 32-bit value passed unchanged to whichever forwarding dependency is selected. Its type and interpretation are unknown. It could represent a handle, pointer, identifier, or another word-sized value; none of these interpretations is established.

### Output

The supplied representation declares no return value. The function does not explicitly return a status, byte count, pointer, or dependency result.

Normal completion means that the selected dependency sequence returned and control reached the function’s end. It does not independently establish successful processing by those dependencies.

## Behavior

### Initial dispatch and branch selection

The function first reads the object’s leading word, uses it to locate the callable entry at table byte offset 8, and invokes that entry with the original object pointer.

The result is represented as a 32-bit integer. Branch selection depends only on whether it equals zero:

- Exactly zero selects the fixed-data path.
- Every nonzero result selects the scratch-storage path.

There is no visible distinction between positive and negative nonzero values. The result is not used as a size, index, offset, or dependency argument.

The indirect call occurs before either branch-specific dependency call. Its effects are not constrained by this function. In particular, the supplied evidence does not establish that it preserves the object, global state, or memory reachable from the object.

### Zero-result path

If the indirect call returns zero, the function invokes F-438680ffebfe with:

1. The original opaque 32-bit input value.
2. The address of one fixed data object.

It then returns, assuming that dependency returns normally.

On this path, the function does not explicitly:

- Read the object word at byte offset 8.
- Invoke F-d84a46f01e0d.
- Read the scratch region’s 16-bit value.
- Invoke F-b287fa5e8a41.

The fixed data object’s contents, extent, mutability, and interpretation are unknown. Passing its address does not establish that it is a string, that it is empty, or that the dependency only reads it.

### Nonzero-result path

If the indirect call returns any nonzero value, the function reads the object word at byte offset 8 and invokes F-d84a46f01e0d with:

1. That word’s value.
2. The address of the scratch region’s initial two-byte area.

This object-field read occurs after the indirect call. Consequently, if the indirect call changes that field while leaving it valid to read, the value supplied to F-d84a46f01e0d is the post-call value. The supplied representation does not show an earlier cached read of that field.

After F-d84a46f01e0d returns, the function reads the initial two-byte area as a 16-bit value. It then invokes F-b287fa5e8a41 with:

1. The original opaque 32-bit input value.
2. The address of the following 510-byte area.
3. The 16-bit value just read, subject to the unknown argument-conversion rules of the dependency interface.

It then returns, assuming that dependency returns normally.

There is no visible branch based on a result from F-d84a46f01e0d. The function does not check whether that dependency initialized the two-byte value or the following byte area before proceeding.

## Acceptance examples

### Zero selects only the fixed-data path

- It receives the original object pointer.
- F-438680ffebfe is called afterward with the original opaque value and the fixed data address.
- F-d84a46f01e0d and F-b287fa5e8a41 are not called by this invocation.

### Negative and positive nonzero values select the same path

### A zero scratch value does not suppress forwarding

Its second argument is still the following byte area’s address. No local special case substitutes the fixed-data path.

### The caller does not clamp the scratch value

F-b287fa5e8a41 is called with the value read from scratch storage. Whether that dependency accepts the value or accesses any particular number of bytes is unknown.
