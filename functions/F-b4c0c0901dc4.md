### Entry behavior

Only after that store does the first indirect invocation occur. Its target is derived from the link-bearing input by adding 4,094. It receives two equal explicit arguments, each obtained by shifting the integer interpretation of the address-bearing input left by nineteen positions. In the nonnegative, representable range, each argument is 524,288 times that input.

Neither argument is a readback from the first byte destination or from the original pointed-to word.
