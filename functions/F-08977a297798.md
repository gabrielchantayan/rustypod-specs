# F-08977a297798

## Purpose

F-08977a297798 conditionally transfers two 32-bit result words into caller-provided storage and returns an integer status.

It first invokes F-946cac4b59bc with zero and the address of a local 12-byte array. It then invokes F-89d1e7e68fff with two caller-supplied values and the address of a different local array. The first invocation is established; initialization or any other memory effect by that dependency is not.

The second dependency’s status determines whether the function examines a one-byte flag. A nonzero status is propagated without either explicit output store. A zero status permits the flag check: bit `0x10` set selects return value `7`; bit `0x10` clear permits two ordered 32-bit output stores and a zero return.

The domain meanings of the inputs, result words, flag, and status `7` are not established. “Success” below denotes only the zero-status, flag-clear extraction path, not an independently verified domain outcome.
