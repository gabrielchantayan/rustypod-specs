# F-5a5558eb330e

## Purpose

F-5a5558eb330e retrieves an eight-byte value from a globally selected memory region. When its input is nonzero, it also replaces that stored value with the contents of the immediately preceding eight-byte region, using two ordered four-byte writes.

The returned value is obtained before either replacement write. A nonzero input therefore selects a read-and-replace operation, not a request to return the replacement value.

Every invocation first calls F-54383d765e10. The selected memory region is consulted after that call. The dependency’s purpose and effects are not established; it must not be assumed to preserve the region selector, other global state, or memory contents.

**Inferred intent:** the two adjacent eight-byte regions may represent a pending value and a current value, with the input controlling whether to advance the current value. Those names are explanatory only. No broader queue, transaction, ownership-transfer, or synchronization semantics are established.

### Nonzero-input path

1. Form an address for the four-byte source at offset `0x3C`.
2. Read the four-byte source at offset `0x38` and write its value to offset `0x40`.

The first four-byte destination write precedes the second four-byte source read and the second four-byte destination write. The replacement is not shown as a single eight-byte copy.
