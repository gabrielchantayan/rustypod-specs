The supplied static representation establishes the order and nominal widths of those writes. It does not establish a higher-level purpose, the ownership of the affected memory, or valid execution beyond the final represented write. ### 3. Halfword write through incoming state

### Ordering and overlap

The represented program order is the first byte, word, halfword, then final byte. This is an ordering of represented write operations, not a guarantee about hardware visibility, atomicity, or persistence.

If destination ranges overlap, later writes can replace bytes written earlier. In particular:

- The halfword write can overwrite part or all of an earlier byte or word write.
- The final byte write can overwrite one byte of the halfword destination.
- Address-width reduction could introduce aliases that do not exist under unbounded arithmetic.

No represented operation restores overwritten data.

For an ordinary memory model, with successful writes and no intervening modification, the last represented write covering a byte determines that byte’s final contents. Applying this rule to multibyte overlaps requires a known byte order and store layout.
