# F-091ca72f80e0

## Purpose

F-091ca72f80e0 performs an ordered, teardown-like transition involving an input object, two objects derived from dependency results, optional associated state, and shared context. On normal completion, it returns the last derived object’s address, which is not established to equal the input address.

The established behavior consists of reads, writes, conditional indirect calls, dependency calls, traversal, and invariant checks. The teardown interpretation is inferred from that sequence; it does not establish concrete types, ownership, destruction, or release of storage.

Seven distinct sites read opaque globals: six supply leading-word replacements, and one supplies an argument to F-77781c8e0ff9. These are reads at their respective execution points, not established constants. Earlier dependencies may affect values read later.

Four invariant-failure paths invoke a diagnostic-like dependency followed, if it returns, by F-feee9156a257, which is annotated as nonreturning. Earlier effects are not rolled back.

## Behavior

It then reads R + 0x170:

### 2. First derived-object transition

It then reads B + 0xEC. A nonzero value leads to F-54385ab29a1f and then F-feee9156a257 if the diagnostic-like call returns.

2. F-7e3145ad059a receives B.
3. F-230c59ef0030 receives T − 0xA4.

## Acceptance examples

These are conditional static acceptance cases, not executed tests.

1. **First invariant fails.** With R + 0x170 observed nonzero, G-entry has already been read and written to R’s leading word. The failure pair follows; R + 0x174 and later global-load sites are not reached.

2. **Second invariant fails.** With the first field zero and R + 0x174 nonzero, the failure pair occurs before F-f8a7a3a1008d.

3. **B invariant fails.** A nonzero B + 0xEC causes failure after the G-B-first load and write, but before the G-B-second load and F-7e3145ad059a.

4. **Later global changes.** If F-a6fdc7050c77 changes the global supplying G-C-second and returns normally, the following leading-word write uses the value subsequently read there, not a value cached before that call.

5. **Additional argument changes during context lookup.** If F-3fdd14ecd250 changes the G-call source before returning, F-77781c8e0ff9 receives the subsequent G-call read, provided argument preparation remains valid.

6. **Conditional callback omitted.** A null result from F-d277584d672d skips both callbacks. A nonnull result whose 0x80 callback returns something other than C skips only the 0x7C callback.

7. **Associated pointer changes.** If association handling changes C + 0x0C, the later +0x04 read follows that current pointer. Traversal and F-8349c252c168 still use captured S.

8. **Traversal yields null.** A nonzero continuation result with a null item performs no item callback but continues traversal. A zero continuation result ends it regardless of the item output.

9. **Collection absent initially.** If S + 0x08 is zero at its initial collection test, no traversal initializer, finalizer, or collection-object callback occurs in that block.

10. **Different context receives the clear.** If one context’s +0x24 equals C but the next lookup returns another context, zero is written to the latter context’s +0x24 without another equality check.

11. **Final global changes during state processing.** If an associated-state dependency changes the G-C-final source, the final leading-word write uses the value loaded after that processing completes.

12. **Subordinate pointer becomes null.** An initially nonzero C + 0x04 followed by a null reread skips the subordinate callback but still checks C + 0x08.

13. **Late invariant bypassed.** An initially zero C + 0x04 permits return of C even when C + 0x08 is nonzero, assuming earlier processing completes normally.
