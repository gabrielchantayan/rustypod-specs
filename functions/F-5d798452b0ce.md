## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not executed tests.

### Signed selection must remain signed

If the initial halfword lookup returns the bit pattern 0xFFFF, the first selected value is −1 after sign extension, not 65535. If the environment permits the resulting accesses, the subsequent doubled-address lookup uses the represented result of twice −1. An implementation that zero-extends this selection does not satisfy the contract.

With no interfering aliasing, the writes at third-argument offsets 0x14 and 0x15 leave bytes 44, AA, 22, 11 at offsets 0x14–0x17. This example is conditional on little-endian storage; byte order itself is not established.
