## Purpose

No application-level purpose is established. The evidence does not identify objects, arrays, initialization, serialization, allocation, or cleanup.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Incoming shift:** If \(I=15\), then \(Q=1\). The early scaled word store writes `0x80000` at `0x200014`, provided execution reaches it.

2. **Byte truncation:** If \(r_4=\texttt{0x12345678}\), the first selected byte store writes `0xe0`; the later high-field byte store writes `0x23`.

3. **Selector reload:** If the two reads at \(Q+1\) yield 5 and 9, their stores target `0x16` and `0x1a`. Matching destinations are not required.

4. **Seven-call completion:** If `F-1106` returns but `F-1107` does not, the subsequent masked word store does not occur. A value returned by the sixth call is not \(r_{11}\). The same final-result rule applies to sequences 17, 19, 29, 31, and 33.

5. **Nine-call completion:** If `F-2108` returns but `F-2109` does not, neither word clear following sequence 21 occurs.

6. **Sequence 23 placement:** Its masked argument goes to `F-2303` immediately after `F-2302`. The clears await completion of all four trailing calls through `F-2307`.

7. **Masked halving:** \(J(\texttt{0xffffffff})=\texttt{0x1fffffff}\), not `0x7fffffff`.

8. **Final selector source:** If \(r_{32}=2\), the final selector read is at `0x11`, regardless of \(A\). Its selected byte receives zero because \(H(2)=0\).

9. **Access failure:** An unmapped selected destination has no represented checked error result or rollback. A word clear at `0x24` is a four-byte access, not a one-byte clear.
