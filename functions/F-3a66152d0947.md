# F-3a66152d0947

## Purpose

F-3a66152d0947 returns an unsigned mask derived from two byte-read expressions at an address selected by a caller-supplied displacement and a base obtained through F-2a4c402ba617.

The result is either zero or 128. Its only potentially set bit is bit 7, numbering bits from zero at the least significant bit.

If both read expressions observe the same byte, the result indicates whether that byte’s bits 7 and 5 differ:

- Equal bits produce zero.
- Different bits produce 128.

That single-byte interpretation is conditional. The supplied representation contains two byte-read expressions and repeats the base-value dereference. It does not establish that the base or selected byte remains unchanged between observations, or that the read expressions execute in a particular order.

**Established static evidence:** one dependency invocation, use of its result as a pointer to an integer-valued base, two byte-read expressions, unsigned bit manipulation, and a returned mask.

**Inferred intent:** extraction of the exclusive-or of two selected bits from a stable byte. The evidence does not establish what those bits mean to a consumer.

### Output

| Return value | Meaning |
|---|---|
| 0 | The two contributing bits are equal. |
| 128 | The two contributing bits differ. |

This is a mask, not a normalized Boolean return of zero or one.

- Bit 7 of the byte used by the unshifted operand.
- Bit 5 of the byte used by the shifted operand.

## Behavior

### Dependency and base acquisition

### Byte selection

Each of the two byte-read expressions obtains an integer base through the returned pointer, adds the supplied displacement, and reads a byte at the resulting address.

The representation repeats this base dereference and byte selection. It does not explicitly establish a saved base value or a saved byte shared by both operands.

Consequently, a specification faithful to the evidence must distinguish two cases:

1. **Stable observations.** Both operand roles use the same base and observe the same byte value.
2. **Different observations.** The operand roles observe different base values, different byte values, or both.

The second case is not evidence that concurrent mutation is supported or safe. It records that the representation does not itself guarantee a common snapshot.

### Bit computation

The byte assigned to the unshifted operand contributes its original bit 7.

The byte assigned to the shifted operand is shifted left by two. Its original bit 5 consequently occupies bit 7.

The exclusive-or combines those operands, and the final mask discards all positions other than bit 7. Thus:

- If the two contributing bits are both clear, the result is zero.
- If the two contributing bits are both set, the result is zero.
- If exactly one contributing bit is set, the result is 128.

All other bits in either byte are irrelevant to the returned value.

For a stable byte, this reduces to testing whether bits 7 and 5 differ. It does not test whether the byte is nonzero, whether either selected bit is set in isolation, or whether both bits are set.
