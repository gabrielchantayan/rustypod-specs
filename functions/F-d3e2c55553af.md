## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **First indexed store.** If the first result has low half 3 and high half 8, the retained shifted word is 12, and the first indexed store writes four bytes representing 12 at numeric address 52.

2. **Snapshot timing.** If G-base contains address A when read, and a subsequent dependency changes G-base to B, the later source-word read still uses A + 20 in the represented flow. If that dependency instead changes memory at A + 20, the later read observes the value present there when the read occurs.

3. **First byte destination.** If the byte at lookup base + 1 is 255 and the retained source word is hexadecimal A5C3E27F, the first byte store writes hexadecimal 7F at numeric address 272.

4. **Second byte selection.** If the second low half is hexadecimal 00600000, the second lookup reads address 4. If that byte contains 5 and the retained source word is hexadecimal 2AC00000, the resulting byte store writes hexadecimal AB at address 22.

5. **Ignored upper bits.** Second low halves hexadecimal 00600000 and C0600000 produce the same second lookup address and final two-byte-clear address. Their upper two bits are masked out for both calculations.

6. **Clear-address boundary.** A second low half of zero selects address zero for the two-byte clear. A low-30-bit value of hexadecimal 3FFFFFFF selects address hexadecimal 007FFFFF. Neither case gains an implicit validity or alignment guarantee.

7. **Overlapping destinations.** If both lookup reads produce the same byte value, the second lookup-directed byte store overwrites the first store’s destination. The two stores are not required to agree.

8. **Failure before completion.** If the second indexed store faults, the later source-word read, subsequent calls, global assignment, and clears are not reached through the represented straight-line path. No rollback is shown.
