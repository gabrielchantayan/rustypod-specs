# F-8f665d464b68

## Purpose

The number of records eligible for examination comes from F-32a0cd51a77a. The record-storage base comes indirectly through the first argument. Records are spaced 12 bytes apart; only the leading integer of each examined record participates in the comparison.

The return value is the zero-based position of the first match, or zero if no match is found. Consequently, zero is ambiguous: it can mean a match at the first record, an empty search, or an unsuccessful nonempty search. The function does not return a separate success flag.

### Search order

The search proceeds in increasing zero-based index order, beginning with index zero.

Before each potential record access, the current index is compared with the captured unsigned bound. If the index is not less than the bound, the function finishes and returns zero without reading a record for that index.
