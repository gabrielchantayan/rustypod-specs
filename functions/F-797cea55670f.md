# F-797cea55670f

## Purpose

F-797cea55670f conditionally updates a destination object using information obtained from an indirectly selected object, then dispatches one of two actions against a handle stored in the destination.

The supplied representation establishes two paths:

- If object selection produces a null pointer, the function returns the 32-bit value 1 without accessing the destination.
- If selection produces a non-null pointer, the function invokes an operation on that object, copies a byte-valued result into the destination, selects an action using a separate zero/nonzero result, and invokes F-feee9156a257 with the selected object.

The final dependency is annotated as non-returning in the supplied representation. Its actual behavior is not independently established. Consequently, successful completion of the non-null path must not be described as an ordinary return of 1.

Names such as “destination,” “selected object,” and “handle” are descriptive roles, not established application-level types. Interpreting this routine as initialization, synchronization, activation, or resource release would require evidence not supplied here.

## Interface

The function accepts one address-like argument identifying the destination.

The supplied representation uses a 32-bit integer type for this argument and forms memory addresses by adding fixed byte offsets. The contract therefore describes the represented 32-bit address model, not a portable host-language pointer interface.

The destination fields accessed are:

| Byte offset from destination | Width | Access | Role established by use |
|---|---:|---|---|
| 0xE1 | 8 bits | Write | Receives the byte-valued result of an indirect operation on the selected object |
| 0xE4 | 32 bits | Read | Supplies the first argument to the branch-specific action dependency |

The byte write covers only offset 0xE1. It does not itself modify offsets 0xE2 or 0xE3, or the 32-bit field beginning at 0xE4. This does not constrain writes performed by dependencies.

No destination access occurs on the null-selection path. On the non-null path, the destination must support the indicated write and read when they occur. No explicit validation of the destination is shown.

### Output and completion

The declared result has a width of 32 bits. The only ordinary return established by the supplied representation yields the numeric value 1.

That return is reached when object selection produces null. The non-null path instead reaches F-feee9156a257, represented as non-returning. The evidence supplies neither an error return nor a meaningful returned status for that path.

## Behavior

### Object selection

The function first calls F-b7af80e829ec without explicit arguments. It uses the returned address as a dispatch object: it reads that object's dispatch-table address and invokes the entry at byte offset 0xE8.

There is no shown null check on the value returned by F-b7af80e829ec before this dispatch access. A usable return value, dispatch table, and callable entry are therefore preconditions for reaching the explicit null-selection test normally.

The object-selection result is checked against null:

- A null result leads directly to the ordinary return of 1.
- A non-null result becomes the selected object used throughout the remaining path.

The null result is not reported as an error. No retry, fallback selection, or destination update is shown.

### Non-null preparation and byte update

For a non-null selected object, the function invokes its dispatch entry at offset 0xE4, passing the selected object.

Only after that operation returns does the function resolve and invoke the selected object's dispatch entry at offset 0x118. It passes the selected object and obtains a byte-valued result.

The function writes that result as one byte at destination offset 0xE1.

The order is significant:

1. The operation at dispatch offset 0xE4 completes.
2. The operation at dispatch offset 0x118 completes.
3. The destination byte is written.
4. The discriminator operation is invoked.

The destination write is therefore already performed before branch selection. A subsequent failure or nonlocal termination does not imply that this write is undone; no rollback is shown.

The dispatch-table accesses for these calls are represented separately. The contract does not require all selected-object calls to use a table value captured before the first call. In particular, dependencies must not be assumed to leave the object's dispatch-table word unchanged.

### Branch discrimination

After writing the destination byte, the function invokes the selected object's dispatch entry at offset 0x134, again passing the selected object.

Its result is represented as a 32-bit integer and is tested only for equality to zero:

- Exactly zero selects the zero branch.
- Every nonzero value selects the nonzero branch.

No particular nonzero value is distinguished. Negative values, if interpreted as signed 32-bit integers, follow the same branch as positive nonzero values.

### Zero branch

On the zero branch, the function reads the 32-bit field at destination offset 0xE4 and passes that value to F-936a8728139d.

No direct invocation of F-6904f7699031 or F-ec4cfa552cce occurs on this branch.

If F-936a8728139d returns normally, control proceeds to F-feee9156a257 with the selected object as its argument.

### Nonzero branch

On the nonzero branch, the function invokes F-6904f7699031 with:

- The 32-bit value read from destination offset 0xE4.
- A value obtained from a referenced global datum.

The global datum's semantic meaning, declared width, and value are not supplied.

If that call returns normally, the function reads the destination's 32-bit field at offset 0xE4 again and passes the newly read value to F-ec4cfa552cce.

The second read is behaviorally important. The first dependency may change the destination field through some other reference or shared state. The second dependency receives the field's value after the first dependency returns, not necessarily the value passed to the first dependency.

The supplied representation does not establish a relative evaluation order between the destination-field read and global-datum read used as arguments to F-6904f7699031. Both supply that invocation; no stronger ordering between those two reads is required here.

If F-ec4cfa552cce returns normally, control proceeds to F-feee9156a257 with the selected object.

### Final invocation

Both action branches converge on F-feee9156a257, provided their preceding dependencies return normally.

The argument is the selected object, not the destination and not the destination's handle field.

The representation marks this invocation as non-returning. It supplies no reliable continuation contract if that annotation is inaccurate and the dependency returns.

## Side effects

The only explicit direct write performed by F-797cea55670f is the one-byte store at destination offset 0xE1 on the non-null path.

Other visible effects can occur through dependencies:

- F-b7af80e829ec and the object-selection operation execute even when selection ultimately produces null.
- The selected object's indirect operations may mutate that object, the destination through aliases, globals, or external state.
- Branch-specific dependencies may alter the destination's handle field or other shared state.
- F-feee9156a257 may terminate control flow or perform other effects not established here.

No allocation, explicit deallocation, ownership transfer, reference-count operation, lock operation, or rollback is directly established. The final invocation must not be labeled a destructor or release solely because it receives the selected object and is marked non-returning.

No dependency is assumed to preserve globals, object contents, destination fields, or memory ownership.

The destination offsets are fixed byte displacements. No loop, scaling, length calculation, or saturation arithmetic is shown. Address overflow, invalid pointers, misalignment behavior, and access faults are not explicitly handled.

## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not executed tests. Each assumes that prerequisites hold and that dependencies return normally except where non-returning behavior is specified.

- F-b7af80e829ec and the selection operation occur.
- No selected-object operation occurs.
- Neither destination field is accessed directly by this function.
- No branch-specific action dependency or final dependency is invoked.

### Zero discriminator

- The destination byte at offset 0xE1 receives 0xA5 before the discriminator invocation.
- F-936a8728139d receives the handle read after the discriminator returns.
- Neither nonzero-branch dependency is directly invoked.
- F-feee9156a257 is invoked afterward if F-936a8728139d returns.

An ordinary returned value of 1 is not required for this path.

### Nonzero discriminator and changed handle

- F-6904f7699031 receives H1 and the referenced global value.
- F-ec4cfa552cce subsequently receives H2.
- F-936a8728139d is not directly invoked.
- F-feee9156a257 follows if F-ec4cfa552cce returns.

### Dependency termination

If the first nonzero-branch dependency does not return, neither the second handle read nor the second action invocation is reached.
