# F-fe23c1492e5d

## Purpose

F-fe23c1492e5d describes an unconditional loop of indirect calls, computed-address memory accesses, and state updates carried into the next iteration.

No application-level purpose is established. The supplied representation does not establish object initialization, collection processing, memory management, or a hardware protocol. Small byte-derived addresses and heavily shifted address calculations do not justify assigning conventional structure or pointer semantics.

The contract below specifies the ordered effects visible in the supplied static representation, conditional on execution reaching them. A dependency that does not return, an invalid call target, or an unsuccessful memory access can prevent later effects.

## Behavior

### Arithmetic and trace conventions

- \(L_n(x)\) means a left shift by \(n\), retaining the low 32 bits.
- \(T(x)=((x\mathbin{\&}\texttt{0x3fffffff})\gg20)\).
- “Low byte” means the least significant eight bits.
- Address additions and scaling use the 32-bit bit-vector interpretation.

The explicitly unsigned right shifts are logical. Some left shifts, multiplications, and additions are displayed with signed types. Wrapping machine behavior is a useful interpretation of the representation, but portable signed-overflow semantics are not established. Arithmetic consequences below are qualified accordingly.

At the start of an iteration:

- \(B\) denotes the first-word-store base.

These are contract symbols, not source identifiers.

## Acceptance examples

These are conditional static acceptance cases, not executed tests. Arithmetic examples use the 32-bit bit-vector interpretation.

1. **Initial word value.** With \(P=3\), the initial word store writes 12 at \(B+20\).

2. **A zero global-derived byte is valid.** If \(G=0\), the first byte-selected store writes zero. The contract does not require a nonzero marker.

3. **Fresh selector reads matter.** If the first selector read returns 5 and a dependency changes that selector to 9 before the first clear, the stores target addresses 22 and 26 respectively.

4. **Global extraction narrows.** For \(G=\texttt{0xffffffff}\), \(G\gg22\) is 1023, but the byte store writes 255.

5. **Masked extraction narrows too.** \(T(\texttt{0x3fffffff})=1023\); storing its low byte writes 255, not a ten-bit value.

6. **The omitted-call interval is observable.** After forwarding the result following the first selector-based clear, a complete trace contains three intervening calls, then a result-producing call, then the call receiving that shifted result twice.

7. **Late call counts exclude producers.** Each interval immediately before F-000000000016, F-000000000017, and F-000000000018 contains three intervening calls. The named result-producing call follows those three.

8. **Explicit word-store accounting.** If an iteration reaches its back edge, it has performed thirteen explicit word stores, regardless of additional stores dependencies may perform.

9. **High shifts discard input bits.** \(L_{28}(L_2(1))=\texttt{0x40000000}\), whereas \(L_{28}(L_2(4))=0\).

10. **Late word value depends on parity.** \(L_{31}(K)\) is zero for even \(K\) and \(\texttt{0x80000000}\) for odd \(K\).

11. **Direct clear does not fix a later selector.** Clearing \(S+1\) does not guarantee that a later selector read returns zero; intervening dependencies may rewrite it.

12. **Continuation is conditional.** If every operation completes, another iteration begins. If a dependency does not return, later effects are not required to occur.
