# F-8ff0260f6859

The established behavior is a byte-replication and dispatch operation. A possible purpose is adapting a byte-sized value to an interface that consumes a repeated-byte word. | Bit range | Value |
|---|---|
| 7–0 | Selected input byte |
| 15–8 | Selected input byte |
| 23–16 | Selected input byte |
| 31–24 | Selected input byte |

The final value is fully determined by those eight input bits. There is no saturation, sign extension, byte reversal, or dependence on the discarded high bits in the visible transformation.
