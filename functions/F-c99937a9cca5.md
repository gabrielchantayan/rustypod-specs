## Acceptance examples

These are conditional deductions from static evidence, not runtime observations.

### Width and extraction

If a byte store receives 0x123456ab, it stores 0xab. If an unsigned byte read yields 0xff, its widened value is 255, not −1.

If a selected low-20-bit field is all ones, extracting positions 10 through 19 and positioning them at bit six yields 0x0000ffc0.

If a combined result’s high word is 0x12345678, a logical right shift of the combined result by 36 followed by word conversion yields 0x01234567, regardless of its low word.

### Fixed-location provenance

If absolute 0x05 contains 0xff when read, the K-supplying word read uses address 0x173. The absolute-0x01 byte store still receives low E, not that byte-derived base.

If the shared-word read yields G and the subsequent absolute-0x60 store changes the same physical storage, publication addresses continue to use retained G.

### Final fixed-location ordering

If V+0x74 aliases absolute 0xa9, both reads remain required. The absolute-0x3a byte write follows both; it cannot be moved before them merely because its destination appears unrelated numerically.

### Reload-sensitive behavior

Suppose low X is 0x12 when written to absolute 0x67. If intervening aliasing stores change that byte to 0x34 before the first U+0x09 consumer and to 0x56 before the second, those two stores receive 0x34 and 0x56 respectively. Reusing 0x12 for both is unacceptable.

### Final argument timing

If the halfword store at twice S changes storage read at S+0x64, A reflects the post-store value. If the later word store of 100 changes storage read at S+0x74, B reflects that later state.

H remains the earlier R+0x14 read even if R+0x14 subsequently changes. C from R+0x64 determines store destinations and must not replace A in the invocation.

### Observable writes and partial execution

If writes are observable events, two consecutive equal byte stores remain two events, and the U+0x20 trace includes 0x20, 0x2f, the widened byte-derived value, and 0x20.

If a dependency does not return, later accesses need not occur. Earlier effects need not be undone.
