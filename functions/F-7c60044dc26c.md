## Acceptance examples

These are conditional static expectations, not executed tests. Each assumes execution reaches the stated operations and that required memory accesses succeed.

1. **Unsigned subtraction boundary.** With second argument 0xA8, the subtraction result, doubled address, and reduced value are zero. The three explicit 0xFFFF stores target addresses four, six, and two, in that order. The destination-selecting halfword is then read at zero.

2. **Unsigned underflow.** With second argument 0xA7, subtraction yields 0xFFFFFFFF, doubling yields 0xFFFFFFFE, and masking then halving yields 0x3FFFFFFF. These values do not imply accessible destinations.

3. **Early termination.** If the first dependency address has bit 31 set, the halfword store at the unresolved dependency base plus four precedes the early termination marker. Selector-dependent and later operations are not reached on that represented branch.

4. **Signed halfword propagation.** Under arithmetic right-shift semantics, a captured halfword of 0x8000 produces a later 32-bit store of 0xFFFFFFFF at the dependency base plus eight. A captured halfword of 0x7FFF produces zero.

5. **Aligned address-global self-store.** Suppose the incoming pointer’s numerical address is 0x0225FAA0 and signed multiplication by four is defined. The assignment to 0x0897EA80 produces 0x0897EA80. In ordinary stable memory, the indirect self-address store targets that global exactly and writes 0x0897EA80 back unchanged. The subsequent fresh read therefore yields 0x0897EA80, and the reduced-value store targets 0x0897EA84. This illustrates a reread without an overlap-induced value change.

6. **Final field reread.** If the final 16-bit field contains 0x1234 when read, the concatenation value is 0x1234EA70, regardless of whether its earlier assignment supplied a different halfword. The example does not establish which intervening destination could overlap that field.

7. **Fresh byte concatenation.** If the global-byte read returns 0xA6, the concatenation value is 0x0005A6. Its complete assignment width remains unknown.

8. **Interrupted sequence.** If the initial memory-selected 32-bit write faults, later dependency-address effects are not established. Earlier successful writes may remain visible.
