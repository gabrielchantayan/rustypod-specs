# F-b0b8a976828c

## Purpose

F-b0b8a976828c specifies an apparent routine that interleaves indirect calls with byte accesses, explicitly 32-bit memory accesses, and four zero assignments to a global at address \(0x24\) whose access width is unknown.

The visible sequence propagates an input, stores scaled call results, performs selected clears, and reaches an invalid-instruction boundary. No application-level purpose, valid object model, resource-management role, or successful-return behavior is established.

The contract separates:

- **Established static evidence:** access widths explicitly represented, call ordering, argument expressions, consumed results, and the terminal boundary.
- **Inferred interpretation:** 32-bit bit-vector arithmetic for represented machine words and calculated addresses.
- **documented_only unknowns:** unresolved dependency behavior, ABI details, memory validity, the width of the global assignments, and actual execution.

Every operation is conditional on execution reaching it, preceding accesses succeeding, and preceding calls returning.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Maximum initial selector.** If \(S=0xff\), the initial selected byte write targets \(0x110\), and the subsequent explicitly 32-bit store of \(P\) targets \(0x410\).

2. **Zero selector and address coincidence.** If \(S=0\), the initial selected byte address is \(0x11\), and the first 32-bit store of \(P\) targets \(0x14\). The later selector-derived store of \(S\) targets \(0x24\) and is explicitly 32-bit. This does not establish the width of the four separate assignments to \(G_{24}\).

3. **Distinct scaled accesses.** If \(R_8=1\), the store after chain 08 targets \(0x24\), but the following read targets \(0x18\). The read cannot be replaced by the stored value.

4. **Changed selector.** If the first relevant read from \(D+1\) yields 2 and the later read yields 7, the selected payload write targets \(0x13\), while the later clear targets \(0x18\).

5. **Retained selector.** If \(T=3\), the clear after chain 16 is an explicitly 32-bit access at \(0x47\), regardless of a later change to \(M_8[E+1]\). Whether that unaligned access succeeds is unknown.

6. **Mask before shift.** If \(Q=0xc0000004\), the value stored after chain 07 is 2, because masking precedes the logical right shift.

7. **Split result.** If chain 18 yields \(L=3\) and \(U=5\), F-X11 receives 12. The subsequent explicitly 32-bit clear targets \(0x4e\), followed by the third width-unresolved zero assignment to \(G_{24}\).

8. **Unknown global extent.** Reaching all four \(G_{24}\) assignments establishes four ordered zero assignments. It does not establish that each writes four bytes or clears the range \(0x24\) through \(0x27\).

9. **Wrapping address calculation.** Under the stated bit-vector interpretation, \(H=64\) makes \(K\) wrap to zero. The corresponding selector read is at address 1, without a represented range check.

10. **No normal-return guarantee.** Even if all calls return and all accesses succeed, the represented path ends at an invalid-instruction boundary.
