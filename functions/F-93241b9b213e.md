The arithmetic in the supplied representation is integer-address arithmetic. The offsets are not scaled by the size of an integer merely because the eventual read is integer-sized. On the apparent byte-addressed target, the fixed offsets are 12 bytes backward and 4 bytes forward.

Only bit `0x2000` of the flags word affects this function’s decision. Other bits may be set or clear without changing the branch outcome, provided the lookup reaches the same readable flags word.

The layout adjustment is signed. A negative adjustment is not rejected by the function. It can therefore place the flags word before the object base, subject to address validity and the target’s arithmetic rules. The fixed addition of 4 is applied as part of the final flags-address calculation.

If the selected flags bit is clear, the function reads the character-sized value reached through an external pointer reference. Zero prevents the dependency call. Any nonzero value permits it; the function does not require a particular positive value or a value of exactly one.

The signedness of a character value does not affect this zero-versus-nonzero decision. A byte with its high bit set is still nonzero under either ordinary signed or unsigned interpretation.
