## Behavior

### Address discovery and read order

The function first forms the location at byte offset `0xF00` from the supplied argument and obtains a four-byte value there.

It then uses that retrieved value as the base for the second lookup. The second location is at byte offset `0xC20` from this retrieved base.

The function obtains an eight-byte value from the second location and returns it.

The second address therefore depends on the value obtained by the first read. It is not a lookup at the sum of both offsets from the original argument. A change to the four-byte address field can redirect the second lookup without changing the original argument.

The available representation contains two logical memory reads in this dependency order:

1. The four-byte address-bearing field.
2. The eight-byte result-bearing field selected by the first read.

This establishes the logical access sequence, not a hardware transaction count. It does not establish whether the eight-byte access is implemented as one machine load or several.
