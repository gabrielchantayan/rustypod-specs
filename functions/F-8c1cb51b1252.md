# F-8c1cb51b1252

## Purpose

F-8c1cb51b1252 selects one of two layout-related data references, passes that selection through a helper using a temporary 32-bit state slot, delivers the helper’s result to an object-dispatched operation, and then invokes a second helper on the same temporary slot.

The selection depends on the zero/nonzero result of F-b7dc2cfb1085. On the zero-result path, an additional object query can enable a call to F-0683c3467ba0 before the selection is processed.

**Established behavior:** the function coordinates these calls, their ordering, and the values explicitly supplied to them.

**Inferred intent:** the two selections appear to request a default layout or a status-bar layout. The names associated with the referenced data suggest that interpretation; the supplied evidence does not establish the resulting user-interface behavior.

## Behavior

Before invoking any dependency, the function copies the fourth argument into a local 32-bit slot.

It then reads the object field at `0xB0` and passes that value to F-b7dc2cfb1085. This read precedes the optional reads of `0xC8`.

### 2. Select the nonzero-result path

If F-b7dc2cfb1085 returns nonzero:

- The function selects the data reference associated with the status-bar-layout name.
- It does not directly read the object field at `0xC8`.
- It does not invoke the indirect query at dispatch offset `0x13C`.
- It does not invoke F-0683c3467ba0.

These exclusions concern this function’s own visible operations. They do not constrain the internal behavior of any dependency.

### 3. Select the zero-result path and perform the optional action

If F-b7dc2cfb1085 returns zero, the function reads the 32-bit object field at `0xC8`.

If that value is zero, it skips both the indirect query and F-0683c3467ba0.

If that value is nonzero, it obtains the object’s dispatch-table pointer and invokes the operation at offset `0x13C`, supplying the object as its explicit argument. The query’s result is again interpreted solely as zero versus nonzero.

If the query returns zero, F-0683c3467ba0 is skipped.

If the query returns nonzero, the function **reads the object field at `0xC8` again** and passes this newly read value to F-0683c3467ba0. It does not reuse the value that originally passed the nonzero test. There is no second nonzero check.

Consequently, a query that changes this field affects the argument supplied to F-0683c3467ba0. If the query changes the field to zero and returns nonzero, the visible behavior is to invoke F-0683c3467ba0 with zero.

After this optional sequence completes normally, the function selects the data reference associated with the default-layout name. The query result and the result of F-0683c3467ba0 do not select the status-bar alternative.
