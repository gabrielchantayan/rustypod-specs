# F-b1d700c3773f

## Purpose

F-b1d700c3773f conditionally updates a destination record according to a one-byte selector read from a separate source object.

The established behavior has three outcomes:

- Selector values **1, 2, or 4** obtain a result from dependency F-8e8cd22930fb, invoke F-74b5a05d0094, and write a result and fixed status values into the destination.
- Selector value **3** obtains a byte-string address from F-95b79f0a129e. A null address causes an immediate return. Otherwise, the function counts groups of bytes using a specific continuation-byte rule, invokes F-74b5a05d0094, and writes the count and fixed status values into the destination.
- Every other selector value updates only a status field and an adjacent byte through this function’s explicit writes.

The apparent intent is to derive a length-like or count-like value for supported source categories and mark unsupported categories differently. The meanings of the categories, result fields, and status encodings are not established. In particular, the byte-string branch is not a validating Unicode decoder.

## Behavior

### Initial selection

The function first loads the source-object address from the third argument’s slot, then reads the selector byte at offset 30 in that object.

The selector is read once by the visible body. All subsequent branch selection uses that sampled value. No dependency is invoked before this read.

The complete selector partition is:

| Selector byte | Selected behavior |
|---|---|
| 1, 2, or 4 | Obtain a result from F-8e8cd22930fb |
| 3 | Obtain and scan a byte string from F-95b79f0a129e |
| Every other byte value | Apply the unsupported-selector status update |

Whether the selector byte is interpreted as signed or unsigned does not affect membership in these four explicitly recognized values.

### Selectors 1, 2, and 4

The function invokes F-8e8cd22930fb and retains its returned 32-bit integer result.

It then proceeds to the common result-commit sequence. No other explicit source-object reads or destination writes occur between the selector read and that sequence.

The supplied body does not establish how F-8e8cd22930fb obtains its inputs or what its result means. In particular, it does not establish that the result is nonnegative.

### Selector 3: acquiring the byte string

The function invokes F-95b79f0a129e and interprets its result as a byte-string address.

If the returned address is null, the function returns immediately:

- F-74b5a05d0094 is not invoked.
- No destination field is explicitly read or written by this function.
- No error status is explicitly installed.

This is not a guarantee that the destination or any other state remains unchanged: F-95b79f0a129e may itself have side effects.

If the returned address is non-null, the function begins a scan with a 32-bit count initialized to zero.

### Selector 3: byte-group counting

The scan stops when the byte at the current scan position is zero. That zero byte does not contribute to the count.

Each nonzero byte reached at the outer scan position contributes exactly one to the count. What follows depends on that byte’s unsigned value:

- For values **1 through 191**, the next outer scan position is the immediately following byte.
- For values **192 through 255**, the scan advances past the current byte and then skips every immediately following byte whose two highest bits are `10`. These skipped bytes are values **128 through 191**. They do not contribute individually to the count.

After such a skip, the first byte outside the continuation range becomes the next outer scan position. That byte is examined by the skip condition before it is examined again by the outer scan. If it is zero, the outer scan terminates.

Consequences include:

- A continuation-range byte reached directly by the outer scan counts as one.
- A byte of value 192 or greater suppresses counting of any number of immediately following continuation-range bytes.
- The function does not enforce a maximum continuation-run length.
- The function does not check whether a high-valued byte is a valid encoding lead byte.
- The function does not reject incomplete sequences, overlong encodings, surrogate encodings, or out-of-range character encodings.
- A high-valued byte immediately followed by zero counts as one.
- Zero always terminates the scan; it is not skipped as a continuation byte.

Thus, for appropriate well-formed inputs this may resemble a character count, but its established contract is the byte-group rule above, not Unicode scalar-value counting or user-perceived character counting.

Once the terminator is reached, the retained count becomes the result for the common result-commit sequence.

### Common result-commit sequence

Both the supported non-string selectors and a completed non-null string scan reach this sequence.

The observable order is:

1. Invoke F-74b5a05d0094.
2. Store the retained 32-bit result at destination offset 8.
3. Store the result shifted right by 31 bits at destination offset 12.
4. Overwrite the entire 16-bit field at destination offset 36 with **4**.
5. Store **1** in the byte at destination offset 38.
6. Return.

Under the signed arithmetic-right-shift interpretation expressed by the supplied representation, the offset-12 value is:

- **0** for a nonnegative 32-bit result.
- **4,294,967,295**, equivalently all 32 bits set, for a negative 32-bit result.

The pair of 32-bit stores therefore has the numerical pattern of a signed 32-bit value extended into two 32-bit components. A particular 64-bit object layout or application-level 64-bit type is not established.

F-74b5a05d0094 runs **before** all four explicit commit writes. Its effects must not be assumed to preserve the destination, the scanned memory, or global state. The subsequent stores use the result already obtained; the body does not recompute that result after the dependency returns.

### Unsupported selectors

For every selector outside 1, 2, 3, and 4, the function:

1. Reads the current 16-bit value at destination offset 36.
2. Clears its lowest five bits and sets those five bits to the value **1**.
3. Writes the modified 16-bit value back to offset 36.
4. Writes **5** to the byte at offset 38.
5. Returns.

Bits 5 through 15 of the status field are preserved by this explicit update. The result fields at offsets 8 and 12 are not explicitly accessed on this path.

No dependency is invoked on this path.

## Side effects

The stores are distinct operations in the supplied body. No atomic transaction, synchronization, or rollback behavior is established.

## Acceptance examples

These examples are conditional on valid memory, normal dependency returns, and no concurrent interference. They describe expected behavior, not executed tests.

### Supported selector with a positive result

Given selector **2**, suppose F-8e8cd22930fb returns **37**.

Expected order:

- F-8e8cd22930fb is invoked.
- F-74b5a05d0094 is invoked.
- Offset 8 receives **37**.
- Offset 12 receives **0**.
- Offset 36 receives the full 16-bit value **4**.
- Offset 38 receives **1**.

### Supported selector with a negative result

Given selector **4**, suppose F-8e8cd22930fb returns **−7**.

Under the signed arithmetic-right-shift interpretation, offset 8 receives the 32-bit representation of **−7**, and offset 12 receives all bits set. The status stores are still **4** and **1**.

### Null string result

Given selector **3**, suppose F-95b79f0a129e returns null.

The function returns without its own destination writes and without calling F-74b5a05d0094. Any effects already performed by F-95b79f0a129e remain outside that no-write guarantee.

### Empty string

Given selector **3** and a returned string whose first byte is zero, the computed result is **0**. The common commit sequence runs.

### Ordinary nonzero bytes

For the hexadecimal byte sequence **41 42 43 00**, the computed result is **3**.

### Lead-like byte followed by continuation bytes

For **E2 82 AC 00**, the computed result is **1**: the first byte counts, and the next two bytes are skipped.

For **F8 80 80 80 80 80 00**, the result is also **1**. No encoding-validity rejection is established.

### Isolated continuation byte

For **80 00**, the computed result is **1**. A continuation-range byte is skipped only when encountered in the skip run following a byte of at least 192.

For **80 C2 80 00**, the computed result is **2**.

### Incomplete sequence

For **E2 00**, the computed result is **1**, followed by the common commit. No incomplete-sequence error is reported.

### Unsupported selector with existing status bits

Given selector **0** and an initial offset-36 value of hexadecimal **ABCD**, the updated value is **ABC1**. Offset 38 receives **5**. The function does not explicitly access offsets 8 or 12.
