# F-c22a394bf51a

## Purpose

F-c22a394bf51a prepares a local 16-byte payload from four global 32-bit values, invokes three dependencies in a fixed order using a shared local working region, and writes a one-byte result from the final dependency to a globally selected destination at byte offset 46.

Each payload word undergoes an independent unsigned right shift by one bit. The transformation is not a right shift of a combined 128-bit value: no bit carries between words.

The function contains no explicit success test, error return, allocation, or cleanup operation. The meanings of the payload, dependency arguments, and final result byte are not established.

A device-related construction or lookup operation is plausible inferred intent, based on the static argument’s descriptive labeling. That interpretation is not part of the required behavior.

## Behavior

### Source capture

Before invoking any dependency, the function reads the four source globals and initializes the corresponding local payload words in ascending payload order.

These are separate reads. The supplied body does not establish an atomic snapshot, synchronization, or protection against concurrent modification. If the globals change during capture, the body provides no consistency guarantee across the four values.

After capture, the transformation operates on the local words. It does not reread the source globals. Changes to those globals alone therefore do not change the already captured payload.

The function performs no direct write back to the four source globals.

### Independent 32-bit transformation

The function transforms the payload words in descending offset order:

1. The word at offset 12.
2. The word at offset 8.
3. The word at offset 4.
4. The word at offset 0.

For each word, it reads the current value through an unsigned 32-bit access and replaces that word with the value shifted right by one bit.

For an unsigned input value \(x\), the transformed value is \(\lfloor x/2 \rfloor\). Consequently:

- Input bit 0 is discarded.
- Input bits 1 through 31 move to positions 0 through 30.
- Result bit 31 is zero.
- No sign extension occurs.
- No discarded bit is inserted into another word.
- The result lies between 0 and 2,147,483,647 inclusive.

The transformation is in place. Each word’s transformed value is stored before the next lower-offset word is transformed. Reverse traversal affects the order of local accesses, but not the four independent arithmetic results.

After all four transformations, the function writes one zero byte at payload-relative offset 16. It does not initialize the remaining seven bytes of the trailing region.

The zero at offset 16 is not proof of a sixteen-character string. Earlier payload bytes may be zero, and neither an encoding nor a dependency’s interpretation of the data is established.

The destination is not captured before the dependency sequence. A dependency’s change to the destination global can therefore redirect the final store.

The function writes the one-byte result obtained from the third call to that selected address. Its direct store:

- Has width one byte.
- Does not explicitly read the previous destination byte.
- Does not compare old and new values.
- Does not normalize the result to zero or one.
- Is not conditional on any recognized success or failure value.
- Does not directly overwrite neighboring bytes.

After the store, the function returns without a value.

The supplied body does not establish pointer width, address-overflow behavior, or a valid interpretation for destination values that do not identify suitable writable storage. Such cases are not assigned wraparound or recovery semantics by this contract.
