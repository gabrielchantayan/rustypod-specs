## Behavior

### Entry decision

The function first reads exactly one byte at offset +3.

If that byte is nonzero, the function skips all remaining direct memory accesses and all dependency calls, then returns `0xFFFFFFFF`.

If that byte is zero, the function reads exactly one byte at offset +1. If this second byte is nonzero, it likewise skips the dependency sequence and returns `0xFFFFFFFF`.

Only zero versus nonzero matters. A byte value of 2, for example, blocks entry just as a byte value of 1 does.

The entry decision uses these ordered reads. It is not a simultaneous observation of the two fields. Offset +3 is not reread before entry, so a later change to that field does not alter the decision already made.

### Entered sequence

When both qualifying reads produce zero, the function performs these actions in order:

1. Writes the one-byte value 1 at offset +1.
2. Calls F-5bcae2eff9a7 with the address at base +96.
3. After that call returns normally, calls F-5bcae2eff9a7 with the address at base +100.
4. After that call returns normally, calls F-fceaba74ea88 with the address at base +104.
5. After that call returns normally, writes the one-byte value 0 at offset +1.
