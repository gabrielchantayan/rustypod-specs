## Acceptance examples

These examples are conditional static acceptance criteria, not executed tests.

1. **Unsigned selector interpretation.** If a selector read returns 255, its byte-selected destination is address 272. It is not address 16 through signed-byte interpretation.

2. **Selector re-read after calls.** If the first argument-base selector read returns 3 and the second returns 9, the corresponding zero writes target addresses 20 and 26, respectively.

3. **Captured selector preservation.** If the captured selector is 7, the later word store in that phase targets address 27 even if a dependency subsequently changes the selector memory to 12.

4. **Byte truncation.** If the byte payload source is 65, the byte write of four times that value stores 4, while the associated call argument is the full word value 260.

5. **Unaligned lookup possibility.** If lookup-token bits 20 through 29 encode 1, the computed word read starts at address 21. The represented behavior does not round this address to alignment.

6. **High-bit base selection.** If the second tertiary value has low two bits equal to 3, the high-bit base is 0xc0000000 under the stated word model.

7. **No normal completion.** If all dependencies return and all accesses succeed, completing the final call begins another iteration rather than returning.

8. **Observable partial progress.** If a dependency does not return after a store, preceding stores have already occurred. No rollback is represented.
