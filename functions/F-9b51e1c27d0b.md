# F-9b51e1c27d0b

## Purpose

F-9b51e1c27d0b dispatches on a classification returned by F-3b33b57eae0c and performs one of three actions:

- For classifications 1 through 7, writes a dependency-selected number of bytes derived from two 32-bit descriptor words.
- For classifications greater than 11, invokes an external operation with a destination, a descriptor-supplied argument, and a descriptor-supplied length. A descriptor flag can enable a second external operation over an address immediately following a currently described region.
- For classifications 0 and 8 through 11, returns zero without directly writing the destination.

The established behavior is dispatch, byte extraction, dependency invocation, and 32-bit arithmetic. Describing the external operations as copying and padding is an inference from their argument patterns, not an established contract of those dependencies.

The second input is not a general destination-capacity check. It is used only in one conditional calculation in the greater-than-11 branch. In particular, it does not limit the direct byte-writing branch or the first external operation.

## Interface

### Inputs

| Input | Width and interpretation | Use |
|---|---|---|
| Destination | 32-bit value represented as a signed integer in the supplied representation | Used as an address for direct byte stores and as an argument to external operations. |
| Limit | Unsigned 32-bit value | Used only when classification exceeds 11 and descriptor bit 11 is set after the first external operation. Its comparison is signed, despite its unsigned representation. |
| Descriptor | Pointer to 32-bit unsigned words | Passed to F-3b33b57eae0c and subsequently read at branch-dependent offsets. |
| Auxiliary value | 32-bit value of otherwise unspecified type | Passed unchanged to F-3b33b57eae0c. Its interpretation is unknown. |

The descriptor has the following observed layout. These names describe use within this function, not an independently established data type.

| Byte offset | Observed role |
|---|---|
| 0 | First payload word for classifications 1–6; additive value for the optional greater-than-11 calculation |
| 4 | Second payload word for classifications 1–6 |
| 8 | First payload word for classification 7 |
| 12 | Second payload word for classification 7 |
| 16 | Not directly accessed |
| 20 | Second argument to the first external operation |
| 24 | Initial external-operation length; later reread for optional-operation address and extent |
| 28 | Flags word; mask `0x00000800` enables the optional operation |

The function does not establish a fixed minimum descriptor size independently of its dependencies. Its own accesses require:

- Words at offsets 0 and 4 for classifications 1–6.
- Words at offsets 8 and 12 for classification 7.
- Words at offsets 20, 24, and 28 for classifications greater than 11, plus offset 0 when the optional operation is enabled.

F-3b33b57eae0c may require additional accessible data.

### Output

The return value is unsigned and 32 bits wide:

- Classifications 1–7: the value returned by F-445198130f42.
- Classifications greater than 11 without the optional-operation flag: the length read before the first external operation.
- Classifications greater than 11 with that flag: the calculated endpoint selected by the signed comparison described below.
- Classifications 0 and 8–11: zero.

The return value is not uniformly a byte count. In the optional-operation case, it is a selected endpoint value, which can differ from both the initial length and the second operation’s extent.

### Preconditions

No explicit validation establishes pointer validity, descriptor size, destination capacity, alignment, non-overlap, or acceptable dependency results.

For defined use, the caller must provide whatever memory and arguments the selected path and its dependencies require. A zero return does not establish that inputs were valid or that dependencies had no side effects.

## Behavior

### 1. Classification

The function first calls F-3b33b57eae0c with the descriptor and auxiliary value.

All branch selection uses that dependency’s unsigned 32-bit result:

| Classification | Selected behavior |
|---|---|
| 1–6 | Direct byte generation from descriptor offsets 0 and 4 |
| 7 | Direct byte generation from descriptor offsets 8 and 12 |
| 0, 8–11 | Return zero |
| 12–`0xFFFFFFFF` | External-operation branch |

The 1–7 test uses unsigned subtraction and comparison. Classification zero therefore does not enter that branch.

Descriptor reads used by the selected branch occur after F-3b33b57eae0c returns. They are not snapshots of descriptor contents from before that call.

### 2. Direct byte generation

For classifications 1–6, the function reads the word at descriptor offset 0, followed by the word at offset 4.

For classification 7, it instead reads the word at offset 8, followed by the word at offset 12.

Call the selected values the first and second payload words. They are captured before the next dependency call.

The function then calls F-445198130f42 with no explicit arguments. Its unsigned 32-bit result determines both the number of byte stores and the function’s eventual return value. No upper bound is enforced.

For a count of zero, no destination byte is written.

For a positive count:

- The first store targets destination offset count minus one.
- Subsequent stores target descending offsets.
- The last store targets destination offset zero.
- The first byte stored is the least-significant byte of the first payload word.
- Each subsequent byte is the next byte of the combined payload, proceeding through the first word and then the second word.

For descriptive purposes, the payload can be viewed as an unsigned 64-bit quantity whose low 32 bits are the first word and whose high 32 bits are the second word. Bytes are extracted from its least-significant end and placed into destination addresses in descending order.

Consequently:

- With a count of eight, ascending destination addresses contain the full payload in most-significant-byte-first order.
- With a count below eight, the function writes the corresponding low-order payload bytes in most-significant-byte-first order.
- With a count above eight, bytes extracted after the first eight are zero. Those zero bytes occupy the lower-addressed portion of the destination range.

The extraction uses unsigned shifts of 32-bit words. It does not sign-extend the payload.

The descending store order is observable where memory access order matters. It must not be replaced in the behavioral contract by merely stating the final byte sequence.

The originally captured payload words remain the source of the bytes even if F-445198130f42 changes the descriptor. Likewise, if destination writes overlap the descriptor, this branch does not reload the payload between stores.

### 3. External-operation branch

For a classification greater than 11, the function first reads the 32-bit word at descriptor offset 24. This saved value is the initial length.

It then invokes F-EXT-A with:

1. The original destination.
2. The current word at descriptor offset 20.
3. The saved initial length.

The word at offset 20 is obtained after the initial-length read. The supplied representation does not establish an external data type for that argument beyond its 32-bit value.

F-EXT-A’s return value is not used.

After F-EXT-A returns, the function reads the flags word at descriptor offset 28 and tests mask `0x00000800`.

If the flag is clear, the function returns the saved initial length. It does not substitute a possibly changed descriptor length.

If the flag is set, the function:

- Reads the current word at descriptor offset 0.
- Adds it to the saved initial length using unsigned 32-bit arithmetic.
- Compares the resulting 32-bit sum with the limit, interpreting both bit patterns as signed 32-bit integers.
- Selects the limit only when the signed limit is strictly less than the signed sum. Otherwise, it selects the sum.

Call the selected value the endpoint.

The function then invokes F-EXT-B with:

1. An address formed from the original destination plus the current word at descriptor offset 24.
2. An extent formed by subtracting a current word at descriptor offset 24 from the endpoint.

The subtraction is unsigned 32-bit arithmetic. An endpoint below the current descriptor length therefore produces a wrapped extent, not an automatically empty operation.

The two uses of descriptor offset 24 belong to the second call’s argument expressions. The supplied representation does not establish their relative evaluation order or a single shared snapshot. For ordinary stable memory, both reads yield the same value. That equality is not established for asynchronously changing or side-effecting memory.

F-EXT-B’s return value is not used. After it returns, F-9b51e1c27d0b returns the endpoint.

### 4. Zero-result branch

For classification zero or 8 through 11, the function returns zero after the classification call.

On this path, the function performs no subsequent direct descriptor reads, direct destination writes, or calls to the other listed dependencies. This does not imply that F-3b33b57eae0c was side-effect-free.

### Arithmetic boundaries

The following distinctions are material:

- Payload shifts operate on unsigned 32-bit words.
- The optional endpoint sum wraps modulo \(2^{32}\).
- Endpoint selection uses signed 32-bit ordering, not unsigned ordering.
- The optional-operation extent wraps modulo \(2^{32}\).
- Address formation is represented through 32-bit quantities. No wider-address or overflow protection is shown.

The signed comparison can select a numerically large unsigned limit because its sign bit is set. It can also retain a sum with its sign bit set even when that sum is larger than the limit under unsigned ordering.

## Side effects

### Direct effects

The direct byte-generation branch writes exactly the count returned by F-445198130f42, assuming execution completes and all addressed stores are valid.

The function contains no direct descriptor stores and no explicit allocation or deallocation.

### Dependency-mediated effects

Every path calls F-3b33b57eae0c. Other calls depend on classification and flags.

No supplied dependency contract establishes that these calls preserve:

- Descriptor contents.
- Destination contents.
- Global state.
- Allocated objects or their lifetimes.
- Error indicators or other process-visible state.

The optional branch deliberately reads descriptor fields after F-EXT-A. A description that snapshots the entire descriptor before that call would therefore be incorrect.

### Ownership and errors

Passing the descriptor to F-3b33b57eae0c does not establish an ownership transfer. Similarly, passing the descriptor-supplied argument to F-EXT-A does not establish whether that dependency borrows, consumes, retains, or releases an object.

There is no explicit error return or recovery path around dependency calls or memory accesses. An invalid destination, an excessive generated count, a wrapped extent, or invalid dependency arguments are not locally rejected.

Whether such conditions cause a fault, an external error, or another effect is documented_only.

## Acceptance examples

These are conditional static expectations, not results of runtime testing. Unless stated otherwise, memory is valid and stable, dependencies return normally, and dependencies make no changes beyond those explicitly described.

### Eight generated bytes

If classification is 1, the first payload word is `0x11223344`, the second is `0x55667788`, and F-445198130f42 returns 8:

- Ascending destination bytes are `55 66 77 88 11 22 33 44`.
- The actual stores occur from the last byte toward the first.
- The return value is 8.

### Short generated output

With the same payload and a generated count of 3:

- Ascending destination bytes are `22 33 44`.
- The store sequence is offset 2 receiving `44`, offset 1 receiving `33`, then offset 0 receiving `22`.
- The return value is 3.

### Generated output wider than the payload

With the same payload and a count of 10:

- Ascending destination bytes are `00 00 55 66 77 88 11 22 33 44`.
- Exactly ten direct byte stores occur.
- The return value is 10.

### Zero generated count

If classification is 7 and F-445198130f42 returns zero:

- The payload words at offsets 8 and 12 have already been read.
- No direct destination store occurs.
- The return value is zero.

### Classification with no subsequent operation

If F-3b33b57eae0c returns 8:

- Neither byte generation nor either external operation occurs.
- The return value is zero.
- Side effects of the classification dependency remain possible.

### Optional operation with an ordinary positive limit

Suppose classification is 12, the initial length is 6, descriptor offset 0 contains 4, and the post-F-EXT-A flag is set. If the limit is 8 and the current length remains 6:

- F-EXT-A receives length 6.
- The endpoint sum is 10.
- Signed comparison selects endpoint 8.
- F-EXT-B receives destination plus 6 and extent 2.
- The return value is 8.

### Descriptor mutation by the first external operation

Suppose the saved initial length is 6. F-EXT-A changes the current length to 9, changes descriptor offset 0 to 7, and sets the flag. With limit 20:

- The endpoint sum uses saved length 6 and current additive value 7, yielding 13.
- F-EXT-B receives destination plus 9 and extent 4.
- The return value is 13.

### Signed comparison and wrapped extent

Suppose the initial and current lengths are 4, the additive value is 4, the flag is set, and the limit is `0xFFFFFFFF`:

- The sum is 8.
- The signed limit is −1, so it is selected.
- F-EXT-B receives extent `0xFFFFFFFB`.
- The return value is `0xFFFFFFFF`.

This is not clamped to zero.
