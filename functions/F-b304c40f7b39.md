- If destination and source compare equal, the function performs no dependency calls and no explicit memory access through either pointer.
- If they compare unequal, the function first invokes F-3cdbb43c2646 on the destination. After that dependency returns normally, it reads one 32-bit value from the source and invokes F-4113700b9ff3 with the destination and that value.

## Behavior

### Equal-pointer path

Pointer equality is evaluated before either dependency is called.

When destination and source compare equal:

1. Neither dependency is invoked.
2. No source value is fetched.
3. No destination storage is explicitly written.
4. The destination pointer is returned.

This branch is based on pointer identity, not equality of stored contents. Two distinct addresses containing identical 32-bit values still take the unequal-pointer path.

The equal-pointer bypass also means that the function does not validate the referenced storage on this path. In particular, the static body contains no dereference when both inputs are null and compare equal. This is a statement about the supplied body, not a general guarantee about external instrumentation or the surrounding execution environment.

### Unequal-pointer path

When destination and source compare unequal, the required sequence is:

1. Invoke F-3cdbb43c2646 with the destination pointer.
2. If that invocation returns normally, obtain the 32-bit value stored at the source pointer.
3. Invoke F-4113700b9ff3 with the destination pointer and the value just obtained.
4. If that invocation returns normally, return the original destination pointer.

The ordering between the first dependency and the source read is material. The source value is not captured before the first dependency runs.

Consequently, the second dependency receives the source value present after the first dependency returns, not necessarily the value present at function entry. If the first dependency changes source storage through aliases or shared state, that change can affect the value subsequently passed to the second dependency.

The source read supplies a value, rather than forwarding the source pointer as an argument. Once that value has been obtained, this body does not explicitly reread the source before the second call.
