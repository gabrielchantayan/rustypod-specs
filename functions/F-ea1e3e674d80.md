# F-ea1e3e674d80

## Purpose

Otherwise, it supplies temporary writable storage and its input argument to a second dependency, then supplies the first and second dependencies’ returned values to a third dependency.

This is an established control-flow and dataflow contract. The meanings of the input, the returned values, and the temporary storage’s contents are not established. In particular, the evidence does not establish that any value represents an object, handle, identifier, status, or owned resource.
