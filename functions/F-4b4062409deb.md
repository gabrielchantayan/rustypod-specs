# F-4b4062409deb

## Purpose

The established behavior has two paths:

- If the reference stored at input-relative byte offset `0x98` is null, the function returns without dispatching.
- Otherwise, the function obtains a dispatch-table address from the referenced object, obtains a function address from table-relative byte offset `0x30`, and transfers control to that address.
