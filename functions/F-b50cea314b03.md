# F-b50cea314b03

Two paths are established by the supplied static evidence:

- If an object flag is nonzero, the function only writes the supplied value to the object and returns.
- Otherwise, it records a byte-sized input, resolves a lookup result, invokes several dependencies, optionally performs an operation using temporary state, records the supplied value, and invokes a final dependency on that temporary state.

No dependencies are called on this path. The byte input is not written, no temporary state is constructed, and the 16-bit object field is not read.
