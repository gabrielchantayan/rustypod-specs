## Behavior

### Ordered operations

The following order is established for the explicit operations in this function:

1. Read the 32-bit value held in the global source location.
2. Write that value to the four-byte destination beginning at the first input address.
3. Call F-b9acea4b06ad, passing only the address four bytes beyond the first input address.
4. If the dependency returns normally, use its result to derive an address eight bytes later.
5. Write the third input to the four-byte destination beginning at that derived address.
6. Return without an explicit result.

The initial write precedes the dependency call. The dependency therefore executes after that write has occurred; if it accesses the same storage, the write is already part of the execution history. This is not a guarantee that the dependency preserves that value.

The final write occurs only after a normal return from the dependency. It uses the dependency’s result, not the first input address, as its address base.

There are no explicit conditional branches, loops, retries, or alternate paths in the shown body.
