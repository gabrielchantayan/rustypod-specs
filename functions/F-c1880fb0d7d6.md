## Acceptance examples

These are conditional static criteria, not executed tests. Each requires execution to reach the relevant operation and the environment to permit its accesses and transfers.

1. **Initial ordering.** With first argument 3, the initial word store writes 3 at address \(0x20\) before F-d001 is invoked with 3.

2. **Fourth-argument boundaries.** With fourth argument \(0xFFFFFFFF\), the store at \(W(A)\) contains \(0x000FFFFF\), and F-d021’s third argument is \(0xFC000000\).

3. **Discarded input bits.** Changing only bits 29 through 31 of the fourth argument leaves both explicit transformations of that argument unchanged. This does not guarantee identical dependency behavior if dependencies inspect ambient incoming state.

4. **Slot aliasing.** If B is zero, both \(V(B)\) and \(W(B)\) are \(0x14\). In ordinary stable memory, with no intervening mutation or read side effects, the preceding zero store causes both F-d011 word reads to return zero.

5. **Separate word observations.** If F-d011’s two reads observe different words, its first and third arguments must reflect their respective observations. Which read occurs first is not established.

6. **Captured-word lifetime.** If the captured word is \(0xABCDEF01\), the later store at \(W(K)\) contains \(0x000ABCDE\), even if a subsequent dependency changes the original source word.

7. **Scaled-value field.** If K is 3, F-d051’s first argument is \(0x00030000\). Its third argument is \(0xC0000000\) only under the conditional 32-bit machine-shift interpretation.

8. **Different byte destinations.** If N is \(0x12345678\), the first byte read returns \(0x20\), and the second returns \(0x40\), the byte stores write \(0xE0\) at \(0x31\) and \(0x23\) at \(0x51\). F-d073’s second argument remains \(0x40\) despite subsequent changes to the byte source.

9. **Store accounting.** A traversal reaching the endpoint passes twelve explicit word-store occurrences: one initial store, six subsequent word-slot stores, and five wide-slot stores. Aliasing does not reduce this occurrence count.

10. **Interrupted execution.** If a dependency does not return, only the established prefix before that call is required. Later accesses, calls, and the endpoint are not required to occur.
