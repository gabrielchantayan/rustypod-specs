# F-4cf39d57f61f

## Purpose

- Zero selects a short sequence ending in a receiver operation with the value 16 and a normal return value of 1.
- Nonzero selects a receiver operation followed by an external-object query. A zero query result leads to preparation and a final delegated return. A nonzero query result leads to another object operation and a dependency marked nonreturning.

These are control-flow descriptions, not semantic claims about starting, stopping, success, or failure. An embedded label suggests a playback-related purpose, but that interpretation does not establish the meanings of the operations.

This contract describes the supplied static representation. It does not establish dependency internals or behavior in omitted regions.

## Acceptance examples

These examples are conditional static specifications, not executed tests. Each assumes valid accesses and normal continuation through earlier calls unless stated otherwise.

1. **Zero second input.**  
   The observable call order is F-ac356e5603c7, F-7d3c7677323d with zero, then the receiver’s offset-184 operation with 16. Normal completion returns 1. No external-object acquisition occurs.

2. **Nonzero input preserved.**  
   With second input 7 and a zero offset-236 query result, the final F-c452dd64d509 call receives 7. If it returns the 32-bit value 42, this function returns 42.

3. **Negative input is not normalized.**  
   With second input −1 under the recovered signed interpretation and a zero query result, the final dependency receives the same 32-bit representation. The zero-second-input path is not selected.

4. **Pointer equality without a content-read claim.**  
   On the zero-query branch, the second and third arguments to F-a3642b19087c must be equal pointers to the same one-byte-displaced location. This requirement does not establish that this function reads that location, nor that its contents are a string.

5. **Fixed-location read occurs after preparation.**  
   If F-9b9c1c7483f4 changes the fixed location later read for F-17d67fcf9aa1, and nothing changes it again before the read, F-17d67fcf9aa1 receives the resulting value. It does not receive an earlier cached value or the location’s address.

7. **Acquisitions may differ.**

8. **Either later query result reaches the nonreturning dependency.**  
   With a nonzero initial query result, both zero and nonzero results from the later offset-280 operation lead to F-feee9156a257 with the offset-244 result object. The offset-280 operation still occurs first.

9. **Invalid receiver has no defined rejection result.**
