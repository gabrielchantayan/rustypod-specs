# F-0384df335e44

## Purpose

The established behavior is the call sequence, the forwarding of returned values, the use of a temporary two-word area, and the final pair of writes. The first write uses a value read from a shared global location. The second uses an earlier read from that same global location, increased by 356.

An inferred purpose is to construct or initialize an object and install a base-related value together with an offset-derived value. That interpretation is not required by this contract: the supplied evidence does not establish object types, allocator semantics, dispatch-table semantics, or ownership.
