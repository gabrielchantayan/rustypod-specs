# F-1ec64f090579

## Purpose

F-1ec64f090579 places two supplied values into a caller-designated memory region: a 32-bit value at the beginning of the region and an 8-bit value immediately after it.

The established behavior is a pair of stores, not a complete object-construction or serialization protocol. The source does not establish a meaning for either field, a larger record size, an allocation policy, or a particular byte order.

| Destination | Address of writable storage | Pointer width is not established |
| First value | Value stored at the destination | 32 bits |
| Second value | Value stored four bytes after the destination | 8 bits |

### Byte-order-dependent observation
