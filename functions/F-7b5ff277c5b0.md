# F-7b5ff277c5b0

## Purpose

F-7b5ff277c5b0 recognizes an ordered set of action identifiers and, unless a suppression condition holds, dispatches one action against a receiver.

The 32-bit result reports **recognition**, not successful execution:

- **1:** an action comparison matched. This includes recognized actions whose execution was suppressed.
- **0:** all comparisons reported nonmatches.

Two distinct global value sources control suppression for two successive search groups. Their numeric values and application meanings are not established. Neither is assumed to represent null, an invalid item, cancellation, or a probe request.

The action labels suggest media and playlist operations. That is inferred intent; the established contract covers comparison order, suppression, target selection, argument forwarding, and recognition results, not downstream media behavior.

Each executed action receives the original receiver followed by the original 32-bit action argument. The identifier is not forwarded to the action.

### Recognized actions

For a matched action, the function compares the original action argument with the applicable suppression value:

- **Equal:** invoke no action and return 1.
- **Unequal:** invoke the selected action once and, if it returns normally, return 1.

For virtual actions, the receiver’s first-field read and selected table-entry read occur only after recognition and the nonsuppression decision. The function does not visibly cache a virtual target before making comparisons.

Direct action dependencies receive the same receiver and action argument as virtual actions. Their own results, if any, do not affect recognition. A failure-like return from an action does not trigger another comparison, another dispatch, or a different local return value.
