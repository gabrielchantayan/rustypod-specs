# F-4b541569265b

## Purpose

F-4b541569265b conditionally returns an unsigned reference value, otherwise returning zero. It compares an unsigned candidate against the reference, conditionally adds a signed adjustment to the candidate, and determines whether the adjusted candidate is strictly above the reference.

The observable selection rule is:

- An original candidate greater than the reference always produces zero.
- An original candidate at or below the reference permits adjustment.
- On that permitted path, an adjusted candidate strictly greater than the reference produces the original reference.
- All other cases produce zero.

The addition must be interpreted using the applicable integer conversion and overflow rules. In particular, this is not necessarily a mathematical interval-crossing check: unsigned wraparound can change the result, including allowing a negative adjustment to produce a large unsigned candidate.

The apparent intent is to detect a transition from at-or-below a reference to strictly above it. That intent is inferred; the comparisons and return selection are established by the supplied static representation.

## Behavior

### Initial comparison

The first decision compares the original candidate with the reference using an unsigned, inclusive comparison.

This decision is retained for the subsequent result selection. It concerns the original candidate, not the adjusted value.

If the original candidate is greater than the reference:

- The adjustment is not added.
- The function returns zero.
- The magnitude and sign of the adjustment cannot change the result.

If the original candidate is less than or equal to the reference, the function proceeds with the addition.

### Conditional addition

On the permitted path, the candidate is replaced locally by the result of adding the adjustment.

Under the integer interpretation described in the interface, this is unsigned modular addition. A negative adjustment is not rejected, clamped to zero, or treated as an error. Its converted unsigned value participates in the addition.

Consequences include:

- A positive adjustment can produce a value smaller than the original candidate through wraparound.
- A negative adjustment can produce a very large unsigned value when subtraction would fall below zero.
- An adjustment of zero leaves the candidate unchanged.
- There is no separate indication that wraparound occurred.

The reference is not changed by this arithmetic.

### Final selection

After an eligible addition, the adjusted candidate is compared with the reference.

The original reference is returned only when the adjusted candidate is **strictly greater** than the reference. An adjusted candidate equal to the reference produces zero. An adjusted candidate below the reference also produces zero.

Thus, under the stated arithmetic interpretation, a nonzero reference is preserved exactly when both conditions hold:

1. The original candidate is at or below the reference.
2. The modularly adjusted candidate is above the reference.

The function never returns the candidate or the adjustment. Its return value is always either zero or the original reference.

### Boundary behavior

**Zero reference.** The returned numeric value is always zero. Even if the comparisons select preservation of the original reference, that preserved value is itself zero. The return value therefore cannot distinguish a successful selection from a rejected selection in this case.

**Maximum unsigned reference.** The function always returns zero. Every possible unsigned candidate is initially eligible, but no adjusted unsigned candidate can be strictly greater than the maximum unsigned value.

**Candidate equal to the reference.** Equality permits the addition. The final result depends on whether the modular result is strictly greater than the reference; equality after adjustment does not qualify.

**Zero adjustment.** The function always returns zero. An initially excessive candidate is rejected without addition. An eligible candidate remains at or below the reference.

**Negative adjustment.** A negative adjustment does not universally imply a zero result. If it wraps a sufficiently small candidate into the high unsigned range, the adjusted value can exceed the reference.
