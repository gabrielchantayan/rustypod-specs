### Initial context mutations

The first read captures Context B’s word at `0x14`; call this address **Initial link**.

The initial write order is:

2. Primary address at `0x64` receives the payload word.

4. Context C at `0x44` receives the payload word.

Context A then receives its own address at `0x54` and the primary address again at `0x60`. Initial companion at `0x09` receives Context C’s low address byte. Context A at `0x15` receives Initial saved word’s low byte; Initial companion at `0x44` receives Initial link; Context A at `0x11` receives Initial companion’s low byte.

### First linked traversal and Publication 1

- First branch at `0x09` receives First record’s low address byte.

First record’s `0x64` link is read. Its referent receives First context capture at `0x44`; Initial link at `0x54` receives First record. First record’s `0x74` word is captured, followed by these mutations: its `0x11` byte receives First context capture’s low byte, its `0x60` word receives `0x72`, and the current linked object’s `0x09` receives Context C’s low address byte.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Initial alias-sensitive reads.** If Context B’s `0x09` byte aliases Context A’s `0x14` word, the Initial saved word capture observes memory after the Context C address-byte write. If Context B’s `0x44` aliases Context A’s `0x44`, Initial companion is read after the Initial link store.

2. **Context capture ordering.** First context capture is obtained after First branch’s `0x09` write but before First record’s first-byte write, Publication 1, and the `0x30` read. Aliasing must be evaluated at those separate checkpoints.

3. **Repeated low-global read.** If the two reads at `0xED` yield distinct accessible addresses, the `0x24` store uses the second, while the subsequent `0x64` read uses the first.

4. **Publication readback.** If Output record’s `0x54` store aliases Publication 2, the later byte-write base comes from the global after that store. Second record still comes from Output reload’s `0x24`, not the published object.

5. **Destination timing.** An alias from Second record’s `0x50` word write can change Nine-word destination before capture. A later alias from its `0x01` byte write cannot change the already captured destination.

6. **Unsigned addressing.** A First byte address of `0xFF` selects word-read addresses `0x163` and `0x123`. A Final byte address of `0xFF` selects byte-write address `0x108`.

7. **Output checkpoints.** Without interfering aliases, the four-word output contains the stated tuple immediately after its stores. The nine-word writes repeat identical captured values at indices 1/4, 2/5, and 3/7/8. Neither checkpoint establishes final persistence.

8. **Failure and overlap.** A null output has no demonstrated clean rejection. An inaccessible late address may fail after earlier mutations. A word write at `0x10` covers `0x11`; the final byte write at `0x14` replaces only part of the preceding word.
