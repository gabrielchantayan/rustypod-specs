## Behavior

### Write forms

Two result-derived write forms recur. Each form consists of **two consecutive 16-bit writes to the same address with the same value**.

**Form A**

For low result half \(L\):

- Destination: \(L \mathbin{\mathrm{>>}} 8\).
- Value: the low 16 bits of \(L \mathbin{\mathrm{>>}} 8\).

Thus the destination ranges from zero through `0x00ffffff`. The written value is also the destination’s low 16 bits.

**Form B**

For low result half \(L\):

- Destination: \((L \mathbin{\&} \texttt{0x07ffffff}) \mathbin{\mathrm{>>}} 3\).
- Value: the low 16 bits of the 32-bit expression \((L \mathbin{\mathrm{<<}} 5) \mathbin{\mathrm{>>}} 8\).

The value simplifies to \((L \mathbin{\mathrm{>>}} 3) \mathbin{\&} \texttt{0xffff}\). This simplification preserves the represented 32-bit shift and truncation behavior. The destination again ranges from zero through `0x00ffffff`.

These are separate accesses, not a single idempotent assignment. A faithful observable trace retains both writes.

1. Write the entry address’s low 16 bits to the entry address.
2. Repeat that same halfword write.
3. Write the same halfword value to the address obtained by doubling the entry address.

Doubling is numeric address arithmetic, not displacement by one halfword.
