# F-d53862ada031

## Purpose

F-d53862ada031 conditionally computes an integer total from up to three contributions associated with a caller-supplied object.

A byte at object offset `0x19` gates all further work. When that byte is zero, the function returns zero without calling any dependency. When it is nonzero, three selection stages execute in a fixed order:

1. A base contribution is selected if either of two predicates succeeds.
2. A second contribution is added if another predicate succeeds.
3. A third contribution is added if a final predicate succeeds.

The base stage uses short-circuit evaluation: its second predicate is called only when its first predicate returns zero. The later stages are independent of whether the base stage selected a contribution.

The selected integers come from indirect records reached through F-702f08e79f1a. Each successful stage calls that dependency separately. Consequently, different stages may observe different records or values.

## Behavior

### Base selection

The function first calls F-672ac96234f4 with the original object address.

- A nonzero result selects the base contribution immediately.
- A zero result causes F-3f720a0cf0e3 to be called with the same object address.
- A nonzero result from that second predicate selects the base contribution.
- If both results are zero, the total remains zero at this stage.

Predicate results are tested only for equality with zero. Their magnitudes are not added to the total. Negative results count as true.

When the base contribution is selected, the function:

1. Calls F-702f08e79f1a with the address at object offset `0x2c`.
2. Reads the address-bearing field at offset `0x04` from that call’s result.
3. Reads the integer at offset `0x04` from the referenced record.
4. Uses that integer as the running total.

### Second contribution

If its result is zero, this stage makes no resolver call and leaves the total unchanged.

If its result is nonzero, the function:

1. Calls F-702f08e79f1a again with the address at object offset `0x2c`.
2. Reads the address-bearing field at offset `0x08` from this call’s result.
3. Reads the integer at offset `0x04` from that referenced record.
4. Adds that integer to the running total.
