## Acceptance examples

The following are conditional acceptance criteria from static evidence, not executed tests.

1. **Configuration truncation.** For configuration `0x123456AB`, the temporary cell initially contains all 32 bits, while the direct byte write at fourth-stage offset `0x73` writes `0xAB`.

2. **Ordinary counter assignment.** If both global reads yield the same address, its counter contains `41`, and relevant storage does not overlap, the identifier write stores `41` at result offset `0x12C`. The subsequent counter write stores `42` at that address plus `0x04`.

3. **Identifier aliases the pointer-global slot.** Suppose both global reads yield the same valid counter-state address, the counter is `41`, result offset `0x12C` exactly overlaps the pointer-global slot, and counter storage is disjoint from that slot. The identifier write replaces the pointer-global contents with `41`. The increment still writes `42` through the previously retained counter-state address, not through address `41`.

4. **Different global observations.** If the first global read observes one address and the second observes another, the identifier comes from the second address’s counter. Its incremented value is written to the first address’s counter. This describes the access sequence, not a guarantee of concurrent-call safety.

5. **Comparison observes post-call storage.** If F-bb50a072e902 changes the stored comparison field, the Boolean must reflect equality with the field as read after that call, not necessarily with the original input.

6. **Processed context copy.** If F-c6d95d05936a changes the imported words, the later transfers to `0xB4` through `0xC0` use the post-call source words.

7. **Paired defaults.** A zero flag at the selection read produces `720` at `0xD0`, then `576` at `0xCC`. Any nonzero byte produces `320`, then `240`, using that same decision.

8. **Registration skipped.** A zero byte at `0xEF` skips both provider alternatives and F-627c5664a32c. Final setup still proceeds.

9. **Acquisition outcomes.** A zero enable word at `0x54` skips acquisition. With acquisition enabled, a zero dependency result is written to `0x48` before the non-returning call. A nonzero result is written first to `0x48`, then to `0x50`, before normal return.
