## Behavior

The function first reads the shared root reference and compares it with zero.

If that read yields zero, the function returns. On this path, it does not read the root-relative field, call F-9813035c7ce7, read the selected-object field, or invoke the indirect dependency.

The initial root test is the only explicit zero check.

### Selecting the object

The source-level access pattern therefore does not establish a single cached root snapshot. If shared state changes between the test and field access, the reference used for the field access need not equal the reference that passed the zero test. No second zero check is shown.

The function reads the 32-bit offset-20 field and retains that value as the selected object reference. This retained value is used for the direct dependency call and, if necessary, for the later offset-4 access.

There is no explicit check that this value is nonzero, aligned, within an allocation, or otherwise valid as an address.

### Calling the direct dependency

The function invokes F-9813035c7ce7 with two arguments, in this positional order:

1. The integer value 1.
2. The retained selected object reference.

After the call returns normally, the function compares its 32-bit result with exactly −1.

Every result other than −1 causes the function to return without invoking the indirect dependency. This includes zero, positive values, and negative values other than −1. The supplied behavior does not classify those other values as success or failure.

Only the exact −1 result enters the indirect-invocation path. Under the represented 32-bit integer interpretation, this is the all-ones 32-bit result pattern.

### Invoking the indirect dependency

On the −1 path, the function obtains a four-byte argument from byte offset 4 of the retained selected object reference. It invokes the indirectly referenced target with that value as its single supplied argument.

This field read occurs after F-9813035c7ce7 returns. Consequently, it observes the field as available after that call, not a value captured before it. If F-9813035c7ce7 changes that field, the subsequent read can observe the changed value.

The object reference itself is not refreshed from the root. Changing the root or its offset-20 field during F-9813035c7ce7 does not redirect the later field access to a newly selected object.
