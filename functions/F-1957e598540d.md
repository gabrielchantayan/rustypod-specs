The adjusted value is constrained, not an independent input. Because four times any 32-bit saved link value is divisible by four and `0x96` is congruent to two modulo four, the adjusted value is always congruent to two modulo four. Reduction modulo \(2^{32}\) preserves this constraint.

Consequently, the calculated base is congruent to eight modulo sixteen.
