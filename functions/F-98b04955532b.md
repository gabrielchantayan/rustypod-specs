That observation does not establish that the function never reads destination storage. The global read may read bytes that also belong to the destination. Consequently, prior destination contents can determine the value written at offset 0 when the global overlaps destination storage.

- If the global occupies destination bytes 0–3, the global read obtains that field’s current value before the first write replaces it with the same 32-bit value.

When the global read does not overlap the destination, the visible initialization does not derive its replacement values from the destination’s prior contents. This is a statement about the accesses after the dependency returns. It does not constrain whether the dependency itself reads destination contents or derives the global value from them.
