These are conditional static-review examples, not executed tests.

1. **Initial forwarding.** For second input 3, the initial invocation receives the unchanged first input, 3, and 192.

2. **Shift width.** Under low-32-bit shift semantics, second input 0x04000000 produces zero as the third initial argument, not a widened product.

3. **Reachable early ordering.** If the small component is zero, the doubled-small base is zero. Both duplicate offset-0x15 byte writes therefore target fixed address 0x15. They precede the fixed-0x05 read, which precedes the fixed-0x01 write. The duplicate destinations do not numerically overlap 0x05; asserting shared underlying storage would require an additional mapping assumption.

4. **Fixed publication boundaries.** Fixed word 0x54 is written before fixed byte 0x15. The publication-base read precedes the fixed-0x60 word store and repetition.

5. **Unsigned widening.** An observed offset-5 byte of 0xFE is published as word 254, not −2.

6. **Reachable transition values.** Under the low-32-bit model, anchor 38 produces adjusted value 2 and fixed-0x3A byte 0x40. Anchor 101 produces adjusted value 254 and byte 0x20. Both adjusted values satisfy the required congruence. Adjusted low bytes 0x03 and 0xFF are unreachable under this model.

7. **Transition overlap.** If the common payload value is 19, tail offset 0x14 numerically equals 0x3A. In an environment supporting that word access, the retained tail word is read after the fixed-0x3A byte write. The payload-offset-0x74 read occurs before it.

8. **Fresh fixed-byte reads.** If a permitted intervening computed store changes fixed byte 0x67 from 0xAA to 0xBB, a later publication supplied by a fresh read uses the newly observed value. Cached 0xAA is not justified.

9. **Store width.** Halfword 0x65 writes 16 bits. A byte store is not equivalent; individual byte placement depends on endianness.

10. **Partial failure and final transfer.** An inaccessible computed address has no represented status-return or rollback path. If execution reaches the final target, its first argument is 0x72 and the final doubled-address word store has already occurred.
