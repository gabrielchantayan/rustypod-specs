# F-a547c43a8237

## Purpose

F-a547c43a8237 conditionally retrieves a 16-bit value from storage reached through its input object. Before deciding whether to retrieve that value, it invokes an indirectly selected function with the same object address.

The indirect call’s result controls the two normal-return outcomes:

- A zero result causes F-a547c43a8237 to return the 16-bit value zero without performing the subsequent payload-address or payload-value reads.
- Any nonzero result causes it to obtain a payload address from the object and return the 16-bit value stored at byte offset 136 from that address.

The supplied static representation establishes this control flow. It does not establish what the object represents, what the returned value means, or whether the indirect call is a readiness check, an update operation, or something else. In particular, a zero return from F-a547c43a8237 is not an unambiguous failure indication: the retrieved value can itself be zero.

**Output.** A 16-bit result. On the zero-result branch, all 16 result bits are zero. On the nonzero-result branch, the result consists of the 16 bits read from the selected payload location.

## Behavior

### Indirect call selection

F-a547c43a8237 first reads an address-bearing value from the beginning of the input object. It then obtains the callable target from byte offset 8 relative to that value.

It invokes that target with the original input object address as its sole shown argument. No other arguments are established by the supplied representation.

The call happens before either the payload-address read or the 16-bit payload read. Consequently, the function does not merely test preexisting payload state and then call a helper. The helper runs first and can affect the state later used for retrieval.

### Zero-result branch

The indirect result is tested for equality with zero.

If it equals zero, F-a547c43a8237 returns the 16-bit value zero. On this branch, the supplied body performs neither:

- The read of the object’s payload-address element.
- The read at byte offset 136 from a payload address.

This omission is branch-specific. It does not imply that the indirect target avoids those locations, or that the entire operation is free of side effects.

The result test is not a positivity test. Under the represented integer result, every nonzero bit pattern selects the other branch, including values interpreted as negative.

### Nonzero-result branch

If the indirect result is nonzero, F-a547c43a8237 reads the payload address from the object after the call has returned.

It then reads a 16-bit value at byte offset 136 from that payload address and returns that value. The retrieved bits are not compared, masked, normalized, or replaced with a status code in the supplied representation.

This sequencing matters if the indirect call changes the object. For example, if it replaces the payload address and returns nonzero, retrieval uses the replacement address. There is no established pre-call snapshot of the payload address.

The input address passed to the indirect target is also the address used for the subsequent object access. A target that invalidates that object and nevertheless returns nonzero would leave the subsequent retrieval without the required readable storage.
