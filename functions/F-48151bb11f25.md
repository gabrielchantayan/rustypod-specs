# F-48151bb11f25

## Purpose

F-48151bb11f25 selects a numeric-processing path from a source object’s one-byte discriminator and updates a destination object. Its directly established outcomes are:

- Store a nonnegative signed-64-bit integer magnitude.
- Store a two-word, 64-bit payload after an optional high-bit toggle and a predicate check.
- Assign a fallback classification while preserving selected classification bits.
- Report the minimum signed-64-bit integer as an overflow case.

The integer behavior supports an absolute-value interpretation: negative values are converted to positive magnitudes, except for the minimum signed-64-bit value, which takes a reporting path.

The two-word behavior establishes bit manipulation, not a numerical format. A floating-point sign interpretation is plausible but unproved. The predicate’s numerical meaning is unavailable.

No explicit return value is provided. Observable behavior consists of reads, writes, and dependency calls. Unknown dependency effects remain outside the direct guarantees of this contract.

## Behavior

| Discriminator | Selected behavior |
|---|---|
| `1` | Integer acquisition and magnitude processing |
| `5` | Immediate fallback |

The comparison with `4` uses the unsigned byte value. Discriminators `128`–`255` are therefore in the unchanged-word category, not a negative-value category.

### Integer acquisition and magnitude

For discriminator `1`, an acquisition dependency returns a 64-bit quantity. Its opaque function ID is unavailable.

The acquired bits are interpreted as a signed, two’s-complement 64-bit value for the negative-value decision:

- Zero remains zero.
- Positive values remain unchanged.
- Negative values other than the signed minimum become their positive magnitudes.
- The signed minimum takes the overflow path.

Negation propagates the required carry between the 32-bit halves. It is full-width negation, not independent negation of each half. Every successful integer result lies in the inclusive range `0` through `9,223,372,036,854,775,807`.

The acquired value, after any required negation, supplies the later payload store. The preparation dependency is not shown providing a replacement payload.

### Fallback

Fallback is reached either directly for discriminator `5` or after a nonzero predicate result.

The function:

1. Reads the current 16-bit classification at destination offset `0x24`.
2. Preserves bits 5–15, clears bits 0–4, and sets bit 0.
3. Writes the resulting 16-bit classification at `0x24`.
4. Writes the 8-bit value `5` at `0x26`.
5. Returns.

For the classification value \(T\) read at fallback time, the replacement is:

\[
(T \mathbin{\&} \texttt{0xFFE0}) \mathbin{|} \texttt{0x0001}.
\]

On predicate-selected fallback, preservation applies to the classification present after the preceding dependencies return, not necessarily its value at function entry.

Discriminator `5` bypasses both acquisition dependencies, evaluation of the external helper inputs, and all four mapped dependencies.

7. **Toggle clears the high bit.** With discriminator `2`, acquired high word `0x80000000`, and a zero predicate result, F-11ed8242c40c receives high word `0x80000000`; the predicate and successful store receive high word `0x00000000`. The low word is unchanged.

10. **External-input timing.** On a two-word path, both external helper arguments are evaluated after acquisition returns and before F-11ed8242c40c executes. 12. **Success replaces classification flags.** If F-74b5a05d0094 leaves classification `0xFFE0`, integer success subsequently replaces it with exactly `4`; two-word success replaces it with exactly `8`.
