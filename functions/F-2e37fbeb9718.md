# F-2e37fbeb9718

## Purpose

F-2e37fbeb9718 conditionally obtains a 32-bit value, passes that value to a second dependency with two zero arguments, and stores the second dependency’s 32-bit result into a caller-supplied memory location. It returns a 32-bit status indicating whether that stored result is nonzero.

A separate dependency gates the entire obtain-and-store sequence. A zero gate result causes an immediate normal return of zero, without a direct write to the caller’s memory.

This is an operational contract, not a semantic identification of the values involved. The supplied static evidence does not establish that any returned value is an allocation, object, handle, or pointer. Those interpretations remain unknown.

### Output

Every established normal return is a 32-bit value with one of two exact values:
