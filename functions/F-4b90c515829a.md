# F-4b90c515829a

## Purpose

F-4b90c515829a performs two ordered dependency calls, then conditionally transfers control to an indirect target according to a pointer-backed state value.

The established behavior is:

1. Call F-338d16f9ce72 with a value obtained from a global reference.
2. Call F-37efbe955e3e with a separate global value and the function’s incoming 32-bit argument.
3. Obtain a state pointer through the first global reference.
4. If that pointer is non-null, read its 32-bit state value.
5. Invoke an indirect target only when both the pointer and the state value are nonzero.

This describes the visible sequencing, not the purpose of either dependency. Interpreting the dependencies as initialization, synchronization, registration, cleanup, or notification would require evidence not supplied here.
