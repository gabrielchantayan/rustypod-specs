This contract separates behavior established by static evidence from inferred intent and unresolved properties. No runtime tests have been performed.

This boundary is a copy boundary, not a synchronization guarantee. The evidence establishes neither atomicity of the four-byte read nor synchronization with concurrent writers. It also establishes no volatile-access requirement or memory barrier.

The ordering above describes the represented operations. It does not independently require an otherwise unobservable temporary assignment to remain a distinct physical memory transaction.
