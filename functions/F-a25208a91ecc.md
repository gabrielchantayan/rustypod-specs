# F-a25208a91ecc

The first dependency receives an address-like value derived from the initial contents of the caller-supplied object, an opaque four-byte argument, and a pointer displaced into or relative to that object. After the first dependency returns normally, the second dependency receives the original object pointer. If the second dependency also returns normally, F-a25208a91ecc returns the result already obtained from the first dependency.

This ordering is established by the supplied static evidence. An interpretation such as “perform an operation, then release the object” is not established: neither dependency’s ownership or cleanup behavior is available.

## Behavior

1. The integer read from the object, increased by hexadecimal 118, equivalent to decimal 280.
2. The opaque four-byte input argument, unchanged.

The first derived argument is computed from the stored integer value. It is not the original object pointer increased by 280.

The third derived argument is computed from the original pointer. It is not obtained by dereferencing the stored integer as an address.
