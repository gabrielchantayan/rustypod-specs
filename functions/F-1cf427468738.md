# F-1cf427468738

## Behavior

### Initial linking

**If the incoming condition is set**, read the incoming link slot as a 32-bit value.

- If it equals the anchor address, write the replacement node’s address to that slot.
- Otherwise, leave that slot unchanged during this phase.

Both outcomes continue to parent assignment and repair. A mismatch does not produce a status or skip the remainder of the body.

**If the incoming condition is clear**, first write the replacement node’s address to the anchor’s first-child field at offset 8. Then read the header address from the container’s offset 16 and compare it with the anchor.

If the header differs from the anchor:

- Select that header’s offset-8 slot.
- Read it.
- Replace it with the replacement node’s address only if its value equals the anchor.

If the header equals the anchor:

- Write the replacement node’s address to that header’s root field at offset 4.
- Read the container’s header-address field again.
- Write the replacement node’s address unconditionally to the newly selected header’s offset-12 slot.

The second header read is significant. An earlier write can affect it through aliasing; the body does not use a single immutable header snapshot.

### Parent assignment and repair cursor

After initial linking, write the anchor address to the replacement node’s parent field at offset 4.

Initialize the repair cursor to the replacement node. The cursor can subsequently move, but the final publication still uses the original replacement node’s address.

These actions occur even if an initial conditional-link comparison failed.

### Repair-loop entry

At the start of each iteration:

1. Read the container’s current header address.
2. Read that header’s root address.
3. Compare the root address with the repair cursor.

If they are equal, leave the loop without reading the cursor’s parent for that iteration.

Otherwise, read the cursor’s parent address and then the parent’s mark byte. If that mark is nonzero, leave the loop. Every nonzero byte value stops repair at this check; the test is not restricted to value 1.

A zero parent mark selects the structural repair logic.
