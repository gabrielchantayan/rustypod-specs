# F-5cf175503def

## Purpose

- A first observation equal to 3 selects one global value and invokes the dependency.

## Behavior

### Selection sequence

The established source-level sequence is:

1. Read Selection-A.
2. Read one byte at the input address plus 0xEC.
3. If that first byte observation equals 3, select the already-read Selection-A value and dispatch.
4. Otherwise, read Selection-B, then read the selector byte again.
5. If that second observation equals 4, select the already-read Selection-B value and dispatch.
6. Otherwise, return without dispatch.

The second selector observation is conditional. A first observation of 3 bypasses both the Selection-B read and the second selector read.

The two selector observations must not be collapsed into one in this behavioral account. They access the same address, but the supplied logic contains two observations on the path where the first comparison fails. No snapshot, locking, or stability guarantee is shown.

Consequently:

- A first observation of 4 is not alone sufficient to dispatch. The second observation must equal 4.
- A first observation other than 3 can still lead to dispatch if the second observation is 4.
- A second observation of 3 does not select Selection-A. Only the first comparison recognizes 3.

These distinctions describe the shown access sequence. Whether changes between observations can occur meaningfully depends on concurrency, storage, and execution rules not established by the evidence.
