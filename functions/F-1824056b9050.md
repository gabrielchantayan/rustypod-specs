## Behavior

2. Store a four-byte zero at offsets 4–7.
3. Store a one-byte zero at offset 8.
4. Invoke F-8e156b91569c, supplying the address at destination offset 12.
5. If the invocation returns normally and execution continues normally, return the original destination address.

The global read supplies the first store. It is not deferred until after the zero writes or the dependency invocation. The function contains no explicit second read of that global and no explicit refresh of the first field after the dependency returns.

The two zero writes have different widths. Immediately before entering the dependency, the function’s own operations have set the four-byte region at offset 4 to zero and the byte at offset 8 to zero. They have not directly initialized the intervening bytes at offsets 9–11.
