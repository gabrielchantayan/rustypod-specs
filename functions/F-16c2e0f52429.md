# F-16c2e0f52429

## Purpose

F-16c2e0f52429 performs a long, state-mutating sequence of indirect calls, byte-selector reads, byte writes, and scaled-address 32-bit word accesses. One direct dependency is identified as F-674e75a953e8.

No application-level purpose is established. Repeated shifts, masks, and scaled publications suggest manipulation of encoded state, but do not identify a particular format, object model, protocol, or ownership scheme.

This contract describes the supplied static representation, not validated executable behavior. The representation reports invalid instruction data and overlapping global storage. Its visible endpoint is an invalid-instruction termination marker rather than an ordinary return.

### Widths and layouts

The representation contains unsigned 8-bit reads, 8-bit writes, 32-bit word accesses, and one represented 64-bit call result.

Arithmetic below uses a conditional 32-bit machine-word interpretation: addition, multiplication, and left shifts retain the low 32 bits; unsigned right shifts insert zeros; byte writes retain the low eight bits. This interpretation does not resolve signed-expression overflow, architecture, alignment, or byte order.

A **word slot selected by an index** is a 32-bit access at address \(20+4\times\text{index}\). Other scale factors are stated separately.

A **selector-directed byte write** first reads an unsigned byte at the stated selector address, then writes one byte at address \(17+\text{selector}\). Its destination is therefore between addresses 17 and 272 inclusive. It is not relative to the selector’s containing object.

Descriptive labels below identify retained values, not permission to reload their original sources.

These are conditional static examples, not executed tests.

1. **Byte truncation:** An initial quantity of 65 and selector of 9 cause the first selector-directed write to store 4 at address 26: 260 is truncated to eight bits.

2. **Selector range:** A selector of 255 selects address 272, not address 255 or an object-relative destination.

3. **Fourth-argument width:** A fourth-argument bit pattern of `0x00400001` becomes `0x00000400` after the represented 32-bit left shift by 10.

4. **Field extraction:** A field word of `0x3ab00000` yields `0x3ab` after masking and shifting right by 20; the byte write stores `0xab`.

5. **Distinct global captures:** If the first global read yields `0x400` and the second yields 3, the masked-and-shifted call argument is 1, while the global-derived selector address is 13. 6. **Stable global case:** If both global reads yield the same value, their derived calculations agree with that shared value. Later global mutation does not change either already captured value.

7. **Raw index versus offset:** If the retained raw index is 3, its fourfold offset is 12. The fifth-group call’s first argument is `0x00030000`, its third argument is `0xc0000000`, and the final selector address is `0x30000001`. Deriving these from the offset instead would be incorrect.

8. **Fresh selector reads:** If an intervening dependency changes a selector, the later write uses the newly read selector. Reusing the earlier selector is not equivalent.

9. **Partial completion:** If F-674e75a953e8 does not return, earlier writes may have occurred, but subsequent publications are not reached.
