# F-39c23d4da3e4

## Purpose

F-39c23d4da3e4 examines a bounded prefix of a zero-terminated character sequence and returns one more than the number of consecutive nonzero character units examined.

The bound limits the number of nonzero units counted. It does not limit the result to that same value: if the entire permitted prefix is nonzero, the mathematical result is the bound plus one.

A null input pointer produces the result one, without a memory read. A nonpositive bound also produces one, without reading character memory, even when the pointer is nonnull.

The additional one is unconditional. It may suggest a size including space for a terminator, but that interpretation is inferred intent, not an established allocation or termination guarantee. In particular, the function can return after exhausting the bound without having observed a terminator.

## Interface

The function accepts two inputs:

- **Sequence pointer:** A pointer to character-addressable memory, or a null pointer.
- **Scan bound:** A signed integer limiting the number of nonzero character units that may be counted.

It returns a signed integer using the same displayed integer type as the bound.

The supplied static representation identifies the integer type as `int`, but does not independently establish its bit width or the target’s signed-overflow behavior. Let **M** denote the greatest representable positive value of that signed integer type. If the type is 32 bits, M is 2,147,483,647. That numeric width is conditional, not verified target metadata.

Memory is traversed in consecutive character-sized units. The operation is a zero test, not character decoding. No encoding, locale, Unicode interpretation, or distinction between positive and negative nonzero character values affects the stopping condition. The number of bits in a character unit and the pointer width are not independently established by the supplied evidence.

## Behavior

### Null pointer

The function first distinguishes a null sequence pointer from a nonnull one.

For a null pointer, it returns one immediately. The scan bound does not change this result, including when the bound is positive, zero, negative, or the greatest representable signed integer. No character memory is accessed.

This is an established special case, not a claim that a null pointer denotes an ordinary empty string.

### Nonnull pointer with a nonpositive bound

For a nonnull pointer, scanning begins with a count of zero.

Before any character read, the function checks whether the remaining bound is positive. If the supplied bound is zero or negative, scanning stops at this check, and the function returns one.

Consequently, this path does not require the pointed-to character location to be readable. It does not validate, probe, or dereference that location.

### Nonnull pointer with a positive bound

For each prospective character examination, the remaining-bound check occurs before the character read. A nonpositive remaining bound ends the scan without another character read.

When the remaining bound is positive, the function reads the current character unit:

- A zero value ends the scan. That unit is not counted, and the pointer is not advanced past it.
- A nonzero value is counted. The local remaining bound decreases by one, and the local pointer advances by one character unit.

This repeats until either a zero unit is observed or the permitted number of nonzero units has been counted.

The source-level sequence after a successful nonzero test is count increment, bound decrement, then pointer advancement. These updates affect local state only. The externally relevant access order is that character locations are read in increasing address order, with each read gated by a positive remaining bound.

If the scan consumes the full bound, it does not read the character immediately following that prefix. It still advances its local pointer after counting the last permitted nonzero unit.

### Result

Let **k** be the number of nonzero character units counted before stopping. When the final addition is representable, the returned result is **k + 1**.

For a positive bound:

- If a zero occurs at zero-based position **j**, with j strictly less than the bound, the function reads that zero and returns **j + 1**.
- If all units within the bounded prefix are nonzero, the function returns the bound plus one without testing the next unit.

The return value does not independently report which stopping condition occurred. For example, a result equal to the bound plus one can describe a prefix that is followed by a terminator, a prefix followed by another nonzero unit, or a prefix with no readable following unit, provided the performed accesses and pointer advancement are valid.

### Arithmetic boundary

The count cannot exceed the initial positive bound. Its increments therefore remain representable through a count of M. The remaining bound is decremented only while positive and cannot underflow through this operation.

The final addition has a distinct boundary: if the initial bound is M and all M examined units are nonzero, the mathematical result is M + 1, which is not representable in the signed return type.

The evidence does not establish a portable numeric result for that case. Signed wraparound, saturation, an error return, or another particular outcome must not be promised. A contract requiring a defined representable result must exclude that case or require a zero to be encountered before M nonzero units have been counted.
