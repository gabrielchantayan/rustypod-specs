# F-be478d0e4014

The established behavior is a sequence of calls and memory writes. It does not establish that any dependency allocates memory, constructs an object, or transfers ownership. Object construction and recovery of a containing-object address are possible interpretations, but neither is required by the available evidence.

The function:

- Passes its incoming 32-bit value and two fixed numeric arguments to F-27a94bce95b7.
- Stores a global 32-bit value through the address returned by that dependency.
- Passes an address 728 bytes beyond that returned address to F-e194f3fbdfaa.
- Uses F-e194f3fbdfaa’s returned address as the base for five further writes.
- Calls F-2e1e5059bccf with an address 28 bytes beyond that second returned address and a zero argument.
- Returns the final dependency’s integer result reduced by 756, subject to the arithmetic qualification in this contract.

The two dependency-returned addresses need not be equal or have any particular relationship.
