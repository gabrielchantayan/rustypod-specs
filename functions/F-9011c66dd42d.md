# F-9011c66dd42d

## Purpose

F-9011c66dd42d specifies an ordered sequence of external calls, byte-selector accesses, explicitly typed 32-bit stores, and zero assignments to an absolute global whose access width is unspecified. The supplied representation ends at an invalid-instruction boundary; it does not establish an ordinary return.

**Established static evidence:** the sequence forwards input and dependency-result words, clears selected locations, stores scaled values, and uses unsigned bytes as absolute-address selectors. Its visible memory effects include eight byte writes, ten explicitly typed 32-bit writes, and four global zero assignments of unknown width.

**Inferred intent:** some operations resemble initialization or construction of linked state. That interpretation does not establish an object layout, device protocol, allocation policy, or successful initialization outcome.

The contract describes the supplied static representation, not verified executable behavior. Control-flow and overlapping-global warnings limit confidence in the reconstruction, especially its low-address accesses and terminal boundary.

### Widths and notation

The following mathematical notation describes the represented word operations:

- **W(x)** means reduction to the low 32 bits.
- **L(x)** means reduction to the low 8 bits.
- **byte[address]** means an unsigned 8-bit read.
- **M = P AND 0x003FFFFF**.
- **B = W(P × 0x400)**.
- **Q = W(P × 0x04000000)**.

Unless stated otherwise, scaled word arguments, word values, and computed addresses use W. This is a machine-word interpretation of the representation, not a claim that overflowing signed expressions have portable language semantics. The actual address width remains documented_only.

A selector byte is zero-extended before address formation. A selector-target byte address is therefore **selector + 0x11**, ranging from **0x11** through **0x110**. No object base is added. The selector-derived 32-bit destination at **selector + 0x44** ranges from **0x44** through **0x143**.

## Behavior

### Initial forwarding and selector write

F-A01 receives the second input. F-A02 produces a 32-bit token that is forwarded to F-A03. Calls F-A04, F-A05, and F-A06 follow, in that order.

F-A07 produces a word, called the **initial result** here. After that call, the sequence reads **byte[W(S + 1)]** and writes **L(R logically shifted right by 22)** to the selected address plus **0x11**. F-A08 then receives **W(initial result × 4)**. Calls F-A09 through F-A12 follow in increasing order.

The selector is read after F-A07, so preceding dependency effects can affect the destination. The byte is not read at entry.

### P-derived clears and ambient-word arguments

After F-A12, one byte at **W(P + 0x0F)** is cleared. The sequence then reads **byte[W(B + 1)]** and clears one byte at that selector plus **0x11**.

F-B01 receives four words: **W(T × 2¹⁹)** in each of its first three positions, followed by **W(T × 2²¹)**. F-B02 produces a token forwarded to F-B03. F-B04, F-B05, and F-B06 follow.

F-B07 produces the **B-phase result**. The sequence rereads **byte[W(B + 1)]**, retains this second selector, and clears one byte at its selected address plus **0x11**. F-B08 receives **W(B-phase result × 4)**; F-B09 through F-B12 follow.

After F-B12, a 32-bit zero is stored at **retained second selector + 0x44**. Next, zero is assigned to the global at **0x24**, with access width unspecified.

The word destination uses the retained second selector. There is no third selector read at this point, even if intervening calls changed the selector source.

### Fixed-size arguments and paired-result processing

F-C01 receives **0, 0x98, B, 0x98**, in that order. F-C02 produces a token forwarded to F-C03. F-C04 produces another token forwarded to F-C05. F-C06, F-C07, and F-C08 follow.

The high half used for that store belongs to F-C14’s retained result. It is not replaced by an output from F-C15.

### Repeated Q-selected writes

F-G01 produces a token forwarded to F-G02. F-G03, F-G04, and F-G05 follow. F-G06 produces the **G-phase scaled result**.

The sequence rereads **byte[W(Q + 1)]**. At this selector plus **0x11**, it writes **L((U AND 0x3FFFFFFF) logically shifted right by 20)**. F-G07 receives **W(G-phase scaled result × 4)**. F-G08 through F-G10 follow.

Thus, the second Q-selected write uses U from F-F11 despite the intervening result from F-G06. F-G12 receives neither V nor the selected destination address.

### Final selector source and terminal boundary

The final selector read is **byte[W(V × 8 + 1)]**. At that selector plus **0x11**, the sequence writes **L((V AND 0x3FFFFFFF) logically shifted right by 20)**. F-H07 receives **W(final scaled result × 4)**.

F-H08, F-H09, F-H10, and F-H11 follow in order. The represented invalid-instruction boundary follows F-H11.

This final selector source depends on V from F-G11, not directly on P, Q, or F-H06’s result.

## Acceptance examples

These are **conditional static expectations**, not executed tests.

1. **Input forwarding.** With second input **0x12345678**, reaching F-A01 forwards that exact 32-bit value. No direct forwarding of the first or third input is visible.

2. **Initial byte extraction.** With **R = 0xFFC00000** and initial selector **0x20**, the first selector write stores **0xFF** at **0x31**.

3. **Selector retention.** If the two B-derived reads yield **0x10** and **0x20**, their byte clears target **0x21** and **0x31**. The later 32-bit zero store targets **0x64**, using the retained second selector even if calls subsequently change the source.

4. **Mask boundary.** With **P = 0x00400000**, M, B, and Q are zero. Mask-derived values are zero, but the direct P-relative byte clear remains at **0x0040000F**.

5. **Retained link value.** If F-E09 returns **3** and F-E14 returns **7**, the first link store writes **12** at **0x44**. The later link store writes the same **12** at **0x30**, not **28**.

6. **Late truncation.** If **U = 0x12345678**, the first Q-selected write stores **0xE0**. The second Q-selected write stores **0x23**, independently of F-G06’s result.

7. **Changing Q selectors.** If the three Q-derived reads yield **0x10**, **0x20**, and **0x30**, the corresponding byte destinations are **0x21**, **0x31**, and **0x41**. F-G12 receives **0x00000030**.

8. **Global-assignment boundary.** Reaching the assignment after the C-phase indexed clear establishes a zero assignment to the global at **0x24**. It does not establish that exactly four bytes are written or that neighboring bytes remain unchanged.

9. **Interrupted execution.** If an access faults without resumption, or a dependency never returns, subsequent effects are not promised. No rollback is visible.
