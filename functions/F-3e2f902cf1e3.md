- Zero selects the branch without dispatch.
- Every nonzero value selects the dispatch branch.
- Under a signed-integer interpretation, negative values are nonzero and therefore also select dispatch.

### Nonzero-result branch

1. Read the first field from the object designated by the input pointer.
2. Use that field’s value as the base address for a dispatch-slot lookup.

4. Invoke that operation with the original input pointer.
