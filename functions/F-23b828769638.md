# F-23b828769638

The supplied static representation establishes individual operations and their state relationships. It does not establish a complete execution sequence: the initial dispatcher state, dispatch origin, transition destinations, and arithmetic coefficients come from globals whose values are unavailable.

The contract is therefore conditional on reaching each operation. Missing global values do not make the operation’s assignments or access order unknown; they make its reachability, successor, repetition count, and eventual termination unknown.

The paired record updates resemble accumulation of two-word quantities. Their application-level meaning is inferred intent, not established behavior.

For p equal to zero, the adjusted alternative is selected; for p equal to one, the unadjusted alternative is selected. The alternatives are combined arithmetically rather than loaded through a short-circuit branch.

## Acceptance examples

These are conditional static acceptance cases, not executed tests.

1. **Lower-word carry.** If selector 10 executes with offset 0 equal to hexadecimal FFFFFFFF, offset 4 equal to 7, L equal to 1, and U equal to zero, the pair becomes 0 and 8, absent interference.

2. **Complete pair overflow.** With both words hexadecimal FFFFFFFF and addend one, a paired update stores zero in both words. It produces no direct overflow indication.

3. **Clearing preserves its gap.** On valid, noninterfering memory, selector 9 leaves offset 32 unchanged by direct writes. It writes offset 28 before offset 24.

4. **Clearing uses the earlier global read.** Suppose S is 3 and the clearing coefficient reads as 7 after offset 12 is cleared. If offset 16 aliases that coefficient, its subsequent zero write does not change this operation’s multiplication: J becomes 21, assuming defined arithmetic and no other interference.

5. **Transition alternatives use distinct observations.** For selector 16 with p zero, if the first transition read yields 100 and the second yields 900, the next state is 101, not 901. With p one, it is 900. Both reads still occur.

6. **Default predicate precedes carrier replacement.** If the default operation starts with P and T both zero, p becomes one. Replacing T later with the scaled S does not retroactively change that predicate.

7. **Origin reload is not necessarily selector zero.** If selector 14 loads an origin value of 100 and the next dispatch observes 99, the selector is 1, provided the subtraction is defined.

8. **Null is not guaranteed safe.** If setup installs null and clearing is later selected, clearing attempts a write through null. A safe rejection cannot be required.

9. **Unformed result.** If selector 6 is reached before selector 11 changes R, the return is zero. That does not establish success.
