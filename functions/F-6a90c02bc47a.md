### Early word propagation and field extraction

That write precedes the early word read selected by the upper ten bits of the incoming unsigned word. The read address is that selector plus `0x14`, without another index multiplication.

The fetched word has two distinct uses. Its logical right shift by one selects a four-byte-indexed destination; the unshifted word also supplies a separate read address after adding `0x14`. The destination write precedes that second read. Consequently, aliasing between those locations can affect the value read.

A dependency-produced value, shifted left by two, is propagated into more than one word field. The later propagation reuses the retained value rather than recomputing it from destination memory.

The second fetched word contributes its upper ten bits to subsequent word stores and dependency arguments. Separately, an early snapshot of the reference global contributes its upper nine bits to dependency arguments.

That nine-bit quantity is later shifted right by another 23 positions. The result is necessarily zero: the original global was only 32 bits wide. This establishes both a word zero store and a subsequent byte-selector read at numerical address one. It does not establish that the stored zero remains unchanged after later calls or writes.

An auxiliary unsigned 32-bit dependency value has two separate roles: selecting a zeroed word field through four-byte indexing, and supplying a later read selector through masking and shifting. The latter retains bits 19 through 28 and adds `0x14` directly. It is not a four-byte-stride lookup.

## Acceptance examples

These are conditional consequences of static evidence, not executed tests. They assume execution reaches the relevant operations and that the stated arithmetic and accesses are valid.

1. **Early aliasing.** If the first direct word destination aliases the following selector-derived word source, the source read follows the store. A pre-store source snapshot does not satisfy the contract.

2. **Repeated extraction becomes zero.** If the first reference-global snapshot is `0xFFFFFFFF`, its upper-nine-bit extraction is 511. Shifting that result right by 23 yields zero. The corresponding word store is zero, and the related byte-selector read is at address one.

3. **Byte truncation does not narrow later indexing.** If the extracted upper-ten-bit field is 1023, its byte write supplies 255, while its separate selector read occurs at 4093.

4. **Retained selector.** If the retained read of address one yields seven, the associated later transfer reads a word at `0x7B` and writes its low byte at address eight, even if address one subsequently changes.

5. **Fresh repeated word read.** If dependencies change the word at a repeated source address between the two transfers, the second transfer uses a new 32-bit read, not the first transfer’s retained value.

6. **Distinct destination stride.** For an index of three, the sixteen-byte-stride propagation destination is `0x44`; an ordinary four-byte-indexed destination would be `0x20`.

7. **Separate global snapshots.** If the reference global changes between its two reads, the late reference-based read uses the second snapshot. If its address aliases the immediately preceding word store, that store precedes the read.

8. **Terminal composition.** If F-159 supplies `0xAB` and the post-clear 24-bit read yields `0x123456`, the output-global write is `0x123456AB`. This example specifies composition, not memory byte order.

9. **Terminal failure.** If calling address zero fails, normal return is not established. Earlier writes precede that call, but their eventual persistence remains unresolved.
