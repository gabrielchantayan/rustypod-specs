## Acceptance examples

These are conditional static criteria, not executed tests. They assume that the relevant path and accesses are valid.

- **Opening observations differ:** If Root `+0x05` changes between observations, the first byte remains Opening byte; the later byte is copied to Root `+0x11`.
- **Distinct displacement destinations:** The halfword sum of Displacement-first and Dispatch is stored at Tertiary plus Entry unsigned plus `0x53`, not at the destination selected by Displacement-address.
- **Pre-shift ordering:** Twice Shift-base receives Dispatch’s low halfword after the Saved-payload halfword store and before the variable shift.
- **Conditional observation:** Carry threshold above `0xffffffa6` suppresses the Carry-addend observation. Otherwise that fresh observation participates in carry detection.
- **Patch reload:** If Linked base `+0x45` overlaps Pointer cell, its halfword write can alter the subsequently reloaded Patch region. Retaining the earlier pointer instead is not equivalent.
- **Opening `0x74` propagation:** If Working region `+0x11` overlaps its `+0x14` payload storage, the payload observation occurs after that byte mutation. The destination base has already been observed; Active region is established by a still later read.
- **Separated Working-region stores:** If Working region `+0x54` aliases Active region `+0x74`, Active-link-first is observed before the Working-region payload store. Moving that store alongside Working region `+0x34` changes the permitted result.
- **Closing `0x66` propagation:** After the two self-address stores, the destination base is read first, Working region `+0x11` is mutated second, and Working region `+0x14` supplies the propagated byte third.
- **Retained payload:** Changes to the Shared-payload external cell after its single observation do not refresh later uses.
- **Distinct final values:** If Dispatch second word is `0x1000` and Doubled-store payload is `0x55667788`, the doubled destination is `0x2000`, while the second indirect argument remains `0x1000`.
- **High-bit character:** A final character with byte pattern `0x80` converts to `0x00000080` or `0xffffff80`, depending on character interpretation. Selecting one is documented_only.
- **Return or failure:** A later failure has no represented rollback. Normal Dispatch return produces no explicit result and implies no preservation guarantee.
