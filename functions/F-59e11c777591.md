# F-59e11c777591

## Purpose

- If the existing value is zero, the function writes the supplied value to that field and returns normally.
- If the existing value is nonzero, the function invokes F-039b80c3dfb5 and then F-feee9156a257. The supplied static evidence identifies the latter call as non-returning. On that model, this path does not reach the field write or return normally.

An inferred intent is to prevent replacement of an already nonzero field. This is not necessarily a strict “write once” operation: writing zero leaves the field eligible for another normal write. Neither a particular application-level meaning for the field nor the reason for the non-returning path is established.
