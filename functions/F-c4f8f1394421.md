## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Aliased indexed byte.** With nonzero second argument equal to 24, the non-null path reads the same byte it subsequently overwrites. F-122d533c3bc0 receives the earlier byte, not a reload.

2. **Narrowing.** If the implicit-state-plus-99 value has low halfword `0x8001`, the doubled halfword store contains `0x0002`, provided the store is reached.

3. **Changed first-store address.** If a below-two iteration reads byte `0x40` and repeats, the next low-result first word store targets address `0x70`. It does not reuse the initial control-position-derived address. Its payload is the newest below-two dependency result’s low word.

4. **Selected-branch write ordering.** For a step-9 halfword of two, the four byte-address-based word stores occur before all six destination-pointer stores. Overlap does not justify reversing or merging them.

5. **Below-two boundary.** A halfword of one selects the below-two branch. After its dependency call, clear bit 26 permits repetition; set bit 26 leads to truncation. Successful preceding calls alone do not establish repetition.

6. **Null input.** A harmless no-op instead of the apparent address-zero halfword store would not match the representation. Later null-path writes remain conditional on passing that access and the empty loop.

7. **Tail boundary.** A dependency result of 148 produces −1 and repetition; 149 produces zero and truncation. In both cases, the byte store occurs before the continuation decision.

8. **Ordinary return mask.** If the downstream null-path call is reached and returns `0x80000000`, its low 24 bits are zero. The global-word copy and ordinary return follow, notwithstanding the high bit.
