# F-d413aa2259a2

## Purpose

**Established static evidence:** the routine consumes register-derived state, reads two global pointer-bearing cells, uses three represented 64-bit call results, and accesses memory through both fixed and computed addresses. **Inferred intent:** some writes resemble record-field or table updates. No application-level purpose, object model, allocation role, or dispatch protocol is established.

This contract describes the supplied static representation. It does not establish that every represented access is executable on an actual platform.

### Halfword stores and early destination update

**F-indirect-09** supplies another represented 64-bit result. Its high word is used as an address base for a halfword-zero store at offset `0x2c`. Next, its low word, logically shifted right by 26 bits, is stored as a word at frame-base offset `0x26c`. This stored value lies between zero and 63.

The latter store discards the upper two bits of the unshifted low word. Both transformations use the retained F-indirect-09 result; no second result read is represented.

### Fixed-address read and breakpoint

### First table store and fixed derived address

The F-indirect-19 result is shifted left by two bits to form a 32-bit table offset.

Independently, the fixed value `0x21c48960` is logically shifted right by 18 bits and multiplied by four. This produces `0x21c4`.

Using the halfword read before the breakpoint as a zero-extended address base, the routine reads a word at offset `0x44` and retains it as the later destination. It then invokes **F-indirect-20** and **F-indirect-21**.

After F-indirect-21 returns, the routine reads a word at offset `0x04` from the same halfword-derived base. **F-indirect-22** receives the F-indirect-21 result and this newly read word.

The table-pointer cell is read next. After **F-indirect-23**, a halfword is stored at the retained table base plus the scaled F-indirect-19 result. The stored value is the low 16 bits of the retained table base itself.

Thus, this table store writes a truncated address value. It does not write the index, the scaled offset, or the F-indirect-21 result.

After **F-indirect-24**, a pointer-like word is read from fixed address `0x2218`, obtained as `0x21c4 + 0x54`. **F-indirect-25** then supplies an address-bearing result. A halfword containing `0x21c4` is stored at offset `0x04` from that result.

- The high result word multiplied by four.

**four times the selector + `0x74`**
