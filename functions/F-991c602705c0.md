Byte stores retain the low eight bits. Unsigned byte loads used as word values or address bases are zero-extended. Represented unsigned right shifts are logical.

Address-bearing arithmetic is represented using 32-bit quantities. Numerical examples below explicitly assume truncating 32-bit arithmetic where necessary. That assumption does not establish portable semantics for signed left shifts, signed multiplication, overflow, or address conversion.

Sequential shifts retain any truncation introduced by an earlier operation. Some dependency transformations shift an unsigned 64-bit result by 34, 36, or 44 bits before narrowing; these must not be interpreted as shifts of an already narrowed word.

A late signed right shift uses the working base’s low eight bits as its count. Negative operands and counts of 32 or greater remain **documented_only**. No modulo-32 count reduction is established.

The access order below is the represented order. Native instruction ordering, volatile behavior, and a concurrency memory model are not independently established. Repeated or overwritten stores remain distinct represented accesses.

## Side effects
