## Acceptance examples

These examples are conditional static deductions, not executed tests.

### Masked index boundary

If the value feeding the small-index calculation has its low seven bits set, the small index is 508 and its doubled base is 1016, subject to the represented shift semantics. Higher bits do not survive the mask. An unrestricted array-index interpretation would be incorrect.

### Ordered byte replacement

If the final high word’s low byte differs from the shifted payload’s low byte, execution reaching both stores produces the first byte write and then its replacement at shifted-payload plus 9. Keeping only the replacement does not preserve an access-sensitive trace.

### Zero extension

If the byte read at packed-base plus 5 is 255, its corresponding offset-52 word store contains 255, not a sign-extended negative value.

### Reload after overlapping mutation

If an intervening access changes storage overlapping packed-base plus 20, the later reload uses memory at its actual read point. The earlier clear does not require the reload to produce zero.

### Base capture before fixed-location mutation

Suppose the final computed offset-32 store has completed and the base-source read yields an accessible address A. If assigning 32 to fixed word location 96 subsequently changes the base-source storage through the environment’s memory semantics, the repeated region still uses captured address A. Delaying the read until after that assignment would violate the capture boundary.

### No refresh during repeated writes

Suppose the base-source read captures A, and a later repeated-region write changes the source word to B. Subsequent repeated-region destinations still use A plus their specified offsets, not B. The narrowed byte derived from the repeated-region base also remains derived from A.

### Repeated constants

For accessible storage and execution reaching the complete sequence, the computed offset-32 location receives 32, 47, the widened loaded byte, and 32 in order. A final value of 32 alone is insufficient evidence of trace equivalence.

### Interrupted execution and terminal interaction

If a dependency never returns, later accesses need not occur, and earlier effects need not be undone. If execution reaches the terminal transfer, its first represented argument is 114; interpreting that number as a character or command is not required.
