# F-9a2fb3178318

## Purpose

F-9a2fb3178318 performs an ordered operation on a caller-supplied memory region. It obtains two samples from shared integer storage, writes values derived from those samples into the region’s first two words, conditionally invokes an indirect dependency, and then invokes another dependency with an interior address. Its ordinary return is the latter dependency’s integer result minus 220.

The two initial writes have different value provenance:

- The first word receives the **later shared-storage sample**.
- The second word receives the **earlier shared-storage sample plus 20**.

The second word therefore need not equal the first word plus 20. That relationship holds only when the two samples are equal and the addition is representable.

These are operations expressed by the supplied static representation. Two represented reads do not independently establish two physical machine loads, nor do they establish atomicity or synchronization.

The semantic purpose of the memory region, the shared storage, and the two dependencies is unknown. Initialization, destruction, resource release, and object-layout adjustment are possible interpretations, not established behavior.

## Behavior

### Initial sampling and writes

The represented sequence begins with a read from shared integer storage. This **earlier sample** is retained for the second-word calculation.

The function then reads the same shared storage again. This **later sample** is written to the first input word.

Only after that first-word write does the function write the second input word, using the retained earlier sample plus 20.

The established value provenance is therefore:

| Destination | Value source |
|---|---|
| First input word | Later shared-storage read |
| Second input word | Earlier shared-storage read, increased by 20 |

No read of the newly written first word supplies the second-word calculation. No third shared-storage read is expressed for that calculation.

If both shared-storage reads produce 100, the two writes contain 100 and 120. If the earlier read produces 100 and the later read produces 140, the writes instead contain 140 and 120. The latter result is consistent with the representation; equality of the samples is not a precondition expressed by the function.

Both represented reads precede the first input write. Consequently, if an input write aliases the shared storage, that write does not change the value already retained from the earlier read or the value already obtained for the first-word assignment.
