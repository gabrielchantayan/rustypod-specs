These are conditional static acceptance examples, not executed tests.

1. **Fourth-argument extraction.** If execution reaches the first word publication and the fourth argument is `0xabcdef01`, the stored word is `0x000abcde`. Changing only its low 12 bits does not change that payload.

2. **Byte truncation.** If a left-shift byte payload is derived from `0x0000007f`, the written byte is `0xfc`. A corresponding masked-right-shift payload derived from `0x3fffffff` writes `0xff`, not the full shifted value `0x000003ff`.
