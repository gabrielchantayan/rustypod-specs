# F-280a6058ff6e

## Purpose

F-280a6058ff6e conditionally adjusts an input integer using an integer read from a fixed displacement relative to a supplied base address.

The selector determines one of three behaviors:

- Selector **5**: return the input value minus the stored adjustment.
- Selector **6**: return the stored adjustment plus the input value.
- Every other selector: return **0**, without accessing the supplied base address.

The established behavior is a selector-controlled arithmetic operation. Interpreting the stored adjustment as a coordinate origin, relocation amount, or other application-specific quantity would be inferred intent, not an established part of this contract.

## Behavior

### Selector dispatch

The function first distinguishes selector 5 from all other values. If the selector is not 5, it then distinguishes selector 6 from the remaining values.

Both comparisons are exact integer comparisons. There is no range classification, masking, normalization, or default interpretation of other selector values.

The dispatch itself does not require a memory read through Base.

### Selector 5: subtraction

For selector 5, the function:

- Uses the address represented by Base plus 16.
- Reads one signed integer adjustment from that address.
- Returns Value minus that adjustment.

The subtraction order is significant: Value is the minuend, and the stored adjustment is the subtrahend. A negative adjustment can therefore increase the result, provided the subtraction remains representable.

The supplied representation contains one read of the adjustment on this path. It does not first read another field, validate the object, or store the computed result back to memory.

### Selector 6: addition

For selector 6, the function:

- Uses the address represented by Base plus 16.
- Reads one signed integer adjustment from that address.
- Returns the stored adjustment plus Value.

The supplied representation contains one read of the adjustment on this path. The intermediate arithmetic result replaces a local parameter value before being returned; this does not constitute a write to the caller’s argument storage or to the addressed object.

### Every other selector

For any selector other than 5 or 6, the result is exactly zero.

On this path:

- Base is not dereferenced.
- No adjustment is fetched.
- Value does not affect the result.
- There is no fallback arithmetic operation or error report.

In particular, a Base value that would be unsuitable for either arithmetic branch does not, by itself, prevent this branch from returning zero.
