### Field selection

When both comparisons return nonzero, the function makes two displayed reads of the same 32-bit location at input plus 44 bytes.

These observations have different roles:

1. The first read supplies a candidate return value.
2. The second read decides whether the fallback is selected.

If the **second** read is zero, the function reads and returns the fallback result.

If the **second** read is nonzero, the function returns the value obtained by the **first** read.

The second observation is therefore a condition, not an unconditional replacement for the first value. If the two reads observe different values, the distinction affects the result:

| Nonzero value A | Nonzero value B | A |
