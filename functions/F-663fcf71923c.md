## Behavior

### Entry and empty-slot path

The function first reads the integer value at the supplied slot address. This is the first established data access.

If that value is zero, the function returns the original slot address immediately. On this path:

- No object-relative field is read.
- The unsigned argument is not behaviorally consulted.
- Neither dependency is invoked.
- No direct memory write is established.

There is no evidence of slot initialization, slot clearing, or an auxiliary notification on this path.

### Nonzero-object path

If the initial slot value is nonzero, that value is retained as the object address for the remainder of the established behavior. The function then reads the integer-sized associated field at byte offset 8 from that address.

If the associated value is zero, the function skips the discriminator read and does not invoke F-8349c252c168. It proceeds directly to F-feee9156a257 with the retained object address.

If the associated value is nonzero, the function reads the unsigned byte at object offset 12. It compares the resulting value with 0x3A:

- A value equal to 0x3A suppresses the call to F-8349c252c168.
- Any other byte value causes a call to F-8349c252c168 with the previously read associated value as the first argument and integer zero as the second argument.

If that conditional call is made and returns normally, execution proceeds to F-feee9156a257. This final call receives the retained object address, regardless of the discriminator value or the associated value.

Thus, the incoming unsigned argument cannot control the optional call. When the associated field is nonzero, the discriminator read replaces its relevant role. When the associated field is zero, the optional call is already excluded.

### Ordering and retained values

The established order is:

1. Read the slot contents.
2. For nonzero contents, read the associated field at object offset 8.
3. For a nonzero associated field, read the discriminator at object offset 12.
4. If the discriminator differs from 0x3A, invoke F-8349c252c168.
5. After that call returns, or immediately if it was skipped, invoke F-feee9156a257.

The function does not establish a second read of the slot, associated field, or discriminator after the optional dependency call. In particular, the final dependency receives the object address captured before that call.
