## Behavior

### Numerical result

For an admissible input, the result is exactly sixteen greater than the received value.

This relationship applies uniformly across the admissible interval. It gives the following sign behavior:

- An input below negative sixteen produces a negative result.
- Negative sixteen produces zero.
- An admissible input above negative sixteen produces a positive result.

Neither zero nor a negative result denotes failure in this contract. A value that another component treats as a sentinel still receives the ordinary numerical adjustment when supplied here; no sentinel convention is established for this function.

The greatest admissible input is sixteen below Maximum, and its result is Maximum. The complete result interval for defined invocations therefore extends from sixteen above Minimum through Maximum, inclusive.
