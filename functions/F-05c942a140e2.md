### Sentinel already present

- F-d9e78f45a0bc is not invoked.
- The function performs no direct marker write.
- The function returns without an explicit result.

The character is still read to decide this branch. The early-return path is not an absence of memory access.

### Sentinel absent

The marker has not yet been written by F-05c942a140e2 when the dependency begins. Consequently, the dependency can observe the preexisting marker state, subject to whatever other state changes occur.

After the dependency returns normally, the function stores −1 through the pointer captured before the call, then returns.

There is no supplied success predicate governing that write. A normal return from the dependency is sufficient for the function to proceed to the marker assignment, regardless of whether the dependency internally accomplished an inferred higher-level task.

### Effects of dependency mutation

The final destination is not refreshed from global state after the dependency returns.

If the dependency changes the global pointer from one valid object to another, the final write still targets the originally captured object. The newly selected object is not directly marked by this function on that invocation.

If the dependency changes the character at the captured destination, the final assignment overwrites that character with −1, provided the destination remains valid and writable.

If the dependency releases or invalidates the captured storage, the function still reaches the write after a normal return. The supplied representation contains no protection against this invalidation. Valid execution therefore requires an appropriate lifetime guarantee outside the shown function.

### Repeated and reentrant invocation

With a stable pointer, valid storage, and a character interpretation under which the stored marker subsequently compares equal to −1, a completed non-sentinel invocation causes later invocations to take the early-return path.

That property is conditional. The function does not prevent:

- External code from changing the marker.
- External code from selecting another object through the global pointer.
- Recursive entry before the outer invocation writes its marker.
- Overlapping invocations from both observing a non-sentinel value.

In particular, the function does not mark an operation as “in progress.” Recursive entry during the dependency call can invoke the dependency again if its own sentinel inspection does not compare equal to −1.
