# F-70fb3b3be496

## Purpose

F-70fb3b3be496 partially initializes caller-provided destination storage after invoking two dependencies. Its direct writes combine global values, temporary values exposed to a dependency, and fields read from a source object.

**Established static behavior:** the visible body performs ten four-byte destination stores. It does not initialize the intervening destination fields. Two final values depend on whether a source word, read late in the operation, equals zero.

**Inferred intent:** the operation resembles object or descriptor initialization, including duplication of one source field and selection of a configuration pair. No field meanings, object lifecycle, or validity invariant are established.

All ordering below describes the supplied static representation. It is not a claim of independently verified machine-instruction ordering, atomicity, or hardware memory-access behavior.

## Behavior

### Dependency phase

The visible sequence is:

1. Initialize the three local values.
2. Invoke **F-304d68214672** without explicit arguments.
3. After that invocation returns, read the four-byte source word at byte offset 100.
4. Invoke **F-ccabec065f5e** with that word and the address of the temporary initially containing the destination pointer.
5. After the second invocation returns, begin the direct destination stores.

The source-offset-100 value is read after the first dependency returns, not before it. Consequently, a modification by F-304d68214672 can change the first argument received by F-ccabec065f5e.

The source fields, global words, and temporary values used later are not visibly captured before these calls. Their later reads use the values then present, subject to the applicable execution model.

### Discriminator and final pair

After the store at destination offset 112, the function reads the source word at offset 104 and captures whether it equals zero. It then reads G2.

| Captured source-offset-104 condition | Destination offset 104 | Destination offset 108 |
|---|---|---|
| Equal to zero | Value obtained from G2 | Value obtained from G3 after the preceding destination store |
| Not equal to zero | Zero | Zero |

The following sequencing details are established:

- G2 is read in the representation on both discriminator paths.
- For a nonzero discriminator, the obtained G2 value is replaced by zero before the store at destination offset 104.
- G3 is read only on the zero-discriminator path.
- On that path, the destination-offset-104 store precedes the G3 read.
- The zero/nonzero decision is captured once. Later writes do not trigger another discriminator read.

Any nonzero 32-bit pattern selects the same path. There is no magnitude threshold or positive-versus-negative distinction.

### Aliasing and changes between reads

The function contains no overlap check or general staging mechanism. Where overlap is valid under the actual execution model, earlier stores can affect later reads.

This applies to both source/destination overlap and destination/global overlap:

- A destination store can modify a source field that has not yet been read.
- The second source-offset-96 read can observe effects of intervening stores.
- A store overlapping G1 can change the value read for destination offset 4.
- On the zero-discriminator path, a destination-offset-104 store overlapping G3 can change the final value obtained from G3.

The globals therefore cannot be treated as immutable constants merely because the dependencies preserve them. The function’s own stores may alter their storage through aliasing.

These are conditional consequences of access order, not a guarantee that arbitrary overlap is legal or supported.

### Source overlap changes the discriminator

Assume valid overlapping storage with the destination base four bytes after the source base. Exclude destination/global overlap, dependency changes to the relevant source or destination fields, and external changes.

Let source offset 92 initially contain nonzero value **B**. The store at destination offset 100 writes B into source offset 104. The discriminator is read afterward and is therefore nonzero, irrespective of its earlier value. The final pair of destination stores writes zero.

### Destination overlap changes a global read

Assume destination offset 0 aliases G1, the four-byte access is valid, and G0 currently contains **A**. Assume no intervening external change.
