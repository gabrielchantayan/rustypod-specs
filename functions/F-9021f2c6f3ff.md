# F-9021f2c6f3ff

## Purpose

F-9021f2c6f3ff performs an ordered sequence of indirect calls, interleaved with word, byte, and halfword memory writes. Several call results are scaled by four and used as addresses or arguments. Two byte writes use an unsigned byte read from one address to select another address in the range 17–272. The final portion updates a global slot, performs two zeroing writes, and invokes address zero with three zero arguments.

The supplied static representation does not establish a higher-level purpose. In particular, it does not justify describing the function as an allocator, serializer, initializer, dispatcher, or cleanup routine.

This contract distinguishes explicit operations from unresolved calling-convention, address-validity, and dependency behavior. All later operations are conditional on earlier calls returning and earlier memory accesses completing.

## Acceptance examples

These examples are conditional static consequences, not runtime observations. They assume applicable arithmetic, valid memory mappings, and normally returning dependencies.

### Aligned destination selection

If the third explicit input is 4099, clearing its lowest two bits yields 4096. The F-D05-derived word is written at 4116. Inputs 4096–4099 select that same destination.

If F-D05 returns 7, the stored value is 28, and F-D06 receives 28 twice.

### Shifted entry-associated value

If the entry-associated unsigned value is 16,777,216, its right shift by 23 is 2. The F-D14-derived destination receives the 32-bit value 2.

This does not imply that later access at the entry-associated value plus one succeeds.

### Split 64-bit result

If F-D19 returns a value whose high half is 10 and low half is 3, the function writes 12 at address 60. F-D20 receives 12, 10, 12, and 12.

If F-D24 later returns 20, the function also writes 12 at address 100 before reading the retained-base payload.

### Low-byte selection

If the first selector read yields 5 and the retained payload is 0xA5C39E72, the first byte-selected destination is address 22, and the written byte is 0x72.

The destination is not the selector-source address plus 22.

### Upper payload-byte extraction

For a retained payload of 0xA5C39E72, bits 22–29 produce the byte 0x97.

If the second selector read also yields 5, the second explicit byte-selected write targets address 22 and writes 0x97 there. Dependencies between the two writes remain free to affect that location.

### Masked address derivation

If the low half of F-D29 is 0xC0000080, masking off its highest two bits leaves 128. The second selector source address is 1, and the final halfword destination is 1.

The halfword destination is therefore odd in this example; successful access requires target support for that access.

### Failure before completion

If the first selector read faults, F-D30 and all subsequent explicit operations are not reached by ordinary sequential execution. Earlier stores are not rolled back by any visible mechanism.

If address zero is not executable, the final invocation may fail after the preceding global update and zeroing writes have occurred.
