## Behavior

### Data selection

The function reads one byte at the first input’s address plus 28. This is the entire visible data source for the extracted field.

It also reads one byte at the second input’s address plus 1. Only the lowest seven bits of that byte contribute to the selector. Its highest bit is ignored.

Consequently, two selector bytes differing only in bit 7 select the same shift distance. For example, selector bytes 1 and 129 both produce a shift distance of two.

### Extraction

The masked selector is doubled to obtain the number of bit positions by which the data value is shifted right. The lowest two bits remaining after that shift become the return value.

For masked selectors 0 through 3, this selects the following fields:

| Masked selector | Shift distance | Selected data bits |
|---|---:|---|
| 0 | 0 | Bits 1–0 |
| 1 | 2 | Bits 3–2 |
| 2 | 4 | Bits 5–4 |
| 3 | 6 | Bits 7–6 |

Bit 0 is the least significant bit of the data byte. These cases do not depend on multi-byte endianness because each memory access obtains a single byte.

The function does not visibly check that the selector is within this four-field range. It does not clamp the selector, reduce it modulo four, or reject an out-of-range selector.
