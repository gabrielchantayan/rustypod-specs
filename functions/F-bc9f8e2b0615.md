## Acceptance examples

These are conditional criteria, not executed tests.

- **Availability denied:** Zero availability permits no subsequent preparation or direct object-field read.
- **Prepared but ineligible:** Captured mode zero with only mask `0x4` set returns after preparation, before P setup.
- **Mode-only eligibility:** Mode 2 selects its preset path even with both gradient masks clear.
- **Mutable flags:** Captured `0x4` set and later `0x8` clear skips gradients. Setting `0x4` only after capture cannot enable them.
- **Changing fill byte:** Reads `128`, `255`, then zero cause no `0x22` setting but do cause the final setting call. Reads `255`, `128`, then `255` cause the opposite.
- **Rejected geometry:** Zero geometry-test result skips detailed construction and second-variant color stores, but still reaches S-to-P composition with G twice.
- **Second-variant initialization boundary:** A nonzero geometry-test result requires all four local color records to be initialized before the context-associated 16-bit read and subsequent target-preparation calls. Moving those stores after F-22ebf78204e2 violates the observed ordering.
- **Zero extent:** N equal to zero still reaches all three step calls. If they return, no loop lines occur, but inner composition and lifecycle calls follow.
- **Mutable table:** A first step call that changes captured-table offset 1 affects the second numerator. Loop starting bytes are reread.
- **Selective auxiliary:** Selector three alone produces placement from current `(E1 + 1, E2)`, not necessarily original geometry.
- **Layer order:** Common fill precedes gradients, then auxiliaries, then edges.
