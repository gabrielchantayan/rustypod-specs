## Behavior

### Initial eligibility decision

The function first compares the original second input with the original first input using an unsigned less-than-or-equal comparison.

If the second input is greater than the first input:

- The adjustment addition is skipped.
- The function returns zero.
- The third input has no effect on the result.

No adjusted value can rescue a failed initial comparison. This remains true even if adding the adjustment hypothetically would produce a value greater than the first input.

If the second input is equal to or less than the first input, the function proceeds to the adjustment.

### Conditional adjustment

After a successful initial comparison, the function adds the third input to the second input and retains the result in the second input’s unsigned type.

Under the unsigned-counterpart interpretation described above, this addition is modular rather than saturating:

- A sum above the maximum unsigned value wraps.
- A negative mathematical sum wraps into the unsigned range.
- No overflow status, error result, or exception is explicitly produced by the body.

The original first input remains the threshold throughout this decision.

### Final selection

After the adjustment, the function returns the original first input only if the adjusted second value is strictly greater than it.

An adjusted value equal to the first input is insufficient. An adjusted value below the first input is also insufficient. Both cases return zero.

The complete return rule is therefore:

\[
R =
\begin{cases}
A, & B \le A \text{ and } ((B+D)\bmod M) > A \\
0, & \text{otherwise}
\end{cases}
\]

The conjunction describes the result, but the addition remains conditional: the actual body skips it when \(B>A\).

### Boundary consequences

Several consequences follow from this rule:

- **A zero adjustment always produces zero.** If the initial comparison succeeds, the second value remains at or below the first.
- **Equality after adjustment always produces zero.** The final boundary is strict.
- **The maximum unsigned first input always produces zero.** No unsigned adjusted value can be greater than that maximum.
- **A zero first input always produces an observable zero result.** If the second input is nonzero, the initial comparison fails. If it is zero, any selected original first input is still zero.
- **A negative adjustment can allow a nonzero return.** Modular underflow can produce an adjusted value greater than the first input.
- **A positive adjustment can produce zero despite a large mathematical sum.** Modular overflow can reduce the adjusted value to or below the first input.

These consequences are numerical properties of the selection rule, not evidence of a domain-specific validation policy.
