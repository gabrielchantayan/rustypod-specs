- If F-e6c2a72b1331 returns a non-null address, F-7774cbea8d57 obtains a callable address through a two-stage memory lookup and invokes that target with the returned address and the second input.

### Non-null dispatch

When the dependency returns a non-null address, the wrapper performs the following ordered actions:

1. Reads the 32-bit value at the beginning of the returned region.
2. Uses that value as an address base and selects the location 256 bytes beyond it.

4. Invokes that target with the original returned address as the first argument and the original second input as the second argument.

These reads are dependent: the callable-address location cannot be selected until the first read supplies its base.

The wrapper shows no write between these reads. It also shows no second call to F-e6c2a72b1331, no retry, and no alternate target selection.

No validation is shown for:

- Validity or alignment of the address stored at its beginning.
- Accessibility of the callable-address entry.
- Non-nullness of the selected callable address.
- Executability or signature compatibility of that address.
- Suitability of the second input for the selected target.

After the indirect operation completes normally, the supplied representation shows the wrapper returning without additional visible work.

The evidence includes uncertainty in recovery of the indirect control transfer. The representation treats it as a call followed by return, but the precise machine-level distinction between an ordinary call and a tail transfer is not established.
