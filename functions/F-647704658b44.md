# F-647704658b44

## Purpose

The established behavior is these two assignments and their order. The supplied material does not establish a higher-level purpose, such as object construction, type tagging, registration, or initialization of a particular data structure.

The shared word is obtained after the second destination field is written. It must not be described as an immutable constant or as a value captured at function entry.

## Behavior

### Ordered accesses

The visible operation has three relevant memory accesses, in this order:

1. A 32-bit write of the supplied word to destination offset 4.
2. A 32-bit read from the shared source location.
3. A 32-bit write of the value obtained by that read to destination offset 0.

No branch, loop, destination-content check, or explicit function call appears in the supplied body.

The first destination field is therefore written last, despite appearing first in the layout. A behavioral replacement must preserve the distinction between field layout and access order wherever that order is observable.

The old contents of the destination fields are not explicitly read for use in either assignment. There is, however, no demonstrated restriction preventing the shared source location from overlapping the destination. In an overlap case, the shared-source read can also be a read of destination storage.

### Ordinary nonoverlapping case

When the shared source is separate from the destination, all accesses succeed, and no other actor modifies the relevant storage:

- The second field ends with the supplied word.
- The first field ends with the word read from the shared source.
- The shared source is not explicitly written by this function.
- Destination storage outside the two fields is not explicitly written.

The first field receives the source value at the time of the read, not necessarily the value that existed at function entry.

The final store writes the obtained word back to the same location. Although the final bits may be unchanged, a read and a write still occur.
