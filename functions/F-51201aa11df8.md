## Behavior

### Byte values and their persistence

The direct byte effects use several independent value sources. Numerical equality during one execution does not erase their different dependencies.

**Incoming byte.** The initial region repeatedly writes the incoming eight-bit value. Most dependency-derived destinations are eight times a newly obtained numerical result. A twofold destination also occurs.

Many of these writes precede interactions receiving two equal arguments scaled by 16384. Exceptions matter: an early write precedes a fourfold-scaled argument interaction producing a 64-bit result; the twofold destination is associated with duplicated 4096-fold arguments; another incoming-byte write precedes duplicated fourfold arguments.

**Explicit zero.** Six subsequent byte writes store zero at destinations derived using an eightfold scale. Dependencies intervene between them. These writes do not establish contiguous clearing, complete-object reset, or reversal of earlier effects.

**Destination-derived byte.** After the six zero writes, one byte write stores the least significant eight bits of its own computed destination. Its following interaction receives two equal 16384-fold-scaled arguments and, in the third position, the full represented eightfold destination value. The stored byte does not preserve that full value.

**Retained derived byte.** A later unsigned 32-bit dependency result establishes a byte equal to the least significant eight bits of eight times that result. Its first destination is sixteen times the result. The following interaction receives two equal arguments scaled by 32768.

This byte remains the value source for numerous later writes and the global assignment. It is not recomputed from each destination. Later destination scales include 65536, 8192, 4096, and eight, applied to different numerical bases.

**Separate extraction.** A subsequent byte write takes bits 19 through 26 from the unsigned result that established the retained derived byte. The preceding selection retains bits through position 28, so ten bits exist before byte-width truncation; only eight are written. This effect does not replace the retained derived byte.

**Three-bit value.** Later byte writes use the highest three bits of a separately retained 32-bit quantity. The retained top byte is reduced to its upper three bits, producing a value from zero through seven.

That three-bit value is reused. Later replacement of the retained top-byte state with its three-bit extraction does not reduce an already extracted value a second time.
