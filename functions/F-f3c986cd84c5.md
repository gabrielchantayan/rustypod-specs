A nonempty slot causes an ordered sequence of dependency calls, a conditional byte update, extraction of a 32-bit field, and delegation to F-2db98b0446c5. The delegated result is returned after a final dependency call.

## Behavior

### 1. Capture the object value

The function first reads the object value from the reference slot and retains that value for the rest of the invocation.

If the captured value is zero, the function returns zero immediately. This path performs no dependency calls and no direct object-field accesses or writes.

The function does not explicitly read the reference slot again. If a dependency later changes the slot, that change does not replace the captured object value used by this invocation.

### 2. Invoke the entry dependency

This call precedes the read of the byte at object offset +1. Consequently, that read observes the value present after F-opaque-01 returns, not necessarily the value present when F-f3c986cd84c5 was entered.

There is no established guarantee that F-opaque-01 preserves the object, reference slot, context-associated memory, or global state.

### 3. Perform the conditional byte update

After F-opaque-01 returns, the function reads one byte at offset +1 of the captured object.

If and only if that byte equals exactly 1:

1. The function writes zero to the byte at object offset +8.
2. It calls **F-opaque-02** with the context value advanced by 28 bytes.

F-opaque-02 is another locally designated external dependency. Its return value is not used.

The write occurs before the call. Thus, subject to the execution environment’s ordinary memory semantics, F-opaque-02 is invoked after the zero has been stored.

If the byte at offset +1 is any value other than 1, neither this direct write nor the F-opaque-02 call occurs. Nonzero values other than 1 do not satisfy the condition. Signed versus unsigned interpretation of a one-byte load does not change whether its value equals 1.

The function does not recheck the condition after the conditional call.

### 4. Capture the four-byte field

- The byte at offset +8 is set to zero before F-opaque-02.

- F-2db98b0446c5 receives the context value, 1056, and the captured object value.

The function does not directly change offset +8 and does not call F-opaque-02. It still captures the four-byte field and continues through F-029f0df8d35a, F-2db98b0446c5, and F-opaque-03.

If F-029f0df8d35a then changes that field to 300, the second argument remains 256 because the field was already captured.

### Delegation returns zero
