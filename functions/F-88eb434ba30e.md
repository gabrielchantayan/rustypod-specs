# F-88eb434ba30e

## Purpose

F-88eb434ba30e derives a one-byte classification from a 16-bit field in caller-supplied storage. It selects the result using four low-order bits with a fixed precedence, then overwrites a neighboring byte in the same storage region.

The established behavior is a priority classification, not a count of set bits or a direct encoding of the input field. When several relevant bits are set, the highest-priority bit determines the result. Bits outside the lowest four positions do not affect the selected value.

The meanings of the flags and output values are unknown. Descriptions such as “status,” “mode,” or “category” would express possible intent, not established domain semantics.

## Behavior

### Classification rule

The source field is interpreted as an unsigned 16-bit quantity. The relevant masks, in descending precedence, are:

| Priority | Mask | Bit position, counting from zero | Output byte |
|---:|---:|---:|---:|
| 1 | 0x0001 | 0 | 5 |
| 2 | 0x0004 | 2 | 1 |
| 3 | 0x0008 | 3 | 2 |
| 4 | 0x0002 | 1 | 3 |
| Default | None of the above set | — | 4 |

The first matching priority wins. In particular, numeric bit order is not the precedence order: bit 2 is considered before bit 3, and both are considered before bit 1.

All results fit exactly in an unsigned byte. No result truncation changes their values. The classification involves bit-mask tests, not addition, subtraction, shifting, or a signed comparison of the source field.

The remaining twelve bits, selected by mask 0xFFF0, are irrelevant to classification. They need not be zero. A source field with only those bits set produces the default result, 4.

### Observable access order

On an ordinary successful execution, the operation has this order:

1. Read the 16-bit source field at offset 28.
2. Select a result from that acquired value.
3. Write the selected byte at offset 30.
4. Return without a value.

There is one explicit source-field read and one explicit destination-byte write in the supplied representation. The classification decisions use the acquired source value; they do not explicitly reread the field between flag tests.

The destination’s previous value is not read. It does not influence the result. The selected value is written even if the destination already contains that value.

The source field is not modified by any explicit write. No other field is explicitly read or written. These statements describe the supplied operation, not physical bus transactions or compiler-level guarantees of atomicity.
