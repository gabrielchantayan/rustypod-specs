## Behavior

### Established predicate

That distance covers 96 consecutive input values:

- The first accepted input is 32.
- The last accepted input is 127.
- The immediately preceding input, 31, is rejected.
- The immediately following input, 128, is rejected.

The lower endpoint is inclusive because subtracting 32 from 32 produces zero, which is below 96. The upper endpoint is inclusive because subtracting 32 from 127 produces 95, which is also below 96. Input 128 produces 96, which fails the strict comparison.
