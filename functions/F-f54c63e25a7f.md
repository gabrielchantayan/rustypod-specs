## Behavior

2. Add 300 to that loaded value.
3. Interpret the resulting value as the address of a function-pointer slot.
4. Read the function pointer held in that slot.
5. Invoke the selected function.
6. Return without an explicit value if the invocation returns normally.

The initial read precedes the dependent slot read, and the slot read precedes invocation. There is no visible loop, alternate branch, retry, second target selection, or post-call verification.
