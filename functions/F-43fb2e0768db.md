# F-43fb2e0768db

## Purpose

F-43fb2e0768db returns a signed adjustment derived from four signed integer values in caller-provided storage.

Two values establish a directed separation. For a nonnegative separation, each complete four-unit interval contributes 32 to the adjustment; any remaining units contribute nothing. A third value supplies an additive correction, and a fourth supplies a subtractive correction.

**Established static behavior:** The supplied definition establishes the input positions, arithmetic grouping, scalar return, and absence of explicit writes or calls.

**Inferred intent:** The calculation resembles a quantized adjustment. Its application, units, and intended operating range are not established.

**Verification status:** Static analysis only. No runtime tests have been performed.

## Behavior

### Separation and interval contribution

The separation is directed from Baseline to Observation. Equal values give zero; an Observation greater than Baseline gives a positive separation.

For nonnegative, representable separations, the interval contribution is:

| Separation | Contribution |
|---:|---:|
| 0–3 | 0 |
| 4–7 | 32 |
| 8–11 | 64 |
| 12–15 | 96 |
| 16–19 | 128 |

The same interval rule continues only while the required arithmetic remains valid.

Quantization applies to the separation, not independently to the two endpoint values. Consequently, moving both endpoints by the same amount preserves the result when their separation and corrections remain unchanged and all intermediate arithmetic remains valid.

The contribution is constant within each interval. Crossing an interval boundary increases it by 32. In particular, a separation of three contributes zero, not 24.

### Negative separation

An Observation below Baseline produces a negative separation.

Interval selection uses a signed right shift by two bit positions. The supplied evidence does not identify the execution environment’s rule for negative operands. Exact negative-separation results therefore remain **documented_only** without that rule.

Under that condition, a separation of −1 contributes −32. Division rounded toward zero would instead select zero and would not satisfy this conditional behavior.

This shift assumption resolves interval selection only. It does not establish wrapping, saturation, or validity of subsequent arithmetic.

### Corrections and grouping

Credit is added to the interval contribution. Debit is then subtracted from that credited contribution.

Within the valid arithmetic domain:

- Increasing Credit by one increases the return value by one.
- Increasing Debit by one decreases the return value by one.
- Negative Credit lowers the result.
- Negative Debit raises the result.
- Equal endpoints eliminate the interval contribution, leaving only the corrections.

The credited contribution is a distinct intermediate value. A later subtraction cannot make an earlier out-of-range addition valid, even if the final unrestricted mathematical total would be representable.

Likewise, an implementation that rearranges the corrections must preserve the defined behavior of the original grouping. This contract does not permit treating a representable final mathematical total as sufficient evidence that all intermediate operations are valid.
