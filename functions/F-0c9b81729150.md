# F-0c9b81729150

## Purpose

F-0c9b81729150 conditionally changes one bit in an indexed record and adjusts a byte-sized counter in the same containing object. The decision depends on a mode argument and the zero-versus-nonzero result of F-dd80959068b2.

The two modes have asymmetric behavior:

- **Zero mode:** a nonzero dependency result permits clearing the selected bit. The counter is then decremented only if its subsequently read value is nonzero.
- **Nonzero mode:** a zero dependency result permits setting the selected bit and incrementing the subsequently read counter.

The function does not establish that the counter equals the number of records whose selected bit is set. In particular, it does not inspect the existing bit before deciding whether to adjust the counter.

The names “record,” “flag,” and “counter” describe the observed layout and operations. Their application-level meanings are inferred, not established.

### 3. Zero mode

When Mode is zero, the function calls F-dd80959068b2 with Base and classifies its result as zero or nonzero.

**If the result is zero:**

- The function returns normally.
- It performs no direct read or write of the selected flag word.
- It performs no direct read or write of the counter.

This does not mean the call is side-effect-free: effects of F-dd80959068b2 remain possible.

**If the result is nonzero:**

1. The function reads the selected 32-bit flag word.
2. It clears bit mask 2 and writes the resulting 32-bit word back.
3. It reads the counter byte at offset 200 from Base.
4. If that byte is zero, it returns without writing the counter.
5. Otherwise, it decrements the byte value and stores the result at the same counter location.

The flag write precedes the counter read. A zero counter does not prevent or undo the flag write.

The existing flag bit does not control the decrement. If the dependency result is nonzero and the counter is nonzero, the counter is decremented even when the selected bit was already clear.

### 4. Nonzero mode

When Mode is nonzero, the function calls F-dd80959068b2 with Base and again classifies its result as zero or nonzero.

**If the result is nonzero:**

- The function returns normally.
- It performs no direct read or write of the selected flag word.
- It performs no direct read or write of the counter.

**If the result is zero:**

1. The function reads the selected 32-bit flag word.
2. It sets bit mask 2 and writes the resulting 32-bit word back.
3. It reads the counter byte at offset 200 from Base.
4. It increments that byte value and stores the result at the same counter location.
5. It returns normally.

There is no visible upper-limit check or saturation branch for the counter.

The existing flag bit does not control the increment. If the dependency result is zero, the counter is incremented even when the selected bit was already set.
