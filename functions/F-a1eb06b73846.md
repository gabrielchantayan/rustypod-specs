# F-a1eb06b73846

## Purpose

Its established local effects, if execution reaches all of them, are eighteen eight-bit writes, one sixteen-bit read, and one signed-integer replacement through an incoming reference. These are individual access events, not a description of final memory contents.

The evidence does not establish an application-level operation such as initialization, decoding, allocation, or validation. It also does not establish successful completion.

This contract separates relationships visible in the supplied representation from execution-model assumptions. Runtime fidelity is **documented_only**. No runtime tests have been performed.

### Late memory observation

This is a late observation, not an entry snapshot. Earlier payload writes or dependency effects can change what it observes.

Write 12 is not established as disjoint from the read region. If they overlap under the applicable storage model, the read follows the write and observes the memory state applicable at the later event. The read region may also overlap the integer-replacement destination.

The evidence fixes the read width at sixteen bits but does not establish byte order, address units, alignment, or an unconditional two-byte layout.

The observed content is not an explicit arithmetic operand of the integer replacement. Its consuming dependency may still affect later execution indirectly.

### Integer replacement and delayed reuse

The replacement is four times the same signed principal result used to determine write 14’s destination. The replacement calculation precedes that payload write.

After write 14, the calculated replacement is stored through the incoming object reference. The following dependency receives the calculated replacement in three equal argument positions.

This is a replacement, not an explicit read-modify-write of the old integer. Although overlapping accesses may observe or modify the same storage, the replacement calculation itself has no direct dependency on the previous integer content.

If write 14 overlaps the referenced integer, the later replacement store may overwrite some or all of that payload write’s effect. The extent depends on the unresolved integer representation and storage layout.

The calculated replacement is also retained for a designated consumer between writes 15 and 16. That consumer receives four times a newly obtained principal result first and the retained replacement second. The delayed second argument is not a fresh read through the reference. Intervening mutation of the referenced storage therefore does not change this represented value relationship.

## Acceptance examples

These are conditional static examples, not observed executions. Each assumes valid preceding execution and an execution model supporting the stated arithmetic, locations, storage, and invocation interfaces.

### Reference value is distinct from referenced content

If the object reference converts numerically to 8, write 1 targets location 2,048, its immediate consumer receives 4,194,304 twice, and the late read starts at location 1,056.

Changing only the initial integer stored through the reference does not directly alter those calculations. It can still affect dependency behavior or an overlapping observation.

### Address and argument scaling are independent

For a designated principal result of 9 at write 2, the destination is 72 and both immediate-consumer arguments are 147,456.

Applying the argument multiplier to destination 72 instead of principal result 9 fails the relationship. Supplying only one copy also fails it.

### Retention is not resampling

An early retained observation of 2 makes write 8 target location 4,096 and makes both immediate-consumer arguments 8,388,608.

The four designated delayed consumers receive 2 second, even if a later auxiliary observation contains 7.

### Overlapping write and read

Suppose write 12 places payload content 60 in the lower-addressed eight-bit unit of the late-read region, and the other unit contains 18 when the read occurs.

Under an illustrative eight-bit-byte, little-endian model, the observation is 4,668. Under the corresponding big-endian model, it is 15,378. Neither layout is established here.

A read performed before write 12 does not satisfy the ordering requirement.

### Stored replacement and retained replacement can diverge

A principal result of 9 at write 14 produces destination 72 and replacement 36. The payload write precedes the replacement store, which precedes delivery of 36 in three argument positions.

If a later dependency stores 99 through the reference, the designated delayed consumer between writes 15 and 16 still receives retained replacement 36 second.

### Opaque content must remain unchanged

If the principal result forwarded between writes 14 and 15 has all thirty-two content bits set, both consuming positions receive that same content.

This establishes neither a signed numerical value nor additional bits in a wider argument channel. Fourfold scaling is not an acceptable replacement.

### Destination representability is insufficient

Under an illustrative signed thirty-two-bit model requiring nonnegative, representable shift results, an early observation of 512 gives write 8 a representable destination of 1,048,576.

Its companion argument would be 2,147,483,648, outside that signed range. Destination representability alone therefore does not establish a valid interaction.

### Interrupted execution has no promised recovery

If F-dep-003 supplies an unusable executable target, graceful handling is not guaranteed.
