# F-622b2cdb7222

## Purpose

F-622b2cdb7222 conditionally updates a 32-bit field in a caller-supplied memory region.

An unsigned 32-bit input is compared with a 32-bit limit stored in that region. If the input is below the limit, the function calls dependency F-870c4fcf7295 with the input and the value 1000, derives a signed scale from another field, and stores a computed result. It returns 0 on this path. Otherwise, it returns 3 without making the dependency call or explicitly updating the destination field.

The field names used below—limit, base, scale source, and destination—describe their roles in this operation. They do not establish application-level meanings, units, or object types.

## Behavior

### 1. Compare the index with the limit

The function obtains the unsigned 32-bit limit from offset +8 and evaluates whether the unsigned index is strictly less than that value.

If the comparison is false:

- The function returns 3.
- It does not call F-870c4fcf7295.
- It performs no explicit destination assignment.
- The base and scale-source values are not needed by this path.

Equality is rejection. The comparison is unsigned, so an index whose highest bit is set is a large nonnegative value, not a negative index.

The limit is not checked again after the comparison. A subsequent change to that field does not, by itself, cause the accepted operation to be reconsidered.

### 2. Obtain the dependency result

If the comparison is true, the function calls F-870c4fcf7295 with two arguments, in this order:

1. The unchanged unsigned index.
2. The integer value 1000.

The dependency’s returned value is used as a signed 32-bit arithmetic operand by this function.

The dependency call completes before evaluation of the destination-assignment expression in the supplied representation. Consequently, the calculation must not be described as using a pre-call snapshot of the base and scale-source fields. Changes made by the dependency may affect the later calculation.

There is no visible inspection of an error indicator, no retry, and no alternate path based on the dependency result.

### 3. Derive the scale

For a stable signed 32-bit scale-source value, the expression derives the quotient obtained by division by 8 with truncation toward zero.

The supplied expression achieves this through a sign-dependent correction followed by a right shift:

- A nonnegative scale source receives no correction.
- A negative scale source receives a correction of 7 before the final shift.

For a stable field, the correction itself does not require a value outside the signed 32-bit range: nonnegative values are unchanged, and negative values are increased by 7 before the final shift.

### 4. Compute and store the result

The intended mathematical relationship of the final expression is:

**destination = derived scale × dependency result + base**

The multiplication precedes the addition as a value dependency. The base contributes as a signed 32-bit value.

The result is written to the four-byte destination field at offset +32. The function then returns 0.

There is no saturation, clamping, explicit overflow detection, or explicit conversion to a wider accumulator. The supplied representation uses signed 32-bit operands for the final multiplication and addition. If either operation exceeds the signed 32-bit range, the evidence does not establish a portable result. In particular, wraparound must not be promoted to a guaranteed contract without additional execution-level evidence.

The representation does not establish the relative physical read order of the base and scale-source fields within the assignment expression. It does establish that the explicit destination assignment follows the dependency call and depends on the calculated result.
