# F-b5026865a49a

The selected location is at displacement fourteen from the supplied base. A successful call returns a value from zero through thirty-one, inclusive. It does not modify the selected storage to remove the other bits.

## Behavior

This is truncation by bit selection, not saturation. Values above thirty-one are not necessarily returned as thirty-one. For example, a selected byte whose numeric value is thirty-two produces zero because its only set bit lies outside the retained field.

The operation is also not validation. Nonzero upper bits do not select an error path or make the value unacceptable to this function. They simply do not affect its result.

A single-byte field does not require a multi-byte endianness interpretation. No ordering of neighboring bytes is involved in the established extraction.
