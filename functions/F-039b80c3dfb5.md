The traversal body performs no represented operation. In particular, the traversal does not:

- Write an element or metadata field.

The stopping condition is equality, not a less-than comparison. A boundary below the initial value therefore does not create an empty range by itself.

A positive distance that is not a multiple of eight is not reached by that sequence.
