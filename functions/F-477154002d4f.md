# F-477154002d4f

## Purpose

F-477154002d4f represents a sequence of indirect calls interleaved with byte and 32-bit memory accesses. Addresses depend on explicit arguments, additional entry state, dependency results, and bytes read from memory. Some stores use absolute addresses 0x0D and 0x11.

No application-level purpose is established. The representation does not establish object construction, allocation, device control, or a recognizable protocol.

The supplied material warns of invalid instruction data and ends at an invalid-instruction boundary. This contract describes the represented path, not a verified executable path. Its distinctions are:

## Acceptance examples

These are conditional deductions from static evidence, not executed tests. Each assumes the required preceding calls and accesses complete.

1. **Third-argument widths.** With third argument 0x123456AB, both byte stores at doubled entry value + 0x0D carry 0xAB. The word store at initial base + 0x14 carries 0x123456AB.

2. **Fourth-argument truncation.** A fourth argument of 0x00000081 produces byte 0x02 at small index + 7. This value does not require signed overflow.

3. **Maximum small index.** A scaling result with its low 27 bits all set produces small index 1023. The fourth-argument byte store targets address 1030. The later small-index byte store carries 0xFF.

4. **Changing selector source.** If the first scaled base + 1 read returns 3 and the second returns 9, the small-index byte targets 0x14, while the later zero targets 0x1A. The selector base is 18.

5. **Overlapping selector stores.** With selector zero, the retained-byte store at selector base + 0x0D targets absolute 0x0D. The separate 0xC0 store follows at that same address.

6. **Byte versus word retention.** With retained result 0x12345678, the retained byte is 0xCF. The word store at high-result index × 4 + 0x14 carries 0x02468ACF, not merely 0xCF.

7. **Final field truncation.** With final scaling result 0x3FF00000, masking and shifting right by 20 produces 1023. The second loaded-base-selected byte store carries 0xFF, not a wider value.

8. **Fresh final selection.** If the two reads at final shifted result × 0x400 + 1 return 4 and 7, the zero stores target 0x15 and 0x18 respectively.

9. **Interrupted execution.** If F-U10.e does not return, its subsequent word store and all later operations are not required to occur. Earlier effects have no established rollback.
