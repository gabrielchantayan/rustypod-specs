# F-93df79ad66b3

## Purpose

F-93df79ad66b3 selects between an early-return path and a longer sequence of dependency calls. The longer sequence obtains local data, invokes a preparation-like operation, forwards a dependency result into a construction-like operation, and, if that operation returns nonzero, writes two caller-provided outputs before a final association-like call.

The routine returns a 32-bit status. A nonzero result can originate from a preliminary check without entering the longer sequence; it does not necessarily indicate a failed construction attempt.

Resource preparation, allocation, construction, registration, initialization, and cleanup are **inferred roles**, not established dependency contracts. The supplied representation establishes call arguments, branch conditions, direct accesses, and ordering. It does not establish what resources the dependencies create, modify, own, or release.

This contract describes static evidence only. No runtime tests have been performed.

## Behavior

Mode is tested only for zero versus nonzero at this decision.

When mode is nonzero, both preliminary operations are skipped. The first call on the longer path is F-576ea5ba1d23 with the first local region’s address.

When mode is zero, the routine invokes the indirect operation selected at dispatch offset `0x50`, passing object and selector.

- If that operation returns nonzero, the longer path is selected. Its result is not directly returned.
- If it returns zero, F-9dbfb3425f54 is called with object, selector, and the 32-bit constant `1`.

For F-9dbfb3425f54:

- Zero selects the longer path.
- Nonzero is returned immediately.

That immediate return precedes both local-region entry calls, F-8157a180d901, and both direct output stores.

## Acceptance examples

These are conditional static acceptance cases, not executed tests. They assume the dependencies return normally where required. Claims about retained memory contents additionally require that dependencies do not overwrite that memory.

1. **Nonzero mode bypasses both checks.**  
   With mode `−1`, neither the indirect operation nor F-9dbfb3425f54 is invoked. F-576ea5ba1d23 is the first call on the longer path. This establishes an address-taking call, not successful resource initialization.

2. **A preliminary status can return immediately.**  
   With mode zero, indirect result zero, and F-9dbfb3425f54 result `12`, the routine returns `12`. Neither local-region entry call, F-8157a180d901, nor either direct output store occurs.

3. **A nonzero indirect result selects further work.**  
   With mode zero and indirect result `12`, F-9dbfb3425f54 is skipped. The routine proceeds to F-576ea5ba1d23 rather than returning `12` directly.

4. **Acquisition-like failure preserves its status.**  
   If F-8748c10b2aa2 returns `−3`, the unidentified first-region dependency is called and the routine returns `−3`. Neither second-region dependency is called. No resource release is implied by this call sequence.

5. **Preparation-like failures are normalized.**  
   Results `1` and `−8` from F-27385576fa62 both cause calls to F-d9c6fcdd6df6 and then the unidentified first-region dependency, followed by return `7`.

6. **The decrement is not saturated.**  
   If F-8810f53aaa0b returns zero, the fourth explicit argument to F-27385576fa62 is `−1`. Signed-minimum behavior remains unresolved.

7. **Zero forwarding is distinct from the failure branch.**  
   If F-8157a180d901 returns zero, F-d0638bfaa856 is still called with zero as its first explicit argument. A zero result from the latter selects return `25`. This does not establish either dependency’s allocation-failure convention.

8. **The constant’s value is established; its unit is not.**  
   F-8157a180d901 receives `0x108`, equivalent to 264. Interpreting that as a 264-byte request requires additional dependency evidence.

9. **Successful publication has an observable order.**  
   If the array’s first word is `0x12345678` when read and F-41a7e6549fb0 returns `42`, the value store publishes `0x12345678` before the identifier store publishes `42`. F-7606ddc32527 is called afterward.

10. **Aliased outputs receive the identifier last.**  
    Under the preceding conditions, if both outputs address the same word, that word contains `42` immediately after the identifier store. Later dependency effects can still change it.
