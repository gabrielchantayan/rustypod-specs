Those pre-call writes are not equivalent to unconditional final-state guarantees. The dependency may modify accessible memory, including destination storage if it can reach it through shared state or aliasing. This function does not restore offsets 4 or 8 after the call.

Consequently, after normal completion:

- Offset 0 contains the dependency result written by this function.
- Offsets 4 and 8 retain their pre-call values only if the dependency and other actors have not changed them.
- The returned pointer has the same value as the supplied destination pointer.
