## Behavior

### Matching is the controlling condition

The guard compares the **selected value**, not the original first input, with the second input.

Consequently, distinct original inputs can select the no-delegation path: the second input need only equal the first input increased by 76. Conversely, equal original inputs do not ordinarily suppress delegation, because the comparison uses the displaced value.

A match guarantees both of the following at this function’s boundary:

- No explicit four-byte payload read occurs.
- F-151ab4bfe553 is not invoked.

Normal completion then returns the selected value. The supplied body establishes no other explicit memory access or external state mutation on this path.
