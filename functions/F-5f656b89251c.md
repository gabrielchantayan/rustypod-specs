## Acceptance examples

These are conditional static consequences, not executed tests. Each assumes execution reaches the relevant operations.

1. **Input selector.** With second input 0x400, both input-derived selector reads use address 3. A selector byte of 0x7F directs the clear to 0x90. If an intervening dependency changes the selector byte, the second clear uses the newly read value.

2. **Selector range.** A selector byte of 0xFF directs a byte store to 0x110, independently of the selector’s own address.

3. **Truncation.** The low 30 bits of 0x3FF00000 shifted right by 20 produce 0x3FF. A byte store of that field writes 0xFF.

4. **Late byte chain.** If the first chain byte is 0x20, the second chain read uses address 0x21. The third chain read still uses address 1. If it returns 0xAB, its later word-slot store writes 0x000000AB, even if intervening calls change address 1.

5. **Fresh selectors.** If a dependency changes address 1 between two zero-derived selector updates, their destinations may differ. Constant selector addresses do not imply constant contents.

6. **A reset is not preservation.** If A changes after its reset, the first later reread consumes the changed value. The late byte chain, its word-slot store, and the offset-9 stores precede that reread.

7. **Retained snapshot.** If the pre-publication snapshot is 0x20, the immediate clear targets 0x31. After B’s first publication, the corresponding word read uses 0x94 and its low byte is stored at 0x21, regardless of subsequent changes to address 1.

8. **Repeated base update.** If a dependency changes the word at a retained base plus 0x74 between the two updates, the second byte store consumes the later word.

9. **Conditional partial finalization.** Assume a fault model that preserves completed accesses, stops forward execution at a faulting halfword clear, and performs no recovery that changes earlier effects. If the external byte clear and B replacement complete before that fault, those effects remain under this model, and the final address-zero call has not occurred. Without these fault-model assumptions, persistence and subsequent control flow are **documented_only**.
