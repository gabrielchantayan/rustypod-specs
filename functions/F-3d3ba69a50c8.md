# F-3d3ba69a50c8

The observable result is one of:

- The 32-bit value `0x00000050` when the first dependency returns a nonzero upper half.
- The 32-bit value `0x00000002` when the first dependency returns a zero upper half and the subsequent shared-state check observes zero.
- The 32-bit result supplied by F-3028a6a8124a when dispatch occurs.

These are established branch outcomes, not established meanings for particular error codes. The available evidence does not identify the operation’s domain, the interpretation of the shared state, or the semantics of either dependency.

### Nonzero upper portion

If the upper portion is nonzero, the function returns `0x00000050`.

On this path, the visible function:

- Does not read the shared cell.
- Does not read the descriptor’s second word.
- Does not call F-3028a6a8124a.
- Does not expose the lower portion through its return value.

The upper portion is tested through a signed 32-bit interpretation, but only equality to zero matters. Every nonzero 32-bit pattern takes this branch, including patterns whose signed interpretation is negative.

This branch does not undo or constrain effects already performed by F-d7be9cfb4000.

### Zero upper portion and shared-state check

If this read observes zero, the function returns `0x00000002`. It does not read the descriptor’s second word or call F-3028a6a8124a on this path.

The shared-cell read occurs after F-d7be9cfb4000 returns. Consequently, the checked value is not established to be the value that existed at function entry. F-d7be9cfb4000 may affect it; no preservation guarantee is available.
