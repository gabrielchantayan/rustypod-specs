# F-51e8a8416c77

## Purpose

F-51e8a8416c77 modifies memory at addresses derived from explicit inputs, incoming machine state, and externally stored values. After those modifications, it transfers control through an incoming target, supplying one derived 32-bit argument.

No application-level purpose is established. The evidence does not support classifying the operation as initialization, decoding, allocation, validation, or conventional table dispatch.

The contract is principally about access widths, temporal ordering, retained values, and address dependencies. It does not promise a particular final memory image: destinations can overlap, external values can change, and the terminal dependency has no established preservation guarantees.

The supplied representation explicitly reports unreliable recovery of the terminal control flow. The behavior below describes the visible static representation, not a verified machine-level calling convention.

## Behavior

### Widths, layout, and arithmetic limits

The visible accesses are 8-bit byte writes, 16-bit halfword writes, and 32-bit word reads or writes. Narrow stores use the low-order portion of their supplied values as represented. The byte derived from negating a narrowed character additionally depends on the character-conversion model; on ordinary 8-bit implementations its stored bits are the negative of the early offset modulo 256.

No aggregate layout, buffer boundary, or object size is established. Numeric offsets denote the represented address displacements; the incomplete pointer and target model limits stronger claims about their machine-level interpretation.

Endianness is unspecified. It does not change the numerical value supplied to a complete halfword or word store, but it changes the placement of its bytes and the effects of partial overlap.

Arithmetic must not be given a blanket wrapping interpretation:

- The explicit integer inputs and several retained external values participate in signed 32-bit arithmetic.
- The two squares are represented as signed multiplications.
- Some offset expressions combine a signed sum with an unsigned comparison result.
- The late offset is retained as an unsigned 32-bit value.
- Converting an unsigned result back into a signed destination can require implementation-specific interpretation when the result is outside the signed range.
- A signed addition or multiplication can exceed its represented range before a later unsigned operation occurs.

The formulas described below therefore establish dependencies, not universal behavior for overflowing inputs. A particular 32-bit wrapping machine interpretation is an additional environment assumption.

### Initial memory effect and early addressing

The first observable operation is a halfword write. Its destination is the sum of the original second and third inputs; its value is the low 16 bits of the original third input. This precedes every external-cell read.

Cells A and B are then read, in that order. Their early values are retained. The low 16 bits of the incoming base are also captured and written at a displacement of 68 from that base.

The original third input is subsequently squared. This **input square** replaces the original third input’s role in later calculations; it does not affect the already completed initial write.

An **early offset** is derived from the first A value, an increment of 70, and a comparison contribution. That contribution is one when the incoming target is represented as less than or equal to the incoming base, and zero otherwise. The evidence does not establish a portable signed or unsigned numerical interpretation of this pointer comparison.

Two byte writes follow. One places B’s retained low byte at twice the first A value. The other uses negative twice the early offset as its destination and the negated narrowed early offset as its byte value.

### Square-derived memory effects

Cells C and D are read after those two byte writes, in that order. C is retained as an unsigned 32-bit value. D is retained for both addressing and squaring.

The captured base halfword is then written again at base displacement 68. This is a separate observable write, not a redundant effect that the contract permits removing. An intervening write may have overlapped the destination, or the destination may expose individual write events.

An **adjusted square** is derived from the input square plus 65, with an additional one exactly when the early offset equals zero. The zero condition concerns the derived early offset, not the original third input.

A byte containing the low eight bits of the input square is written at the sum of the input square and the retained D value. Cell E is read after that byte write. The retained D value is then squared to form the **external square**.

The following memory effects occur in this order:

- The external square’s low halfword is written at the sum of the adjusted square and the external square.
- The complete adjusted-square word is written at the sum of retained E and the adjusted square.
- The captured base halfword is written at the sum of the input square and the external square.
- The external square’s low halfword is written at the incoming base displaced by the external square.

These effects use the retained D and E values. Changes to their external cells after their reads do not replace those retained values.

### Late snapshots and writes

After the square-derived writes, the external read order is F, a new read of A, and a first read of G. Those three values are retained.

G is then read **again** to obtain the address contribution for a byte write. The destination is twice this second G value; the stored byte comes from retained C.

The distinction between the two G reads is material. The first G value remains the source for the later offset, word-write destination, and final halfword write. Only the second G value determines this byte-write destination. With stable ordinary memory the two values coincide; that coincidence is not a replacement for the two-read contract.

Next, the fixed halfword value 78 is written at twice the later A value.

H is read for the first time and retained for the final argument. A **late offset** is formed from the first retained G value plus 78, with an additional one when the incoming threshold is less than or equal to retained C. This comparison is unsigned and 32-bit; equality includes the increment.

H is then read again. A byte containing the low eight bits of the late offset is written at the sum of this second H value and the late offset. The first H value remains reserved for the final argument.

Two further writes complete the direct memory effects:

- The retained F word is written at twice the **first** G value.
- The low halfword of the first G value is written at the sum of the fourth input and that first G value.

The late word write and the earlier C-derived byte write share a destination only if doubling the first and second G values produces the same address. Stable equal G readings are sufficient for that equality, but equality is not established unconditionally.

### Terminal transfer

After all direct writes, control is transferred through D-01. Its explicit argument is the 32-bit bitwise OR of the late offset and the **first** H value.

The recovered representation shows a return after this transfer, with no further explicit operation. Because the evidence warns that an indirect jump was represented as a call, an ordinary call-and-return sequence is not established.

## Side effects

The visible body contains **15 direct writes**:

- **Five byte writes.**
- **Eight halfword writes.**
- **Two word writes.**

It also contains **11 explicit external-cell reads**. Their order is:

**A, B, C, D, E, F, A, G, G, H, H.**

The repeated reads of A, G, and H have distinct consumers. Implementations of this contract must not collapse them into a single snapshot without an additional environmental guarantee that makes such substitution observationally equivalent.

The direct destinations have no established disjointness. Writes can overlap earlier destinations, external cells, executable storage, or other process state. Consequently:

- A read observes its cell at its own position in the sequence.
- Retained values remain distinct from later readings of their source.
- A later complete write determines the overlapping bytes only until another write or dependency modifies them.
- An overwritten write still belongs to the observable history.
- Final memory cannot generally be obtained by independently evaluating disjoint destinations.

No synchronization or atomicity guarantee is established. Ordinary memory, device memory, asynchronously changing storage, and faulting destinations can expose different consequences; the evidence does not identify which environment applies.

## Acceptance examples

These examples are conditional static consequences, not observed executions. Each assumes that the calculations and accesses concerned are valid in the selected environment. Non-overlap, stable storage, and dependency return are assumed only where explicitly needed.

### Original input versus its square

With second input 4096 and third input 3, the first write supplies halfword value 3 at address 4099. The later input square is 9.

This example requires an environment permitting that halfword access at 4099. It does not assert that unaligned accesses are universally valid.

### Early comparison and byte narrowing

With the first A value equal to 100, a false target-to-base comparison gives early offset 170; a true comparison gives 171.

Under ordinary 8-bit narrowing semantics, the corresponding negative-offset bytes are 86 and 85. Their destinations are numerically −340 and −342 under an address model admitting those calculations. Neither address is thereby established as accessible.

### Zero-offset adjustment

If the input square is 9, an early offset of zero gives adjusted square 75. A nonzero early offset gives 74.

The extra increment must follow the early-offset equality condition, even when the original third input is nonzero.

### Unsigned comparison boundary

With the first G value equal to 1000 and the incoming threshold equal to retained C, the late offset is 1079.

If the incoming threshold is 2,147,483,648 and retained C is 1, the unsigned comparison is false and the late offset is 1078. Treating the threshold as a negative signed number would produce the wrong branch.

### Distinct G readings

Suppose the first G read yields 1000 and the second yields 2000, through an environment capable of changing the cell between reads.

The C-derived byte is written at address 4000. The later F word is written at address 2000. The late offset and final halfword destination still use 1000.

An explanation that unconditionally makes the word overwrite that earlier byte fails this case.

### Stable G and overlapping widths

If both G readings yield 1000, the C-derived byte and later F word both begin at address 2000.

With ordinary memory, a completed word write, and no subsequent overlapping modification, the resulting four bytes reflect F in the environment’s byte order. Both write events remain part of the history.

### Distinct H readings

If the first H read yields 4096 and the second yields 8192, the late byte destination is 8192 plus the late offset. D-01’s argument instead uses 4096 OR the late offset.

Using either H snapshot for both purposes violates the represented dependencies.
