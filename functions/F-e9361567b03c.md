### Widths and arithmetic

The representation distinguishes:

- Thirty-two-bit reads, writes, argument words, and address calculations.

A byte read used as an address component is zero-extended. A byte write retains only the low eight bits of its supplied value. Converting a 32-bit word to a byte does not mean reading the first byte of that word from memory.

This is an architectural interpretation of the represented operations, not an assertion that every displayed signed expression has defined language-level overflow behavior.

## Acceptance examples

These examples are conditional static expectations, not executed tests.

1. **Entry payload narrowing.** If the entry payload is `0xABCDEF00` and the first selected byte is 5, the first byte write targets address 22 and stores `0xAF`, provided the preceding calls return and the access is valid.

2. **Fresh byte selection.** If the first entry-derived byte read returns 7 and an intervening dependency changes that location to 9, the corresponding zero writes target addresses 24 and 26. Reusing 7 would violate the represented read order.

3. **Numeric word narrowing.** If a captured offset-116 word is `0x12345678`, its associated offset-one byte write stores `0x78`. That does not depend on selecting a particular byte address within the original word.

4. **Masked index boundary.** If the first index is `0xFFFFFFFF`, its masked index is `0x3FFFFFFF`, and the retained right-shifted value is `0x0FFFFFFF`. The earlier scaled store still derives from the unmasked first index.

5. **Small-base bound.** If the selected byte is 255, the small base is 510. Its offset-13 byte store targets address 523; its offset-36 word store starts at address 546.

6. **Partial execution.** If a dependency fails after the direct write of 192 to address 13, that write has already occurred. No restoration or later store is guaranteed.

7. **Endpoint.** If all represented calls return and accesses succeed, the supplied path reaches the invalid-instruction boundary. Normal return is not an established acceptance condition.
