## Acceptance examples

These examples are conditional static deductions, not executed tests.

1. **Distinct consecutive transfers.** If execution reaches T-08 and T-09 and their common payload is 37, both use selectors (0, 3, 7) and payload 37. T-08 consumes incoming operands 6 and 15; T-09 consumes 15 and 15. Equal payloads do not justify merging them.

2. **Distinct zero transfers.** T-14 uses selectors (0, 7, 7) with operands 9 and 15. T-15 uses (0, 0, 7) with operands 15 and 15. Both payloads are zero, independently of dependency return values.

3. **Conditional zero collapse.** Under truncating word shifts, T-11’s payload is zero for every U-10 result. Its selectors remain (0, 5, 7), and its incoming operands remain 5 and 15.

4. **Masked argument boundary.** If U-04’s bottom 18 low-word bits are all set, the masked four-argument call receives 4,194,288 as its third argument. Higher bits cannot affect that argument.

5. **Signed-sensitive loss.** If U-08 returns only bit 26 set, the left-5/right-5 transformation produces −67,108,864 under arithmetic-right-shift semantics, not +67,108,864.

6. **Terminal address boundaries.** U-15 top-twelve-bit values of 0, 1, and 4,095 produce addresses 0, 1, and 5,118 respectively. These are attempted destinations, not guaranteed writable addresses.

7. **Discarded terminal bits.** Changing U-15’s bottom 52 bits while retaining its top twelve bits leaves the terminal destination unchanged. Earlier calls can still observe changed low-word values.

8. **Interrupted execution.** If F-0e02e4c13579 never returns, later represented operations are not reached. If the terminal write faults, reaching the subsequent bad-instruction marker is not required.
