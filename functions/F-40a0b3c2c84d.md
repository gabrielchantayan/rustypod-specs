## Acceptance examples

These are conditional static acceptance criteria, not executed tests. Arithmetic examples assume the 32-bit bitvector model, valid accesses, and returning dependencies.

1. **Captured initial selector.** With initial selector 7 and entry byte 171, the first write stores byte 171 at address 24. F-A06 later receives selector argument 7 even if a dependency changes the original selector location.

2. **Zero-store selector is still read.** If the third-input-derived address contains selector 12, the post-F-A09 access reads that byte and writes zero at address 29. Replacing this operation with a zero write to an independently chosen address would not preserve the behavior.

3. **Input truncation.** For fourth input `0x00400001`, both F-A08 arguments are `0x00000400` under the conditional arithmetic model.

4. **Pair halves remain distinct.** If F-B14 supplies high half 3 and low half 1, the immediate zero-word store targets address 32. The later Phase C scaled store writes `0x04000000` at `0x10000014`.

5. **Masked extraction.** For pair-low `0xFFFFFFFF`, Phase D’s extracted word is `0x000FFFFF`, not a value retaining the original top three bits.

6. **Independent word reads.** If Phase E’s two source reads yield different values, F-E01’s first and third arguments reflect their respective reads and transformations. The evidence does not select which read happens first.

7. **Final byte truncation.** For final source word `0xABCDEF01`, Phase I writes byte `0x04`. Phase J writes byte `0xBC`: the mask and right shift produce `0x2BC`, which the byte write truncates.

8. **Separate selector destinations.** If Phase I reads selector 5 and Phase J reads selector 9, their stores target addresses 22 and 26. The second read cannot be replaced by the first captured selector.

9. **Full-path accounting.** If all operations complete, the trace contains five selector reads, including the zero-store selector read and both anchor-derived reads. It ends at the invalid-instruction marker, not an established success return.
