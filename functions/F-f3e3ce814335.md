## Acceptance examples

These are conditional static examples, not executed tests.

1. **Initial scaling.** If A is `3`, the first word destination is `0x20`. If B is `5`, both later stores carrying `B << 2` write `20`.

2. **Unsigned halving.** If P is `7`, the store indexed by `P >> 1` targets `0x20`, while the subsequent word read targets `0x1b`. The latter uses P, not its halved value; its alignment is not guaranteed.

3. **Field extraction.** If Q is `0xffc00000`, H is `1023`. If G₁ is `0xffffffff`, J is `511`, and the later word store of `J >> 23` writes zero.

4. **Selector truncation.** If L is `0x301` and the byte read at address `1` is `0x20`, the byte store writes `0x01` at `0x31`.

5. **Repeated selector reads.** If one G-C read yields `0x20` and a later read yields `0x40`, the corresponding zero-byte stores target `0x31` and `0x51`. The earlier selector is not reused for the later read.

6. **Retained base.** If R is `0x40` and `W(0xb4)` is `0x123456ab`, the subsequent copy writes byte `0xab` at `0x41`, regardless of a later change to G-C.

7. **Repeated word reads.** If the two reads at `V + 0x74` observe words ending in `0xaa` and `0xbb`, the two writes at `V + 1` write those bytes in that order.

8. **Partial failure.** If an indirect call does not return after an earlier zero-word store, later accesses are not reached. No restoration of the earlier word is specified.

9. **Terminal publication.** If execution reaches the end, the byte clear through AP precedes the final G-B write, which precedes the halfword clear and zero-address call. A fault at that final call does not imply those writes were undone.
