## Side effects

On a path that reaches the terminal boundary with all preceding operations completing, the representation contains:

- Four selector-byte reads.
- Four one-byte writes.

The first three selector reads use the same calculated address but occur at different times. They must be treated as distinct observations. Dependencies can change the value between reads.

The fourth selector address is derived from U rather than R. It may equal the earlier selector address, a write destination, or some other address; no disjointness guarantee is present.

The write destinations may also coincide. If multiple writes address the same ordinary memory byte, later writes overwrite earlier ones, subject to intervening dependency effects.
