A byte store retains only the low eight bits of its value. A 32-bit read followed by a byte store is not a four-byte copy. A zero halfword store affects two bytes, subject to target memory semantics.

Unsigned right shifts are logical. Masks restrict the participating bits before extraction. Under a 32-bit bit-vector interpretation, shifting left by 31 retains only the original bit zero, moved into bit 31.

Unsigned calculations have their displayed 32-bit width. Signed multiplication and left shifts require additional execution semantics before overflow cases can be assigned behavior. Address formulas below are not permission to substitute unbounded arithmetic or assume a particular pointer width.
