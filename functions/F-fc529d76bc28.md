### Terminal memory write

The final address is derived from one late 64-bit call result. Define its **address selector** as its upper twelve bits, interpreted as an unsigned integer from 0 through 4095.

The destination is:

**address selector + floor(address selector / 4).**

The extraction is width-sensitive. The representation first shifts the unsigned 64-bit result right by forty-one, leaving at most twenty-three bits. Its later signed right shift by eleven therefore operates on a nonnegative value. That signed shift does not introduce a negative address component.

Consequences:

- The destination range is **0 through 5118 inclusive**.
- The destination is an absolute computed address in the representation, not a visible offset from an allocation or caller buffer.
- The mapping is not a fixed-stride array mapping.
- Some destinations are odd; two-byte alignment is not guaranteed.

The address-controlling result is produced before the write. Its lower word is first passed to another dependency. Further calls follow, including a two-argument call with a zero-derived second argument and a final no-argument call. All of those calls precede the explicit write.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Input forwarding.** Given an explicit input of 0x12345678, valid entry context, and a reachable first target, the first call receives 0x12345678 unchanged. No preceding input validation is represented.

2. **Discarded incoming bits.** Under the stated 32-bit model, successive left shifts by sixteen, nine, and twenty produce zero for every incoming word. F-a574095572d7 receives zero, not an unbounded-integer shift result.

3. **Eighteen-bit extraction.** If the word used for the eighteen-bit masked argument is 0xFFFFFFFF, that argument is 0x003FFFF0. The other three arguments at that call site are zero.

4. **Arithmetic shift distinction.** If the word subjected to left-five/right-five processing is 0x04000000, the left shift produces 0x80000000 and the arithmetic right shift produces 0xFC000000. An implementation treating the pair as an identity would not match this conditional machine interpretation.

5. **Unresolved second argument.** At a call with zero first, third, and fourth arguments, the second argument must not be asserted to be zero merely because its value comes from an unresolved secondary-register output.

6. **Address boundaries.** Address selectors of 0 and 4095 produce destinations 0 and 5118, respectively. Both cases still require every intervening operation to complete and the destination write to be permitted.

7. **Spacing and alignment.** Selectors of 3 and 4 produce destinations 3 and 5. Neither address is two-byte aligned. The representation supplies no alignment correction.

8. **Address equivalence is not effect equivalence.** Two controlling results with equal upper twelve bits produce equal destinations. Their lower words can differ and are passed to an intervening dependency, so equal destinations do not imply equal overall side effects.

9. **Write width.** A permitted terminal write stores the 16-bit value 0x00CD. Byte order is platform-dependent. The explicit operation does not request a wider store, although dependencies may independently modify surrounding memory.

10. **Interrupted path.** If any preceding dependency never returns, the final write is not reached along the represented path. No compensating action is visible.
