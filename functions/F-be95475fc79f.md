# F-be95475fc79f

## Purpose

The function checks only whether the index exceeds 2. An index above that threshold causes a call to F-a817d8d58c10 before any selected-word read. A supplied annotation describes that dependency as non-returning, but its implementation is unavailable.

This is not a general bounds-checked accessor. The visible behavior does not reject negative indices, check an allocation length, validate the base address, or establish that the selected field is readable.
