# F-3f358d6f0679

## Purpose

F-3f358d6f0679 requests a state address from F-7fba0909c452, then conditionally updates one of two locations relative to that address.

Two distinguished input values select a one-byte state assignment. Every other input selects a conditional initialization of the leading integer field. A null address causes the function to return without directly accessing state.

These operations are established by the supplied static representation. The semantic meanings of the input values and state fields are unknown. Terms such as “mode,” “enabled,” and “error” would imply behavior not established by the evidence and are not part of this contract.

## Behavior

### Dependency call and null handling

Every invocation first calls F-7fba0909c452 exactly once.

The call occurs before the represented input comparisons and before any direct state-field access. No input value bypasses it.

If the returned address is null, the function returns immediately. In this case, it performs no direct read or write at either documented state location. This does not imply that the dependency call itself had no side effects.

If the result is nonnull, the function retains that address for the selected access. It does not obtain another address or make another visible dependency call.

### Distinguished input `0x1D00`

For input `0x1D00`, the function writes the eight-bit value zero to offset `0x9EC` from the returned address, then returns.

It does not first inspect the destination byte. The assignment is represented even if that byte already contains zero.

The function does not directly read or write the leading 32-bit field on this path. In particular, it does not initialize a zero leading field as an additional action.

### Distinguished input `0x1D01`

For input `0x1D01`, the function writes the eight-bit value one to offset `0x9EC` from the returned address, then returns.

It does not first inspect the destination byte. The assignment is represented even if that byte already contains one.

As with `0x1D00`, this path does not directly read or write the leading 32-bit field.

### Every other input

For any input unequal to both distinguished values, the function reads the 32-bit integer at offset zero.

If the observed value is zero, it writes the 32-bit value `0x500`, decimal 1280, to that same location. It then returns.

If the observed value is nonzero, it returns without a direct state write. All nonzero values have the same outcome; there is no separate treatment for negative values or particular bit patterns.

This path does not directly read or write the byte at offset `0x9EC`.

### Widths and arithmetic

The input undergoes equality comparisons only. There is no input-dependent arithmetic or computed selector transformation.

The distant-field displacement is fixed. The supplied representation contains no bounds check, allocation-size check, or check for pointer-address overflow.
