# F-3e52d18dd87e

## Purpose

F-3e52d18dd87e recognizes three exact 32-bit request discriminators and selects one of three operations:

- Pass a local 32-bit temporary’s address, a request-supplied value, and count `3` to an external dependency; then invoke an indirect object method with three values extracted from the temporary.
- Load a 32-bit value through a request-supplied address and pass it, with the object reference, to F-31e8feff54e1.
- Execute a flag-gated dependency sequence in which a captured 32-bit predicate result of zero enables a final pair of calls.

The normal Boolean return reports **recognition**, not successful execution of a requested action. A recognized discriminator returns true on normal completion even when a gate suppresses all subsequent calls.

The recognized values are exactly `0x00004E00`, `0x4E000007`, and `0x4E000008`. Every other 32-bit discriminator returns false.

The external call in the first branch does not, by itself, establish that any bytes are copied or that the temporary changes. Source-byte forwarding and partial overwrite are conditional consequences of conventional copy semantics, not unconditional guarantees of this function.

## Behavior

### Common entry and dispatch

The function reads the request’s 32-bit discriminator and initializes its local 32-bit temporary from the fourth input before executing a selected branch.

The discriminator is captured once. No later discriminator read or redispatch appears. A dependency’s mutation of request storage therefore does not change the already-selected branch through any operation shown in this body.

Comparisons are exact 32-bit equality comparisons. There are no ranges, masks, signed ordering tests, or partial matches in discriminator selection.

The third input contributes to no direct read, branch decision, or constructed dependency argument shown.

### Discriminator `0x00004E00`: temporary-based indirect invocation

The established sequence is:

1. Read the 32-bit payload field at request offset `0x0C`.
2. Invoke F-a00000000001 with the local temporary’s address, that payload value, and integer count `3`.
3. After the call returns, resolve an indirect callable through the object’s first word and the table entry at byte offset `0x100`.
4. Invoke F-a00000000002, the opaque label for that indirect call site, with the original object reference and three values extracted from the temporary.
5. Return true if execution completes normally.

The three extracted values are:

- The temporary’s 32-bit value masked with `0xFF`, yielding a value from `0` through `255`.
- Its one-byte portion at byte offset `1`.
- Its one-byte portion at byte offset `2`.

The source representation establishes these selections. It does not independently establish the complete calling convention, argument promotion rules, or target byte order.

F-a00000000001 receives a writable local address, but its implementation is unavailable. The contract therefore does **not** guarantee that it copies three bytes, writes anything, preserves the rest of the temporary, or confines its effects to that storage. Its return value is ignored.

Under the explicit additional assumptions of a conventional three-byte copy and little-endian representation, source bytes `a`, `b`, and `c` at ascending addresses become the three indirect-method values in that order. Under those assumptions, the temporary’s highest byte retains its initialization from the fourth input and is not forwarded. Without those assumptions, neither the source-byte correspondence nor the partial-overwrite description is established.

Method resolution follows F-a00000000001. An implementation must not substitute a method-table value captured before that dependency: the dependency is not known to preserve object or table state.

The indirect method’s return value is also ignored. Normal completion returns true regardless of either dependency’s returned value.

### Discriminator `0x4E000007`: indirect 32-bit payload forwarding

This branch:

1. Reads the 32-bit address-bearing payload field at request offset `0x0C`.
2. Reads one 32-bit value at the address represented by that field.
3. Calls F-31e8feff54e1 with the original object reference and the loaded 32-bit value.
4. Returns true on normal completion.

The forwarded value is the dereferenced payload, not the payload field itself. No content validation, transformation, or interpretation of that value appears.

The body does not directly inspect object fields to prepare this call. Whether F-31e8feff54e1 requires a non-null object, interprets the value as an address, or changes ownership is unknown.

### Discriminator `0x4E000008`: two-gate conditional sequence

This discriminator is recognized regardless of either gate’s outcome.

The first gate tests the low eight bits of the object’s 32-bit word at byte offset `0x30`:

- Low eight bits zero: skip the entire dependency sequence and return true.
- Low eight bits nonzero: continue.

Bits above bit 7 do not enable the sequence. The gate is not a full-word nonzero test. Interpreting a nonzero low byte as signed or unsigned does not change the zero comparison.

When the first gate permits execution:

1. Call F-d189d16d5a68 without explicit arguments.
2. Use its result as an address-bearing value.
3. Read the 32-bit field at byte offset `0x28` from that result.
4. Pass the loaded value to F-d35171ffbceb.
5. Capture the result of F-d35171ffbceb as a **32-bit integer**.
6. Compare that captured 32-bit integer with zero.

The second gate applies specifically to this captured value:

- Captured 32-bit result nonzero: skip the final pair of calls and return true.
- Captured 32-bit result zero: execute the final pair.

For a captured result of zero:

1. Call F-6ac70711bbb5 without explicit arguments.
2. Obtain the external static argument used by the subsequent call.
3. Call F-2926dbb9b751 with the result of F-6ac70711bbb5 and that static argument.
4. Return true on normal completion.

The result of F-6ac70711bbb5 is represented as a 32-bit value in the supplied body. Its semantic type is unknown.

The static argument is prepared for the final call after F-6ac70711bbb5 returns. It must not be treated as an entry-time snapshot. If its storage is mutable, changes made by preceding dependencies may affect the argument supplied.

The static argument’s representation and meaning are not established. In particular, it is not proven to be a string, resource identifier, message, or address.

## Acceptance examples

These are conditional consequences of static evidence, not executed tests. Unless stated otherwise, all reached accesses and calls are assumed valid and normally completing.

1. **Unrecognized request.** A discriminator of `0x00000000` returns false. The body neither reads the payload nor inspects the object nor invokes a dependency.

2. **Exact matching.** `0x00004E01` is unrecognized. Its similarity to `0x00004E00` does not select the first branch.

3. **First branch without assumed copy semantics.** For `0x00004E00`, the external call receives the temporary’s address, the payload value, and `3`. The indirect method is resolved afterward and receives values extracted from the temporary’s resulting contents. No particular source-byte correspondence is required without a dependency contract.

4. **Conditional conventional-copy interpretation.** For the same discriminator, additionally assume little-endian representation and a conventional three-byte copy. With initial temporary `0xAABBCCDD` and source bytes `0x12`, `0x34`, `0x56`, the temporary becomes `0xAA563412`; the indirect-method values are `0x12`, `0x34`, `0x56`. This example does not establish those additional assumptions.

5. **Payload indirection.** For `0x4E000007`, a payload pointing to the readable 32-bit value `0x12345678` causes F-31e8feff54e1 to receive `0x12345678`, not the payload address.

6. **Flag disabled despite upper bits.** For `0x4E000008`, an object flag word of `0x00000100` skips every dependency in the conditional sequence and still returns true.

7. **Captured nonzero predicate.** With the flag enabled, a captured 32-bit result of `0x00000001` or `0xFFFFFFFF` from F-d35171ffbceb suppresses both final calls. The return remains true. This condition concerns the captured 32-bit value, not an unspecified wider return representation.

8. **Captured zero predicate.** With the flag enabled and the captured 32-bit predicate result equal to zero, F-6ac70711bbb5 runs before F-2926dbb9b751. The latter receives its result and the subsequently obtained static argument.

9. **Post-dependency method resolution.** If F-a00000000001 changes the object’s method-table reference while leaving the subsequent accesses valid, the indirect target is resolved from the post-call state, not a pre-call snapshot.

10. **Unused third input.** Changing only the third input changes no direct decision or explicitly constructed dependency argument shown in this body.

11. **Non-normal completion.** An invalid reached payload address has no specified false-return fallback. The body provides no recovery contract for the failed read.
