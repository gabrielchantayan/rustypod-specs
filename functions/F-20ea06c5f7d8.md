### Byte-address selection

A **Q-selected update** consists of two ordered accesses:

1. Read one unsigned byte at Q + 1.
2. Write one byte at seventeen plus the numeric value just read.

The selected destination therefore lies between addresses 17 and 272. Each update reloads the selector; it does not reuse an earlier byte.

A separate lookup address, called **scaled lookup**, is formed later from the retained value representing T shifted left by two: multiply that retained value by 1024, then add one. Under wrapping 32-bit machine arithmetic this is the low-32-bit address corresponding to 4096 × T + 1. The representation does not establish those wrapping semantics generally.
