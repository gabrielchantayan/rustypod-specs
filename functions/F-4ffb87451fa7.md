# F-4ffb87451fa7

## Purpose

F-4ffb87451fa7 conditionally reconciles a 32-bit field in a related object with a 32-bit field in the supplied object, then dispatches an operation on the supplied object.

The established behavior is a comparison, a conditional sequence involving a temporary record and two dependencies, and an unconditional final indirect dispatch. The conditional sequence uses the difference between the two compared fields. It also supplies a four-word record copied from the related object to an indirect operation on that object.

Interpreting this as synchronization, repositioning, or adjustment is **inferred intent**. The supplied evidence does not establish the semantic meaning of the fields, the temporary record, or the indirect operations.

### Conditional comparison

The function reads the related-object pointer from the object at `0xEC`. This supplies a related-object snapshot for the comparison and, if necessary, the later record copy.

It compares:

- The object’s 32-bit field at `0x80`.
- The 32-bit field at `0x80` in that related-object snapshot.

If they are equal, the entire conditional sequence is skipped. Execution proceeds to the final dispatch.

If they differ, the function performs the following conditional sequence.

### Temporary-record population

This is a 16-byte, four-word record in the supplied 32-bit layout. It is not established as a higher-level structure with known field meanings.
