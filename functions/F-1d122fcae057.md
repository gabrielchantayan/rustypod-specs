## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Input truncation.** With second input 0x123456AB, the early Root B +0x11 byte write is 0xAB, while its +0x64 and +0x34 word writes are 0x123456AB. Later aliases may overwrite them.

2. **Overlapping widths.** The Root A +0x11 byte write precedes the Root A +0x10 word write. The earlier byte is not an unconditional final value.

3. **Phase-three read timing.** After the second secondary +0x14 read establishes target T, capture X must be read from primary +0x64 and written back before target T +0x0C receives 0x73. Moving that byte write earlier can change X under aliasing.

4. **Distinct captures around 0x73.** If target C +0x20 is exactly primary +0x64, the word-0x73 store makes V equal 0x00000073. U retains the preceding word. Subsequent uses must retain their documented U-versus-V distinction.

5. **Retained versus fresh link.** The 0x74-store destination is captured before the repeated primary +0x0D writes and the primary +0x64 replacement. The following traversal rereads base H +0x04 after the word-0x74 store. If an intervening alias changes that link, the destinations may differ.

6. **Late overlapping stores.** If late target +0x34 and primary +0x14 designate the same word, R is stored first and the retained replacement primary link second. At that point, the second store determines the word’s contents.

7. **Tail conversion.** A read byte of 0x12 produces tail index 0x00000012 under either ordinary character interpretation. The tail word destination is 0x57, its byte destination is 0x56, and the first terminal argument is 0x56. For byte 0x80, zero-extension yields 0x00000080, whereas sign-extension followed by unsigned conversion yields 0xFFFFFF80; the corresponding wrapped word destinations are 0x000000C5 and 0xFFFFFFC5.

8. **Failure without transactionality.** If an early destination is inaccessible, no successful return or error code is promised. Already completed writes are not visibly undone.
