2. **Setup failure.** With a nonzero resource-gate result and setup status `7`, F-289ec4311c64 still runs. Traversal is skipped, finalization follows, and the function returns `0`.

3. **Any-bit token acceptance.** At a `0x39` mask gate, token `0x01` passes and token `0` fails. Exact equality to `0x39` is unnecessary.
