# F-adb9b73e2498

## Purpose

F-adb9b73e2498 selects one of two externally supplied memory regions, clears bit 0 of a channel-associated 32-bit word, and then writes a channel-derived bit value to the first 32-bit word of the selected region.

The supplied representation establishes the selection rule, the two ordered destination writes, and two return values. It does not establish the meaning of either memory region. Interpreting the operation as enabling, disabling, acknowledging, or configuring a hardware channel would be inferred intent, not an established contract.

The function contains no represented calls to other functions. It does not validate the channel argument, check the selected pointer, or report memory-access failures through a dedicated return value.

## Interface

### Inputs

The function accepts two scalar inputs:

| Input | Represented type and width | Meaning established by the supplied representation |
|---|---|---|
| Selector | Signed 32-bit integer | Value 1 selects region A; value 2 selects region B. Every other value takes the rejection path. |
| Channel | Unsigned 32-bit integer | Determines both the channel-associated word address and the shift count used for the final write. |

The 32-bit interpretation follows the supplied type representation and its 32-bit mask and result values. An independent ABI declaration was not provided.

The function also consumes two externally stored base pointers:

- **Region A pointer slot:** supplies the base selected for selector 1.
- **Region B pointer slot:** supplies the base selected for selector 2.

These labels describe distinct pointer sources, not necessarily distinct destination regions. Their pointer values may be equal, overlapping, invalid, or externally mutable; the supplied representation imposes no separation guarantee.

### Output

The return value is represented as a 32-bit scalar:

- **0:** the accepted-selector path reached its normal return after the two destination writes.
- **19**, equivalently **0x13:** the selector was neither 1 nor 2.

The representation does not establish that this return value is a signed status, an enumeration, or a standardized error code. No other normal return value is shown.

A return of 0 does not report or verify any downstream hardware effect. It establishes only completion of the represented accepted path.

### Address layout

For a selected region base \(B\), the function uses:

1. **The base word:** the 32-bit word at \(B\).
2. **The channel-associated word:** the 32-bit word at word index
   \[
   I=(8\times\text{channel}+66)\bmod 2^{32}.
   \]

For channels whose calculation and address formation do not encounter wrapping or platform-specific pointer behavior, the channel-associated byte offset is:

\[
264+32\times\text{channel}.
\]

Consequently:

- Channel 0 uses byte offset 264.
- Channel 1 uses byte offset 296.
- Successive small channel values advance the target by 32 bytes.

The unsigned index calculation and the subsequent pointer-address calculation are separate concerns. The supplied representation does not justify treating every possible channel as a valid offset into a real region.

### Preconditions for normal completion

For an accepted selector, normal completion requires the pointer-slot reads and selected destination accesses to be valid in the execution environment. In particular:

- The pointer slots actually read must be accessible.
- The selected base must support the required 32-bit accesses.
- The channel-associated address must support both a read and a write.
- The base address must support a write.
- Address formation and the shift must have defined behavior under the applicable target semantics.

No region length, channel limit, alignment declaration, or memory-mapping description was supplied. These requirements are caller or environment obligations, not checks performed by this function.

## Behavior

### Selection and rejection

The supplied representation first reads the region A pointer slot.

- If the selector is 1, that pointer becomes the selected base. The region B pointer slot is not read on this path.
- If the selector is not 1, the function next reads the region B pointer slot.
  - If the selector is 2, that pointer becomes the selected base.
  - Otherwise, the function returns 19.

Thus the rejected-selector path still contains pointer-slot reads: region A first, then region B. It performs no represented read or write through either region pointer.

This distinction matters if pointer-slot reads themselves can fault or have externally visible effects. The supplied representation does not establish that they are inert ordinary-memory reads.

### Channel-associated update

For selector 1 or 2, the function forms the channel-associated word address from the selected base and the unsigned channel index calculation.

It reads that 32-bit word, clears its least significant bit, and writes the resulting 32-bit value back to the same address:

\[
\text{new word}=\text{observed old word}\mathbin{\&}\texttt{0xFFFFFFFE}.
\]

The update has these properties:

- Bit 0 becomes zero.
- Bits 1 through 31 retain the values observed by this read.
- The read and write are both represented, including when bit 0 was already zero.
- The update is not shown as an atomic operation.
- A concurrent modification between the read and write may be overwritten by the function’s write.

The entire channel value participates in the index calculation, subject to unsigned 32-bit arithmetic. The channel is not reduced to eight bits for this address calculation.

### Base-word write

After the channel-associated write, the function writes a shift-derived value to the base word.

The shift count is the channel’s low eight bits:

\[
S=\text{channel}\mathbin{\&}255.
\]

The represented value expression shifts the integer value 1 left by \(S\).

For \(0\leq S\leq30\), the resulting 32-bit value is unambiguous under the represented conventional 32-bit integer interpretation:

\[
2^S.
\]

The final operation replaces the base word; it does not read that word and combine the new bit with its existing contents. Existing base-word bits therefore do not survive merely because they were previously set.

Counts from 31 through 255 require the qualifications in **Uncertainties**. In particular, this contract does not invent modulo-32 shift behavior.

The address index and shift count are deliberately described separately: a channel whose low byte is zero can select a distant channel-associated word while producing a shift count of zero.

### Completion and ordering

On an accepted-selector path that completes normally, the represented order is:

1. Read the pointer slots required by selection.
2. Read the selected channel-associated word.
3. Write that word with bit 0 cleared.
4. Write the shift-derived value to the selected base word.
5. Return 0.

The selected base is obtained before the destination updates. The representation does not show a pointer-slot reread between the two destination writes.

There is no represented rollback. If execution is interrupted or faults after the channel-associated write, the first update may remain even though the base-word write or normal return does not occur.

This is the order expressed by the supplied representation. Actual bus transactions, compiler transformations, and hardware ordering guarantees are not independently established.

## Side effects

For a valid selector and defined, accessible operands, the function changes two logical destinations:

- The channel-associated word, by clearing bit 0.
- The base word, by replacing it with the shift-derived value.

No allocation, deallocation, ownership transfer, logging, callback, or additional state update is represented.

The function uses externally supplied storage; it does not establish ownership of that storage. Nothing in the supplied representation establishes whether a caller may release it, whether another component owns it, or whether it denotes ordinary memory or device registers.

The following are not guaranteed:

- Atomicity of the read-modify-write.
- Mutual exclusion against other agents.
- Memory barriers or device synchronization.
- Preservation of externally updated bits during a race.
- Persistence or hardware acknowledgement of either write.
- Recovery from invalid addresses.

No write to either pointer slot is explicitly represented. However, the destination regions are not proven disjoint from the pointer slots or other state. If they overlap in an actual environment, destination writes can affect that overlapping storage.

## Acceptance examples

These examples are conditional static acceptance criteria, not reported runtime results. Unless stated otherwise, assume valid pointer slots, accessible nonoverlapping ordinary memory, conventional 32-bit integer semantics, and no concurrent modifications.

### Selector 1, channel 0

Given a channel-associated word at region A byte offset 264 containing `0xA5A5A5A5`:

- The region A pointer slot is read.
- The region B pointer slot is not read.
- The word at offset 264 is read and then written as `0xA5A5A5A4`.
- Region A’s base word is subsequently written as `0x00000001`.
- The function returns 0.

### Selector 2, channel 1

Given a channel-associated word at region B byte offset 296 containing `0xFFFFFFFF`:

- The region A pointer slot is read, followed by the region B pointer slot.
- The word at region B offset 296 is written as `0xFFFFFFFE`.
- Region B’s base word is subsequently written as `0x00000002`.
- The function returns 0.

With disjoint regions, no destination in region A is accessed on this path.

### Bit 0 already clear

Given selector 1, channel 0, and a channel-associated word of `0x12345678`:

- The represented read and write still occur.
- The written channel-associated value remains `0x12345678`.
- The base-word write still follows.

An unchanged value does not eliminate the represented write.

### Replacement rather than accumulation

Given selector 1, channel 3, and an initial base word of `0xFFFFFFFF`:

- After the channel-associated update, the base word is written as `0x00000008`.
- The result is not `0xFFFFFFFF` and is not an OR-accumulation of the old base value.

### Full channel affects the address

Given selector 1 and channel 256, with a region large enough for the access:

- The channel-associated byte offset is 8,456.
- The shift count is zero.
- The channel-associated word has bit 0 cleared.
- The base word is written as 1.

This distinguishes the full-width address calculation from the low-eight-bit shift calculation.

### Rejected selector

Given selector 0, or any selector other than 1 and 2, and readable pointer slots:

- The region A and region B pointer slots are read in that order.
- No selected-region contents are read or written.
- The function returns 19, independently of the channel value.

### Shift boundary

For channel 30, with valid addressing, the base-word value is `0x40000000`.

For channel 31 or 32, a portable successful result is not established by the supplied representation. Acceptance must depend on separately documented target shift semantics; it must not assume saturation, zero, or modulo-32 behavior.
