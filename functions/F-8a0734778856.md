### Address roles and opening memory traffic

The following are descriptive roles, not implementation identifiers:

- **Carrier base:** an earlier result multiplied by \(2^{25}\).
- **Tag base:** an earlier aggregate’s low part shifted left by twenty-five.
- **Saved shifted value:** another result shifted left by eight.
- **Small index:** a result shifted left by eight, masked with 0x7FFF, then shifted right by six.
- **Small base:** twice the small index.
- **Pair low** and **pair high:** parts of the last aggregate result before direct mutation.

Under the bit-vector model, the small index ranges over 0, 4, …, 508; the small base ranges over 0, 8, …, 1016.

The captured carrier word is not unconditionally zero: intervening stores can alias it, and observable storage need not behave as ordinary RAM.

## Acceptance examples

These are conditional static criteria, not executed tests.

### Fixed-storage conversion

If the declaration at 0x05 establishes an unsigned eight-bit value 0xFF, the fixed-selected base is 255. If it instead establishes a signed value −1, conversion to unsigned 32 bits yields 0xFFFFFFFF. Restricting both cases to 255 is unacceptable.

### Narrow value versus narrow access

An assignment to fixed storage at 0x67 supplies 0x78 when the captured 32-bit value is 0x12345678. This does not prove that only one byte is written. Conversely, an explicit byte-pointer destination supplied 0x12345678 stores 0x78.

### Sparse index

Under the bit-vector model, a contributing result with low byte 0x7F produces small index 508 and small base 1016. The index is not an arbitrary integer from 0 through 511.

### Capture boundaries

The read associated with 0x087FBBBC must precede the 0x60 assignment regardless of their unresolved widths.

If an environmental declaration establishes a byte write at 0x3A and double base plus 0x14 equals 0x3A, the later word capture includes that write’s effect according to byte order. Moving the capture earlier is unacceptable.

### Independent fixed-storage reads

If observable storage supplies distinct values on the three reads at 0x67, the first supplies the 0x21 assignment; the latter two independently supply explicit byte stores at adjusted base plus nine. Their byte destinations do not authorize byte-width source assumptions or cached reuse.

### Shift and termination

If an early dependency does not return, later mutations are not required. Reaching the terminal transfer establishes first argument 0x72, not normal completion.
