# F-2184ce65a9ac

## Purpose

F-2184ce65a9ac specifies the observable execution prefix established by the supplied static representation. It covers path selection, memory accesses, dependency invocations, arithmetic, and ordering. It does not establish a complete returning operation.

Three mutually exclusive behaviors are visible:

- Two halfword observations at one source address, followed by a halfword store whose destination depends on one observation, then a byte store.
- Three ordered word reads, a dependency invocation, a word store using retained data, then a halfword store derived from the second argument.
- A dependency invocation, a post-call byte read, a halfword store addressed using that byte, then a word store whose payload and destination depend on the dependency result.

In the third behavior, the halfword store precedes the final word store, **not** the dependency invocation.

**Established static evidence:** Incoming condition state selects the first behavior. Otherwise, an unsigned context value supplies a five-bit index and a separate selection bit. Every visible path ends at an unavailable continuation.

**Inferred intent:** The operation may manipulate low-level or packed memory state. No application-level purpose is established. Small numeric addresses must not be replaced with presumed allocation or table addresses.

Numeric address formation and access validity are separate. A defined arithmetic result does not establish a mapped address, supported alignment, successful access, or normal completion.
