Several distinct bases matter at this boundary:

- A previously captured value shifted left by 25.

- A small base obtained by doubling a masked-and-shifted result.

These bases must not be conflated. In particular, the early word readback is from the scaled base that was explicitly cleared, not necessarily from the final result’s high-word base.

The opening mutations couple a word publication with two byte publications to another address. An intervening word store separates those byte publications. The function then clears a word at offset 0x14 of the scaled base, reads its byte at offset 0x05, and publishes the unsigned byte value as a word at offset 0x34 of that base.

## Acceptance examples

These are conditional criteria, not executed tests.

1. **Explicit-input truncation.** Under low-32-bit shift semantics, fourth-input values differing only above bit 6 produce the same early left-shifted argument word. This does not establish identical overall behavior.

2. **Upper-result extraction.** A 64-bit result of 0x0000010000000000 yields 0x10 when shifted right by 36. Extracting its low word first would incorrectly yield zero.

3. **Unsigned byte publication.** If the applicable byte read produces 0xFE, the corresponding widened word is 254, not a sign-extended negative value.

4. **Distinct opening bases.** The early offset-0x14 readback must use the cleared scaled base. Substituting the final dependency result’s high-word base is acceptable only if those addresses actually coincide.

5. **Aliasing after a clear.** If an intervening byte or word write overlaps the cleared location, its later read observes the resulting contents rather than an assumed zero.

6. **Duplicate publications.** Where writes are observable, retaining only the last of two identical adjacent writes is insufficient.

7. **Fixed-location rereads.** If a derived write changes address 0x67 after its initial publication, a later read of 0x67 uses the changed byte. Reusing the initial low byte is insufficient.

8. **Variable-shift boundary.** Under modular 32-bit arithmetic, the payload base is congruent to 8 modulo 16. Its low-byte shift count can therefore be 8, 24, or a larger value congruent to 8 modulo 16. Counts at least 32 require the unresolved execution semantics; they are not automatically reduced modulo 32.

9. **Terminal captures.** A later overwrite of a location supplying a captured terminal argument does not require reloading that argument. The first terminal argument remains 0x72.

10. **Interrupted dependency phase.** A nonreturning early dependency imposes no requirement to perform the later direct-memory writes.
