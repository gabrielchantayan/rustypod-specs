# F-2973ca21b889

## Purpose

F-2973ca21b889 selects one of three downstream operations according to its second input and a global byte-pointer setting. It returns a 32-bit value obtained from a downstream operation, except for an explicit **zero-result early return** on one route.

The established routes are:

- A nonzero second input selects a context-directed dispatch.
- A zero second input and, under stable global observations, a nonnull global pointer with a nonzero first byte select a size-related call followed by dispatch through the third input. That dispatch’s result determines whether execution returns zero or continues to a final indirect call.
- Otherwise, the zero-input route selects a fallback dispatch through the third input.

The zero/nonzero distinction on the intermediate result is strictly a control-flow distinction. The supplied evidence does not establish that zero means failure, that nonzero means success, or that either result identifies an owned resource.

A possible intent of the populated-global route is to obtain space for a terminated byte sequence and then transfer that sequence. Length calculation, allocation, and copying are **inferred intent**, not established dependency behavior.

### Global-dependent selection

Under a stable global setting, selection has the following meaning:

- A null pointer selects fallback without dereferencing that pointer.
- A nonnull pointer whose first byte is zero selects fallback.
- A nonnull pointer whose first byte is nonzero selects the populated-global route.

Only one byte of content is examined locally. It is interpreted as an unsigned byte, so values from 1 through 255 satisfy the nonzero content condition. No local scan, terminator search, encoding check, or storage-bound check occurs.

The supplied representation contains multiple global observations rather than one immutable selection snapshot. After the entry capture, it checks whether the current setting is nonnull, conditionally reads a first byte through the global pointer, and later checks the setting for nonnull again.

The intermediate selection value initially comes from the third input and is replaced by the zero-extended first byte when the conditional byte read occurs. Consequently, the stable-setting description must not be promoted into a guarantee for changing global observations. In particular, if the first null check skips the byte read but the later null check observes a nonnull setting, the remaining nonzero test concerns the retained third-input value, not an observed byte.
