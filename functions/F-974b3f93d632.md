# F-974b3f93d632

### 3. Obtain the selection result

- Zero enters the default-resource path.
- Any nonzero value enters the status-bar-resource path.

### 4. Perform the optional action on the zero-result path

Only when F-b7dc2cfb1085 returns zero does the function read the field at offset 0xC8.

If that read yields zero, the optional indirect call and F-0683c3467ba0 are both skipped.

If that read yields a nonzero value:

1. The receiver’s dispatch-table address is read.
2. The entry at table offset 0x13C is invoked with the receiver as its explicit argument.
3. The returned integer is tested against zero.
4. If the result is nonzero, the field at receiver offset 0xC8 is read again, and its then-current value is passed to F-0683c3467ba0.

The second read of offset 0xC8 is significant. The value supplied to F-0683c3467ba0 is not necessarily the value that satisfied the earlier nonzero check. The indirect call may have changed receiver state. The function does not recheck the newly read value against zero before passing it onward.
