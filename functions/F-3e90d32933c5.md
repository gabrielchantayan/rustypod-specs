### Arithmetic and trace notation

The following symbols are explanatory quantities, not source identifiers:

- **A**: result of the first five-call opening sequence.
- **B**: result of the next five-call sequence.
- **P**: `16 × B`.
- **Q**: `(B masked with 0x3fffffff)`, logically shifted right by one.
- **R**: a later call result retained across multiple stages.
- **S**: `1024 × Q`.
- **T**: `Q masked with 0x3fffff`.
- **V**: `0x4000000 × Q`.
- **W**, **X**, and **Y**: successive late-stage call results.

Unless expressly identified as a byte, stored values occupy 32 bits. A “byte selector” is an unsigned eight-bit read. A write through a selector uses the selector’s numeric value as an address component, not as a pointer loaded from a table.

The recovered widths support a 32-bit machine interpretation. Under that interpretation, address arithmetic, multiplication, and left shifts retain their low 32 bits; byte writes retain their low eight bits. Some recovered expressions are signed, however. These machine-width rules are an interpretation of the apparent target operations, not a claim that overflowing signed expressions have portable language semantics.

Unsigned masks and logical right shifts are explicit. In particular:

- Q ranges from zero through `0x1fffffff`.
- T ranges from zero through `0x3fffff`.
- `128 × T` fits in 29 bits.
- `16 × T` fits in 26 bits.
- A masked value shifted right by 20 may contain ten bits before narrowing to a byte.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Second-input propagation.** If A is 3 and execution reaches the first store, the second input is written as a 32-bit word at `0x20`. The next call receives 12.

2. **Early address derivation.** If B is 2, then P is `0x20` and Q is 1. The second third-input store targets `0x44`; the explicit word read targets `0x94`. The early selector read targets `0x21`.

3. **Selector is an address component.** If a selector read yields `0x80`, its associated byte store targets `0x91`. It does not dereference a pointer located at `0x80`.

4. **Selector refresh matters.** If an early selector initially equals 2, but an intervening dependency changes it to 9, the later zero-byte write targets `0x1a`, not `0x13`.

5. **Retained selector matters.** If the selector retained in step 15 is 7, the later zero-word store targets `0x4b`, even if a dependency changes the selector in memory before that store.

6. **Byte narrowing matters.** If W is `0x00100001`, the first late byte value is `0x04`; the subsequent masked-and-shifted byte value is `0x01`.

7. **Mask and narrowing are distinct.** If B is `0x3ff00000`, the early masked right shift yields `0x3ff`, but the stored byte is `0xff`.

8. **No completion on failed access.** If the first computed word destination is inaccessible and faults, later calls and stores are not guaranteed. No visible rollback or local recovery path applies.
