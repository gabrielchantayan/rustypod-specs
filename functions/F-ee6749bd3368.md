# F-ee6749bd3368

No domain-level purpose is established. The evidence does not support describing the operation as allocation, initialization, formatting, rendering, or collection traversal.

### First direct mutations

Near the end of the invocation phase, the operation retains several address components:

- A returned word multiplied by 2²⁵.
- A returned word shifted left by 8.
- A returned word shifted left by 25.
- A bounded component obtained by shifting a word left by 8, masking with 0x7FFF, and logically shifting right by 6.

Under 32-bit bit-vector arithmetic, the bounded component is four times its source’s low seven bits: a multiple of four between 0 and 508. Its double is a multiple of eight between 0 and 1016.

The first explicit store writes the retained left-by-25 value as a word at offset 0x14 from the high half of the last represented paired result. A byte store at offset 9 from the left-by-25 base follows, initially containing the low byte of that high half.

Next, a word at offset 0x54 from the paired result’s low half multiplied by 256 receives the multiplication-by-2²⁵ base. The earlier offset-9 byte destination is then written again, this time with the low byte of the retained left-by-25 value.

The multiplication-derived base subsequently receives a zero word at offset 0x14. An unsigned byte is read at offset 5. A zero word is stored at offset 0x14 from the doubled bounded component, and the previously read byte is zero-extended into a word store at offset 0x34 from the multiplication-derived base.

The word at the multiplication-derived base plus 0x14 is then reloaded. Another zero-word store through the doubled bounded component follows, then two byte stores of the reloaded word’s low byte at offset 0x15 from that doubled component.

The reload is not unconditionally zero: intervening accesses can alias it, and memory semantics are unknown.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Third-input truncation.** Under 32-bit bit-vector shifts, low-two-bit values 0, 1, 2, and 3 produce the displayed argument 0x00000000, 0x40000000, 0x80000000, and 0xC0000000. This is not a whole-function equivalence claim.

2. **Masked extraction.** Masking 0xAB123456 to 24 bits and logically shifting right by 8 produces 0x1234.

3. **Bounded component.** A source with low seven bits equal to 127 produces 508, whose double is 1016. Low seven bits zero produce zero without a visible special-case branch.

4. **Early global ordering.** If execution reaches the relevant region, the read at 0x05 occurs before the byte write at 0x01. A replacement must not move the read after that write or silently choose its unresolved memory width.

5. **Repeated-region boundary.** The read at 0x087FBBBC occurs before the word write of 0x20 at 0x60, which occurs before the repeated-store region. A derived write overlapping the global does not cause an unrepresented reload of the retained base.

6. **Fresh global-byte reads.** Suppose the word read at 0xA9 has low byte 0x12. The explicit write at 0x67 receives 0x12. If an intervening aliasing write changes 0x67 to 0xAB before a later byte read, the corresponding derived offset-9 store uses 0xAB, assuming ordinary byte-memory semantics. It must not substitute the retained 0x12.

7. **Retained full word.** Changing the byte at 0x67 after its initialization does not itself change the already retained 32-bit value from 0xA9 used by the later offset-0x44 word store.

8. **Intermediate effects.** An observer distinguishing accesses to the successive-constant destination sees ordered word writes of 0x20, 0x2F, the freshly read zero-extended byte, and 0x20—not merely the final value.

9. **Aliased reload.** The early offset-0x14 reload uses memory as encountered at that read. Replacing it with zero requires independent proof about aliasing and memory semantics.

10. **Final dispatch.** If preceding operations complete, the final invocation receives first argument 0x72 and the three separately sourced words described above. No status return is required by the evidence.
