# F-499b56daf37d

## Purpose

F-499b56daf37d selects one of two operations on a caller-supplied destination. Its decision combines the low 32 bits of a dependency result with a 32-bit field of a supplied object.

The established selection rule is:

- Invoke F-ce21d81c6660 only when the dependency result’s low 32 bits are nonzero and the object field at byte offset 48 is nonzero.
- Otherwise, invoke F-ba5a4c1e0746 with the destination and two zero-valued arguments.

The function surrounds this decision with calls involving an embedded object region and a temporary representation obtained through an indirect object operation. The names and purposes of these mechanisms are not established. In particular, synchronization, lookup, initialization, and cleanup are possible interpretations, not guaranteed semantics.

This contract describes behavior supported by the supplied static material. It does not establish the behavior of the called functions, and no runtime tests have been performed.

## Behavior

### Entry and indirect operation

The first visible action is a call to F-4a19e3742733 with the address 544 bytes beyond the object base.

Only after that call returns does the function read the object’s dispatch-table address and resolve the operation at table offset 164. It invokes that operation with the object pointer.

This order matters. The dispatch information is read after F-4a19e3742733 has had an opportunity to change reachable state. A behavioral substitute must not assume that entry-time dispatch state is necessarily the state used by the indirect call.

The indirect operation’s 32-bit result is passed to F-1c06d0a5910b, together with:

- The address of the 20-byte temporary region.
- A zero-valued third argument.

The function then calls F-961dd3c5e67e with the address of the 16-byte region followed by the address of the 20-byte region. The visible order of these arguments is established; an interpretation such as copying, converting, borrowing, or retaining is not.

### Decision-producing dependency

F-d45d65316ed3 is called with:

1. The address of the 16-byte temporary region.
2. The original auxiliary value.

Its result is represented as 64 bits. For the destination-operation decision, only the low 32 bits matter.

The supplied representation also extracts the high 32 bits. That extraction does not affect which destination operation is selected:

- When the low 32 bits are zero, the fallback operation is selected regardless of the high 32 bits.
- When the low 32 bits are nonzero, the high-part value is replaced for the decision by a fresh read of the object field at offset 48.

Consequently, the high 32 bits are not an error code, status, pointer, or second decision input under this contract. Their interpretation remains unknown, and no interpretation is needed to describe the observed branch behavior.

### Conditional object-field read

If the low 32 bits are zero, the function does not read the object field at offset 48.

If the low 32 bits are nonzero, the function reads that 32-bit field after F-d45d65316ed3 returns. It compares the field with zero.

This is a late read, not an entry-time snapshot. Earlier dependencies may have modified the object or other reachable state. The condition therefore uses the value visible at this point in the sequence.

Both comparisons are zero-versus-nonzero tests. A 32-bit value with its most significant bit set is still nonzero; there is no positive-only condition.
