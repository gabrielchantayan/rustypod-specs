1. **Stable writable base.** If both base-producing calls return the same valid base, all calls return normally, and offsets 48 through 51 are writable, the final explicit store sets those four bytes to zero after F-67223611579f returns.

7. **Neighboring storage.** If all dependencies leave neighboring bytes untouched and the final write succeeds, the wrapper’s explicit store changes only offsets 48 through 51. This is not a guarantee that the entire invocation preserves other storage.
