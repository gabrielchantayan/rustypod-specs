# F-7431d9b27a62

## Purpose

This numerical description is conditional on a 32-bit signed input and 32-bit unsigned arithmetic and result. Under that model, it is established for every input except −2,147,483,648. The supplied definition does not establish ordinary completion for that minimum input because its treatment requires a signed value outside the representable range.

**Inferred intent:** Numerical quantization. No application-specific units, fixed-point format, or reason for the spacing are established.

### Zero region and halfway cases

The adjacent halfway inputs lie outside that region:

- 32,768 selects 65,536 and returns 65,536.
- −32,768 selects −65,536 and returns 4,294,901,760.
