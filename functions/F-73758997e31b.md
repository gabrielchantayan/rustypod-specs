# F-73758997e31b

## Purpose

F-73758997e31b performs a stateful sequence of indirect calls, computed-address memory accesses, and conditional iteration. It can return a packed 64-bit value or continue indefinitely.

**Established static behavior:** Each iteration begins with two calls followed by a 32-bit store. A test of a derived 32-bit value selects either an immediate return or a longer path. The longer path performs additional calls and stores, then reads a global control value and compares it with zero. Zero selects a return; nonzero selects a continuation store and another iteration.

**Inferred intent:** The routine appears to update externally managed state. The supplied material does not establish an application-level purpose, data structure, or protocol.

The contract describes operations visible in the supplied representation. It does not establish memory safety, termination, or the behavior of opaque dependencies.

1. Current C.
2. Current B.
3. An address into the current stack frame.

No explicit return value from F-U01 is consumed. Its effects on stack storage, globals, registers, and retained references are unknown.

F-U02 is then called with no explicit arguments. Its represented 64-bit result provides:

- A low word used as data and as the early-return input.
- A high word used as an address base on the longer path.

The routine forms an adjusted value equal to current B plus 10.

### 2. Unconditional store and early-return test

After both initial calls, the routine stores current D as 32 bits at:

**current B + 62**

This store precedes the branch and occurs on both normal return paths reached from that iteration.

The branch tests whether the signed result of multiplying the adjusted value by 65,536 is negative. Under the 32-bit bit-vector interpretation, this is equivalent to testing bit 15 of the adjusted value.

If that bit is set, execution reaches the shared return point:

- The selected lower-word input is F-U02’s low word.
- The lower return word is that input shifted left once.
- The upper return word is the return-global word minus 84.

None of the longer-path operations occur on this branch.

This condition is not a general test of whether B is negative. Under the bit-vector interpretation, bits above bit 15 do not determine the branch.

### 3. Longer-path stores and calls

If the early-return condition is false, the routine stores the low 16 bits of F-U02’s low word at:

**F-U02 high word + 60**

F-U03 is then called with no explicit arguments. No explicit result is consumed.

Next, F-U04 is called with no explicit arguments. Its 32-bit result is used as an address base, and the routine stores the 16-bit value 38 at:

**F-U04 result + 2**

### 4. Mixed-address construction

The routine derives a signed intermediate value by shifting the adjusted value left by 28 bits within 32 bits, then arithmetic-right-shifting that result by 9.

It adds the adjusted value to this intermediate value and captures a 32-bit global mixing word.

F-U05 is then called with two explicit arguments:

1. F-U04’s result shifted left once.
2. The adjusted value multiplied by 65,536, then reduced by 81.

After F-U05 returns, the earlier sum is exclusive-ored with the previously captured mixing word. The result is the **mixed address**.

The mixing global is read before F-U05. A change to that global during F-U05 does not substitute a newly read value into this calculation.

The routine also forms a **derived value** equal to the intermediate value plus 47.
