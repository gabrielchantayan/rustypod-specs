### Transfer eligibility

This read occurs even when the second input is zero. The field comparison is evaluated before the second input’s nonzero condition in the transfer condition.

The transfer path continues only if both of these conditions hold:

- The observed source field is nonzero.
- The second input is nonzero.

If the field is nonzero but the second input is zero, the transfer path likewise stops without another F-fdd8589eca2d call.

### Destination check

If transfer eligibility holds, the function calls F-fdd8589eca2d again.

It treats this call’s result as an address and reads the 16-bit field at that address plus 0x80.

If the observed destination field is nonzero, no direct field write occurs, and no further F-fdd8589eca2d call is made.

If the observed destination field is zero, execution proceeds to the transfer.

There is no explicit validation of the address returned by this lookup. Safe normal execution therefore requires its offset-0x80 field to be readable.

### Transfer

When the destination check observes zero, the function calls F-fdd8589eca2d once more.

This is a separate lookup. Its returned address, not the address from the destination check, supplies the destination base for the write.

After that final lookup returns, the function reads the 16-bit source field at the first input’s base plus 0xF2 again. It writes that value to the 16-bit field at the final lookup’s returned address plus 0x80.

Consequences of this sequencing include:

- The destination checked for zero and the destination written need not be the same object.
- The written source value need not equal the source value that originally established eligibility.
- The source can become zero after eligibility was established; the later read can then cause zero to be written.
- The final destination’s field is not checked for zero before the write. If the final lookup selects another object, its existing value can be overwritten even if it is nonzero.
- A dependency can affect the final source value or destination selection. The wrapper does not snapshot either one across the complete decision process.

The final destination field must be writable, and the source field must remain readable at the later read.

### Completion

There is no explicit retry, rollback, or alternate return path for failure in the supplied body.
