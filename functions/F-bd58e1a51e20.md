## Behavior

### 3. All other selectors

Every selector other than 117 follows the same decision tree.

#### Negative high word

If the high word is negative under a signed 32-bit interpretation:

- The routine records whether the original low word is nonzero.
- It negates the low word.
- It replaces the high word with the negation of the sum of the original high word and that nonzero-low indicator.
- It selects a second fixed auxiliary-data pointer.
- It sets the indicator to one.
- It performs no direct context flag read.

Under 32-bit wrapping word arithmetic, the resulting two-word value is the two’s-complement negation of the original 64-bit bit pattern. The nonzero-low adjustment propagates the required carry between words.

For an original low word of zero, the transformed low word remains zero and the high word is negated without the additional one. For an original low word other than zero, the high-word correction includes that additional one.

This operation does not establish that the resulting 64-bit value is positive under a signed interpretation. In particular, the most-negative 64-bit bit pattern remains unchanged under wrapping two’s-complement negation.

The exact treatment of signed minimum values in the supplied representation is discussed under **Uncertainties**.

#### Nonnegative high word

If the high word is nonnegative, the input value words are not changed.

The routine first reads the 32-bit context word at offset 24 and tests mask 2.

- If mask 2 is set, it selects a third fixed auxiliary-data pointer and sets the indicator to one.
- If mask 2 is clear, it reads the context word again and tests mask 4.
  - If mask 4 is set in this second read, it selects a fourth fixed auxiliary-data pointer and sets the indicator to one.
  - If mask 4 is clear, it retains the default pointer and zero indicator.

These are two separately represented reads on the path that reaches the mask-4 test. A contract must not replace them with one cached snapshot without an additional stability assumption.

For stable context storage with both masks set, mask 2 takes precedence. If the context changes between reads, the mask-4 decision uses the second observed word.

### 4. Sequence-generation loop

After selection and any value adjustment, the routine constructs its 64-bit working value and initializes the byte count to zero.

At the start of every loop pass, the supplied representation sets the byte later used for output generation to zero. It then checks whether the working value is zero.

If the working value is zero:

- No transformation dependency is called for that pass.
- No byte is written for that pass.
- The loop ends.

Otherwise:

1. F-5ecc94b34ace is called with the low and high 32-bit words of the current working value, in that order.
2. Its returned 64-bit value replaces the working value.
3. The routine stores the byte value for `0` at the temporary array offset equal to the current count.
4. The count increases by one.
5. The next pass tests the returned working value.

Thus, a nonzero value that becomes zero after one dependency call still produces one stored byte. An initially zero value produces none.

The supplied representation does not show a returned remainder or another explicit output from F-5ecc94b34ace being used to choose the stored byte. Treating the stored bytes as decimal digits other than `0` would require evidence beyond the supplied material.
