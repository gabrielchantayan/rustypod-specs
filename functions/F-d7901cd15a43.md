# F-d7901cd15a43

- It reads the word at record offset 0 after the submission call.
- It treats that word as a dispatch-table base address.
- It reads a callable target from byte offset 4 relative to that base.
- It invokes that target with the record address as its sole explicit argument.
- If the invocation returns normally, this function returns.
