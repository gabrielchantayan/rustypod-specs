## Behavior

### Search activation

The function tests whether either the fourth or third argument is nonzero.

If both are zero:

- The result is zero.
- Neither dependency is called.
- No entry-field access occurs.

If either is nonzero, traversal begins by calling F-65fe7bd54a4b with the first argument. A zero return value ends the search immediately with result zero. A nonzero return value becomes the first entry examined.

There is no separate visible validation of the first argument before that call. Its validity requirements belong to the dependency’s unknown contract.

### Entry examination

For each nonzero entry, the function first reads the 32-bit field at byte offset 52 and compares it with the fourth argument.

If that comparison fails, the function does not read the field at byte offset 48 for that examination.

If the offset-52 comparison succeeds, the function reads the 32-bit field at byte offset 48 and compares it with the third argument.

If both comparisons succeed, the function returns the current entry value immediately. It does not call F-986cc6891b07 for that matching entry and does not examine later entries.

Thus, the externally relevant field-access order is:

1. Offset 52.
2. Offset 48, conditionally.

The comparison order is not interchangeable when memory access itself is observable or when one of the fields cannot safely be read. In particular, a readable but nonmatching offset-52 field prevents the offset-48 load.

The two field reads are separate operations. The supplied representation establishes neither an atomic pairwise snapshot nor synchronization with concurrent mutation.

### Advancement and termination

After an entry fails either comparison, the function calls F-986cc6891b07 with that entry value.

A zero result terminates traversal and produces result zero. A nonzero result becomes the next entry examined using the same comparison order.

The selected result is therefore the first match in the sequence actually returned by the dependencies. The function imposes no independent ordering and does not choose a minimum, maximum, newest, or otherwise preferred match.

There is no visible iteration limit, cycle detection, or repeated-entry suppression. If the dependency continues returning nonzero entries and no examination succeeds, normal termination is not guaranteed.

### First of multiple matches

### One zero component remains searchable
