   If the saved base is `0x2000`, later changing the global base cell to `0x3000` does not redirect the visible word read: it remains at `0x2014`. A write to `0x2014` before that read can change S.

6. **Second byte payload is a bit slice, not the highest byte.**  
   If S is `0xFFFFFFFF`, the second byte payload is `0xFF`. If S is `0xC0000000`, the payload is `0x00`, because only bits 22 through 29 survive truncation.

7. **The final halfword destination may be unaligned.**
