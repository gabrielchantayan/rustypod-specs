# F-3f35b3cd17e1

## Purpose

F-3f35b3cd17e1 transfers four 32-bit words from a source region to a destination region through four ordered assignments. The destination positions are processed in the order **0, 2, 1, 3**, rather than in ascending address order.

For valid, nonoverlapping regions whose source contents remain stable, the completed operation leaves the destination’s four words equal to the source’s corresponding words. Overlap requires a different interpretation: each assignment obtains its source value at that point in the sequence. An earlier destination write can therefore affect a later source read.

This is an ordered word transfer, not an established snapshot copy or overlap-safe move.

### Nonoverlapping regions

### Identical addresses
