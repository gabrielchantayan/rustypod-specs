# F-6ff31285a1ee

## Purpose

F-6ff31285a1ee transforms four statically stored 32-bit words into a temporary 16-byte value, passes that value and a separate workspace through three dependencies, and writes a resulting byte into externally addressed storage. It then obtains an opaque 32-bit result and passes that result, together with a freshly read state byte, to a final dependency.

The destination-address global is read **twice** after the third dependency returns. The first address is retained for the later byte read. The second address selects the byte-write destination. Equality of those addresses requires the global to remain unchanged between these two reads; it is not guaranteed by the displayed accesses.

## Behavior

### 1. Read and transform the four static words

The function copies the four static 32-bit values into words 1 through 4, in that order.

It then updates the temporary fields in decreasing address order: word 4, word 3, word 2, then word 1. Each update is an unsigned right shift by one bit. The previous low bit is discarded, and the new high bit is zero.

After all four shifts, it applies a low-24-bit mask to word 4.

Consequently:

- Words 1–3 contain their respective original unsigned values divided by two, with any remainder discarded.
- Word 4 contains its original unsigned value divided by two, then restricted to the low 24 bits.

The transformations are independent. No discarded bit is transferred into an adjacent word. This is not a right shift of one combined 128-bit integer.

The function does not directly overwrite the four static source words.
