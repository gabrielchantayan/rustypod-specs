# F-bf0c3db53367

No domain-level purpose is established. The evidence does not justify identifying this behavior as parsing, formatting, allocation, rendering, or initialization. Character-like constants and recurring offsets are insufficient to establish a text interface or object model.

This contract distinguishes:

### Width and arithmetic rules

Byte accesses are 8 bits, halfword accesses are 16 bits, and ordinary word accesses are 32 bits. Byte-to-word conversions explicitly represented as unsigned widening produce values from 0 through 255. Byte stores retain the low eight bits; halfword stores have a distinct 16-bit effect.

The dependency phase includes:

- Lower- and upper-half extraction from 64-bit results.
- Unsigned 64-bit right shifts by 34, 36, and 44 positions before conversion to 32 bits.
- Logical right shifts of unsigned 32-bit quantities.
- Masks selecting fields of widths including 24, 22, 21, 20, 19, 18, 17, 16, 15, 14, 13, 12, 11, and one bit.
- Left shifts and multiplication whose represented destinations remain 32 bits.

An upper-half extraction is not a 32-bit shift by 32. Likewise, successive left shifts do not create wider storage: under a truncating 32-bit model, two successive 28-position left shifts leave zero.

Several explicitly zeroed intermediates remain zero through subsequent shifts under ordinary fixed-width interpretation. Their values do not eliminate associated calls or establish the values of other call arguments.

**Arithmetic qualification:** signed shifts, additions, and multiplication can exceed signed 32-bit range. A late signed right shift uses a count obtained from a low byte, potentially exceeding 31. The supplied representation does not resolve all underlying machine semantics. Modulo-2³² address and value arithmetic is therefore a conditional interpretation, not an unconditional language-level guarantee. The observable width of the resulting access remains material.

### Global capture survives the fixed store

If the global read captures a base of 0x2000, subsequent repeated global-relative destinations include 0x2019 and 0x2034. Even if the later fixed-address store at 0x60 changes the global storage through aliasing or mapped side effects, these destinations continue to use captured base 0x2000.

### Overlap and partial completion

A cleared word reads back as zero only if intervening overlapping effects do not change it. If execution stops during repetition, earlier calls and stores need not be undone, and the final invocation must not be reported as completed.
