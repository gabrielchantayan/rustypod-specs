# F-cb1c38417d8f

## Purpose

1. Copy a 32-bit value from a fixed global location into the first field.
2. Obtain a value from F-8157a180d901 using the argument 36, pass that result to F-3a72c6464076 with the caller’s second argument and the value 1, and store the latter dependency’s result in the second field.
3. Repeat the dependency sequence using a fresh call to F-8157a180d901 and the value 0 instead of 1, then store the resulting value in the third field.

The supplied evidence does not establish what either dependency creates, whether either allocates memory, or what the two mode values mean.
