### Initial publication and zero invariant

Shifted base is published as a word at final pair high word plus 0x14. Shifted base plus 0x09 receives the high word’s low byte. Before that byte is overwritten with shifted base’s low byte, primary base is stored at 256 times final pair low word plus 0x54.

Primary base plus 0x14 is then zeroed as a word. An unsigned byte is read at primary base plus 0x05. Index base plus 0x14 receives a zero word, followed by publication of the saved byte, zero-extended, at primary base plus 0x34.

The next word read at primary base plus 0x14 supplies the **initial zero snapshot**.

Under ordinary byte-addressed, fixed-width memory semantics, with no external mutation or access side effects, this snapshot is zero. The intervening index-base store contains only zero bits, so even partial overlap preserves zero. The four-byte range at primary base plus 0x34 is disjoint from the four-byte range at primary base plus 0x14. The represented stores therefore cannot introduce nonzero bits into this snapshot.

Index base plus 0x14 is zeroed again. Two separate byte stores then write the snapshot’s low byte at index base plus 0x15. Both are zero under the stated memory conditions.

A nonzero initial snapshot would require behavior outside that ordinary-memory model, such as external mutation, nonordinary address mapping, or read/write side effects. It is not justified by aliasing among these represented stores.
