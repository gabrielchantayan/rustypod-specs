These are **conditional acceptance criteria, not executed tests**. They assume preceding calls return, required memory accesses are valid, and the stated 32-bit arithmetic interpretation applies.

1. **Byte versus word preservation.** With third argument `0x123456AB`, both writes at doubled entry base plus `0x0D` store byte `0xAB`; the write at initial base plus `0x14` stores word `0x123456AB`.

2. **Fourth-argument truncation.** With fourth argument `0x81`, the one-bit shift produces `0x102`, and the small-selector-relative byte write stores `0x02`.

3. **Small-selector boundary.** Scaling result `0xFFFFFFFF` produces small selector `0x3FF`; the fourth-argument byte destination is therefore `0x406`.

6. **Fresh final-update indices.** If loaded base plus `0x01` contains 2 for the first phase-10 read and 9 for the second, the writes target `0x13` and `0x1A`. Reusing the first index is not equivalent.

7. **Ten-bit extraction narrowed to a byte.** Final selector `0x3FF00000` yields `0x3FF` after masking and the 20-bit right shift. Its second indexed update writes `0xFF`, not a wider value.

8. **Repeated clears.** If the final-clear source byte changes between reads, the two clears can target different addresses. Both reads and both writes remain part of the trace.
