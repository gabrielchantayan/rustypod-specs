## Behavior

1. Offset `0x28`: explicit value shifted left by six bits.
2. Offset `0x20`: first signed stack value, widened to the integer calculation width and shifted left by six bits.
3. Offset `0x24`: second signed stack value, widened similarly and shifted left by six bits.
4. Offset `0x18`: the 32-bit value read at pair-base offset `4`, shifted left by six bits.
