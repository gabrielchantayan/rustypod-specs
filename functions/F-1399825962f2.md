### Two reads before one write

An access observer must distinguish the two reads within the small-base-plus-0x74 assignment. Both precede its destination write; which read supplies the destination base is not determined by an established evaluation order.

A later third read remains separate. If the destination aliases the source, that later read can observe the write, subject to intervening effects.

### Repeated destination and global capture

If the saved base is 0x1000, both offset-0x24 writes target 0x1024 and contain 0x1000.

The retained-global load precedes the word write to 0x60. Repeated groups use that captured value even if moving the load afterward would produce a different value.

### Restricted shift counts

For saved-base values 38, 39, and 40, the defined adjusted/update calculations yield update bases 8, 24, and 40 respectively. Their shift counts are therefore 8, 24, and 40.

The third case does not establish a valid 32-bit signed shift result: count 40 is oversized. Neither count zero nor an arbitrary low-byte count is justified.

### Distinct late payload and destination

Suppose the earlier saved base is 0x1000, the late destination selector is loaded as 0x2000, and the later payload load from doubled-selector base plus 0x64 returns 0x3000. If the operations complete:

- The preceding late word write targets 0x3054 and contains 0x2000.
- The final direct store targets 0x4000 and contains 0x3000.
- Final transfer argument two is 0x2000.

Storing 0x1000 at 0x4000 would substitute the earlier saved base for a distinct late load.

### Interleaving and interruption

The retained reads from doubled-selector base plus 0x14 and update base plus 4 occur after the byte write to 0x3A. Capturing them earlier is not equivalent when the accesses interact.

The three 0x3A writes retain their distinct widths. If an earlier dependency never returns, later writes are not promised, and rollback is not promised.
