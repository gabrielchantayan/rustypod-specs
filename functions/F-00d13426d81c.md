# F-00d13426d81c

## Purpose

The supplied representation describes a non-returning sequence of indirect calls, computed-address memory accesses, and state updates. One byte is written before entry into an unconditional loop. Each loop iteration performs additional byte and 32-bit writes, reads byte-sized address selectors, reads one computed-address 32-bit word and one global word, and establishes inputs for the next iteration.

No application-level purpose is established. In particular, the evidence does not justify identifying the operation as initialization, allocation, serialization, device control, or collection traversal.

This contract describes the behavior expressed by the supplied static representation, conditional on its arithmetic, memory accesses, and indirect calls having executable meanings on the target. It does not establish that the representation accurately recovers the original executable’s calling convention or control flow.

## Interface

### Explicit inputs

The presented interface has four 32-bit input words:

| Input | Established use |
|---|---|
| First input | Passed to the first indirect call of each iteration. Replaced near the end of the iteration. |
| Second input | Passed alongside the first input. At the iteration boundary, replaced with the same shifted result as the first input. |
| Third input | Initially contributes a left-shifted argument to an indirect call. Later replaced by an indirect-call result and used in a 32-bit store. Its replacement persists into the next iteration. |
| Fourth input | Initially contributes a computed write address and a shifted call argument. Later replaced with four times the low word of a paired-word result. Its replacement persists into the next iteration. |

## Behavior

This write occurs once per function entry, not once per iteration.

### Ordered iteration

#### 1. Produce and publish the initial payload

**F-U01** consists of five calls. The first receives the current first and second inputs. The next four have no explicit arguments. The last produces a word.

The **initial payload** is that returned word shifted left by two bits.

The function writes the initial payload as a word at:

- `fourth input × 4096 + 0x14`.

**F-U02** consists of five calls. Its first receives the fourth input shifted left by 14 bits; its last returns a word designated the **first destination index**.

The function writes the same initial payload at:

- `first destination index × 4 + 0x14`.

These stores are separate operations. Aliasing does not eliminate either operation.

#### 2. Obtain the first paired result and publish a byte

**F-U03** consists of five calls. Its first receives four times the first destination index. Its last produces a paired-word result.

Define the **first scaled result** as the low word of that result shifted left by two bits.

The function then:

1. Reads a byte at `entry selector-read index × 4096 + 1`.
2. Uses that byte’s numeric value plus `0x11` as a write address.
3. Writes the byte obtained by masking the initial payload with `0x3fffffff`, shifting right by 20 bits, and truncating to eight bits.

The resulting byte represents initial-payload bits 20 through 27. The selector byte is not multiplied by a stride or added to a separate table base.

#### 3. Clear two selected byte locations

**F-U04** receives the high word of the first paired result, then makes another call producing a word. **F-U05** receives that word, obtains a paired-word result from its next call, passes both halves to its following call, makes another call, and finally obtains a word.

After those calls, the function reads a byte at:

- `first scaled result × 0x10000000 + 1`.

It writes zero at the address equal to that byte plus `0x11`.

**F-U06** begins with the final word from F-U05 shifted left by two bits, makes four further calls, and obtains a word designated the **middle index**.

The function then reads a byte at:

- `first scaled result × 4 + 1`.

It writes zero at that byte’s value plus `0x11`.

These two selector reads use different address expressions. They are not interchangeable.

#### 4. Use the third input and repeat a selected clear

**F-U07** first receives the first scaled result shifted left by 10 bits. Its next call produces a word. A subsequent call receives that word and the current third input shifted left by 28 bits. Four further calls follow, the last producing another word.

The function again reads the byte at:

- `first scaled result × 4 + 1`.

It writes zero at the newly read byte’s value plus `0x11`.

The selector is read again after intervening calls; the earlier selector value is not reused.

**F-U08** begins by receiving the final F-U07 result shifted left by two bits, followed by four calls with no explicit arguments.

#### 5. Produce and publish the middle payload

The **middle payload** is the middle index shifted left by 14 bits.

The function writes it as a word at:

- `(middle index × 4) × 4096 + 0x14`.

**F-U09** receives `(middle index × 4)` shifted left by 14 bits, then makes another call.

**F-U10** begins with two arguments:

- The middle payload shifted left by 28 bits.
- An additional dependency-produced machine word whose origin is not fully specified.

Four further calls follow, the last producing the **second destination index**.

Under 32-bit truncating arithmetic, the first argument to F-U10 is zero: the middle payload already has at least 14 low zero bits, and shifting it left another 28 bits discards every bit. The second argument remains unknown.

The function writes the middle payload at:

#### 6. Obtain the second scaled result and publish another byte

The function rereads the byte at:

**F-U23** receives the late payload word shifted left by two bits, obtains a word from its next call, then calls with that word and the late payload word shifted left by 30 bits. Four further calls produce another result.

2. Retains this particular selector value.
3. Writes the byte extracted from late-payload bits 20 through 27 at the retained selector plus `0x11`.

#### 11. Snapshot the global and establish the next iteration

The function reads the global word after the preceding word store and before the next call group.

**F-U24** begins with `late record index × 4` and obtains a paired-word result after four further calls.

The fourth input is replaced with the low word shifted left by two bits.

The function rereads the byte at `late byte base + 1` and writes the byte-truncated global snapshot shifted right by 22 bits at the selector plus `0x11`.

The next calls consume the high half of the paired result, obtain another word, and call with that word and the replacement fourth input shifted left by 28 bits. Four further calls produce a result.

- The first-call anchor is replaced with a fixed continuation-derived anchor.

## Acceptance examples

These are conditional static examples, not runtime test results.

1. **Entry ordering.** With valid entry state, the entry byte write occurs before the first indirect call. No loop-body call precedes it.

2. **Initial payload arithmetic.** If F-U01 returns `3` and the fourth input is `2`, the initial payload is `12`, written at `0x2014`. If F-U02 returns `5`, the second write of that payload is at `0x28`.

3. **Selector interpretation.** If a specified selector-byte read returns `0xa0`, its selected byte-write address is `0xb1`. It is not an address loaded from a pointer-sized field.

4. **Byte extraction.** An applicable payload of `0x3ab00000` produces byte `0xab` through the masked extraction. The wider shifted value is truncated to eight bits.

5. **Selector mutation across calls.** If a dependency changes a repeatedly read selector from `0x20` to `0x40`, the later selected address is `0x51`, not the earlier `0x31`.

6. **Retained-selector exception.** If the retained late selector is `0x20`, the replacement-third-input word store targets `0x34`, even if intervening calls change the source selector byte to `0x40`.

7. **Arithmetic collapse.** Under wrapping 32-bit arithmetic, F-U10’s middle-payload-derived first argument is zero for every middle index. This does not constrain its additional machine-word argument.

8. **Global snapshot.** A dependency modifying the global after its explicit read does not change the snapshot used for the later extracted-byte write.

9. **No successful return requirement.** Reaching the iteration boundary establishes continuation with updated inputs, not completion of the function.
