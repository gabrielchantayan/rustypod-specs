# F-c22cd43bf418

## Purpose

F-c22cd43bf418 evaluates a strict, direction-selectable ordering between a value obtained through an indirect reference and a comparison value stored in the supplied record. It returns a four-byte Boolean result.

The direction is selected by a one-byte field:

- When the field is zero, the result is 1 exactly when the indirectly obtained value is strictly less than the comparison value.
- When the field is nonzero, the result is 1 exactly when the indirectly obtained value is strictly greater than the comparison value.
- Equality produces 0 in both modes.

This comparison behavior is established by the supplied static representation. The application-level meaning of the records, values, direction field, and result is unknown.

## Behavior

### Observable read order

The displayed behavior performs its reads in this order:

1. Read the four-byte address-bearing field at offset +4 in the supplied record.
2. Using that value as the base of the second record, read its signed four-byte value at offset +92.
3. Read the one-byte direction selector at offset +28 in the supplied record.
4. Read the signed four-byte comparison value at offset +8 in the supplied record.
5. Return 0 or 1 according to the selected strict comparison.

The indirect value is therefore obtained before the direction selector and comparison value. Both direction branches read the comparison value, but neither branch reads the indirect value again.

This order describes the supplied static representation. It is not an independently established guarantee about physical load timing, compiler transformations, volatile accesses, or processor memory ordering.

### Zero direction selector

When the direction byte equals zero, the function returns:

- 1 if the indirect value is less than the comparison value.
- 0 if the indirect value is equal to or greater than the comparison value.

The comparison is signed. In particular, negative values sort below zero and positive values.

### Nonzero direction selector

When the direction byte does not equal zero, the function returns:

- 1 if the indirect value is greater than the comparison value.
- 0 if the indirect value is equal to or less than the comparison value.

The selector is tested only for equality with zero. There is no distinct behavior for different nonzero byte patterns. Whether a nonzero byte would otherwise be interpreted as a positive or negative character does not affect this selection.
