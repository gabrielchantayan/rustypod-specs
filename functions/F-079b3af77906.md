### Count transformation

For an unsigned input count \(n\), the resulting value is:

\[
\left\lfloor \frac{n}{2} \right\rfloor
\]

The transformation has these properties:

- The low bit is discarded.
- Even values divide exactly by two.
- Odd values round down.
- Zero remains zero.
- The maximum unsigned 32-bit input, 4,294,967,295, becomes 2,147,483,647.
- There is no rounding upward, saturation, multiplication, or additional subtraction.

The operation uses the unsigned interpretation of the count. A high bit does not make the count negative.

No range check ties the reported count to either 150 or 152. The wrapper does not establish whether any particular reported count is safe for the second dependency.
