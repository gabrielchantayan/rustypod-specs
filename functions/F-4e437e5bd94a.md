# F-4e437e5bd94a

## Purpose

F-4e437e5bd94a performs a destructive status check over two externally stored values. It restricts one status location to bit 11, samples a one-byte flag through an externally stored base address, clears that flag, and returns whether either sampled condition was nonzero.

The operation is not a read-only query. The status write and the flag clear occur regardless of whether the result is true or false. In particular, status bits other than bit 11 do not contribute to the result and are removed by the status write.

Interpreting the locations as hardware status and an event flag is plausible intent, not established behavior. Their ownership, volatility, synchronization requirements, and device semantics are not supplied.

## Behavior

### Ordered state interaction

The supplied representation establishes this sequence of external state interactions:

1. Read the status slot, retain only bit 11, and write the masked value back to the status slot.
2. Resolve the base reference and read the byte at the resulting address plus one byte. Retain the sampled byte for the eventual return decision.
3. Read the status slot again and retain whether this later read is nonzero.
4. Resolve the base reference for the flag destination and write zero to the byte at that address plus one byte.
5. Return the logical OR of the retained status predicate and the retained flag-byte predicate.

This ordering is important. The returned status predicate comes from a read after the masking write and after the flag sample. It is not simply calculated from the initial status value.

Likewise, the flag predicate uses the sampled byte, not a read performed after clearing it. Clearing the flag therefore does not erase its contribution to this invocation’s result.

Both inputs have already been sampled, and both writes have already been attempted, before the final Boolean result is formed. A true status predicate does not skip the flag read or flag clear.

### Status transformation

The status write preserves only bit 11 from the value used by the initial read. Every other bit in that value is written as zero.

Under ordinary stable-memory conditions, the value written is therefore either:

- Zero, when bit 11 was clear; or
- 0x800, when bit 11 was set.

The operation is a read followed by a write in the supplied representation. No atomic read-modify-write primitive, lock, or critical section is shown.

The later status test checks for any nonzero value. It does not independently apply the bit-11 mask again. Consequently, if another participant changes the status slot between the write and the later read, a newly set bit other than bit 11 can make the returned status predicate true.

Conversely, if another participant clears bit 11 before that later read, the status predicate can be false even though the masking write retained bit 11.

### Flag consumption

Every nonzero flag-byte value has the same effect on the result. There is no decoding of individual flag bits or validation of a particular nonzero encoding.

The clear writes a full zero byte. It does not selectively clear a bit, decrement a counter, or restore the sampled value.

The base reference is used in separate expressions for the read and the clear. The fragment does not establish a retained address shared between them. With a stable base reference, both accesses target the same byte. If the reference changes between those evaluations, the sampled byte and cleared byte may be different locations.

Whether machine execution actually reloads the reference, or preserves and combines accesses under the applicable memory model, is not established by this fragment.

### Stable-state result

With ordinary memory, a stable base reference, no aliasing between the relevant locations, and no intervening changes:

- The result is true exactly when the initial status value had bit 11 set or the initial flag byte was nonzero.
- The final status slot contains only the initial value of bit 11.
- The final flag byte is zero.

These are conditional conclusions, not guarantees in the presence of concurrent writers, device-specific access semantics, or overlapping storage.

- A zero-byte write through the base reference at offset one.

Both writes occur on the normal path, including when the result is false. There is no branch that preserves unrelated status bits or leaves a nonzero sampled flag intact.

The function may destroy information:
