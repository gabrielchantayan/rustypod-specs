## Acceptance examples

These are conditional static consequences, not executed tests.

1. **First write precedes calls.** If the initial selector is 255 and the entry byte is `0xab`, the first write stores `0xab` at numeric address 272 before any indirect invocation.

2. **Selector reload changes destinations.** If a paired byte update first reads selector 3, then an intervening dependency changes that selector location to 9, the writes target addresses 20 and 26. Reusing the first selector would violate the trace.

3. **Byte truncation.** A left-by-two byte update using `0x123456ff` stores `0xfc` under the 32-bit bit-vector interpretation.

4. **Masked fragment truncation.** For `0xffffffff`, masking with `0x3fffffff` and logically shifting right by 20 produces `0x3ff`; the byte write stores `0xff`.

5. **Distinct global snapshots.** If the two global reads differ, the later masked call argument derives from the first read, while the address base derives from four times the second.

6. **Wide-result stores.** If the high half is 7 and the low half is 3, the high-selected zero store targets address 48. Under 32-bit modular arithmetic, the first low-derived store targets `0x30000014` and stores `0x0c000000`.

7. **Large-shift collapse.** Under 32-bit modular arithmetic, shifting any 32-bit quantity left by 26 and then multiplying by 1024 yields zero. The associated byte-selector address is therefore one under that interpretation.

8. **Fourth construction captures before calls.** Suppose its construction index is 2. The formed word is 8, stored at address 52; the subsequent capture reads address 28. If that read yields `0x12345000`, an intervening dependency changes address 28, and the later destination index is 3, address 32 receives `0x00012345`. The later mutation does not replace the captured value.

9. **Construction count and pairing.** If the full construction sequence is reached, there are five construction stores and five corresponding later stores. Four later stores copy their construction’s formed word; the fourth stage instead stores its captured word shifted right by 12. This is five constructions and four complete pairs, not six constructions.

10. **Partial execution is not success.** If the first indirect call never returns, the initial byte write has already occurred. Conversely, reaching the final boundary does not establish normal return or a success code.
