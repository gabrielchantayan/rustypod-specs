# F-e135feff4093

## Purpose

- The 32-bit field at object offset **0x14** is nonzero.
- That field is zero and the byte at offset **0x0B** in a referenced object has mask **0x10** set.

## Behavior

### Primary decision

The first evidenced data access is a 32-bit read at the input address plus **0x14**. The value read is compared with zero.

If it is nonzero, the function returns **true**. In this case:

- The referenced-address field at offset **0x04** is not read.
- The flag byte is not read.
- No information from those locations affects the result.

A negative signed interpretation of the primary field does not change this behavior. The predicate distinguishes only zero from nonzero.

### Conditional flag decision

If the primary field is zero, the function reads the 32-bit referenced address from input offset **0x04**.

It then reads exactly one byte at that referenced address plus **0x0B**. The byte is treated as unsigned and widened without sign extension before the mask is applied.

The function returns:

- **True** if mask **0x10** is present.
- **False** if mask **0x10** is absent.

Only that bit matters. Other bits in the byte do not contribute to the result. In particular, a byte may be nonzero and still produce **false**.

No second read of the primary field is evidenced. Once the initial read has selected a path, the function does not revisit that decision.
