# F-766473d455b3

## Purpose

F-766473d455b3 performs a conditional lookup through a caller-supplied record and returns a 32-bit value obtained from the lookup result.

The established behavior has three early outcomes:

- If the record’s initial 32-bit reference is zero, return `0xFFFFFFFF`.
- If that reference is nonzero but a secondary reference at byte offset `0x1B0` is zero, return `0x00000000`.
- If dependency F-a2a686313150 returns zero, return `0x00000000`.

Otherwise, the function follows two fields from the dependency’s result and returns the final 32-bit word unchanged.

The apparent intent is to retrieve a property associated with a signed selector. That interpretation is inferred, not established: the available evidence does not identify the referenced objects, the property’s meaning, or the dependency’s lookup rules. In particular, a zero return does not uniquely indicate lookup failure, and `0xFFFFFFFF` is not established as a universally reserved error value.

### Secondary reference decision

The function reads a 32-bit value at byte offset `0x1B0` from the outer reference used for this access.

If the secondary reference is zero, the function returns zero. It does not read the selector or call the dependency on this path.

If the secondary reference is nonzero, it is retained as the dependency’s first argument. No additional validation of that reference is established.

### Selector conversion and dependency call

The function reads the 16-bit field at byte offset `0x1A` of the input record as a signed integer. It widens that value to a signed 32-bit integer by sign extension, not zero extension.

Consequently:

- `0x0000` becomes `0`.
- `0x7FFF` becomes `32767`.
- `0x8000` becomes `-32768`.
- `0xFFFF` becomes `-1`.

The function calls F-a2a686313150 exactly once on this path, supplying:

1. The nonzero 32-bit secondary reference.
2. The sign-extended selector.

There is no locally established restriction against negative selectors.

The secondary reference and selector have been read before the call. Changes made by the dependency do not retroactively change those argument values. This does not imply that the dependency preserves the input record, any referenced object, or any global state.

### Dependency result decision

If F-a2a686313150 returns zero, F-766473d455b3 returns zero without traversing a result object.

If the dependency returns nonzero, that result is treated as the address of an object containing a 32-bit reference at byte offset `0x7C`.

The function reads that reference and then reads a 32-bit word at byte offset `0x04` from the referenced object. It returns this last word without transformation.

There is no explicit zero test for the reference read at offset `0x7C`. If that reference is zero, the next attempted access is at address `0x00000004`; the function does not deliberately convert that condition into a zero return.
