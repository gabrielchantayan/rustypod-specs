## Behavior

### Normal completion

Normal completion is established for an execution in which both guard reads produce zero and the required memory operations succeed.

The first guard is read before the second. Only after both guard decisions have passed does the function clear the first reset field and then the second reset field. Each clearing operation writes a four-byte zero value.

The function then returns without an explicit result.

On this path:

- Neither dependency is called.
- The previous contents of either reset field are irrelevant to the decision.
- The reset fields are not read before being overwritten.
- The guard fields are not directly written.
- No blanket clearing of the containing region occurs.

The function performs the clearing writes even if the reset fields already contain zero. There is no visible equality check that skips a redundant write.

### External handling selected by the first guard

If the first guard read produces a nonzero value, the function invokes F-ffa7163332aa. If that call returns normally, the next call is F-feee9156a257.

Before this call sequence, the function has not read the second guard or written either reset field. Thus, selection by the first guard does not depend on the second guard’s value.

Under the supplied non-returning description of F-feee9156a257, this path does not reach the second guard read or either clearing write. No normal return from F-409402753026 is established for it.

If F-ffa7163332aa itself does not return, the subsequent dependency call is not reached. Its return behavior is not provided.

### External handling selected by the second guard

The second guard is read only after the first guard has been read as zero.

If the second guard is nonzero, the same dependency sequence is selected: F-ffa7163332aa, followed by F-feee9156a257 if the first call returns normally.

Neither clearing write occurs before this sequence. Under the represented non-returning behavior of the second dependency, neither clearing write is subsequently reached.

These are conditional acceptance criteria derived from static evidence, not executed tests. They assume valid memory and successful memory operations unless stated otherwise.

1. **Both guards are zero.**  
   Given arbitrary initial reset-field contents, the function reads the first guard and then the second, writes four-byte zero values to +0x2C and +0x34 in that order, and returns normally. Neither dependency is invoked.

2. **The first guard is nonzero.**  
   The function invokes F-ffa7163332aa without first reading the second guard or clearing either reset field. If the dependency returns normally, F-feee9156a257 is called next. Under its represented non-returning behavior, the clearing operations are not reached.

4. **A guard contains a nonzero value other than one.**

5. **The reset fields already contain zero.**  
   With both guard reads zero, both clearing writes still occur. The established behavior is not a read-and-skip optimization.

6. **The first dependency changes memory.**  
   If F-ffa7163332aa returns after modifying the supplied region, the next established action is the call to F-feee9156a257. No intervening guard re-evaluation or reset-field write is shown. Final memory contents cannot be predicted without dependency behavior.

7. **Repeated normal-path calls.**
