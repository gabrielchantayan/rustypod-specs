# F-41bb5880f4ae

## Purpose

F-41bb5880f4ae partially initializes or updates a destination record from a source record and two auxiliary 32-bit inputs. It performs an initial copy and dependency-mediated check, converts four signed source values, resolves an external object, and conditionally derives additional destination fields from that object.

The operation is not transactional. A return indicating failure can follow destination writes and dependency side effects. An early return whose low word is one does not imply that the full initialization path ran.

The apparent intent is to configure a resource-backed record containing scaled values and derived metrics. That interpretation is inferred; the established contract is the field access, dependency-call, and return behavior below.

### Rounding and width boundaries

For inputs whose intermediate signed arithmetic is representable, rounding divides by 64 to the nearest integer, with exact halves rounded away from zero. Examples include:

- 31 → 0
- 32 → 1
- 95 → 1
- 96 → 2
- −31 → 0
- −32 → −1
- −96 → −2

The operation forms a magnitude, adds 32, shifts right by six, and restores the sign. For arbitrary signed 32-bit inputs, negating the minimum value or adding 32 near the positive limit can overflow. Exact outcomes for those cases are documented_only.
