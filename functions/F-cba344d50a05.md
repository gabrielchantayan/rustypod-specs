## Behavior

3. The invocation receives four integer arguments, in order: zero, zero, zero, and 34.
4. If the invocation returns normally, the zero-valued intermediate is assigned to the abort-related global destination.

The indirect invocation precedes the global assignment. The visible sequence does not clear the global before invoking the dependency.

The invocation’s return value, if any, is not consumed by the recovered body. No return-value-dependent branch is visible. In particular, the global assignment is not visibly conditioned on the dependency reporting success.
