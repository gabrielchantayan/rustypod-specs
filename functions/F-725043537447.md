# F-725043537447

## Purpose

F-725043537447 selects a 32-bit result through three ordered dependency-and-comparison stages, followed by a fallback obtained from caller-supplied storage or a global value.

Each comparison stage can terminate the function immediately. A comparison result equal to zero selects that stage’s associated global result. Any nonzero comparison result advances to the next stage. If all three comparisons are nonzero, the function selects between a field at byte offset 44 from the supplied base and a final fallback global.

This is an established description of the selection behavior. Interpreting the comparisons as string equality, the returned values as handlers, or the function as a history resolver would be inferred intent, not an established contract.

### Final field selection

The supplied representation shows two accesses to the 32-bit field at input base plus 44:

1. A first field value is retained as the provisional result.
2. A subsequent field value is tested for equality to zero.

If the tested value is zero, the function reads R4 and returns that global value.

If the tested value is nonzero, the function returns the first field value.

For stable ordinary storage, both accesses yield the same value. The resulting behavior is then straightforward: return the field when nonzero; otherwise return R4.

For storage that can change between accesses, the two values need not agree. In the represented behavior, a nonzero tested value does not guarantee a nonzero return: the first value could have been zero. Conversely, a nonzero first value does not prevent fallback selection if the tested value is zero.
