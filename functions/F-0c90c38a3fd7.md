# F-0c90c38a3fd7

## Purpose

F-0c90c38a3fd7 selects a record, associates it with a 32-bit input value, and attempts a subordinate operation only when a classification dependency returns exactly 6. It returns the selected record when that subordinate operation returns a nonzero value. Otherwise, it reports an error and returns a null pointer, with conditional cleanup of the selected record.

The record can come from a caller-supplied pointer slot or from a record-provider dependency. A successful operation publishes the selected record through the caller’s slot, if one was supplied. Failure does not roll back record writes already performed.

**Established behavior:** record selection, field-write order, classification gating, conditional publication, error-call argument values, and the final cleanup condition are visible in the supplied static evidence.

**Inferred intent:** the operation appears to initialize or reuse a record containing a classification, an input value, and a subordinate result. Allocation, resource ownership, and the semantic meaning of classification 6 are not established.

## Behavior

### Record selection

If the pointer-slot address is nonnull, the function first reads its current record pointer. A nonnull pointer obtained by this read becomes the selected record, and the record-provider dependency is not called.

Otherwise, the function calls F-19dae32a5b2b with no visible arguments. Its returned pointer becomes the selected record.

If that returned pointer is null, the function:

- Calls F-4fc89ec41a6d with the five visible argument values 13, 155, 6, 0, and 0, in that order.
- Returns null after that call returns.
- Performs no direct record write and makes no cleanup call.

This path does not reread or publish to the caller’s slot. The provider or error dependency may nevertheless have side effects; their behavior is not established here.

### Record preparation and classification

Once a nonnull record has been selected, the function directly writes the first input value to offset 4.

It then calls F-c934f9d79bc0 with that same input value. After the dependency returns, the function writes its 32-bit result to offset 0.

The classification decision uses the returned value. Only an exact result of 6 permits the subordinate operation. Zero, negative values, and every other representable value take the post-selection failure path.

The ordering is observable:

- The offset-4 write precedes the classification call.
- The offset-0 write follows that call.
- A classification dependency that independently accesses the record could observe the first write before the second occurs.
- The function does not read the record’s previous classification before replacing it.

No visible arithmetic transforms either the input or the classification result.

### Subordinate operation and success

When classification returns exactly 6, the function calls F-77a218144a40 with:

- A first argument equal to zero.
- The first opaque argument.
- The second opaque argument.

Its returned four-byte value is written to offset 12 before the function tests whether that value is zero.

A nonzero result is success. If the caller supplied a pointer-slot address, the function writes the selected record pointer into that slot. It then returns the selected record pointer.

Success does not require the slot still to contain its initial value. Publication occurs unconditionally whenever a slot address was supplied, including when the same record was initially obtained from that slot.

The function does not revalidate classification or inspect the record after the subordinate call. Consequently, the visible write sequence does not guarantee final values for fields that a dependency subsequently changes. For example, the subordinate dependency could alter offsets 0 or 4 without this function detecting or restoring them.

A zero subordinate result is failure. The zero is still written to offset 12 before failure processing begins.

### Post-selection failure and cleanup

Either of the following reaches the same post-selection failure path:

- Classification returns a value other than 6.
- Classification returns 6, but the subordinate operation returns zero.

The function first calls F-4fc89ec41a6d with the two visible argument values 13 and 155.

Only after that call returns does it decide whether to invoke cleanup:

- If the pointer-slot address is null, it calls F-55d57b266fd4 with the selected record.
- If the pointer-slot address is nonnull, it rereads the pointer currently stored there. It calls F-55d57b266fd4 only if that pointer differs from the selected record.
- If the reread pointer equals the selected record, it does not call cleanup.

It then returns null.

This is a current-pointer-equality rule, not an allocation-origin rule. The decision is not based solely on whether the record came from the provider or was initially supplied by the caller. In particular, side effects of classification, the subordinate operation, or error reporting may affect the slot value used by this decision.

The failure path does not directly clear the caller’s slot, restore an earlier slot value, restore overwritten record fields, or clear offset 12 when classification did not reach the subordinate operation.
