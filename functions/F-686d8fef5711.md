### Disabled store

If the incoming condition is false, the function omits the represented store and proceeds to the same unresolved boundary.

The explicit input byte does not otherwise affect any visible operation on this path. No destination-memory read is represented merely to decide whether to write.

This permits a narrow distinction: a false condition avoids the shown destination access. It does not establish successful function completion, because the following boundary remains unresolved.
