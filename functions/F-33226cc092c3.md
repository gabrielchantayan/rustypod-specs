## Behavior

### Byte examination and stopping rules

The accumulated count begins at zero.

When the current limit is nonzero, the function reads one byte from the current address. A zero byte ends the scan immediately. That terminating byte is not counted.

A nonzero byte is counted. The limit is then decreased by one, and the current address advances by one byte. Examination can continue from the new address.

When the current limit is zero, the scan ends without reading a byte at the current address. This applies both to an initially zero limit and to a positive limit that has just been exhausted.

These rules distinguish two stopping conditions:

- **Zero-byte termination:** the zero byte is read but not counted.
- **Limit exhaustion:** no byte beyond the exhausted limit is read.

For a positive initial limit and readable, stable storage, the count is the number of consecutive nonzero bytes preceding the first zero within the allowed range, or the initial limit if no such zero occurs.

A byte with its high bit set remains nonzero. Values from 128 through 255 are counted just as values from 1 through 127 are counted; no signed-byte interpretation affects termination.

2. Perform any required scan reads in increasing address order.
