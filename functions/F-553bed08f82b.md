## Behavior

1. Read the four-byte object-address representation at the input address.
2. Read the four-byte table-address representation at the resulting object address.
3. Locate the dispatch entry at a displacement of 28 bytes from the table address.
4. Obtain the callable address stored at that entry.
5. Invoke or transfer control to that callable address.
6. If control returns normally under the recovered calling model, return without an explicit result.
