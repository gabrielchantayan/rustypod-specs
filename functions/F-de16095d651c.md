# F-de16095d651c

## Purpose

F-de16095d651c exposes a partially recoverable sequence of indirect invocations, an intervening byte read and byte write, and two transformations of dependency results into later arguments.

Its application-level purpose is unknown. The supplied static representation supports a contract for the visible ordering and data flow, but not an assertion that this is a complete, valid, normally returning routine. The representation explicitly reports invalid instruction data and terminates at an unrecovered instruction boundary.

The central observable behavior, conditional on the preceding invocations returning and the memory accesses succeeding, is:

- Make five indirect invocations.
- Read one byte through an inherited address-bearing state value.
- Use that byte to select a low numeric destination address.
- Write one byte derived from a separate inherited 32-bit state value.
- Make seven further indirect invocations, forwarding transformed results and the previously read byte.
- Reach an instruction boundary whose actual execution behavior is not established.

This is a static-evidence contract. No runtime tests have been performed.
