# F-c98ed7b94040

## Purpose

F-c98ed7b94040 performs an initialization sequence over storage obtained through two dependencies. It writes fixed-width defaults, invokes initialization and configuration dependencies for three embedded regions, selects two 32-bit values through either direct input reads or dependency calls, and returns a base address derived from an intermediate address.

**Established static behavior:** the function returns the intermediate address minus 0x108. It does not simply return the address supplied by its first dependency.

**Inferred intent:** the operation resembles construction or initialization of a composite object containing three configurable subobjects. The source does not establish object types, field meanings, allocator semantics, or whether any configured quantity represents time.

This contract describes the supplied static representation. It does not claim runtime validation or resolve ambiguities in the recovered calling convention.

## Behavior

The function first captures S from the incoming stack location.

It then performs these operations in order:

1. Calls F-da04303b789f without visible arguments and receives P.
2. Reads K0 and writes its 32-bit value at P.
3. Calls F-78801ca166f2 with P + 0x108 and receives A.
4. Computes B as A − 0x108.

The source does not establish that A equals P + 0x108. Consequently, it does not establish that B equals P.

### 4. Copy one input word and select a branch

1. Reads 32 bits from S + 0x64.
2. Writes that value to A + 0x1C.
3. Reads a 32-bit word from A − 0xC0.
4. Tests whether mask 0x20000000 is clear.

Only the masked bit determines this branch. Other bits do not directly affect the decision.

The flag read occurs after all initialization and configuration calls. It is not a snapshot taken before them.

### 5. Produce the two selected values

#### Mask clear: direct input path

If the masked bit is clear:

1. Read 32 bits from S + 0x5C.
2. Write that value to A − 0x08.
3. Read 32 bits from S + 0x60.
4. Write that value to A − 0x04.

Neither conditional F-5710a8628cba call occurs on this path.

The first destination store precedes the second input read. If storage aliases, the second read observes memory as it exists after that store, not necessarily as it existed at function entry.

#### Mask set: dependency-derived path

If the masked bit is set:

1. Call F-5710a8628cba with three 32-bit arguments:
   - the word at A − 0xD0;
   - K1;
   - the word at A − 0xC4.
2. Store its 32-bit result at A − 0x08.
3. Call F-5710a8628cba again with:
   - the word at A − 0xD0;
   - K2;
   - the word at A − 0xC4.
4. Store its 32-bit result at A − 0x04.

The first result is stored before the second call.

The words at A − 0xD0 and A − 0xC4 are read again for the second call. They must not be treated as necessarily equal to the first call’s arguments: the first call, its result store, or aliasing may affect them. The relative evaluation order of arguments within either call is not established here.

There is no visible error check on either result. Any returned 32-bit pattern is stored.

### 6. Complete the final state and return

After either branch, the function performs these operations in order:

1. Writes 32-bit zero to A + 0x10.
2. Reads 32 bits from A − 0x08 and writes the value to A + 0x14.
3. Writes 32-bit zero to A + 0x18.
4. Reads 32 bits from A − 0x08 again and writes the value to A − 0x0C.
5. Reads a 32-bit integer at S + 0x68 and writes a one-byte Boolean at A + 0x60: zero for an all-zero input, one otherwise.
6. Reads 32 bits from S + 0x68 again and writes that value to A + 0x98.

The Boolean operation tests nonzero, not positivity. A value with only its highest bit set therefore produces Boolean one.

The two reads from S + 0x68 are distinct. The Boolean store lies between them. Consequently, agreement between the Boolean and the later 32-bit copy requires the underlying source value to remain unchanged across those operations.

## Acceptance examples

These examples are conditional static expectations, not executed tests.

### Direct-copy branch with stable, non-aliasing storage

Assume the flag mask is clear, dependencies return normally, and relevant storage does not change unexpectedly. Let:

- S + 0x64 contain 0x12345678;
- S + 0x5C contain 0x11223344;
- S + 0x60 contain 0x55667788;
- S + 0x68 contain zero.

Expected explicit results include:

- A + 0x1C receives 0x12345678.
- A − 0x08, A + 0x14, and A − 0x0C receive 0x11223344.
- A − 0x04 receives 0x55667788.
- A + 0x10 and A + 0x18 receive zero.
- A + 0x60 receives one-byte zero.
- A + 0x98 receives 32-bit zero.
- F-5710a8628cba is not called.
- The return value is A − 0x108.

### Dependency-derived branch

Assume the mask is set and the two F-5710a8628cba calls return 0x01020304 and 0xA0B0C0D0.

With stable, non-aliasing relevant storage, A − 0x08, A + 0x14, and A − 0x0C receive the first result; A − 0x04 receives the second.

If the first call changes the word at A − 0xD0, the second call receives the changed word. An implementation that unconditionally reuses the first call’s captured argument would not preserve the described behavior.

### Nonzero Boolean input

If both reads at S + 0x68 observe 0x80000000, the byte at A + 0x60 becomes one, while A + 0x98 receives 0x80000000. The Boolean conversion does not reduce the later copied word to one.

### Aliasing-sensitive final reads

If S + 0x68 aliases A + 0x60, the Boolean store may change bytes that the subsequent 32-bit input read consumes. The resulting word depends on byte layout and prior contents. Acceptance must preserve the read–store–read sequence rather than require both reads to return an identical value.

### Distinct returned base

If F-78801ca166f2 returns an address different from P + 0x108, successful execution still returns A − 0x108, not P.
