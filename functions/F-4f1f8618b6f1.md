# F-4f1f8618b6f1

## Purpose

The operation proceeds only when the second argument equals 2 and the third argument satisfies a subtraction comparison. Under ordinary 32-bit arithmetic, the accepted third-argument value is 10008, hexadecimal 0x2718. ## Behavior

### Selection and rejection

The second argument determines whether the numeric condition is relevant.

If the second argument is not 2, the function returns 0. The third argument need not satisfy any condition on this path. The function does not call F-c0c0b8633623 or directly read or write memory through the first argument.

If the second argument is 2, the function subtracts 9216 from the third argument and compares the result with 792. Failure of this comparison also produces a return value of 0 without the dependency call or destination write.

The accepted third-argument value follows from:

**9216 + 792 = 10008 = 0x2718.**

For the accepted value, the subtraction produces 792 without signed overflow in an ordinary 32-bit interpretation. Under 32-bit modular arithmetic, 0x2718 is also the unique accepted input bit pattern.

The evidence does not resolve source-language signed-overflow behavior for extreme rejected inputs.
