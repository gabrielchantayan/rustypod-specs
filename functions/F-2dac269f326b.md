### Search domain and order

For a positive bound \(N\), the candidate indices are the integers from zero through \(N-1\), in ascending order.

Before each potential probe, the function compares the current index against the captured bound using signed ordering. It returns when the index has reached or exceeded that bound.

Consequently:

The probe dependency receives the original object-address argument and the current index. A zero probe result means that searching may continue. Any nonzero result ends the search and selects the triggered sequence; the result’s magnitude and sign have no further significance.
