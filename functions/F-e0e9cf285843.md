## Behavior

- If bit 0 is set, none of the four dependencies is called.
- If bit 0 is clear, the function proceeds to the second gate.

The offset is a byte displacement of 8; it is not an index of eight 32-bit elements. No range check, null check, or explicit address-overflow check appears before this access. ### Dependency gate
