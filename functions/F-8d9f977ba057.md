## Acceptance examples

These are conditional specification examples, not reported executions. They assume relevant memory is accessible, dependencies return as described, and no unspecified interference alters the particular observations.

### Initial store precedes dependency execution

With P = 3, the first visible store writes the 32-bit value 3 at address 32. That store precedes F-000000000001 receiving 3.

A behavior that defers this store until after the first call does not match the visible ordering.

### Distinct word-read and word-write locations

With R2 = 2, the scaled value S2 is 8. The routine writes 8 at address 52 and subsequently reads a word from address 28.

Reading the word from address 52 instead would incorrectly collapse the distinct scale factors.

### Aliasing within the word stage

With R2 = 0, the write and read addresses are both 20. If ordinary memory retains the completed write and there is no external interference, V is zero.

This example is conditional on memory behavior; it is not a universal claim for device-backed memory.

### Unsigned extraction

If V = 0xFEDCBA98 and R3 = 4, the later 32-bit store writes 0x000FEDCB at address 36.

An arithmetic right shift yielding a sign-extended value would not match the unsigned read and shift.

### Byte reread can change the destination

Suppose R6 = 0x0AB00003, the first byte read yields 5, and the second yields 9.

The first byte write stores 0x0C at address 22. The second stores 0xAB at address 26. F-000000000043 later receives 9 as its second argument.

Reusing the first byte would incorrectly redirect the second write and change the final argument.

### Repeated byte destination

Under the same R6, if both byte reads yield 5 and no other relevant write intervenes, both byte writes target address 22. The second changes the byte there from 0x0C to 0xAB.

The final stored byte need not preserve the first write, but both accesses remain part of the visible sequence.
