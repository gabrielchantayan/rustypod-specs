# F-3044f680bd12

## Purpose

F-3044f680bd12 conditionally obtains two pointer-valued results, invokes an indirect operation associated with the second result, and passes that operation’s 64-bit result to an indirect operation associated with the first result. The last operation also receives the address of a mutable 32-bit result cell. On the completed path, the function returns the cell’s final contents.

If either pointer-valued result is null, the function returns the 32-bit value zero without invoking the later operations.

This is a source-facing behavioral contract based on the supplied static representation. It does not establish the application-level purpose of the objects, the meaning of the 64-bit value, or the semantics of the indirect operations.
