The established behavior is a status-gated result, not a Boolean conversion:

- A status greater than or equal to one retains the first 32-bit word of temporary storage.
- A status less than one forces that word to zero.
- The wrapper returns the resulting word without a visible conversion or interpretation.

## Behavior

2. The value obtained from the global data item.

No retry, alternate dependency, or wrapper-level recovery path is present.

### Status selection

After the dependency returns normally, the wrapper compares its returned status against one using a signed integer comparison.

In the represented 32-bit integer model:

- Statuses from −2,147,483,648 through zero select the zero-result path.
- Statuses from one through 2,147,483,647 select the retained-result path.

This is not a nonzero test. Negative statuses do not retain the dependency’s output.

The comparison introduces no visible addition, subtraction, narrowing, saturation, or overflow-dependent behavior.

### Status below one

When the status is less than one, the wrapper writes zero to the first temporary word after the dependency returns.

This write supersedes whatever value the dependency may have placed in that word. The wrapper then returns zero.

The overwrite affects only the first word. It is not evidence that the dependency’s other effects are rolled back, that the full temporary storage is cleared, or that any resource is released.

### Status at least one

When the status is at least one, the wrapper performs no visible replacement of the first temporary word. It returns that word’s post-call contents.

Consequences include:

- A dependency-written output is retained.
- If the dependency leaves the first word unchanged, the initialized zero is retained.
- If the dependency changes only the second word, that change does not directly affect the wrapper’s selected return value.
- A positive status does not imply a nonzero result.

The wrapper has no visible validation of the retained output.

### Abnormal execution
