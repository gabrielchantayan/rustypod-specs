# F-d0aa875f3558

The established contract consists of visible calls, memory accesses, branch conditions, and return propagation. “Acquisition,” “interpretation,” “buffer,” and “cleanup” describe apparent roles; they do not establish resource types or dependency contracts.

Two mutable-storage properties are significant:
