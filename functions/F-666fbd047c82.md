# F-666fbd047c82

## Purpose

The established behavior is narrowly defined:

- Read the four-byte dependency argument at byte offset 4.
- Invoke F-ce26009319e1 with that value.
- After the invocation returns normally, write zero at byte offset 446.

The apparent intent is to clear one state indicator and, on one dependency outcome, enable two adjacent indicators. That interpretation is inferred intent only. No business meaning, success convention, or field names are established.

### Writes after normal return

- **Zero result:** write the one-byte value one at offset 444, then write the one-byte value one at offset 445.
