The established behavior is target selection and invocation. The supplied evidence does not identify the selected operation, its argument requirements, or its effects. A fixed-slot object or interface dispatch is a plausible interpretation, not an established semantic identity.

This contract separates the wrapper’s explicit operations from the unknown behavior of its selected target. It also distinguishes the recovered integer calculation from native address arithmetic. No runtime tests have been performed.

4. Read the callable-pointer entry at that address.
5. Invoke the selected target.
6. Return from the wrapper if the target returns normally.

The first read supplies the operand needed to calculate the lookup location. The entry read supplies the target needed for the indirect invocation. The wrapper therefore does not resolve the entry independently of its input.
