# F-91952b324604

## Purpose

F-91952b324604 selects between two behaviors using a signed test of the third explicit argument after adding 100:

- A short path calls a dependency and writes a 20-byte record at an address obtained from that dependency’s result.
- A long path performs an ordered sequence of memory accesses, indirect calls, result splitting, and a final unresolved control transfer.

The application-level purpose of the long path is not established. The short path resembles record construction, but neither allocation nor ownership transfer is established.

This contract describes static evidence, not verified runtime behavior. Arithmetic semantics, hidden calling-convention details, and dependency effects remain conditional where the supplied representation does not resolve them.

## Behavior

### Path selection

The function adds 100 to the third argument and tests the adjusted value as signed.

- An adjusted value of zero or greater selects the short path.
- A negative adjusted value selects the long path.

For additions within the signed 32-bit range, −100 selects the short path and −101 selects the long path.

This is not an unconditional mathematical comparison of the original argument with −100. Overflow in the addition can affect selection. Under wrapping 32-bit arithmetic, sufficiently large positive inputs produce negative adjusted values.

### Short path

The short path performs these operations in order:

1. Call F-c00000000001 with the explicit argument 115.
2. Treat its result as 64 bits.
3. Extract the upper 32 bits and use that bit pattern as destination address P.
4. Store the complete 64-bit result at P.
5. Store the adjusted third argument as 32 bits at P + 8.
6. Store the fourth argument as 32 bits at P + 12.
7. Store the context scalar as 32 bits at P + 16.
8. Return.

With third argument −101, the adjusted value is −1 and the long path must be selected.
