# F-2c6bf41c5b21

## Purpose

F-2c6bf41c5b21 conditionally obtains and returns one 32-bit value through three dependencies.

The function first passes an address four bytes beyond its first input to a gate dependency. A nonzero gate result causes an immediate zero return. A zero gate result permits two further calls: one prepares temporary storage, and another receives that storage, a separate output area, and the second input. The function then loads its return value indirectly through the first pointer in the output area.

This establishes a gated extraction operation. It does not establish what the gate tests, what kind of object occupies the input address, or what the extracted value means. In particular, zero is not proven to mean failure: both the skipped branch and a successful final load can produce zero.

## Behavior

### Gate and branch selection

The first externally relevant action is a call to F-3538c6888938 with the address obtained by adding four to the base input.

The returned integer selects the branch:

- **Nonzero:** return zero. Do not call either of the other two dependencies, and do not perform the final pointer-mediated load.
- **Zero:** continue to preparation and extraction.

Positive and negative nonzero gate results have the same branch effect. The function does not distinguish particular nonzero codes.

The gate call occurs even when the later operation will be skipped. Consequently, a zero return on this branch does not imply that the operation had no side effects.

### Preparation

The caller does not consume a return value from this dependency. Its next visible use of the preparation area is to pass its address to F-57e46da8ee17.
