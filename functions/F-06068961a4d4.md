These are conditional consequences of the static representation, not executed tests. Each assumes that the relevant preceding operations complete and that required memory and call targets are usable.

1. **Input truncation.** With third input `0x123456AB`, the entry-base-A-plus-13 byte store writes `0xAB`. The later entry-base-C-plus-20 word store writes the 32-bit pattern `0x123456AB`.

2. **Seed arithmetic.** With seed `0x00020003`, primary base is `0x00400060`, primary word is `0x01000180`, and small base is 1. The fourth-input-derived byte is therefore stored at address 8.

3. **Unsigned byte addressing.** A destination-selecting byte read of 255 yields destination address 272. Sign-extending that byte and targeting address 16 would contradict the represented operation.

4. **Fresh reads.** If the first read at primary base plus 1 yields 4, and an intervening dependency changes that location to 9 before the later read, the earlier small-base-derived store targets address 21 and the later zero-byte store targets address 26.

5. **Byte versus word retention.** With retained result `0x12345678`, logical right shift by three yields `0x02468ACF`. Explicit retained-byte stores write `0xCF`; the first-high-half-indexed word store writes the full `0x02468ACF`.

6. **Unknown assignment width.** If saved byte is 7, the earlier assignment at absolute address 13 has expression value 7, and the later assignment has expression value 192. This does not establish one-byte accesses, unchanged adjacent bytes, or a particular final byte representation. Those conclusions require the missing destination declaration and, for final state, constraints on subsequent dependency effects.

7. **Late truncation.** With late seed `0x3AB00000`, the second late-seed-derived byte store writes `0xAB`. This follows from masking the original seed, shifting right by 20, and retaining eight bits.

8. **Partial completion.** If the first entry byte store completes and the second faults, the first store is the only completed effect established by that prefix. No rollback or first indirect call is required by the visible sequence.
