# F-0d581569fe9d

## Behavior

### Interpretation conventions

For compactness, the following mathematical descriptions denote observable operations, not callable interfaces:

- A **selector write** reads the byte at the stated selector location, then writes the stated byte value at the selected byte plus 0x11.
- A **scaled slot** for a dependency result is the address obtained by multiplying that result by 16 and adding 0x14. Its usual stored value is that result multiplied by four.
- A **quarter-scale slot** uses the result multiplied by four, plus 0x14.

Unsigned shifts are logical. Calculations explicitly carried in unsigned 32-bit values discard bits beyond that width. Several dependency results instead appear as signed 32-bit values; overflow and signed-left-shift semantics for those calculations remain unresolved. Examples involving those calculations therefore require representable, nonnegative intermediate values unless stated otherwise.

Dependency labels below identify documentary call sites or call-site groups. They do not establish resolved function identities.

### Initial byte writes and input-selected word writes

The routine first performs a selector write using the byte at the incoming register-held address plus one. The written value is the low byte of the first input.

It then invokes five dependencies in order, grouped as **D-01**. The first receives the complete first input. Only the fifth primary result is visibly retained.

The selector byte is read again from the same address, and a second byte is written. Its value is the low byte of the first input logically shifted right by 22. Because dependencies occur between these operations, the second selector read need not return the first selector value.

Five further calls, **D-02**, follow. The first receives the retained result from D-01 multiplied by four.

Next, the routine reads the fixed datum at 0x3C and converts it to a 32-bit unsigned value. The source datum’s original width and extension behavior are not established.

The third input selects a destination:

- Logically shift the third input right by seven.
- Multiply by four.
- Add 0x14.

The captured datum is written there. Five calls, **D-03**, follow; the first receives that datum and the fifth supplies a retained primary result.

The routine writes the same captured datum to the same destination again. It does not visibly reread 0x3C. Five calls, **D-04**, follow; the first receives four times the retained D-03 result.

The third input therefore selects four-byte-spaced destinations. Its low seven bits do not affect this address. The destination range is 0x14 through 0x08000010 inclusive.

### Unconditional loop

- Executes D-38, whose first call receives the loop-carried argument and the loop quantity shifted right by eight.
- Performs a fresh selector write of zero using the selector location established immediately before D-37.

## Acceptance examples

These examples are conditional static acceptance criteria, not executed tests.

1. **First-input byte extraction.** With first input 0xFFFFFFFF, the first two selector writes carry 0xFF. With first input 0x00400000, they carry 0x00 and 0x01 respectively. The destination may differ because its selector is reread.

2. **Third-input grouping.** Third inputs 0 and 127 select address 0x14; input 128 selects 0x18. The maximum 32-bit unsigned input selects 0x08000010. Both early writes use the same captured datum.

3. **No implicit global reread.** If a dependency changes the datum at 0x3C after its capture, the second input-selected word write still uses the captured value.

4. **Write-before-read alias.** If D-04 returns zero, stage A writes zero at 0x14 and then reads the first captured word from 0x14. Subject to ordinary memory semantics and successful accesses, that captured word is zero.

5. **Retained-word extraction.** If the first captured word is 0x89ABCDEF, its upper-16-bit arguments are 0x89AB, its stage-R written value is 0x89, and its final direct-byte destination is 0x1D.

6. **Fresh selector behavior.** If a dependency changes the late selector byte between two selector writes, the later write follows the new selector. Reusing the earlier destination would violate the visible behavior.

7. **Loop boundary.** Regardless of D-36’s final result, the first D-38 invocation receives zero as its second explicit argument. Later iterations need not do so.

8. **No successful completion.** If all calls return and all accesses succeed indefinitely, the represented routine continues looping rather than returning.
