### Byte expansion boundary

Suppose the byte read in step 42 has bit pattern `0x80`.

- If the represented character interpretation is signed 8-bit, conversion to unsigned 32-bit yields `0xFFFFFF80`.
- If it is unsigned 8-bit, the result is `0x00000080`.

Consequently, the later addresses and first call argument differ. A contract that unconditionally substitutes `128` is not supported without resolving character signedness.
