# F-2a8c4056a1d0

## Purpose

The supplied static representation describes a routine that repeatedly invokes unresolved dependencies and interleaves byte and 32-bit memory accesses. Dependency results determine subsequent arguments, stored values, and addresses. Several values carry into the next iteration.

No application-level purpose is established. Repeated offsets do not establish an object layout, buffer format, device interface, allocation protocol, or initialization operation. Small absolute addresses and implicit entry state make ordinary-pointer interpretations unsafe.

This contract describes the visible ordering and data relationships. It does not establish executable validity or supply missing dependency contracts.

### Widths and notation

- \(W(x)\): the low 32 bits of \(x\).
- \(L(x,n)=W(x2^n)\): a 32-bit left shift.

- \(B(x)\): the low eight bits.
- A byte access transfers eight bits; a word access transfers 32 bits.

## Acceptance examples

These are conditional static consequences, not executed tests.

1. **Initial scaling and order.** With third word \(0x40000001\), the initial stored value is \(0x00000004\) under wrapping arithmetic. F-opaque-001 precedes that store.

2. **Zero-valued first byte update.** If the captured global word is zero, the phase-1 byte write stores zero. It remains a value-dependent write; it is not guaranteed nonzero.

3. **Selector width.** A selector read yielding \(0xff\) directs its corresponding byte store to \(0x110\). It does not load a pointer-sized destination.

4. **Fresh reset destination.** If the selector changes between phase 1 and phase 2, the reset uses the newly read selector. Acceptance must not require both stores to share a destination.

5. **Extraction and truncation.** For a captured word \(0xffffffff\), masking with \(0x3fffffff\) and shifting right by 20 yields \(0x3ff\). A byte store writes only \(0xff\).

6. **Necessarily zero argument.** In phase 6, \(L(L(E,14),28)=0\) for every 32-bit \(E\). The unresolved second argument remains unconstrained.

7. **One-bit-derived word store.** The phase-11 value \(L(M,31)\) is zero when \(M\) is even and \(0x80000000\) when \(M\) is odd.

8. **Captured next store base.** If the final selector read yields \(0x7a\), the next iteration’s initial word-store address is \(0x8e\). Later mutation of the selector byte does not replace that captured base in the represented computation.

9. **Tail assignment boundary.** F-opaque-003 and F-opaque-004 occur before the fixed continuation assignment; F-opaque-005 occurs after it. Placing the assignment after F-opaque-005 violates the visible order, even if its explicit argument list is empty.

10. **Repetition rather than success return.** If all dependencies return and every access completes, the routine begins another iteration instead of returning success.
