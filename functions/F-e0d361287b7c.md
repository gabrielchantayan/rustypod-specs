## Acceptance examples

These are conditional static criteria, not executed tests.

### Width preservation

A byte store whose source ends in 0xAB writes byte 0xAB without itself changing adjacent bytes. A halfword store of 0x65 remains a two-byte event; it must not be replaced with a one-byte store. Byte order remains target-dependent.

### Fixed-storage capture precedes the absolute store

If fixed storage contains address-bearing word 0x12345678 when read, subsequent publications use that captured value even if the later word store of 0x20 at absolute address 0x60 overlaps the storage. An access trace placing the capture after that store does not satisfy the represented order.

### Fresh reads can diverge

Suppose the original publication makes absolute byte address 0x67 contain 0xA5. Suppose the first later offset-9 assignment reads 0xA5, and the intervening byte store through the doubled loaded base aliases 0x67 and writes 0xB8. If no subsequent effect changes that byte before the next read, the second global-derived offset-9 assignment receives 0xB8.

Reusing the original 0xA5 for both assignments would violate the fresh-read requirement.

### Ordered overwrites

If the adjusted-base offset-0x20 publications are reached, their trace retains 0x20, 0x2F, the zero-extended freshly loaded byte, and 0x20. Reporting only the final word is insufficient.

### Narrow address boundary

Under 32-bit bit-vector semantics, the narrow address component is a multiple of four no greater than 508. Its doubled form is a multiple of eight no greater than 1016. Neither bound proves that the resulting access is valid.

### Completion

An all-zero represented argument group does not suppress its invocation. If every operation completes and the final dependency returns normally, control reaches the represented return without an established success value.
