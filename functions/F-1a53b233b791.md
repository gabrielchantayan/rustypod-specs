## Acceptance examples

These examples are conditional static expectations, not executed tests. They assume valid accesses, returning dependencies, and the inferred 32-bit word interpretation where applicable.

1. **First-argument extraction.**  
   With first argument hexadecimal `804000AB`, the first selector-directed write stores hexadecimal `AB`. The second stores hexadecimal `01`: shifting right by 22 produces a value whose low byte is one.

2. **Selector rereading.**  
   If the first initial-selector read yields 3, its destination is address 20. If a later call changes that selector byte to 9, the next selector-directed write targets address 26. Reusing address 20 would not match the represented behavior.

3. **Fourth-argument boundary.**  
   Fourth arguments zero through 127 all select address 28 for the retained-word byte write. A fourth argument of 128 selects address 29. F-U13 receives zero in the first range and one in the latter case.

4. **Retained-word calculations.**  
   If F-U12 returns hexadecimal `12345678`, the fourth-argument-directed write stores hexadecimal `E0`, and F-U15 receives hexadecimal `0048D159`. Under word-wrapping address arithmetic, the derived selector is read at hexadecimal `45678001`.

5. **Initial loop argument.**  
   Regardless of F-U24’s returned word, F-U27 receives zero as its second argument. Its first argument is F-U26’s result, without the later-iteration left shift.

6. **Loop-carried values.**  
   If F-U36 returns one, the next F-U37 call receives first argument 4 and second argument 262,144. If F-U36 returns 64, the next first argument is 256 and the second is zero. The second argument depends only on the returned word’s low six bits.

7. **Target transition.**  
   An execution reaching two loop iterations calls F-U27 at the start of the first and F-U37 at the start of the second. Treating these as the same target is not supported.

8. **Interrupted progression.**  
   If F-U19 does not return, the following selector-directed zero write and all later calls are not reached. The function provides no visible compensating action.
