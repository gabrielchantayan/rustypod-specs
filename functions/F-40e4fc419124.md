# F-40e4fc419124

## Purpose

F-40e4fc419124 extracts an unsigned value from a record whose interpretation depends on a discriminator in another record.

The established behavior has two cases:

- When the discriminator is not 8, return a zero-extended 16-bit value.
- When the discriminator is 8, return a 32-bit value formed from two 16-bit fields, with one supplying the upper half and the other supplying the lower half.

The routine always reads the lower-half field before reading the discriminator. On the discriminator-8 path, it reads that lower-half field again. This distinction is observable when memory can change between reads or reads themselves have side effects.

A likely intent is selection between a narrow and an extended record representation. That interpretation is inferred; the meaning of the records and discriminator is not established.

## Interface

The routine accepts two address-bearing arguments and returns an unsigned 32-bit value.

| Argument | Established use |
|---|---|
| First argument | Base address of a record containing a 16-bit discriminator at byte offset `0x6C` (108). |
| Second argument | Base address of a record containing a 16-bit lower-half field at byte offset `0x1A` (26), and a conditional 16-bit upper-half field at byte offset `0x14` (20). |

The supplied representation declares the arguments as integer values but uses them as addresses. It does not establish a portable pointer API, host-language calling convention, or supported address range. Callers must supply values that resolve to suitable readable storage in the target execution environment.

The relevant record layout is:

## Behavior

### Unconditional lower-half read

The first established memory access is a 16-bit unsigned read from the second argument at offset `0x1A`.

The value is initially extended to the 32-bit result width by inserting zeroes into the upper 16 bits. Thus, absent the discriminator-8 case, the result lies between 0 and 65,535 inclusive.

This read occurs regardless of the discriminator. A caller cannot make the lower-half location unnecessary by choosing any particular discriminator value.

### Discriminator read and branch selection

After the initial lower-half read, the routine reads the 16-bit discriminator from the first argument at offset `0x6C` and compares it with 8.

Only equality with 8 selects the extended case. Every other 16-bit pattern selects the narrow case. In particular, negative signed discriminator values do not receive separate handling.

For equality with 8, the discriminator must have the 16-bit pattern `0x0008`. Although the discriminator is interpreted as signed, signedness does not change which bit pattern satisfies this comparison.

The discriminator is read once in the supplied representation. A subsequent change to its storage does not cause a second decision.

### Narrow case

If the discriminator is not 8, the routine returns the value obtained by the initial lower-half read, zero-extended to 32 bits.

The upper-half field at offset `0x14` is not read on this path. Its contents therefore do not contribute to the result, and it need not be readable solely for this invocation’s established accesses.

### Extended case

If the discriminator is 8, the routine obtains:

- A 16-bit upper-half bit pattern from the second argument at offset `0x14`.
- A new 16-bit unsigned lower-half value from the second argument at offset `0x1A`.

The result is the upper-half bit pattern multiplied by 65,536, plus the newly read lower-half value, interpreted as an unsigned 32-bit value.

The two components occupy disjoint halves of the result. No sign extension is applied to either component. The construction can produce every value from 0 through 4,294,967,295 without requiring arithmetic beyond 32 bits.

The initial lower-half read does not supply the returned lower half on this path. Nevertheless, that initial read still occurs and can have an observable effect.

The supplied expression establishes both conditional reads after the branch decision, but does not establish their relative execution order. A contract requiring the upper-half read to precede the second lower-half read, or the reverse, would exceed the evidence.
