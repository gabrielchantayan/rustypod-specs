### Per-node operation

For each nonzero current node link, the observable sequence is:

1. Write a four-byte zero value at node offset `0x20`.
2. Read the four-byte successor link at node offset `0x04`.
3. Use that newly read link to decide whether to continue.

The write therefore precedes the successor read for the same visit. The successor is not visibly fetched in advance.

This order matters for aliasing or externally observable memory. The traversal follows the value obtained by the successor read after the node-field write, not a previously captured snapshot. The function repeats this operation until a successor read produces zero. There is no visible node limit, cycle detection, cancellation condition, or alternate exit.
