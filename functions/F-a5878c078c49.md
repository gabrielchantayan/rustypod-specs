## Behavior

### Mode selection

After the dependency returns, the function reads the 8-bit field at offset +14.

If that field equals 4:

- The unsigned threshold is 252.
- The mode contribution is 2.

Otherwise:

- The unsigned threshold is 253.
- The mode contribution is 1.

### Threshold decision

The function next reads the unsigned 16-bit field at offset +12.

It selects a threshold contribution as follows:

- 3 if this first field value is strictly greater than the selected threshold.
- 1 otherwise.

Equality does not take the greater-than branch.

Thus:

- With mode 4, values 0–252 select contribution 1; values 253–65,535 select contribution 3.
- With any other mode, values 0–253 select contribution 1; values 254–65,535 select contribution 3.

The comparison is unsigned. Values with the high bit set are large positive field values, not negative inputs.

### Final calculation

The unsigned 16-bit field at offset +12 is read again for the return calculation. This second value is added to:

- The dependency contribution, either 0 or 1.
- The previously selected threshold contribution, either 1 or 3.
- The previously selected mode contribution, either 1 or 2.
- A fixed contribution of 3.
