# F-e75d309a4b4b

## Purpose

F-e75d309a4b4b conditionally updates one bit in a globally addressed 32-bit word. The first input byte selects the word and is also passed to dependency F-d1db756204ac. That dependency receives a mutable 32-bit value initialized from the fourth argument; the low eight bits of the value after the dependency returns determine the requested bit position.

The byte value 200 is a distinguished early-return case: the function returns 200 without invoking the dependency or accessing the word table.

**Established static behavior:** for other byte values, the function selects a word, requests either a bit clear or a bit set, writes the resulting word, and returns zero if execution completes normally.

**Inferred intent:** the byte appears to encode a word selector and information used to resolve a bit position. The second argument acts as an enable/disable flag. These interpretations do not establish a domain-specific meaning for the byte, table, or bit.

This contract is based on the supplied static representation. No runtime tests have been performed.

### Memory layout

The selected word is addressed relative to a globally obtained base address. Each entry occupies four bytes, and accesses are represented as 32-bit reads and writes.

Let the initially read byte be the selector. Its upper three bits identify a group from 0 through 7. The word index is:

**6 − group**

The corresponding byte displacement from the base is four times that index. Possible displacements therefore range from **−4 through +24**.

This is not necessarily a conventional seven-entry array. Selectors in the highest group address the word immediately before the base. The supplied representation provides no bounds information that establishes whether that preceding word is valid.

The layout’s byte order is not established. The operation is defined in terms of a 32-bit word value, not a sequence of individually updated bytes.

## Behavior

### Initial read and distinguished return

The function first reads one byte through its first argument.

If that byte equals 200, it immediately returns the 32-bit value 200. In this case:

- F-d1db756204ac is not called.
- No local copy of the fourth argument is passed to a dependency.
- No selected table word is read or written.
- The second, third, and fourth arguments have no visible effect on the result.

An invalid first pointer is not protected by the distinguished-value branch: the byte must be read before the branch can be selected.

### Dependency interaction

Before calling F-d1db756204ac, the function creates a local 32-bit object containing the fourth argument.

It invokes the dependency with:

1. The original selector byte as a numeric value.
2. The address of that local 32-bit object.

The dependency may modify that object. The caller uses its contents after the call, rather than assuming the fourth argument remains the effective bit-position input.

No dependency return value is examined. There is no visible failure branch based on such a value.

The dependency executes before the table word is read. Consequently, its effects on global state can influence which table storage is subsequently accessed or what value is read there. The supplied body does not justify assuming that the dependency preserves globals or leaves the table untouched.

### Mask and word update

After the dependency returns, the function reads the selected 32-bit word using the globally addressed base.

The bit-position input is the low eight bits of the local 32-bit object after the dependency call. Its upper 24 bits do not participate in the visible shift-count expression.

The function forms a mask by shifting a value of one left by that count. For counts from 0 through 30, the supplied expression establishes an ordinary single-bit mask without reaching the signed high-bit boundary. The count-31 case and counts of 32 or greater require the execution-semantics qualifications described under **Uncertainties**.

When the mask is well-defined:

- A zero second argument clears every bit selected by the mask.
- A nonzero second argument sets every bit selected by the mask.
- Other bits retain their values from the word read after the dependency call.

The result is written back as a 32-bit word to the selected destination. The visible update path performs this write even when the resulting value equals the value read.

The function then returns zero.

### Arithmetic boundaries

The selector is an unsigned eight-bit value. Its upper-three-bit group is therefore always between 0 and 7. Subtracting that group from six produces a mathematical index between −1 and 6; the corresponding displacement is between −4 and 24 bytes.

The fourth argument is copied at 32-bit width before the dependency receives its address. Only eight bits of the resulting object are used as the shift count. This reduction permits counts through 255; it is **not** a reduction modulo 32.

The second argument is tested only for equality with zero. A negative value requests setting just as a positive nonzero value does.
