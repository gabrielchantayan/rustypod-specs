## Behavior

| Access | Destination | Stored value |
|---|---|---|
| Word write | Twice A, plus `0x54` | P |
| Byte write | B plus `0x19` | Low byte of A |
| Byte write | A plus `0x11` | Low byte of B |

The repetitions are behaviorally distinct from a single copy of the pattern. On device-backed memory, or where writes themselves are observed, all thirteen repetitions may matter. With ordinary non-overlapping memory and no external observation, the repetitions may leave the same final contents as one repetition, but that does not erase the represented write sequence.

Aliasing between destinations is permitted by the representation. If destinations overlap, the later accesses determine the resulting bytes according to the target’s storage rules. A complete final byte layout cannot be specified without endianness and alignment information.

### Initial capture and fixed-location updates

After the repeated writes, the routine captures a word from `0xA9`, then captures a word from P plus `0x74`.

It next writes a byte to `0x3A` equal to:

\[
(2 \times \operatorname{low8}(A) + 0x30) \bmod 256.
\]

This formula describes the stored byte without assuming whether the intermediate character value is signed.

The routine then captures a word from C plus `0x14`, followed by a word from A plus `0x04`. These captures happen after the write to `0x3A`, so any aliasing with that write affects the values obtained.

The next mutation group:

- Writes the low byte of A to C plus `0x0D`.
- Writes byte `0x6C` to A plus `0x08`.
- Writes the low byte of B to A plus `0x0D`, then to A plus `0x09`.
- Writes C as a word to C plus `0x54`.
- Writes the low byte of the captured word from `0xA9` to `0x67`.

These are ordered writes, not an atomic update.

### Derived word and shifted-byte updates

The routine next reads a word from C plus `0x44`. Call this captured value **the first derived word**.

It then reads the byte at `0x67` and writes that byte to `0x21`. This is a fresh memory read, not merely an assumed reuse of the byte previously written to `0x67`.

The low byte of the first derived word is written to A plus `0x10`, and the entire first derived word is written to B plus `0x54`.

A byte derived by right-shifting the first derived word is then written to C plus `0x01`. The shift count is the low eight bits of A. The shifted operand is represented as signed.

Two limitations apply:

- For negative operands, the representation alone does not establish the target’s signed-right-shift rule.
- Counts from 32 through 255 exceed the width of a 32-bit operand. The representation does not establish a portable result for those counts.

Immediately afterward, B plus `0x54` is overwritten with A as a word. The earlier store of the first derived word remains part of the visible access sequence even though this later write targets the same word.

- Writes the previously captured word from A plus `0x04` to B plus `0x74`.
- Writes the newly captured word from A plus `0x40` to A plus `0x10`.

## Acceptance examples

These are conditional static acceptance examples, not executed tests.

### Repeated writes remain observable

Given accessible destinations and an observer that records writes, acceptance requires thirteen occurrences of the four-write pattern in the stated order before the read from `0xA9`. Replacing that phase with a single pattern does not preserve the represented access trace.

### Low-byte truncation

If A’s low byte is `0xFF`, the byte written to `0x3A` is `0x2E`, provided execution reaches that write. The result follows from byte truncation of \(2 \times 255 + 48\), regardless of the signed interpretation of the intermediate character.

### Captured value versus later memory

Suppose C plus `0x14` contains word value W when its early read occurs. If that memory later changes, the third indirect-call argument remains W, assuming execution reaches the call. The contract does not authorize rereading the location for that argument.

### Overlapping byte and word writes

If A-relative storage is ordinary writable memory, the word write at A plus `0x10` replaces the bytes at offsets `0x10` through `0x13`. The earlier low-byte write at offset `0x10` is not guaranteed to survive. Exact byte placement within the replacement word depends on endianness.

### Shift boundary

For a nonnegative first derived word and a shift count from 0 through 31, the stored byte at C plus `0x01` is the low byte of the right-shifted value, subject to earlier aliasing effects on the captured operand.

For a count of 32 or greater, this contract supplies no numeric acceptance value. Target semantics must first be established.

### Failure after partial mutation

If the first invalid access is the read at P plus `0x74`, the thirteen repeated write groups and the preceding read from `0xA9` have already been reached in the represented sequence. There is no visible rollback restoring the writes.
