# F-50be1c0375de

## Purpose

F-50be1c0375de reports whether two caller-supplied integer objects have equal values.

This is value equality, not pointer equality. Distinct objects containing equal integers produce a true result. Supplying the same valid integer object as both arguments also produces a true result, provided its value remains stable during evaluation.

**Established static evidence:** the supplied representation compares the integer values obtained by dereferencing the two arguments and returns that comparison as a Boolean.

**Inferred intent:** this is an integer-equality predicate. No broader role, such as ordering, identity checking, container lookup, or ownership management, is established.
