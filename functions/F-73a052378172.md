## Acceptance examples

All examples are conditional static expectations, not executed tests. Required addresses must be accessible, preceding calls must return, and relevant signed operations must have an established interpretation.

1. **Duplicated initial input.** The initial call's first two explicit arguments both equal the second input. Its third is \(P\), and its fourth is the additional unsigned entry word shifted right by three.

2. **Reachable masked product.** If \(D=-1\), its signed product \(4D=-4\) is representable. Conversion gives \(L=0xfffffffc\), and the later stored \(T(L)\) is 0x1ffffffe—not the unmasked logical-shift result 0x7ffffffe. A premise of \(L=0xffffffff\) is incompatible with a defined product \(4D\), and also with ordinary 32-bit wrapping multiplication by four.

3. **Third-input address.** If \(P=8\), the first store of \(P\) targets 0x80024 and writes word 8.

4. **Changed selector.** If successive reads at \(B_R+1\) produce 2 and 9, their corresponding byte writes target 0x13 and 0x1a. The contract does not require a common destination.

5. **Byte truncation.** If \(R=0x3ff00000\), then \(H(R)=0x3ff\), and the corresponding byte write stores 0xff.

6. **Retained selector.** If retained \(b=7\), the subsequent word clear targets 0x4b even if an intervening dependency changes the selector's original storage.

7. **Expanded sequence capture.** If positions 2 and 4 of the expanded sequence capture different words, position 3 receives the first and position 5 receives the second. No captured return from position 3 supplies position 5's argument.

8. **Unsigned multiplication wrap.** If \(U=64\), obtainable from \(R=128\), unsigned multiplication by 0x4000000 yields zero. The final selector-read address is therefore 1.

9. **Repeated absolute clear.** A dependency may modify address 0x24 after one explicit clear. Each later scheduled clear still occurs if execution reaches it.

10. **Interrupted execution.** A dependency that does not return prevents later scheduled effects from being required. No rollback of completed writes is established.
