# F-ffdd608724b5

## Behavior

These two reads precede every dependency call. Branch selection uses their initially observed values; the function does not reread either field after calling a dependency.

Other than the final destination-field assignment, all object manipulation is delegated.

1. The destination.
2. The original first input.
3. The original second input.

The inputs retain their original argument order on this path. The ordering dependency is not called.

If F-782bee8991b2 returns any nonzero value:

- Otherwise, it writes 1 to that field.

## Side effects

2. Read four bytes from the second input at offset 12.
3. Invoke the dependency or dependencies selected by those observations.

### Dependency effects and failure

The dependency bodies are unavailable. They may alter the destination, either input, other memory, or global state. This function does not establish that dependencies preserve any of those locations.
