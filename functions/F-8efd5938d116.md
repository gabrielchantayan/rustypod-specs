### Second region and narrow propagation

A word read at Base C plus `0x04` supplies **Region Q**. Base B’s low byte is written at Region Q plus `0x09`, followed by a word read at Region Q plus `0x50`. That word is retained as **Q word**.

Saved word’s low byte is then written at Region Q plus `0x11`, followed by another write of Base B’s low byte at Region Q plus `0x09`. The two writes to the latter destination are distinct accesses, separated by a word read and another byte store.

Three more stores follow: Saved word as a full word at Base B plus `0x14`; Region Q’s low address byte at Base B plus `0x0D`; and Q word’s low byte at Region Q itself.

The store at Base B plus `0x0D` carries only a truncated address value. It does not create a full pointer or establish ownership of Region Q.

2. Word value `100` at Base B plus `0x54`.

### Halfword transfers and byte conversion

External value 1 is read and retained as **External address 1**. A word read at Base B plus `0x74` then supplies **Offset U**.

Offset U’s low halfword is written at the address obtained by adding Offset U and Base B. External address 1’s low halfword is next written at twice Region T’s retained address value. The latter calculation doubles the address itself; it does not read a value from Region T.

One byte is then read at Offset R plus Base B. Its represented character-to-unsigned conversion produces the retained 32-bit **Converted byte**.

For source bytes from `0x00` through `0x7F`, Converted byte equals the byte’s numeric value. For bytes from `0x80` through `0xFF`, the supplied evidence does not establish character signedness. An unsigned character interpretation preserves values from 128 through 255. A signed interpretation can first produce a negative value, which becomes its unsigned 32-bit representation.

After that byte read, Offset U’s low halfword is written at External address 1 plus Offset U. The same halfword is then written again at Offset U plus Base B.

Finally, a full word carrying `0x00000045` is written at Converted byte plus `0x45`. The destination addition uses unsigned 32-bit arithmetic.

The repeated halfword stores at Offset U plus Base B remain separate operations. In particular, the intervening byte read can observe the first store if the accesses overlap.

### Repeated stores and truncation

Suppose Base B’s low byte is `0xCD` and Saved word is `0x12345678`.

The access trace includes two separate byte stores of `0xCD` at Region Q plus `0x09`, and a byte store of `0x78` at Region Q plus `0x11`. Full-word stores at Base B plus `0x14` and Base B plus `0x24` carry `0x12345678`.

Base B plus `0x0D` first receives Region Q’s low address byte and later receives `0x78`. Base B plus `0x54` first receives Base B and later receives the word `100`.

A model that retains only final contents does not preserve these required accesses.

### Addition differs from bitwise OR

Suppose the conversion source byte is `0x44`.

The word carrying `0x45` is written at address `0x89`. The final byte carrying `0x44` is written at address `0x88`. The first explicit dependency argument is nevertheless `0x44`, because bitwise-OR of `0x44` with itself is `0x44`.

Normal completion requires those low addresses to be accessible.

### Halfword payload width

Each of the three halfword stores sourced from Offset U carries `0x5678`: twice at Offset U plus Base B and once at External address 1 plus Offset U. None transfers Offset U’s full 32-bit value.

### Captured data under aliasing

If execution reaches the invocation, the third explicit argument remains `0xAABBCCDD`. The later store changes memory, not the already captured argument.

### High-bit character conversion

Under an unsigned character interpretation, Converted byte is `0x000000FE`. The word-store destination is `0x143`, the final byte-store destination is `0x142`, and the first dependency argument is `0x000000FE`.
