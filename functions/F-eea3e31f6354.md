# F-eea3e31f6354

- The initially retained value is preserved for the later indirect invocation.

The static representation nevertheless distinguishes the retained value from the dependency’s argument expression. It does not prove that two separate physical memory transactions occur. Nor does it establish volatility, atomicity, synchronization, or whether an execution environment permits the evaluations to observe different values.
