# F-4a680fb472e9

## Purpose

F-4a680fb472e9 conditionally obtains a byte-oriented result from F-f03658903e83 and passes it to F-dece790ddc92.

The established eligibility conditions are:

- A captured unsigned 16-bit record field exceeds 3.
- F-d5cded701dac returns exactly 6.
- A byte selected through a subsequently read global base value equals exactly 2.

If those conditions hold, F-f03658903e83 is called. Its status becomes the function’s return value. A zero status additionally causes a call to F-dece790ddc92; that call’s result does not replace the status. If an eligibility condition fails, the function returns 62.

The table lookup uses a value read from global storage after classification, not an established fixed table address or an entry-time snapshot. Changes to that global value by the context provider or classifier can therefore change which byte is inspected.

“Result production,” “classification,” and “forwarding” describe argument and control flow. Their application-level meanings are not established.

## Interface

### Arguments

The function accepts two arguments:

1. **An opaque 32-bit value.** The supplied body does not inspect it, forward it, or otherwise make behavior depend on it.
2. **A pointer to a record.** The function directly reads these fields:

| Record byte offset | Access width | Read timing | Established use |
|---|---:|---|---|
| 0 | 32 bits | Only after F-f03658903e83 returns zero | Second argument to F-dece790ddc92 |
| 8 | 32 bits | After F-5f5f14cedda3 returns, before threshold rejection | Second argument to F-f03658903e83 |
| 12 | Unsigned 16 bits | Before any dependency call | Threshold gate and decremented producer argument |

The record pointer is also passed to F-5f5f14cedda3 and, conditionally, F-dece790ddc92. Their additional record accesses are unknown.

The offset-12 access reads a halfword, not the full 32-bit word beginning there. Bytes at offsets 14 and 15 do not contribute to this directly captured value.

The body contains no explicit null-pointer, size, alignment, or accessibility checks. Each reached access requires suitable readable storage at that time. A readable record on entry is not sufficient if an earlier dependency invalidates it before a later access.

### Return value

The normal return value is a 32-bit integer:

- **62** when an eligibility gate fails.
- **The status returned by F-f03658903e83** when that dependency is called.

A nonzero producer status is returned without forwarding. A zero producer status causes forwarding and remains the final status if forwarding returns normally.

No separate failure handling is established for the index resolver, context provider, classifier, global-base access, table-byte access, or forwarder. Faults, exceptions, nonlocal transfers, and dependencies that do not return are outside these normal-return rules.

### Invocation-local storage

The function provides:

- A 256-byte temporary buffer.
- A 32-bit unsigned length-like cell.

The length-like cell is initialized to zero after the index-resolution call and the offset-8 record read, before the threshold gate. It is changed to 255 immediately before F-f03658903e83 is called.

The function does not initialize the temporary buffer before giving its address to the producer. The initial cell value of 255 is distinct from the buffer’s 256-byte extent; the supplied evidence does not establish the cell’s intended convention.

## Behavior

### Initial capture and unconditional resolution

The function first captures the unsigned 16-bit field at record byte offset 12.

It then calls F-5f5f14cedda3 with the record pointer and retains its 32-bit integer result as an index-like value. After that call returns, it reads and retains the 32-bit record field at byte offset 8. It then initializes the length-like cell to zero.

These operations precede threshold rejection. Consequently:

- F-5f5f14cedda3 is called even when the threshold is 0, 1, 2, or 3.
- The offset-8 field is read even when the threshold will reject the operation.
- Changes by F-5f5f14cedda3 to offset 12 do not replace the threshold already captured.
- Changes by that dependency to offset 8 can affect the subsequently captured word.

The returned index is not explicitly validated.

### Threshold gate

A captured threshold of 0 through 3 causes a normal return of 62.

A captured threshold of 4 through 65,535 permits evaluation to continue. The function then calls a zero-argument context-provider dependency whose opaque function ID was not supplied.

The context provider’s 32-bit result and the retained index are passed, in that order, to F-d5cded701dac. The context-provider call completes before classification begins.

### Classification and two-stage table access

F-d5cded701dac must return exactly 6. Any other result causes a return of 62 without either of the table-related reads below.

When classification returns 6, the function performs two distinct reads, in this order:

1. **Global base-value read.** It obtains an address-forming base value from global storage.
2. **Indexed byte read.** It reads one unsigned byte at the address formed from that obtained base, the retained index multiplied by 36, and an additional displacement of 28 bytes.

The base-value read occurs after both the context provider and F-d5cded701dac have returned. It is not a base captured at function entry. If either dependency changes the global base value and that change remains in effect when the read occurs, the changed base participates in the lookup. The same applies to an earlier change by F-5f5f14cedda3.

The supplied body establishes one such base-value read followed by the selected byte read. It does not establish synchronization, atomicity, or protection against concurrent changes to the global storage or selected memory.

The selected byte must equal exactly 2. Every other byte value causes a return of 62 without calling the producer.

The lookup has no explicit index-range check, negative-index rejection, base validation, or address-readability check. The stride and displacement are established, but valid table bounds and portable overflow behavior are not. A normal lookup requires that the target’s actual address calculation reach readable storage.

### Result production

After all eligibility gates pass, the function sets the length-like cell to 255 and calls F-f03658903e83 with five arguments:

| Position | Value |
|---|---|
| 1 | Retained index from F-5f5f14cedda3 |
| 2 | Captured 32-bit record field from offset 8 |
| 3 | Captured unsigned 16-bit threshold minus one |
| 4 | Address of the 256-byte temporary buffer |
| 5 | Address of the 32-bit unsigned length-like cell |

The third argument is an integer subtraction result, not an 8-bit quantity. Its reachable numeric range is 3 through 65,534. Because the threshold has already been established as greater than 3, this subtraction does not underflow.

The offset-8 argument remains the value captured before the context-provider and classifier calls. Later changes to that record field do not replace it.

The function retains the producer’s 32-bit status. A nonzero status is returned directly; buffer and length-cell changes do not independently trigger forwarding.

The caller supplies 256 bytes of buffer storage, but the producer’s write bounds and interpretation of the initial cell value are unknown. The caller performs no explicit post-call validation of either object.

### Conditional forwarding

If F-f03658903e83 returns zero, the function calls F-dece790ddc92 with seven arguments:

| Position | Value |
|---|---|
| 1 | Original record pointer |
| 2 | 32-bit word read from record byte offset 0 for this call |
| 3 | Zero |
| 4 | Zero |
| 5 | 30 |
| 6 | Address of the temporary buffer |
| 7 | Current length-like cell masked to its low 16 bits |

The offset-0 read occurs after the producer returns. It is not an entry-time snapshot. Changes to that field by earlier dependencies can therefore affect the forwarded value.

The length argument is the numeric result of masking a 32-bit unsigned cell. Its range is 0 through 65,535. This operation discards the upper 16 bits; it does not clamp the value to 255 or to the 256-byte buffer extent.

The function does not check whether the forwarded length:

- Fits within the buffer.
- Matches the amount written by the producer.
- Refers only to initialized bytes.

After F-dece790ddc92 returns normally, the function returns zero. Any return value from that dependency is unused.

## Side effects

### Direct reads and writes

Direct external-memory reads are:

- The offset-12 record halfword.
- The offset-8 record word.
- Conditionally, the global address-forming base value.
- Conditionally, the byte selected using that base.
- On producer success, the offset-0 record word.

The global base-value read and selected byte read are separate, ordered accesses. Neither occurs when classification differs from 6.

The function directly writes its invocation-local length-like cell. It provides temporary storage to dependencies but contains no explicit store to the caller’s record or the global table-related storage.

Absence of direct external stores does not imply absence of caller-visible changes: dependency side effects are not characterized.

### Call effects and failure paths

Every normally progressing invocation calls F-5f5f14cedda3. Threshold-eligible invocations additionally call the context provider and classifier. Only invocations passing all gates call F-f03658903e83, and only a zero producer status permits F-dece790ddc92.

A return of 62 does not establish that nothing happened. Earlier dependencies may already have changed the record, global base, selected memory, or other reachable state. The function provides no rollback.

### Ownership and lifetime

The supplied body contains no explicit allocation, deallocation, or ownership-transfer operation for the record. This does not establish that dependencies preserve its ownership or lifetime.

The buffer and length-like cell have invocation-local lifetime. Their addresses are passed during dependency calls and are not returned to the caller. Retaining either address for use after this function returns would outlive that storage. Whether dependencies retain addresses, release other memory, or assume ownership is unknown.

The function performs no explicit buffer initialization, scrubbing, or post-use clearing.

## Acceptance examples

These are conditional consequences of the static evidence, not runtime observations. Unless otherwise stated, they require valid reached memory accesses and normally returning dependencies.

1. **Threshold rejection still performs early work.** With a captured threshold of 3, F-5f5f14cedda3 is called, the offset-8 word is read, and the length-like cell is initialized to zero. The function returns 62 without calling the context provider or classifier and without reading the global base or selected byte.

2. **Minimum eligible threshold.** With threshold 4, classifier result 6, and selected byte 2, the producer receives third argument 3 and an initial length-like cell of 255.

3. **Maximum threshold.** With threshold 65,535 and passing later gates, the producer receives 65,534. There is no 8-bit truncation or subtraction underflow.

4. **Classification rejection prevents both lookup reads.** With threshold above 3 and classifier result 5, the function returns 62 without reading either the global base value or an indexed table byte.

5. **Context-provider mutation affects the lookup.** Suppose the context provider changes the global base from one valid region to another, the classifier returns 6 without replacing that change, and the selected byte under the new base is 2. The function uses the new base. It does not use a base snapshot from before the context-provider call.

6. **Classifier mutation affects table rejection.** Suppose classification returns 6 after changing the global base. If the byte selected under that new base is 1, the function returns 62 even if the corresponding byte under the former base was 2.

7. **Producer failure propagates.** If all gates pass and the producer returns −7, the function returns −7 without forwarding, regardless of any buffer or length-cell changes.

8. **Zero status forwards current values.** If the producer returns zero and leaves the cell at 255, the forwarder receives length 255, fixed arguments 0, 0, and 30, and the offset-0 word read after production. The function returns zero if forwarding returns normally.

9. **Masking is not bounds enforcement.** A producer-written cell value of 65,538 produces forwarded length 2. A value of 65,536 produces zero. A value of 300 produces 300, despite the buffer extent being 256 bytes. Whether those cases are safe for the dependencies is unresolved.

10. **Record fields have different capture times.** If the index resolver changes offsets 12 and 8, the original offset-12 halfword still controls gating and subtraction, while the changed offset-8 word is captured for production. A later change to offset 0 can affect forwarding.

## Uncertainties

The following remain **documented_only**:

- Domain meanings of the record, index, table entry, constants 6, 2, and 30, and status 62.
- The context provider’s opaque identity and semantics.
- The exact representation and storage width of the global address-forming base value.
- Table allocation bounds, index validity, and overflow behavior of address arithmetic.
- Target byte order, precise ABI, and access-alignment requirements.
- Dependency mutations, memory-access bounds, ownership behavior, and global-state preservation.
- Whether 255 denotes capacity, a count, a limit, or another convention.
- Whether producer success guarantees initialized bytes or a usable length.
- Whether forwarding validates length, consumes bytes synchronously, or retains their address.
- Exceptional control flow, synchronization, concurrency, and reentrancy requirements.

The buffer and mutable length cell suggest an output-generation interface. That is inferred intent, not an established producer contract. Likewise, “forwarding” does not prove transmission, persistence, or copying.

The timing of the global base-value read is established despite the unresolved representation: it occurs on the classifier-equals-6 path, after the context-provider and classifier calls, before the indexed byte read.
