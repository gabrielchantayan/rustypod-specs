# F-90cc45c79b34

## Purpose

F-90cc45c79b34 calls F-936a8728139d with an address at offset `0x220` within a caller-supplied object, then directly writes a 16-bit field at object offset `0x250`. The first call’s implementation is unavailable; the call does not establish that any region is initialized.

The function also constructs a temporary four-word record. Three ordered conditions control whether that record is supplied to additional dependencies. Within that conditional path, a captured related-object value controls one optional call, and a subsequently obtained target value controls two further calls.

On normal completion, the function returns a 64-bit value formed from the final first and second words of the temporary record.

The object’s domain meaning, the purpose of the dependencies, and the interpretation of the returned pair are not established.
