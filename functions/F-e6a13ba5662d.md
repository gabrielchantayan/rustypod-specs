# F-e6a13ba5662d

## Purpose

F-e6a13ba5662d resolves a handle, obtains a candidate 32-bit extent from a dependency, and conditionally updates the extent and associated handle fields. It returns a Boolean outcome and passes a separate status value to F-038b46411c0c.

**Established behavior:** the function rejects the candidate sentinel `0xFFFFFFFF` and candidates greater than the stored unsigned extent. Equality bypasses the explicit mutation path. The reduction path selects two unit values, publishes the candidate extent, and invokes further dependencies. Failures can occur after state changes; there is no explicit rollback.

**Inferred intent:** the extent comparisons, unit traversal, and zero-extent handling are consistent with truncation of a storage-backed object. Neither that interpretation nor persistence, allocation, reclamation, or synchronization semantics is established by the supplied body. This contract uses *extent*, *unit*, *descriptor*, and *context* as descriptive labels only.

### Unit selection

Entering the reduction path first writes one to handle +20. Later traversal failure does not undo this write.

The next branch intersects the candidate with the 32-bit mask at saved-context +104. This is a bitwise AND, not division or remainder.

#### Nonzero intersection

The current unit at handle +12 becomes the retained unit. F-073075d3cf3f receives the saved context and that unit; its result becomes the following unit.

At this point, the function does not write handle +12 or +16. A zero current unit is not rejected before the call. A zero following result is permitted on this branch and does not itself select failure.

#### Zero intersection

The current unit is captured as a target. F-40e4fc419124 receives the context and metadata references obtained from the descriptor retained during extent validation. Its result is the first search candidate.

The first candidate also initializes the prospective retained unit. Each candidate is compared with the captured target before another successor is requested.

When equality is found:

1. The prospective retained unit is written to handle +12.
2. If it is zero, zero is written to handle +16.
3. Otherwise, F-08426f0ea83d receives the saved context and retained unit; its result is written to handle +16.
4. The captured target supplies the following unit for subsequent processing.

The +12 write therefore precedes the F-08426f0ea83d call when that call occurs.

After a mismatch, F-073075d3cf3f receives the saved context and the candidate just examined. That examined candidate becomes the prospective retained unit. A nonzero successor is compared with the target on the next iteration. A zero successor immediately ends the search unsuccessfully; it is not compared with the target.

Consequences include:

- A target reached after one or more advances retains its predecessor.
- A target equal to the first candidate retains that same candidate.
- A first candidate and target both equal to zero succeed immediately, writing zero to +12 and +16.
- A zero first candidate with a nonzero target is passed to F-073075d3cf3f; it is not rejected before that call.
- A later zero successor does not match a zero target because termination precedes the next comparison.

## Side effects

The principal partial-state boundaries are:

- Rejected candidates and equal-extent paths perform none of the explicit reduction-path writes.
- Traversal failure can leave handle +20 set.
- Successful search can update +12 and +16 before extent publication.
- A zero primary-update result can leave the new extent and earlier handle changes in place.
- Zero-extent clearing occurs before the primary-update result is known.
- Later checked failures do not prevent F-f323001005c6 or the +32 assignment.
- No explicit rollback restores previous values.

Absence of direct writes on a branch does not imply absence of dependency-induced mutation.

Invalid-reference recovery and exception handling are not visible. The return and reporting guarantees above apply to normal completion, not faults or nonreturning dependencies.

2. **Signed eligibility:** two produces false and status 30. One, zero, and negative one pass this check.
