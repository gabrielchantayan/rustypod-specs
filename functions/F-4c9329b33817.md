# F-4c9329b33817

## Purpose

F-4c9329b33817 queries a selected bit in a word reached through an indirect address. Its first input identifies an address-bearing slot; its second input supplies a selector. Only the selector’s least significant eight bits participate in the selection.

Under the recovered 32-bit interpretation and ordinary signed-integer shift rules, the established effective-selector range is **0 through 30 inclusive**. With valid memory accesses and an effective selector in that range, the function returns true exactly when the selected bit is set.

**Effective selector 31 is conditional.** The mask construction shifts the signed integer literal 1. Under ordinary 32-bit C signed-shift rules, shifting that value into bit 31 does not establish a defined positive signed result. A high-bit query therefore requires independently established language or target semantics.

**Effective selectors 32 through 255 remain unresolved.** Reducing the selector to eight bits does not establish valid shifts for those counts, nor does it establish five-bit shift-count normalization.

The inferred intent is a read-only bit-membership query. No application-specific meaning for the inspected word is established.

## Interface

### Inputs

| Input | Recovered representation | Contract |
|---|---|---|
| Address-slot reference | Pointer to a four-byte storage element | Identifies the slot containing the address of the word to inspect. |
| Selector | Unsigned integer, interpreted as 32 bits in the recovered model | Its low eight bits determine the effective selector. |

The first input is **not** directly the address of the inspected word. The operation has two levels of indirection:

1. Obtain an address-bearing value from the supplied slot.
2. Interpret that value as an address and obtain the unsigned word stored there.

A caller must provide the slot containing the target address, not merely the target word’s address in place of that slot. The numerical contents of the slot are used as an address, not as the bit field being queried.

### Output

For effective selectors 0 through 30, subject to the memory and representation preconditions below, the semantic output is:

- **True:** the selected bit of the inspected word is one.
- **False:** the selected bit is zero.

The output is a Boolean, not the selected mask, the original word, or a population count.

For effective selector 31, this Boolean interpretation applies only if independently established execution semantics support the corresponding high-bit mask. For effective selectors 32 through 255, no Boolean result is established by the supplied material.

The physical return-register width, calling convention, and ABI encoding of Boolean values are not supplied.

## Behavior

### Selector reduction

The effective selector is the unsigned input’s low eight bits, giving a value from 0 through 255. Numerically, this is reduction modulo 256.

Selector bits above bit 7 do not affect that effective value. Consequently, inputs differing only in those higher bits have the same selection behavior when the remaining preconditions are satisfied.

This reduction is **not modulo 32**:

### Mask construction and bit test

For effective selectors 0 through 30, shifting the signed integer value 1 produces a representable positive 32-bit value with exactly the selected bit set. The operation intersects that mask with the inspected unsigned word, then returns whether the intersection is nonzero.

The unsigned interpretation used by the intersection does not retroactively make an invalid signed shift valid. In particular, the unsigned target word does not remove the selector-31 limitation.

Bit numbering is by numerical significance:

- Bit 0 is the least significant bit.
- Bit 30 is the highest bit selectable without the signed-shift qualification under the recovered model.
- Bit 31 is the word’s most significant bit, but querying it remains conditional.

Within the established range, unselected bits cannot change the result. A word with many set bits can return false if the selected bit is clear. Conversely, a single set bit at the selected position is sufficient for true.

### Logical reads and ordering

The supplied expression contains:

No loop, retry, reread, or consistency check is expressed. In particular, the operation does not check whether the slot still contains the same address after obtaining the target word.
