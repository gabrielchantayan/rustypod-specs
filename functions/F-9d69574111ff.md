# F-9d69574111ff

## Purpose

F-9d69574111ff conditionally updates range-related state, derives geometry and aggregate extents, obtains an associated object, performs two allocation-and-construction sequences, and invokes a final adjustment.

Two gates control progress:

- A zero lookup-context field causes an immediate return without dependency calls or direct state writes.
- A null geometry-descriptor result causes a later return, retaining the range updates already performed.

The function has no explicit status result, rollback, allocation-failure handling, or direct resource-release operation.

Range, geometry, layout, and construction terminology below describes inferred roles. The established contract consists of the observed accesses, arithmetic, branches, and dependency calls; those descriptive names do not establish application-level types or units.

## Behavior

### 1. Initial gate and lookup inputs

The function first reads `0x38`. If it is zero, it returns immediately.

Otherwise, it calls F-5710a8628cba with three arguments:

1. The lookup context read from `0x38`.
2. The value read from the global-backed selector source corresponding to the packed-range lookup.
3. The auxiliary value read from `0x44`.

Every later call to this dependency similarly obtains its state arguments and corresponding global-backed selector value for that call. The initial nonzero check does not establish that later context reads remain nonzero.

No total ordering between argument-expression reads within one call is established. Their placement before the corresponding call, and after earlier completed calls, is established.

### 2. Range selection

If the first lookup returns nonzero, its result is treated as a three-word descriptor. The function performs these stores in order:

1. Descriptor word 1 to `0xAC`.
2. Descriptor word 2 to `0xB0`.
3. Descriptor word 0 to `0xA8`.

It then retains an adjustment basis equal to descriptor word 0 minus descriptor word 1. Those descriptor words are read again for this calculation; the earlier values are not established as reused. Descriptor aliasing with state can therefore affect the result.

If the first lookup returns zero, three further F-5710a8628cba calls occur:

1. The fallback-start lookup result is stored at `0xAC`.
2. The fallback-end lookup result is stored at `0xB0`.
3. The fallback-selected lookup result has the then-current `0xAC` subtracted from it, producing the retained adjustment basis.

The function next stores the then-current `0xAC` plus that basis at `0xA8`.

Each fallback call reads its corresponding global-backed selector value and current state arguments. The selector values may coincide. Earlier calls may change state or globals consumed by later calls.

With stable state and nonoverflowing arithmetic, `0xA8` equals the fallback-selected result. That equality does not replace the observed subtraction, reread, and addition.

### 3. Geometry lookup and partial completion

The function next calls F-5710a8628cba using the current state arguments and the value read from the global-backed geometry-selector source.

A zero result ends execution. Prior range stores and dependency effects remain; no rollback occurs.

A nonzero result is treated as a four-word descriptor. The following stores occur in order:

1. Word 3 minus word 1 to `0xD4`.
2. Word 2 minus word 0 to `0xD0`.
3. Word 3 to `0xDC`.
4. Word 2 to `0xD8`.

The descriptor reads occur in their respective expressions, rather than through an established immutable snapshot.

The terminal descriptor values stored at `0xD8` and `0xDC` are distinct from the differences stored at `0xD0` and `0xD4`. Subsequent aggregate calculations use the terminal values.

F-b6d5936dcfc5 is then called with the state address.

### 4. Count normalization and aggregate extents

After that call returns:

1. If `0xBC`, interpreted as signed 32-bit, is below 1, it is assigned 1.
2. The resulting first count is retained locally and copied to `0xC0`.
3. If `0xB8`, interpreted as signed 32-bit, is below 1, it is assigned 1.
4. `0xC8` receives the retained first count multiplied by current `0xD8`.
5. `0xCC` receives current `0xB8` multiplied by current `0xDC`.
6. F-98677f140659 receives the state address and the retained first count multiplied by current `0xB8`.

The comparisons normalize zero and negative counts to 1. Positive counts have no visible upper bound. Geometry values are not normalized.

After F-98677f140659 returns, `0xE8` is assigned the 32-bit pattern `0xFFFFFFFF`. Its semantic meaning is unknown.

## Acceptance examples

2. **Partial range update.** A nonnull packed-range descriptor followed by a null geometry result updates `0xAC`, `0xB0`, and `0xA8`, then returns without allocation or final adjustment.

3. **Fallback arithmetic.** If fallback results are start 10, end 18, and selected value 13, with relevant state preserved, the final range fields are 10, 18, and 13. The retained adjustment basis is 3.

4. **Selectors may coincide.** If two corresponding global-backed selector sources contain the same value when read, both lookup calls receive that same selector value. The function does not require distinct selectors.

5. **Later selector mutation.** If an earlier lookup changes the global-backed value used by the geometry lookup, the geometry call receives the changed value when its own argument is read.

6. **Differences are not aggregate inputs.** Geometry descriptor `[2, 3, 8, 11]` produces ordered stores `0xD4 = 8`, `0xD0 = 6`, `0xDC = 11`, and `0xD8 = 8`. Aggregate calculations use 8 and 11.

9. **Optional dispatch.** A valid nonnull object and displacement 5 produce arguments consisting of the object, zero, −5, one, and zero. A null object or zero displacement suppresses the call.

11. **Final adjustment.** A retained basis of 3 and F-30ee4f4bfdfc result of 2 produce final adjustment 1 with two trailing zeros.
