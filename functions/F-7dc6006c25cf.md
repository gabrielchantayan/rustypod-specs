### Width conventions

Unsigned 32-bit arithmetic wraps modulo \(2^{32}\). Right shifts of the unsigned values described here are logical. Some scaling and address expressions are represented using signed 32-bit types; their wrapping interpretation is conditional on the representation corresponding to ordinary machine-width operations. This contract does not impose language-level signed-overflow semantics.

Word endianness is unknown. A word’s numerical low byte cannot be identified with a particular addressed byte without an endianness assumption.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Early truncation:** An early result of `0x12345678` produces byte `0xe0` when multiplied by four and truncated. Its later 30-bit-mask/right-shift-by-20 byte is `0x23`. The two selector reads remain distinct.

2. **Selector width:** A selector byte of `0xff` selects address `0x110` when followed by offset `0x11`. It does not supply a full-width pointer.

3. **Argument masking:** Address argument `0x00400000` produces masked argument base zero. Its times-`0x80000` selector read addresses `0x1`; validity of that access remains unknown.

4. **Wrapping boundary:** Under 32-bit wrapping arithmetic, masked-argument-base times `0x80000` depends only on the address argument’s low five bits; multiplication by `0x100000` depends only on its low four bits.

5. **Correct triple argument:** If R is one, occurrence 28 receives four, but occurrence 29 receives `0x00200000` three times—not `0x00800000`.

6. **First-small-base ordering:** Four unparameterized calls occur after occurrence 04 and before the selector read. Occurrence 05 executes only after that read and its zero store. A dependency observing memory at occurrence 05 therefore observes the ordering of the completed store, subject to other effects.

7. **Changing selectors:** If intervening dependencies change a selector from `0x10` to `0x20`, successive fresh reads may select writes at `0x21` and `0x31`. Reusing the first selector would violate the represented accesses.

8. **Paired overwrite:** If both word writes reach selector-value-times-eight plus `0x34`, the later 64-bit result’s high half is written after the earlier paired-source-times-four value. Occurrence 22 receives the earlier value before this overwrite.

9. **Fixed-address aliasing:** With saved selector zero, the payload-byte store at twice-saved-selector plus `0x0d` targets `0x0d`. The subsequent `0xc0` store targets the same address. Both stores remain observable.

10. **Transformation forwarding:** If occurrence 34 receives four times a preceding result and returns seven, occurrence 35 receives 28. It does not necessarily receive occurrence 34’s input again.

11. **Partial execution:** A dependency that does not return prevents later represented effects. Earlier completed stores have no established rollback.
