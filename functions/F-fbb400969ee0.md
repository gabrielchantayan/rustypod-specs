## Acceptance examples

These are conditional consequences of static evidence, not executed tests.

1. **Stable entry dispatch source.** If both entry reads yield the same value, incoming offset `0x000` receives that value and offset `0x01c` receives its `0xdc` adjustment. This case does not eliminate the separate reads.

2. **Second dispatch provenance.** The second transition’s base write is supplied by its assignment-time global read; its companion write is supplied by the earlier capture plus `0xdc`. Acceptance must preserve both read events without requiring equality or inequality.

3. **Post-accessor opaque value.** If preceding calls affect the opaque argument global, F-77781c8e0ff9 uses the value read after the context accessor returns, not an entry-time snapshot.

4. **Optional node absent.** A zero incoming `0x228` skips the pending drain even when incoming `0x218` is nonzero.

5. **One pending node.** If preparation leaves one node with a zero next pointer and callbacks do not repopulate the head, the head becomes zero before the payload-shaped call, which precedes the node-shaped call.

6. **Preparation replaces the optional node.** The post-helper reload determines the node linked into the second chain. If that reload is zero, no protective null branch exists.

7. **Scratch mutation.** If preparation changes scratch words A and B, a later early callback receives those current values.

8. **Associated state absent or predicate false.** Absent associated state skips the entire associated stage. A false predicate skips only its conditional context-interaction block.

9. **Repeated captured-word operation.** A true predicate plus a later context `0x28` equality causes two calls to F-a82ec4b43e2f using the original associated word.

10. **Changing context accessor results.** If the context used for the `0x24` equality check differs from the subsequent returned context, the clear targets the latter, without a repeated equality check.

11. **Collection cleared before completion.** If the retained associated state’s collection field is zero at the post-finalization check, the final collection callback is skipped.

12. **Final-target boundary.** Clearing the final target during F-c719314a16bb skips its callback but does not skip the termination-condition check. An initially absent final target skips that check entirely.
