# F-8f470c09d76b

## Purpose

The supplied static representation establishes two ordered memory reads:

1. Read a 32-bit address-bearing value from byte offset `0xF00` within the region addressed by the input.
2. Read and return the 32-bit value at byte offset `0xAF8` from the address obtained by the first read.

The function does not interpret the returned bits, validate either address, or explicitly modify memory.

## Behavior

### Established access sequence

The function first computes the location at input-base offset `0xF00` and reads four bytes from it. That read supplies the address base used for the next operation.

Only after obtaining that value does it compute the second location, at offset `0xAF8` from the newly obtained base. It reads four bytes there and returns their contents.

This is a dependent access sequence. The second address is determined by the value actually obtained from the first read. It is not derived directly from the original input.

The two offsets must not be combined into a single offset from the input. A direct read at input-base offset `0x19F8` would generally access a different location and would not satisfy this contract.

The supplied representation contains one explicit read at each location. It contains no explicit retry, repeated sampling, alternate path, fallback address, or additional field access.

### Value handling

The returned value is not compared, masked, shifted, incremented, dereferenced, or otherwise interpreted within this function. Its bits are passed through as the result.

The intermediate value is used to locate the final read. It is not returned directly. Changing that intermediate value can therefore redirect the function to a different final location even when the original input is unchanged.

There is no requirement in the visible behavior that either the intermediate value or the final value be nonzero. Zero has consequences only through its use:

- A zero intermediate value makes the second effective address `0xAF8`, subject to target address semantics.
- A zero final value is returned as zero if both reads complete.

Neither case activates a special branch.
