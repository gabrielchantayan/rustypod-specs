# F-7900a78772a8

## Purpose

F-7900a78772a8 performs a fixed sequence of low-address state updates and writes through addresses derived from its second argument. The supplied representation then terminates at an invalid-instruction boundary; it does not establish a normal return.

**Established static evidence:** the visible sequence clears several state locations, records a truncated scaled address, publishes two successive pointer values to one state slot, and writes zero and ambient register-derived values to argument-derived locations.

**Inferred intent:** the sequence resembles low-level initialization or machine-state setup. That interpretation does not establish a device protocol, buffer layout, reset procedure, or successful initialization outcome.

**Scope:** this contract describes the visible sequence and its ordering. It does not repair suspicious arithmetic, infer missing control flow, or treat the terminal operation as a successful completion.

The second argument is not shown as an array of a known length. Its pointer type establishes the scaling of one pointer expression, not the allocation size, ownership, alignment guarantees, or intended object identity.

### Ordered visible effects

The following order is established by the supplied representation. A fault or target-specific exceptional effect can prevent later operations.

1. **Clear G36.**  
   Zero is assigned to G36. The assignment does not establish its storage width.

2. **Clear U.**  
   Zero is assigned to U. Its width and any hardware meaning are not established.

3. **Store a narrowed scaled address in G2A.**  
   The integer form of P is multiplied by eight and explicitly narrowed to 16 bits before assignment to G2A. Where ordinary low-bit narrowing applies, the assigned value is the low 16 bits of that product.

   This is address arithmetic. It does not read a 16-bit value from P.

4. **Publish P to R.**  
   R receives the second argument’s pointer value.

5. **Write G2A to the scaled destination.**  
   A 16-bit write is directed to B + 0x20. Its value is obtained from G2A at this point in the sequence.

   The destination is not P + 0x20. The multiplication by eight precedes the addition.

   The value is also not unconditionally a fresh recomputation of the earlier truncated product. If the intervening assignment to R affects storage overlapping G2A, the value read here can reflect that overlap.

6. **Clear four bytes at P + 4.**  
   A zero-valued 32-bit store is directed to P + 4. The four-byte displacement follows from advancing the 16-bit pointer by two elements before interpreting the destination as four-byte storage.

7. **Repeat the same four-byte clear.**  
   A second zero-valued 32-bit store is directed to the same address, P + 4.

   Both stores are present in the visible sequence. They must not be collapsed in this contract merely because their values and destinations match. Repeated writes may matter for memory-mapped devices or other observable storage.

8. **Write V at C.**  
   A four-byte integer store writes the ambient value V to C.

9. **Clear the next four-byte word.**  
   A four-byte zero store is directed to C + 4.

10. **Write a shifted form of V.**  
    A four-byte integer store is directed to C + 8. Its represented value is V shifted left by ten bit positions.

    The representation does not establish a safe signed-arithmetic interpretation for every possible V. In particular, negative values and values whose mathematical shifted result exceeds the signed range require target-level evidence before their exact result can be specified.

11. **Clear A.**  
    Zero is assigned to A. Its storage width is not established.

12. **Replace R using a late read of S.**  
    S is read, converted to an unsigned 32-bit value, shifted left by 16 bit positions, converted to a pointer, and assigned to R.

    At the represented unsigned-operation level, the shifted result retains only the low 16 bits of the converted source, placing them in bits 16–31; its low 16 bits are zero. The subsequent integer-to-pointer conversion remains target-dependent.

    This is a late read, not an entry-time snapshot. Earlier writes may affect S if their storage overlaps it.

13. **Clear the first 16 bits at P.**  
    A 16-bit zero store is directed to P.

    This write uses the original argument value P, not the replacement value most recently assigned to R. It can nevertheless alter R’s storage if P aliases that storage.

14. **Reach the terminal invalid-instruction operation.**  
    The supplied representation ends here. No subsequent memory effects or return path are established.

### Arithmetic boundaries

The multipliers eight and 256 apply to the integer form of the address. They are not element counts for a validated array.

Three distinctions are material:

- The value assigned to G2A is explicitly narrowed to 16 bits.
- B and C are calculated independently from P; neither is obtained by widening the narrowed value in G2A.
- The unsigned shift used for R’s second assignment has a clearer 32-bit bit-pattern interpretation than the signed multiplication and signed shift expressions elsewhere.

The supplied representation does not independently prove overflow behavior for the signed address calculations. A 32-bit modular-address interpretation may be appropriate to the underlying machine, but it is not an unconditional finding of this contract.

## Side effects

| Destination | Write width | Value |
|---|---:|---|
| B + 0x20 | 16 bits | G2A as read at that step |
| P + 4 | 32 bits | Zero, written twice |
| C | 32 bits | V |
| C + 4 | 32 bits | Zero |

This table is not a final-memory guarantee. Destinations may overlap one another or the named state slots. Later writes take precedence where the target’s access semantics permit ordinary overlapping writes.

There is no visible direct write to the two bytes at P + 2. That omission does not prove those bytes remain unchanged: another computed destination or named-state assignment may overlap them.

No locking, atomicity, interrupt masking, memory barrier, or concurrency guarantee is established. The ordered description records the supplied representation; it does not independently establish device-bus transaction order or compiler-preserved observability for every target.

## Acceptance examples

These are conditional static examples, not executed tests.

### Non-overlapping, representable addresses

Assume:

- P has integer value 0x1000.
- All relevant accesses succeed.
- Named state locations and computed destinations are disjoint.
- V is 3.
- S yields 0x1234 at its late read.
- The stated address and pointer conversions behave as represented.

The visible sequence requires:

- G2A receives 0x8000.
- A 16-bit value of 0x8000 is written at 0x8020.
- Two distinct 32-bit zero stores target 0x1004.
- The four-byte words at 0x100000, 0x100004, and 0x100008 receive 3, zero, and 0xC00 respectively.
- R first receives P and later the pointer conversion of 0x12340000.
- A 16-bit zero store targets 0x1000 after R’s replacement.
- The terminal boundary is reached rather than a demonstrated normal return.

The untouched gap at P + 2 is not an implied zeroed field.

### Narrowed value versus full computed destination

Assume P has integer value 0x3000, with ordinary representable arithmetic and no relevant aliasing.

Eight times P is 0x18000. G2A receives 0x8000 after narrowing, while the 16-bit store destination is 0x18020. Using 0x8020 as the destination would incorrectly narrow the address along with the stored value.

### Late source read

Assume an earlier write changes storage overlapping S. R’s second assignment must use S as observed at the late read, not S’s entry value. The exact value depends on overlap, byte order, widths, and access behavior.

### Early access failure

If the write to B + 0x20 fails, the contract does not require either clear at P + 4, any write at C, or arrival at the terminal boundary. No rollback of preceding state assignments is established.
