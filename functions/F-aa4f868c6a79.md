# F-aa4f868c6a79

## Purpose

F-aa4f868c6a79 exposes a partially recovered sequence of indirect calls, five 32-bit memory writes, four byte writes, and four byte reads. The recovered sequence ends at an instruction-decoding failure rather than an established normal return.

The evidence supports a contract for the **visible execution prefix**, conditional on its calls returning and its memory accesses succeeding. It does not establish a complete callable routine, a successful completion condition, or a higher-level purpose.

The repeated scaling and fixed-offset writes suggest structured state manipulation, but neither the structures nor the meaning of their fields is established. In particular, the byte writes must not be described as serialization into a contiguous output buffer: each destination depends on a byte read from memory, and intervening calls can change that byte.

### 6. First byte write

2. Adds 17 to the byte’s zero-extended value.
3. Writes the low eight bits of the first unsigned payload shifted left by two to that destination.

The destination is consequently in the inclusive range 17 through 272. It is not the retained byte-source base plus 17.

F-unknown-33 then receives the full 32-bit unsigned result of shifting the first unsigned payload left by two. Bits shifted beyond bit 31 are discarded.

F-unknown-40 then receives the result of F-unknown-39 shifted left by two. The recovered representation treats that result as signed; overflow and negative-value behavior require the qualifications in **Uncertainties**.

## Acceptance examples

These are conditional static examples, not executed tests. Each assumes the relevant calls return, arithmetic has the stated representable values, and all referenced memory is accessible.

1. **First word destination:** If F-unknown-05 returns 3, the first word store targets address 32 and writes the incoming stored word. F-unknown-06 receives 12.

2. **Different value and address scales:** If F-unknown-10 returns 5, the second word store writes 20 at address 100. If F-unknown-15 later returns 7, the third word store also writes 20, but at address 48. F-unknown-16 receives 28.

3. **Fourth word and arguments:** If F-unknown-20 returns 2, the fourth word store writes 8 at address 52. F-unknown-21 receives 8 followed by 32.

4. **Byte truncation:** If the first unsigned payload is 67 and the first selector read returns 9, the first byte store writes 12 at address 26. F-unknown-33 receives 268, not 12.

5. **Fresh selector reads:** If the first selector read returns 9 but an intervening dependency changes the same source byte to 12, the second byte write targets address 29 rather than address 26.

6. **Upper-bit extraction:** If the first unsigned payload is hexadecimal 12345678, the second byte store writes hexadecimal 23. This demonstrates truncation of the ten-bit mask-and-shift result to eight bits.

7. **Third-call argument distinction:** If the third selector read returns 200 and the second unsigned payload is 1, the third byte write stores 4 at address 217. F-unknown-45 receives 200.

8. **Different final selector source:** If the second unsigned payload is 1, the final selector read is from address 9, regardless of the retained control-word-derived source address.
