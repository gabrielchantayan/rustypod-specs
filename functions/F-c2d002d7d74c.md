# F-c2d002d7d74c

## Purpose

F-c2d002d7d74c classifies an integer argument into a small set of 32-bit results. Classification depends on both the argument and a global comparison value.

The function is not an unconditional lookup table. It first tests whether the argument equals the global value. If that test succeeds, it returns zero. Otherwise, a comparison against the global value selects one of two distinct classification tables. A value recognized by one table can be rejected when the other table is selected.

The established result set is:

- Zero for the initial equality case.
- One, two, four, or five for selected argument values in the selected table.
- The 32-bit all-ones pattern for any argument not recognized by the selected table.

## Behavior

### Equality takes precedence

The function first compares the input with the comparison value.

If they are equal, the result is zero. No subsequent classification table is consulted.

This precedence applies even when the input is otherwise recognized by a table. For example, equality at input 2 produces zero rather than two; equality at input 0x1908 produces zero rather than four.

Equality is the only explicit route to a zero result.

### Selection of the classification table

When the initial equality test fails, the function evaluates whether the comparison value is less than the input.

- If that comparison is true, it uses the **upper-side table**.
- If that comparison is false, it uses the **remaining-side table**.

These names describe control flow, not an independently established numeric encoding.

With a stable comparison value and ordinary consistent integer ordering, the remaining-side table corresponds to inputs strictly below the comparison value, because equality has already returned. That interpretation must not be assumed if the two global observations can differ.
