## Behavior

The sequence below preserves represented ordering. Any earlier fault or abnormal endpoint can prevent later operations.

### 1. Initial arithmetic

Form the unsigned 32-bit difference B minus `0xA8`, modulo \(2^{32}\).

From that difference, derive:

- A halfword-addressed base **H**, equal to twice the difference under unsigned 32-bit arithmetic.
- A masked value **M**, retaining only bits 0 through 30.
- An index **I**, equal to M logically shifted right by one.

I ranges from zero through `0x3FFFFFFF`.

A separate word-addressed base **W** is represented by shifting signed D left by two and then right by 32. W is **documented_only**: neither a portable result for the shift by 32 nor safe signed-left-shift behavior is established. W must not be silently replaced with zero or evaluated using an assumed processor shift-count rule.

3. Write the low byte of B at address B plus six. This addition is represented with unsigned 32-bit arithmetic.
4. Write B as a word at W.
5. Write halfword `0xFFFF` at H plus four.
6. Write halfword `0xFFFF` at H plus six.

### 3. First dependency reference and early endpoint

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Zero difference.**  
   With B equal to `0xA8`, H, M, and I are zero under the represented unsigned arithmetic. Low-address accesses remain present; successful execution is not promised.

2. **Unsigned wraparound.**  
   With B equal to zero, the difference is `0xFFFFFF58`, H is `0xFFFFFEB0`, M is `0x7FFFFF58`, and I is `0x3FFFFFAC`. The initial index-derived byte is `0xAC`; M shifted right by 17 is `0x3FFF`.

3. **Negative reference endpoint.**  
   If signed R is negative and preceding accesses complete, the halfword store at Q plus four occurs before the first abnormal endpoint. Acceptance must not require unchanged memory.

4. **Signed halfword reduction.**  
   Under arithmetic right shifts, a halfword read of `0x7FFF` yields a stored word of zero; `0x8000` yields `0xFFFFFFFF`.

5. **Repeated stores.**  
   If storage records each access, both halfword stores at Q plus `0x12` and both word stores at R remain observable around the intervening signed halfword read.

6. **Stable later address global.**  
   If the assignment to `0x0897EA80` produces value A, all subsequent relevant reads return A, and address arithmetic is valid, the self-addressed store writes A at A and the following store writes I at A plus four. This consequence requires the stated stability assumptions.

7. **Changing later address global.**  
   If the self-addressed store’s address read returns A and its value read returns B₁, that store writes B₁ at A. If the following destination read returns C, the next store targets C plus four. Equality among these reads is not required by the static evidence.

8. **Fresh reset halfword.**  
   If `Reset_2` is initially assigned `0x1234` but its final read returns `0xABCD`, the final concatenation is `0xABCDEA70`, not `0x1234EA70`.

9. **No fabricated success.**  
   Reaching the final assignment leads to the final abnormal-instruction marker, not a documented normal return.
