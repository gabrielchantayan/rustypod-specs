# F-a805b851fa00

## Purpose

F-a805b851fa00 repeatedly executes an ordered sequence of indirect calls, memory accesses, and a software breakpoint. The supplied static representation has an unconditional loop and no normal return path.

Its established behavior is dispatch and state mutation. No application-level purpose, such as initialization, data transfer, or device control, is established.

An uninterrupted iteration reaches 37 call sites and issues 15 explicit memory stores: three byte stores, five halfword stores, and seven word stores. Reaching the next iteration requires every intervening call, access, and breakpoint operation to permit continuation.
