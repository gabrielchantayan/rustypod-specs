## Behavior

### Selection and direct result

The first logical field access is the unsigned 32-bit selector at primary offset `0x124`.

Only its least significant bit affects the selected path. Other bits are ignored by this function.

If that bit is set, the function reads the signed 32-bit value at primary offset `0x11C` and returns it unchanged. This path does not call F-870c4fcf7295 and does not inspect the related-object reference.

The direct result can be positive, zero, or negative. No lower-bound adjustment applies to it.

### Absent related object

If selector bit zero is clear, the function reads the address-like field at primary offset `0xEC`.

If that value is zero, the function returns zero. It does not call F-870c4fcf7295. In particular, it does not return the field at `0x100` on this path.

No attempt to inspect a related object occurs after the zero-reference decision.

### Derived result

When selector bit zero is clear and the related-object reference is nonzero, the function obtains a signed reference value from related offset `0x80`.

It then forms two signed differences:

- First dependency input: the primary value at `0xD0` minus the captured related value at `0x80`.
- Second dependency input: the related value at `0x88` minus that same captured value.

F-870c4fcf7295 receives those two differences, in that argument order, and supplies a signed integer result.

After the dependency returns, F-db43e2972367 reads the primary value at `0x100`. This timing is part of the contract: the value used is obtained after the call, not captured before it.

For representable signed arithmetic, the function returns the greater of:

- That post-call value at `0x100`.
- That value plus the dependency’s result.

Consequently, within this arithmetic domain:

- A positive dependency result increases the returned value.
- A zero dependency result leaves the value unchanged.
- A negative dependency result also leaves the value unchanged.

This is a lower-bound rule relative to the post-call field. It is not an established upper-saturation rule.
