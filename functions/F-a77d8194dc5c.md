# F-a77d8194dc5c

## Purpose

F-a77d8194dc5c performs a recovered sequence of three indirect operations: one on an object referenced by the receiver, followed by two on the receiver itself.

After the first operation returns, the function captures an external shared value into a four-byte temporary. It then **reads the same external storage separately** while preparing the middle operation. The middle operation receives that separate read; only the final operation explicitly receives the retained temporary.

Consequently, the middle and final shared arguments need not be equal. Equality requires the two reads to observe the same value.

The supplied static representation does not establish the operations’ application-level purpose. Initialization, notification, resource management, and similar interpretations remain unsupported.

An unresolved indirect-control-flow boundary affects the final operation. This contract distinguishes the recovered invocation sequence from a runtime-established guarantee about the executable’s final transfer and continuation.
