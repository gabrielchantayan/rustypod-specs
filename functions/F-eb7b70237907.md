# F-eb7b70237907

## Purpose

F-eb7b70237907 performs an ordered, first-positive dispatch over twelve candidate values obtained from a global table. It compares an input selector against each candidate using F-a1e68ae27737. On the first nonzero comparison result, it prepares a local two-word working area through F-1ece76539767 and invokes the handler associated with that candidate.

The Boolean result indicates whether a candidate produced a nonzero comparison result. It does not establish that preparation or handling succeeded.

The observable contract is defined by candidate offsets, comparison order, dependency arguments, and the returned Boolean. The meanings of the candidates, the comparison relation, and the individual operations are not established.

### First-positive precedence

Only the first candidate producing a nonzero comparison result is selected. After selection:

- No later candidate is compared.
- No later candidate read is required by the visible control flow.
- Exactly one preparation call is made.
- Exactly one handler call is made, provided preparation returns normally.

Duplicate candidate values do not change this precedence. If multiple candidates would produce nonzero results, the earliest reached candidate wins.

Candidate values are obtained when their comparisons are reached, rather than being visibly copied into a complete local snapshot before comparisons begin. This matters if a dependency modifies table memory between comparisons.
