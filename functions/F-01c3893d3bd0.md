### 4. Transition to the repeating cycle

The operation extracts bits 25 through 29 of the `F-D34` result. This produces a value from 0 through 31.

A second selector-read address is formed from the retained shifted `F-D22` result: multiply that retained value by `0x400`, then add one. The operation reads one unsigned byte at this address and writes zero at the address obtained by adding `0x11` to that byte.

This read address is distinct in construction from the earlier selector base. It does not depend on the just-computed five-bit extraction.

The operation calls:

35. `F-D35`, with twice the five-bit extraction. Its explicit argument is therefore an even number from 0 through 62.
36. `F-D36`, with no explicit argument, retaining its result as the initial cycle payload.

The five-bit extraction becomes the initial cycle bit-state.

### 5. Unconditional repeating cycle

The first cycle entry calls `F-D37` with two explicit arguments:

- The current cycle payload.
- The current cycle bit-state logically shifted right by eight.

On this first entry, the second argument is necessarily zero because the initial bit-state is at most 31.

The remainder of the cycle is:

1. Call `F-D38`, `F-D39`, and `F-D40`, each with no explicit argument.
2. Call `F-D41`, with no explicit argument, retaining its result.
3. Read a fresh unsigned byte from the second selector-read address established above.
4. Write zero at that byte value plus `0x11`.
5. Call `F-D42`, with the result of `F-D41` shifted left by two.
6. Call `F-D43`, `F-D44`, and `F-D45`, each with no explicit argument.
7. Call `F-D46`, with no explicit argument, retaining its result.

The cycle payload becomes the result of `F-D46` shifted left by two. The cycle bit-state becomes that result shifted left by 26.

Execution then repeats without a visible exit test. Crucially, subsequent cycle entries call `F-D47`, not `F-D37`, with the same two-argument arrangement. The remainder of the cycle continues to use `F-D38` through `F-D46`.

Under a 32-bit shift interpretation, the recurring bit-state retains only the low six bits of the latest `F-D46` result, positioned at bits 26 through 31. Its logical right shift by eight therefore supplies those six bits at positions 18 through 23 to `F-D47`.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests.

1. **Initial store ordering.** With a first argument of 3 and valid applicable arithmetic and memory, the first four-byte write stores 3 at address `0x20`. Only after `F-D01` through `F-D05` complete does the second four-byte write store 12 at that same address.

2. **Selector re-read.** If the selector byte is 4 for the first selector-directed write, its destination is `0x15`. If dependencies change that byte to 9 before the next selector-directed write, the latter destination is `0x1a`, not `0x15`.

3. **First retained result extraction.** If `F-D10` returns `0x12345678`, the first selector-directed byte is `0xe0`. The later selector-directed byte derived from that same retained result is `0x23`, assuming intervening execution completes.

4. **Fourth-argument addressing.** With a fourth argument of `0x100`, the fourth-argument base is 2. The direct byte-write destination is `0x1e`, and the explicit argument to `F-D23` is 2.

5. **24-bit extraction.** If `F-D22` returns `0x12345678`, the explicit argument to `F-D25` is `0x0048d159`. This extraction uses the unshifted retained result.

6. **Initial cycle entry.** If bits 25 through 29 of the `F-D34` result are all set, `F-D35` receives 62. The second argument to the first cycle-entry dependency, `F-D37`, is still zero.

7. **Recurring cycle state.** Under 32-bit shift semantics, if `F-D46` returns 1, the next cycle payload is 4 and the next bit-state is `0x04000000`. The ensuing `F-D47` call receives 4 and `0x00040000`.

8. **Early interruption.** If the first memory write cannot complete, no later direct effect is guaranteed. If a dependency fails to return, none of the subsequent operations is guaranteed.
