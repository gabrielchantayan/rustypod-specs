# F-6d4e5f4e1b57

## Purpose

F-6d4e5f4e1b57 conditionally retrieves a 32-bit value from a caller-supplied memory region. A selector and a one-byte discriminator determine whether the result comes from offset 36, 40, or 44 relative to the supplied base address. When no selection condition succeeds, the function returns a 32-bit zero.

The established behavior is a conditional memory lookup. The semantic meaning of the discriminator, selectors, and stored values is unknown. In particular, the stored values are not established to be pointers, handles, counts, or status codes.

The function has no visible writes and no visible function calls. Its result can nevertheless depend on memory changing between reads: selector 0 sometimes reads the discriminator twice.

## Behavior

### Stable-memory selection

When the discriminator remains unchanged throughout the invocation, the selection behavior is:

| Selector | Required discriminator | Result on success |
|---:|---|---|
| 0 | 0 or 1 | Slot A, offset 36 |
| 1 | 1 | Slot B, offset 40 |
| 2 | 0 | Slot B, offset 40 |
| 3 | 0 | Slot C, offset 44 |

| 5 | 3 | Slot A, offset 36 |
| 6 | 4 | Slot A, offset 36 |
| Any other value | None | Zero; no region reads |

For selectors 0 through 6, failure to meet the applicable discriminator condition produces zero without reading a result slot.

Discriminator comparisons are exact byte comparisons against 0, 1, 2, 3, or 4. Other byte patterns do not satisfy those comparisons. No ordering, range interpretation, or arithmetic is applied to the discriminator.

### Read order and repeated observations

The following describes the access sequence represented by the supplied static evidence. It does not establish machine-level atomicity, memory-ordering guarantees, or a supported concurrency model.

**Selector 0**

The discriminator is read first.

- If the first observation is zero, the function reads slot A and returns its value. There is no second discriminator read on this path.
- If the first observation is nonzero, the function reads the discriminator again.
- If that second observation is exactly 1, the function reads slot A and returns its value.
- If that second observation is anything other than 1, the function returns zero without reading a result slot.

Consequently, “discriminator is 0 or 1” is only a stable-memory summary. The general behavior depends on the two observations separately.

For example, an initial observation of 2 followed by an observation of 1 selects slot A. An initial observation of 1 followed by an observation of 0 returns zero. Neither outcome can be described accurately by treating the two reads as one snapshot.

**Selectors 1 through 6**

Each of these selectors reads the discriminator once. A successful comparison is followed by one four-byte read from the applicable result slot. A failed comparison returns zero without a result-slot read.

**Unsupported selectors**

The function returns zero without reading the discriminator or any result slot. The supplied base address does not participate in a visible memory access on these paths.

### Result timing

A selected result comes from the later result-slot read, not from an earlier snapshot of the region. The function does not read candidate result slots before checking the discriminator.

Once a discriminator condition succeeds, no further discriminator check is shown before the selected result is returned. Changes to the discriminator after the successful observation therefore do not cause a visible recheck in this function.

The function performs no visible retry, fallback lookup, or validation of the selected value. Failure to select slot A does not cause slots B or C to be examined.
