# F-97b91f6ee296

## Behavior

### Initial selection and transfer order

A nonzero seed bypasses the initial transfer and all gated middle-section work. The terminal cycle begins with the incoming link address as its initial call base.

A zero seed enables the initial transfer. Its represented order is:

1. Form an auxiliary address from the link address, incoming carry, and entry stack address shifted right by one.
2. Calculate the destination as the transfer base plus the displacement, using a byte offset.
3. Read one 16-bit value from the original transfer base.
4. Update the comparison-address state to the destination minus the adjustment.
5. Write the previously read 16-bit value to the destination.
6. Clear the carry used by the following condition chain.

The comparison-state update therefore occurs **after the source read and before the destination write**. The destination write does not precede that update.

Once the seed is zero, a nonzero link address does not suppress the transfer. It only prevents progress through the later gates.

The source and destination may coincide: the representation still contains a read followed by a write. It does not test for equality or require non-overlap.

Updating the comparison address performs arithmetic; it does not read memory at the resulting address. The update also does not change the already calculated destination or the retained halfword being written.

### Zero-gated condition chain

Each middle-section stage is enabled only when the preceding relevant condition succeeds. A failed gate skips the remaining gated work and reaches the terminal cycle; it does not return an error.

Several gates combine exclusive-or with a right shift whose count is selected from the low byte of the preceding result. On the reachable gated prefix, that preceding result is zero. The relevant shift count is consequently zero.

These operations therefore act as equality or zero tests on that prefix. No assumption about large variable shift counts is needed for the reachability deductions below.

### Conditions for the exceptional path

Under the stated arithmetic model, reaching the exceptional additional write requires:

- Seed equals zero.
- Link address equals zero.
- Auxiliary address equals zero.
- Displacement equals comparison word.
- The updated comparison address equals adjustment.
- Accumulator equals zero.
- Entry stack address plus twice the displacement equals zero modulo \(2^{32}\).

The accumulator requirement follows because the seed has already been forced to zero and carry has been cleared. The gated addition therefore reduces to the accumulator alone and produces no carry when its result is zero.

With the link address zero, the auxiliary address is the logical right shift of the entry stack address by one, plus the incoming carry. The shifted value lies between zero and \(2^{31}-1\); adding a one-bit carry cannot wrap it to zero. A zero auxiliary address therefore requires:

- Entry stack address is zero or one.
- Incoming carry is zero.

The later requirement involving twice the displacement excludes an entry stack address of one. Twice a 32-bit quantity is even modulo \(2^{32}\), so adding one cannot produce zero.

The complete conditions reduce to:

- Seed, link address, entry stack address, incoming carry, and accumulator are zero.
- Displacement is either zero or `0x80000000`.
- Comparison word equals displacement.
- Transfer base plus displacement equals twice the adjustment modulo \(2^{32}\).

These are derived reachability conditions, not checks performed at entry or evidence that such machine states are operationally valid.

### Exceptional additional write

If all gates succeed, the representation performs the following exceptional work:

- Assign the opaque machine-state slot the entry stack address multiplied by 64.
- Form a revised link-derived address by adding 64 times the entry stack address to the link address.
- Read a halfword at the link address to select a destination address.
- Read a halfword at the same link address to obtain a value, then add 15 to that value.
- Write the low 16 bits of the sum to the selected destination.
- Advance the seed-derived address by one halfword, meaning two bytes.
- Clear the carry used by the next chain and adopt the revised link-derived address.

The two halfword reads occur within one represented write expression. Their relative evaluation order is not established. Both must supply their values before the dependent write, but a contract must not require the address-selecting read to precede the value-selecting read or vice versa.

On this path, the link address and entry stack address have already been forced to zero. Consequently:

- The opaque slot receives zero.
- The revised link-derived address is zero.
- Both halfword reads address zero.
- The selected destination is the zero-extended 16-bit result of the address-selecting read.
