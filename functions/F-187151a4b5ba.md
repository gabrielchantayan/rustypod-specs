# F-187151a4b5ba

## Purpose

The writes affect the single byte at offset `0xB1` and the sixteen-byte range from `0xB4` through `0xC3`, inclusive. The intervening bytes at offsets `0xB2` and `0xB3` are not written.

## Behavior

There are no conditional branches in the supplied body. Every destination is attempted on the normal execution path, regardless of the previous contents of any destination.

No destination value is read before being overwritten. The operation does not compare existing contents, preserve selected bits within a written location, or skip a write because a location already contains zero. In particular, an already-cleared region still follows the same write sequence.

For ordinary byte-addressable memory, successful completion leaves:

- The byte at `0xB1` equal to zero.
- Every byte from `0xB4` through `0xC3` equal to zero.
- Bytes outside those destinations unchanged by the function’s explicit stores.

The four-byte zero writes produce zero in all four covered bytes; this result does not depend on byte order.

The sixteen-byte affected range is not represented as one bulk write. Its established access structure is three four-byte writes and four one-byte writes. Together with the separate byte at `0xB1`, this yields eight explicit stores. The evidence does not, however, establish atomicity or hardware-level visibility guarantees for those stores.
