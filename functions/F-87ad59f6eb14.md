# F-87ad59f6eb14

## Purpose

F-87ad59f6eb14 observes a single flag in storage addressed through its input and returns that flag as an unsigned zero or one.

The selected flag is **bit 4**, counting from the least significant bit as bit zero. Its numeric weight is **16**. The containing byte is located at an address obtained by adding **24** to the supplied integer.

For every defined, normally completed invocation:

- The result is **0** when the selected bit is clear.
- The result is **1** when the selected bit is set.
- Other bits in the observed byte do not affect the result.

No application-level meaning for the flag is established. In particular, a result of one is not evidence of initialization, validity, ownership, availability, or successful completion of another operation.

This is a static behavioral contract. No runtime tests have been performed.

## Behavior

### Flag observation

The result reflects the selected bit in the value obtained by the byte read. All other bits are discarded for purposes of the result.

For example, a byte with only bit 4 set produces one. A byte with every low-order eight-bit position set except bit 4 produces zero. These outcomes distinguish a normalized flag query from either returning the whole byte or checking whether the byte is merely nonzero.

The return value does not preserve any information about neighboring flags. A consumer cannot distinguish two byte values that agree on bit 4 by calling this function alone.

### Observable access and ordering

The body contains one logical byte read and no explicit memory writes. The return value depends on that read, so a successful result follows the observation of the selected storage.

There are no explicit calls, additional data reads, validation accesses, or intervening updates in the body.
