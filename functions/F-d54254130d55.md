1. **Initial observable write.** If A is 3 and the destination is writable, the first direct write stores the 32-bit value 3 at address `0x20`, before F-0001. No behavior is established if that destination faults.

3. **Byte truncation.** If X is `0x10000041`, the first P-selected store writes `0x04`; the later P-selected store derived from X writes `0x00`. Neither store writes a full shifted word.

4. **Changing selector.** If the selector read for one P-based write returns 2, that write targets `0x13`. If a later selector read returns 9, the later write targets `0x1a`. Reusing `0x13` would not match the represented behavior.

5. **Aliasing between adjacent operations.** If the Q-derived direct byte destination equals the P-selector address, the subsequent zero write selects its destination using the byte just written there, assuming no intervening external memory change.

7. **Later loop argument boundary.** Under 32-bit truncating shifts, if K is `0xffffffff`, the next F-0061 arguments are `0xfffffffc` and `0x00fc0000`.

8. **Nonreturning dependency.** If a dependency does not return, no later represented operation is required to occur. Earlier writes remain observable subject to the environment’s memory semantics.
