1. **First-target calculation.** If incoming link state is `0x08712031`, F-U01 targets `0x0871302f`. Reaching the final assignment establishes that same represented calculation for the next iteration, subject to continuation and hidden-state qualifications.

2. **Assignment before final read.** If execution reaches the link-state assignment but the subsequent F-U37 argument read faults, the visible sequence has already assigned `0x08712031`; F-U37 has not been invoked.

3. **Equal targets, distinct interfaces.** F-U05 and F-U06 must use equal target addresses even though one occurrence supplies a paired result and the other receives two explicit arguments. Equal addresses do not require equal results.

4. **Unsigned extraction and shift.** If F-U09’s low half is `0xfc000003`, the frame-offset `0x26c` store contains 63. Its later unsigned left-shifted word store contains `0xf000000c`.

5. **Zero-extension.** If the third halfword is `0xffff`, both destination word stores at offsets `0x54` and `0x64` contain `0x0000ffff`, not `0xffffffff`.

6. **Captured first global.** If the first global yields address A and F-U04 changes the global to B, the byte stores still use A plus `0x11` and A plus `0x15`, provided execution remains valid.

7. **Captured byte.** If the late source-byte read yields `0x7a` and F-U34 changes that source to `0x22`, the following byte store still writes `0x7a`.

8. **Halfword truncation.** If the captured second global has low 16 bits `0x5678`, its dependent halfword store writes `0x5678`; its destination still uses the captured full word plus the scaled F-U19 result.

9. **Breakpoint interruption.** If execution stops permanently at the breakpoint, none of the post-breakpoint operations occurs.

10. **Anchor movement.** For an iteration beginning with anchor S, the F-U28 frame store uses S plus `0x258`. If repetition occurs without other anchor alteration, the next iteration’s frame-relative accesses use S minus `0xf4`.
