# F-ebb362b154c9

## Purpose

F-ebb362b154c9 reverses the byte order within each of three selected unsigned words in supplied storage. Under the unsigned 32-bit interpretation, each selected word contains four 8-bit bytes. The selected word indices are 0, 1, and 13 relative to the supplied address.

Each transformed value replaces its own input word. The function does not exchange the selected words, reverse the surrounding storage, or transform the intervening words.

**Established static evidence:** the supplied representation contains three ordered read–transform–write operations, with no calls, branches, loops, or explicit error handling.

**Inferred intent:** the transformation is consistent with byte-order conversion for three fields of a larger record. The record format, application, and intended source and destination byte orders are not established.

## Behavior

### Transformation

For each selected 32-bit word, the replacement reverses the significance order of its four bytes.

If the original bytes, from most significant to least significant, are A, B, C, and D, the replacement bytes in that same significance order are D, C, B, and A.

For a numerical input \(x\), let:

\[
b_k=\left\lfloor\frac{x}{256^k}\right\rfloor\bmod256,
\qquad k\in\{0,1,2,3\}.
\]

The replacement is:

\[
256^3b_0+256^2b_1+256b_2+b_3.
\]

Every input byte contributes to exactly one output byte. Bytes from different selected words are not combined.

Under unsigned 32-bit semantics:

- The lowest byte moves to the highest byte position.
- The next-lowest byte moves to the next-highest position.
- The next-highest byte moves to the next-lowest position.
- The highest byte moves to the lowest position.
- Right shifts introduce zeros.
- Bits shifted beyond the 32-bit result are discarded.
- The middle-byte masks isolate their respective contributions.
- The four contributions occupy disjoint bit positions.

The replacement lies between zero and \(2^{32}-1\), inclusive. No arithmetic error is reported.

This numerical transformation does not require assuming host endianness. Describing it as conversion to a particular external byte order would require additional evidence.

### Repeated application and fixed points

Four-byte reversal is an involution: applying it twice restores the original word.

Two completed calls therefore restore all three selected words when their storage remains valid and nothing else changes their contents during or between calls.

A single application leaves a word numerically unchanged when its outer bytes match each other and its inner bytes match each other. Examples include zero, the maximum unsigned 32-bit value, and `0x12ABAB12`.

These properties describe resulting values. They do not remove the represented accesses or establish synchronization guarantees.
