### Current values, not an entry snapshot

The function does not first copy all input fields. Each field is read only when its step is reached.

Consequently, an earlier dependency can affect a later input if it can reach the same storage through an external alias. The later call receives the value present at the later read, not necessarily the value present when F-5882e0ac208c was entered.

Each dependency receives a scalar field value, not an explicit address of that field. This does not prove that the dependency lacks other access to the buffer or related state.

The result of each dependency is written after that dependency returns. If the dependency changed the currently processed field through an external alias, the subsequent direct write replaces that field with the returned result. Changes to already processed fields are not subsequently repaired or revisited by this function.
