## Acceptance examples

These examples are conditional static criteria, not executed tests.

1. **Unsigned widening.** If an explicit unsigned byte load yields 0xFE, its associated widened word value is 0x000000FE, not a sign-extended negative value.

2. **Small-component boundary.** Under 32-bit bit-vector arithmetic, a contributing result whose low seven bits are all set produces 508; doubling produces 1016. Storage validity remains a separate precondition.

3. **Successive truncation.** A word shifted left by 25 and then left by seven becomes zero under that model. A wider intermediate retaining discarded bits would not match it.

4. **Global read timing.** If earlier writes change the word at 0x087FBBBC before its specified read, the repeated region uses the changed word. Capturing an entry-time value instead is not equivalent.

5. **Retained global-derived base.** If a repeated-region store subsequently aliases 0x087FBBBC, later groups still use the captured base. No reload is represented.

6. **First 0x67 read.** The trace includes the initial byte write at 0x67, then the computed offset-0x44 word load, then the byte read supplying 0x21. Moving the byte read before that word load does not preserve the represented ordering.

7. **Later 0x67 reads.** If intervening computed writes change 0x67 between its second and third reads, the two associated computed byte stores may receive different values. Reusing the second read for both stores is not justified.

8. **Stable byte storage.** If no intervening write, read side effect, or external event changes ordinary byte storage at 0x67, all three reads yield the initially written byte. This is conditional, not a general invariant.

9. **Access widths.** A halfword store of 0x003A cannot be replaced by a byte store solely because both retain 0x3A in their low eight bits.

10. **Failure and ownership.** An invalid indirect destination has no promised clean failure status. An address-bearing dependency result creates no inferred release obligation. If F-U003 does not return, normal completion is not required.
