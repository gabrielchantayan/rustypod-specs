# F-22114ba36547

## Purpose

F-22114ba36547 is a two-way indirect dispatcher. It selects one of two callable targets according to whether its single integer argument equals zero.

The established behavior is narrow:

- For zero, transfer control to the zero-case target without supplying explicit arguments.
- For any nonzero value, transfer control to the nonzero-case target with two explicit arguments: integer zero followed by the original input.
- If the selected target returns normally, complete without returning a defined value.

There is no established distinction between positive and negative nonzero inputs. There is no visible normalization, range restriction, error translation, or fallback target.

**Inferred intent:** the function acts as a forwarding or compatibility entry point that distinguishes a special zero case from ordinary nonzero requests. The meaning of those requests and the reason for the leading zero argument are not established.

This contract describes the behavior visible in the supplied static representation. It does not establish the correctness of that representation’s reconstruction of indirect control flow.
