# F-f5689324a5ef

The second input selects between two dependency-call configurations: zero selects one configuration; every nonzero value selects the other. The original second input is also forwarded to the dependency without visible normalization.

## Side effects

### Direct memory effects

The function directly writes only the destination ranges listed above. In particular, it does not visibly initialize the gaps between them. A byte write at offset 28 does not establish any value for offsets 29 through 31.

This limitation concerns F-f5689324a5ef’s own stores. F-793a94891814 may have initialized or otherwise changed the same storage before returning.

### External state and read timing

The branch-selected external value is read before the dependency call. Word-0 through Word-6 are read afterward, with Word-1 captured first.

The dependency must not be assumed to preserve external state. If it changes one of the later-read locations, the subsequent initialization uses the value observed after that change.

Likewise, disjointness between destination storage and external data is not established. If an earlier destination write changes a location read later, that later read may observe the change. Word-1 is protected only by its explicit early capture.

### Ownership and lifetime

No allocation or release primitive is directly visible in this function. Allocation, registration, ownership transfer, and retention by F-793a94891814 are unknown.

The function uses the returned address but does not visibly free it or hand it to another dependency. This does not establish who owns the storage or how long it remains valid.

### Failure behavior

The evidence does not establish whether such failures produce an exception, a process fault, another control transfer, or any caller-visible diagnostic.

## Acceptance examples

### Nonzero input is preserved

### Dependency mutation affects later initialization

A change to Selector-zero or Selector-nonzero during the call does not retroactively alter the already supplied third argument.

### Word-1 is captured before the first destination write

This criterion depends on the stated accesses being valid; it does not assert that such aliasing occurs in ordinary use.

### Byte fields do not imply word initialization

The same one-byte rule applies at offsets 124, 136, 148, and 160.

### Invalid dependency result has no checked fallback
