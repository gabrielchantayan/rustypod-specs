## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Entry argument duplication.** If entry dispatch is reached, its first and fourth explicit arguments must both equal the first input. The second and third must retain their respective input positions.

2. **Byte-selected destination.** If the first byte read yields 200 and entry byte is 171, the first direct store writes byte 171 at numeric address 217. It does not write at entry base plus 217.

3. **Repeated reads may differ.** If the first entry-selector read yields 3 and an intervening dependency changes it to 9, the corresponding byte destinations are 20 and 26. Reusing the first read would violate the represented sequence.

4. **Shift then byte truncation.** If the first exposed unsigned secondary value is all one bits, shifting right by 22 yields 1,023; the subsequent byte store writes 255.

5. **First indexed word store.** If first index is 3 and retained result is 7, the direct word store targets address 32 and writes 7, assuming the address is accessible.

6. **Zero-dependent source address.** The zero-byte stage reads address 1 regardless of earlier retained results. If that read yields 255, zero is written at address 272.

7. **Paired-result splitting.** If the paired high word is 3 and paired low word is 5, the first paired-result store writes zero at address 32. Later low-word transformations use 5, not 3.

8. **Different store and read scales.** If scale result A is 2, scaled A is 8. The direct store targets address 52, while the subsequent argument reads target address 28. The stored value alone does not determine those read results.

9. **Conditional machine wraparound.** Under 32-bit modular arithmetic, a paired low word of 16 makes its product with 268,435,456 wrap to zero. The associated word destination is then address 20. This example is conditional on machine-width semantics, not a portable signed-arithmetic guarantee.

10. **No successful-return requirement.** Reaching the represented invalid-instruction endpoint does not demonstrate successful normal completion.
