## Behavior

### Global acquisition and first selection

Before the first dispatch, the function reads the value of the designated global datum. That value supplies the first base.

Using that base, the function accesses the pointer field at byte offset 4. The retrieved pointer identifies an intermediate record. The function reads the table address at the beginning of that record, obtains the callable target at table offset 120, and invokes that target.

The established logical read order is therefore:

1. Read the designated global datum’s value.
2. Read the intermediate-record pointer at that value plus 4 bytes.
3. Read the table address from the beginning of the intermediate record.
4. Read the callable target at the table address plus 120 bytes.
5. Invoke the selected target.

There is no visible validation, fallback target, or explicit state update between those operations.

The global value is acquired before the first invocation. A subsequent change to the global does not retroactively alter the target already selected. No later read of that global is explicitly shown in this function.

This does not imply that dependencies preserve the global or that the reads form an atomic snapshot.

### Second selection and final transfer
