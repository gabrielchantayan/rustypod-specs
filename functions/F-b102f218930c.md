# F-b102f218930c

## Purpose

F-b102f218930c evaluates three ordered conditions over an input record and two indirectly referenced memory regions. It returns a one-byte Boolean result.

The result is 1 exactly when all three conditions hold:

- Bit 0 of the byte at input-record offset 29 is clear.
- Bit 2 of the byte at offset 20 in the region referenced by the input record’s offset-32 field is set.
- Bit 6 of the unsigned 32-bit word at offset 188 in the region referenced by the input record’s offset-0 field is set.

Otherwise, it returns 0. Conditions are evaluated in that order, with short-circuiting: a condition that determines failure prevents the later conditions and their associated pointer-field and target-field reads.

This is an established bit-test predicate. The application meanings of the record, references, and flag bits are unknown. Interpreting them as permissions, readiness, ownership, or another higher-level state would be inferred intent, not established behavior.

## Behavior

### Ordered evaluation

The first relevant read is the byte at input-record offset 29. Only its least significant bit matters.

- If bit 0 is set, the routine returns 0.
- If bit 0 is clear, evaluation proceeds to the second condition.
- Bits 1 through 7 do not affect this decision.

For the second condition, the routine reads the 32-bit address-bearing field at input-record offset 32. It uses that value to locate a byte 20 bytes into the referenced region.

- If bit 2 of that byte is clear, the routine returns 0.
- If bit 2 is set, evaluation proceeds to the third condition.
- The remaining seven bits of that byte do not affect this decision.

For the third condition, the routine reads the 32-bit address-bearing field at input-record offset 0. It uses that value to locate an unsigned 32-bit word 188 bytes into the referenced region.

- If bit 6 of that word is set, the routine returns 1.
- If bit 6 is clear, the routine returns 0.
- The remaining 31 bits of that word do not affect the result.

This ordering is part of the contract. An implementation that unconditionally reads both referenced regions would not preserve the established short-circuit access behavior.
