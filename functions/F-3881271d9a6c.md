# F-3881271d9a6c

## Purpose

F-3881271d9a6c retrieves a signed integer from a fixed location relative to a caller-supplied base address. It returns zero when the retrieved value is negative one; otherwise, it returns the retrieved value unchanged.

The observable transformation merges two stored values into the same result: stored zero and stored negative one both produce returned zero. Every other representable stored value remains distinguishable by its return value.

The supplied static evidence does not establish the meaning of the surrounding object or the selected integer. Treating negative one as an “unset,” “invalid,” or “absent” marker is plausible intent, not an established semantic guarantee.
