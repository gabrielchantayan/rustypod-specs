# F-f726434d18e4

## Purpose

F-f726434d18e4 conditionally invokes one of two dependencies:

- Selector 1 and a recognized third-argument token invoke F-ca2888499290 with descriptor-derived arguments and a temporary payload containing the fourth argument.
- Selector 4 invokes F-034cfcd689bb unconditionally.
- Selector 8 invokes F-034cfcd689bb only when a character read from an indexed address compares unequal to −2 after integer promotion.

Every path that completes normally returns the 32-bit value zero. This result does not identify whether dispatch occurred and does not propagate a dependency’s ordinary return value.

The static evidence establishes routing, argument construction, and directly accessed storage. It does not establish the application-level meaning of the selectors, tokens, descriptor, or indexed data.

## Interface

The function accepts four arguments:

| Argument | Visible representation | Established role |
|---|---|---|
| First | Pointer to four-byte words | Its incoming value is not dereferenced or forwarded by the visible body. Recognized-token dispatch replaces it with a descriptor-derived value. |
| Second | Integer, treated as 32 bits in the supplied representation | Selector compared with 1, 4, and 8. |
| Third | Pointer-shaped value | Compared by value with tokens for selector 1; converted to an integer for selector-8 address calculation. |
| Fourth | Opaque four-byte value | Copied into the first word of a temporary area. |

The return value is four bytes wide and is zero on normal completion.

### Representation limits

The supplied representation explicitly uses four-byte payload and descriptor words. It does not independently establish the complete target ABI, pointer width, character width, or plain-character signedness.

The third argument is not uniformly a pointer to accessible caller storage:

- Selector 1 examines its value without dereferencing it.
- Selector 8 converts its value to the integer type used in the address expression.
- Other selectors do not directly use it to access memory.

A wider caller representation requires an independently defined ABI conversion. The contract does not assume silent truncation or portability to a wider host.

### Path-dependent preconditions

The visible body requires different storage validity depending on the selected path:

- Unrecognized selectors require no caller-buffer access.
- Selector 1 with an unrecognized token requires no dereference of the first or third argument.
- Selector 1 with a recognized token requires a readable global descriptor slot and a readable four-byte word at byte offset 4 from the resulting descriptor value.
- Selector 8 requires a readable table-base slot and a readable character at the computed address, subject to valid conversion and arithmetic.
- Selector 4 introduces no direct descriptor or indexed-character access. F-034cfcd689bb may have additional requirements.

No visible null check, index bound, descriptor validation, or recovery mechanism relaxes these preconditions.

## Behavior

### Temporary payload preparation

Before selector-dependent dispatch, the function copies the fourth argument into a temporary two-word area belonging to the current invocation.

| Byte offset | Size | Contents established by this body |
|---|---:|---|
| 0 | 4 bytes | Exact four-byte value of the fourth argument |
| 4 | 4 bytes | Not initialized |

Only the first word has established contents. The second word is not established to be zero, a terminator, a length, or another payload value.

This preparation occurs even on paths that never expose the temporary area to a dependency. It is not a write to caller-supplied storage.

### Selector 1: token-controlled dispatch

Selector 1 recognizes four third-argument values:

- Numeric token 5.
- Numeric token 6.
- Numeric token 7.
- One additional symbol-address token whose numeric value is not supplied.

Recognition compares values. It does not read memory at the token addresses.

An unrecognized token produces no dependency call. The function then returns zero normally. Selector 1 does not fall through into selector-4 or selector-8 behavior.

For any recognized token, the function performs the following observable interaction:

1. Reads a descriptor value from a global descriptor slot.
2. Reads the four-byte word at byte offset 4 from the referenced descriptor storage.
3. Calls F-ca2888499290 with these arguments, in order:
   - The descriptor’s offset-4 word, interpreted in the pointer-shaped role used for the call.
   - The descriptor value captured from the global slot.
   - A pointer to the beginning of the temporary payload area.
4. Returns zero if the dependency returns normally.

The incoming first argument is not forwarded. The recognized token is not forwarded. All four recognized tokens select the same visible argument construction.

The function does not directly read the descriptor’s offset-0 word or any field beyond the offset-4 word. The second dependency argument is the captured descriptor value; the function does not reload the global slot after the dependency call.

Any ordinary dependency result is ignored.

### Selector 4: unconditional secondary dispatch

Selector 4 calls F-034cfcd689bb without explicit arguments.

This path bypasses the selector-8 condition. It does not convert the third argument into a table index or directly read the indexed character.

If the dependency returns normally, the function returns zero regardless of the dependency’s ordinary result.

### Selector 8: character-controlled secondary dispatch

Selector 8 computes an address from:

- A base value read from a global table-base slot.
- The third argument converted to the integer type shown in the supplied representation.
- A scale factor of 0x114, or 276 decimal.

The character is read at the table base plus the converted index multiplied by 276. The evidence supports this spacing in the supplied address expression; it does not establish a complete table-record layout.

The read uses **plain character type**, not an independently established signed-character type. The resulting character undergoes integer promotion and is compared with the integer value −2:

- If the promoted value equals −2, no dependency is called.
- If the promoted value differs from −2, F-034cfcd689bb is called without explicit arguments.

The signedness distinction changes observable dispatch behavior:

- **With signed eight-bit characters using the ordinary two’s-complement mapping**, byte pattern 0xFE represents −2, promotes to −2, and suppresses dispatch. Other byte patterns permit dispatch.
- **With unsigned eight-bit characters and the stated 32-bit integer representation**, every character value lies between 0 and 255 and promotes to that same nonnegative integer. No value equals −2. Every successfully read byte therefore permits dispatch, including 0xFE.

The static listing alone does not select between those character interpretations. Suppression by byte pattern 0xFE is consequently conditional, not an unconditional property of this function.

Only the character at the computed address is directly inspected. The function does not access the other locations within the 276-unit spacing, establish their readability, or prove that they form records.

There is no visible index validation. Conversion of an out-of-range pointer-shaped value, negative indices, multiplication overflow, and address overflow require target-specific semantics not supplied here. The contract does not assume modulo arithmetic, wrapping, clamping, or rejection.

If the address calculation and read succeed, and any selected dependency returns normally, the function returns zero.

### Other selectors

Selectors other than 1, 4, and 8 make no dependency call and perform neither descriptor lookup nor indexed-character lookup.

The initial local payload write still occurs. Normal completion returns zero.

### Failure and nonlocal completion

The zero result describes normal completion only.

The body contains no visible handler for an invalid descriptor access, invalid indexed access, arithmetic behavior outside the established target model, dependency fault, dependency termination, or other nonlocal transfer.

It does not convert such events into an error status. If a dependency does not return normally, the function’s final zero return is not reached.

### Dependency effects

For selector 8 and index 2, byte pattern 0xFE at table base plus 552 bytes promotes to −2. F-034cfcd689bb is not called; normal completion returns zero.
