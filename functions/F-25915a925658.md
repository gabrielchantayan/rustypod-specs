## Acceptance examples

The following are conditional static acceptance examples, not executed tests.

1. **Hidden-value write.** If F-D005 returns 3 and the hidden incoming word is `0x11223344`, the first direct store writes that word at numeric address 32.

2. **Different store and load addresses.** If B is 2, B4 is 8. The corresponding word store targets address 52, while both load expressions supplying F-D011 target address 28. Treating both as one field would be incorrect.

3. **Distinct repeated reads.** If the first load supplying F-D011 observes `0x12345000`, its derived first argument is `0x00012345`. If the other load observes a different word, the third argument derives from that other observation. The evidence does not mandate which load executes first.

4. **Fourth-input truncation.** Under 32-bit left-shift semantics, fourth-input values 1 and 65 both yield `0x04000000` for F-D021’s third argument.

5. **Captured-word stability.** If CapturedWord is `0xABCDEFFF`, the later shifted-snapshot store writes `0x000ABCDE`, even if F-D041 or subsequent calls change the original source location.

6. **First byte truncation.** If M is `0x00000043`, M4 is `0x0000010C`. The first byte store writes `0x0C`, not a word-sized `0x0000010C`.

7. **Second byte extraction.** If M is `0x3AB00000`, the masked and shifted expression is `0x3AB`, but the second byte store writes `0xAB`.

8. **Selector changes across calls.** If FirstSelector is 10 and SecondSelector is 20, the byte stores target addresses 27 and 37 respectively. F-D073 receives 20 as its second explicit argument.
