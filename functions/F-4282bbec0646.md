# F-4282bbec0646

## Purpose

F-4282bbec0646 conditionally prepares two nominally 25-byte records and writes their addresses and lengths into a caller-supplied descriptor. Each preparation uses two source operands, obtains a 16-bit value using a record-specific selector, and explicitly writes that value’s two bytes and a fixed marker.

Construction is sequential and non-transactional. A zero result from the first storage request prevents all subsequent local construction. If execution reaches the second storage request, the first address and length stores have already occurred. A zero result from that second request causes return without an explicit rollback.

These are ordering guarantees, not guarantees of surviving state. The second storage dependency may modify the descriptor, alter the first record, or invalidate its storage before returning. Claims that the first publication remains intact require dependency-preservation and suitable aliasing assumptions.

Every normally returning path returns the original descriptor address. There is no separate success result.

“Storage request,” “record,” and “publication” describe inferred intent. The established behavior is the sequence of calls, result checks, explicit stores, and return. No protocol, allocation policy, or ownership transfer is established.
