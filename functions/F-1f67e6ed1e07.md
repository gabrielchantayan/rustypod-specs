# F-1f67e6ed1e07

## Purpose

F-1f67e6ed1e07 dispatches on a 32-bit event type. For type `0x16`, it extracts a selector and payload, then chooses actions using equality and signed ordering against separately observed threshold values. For type `0x20003`, it executes an ordered transition sequence, writes one controller byte, and conditionally invokes a dependency with argument `0x10`.

The normal return value is a 32-bit recognition indicator:

- `0`: the selected dispatch region does not recognize the observed type or selector.
- `1`: the selected path is recognized, including paths with no further branch-specific action.

A return of `1` does not establish that dependencies succeeded, that an external operation completed, or that any resource was acquired or released.

“Controller,” “event,” “state,” and “payload” are descriptive role names inferred from usage. The contract establishes represented accesses, calls, and control flow, not those objects’ domain semantics. All evidence is static; no runtime tests have been performed.

## Interface

### Inputs and result

The supplied representation has four 32-bit arguments:

| Input | Established use |
|---|---|
| Controller address | Identifies storage containing configuration, state, a method-table address, and a subordinate-object address. |
| Event address | Identifies storage whose word at offset `0x04` controls outer dispatch. |
| Auxiliary word | Initializes a local 32-bit slot passed by address on selected paths. |
| Operation word | Initializes a local 32-bit slot passed by value or address on selected paths. |

Local copies of the controller and event arguments are also initialized. The controller-copy slot is passed by address on the `0x20003` path. The event-copy slot has no subsequent represented use.

A local-slot address is not the address of the caller’s original argument storage. A dependency may nevertheless affect other storage through an address held in that slot. The function does not establish ownership of such referenced storage.

Every explicit normal return is the 32-bit value `0` or `1`. There is no separate error code.

## Behavior

### Entry and outer dispatch

At entry, the function reads an address from an external slot and retains that address. Selected paths later read a 32-bit shared word through this captured address for F-b002ce492389.

The capture fixes the address used by those later reads, not the value stored there. No stability of the pointee is assumed.

The function reads the event type at offset `0x04` and checks for `0x16`. If that check fails, it reads the same field again and checks for `0x20003`. If the second observation is not `0x20003`, the function returns `0`.

These are two represented reads, not one cached type value. A first observation other than `0x16` followed by a second observation of `0x20003` selects the latter path.

### Type `0x16`: extraction and dispatch inputs

F-682adfd5a561 receives the event address and `0xF00`. Its return is used as an extracted-record address without validation.

The represented read order after that call is:

1. Read the nested address from extracted-record offset `0x08`.
2. Read the payload address from that nested structure’s offset `0x0C`.
3. Read the nested address from extracted-record offset `0x08` again.
4. Read the selector from the second nested address at offset `0x04`.
5. Read the 32-bit word at the saved payload address.

Thus the selector and payload address need not originate from the same nested structure if the repeated address observations differ. The payload-word read occurs before threshold dispatch, even for a selector that ultimately returns `0` or performs no further action.

The initially read payload word is retained for selector `0x20008`. Selector `0x20001` instead uses an additional payload read for its byte-based decision.

### Threshold observations and precedence

Let **S** be the extracted 32-bit selector, **E** the threshold observed for equality, and **L** the threshold observed for ordering.

- If S equals E, the equality branch executes. There is no second threshold observation.
- Otherwise, the threshold is read again as L.
- S and L are compared using signed 32-bit ordering.
- S less than L selects the lower region; S greater than or equal to L selects the residual region.

Equality compares all 32 bits. For ordering, values with the high bit set are negative. No selector arithmetic is performed.

The residual region is not generally “above E”: its conditions are failed equality against E and signed S greater than or equal to L. In particular, S may equal L. Only an explicit assumption that E and L agree permits describing the regions relative to one stable threshold.

## Side effects

The only explicit write to controller storage is the one-byte store of `2` at offset `0x2C` on the `0x20003` path. Other represented assignments initialize local slots or retain intermediate values.

Dependencies receive selected local-slot addresses. Their ability to modify those slots does not establish ownership transfer or permission to retain the addresses after this invocation returns. No allocation, reference counting, release, or destruction contract is established for the slots or their contents.

Dependency effects are otherwise unbounded by this representation. Calls may change controller storage, referenced objects, external slots, captured-address pointees, or other reachable state. Consequently:

- Later reads are not guaranteed to reproduce earlier observations.
- The byte store is not a guarantee of the controller’s final state.
- The retained gate is tested after slot-processing calls; those calls’ return values do not replace it.
- There is no explicit rollback or alternate cleanup path for a dependency that fails to return normally.

The specified order describes represented accesses and calls. It does not independently establish physical memory transactions or behavior under unsynchronized concurrent mutation.

## Acceptance examples

These are conditional static acceptance cases, not executed tests. All assume valid accessed storage and normally returning dependencies.

1. **Unrecognized outer type.** If both type observations are `0x99`, return `0` without F-682adfd5a561.

2. **Changing outer type.** If the first observation is `0x99` and the second is `0x20003`, execute the full `0x20003` path.

3. **Equality precedence.** If S and E are both `0x20008`, execute the equality branch. Do not make a second threshold observation or execute the numeric `0x20008` operation.

4. **Distinct threshold observations.** With S `0x20008`, E `0x20009`, and L `0x20008`, select the residual `0x20008` path despite S being less than E.

5. **Signed ordering.** With S `0x20006`, E zero, and L `0x80000000`, select the residual region and return `0`; the lower-region recognized no-action case does not apply.

6. **Fresh payload decision.** For lower-region `0x20001`, an initial payload of `1` and a fresh read of `0x00000100` omit entry `0x98`. An initial zero followed by fresh `1` enables it. F-f2db0ea1d7cc and the shared-word call still occur in either case.

8. **Recognized no-action case.** Lower-region `0x20006` returns `1` after extraction and the initial payload read.

9. **State inhibition.** Residual `0x20008` with controller word `0x00000101` returns `1` without subordinate entry `0x58`. Word `0x00000100` instead permits payload dispatch.

10. **Saved payload.** Residual `0x20008`, zero narrowed state, and initial payload `0x1E` produce subordinate entry `0x58`, F-b514896c8fc0, then F-8a5aadac202f. Later payload-storage changes do not replace the retained decision.

12. **Opaque static data.** On type `0x20003`, acceptance requires the first F-398e0e9a318a call’s referenced static-data argument, not any asserted literal string or terminator. Its bytes cannot be checked from the supplied evidence.

13. **Retained gate.** A nonzero F-efdae002d289 result causes F-f56332198639 with `0x10` after both F-289ec4311c64 calls and before the final two dependencies. Zero omits only that gated call.
