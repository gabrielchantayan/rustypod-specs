## Acceptance examples

These examples are conditional criteria, not executed tests.

1. **Entry truncation.** With truncating 32-bit shifts, inputs 1 and 65 both produce first displayed argument 0x04000000. Input 63 produces 0xFC000000; input 64 produces zero. The second argument is zero. Complete executions need not be equivalent.

2. **Independent provenance.** If the retained-word source is 1 and the sparse-index source is 127, the retained shifted word is 0x100 and the sparse index is 508. Deriving both from one call result is incorrect.

3. **Sparse boundary.** A sparse source with low seven bits equal to 127 produces doubled index 1016. Its zero word store at offset 0x14 addresses 0x40C.

4. **Mask width.** Extraction of bits 8–23 from 0xAB123456 yields 0x1234, not 0xAB1234.

5. **Ordered overwrite.** Individually observable word stores at derived base plus 0x20 expose 0x20, 0x2F, the sampled byte as a word, then 0x20. One final store is insufficient.

6. **Global sampling.** If the absolute 0x60 store affects the fixed global location, later association accesses still use the global base captured before that store.

7. **Intervening arithmetic byte.** If the 0x3A byte store overlaps partner base plus 0x14, the subsequent word sample reflects that mutation according to the platform’s byte layout.

8. **Overlapping final copies.** Suppose global base plus 0x74 equals derived base plus 0x10. If the captured derived-base-plus-4 word is 0x11223344 and the fresh derived-base-plus-0x40 sample is 0x55667788, the shared destination receives 0x11223344 first, then 0x55667788. Immediately after the second store, absent another external mutation, it contains 0x55667788. Reversing those stores is incorrect.

9. **Fresh sample before either copy.** If the global-base-plus-0x74 store overlaps derived base plus 0x40, the later copy to derived base plus 0x10 nevertheless uses the word sampled before that overlapping store.

10. **Three 0x67 samples.** If the distinct reads observe 0x11, 0x22, and 0x33, their corresponding stores receive those values: absolute 0x21, then derived base plus 9 twice. Reusing the original captured byte is insufficient.

11. **Interrupted execution.** A non-returning dependency prevents subsequent effects. A later fault does not imply rollback or a returned status.
