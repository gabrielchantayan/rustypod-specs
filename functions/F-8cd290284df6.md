## Behavior

The visible prefix contains no conditional branch, loop, bounds check, null check, or explicit error check. Its operations are ordered, with many indirect calls between memory effects.

All descriptions below mean “if execution reaches this point.” A callee may fault, terminate, alter shared memory, or otherwise prevent later effects. A memory access may also prevent progress.

The following stages preserve the order of explicit memory effects. Intervening calls are material: they may change memory that a later access reads.

## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Byte narrowing.** If early payload is `0x000000ff`, its first explicit byte value is `0xfc`. Both early stores use that byte, provided the first store completes.

2. **Selector range.** A selector byte of `0xff` selects address `0x110`, not an address derived by loading a word-sized pointer.

3. **Selector rereading.** If an intervening call changes an early selector from 2 to 5, the later selector write targets `0x16`; it need not revisit `0x13`.

4. **Retained selector.** Once the first retained selector is captured, its later offset-`0x74` read uses that captured byte value. It does not reload the original selector location.

5. **Packed arithmetic.** Under modulo-\(2^{32}\) arithmetic, packed basis multiplied by `0x80000` depends only on the input basis’s low five bits. For input basis 0 or 32, the corresponding selector read address is 1. This is a conditional arithmetic consequence, not evidence that address 1 is valid.

6. **Overwrite visibility.** The first write to the eightfold record’s `0x34` slot precedes intervening calls and the second write. Replacing both with only the second write would remove an observable intermediate state.

7. **No final-global guarantee.** Absolute address `0x0d` is explicitly written first with the captured selector and later with `0xc0`. Later dependencies may overwrite it again.

8. **Failure prefix.** If a word read faults after earlier byte stores, the contract does not imply that those stores are undone or that subsequent calls occur.
