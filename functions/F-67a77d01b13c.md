# F-67a77d01b13c

## Purpose

F-67a77d01b13c performs a staged operation on a caller-supplied mutable context. It stages an input value, obtains or resolves an interface, invokes an interface method, copies configuration fields into the context, and then conditionally invokes three further dependencies.

Its normal return value is one of three 32-bit values:

- **0:** The final dependency returned zero, and the context’s result byte was set to zero.
- **4:** The final dependency returned one, and the context’s result byte was set to one.
- **3:** An earlier stage failed, a signed threshold condition was not satisfied, or the final dependency returned another value.

These descriptions are branch-level facts, not domain-specific interpretations. The supplied evidence does not establish that the operation opens a particular resource, decodes a particular format, or transfers ownership.

The operation is not transactional. Returning 3 does not imply that the context or external state is unchanged.

## Behavior

### 1. Stage the input and resolve an interface

The function first calls F-fac138f80b6d with:

1. Context address plus 0x58.
2. The input argument.
3. The integer 0x1000, or 4096.

Any result from this call is ignored. The constant does not, by itself, establish that exactly 4096 bytes are copied, that a string is terminated, or that the input has a particular encoding.

Next, F-6651d6fbf9ca receives these addresses, in order:

1. Context plus 0x13C6.
2. Context plus 0x58.
3. Context plus 0x107C.

A nonzero result immediately causes return value 3. No later interface invocation, descriptor copying, or direct result-byte write occurs on that path. Effects already produced by the two dependencies remain possible.

### 2. Invoke the resolved interface

After a zero result from F-6651d6fbf9ca, the function reads the interface pointer stored at context offset 0x107C. It follows the pointer stored at the start of that interface object, then obtains a callable entry at byte offset 0x1C in the referenced table.

The selected method is invoked with:

1. The interface pointer loaded from context offset 0x107C.
2. Descriptor address plus 24.

The method’s return value is not used.

The callable entry is retained locally. Unless the later descriptor flag is nonzero, that retained callable address becomes the initial value of a subsequent query slot.

The descriptor fields used in the next stage are read **after** this method returns. Consequently, modifications made by the method can affect the copied configuration. No preservation of the context, descriptor, or other global state is assumed.

### 3. Copy configuration in observable order

The direct descriptor reads and context writes occur in this order:

1. Read the 32-bit descriptor field at offset 0 and write it to context offset 0x1058.
2. Read the 32-bit descriptor field at offset 4 and write it to context offset 0x105C.
3. Read and retain the 32-bit descriptor field at offset 12.
4. Read the 32-bit descriptor field at offset 8 and write it to context offset 0x08.
5. Write the retained offset-12 value to context offset 0x0C.
6. Read the single byte at descriptor offset 16 and write it to context offset 0x10.

This is not an atomic snapshot or a bulk copy. In particular, the offset-12 descriptor value is captured before the context offset-0x08 write. That distinction can matter if the descriptor and context overlap.

If the captured flag byte is nonzero, the function:

- Selects context address plus 0x1C as the initial query-slot value.
- Calls F-d86d14a75ba2 with context address plus 0x20.

The branch uses the captured flag byte. Changes made by F-d86d14a75ba2 do not retroactively alter that decision.

If the flag is zero, F-d86d14a75ba2 is skipped, and the retained interface-method address remains the initial query-slot value.

### 4. Prepare a mutable operation value

- A value slot containing the fourth argument.

F-542bb9723c00 receives the context address and the address of the value slot.

If its result is nonzero, the function returns 3. There is no direct write to context offset 0x106C on this path.

If its result is zero, processing continues. The value slot is not reset to the original fourth argument; subsequent use observes its post-call contents.

### 5. Query and apply a signed threshold

F-1c86b33764dc receives:

1. The 32-bit value currently stored at context offset 0x1060.
2. The address of the query slot.

If its result is nonzero, the function returns 3 without directly writing context offset 0x106C.

If its result is zero, the query slot is interpreted as a **signed 32-bit integer**:

- Values greater than 3 permit the final dependency call.

The signed interpretation is material. For example, the bit pattern 0xFFFFFFFF is −1, not a large qualifying positive value.

## Side effects

### Partial state is retained

Failures do not undo earlier calls or writes. Depending on the failing stage, a return of 3 can follow:

- Only staging and resolution attempts.
- Interface invocation and all descriptor-derived writes.
- Optional initialization through F-d86d14a75ba2.
- Preparation and query calls.
- A final dependency call and two direct status writes.

The return value alone therefore cannot identify how far execution progressed.

### Result fields are not universally reset

Context offset 0x106C is directly assigned only after a successful query:

- 2 when the signed query value is at most 3.
- 0, 1, or 2 after the final dependency returns.

Earlier failure paths do not directly initialize or clear it.

Context offset 0x1390 is directly assigned only when the final dependency returns neither zero nor one. Successful completion does not directly clear a previous value there.

These statements concern this function’s explicit writes. Dependencies may independently alter either field.

## Acceptance examples

These are conditional acceptance criteria derived from static evidence, not executed tests. They assume valid memory, normal dependency returns, and no unspecified dependency effects that contradict the stated setup.

1. **Resolution failure:** If F-6651d6fbf9ca returns any nonzero value, the function returns 3. The interface method and subsequent dependencies are not invoked, and descriptor-derived direct writes do not occur.

2. **Method changes configuration:** If the interface method changes the descriptor field at offset 0 before returning, the subsequent write to context offset 0x1058 uses the changed value.

3. **Nonzero flag:** If descriptor byte 16 is 0x80 when read, context byte 0x10 is written as 0x80, F-d86d14a75ba2 is called, and the query slot is initially assigned context address plus 0x1C. The flag is not normalized to 1.

4. **Zero flag:** If descriptor byte 16 is zero, F-d86d14a75ba2 is skipped, and the query slot initially contains the selected interface-method address.

5. **Preparation failure:** If F-542bb9723c00 returns nonzero, the function returns 3 without calling F-1c86b33764dc or F-e162eb24ee4a. Descriptor writes have already occurred.

6. **Query failure:** If preparation succeeds but F-1c86b33764dc returns nonzero, the function returns 3 without a direct write to context byte 0x106C.

7. **Threshold boundary:** If the query succeeds and leaves the query slot equal to 3, F-e162eb24ee4a is skipped, context byte 0x106C becomes 2, and the function returns 3. A slot value of 4 permits the final call.

8. **Signed boundary:** A successful query leaving 0x80000000 does not permit the final call. A slot value of 0x7FFFFFFF does.

9. **Modified operation value:** If F-542bb9723c00 replaces the value slot and returns zero, a later final call receives the replacement rather than the original fourth argument.

10. **Final classification:** With a qualifying query value, final results 0, 1, and −1 respectively produce return/status-byte pairs of (0, 0), (4, 1), and (3, 2). For −1, the byte at context offset 0x1390 is first set to 3.
