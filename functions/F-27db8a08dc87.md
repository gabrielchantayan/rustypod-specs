# F-27db8a08dc87

## Purpose

F-27db8a08dc87 coordinates a direction-dependent transition across a receiver, a current context, a context-associated resource, and several service objects.

- **Entry direction:** save the low 16 bits of an observed resource setting, modify selected bits of that setting, invoke two ordered helpers, and conditionally deliver a constructed value to the receiver.
- **Exit direction:** supply the saved 16-bit setting to the resource-setting dependency, conditionally change a history-related selection, and conditionally write a global output-state word.

The direction and variant names describe observed branches. Their application-level meanings are inferred, not verified dependency semantics.

The operation is not demonstrably transactional. Writes and calls precede early returns, with no visible rollback.

### External storage and captured values

The following symbolic names distinguish external storage from values retained locally:

- **Primary marker:** a 32-bit value read from external storage immediately after the second context acquisition and before the nested resource-handle read. This captured value is used later; it is not reread for the entry bounds or ordinary state comparisons.
- **Ordinary-entry bound:** a 32-bit value read from separate external storage after F-ef0964bd9b8a returns on ordinary entry.
- **Exit target:** a 32-bit value captured from external storage after the exit restoration call.
- **Special target:** an externally stored value compared with a fresh read of exit-target storage on alternate exit.
- **Temporary mode:** a 32-bit value read from external storage after F-5c5958cfd5fe returns on the alternate-exit selection-change path and before F-e2d95185a0cc is called.

The primary-marker, ordinary-entry-bound, and temporary-mode locations are **not established as immutable constants**. Their mutability and writers are unknown. Dependencies must not be assumed to preserve them. Numeric values and application meanings are unavailable.

## Behavior

For exit, neither capability predicate is called, and F-14cc18aad1ea receives a 32-bit zero. For entry, F-c60499d3eebf is called first. F-f4182470a14d is called only if the first result is nonzero. F-14cc18aad1ea receives one only when both results are nonzero; otherwise it receives zero.

The function then acquires its first context through F-d189d16d5a68 and reads the 32-bit handle at offset `0x28`. That captured handle is used throughout the following context-related operations:

1. F-4de397319cc8 receives the handle. A nonzero result causes F-1b4132d1996d to receive the same handle.
2. F-b7af80e829ec supplies a service, whose slot `0xE8` is invoked.
   - A null subordinate skips the remaining conditions in this block.
   - Otherwise, subordinate slot `0x118` is invoked.
   - A nonzero slot result causes F-e83d0004f052 to receive the handle.
   - A zero result from F-e83d0004f052 causes F-d3924012ab57 to receive the handle.
3. F-baabc64698a1 receives the handle.
   - A zero result skips the second service query.
   - A nonzero result causes another F-b7af80e829ec acquisition and another slot `0xE8` invocation.
   - If this subordinate is nonnull, its slot `0x118` is invoked.
   - A zero slot result causes F-09d363f7f1ec to receive the handle.
   - A nonzero slot result causes F-d3924012ab57 to be called at a site with no recoverable explicit argument in the supplied representation.

The two service acquisitions and subordinate queries are distinct observations. Neither object identity nor repeated predicate results may be assumed.

F-d189d16d5a68 is then called a second time. After it returns, the primary marker is read and captured. Only then is the second context’s pointer at `0x28` read, followed by the resource handle at the pointed-to object’s offset `0x30`.

The first context handle and second context’s resource handle have different observed roles. The two context acquisitions must not be merged.

### Entry: setting preservation and modification

On nonzero direction, F-14c8f45fd168 receives the resource handle and returns a 32-bit setting.

The low 16 bits are written to receiver offset `0x3A`. F-44bef9f36df7 then receives the resource handle and a modified 32-bit setting: bits `2` and `3` are cleared, bit `2` is set, and every other bit is preserved. The equivalent mask and combination are `0xFFFFFFF3` and `0x00000004`.

F-6ac70711bbb5 is called next, followed by F-9134292d7e36. Both precede any entry-variant early return or receiver callback.

#### Ordinary entry

For variant zero, F-fdd8589eca2d supplies a state object. Its 32-bit identifier at offset `0x20` is compared with the captured primary marker.

Equality returns immediately. The saved-field write, resource-setting call, and two entry helpers have already occurred.

On inequality:

- F-ef0964bd9b8a is called.
- After it returns, the ordinary-entry bound is read from external storage.
- F-1958950ee503 receives, in order, the acquisition result, captured primary marker, newly read ordinary-entry bound, and zero.
- Receiver slot `0xC8` is invoked with the receiver explicitly supplied and the result of F-1958950ee503.

A dependency may change primary-marker storage after its capture without changing the marker used here. Conversely, a change to ordinary-entry-bound storage before its later read can affect the supplied bound.

#### Alternate entry

For nonzero variant, F-10655c9db871 is called before F-ef0964bd9b8a.

F-1958950ee503 then receives the acquisition result, the captured primary marker minus `3`, the captured primary marker minus `2`, and zero. Its result is delivered through receiver slot `0xC8`, with the receiver explicitly supplied, and the function returns.

This branch does not perform the ordinary-entry state-identifier query or read the ordinary-entry-bound storage.

The arithmetic uses the apparent 32-bit integer representation. No range check is visible. Exact overflow behavior at signed arithmetic boundaries remains unresolved.

### Exit: restoration and branch selection

On zero direction, the saved 16-bit field at receiver offset `0x3A` is read and supplied to F-44bef9f36df7 with the resource handle. The external exit-target value is captured only after this call returns.

The saved-field read is unsigned in the supplied representation. This operation does not reconstruct the upper 16 bits of the setting observed during entry. The dependency’s semantic parameter width and interpretation are not established.

There is no check that entry previously initialized the saved field.

#### Ordinary exit

For variant zero, F-fdd8589eca2d supplies a state object. If its 32-bit identifier at offset `0x20` differs from the captured primary marker, the function returns after restoration.

Equality permits final exit processing. The captured exit target is not used as a selection target on this branch.

#### Alternate exit

For nonzero variant, a fresh read of exit-target storage is compared with special-target storage. This comparison is distinct from the earlier exit-target capture.

If equal, F-fdd8589eca2d supplies a state object, and the 16-bit value `6` is written at its offset `0x80`.

Next:

- F-17fe47085641 supplies a controller.
- F-76b1c50b12f7 supplies a history-related service.
- Service slot `0x14` is invoked with the service explicitly supplied.
- Slot `0x68` of the returned object supplies a selection identifier.

If the selection identifier equals the **captured** exit target, the function returns. Restoration and any conditional write of `6` have already occurred; no subsequent mode change, history construction, or final exit processing occurs.

On inequality, the following order applies:

1. F-5c5958cfd5fe returns a 32-bit value that is retained.
2. Temporary-mode storage is read after that return.
3. F-e2d95185a0cc receives the just-read temporary-mode value.
4. The retained controller’s slot `0x1DC` is invoked with the controller explicitly supplied.
5. History-service slot `0x50` receives the service, captured exit target, and zero.
6. F-e2d95185a0cc receives the retained value from F-5c5958cfd5fe with bit `14` forced on by combination with `0x4000`.
7. F-8157a180d901 receives size `0x78`, or 120 bytes.
8. F-1e30c9d0c388 receives that result and the designated history label.
9. History-service slot `0x04` receives the service and the construction result.

The temporary mode is not established as a fixed literal. In particular, F-5c5958cfd5fe may affect the storage from which it is subsequently read. The later mode-setting call uses the retained earlier result with bit `14` set, not a fresh mode read or an exact restoration.

### Final exit processing

This phase is reached only when the preceding exit conditions permit it.

A controller is acquired through F-17fe47085641. This is a fresh acquisition, including after alternate-exit history processing.

F-5c5958cfd5fe returns a 32-bit value that is retained. F-e2d95185a0cc then receives literal `0x10`. Controller slot `0x19C` is invoked with the controller explicitly supplied.

F-d2bc4a2e390c receives the retained 32-bit value twice and returns a 64-bit result. Let its two components be the low 32-bit word and high 32-bit word.

- If the low word is nonzero and bit `14` of the high word is clear, the function returns without the final write.
- Otherwise, output-state-base storage is read, and a 32-bit value is written at that base plus `4`: the high word masked with `0xFFFFBFFF`.

The tested bit is bit `46` of the full 64-bit result. No visible unconditional restoration follows installation of mode `0x10`; any such behavior inside dependencies is unknown.

## Acceptance examples

These are conditional criteria, not executed tests. Assume valid memory and dependency behavior consistent with each scenario.

1. **Capability short-circuiting.** Direction zero skips both predicates and supplies zero to F-14cc18aad1ea. Nonzero direction with a zero first result skips the second predicate. Only two nonzero results produce one.

2. **Setting truncation.** An entry setting of `0x1234ABCF` produces saved field `0xABCF` and setting argument `0x1234ABC7`. A later exit with the field unchanged supplies `0xABCF`, not the original 32-bit value.

3. **Ordinary-entry early return.** A state identifier equal to the captured primary marker prevents the receiver callback, but does not undo the setting save, setting call, or two entry helpers.

4. **Distinct external-value observations.** Suppose the second context acquisition leaves primary-marker storage holding `100`. That value is captured before the nested resource read. If later entry dependencies change that storage to `200`, ordinary-entry comparison and construction still use `100`. If F-ef0964bd9b8a leaves ordinary-entry-bound storage holding `150`, construction uses `150` as its third argument.

5. **Alternate-entry bounds.** With captured primary marker `100`, F-1958950ee503 receives bounds `97` and `98`. Later changes to marker storage do not change these operands. Ordinary-entry-bound storage is not read on this branch.

6. **Temporary-mode observation.** On alternate exit with a differing selection, suppose F-5c5958cfd5fe returns `0x20` and, before returning, changes temporary-mode storage to `0x80`. The next F-e2d95185a0cc receives `0x80`; the later call receives `0x4020`.

7. **Alternate-exit equal selection.** If the special-target comparison succeeds and the selection equals the captured exit target, the 16-bit write of `6` occurs before return. Subsequent mode operations, construction, and final processing are skipped.

8. **Final-result gate.** Low word `1` with high word `0x20` suppresses the final write. Low word `0` with high word `0x20` permits writing `0x20`. Low word `1` with high word `0x4020` also permits writing `0x20`.

9. **Fresh contexts.** If the two acquisitions return different contexts, common context operations use the first context’s captured handle; the setting operations use the second context’s nested resource handle.
