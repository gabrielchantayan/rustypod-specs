## Behavior

### Setup, normalization, and range rejection

The associated-object pointer is read from context offset `0x18` and retained.

If the 16-bit gate at `0x3e` is zero, F-4aa9d52845df receives the retained associated-object pointer, the word at `0x1c`, and the address of context offset `0x20`. After it returns, the marker at `0x42` is written as `1`. No result is checked. This function does not itself update the gate.

The effective base is then formed from the current word at `0x20` plus the zero-extended displacement at `0x38`. This computed base is retained across subsequent calls.

The flag at offset `0x03` of the retained associated object is examined. If zero, the adjustment is read from context offset `0x28`; otherwise the adjustment is zero. A nonzero selector adds this adjustment to position.

The function compares the unsigned interpretations of:

- The context word at `0x30` plus the selected adjustment.
- The adjusted position plus count.

If the first is smaller, it returns `1`. The adjustment affects the limit expression even when the selector disables its addition to position. Setup and the marker write may therefore precede range rejection.

### Initial-region segment

After range acceptance, context offset `0x3a` is read as an unsigned 16-bit length. This **first length observation** governs the initial-region decision and segment boundary.

If adjusted position is signed-less-than that length, the selected segment initially equals count. It is reduced to length minus position only if the length is signed-less-than position plus count.

F-3a56d762606b receives, in order:

1. Effective base plus adjusted position.
2. Current transfer address.
3. Selected segment length.
4. Transfer option.
5. The word at offset `0x48` of the retained associated object.

After return, the transfer address advances and count decreases by the selected length. The linked-region offset becomes zero.

Otherwise, no initial segment call occurs. The linked-region offset becomes adjusted position minus the first length observation.

The descriptor pointer is then read from context offset `0x04`, before checking the initial segment’s status. A nonzero status returns immediately. Otherwise, signed count below one returns `0`.

There is no universal empty-request shortcut: zero or negative count can reach the initial segment dependency when position selects that region.

### Linked initialization and independent length reads

Context offset `0x3a` is then read **again**. F-d1e995cfb2d3 receives effective base plus this **second length observation**. Its result becomes the current identifier.

The second observation need not equal the first: an intervening initial segment dependency may have modified the field. The previously calculated linked-region offset is not recomputed.

- A nonzero enable byte with a nonzero cache pointer proceeds without allocation.

### Traversal and segment operations

1. Pending status: nonzero returns immediately.
2. Signed remaining count: below one returns `0`.
3. Current identifier: zero returns `11`.

Thus a final-segment error takes precedence over completion.

Before acquiring or skipping a unit, the function tests the context cache pointer. When nonzero, it writes the current identifier at the current index, using the context pointer read for the entry address. Cache population precedes acquisition or skip resolution.

1. The current first word of the retained descriptor.
2. Current identifier.
3. Address of the handle output slot.
4. Zero.

A nonzero acquisition status causes no segment or release call on this path. The iteration advances its index, then returns that status at the next status check.

2. F-d1e995cfb2d3 receives that loaded address-like word. Its result is assigned to current identifier.
3. A segment is selected from remaining count and capacity minus within-unit offset, using signed endpoint comparison.
4. F-3a56d762606b receives the retained address-like word plus offset plus four, current transfer address, selected length, transfer option, and **the handle slot’s value read after identifier decoding returns**.
5. F-44d249c54e70 receives **the handle slot’s value read after the segment dependency returns**, irrespective of the segment’s zero or nonzero status.

## Acceptance examples

These are conditional static expectations, not executed tests. Except where mutation is explicitly described, assume valid storage, nonoverflowing arithmetic, and no relevant dependency mutations.

1. **Setup before rejection.** With gate zero and an unsigned endpoint exceeding the unsigned limit expression, setup runs and the marker is written before status `1`. No segment call follows.

2. **Initial-only request.** First length observation `20`, adjusted position `5`, and count `7` select one segment at effective base plus `5`, length `7`. A zero segment status leads to return `0` after the descriptor-pointer read.

3. **Boundary crossing.** First length observation `20`, position `18`, and count `6` select an initial segment of `2`. With capacity `8`, successful linked initialization and acquisition select a payload segment of `4`, at the loaded address-like word plus four.

4. **Empty initial-region request.** Position `5`, first length observation `20`, and count zero still select an initial segment call of length zero. Its nonzero status propagates.

5. **Distinct length observations.** Suppose the first observation is `20`, position `18`, and count `6`. If the initial segment changes `0x3a` to `24`, linked initialization uses effective base plus `24`, while the remaining count is `4` and linked offset is zero. If decoding then changes `0x3a` to `28`, a reached allocation calculation subtracts `28`, not `20` or `24`.

6. **Cache replacement during lookup.** If F-870c4fcf7295 replaces a previously nonzero cache pointer, its candidate index is looked up through the replacement pointer. If it clears the field, the function nevertheless attempts the entry access using zero as the base; no missing-cache fallback is established for that situation.

7. **Changed handle slot.** If acquisition supplies handle A, decoding changes the escaped slot to B, and the segment call changes it to C, the address-like word is loaded through A, the segment receives B, and release receives C.

8. **Final segment failure.** A final payload segment returning nonzero status still precedes a release call. Assuming normal dependency returns, that status wins over the now-exhausted count.

9. **Allocation failure.** Nonzero allocation count and zero allocation result write zero to the cache field and return `7`.

10. **Missing identifier.** Positive remaining count with current identifier zero returns `11` before cache population or acquisition.

11. **Cached skip.** An offset requiring a skip and a nonzero next cache entry avoid F-061ad70be17c for that skip.
