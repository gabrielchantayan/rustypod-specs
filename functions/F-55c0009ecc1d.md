## Behavior

### Widths, addressing, and call-order notation

A **fourfold offset** means four times a returned quantity; a **sixteenfold offset** means sixteen times that quantity. A word destination described as an offset plus `0x14` receives four bytes. These calculations do not establish an array or object layout.

A **selected byte write** consists of:

1. Reading an unsigned byte at a specified selector address.
2. Adding `0x11` to the byte value.
3. Writing one byte at that resulting address.

Selected destinations therefore range from `0x11` through `0x110`. The selector is not a full-width pointer. Every described selected write performs a fresh selector read.

Unsigned 32-bit shifts are logical, and unsigned arithmetic discards bits above bit 31. Byte writes retain the low eight payload bits. Some scaling and left shifts involve signed integer intermediates; their overflow behavior and its correspondence to actual instructions remain `documented_only`. Numerical conclusions involving those operations are conditional where stated. Word byte order, alignment, and atomicity are not established.

## Acceptance examples

These are conditional static criteria, not executed tests.

1. **Selector reread.** If the opening selector is `0x20`, its selected destination is `0x31`. If a callee changes it to `0x40`, the subsequent opening write targets `0x51`.

2. **Packed-byte extraction.** An opening packed value of `0x12345678` produces byte payloads `0xe0` and `0x23`.

3. **Unknown-width global capture.** If reading the object at `0x3c` and applying the represented conversion yields `0xaabbccdd`, both third-input-derived stores write that four-byte payload. This criterion imposes no four-byte source-read requirement.

4. **Third-input grouping.** Third inputs 0–127 produce destination `0x14`; 128 produces `0x18`, subject to valid accesses.

5. **Secondary argument duplication.** If the secondary fourfold offset is `0x40`, its snapshot read is at `0x54`, and F-U11 receives `0x40` twice after that read.

6. **Snapshot scaling.** A primary snapshot of `0x12345678` gives snapshot-derived offset `0x0091a2b0`, before adding `0x14`.

7. **Later three-argument dependency.** If the original primary snapshot is `0x12345678` and F-U37’s sixteenfold offset is `0x100`, F-U37 receives `0x100`, `0x100`, and `0x24`. Its destination at `0x114` receives the sixteenfold payload only after the following four-call interval.

8. **Consecutive aliasing writes.** If F-U42’s direct destination equals the following selected destination, and the selector read resolves accordingly, the selected zero write follows the packed byte with no intervening call.

9. **Loop derivation.** The first F-U46 second argument is zero. If an iteration’s final result is 1, the next carried argument is 4 and the next second argument is `0x00040000`, conditional on the represented 32-bit shift interpretation.
