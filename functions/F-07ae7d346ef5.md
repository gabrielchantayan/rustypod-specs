If the primary components are equal, it compares the secondary components using unsigned ordering:

- When the right secondary component is less than or equal to the left secondary component, it returns 0.
- Otherwise, it returns 1.

If the primary components are unequal, it compares those primary components using unsigned ordering:

- When the right primary component is less than or equal to the left primary component, it returns 0.
- Otherwise, it returns 1.
