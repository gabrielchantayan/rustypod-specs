The fourth input initializes the first word of that storage. The dependency’s status determines whether the wrapper returns the first word’s post-call contents or returns zero.

The established behavior is a zero/nonzero status gate:

- A zero dependency status permits the first temporary word to become the result.
- A nonzero dependency status causes the wrapper to overwrite that word with zero and return zero.
