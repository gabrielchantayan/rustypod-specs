# F-643f64d6dc60

## Purpose

F-643f64d6dc60 computes a 32-bit unsigned result from three unsigned inputs using a fixed-length binary reduction process. Its apparent intent is to obtain a quotient from a two-word unsigned numerator and a one-word unsigned divisor, provided the upper numerator word is smaller than the divisor.

That interpretation has an important limitation: the reduction retains only 32 bits of its intermediate remainder. A bit shifted beyond that width is discarded rather than carried into the comparison. Consequently, the function must not be specified as unrestricted 64-bit-by-32-bit unsigned division.

The established behavioral contract is:

- If the first input is greater than or equal to the third input, return `0x7FFFFFFF`.
- Otherwise, consume all 32 bits of the second input, most significant bit first, and produce one result bit for each consumed bit.
- Intermediate left shifts and subtraction follow unsigned word arithmetic under the width model below.
- Return only the accumulated result. No remainder is exposed.

The division interpretation is inferred intent. The fixed-width reduction and initial rejection behavior are established by the supplied static evidence.

## Behavior

### Initial gate

The first externally relevant decision compares the upper word with the divisor.

If the upper word is greater than or equal to the divisor, the function returns `0x7FFFFFFF` without performing the reduction. The lower word does not affect that result.

Consequences include:

- Equal upper word and divisor are rejected.
- A zero divisor always takes this return path because every unsigned upper word is greater than or equal to zero.
- Rejection does not produce an exceptional control transfer in the supplied representation.
- The sentinel is not guaranteed to distinguish rejection from successful computation: an accepted input can also produce `0x7FFFFFFF`.

If the upper word is strictly smaller than the divisor, the function performs exactly 32 reduction rounds. There is no early exit based on the evolving state or the partial result.

### Accepted-input reduction

The lower word supplies a sequence of 32 bits in descending significance, beginning with its bit 31 and ending with its bit 0. Each bit participates exactly once.

The function maintains an unsigned reduction state initially equal to the upper word. For each incoming bit, it forms the low 32 bits of twice the current state plus that bit. This truncated value, not an unbounded mathematical value, is compared with the divisor:

- If the truncated value is at least the divisor, the next result bit is one and the next state is that value minus the divisor.
- Otherwise, the next result bit is zero and the next state is the truncated value.

The first generated result bit becomes bit 31 of the return value. The final generated bit becomes bit 0.

Equivalently, the return value encodes the 32 successive comparison outcomes in their original order. This specifies result-bit significance without depending on a machine’s byte order.

Each round performs at most one subtraction. There is no repeated subtraction until a threshold is satisfied. However, throughout the accepted path the state remains strictly smaller than the divisor:

- It begins smaller because of the initial gate.
- If no subtraction occurs, the comparison itself establishes that the next state is smaller.
- If subtraction occurs, either the doubled state did not overflow and was less than twice the divisor, or truncation removed a full word’s range before comparison. In either case, the resulting state remains below the divisor.

The internal final state is not returned.

### Relationship to division

Let the conceptual two-word numerator be:

\[
N = 2^{32}H + L,
\]

where \(H\) is the upper word and \(L\) is the lower word.

For a positive divisor \(D\), the initial condition \(H < D\) is also the conventional condition under which the mathematical quotient \(\lfloor N/D \rfloor\) fits in 32 bits. That supports the inferred quotient-producing intent.

It does not establish that the returned value always equals that quotient. A carry beyond bit 31 of the evolving reduction state is discarded before comparison.

A sufficient condition for ordinary unsigned-division behavior is:

\[
H < D \quad\text{and}\quad 1 \le D \le 2^{31}.
\]

Within that range, the state is less than \(D\), so twice the state plus one cannot exceed `0xFFFFFFFF`. No significant carry is lost, and the reduction yields the mathematical quotient.

For divisors greater than \(2^{31}\), some inputs still produce the mathematical quotient, but that is not guaranteed. The required behavior remains the truncated reduction described above. An implementation conforming to this contract must not silently replace that behavior with unrestricted mathematical division.
