# F-a118ec4533d5

## Purpose

F-a118ec4533d5 conditionally invokes one dependency twice. A 32-bit field at byte offset 44 from the first input controls whether either invocation occurs. When that field is initially nonzero, the function makes two ordered calls: one using the second input unchanged, and one using that input advanced by eight.

The field is read again for each dependency call. Consequently, the two calls need not receive the same field value. In particular, changes made by the first dependency invocation can affect the second invocation.

The function has no explicit result value. Its externally relevant behavior consists of the field accesses, the decision to invoke the dependency, the ordered calls and their arguments, and any effects of those calls.

**Inferred intent:** the paired calls may represent operations on two locations eight bytes apart. The available evidence does not identify those locations’ contents, sizes, ownership, or meaning.
