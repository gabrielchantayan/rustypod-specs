### Final-read interleaving

If the `0x3A` byte write aliases a byte of either word subsequently read at doubled-lookup offset `0x14` or working offset `0x04`, that read occurs after the write and must reflect the applicable memory semantics. The earlier computed offset-`0x74` read is already captured.
