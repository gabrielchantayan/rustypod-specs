## Behavior

### Initial gate

The function first reads a value through the control reference and tests its least significant bit using a mask of one.

This is a bit test, not an equality test against zero. Values with other bits set still pass this first gate when bit zero is clear. Conversely, any value with bit zero set fails it, regardless of the remaining bits.

If bit zero is set:

- F-b255b26284e6 is not called.
- F-20cfa48c6025 is not called.
- F-804adc29bbfb is not called.
- F-d08d3ca17b81 is not called.
- Execution proceeds to the final return-operand use.

The initial test is performed once in the supplied representation. There is no visible polling, retry, or second inspection of that bit.

### Dependency-controlled gate

If bit zero is clear, the function calls F-b255b26284e6 with the control reference.

Its result is compared with zero:

- Zero skips the remaining three dependency calls.
- Any nonzero result enters the active path.

The visible condition is not “positive,” “equal to one,” or a test of a particular result bit. Any representable nonzero result satisfies the condition.

The supplied representation stores this result in an integer-typed temporary, but does not explicitly establish the target integer width or the dependency’s full return ABI. The established behavioral distinction is zero versus nonzero.

The initial bit condition is not checked again after this call. If F-b255b26284e6 changes the control state, a nonzero return still leads into the active path under the visible logic.

1. F-20cfa48c6025 receives the return operand.
2. After that call returns normally, F-804adc29bbfb receives:
