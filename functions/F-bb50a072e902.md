# F-bb50a072e902

## Purpose

F-bb50a072e902 selects one of two globally supplied 32-bit results. For either supported selector, it may perform a three-call preparation sequence before returning that selector’s result.

The preparation sequence is conditional on both:

- Bit 0 being clear in a selector-specific flag element.
- A selector-specific call to F-b255b26284e6 returning a nonzero value.

A selector other than 0 or 1 returns zero without executing either supported branch.

**Established behavior:** the function selects a result, conditionally invokes dependencies in a fixed order, and obtains the selected result for return after those calls.

**Inferred intent:** the flag test and surrounding dependency calls resemble guarded initialization. Neither initialization, locking, synchronization, nor resource acquisition is established by the supplied evidence. Those interpretations must not replace the observable contract below.

## Interface

### Input

One 32-bit integer selector:

| Selector | Selected result | Flag element tested | Guard argument |
|---|---|---|---|
| 0 | Result slot A | Second element of the flag region | Separate guard slot |
| 1 | Result slot B | First element of the flag region | Flag-region reference |
| Any other value | Literal zero | None | None |

Selector comparison is exact. Negative values and positive values other than 1 take the unsupported-selector path. No range normalization or truncation to a smaller selector is shown.

### Output

A 32-bit result:

- Selector 0 returns the value obtained from result slot A at the return point.
- Selector 1 returns the value obtained from result slot B at the return point.
- Every other selector returns the 32-bit value zero.

The result’s interpretation is unknown. It may represent an address, handle, scalar, or other 32-bit quantity. The evidence does not establish a nullability rule, ownership transfer, or success/error encoding.

## Behavior

### Unsupported selectors

If the selector is neither 0 nor 1, the function returns zero.

No branch-specific global read, flag test, or dependency invocation is shown on this path. In particular, an unsupported selector does not fall back to either supported result slot.

### Selector 0

The function tests bit 0 of the second element in the flag region.

If that bit is set:

- F-b255b26284e6 is not called.
- The preparation sequence is skipped.
- The function obtains result slot A for return.

If that bit is clear, the function calls F-b255b26284e6 with the value supplied by the separate guard slot.

If F-b255b26284e6 returns zero:

- No further dependency is called by this invocation.
- The function obtains result slot A for return.
- The guard dependency’s zero result is not returned as this function’s result.

If F-b255b26284e6 returns nonzero, the function performs these calls in order:

1. F-b346ab689ca3 receives the then-current value from result slot A as its first argument and literal selector value 0 as its second argument.
2. F-804adc29bbfb receives the 32-bit result of that call as its first argument, the value from shared argument X as its second, and the value from shared argument Y as its third.
3. F-d08d3ca17b81 receives the value supplied by the separate guard slot at that later call point.

After those calls return normally, the function obtains result slot A for return.

The separate guard slot is referenced for two distinct calls. Its value at the final dependency call must not be assumed equal to its value at the earlier guard call if an intervening dependency can change the relevant global state.

### Selector 1

The function tests bit 0 of the first element in the flag region.

If that bit is set:

- F-b255b26284e6 is not called.
- The preparation sequence is skipped.
- The function obtains result slot B for return.

If that bit is clear, the function calls F-b255b26284e6 with the flag-region reference as its argument.

If F-b255b26284e6 returns zero:

- No further dependency is called by this invocation.
- The function obtains result slot B for return.

If F-b255b26284e6 returns nonzero, the function performs these calls in order:

1. F-b346ab689ca3 receives the then-current value from result slot B as its first argument and literal selector value 1 as its second argument.
2. F-804adc29bbfb receives the 32-bit result of that call as its first argument, followed by shared argument X and shared argument Y.
3. F-d08d3ca17b81 receives the flag-region reference as obtained for that later call.

After those calls return normally, the function obtains result slot B for return.

The flag-region reference used for the guard call and the reference used for the final call must not be treated as an immutable captured value. The supplied representation accesses that global role at both call sites.

### Flag semantics

Only bit 0 affects the decision. Other flag bits do not independently enable or suppress preparation.

The flag test occurs before the guard call. It is not repeated after F-b255b26284e6 returns. Therefore, if that dependency changes the tested flag, its return value still determines whether the remaining sequence executes.

The function does not directly set or clear a flag. A successful guard call does not, by itself, establish that any flag has changed.

### Result timing

The selected result has two potentially separate observations:

- An observation for the first argument to F-b346ab689ca3, if that call is reached.
- An observation for the function’s final return.

The returned value is not the saved result of F-b346ab689ca3. That dependency’s result is passed to F-804adc29bbfb.

A dependency may change the selected result slot before the final return. Subject to normal completion and valid memory access, the return uses the selected slot’s value at that later point.

## Acceptance examples

These are conditional specification examples, not executed tests. Each assumes valid required memory access and normal return from every invoked dependency.

1. **Unsupported selector:** With selector −1, 2, or any other value outside {0, 1}, the result is zero and no dependency is called.

2. **Selector 0, low bit set:** If the second flag element has bit pattern 3 in its low bits, preparation is skipped. The function returns result slot A’s value at return.

3. **Selector 1, other bits set:** If the first flag element has value 2, bit 0 is clear. F-b255b26284e6 is called with the flag-region reference; the other set bit does not suppress that call.

4. **Guard rejects preparation:** With selector 0, a clear tested bit, and a zero result from F-b255b26284e6, only that dependency is called. If it changes result slot A, the subsequently obtained value is returned.

5. **Guard permits preparation:** With selector 1, a clear tested bit, and any nonzero guard result, all four dependencies are called in the stated order. F-b346ab689ca3 receives selector value 1; F-804adc29bbfb receives its returned value.

6. **Flag changes during the guard call:** If F-b255b26284e6 sets the tested bit but returns nonzero, the remaining three dependencies still execute. There is no second flag test.

7. **Selected result changes during preparation:** If result slot A is 10 when supplied to F-b346ab689ca3 but becomes 20 before selector 0’s final return, the preparation argument is 10 and the function returns 20.

8. **Guard storage changes:** If selector 0’s separate guard slot changes during preparation, the argument supplied to F-d08d3ca17b81 comes from the later slot access, not an assumed saved guard value.

9. **Preparation returns zero:** A zero result from F-b346ab689ca3 is still passed to F-804adc29bbfb. No local rejection or early return is shown for that value.
