- The shifted value ranges from zero through `0x01FFFFFF`.
- The destination ranges from `0x0000001C` through `0x0200001B`.
- This particular addition does not overflow a 32-bit unsigned word.
- The write affects one byte, not a full word.

This store precedes the first selector read and all visible dependency calls.

### 2. First context-selected clear
