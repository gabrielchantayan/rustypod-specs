2. Final-record offset 9 receives the **low byte of the retained late base**.
3. Closing-destination-base offset 0x54 receives the **retained second terminal argument**, as a word.

## Acceptance examples

These are conditional static examples, not executed tests.

1. **Access width.** A byte payload of 0x123456AB writes 0xAB at its destination, not a four-byte replacement. A halfword 0x65 occupies two bytes; their order depends on endianness.

2. **Paired extraction.** With paired-result high word 0x12345678, logical 64-bit right shift by 36 followed by 32-bit narrowing yields 0x01234567.

3. **Global capture.** If publication-base storage overlaps fixed address 0x60, the retained base reflects the observation before the 0x20 word store. Re-reading afterward is not equivalent.

4. **Publication ordering.** Each scaled-destination offset-0x54 word publication precedes its associated two byte publications and offset-0x34 word publication.

5. **Post-mutation capture.** If fixed address 0x3A overlaps final-record offset 0x14, the third terminal argument reflects the word observed after that byte mutation, subject to overlap position and endianness.

6. **Fresh byte values.** If fixed byte 0x67 initially receives 0xAB but intervening overlapping stores change it to 0xCD and then 0xEF before the second and third observations, the corresponding derived-base offset-9 stores consume 0xCD and 0xEF—not cached 0xAB.

7. **Closing direction.** Suppose the retained second terminal argument is 0x3000 and the closing destination base is 0x4000. With valid mappings and ordinary non-overlapping storage, the first closing word store writes 0x3000 at 0x4054. The following word store writes 0x4000 at 0x6000. Writing 0x4000 at 0x3054 is incorrect.

8. **Intervening closing byte.** If the retained late base is 0x123456AB, final-record offset 9 receives 0xAB after the closing destination-base read and before both closing word publications. If that byte overlaps either word destination, the byte write still occurs first and may subsequently be overwritten.

9. **Capture survives aliasing.** If the closing byte store overlaps storage from which the second terminal argument was captured, it does not change that retained argument or the payload of the first closing word store.

10. **Partial completion.** If an early dependency never returns, later direct mutations and the terminal invocation are not reached. No timeout result is established.
