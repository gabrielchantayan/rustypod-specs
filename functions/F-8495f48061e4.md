# F-8495f48061e4

## Purpose

F-8495f48061e4 performs an indirect call selected through two memory lookups relative to its input, then toggles the least significant bit of the unsigned result.

The transformation is **bitwise XOR with one**, not general Boolean negation. A result of zero becomes one, and one becomes zero, but other values retain all bits except the least significant bit. The function does not normalize the result to a Boolean.

The lookup pattern is consistent with dispatch through an object-associated function table. That interpretation is inferred intent, not an established requirement: the available evidence establishes address-relative reads and an indirect call, but does not establish an object type, class hierarchy, or table format beyond the accessed slot.

## Behavior

### Lookup and invocation order

The established sequence is:

1. Read an address-bearing value from the location 68 bytes before the input-derived address.
2. Use that value as the base of the dispatch lookup.
3. Read the callable target from the location 104 bytes beyond that base.
4. Invoke the selected target.
5. If the invocation returns normally, toggle bit zero of its unsigned result.
6. Return the transformed result.

The first lookup must supply the base used by the second lookup. The second lookup must supply the target used by the call. The result transformation occurs only after that call returns.

The recovered representation shows one invocation of the selected dependency. It does not show a retry, fallback target, second dispatch, or conditional bypass.

### Result transformation

The final operation changes only the least significant bit:

- An even unsigned result becomes the next greater odd value.
- An odd unsigned result becomes the immediately preceding even value.
- Zero becomes one.
- One becomes zero.
- Every bit above bit zero is preserved.

The even-value increment description does not imply an addition instruction or arithmetic overflow. The operation is XOR. At any fixed width, the largest unsigned value is odd and maps to the value immediately below it. The largest even value maps to the largest unsigned value.

Consequently, interpreting the function as “return whether the dependency failed” or “negate the dependency’s truth value” requires an additional external guarantee that the dependency returns only zero or one. No such guarantee is present.
