## Acceptance examples

These are conditional static criteria, not executed tests.

- **Scaling distinction:** If scaling seed is 1, scaled address is `0x02000000` and both double-scaled stores receive `0x04000000`. They do not receive zero from shifting the already scaled address by 26.
- **Small-base boundary:** A small-extraction source with low seven bits all set produces small extraction 508 and small base 1016 under the width model.
- **Byte promotion:** A scaled-address-offset-`0x05` read of `0xfe` supplies word value `0x000000fe` to the associated offset-`0x34` store.
- **Linked-store ordering:** The quarter-base-offset-`0x54` replacement by quarter base precedes the doubled-small-link store at saved-link offset `0x44`. The intermediate-link byte store precedes its offset-`0x14` self-store.
- **Alias-sensitive reload:** If intervening mutations change the byte-source field, selection of the selected link uses the second byte observation, not the first.
- **Fixed ordering:** The `0x05` read precedes the `0x01` store. The `0x54` word store precedes the `0x15` byte store. The shared-base load precedes the `0x60` word store and preparation group.
- **Independent fixed reloads:** If the three reads at `0x67` yield `0x12`, `0x34`, and `0x56`, their corresponding stores receive those respective values.
- **Failure:** An inaccessible reached address has no established conversion into a normal error result.
- **Terminal arguments:** Reaching F-opaque-003 requires the four represented arguments above; normal return is not guaranteed.
