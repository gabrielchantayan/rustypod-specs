# F-7019e9c6c658

## Purpose

F-7019e9c6c658 updates bit 1 of an unsigned state word located at byte offset 16 from a caller-supplied base address. A zero selector clears that bit; any nonzero selector sets it. Every other bit retains its value from the word read by this invocation.

This is a read–modify–write operation, not merely a request to change the logical state. A successful invocation writes the resulting word even when the selected bit already has the requested value.

The established behavior is limited to this state-word update. The meaning of bit 1, the identity of any containing object, and the caller’s reason for selecting either state are unknown.

- **Selector:** An integer-valued argument tested for equality with zero. Zero requests clearing bit 1. Every nonzero value requests setting bit 1. The selector is not restricted to Boolean values.

## Behavior

### Selection rule

The selector chooses between two transformations:

| Selector | Required value of bit 1 after the write |
|---|---|
| Zero | Clear |
| Any nonzero value | Set |

The nonzero case does not inspect the selector’s individual bits. A selector whose numeric value is 2 does not have different behavior from another nonzero selector. Negative selectors likewise take the set branch if supported by the declared integer argument.

### State transformation

Let the original state be the unsigned word obtained by this invocation’s read.

For a zero selector, the replacement word has bit 1 cleared and all other bits copied from the original state.

For a nonzero selector, the replacement word has bit 1 set and all other bits copied from the original state.

Under the 32-bit word interpretation:

- Clearing uses the mask `0xFFFFFFFD`.
- Setting uses the bit value `0x00000002`.
- The other 31 bits are preserved from the value read.

The transformation does not depend on the previous value of bit 1 except to determine whether the resulting numeric word differs from the original word.

### Observable access order

On either branch, the supplied body establishes this memory-access sequence:

1. Read the unsigned word at base plus 16 bytes.
2. Form the replacement value according to whether the selector is zero.
3. Write the replacement word to the same address.
4. Return without a value.

There is one explicit word read and one explicit word write. There is no preliminary object-field read, no conditional omission of the write, and no subsequent readback.

These are source-level access observations. The supplied representation alone does not establish instruction count, bus transaction count, or compiler treatment of accesses to special memory.

### Repeated calls and interference

For stable ordinary memory without intervening modification, repeated calls requesting the same state leave the same stored numeric value after the first call. They still perform the represented write on every invocation.

The operation is not established as an atomic bit update. If another actor modifies the target after this invocation reads it but before it writes, the replacement is based on the earlier read. Consequently, another actor’s changes to otherwise preserved bits can be overwritten.

Preservation of other bits therefore means preservation relative to this invocation’s observed input word, not preservation of every concurrent update.
