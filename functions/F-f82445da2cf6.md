## Behavior

### Ordered access contract

The established source-level order is:

1. Read the four-byte value at source offset +8 and retain it.
2. Read the four-byte value at source offset +4.
3. Write the value obtained in the second read to destination offset +0.
4. Write the retained value from the first read to destination offset +4.
5. Return without an explicit result.

The transfer therefore has an important distinction between source order and destination order: the second source field is read first, but the first destination element is written first.

Both source values are obtained before the first destination write. The value from source offset +8 is not reread after the first destination write.

This is an abstract access-order contract supported by the supplied representation. It does not establish processor instructions, bus transactions, compiler barriers, or ordering guarantees for memory-mapped devices.
