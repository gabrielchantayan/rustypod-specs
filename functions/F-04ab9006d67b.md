# F-04ab9006d67b

## Purpose

F-04ab9006d67b selects one of two sources for an address-like value, passes that value to an indirect dependency together with a caller-supplied 32-bit value and the constant 10, and returns the dependency’s 32-bit result.

The selection depends on a single byte at offset 24 from the first input:

- A nonzero byte selects an address 26 bytes beyond the first input.
- A zero byte selects the result of a two-dependency sequence involving F-938c950e5046 and F-5710a8628cba.

This is the established behavior of the supplied representation. The meanings of the selected data, the constant 10, and the final operation are not established. In particular, a numeric-conversion interpretation would be inferred intent, not part of this contract.

### Dependency-derived path

After that call returns, its 32-bit result becomes the first argument to F-5710a8628cba. The second and third arguments to F-5710a8628cba are values obtained from two distinct global data locations. This contract identifies those locations by their argument roles:
