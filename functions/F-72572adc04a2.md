On normal completion, it returns the pointer originally obtained from the first dependency.

The supplied static evidence does not establish the structure’s identity, whether the first dependency allocates it, or what the indirect operation does.

- The indirect operation receives an interior pointer to the field at byte offset 20, not the returned base pointer.
