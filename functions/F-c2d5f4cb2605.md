## Behavior

### Ordered gate evaluation

If it differs from 1, evaluation stops at that gate. The pointer field and its pointee are not accessed by the visible body. F-fbe40d09d5eb is not called, and the return value is 4.

If the 16-bit field equals 1, the function evaluates the first byte comparison:

- It obtains the pointer stored at offset 8.
- It reads the byte addressed by that pointer.
- It compares the byte with 1.

If that comparison succeeds, the alternative comparison against 2 is skipped. F-fbe40d09d5eb is called once.

If the first byte comparison fails, a second pointer-and-byte expression is evaluated:

- The pointer field at offset 8 is evaluated again.
- The byte addressed by that evaluation is read.
- That byte is compared with 2.

If the second comparison succeeds, F-fbe40d09d5eb is called once. If it fails, the function returns 4 without calling the dependency.

This is an ordered, short-circuit decision. It is not evidence of one captured byte being reused for both comparisons.
