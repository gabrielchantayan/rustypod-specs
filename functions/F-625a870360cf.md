## Behavior

### State acquisition

### Bound check

After a nonzero state reference is obtained, the function reads the unsigned 32-bit bound at offset 0xAD0.

The supplied index must be **strictly less than** this bound to reach the table lookup. Equality is rejected. If the comparison fails, the function returns 0 without explicitly reading the table-address field or a table entry.

Consequences include:

- A bound of zero rejects every possible input.
- With a bound of one, only index zero can reach the table lookup.
- An input of 4,294,967,295 cannot reach the table lookup, even when the bound is also 4,294,967,295.

The bound is a gate, not evidence that the table actually contains that many accessible entries.

### Entry lookup and bit test

For an in-range index, the function reads the table-address field at offset 0xAC8 and selects the four-byte entry at the index’s four-byte displacement from that address.

It examines only bit 0 of the entry:

- Bit 0 clear produces 1.
- Bit 0 set produces 0.

All other entry bits are ignored. In particular, a nonzero entry can produce 1. The function is not a test for the entire entry being zero.

The function neither modifies the selected entry nor advances or updates the table reference.
