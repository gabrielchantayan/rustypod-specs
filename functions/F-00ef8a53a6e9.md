The static evidence establishes data movement and call ordering, but not an application-level purpose. It does not establish object construction, resource management, successful initialization, or successful termination.

This contract distinguishes:

## Acceptance examples

These are conditional derivations, not executed tests. Each assumes execution reaches the relevant operation and that required accesses complete.

1. **Fourth-input extraction.** A fourth input of 0xFF800000 supplies 511 as the third argument to F-10000003. A fourth input of 0x007FFFFF supplies zero.

2. **Fresh repeated read.** If the first read at **A + 116** yields 0x123456AB, the first store at **A + 1** writes 0xAB. If intervening calls change the source word to 0x876543CD, the second store writes 0xCD.

3. **Captured full word.** If **W = 0x89ABCDEF**, the store at **C + 1** writes 0xEF. The stores at **S16(D) + 20** and **S4(E) + 20** each write the full 0x89ABCDEF, not a later rereading of the source.

4. **Truncation before argument packing.** Under 32-bit modular arithmetic, **B = 0xC0000001** produces **U = 4**. F-10000027 receives 0x00010000. The original high bits of **B** are not retained.

5. **First byte-derived destination.** If **W = 0**, the first lookup reads address 1. If that byte is 0xFF and **T = 0xAABBCCDD**, the subsequent byte store writes 0xDD at address 272.

6. **Second extraction boundary.** If **T = 0x00400000**, the second byte-derived store writes 0x01. If **T = 0xC0000000**, it writes zero. This distinguishes bits 22–29 from the top eight bits.

7. **Captured global base.** If **K** is captured as 0x1000 and a dependency later changes the global base cell to 0x2000, the specified read still uses address 0x1014. The word found there is read only at the later specified point.

8. **Aliasing at the late word read.** If **S4(J) = K**, the store of **Q** and following read of **T** address the same word. In ordinary sequential memory without intervening external modification, **T** equals **Q**.

9. **Unaligned halfword destination.** If **V = 0x80**, the final halfword destination is address 1. No adjustment is made; success depends on the environment.

10. **Partial effects on fault.** If F-10000081 returns and the residual-pointer byte store faults, the global-result assignment has already occurred. The halfword store and null-target call have not occurred.
