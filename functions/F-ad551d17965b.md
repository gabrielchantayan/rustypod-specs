# F-ad551d17965b

## Purpose

F-ad551d17965b conditionally retrieves and clears one four-byte slot in caller-supplied storage.

A selector equal to negative one disables the operation: the function returns a zero-valued four-byte result without accessing the supplied storage. Every other selector identifies a slot through a four-byte stride and a fixed displacement of 216 bytes. The function reads the selected slot, replaces its contents with a four-byte zero, and returns the value read.

This is a destructive retrieval operation, not a read-only lookup. A zero result alone does not distinguish a disabled operation from retrieval of a slot that already contained zero.

The supplied representation establishes the read-and-clear behavior. It does not establish the application-level meaning of the slots, whether returned values represent addresses or handles, or whether retrieval transfers ownership.

## Behavior

### Disabled selection

The function first distinguishes selector negative one from all other selector values.

When the selector is negative one:

- The returned four-byte value is zero.
- No slot value is read.
- No clearing write is performed.
- The supplied storage address is not dereferenced.

In particular, negative one is a control value, not an ordinary selector for a location four bytes before the zero-selector slot.

### Active selection

For every other selector, the function identifies a four-byte slot using the base address, the selector scaled by four, and the fixed displacement of 216 bytes.

On a normally completing execution, the relevant observable memory effects occur in this order:

1. The selected four-byte value is read.
2. A four-byte zero is written to that same location.
3. The previously read value is returned.

The returned value is the read result, not the result of reading the slot again after clearing it. The source shows no later reread and no conditional suppression of the write.

If the slot already contains zero, the function still takes the active path: it reads zero and writes zero. Equal final contents do not imply that no access occurred.

No other memory location is explicitly accessed by the function body.

Only negative one receives special treatment. The source does not reject other negative selectors.
