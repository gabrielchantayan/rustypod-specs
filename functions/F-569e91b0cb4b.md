# F-569e91b0cb4b

## Purpose

F-569e91b0cb4b coordinates a preliminary lookup, optional secondary processing, and a fallback operation using caller-provided object references and result storage. It reports success or a sign-extended 16-bit dependency error, updates selected outputs, and conditionally invokes a completion dependency.

The established behavior is control flow and data movement. Interpreting the referenced objects as records, candidates, or traversal positions is inferred intent, not an established domain contract. The byte flags have observable write conditions described below; their application-level meanings are unknown.

This specification is based only on the supplied static representation. No runtime tests have been performed.

### Return value

- Zero denotes the wrapper’s successful return paths.
- A nonzero error returned by F-5f9a16493218, F-a51e4d3e8ef4, F-f52000074a41, or F-0bbf0f39df9a is interpreted as a signed 16-bit value and sign-extended to 32 bits.
- Before returning such an error, the function calls F-b0f922796692. That dependency’s return value does not replace the saved error.

The preliminary dependency’s 32-bit result is internal control state, not a directly propagated public error.

## Behavior

### 1. Entry initialization and preliminary selection

The first direct caller-visible write sets Flag C to zero. Flags A and B are not initialized.

The function calls F-4055be9c3f18 with the current primary reference plus 4. Its 32-bit result serves two purposes:

1. If it equals the requested position, the auxiliary-reference slot is selected for preliminary processing. Otherwise, the primary-reference slot is selected.
2. Whether that result is zero determines whether the later secondary-processing phase is entered.

The selected object reference is read from the selected slot after F-4055be9c3f18 returns. Consequently, changes that dependency makes to either slot can affect the next call.

F-dfe52f60212b is then called with:

- The context.
- The selected object reference.
- The full-width selector.
- Descriptor values at offsets 0, 8, 4, and 10, in that argument order.

The result is retained as a 32-bit preliminary status.

If that entire status is nonzero, the function:

1. Writes the requested position to the 32-bit position output.
2. Writes the selector’s low 16 bits to the selector output.
3. If the full-width selector equals zero, reads the selected object’s byte at offset 9 and the context’s unsigned 16-bit field at offset 2. If they differ, it writes 1 to Flag A.
4. Returns zero immediately if the preliminary status’s low eight bits are nonzero.

The full-width nonzero test and low-byte nonzero test are distinct. A status such as 256 causes the output writes but does not cause the immediate return.

### 2. Optional secondary processing

This phase is entered only if the original F-4055be9c3f18 result was nonzero.

If the current auxiliary reference is zero, F-5f9a16493218 is called with the context, that original result, and the auxiliary-reference slot address. A nonzero signed 16-bit result enters the common error path.

After any successful materialization call, the descriptor byte at offset 13 is read:

- If nonzero, F-a51e4d3e8ef4 is skipped.
- If zero, F-a51e4d3e8ef4 is called.

F-a51e4d3e8ef4 receives the context, current auxiliary and primary references, selector, descriptor values at offsets 0, 4, and 10, the selector-output and position-output addresses, an address for the 32-bit internal status, and temporary 16-bit storage.

A nonzero signed 16-bit return enters the common error path.

On a zero return:

- If the updated internal status has a zero low byte, processing proceeds directly to the fallback phase.
- If that low byte is nonzero, the function evaluates an early-return condition using descriptor byte 12, the first unsigned 16-bit temporary value, and the full-width selector.

The early-return condition is exactly:

- Descriptor byte 12 is zero;
- The temporary value is either 0 or 1; and
- The selector equals zero.

When all three hold, the function returns zero without directly setting Flag A at this point. Otherwise, it writes 1 to Flag A, then returns zero because the internal status has a nonzero low byte.

If secondary processing was suppressed by descriptor byte 13, the function instead tests the retained preliminary status’s low byte. A nonzero value returns zero; a zero value falls through. Under the directly visible ordinary flow, a nonzero preliminary low byte would already have returned during the preliminary phase.

### 3. Fallback processing

F-f52000074a41 is reached when neither earlier phase has completed the operation successfully.

It receives:

- The context.
- Auxiliary-reference and primary-reference slot addresses.
- The requested position and full-width selector.
- Descriptor values at offsets 0, 4, and 10.
- Selector-output and position-output addresses.
- Temporary 16-bit storage.

A nonzero signed 16-bit return enters the common error path.

On zero return, the function compares the byte at offset 9 of the **current** primary object with the context’s unsigned 16-bit field at offset 2. This is a fresh primary-reference read after F-f52000074a41; it does not necessarily use the initially referenced object.

If the values are equal:

1. F-0bbf0f39df9a is called with the context and current auxiliary reference.
2. A nonzero signed 16-bit result enters the common error path.
3. On a zero result, Flag C is written to 1.
4. The function returns zero.

If the values differ:

1. Flag B is written to 1.
2. The same early-return condition used after secondary processing is evaluated, using descriptor byte 12, the first temporary unsigned 16-bit value produced for fallback processing, and the selector.
3. If that condition holds, the function returns zero without directly setting Flag A on this branch.
4. Otherwise, Flag A is written to 1, followed by a zero return.

The object byte is zero-extended, not sign-extended. A context comparison value above 255 therefore cannot equal that byte.

### 4. Common error path

A nonzero signed 16-bit result from any of the four error-producing dependencies causes:

1. A call to F-b0f922796692 with the context and auxiliary-reference slot address.
2. Return of the saved error, sign-extended to 32 bits.

There is no direct rollback of position output, selector output, or any flag. In particular, entry initialization of Flag C and any earlier preliminary output writes remain observable unless a dependency or overlapping storage changes them.

## Side effects

### Direct writes

The wrapper directly performs only these caller-visible writes:

- Flag C ← 0 on entry.
- Position output ← requested position when the full preliminary status is nonzero.
- Selector output ← selector’s low 16 bits under the same condition.
- Flag A ← 1 under the preliminary mismatch or later policy conditions.
- Flag B ← 1 after successful fallback processing when the current primary object’s comparison byte differs from the context field.
- Flag C ← 1 only after the equal-field fallback branch and successful F-0bbf0f39df9a completion.

Flags A and B retain their incoming values on paths without a direct write to them, subject to dependency effects and aliasing. A zero return does not imply Flag C is 1.

### Dependency effects and read timing

Descriptor fields and referenced object fields are not all captured at entry. Later phases read them after intervening dependency calls. Their values can therefore differ between phases.

The supplied representation establishes phase ordering and direct write ordering, but not a portable ordering among separate argument-expression reads within one dependency call.

Dependencies receive addresses of mutable reference slots, output storage, or temporary state as described above. Their complete write sets are unknown. No dependency is assumed to preserve globals, context contents, descriptor contents, references, or previously written outputs.

### Ownership

No direct allocation, deallocation, or ownership transfer is visible in the wrapper. F-5f9a16493218 may populate the auxiliary slot, and F-b0f922796692 receives that slot on errors, but these facts do not establish acquisition or release semantics.

The caller must not infer that a nonzero return restores, clears, or releases the auxiliary reference.

## Acceptance examples

These are conditional static acceptance cases, not executed tests. Unless stated otherwise, assume valid nonoverlapping storage and dependencies that do not introduce additional mutations.

1. **Immediate preliminary completion.**  
   If F-dfe52f60212b returns 1, the position output receives the requested position, the selector output receives the selector’s low 16 bits, and the function returns zero without secondary or fallback processing. Flag C remains zero from entry.

2. **Full-width status differs from low-byte status.**  
   If the preliminary result is 256, the two preliminary outputs are written, but processing continues because its low byte is zero. Treating every nonzero preliminary status as immediate completion would violate this contract.

3. **Selector truncation does not change selector predicates.**  
   For selector 65,536 and a nonzero preliminary status, the selector output becomes zero. The selector is nevertheless not equal to zero for the preliminary mismatch check or later early-return conditions.

4. **Selection by equality.**  
   If the first dependency returns the requested position, preliminary processing uses the auxiliary-reference slot. This remains true when both values are zero; no auxiliary-reference validity check precedes that preliminary call.

5. **Secondary early return.**  
   If secondary processing succeeds, produces a nonzero low-byte internal status and temporary value 1, descriptor byte 12 is zero, and selector is zero, the wrapper returns zero without directly setting Flag A on that secondary branch.

6. **Temporary-value boundary.**  
   Under the preceding conditions, changing only the temporary value from 1 to 2 prevents that early return. The wrapper writes Flag A to 1 before returning zero.

7. **Fallback mismatch with conditional Flag A.**  
   If fallback processing succeeds but the comparison fields differ, Flag B is written to 1. With descriptor byte 12 zero, selector zero, and temporary value 0, the wrapper returns without directly setting Flag A on that branch.

8. **Fallback completion failure.**  
   If fallback processing succeeds and the fields match, but F-0bbf0f39df9a returns the 16-bit value −2, F-b0f922796692 is called and the public return is −2. The wrapper does not perform its Flag C ← 1 write.

9. **Unsigned comparison width.**  
   An object byte of 255 matches a context field of 255, but not 65,535. The byte is not interpreted as −1.

10. **Earlier writes survive errors.**  
    If a preliminary result of 256 writes both outputs and a later dependency returns an error, those writes are not directly undone by the wrapper.

The distinction between full 32-bit status, low-byte status, signed 16-bit dependency results, unsigned 16-bit comparisons, and byte flags is established and must not be collapsed.
