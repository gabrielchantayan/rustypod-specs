It obtains an intermediate 32-bit value using the constant 236, passes that value and the first caller input to another dependency, writes a designated global value through the resulting address, and invokes a third dependency with an address displaced by 176 bytes. It then writes two caller-supplied values and a zero byte relative to the third dependency’s result.

## Behavior

3. Read the designated 32-bit global value and store that value as four bytes at the primary address.
4. Invoke F-9563b8df22d3 with three arguments, in order:
   - The primary address displaced forward by 176 bytes, hexadecimal 0xB0.
   - The second caller input.
   - The integer constant 1.
5. Store the third caller input as four bytes at secondary address plus 48, hexadecimal 0x30.
6. Store the fourth caller input as two bytes at secondary address plus 54, hexadecimal 0x36.
