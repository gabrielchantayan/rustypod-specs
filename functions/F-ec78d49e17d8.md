- Input bit 0 is discarded.
- Input bit 1 becomes output bit 0.
- Input bit 16 becomes output bit 15.
- Input bits 17 through 31 are discarded.

It therefore does not, by itself, make a negative or overflowing signed left shift defined under language-level rules.
