Numerical extraction of a wide result’s high half does not establish memory serialization. Unsigned shifts of a 64-bit value by 34, 36, and 44 correspond to its high 32-bit half shifted right by 2, 4, and 12 respectively.

**[INFERENCE: 32-bit target-word interpretation]** If intermediate 32-bit operations retain their low 32 bits:

- Left shift by 8 followed by logical right shift by 8 retains the original low 24 bits.

## Acceptance examples

These are conditional static acceptance examples, not executed tests.

1. **Truncation and promotion.** A byte store receiving a word ending in 0xAB writes only 0xAB. A byte read producing 0xFE, when zero-extended for a word store, supplies numeric 254.

2. **Intermediate writes.** An observer of the adjusted-displacement-0x20 sequence sees 0x20, 0x2F, the promoted byte, and 0x20, if all accesses complete. The final value alone is insufficient.

3. **Global read before fixed write.** If the publication-global read returns a value and the subsequent 0x60 store changes overlapping storage, publication still uses the retained read result. Re-reading after the store is not equivalent.

4. **0x3A aliasing.** If absolute address 0x3A overlaps the later relationship-displacement-0x14 read, that read occurs after the byte write and must reflect the actual mapping and byte order. An entry-time snapshot is unjustified.

5. **Independent 0x67 reads.** If intervening aliased writes make the three reads return 0x12, 0x34, and 0x56, the 0x21 store consumes 0x12 and the two specified adjusted-displacement-9 stores consume 0x34 and 0x56 respectively. Later overwrites remain separate effects.

6. **Width-sensitive arithmetic.** Under the 32-bit target-word interpretation, successive left shifts by 25 and 11 produce zero. Retaining a 36-bit intermediate would not match that interpretation.

7. **Invalid address.** If a zero-extended byte leads to an inaccessible word address, no fallback or successful completion is specified. Silently skipping the access is not authorized.

8. **Terminal transfer.** If preceding operations complete, the first terminal argument is 0x72 and the remaining arguments have the retained origins specified above. Normal return remains conditional on the destination.
