# F-5670512d89b6

## Purpose

The established behavior is structural. The semantic meanings of the object, sentinel, field pairs, and derived values are not supplied. Describing the operation as a particular conversion, rendering operation, or resource-management operation would be inferred intent rather than an established contract.

The function returns either the fixed validation result −50 or the 32-bit result of its final dependency call.

## Behavior

### 1. Validate the required nonzero inputs

The function rejects the request if any of these conditions holds:

- Input 5 is null.
- Input 7 is zero.
- Input 1 is zero.

The rejection result is −50, represented as a 32-bit signed integer. No dependency call or pointed-to memory access is shown on this path.

Input 2, input 3, input 4, and input 6 do not affect this validation.

### 2. Populate temporary state and read the sentinel

For a request that passes validation, the function calls F-a5a54f2ab506 with:

1. Input 1.
2. The address of the temporary region.

The function does not inspect a return status from this dependency.

After that call, it reads a shared 32-bit sentinel value and retains it for the later comparison involving the second pair. This read occurs even when input 6 is zero.

The shared value is not established to be a constant. It is therefore important to distinguish this retained value from the subsequent shared-value reads used while checking the first pair.

### 3. Optionally replace the first pair

This phase is reached only when input 6 is nonzero.

The first pair qualifies for replacement only if both of its words equal the shared sentinel:

1. The word at temporary offset 4 is compared with a read of the shared value.
2. Only if that comparison succeeds is the word at temporary offset 0 compared with another read of the shared value.

The two comparisons are short-circuited in that order. They do not use the retained sentinel value established for the second pair. No assertion of atomicity or stability across shared-value reads is warranted.

If both comparisons succeed:

1. The marker byte at input 5, offset 0, is read.
2. If the marker is zero, F-a2533513d744 is called with input 5.
3. A 32-bit word is read from input 5, offset 8, and assigned to temporary offset 0.
4. A 32-bit word is read from input 5, offset 12, and assigned to temporary offset 4.

The replacement reads occur after the conditional dependency call. They therefore consume whatever values exist at those locations after that call returns.

The marker is not rechecked between the call and these two replacement reads.

### 4. Optionally replace the second pair

Still under the input-6 gate, the second pair is considered after the first pair’s entire processing.

It qualifies for replacement only if:

1. The word at temporary offset 28 equals the retained sentinel value.
2. If that comparison succeeds, the word at temporary offset 24 also equals that retained value.

Unlike the first pair’s comparisons, both comparisons use the sentinel value retained before either substitution phase. A change to the shared sentinel during first-pair processing does not update this retained comparison value.

If both comparisons succeed:

1. The marker byte at input 5, offset 0, is read again.
2. If the marker is zero, F-a2533513d744 is called with input 5.
3. A 32-bit word is read from input 5, offset 16, and assigned to temporary offset 24.
4. A 32-bit word is read from input 5, offset 20, and assigned to temporary offset 28.

There is no single cached marker decision shared by the two substitution phases. If both pairs qualify and the marker remains zero through both marker reads, F-a2533513d744 is called twice. If the first call changes the marker to nonzero, the second phase still reads the marker but does not make a second call.

### 5. Read and normalize the object flags

After optional substitutions, the function reads the 32-bit unsigned flags word at input 1, offset 4.

- If bit mask 0x200 is clear, the word is passed onward unchanged.
- If bit mask 0x200 is set, that bit is cleared and bit mask 0x100 is set.
- All other bits are preserved.

This is a transformation of the locally loaded argument value. The function does not directly write the transformed value back to the object.

The flags read occurs after all conditional F-a2533513d744 calls. Changes those calls make to the object or shared state must not be assumed absent.

2. F-f51dad4c1b38, with the same address.

Each produces a 64-bit result.

The order matters: no evidence establishes that the first dependency leaves the temporary region or other state unchanged. The second dependency receives the state that exists when its call begins, not a separately preserved snapshot.

## Acceptance examples

These are conditional contract examples, not executed tests. Successful-path examples assume valid memory and dependencies that return normally.

1. **Rejected request.** If input 1 is zero, the result is −50 regardless of the other inputs. The same rejection applies independently to null input 5 or zero input 7. No dependency is called.

2. **Substitution disabled.** If input 6 is zero, neither pair is checked for sentinel equality, and the input-5 marker and replacement fields are not directly read. Input 5 must nevertheless be non-null to pass validation. Temporary population, the sentinel read, flag preparation, both derivation calls, and final delegation still occur.

3. **Only the first pair qualifies.** Suppose the shared sentinel remains stable, both words of the first pair equal it, and the second pair does not qualify. With a nonzero marker, the first pair is replaced from input-5 offsets 8 and 12 without calling F-a2533513d744. The second replacement pair is not read.

4. **Both pairs qualify with a persistent zero marker.** If both pairs meet their respective comparisons and the marker is observed as zero in both phases, F-a2533513d744 is called twice. The second call is not suppressed merely because the first call occurred.

5. **The first marker call changes the second decision.** If both pairs qualify, the first marker is zero, and the resulting dependency call changes that marker to nonzero, there is only one F-a2533513d744 call. Each pair still receives its selected replacement fields.

6. **Partial pair mismatch.** If the first pair’s offset-4 word matches the sentinel but its offset-0 word does not, neither word is replaced. Pair replacement is not performed one matching word at a time.

7. **Flags normalization.** A flags word of 0x200 becomes 0x100. A word of 0x300 also becomes 0x100. A word of 0x80 remains 0x80. These are final-call argument values, not promised object updates.

8. **Wide-result forwarding.** If F-f51dad4c1b38 produces 0x123456789ABCDEF0, the second final-call argument has bit pattern 0x12345678, while the fifth argument retains all 64 bits.

9. **Final result propagation.** If F-ec96c59e8446 returns −7, F-5670512d89b6 returns −7. No success-only normalization is applied.
