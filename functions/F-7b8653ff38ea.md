# F-7b8653ff38ea

## Purpose

The visible sequence passes a scaled third input to the first call. It later passes a scaled result from the fifth call to the sixth call. Between those calls, it obtains a destination address from an unsigned byte in ambient memory and stores a byte extracted from an ambient unsigned word.

No application-level purpose is established. In particular, the evidence does not establish that the routine is an allocator, serializer, device operation, dispatcher, or successful initialization sequence.

**Evidence boundary:** the supplied representation includes a warning about invalid instruction data and ends at a truncated control-flow boundary. This contract therefore distinguishes the behavior represented by the visible fragment from any claim about complete executable behavior. All sequence descriptions below are conditional on the recovered operations being valid and execution reaching them.

### Selector boundaries

A selector byte of zero selects address 0x11.

A selector byte of 255 selects address 0x110, not 0x10 and not an address relative to the ambient base.

These expectations require no assumption about the selector byte’s original signed interpretation elsewhere: this read is represented as unsigned.

### Extraction boundaries

An ambient unsigned word of 0x003FFFFF produces a stored byte of zero, because all set bits lie below bit 22.

An ambient unsigned word of 0x3FC00000 produces a stored byte of 0xFF.

An ambient unsigned word of 0xC0000000 produces a stored byte of zero. Its set bits are above the eight-bit extraction window.
