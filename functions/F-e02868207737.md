# F-e02868207737

## Behavior

### 1. Initial admission check

The first observable object read is the byte at `0x19`.

- If it is nonzero, admission succeeds without reading `0x18` or `0x17` for this check.
- If it is zero, the byte at `0x18` is read.
  - A nonzero value causes an immediate return of zero.
  - Only when `0x18` is zero is `0x17` read. A nonzero value there also causes an immediate return of zero.

An immediate rejection makes no dependency calls and does not decrement `0xE0`.

After admission, the mutable local slot is initialized from the caller value, and F-b93e3fe564f6 is called with the object. Its return value is ignored.

Subsequent object reads occur after this call. They must not be interpreted as snapshots of the object’s entry state: the dependency may have changed the object or other relevant state.

### 2. Top-level selection

The byte at `0x0E` is read after F-b93e3fe564f6.

**If it equals 5:**

- Read `0x14`.
- If `0x14` is zero, skip further processing and proceed to the final decrement with status zero.
- If `0x14` is nonzero, take the direct indexed-processing path below.

**If it does not equal 5:**

- Read `0x14`.
- If it is nonzero, take the direct indexed-processing path.
- Otherwise read `0x12`.
  - If `0x12` is zero, proceed to the final decrement with status zero.
  - If nonzero, read `0x15`.
    - A nonzero value selects transition processing.
    - Zero selects preparation and possible candidate scanning.

The tests of `0x12` and `0x15` do not occur on the direct indexed-processing path.

### 3. Direct indexed processing

When selected by `0x14`:

- A zero starting index causes no indexed dependency call and proceeds to the final decrement with status zero.
- A nonzero starting index causes F-b73a5da2c7c4 to be called with the object and starting index.

Its result becomes the status. This path then reaches common status normalization and the final decrement; it does not continue into candidate scanning or transition processing.

### 4. Preparation before fallback or scanning

This branch calls F-7779b676efb8 with the object and a zero second argument.

- A nonzero result ends branch processing and becomes the status.
- A zero result permits further work:
  - If the starting index is zero, use the fallback sequence.
  - Otherwise, initialize and enter the candidate scan.

### 5. Candidate scan

Before scanning, F-870c4fcf7295 is called with the 32-bit constant `0x40000000` and the current 32-bit field at `0x40`.

Its result is retained as a 32-bit value for identifying one excluded candidate. The scan cursor begins at the starting index.

For each iteration:

1. Increment the cursor using unsigned 32-bit arithmetic.
2. Read the current upper bound at `0x28`. If the incremented cursor is greater than that bound under unsigned comparison, leave the scan and run the fallback sequence.
3. Otherwise read the current field at `0x54` and call F-811a25bdbe21 with that value and the cursor.
4. Skip this candidate if the lookup result is nonzero.
5. If the lookup result is zero, also skip the candidate when its index equals the retained result from F-870c4fcf7295 plus one, computed modulo \(2^{32}\).
6. For a candidate not skipped, call F-133a6620fb39 with:
   - the object;
   - the cursor;
   - the address of the mutable local slot;
   - a zero fourth argument.
7. If that call returns nonzero, stop scanning with that status. Neither F-81c906bf6e3a nor F-44d249c54e70 is called for that candidate.
8. If it returns zero, call F-81c906bf6e3a with the slot’s current value. Then call F-44d249c54e70 with the slot’s value, regardless of whether F-81c906bf6e3a returned zero or nonzero.
9. A nonzero result from F-81c906bf6e3a stops scanning. A zero result continues to the next candidate. The return from F-44d249c54e70 is ignored.

Candidate lookup therefore occurs even for the excluded index. The exclusion check is not a substitute for that call.

The upper bound and lookup-context field are reread on subsequent iterations. There is no established guarantee that dependencies leave either unchanged.

Unsigned cursor increment wraps from `0xFFFFFFFF` to zero. Consequently, a maximal bound does not by itself ensure scan exhaustion or termination.

### 6. Fallback sequence

Fallback is reached either immediately after successful preparation with a zero starting index or after the scan cursor exceeds the current upper bound.

First, F-b7c1c2525770 receives the object and auxiliary value.

- A nonzero result becomes the status and prevents further fallback work.
- On zero, F-eae643b3e145 receives the object.
  - A nonzero result becomes the status.
  - A zero result enters transition processing.

Successful fallback does not bypass the starting-index check within transition processing. Thus a nonzero starting index can still cause F-b73a5da2c7c4 to run after scan exhaustion and successful fallback.

Early no-work paths bypass status normalization but already have status zero. Initial admission rejection bypasses both normalization and decrement.

These are conditional acceptance criteria derived from static control flow, not executed tests. Unless stated otherwise, dependencies return normally.

4. **Direct status conversion:** If direct indexed processing calls F-b73a5da2c7c4 and receives `0xB0A`, return 5 after the final decrement.

5. **Excluded candidate still looked up:** With cursor initially 7, bound at least 8, and retained exclusion result 7, candidate 8 is passed to F-811a25bdbe21. Even if lookup returns zero, F-133a6620fb39 is not called for candidate 8.

6. **Candidate-operation failure still followed by paired call:** If F-133a6620fb39 returns zero and supplies a slot value, then F-81c906bf6e3a returns a nonzero status, F-44d249c54e70 must still be called before scanning ends.

7. **Candidate acquisition failure:** If F-133a6620fb39 returns nonzero, neither subsequent slot-consuming dependency is called for that candidate.

8. **Fallback short circuit:** A nonzero result from F-b7c1c2525770 prevents F-eae643b3e145 and transition processing. The status is normalized if necessary, and `0xE0` is decremented.

9. **Optional-call error does not prevent state write:** If transition processing reaches F-b6413637baad and it returns a nonzero status, `0x0E` is nevertheless written as 5 before the final decrement and return.

10. **Original caller value controls the optional call:** A nonzero original caller value suppresses F-b6413637baad, even if scanning or the later `0x90` read has replaced the mutable local slot with zero.
