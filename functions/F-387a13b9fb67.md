## Behavior

2. Read offset 0 from the second address.
3. Compare the two values.
4. If they differ, complete with 0.
5. If they match, read offset 1 from the first address, then offset 1 from the second address.
6. Compare those second-byte values.
7. If they differ, complete with 0.
