## Acceptance examples

These are conditional criteria from static evidence, not executed tests.

1. **Distinct first-stage global reads.** If the first read yields `0x1000` and the second yields `0x2000`, +0 receives `0x2000` before +28 receives `0x10E4`. If preparation occurs, F-672ce4a07539 also receives `0x10E4`.

2. **Distinct second-stage global reads.** Reads yielding `0x3000` and `0x4000` cause +0 to receive `0x4000`, followed by +28 receiving `0x30DC`.

3. **Initial-record distinction.** The first record uses arguments 1 and 3. A subsequent record uses its own +8 word and zero instead. Each record-address call follows its payload call.

4. **Skipped structure.** A zero +80 gate leaves the first structure untouched by its preparation, splice, drain, and clearing phase, even if +68 is nonzero.

5. **Removal before calls.** A record selected from +40 has already been removed from that head when its first F-ff1bdc376dcd call begins.

6. **Retained incoming argument 5.** If the loop is reached, F-ebd94610a438 returns nonzero without writing the slot, and the incoming pointer remains there, the indirect-call decision uses that incoming pointer. A null incoming pointer skips the call; a valid nonnull pointer selects it.

7. **Repeated retained pointer.** Two nonzero returns without slot modification can cause two calls through the same retained pointer. This requires the pointer and target to remain valid.

8. **Zero result ignores slot.** A zero F-ebd94610a438 result exits the loop even if the slot is nonnull.

9. **Repeated auxiliary notification.** A nonzero predicate and a later manager +40 equality can produce two F-a82ec4b43e2f calls with the original captured word.
