## Behavior

If the field is zero, it skips the indirect invocation. It does not return early: the global-to-record write and the call to F-22abefe7f288 still follow.

If the field is nonzero, the function resolves and invokes the target through the dispatch chain described above. No validation is shown for the intermediate storage, table address, table entry, or target compatibility.

### Optional indirect invocation

When selected, the indirect invocation precedes the function’s explicit first-word replacement.

Thus, absent changes made by other actors, the indirect target executes before that replacement has occurred. An implementation that writes the replacement first and calls the target afterward would change the established ordering.

The target’s result is not used by the shown logic. Its normal return is necessary to reach the subsequent write through this sequence.

### Replacement read and write
