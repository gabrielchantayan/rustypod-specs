# F-21e1baf63821

## Purpose

F-21e1baf63821 performs conditional halfword memory manipulation and then enters a nonterminating dispatch-and-interrupt cycle. No normal return is represented.

The supplied static representation does not establish an application-level purpose. In particular, it does not establish that this function implements a parser, allocator, serializer, device operation, or error handler.

A substantial portion of the represented conditional processing is unreachable under a consistent 32-bit, wrapping-address interpretation. This contract distinguishes those reachability conclusions from operations merely present in the representation. The unusual entry-state dependencies and address calculations make the machine interpretation an important qualification, not an implementation detail.

## Behavior

### Initial branch and memory transfer

The initial branch is selected when the low four bits of Selector are zero.

This follows from multiplying Selector by \(2^{28}\) in 32-bit arithmetic and testing the result for zero. Higher selector bits do not affect that decision.

When the low four bits are nonzero:

- The initial halfword transfer is skipped.
- The later conditional memory blocks are not reached under the stated arithmetic interpretation.
- Processing proceeds to the dispatch cycle.

When the low four bits are zero, the following transfer occurs before subsequent equality gates:

1. A destination address is formed by adding Offset to Source address, in bytes, modulo \(2^{32}\).
2. One unsigned 16-bit value is read from Source address.
3. The internal source-address state is replaced by destination address minus Displacement.
4. The previously read 16-bit value is written to the destination address.

The transfer copies the halfword’s bit pattern without widening the stored value.

The source read precedes the destination write. If the addresses are equal, the function still performs the represented read and write; this is not specified as a skipped self-copy. Whether either access has device-specific effects depends on the memory mapping.

The destination is computed before the source-address state is updated. The write does not use the updated state as its destination.

A memory fault during either access can prevent the later cycle from being reached. There is no represented recovery path.

### Conditional processing after the transfer

The remaining initial gates compare derived address-sized values with zero. Although the representation includes shift counts extracted from low bytes, the gates that permit these particular operations also force the shifted controlling value to zero. Consequently, the reached shifts in this chain have a count of zero.

Under the stated arithmetic interpretation, the exceptional memory block after this chain requires all of the following:

- Selector has its low four bits clear.
- Entry base is zero.
- Argument address is zero.
- Peer value equals Offset.
- Offset is either zero or `0x80000000`.
- The updated source-address state equals Displacement.
- Auxiliary value is zero.

The updated-source equality can equivalently be expressed as Source address plus Offset equaling twice Displacement, modulo \(2^{32}\).

The requirement that Argument address be zero is a derived restriction, not a general precondition imposed on callers. In an ordinary environment where the fifth argument occupies valid nonzero stack storage, this exceptional block cannot execute under the stated model.

The restriction follows from two earlier gates. With Entry base zero, the first requires Argument address shifted right by one to be zero, leaving only addresses zero or one. A subsequent requirement that Argument address plus twice Offset equal zero excludes address one.

### Exceptional halfword operation

If the exceptional block is reached, it reads a halfword at Entry base and interprets that halfword as a zero-extended address. It writes the original halfword plus 15 to that address, retaining only the low 16 bits.

The represented expression references the halfword both as a destination selector and as an arithmetic operand. The supplied evidence does not establish a single-load guarantee or the relative ordering of those operand evaluations. This matters for volatile or device-backed memory.

Under the derived entry conditions, Entry base is zero. Execution therefore requires the read at address zero to be meaningful in the actual execution environment.

The block also represents:

- An assignment to a recovered machine-state location, using Argument address multiplied by 64.
- A candidate update of Entry base by the same byte displacement.
- A two-byte increment to another address-valued state.

Because Argument address must be zero, the multiplication produces zero and Entry base remains zero. The machine-state location’s architectural meaning is unknown.

### Later represented blocks

After the exceptional block, another zero-gated chain cannot progress far enough to reach the later memory blocks.

If the exceptional block was skipped, its continuation gate is false. If it executed, the next gates encounter the two-byte increment described above and produce a nonzero result of two. That prevents the remaining zero-gated chain from continuing.

Accordingly, under the stated model, the following represented operations do not execute:

- Later pointer-table reads.
- Later signed-halfword conversion and paired pointer stores.
- Later writes to addresses derived by subtracting fixed constants from a signed-halfword value.
- Later changes to the dispatch base associated with those blocks.

These operations are present in the static representation but are not established reachable behavior. Treating them as ordinary observable outputs would overstate the evidence.

### Dispatch-and-interrupt cycle

Once reached, the final cycle has this order:

1. Invoke an indirect target at the current dispatch base plus `0xEB6` bytes.
2. Invoke the fixed target at `0x0857A94B`.
3. Issue software interrupt `0x5B`.
4. If execution resumes normally, replace the dispatch base with `0x083D4CC2`.
5. Repeat indefinitely.

The first indirect invocation receives three represented argument words:

- Zero.
- Zero.
- `0xFFFFFFA5`.

The third word is the unsigned 32-bit value 4,294,967,205; interpreted as signed 32-bit, the same bit pattern is −91. The callee’s expected interpretation is unknown.

No explicit arguments are represented for the second invocation. This does not establish that the target consumes no machine-state inputs.

Under the reachability analysis above, the first iteration’s dispatch base is Entry base. Its target is therefore Entry base plus `0xEB6`, modulo \(2^{32}\).

After an interrupt returns and the reset executes, subsequent first-call targets are `0x083D5B78`.

The cycle advances only when the preceding operation returns or resumes. An indirect callee may fail to return; the interrupt may trap, terminate execution, or transfer control elsewhere. None of those outcomes is resolved by the supplied evidence.

## Acceptance examples

These are conditional acceptance criteria derived from static evidence. They are not runtime observations.

### Selector bypass

Given Selector equal to `1` and a usable Entry base:

- No initial halfword copy is performed.
- The first dispatch target is Entry base plus `0xEB6`.
- Its explicit argument words are zero, zero, and `0xFFFFFFA5`.

Reaching the second invocation additionally requires the first invocation to return.

### High selector bits do not prevent the copy

Given Selector equal to `0x80000010`, readable Source address, and writable destination:

- The low four bits are zero.
- The initial halfword transfer occurs despite the high selector bit being set.
- The destination address is Source address plus Offset, not Source address plus twice Offset.

### Aliased source and destination

Given Selector equal to zero and Offset equal to zero:

- The function reads a halfword from Source address.
- It writes that halfword back to the same address.
- It does not omit the accesses merely because the addresses coincide.

### Nonzero argument storage

Given a nonzero Argument address and the stated 32-bit arithmetic model:

- The exceptional halfword-derived write is not reached.
- If the initial copy is selected, it can still occur.
- The final dispatch uses Entry base without a reachable adjustment from the later memory blocks.

### Exceptional zero-address case

Given zero Selector, Entry base, Argument address, Source address, Offset, Displacement, Peer value, and Auxiliary value, and an environment supporting the required zero-address accesses:

- The initial transfer reads and writes address zero.
- The exceptional block uses the halfword at address zero to select a destination.
- It stores that halfword plus 15, reduced to 16 bits.
- The later zero-gated memory blocks remain unreachable.
- The first dispatch target is `0x00000EB6`.

For a stable halfword value of `0xFFF8` at address zero during the exceptional expression, the destination is `0x0000FFF8` and the stored halfword is `0x0007`.

### Continuing cycle

If both targets return and interrupt `0x5B` resumes normally:

- The next first-call target is `0x083D5B78`.
- The fixed second target and interrupt follow in the same order.
- No normal return occurs.
