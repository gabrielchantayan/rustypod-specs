# F-4eb33f6e360d

## Purpose

F-4eb33f6e360d is represented as a machine-state-dependent operation that performs conditional memory accesses, invokes unresolved dependencies, constructs a fixed-address record, and reaches invalid-instruction termination on every explicitly completed path.

An application-level purpose is not established. The evidence does not support identifying it as a controller, allocator, loader, serializer, or validator.

This contract distinguishes:

- **Established static evidence:** operations, widths, value relationships, and ordering visible in the supplied representation.
- **Inferred intent:** interpretation rather than a behavioral guarantee.
- **documented_only:** behavior unresolved by the supplied evidence.

Warnings about invalid instruction data and overlapping global storage limit confidence in the executable interpretation. All behavior below is conditional on execution reaching the described operation. No runtime tests have been performed.

## Behavior

### Entry and early termination

Before deciding between branches, the operation:

1. Reads a 32-bit word from a global region.
2. Forms the adjusted third argument using B.
3. Reads a byte at the 32-bit address R plus the fourth argument.
4. Interprets that byte as P through the represented signed extension.

Thus even immediate early termination requires both entry memory reads.

If **L ≤ R under unsigned comparison**, the following occur in order:

1. A signed global word is read and arithmetically shifted right by 26.
2. A pointer-valued global is read.
3. B is written as a 32-bit word at that pointer plus 0x54.
4. The low byte of the entry global word is written at B + 1.
5. The shifted signed value is written as a 32-bit word at twice the second argument.
6. Invalid-instruction termination is reached.

Under the represented arithmetic shift, the shifted value lies from −32 through 31. The second argument’s signed doubling may require overflow qualification.

### Secondary branch selection

When **L > R unsigned**, the next predicate is signed-subtraction overflow for the 32-bit subtraction **R − L**. This is not unsigned borrow.

If overflow is indicated:

- The selected 64-bit value is 0x0000002100000079.
- Long-branch initialization and processing are skipped.
- P retains its initial signed-byte-derived interpretation.
- The common continuation’s first target is derived from the incoming link value plus 0xFFE.

Its two explicit arguments are consequently 0x79 and 0x21.

Otherwise, execution takes the long branch.

### Long-branch initialization and frame ordering

The following ordering is established and is significant even when addresses alias:

1. A coprocessor write uses the incoming machine and coprocessor values, with represented selectors 0xD, 6, and 3.
2. A signed global word is read and captured.
3. F-U001 is invoked with no explicit arguments.
4. Immediately after its return, the captured global word plus 0xA8 is written to its frame slot.
5. A 32-bit word is read at the adjusted-third-argument address plus the current P. Call this captured word the **loaded word**.
6. The low 16 bits of R are written through the current P.
7. A signed halfword is read at B + R; its sign-extended pointer interpretation replaces P.
8. The loaded word is written as 32 bits at the replacement P plus B.
9. The represented stack-base register is assigned the address of the frame’s first word slot.
10. The remaining frame slots are written, in order: the loaded word, replacement P, and a fixed code-associated value.

The apparent four-word frame, in increasing slot order, contains:

| Slot offset | Value |
|---:|---|
| 0 | Loaded word |
| 4 | Captured signed global word plus 0xA8 |
| 8 | Replacement P |
| 12 | Fixed code-associated value |

The offset-4 write occurs before the loaded-word read and the halfword/word operations, not alongside the other three frame writes. The stack-base assignment occurs after those memory operations but before the remaining frame writes.

There is no post-F-U001 reread of the signed global for this frame value. Changes to that global during F-U001 do not replace the captured operand. Signed overflow in adding 0xA8 remains target-qualified.

No disjointness is established among the frame, globals, and computed addresses. Consequently, the early frame write can affect subsequent reads, and the halfword write can affect the following signed-halfword read.

## Side effects

Established effects include mixed-width memory accesses, low-address and potentially unaligned accesses, a long-branch coprocessor operation, a stack-base assignment, and numerous dependency invocations.

Writes are not transactional. Later faults or invalid-instruction termination do not establish rollback.

Dependencies may modify globals or memory before subsequent reads. Captured values and fresh reads are distinct throughout this contract. No assumption of global stability, memory ownership, register preservation, or normal dependency return is justified.

Invalid addresses, unsupported coprocessor operations, alignment restrictions, or invalid call targets may stop execution before an explicit terminal marker. The resulting platform behavior is documented_only.

## Acceptance examples

These are conditional static expectations, not observed executions.

- **Equality:** If L = R, both entry reads still occur. The early writes occur in their specified order, followed by termination. No continuation call is reached.

- **Unsigned order versus signed overflow:** With R = 0x7FFFFFFF and L = 0x80000000, unsigned ordering selects the secondary branch and signed subtraction overflows. F-C001 receives 0x79 and 0x21 through the incoming-link-derived target. With R = 0 and L = 1, subtraction does not overflow, so long initialization occurs instead.

- **Global capture across F-U001:** If the signed global contains 5 when captured and F-U001 changes it to 9, the early frame slot receives 0xAD, not 0xB1, provided the represented operations complete. No reread supplies the frame operand.

- **Early frame-write aliasing:** If that frame slot overlaps the later loaded-word read address, the read observes memory after the frame write and any F-U001 effects. It must not be specified using an unconditional pre-call memory snapshot.

- **Intervening byte mutation:** If F-L030 changes the byte at the selected 0x10/0x11 address, the subsequent read for F-L031 occurs after that change. The same rule applies to F-L044 and the byte supplied to F-L045.

- **Signed P:** Under the represented signed-byte interpretation, an initial byte of 0xFF gives P = 0xFFFFFFFF. On the shortcut, the later doubled-P halfword destination is 0xFFFFFFFE under the represented 32-bit address interpretation, without any accessibility guarantee.

- **One-bit extraction:** For bit 24, 0x01000000 produces 1 and 0x02000000 produces 0.

- **Late rejection:** A late unsigned-global value of 9 still permits the offset-0x68 write before termination. A value of 8 proceeds to F-U002 and the final write sequence.
