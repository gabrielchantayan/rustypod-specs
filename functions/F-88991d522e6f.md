# F-88991d522e6f

An initially nonzero field causes immediate return. Otherwise, the callback is invoked. A zero callback result also causes return. A nonzero callback result leads to a call to F-8157a180d901 with the numeric argument **8**, followed by a call to F-d9e0ae06e54d using both returned values.

## Behavior

### Initial gate

The first directly visible object access is a read of the 32-bit field at offset 8.

If that value is nonzero, the function returns immediately. Every nonzero bit pattern satisfies this test. There is no check that the field contains a valid address, a recognized handle, or a successful prior result.

On this path, the function performs no direct data write and invokes no dependency. It does not resolve the indirect callback.

### Callback lookup and early return

If the initial gate is zero, the function reads the first object word and uses its represented address to locate the callback slot at byte offset 44. It then invokes the resolved target with the original object pointer.

For this document, that unresolved target is designated **F-indirect-01**. This is a document-local opaque identifier, not an established identity for the target.

The callback result is represented as a 32-bit integer. The function tests it against zero:

- Zero causes immediate return.
- Any nonzero result permits the remaining dependency sequence.

On the zero-result path, neither F-8157a180d901 nor F-d9e0ae06e54d is called. The function performs no direct assignment to the gate on that path.

The callback may itself change the object or other state. Therefore, a zero callback result does not establish that the object remains unchanged or that the gate remains zero.

### Completed dependency sequence

After a nonzero callback result, the function calls F-8157a180d901 with the numeric argument **8**.

Its result is represented as a 32-bit quantity. The function neither tests nor directly dereferences that result. Instead, after F-8157a180d901 returns normally, it calls F-d9e0ae06e54d with:

1. The result of F-8157a180d901.

The source establishes this argument order. It does not establish semantic types such as allocated pointer, source object, or ownership token.

When F-d9e0ae06e54d returns normally, its represented 32-bit result is written into the original object at offset 8. The function then returns.

There is no intervening branch based on the first dependency’s result and no validation of the final result before storage.

### Gate mutations during calls

Consequently, if the callback changes the gate to a nonzero value but itself returns nonzero, that mutation does not suppress the two subsequent calls. If the calls complete and the destination remains valid, the final assignment replaces the value then present at offset 8.
