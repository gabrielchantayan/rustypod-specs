No application-level purpose is established. The access patterns do not establish an initializer, allocator, serializer, interpreter, or operating-system service.

For a selector read at a base plus one, the write is not to the base plus 17. Without address-translation qualifications, the selected destination is between 17 and 272 inclusive.

A **scaled word slot** denotes a 32-bit access at an address such as four times an index plus 20, or sixteen times an index plus 20. These formulas do not establish arrays, common allocations, bounds, or object types.

Each represented read occurs at its own position in the sequence. Dependencies between accesses may change memory. ## Acceptance examples

These are conditional static obligations, not executed tests.

1. **Initial truncation.** If the incoming packed value is 0xABC00000 and the first selector sample is 5, the first byte write stores 0xAF at address 22.

2. **Selector reload.** If the second argument is 0x1200, both early selector reads use address 10. If their samples are 3 and 7 because an intervening dependency changes memory, the zero writes target addresses 20 and 24 respectively.

3. **High-bit offset.** For the right-19/left-31 address transformation, 0x00080000 produces offset 0x80000000 under unsigned 32-bit arithmetic. Zero produces offset zero.

4. **Post-reset chain.** If the saved full-width result is 0x1000 and the later byte read at 0x1001 yields 7, the dependent read uses address 8. It does not use 0x1002. Both reads occur after the G0 reset and F-dep-003.

5. **Captured absolute selector.** Suppose the designated capture reads 5 from address 1. The immediate zero write targets address 22. If dependencies later change address 1 to 9, the first post-assignment offset-116 copy still reads its word at address 121 and writes its low byte at address 6—not at addresses 125 and 10.

6. **Delayed word read.** Continuing the preceding example, if an intervening dependency changes the word at address 121 to 0x123456AB before the copy, the byte written at address 6 is 0xAB. The selector is saved earlier; the word is not.

7. **Shared-state mutation.** If a dependency changes G0 after its zero assignment, a subsequent G0 read consumes the changed value. The double right-23 transformation still yields zero for any unsigned 32-bit sample.

8. **Terminal ordering.** If the final result byte is 0xAB and the upper shared field is 0x123456, the terminal G1 assignment is 0x123456AB. The pointer-byte clearing precedes that assignment; the 16-bit clearing follows it; the address-zero invocation follows both. Non-return from that invocation prevents the represented return without implying rollback.
