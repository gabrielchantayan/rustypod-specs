# F-508d288c8328

## Purpose

F-508d288c8328 is an incompletely recovered, state-mutating execution fragment. The supplied static representation establishes indirect calls, byte and 32-bit memory accesses, and arithmetic transformations of dependency results and implicit entry state. It does not establish an application-level purpose.

Its defensible contract is an ordered trace of calls and memory effects, not a claim that it constructs, serializes, allocates, or releases a particular object.

The visible fragment:

- Has three nominal 32-bit arguments.
- Depends on additional entry-register state.
- Calls unresolved indirect dependencies.
- Uses byte values, words, and scaled results as addresses.
- Writes bytes and 32-bit words, including bytes at absolute addresses 0x0D and 0x11.
- Reaches a bad-instruction recovery boundary without an established normal return.

All behavior below is conditional on the accuracy of the supplied static representation. No runtime tests have been performed.

## Acceptance examples

These are conditional static expectations, not executed tests.

1. **Initial selector.** If entry base + 1 contains 0xA0 and the entry bit source is 0xABCDEF00, the initial selected store writes 0xAF at address 0xB1, provided preceding calls and accesses complete.

2. **Word narrowing.** If an applicable offset-0x74 word read yields 0x12345678, its associated byte store writes 0x78. This is numeric narrowing, not an endianness assertion.

3. **Fresh selector.** If an early selector is 2 and an intervening dependency changes its source byte to 9, the later read selects address 0x1A rather than 0x13.

4. **Unsigned retained field.** If the word shifted right by 22 is 0xFFC00000, the retained quantity is 0x3FF. Its low nine bits shifted left by 21 yield 0x3FE00000. Its unsigned 32-bit left shift by 23 yields 0xFF800000.

5. **Offset-7 provenance.** If the origin result is 0xC000012C, its origin mask is 0x0000012C and its saved quarter-mask is 0x4B. Doubling produces 0x96, the later offset-7 byte payload. If the independent bounded selector is 0x3FF, that store writes 0x96 at address 0x406.

6. **Offset-7 narrowing boundary.** An origin result of 0xFFFFFFFF produces a saved quarter-mask of 0x0FFFFFFF. Doubling yields 0x1FFFFFFE; the offset-7 byte store retains 0xFE. An origin result of 0x00000200 instead produces a doubled quantity of 0x100 and stores 0x00.

7. **Low-address overwrite.** Absolute address 0x0D receives a retained selector and later 0xC0. Intervening dependencies may observe the first value; the second store does not erase that event from the contract.

8. **Partial execution.** If a dependency does not return after preceding stores, no later write or rollback is guaranteed.
