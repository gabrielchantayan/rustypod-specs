## Behavior

### Established operation order

The wrapper performs the following observable sequence:

1. It writes the 16-bit prefix value at D.
2. It calls F-fac138f80b6d with:
   - First argument: D + 2.
   - Second argument: the supplied 32-bit dependency payload.
   - Third argument: the numeric constant 255, also expressible as hexadecimal FF.
3. After that call returns normally, it writes the value zero as a single byte at D + 257.
4. It returns without an explicit result.

The dependency’s third argument has the established numeric value 255. Its declared parameter width and signedness are not supplied.

The first address calculation advances by one 16-bit element, so its byte displacement is two, not one. The final store uses a byte displacement of 257 from the destination base.

### Dependency boundary

There is no corresponding post-call restoration of the prefix. If the dependency modifies bytes 0–1, the wrapper does not write the original prefix there again.

These ordering statements do not establish that the dependency confines its accesses to any particular region. The address and constant passed to it are known; its interpretation of them is not.
