The wrapper first evaluates whether the second input equals zero.

If it does:

1. No indirect invocation is performed.
2. The third input is not forwarded anywhere by the represented body.
3. The first input has no represented effect.
4. The wrapper returns normally.

This path contains no represented lookup of the indirect target and no explicit memory write. It does not inspect or dereference storage that either four-byte input might happen to denote.
