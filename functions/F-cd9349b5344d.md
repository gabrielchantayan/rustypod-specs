# F-cd9349b5344d

## Purpose

F-cd9349b5344d transforms four apparent input words, performs memory writes and unresolved calls, and selects among record construction, a constructed two-word return, an unresolved dispatch, abnormal termination, and a potentially unbounded loop.

An application-level purpose is not established. “Record construction” describes the shape of the final writes, not a proven object type or allocation protocol.

**Contract status: documented_only.** This contract describes the supplied static representation. It does not establish that every represented path is executable, that function boundaries are accurate, or that the apparent interface is complete.

## Behavior

### Preliminary special path

After the initial transformations, a second input with the 32-bit representation of 76 selects this sequence:

1. Call an unresolved target derived from incoming return-address-like state, passing the shifted first input.
2. Read a global word and double it.
3. Read that global again; form an address-like value equal to four times this observation plus 62.
4. Load a 32-bit word at that address-like value plus the fourth input. It replaces the transformed third input.
5. Read the global for a halfword payload, then separately for a destination. Write the payload’s low 16 bits first at fourth-input-plus-destination-observation, then at the earlier doubled observation plus 4.
6. Make two unresolved calls. From the second call’s returned address, load an **unsigned halfword at offset 4**. Its zero-extended value replaces the second-input-derived working quantity.
7. Call another unresolved dependency and write its returned byte at offset 1 through an incoming stack-supplied pointer.
8. Make another unresolved call.
9. Write the low byte of the address-like value from step 3 at that value plus the replacement third input.
10. Replace the transformed first input with zero and subtract 64 from the fourth input.

The four global observations in steps 2–5 follow the first call and precede the next call. A word load and two halfword stores occur in that interval. No call separates those global observations, but aliasing or other memory effects must not be assumed absent.

4. Make another unresolved call.

## Acceptance examples

These are conditional static consequences, not executed tests.

1. **Special-path replacement:** second input 76 selects the preliminary path. A returned-address-plus-4 unsigned halfword of 9 makes the common character-read address replacement-third-input-plus-9. The primary call receives zero as its first argument.

2. **Threshold:** primary high word zero and low word 56 produce doubled quantity 112, bypassing the alternate region and reading the unsigned byte at address 146. Low word 57 produces 114; subtraction of 113 has no signed overflow, selecting the alternate region.

3. **Entry predicate and direction:** a preceding result of zero makes the unsigned comparison false and enters the continuation without the offset-42 halfword store. A preceding result of signed −1 makes it true. After the store, a nonnegative object address and new high word zero give two false predicates, whose equality selects the continuation.

4. **Loop-carried values:** if a continuation’s low word is 3 and high word is 2, the next inner call’s first argument is 6, and its offset-62 store payload is 16, assuming the represented arithmetic and successful preceding operations. It does not reuse the initial difference.

5. **Carry boundary:** captured object byte zero gives operand 18. A large-offset word of 4,294,967,277 produces 4,294,967,295 without first-addition carry. A base above 4,177,526,783 makes the second addition carry; a base at or below the threshold selects the byte write and termination marker.

6. **Captured observations:** changing the inner arithmetic global during the intervening call does not change the captured exclusive-or operand. Conversely, neither the dispatch’s two global occurrences nor the final destination-global occurrences may be collapsed into one guaranteed observation.

7. **Record order:** reached record stores occur at offsets 100, 0, 4, 8, and 12 in that order. Later failure does not imply rollback.
