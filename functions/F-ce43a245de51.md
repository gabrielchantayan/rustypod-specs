## Acceptance examples

These are conditional static obligations, not executed tests.

1. **Third input of one.** Under 32-bit bitvector arithmetic, the retained three-bit-shifted value is 8. Its independently further-shifted forms are 8192 and `0x20000000`.

2. **Extraction width.** Masking `0xAB123456` to 24 bits and shifting left by six produces `0x048D1580`. Truncating to sixteen bits first is not equivalent.

3. **Small-index boundary.** The small index is a multiple of four no greater than 508; its doubled base is a multiple of eight no greater than 1016. Neither range proves a valid address.

4. **Late snapshot.** If earlier writes change the global at `0x087FBBBC`, the value at its post-offset-`0x20` read supplies the repeated-region base, not an entry-time value.

5. **Fresh fixed-byte reads.** If `0x67` receives `0xAB` and an intervening aliased write changes it to `0xCD`, a subsequent copy reads `0xCD`. Reusing the original saved low byte is not equivalent.

6. **Fourth-argument alias.** Suppose the final argument base is `0x1000` and the retained destination base is `0x1020`, with ordinary address arithmetic and valid accesses. Both the constant store and fourth-argument read address word `0x1074`. With no external modification, the fourth argument is 100. The earlier second-argument snapshot is not replaced by 100.

7. **Linked-destination alias.** If the constant-100 destination exactly matches the link base’s offset-`0x64` word, the subsequent linked read obtains 100 absent external modification. Later stores use that loaded destination value, subject to validity of the resulting addresses.

8. **Interrupted execution.** A nonreturning preparation dependency prevents the suffix from being reached. Failure provides no guaranteed rollback and no guaranteed preservation of prior writes; external restoration is not excluded.
