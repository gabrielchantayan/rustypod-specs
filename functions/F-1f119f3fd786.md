### Value production, separate base reads, and publication

After the final gate returns nonzero, F-unmapped-01 is invoked without explicit arguments. Its result is used as a 32-bit value.

After that dependency returns, the represented access sequence is:

1. Read the shared address-bearing location and retain its value as the saved first base.
2. Read that same location again to obtain the publication destination base.
3. Store the dependency’s 32-bit result at the second base plus 8 bytes.
4. Read the pointer at the saved first base plus 4 bytes.
5. Read the first 32-bit word at the address obtained from that pointer.

This sequence has several contractual consequences:

- Neither base is captured before F-unmapped-01 runs.
- There are two represented reads of the address-bearing location, not one shared capture.
- The store uses the second read; the pointer-chain access uses the first.
- The publication store precedes both pointer-chain reads.
- Saving the first base does not save the contents at that base’s offset +4.
- The two bases are not required to be equal by this body.

If the publication store aliases storage subsequently read through the saved first base, the subsequent reads occur after that store. There is no non-aliasing guarantee.

These are access relationships in the supplied static representation. They do not establish that compiled execution must issue two distinct physical memory transactions under all optimization or concurrency conditions.

## Acceptance examples

These are conditional static acceptance criteria, not executed tests. They assume normal dependency completion and valid accesses unless the example explicitly addresses invalidation.

### Equal base values permit a shared-object interpretation

This example requires equality as a condition. Equality is not a general guarantee.

### Different base values remain distinct

- The publication value is stored at the second base +8.
- The pointer is subsequently read from the first base +4.
- The downstream second argument comes from dereferencing that pointer.

Using the second base for the pointer chain, or the first base for the store, would not match the represented behavior.

### Only exact −1 selects the indirect path

If it returns −1, those two reads are reached. Neither is required to precede the other.

### Downstream mutation can affect target and argument independently
