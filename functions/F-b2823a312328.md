# F-b2823a312328

## Purpose

The visible effect is to place a supplied 32-bit value and a value derived from incoming machine state into two fields of a base-addressed region, then write an incoming 16-bit value through an address obtained from global storage.

This contract distinguishes:

- **Established static evidence:** operations explicitly present in the supplied representation.
- **Inferred intent:** plausible interpretations that are not binding behavior.
- **Documented-only unknowns:** behavior the available evidence cannot determine.

The description of the three writes is conditional on the recovered instruction sequence being accurate and execution reaching it. The supplied warnings materially limit confidence in both reachability and completeness.

### 2. Store a shifted incoming value

The result is represented as the incoming 32-bit machine-state value shifted left by one bit. It is not derived from the second explicit argument, the third explicit argument, or a visible read of either destination field.

The supplied expression does not safely establish all edge behavior:

### 3. Read the global base and perform a two-byte store
