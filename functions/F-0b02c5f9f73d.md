### First byte write: conditional address selection

The first boundary producer supplies an unsigned 32-bit result. Bit 30, selected by mask `0x40000000`, determines the selected intermediate value:

- If bit 30 is set, the intermediate value is the producer result shifted left by two bits.
- If bit 30 is clear, the intermediate value is the entry alternate-address value shifted left by ten bits.

The write address is twice the selected intermediate value. The byte written is the low eight bits of the entry payload value.

After the write, the next dependency receives the selected intermediate value in both explicit argument positions. It does **not** receive the final doubled write address merely because that address was just used.

The branch depends specifically on bit 30. Nonzero status, bit 31, or the sign of an alternative signed interpretation is not an equivalent decision rule.

The doubled address calculation is represented through signed integer arithmetic. Overflow behavior is not established merely because the producer’s initial result was unsigned.

### Second byte write: payload slice

The second boundary producer supplies a 32-bit result.

- The destination address is that result shifted left by three bits.
- The stored byte is obtained by logically shifting the unsigned entry payload value right by 22 bits and retaining the low eight bits.

Thus, the stored byte corresponds to payload bits 22 through 29. Payload bits 30 and 31 are not included.

After the store, the next dependency receives:

1. The producer result multiplied by four.
2. The producer result shifted left by ten bits.

These arguments derive from the same producer result. Neither is specified as a readback from the written memory location.

### Third and fourth byte writes: independent zero stores

Each of the final two write boundaries has its own producer result.

At each boundary:

- The destination address is the current producer result shifted left by three bits.
- Exactly one zero byte is written.
- The next dependency receives the current producer result shifted left by fourteen bits in both explicit argument positions.

The two writes are not established to share an address. Equal destinations are possible only if the respective calculations yield equal addresses.
