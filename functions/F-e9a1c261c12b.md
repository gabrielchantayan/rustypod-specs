## Acceptance examples

These are conditional static consequences, not executed tests.

1. **Initial displacement:** With a fourth argument of zero, the first explicit store places S in the temporary region’s first four bytes. A displacement of 21 extends that store beyond the region. No rejection is visible.

2. **Unsigned halfword-read address:** If S is `0x0080FFFE`, then Q is one. The sign-extended multiplication operands are −2 and two. Their product, plus unsigned two, becomes `0xFFFFFFFE`; logical right shift by eight and addition of `0x38` produce address `0x01000037`, not `0x37`.

3. **Interrupt continuation:** If the interrupt does not resume this execution, the fixed-object assignment associated with `0x34` and all later operations are not reached.

4. **Conditional pair:** A zero result from F-0036 selects F-0037 and F-0038 and changes the retained derived value. A nonzero result skips both. Both paths subsequently attempt the explicit zero stores at addresses zero and four.

5. **Upper-fragment source:** If the separately read upper fragment is `0xABCD` and the lower fragment is `0x1234`, the reset-labelled assignment value is `0xABCD1234`. This does not establish the destination’s previous upper halfword or the assignment access width.

6. **Captured value:** If F-0023 modifies the object that supplied P, the following halfword store still targets captured P plus six.

7. **Double byte store:** If C is three, address `0x300` first receives byte three, then the byte freshly read from 128 times J, provided both accesses are reached.

8. **Invalid access or oversized shift:** An inaccessible zero address can stop execution at the first zero store. A variable shift count of 32 or greater has no selected result under this contract.
