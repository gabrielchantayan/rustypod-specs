# F-78f195f0a104

## Purpose

F-78f195f0a104 selects one of two construction variants, invokes F-793a94891814, and writes a fixed set of fields into the storage returned by that dependency.

The selection depends solely on whether the second input equals zero. The second input is also forwarded unchanged to the dependency; it is not reduced to a Boolean value.

The function then performs thirteen writes at specified byte offsets from the returned address. Eight writes are four bytes wide and obtain their values from external data slots. Five writes are one byte wide and use fixed numeric values.

## Behavior

- **Zero:** select numeric value 13 and read a four-byte value from the external slot associated with the zero case.
- **Nonzero:** select numeric value 14 and read a four-byte value from the external slot associated with the nonzero case.

These two external slots are distinct in the supplied evidence. Their contents are unknown. They could contain equal values; distinct slots do not imply distinct contents.

Only the selected slot is explicitly read by this function before the dependency call. Neither selected value is interpreted locally.

The selected four-byte value is captured before the call. A later modification of that slot by the dependency does not retroactively change the argument already passed.
