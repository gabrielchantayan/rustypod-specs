1. Replace its first 32-bit word with a value read from a global source.
2. Read its second 32-bit word, add the fixed byte displacement 36, and pass the resulting value together with the original input pointer to F-fe320f2fd4e0.
3. If that dependency returns normally, return the original input pointer.

This describes the established local behavior, not a complete object lifecycle. ## Behavior

The previous first-word value is not read by the visible body. It does not participate in the argument calculation or determine whether the dependency is called. There is no local comparison, conditional replacement, or preservation of the old value.

The global value is not identified as an immutable constant. The contract therefore refers to the value obtained by this invocation, not to a fixed numeric value or a value assumed stable across calls.

### Argument derivation

It adds hexadecimal 0x24, decimal 36, to that word. No local dereference through the resulting value is shown. The visible body passes the result to F-fe320f2fd4e0 rather than directly accessing storage at that result.

The expression is presented as word-valued arithmetic. Under a 32-bit unsigned interpretation, addition is modulo 2³²: the low 32 bits are retained, and an overflow carry is discarded. The fragment contains no explicit overflow check, saturation, or error branch.

The first-word replacement precedes this call. The dependency is therefore entered after that local write has occurred. This does not guarantee what the dependency will observe in the presence of concurrent modification, nor does it establish any synchronization mechanism.

2. Store the obtained value at input offset 0.
3. Read the 32-bit word at input offset 4.
4. Invoke F-fe320f2fd4e0 with the derived value and the input pointer.
