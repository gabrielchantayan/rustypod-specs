## Acceptance examples

These are conditional static acceptance cases, not executed tests.

1. **Initial byte truncation.** If B is 0x12345678 and the write is permitted, the first direct byte write places 0x78 at `B + 9`. The read at `B + 52` occurs afterward.

2. **Write/read aliasing.** If I1 is zero, W(I1) and R(I1) both address 20. Absent intervening mutation, the read observes the just-written P.

3. **Double shift.** For every 32-bit E, shifting E right by 23 twice yields zero. Thus the corresponding word write is zero, and the associated selector-source read is at address 1.

4. **Selector truncation.** If H22 is 0x123 and the byte at address 1 is 0x40, the selected byte write places 0x23 at address 0x51.

5. **Distinct selector snapshots.** If dependencies change the byte at address 1 between the separately described reads, later reads can select different destinations. The saved S nevertheless retains its earlier value.

6. **Fresh field reads.** If the word at `T + 116` changes between the two accesses, each write to `T + 1` uses the low byte observed by its own read.

7. **Terminal control transfer.** If every earlier operation completes but address zero is not executable, the static sequence still attempts that call. A normal return must not be invented.

8. **Failure after mutation.** If an intermediate dependency fails to return, earlier writes remain part of the observed prefix. Later writes are not guaranteed.
