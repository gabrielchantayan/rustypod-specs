# F-7a3bf2d0007a

## Purpose

The supplied static representation describes an ordered sequence of indirect calls, byte accesses, and 32-bit writes. It does not establish a reliable application-level purpose.

The visible operations include:

- Writing the third input to two computed locations.
- Reading byte-sized selectors and using their values to address low-memory byte and word locations.
- Clearing several computed words and repeatedly clearing the word at address `0x24`.
- Storing values derived from the first input and from dependency results.
- Ending at an explicitly marked invalid-instruction boundary, without a visible normal return.

An initialization or configuration role is plausible, but remains inferred intent. The contract below describes the visible accesses and their ordering, not an inferred object model, hardware protocol, or successful initialization outcome.

## Acceptance examples

These are conditional static acceptance examples, not executed tests. Each assumes valid accesses and returning dependencies.

1. **Zero first input.** P, Q, T, M, and H are zero. The second write of the third input targets `0x24`; a later explicit zero write can overwrite it. The first input-derived selector reads use address `1`.

2. **Input-bit truncation.** If A is `0xffffffff`, the first selector-byte value is `0xff`, not the full shifted value `0x3ff`.

3. **Fresh selector reads.** If the first read at P plus one yields `0x10` and the second yields `0x20`, the initial byte update targets `0x21`, while the later clear targets `0x31`. Reusing the first selector would contradict the visible behavior.

4. **Saved selector reuse.** If B is `0x30`, the later word clear targets `0x74`, even if an intervening dependency changes the byte at T plus one.

5. **Retained linked value.** If L is three, V is twelve. A subsequent result of five selects address `0x28`, but the stored word remains twelve.

6. **Split result.** If the represented 64-bit result has low half three and high half five, F-C13 receives twelve. The following computed word clear targets `0x4e`. Whether that unaligned access is supported is not established.

7. **Final byte truncation.** If Z is `0x12345678`, its low-byte-times-four write stores `0xe0`. Its later masked-and-shifted byte write stores `0x23`.

8. **Interrupted execution.** If a dependency does not return, no later visible write is required to occur. Earlier writes are not specified to be undone.
