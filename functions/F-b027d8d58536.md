# F-b027d8d58536

## Purpose

F-b027d8d58536 performs a fixed sequence of external calls, computed-address memory accesses, data transfers, and global-state updates. Its visible body has no conditional branches or loops. Completion depends on every preceding call returning and every reached memory operation completing.

The supplied static representation establishes an operational contract, not an application-level purpose. It does not establish an object model, device protocol, or meaning for the small computed addresses.

This specification distinguishes:

- **Established static evidence:** represented accesses, widths, calculations, and ordering.
- **Inferred intent:** possible interpretations that are not acceptance requirements.
- **documented_only:** unresolved behavior requiring dependency contracts, execution-platform information, or lower-level evidence.

No runtime tests have been performed.

The represented interface accepts three 32-bit arguments.

| Argument | Direct use |
|---|---|

## Behavior

The following phases specify execution order. A call with “no represented arguments” has no explicit arguments in the supplied representation; it is not guaranteed to receive no meaningful machine-register inputs.

### 1. Initial calls and first word transfer

The initial target is the incoming return-link value plus 0xF38. It receives the first explicit argument.

A result-producing call follows, then a call consuming that 32-bit result. Three calls with no represented arguments follow. Another call produces an index-like result.

The function then:

1. Writes the third argument logically shifted right by 23 at four times that index plus 0x14, using a 32-bit write.
2. Reads a 32-bit word at context A logically shifted right by 22, plus 0x14.
3. Passes four times the index to a call.
4. Makes four calls with no represented arguments.

The write precedes the read. If their storage overlaps, the read can observe the write.

### 2. First selector-based byte update

Two quantities are retained: context B logically shifted right by 22, and the previously read word logically shifted right by 22.

The function reads an unsigned byte at context B plus one. It writes the low byte of the shifted word at the selector byte plus 0x11. The destination therefore lies from 0x11 through 0x110 inclusive.

A call receives three copies of a secondary-register value followed by shifted context B. The provenance of that secondary-register value is not established.

After one call with no represented arguments, another receives shifted context B logically shifted right by a further 23 bits. This argument is necessarily zero: the preceding 22-bit shift leaves at most ten significant bits.

Three calls with no represented arguments follow, then another call produces an index-like result.

### 3. Initial zeroing and retained secondary value

The function reads a selector byte at four times the shifted word, plus one, and writes zero at that selector plus 0x11. It then passes the newly produced index shifted left by two to a call.

Three calls with no represented arguments follow. Another produces a result, and the next receives two copies of that result shifted left by two.

A further call produces a 32-bit value. The next receives that value unchanged, followed by a call with no represented arguments.

Context B’s sign selects the next byte-read address:

- Address 1 for a nonnegative signed interpretation.
- Address 2 for a negative signed interpretation.

The selected byte is read, and zero is written at its value plus 0x11.

A secondary-register value is retained for later shifts. A call receives three copies of it. Another call produces a 32-bit result; the next receives that result and the earlier 32-bit value logically shifted right by 23.

### 4. Repeated selector access and first control-slot write

Three calls with no represented arguments precede another index-producing call.

The sign-selected byte at address 1 or 2 is read again. Zero is written at its value plus 0x11, and this newly read selector is retained. This is a fresh access, not reuse of the earlier selector. Intervening calls may have changed its contents.

The index shifted left by two is passed to a call. After three calls with no represented arguments, another result is produced, and the following call receives two copies of that result shifted left by two.

A subsequent call produces a 32-bit value. The function stores it in the control slot, passes the same retained value to the next call, and then makes a call with no represented arguments.

### 5. Word-to-byte transfers and routing retention

Using the retained selector from phase 4, the function reads a 32-bit word at selector plus 0x74 and writes its low byte at selector plus one.

A call receives the retained secondary-register value shifted left by 11. The next produces a 64-bit result. A following call receives:

1. Its low 32-bit half.
2. Its high 32-bit half.
3. The retained value previously written to the control slot, logically shifted right by 23.

The third argument is not a fresh control-slot read.

After three calls with no represented arguments, an index-producing call supplies a value whose four-times scaling is retained as a byte-address base. A word at base plus 0x74 is read, and its low byte is written at base plus one. The base is then passed to a call.

Three calls with no represented arguments precede another index-producing call. This new index shifted left by two becomes the **scaled routing value**.

The word-to-byte transfer at the preceding base is repeated, including a fresh full-width source read. The next call receives:

- The retained secondary-register value shifted left by 12.
- Two copies of the scaled routing value.
- The new index shifted left by 18.

The two transfers at the same base remain separately observable across the intervening calls.

### 6. Saved-word propagation

Two successive result-producing/result-consuming call pairs occur. Three calls with no represented arguments follow, then another index-producing call.

A 32-bit word at four times that index plus 0x74 is read and retained as the **saved word**. Its low byte is written at four times the index plus one. Four times the index is passed to a call.

After three calls with no represented arguments, another index is produced. The saved word is written at sixteen times that index plus 0x14.

The next call receives the scaled routing value logically shifted right by two and then shifted left by 16. Under 32-bit bit-vector semantics, the right shift does not recover high bits discarded when the scaled routing value was formed.

Two more result-producing/result-consuming pairs occur. After three calls with no represented arguments, an index-producing call supplies the destination for a saved-word write at four times the index plus 0x14. Four times that index is then passed to a call.

### 7. Routing write and zero-word write

Three calls with no represented arguments precede another index-producing call.

That index shifted left by two is written as a 32-bit word at the scaled routing value with its low two bits cleared, plus 0x14. Under 32-bit bit-vector semantics, those low bits were already cleared by the earlier left shift; the mask does not restore discarded high bits.

The following call receives two copies of the written shifted index.

Two result-producing/result-consuming pairs follow, then three calls with no represented arguments. A further call produces an index. A 32-bit zero is written at four times that index plus 0x14, and four times the index is passed to the next call.

### 8. Split-result routing and auxiliary snapshot

Three calls with no represented arguments precede a 64-bit-result call.

The low half shifted left by two is written as a 32-bit word at four times the high half plus 0x14. Only after this write does the function read the auxiliary slot, retaining its 32-bit value as an address base.

The next call receives the shifted low half, the high half, and two further copies of the shifted low half.

After three calls with no represented arguments, another index is produced. The shifted low half is written at four times that index plus 0x14.

A 32-bit word is then read at the retained auxiliary base plus 0x14 and retained as the **auxiliary word**. The auxiliary slot is not reread to obtain this base.

Four times the index is passed to a call. Three calls with no represented arguments follow, then another 64-bit-result call.

### 9. Final selector-based byte updates

The last 64-bit result’s low half becomes the **final routing word**.

The function reads a selector byte at the saved word logically shifted right by 23, plus one. It writes the auxiliary word’s low byte at selector plus 0x11.

A call receives three copies of the last 64-bit result’s high half and the final routing word shifted left by two.

A result-producing/result-consuming pair follows. After three calls with no represented arguments, another index is produced.

The next selector byte is read at the final routing word masked to 30 bits, logically shifted right by 21, plus one. The low byte of the auxiliary word logically shifted right by 22 is written at selector plus 0x11.

The index shifted left by two is passed to a call. Three calls with no represented arguments precede another index-producing call. The following call receives two copies of that index shifted left by two.

### 10. Terminal effects

One call with no represented arguments occurs, followed by a result-producing call, a call consuming that result, and a call producing an 8-bit result.

The terminal sequence is:

1. Write an 8-bit zero through a secondary-register pointer.
2. Read the represented 24-bit global operand.
3. Combine that operand as the upper 24 bits with the retained 8-bit call result as the low byte.
4. Write the resulting 32-bit value to the control slot.
5. Write a 16-bit zero at the final routing word masked to 30 bits and logically shifted right by seven.
6. Invoke address zero with three explicit zero arguments.

The 24-bit operand is read after the pointer store. The pointer may alias its storage, so a value captured before that store is not equivalent.

This establishes one represented 24-bit operand, not three separately referenced bytes. It does not establish separate byte reads, byte-read ordering, atomicity, or a particular machine-load implementation.

## Side effects

Direct effects comprise the ordered memory accesses above and two explicit control-slot writes. The later write is not guaranteed to be the final stored value: subsequent accesses, aliasing, or the terminal dependency may modify overlapping storage.

Dependencies may independently access memory, modify globals, allocate or release storage, fault, or transfer control. No preservation guarantees are supplied.

Consequences include:

- Retained scalar values differ from subsequent reads of their original storage.
- Repeated reads cannot be collapsed across calls.
- The auxiliary-slot snapshot occurs after the preceding routed word write, which may alias it.
- The terminal pointer store may affect the subsequently read 24-bit operand.
- The terminal halfword write may overlap control storage or other previously accessed storage.
- Earlier completed effects are not rolled back if execution stops.

No explicit allocation or release operation is identified. Neither borrowing nor ownership transfer is established for numeric arguments interpreted as addresses.

Endianness is unknown. Numeric low-byte extraction and the upper-24/lower-8 composition are nevertheless represented explicitly.

## Acceptance examples

These are conditional static examples, not observed executions. They assume all preceding calls and accesses complete.

1. **Third-argument extraction.** A third argument of 0xFFFFFFFF produces a first stored word of 0x000001FF. A value below 0x00800000 produces zero.

2. **First selector update.** If the initial read word is 0xABCDEF12, shifting right by 22 produces 0x2AF. A selector byte of 0x20 therefore causes byte 0xAF to be written at address 0x31.

3. **Forced-zero argument.** Every 32-bit context B produces zero when logically shifted right first by 22 and then by 23.

4. **Sign selection and fresh reads.** Context B of 0x7FFFFFFF selects address 1; 0x80000000 selects address 2. If successive reads of the selected address yield 0x20 and 0x30, the corresponding zero stores target 0x31 and 0x41.

5. **Full-width transfer.** A word read yielding numeric value 0x12345678 causes byte 0x78 to be written. Availability of only one readable source byte does not satisfy the represented four-byte read.

6. **Distinct destination scaling.** Index 3 selects address 0x44 for the sixteen-times-index saved-word write, but address 0x20 for a four-times-index write.

7. **Terminal composition.** If the retained 8-bit result is 0x5A and the 24-bit operand read after the pointer-zero store is 0xA1B2C3, the control-slot write is 0xA1B2C35A.

8. **Aliasing-sensitive operand read.** Suppose the pointer-zero store changes the operand from a prior value to a post-store numeric value of 0x123400. With retained result 0xA5, the composition is 0x123400A5. Reusing the prior operand value would violate the represented ordering. This example assumes the stated post-store value; it does not prescribe endianness.

9. **Potentially unaligned halfword.** Final routing word 0xC0000180 yields halfword destination 3 after masking and shifting. No alignment correction appears.

10. **Partial terminal execution.** A failure reading the 24-bit operand can occur after the pointer-zero store but before the control-slot write. A failure in the later halfword write prevents asserting that the address-zero call occurred.
