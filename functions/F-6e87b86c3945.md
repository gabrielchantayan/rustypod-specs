## Acceptance examples

These examples are conditional static acceptance criteria, not executed tests.

1. **Byte truncation.** If entry base is 0x12345678 and the first byte store is reached, it writes 0x78 at address 0x12345681.

2. **Scaled versus unscaled addressing.** If first index is 8, the entry-payload store targets address 52, while the following word read targets address 28. Treating both as one field location is incorrect.

3. **Double extraction becomes zero.** If the sampled global A value is 0xffffffff, first extraction is 511 and its subsequent right shift by 23 is zero. The later byte-source address derived from that result is 1.

4. **Low-byte projection after extraction.** If selected word is 0xffffffff, selected field is 1,023. Its byte write stores 255, not the full 10-bit value.

5. **Distinct propagation strides.** If the result selecting the 16-stride destination is 3, captured word is written at address 68. A four-stride interpretation would incorrectly select address 32.

6. **Fresh refresh read.** If a dependency changes the word at refresh base plus 116 between the two refresh operations, the second byte write reflects the changed word’s low byte.

7. **Partial completion.** If a dependency fails after global B receives published word, the earlier global write is not visibly undone.

8. **Final global assembly.** If the neighboring 24-bit value at final assembly is 0xabcdef and the returned byte is 0x12, the assembled 32-bit value is 0xabcdef12.

9. **Final transfer.** If address zero is not callable, normal return is not an acceptance expectation. The visible behavior is an attempted call after the preceding stores, subject to earlier accesses succeeding.
