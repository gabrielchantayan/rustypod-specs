# F-78f47041b452

## Purpose

F-78f47041b452 constructs a 32-bit word from a tagged descriptor and appends it through a destination context. It recognizes descriptor tags 2, 15, 16, and 17. Any other tag causes a return without invoking dependencies or writing output.

The word combines descriptor-derived values, an operation selector, and a variant-dependent contribution. A zero variant selector chooses one encoding; every nonzero selector chooses the other.

**Inferred intent:** the layouts and bit patterns resemble instruction encoding. No instruction-set interpretation is required by this contract.

**Established limitation:** tag 16 with a nonzero variant selector reads a 32-bit global data location whose contents are not supplied. Its output depends on the value actually read after the branch’s transformation dependency returns, not on an assumed constant or entry-time snapshot.

## Interface

The function accepts four 32-bit arguments and has no explicit return value.

| Argument | Role |
|---|---|
| Destination owner | Address of an object containing the append-context reference |
| Descriptor | Address of the tagged input structure |
| Operation selector | Supplies a contribution shifted left by 21 bits |
| Variant selector | Selects zero versus nonzero behavior |

There is no returned word, success flag, or appended-byte count. Output is observable through the mapped destination and the context’s position field.

### Descriptor layout

All offsets are byte offsets from the descriptor address.

| Offset | Width read | Use |
|---|---:|---|
| 8 | 8 bits | Dispatch tag |
| 12 | 32 bits | Reference chain supplying a common byte |
| 20 | 32 bits | Reference chain supplying another common byte |
| 24 | 32 bits | Reference for tags 2, 16, and 17; raw value for tag 15 |
| 28 | 32 bits | Reference for tag 16; integer amount for tag 17 |
| 32 | 8 bits | Argument to F-6ba458b31a69 for tags 16 and 17 |

A referenced byte is obtained through three dependent reads:

1. A 32-bit reference from the relevant descriptor field.
2. A 32-bit reference at offset 8 from that referenced object.
3. An unsigned byte at offset 12 from the second referenced object.

The following names describe values obtained by those reads:

- **A:** byte reached through descriptor offset 12.
- **B:** byte reached through descriptor offset 20.
- **R:** byte reached through descriptor offset 24.
- **S:** byte reached through descriptor offset 28, only when that field is used as a reference.

These names do not imply that the descriptor or referenced objects are snapshotted at entry.

### Destination and global state

The destination owner contains a 32-bit append-context reference at offset 16.

The append context contains a 32-bit position field at offset 2052, hexadecimal `0x804`. This field is read for destination mapping and read again before being increased by four.

A separate 32-bit global data location is read only for tag 16 with a nonzero variant selector. **K** denotes the value obtained by that read. K is not specified as an immutable constant.

### Preconditions

Every memory access on the selected path must be valid. Supported paths require accessible reference chains, an accessible destination-owner field and context, and a mapping result that permits a 32-bit store. Tag 16’s nonzero path additionally requires the global data location to be readable.

The function performs no local validation of:

- Null, invalid, or misaligned references.
- Descriptor extent.
- Operand-byte or operation-selector ranges.
- Destination capacity.
- Mapping failure.
- Position arithmetic overflow.

An unsupported tag requires only the tag byte to be readable; it does not require the remaining descriptor fields or destination owner to be accessible.

## Behavior

### Construction and arithmetic rules

All word contributions are combined by bitwise OR, not addition. Overlapping bits are retained without validation or normalization.

Referenced operand bytes are zero-extended from eight bits. Except where explicitly masked, their full byte values participate:

| Contribution | Placement |
|---|---|
| A | Shifted left by 12 |
| B | Shifted left by 16 |
| Operation selector | Shifted left by 21 |

A and B are not restricted to four bits. Their contributions can overlap each other, the operation contribution, or the branch-specific base.

The operation selector is not masked before its shift. The supplied representation uses a signed integer input for this shift; behavior for negative values or signed left-shift overflow is not independently established. Numeric examples below avoid those cases.

Word formulas describe 32-bit contributions. This does not establish that all signed arithmetic in the representation wraps modulo \(2^{32}\).

### Dispatch

The first access is the one-byte tag read at descriptor offset 8.

| Tag | Selected form |
|---:|---|
| 2 | Direct referenced byte |
| 15 | Transformed immediate-like value |
| 16 | Referenced shift operand |
| 17 | Integer shift amount |
| Other | Immediate return |

The recognized tag values are the same whether the initial byte is interpreted as signed or unsigned. The tag is not reread after a dependency call.

### Tag 2: direct referenced byte

The function obtains R before selecting the variant-specific base.

The word is the bitwise OR of R, the common A and B contributions, the operation contribution, and:

- `0xE0000000` for a zero variant selector.
- `0xE0100000` for a nonzero variant selector.

No transformation dependency is called. The global location supplying K is not read.

The independent A and B reference chains occur during subsequent word construction. Their relative evaluation order is not established.

### Tag 15: transformed immediate-like value

The function reads the 32-bit value at descriptor offset 24 and calls F-4f304cbf4c44 with that value. Let **H** denote the 32-bit result.

After the dependency returns, descriptor offset 24 is read again. Let **V** denote this later value, interpreted as signed for the represented right shift.

The effective shift count is the low five bits of the 32-bit unsigned difference between 32 and H. It is therefore in the range 0 through 31. In particular, H equal to zero gives a zero-bit shift.

The word combines:

- The low eight bits of V after the signed right shift by that count.
- H masked with `0x1E`, then shifted left by 7.
- The common A and B contributions.
- The operation contribution.
- `0xE2000000` for a zero variant selector, or `0xE2100000` otherwise.

The dependency’s argument and V come from distinct reads. A dependency-induced change to descriptor offset 24 can therefore affect V without changing the argument already delivered to the dependency.

A and B are also read after the dependency returns. The relative order among the independent reads within this construction expression is not established.

The representation identifies a signed right shift, but does not independently establish target behavior for negative V. The global location supplying K is not read on this path.

**Inferred intent:** the dependency result appears to describe a transformed immediate encoding. Its actual transformation and valid input domain remain unknown.

### Tag 16: referenced shift operand

The function reads the byte at descriptor offset 32 and calls F-6ba458b31a69 with that eight-bit value.

Let **T** be the low two bits of the dependency’s result. After the call returns, the function constructs the word from:

- R.
- T shifted left by 5.
- S shifted left by 8.
- The common A and B contributions.
- The operation contribution.
- The variant-specific contribution described below.

For a zero variant selector, the additional contribution is `0xE0000010`. The global location supplying K is not read.

For a nonzero variant selector, the additional contribution is **K**, obtained by a 32-bit read from the global data location.

The ordering of that global read is part of the contract:

- It occurs after F-6ba458b31a69 returns.
- It occurs during word construction, before the destination owner’s append-context reference is read.
- Its order relative to the independent R, S, A, and B reads within the same compound expression is not established.

F-6ba458b31a69 may change the global location. K must therefore mean the post-call value actually read, not its value at function entry. No supplied evidence establishes that this global is constant or that successive invocations observe the same value.

K participates in the same bitwise OR as the other contributions. Its bits may overlap or subsume them. The exact nonzero-variant word remains **documented_only** unless the value observed by this read is known.

### Tag 17: integer shift amount

The function reads the byte at descriptor offset 32 and calls F-6ba458b31a69.

After the call returns:

- R is obtained through descriptor offset 24.
- The 32-bit integer at descriptor offset 28 is read and masked to its low five bits. Call this masked value **N**.
- The low two bits of the dependency result supply T.

The initial operand contribution combines R, T shifted left by 5, and N shifted left by 7.

The function subsequently adds, by bitwise OR, the common A and B contributions, the operation contribution, and:

- `0xE0000000` for a zero variant selector.
- `0xE0100000` for a nonzero variant selector.

The R and integer-amount reads precede the subsequent common A and B construction stage. No relative order between R and the integer-amount read is established.

Only the low five bits of the integer amount affect the word. R, A, and B retain their full unsigned-byte widths. The global location supplying K is not read.

### Common append sequence

For each supported tag, word construction completes before the append sequence begins.

The observable sequence is:

1. Read the append-context reference from destination-owner offset 16.
2. Call F-fce07581564d with that saved reference and the size value 4.
3. Read the saved context’s 32-bit position field.
4. Call F-7102092276c8 with the saved context and the position just read.
5. Store the constructed word through the returned address as one 32-bit write.
6. Read the saved context’s position field again.
7. Add four to this later value and write the result back to that field.
8. Return.

The destination-owner field is not reread between the dependency calls. Changing it does not replace the saved context reference used by the remaining sequence.

The position passed to the mapper is read after F-fce07581564d returns. The position used for the final increment is read after F-7102092276c8 returns and after the output store. Consequently, the final position need not equal the mapped position plus four.

The final increment is represented as signed integer addition. Defined overflow or wraparound behavior is not established.

The word is not recomputed after either append dependency. This also means that a later change to the global supplying K does not alter the already-constructed word.

## Side effects

### Direct reads and writes

On a supported path that completes normally, the function performs two direct writes:

- One 32-bit output-word store.
- One 32-bit position update, after the output store.

There is no direct descriptor write or global-data write. Nevertheless, the output address may alias other state:

- If it aliases the position field, the stored word becomes the value subsequently read for the increment.
- If it aliases descriptor or global memory, that memory is modified by the output store.
- Such aliasing does not trigger word reconstruction.

Only tag 16 with a nonzero variant selector directly reads the global location supplying K. Reads of that location on other paths are not part of this function’s established behavior; opaque dependencies may independently access global state.

No byte-order conversion is visible. The output is a native 32-bit store; its byte sequence depends on target endianness.

### Ownership and dependency effects

Existing references are passed to dependencies, and the function writes through a returned address. No ownership transfer or release obligation is established.

Dependencies must not be assumed to preserve the descriptor, context, global state, or referenced objects. In particular, F-6ba458b31a69 may alter the global later read as K.

The evidence does not establish whether dependencies allocate, relocate, retain, or release memory. No explicit release operation appears in this function.

### Errors and partial completion

There is no local error return, recovery branch, or rollback.

A dependency that does not return prevents subsequent actions. Invalid references, an unusable mapping result, or a failing store have no established local recovery behavior.

The output store and position update are separate actions. No atomicity, transactional behavior, or synchronization guarantee is established.

## Acceptance examples

These are conditional static expectations, not runtime observations. Unless stated otherwise, dependencies return normally, relevant memory remains unchanged, addresses are valid, and output storage does not alias the position field.

### Unsupported tag

With tag 3, the function reads the tag and returns. It makes no dependency calls, reads no append-context reference or K global, and performs no direct writes.

### Direct form

For tag 2, R = 3, A = 1, B = 2, and operation selector zero:

- Variant zero produces `0xE0021003`.
- Any nonzero variant produces `0xE0121003`.

If both append dependencies leave position 100 unchanged, the mapper receives 100 and the final position is 104.

### Repeated immediate read

For tag 15, A and B zero, operation selector zero, H = 0, and the later descriptor-offset-24 read equal to `0x000000AB`:

- The effective shift count is zero.
- Variant zero produces `0xE20000AB`.
- A nonzero variant produces `0xE21000AB`.

The earlier value passed to F-4f304cbf4c44 need not equal `0x000000AB`.

### Referenced shift operand

For tag 16, R = 3, S = 4, A = 1, B = 2, operation selector zero, and T = 2:

- Variant zero produces `0xE0021453`, without reading the K global.
- A nonzero variant produces K OR `0x00021443`.

No unconditional numeric output is established for the second case.

### Global changed by the transformation dependency

Use the preceding tag-16 operands with a nonzero variant selector. Suppose the global contains `0xE0000010` at entry, but F-6ba458b31a69 changes it to `0xE0100010` before returning.

If it remains unchanged until the function’s global read, K is `0xE0100010`, and the word is `0xE0121453`. The entry value must not be substituted.

If an append dependency changes that global afterward, the already-constructed word remains `0xE0121453`.

### Masked integer amount

For tag 17, variant zero, operation selector zero, R = 3, A = 1, B = 2, T = 2, and descriptor offset 28 containing 33:

- N is 1.
- The word is `0xE00210C3`.

Replacing 33 with 1 produces the same word under otherwise identical conditions.

### Position changed during append

If F-fce07581564d changes the position to 200, the mapper receives 200. If F-7102092276c8 then changes it to 300 and the output store does not alter that field, the final position becomes 304.
