### Evaluation and update order

The first decision checks for membership. Within that decision, comparisons appear in this order:

1. Equality with 32.
2. Equality with 9, if the preceding comparison did not match.
3. Equality with 13, if neither preceding comparison matched.
4. Equality with 10, if no preceding comparison matched.
