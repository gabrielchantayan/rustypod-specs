# F-2b86f305a556

The established behavior is a lookup, not a calculation over the returned value. The function obtains an intermediate address-bearing value from a location four bytes beyond a global-derived base, then obtains its result from a location 60 bytes beyond that intermediate value.

## Behavior

### Lookup sequence

The function evaluates the global-derived root value and uses it to locate the first indirect read.

1. The first explicit indirect read begins four bytes beyond the root value. It obtains the intermediate value.
2. The intermediate value is used as an address base. The second explicit indirect read begins 60 bytes beyond that base.
3. The four-byte value obtained by the second read is returned without an established transformation.

Both offsets are byte offsets. Four is not an element count, and 60 is not a count of words.

The second read depends on the result of the first. It is therefore not an independent lookup from the original root. In particular, this behavior is not equivalent to reading directly 64 bytes beyond the root.

This establishes a data-dependent lookup sequence. It does not establish hardware memory barriers, atomic snapshot semantics, or synchronization with concurrent writers.
