2. Read the record address from `0x194` again. Read the signed four-byte value at record offset `0x05C`, add one, and write the result at object offset `0x174`.

4. Read the signed four-byte value at `0x174`, shift it left by four bits, and write the result at `0x17C`.

5. Read the signed four-byte value at `0x178`, shift it left by four bits, and write the result at `0x180`.

7. Read the signed four-byte value at `0x17C` again, divide it by two using signed integer division, and write the result at `0x184`. Signed division truncates toward zero.

9. Read the four-byte value at `0x02C` again and invoke F-16a7b9c2ce97 with two arguments: zero, followed by that four-byte value.
