# F-c70776c346eb

- Right shifts introduce zero bits.
- Bits shifted beyond the 32-bit result width are discarded.

**Offsets 0, 4, 8, 12, 16, 36, 20, and 24.**

### 16-bit transformation

### Little-endian interpretation

- The write at offset 30 reverses the original bytes at offsets 30–31.

- The subsequent write at offset 30 reverses those same original bytes in place.
