### 2. Allocate and initialize the object

The returned pointer is used immediately. Before any visible null check, the function performs these operations in order:

1. Store a 32-bit zero at object offset 0.
2. Store a 32-bit zero at object offset 4.
3. Store a 32-bit zero at object offset 8.
4. Call F-b00260d1087a with the address at offset 12.

## Acceptance examples

These are conditional static acceptance scenarios, not reports of executed tests.

If an unusual environment permits the preceding accesses and dependencies to complete with that pointer value, the later null branch skips submission, finalizes Context B and then Context A, and returns zero.
