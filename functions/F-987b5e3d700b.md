# F-987b5e3d700b

## Purpose

F-987b5e3d700b conditionally updates a shared word. When its third argument is zero, it returns without accessing the shared state shown in the supplied representation. Otherwise, it replaces bits 4–10 of a destination word with the low seven bits of its second argument. All other destination bits are retained only where a separately read mask word permits them.

This is not simply a seven-bit field replacement: the mask word can also clear destination bits outside the replaced field. It cannot set those outside bits.

The established behavior is a conditional, masked state update. Interpreting the destination as a hardware register, or assigning a device-specific meaning to the field, would be inferred intent rather than established evidence.

## Behavior

### Disabled invocation

The third argument is examined before the shared-state update.

When it equals zero:

- The function returns.
- The destination word is not read or written by the represented body.
- The mask word is not read by the represented body.
- Neither the first nor the second argument changes this outcome.

This is a complete early exit, not a write of the destination’s existing value. Any external observer sensitive to accesses must therefore distinguish this case from an enabled invocation whose computed value happens to equal the previous destination value.

### Enabled invocation

When the third argument is nonzero, the function evaluates an update using the destination word and mask word, then assigns the resulting value to the destination.

The supplied expression establishes that both input values contribute to the assigned result. It does **not** establish which of the destination read and mask read occurs first. It also does not establish a coherent snapshot if another execution context can modify either location between those reads.

The numerical transformation is:

- Bits 4–10 of the destination’s contribution are cleared.
- The low seven bits of the second argument are placed into bits 4–10.
- Every bit outside bits 4–10 is the logical AND of the corresponding bits read from the destination and mask.

The explicit fixed mask is `0xFFFFF80F`. It has zeros precisely at bits 4–10 and ones at bits 0–3 and 11–31.

Consequently, the output layout is:

| Destination bit range | Assigned value |
|---|---|
| 0–3 | Previous destination bits AND corresponding mask bits |
| 4–10 | Second-argument bits 0–6, respectively |
| 11–31 | Previous destination bits AND corresponding mask bits |

The mask word has no effect on the assigned values of bits 4–10. Even when those mask bits are zero, the second argument can set the corresponding destination-field bits.

Outside that field:

- A zero destination bit remains zero.
- A one destination bit survives only if its mask bit is one.
- A zero mask bit forces the assigned destination bit to zero.

The second argument cannot set any destination bit outside bits 4–10.

### Width and arithmetic boundaries
