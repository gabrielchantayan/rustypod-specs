### Fixed-input ordering

If the final computed constant store changes storage supplying B through aliasing, the B read must obtain the post-store value. That read still precedes the fixed word write at 0x60.

### Reloaded fixed byte

### Narrowing and widening

A byte write supplied with 0x12345678 stores 0x78. An unsigned byte read returning 0xE1 supplies word value 0x000000E1 when widened, not 0xFFFFFFE1.

### Intermediate effects

Observable storage at C + 0x20 must receive 0x20, 0x2F, the freshly read byte widened to a word, and 0x20 in order. A single final store is not trace-equivalent.

### Captured dispatch state

### Invalid access
