### Evaluation order

The supplied body establishes a descending search. Bit 7 is considered first, followed by bits 6 through 0. The function returns immediately upon finding a set bit.

This ordering determines precedence when multiple bits are set. A set bit at position 7 wins over every lower bit; position 6 wins when position 7 is clear, and so on. Lower positions are not examined after a match.

If all eight positions are clear, the search reaches a terminal state with a zero-valued selection mask and a candidate result of −1. The zero-mask match check cannot succeed. The terminal condition then ends the search, and −1 is returned.

That final state matters to the boundary behavior: the all-clear case is not reported as position 0. The function has already passed the bit-0 check before producing the negative sentinel.
