# F-75c66772c9ce

## Purpose

The supplied static representation describes a sequence of indirect calls, byte-addressed state updates, word transfers, and transformations of 32-bit values. It does not establish a reliable application-level purpose.

The observable work includes:

- Reading byte selectors and using them to address a small, low-address byte region.
- Copying the low eight bits of 32-bit words into byte fields.
- Writing scaled or masked values into word fields at computed addresses.
- Passing transformed inputs and dependency results to further indirect calls.
- Writing the absolute byte locations `0x0D` and `0x11`.
- Reaching an explicitly truncated terminal boundary rather than an established normal return.

The contract below is conditional on the supplied operations accurately representing executable behavior. The source data explicitly reports invalid instruction data and truncated control flow. Consequently, this document specifies the represented prefix, not a proven complete function.

## Acceptance examples

These examples are conditional static checks, not executed tests.

1. **Selector destination width.** If a selector read returns `0xFF`, its corresponding write targets `0x110`, not an address obtained by eight-bit wrapping of the addition.

2. **Low-byte transfer.** If a word read at a relevant base plus `0x74` yields `0x123456AB`, the corresponding byte write stores `0xAB`. This does not establish target byte order.

3. **Changed selector across calls.** If the byte used by an initial selector write is `3`, and intervening dependencies change it to `9`, a later selector write that rereads it targets `0x1A`, not `0x14`.

4. **Input scaling wrap.** Under the 32-bit bit-vector interpretation, input `0x2000` produces zero for input multiplied by \(2^{19}\), and zero for the masked 13-bit field shifted left 17. This example requires the resulting low-address accesses to be valid.

5. **Descriptor truncation.** If descriptor word is `0xFFFFFFFF`, the repeated masked argument is `0x3FE00000`, while the later stored value is `0xFF800000`. Preserving a tenth shifted bit in a wider destination would not match the represented 32-bit store.

6. **Distinct absolute-byte stores.** If execution reaches both writes to absolute `0x0D`, the earlier write stores final selector and the later write stores `0xC0`. They must not be collapsed into a single effect when intervening calls can observe memory.

7. **Aliasing.** If two computed destinations coincide, their stores occur in the specified order. No non-aliasing precondition is established.

8. **Nonreturning dependency.** If a dependency fails to return, subsequent represented operations are not required to occur. The body provides no local recovery path.
