# F-38db3e9c0785

## Purpose

F-38db3e9c0785 classifies an unsigned word by the position of its most significant set bit. For a nonzero 32-bit input, the result is the number of zero bits preceding that bit when the word is viewed from bit 31 toward bit 0.

Zero is a special boundary case: the result is **31**, not 32. Consequently, zero and one produce the same result. The function must not be specified as an unrestricted, conventional 32-bit leading-zero count without documenting this difference.

The established behavior is a pure numerical mapping in the supplied source representation. There is no evidence of validation, error reporting, allocation, external calls, or persistent state changes.

## Behavior

### Numerical classification

For nonzero inputs, only the position of the highest set bit affects the answer. All less significant bits are irrelevant to the result.

Examples of the resulting classes are:

- Every word with bit 31 set returns 0.
- Every word whose highest set bit is bit 30 returns 1.
- Every word whose highest set bit is bit 16 returns 15.
- Every word whose highest set bit is bit 8 returns 23.
- Every word whose highest set bit is bit 1 returns 30.
- The word with only bit 0 set returns 31.
- The all-zero word also returns 31.

Thus, each nonzero magnitude interval bounded by consecutive powers of two maps to one result. This is not a population count: setting or clearing lower bits does not change the answer while the highest set bit remains unchanged.

### Zero behavior

Zero completes normally and returns 31. There is no separate error indication or exceptional path for this input.

A consumer cannot distinguish zero from one using the return value alone. A consumer that requires a conventional leading-zero count of 32 for zero must handle that requirement outside this function. Such handling is not present in the supplied behavior.

### Boundary behavior

At each power-of-two boundary above one, the result decreases by exactly one. Immediately below that boundary, the previous classification still applies.

For example:

- 255 returns 24.
- 256 returns 23.
- 257 also returns 23.

The transition from zero to one is different: both return 31. The transition from one to two then decreases the result to 30.

Across the unsigned 32-bit domain, the mapping is nonincreasing as the input value increases. It is not strictly decreasing because many inputs share each classification.
