# F-760ad8c87cc2

## Purpose

F-760ad8c87cc2 processes a 32-bit request against a caller-supplied object. An object byte selects between:

- A short path that records the request and returns.
- A processing path that records an option byte, resolves the request, invokes dependencies, prepares temporary storage, optionally invokes an operation, and then records the request.

The optional operation can receive a 16-bit value read from the object. Its address is determined by reading a displacement global during that invocation, after a context-provider call. This displacement is not a fixed layout offset whose value is merely absent from the evidence.

These are structural descriptions. The domain meanings of the request, object fields, dependency results, and optional operation are not established.

This contract describes static evidence and separates it from inferred intent and unresolved behavior. No runtime tests have been performed.

## Behavior

### Initial selection and short path

The first direct object access reads the byte at `+0x104`.

If it is nonzero, the function writes the request to the 32-bit field at `+0xFC` and returns. All nonzero byte values select this same path.

On this path:

- No option-byte write occurs.
- No dependency is called.
- No context or displacement global is read.
- No temporary storage is passed to a dependency.
- Neither integer selector affects the result.

### Processing-path setup and resolution

If the initial byte is zero, the function first writes the option byte at `+0x100`.

It then calls F-1f46730b1ced with the object address advanced by `0xCC` and the original request. The returned 32-bit integer-shaped value is retained for later calls.

A zero result causes a call to F-a817d8d58c10. The supplied source annotation describes this dependency as non-returning; its implementation is not available here.

If it returns despite the annotation, the visible body contains no further zero-result check or recovery branch; subsequent processing uses the retained zero value.

The option-byte write precedes this failure-related call. No rollback is shown.

## Acceptance examples

These are conditional acceptance criteria, not executed tests. Except where stated otherwise, storage is valid and dependencies return normally. Call counts refer to calls made directly by this function.

### Nonzero initial byte

For any nonzero byte at `+0x104`, the request is written at `+0xFC`, and the function returns without dependency calls, an option-byte write, or a displacement-global read.

### Successful processing setup

With an initial zero byte and a nonzero resolver result:

- The option write precedes F-1f46730b1ced.
- F-d2f99870cc43, F-bf557f07179f, and F-fa8898fa75ae occur in that order.
- Any later optional operation receives the original resolver result, not the value returned by F-d2f99870cc43.

### Mode exactly eight

With mode result `8`:

- There are exactly two direct context-provider calls.
- Temporary preparation occurs.
- The displacement global and optional object halfword are not read.
- F-818c773e8c8a is skipped.
- The request write precedes F-920630e53283.

### Eligible read with a changed displacement

With mode other than `8`, zero suppression, and a nonzero operation argument, suppose the third context-provider call changes the displacement global from one valid displacement to another.

The function must read the global after that call and use the later displacement to select the 16-bit object value. Using a displacement cached before the call would not match the supplied behavior.

This criterion does not require the two target halfwords to differ, but differing values would distinguish the address selections.

### Forced zero

With mode other than `8`, either a nonzero suppression selector or a zero operation argument prevents both the displacement-global read and the 16-bit object read.

The third context-provider call and F-818c773e8c8a still occur. The operation receives a zero final argument.

### Unchanged signed argument

With zero suppression, a mode other than `8`, and an operation argument of `-1`, the optional read is eligible. F-818c773e8c8a receives the original `-1` argument, not Boolean one.

### Distinct context results

If the first two context calls return different addresses, temporary preparation receives the byte sampled from the first address and the 32-bit value sampled from the second. Replacing both samples with fields from one context would not match the contract.

### Zero resolver result

If resolution returns zero, F-a817d8d58c10 is invoked after the option-byte write. If it does not return, the later request write and final dependency are not reached. No option rollback is shown.
