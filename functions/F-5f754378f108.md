### Width and address conventions

The following notation describes bit patterns without asserting that the displayed signed expressions are portable language operations:

- \(L_n(x)\): the low 32 bits of \(x\) shifted left by \(n\), retaining only 32 result bits.
- \(M_k(x)\): multiplication by \(k\), retaining only 32 result bits.
- \(B(x)\): the low eight bits of \(x\).
- \(E(x)=B((x\mathbin{\&}\texttt{0x3fffffff})\gg20)\).

Address additions in the behavioral formulas use the same 32-bit bit-pattern interpretation. Exact overflow semantics of the underlying machine are **documented_only**: the source representation uses signed types for several operations that can overflow or shift into the sign bit.
