Established behavior consists of an initial table-base snapshot, a suppression check, category-label selection, message construction, optional detail processing, context-derived processing, formatting, submission, and normal-path cleanup calls. The function has no explicit result value.

## Behavior

The function first reads the global table-base word and retains its value. It then obtains a context address through the context slot and checks the byte at offset 0x39.

A nonzero suppression byte ends processing immediately:

- The initial global read has already occurred.
- No category resource is selected.
- No diagnostic-record field or table entry is directly read.
- No dependency is called.
- No temporary cleanup is performed.

A zero suppression byte permits the remaining operations.
