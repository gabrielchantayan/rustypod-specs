# F-42add4590c6c

## Behavior

### Scan

The function begins with a zero record index and a false accumulated match result.

Each loop-condition evaluation reads the signed 32-bit bound at object offset `0x1080`. Scanning continues while the current index is less than that value.

For every visited record, the function reads one byte at:

`object base + 0x128E + 0x50 × record index`

A flag contributes a match only when its byte value is exactly 1. Values such as 0, 2, and 255 do not qualify.

Once a qualifying flag is encountered, the accumulated match result remains true for the rest of the scan. Later nonmatching flags do not clear it. Nevertheless, later records are still visited: this is not a short-circuit search.

For an unchanged bound of \(N > 0\), assuming valid arithmetic and memory:

- Exactly \(N\) flag bytes are read.
- Record indices run from 0 through \(N-1\), in increasing order.
- The bound is read for every iteration and once more for the terminating condition.
- The accumulated result is true precisely when at least one of those \(N\) bytes equals 1.

For an unchanged bound of zero or a negative signed value, the initial condition fails. No flag byte is read, and the match result remains false.

The mask does not control whether scanning occurs. Even a zero mask leaves the scan and its memory accesses intact.

### Conditional dependency invocation

After the scan completes, the function combines the 32-bit mask with the accumulated match result. That result is represented as either zero or one.

Consequently, the dependency is invoked if and only if both conditions hold:

1. At least one visited flag equaled exactly 1.
2. Bit 0 of the trigger mask is set.

Other mask bits cannot independently enable the call. An odd mask enables the call when there is a match; an even mask does not.

When enabled, the function:

- Reads the 32-bit value at object offset `0x1380`.
- Passes that value as the first argument to F-c8120265b43a.
- Passes the integer constant 1000 as the second argument.
- Waits for that invocation to return before proceeding to the state store.

There is at most one such invocation per normally progressing call, regardless of the number of matching records.

The constant 1000 has no established unit or interpretation. The 32-bit object field is an opaque value: it is not established to be a pointer, resource handle, identifier, or owned allocation.

When the trigger is false, this function does not read the field at `0x1380` and does not invoke the dependency.

### Final state update

After the conditional invocation has been skipped or has returned, the function writes the supplied state byte to object offset `0x13C4`.

This write is not conditional on a match, the mask, or any inspected dependency result. It is a one-byte write; no adjacent-byte update is established.

The function then returns zero.
