# F-3805a25164a0

## Purpose

If the observations are equal and zero, it returns zero. Equal nonzero observations cause another iteration.

One initial state value comes from a field in a caller-supplied object; the other comes directly from the second argument. A zero initial value selects a shared global fallback value.

## Behavior

### Initialization

Initialization proceeds before either dependency is called.

1. The integer field at object offset 4 is read and its value becomes the provisional first state.
2. The same object field is read again to test whether it is zero.
3. If the second field read is zero, the shared global fallback is read and replaces the provisional first state.
4. The second argument is tested for zero.
5. If the second argument is zero, the shared global fallback is read and becomes the second state. Otherwise, the argument itself becomes the second state.

The two field reads have different roles: the first supplies the provisional value, while the second controls fallback selection.

Consequently, if the reads can observe different values, the first state is not necessarily the value observed by the zero test. For example, an initial read of 18 followed by a zero-test read of 27 retains 18, not 27. An initial read of 18 followed by a zero-test read of zero replaces 18 with the fallback.

This distinction describes the accesses shown in the supplied representation. It does not establish volatile access semantics, atomicity, valid concurrent modification, or a guaranteed physical load count after compilation.

If both initial states require fallback substitution, the fallback is read separately for each one. The function does not explicitly capture it once for reuse. No dependency calls occur between these initialization steps.

A fallback value of zero is accepted. There is no second fallback, validation, or early return when substitution still yields zero.

### Iteration order

Each iteration performs the following ordered operations:

1. Call F-d3922c7fe0ec with the address of the first state cell.
2. Call F-5afffd4d8a24 and retain its returned observation as the first observation.
3. Call F-d3922c7fe0ec with the address of the second state cell.
4. Call F-5afffd4d8a24 and retain its returned observation as the second observation.

Any modifications made to either local state cell persist into the next iteration. The function does not reinitialize the cells from the object, arguments, or fallback after entering the loop.

### Mismatch and termination
