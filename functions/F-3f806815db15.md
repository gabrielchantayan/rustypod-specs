# F-3f806815db15

## Purpose

F-3f806815db15 performs a state-dependent sequence of memory accesses, unresolved dependency calls, machine-state operations, and eventual abnormal termination.

The supplied static representation does not establish a higher-level purpose. In particular, it does not justify identifying this operation as a loader, decoder, allocator, or object initializer. An early branch writes three consecutive 32-bit fields, but the subsequent behavior is too uncertain to assign those fields a semantic object type.

This contract describes the observable behavior represented by the supplied material, conditional on execution reaching each operation. The material explicitly reports invalid instruction data and truncated control flow. Consequently, this is a source-facing contract, not a claim that all represented operations are executable or that the recovered interface is complete.

No runtime tests have been performed.

## Behavior

### 1. Entry observations and branch selection

The following order is represented before the branch:

1. Capture the incoming stack word W.
2. Read an unsigned 16-bit value at B + 0x14 and retain its zero-extended value. Call this snapshot **flags**.
3. Store the 32-bit value S at T − 8.
4. Compute a 32-bit unsigned working value:
   \[
   Q = ((T - 0x70) \bmod 2^{32}) \mathbin{\gg} 27.
   \]
5. Select the branch according to whether K is zero.

The flags read precedes the store at T − 8. If those addresses overlap, later memory changes do not retroactively alter the retained flags snapshot.

Q initially lies between 0 and 31 inclusive.

### 2. Zero-selector branch

If K is zero, three 32-bit writes occur in this order:

| Address | Value |
|---|---|
| B | B |
| B + 4 | C’s 32-bit representation |
| B + 8 | Zero |

An unresolved dependency is then invoked with the 32-bit result of B shifted left by 13. Bits shifted beyond bit 31 are discarded.

After that invocation returns, execution tests the previously captured flags. It reaches an invalid-instruction termination marker when both conditions hold:

- Bit 5 is set.
- At least one bit in positions 6 through 15 is set.

This is not simply a test that flags is nonzero or exceeds a threshold. A dependency call and the three writes precede this termination check.

If execution continues:

- A coprocessor operation uses incoming machine state.
- Another unresolved dependency is invoked.
- A local stack value is formed by adding 0xA8 to flags. Because flags is at most 0xFFFF, this addition does not overflow 32 bits.
- A 32-bit value is read from the address formed by C + H. Call the result **X**.
- A 16-bit zero is written at H.
- A signed 16-bit value is read at S + 0x61 and sign-extended. Call it **D**.
- A 32-bit copy of X is written at S + 0x61 + D.

The read of D occurs after the zero write at H. Therefore, overlapping addresses can change D. The 32-bit write uses the newly read signed displacement, not the original H.

The represented stack state is then changed. Local storage retains X, D, a control value, and the flags-derived value. A long ordered dependency sequence follows.

That sequence includes these established argument relationships:

- X is passed twice to one dependency, together with a stack-derived address shifted right by 21.
- Two later argument calculations isolate bit 24 of a retained 32-bit value:
  \[
  (V \mathbin{\&} 0x01FFFFFF) \mathbin{\gg} 24.
  \]
  Each result is either 0 or 1.
- Another calculation isolates bit 29:
  \[
  (V \mathbin{\&} 0x3FFFFFFF) \mathbin{\gg} 29.
  \]
- A subsequent 8-bit read uses address 0x10 or 0x11, selected by that same bit-29 calculation.
- Several dependencies produce represented 64-bit values. Their low 32-bit halves are passed onward, sometimes twice in the same invocation.
- One argument is the top bit of the unsigned 32-bit result of subtracting 7 from a retained high half. This is a modular subtraction followed by a logical shift, not an unrestricted signed comparison.
- A later byte-read address is formed as 0x10 minus the signed-right-shift result of a high-half expression involving subtraction of 7. Its exact overflow and shift semantics are not established.
- Two later argument calculations extract bit 63 from separately retained 64-bit results.
- Other intervening dependency invocations have no explicit arguments in the supplied representation. That does not prove they consume no machine-state inputs.

On completion of this branch’s dependency sequence, a final represented 64-bit result becomes the input pair for the shared continuation. Q is replaced with the original stack word W, not with a later memory reread of that stack location.

### 3. Nonzero-selector branch

If K is nonzero, the early B-field writes, zero-selector flag check, coprocessor operation, and long branch-specific dependency sequence are skipped.

The shared continuation instead receives a constructed 64-bit pair:

- Low half: B shifted left by 13, truncated to 32 bits.
- High half: B logically shifted right by 22.

This pair is not generally equivalent to an ordinary 64-bit left shift of B by 13. The high-half expression must remain as represented.

Q retains its entry-derived value between 0 and 31.

### 4. Shared continuation

The selected low and high halves are passed as two arguments to an unresolved dependency. Its target depends on the incoming link/control value on the nonzero-selector branch and on branch-established control state on the zero-selector branch.

A subsequent dependency sequence:

- Passes onward a returned 32-bit value.
- Supplies another invocation with bit 22 of that retained value:
  \[
  (V \mathbin{\&} 0x007FFFFF) \mathbin{\gg} 22.
  \]
- Obtains a further return value.
- Passes that value twice to another dependency.

Before this last duplicated-value invocation, the function writes the 16-bit value 0x002F at the address obtained by multiplying the current H-like value by two. On the zero-selector branch, this value is the sign-extended displacement D. On the nonzero-selector branch, it remains the incoming H value.

Further calls yield a 32-bit result. Its upper four bits are passed to F-2cc1255261f3, giving that dependency an explicit argument between 0 and 15.

A source address for later reads is formed as:

\[
P = ((Q - 0x33) \bmod 2^{32}) \mathbin{\gg} 24.
\]

P is a numeric address between 0 and 255, not an index multiplied by a word size. Several more dependency invocations occur before the reads through P.

If K is nonzero, Q is between 0 and 31. Therefore P is always 0xFF on that branch.

### 5. Low-address reads and fixed-address writes

After the intervening calls, four 32-bit values are read in this order:

| Read address | Later use |
|---|---|
| P | First explicit argument of a later dependency |
| P + 4 | Fourth explicit argument of that dependency |
| P + 8 | Stored at 0xCB |
| P + 16 | Stored at 0xCF and retained for a later stack-relative store |

There is no represented read at P + 12.

The function then performs these 32-bit writes in order:

1. At 0xC3, store an additional register output from a preceding unresolved call.
2. At 0xC7, store the address 0xC3.
3. At 0xCB, store the value read at P + 8.
4. At 0xCF, store the value read at P + 16.

These addresses are not naturally aligned for 32-bit accesses. The representation supplies no alignment repair or alternative path.

A 32-bit value is then read from fixed static storage. Call this retained address-like value **G**. A dependency is invoked with:

- The value read at P.
- The additional register output used at 0xC3.
- The address 0xC3.
- The value read at P + 4.

After that call:

1. Read another fixed 32-bit static value. Call this snapshot **N**.
2. Store an additional register output from the call at G + 0x68.
3. If N is greater than 8 under unsigned comparison, reach an invalid-instruction termination marker.

G is captured before the call. N is read after it. A dependency’s modifications to static storage can therefore affect N; modifications to the storage from which G was read do not change the retained G used by the subsequent store.

### 6. Final represented path

If N is at most 8, another unresolved dependency returns a represented 64-bit value.

The function then writes, in order, four 32-bit values below the current stack-like register:

- At offset −4: the retained value originally read at P + 16.
- At offset −8: the retained N snapshot.
- At offset −12: 0xC3 shifted right by 14, which is zero.
- At offset −16: retained G.

It then:

1. Writes the low 8 bits of N at G + 0x0F.
2. Writes a 16-bit stack-address-derived quantity at N + 0x28. The quantity includes an adjustment of 0x398 and is truncated to 16 bits.
3. Invokes a final dependency with the low and high halves of the last 64-bit result and the constant 0x74.
4. Reaches another invalid-instruction termination marker.

Because N is at most 8 on this path, the 16-bit write address lies between 0x28 and 0x30 inclusive.

## Acceptance examples

These are conditional static acceptance examples, not executed tests. Each assumes execution reaches the described operations and that preceding accesses and dependencies complete.

1. **Flags captured before an overlapping write.**  
   If the initial flags read yields 0x0060, later modification of its memory location does not change the branch’s retained test. For K = 0, the three B-field writes and entry dependency invocation precede the termination marker.

2. **Bit 5 alone does not trigger the early marker.**  
   Flags 0x0020 do not satisfy the upper-bit condition. Flags 0x0040 do not satisfy the bit-5 condition. Flags 0x0060 satisfy both.

3. **Nonzero selector bypasses initialization.**  
   For K ≠ 0, no explicit writes to B, B + 4, or B + 8 occur in the branch. The earlier flags read and T − 8 store still occur.

4. **Constructed halves are not a conventional wide shift.**  
   For B = 0x00400000 on the nonzero-selector branch, the constructed low half is zero and the high half is one.

5. **Nonzero-selector low-address source.**  
   For every permitted entry-derived Q between 0 and 31, the later source address is 0xFF. The four represented reads are therefore at 0xFF, 0x103, 0x107, and 0x10F.

6. **Unsigned subtraction wraps on the other branch.**  
   If K = 0 and W = 0x00000032, P becomes 0xFF. If W = 0x00000033, P becomes zero.

7. **Late termination follows a write.**  
   If the retained N snapshot is 9, the store at G + 0x68 occurs before the unsigned comparison terminates the path. The final dependency sequence is not reached.

8. **Boundary value 8 continues.**  
   If N is 8, execution can reach the byte store of 8 at G + 0x0F and the 16-bit store at 0x30, followed by the final dependency and terminal marker. This does not establish successful return.
