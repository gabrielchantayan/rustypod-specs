# F-5c754c98fcc0

## Purpose

F-5c754c98fcc0 dispatches among 32 alternatives, maintains retained words and references, invokes opaque dependencies, and conditionally modifies shared memory. If its return alternative is reached, it returns a 32-bit accumulator.

The supplied static representation establishes individual operations and their data dependencies. It does not establish the initial dispatch alternative, complete execution paths, termination, or an application-level purpose. Initialization, resource management, and status decoding are possible interpretations, not established semantics.

All alternative-specific behavior below is conditional on reaching that alternative. Unknown transition values do not make its established arithmetic or retained-state changes optional.

## Interface

### Inputs and output

The five inputs are 32-bit words. Input 2 is explicitly unsigned; the others have opaque 32-bit representations. No input is established as a pointer, length, handle, or ownership-bearing value.

Inputs 1–4 are retained on entry. Input 5 is available for a later preparation operation.

The output is an unsigned 32-bit word. Its accumulator starts at zero and is replaced only by alternative `0x1F`. Alternative `0x0A` returns its current value. Return is not guaranteed.

## Behavior

### Global provenance and dispatch

The shared-object base is captured before other setup. Flag accesses subsequently use this captured value, not a reload of its originating global.

The initial state is read before dispatch. Before every range check, six globals are loaded in this order:

1. Notification-A word.
2. Successor for the `0x40000000` setter.
3. Notification-B word.
4. Notification-C word.
5. Successor for the `0x01000000` setter.
6. Scale coefficient.

Call the sixth snapshot \(g\). A fresh read of the same scale location is denoted \(G\). Other recurring global locations are:

- \(D\): multiplier used in preparation, status arithmetic, and secondary-word scaling.
- \(C\), \(B\): coefficients used in status-derived arithmetic.
- \(R\): coefficient used in two high-bit predicates.
- Secondary seed: global assigned directly to \(Y\).

These labels identify locations. Every occurrence described as fresh is a separate read; equal labels do not imply equal values across reads.

After the six loads, a bias is read. State plus bias is compared with 31 as an unsigned 32-bit value. An out-of-range result causes:

1. F-11bc1f81fac4 to receive the second handle and the normalized live status.
2. Its result to replace live status after normalization.
3. A retry-state global to be read.
4. Another complete six-load sequence and range check.

There is no visible retry limit.

For an in-range result, dispatch reads the bias again. The checked and selected indexes can therefore differ if that global changes. Behavior when the second index lies outside the represented alternatives is **documented_only**.

Unless specifically identified as snapshots, transition values are fresh global reads. Repeated references to the same transition location remain separate reads.

### Widths and arithmetic notation

For an input word \(v\), normalization is:

\[
N(v)=(129v)\bmod256.
\]

Thus \(N(0x101)=0x81\), and normalizing that byte again gives `0x01`. Multiplication by 129 without the byte mask is not normalization.

The equations below describe 32-bit word results. Unsigned additions, multiplications, and complements retain their low 32 bits. Complements are 32-bit complements, not byte complements. \(\operatorname{bit31}\) extracts the most significant bit as zero or one.

Explicit conversion to signed 32-bit before a right shift is identified as \(\operatorname{ASR}_{32}\). The representation does not fully establish the signedness of other global operands, including \(B\). Consequently, shifts of \(B\) retain the represented right-shift operation; whether they are arithmetic or logical remains **documented_only**. Original signed-overflow semantics are also unresolved where signed intermediates occur.

Within an expression containing multiple global references, the representation does not establish a total machine evaluation order. It does establish separate references and boundaries between completed assignments and calls. The numbered coefficient reads below distinguish syntactic occurrences, not an additional evaluation-order guarantee.

## Acceptance examples

These are conditional acceptance examples, not executed tests.

1. **Retry refreshes snapshots.** If an out-of-range handler returns, the next check must follow six fresh ordered loads. Reusing the preceding snapshots changes established behavior.

2. **Notification follows the flag write.** If `0x05` reads flags `0x00000005`, its explicit write is `0x20000005`. Notification receives the earlier Notification-A snapshot and 8, even if its originating global changes during the call.

3. **Unmasked multiplication survives.** If `0x06` receives a dependency result `0x101`, then \(Z=0x101\), \(X=S=0x81\), and \(W=0x4101\). Replacing \(W\) with `0x01` would incorrectly add a byte mask.

4. **Secondary-word clearing affects return preparation.** If `0x12` executes and `0x1F` follows without an intervening change to \(Y\), the accumulator becomes zero regardless of the fresh scale coefficient.

5. **Secondary scaling is retained.** If `0x1C` observes \(D=3\), incoming \(Y=5\), and \(G=7\), both \(W\) and \(Y\) become 105. If `0x1F` next observes \(G=2\), the accumulator becomes 210.

6. **Distinct scale provenance.** A scale mutation inside F-c8e906e0b5f9 does not recompute its saved product or replace the pre-dispatch \(g\) used by its predicate. Post-call coefficient reads remain independently observable.

7. **Product survives the byte-producing call.** If F-46b69b47db18 changes the scale global, F-9976748a38b8 still receives the product computed before that call.

8. **Argument retention is explicit.** In `0x0F`, incoming operand and \(A\) become saved operand and \(Q\); \(O\) becomes \(K\). A later call must use those updated fields unless an intervening alternative changes them.

9. **Return and byte write.** Return without `0x1F` yields zero. A valid `0x1A` write changes only the explicitly addressed byte; it does not initialize the other 255 temporary bytes.
