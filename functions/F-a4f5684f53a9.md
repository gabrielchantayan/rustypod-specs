# F-a4f5684f53a9

## Purpose

F-a4f5684f53a9 specifies an unconditional repeating control sequence. Each iteration attempts two indirect calls, in order, followed by a software interrupt with immediate value 0x5B. If execution continues after that interrupt, the function establishes a fixed base for computing the first call target in the next iteration.

The first iteration differs from subsequent iterations: its first call target depends on an incoming value whose origin and initial value are not established by the supplied body. Later iterations use a base assigned after the preceding interrupt.

This contract describes statically established control flow and expressions. It does not establish that the indirect targets are executable, that the calls return, or that the interrupt resumes execution.

No application-level purpose is established. Describing the sequence as a scheduler, service loop, retry policy, exception handler, or termination mechanism would require additional evidence.

## Behavior

### Ordered iteration

Subject to each preceding operation returning or resuming normally, an iteration has the following observable order:

1. Establish 0x08579C95 as the fixed base for the second call.
2. Compute the first indirect-call target using the current target base plus 0xEB6.
3. Invoke that target with the explicit arguments zero, zero, and 0xFFFFFFA5.
4. Compute the second indirect-call target using the fixed base established earlier in the iteration plus 0xCB6.
5. Invoke the second target with no explicit arguments.
6. Request software interrupt 0x5B.
7. If execution continues past the interrupt, assign 0x083D4CC2 as the current target base.
8. Continue into the next iteration without evaluating a termination condition.

The second-call base is established before the first call. It is not derived from the first call’s return value.

The target-base assignment for the next iteration occurs after the interrupt. Reaching the interrupt alone does not establish that this assignment has occurred.
