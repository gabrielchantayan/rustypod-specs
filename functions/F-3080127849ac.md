# F-3080127849ac

## Purpose

F-3080127849ac selects a location associated with an input descriptor and returns its address-like value. A null input returns zero. A non-null input selects one of two paths according to an unsigned descriptor field:

- Values below 1000 use a secondary output from F-d7be9cfb4000 to calculate a location within a base-relative region.
- Values of 1000 or greater first query F-e811f22d3ad4 and, only if that returns zero, query F-aa594f01a93f. A nonzero result from either query is advanced by 16 address units.

The address-selection behavior is established by the supplied static representation. The domain meaning of the descriptor, the selected locations, and the boundary at 1000 is not established. Describing the function as a lookup or selector is inferred intent, not evidence of a particular data model.

## Interface

### Input

The function accepts one integer-shaped argument used as an address to a descriptor. Zero is recognized explicitly as a null input.

For a nonzero input, the following layout is accessed:

| Object | Byte offset | Accessed value |
|---|---:|---|
| Input descriptor | 4 | Address-like link to another object |
| Input descriptor | 8 | Unsigned selection field |
| Linked object | 8 | Base value retained for subsequent computation or dependency calls |
| Linked object | 12 | Argument supplied to F-d7be9cfb4000 on the below-1000 path |

The supplied representation uses four-byte scalar accesses for these fields. It expresses the addresses and return value through integer-shaped quantities, consistent with a 32-bit address model. The exact target ABI, pointer width, alignment rules, and byte order are not independently established.

The descriptor’s first four bytes are not accessed by the visible body. No size, tag, ownership marker, or validity field is checked.

### Output

The return value is integer-shaped and used as an address-like result:

- Zero for a null input.
- A computed base-relative value on the below-1000 path.
- Zero if both dependencies on the at-least-1000 path return zero.
- A successful dependency result plus 16 on the at-least-1000 path.

The function does not return an independent success indicator. A zero result therefore does not distinguish null input from unsuccessful queries. Arithmetic could also produce zero under some machine-arithmetic interpretations; the visible body does not exclude that possibility.

### Preconditions

For ordinary completion with a nonzero input, every memory read actually reached must be valid under the execution environment’s rules.

In particular:

- The descriptor fields at offsets 4 and 8 must be readable.
- The linked object’s field at offset 8 must be readable before either selection path begins.
- On the below-1000 path, the descriptor link is read again, and the object reached by that second read must have a readable field at offset 12.
- Each invoked dependency must accept its supplied arguments and return normally for the enclosing function to complete normally.

A nonzero descriptor does not imply that its linked address is nonzero or valid. No defensive check protects that dereference.

## Behavior

### Null input

If the input is zero, the function returns zero immediately.

No descriptor fields are read, and none of the listed dependencies is called.

### Common non-null prefix

For a nonzero input, the function first reads the descriptor’s link at byte offset 4. Through that link, it reads and retains the base value at byte offset 8.

Only after this base read does it read the descriptor’s unsigned selection field at byte offset 8 and compare that field with 1000.

Consequently, the linked base must be accessible even when both later queries would return zero. There is no path that inspects the selection field and rejects or resolves the request before reading the base.

The comparison is unsigned and strict:

- 0 through 999 select the below-1000 path.
- 1000 and above select the query path.

Under the indicated 32-bit field interpretation, the largest unsigned value also selects the query path; a high-bit-set representation is not treated as a negative value for this comparison.

### Below-1000 path

The function reads the descriptor’s link at offset 4 again. It then reads the field at offset 12 from the object reached by this second link value.

That field is supplied as the first argument to F-d7be9cfb4000. The second argument is 20.

The location calculation uses a secondary register output associated with this call, rather than an established ordinary return value. Calling that secondary output \(q\), and the previously retained base \(B\), the visible calculation is:

\[
B + 88q + 228
\]

The result is returned directly.

Important constraints and absences:

- The selection field is not visibly passed to this dependency.
- The selection field is not used directly as the multiplier in the calculation.
- No visible check establishes that \(q\) is nonnegative or within a valid region.
- No visible check establishes that the computed location is readable, writable, aligned, or nonzero.
- Neither F-e811f22d3ad4 nor F-aa594f01a93f is called on this path.
- The base is not reloaded after the dependency call.

The repeated link read matters. The base can originate from the object reached by the first read, while the dependency argument originates from the object reached by the second read. The visible body neither locks the descriptor nor enforces equality between those two observations.

### At-least-1000 path

The function first calls F-e811f22d3ad4 with the retained base.

If that dependency returns a nonzero value, the function adds 16 to that value and returns the result. F-aa594f01a93f is not called, and the descriptor’s selection field is not read again by the visible body.

If F-e811f22d3ad4 returns zero, the function reads the descriptor’s field at offset 8 again. It then calls F-aa594f01a93f with:

1. The retained base.
2. The newly read four-byte selection value.

The second read is not constrained to equal the value used for branch selection. In particular, the first dependency may change accessible state. The supplied representation does not justify assuming that it preserves the descriptor or any globals.

If F-aa594f01a93f returns nonzero, the function adds 16 and returns that result. If it returns zero, the function returns zero without adding 16.

The original branch decision is not reconsidered after the second selection-field read. Even if the later value is below 1000, the function continues through F-aa594f01a93f rather than switching to the below-1000 path.

## Acceptance examples

These are conditional behavioral examples derived from static evidence. They are not runtime test results. Numeric addresses are illustrative, and arithmetic examples assume valid accesses, normally returning dependencies, and representable calculations.

### Null input

Given an input of zero:

- Return zero.
- Perform no descriptor reads.
- Call none of the three dependencies.

### Below-boundary selection

Given an initial selection value of 999, a retained base of 4096, and a secondary output of 3 from F-d7be9cfb4000:

- Call F-d7be9cfb4000 with the field at offset 12 through the reread link and with 20.
- Return \(4096 + 88 \times 3 + 228 = 4588\).
- Call neither query dependency.

The same branch is selected by an initial selection value of zero. That value alone does not determine the secondary output or the final location.

### Exact boundary with first-query success

Given an initial selection value of 1000 and a return value of 8192 from F-e811f22d3ad4:

- Call F-e811f22d3ad4 with the retained base.
- Return 8208.
- Do not call F-aa594f01a93f.

### Fallback observes a changed selection value

Given an initial selection value of 1200, suppose F-e811f22d3ad4 changes the descriptor’s selection field to 7 and then returns zero.

If the subsequent read observes 7:

- Call F-aa594f01a93f with the retained base and 7.
- Do not switch to the below-1000 path.
- If the fallback returns 12288, return 12304.

### Both queries fail

Given an initial selection value of at least 1000 and zero results from both query dependencies:

- Call F-e811f22d3ad4 first.
- Reread the selection field before calling F-aa594f01a93f.
- Return zero, not 16.
