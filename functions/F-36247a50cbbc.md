## Acceptance examples

These are conditional static criteria, not executed tests. They assume valid selected accesses, arithmetic yielding the stated values, and external controls producing the stated selectors.

1. **Immediate return.** An initial selector of 8 causes an iteration-entry shared-scale read and returns zero. Neither dependency is called.

2. **Default action.** An initial selector outside 0 through 9 performs saved-result calculation. Since the initial working value is zero, the saved result remains zero. The routine does not reject the selector.

3. **Argument reordering.** If preparation supplies caller words \(A\) in position three and \(B\) in position four, later processing receives \(B\) as argument one and \(A\) as argument four.

4. **Processing before preparation.** If processing executes before preparation and no earlier action supplies a field word, all four dependency arguments are zero. The fresh shared-scale factor still participates in argument-two calculation.

5. **Two different processing scale accesses.** Suppose preparation uses coefficient 2 for second caller argument 3, producing prepared value 6. If the processing iteration captures scale 5 and its later call-expression scale access also yields 5, argument two is 30. If that later access instead yields 13, argument two is 78. In either case, if the dependency returns 7 and the post-call coefficient is 11, the stored intermediate and working values become 385, using the captured factor 5. A scale change during the call does not replace that factor.

6. **Repeated lookup-base references.** After lookup returns, both continuation-base occurrences remain in the successor expression, including the occurrence in the zero-weighted term. If both yield 20, a zero result produces state 21 and a nonzero result produces state 20. Dispatch bias still affects the next selector.

7. **Field replacement and clearing.** A field read loading word \(W\) makes \(W\) the third processing argument unless another field read or selector 3 intervenes. Selector 3 clears it and also replaces the working value.

8. **Fixed seed to returned result.** If selector 7 reads seed 7, no intervening action changes the working value before saved-result calculation, that calculation’s fresh shared-scale access yields 3, and selector 8 is reached without another saved-result update, the returned value is 21.

9. **Sign of the combined products.** If the prepared first argument is 1, its fresh shared-scale product is `0x80000000`, and its alternate-scale product is zero, the combined word has its high bit set. If both sign-base occurrences yield the same base, the successor is that base, not base minus nine.

10. **Nontermination remains possible.** A configuration that repeatedly selects a cycle excluding selector 8 has no visible internal counter forcing return. Dependencies or invalid accesses may independently prevent continued execution.
