# F-42fba8a65c83

- Deliver the text `GotoNowPlaying` through the receiver when a particular state-and-equality predicate holds.
- Otherwise, obtain and prepare another object, then pass it with the resolved token and auxiliary context to F-69a62b9a6385.

The interpretation as navigation toward currently playing content is **inferred intent**, supported by the text payload and the branch structure. 1. F-05cc4e9ef0f4 is called on the first comparable value.
2. F-05cc4e9ef0f4 is called on the second comparable value.

## Acceptance examples

### Initial state query is nonzero

- Both extraction calls occur, first value before second.
- The values compare unequal despite having matching low 32 bits.
- The `0x13C` query is skipped.

### Equality with enabling query nonzero

Given an initial state-query result of zero, equal 64-bit extraction results, and a nonzero `0x13C` result:

- The text action dispatches the value returned by F-9b9c1c7483f4.
- The construction input includes exactly `GotoNowPlaying`.
- Text-holder finalization occurs before shared finalization.
- No alternate object is obtained.

### Equality with enabling query zero

- Equality alone does not select the text action.
- The alternate-object action occurs.
- F-69a62b9a6385 receives the original resolved token, not either extracted comparison value.

### Equal high-bit-set values

Given both extracted values equal to `0xFFFFFFFFFFFFFFFF`, equality succeeds. No signed interpretation is needed; the `0x13C` result determines the branch.

### Changing wrapper resolutions
