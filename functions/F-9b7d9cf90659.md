### First selector-directed writes

This conversion matters both to the next byte write and to F-D11’s arguments. Without a conversion model, an out-of-range unsigned result cannot unconditionally be described as retaining its shifted bit pattern in signed storage.

The routine reads a selector byte at the context selector base plus one. It writes a byte derived from the converted signed value at the selector value plus 17.

F-D11 then receives three copies of that converted signed value.

F-D12 returns an opaque 32-bit **third result**, which is passed to F-D13. Four no-explicit-argument calls follow; F-D17 supplies the signed 32-bit **fourth result**.

The routine performs a fresh read of the selector byte at the context selector base plus one. It writes a byte derived from the original second result after masking to 30 bits and logically shifting right by 20.

Under low-byte narrowing, this second write contains bits 20 through 27 of the second result. The intermediate value can occupy ten bits; the byte write retains eight.

The seventh result is masked to 30 bits and logically shifted right by 25. The resulting **extracted field** ranges from 0 through 31.

The routine changes selector sources. The new source address is formed by multiplying the retained signed conversion of the shifted fifth result by 1,024, then adding one.

1. The unsigned-to-signed conversion must have an established outcome.
2. The signed multiplication must be defined.
3. The signed addition and subsequent address interpretation must be defined.

Consequently, an unsigned shift that is defined does not by itself establish this later address.

The routine then:

- Rereads the fifth-result-derived selector source.
- Writes zero at the selector value plus 17.
