- **Zero result:** test the receiver’s low-order byte at `0x38`. Only if that byte is nonzero is the low-order byte at `0x30` tested. The optional calls occur only when both tested bytes are nonzero.

The supplied representation establishes the read after the call, without establishing a broader concurrency or synchronization model.
