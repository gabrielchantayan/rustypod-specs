## Acceptance examples

These are conditional arithmetic and ordering examples, not executed tests. They assume the stated 32-bit interpretation, completing accesses, returning dependencies, and the specified read results.

1. **Initial operation precedes calls.** With first input 4,096 and incoming hidden word 0x12345678, the initial store writes that word at address 4,116. F-dep-001 subsequently receives 4,096.

2. **First scaled transfer.** A first producer result of 3 produces a word store of 12 at address 68. With fourth input 65, F-dep-006 receives 12, 12, and 0x04000000. A second producer result of 7 then selects address 48 for the retained word 12.

3. **Capture need not be readback.** A fifth producer result of 2 produces a store of 8 at address 52, followed by a word read at address 28. If that read returns 0xABCDEFFF and the sixth producer result is 9, the shifted transfer writes 0x000ABCDE at address 56.

4. **Later changes do not replace the captured value.** If the captured word is 0x80000000, the shifted transfer value is 0x00080000. A later change to the original capture location introduces no replacement read in the represented data flow.

5. **Packed fields select the low producer bits.** A sixth producer result of 0x1234567B yields first and third F-dep-036 arguments of 0x000B0000 and 0xC0000000. A sixth producer result of 4 yields first argument 0x00040000; a result of 16 yields first argument zero. These distinguish selection of original bits 0–3 from selection of bits 2–5.

6. **Separate selector reads.** With ninth producer result 0x12345678, the first stored byte is 0xE0. A first selector of 200 selects address 217. If the second selector read returns 10, the second store writes 0x23 at address 27, and F-dep-058 receives 10 as its second argument.

7. **Mask, shift, then truncate.** With ninth producer result 0x3FF00000, the 30-bit mask leaves 0x3FF00000. The right shift produces 0x000003FF, and the byte store writes 0xFF.

8. **Selector boundaries and repeated destination.** Selector values zero and 255 select addresses 17 and 272 respectively. If both reads return 255, both byte stores target address 272; the second selector passed to F-dep-058 is 255, not 272.

9. **Incomplete progress.** If a dependency does not return, later represented operations need not occur. If an access cannot complete, no replacement value, recovery sequence, or application-level error response is established.
