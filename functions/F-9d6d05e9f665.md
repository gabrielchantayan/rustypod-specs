# F-9d6d05e9f665

This is inferred intent, not a complete semantic description: the context provider is invoked separately for testing and writing, and the source field is read again before the write. The following distinctions are part of the contract:

- The initial context result is not reused for either later field access.
- The address whose field is tested is not necessarily the address whose field is written.
- The source value used for the initial nonzero test is not retained for the eventual write.
- There is no second nonzero test of the source value.
- There is no zero test of the final write destination unless that address happens to equal the earlier checked address.
