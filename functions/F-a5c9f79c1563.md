# F-a5c9f79c1563

## Purpose

F-a5c9f79c1563 performs an unconditional delegated operation on an object, with additional work selected by whether a supplied control value is zero.

For a zero control value, it first invokes a dependency on an interior region of the object, then performs the unconditional operation and returns.

For a nonzero control value, it performs the unconditional operation first. It then conditionally evaluates dimensions in a related object, selects either an object-held value or zero, and invokes an adjustment dependency unless the related object already satisfies the selected equality condition. After an adjustment, it queries another object through indirect dispatch and may perform a further notification.

The dimensional interpretation is inferred intent. The established behavior consists of field reads, comparisons, dependency calls, and early returns. One input to the dimensional decision is unresolved in the supplied representation, so the decision cannot be specified solely as a function of the two explicit arguments.

## Interface

### Explicit inputs

- **Object reference:** a pointer to mutable, word-addressed storage. The supplied representation accesses fields through byte offset `0x2e4` and passes an interior address at byte offset `0x2dc` to a dependency.
- **Control value:** an integer tested only for equality or inequality with zero. No distinction between positive and negative nonzero values is established.

The same explicit object reference and control value are passed to F-9aa3a9791e88.

### Result

There is no explicit result value. Successful completion is observable through dependency invocations and any changes those dependencies make.

No error code, Boolean success result, or returned ownership is established.

## Behavior

### 1. Zero-control preliminary operation

If the control value is zero, the function invokes F-2318d06eb0b2 with the address at primary-object offset `0x2dc`.

This call precedes F-9aa3a9791e88. The supplied body does not inspect its result.

The address is an interior address, not a separately allocated object established by this function. Its type, extent, and dependency-specific ownership rules are unknown.

### 2. Unconditional delegated operation

The function invokes F-9aa3a9791e88 with the primary object reference and the original control value, regardless of whether that value is zero.

For a zero control value, the function returns after this call. It does not evaluate the later eligibility fields, related-object dimensions, or dispatch-result flags.

For a nonzero control value, evaluation continues using object state observed after this dependency returns. Entry-state field values must not be substituted for these later reads: the dependency may change the object or shared state.

### 3. Eligibility for nonzero-control processing

Further processing occurs if either of two alternatives succeeds:

1. The word at offset `0x74` is zero and bit `0x20` is set in the word at offset `0x78`.
2. The word at offset `0x5c` is zero and bit `0x20` is set in the word at offset `0x60`.

Evaluation is short-circuited:

- The word at `0x74` is examined first.
- The flags at `0x78` are examined only if that word is zero.
- If the first alternative succeeds, the second alternative is not evaluated.
- Otherwise, the word at `0x5c` is examined.
- The flags at `0x60` are examined only if that word is zero.

Unrelated flag bits do not affect these tests. A nonzero tested word disables its own alternative, irrespective of the corresponding flags.

If neither alternative succeeds, the function returns without the dimensional query, adjustment, or later indirect calls.

### 4. Related-object query and subsequent reload

For an eligible object, the function reads the pointer at primary-object offset `0xb4` and calls F-756b664b4a2c with:

- that related-object pointer; and
- an address into a local scratch area represented as two 32-bit words.

After the call, the function reads the pointer at primary-object offset `0xb4` again.

This reload is significant. The pointer used for the following field accesses need not equal the pointer passed to F-756b664b4a2c if that dependency changes the primary object.

Only the first scratch word is explicitly consumed by the supplied body. The dependency’s initialization of that word is not shown. No use of the second scratch word is established.

### 5. Select the adjustment value or return

The function compares these two differences:

- the related object’s word at `0x88` minus its word at `0x80`;
- the unresolved integer value minus the first scratch word.

The comparison is signed in the supplied representation.

If the first difference is strictly less than the second:

- The candidate adjustment is read from primary-object offset `0x2e4`.
- The difference between the related object’s words at `0x8c` and `0x84` is compared with that candidate.
- Equality causes an immediate return.
- Inequality leads to adjustment using the candidate.

Otherwise, including equality in the first comparison:

- The words at related-object offsets `0x8c` and `0x84` are compared directly.
- Equality causes an immediate return.
- Inequality leads to adjustment using zero.

Thus, equality at the first comparison takes the zero-selection branch, not the object-held-candidate branch.

The candidate at primary-object offset `0x2e4` is not read on the zero-selection branch.

The function does not clamp negative differences or candidate values. It does not establish that the four related-object words are ordered coordinates or that either difference is nonnegative.

### 6. Adjustment and conditional notification

When neither equality return applies, the function calls F-d25031d00f00 with the primary object reference and the selected adjustment value.

Only after that call returns does the function perform indirect dispatch:

1. It resolves the callable at byte offset `0x5c` in the primary object’s dispatch table.
2. It calls that entry with the primary object reference.
3. It reads the flags word at byte offset `0x48` in the returned object.
4. It tests bit `0x40`.

If that bit is clear, the function returns.

If the bit is set:

- It performs the same form of indirect dispatch again.
- The second return value is not consumed by an explicit operation in the supplied body.
- It invokes F-6dd3097a8880 with no explicit arguments.
- It then returns.

The second indirect call is a separate invocation, not reuse of the first result. Its target is resolved through the primary object again; changes made by the first call may therefore affect that resolution. The first returned object’s flags control whether the second call occurs. No second flags test is shown.

## Acceptance examples

These are conditional static expectations, not executed tests. Numeric arithmetic examples assume representable signed 32-bit intermediate results.

1. **Zero control.** Given accessible inputs and normally returning dependencies, the observed calls are F-2318d06eb0b2 followed by F-9aa3a9791e88. No eligibility or dimensional processing follows.

2. **Nonzero control without eligibility.** If, after F-9aa3a9791e88 returns, both tested words at `0x74` and `0x5c` are nonzero, the function returns without F-756b664b4a2c or F-d25031d00f00. Neither eligibility flags word needs to be read.

3. **First alternative succeeds.** If the post-call word at `0x74` is zero and its flags include `0x20`, processing reaches F-756b664b4a2c without evaluating the second eligibility alternative.

4. **Candidate already satisfied.** Suppose the first related-object difference is 30 and the unresolved-value-minus-scratch difference is 40. If the candidate is 12 and the second related-object difference is also 12, the function returns without adjustment or indirect dispatch.

5. **Candidate adjustment required.** Under the same first comparison, if the candidate is 12 but the second related-object difference is 8, F-d25031d00f00 receives 12. Indirect dispatch follows its return.

6. **Boundary selects zero.** If both sides of the first comparison equal 30, and the related words at `0x8c` and `0x84` differ, F-d25031d00f00 receives zero. The candidate field is not needed on this branch.

7. **Zero condition already satisfied.** If the first comparison is false and the related words at `0x8c` and `0x84` are equal, the function returns without adjustment.

8. **Notification flag distinction.** Following an adjustment, a clear `0x40` bit produces one indirect call and no F-6dd3097a8880 call. A set bit produces a second indirect call followed by F-6dd3097a8880.

9. **Related-object replacement.** If F-756b664b4a2c replaces the pointer at primary-object offset `0xb4`, subsequent dimension reads use the replacement. They are not constrained to the object originally passed to that dependency.
