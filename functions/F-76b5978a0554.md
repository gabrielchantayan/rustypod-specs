## Behavior

### 1. Read the initial offset and selected entries

The function first reads the unsigned 16-bit field at descriptor address + 28. It adds that value to the buffer address to obtain an initial anchor.

It then uses the selector to locate a pair of adjacent 16-bit entries before that anchor:

- **A** is read at anchor − 2 × selector − 2.
- **B** is read at anchor − 2 × selector − 4.

The read of A precedes the read of B. Both are signed 16-bit reads extended to the working integer width. Each saved value is therefore in the range −32,768 through 32,767.

The selector is not converted to a 16-bit index. Its 32-bit value participates in the calculation. Zero and negative selectors are not rejected; they simply produce different addresses, subject to arithmetic and memory-access validity.

The initial descriptor offset, A, and B are obtained before any dependency is invoked.

### 2. Read the initial boundary and decide whether to make the optional call

The function next reads the unsigned 16-bit field at buffer address + 10. Using the initial anchor and that count-like value, it reads an unsigned 16-bit boundary entry at:

**initial anchor − 2 × initial count − 2 bytes**

The optional call is made exactly when that boundary’s 16-bit bit pattern differs from B’s 16-bit bit pattern.

Equivalently, the low 16 bits of the boundary-minus-B difference must be nonzero. This is not an unrestricted mathematical comparison between an unsigned integer and a signed integer.

Consequences include:

- A boundary value of 65,535 and B equal to −1 suppress the optional call: both have the same 16-bit pattern.
- A boundary value of 32,768 and B equal to −32,768 also suppress it.
- No property of A determines whether this call occurs.
- The decision does not test the difference between A and B.

When the condition is satisfied, the function invokes **F-EXTERNAL-01** with these arguments, in order:

1. Buffer address + A.
2. Buffer address + B.

These are address-valued integer arguments. A and B are signed displacements and may place either argument below the buffer address. The function does not establish that either argument is in bounds, that the first precedes the second, or that either is the start of an owned object.

No result from F-EXTERNAL-01 is used.

### 3. Invoke F-328d7ef52173

After the optional call, or immediately after the condition when that call is skipped, F-76b5978a0554 invokes F-328d7ef52173.

It passes the original three input values unchanged and in their original order:

2. Buffer address.
3. Selector.

This call occurs on every ordinary path that reaches this stage. Its execution is not conditional on A and B differing, or on the optional call having occurred.

No returned result is used.

The original argument values remain the inputs to subsequent address calculations. That does not imply that the memory they designate remains unchanged.

### 4. Read current metadata and invoke the indirect target

After F-328d7ef52173 returns, the function reads the descriptor’s unsigned 16-bit offset field again. It also reads the buffer’s unsigned 16-bit count-like field again.

It uses these current values to locate:

**buffer address + current descriptor offset − 2 × current count − 2 bytes**

At this location, it reads a **signed** 16-bit displacement.

The first argument to the final indirect call is the buffer address plus that freshly read signed displacement.

The second argument is the signed 16-bit interpretation of **B − A**, extended to the working integer width. It is not necessarily the full mathematical difference. Differences outside −32,768 through 32,767 wrap to the corresponding signed 16-bit result in the represented operation.

For example:

- A = 10 and B = 30 produce a second argument of 20.
- A = 30 and B = 10 produce −20.
- A = −32,768 and B = 32,767 produce −1 rather than 65,535.
- A = 32,767 and B = −32,768 produce 1 rather than −65,535.

The function then invokes **F-INDIRECT-01** with:

1. The address calculated from the current boundary displacement.
2. The signed 16-bit-wrapped difference derived from saved B and A.

The final boundary read is not reused from the earlier condition. Its location and contents may have changed because of either preceding call or other effects outside this function.

The saved A and B values are not refreshed.

The supplied representation does not establish the relative evaluation order of the final target lookup, the descriptor-field reread, and the count-field reread. It does establish that the final invocation follows the return from F-328d7ef52173.

### 5. Return

If the final indirect call returns normally, F-76b5978a0554 returns without producing a value.
