**[INFERENCE]** With ordinary flat byte-addressed memory, 32-bit bit-vector addressing, completed accesses, and no external mutation or special memory effects, the early capture is zero. The intervening stores are another zero word and a word at scaled base plus 0x34. The latter cannot overlap the offset-0x14 word: their starts differ by 0x20 modulo \(2^{32}\), and each spans four bytes. An overlapping zero store cannot introduce nonzero bytes.

### Store order under aliasing

The final-base offset-0x0d byte store precedes the working-base offset-8 store of 0x6c, which precedes the working-base offset-0x0d and offset-9 copies.

**[INFERENCE]** In a flat 32-bit address model, final base 0xfffffe54 and working base 0xfffffe58 make final base plus 0x0d and working base plus 9 both address 0xfffffe61. The later working-base copy overwrites the earlier copy there. The 0x6c store remains between those two accesses.

### Late selection boundaries

The saved working word must be captured after restoration at final base plus 0x54 and before the subsequent final-base offset-0x11 byte store.

If earlier late base plus 0x54 aliases newly selected base plus 0x74, the word-100 store precedes the fourth-argument read. With ordinary stable storage, that read therefore observes 100. Reading it before the store fails the specified ordering.

Likewise, if the final-base offset-9 byte store overlaps the last destination’s offset-0x54 word, it occurs before that word store, not after it.
