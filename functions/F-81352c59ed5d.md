### 1. Initial writes

The routine performs these operations in order:

1. Writes the first argument’s low byte eight bytes beyond the first incoming unsigned address.
2. Writes the second incoming unsigned quantity’s low byte six bytes beyond the address represented by that same quantity.
3. Writes the second argument through the incoming four-byte pointer.
4. Forms a 32-bit mask: all ones when bit six of the first incoming unsigned quantity is clear, otherwise zero.
5. Writes that mask as a 32-bit word at third-argument byte offset four.
6. Writes the first incoming unsigned quantity’s low byte at byte offset four from the incoming four-byte pointer.
7. Writes the mask’s low halfword at third-argument byte offset two.
8. Assigns the low 16 bits of the third argument’s pointer representation to shared pointer-fragment storage.
9. Reads the third argument’s first unsigned halfword and uses its unsigned numerical value as the destination of a 32-bit write.

The final write’s payload is the bitwise intersection of the second incoming unsigned quantity and the first argument shifted left by four. The signed shift’s validity and overflow behavior are unresolved.

The destination halfword is read after the earlier writes. Aliasing may therefore change it before it determines the destination. The pointer-fragment assignment uses pointer-representation bits, not pointed-to data.

### 2. Dependency-associated captures and early termination

## Acceptance examples

These are conditional static consequences, not observed execution results. Each assumes that its relevant prefix is reached and all necessary accesses succeed.

1. **Mask selection.** If bit six of the first incoming unsigned quantity is clear, third-argument offset four receives the word 0xffffffff and offset two receives the halfword 0xffff. If the bit is set, both receive zero. Later aliases may overwrite either result.

2. **Halfword-derived destination.** If the first halfword actually read through the third argument is 0x1234, the masked word write targets address 0x00001234. The third argument’s pointer upper bits do not supply this address.

3. **Independent termination and fragment.** If the first F-e47d7b2e9c88 capture is interpreted as negative and the third read converts to signed value one, the fragment is zero. Its offset-four write still precedes early termination.

4. **Signed-halfword reduction.** Assuming arithmetic right shift, a captured signed halfword with bit pattern 0x7fff produces zero at derived-base offset eight; bit pattern 0x8000 produces 0xffffffff.

5. **Unknown instruction-exception storage.** If the incoming offset’s low eight bits are 0x34, the assignment expression is the unsigned eight-bit value 0x34. This alone establishes neither a byte-sized store nor the value of a later read.

6. **Fresh unsigned-16 conversion.** If the fresh instruction-exception read converts to unsigned-16 value 0x1278, that is the expression assigned to the overlapping object—not 0x0078. This example requires a read type and value permitting that conversion; those properties are undocumented.

7. **Low-eight-bit concatenation.** If the later instruction-exception read has low eight bits 0x78, the 24-bit construction is 0x000578, regardless of its higher bits. Conversion to the undeclared destination remains separate.

8. **Distinct later dependency captures.** If the first F-8afdaab91693 capture is 16 and the second read yields 20, with suitable arithmetic semantics, the zero-word destination is 128 and the shifted payload is 80.

9. **Publication reread.** If the publication read after the preceding write yields a value whose addition and address conversion produce 0x3004, the incoming signed offset is written there. An earlier destination does not fix this address.

10. **Shared-input boundary.** If the shared-input read converts to signed 32-bit value three, its multiplication by four produces twelve without overflow. This establishes neither a four-byte source read nor the source object’s width.

11. **Invalid destination.** If the halfword-derived destination is unwritable, no visible validation intervenes before the attempted word write. The platform response remains outside this contract.
