## Acceptance examples

These examples are conditional static acceptance criteria, not observed executions.

1. **Entry write precedes calls.** With A = 3 and a valid writable destination, the first represented memory effect writes word value 3 to address 32. The first indirect call follows it.

2. **Repeated write is retained.** If the initial calls return, the write of A to \(4A+20\) occurs again before the next scaled-result call, even if the address and value are unchanged.

3. **Third-argument shift is cumulative.** With P = 16,384, the fourth argument of the call preceding write 6 is 1, not 128.

4. **Selector is unsigned and supplies the destination component.** A selector value of 255 produces destination 272, not \(B+272\) and not a sign-extended negative destination.

5. **Selectors are reread.** If successive reads at \(B+1\) yield 4 and 9, the corresponding writes target 21 and 26.

6. **Byte truncation is observable.** With X = 65, the first selector-based byte write stores 4: the shifted value is 260, and only its low byte is written.

7. **Word writes 13 and 14 are distinct.** With \(R_8=2\), both target address 52. They write 8 and then 32, separated by dependency calls.

8. **First iteration uses the initialization result unchanged.** If I = 5, the first leading loop call receives first argument 5, not 20. Its second argument is zero.

9. **Later iterations scale the final result.** If a completed iteration’s final result Z is 3, the next leading call receives first argument 12. Q is separately \(3\) shifted left by 26 bits, and its right-shifted second argument is 786,432. These values do not require signed overflow.

10. **Q does not derive from the scaled first argument.** Under 32-bit wrapping semantics, Z = 65 produces next first argument 260, Q = 67,108,864, and next second argument 262,144. Shifting 260 left by 26 bits would incorrectly form Q.

11. **Selector source remains fixed in expression.** Loop return values may change call arguments, but do not replace K. Each loop selector read still uses \(1024K+1\).

12. **No success return is invented.** If calls return and accesses succeed indefinitely, the represented procedure continues looping rather than returning normally.
