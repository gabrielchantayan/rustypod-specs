# F-98270ff18940

## Purpose

After dispatch returns, it clears an entry-time marker location and conditionally performs an additional completion sequence.

## Behavior

It then separately accesses that global pointer to obtain the destination for a write of byte value 1. The initial write is not expressed through the retained address.

These are distinct pointer accesses:

- The first supplies the retained destination for the eventual clear.

Without an explicit stability assumption, the two accesses must not be contracted into a single pointer snapshot. If they produce different addresses, the initial set and later clear affect different locations.

### 4. Content selection

- Does not locally write the object’s field at +0xDC.
