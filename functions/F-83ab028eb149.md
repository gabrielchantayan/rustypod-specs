## Acceptance examples

These examples are conditional consequences of the static representation, not executed tests. They assume execution reaches the stated effects and the relevant writes succeed.

### Fourth argument used as both address and byte value

Let D be hexadecimal 0x1234, with the necessary arithmetic representable.

The first store writes A at hexadecimal address 0x1248. The byte value derived from D is 0x34: it is written once at 2X + 21 and twice at Z + 21.

Writing all 32 bits of D at those latter destinations would violate their explicit one-byte widths.

### Intermediate overwrite within a group

Let X = 1 and consider group 5.

At decimal address 28, the group first writes byte 2 and then byte 8. Both writes are part of the represented behavior.

This is not a claim that address 28 contains 8 at completion. Decimal 28 is hexadecimal 0x1C: although no zero assignment starts there, an assignment beginning elsewhere could overlap it, depending on the unresolved widths.

### Three byte writes followed by a later zero

Let X = 1 and consider group 9.

The destination 32X + 30 is decimal address 62. That group writes bytes **8, 8, and 128**, in that order. The repeated write of 8 remains a separate represented effect.

Decimal 62 is hexadecimal 0x3E, the explicit starting address of the last fixed-address zero assignment. If execution reaches that assignment and it succeeds, it writes zero at address 62. This consequence does not depend on knowing its width; the width uncertainty concerns additional affected bytes.

Thus the earlier three-write sequence and the later zero overwrite must both be retained. Neither a final value of 128 nor a single zero write fully describes the represented sequence.

### Collapsed scaled destinations

Let X = 0.

All byte values derived from X are zero. Destinations based solely on scaled X reduce to their additive offsets, decimal 21 through 31. Several writes therefore share addresses.

The represented byte-store count remains 31. The write at 2X + 21 still stores low8(D), not necessarily zero. Writes based on D, Y, and Z remain governed by those separate inputs and may introduce further aliasing.

### Abnormal completion and failure

Even if every memory write succeeds, acceptance must not require a normal return: none is represented.

If an earlier write faults and execution stops, acceptance must not require later writes or rollback of earlier effects. Neither continuation after a fault nor rollback is established.
