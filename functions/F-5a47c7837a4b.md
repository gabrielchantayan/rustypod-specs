### Final branch and memory write

Divide the 64-bit result into a low word, bits 0–31, and a high word, bits 32–63.

The function returns without its final direct store if both conditions hold:

- The low word is nonzero.
- High-word bit 14 is clear.

High-word bit 14 is bit 46 of the complete 64-bit result. Other bits of the low word affect only whether that word is zero.

In every other case, the function obtains the final-state base and writes a 32-bit value at the destination represented as four bytes beyond that base. The written value is the high word with bit 14 cleared, equivalently the high word masked by `0xffffbfff`.

Consequences:

- A zero low word always selects the store.
- A set bit 46 always selects the store.
- A nonzero low word with bit 46 clear suppresses the store.
- The low word is never the stored value.
- The old destination value is not explicitly read or merged into the store.
- Clearing bit 14 preserves the other 31 high-word bits.

The final-state base is used after F-d2bc4a2e390c returns and after the branch selects the store. It must not be treated as an address captured before that call.
