# F-23cfa9601de8

## Purpose

A matching total selects an ordered sequence of one or two processing calls. The first nonzero processing result is stored in the state’s status field. A mismatching total selects two different dependencies and performs no direct status write.

The established contract concerns memory accesses, argument values, call ordering, and conditional status recording. Interpreting the quantities as lengths, the opaque input as a data source, or nonzero results as errors is inferred intent, not an established interface guarantee.

## Behavior

The first direct state access reads the 32-bit status at offset +4.

If the value is nonzero, the function returns immediately. On this path it does not read either quantity, evaluate the mismatch-path globals, invoke a dependency, or perform a direct store.

Any nonzero status selects this path, including negative values.

If the status is zero, execution continues. The function does not subsequently recheck the status before either processing call or before recording a nonzero result.
