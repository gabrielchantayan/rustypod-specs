# F-327ce44d90ef

## Purpose

F-327ce44d90ef conditionally writes two adjacent bytes associated with its first argument, then invokes a final dependency with the original first and second arguments. If execution reaches the final dependency and that dependency returns normally, this function returns the 32-bit value 1.

Each possible byte write is controlled by a query constructed using mutable copies of the third and fourth arguments. When a query returns nonzero, a separate construction using mutable copies of the first and second arguments supplies the input for obtaining the byte to store.

The apparent purpose is to refresh two optional byte-valued properties before a final operation. This is **inferred intent**, not an established interpretation of the data. The established contract consists of the conditional calls, state captures, selector reads, byte writes, and return behavior below.

## Behavior

### Entry state and argument copies

The function reads State A at entry and retains that base address before testing the second argument. This entry read occurs even when updates are disabled.

All four arguments are copied into mutable local slots. The copies are not restored between phases. A dependency that changes a supplied slot may therefore affect inputs observed by a later construction or paired call.

The original first and second arguments remain distinct from these exposed copies. Changes to the copies do not redirect the function’s direct destination writes, alter the original enable decision, or replace the arguments supplied to the final dependency.

### Updates disabled

If the original second argument is zero, neither update phase executes. There are no State B reads, selector-field reads, construction calls, query calls, byte-producing calls, or paired calls attributable to those phases.

The function proceeds to F-876f4b90d114 with the original first and second arguments. If that call returns normally, the function returns 1.

F-9b9c1c7483f4 receives, in argument order:

- The address of the fourth-argument local copy.
- The 32-bit selector just read.
- The address of the third-argument local copy.

After this construction returns, the function performs **two separate reads of State B**:

- The first read is retained for later query and byte-producing calls.
- The second read supplies the first argument of the first F-8094c3d72052 call.

The other argument to that query call is the 32-bit construction result. No intervening dependency call is shown between the two State B reads. Nevertheless, the reads are distinct; their equality is not established without a stability assumption.

After the query returns, F-8a5aadac202f receives the address of the fourth-argument local copy. Only after this paired call returns does the function test the saved 32-bit query result against zero.

### First enabled byte update

F-9b9c1c7483f4 receives the address of the second-argument local copy, that freshly read selector, and the address of the first-argument local copy.

The resulting 32-bit value is supplied to F-cf946f91e683 together with the **retained value from the first State B read**. This is not necessarily the State B value used by the first query.

The byte write precedes this paired call. No rollback of the write is established if the paired call fails to return normally.

### Second query and enabled byte update

The function reads the 32-bit selector at offset 0x10 through the entry-captured State A base. F-9b9c1c7483f4 receives the address of the fourth-argument local copy, that selector, and the address of the third-argument local copy.

These are conditional static acceptance criteria, not executed tests. Except where stated otherwise, accesses are valid and dependencies return normally.

1. **Updates disabled.** With the original second argument zero, expect one entry read of State A, no State B or selector reads, no conditional-phase calls, and no direct byte writes. The final dependency receives the original first argument and zero. Normal completion returns 1.

The 0xB1 write precedes its paired call and the final operation. Both byte-producing calls use the retained first State B read.

Both possible byte-producing calls and the second query receive the first value. No intervening dependency call is required by this criterion, and no equality assumption may collapse the reads.

6. **State B changes during dependencies.** A change made by the first construction can affect both subsequent reads. A change made after those reads does not replace the retained value used by later calls. The first query’s own global side effects do not cause a further State B reload.
