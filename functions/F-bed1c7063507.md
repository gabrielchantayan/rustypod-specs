## Behavior

### Established transformation

Let the value obtained by the state-word read be the original word. The function clears bit 1 of that value using the 32-bit mask `0xFFFFFFFD`.

It then determines the replacement bit from the input:

- If the input is zero, bit 1 remains clear.
- If the input is nonzero, bit 1 is set using the mask `0x00000002`.

The resulting 32-bit word is written to the designated state location.

This is replacement, not toggling. Repeating a call with the same zero/nonzero classification produces the same stored value if the referenced object and its other bits remain unchanged between calls.

The transformation is entirely bitwise. There is no arithmetic increment, decrement, multiplication, signed negation, or input-dependent address calculation. Consequently, the input’s magnitude does not create an arithmetic-overflow case in the shown behavior.

### Observable order

The supplied source establishes the following logical order:

1. Obtain a 32-bit value from byte offset 8 of the object designated by the global reference.
2. Derive a replacement value from that read and the input’s zero/nonzero classification.
3. Write the replacement as a 32-bit word at byte offset 8 of the object designated by the global reference used for the write.
4. Return a 32-bit zero.

The state-word read precedes the state-word write. The write is unconditional: an already-clear bit is still written for zero input, and an already-set bit is still written for nonzero input. There is no visible early return that skips the write because the result equals the original word.

### Preservation boundary

For example, if another actor changes bit 5 after this function’s read, the subsequent full-word write can overwrite that change with the previously read bit-5 value. The shown operation provides no synchronization or atomic read-modify-write guarantee.
