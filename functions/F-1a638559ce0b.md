# F-1a638559ce0b

## Purpose

F-1a638559ce0b programs a globally addressed block using a supplied address-like value, a quantity, two selectors, and a 16-bit discriminator read from a caller-supplied object.

Its established behavior is a fixed sequence of field writes and control-word read-modify-write operations. One selector chooses between two ordinary field pairs; the other selects an alternative address-only field. Both selectors also affect control bits, including when the ordinary field pairs are bypassed.

The field arrangement and control operations suggest hardware or device-state configuration. That interpretation is **inferred intent**, not an established interface guarantee. The supplied evidence does not identify a device, establish transfer units, or prove that any operation starts a transfer.

## Behavior

### 1. Capture the block base and mask the address

The function captures the global block base before performing block writes.

It reduces the address value to its low 31 bits using mask `0x7FFFFFFF`. This is bit clearing, not validation or saturation. For example, `0x80000001` becomes `0x00000001`, and `0xFFFFFFFF` becomes `0x7FFFFFFF`.

The original high bit is never stored by this function.

### 2. Write the selected address and optional shifted quantity

The alternate selector has precedence over the direction selector for this stage.

**Alternate selector zero, direction selector zero:**

1. Write quantity shifted left by 9 to offset `0x40`, using the additional global-base reference.
2. Write the masked address to offset `0x3C` of the captured block.

**Alternate selector zero, direction selector nonzero:**

1. Write quantity shifted left by 9 to offset `0x48`, using the additional global-base reference.
2. Write the masked address to offset `0x44` of the captured block.

**Alternate selector nonzero:**

1. Write the masked address to offset `0x88`, using the additional global-base reference.
2. Do not perform either ordinary shifted-quantity write or either ordinary address write.

Thus the ordinary cases write the shifted quantity before the address. The alternate case writes only an address at this stage.

The direction selector remains significant in the alternate case because it is used later to configure control bit 4.

### 3. Write the common quantity-derived field

After the selected field writes, write the quantity multiplied by 512, minus 1, to offset `0x34` of the captured block.

This write occurs in every branch, including the alternate case.

For nonnegative quantities from 0 through 4,194,303, both quantity expressions fit the relevant signed 32-bit limits without overflow. Within that range:

- A quantity of 0 yields a shifted quantity of 0 and a common value of −1.
- A quantity of 1 yields 512 and 511.
- A quantity of 2 yields 1,024 and 1,023.
- A quantity of 4,194,303 yields 2,147,483,136 and 2,147,483,135.

Negative quantities and larger positive quantities require an established arithmetic model. The evidence does not justify silently treating all such cases as defined modulo-\(2^{32}\) arithmetic.

### 4. Read the object discriminator and apply the first control mask

Only after the common quantity write does the function read the 16-bit discriminator at object offset `0x24`.

It then reads the control word at block offset `0x18` and writes back:

- The read value with mask `0x00000408` ORed into it, if the discriminator is zero.
- The read value with mask `0x0000060C` ORed into it, if the discriminator is nonzero.

Both masks set bits 10 and 3. The nonzero-discriminator mask additionally sets bits 9 and 2.

A zero discriminator does **not** explicitly clear bits 9 or 2. Their existing values survive this stage.

### 5. Clear control bits 8 and 7

The function reads the control word again and writes back the value ANDed with `0xFFFFFE7F`.

This clears bits 8 and 7. It is a distinct read and write, not merely part of a combined final-value calculation.

### 6. Set control bit 4 from the direction selector

The function reads the control word again.

- If the direction selector is zero, it clears bit 4 using mask `0xFFFFFFEF`.
- If the direction selector is nonzero, it sets bit 4 using mask `0x00000010`.

It writes the result back to the control word.

### 7. Optionally set control bit 12

If the alternate selector is nonzero, the function performs one more control-word read and writes back the value with bit 12 set using mask `0x00001000`.

If the alternate selector is zero, this stage performs no read or write. In particular, it does not clear bit 12.

### Final control-state summary

If control reads return the preceding stored state and there are no external changes or special register semantics, the final control word has these properties:

| Bits | Final effect |
|---|---|
| 10 and 3 | Set |
| 9 and 2 | Set for a nonzero discriminator; otherwise preserved |
| 8 and 7 | Cleared |
| 4 | Cleared for a zero direction selector; set otherwise |
| 12 | Set for a nonzero alternate selector; otherwise preserved |
| All other bits | Preserved |

This summary is conditional. It does not replace the ordered access contract.

## Side effects

The function performs:

- Two selected block writes in an ordinary case, or one in the alternate case.
- One common quantity-derived block write.
- One 16-bit object read.
- Three control-word read/write pairs when the alternate selector is zero.
- Four control-word read/write pairs when the alternate selector is nonzero.

There are therefore six block writes in each branch: ordinary cases have three data-field writes and three control writes; alternate cases have two data-field writes and four control writes.

The updates are sequential, not transactional. Intermediate control values may be observable. No explicit locking, barrier, rollback, or completion wait is visible.

If an access fails during execution, earlier writes may already have occurred. The function contains no explicit recovery or status reporting. The platform’s fault behavior is not established.

Aliasing matters. If the object field overlaps previously written storage, the discriminator read occurs after those writes and may observe their effects. Likewise, if the global base changes between its initial capture and its additional reference, the first selected write may target a different block.

The function itself does not write ordinary field pairs in alternate mode, clear the alternate address field in ordinary mode, or reset unselected fields. Whether accessed registers cause additional hardware side effects is unknown.

## Acceptance examples

These examples are **conditional static acceptance criteria**, not executed tests. Unless stated otherwise, they assume one stable block base, ordinary read/write storage, no concurrent mutation, valid accesses, and quantities within the defined arithmetic range.

### Ordinary zero-direction case

Given an address value of `0x80000005`, quantity 2, both selectors zero, a zero discriminator, and an initial control word of zero:

- Offset `0x40` receives 1,024 before offset `0x3C` receives `0x00000005`.
- Offset `0x34` then receives 1,023.
- The discriminator is read.
- The successive control writes are `0x00000408`, `0x00000408`, and `0x00000408`.
- There is no write to offsets `0x44`, `0x48`, or `0x88`.

Repeated writes remain part of the contract even when their values are identical.

### Ordinary nonzero-direction case

Given quantity 1, a nonzero direction selector, a zero alternate selector, a nonzero discriminator, and an initial control word of zero:

- Offset `0x48` receives 512 before offset `0x44` receives the masked address.
- Offset `0x34` receives 511.
- The successive control writes are `0x0000060C`, `0x0000060C`, and `0x0000061C`.
- Control bit 12 is not explicitly changed.

Any nonzero direction value, including a negative value, selects this behavior.

### Alternate case

Given quantity 1, both selectors nonzero, a zero discriminator, and an initial control word of zero:

- Offset `0x88` receives the masked address.
- Neither ordinary field pair is written.
- Offset `0x34` receives 511.
- The successive control writes are `0x00000408`, `0x00000408`, `0x00000418`, and `0x00001418`.

This establishes that the direction selector still affects the control word in alternate mode.

### Preservation versus clearing

Given an initial control word of `0x00001384`, a zero discriminator, and both selectors zero:

- The first control write is `0x0000178C`.
- The second is `0x0000160C`, clearing bits 8 and 7.
- The third remains `0x0000160C`.

Previously set bits 9, 2, and 12 survive despite a zero discriminator and a zero alternate selector.

### Zero quantity

- Every case writes −1 to the common quantity-derived field, represented as `0xFFFFFFFF` in a 32-bit two’s-complement representation.
- No visible check rejects the quantity or bypasses control updates.
