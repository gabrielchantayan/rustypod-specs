# F-3f2c2a170c13

## Purpose

F-3f2c2a170c13 returns a signed 32-bit result derived from scalar inputs and a caller-supplied record. It has three cases: zero-valued equal endpoints, nonzero equal endpoints, and unequal endpoints. Only the unequal-endpoint case invokes F-870c4fcf7295.

The result depends on two accesses to the same record position: an initial value retained before case selection and a later value obtained during result formation. The contract must preserve that distinction. In particular, the dependency is not known to preserve the record or other shared state.

A possible interpolation-related purpose is **inferred intent**, not established behavior. Neither a division operation nor any particular rounding rule can be attributed to the dependency from the supplied evidence.

This is a static behavioral contract. Conventional fixed-width interpretations are stated conditionally; unresolved execution details remain `documented_only`.

## Behavior

### Case selection and intermediate value

Every case uses an initially retained value of Word B. Its access precedes case selection, any Word D access, and any dependency invocation.

The selection depends on whether the represented 32-bit difference between End and Start is zero. With representable signed subtraction, this is equivalent to endpoint equality. It is also equivalent under conventional modulo-32-bit subtraction. A strict signed-arithmetic interpretation does not establish behavior when that subtraction overflows.

| Case | Intermediate value | Dependency use | Other record positions used |
|---|---|---|---|
| Zero difference and End equal to zero | Zero | None | None |
| Zero difference and End nonzero | A signed 16-bit reduction of the difference between narrowed Word D and narrowed initial Word B | None | Word D |
| Nonzero difference | A signed 16-bit reduction of the dependency result | Exactly one invocation, if execution reaches and completes it | Words A, C, and D |

In the zero-valued endpoint case, Position has no effect. Words A, C, and D need not be read. Nevertheless, the result is not unconditionally zero: the later Word B access still contributes to it.

In the nonzero equal-endpoint case, Word D and the retained Word B are each interpreted through signed 16-bit narrowing before subtraction. Their mathematical difference can range from −65,535 to 65,535. That difference is itself stored as signed 16-bit before being extended into the 32-bit working result.

Consequently, operand narrowing and result narrowing are distinct parts of the behavior. Under low-bit narrowing, this case retains the low 16 bits of the difference and interprets them as signed. It does not clamp an out-of-range difference.

The first argument is represented using 32-bit operands without visible widening to a 64-bit product. Replacing it with an unlimited-precision product would add behavior not established by the evidence.

The third and sixth arguments originate from the same retained value. Neither requires another Word B access during argument preparation.

The fourth and seventh positions contain separate Word C access expressions. The evidence does not establish their relative evaluation order or require them to observe equal values if storage can change. It also does not establish a particular physical load count after compilation.

No ordering is established among the Word A, Word C, and Word D accesses used to prepare the call. They follow the initial Word B access and must supply their argument values before the dependency executes.

The dependency’s result is narrowed into signed 16-bit storage and then extended into the 32-bit working value. Its complete return value is not carried forward unchanged. The dependency’s return type and the precise treatment of an out-of-range return value remain unresolved.

### Result relationship

After the selected intermediate is available, the function accesses Word B again.

The result combines the intermediate with the initial Word B value minus this later Word B value. The represented final transformation multiplies that combined quantity by 65,536 and shifts the result right by 16 positions.

Under conventional 32-bit wraparound and arithmetic right shift, this transformation retains the combined quantity’s low 16 bits and returns their signed interpretation. It is neither saturation nor validation.

Two consequences are important:

- If the two Word B accesses observe the same value, their contribution cancels.
- If the later value differs, the result includes the negative of that change, subject to the final 16-bit reduction.

The later access cannot be replaced by the retained value merely because the Record address is absent from the dependency’s explicit arguments.
