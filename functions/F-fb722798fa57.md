# F-fb722798fa57

## Purpose

F-fb722798fa57 performs an unconditional repeating sequence of indirect calls, fixed-width memory accesses, arithmetic transformations, and a software breakpoint.

The established behavior is this ordered sequence. No higher-level purpose, such as initialization, scheduling, device control, or data conversion, is established. In particular, the use of zero-extended 16-bit values as addresses and the storage of truncated pointer values must not be replaced by more conventional interpretations.

There is no represented normal return. Progress depends on preceding dependencies returning, memory accesses completing, and execution continuing after the breakpoint.

## Interface

### Entry, exit, and ambient state

The represented interface has no declared parameters and no returned value. It nevertheless depends on:

- An incoming link-like value used to select the first call target.
- A working-base register used for several memory accesses and explicitly decreased during each iteration.
- Another incoming register value used in a late byte-store address.
- Two pointer-valued global slots.
- Memory reached through fixed addresses, captured pointers, call results, and arithmetic-derived addresses.
- Additional machine-level inputs potentially consumed by indirect calls.

There is no explicit error result, validation path, cleanup path, or loop exit.

## Behavior

### Initial dispatch and captured-pointer writes

Each iteration begins by resetting two byte-sized temporaries to zero. One supplies the extra term in F-D06’s second argument; the other supplies the later zero byte store.

F-D01 is invoked with two zero arguments at the target selected by **L + 0xFFE**. F-D02 and F-D03 follow, in that order, without explicit arguments.

After F-D03 returns, the function reads the 32-bit value in **G-A** and captures it as **P**. F-D04 then runs. F-D05 follows and supplies a represented 64-bit result, divided into lower half **A** and upper half **H**.

F-D06 receives **A** as its first argument. Its second argument is the represented 32-bit sum of **H**, **A**, and the explicitly zero byte term. There is no established nonzero carry input. F-D05 and F-D06 select the same target address despite their different represented call-site interfaces.

After F-D06 returns, an auxiliary byte output associated with that call is stored at **P + 0x11**. F-D07 then runs, followed by an explicit zero-byte store at **P + 0x15**.

F-D08 supplies a represented 16-bit result. That result is stored at offset **0x0C** from an auxiliary pointer output associated with F-D08. Neither auxiliary-output mechanism has an established ABI contract.

### First split result, base-relative accesses, and breakpoint

F-D09 supplies a represented 64-bit result, retained as lower half **X** and upper half **Y**. Before the next call, the function stores:

- A 16-bit zero at **Y + 0x2C**.
- The 32-bit value **X logically shifted right by 26** at **B + 0x26C**.

The second value is necessarily between 0 and 63.

After F-D10 returns, a 32-bit pointer is read from **B + 0x320** and captured as **Q**. F-D11 and F-D12 then run. The function subsequently stores **X shifted left by 2**, with unsigned 32-bit truncation, at **Q + 0x54**.

F-D13, F-D14, F-D15, F-D16, and F-D17 run in order. F-D13 selects the same target as F-D09, but this call site does not explicitly consume a result.

An unsigned 16-bit read from absolute address **0x21C48994** supplies **U**. F-D18 then runs. A 32-bit read from **B + 0x280** supplies the explicit argument to F-D19; its represented 32-bit result is retained as **I**.

A software breakpoint with immediate **0x92** follows F-D19. There is no represented branch around it. Every subsequent action is conditional on execution continuing beyond it.

### Indexed halfword writes

After the breakpoint, the function forms the four-times-scaled **I** and derives a second value from the constant **0x21C48960** by logical right shift through 18 positions, followed by multiplication by four. The latter value is exactly **0x21C4**.

A 32-bit pointer read from **U + 0x44** is captured as **T**, before F-D20 runs.

F-D21 then supplies a represented 32-bit result. After that call returns, the function reads a 32-bit value from **U + 4**. F-D22 receives the retained F-D21 result first and the newly read memory value second.

The function next captures the 32-bit value in **G-B** as **V**. F-D23 runs before a halfword store to **V + 4 × I**. The payload is the low 16 bits of **V** itself—not a value read through **V**.

F-D24 then runs. It selects the same target as F-D17. A 32-bit pointer is subsequently read from absolute address **0x2218**, the sum of **0x21C4** and **0x54**, and retained as **W**.

F-D25 supplies a represented 32-bit destination pointer. A halfword store writes **0x21C4** at offset four from that destination.

After F-D26 and F-D27 run, an unsigned 16-bit read from **W + 0x34** supplies **N**. Both **U** and **N** remain zero-extended 16-bit quantities even when used for addressing.

### Final split result and working-base transition

F-D28 supplies a represented 64-bit result, retained as lower half **J** and upper half **K**.

The function first stores **J** as a 32-bit value at **B + 0x258**. It then reads an unsigned 16-bit value from **K + 0x14**, retaining its zero-extended value as **Z**.

The subsequent address and payload calculations use **J shifted left by 6**, **4 × K**, and **4 × N**. The represented working base is explicitly decreased by **0xF4**, or 244 bytes. The earlier store at **B + 0x258** precedes this decrement.

A 32-bit store writes **J** at **4 × N + 0x74**. F-D29 then runs, followed by a 32-bit store of **Z** at **T + 0x54**. F-D30 runs next, followed by another 32-bit store of **Z**, this time at **T + 0x64**.

F-D31 selects the same target as F-D19. At this later site, no explicit arguments are represented, and an auxiliary pointer-sized output contributes to the next store address. That halfword store writes the low 16 bits of **T** at the sum of this auxiliary output and **J shifted left by 6**.

F-D32 and F-D33 then run. F-D32 selects the same target as F-D25, but no explicit result is consumed here.

A byte is read from **N + 4 × N**, equivalently **5 × N**, and retained across F-D34. After F-D34 returns, that retained byte is stored at **Z + R + 0x19**. The source is not explicitly reread.

F-D35 follows. The function then stores **4 × K** as a 32-bit value at **T + 0x44**, before invoking F-D36.

Before F-D37, the represented link-like selector is assigned the fixed value **0x08712031**. A 32-bit value read from **4 × K + 0x44** is passed to F-D37. If F-D37 returns, execution repeats.

### Repetition and retained state

The represented loop contains no compensating increment of **B**, no restoration of written memory, and no exit condition.

The next iteration uses the assigned link-like selector rather than the original entry value. In the represented arithmetic, its F-D01 target expression consequently evaluates to **0x0871302F**.

The late byte read does not carry into the next iteration’s zero store at **P + 0x15**: that byte-sized temporary is explicitly reset at the iteration’s start.

## Side effects

### Direct effects and ordering

Direct effects include:

- Reads from both pointer-valued global slots.
- Base-relative word reads and writes.
- Pointer-relative byte, halfword, and word accesses.
- Fixed-address reads and accesses through zero-extended halfword values.
- Halfword stores containing truncated pointer values.
- A byte transfer with a dependency call between its read and write.
- An explicit decrease of the working base.
- A software breakpoint on every iteration that reaches it.

Memory aliasing is unrestricted by the supplied evidence. Different expressions can designate overlapping storage, and dependency effects can change memory read later. The specified ordering therefore matters.

A captured pointer is not implicitly refreshed from its originating global or memory slot. For example, changing **G-A** after **P** is captured does not introduce a new read of **G-A** before the two stores through **P**.

## Acceptance examples

These are conditional static criteria, not reported executions. They assume accessible memory, returning dependencies, defined arithmetic for the chosen values, and breakpoint continuation where required.

1. **Unsigned split-result shifts.** If **X = 0xFC000003**, the store at **B + 0x26C** writes 63, and the later store at **Q + 0x54** writes **0xF000000C**.

2. **Equal target, separate calls.** F-D05 and F-D06 must select the same target. F-D05’s result is obtained before F-D06 receives its derived arguments; equality does not collapse them into one invocation. The same target-equality requirement applies independently to F-D09/F-D13, F-D17/F-D24, F-D19/F-D31, and F-D25/F-D32.

3. **Zero-extended addressing.** If **U = 0xFFFF**, the read at **U + 0x44** addresses **0x10043**, not an address derived from negative one.

4. **Truncated pointer payload.** If **V = 0x12345678** and **I = 2**, the indexed halfword store addresses **0x12345680** and writes **0x5678**. It does not read a payload through **V**.

5. **Constant-derived access.** The pointer read before F-D25 addresses **0x2218**. The following halfword store writes **0x21C4** at offset four from F-D25’s result.

6. **Retained byte across a call.** If **N = 3**, **Z = 7**, and **R = 0x1000**, the byte source is address 15 and the destination is **0x1020**. A source-memory change during F-D34 does not cause an explicit reread.

7. **Breakpoint interruption.** If execution permanently stops at breakpoint **0x92**, none of the later accesses or calls in that iteration occurs.

8. **Base transition.** If **B = 0x10000** immediately before the store at **B + 0x258**, that store addresses **0x10258**. If **B** remains unchanged until its explicit decrement, the decrement produces **0xFF0C**. No restoration is represented afterward.

9. **Partial progress without rollback.** If F-D30 never returns, the preceding store at **T + 0x54** has occurred, while the subsequent store at **T + 0x64** has not occurred.
