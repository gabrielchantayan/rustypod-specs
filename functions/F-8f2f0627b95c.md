# F-8f2f0627b95c

## Purpose

F-8f2f0627b95c conditionally derives a position and a Boolean result from a byte sequence associated with a tagged input object. It also exposes a separate Boolean derived from a dependency-supplied flag byte.

The function has three distinguishable outcomes:

1. The input fails the initial structural gate.
2. The input passes that gate, but subsequent processing produces no accepted position.
3. Processing accepts a noninitial stopping position in the associated byte sequence and writes the position and Boolean result.

These outcomes are encoded in a 64-bit return value. Output arguments are not transactional: the flag-derived output can be written even when the function ultimately reports no accepted position.

This contract describes the supplied static evidence. Semantic interpretations such as “lookup,” “polarity,” or “sequence preparation” are descriptive labels, not established application-level meanings. No runtime tests have been performed.

### Return layout

The return value consists of two 32-bit halves:

| Outcome | Upper half | Lower half |
|---|---:|---:|
| Initial gate fails | Original input-object address | 0 |
| Initial gate passes, later processing does not succeed | 1 | 0 |
| Position is accepted and final outputs are written | 1 | 1 |

The original input-object address is zero-extended into the upper-half construction; this is not a sign extension of that address.

Passing the initial gate changes the upper-half result permanently to one for the remainder of this invocation. A later dependency failure does not restore the original address.

## Behavior

### 1. Initial gate

The function first reads the input tag.

Only if that tag matches 0x94 does it test the associated-record pointer at offset +16. Only if that pointer is nonzero does it read the associated record’s discriminator.

The gate passes exactly when all three conditions hold:

- The input tag matches 0x94.
- The associated-record pointer is nonzero.
- The associated discriminator equals 2.

On failure, no dependency is called and none of the three output locations is written by this function. The return has the original input-object address in its upper half and zero in its lower half.

### 2. Dependency result and flag qualification

After the gate passes, the function initializes an addressable 32-bit local word with the numeric value of the Boolean-output pointer.

It calls F-d92bc662c47a with six arguments, in this order:

1. Context.
2. Input word at offset +20.
3. Input unsigned word at offset +24, logically shifted right by one.
4. The value 2.
5. The value 1.
6. The value 0.

The right shift discards the original least-significant bit. It is an unsigned shift, not division with signed rounding.

A zero dependency result ends processing without direct output writes. A nonzero result permits a byte read at result offset +4.

If bit 0 of that flag byte is clear, processing ends without direct output writes. If bit 0 is set, processing continues.

The function then calls F-unmapped-01, a locally assigned opaque identifier for the external dependency whose stable identity was not supplied. Its arguments are:

1. Address of the local 32-bit word.
2. The 32-bit value at dependency-result offset +8.
3. The value 3.

The supplied evidence does not establish this dependency’s transfer semantics. In particular, a three-byte copy is a plausible interpretation of the call shape, not a proven contract.

After this call returns, the function computes a Boolean from the previously captured flag byte:

- Flag bit 1 clear: value 1.
- Flag bit 1 set: value 0.

Other flag bits do not affect this calculation. The function writes that value to the flag output before checking the candidate record or qualifier.

Consequently, later rejection does not imply that outputs remain unchanged.

### 3. Candidate and mode qualification

After writing the flag output, the function follows the input’s associated-record pointer and its word-array pointer to obtain the candidate record.

The candidate qualifies if either:

- Its first byte is 0x58; or
- Its first byte is 0x7F and its unsigned 32-bit field at offset +40 equals 0x58.

The second case does not replace the candidate pointer. Subsequent processing continues with the same record whose first byte was 0x7F.

A nonqualifying candidate ends processing.

For a qualifying candidate, the function obtains the qualifier pointer from word-array offset +12. The qualifier must have tag 0x95. Otherwise processing ends.

The qualifier’s pointer at offset +4 selects the mode-bearing record. If that pointer is zero, the function instead reads the pointer at context offset +44.

Mode qualification is:

| Mode byte | Required flag-derived value |
|---:|---:|
| 1 | 0 |
| 2 | 1 |
| Any other value | Never qualifies |

If the first mode-byte read is not 1, the source performs another mode-byte read to check for 2. No dependency call occurs between those reads.

When mode qualification passes, F-2ec6da92c04c is called with the context and the candidate-record pointer. Only after that call returns does this function read the sequence pointer at candidate offset +20.

A zero sequence pointer ends processing.

### 4. Sequence scan and acceptance

The scan uses the numeric contents of the local 32-bit word after the preceding dependency calls. It extracts three comparison bytes:

- Bits 0–7.
- Bits 8–15.
- Bits 16–23.

Bits 24–31 do not participate.

Starting at position zero, the function advances until the current sequence byte is either:

- Zero; or
- Equal to any of those three comparison bytes.

A byte of 0xFF does not independently terminate the scan. It stops the scan only if it matches one of the comparison bytes.

If the scan stops at position zero, processing fails without writing the position or Boolean outputs.

For a nonzero stopping position, the stopping byte is read again. A value of 0xFF rejects that position.

Every other stopping byte, including zero, is accepted.

The Boolean output is one exactly when both conditions hold:

- The accepted stopping byte equals the comparison byte from bits 0–7.
- The immediately following sequence byte is zero.

Otherwise the Boolean output is zero. The following-byte read occurs only when the first condition holds.

The function writes the Boolean output first, then writes the position output, and returns upper half one, lower half one.

A terminator reached after a nonempty prefix can therefore produce success even when none of the nonzero sequence bytes matched a comparison byte.

## Acceptance examples

These examples are conditional on valid memory, returning dependencies, and the stated state remaining available at each relevant read.

1. **Initial tag mismatch.**  
   With an input tag other than 0x94, the function returns the original input address in the upper half and zero in the lower half. It makes no dependency calls and no direct output writes.

2. **Gate passes, dependency returns zero.**  
   With a valid initial gate and a zero result from F-d92bc662c47a, the return halves are one and zero. None of the outputs is directly written.

3. **Qualifying flags, candidate rejected.**  
   If the captured flags are 0x01, F-unmapped-01 returns, and the candidate later fails qualification, the flag output is written as one. The position and Boolean outputs are not directly written. The return halves are one and zero.

4. **Mode selection.**  
   Captured flags 0x03 produce flag value zero and permit mode 1, but reject mode 2. Captured flags 0x01 produce flag value one and permit mode 2, but reject mode 1.

5. **Primary-byte match followed by terminator.**  
   Suppose the comparison bytes are 0x41, 0x42, and 0x43, and the sequence is 0x10, 0x41, 0x00. The accepted position is one. The Boolean output is one, and the return halves are one and one.

6. **Secondary-byte match.**  
   With the same comparison bytes and sequence 0x10, 0x42, 0x00, the accepted position is one, but the Boolean output is zero.

7. **Zero terminator after an unmatched prefix.**  
   With the same comparison bytes and sequence 0x10, 0x20, 0x00, position two is accepted. The Boolean output is zero.

8. **Immediate stop is rejected.**  
   If the first sequence byte is zero or matches any comparison byte, the stopping position is zero. No final Boolean or position write occurs.

9. **0xFF is not a universal sentinel.**  
   If no comparison byte is 0xFF, the scan can advance past 0xFF. If a comparison byte is 0xFF and it causes a stop at a nonzero position, that position is rejected.

10. **Primary comparison byte is zero.**  
    If bits 0–7 of the local word are zero and the scan reaches a terminator at a nonzero position, the function reads the byte after that terminator. The Boolean output is one only if that following byte is also zero.
