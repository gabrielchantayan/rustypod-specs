# F-92c7f255e8d7

The established operation is a bitwise update using the mask **0x00002000**. With a stable address and no intervening modification, the resulting word equals the original word with that bit set; all other bits retain their previous values.

## Behavior

### Established update

The function obtains a word from the address four bytes beyond the globally supplied base and combines that value with the mask 0x00002000 using inclusive bitwise OR. It writes the combined value to the destination at that same offset from the globally supplied base.

Under stable-address, ordinary-memory conditions, the update has these properties:

- Bit numbering starts at zero, so the affected bit is bit 13.
- Bit 13 is one after the write.
- Every other bit equals its value in the word read for this update.
- If bit 13 was already one, the computed value is unchanged.
- A store is still expressed when the computed value equals the value read.
- There is no arithmetic carry, signed comparison, or overflow-dependent behavior.

For a 32-bit word, the preservation property covers bits 0–12 and 14–31. The operation is not an increment and does not clear any bit.

### Read and write ordering

The target-word read supplies the value used to compute the target-word write. Consequently, that read must supply its value before the resulting write can occur.

The evidence does not establish the relative evaluation order of those address expressions or guarantee that the address source is fetched exactly once.
